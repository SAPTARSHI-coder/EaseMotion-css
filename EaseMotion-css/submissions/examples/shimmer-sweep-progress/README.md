# CSS Shimmer-Sweep Progress Bar

A modern **Shimmer-Sweep Progress Bar** built using **pure HTML and CSS**. It features a sleek minimalist design with a shimmering sweep animation, rounded progress track, and responsive layout—ideal for dashboards, loading indicators, and progress displays.

---

## ✨ Features

- ✨ Animated shimmer sweep effect
- 📊 Smooth gradient progress fill
- 🎯 Minimalist tech-inspired design
- 🎨 Easy customization using CSS variables
- 📱 Fully responsive
- ♿ Supports `prefers-reduced-motion`
- 🚫 No JavaScript required

## Usage

1. Open `demo.html` in a modern browser.
2. Change the progress value by adjusting the `.progress-fill` width.
3. Customize colors and sizing using the CSS variables.

---

## CSS Variables

```css
:root{
    --bg:#0f172a;
    --card:#1e293b;
    --track:#334155;
    --fill:#3b82f6;
    --fill-end:#06b6d4;
    --text:#ffffff;
    --muted:#cbd5e1;
    --radius:18px;
}
```
