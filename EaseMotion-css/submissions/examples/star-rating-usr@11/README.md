# Interactive Star Rating Submission

## 1. What does this do?
It provides a modern, accessible star rating component with multiple variants: basic 5-star rating, half-star precision, display-only ratings, and fun emoji ratings. All with smooth hover animations and pure CSS interactions.

## 2. How is it used?
Wrap radio inputs and labels in a `.star-rating` container. Use `.half-stars` class for half-star precision. For display-only ratings, use `.star-display` with `data-rating` attribute. Emoji ratings use `.emoji-rating` class.

## 3. Why is it useful?
- Essential component for e-commerce, review systems, and feedback forms
- Multiple rating styles: basic stars, half-stars, emoji, display-only
- Pure CSS hover animations (no JavaScript required for basic functionality)
- Smooth scale, color, and glow transitions
- Fully accessible with keyboard navigation and ARIA labels
- Includes `prefers-reduced-motion` support for accessibility
- Mobile-responsive design
- Easy to customize colors and sizes
- Maintainer can easily standardize this as `.ease-rating-[YOUR_INITIALS]` in the core library.
