Hover anywhere over the carousel card to pause the auto-rotation loop. Click the dot indicators below to switch slides manually.

Carousel Specifications

🔄

Auto-Rotation Keyframes

Employs infinite keyframe translation animations (`@keyframes autoRotate`) with seamless 12-second total cycle durations.

⏸️

Pause-On-Hover Physics

Uses `.slides-track:hover` to set `animation-play-state: paused`, allowing users to comfortably read quotes.

⭐

Staggered Star Rating

Features per-star staggered spring bounce animations (`--s: index`) when each card transitions into view.

♿

Reduced Motion Friendly

Automatically halts infinite auto-rotation and provides static tabbed navigation when reduced motion is preferred.
