# CSS Quantum Energy Shield Text Animation

A pure CSS science-fiction typography animation that encapsulates text inside a pulsating, multi-spectrum quantum energy shield barrier upon hover and focus.

## 🎯 Features
- **Pure CSS/HTML:** Zero JavaScript dependencies.
- **Hardware-Accelerated Glow & Shield:** Leverages pseudo-elements, multi-layered box-shadows, and radial gradients for smooth GPU rendering.
- **Dark Mode Compatible:** Tuned with vibrant quantum cyan (`#38bdf8`) and plasma purple (`#9333ea`) accents on deep void backgrounds.
- **Accessible & Responsive:** Fluid `clamp()` typography, `:focus-visible` keyboard states, and reduced motion fallbacks via `@media (prefers-reduced-motion: reduce)`.
