# Image Stack Hover

A tidy stack of photos that fans out into a splayed deck the moment you hover.

## Features
- Compressed stack relaxes into a fanned deck
- Each card rotates to its own angle on hover
- Depth via layered shadows and z-index

## Usage
```html
<div class="is-stack">
  <div class="is-card s1"></div>
  <div class="is-card s2"></div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
