# Typewriter Hero

A hero tagline that types itself character by character with a blinking caret.

## Features
- Characters reveal one at a time
- Blinking caret at the typing edge
- Loops the message for a continuous show

## Usage
```html
<p class="tw-line">SHIP AT THE SPEED</p>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
