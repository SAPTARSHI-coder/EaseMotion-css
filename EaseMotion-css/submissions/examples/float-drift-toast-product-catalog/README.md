# Float-Drift Toast Product Catalog

A lightweight product catalog showcase featuring a CSS Float-Drift Toast
interaction.

The example uses only HTML and CSS and requires no JavaScript or external
framework.

## Features

- Pure HTML and CSS
- Float-drift toast animation
- CSS keyframe animation
- Smooth transitions
- Responsive product grid
- Desktop, tablet, and mobile support
- Keyboard focus support
- `prefers-reduced-motion` support
- CSS custom properties
- No external dependencies
