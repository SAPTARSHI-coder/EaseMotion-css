# Parallax Footer with Neumorphism

A responsive footer component featuring a clean neumorphic design with subtle
parallax-inspired decorative elements.

## Features

- Fully responsive layout
- Neumorphic UI design
- Parallax-inspired decorative elements
- Hover animations
- Mobile-friendly
- Pure HTML and CSS
- No JavaScript required
- Easy to customize

## Technologies Used

- HTML5
- CSS3
