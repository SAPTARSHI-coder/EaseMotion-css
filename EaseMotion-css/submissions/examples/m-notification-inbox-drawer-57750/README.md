# Notification Inbox Drawer

A responsive **Notification Inbox Drawer** built with HTML, CSS, and lightweight JavaScript for the EaseMotion CSS examples collection.

## ✨ Features

- Slide-in notification drawer
- Drawer backdrop overlay
- Animated unread badge
- Swipe/dismiss notification animation
- Filter tabs (All, Unread, Mentions)
- ESC key support
- Responsive design
- CSS Custom Properties
- `prefers-reduced-motion` support

## Usage

Open `demo.html` in a modern browser.

---

## Features Included

- Drawer opens from the right
- Click overlay or ✕ button to close
- Press **Esc** to close
- Dismiss notifications with slide-out animation
- Animated unread badge
- Responsive mobile layout
