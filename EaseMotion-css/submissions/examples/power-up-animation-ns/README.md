# CSS Power Up Animation (#71000)

A gaming-inspired power-up animation component featuring spring pop-in entrance effects, 360-degree rotational ring spinning, glowing aura pulses, and idle floating bobs using pure CSS.

## Features
- Multi-stage CSS `@keyframes` sequence (`ease-powerup-pop`, `ease-powerup-float`, `ease-ring-spin`, `ease-aura-pulse`).
- Soft drop-shadow glow filters paired with blurred background auras.
- Responsive grid layout with hover and keyboard focus states.
- Accessibility support including `role="img"`, `tabindex="0"`, and `prefers-reduced-motion` safety fallbacks.
