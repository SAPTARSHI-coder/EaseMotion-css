# Infinite Seamless Logo Carousel

A compact, mobile-first logo carousel component with a continuously scrolling,
seamless animation and pause-on-hover interaction.

## Features

- Infinite seamless scrolling
- Pause animation on hover
- CSS-only animation
- Responsive mobile-first design
- Modern glassmorphism cards
- Gradient logo accents
- Keyboard-friendly semantic markup
- Reduced-motion accessibility support
- No external dependencies
