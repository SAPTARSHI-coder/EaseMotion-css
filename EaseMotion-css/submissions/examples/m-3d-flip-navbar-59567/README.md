# CSS 3D-Flip Navbar for SaaS Showcase Layouts

A modern **3D-Flip Navbar** built using pure HTML and CSS. The navigation bar enters with a smooth 3D flip animation and features a premium glassmorphism design suitable for SaaS landing pages and dashboards.

## ✨ Features

- Pure HTML5 & CSS3
- 3D flip entrance animation
- Glassmorphism navbar
- Responsive layout
- Gradient CTA button
- CSS Custom Properties
- `prefers-reduced-motion` support
- No JavaScript required
