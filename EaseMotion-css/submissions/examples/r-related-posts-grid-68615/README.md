# CSS Related Posts Grid

A responsive, pure CSS related-posts grid for displaying article
thumbnails, titles, categories, descriptions, and estimated reading
times.

## Features

- Pure HTML and CSS
- Responsive three-column grid
- Tablet and mobile layouts
- Article thumbnail areas
- Category badges
- Read-time metadata
- Hover lift interaction
- Animated decorative thumbnail elements
- Keyboard-focus styling
- Reduced-motion support
- No JavaScript required
