# Scroll Progress Scroll Offset Calc - Edge Case Assertions

A comprehensive Vitest test suite and demo for **Scroll Progress Scroll Offset Calc** edge cases.

## Features

- 📜 Accurate scroll progress percentage calculation
- 🛡 Division-by-zero protection (`maxScroll <= 0`)
- 🎯 Boundary clamping for negative scroll elastic bounce and overscroll values
- 📊 Precision decimal formatting support
