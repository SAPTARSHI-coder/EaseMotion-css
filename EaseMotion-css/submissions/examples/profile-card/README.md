# Profile Card

1. What does this do? A developer profile card with a rotating gradient avatar ring, name, role, bio, skill chips, and Follow/Message actions.
2. How is it used? Build a `.profile-card` with a `.profile-card__avatar-ring` wrapping a `.profile-card__avatar` (initials), then `.profile-card__role`, `.profile-card__bio`, a `.profile-card__skills` list of chips, and `.profile-card__actions` with `.profile-card__cta` and `.profile-card__ghost` buttons. Customize colors and hover speed via `--prc-accent`, `--prc-ink`, `--prc-muted`, and `--prc-speed`.
3. Why is it useful? It gives a polished developer profile presentation with pure CSS (no images or JavaScript), a gently rotating avatar ring, and `prefers-reduced-motion` support.
