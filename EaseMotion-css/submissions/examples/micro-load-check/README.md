# Micro Load Check

A tiny action button that spins into a checkmark when its job is done.

## Features
- Spinner rings around the icon
- Loader morphs into a check
- Button tints green on success

## Usage
```html
<button class="mlc-btn">&#10004;</button>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
