# Friction Clutch Engage

## What does this do?
Renders a self-contained CSS-only `ease-friction-clutch-engage` demo: Automotive clutch plates engaging with pressure.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-friction-clutch-engage`. No build step or JavaScript is required for the effect.

```html
<section class="ease-friction-clutch-engage">
  <div class="ease-friction-clutch-engage__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
