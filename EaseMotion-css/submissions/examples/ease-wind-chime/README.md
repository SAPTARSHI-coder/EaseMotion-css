# 🔔 Wind Chime – Chimes Sway and Tinkle

> A calming wind chime component where chimes sway and tinkle with 4 tones (Gentle, Bright, Deep, Magical), wind control (0-10), and realistic sway physics.

---

## 📖 Description

The **Wind Chime** component creates a calming wind chime experience where chimes sway and tinkle in the breeze. Built with vanilla HTML, CSS, and JavaScript, it features 4 tones (Gentle, Bright, Deep, Magical), wind control (0-10), and realistic sway physics.

### 🎯 Core Features

- **Swaying chimes** – chimes sway with realistic physics
- **4 tones** – Gentle (🌸), Bright (✨), Deep (🌙), Magical (🪄)
- **Wind control** – adjust wind from 0-10 affecting sway
- **Clink effects** – chimes sparkle when they hit each other
- **Chime counter** – tracks number of chimes
- **Interactive controls** – wind slider, tone buttons, keyboard shortcuts
- **Responsive design** – adapts to different screen sizes

### ⌨️ Interaction Options

| Method | Action |
|--------|--------|
| **Slider** | Adjust Wind (0-10) |
| **Buttons** | Tone selection |
| **Keyboard** | `R` – Reset |

### ✨ Wind Chime Experience

When interacting:
1. **Chimes sway** – chimes move with wind physics
2. **Clink effects** – sparkles when chimes collide
3. **Wind applies** – controls sway intensity
4. **Tone applies** – changes chime colors and sizes
5. **Counter updates** – chime count in real-time

### 💡 Why Use This Component?

- Perfect for meditation apps, relaxation tools, or calming interfaces
- Calming wind chime experience with realistic physics
- Self-contained – no external dependencies or frameworks
- Easy to customize (colors, tones, wind behavior)
- 4 tones for variety
- Wind control for atmosphere

### 🛠️ Technologies Used

- **HTML5** – semantic structure with Canvas
- **CSS3** – gradients, backdrop-filter, transforms
- **JavaScript (ES6)** – Canvas API, requestAnimationFrame, physics simulation

### 🎨 Design Philosophy

This component embodies **EaseMotion CSS's animation-first philosophy** through:

- **Realistic physics** – chimes sway with wind
- **Clink effects** – sparkles on collision
- **Visual feedback** – status updates, counter, controls
- **Calming atmosphere** – gentle swaying and tones
- **Human-readable classes** – `.chime-controls`, `.tone-btn`, `.chime-text`

### 🔧 Customization Options

| Property | Location | Default |
|----------|----------|---------|
| Tones | `tones` object | 4 tones |
| Wind range | `windSlider` | 0-10 |
| Chime count | `generateChimes()` | 5-8 |
| Chime length | `length` | 60-120px |
| Sway speed | `swingSpeed` | 0.02-0.04 |
