# CSS Fade-In Tabs for Gaming Hub Layouts

## Overview

A lightweight CSS-only Fade-In Tabs component designed for gaming dashboards and modern UI layouts.

This component provides smooth fade animations when switching between different tab sections using only HTML and CSS.

---

## Features

- Pure HTML and CSS
- Smooth fade-in animation
- Responsive design
- No JavaScript required
- CSS custom properties
- Hover interactions
- Accessibility support with prefers-reduced-motion

---
