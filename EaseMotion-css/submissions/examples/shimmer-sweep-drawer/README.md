# CSS Shimmer-Sweep Drawer

A responsive portfolio drawer with a shimmer sweep hover animation built using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Responsive
- Smooth transitions
- Accessible
- Supports prefers-reduced-motion

## Files

- demo.html
- style.css

## Usage

Open `demo.html` in your browser.

## Customization

Modify CSS variables:

```css
:root{
  --drawer-bg:#111827;
  --drawer-text:#fff;
  --accent:#38bdf8;
  --duration:.5s;
}
