# Floating Card - Material Design

A responsive floating card inspired by Material Design elevation and
surface principles.

## Features

- Responsive layout
- Material Design inspired elevation
- Smooth floating hover animation
- Accessible keyboard focus states
- Dark mode support
- Reduced-motion support
- No external JavaScript
- No external dependencies
