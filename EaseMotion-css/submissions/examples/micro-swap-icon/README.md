# Micro Swap Icon

An icon button whose glyph flips, rotates and swaps with a spring on hover.

## Features
- Two stacked icons swap on hover
- Rotation + flip makes the swap obvious
- Background tint sweeps in behind

## Usage
```html
<div class="msi-btn">
  <span class="msi-icon a">&#128263;</span>
  <span class="msi-icon b">&#128483;&#65039;</span>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
