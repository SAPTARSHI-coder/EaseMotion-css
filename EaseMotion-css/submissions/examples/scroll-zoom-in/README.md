# Scroll Zoom In

A hero image gently zooms while the section scrolls out of view.

## Features
- Zoom tied to scroll progress
- Subtle Ken Burns feel
- Keeps image crisp with transform only
- Pure CSS

## Usage
```html
<div class="szi-frame"><div class="szi-bg"></div></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
