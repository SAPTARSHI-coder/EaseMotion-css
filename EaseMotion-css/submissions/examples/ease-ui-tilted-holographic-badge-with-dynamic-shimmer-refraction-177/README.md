# Tilted Holographic Badge with Dynamic Shimmer Refraction (Dark Mode Variant)

A modern dark-themed holographic badge featuring dynamic shimmer refraction, subtle tilt effects, and smooth hover animations built using pure HTML and CSS.

## Features

- Dark Mode UI
- Holographic shimmer effect
- Tilted badge design
- Smooth hover animations
- Responsive layout
- Pure HTML & CSS

## Folder Structure

```
ease-ui-tilted-holographic-badge-with-dynamic-shimmer-refraction-177/
├── README.md
├── demo.html
└── style.css
```

## Usage

Open `demo.html` in your browser.

Modify colors, gradients, and animation speed in `style.css`.

## Technologies

- HTML5
- CSS3
