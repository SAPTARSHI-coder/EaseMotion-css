# Glow Switch Theme

A theme toggle that glows in the dark and slides its moon or sun icon across.

## Features
- Track glows with a soft aura on hover
- Knob carries a moon and a sun
- Icons swap with a tiny spin

## Usage
```html
<div class="gt-switch">
  <span class="gt-knob"><span class="gt-sun">&#9728;&#65039;</span><span class="gt-moon">&#127769;&#65039;</span></span>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
