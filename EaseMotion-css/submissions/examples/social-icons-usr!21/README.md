# Animated Social Media Icons Submission

## 1. What does this do?
It provides a set of modern, animated social media icons with smooth hover effects and brand-specific color transitions, perfect for website footers and contact sections.

## 2. How is it used?
Wrap each SVG icon in the `.social-icon` class and combine it with EaseMotion utilities like `ease-hover-scale`. Each icon automatically displays its brand color on hover.

## 3. Why is it useful?
- Social media icons are essential for every website's footer and contact sections.
- Demonstrates smooth hover animations with brand-specific color transitions.
- Glassmorphism design with backdrop blur effects.
- Fully accessible with proper ARIA labels and focus states.
- Includes `prefers-reduced-motion` support for accessibility.
- Maintainer can easily standardize this as `.ease-social-[YOUR_INITIALS]` in the core library.
