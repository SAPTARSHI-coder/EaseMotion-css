Welcome to the Application

Screen reader users rarely read a page from top to bottom. Instead, they use keyboard shortcuts (like the 'D' key in NVDA or the Rotor in VoiceOver) to pull up a list of landmarks and jump directly to the section they care about.

By using HTML5 semantic elements (header, nav, main, aside, footer), you automatically build this map for them.
