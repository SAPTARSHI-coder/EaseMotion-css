# Reduced Motion Preference Demo

1. What does this do?
It shows animated cards, progress pulse, and shimmer behavior by default, then switches to instant fallback styling when `prefers-reduced-motion: reduce` is enabled.
2. How is it used?
Open `demo.html` and interact with the cards; check normal motion and reduced-motion states by toggling your system accessibility setting.
3. Why is it useful?
It demonstrates a practical accessible motion pattern for EaseMotion examples that protects motion-sensitive users without sacrificing visual affordance.
