# Image Pixelate Reveal

A pixelated image sharpens block by block into full focus.

## Features
- Pixel block sharpen
- Progressive resolution
- Poster stand-in
- Pure CSS

## Usage
```html
<div class="ipr-img"></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
