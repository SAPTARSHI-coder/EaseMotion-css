# Neon Orbit System 🪐✨

A mesmerizing neon orbital system featuring concentric rotating rings, glowing orbiters, pulsing core, expanding pulse waves, and twinkling stars. Built entirely with pure CSS animations.

## Features
- **4 Concentric Orbit Rings**: Each with independent rotation speed and direction.
- **7 Glowing Orbiters**: Neon-colored spheres with blur glow effects orbiting at different speeds.
- **Pulsing Core**: Central energy source with radial gradient and breathing animation.
- **Expanding Pulse Waves**: Ripple effects emanating from the core.
- **Twinkling Stars**: Background star field with independent twinkle animations.
- **Hover Interaction**: Rings brighten and pulse waves change color on hover.
- **Zero JavaScript**: All animations are pure CSS.

## Customization
Edit CSS variables in `:root`:
- `--ring-1` through `--ring-4`: Adjust orbit ring diameters.
- `--neon-*`: Change the neon color palette.
- `--orbit-speed`: Control base rotation speed.
- `--core-size`: Adjust the central core size.

## Browser Support
Works in all modern browsers. Uses CSS transforms, `filter: blur()`, and `radial-gradient`.
