# Scroll-Triggered Animations Demo

Demonstrates scroll-triggered animations using IntersectionObserver + EaseMotion CSS classes.

## Features
- IntersectionObserver-based reveal
- 6 different animation types (slide, fade, scale, flip, bounce)
- One-shot animations (no re-trigger)
- Reduced motion support
