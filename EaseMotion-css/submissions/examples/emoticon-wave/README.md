# Emoticon Wave

A row of emoji that wiggle, jump and wave in sequence like a happy crowd.

## Features
- Each emoji dances on its own beat
- Wave travels across the row
- Staggered delays create a ripple

## Usage
```html
<div class="ew-row">
  <span class="ew-emo">&#128512;</span>
  <span class="ew-emo">&#129321;</span>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
