# Card Flip Animation

## 1. What does this do?
Adds a 3D card flip animation for interactive reveals, quizzes, or memory games.

## 2. How is it used?
```html
<div class="ease-card-flip">
  <div class="ease-card-front">Front</div>
  <div class="ease-card-back">Back</div>
</div>
```

## 3. Why is it useful?
Card flip animations provide engaging interactive experiences for users.
