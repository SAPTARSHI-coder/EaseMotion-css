# Tooltip Z-Index Fix

## Description

This example demonstrates a tooltip that remains visible above surrounding elements by using proper positioning and a higher stacking order.

## Features

- Responsive tooltip
- Higher z-index
- Smooth fade animation
- Pure HTML & CSS

## Usage

```html
<button class="tooltip-btn">
    Hover Me
    <span class="tooltip">Tooltip Text</span>
</button>
```
