# Keyboard Shortcut Component

Add ease-keyboard-shortcut-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|---------|
| `--ksc-accent` | `#6366f1` |
| `--ksc-radius` | `8px` |
| `--ksc-shadow` | `0 4px 16px rgba(0,0,0,.3)` |

## Technique

Key cap styling with `box-shadow` creates 3D raised-button effect.
