# Mezzotint Rocker Roll

## What does this do?
Renders a self-contained CSS-only `ease-mezzotint-rocker-roll` demo: Mezzotint rocker rolling textured ground.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-mezzotint-rocker-roll`. No build step or JavaScript is required for the effect.

```html
<section class="ease-mezzotint-rocker-roll">
  <div class="ease-mezzotint-rocker-roll__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
