# Float Drift Dropdown
A modern CSS-only floating dropdown component featuring a smooth drift animation and glassmorphism styling for creative portfolio layouts.

## Features
- Pure HTML & CSS
- CSS-only hover interaction
- Smooth float drift animation
- Glassmorphism dropdown
- Gradient hover effects
- Responsive layout
- Keyboard accessible
- Supports `prefers-reduced-motion`
- No JavaScript required

## Folder Structure

```
float-drift-dropdown-arpita/
├── demo.html
├── style.css
└── README.md
```

## Usage
Open `demo.html` in any modern browser and hover over the menu buttons to reveal the animated dropdown.

## Technologies Used
- HTML5
- CSS3
- CSS Grid
- Flexbox
- CSS Animations
- Glassmorphism

## Browser Support
- Chrome
- Edge
- Firefox
- Safari

## Accessibility
- Responsive across desktop, tablet, and mobile.
- Keyboard friendly using `:focus-within`.
- Supports users with reduced motion preferences.
