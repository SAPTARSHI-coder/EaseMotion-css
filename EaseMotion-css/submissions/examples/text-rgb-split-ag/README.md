# Text RGB Split

1. What does this do? Creates an interactive hover effect where the text separates into its underlying cyan and magenta (RGB-style) color channels, which drift apart and return smoothly when the cursor leaves.
2. How is it used? Apply `.text-rgb-split` to a text element and set the `data-text` attribute to match the text content inside the element.
3. Why is it useful? It adds a premium, high-tech, or cyberpunk feel to typography. By using pseudo-elements and CSS `mix-blend-mode`, it achieves a complex visual effect entirely in CSS without needing any JavaScript dependencies.
