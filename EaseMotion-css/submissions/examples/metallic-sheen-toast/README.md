# Metallic Sheen Toast

A sleek notification toast inspired by polished metal surfaces and
subtle reflective lighting.

## Features

- Metallic gradient surface
- Animated reflective sheen
- Polished metallic icon
- Smooth entrance animation
- Hover interaction
- Responsive layout
- Dark mode support
- Light mode support
- Keyboard focus support
- Reduced-motion accessibility support
- Pure HTML and Vanilla CSS
- No external dependencies

## Preview

The component presents a modern notification card with layered metallic
gradients, reflective highlights, subtle shadows, and a moving sheen
effect.
