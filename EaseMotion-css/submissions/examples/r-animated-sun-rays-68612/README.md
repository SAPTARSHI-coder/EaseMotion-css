# CSS Animated Sun and Rays

A decorative CSS sun with rotating rays and a subtle breathing
glow effect.

## Features

- Pure HTML and CSS
- Rotating sun rays
- Pulsing sun glow
- Responsive layout
- No external assets
- Reduced-motion support
- No JavaScript required

## Usage

Copy the sun markup and include `style.css`.

## Accessibility

The decorative sun uses `aria-hidden="true"` because the
weather information is already provided as accessible text.

Motion is disabled for users who prefer reduced motion.

## Customization

Adjust the sun and sky colors through the CSS custom properties
at the beginning of `style.css`.
