
---

## 🚀 Usage
1. Clone or copy the files into your project.
2. Open `demo.html` in your browser.
3. The hero section will display with neumorphic SaaS styling.

---

## 🛠️ Customization
- **Colors** → Adjust background and text colors in `.hero-content`.
- **Shadow depth** → Modify `box-shadow` values for stronger/weaker neumorphism.
- **CTA button** → Customize hover colors and shadow intensity.

---

## 📖 Accessibility
- Uses `role="banner"` and `aria-label="Neumorphic SaaS Hero Section"`.
- Button is keyboard accessible with clear hover/focus states.
