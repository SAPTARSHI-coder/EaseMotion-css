# CSS Zoom-In Popover for Product Catalog Layouts

A modern **Zoom-In Popover** component built using pure HTML5 and CSS3 for the EaseMotion CSS project. The popover smoothly zooms into view on hover, creating an engaging product preview while maintaining a clean and responsive design.

---

## ✨ Features

- Pure HTML5 & CSS3
- Smooth zoom-in popover animation
- Modern glassmorphism interface
- Responsive product catalog layout
- CSS custom properties for easy customization
- Hover interactions with smooth transitions
- Supports `prefers-reduced-motion`
- No JavaScript required
