# CSS 3D-Flip Navbar

A minimalist responsive navigation bar with a pure CSS 3D flip interaction.

## Features

- Pure HTML and CSS
- No JavaScript dependencies
- 3D flip hover animation
- Keyboard focus support
- Responsive navigation layout
- Minimalist technology-focused design
- Reduced-motion support
