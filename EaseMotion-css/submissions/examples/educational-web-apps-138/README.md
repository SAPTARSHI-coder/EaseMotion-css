# Interactive Flip Flashcard Component

A modern Cyberpunk-themed interactive flashcard component designed for
educational websites.

## ✨ Features

- 3D flip animation
- Cyberpunk neon visual style
- Question and answer sides
- Click-to-flip interaction
- Dedicated Flip Card button
- Keyboard support
- Responsive design
- Reduced-motion accessibility support
- Pure HTML, CSS and JavaScript
- No external dependencies
