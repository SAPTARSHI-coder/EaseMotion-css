
---

## 🚀 Usage
1. Clone or copy the files into your project.
2. Open `demo.html` in your browser.
3. Hover over the eye to see it open/close.

---

## 🛠️ Customization
- **Animation speed** → Adjust `transition: transform 0.6s` for faster/slower eyelid movement.
- **Eye size** → Modify `.eye` width/height.
- **Iris color** → Change `background: #1976d2` in `.iris`.

---

## 📖 Accessibility
- Uses `role="img"` and `aria-label="Eye icon for password visibility"` for screen readers.
- Hover interaction demonstrates open/close states.
