# Range Finder Coincidence

## What does this do?
Renders a self-contained CSS-only `ease-range-finder-coincidence` demo: Coincidence rangefinder images sliding into alignment.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-range-finder-coincidence`. No build step or JavaScript is required for the effect.

```html
<section class="ease-range-finder-coincidence">
  <div class="ease-range-finder-coincidence__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
