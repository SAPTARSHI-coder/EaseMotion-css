# Isometric Cube

A CSS isometric cube built from three skewed faces, gently bobbing.

## Features
- Skew-built isometric illusion
- Floating bounce animation
- Distinct face tints
- Pure CSS

## Usage
```html
<div class="iso-cube"><div class="iso-face iso-top"></div></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
