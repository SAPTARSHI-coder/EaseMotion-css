Sticky Header Shrink

Scroll down. The header condenses when it leaves the top of the page, detected with a scroll-driven animation timeline instead of a scroll listener.

The effect is driven by animation-timeline: scroll(), so the browser samples it off the main thread. There is no scroll handler, no IntersectionObserver, and no class toggling.

Browsers without scroll-driven animation support simply keep the full-size header, which is the correct fallback rather than a broken one.

End of demo.
