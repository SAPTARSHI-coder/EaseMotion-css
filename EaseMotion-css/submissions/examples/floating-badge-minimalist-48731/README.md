# Floating Badge with Minimalist Styling

A sleek, responsive floating badge component positioned over container edges or images with a clean, minimalist design.

## Usage

Include the `floating-badge` class inside a parent container with `position: relative`:

```html
<div class="card" style="position: relative;">
    <div class="floating-badge">New</div>
    <!-- Card content here -->
</div>
```

## Why is it useful?

It provides an elegant, non-intrusive way to highlight statuses, labels, or notifications on top of cards or images, fitting perfectly into modern, minimalist UI designs.
