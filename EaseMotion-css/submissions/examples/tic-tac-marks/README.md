# Tic Tac Marks

Tic-tac-toe marks draw themselves in sequence across the grid.

## Features
- Self-drawing X and O
- Sequential turns
- Winning line flash
- Pure CSS

## Usage
```html
<div class="ttm-cell"><i class="ttm-x"></i></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
