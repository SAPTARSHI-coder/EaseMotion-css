# Neumorphic Footer with Material Design Styling

A responsive, pure-CSS footer component blending soft Neumorphic extruded and inset shadow states with Material Design color palette principles.

## Features

- **Pure CSS & Zero Dependencies:** Operates without any JavaScript framework or library.
- **Neumorphic Depth Effects:** Includes outer convex shadows for default buttons and smooth inset pressed states upon interaction.
- **Material Design Touches:** Formatted with Material primary accent hues, clear hierarchy, and responsive grid layouts.
- **Accessibility Ready:** Accessible focus indicators, semantic markup, and proper ARIA labels on controls.
