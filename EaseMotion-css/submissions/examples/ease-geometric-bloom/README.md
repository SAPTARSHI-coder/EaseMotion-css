# Geometric Bloom · Shapes Bloom from Center 🌸

An interactive geometric bloom where shapes burst and bloom from the center with vibrant colors, smooth animations, and mesmerizing radial patterns.

## Features

- 🌸 **Geometric Bloom** – Shapes bloom from center
- 🌱 **Bloom Animation** – Smooth outward growth
- 🎨 **Vibrant Colors** – Dynamic HSL shifting
- 🎚️ **Speed Control** – Adjust bloom speed (1-10)
- 🎚️ **Petal Count** – Adjust number of petals (4-12)
- ⏸️ **Pause/Resume** – Toggle animation
- 🔄 **Reset** – Reset to initial state
- ✨ **Glow Effects** – Soft petal glow

## How to Use

1. Click **BLOOM** or press **Space** to watch shapes bloom
2. Watch petals burst from the center
3. Adjust **Speed** for bloom pace
4. Adjust **Petals** for shape complexity
5. Press **RESET** or **R** to reset
6. Press **PAUSE** or **P** to pause/resume animation

## Controls

| Action | Method |
|--------|--------|

## Technical Details

- **Petals:** 4-12 tear-drop shapes
- **Bloom:** Smooth cubic ease-out growth
- **Colors:** HSL-based dynamic coloring
- **Performance:** 60fps with requestAnimationFrame

## Customization

You can easily customize:
- **Petals:** Adjust slider range (4-12)
- **Speed:** Modify bloom speed
- **Colors:** Change color generation
- **Shape:** Modify petal shape
- **Size:** Adjust petal size

## Browser Support

Works in all modern browsers:
- Chrome, Firefox, Safari, Edge

## Run Locally

Simply open `index.html` in your browser – no server required!
