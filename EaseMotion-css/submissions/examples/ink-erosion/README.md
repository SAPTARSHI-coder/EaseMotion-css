# 🖋️ Ink Erosion

Ink Erosion is a dependency-free interactive canvas experiment where pointer movement behaves like an invisible stream of water moving across wet pigment.

Instead of drawing with the cursor, the user erodes the existing ink.

The result is a continuously changing surface containing:

- Flow
- Pigment
- Channels
- Islands
- Erosion
- Dissipation

The component is designed to feel more like interacting with a physical material than operating a conventional UI.

---

## ✨ Features

- Interactive ink field
- Procedural fluid-like movement
- Pointer-based erosion
- Speed-sensitive disturbances
- Organic particle distribution
- Temporary flow channels
- Fading ink fragments
- Click-based erosion
- Pause/resume
- Clear surface
- Reload surface
- Keyboard controls
- Touch support
- Responsive layout
- Reduced-motion consideration
- Zero external dependencies
