How it works

The whole system uses three modern CSS features together:

1. @starting-style

Defines the element's style before it's rendered — the initial state for the entrance animation. Without this, browsers animate from the computed style, which means no entrance effect.

2. transition-behavior: allow-discrete

Enables transitions on discrete properties like display. Without it, display: none → display: block is an instant jump. With it, the browser defers the display change so the animation can run.

3. overlay

For elements in the top layer (like dialogs). Toasts using regular DOM flow don't need it, but it's useful for modal-style overlays that should auto-animate out on dismiss.

This submission demonstrates @starting-style — a 2024 CSS feature — for EaseMotion CSS. All enter/exit animations are pure CSS. The buttons use minimal JavaScript only to add <div> elements to the DOM; the animation system itself is zero-JS.
