# Glassmorphism Neon Badge

A modern responsive badge component built using pure HTML and CSS.

This component combines glassmorphism effects with neon lighting,
animated borders, glowing text, and smooth hover interactions.

## ✨ Features

- Glassmorphism UI
- Neon glowing border
- Animated gradient border
- Glowing status indicator
- Hover interaction
- Responsive design
- Pure HTML and CSS
- No JavaScript or external libraries
- Reduced-motion accessibility support
