# Motion Engine Parser Speed Benchmark

A lightweight benchmark demo for measuring the performance of
Motion Engine attribute parsing.

## Features

- Measures parser operations per second.
- Measures average execution time.
- Estimates FPS capacity.
- Provides a simple PASS/FAIL performance indicator.
- Responsive layout for desktop and mobile screens.
- Runs directly in the browser without a server.
