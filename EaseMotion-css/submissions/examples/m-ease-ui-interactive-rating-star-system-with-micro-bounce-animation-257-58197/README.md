# Interactive Rating Star System with Micro-Bounce Animation (Dark Mode Variant)

A modern **Dark Mode Rating Star Component** built using pure HTML and CSS. The component features interactive stars with smooth micro-bounce hover animations and a clean responsive layout.

## ✨ Features

- Pure HTML5 & CSS3
- Interactive 5-star rating system
- Micro-bounce hover animation
- Dark mode design
- Gradient submit button
- Responsive layout
- CSS Custom Properties
- `prefers-reduced-motion` support
- No JavaScript required
