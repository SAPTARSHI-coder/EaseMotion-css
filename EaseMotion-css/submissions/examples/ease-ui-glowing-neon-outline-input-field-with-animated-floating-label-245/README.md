# Glowing Neon Outline Input Field with Animated Floating Label (Minimalist Clean Edition)

1. **What does this do?** 
   A clean, modern input field designed for light-themed interfaces. It features a sleek floating label that transitions out of the input area upon focus, revealing a crisp, bright blue "neon" outline with a soft, diffused drop-shadow.

2. **How is it used?** 
   Copy the `demo.html` markup and link the `style.css`. Like all components in this series, it relies purely on CSS pseudo-classes (`:focus` and `:not(:placeholder-shown)`) to handle the complex state animations. There is absolute zero JavaScript required! It utilizes a clever spacing trick to allow the label to break the input border flawlessly.

3. **Why is it useful?** 
   Forms need to be accessible and highly interactive. This component bridges the gap between the aggressive "cyberpunk" glow effects and professional corporate UI design. It provides the "Micro-Animations" that EaseMotion CSS champions while keeping the overall aesthetic lightweight, clean, and highly professional.
