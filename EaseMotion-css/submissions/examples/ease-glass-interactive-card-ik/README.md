# EaseMotion CSS — Interactive Glassmorphic Card (`ease-glass-interactive-card-ik`)

A modern glassmorphism UI card component featuring backdrop blur filters, spring hover elevation, glowing accent borders, and accessible reduced-motion fallbacks.

Submitted by: **@Ishita-Katiyar-06** (`-ik`)

---

## 1. What does this do?

Provides an interactive glassmorphic UI card component class (`ease-glass-hover`) combining `backdrop-filter: blur(16px)` translucency with cubic-bezier spring hover translations (`translateY(-8px)`).

---

## 2. How is it used?

Apply the `ease-glass-hover` class directly to card containers:

```html
<article class="glass-card ease-glass-hover">
  <h2>Glass Surface Title</h2>
  <p>Translucent glass card content...</p>
</article>
```

---

## 3. Why does it fit EaseMotion CSS?

EaseMotion CSS emphasizes human-readable, animation-first component design. This component delivers modern glassmorphism aesthetic trends while maintaining 60fps GPU compositor acceleration and `prefers-reduced-motion` compliance.
