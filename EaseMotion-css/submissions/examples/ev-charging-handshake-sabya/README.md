# EV Charging Handshake

**What does this do?**
It is a CSS-only animated component simulating an EV charge port connection with a sliding connector latch and glowing energy flow indicators.

**How is it used?**
Wrap your HTML elements inside the `ease-ev-charging-handshake-sabya` shell. The animation is driven entirely by standard CSS `@keyframes` on the child elements.

**Why is it useful?**
It expands the library with a recognizable, real-world motion metaphor for system connections or data transfers, strictly adhering to the CSS-only, JavaScript-free philosophy of EaseMotion.
