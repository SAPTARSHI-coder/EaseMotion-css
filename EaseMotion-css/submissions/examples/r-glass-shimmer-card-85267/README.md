# Glass Shimmer Card

A smooth and lightweight **Glass Shimmer** card effect built with pure HTML and vanilla CSS.

## Features

- Pure HTML and CSS
- No JavaScript required
- Smooth shimmer animation
- Glassmorphism-inspired design
- Responsive layout
- Keyboard accessible button
- Reduced-motion support
- Hardware-friendly transforms

## Usage

Add the `glass-shimmer-card` class to the card container:

```html
<section class="glass-shimmer-card">
  <span class="card-badge">EaseMotion CSS</span>
  <h1>Glass Shimmer</h1>
  <p>Hover to reveal the shimmer effect.</p>
</section>
