# Glow Running Border

## Overview

A modern glowing border animation built with pure HTML and CSS. The animated gradient creates the illusion of light continuously moving around the component, making it suitable for feature cards, pricing cards, or call-to-action sections.

## Features

- Animated glowing border
- Gradient running effect
- Pure HTML & CSS
- Responsive layout
- Smooth animation
- Supports `prefers-reduced-motion`
- No JavaScript required

## Files

- `demo.html`
- `style.css`
- `README.md`

## Usage

Open `demo.html` in any modern browser to view the animation.
