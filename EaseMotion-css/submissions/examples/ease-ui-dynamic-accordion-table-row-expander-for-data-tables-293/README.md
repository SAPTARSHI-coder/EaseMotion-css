# Dynamic Accordion Table Row Expander for Data Tables (Minimalist Clean Edition)

A clean and lightweight expandable data table built using HTML, CSS and JavaScript. Each row expands smoothly to reveal additional details while maintaining a minimalist interface.

## Features

- Minimalist clean design
- Smooth accordion row animation
- Responsive table layout
- Pure HTML, CSS & JavaScript
- Lightweight and reusable

## Folder Structure

```
ease-ui-dynamic-accordion-table-row-expander-for-data-tables-293/
├── README.md
├── demo.html
├── style.css
└── script.js
```

## Usage

Open `demo.html` in your browser.

Customize spacing, colors and typography inside `style.css`.
