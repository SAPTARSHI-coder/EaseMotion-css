# Ease Stat Number

## What does this do?

A highlighted statistic component for displaying important numerical values with a label and optional description.

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<div class="stat-number">
    <span class="stat-label">Total Projects</span>

    <strong class="stat-value">248</strong>

    <span class="stat-description">
        Projects completed this year
    </span>
</div>
```

### Features

- Large statistic number
- Label
- Optional description
- Entrance animation
- Hover interaction
- Responsive layout
- Pure CSS
- No JavaScript required

## Why is it useful?

Statistic numbers are commonly used in dashboards, landing pages, analytics interfaces, reports, and business applications to highlight important numerical information.

This component provides a simple and reusable way to emphasize key statistics with a subtle entrance animation while following the animation-first philosophy of EaseMotion CSS.
