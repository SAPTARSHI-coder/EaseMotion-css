# Trebuchet Counterweight

## What does this do?
Renders a self-contained CSS-only `ease-trebuchet-counterweight` demo: Trebuchet counterweight swinging to launch the arm.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-trebuchet-counterweight`. No build step or JavaScript is required for the effect.

```html
<section class="ease-trebuchet-counterweight">
  <div class="ease-trebuchet-counterweight__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
