# CSS Email Notification Card

A responsive and accessible email notification card built using pure HTML and CSS, featuring a sender avatar, unread indicator, message preview, timestamp, attachment badge, and interactive hover/focus states.

## Features

- Pure HTML and CSS
- No JavaScript
- Responsive design
- Sender avatar
- Unread notification indicator
- Animated unread indicator
- Email sender and address
- Timestamp using semantic `<time>`
- Message preview
- Attachment indicator
- Interactive Open button
- Hover elevation animation
- Keyboard focus support
- `prefers-reduced-motion` accessibility support
- Works without external libraries or CDNs
