# Rotate-Fade Drawer

A modern **CSS-only Rotate-Fade Drawer** designed for gaming dashboards and application layouts. The drawer smoothly rotates into view while fading in, creating an immersive navigation experience without any JavaScript.

---

## 📂 Folder Structure

```
rotate-fade-drawer/
│── demo.html
│── style.css
└── README.md
```

---

## ✨ Features

- 🎮 Gaming Hub inspired interface
- 🔄 Smooth Rotate + Fade drawer animation
- 💯 Pure HTML & CSS (No JavaScript)
- 📱 Fully responsive layout
- ♿ Accessibility support with `prefers-reduced-motion`
- 🎨 CSS Custom Properties for easy theme customization
- 🌈 Modern glassmorphism inspired design
- ⚡ Lightweight and easy to integrate

## 🎨 CSS Custom Properties

The component uses CSS variables for easy customization.

```css
:root{
    --bg:#0f172a;
    --panel:#18233d;
    --card:#1f2d4f;
    --primary:#6d5dfc;
    --secondary:#00d4ff;
    --text:#ffffff;
    --muted:#c7d2fe;
    --radius:20px;
}
```

You can modify these values to quickly change the appearance.

## ♿ Accessibility

Supports:

```css
@media (prefers-reduced-motion: reduce)
```

to disable animations for users who prefer reduced motion.

The navigation drawer combines:

- RotateY Transform

This produces a lightweight, polished drawer interaction suitable for gaming interfaces.
