# CSS Scale-Hover Hero Section for Product Catalog Layouts

A modern **Scale-Hover Hero Section** built using pure HTML and CSS. The component features elegant scale-hover interactions, responsive hero layout, CSS custom properties, and lightweight styling suitable for product catalog landing pages.

## ✨ Features

- Pure HTML5 & CSS3
- Scale-hover animation
- Responsive hero section
- Glassmorphism product card
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
