# Liquid Audio Equalizer Visualizer - GSSoC 2026

A liquid audio equalizer spectrum visualizer featuring staggered CSS keyframes, gradient pillars, and glassmorphic player card encapsulation.

## 1. What does this do?
It renders a dynamic real-time audio spectrum frequency equalizer animation inside a sleek music card interface.

## 2. How is it used?
Link `style.css` in your HTML document and include `.equalizer` containing animated `.bar` elements with staggered classes.

## 3. Why is it useful?
It provides rich ambient visual feedback for audio players, podcast cards, and media streaming apps using pure CSS.
