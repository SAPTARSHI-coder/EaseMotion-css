# Elastic-Slide Accordion for Product Catalogs

A lightweight, pure CSS/HTML **Elastic-Slide Accordion** designed for modern product catalog layouts.

The component uses smooth accordion expansion combined with elastic entrance motion to create an interactive and responsive product browsing experience without JavaScript.

## Features

- Pure HTML and CSS
- No JavaScript or external dependencies
- Elastic-slide entrance animation
- Smooth accordion expand/collapse interaction
- CSS-only interaction using checkbox inputs
- Responsive across desktop, tablet, and mobile
- Hover interactions for product items
- Customizable CSS custom properties
- Keyboard focus-visible support
- Accessible `prefers-reduced-motion` support
- Lightweight and reusable for product catalog interfaces
