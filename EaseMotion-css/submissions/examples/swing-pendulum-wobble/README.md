# Swing Pendulum Wobble

**What does this do?**  
This provides a keyframe animation and utility class that animates an element like a swinging pendulum with a wobbly settle effect.

**How is it used?**  
Add the class to any element:
```html
<div class="ease-anim-swing-pendulum-wobble">Content</div>
```

**Why is it useful?**  
It creates a playful, physics-inspired motion that draws user attention, fitting nicely into EaseMotion's philosophy of dynamic, hardware-accelerated animations.
