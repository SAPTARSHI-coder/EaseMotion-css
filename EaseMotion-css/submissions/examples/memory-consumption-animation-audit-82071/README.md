# Memory Consumption Animation Audit

A CSS-only visual audit component for reviewing memory-sensitive patterns in continuous CSS animation loops.

## Features

- Animation load indicator
- GPU layer indicator
- FPS target indicator
- Continuous animation signal analysis
- Visual identification of compositor-friendly animation
- Reduced-motion support
- Responsive layout
- No JavaScript required

## Files

- `demo.html` — standalone demonstration
- `style.css` — complete styling and animations
- `README.md` — documentation

## Usage

Open `demo.html` directly in a browser.

Or include the stylesheet in an existing page:

<link rel="stylesheet" href="style.css">
