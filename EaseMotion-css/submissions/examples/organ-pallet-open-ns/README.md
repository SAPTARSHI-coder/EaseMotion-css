# Organ Pallet Open

## What does this do?
Renders a self-contained CSS-only `ease-organ-pallet-open` demo: Organ pallet opening wind to the pipe.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-organ-pallet-open`. No build step or JavaScript is required for the effect.

```html
<section class="ease-organ-pallet-open">
  <div class="ease-organ-pallet-open__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
