# Hamburger Menu Component

Add ease-hamburger-menu-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|---------|
| `--hbg-accent` | `#6366f1` |
| `--hbg-bar` | `#f8fafc` |
| `--hbg-width` | `28px` |

## Technique

Hidden checkbox + `:checked` drives all menu states: hamburger → X, drawer slide-in, overlay fade.
