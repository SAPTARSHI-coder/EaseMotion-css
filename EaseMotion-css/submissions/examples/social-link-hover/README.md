# Social Link Hover

Icon chips that fill with their brand color and lift on hover, stacked in a neat row.

## Features
- Circular chips fill with a brand-tinted gradient
- Icon lifts while a soft halo expands beneath
- Uniform motion across the whole row

## Usage
```html
<div class="sl-row">
  <a class="sl-link sl-x" href="#">&#120143;</a>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
