# Cosmic Orbit Planet Showcase (v40.5)

An interactive, pure CSS and JavaScript orbital system showcase component with animated planet trajectories, depth effects, and detail cards.

## 🌟 Features

- **Animated Orbital Mechanics**: Smooth infinite CSS rotation for concentric orbits and planets with counter-rotated text labels.
- **Interactive Planet Selector**: Click any orbiting celestial body to display its facts and astronomical metrics.
- **Glassmorphic Info Panel**: Glass-like overlay panel with smooth text transitions.
- **Layered Starfield**: CSS radial-gradient multi-layered ambient space background with subtle twinkling keyframes.
- **Responsive Scaling**: Automatically scales the solar system and transforms layout grids on smaller screens.
