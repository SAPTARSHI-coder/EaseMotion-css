# CSS Drawer: Subtle Elevate

A smooth and accessible drawer/sidebar component featuring a subtle elevation effect using pure HTML and vanilla CSS.

## Features

- Pure HTML and CSS
- Subtle elevation on hover
- Soft neumorphic-inspired shadows
- Responsive layout
- Dark mode support
- Keyboard-friendly navigation
- Visible focus states
- Reduced-motion support
- No external dependencies

Include the stylesheet:
