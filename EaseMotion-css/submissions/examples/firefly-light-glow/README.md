# Firefly Light Glow Animation

## Overview

This submission demonstrates a reusable **Firefly Light Glow** animation using pure CSS. The element emits a soft glowing pulse inspired by the flicker of fireflies.

## Features

- Pure CSS animation
- Soft glowing pulse effect
- CSS keyframes
- Configurable timing using CSS variables
- `prefers-reduced-motion` support
- Responsive demo

## Customization

```css
--ease-duration: 900ms;
--ease-timing: ease-in-out;
```

## Demo

Open `demo.html` directly in any modern browser.
