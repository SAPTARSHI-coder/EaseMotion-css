EaseMotion Material

Note: Built with 100% pure CSS (Zero JS). Utilizes the Checkbox Hack pattern to manage open/close states globally.

This variant strictly adheres to Google's Material Design specifications:

  • Elevation: Uses Elevation Level 16 (0px 16px 24px) when open.
  • Motion: Utilizes standard Material deceleration (cubic-bezier(0.0, 0.0, 0.2, 1)) for entering, and standard curve (cubic-bezier(0.4, 0.0, 0.2, 1)) for exiting.
  • Scrim: The background overlay fades in to 32% opacity black.
  • Typography: Uses Roboto/system font stacks with standard weight and tracking.
