# Shimmer Loading Placeholder

**What does this do?**
Creates a reusable skeleton-loading placeholder with a soft animated highlight sweeping across its surface to indicate loading state.

**How is it used?**
```html
<div class="ease-shimmer">
  <span class="ease-shimmer__line"></span>
  <span class="ease-shimmer__line ease-shimmer__line--short"></span>
</div>
```

**Why is it useful?**
Skeleton loaders improve perceived responsiveness while content is being fetched. A reusable shimmer utility provides a practical animation pattern for cards, lists, and content-heavy interfaces, all while avoiding external images or JavaScript dependencies.
