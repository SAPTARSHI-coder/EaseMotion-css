# Liquid Fill Button

1. What does this do? Creates an interactive button where a liquid wave effect rises from the bottom to fill the button completely when hovered.
2. How is it used? Apply `.liquid-fill-btn` to a `button` or `a` tag. Note: Ensure the text inside is wrapped in a `span` so it stays above the liquid wave layer.
3. Why is it useful? Fluid and organic animations are heavily utilized in modern UI to provide a playful, engaging user experience. Achieving this entirely in CSS using pseudo-elements keeps the DOM clean and avoids expensive JavaScript animations.
