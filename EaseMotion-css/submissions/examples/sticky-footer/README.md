# CSS Sticky Footer with CTA

This project demonstrates how to create a **sticky footer with a call-to-action (CTA)** using HTML and CSS.

## Features
- Sticky footer that remains visible at the bottom of the viewport.
- Responsive design with flexbox layout.
- CTA section with text and a prominent button.
- Extended content sections to show scrolling behavior.

## Files
- `demo.html` → Contains the page structure: header, main content, and sticky footer.
- `style.css` → Provides styling for layout, typography, sticky footer, and responsiveness.
- `README.md` → Documentation and usage instructions.

## How It Works
- The footer uses `position: sticky` with `bottom: 0` to stay visible when scrolling.
- Flexbox ensures the footer content (text and button) is aligned neatly.
- Responsive media queries adjust the layout for smaller screens.

## Usage
1. Open `demo.html` in your browser.
2. Scroll down the page and observe the sticky footer staying in place.
3. Click the **Subscribe Now** button to simulate a CTA action.

## Customization Ideas
- Replace the CTA button with a link to a signup form or checkout page.
- Change the color scheme to match your brand.
- Add animations to the button for more interactivity.
- Extend the footer with social media icons or quick links.
