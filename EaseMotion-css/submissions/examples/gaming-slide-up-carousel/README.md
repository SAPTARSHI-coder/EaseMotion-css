# CSS Slide-Up Carousel for Gaming Hub Layouts

A modern **Gaming Hub Slide-Up Carousel** built entirely with **HTML5 and CSS3**. This showcase demonstrates elegant slide-up overlay animations, glassmorphism effects, responsive layouts, and accessibility-friendly interactions without using JavaScript.

---

## ✨ Features

- 🎮 Gaming Hub inspired carousel
- ⬆️ Smooth Slide-Up overlay animation
- ✨ CSS-only hover interactions
- 🌈 Neon gradient action buttons
- 🪟 Glassmorphism overlay
- 📱 Fully responsive
- ⚡ Pure HTML5 & CSS3
- 🎯 CSS Custom Properties
- ♿ `prefers-reduced-motion` support
- 🚀 Lightweight and easy to customize

## 🚀 Getting Started

1. Open `demo.html` in any modern browser.
2. Hover over the cards to reveal the slide-up content.
3. Customize colors, spacing, and animation timing through CSS variables.

:root{
