# 🪨 Parallax Fossil

An interactive geological specimen component that creates the illusion of depth by placing a fossil inside multiple independently moving sedimentary layers.

Instead of using a 3D engine, Parallax Fossil uses CSS transforms and pointer interaction to simulate geological depth.

---

## ✨ Features

- 🪨 Layered geological strata
- 🦴 Interactive fossil specimen
- 📐 Depth-based parallax
- 💡 Pointer-controlled lighting
- 🔬 Specimen inspection mode
- 📊 Fossil metadata
- 🏷️ Geological annotations
- 📏 Depth measurement
- 🖱️ Pointer interaction
- 📱 Touch-friendly interaction
- ⌨️ Keyboard controls
- 📱 Responsive layout
- ♿ Reduced-motion support
- 🚫 Zero dependencies

---

## 🧠 Concept

A fossil is rarely found sitting on the surface.

It is preserved inside layers of geological material accumulated over extremely long periods.

Parallax Fossil uses that idea as the foundation of the interaction.

The component contains multiple geological layers, each representing a different depth.

When the user moves the pointer:

```text
Pointer Movement
       ↓
Depth Calculation
       ↓
Layer Displacement
       ↓
Parallax
       ↓
Perceived Geological Depth
