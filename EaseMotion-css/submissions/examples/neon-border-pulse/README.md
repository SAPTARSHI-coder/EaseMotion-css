# Neon Border Pulse

A card with a neon outline that breathes and strokes a light trail around the edges.

## Features
- Border glow breathes on a loop
- Light trail races around the frame
- Dark glass card lets the neon pop

## Usage
```html
<div class="nb-card">
  <div class="nb-trail"></div>
  <h3>NEON</h3>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
