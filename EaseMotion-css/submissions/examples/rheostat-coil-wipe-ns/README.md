# Rheostat Coil Wipe

## What does this do?
Renders a self-contained CSS-only `ease-rheostat-coil-wipe` demo: Rheostat contact wiping along a coiled resistance.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-rheostat-coil-wipe`. No build step or JavaScript is required for the effect.

```html
<section class="ease-rheostat-coil-wipe">
  <div class="ease-rheostat-coil-wipe__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
