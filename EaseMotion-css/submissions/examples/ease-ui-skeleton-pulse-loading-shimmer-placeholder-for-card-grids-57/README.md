# Skeleton Pulse Loading Shimmer Placeholder for Card Grids

## Overview

A modern dark mode skeleton loading UI component that creates
animated shimmer placeholders for card-based layouts.

Designed for modern dashboards, SaaS applications, and content
loading states.

## Features

- ✨ Animated pulse shimmer effect
- 🌙 Dark mode optimized design
- 🎨 Glassmorphism card styling
- ⚡ Smooth loading animations
- 📱 Responsive card grid layout
- 🖱️ Interactive hover elevation
- ♿ Reduced motion accessibility support
- 🚀 Pure HTML, CSS and JavaScript

## Usage

1. Open `demo.html` directly in a browser.
2. Customize card layouts according to your application.
3. Modify CSS variables to change colors and animation speed.

## Customization

You can update:

- Skeleton colors in `style.css`
- Animation duration
- Card count
- Layout breakpoints

## Accessibility

- High contrast dark theme
- Responsive mobile support
- Reduced motion preference handling
