# Task Progress List

A to-do list where completed tasks draw a checkmark and fade into the background.

## Features
- Checkbox pops a springy check
- Completed tasks cross out with a sweep
- Staggered reveal keeps the list tidy

## Usage
```html
<div class="tp-list">
  <div class="tp-item"><span class="tp-box"></span><span class="tp-label">Write the plan</span></div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
