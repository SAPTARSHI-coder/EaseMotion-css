# CSS Shimmer Sweep Popover

A lightweight portfolio popover featuring a shimmering sweep animation built with pure HTML and CSS.

## Features

- Pure HTML & CSS
- Smooth shimmer sweep animation
- Responsive layout
- Accessible
- Supports prefers-reduced-motion
- No JavaScript required

## Files

```
demo.html
style.css
README.md
```

## Usage

Open `demo.html` in your browser.

## Customization

You can modify:

- Card width
- Background color
- Animation duration
- Border radius
- Button colors

## Browser Support

Works in all modern browsers supporting CSS animations.
