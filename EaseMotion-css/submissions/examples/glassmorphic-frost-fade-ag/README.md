# Glassmorphic Frost Fade

1. What does this do? A card entrance animation where an element starts fully transparent with a heavy blur filter, and gracefully fades in while the frost/blur effect clears up, settling into a beautiful glassmorphism panel.
2. How is it used? Apply `.glass-frost-fade` to a container element.
3. Why is it useful? Glassmorphism is a core tenet of modern UI design. Combining a backdrop-filter blur with a fade-in creates a premium entrance effect that developers frequently request, provided here as a simple utility class.
