# Glassmorphism Blur Badge

A pure HTML and Vanilla CSS badge/chip component featuring a modern Glassmorphism Blur design.

## Features

- Pure HTML and CSS
- No external JavaScript
- Glassmorphism blur effect
- Translucent badge surfaces
- `backdrop-filter` based blur
- Multiple badge variants
- Smooth hover transitions
- Dark mode support
- Responsive layout
- Hardware-friendly transforms
- Reduced-motion accessibility support

## Variants

The demo includes:

- Active
- Verified
- Premium
- Pending
- Offline
- New

## Technologies

- HTML5
- CSS3
- CSS Backdrop Filter
- CSS Media Queries
- CSS Transitions
