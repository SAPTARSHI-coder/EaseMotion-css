# Proportional Compass Scale

## What does this do?
Renders a self-contained CSS-only `ease-proportional-compass-scale` demo: Proportional compass scaling a drawing.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-proportional-compass-scale`. No build step or JavaScript is required for the effect.

```html
<section class="ease-proportional-compass-scale">
  <div class="ease-proportional-compass-scale__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
