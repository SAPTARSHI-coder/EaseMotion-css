# Frosted Glass / Glassmorphism Card

A modern UI card component implementing the Glassmorphism design pattern with semi-transparent backgrounds, subtle borders, and smooth backdrop blurring.

## Class Reference

- `.ease-glass-card`: Primary container class providing `backdrop-filter: blur()`, translucency, and elevation styling.

## Key Features

- **Pure CSS**: Zero external runtime dependencies or JavaScript required.
- **Glassmorphism**: Leverages standard `backdrop-filter` for hardware-accelerated background blurring.
- **Responsive & Accessible**: Seamlessly scales across viewports with accessible focus states and semantic markup.

## Usage

Include `style.css` in your project and apply the `.ease-glass-card` class to any card or container element over a colored or image-based background.
