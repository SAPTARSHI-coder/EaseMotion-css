# Image Sheen Move

A glossy sheen periodically sweeps across the image frame.

## Features
- Periodic sheen sweep
- Skewed beam
- Looping delay
- Pure CSS

## Usage
```html
<div class="ism-sheen"></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
