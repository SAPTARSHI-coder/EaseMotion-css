# Tilt Rotate Card

A card tilts along X and Y with a live shadow as the pointer moves over it.

## Features
- Pointer-driven 3D tilt with CSS variables
- Live glare highlight following the cursor
- Depth boost via hovered scale
- Smooth transition back to rest

## Usage
```html
<div class="trc-card">...</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
