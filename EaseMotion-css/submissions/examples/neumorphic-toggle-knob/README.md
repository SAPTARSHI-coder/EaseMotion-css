# Neumorphic toggle knob

A dual-shadow soft switch that depresses slightly when the knob moves between off and on states.

## How to view

Open `demo.html` in any modern browser. The demo is fully self-contained — no CDN, no framework, no JavaScript.

## How to use

Copy `style.css` into your project's stylesheet. Every class used in the demo is namespaced with `neumorphictoggleknob-` to avoid collisions.

## Why this is useful for EaseMotion CSS

Tactile pattern; the soft shadow contrast sells the change without a heavy border.
