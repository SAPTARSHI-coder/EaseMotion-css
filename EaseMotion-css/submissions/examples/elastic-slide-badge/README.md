# CSS Elastic-Slide Badge

A modern animated badge component featuring an elastic slide entrance for creative portfolio layouts.

## Features

- Pure HTML & CSS
- Elastic slide animation
- Hover lift effect
- Responsive layout
- Accessible
- Supports `prefers-reduced-motion`

## Files

- demo.html
- style.css

## Usage

```html
<link rel="stylesheet" href="style.css">

<span class="elastic-badge">Frontend</span>
```

## Customization

Modify the CSS variables:

```css
:root{
  --primary:#6d5dfc;
  --secondary:#8b7dff;
  --duration:.55s;
}
```

## Accessibility

- Keyboard friendly
- Motion reduction support
- Responsive on desktop, tablet and mobile
