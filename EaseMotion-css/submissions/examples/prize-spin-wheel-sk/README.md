# Prize Fortune Spin Wheel

## What does this do?

A conic-gradient prize wheel that spins to a wedge on toggle.

## How is it used?

```html
<div class="wheel"><div class="wheel__disc"></div><label><input class="wheel__toggle" type="checkbox" hidden/><span>Spin</span></label></div>
```

Open `demo.html` in a browser to try it.

## Why is it useful?

Expressive reward motion for promotions while staying self-contained.
