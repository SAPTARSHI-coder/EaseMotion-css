# Blur-Entrance Modal

A lightweight, pure CSS/HTML modal animation designed for minimalist technology-focused interfaces.

## Features

- Blur-to-focus entrance animation
- Opacity and scale transition
- CSS-only interaction using a checkbox toggle
- Responsive across desktop, tablet, and mobile
- CSS custom properties for easy customization
- No JavaScript or external dependencies
- `prefers-reduced-motion` support
- Self-contained browser demo

## Files

- `demo.html` — Standalone demonstration page
- `style.css` — Modal styles and animation
- `README.md` — Usage and feature documentation
