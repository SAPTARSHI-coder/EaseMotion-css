# Quantum Particle Matrix Loader

## 1. What does this do?
This contribution provides a multi-axis gyroscopic loader component with independent 3D ring orbits, a central pulsating energy core, and glowing status text.

## 2. How is it used?
Include `style.css` in your project HTML and add the quantum loader structure to your loading states.

```html
<link rel="stylesheet" href="style.css">

<div class="quantum-loader" aria-label="Loading..." role="status">
  <div class="ring ring-outer"></div>
  <div class="ring ring-middle"></div>
  <div class="ring ring-inner"></div>
  <div class="particle-core"></div>
</div>
```

## 3. Why is it useful?
It provides an engaging, sci-fi loading animation for modern web apps, AI dashboards, and crypto/web3 platforms without requiring heavy 3D WebGL or Canvas libraries.
