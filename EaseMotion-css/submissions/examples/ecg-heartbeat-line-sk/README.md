# ECG Heartbeat Monitor Line

## What does this do?

A continuous ECG-style stroke animation with an optional flatline alert state.

## How is it used?

```html
<svg class="ecg" viewBox="0 0 400 80"><path class="ecg__line" d="M0 40 H40 L55 40 L70 10 L85 70 L100 40 H400" pathLength="1"/></svg>
```

Open `demo.html` in a browser to try it.

## Why is it useful?

Clear monitoring metaphor for health-themed dashboards (decorative only).
