# Skew-Active Tabs (Fintech Dashboard)

## Overview

A modern fintech dashboard featuring skew-active navigation tabs built with pure HTML and CSS. The active tab uses a subtle skew transformation to emphasize the selected section while maintaining a clean, dashboard-focused interface.

---

## Features

- Skew-active navigation tabs
- Glassmorphism dashboard panel
- Financial overview section
- Interactive statistic cards
- Smooth hover transitions
- Responsive design
- Pure HTML & CSS
- Supports `prefers-reduced-motion`
