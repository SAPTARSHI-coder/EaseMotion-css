# ease-slide-progress-bh

Pure CSS slide-up progress bar component.

## What does this do?
Creates animated progress bars with slide-up animation effect.

## How is it used?
```html
<div class="ease-slide-progress-bh">
  <div class="ease-slide-progress-fill-bh" style="--progress: 75%"></div>
</div>
```

## Why is it useful?
Creates dynamic progress indicators with slide animation for gaming layouts.
