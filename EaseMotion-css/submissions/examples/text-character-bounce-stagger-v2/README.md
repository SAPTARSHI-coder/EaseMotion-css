# Text character bounce stagger

A heading whose individual letters bounce up in sequence on hover.

## How to view

Open `demo.html` in any modern browser. The demo is fully self-contained — no CDN, no framework, no JavaScript.

## How to use

Copy `style.css` into your project's stylesheet. Every class used in the demo is namespaced with `textcharacterbouncestaggerv2-` to avoid collisions.

## Why this is useful for EaseMotion CSS

Hero / nav pattern; the staggered bounce gives a playful personality.
