# Responsive Cookie Banner with Retro Pixel Styling

A responsive cookie consent component inspired by retro pixel and arcade interfaces.

The component combines chunky borders, hard pixel shadows, monospace typography, bright accent colors, and CSS-only interactions.

## Features

- Retro pixel visual style
- Responsive cookie banner
- Pixel-inspired borders and shadows
- Arcade-style accent colors
- Cookie status indicator
- Cookie preference controls
- Interactive checkbox
- CSS toggle switches
- Accept and decline actions
- Cookie settings section
- Responsive desktop, tablet, and mobile layouts
- Keyboard-accessible controls
- Visible focus states
- `prefers-reduced-motion` support
- Pure HTML and CSS
- Zero JavaScript dependencies
- No external assets or libraries
