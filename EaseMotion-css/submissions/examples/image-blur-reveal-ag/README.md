# Image Blur Reveal

1. What does this do? Creates an elegant interactive hover effect where a heavily blurred and slightly zoomed-in placeholder image smoothly sharpens into focus and scales down to its natural size.
2. How is it used? Apply `.image-blur-reveal` to a figure or container that holds an `img` tag.
3. Why is it useful? Progressive image loading and blur-reveals are highly popular patterns in premium portfolios and modern UI design. This utility class provides a stunning, hardware-accelerated version of this effect without requiring any JavaScript.
