# CSS Morph-Glow Feature Grid for Fintech Dashboard Layouts

A modern **Morph-Glow Feature Grid** built using pure HTML and CSS. The component features elegant morph-glow hover animations with premium glassmorphism styling, responsive layouts, and reusable feature cards for fintech dashboards.

## ✨ Features

- Pure HTML5 & CSS3
- Morph-glow hover animation
- Glassmorphism feature cards
- Responsive grid layout
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
