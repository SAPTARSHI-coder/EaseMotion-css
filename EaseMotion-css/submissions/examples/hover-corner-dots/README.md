# Hover Corner Dots

1. **What does this do?**
   Adds four small dots that smoothly appear at the corners of an element when it is hovered.

2. **How is it used?**
   Apply the `.hover-corner-dots` class to an element you want to highlight on hover.

   ```html
   <div class="hover-corner-dots">
     Hover Me
   </div>
   ```

3. **Why is it useful?**
   It provides a simple, readable, and composable hover interaction that fits EaseMotion CSS's animation-first philosophy.
