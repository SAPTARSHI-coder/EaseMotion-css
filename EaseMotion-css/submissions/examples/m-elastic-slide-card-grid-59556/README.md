# CSS Elastic-Slide Card Grid for SaaS Showcase Layouts

A modern **Elastic-Slide Card Grid** built using pure HTML and CSS. The cards animate into view with a smooth elastic slide effect while using a premium glassmorphism design, making them perfect for SaaS landing pages, dashboards, and feature showcases.

## ✨ Features

- Pure HTML5 & CSS3
- Elastic slide entrance animation
- Glassmorphism cards
- Responsive grid layout
- CSS Custom Properties
- Smooth hover interactions
- `prefers-reduced-motion` support
- No JavaScript required
