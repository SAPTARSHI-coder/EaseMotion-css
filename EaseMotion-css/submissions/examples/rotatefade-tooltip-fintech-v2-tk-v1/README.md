# Rotate-Fade Tooltip (Fintech Dashboard)

## Overview

A modern fintech dashboard showcasing interactive information cards with rotate-and-fade tooltips. The tooltips smoothly rotate into view while fading in, providing additional financial insights without cluttering the interface.

---

## Features

- Rotate + fade tooltip animation
- Glassmorphism dashboard cards
- Smooth hover interactions
- Floating tooltip panels
- Responsive design
- Pure HTML & CSS
- Supports `prefers-reduced-motion`
