# Remontoire Rewind Pulse

## What does this do?
Renders a self-contained CSS-only `ease-remontoire-rewind-pulse` demo: Remontoire delivering a sharp rewind pulse to the train.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-remontoire-rewind-pulse`. No build step or JavaScript is required for the effect.

```html
<section class="ease-remontoire-rewind-pulse">
  <div class="ease-remontoire-rewind-pulse__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
