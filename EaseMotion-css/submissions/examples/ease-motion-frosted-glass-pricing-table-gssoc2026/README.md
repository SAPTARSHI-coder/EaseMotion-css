# Frosted Glass Pricing Table - EaseMotion CSS

A modern glassmorphism pricing tier grid with spring hover transitions and backdrop blur filtering.

## 1. What does this do?
This component presents plan subscription pricing cards with backdrop filter blur surfaces and elastic scaling feedback.

## 2. How is it used?
Link `style.css` and structure your pricing grid:

```html
<link rel="stylesheet" href="style.css">

<div class="pricing-grid">
  <div class="price-card">...</div>
  <div class="price-card featured">...</div>
</div>
```

## 3. Why is it useful?
- **Glassmorphism Styling:** Utilizes native `backdrop-filter: blur()` for sleek visual depth.
- **Featured Tier Prominence:** Emphasizes recommended conversion tiers through CSS scaling and luminous borders.
- **Responsive Flex/Grid:** Scales fluidly across mobile and desktop viewport widths.
