# Online Course Card

This submission demonstrates a modern online course card built with
**EaseMotion CSS**. It includes animated entrance effects, hover motion,
course stats, tags, rating, price section, and responsive layout.

## 🌟 Features

- **Course card** with banner, level badge, title, instructor, and rating.
- **Course stats** for lessons, duration, and students.
- **Topic tags** for course skills.
- **Price section** with enroll button.
- **Staggered entrance animation** using `ease-slide-up` and delay utilities.
- **Hover lift effect** using `ease-hover-lift`.
- **Button hover animation** using `ease-hover-grow`.
- **Responsive layout** for mobile and desktop.
- **Reduced motion support** for users who prefer less animation.

## 📁 Files

- `demo.html` — interactive online course card demo
- `style.css` — original course card styling
- `README.md` — documentation for this submission

## 🛠️ How to Run

1. Open `demo.html` in your browser.
2. Watch the course card animate on page load.
3. Hover over the card to see the lift effect.
4. Hover over the enroll button to see the grow effect.
5. Resize the browser window to check responsive behavior.
