# Interrupted Loader Animation Tests

A pure HTML & CSS demonstration that visually represents common interrupted loader animation scenarios.

## Features

- Running loader animation
- Interrupted (paused) animation
- Restarted animation
- Cancelled loader state
- Rapid start/stop visualization
- Multiple loader styles
- Responsive layout
- Dark theme
- Pure HTML & CSS
- No JavaScript

## Folder Structure

```
interrupted-loader-animation-tests/
├── demo.html
├── style.css
└── README.md
```

## Included States

- Running
- Interrupted
- Restarted
- Cancelled
- Rapid Start/Stop
- Stable Multiple Variations

## Technologies

- HTML5
- CSS3
- Flexbox
- CSS Grid
- CSS Animations
- Media Queries

## Purpose

This example provides a visual reference for interrupted loader animation scenarios, helping contributors manually inspect animation behavior and identify potential regression issues while remaining fully HTML & CSS based.
