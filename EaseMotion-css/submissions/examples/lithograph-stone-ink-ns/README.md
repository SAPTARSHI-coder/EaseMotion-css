# Lithograph Stone Ink

## What does this do?
Renders a self-contained CSS-only `ease-lithograph-stone-ink` demo: Lithograph stone ink roller pass.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-lithograph-stone-ink`. No build step or JavaScript is required for the effect.

```html
<section class="ease-lithograph-stone-ink">
  <div class="ease-lithograph-stone-ink__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
