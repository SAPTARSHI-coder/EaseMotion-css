ease-dropdown CSS @layer Demo

CSS Cascade Layers in Action:

All three cards use the same base component CSS. The middle card adds .theme-dark and the right card adds .theme-brand. These are resolved via @layer priority, NOT selector specificity. This makes overrides completely predictable.

Base Component

Styled by the ease-dropdown-component layer. Default appearance with no theme overrides.

Dark Theme

The ease-dropdown-theme layer overrides the component layer background. No specificity tricks needed!

Brand Theme

Utility class .u-rounded from the utilities layer rounds the button, always winning over component styles.
