# Elastic-Slide Dropdown for Gaming Hub

A lightweight, responsive CSS-only dropdown component designed for modern
Gaming Hub interfaces.

## Features

- Pure HTML and CSS
- No JavaScript required
- Elastic slide-down animation
- Smooth dropdown expansion
- Animated chevron indicator
- Responsive desktop, tablet, and mobile layouts
- Keyboard accessible native `<details>` and `<summary>`
- `:focus-visible` support
- `prefers-reduced-motion` support
- CSS custom properties for customization
- Gaming dashboard showcase design
