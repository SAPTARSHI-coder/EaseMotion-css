# Slide-Up Stepper (Gaming Hub Layout)

A modern, lightweight, pure CSS/HTML showcase example featuring a slide-up stepper for gaming hub layouts.

## 🎯 Features
- **Pure CSS & HTML**: No JavaScript required!
- **Slide-Up Animation**: Smooth slide-up transition on hover.
- **Gaming Aesthetics**: Dark mode, neon accents, and clean UI.
- **Responsive**: Fully adapts to desktop, tablet, and mobile screens.
- **Accessibility**: Includes `prefers-reduced-motion` support.

## 📂 Files Included
- `demo.html` — Clean HTML5 showcase page using standard EaseMotion classes
- `style.css` — Pure CSS stylesheet with smooth, performant animations
- `README.md` — Documentation detailing usage, CSS custom properties, and features

## 🎨 CSS Custom Properties
This component utilizes CSS variables for easy customization:

```css
:root {
  --stepper-bg: #0f0f13;
  --stepper-card-bg: rgba(255, 255, 255, 0.03);
  --stepper-card-border: rgba(255, 255, 255, 0.08);
  --stepper-accent: #00ffcc;
  --stepper-accent-glow: rgba(0, 255, 204, 0.4);
  --stepper-text: #ffffff;
  --stepper-text-muted: #8892b0;
  --transition-speed: 0.4s;
  --font-family: 'Segoe UI', system-ui, -apple-system, sans-serif;
}
```

## 🚀 Usage
Just include the `style.css` in your project and copy the HTML structure from `demo.html`.
