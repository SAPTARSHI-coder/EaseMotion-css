# Progress Steps Dots

A wizard-style step indicator where dots fill and connect as you advance.

## Features
- Dots pop as they activate
- Connecting bars sweep from left to right
- Labels slide in below each step

## Usage
```html
<div class="pd-track">
  <div class="pd-dot active">1</div>
  <div class="pd-dot">2</div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
