# Holographic Flicker - Sci-Fi HUD

A pure CSS sci-fi HUD component featuring a holographic flicker effect,
scanlines, glitch layers, glowing status indicators, and a futuristic
interface style.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript or external dependencies
- Holographic flicker animation
- Glitch-style text layers
- Animated scanline
- Sci-fi HUD corner indicators
- Glowing status indicator
- Dark-mode friendly design
- Hardware-accelerated transforms
- Responsive layout
- Respects `prefers-reduced-motion`
