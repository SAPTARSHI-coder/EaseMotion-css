# Shine Sweep Button

1. What does this do? Adds a metallic aesthetic to a button by sweeping a bright, skewed gradient light streak diagonally across it on hover.
2. How is it used? Apply `.shine-sweep-btn` to a `button` element.
3. Why is it useful? It's a classic, premium interaction effect often seen in gaming UI or modern SaaS calls-to-action. By utilizing CSS transitions and a pseudo-element gradient, it provides a highly polished micro-interaction with zero dependencies.
