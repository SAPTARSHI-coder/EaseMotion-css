# CSS Glassmorphism Pagination (Minimalist)

A clean, minimalist pagination component that utilizes CSS `backdrop-filter` to create a frosted glass effect. Designed to float beautifully over vibrant or complex background layouts.

## 🎯 Features
- **Pure CSS/HTML:** Zero JavaScript dependencies.
- **Glassmorphism Aesthetic:** Uses translucent RGBA backgrounds, subtle borders, and background blurring to create physical depth without heavy shadows.
- **Semantic & Accessible:** Built using `<nav>` and `<ul>` tags. Includes ARIA labels, `aria-current="page"` for active states, and `aria-disabled="true"` for inactive navigation arrows.
- **Responsive:** Flexbox-based layout automatically adapts to content size.
- **Reduced Motion Support:** Automatically strips hover translation animations for users who prefer reduced motion.
