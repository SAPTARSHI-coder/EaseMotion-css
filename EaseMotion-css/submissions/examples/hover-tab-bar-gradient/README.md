# Gradient Hover Tab Bar

A responsive navigation tab bar featuring smooth gradient hover effects using pure HTML and Vanilla CSS.

The component is lightweight, accessible, responsive, and requires no JavaScript or external dependencies.

## Features

- Smooth gradient hover animation
- Responsive layout
- Pure HTML and Vanilla CSS
- No JavaScript
- No external libraries
- Keyboard focus support
- Active tab styling
- Animated gradient background
- Mobile-friendly layout
- Reduced-motion support
- Works directly by opening `demo.html`
