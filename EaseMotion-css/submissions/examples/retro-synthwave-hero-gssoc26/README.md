# Retro Synthwave Hero Banner Component

An 80s Synthwave Retro Hero Banner featuring 3D animated perspective grid scrolling, neon sun glow, and text flicker animations.

## What does this do?
Renders an energetic 80s retro-futuristic landing section featuring a perspective grid scrolling background, neon typography, and glowing call-to-action buttons.

## How is it used?
1. Open `demo.html` to experience the animated 3D grid scrolling and neon text flicker.
2. Incorporate the `.synth-hero` section into creative hero pages or gaming applications.
3. Import `style.css` to activate 3D grid scrolling keyframes.

## Why is it useful?
Delivers a high-impact aesthetic for creative landing pages. Uses CSS hardware-accelerated infinite background translation for 60fps grid movement without JavaScript listeners.
