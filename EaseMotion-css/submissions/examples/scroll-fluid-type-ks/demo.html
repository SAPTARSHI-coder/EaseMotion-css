Technique 1

Font Size That Grows With Scroll

This heading uses @property --fluid-fs registered with syntax: '<length>', then animates it via animation-timeline: view(). As the heading enters and progresses through the viewport, its font-size fluidly transitions from small to large. The animation range is controlled with animation-range for precise timing.

Technique 2

Weight That Gains Confidence

@property --fluid-weight is registered with syntax: '<number>', inherits true, and animates from 100 to 900 as the section enters the viewport. Because @property tells the browser the value type, font-weight interpolates smoothly — something that was impossible without this API.

Technique 3

Letter Spacing That Breathes

@property --fluid-ls with syntax: '<length>' animates letter-spacing in lockstep with the scroll timeline. Characters spread apart and come together as the user scrolls through this section — creating a breathing rhythm.

Technique 4

Line Height That Opens Up

@property --fluid-lh registered with syntax: '<number>' animates line-height as the user scrolls. Combined with the growing font-size, this creates a dramatic typographic experience that feels alive and responsive to the reader's scrolling behavior.

CSS APIs Used

The modern CSS primitives powering this demo
API Role Browser Support
@property Registers custom properties with typed syntax, enabling smooth interpolation of any value Chrome 85+, Edge 85+, Safari 16.4+, Firefox 128+
animation-timeline: scroll() Drives animation progress from the scroll position of any element Chrome 115+, Edge 115+, Safari 18+, Firefox ❌
animation-timeline: view() Drives animation progress from an element's visibility within its scroll container Chrome 115+, Edge 115+, Safari 18+, Firefox ❌
animation-range Controls when an animation starts and ends within its timeline Chrome 115+, Edge 115+, Safari 18+

For browsers without scroll-driven animation support, static fallback typography values are defined in the base styles — ensuring content remains readable everywhere.
