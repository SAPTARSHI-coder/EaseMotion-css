# Scroll Shake Hint

A small animated chevron that gently shakes back and forth to encourage visitors to scroll and discover additional content.

## Features

- Subtle continuous shake animation
- Smooth scrolling
- Dependency-free
- Keyboard accessible
- Responsive design
- Reduced-motion support
- Hand-crafted CSS
