# Quantum Spin Loader 🌌

A highly advanced, pure CSS 3D loader featuring nested rotating rings, orbital particles, and a dynamic hue-shifting core. Zero dependencies, fully responsive, and perfect for sci-fi or cyberpunk themed applications.

## Features
- **True 3D Transforms**: Uses `preserve-3d` and multi-axis rotations for a realistic gyroscope effect.
- **Dynamic Hue Shifting**: Advanced color transitions using CSS animations.
- **Neon Glow Effects**: Layered `box-shadow` and `text-shadow` for authentic aesthetics.
- **Orbital Particles**: CSS-only orbiting elements around the central core.

## Customization
You can easily tweak the CSS variables at the top of the `style.css` file:
- `--neon-cyan` & `--neon-magenta`: Change the primary neon colors.
- `--anim-duration`: Speed up or slow down the global rotation.
- `--ring-size` & `--core-size`: Adjust the dimensions of the loader.

## Demo
Open `demo.html` in a modern web browser to see the 3D effect in action.
