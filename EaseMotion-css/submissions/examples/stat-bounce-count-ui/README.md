# Stat Bounce Count

A counter ticks up with each digit bouncing as it lands.

## Features
- Bounce-on-land digits
- Staggered per digit
- Ticker frame
- Pure CSS

## Usage
```html
<span class="sbc-digit" style="--i:0">9</span>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
