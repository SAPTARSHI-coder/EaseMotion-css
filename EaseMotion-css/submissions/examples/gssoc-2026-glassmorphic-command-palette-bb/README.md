# Glassmorphic Command Palette Showcase

A modern, accessible, high-performance **Glassmorphic Command Palette** built with EaseMotion CSS utility classes and backdrop blur effects.

## 🌟 Features

- **Spring Popup & Blur Backdrop**: Smooth scale physics and glassmorphism styling (`backdrop-filter: blur(16px)`).
- **Keyboard Navigation**: Open with `Ctrl` + `K` / `Cmd` + `K` and close with `ESC`.
- **Category Filtering & Search**: Interactive tags to filter results dynamically.
- **Accessibility & Reduced Motion**: Fully compliant with `prefers-reduced-motion` and keyboard focus traps.

## 🚀 Usage

Open `demo.html` in your web browser or inspect `style.css` for integration into your web application.

```html
<link rel="stylesheet" href="style.css">
<button class="command-trigger-btn">Search... <kbd>Ctrl K</kbd></button>
```
