# Ramen Steam Bowl

## What does this do?
Renders a self-contained CSS-only `ease-ramen-steam-bowl` demo: Ramen bowl with rising steam wisps and chopstick settle.

## How is it used?
Open `demo.html` in a browser. The animated face uses classes like `ease-ramen-steam-bowl`, `ease-ramen-steam-bowl__arm`, and `ease-ramen-steam-bowl__core`. No build step or JavaScript is required for the motion.

```html
<section class="ease-ramen-steam-bowl">
  <div class="ease-ramen-steam-bowl__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
