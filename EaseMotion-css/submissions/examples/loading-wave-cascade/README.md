# Loading Wave Cascade

A wave of thin bars ripples across, like an audio equalizer loading.

## Features
- Equalizer-style bars
- Phase-shifted wave
- Smooth easing
- Pure CSS

## Usage
```html
<i style="--i:0"></i>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
