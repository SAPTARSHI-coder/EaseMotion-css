# CSS Ripple Water Effect

A calm animated water surface created entirely with CSS.

## Features

- Pure CSS implementation
- Layered radial-gradient water styling
- Expanding ripple animation
- Animated water highlights
- Responsive design
- No JavaScript required
- Reduced-motion support
- Accessible visual description

## Usage

Include `style.css` and use the `.water` component in your HTML.

The colors and animation timing can be customized using the CSS
custom properties in `:root`.
