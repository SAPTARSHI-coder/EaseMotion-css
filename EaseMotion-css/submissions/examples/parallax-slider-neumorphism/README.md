# Parallax Slider - Neumorphism

A responsive parallax-style slider featuring a soft neumorphic interface built entirely with HTML and Vanilla CSS.

The component uses CSS radio controls for slide navigation, layered 3D-inspired visuals, smooth transitions, and responsive layouts without JavaScript.

## Features

- Neumorphic visual design
- Responsive parallax-style slider
- Pure HTML and Vanilla CSS
- No JavaScript
- No external dependencies
- CSS-only slide navigation
- Layered depth effects
- Smooth transitions
- Responsive on desktop, tablet, and mobile
- Reduced-motion support
- Works directly by opening `demo.html`
