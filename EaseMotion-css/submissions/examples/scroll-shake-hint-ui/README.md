# Scroll Shake Hint

A small chevron shakes back and forth inviting the visitor to scroll.

## Features
- Infinite shake animation
- Arrow + label cue
- Fades at the bottom of the viewport
- Pure CSS

## Usage
```html
<div class="ssh-stage"><div class="ssh-arrow"></div></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
