# ease-skew-drawer-bh

Pure CSS skew-active drawer for fintech dashboards.

## Features
- Skew hover effect
- Multiple positions
- Responsive design
- Accessibility support

## Usage
```html
<div class="ease-drawer ease-drawer-skew">Content</div>
```

## CSS Classes
- `.ease-drawer` - Base drawer
- `.ease-drawer-skew` - Skew hover effect
