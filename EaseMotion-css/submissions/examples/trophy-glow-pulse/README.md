# Trophy Glow Pulse

A trophy icon pulses with a golden glow to celebrate a win.

## Features
- Golden glow pulse
- Rising sparkle dots
- Winning badge context
- Pure CSS

## Usage
```html
<div class="tgp-trophy">&#127942;</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
