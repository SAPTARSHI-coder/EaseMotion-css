Switch with Icon

A status switch whose icon swaps from a bell-off to a bell-ring as it turns on.

Default

Notifications

Pre-checked

Sound alerts

Disabled

Locked setting

Usage

<label class="ease-switch-icon">
  <input type="checkbox" class="ease-switch-icon-input" />
  <span class="ease-switch-icon-track">
    <span class="ease-switch-icon-knob">
      <svg class="ease-switch-icon-bell-off">...</svg>
      <svg class="ease-switch-icon-bell-on">...</svg>
    </span>
  </span>
</label>

No JavaScript required — the icon swap and knob slide are driven entirely by the :checked pseudo-class via the sibling combinator.
