# Neon Border Card Hover

A modern **CSS-only Neon Border Card Hover** effect created for EaseMotion CSS.

## Features

- 🌈 Animated gradient border
- ✨ Smooth hover animation
- 💡 Soft neon glow
- 🎨 Modern UI
- 📱 Responsive layout
- 🚫 No JavaScript required

## Folder Structure

```
neon-border-card-hover/
├── demo.html
├── style.css
└── README.md
```

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over the card to see the animated neon border and glow effect.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Gradients
- CSS Animations
- Pseudo Elements

## Preview

The demo displays a modern card with:

- Animated glowing border
- Floating hover effect
- Interactive button
- Dark theme background
