# CSS Bounce-Pulse Modal

A modern **Bounce-Pulse Modal** built using pure HTML5 and CSS3 for Gaming Hub layouts. The modal opens with a smooth bounce-pulse animation while remaining lightweight, responsive, and accessible.

---

## ✨ Features

- Pure HTML5 & CSS3
- Bounce-pulse opening animation
- Gaming-inspired interface
- Fully responsive
- CSS Custom Properties
- Lightweight and performant
- Accessible structure
- `prefers-reduced-motion` support
- No JavaScript required

## 🚀 Usage

1. Copy the component into your project.
2. Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

3. Open `demo.html` in your browser.
