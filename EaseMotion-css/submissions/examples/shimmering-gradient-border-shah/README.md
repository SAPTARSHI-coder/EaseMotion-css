# Shimmering Gradient Border

1. What does this do? Creates a card component where an animated, colorful gradient continuously spins along the border of the element, creating a premium "shimmering edge" effect.
2. How is it used? Apply `.shimmer-border-card` to an outer container, and place your content inside a child element with the `.card-content` class.
3. Why is it useful? Premium, glowing borders are incredibly popular in Web3, AI, and SaaS design. Achieving this purely in CSS using `conic-gradient` and pseudo-elements is highly performant and gives developers an elite design token out of the box without complex SVG paths.
