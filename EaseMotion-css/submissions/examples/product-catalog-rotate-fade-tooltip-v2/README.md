\# CSS Rotate-Fade Tooltip for Product Catalog



A lightweight, pure CSS/HTML tooltip component designed for product catalog interfaces.



The tooltip combines a subtle rotation, fade, translation, and scale effect to provide a polished interaction when users hover over or focus on product badges and information controls.



\## Features



\- Pure HTML and CSS

\- No JavaScript required

\- Rotate + fade tooltip animation

\- Smooth transform and opacity transitions

\- Works with mouse hover

\- Keyboard accessible with `:focus-visible`

\- Responsive product catalog layout

\- Mobile-friendly tooltip sizing

\- CSS custom properties for easy customization

\- Supports `prefers-reduced-motion`

\- Lightweight and framework-independent

\- Suitable for product cards, badges, labels, and informational controls
