# Stack Layers 3D

Layered panels stack in 3D space and fan out on hover.

## Features
- translateZ layering
- Fan-out spread on hover
- Keeps centre of focus
- Pure CSS transform choreography

## Usage
```html
<div class="sl3-layer" style="--d:34px">2</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
