# Morphing Floating Action Menu (FAB Speed Dial) Component

A material speed-dial Floating Action Button (FAB) menu featuring icon rotation physics, radial action buttons, and tooltip previews.

## What does this do?
Renders an interactive floating action menu with spring-rotation hover transformations and animated tooltip labels for quick mobile actions.

## How is it used?
1. Open `demo.html` to preview the FAB menu animations.
2. Integrate `.fab-container` into mobile app layouts or dashboard corners.
3. Import `style.css` to enable spring transform keyframes.

## Why is it useful?
Provides an efficient, space-saving mobile navigation pattern. Hardware-accelerated CSS transforms ensure 60fps responsiveness across devices.
