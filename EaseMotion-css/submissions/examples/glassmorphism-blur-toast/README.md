# Glassmorphism Blur Toast

A modern notification/toast component featuring a translucent
Glassmorphism Blur visual style.

## Features

- Pure HTML and Vanilla CSS
- No external JavaScript
- Glassmorphism-inspired translucent surface
- Strong backdrop blur and saturation
- Animated glass reflection
- Soft accent glow
- Smooth hover elevation
- Dark-mode compatible
- Responsive layout
- Hardware-accelerated transforms
- Accessible notification semantics
- Keyboard-accessible close button
- Visible focus state
- `prefers-reduced-motion` support
- No external dependencies
