# Juggling Balls · Balls Juggle in Arc 🟠

An interactive juggling simulation with realistic arc motion, catching, and throwing physics. Watch balls arc through the air in a graceful pattern!

## Features

- 🟠 **Juggling Balls** – Realistic arc motion
- 🎚️ **Speed Control** – Adjust juggling speed (1-10)
- 🎚️ **Ball Count** – Adjust number of balls (3-7)
- ⏸️ **Pause/Resume** – Toggle animation
- 🔄 **Start/Stop** – Control juggling
- 🔄 **Reset** – Reset all balls
- 📊 **Counter** – Tracks catches and throws

## How to Use

1. Click **START** or press **Space** to begin juggling
2. Click **STOP** or press **Space** again to stop
3. Adjust **Speed** for juggling pace
4. Adjust **Balls** for number of balls
5. Press **RESET** or **R** to reset
6. Press **PAUSE** or **P** to pause/resume animation

## Controls

| Action | Method |

## Technical Details

- **Motion:** Sinusoidal arc pattern
- **Physics:** Independent ball phases
- **Rendering:** Glowing balls with trail
- **Performance:** 60fps with requestAnimationFrame

## Customization

You can easily customize:
- **Speed:** Adjust slider range (1-10)
- **Balls:** Adjust slider range (3-7)
- **Colors:** Modify ball colors
- **Arc Height:** Adjust amplitude
- **Trail:** Modify trail length
