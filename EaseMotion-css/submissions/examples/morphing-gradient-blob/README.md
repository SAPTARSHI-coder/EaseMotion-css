# Morphing Gradient Blob

Three gradient blobs that morph between rounded shapes behind hero content.

## Features
- Blobs morph border-radius continuously
- Saturated gradients blur into the backdrop
- Each blob moves on its own offset path

## Usage
```html
<div class="stage">
  <div class="mg-blob mg-b1"></div>
  <div class="mg-blob mg-b2"></div>
  <div class="mg-blob mg-b3"></div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
