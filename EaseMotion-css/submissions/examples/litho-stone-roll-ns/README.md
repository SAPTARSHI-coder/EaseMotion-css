# Litho Stone Roll

## What does this do?
Renders a self-contained CSS-only `ease-litho-stone-roll` demo: Lithographic roller inking a prepared stone.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-litho-stone-roll`. No build step or JavaScript is required for the effect.

```html
<section class="ease-litho-stone-roll">
  <div class="ease-litho-stone-roll__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
