# Masonry Grid

A Pinterest-style masonry layout built with CSS columns and colorful gradient tiles.

## Features
- True masonry flow via CSS multi-column layout
- Varied tile heights create organic rhythm
- Cards lift and pop their shadow on hover

## Usage
```html
<div class="mg-grid">
  <div class="mg-item a">Tile</div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
