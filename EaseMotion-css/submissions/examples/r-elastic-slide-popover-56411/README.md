# CSS Elastic-Slide Popover

A modern **Elastic-Slide Popover** built using pure HTML5 and CSS3 for Gaming Hub layouts. The popover slides into view with a smooth elastic effect while remaining lightweight, responsive, and accessible.

---

## ✨ Features

- Pure HTML5 & CSS3
- Elastic slide animation
- Gaming-inspired design
- Fully responsive
- CSS Custom Properties
- Keyboard accessible
- Lightweight and performant
- `prefers-reduced-motion` support
- No JavaScript required
