# Gradient Wave Ocean 🌊✨

A mesmerizing ocean scene with layered gradient waves, floating bubbles, twinkling sparkles, and a glowing celestial body. Built entirely with pure CSS animations and border-radius morphing.

## Features
- **4 Layered Wave Systems**: Each with 2 wave shapes, independent speeds, and border-radius morphing.
- **Border-Radius Wave Animation**: Waves morph shape using animated `border-radius` values.
- **Floating Bubbles**: 8 bubbles rising with staggered delays and fade effects.
- **Twinkling Sparkles**: Star-like particles in the sky with independent twinkle animations.
- **Celestial Glow**: Pulsing sun/moon with radial gradient and blur.
- **Horizon Shimmer**: Animated glow line at the water's edge.
- **Hover Interaction**: Waves speed up and celestial glow intensifies on hover.
- **Zero JavaScript**: All animations are pure CSS.

## Customization
Edit CSS variables in `:root`:
- `--wave-speed`: Control base wave animation speed.
- `--wave-color-1` through `--wave-color-4`: Change wave colors.
- `--sky-top`, `--sky-mid`, `--sky-bottom`: Adjust sky gradient.
- `--glow-color`: Change the celestial body color.

## Browser Support
Works in all modern browsers. Uses CSS transforms, `border-radius` animation, and `radial-gradient`.
