# Toast with Undo Action Slot

## What does this do?

A timed toast with an Undo button and countdown rail that pauses on hover.

## How is it used?

```html
<div class="toast"><span>Item archived</span><button>Undo</button><span class="toast__countdown"></span></div>
```

Open `demo.html` in a browser to try it.

## Why is it useful?

Practical feedback pattern with readable auto-dismiss timing.
