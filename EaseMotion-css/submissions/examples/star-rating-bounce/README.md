# Star Rating Bounce

A star rating bar where stars light up with a bounce as you move across them.

## Features
- Each star springs in when lit
- Sibling fill shows partial ratings
- Shadow pop marks the active star

## Usage
```html
<div class="sr-stars">
  <span class="sr-star">&#9733;</span>
  <span class="sr-star">&#9733;</span>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
