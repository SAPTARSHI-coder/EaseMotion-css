# Inbox Item

A single conversation row that slides in, responds to hover, and shows a delivery state.

## Features
- Row slides in with a subtle clip reveal
- Hover shifts the row and expands a chevron
- Unread dot and time badge complete the layout

## Usage
```html
<div class="ii-row">
  <div class="ii-avatar ii-a1">AD</div>
  <div class="ii-body"><strong>Name</strong><span>Preview</span></div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
