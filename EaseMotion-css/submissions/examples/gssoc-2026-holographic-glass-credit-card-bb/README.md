# Holographic Glass Credit Card

A 3D perspective glassmorphic credit card component with color-dodge holographic sheen animations and contactless payment iconography.

## 1. What does this do?
This component renders an interactive glass credit card styled with backdrop filter blur, metallic EMV chip styling, monospaced card numerals, and dynamic rainbow sheen reflections upon focus or hover.

## 2. How is it used?
Link `style.css` and structure the card markup inside `.card-wrapper`:

```html
<link rel="stylesheet" href="style.css">

<div class="card-wrapper">
  <div class="holo-glass-card" tabindex="0">
    <div class="holographic-sheen"></div>
    <div class="card-number-display">4920 •••• •••• 8819</div>
  </div>
</div>
```

## 3. Why is it useful?
It provides Web3 platforms, crypto wallets, and fintech checkout forms with an ultra-premium, interactive payment card interface requiring zero external scripts.
