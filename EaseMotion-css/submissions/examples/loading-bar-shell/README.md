# Loading Bar Shell

A webpack-style loading bar that fills with a striped gradient and bounces at the end.

## Features
- Striped progress bar with running stripes
- Soft glow at the fill edge
- Percent label ticks upward

## Usage
```html
<div class="lb-track">
  <span class="lb-percent"></span>
  <div class="lb-fill"></div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
