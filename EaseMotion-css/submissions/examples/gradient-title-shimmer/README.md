# Gradient Title Shimmer

A big hero headline filled with a gradient that shimmers as a light band sweeps across.

## Features
- Gradient text with animated background position
- Sweeping white shimmer band
- Responsive clamp sizing for heroes

## Usage
```html
<h2 class="gs-title">Make it move</h2>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
