# Pixel Explosion · 8-bit burst 💥

An interactive 8-bit pixel art canvas where each click creates a colorful explosion effect. Pixels burst outward from the click point with retro-style colors and physics.

## Features

- 🎨 **8-bit aesthetic** – Crisp pixel blocks with a retro color palette
- 💥 **Explosion mechanics** – Click anywhere to trigger a burst effect
- 🔄 **Random patterns** – Each reset generates a new pixel arrangement
- 📱 **Touch compatible** – Works on mobile devices with tap support
- ⌨️ **Keyboard shortcut** – Press 'R' to reset the pattern
- 🖱️ **Double-click reset** – Double-click anywhere on the canvas to reset

## How to Use

1. **Click/Tap** on the canvas to create an explosion at that point
2. **Double-click** to reset the pattern completely
3. **Press 'R'** key to generate a new random pattern
4. Watch as pixels burst outward with different colors!

## Files Included

- `index.html` – Main HTML file with embedded JavaScript
- `style.css` – All styling and responsive design
- `README.md` – This documentation

## Technical Details

- Canvas size: 400×400 pixels (scaled up to 600×600 for display)
- Grid: 8×8 pixel blocks (each block is 50×50 pixels)
- 14 retro-inspired colors in the palette
- Explosion physics with random direction and strength
- Smart placement algorithm to avoid overlapping pixels

## Browser Support

Works in all modern browsers that support HTML5 Canvas:
- Chrome, Firefox, Safari, Edge
- Mobile browsers with touch support

## Run Locally

Simply open `index.html` in your browser – no server required!
