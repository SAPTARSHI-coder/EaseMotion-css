# Glass Particle Burst

A smooth glassmorphism UI effect featuring a subtle particle burst interaction.

## ✨ Features

- Pure HTML and Vanilla CSS
- Glassmorphism styling
- Particle burst hover effect
- Smooth transitions
- Responsive design
- Dark-mode friendly
- Hardware-accelerated transforms
- Keyboard-accessible button
- `prefers-reduced-motion` support
- No JavaScript or external dependencies
