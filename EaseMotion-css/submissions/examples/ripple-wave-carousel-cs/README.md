# CSS Ripple-Wave Carousel for Fintech Dashboard Layouts

A lightweight, responsive CSS-only carousel designed for fintech dashboards and financial data interfaces.

The component uses native HTML radio inputs and labels to control the active slide without JavaScript. CSS transitions and keyframe animations provide the ripple-wave visual effect during slide changes.

## Features

- Pure HTML and CSS
- No JavaScript required
- No external JavaScript frameworks
- CSS-only slide navigation
- Ripple-wave transition animation
- Previous and next controls
- Dashboard-oriented financial UI
- Responsive desktop, tablet, and mobile layouts
- Keyboard-friendly native form controls
- Visible focus behavior through native labels
- `prefers-reduced-motion` support
- EaseMotion utility class integration
- Customizable CSS properties
- Scoped component class names using the `-rwcf` suffix
