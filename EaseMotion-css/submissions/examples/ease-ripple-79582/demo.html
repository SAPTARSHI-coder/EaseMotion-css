Ease Ripple Utility

A lightweight, pure CSS, JavaScript-free utility class for Material-style click ripples.

Example 1: Standard Button

Ripples inherit the text color by default (currentColor) at reduced opacity.

Example 2: Custom Colors

Easily override the ripple color via the --ease-ripple-color CSS variable.

Example 3: Custom Durations

Control the animation speed via --ease-ripple-duration.

Example 4: Links & Block Elements

The utility works seamlessly on links and list/card items as long as they are structurally clickable.
