File Size Optimization Script

This submission provides a Node.js utility to aggressively strip legacy vendor prefixes (like -moz-, -ms-, and -o-) from the compiled easemotion.min.css bundle.

Why do this?

If you are building a modern web application that drops support for Internet Explorer 11 and ancient versions of Firefox, you do not need the heavy legacy vendor prefixes that EaseMotion ships with by default. This script strips them out, drastically reducing the file size and saving network bandwidth for your users.

How to use:

# Navigate to this example folder
cd submissions/examples/file-size-optimization-script/

# Run the script
node optimize.js
