# CSS Ripple Wave Modal

## Overview

A responsive gaming-inspired modal with a ripple wave animation built using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Responsive Modal
- Ripple Wave Animation
- CSS Custom Properties
- Accessible (`prefers-reduced-motion`)
- No JavaScript Required

## Folder Structure

```text
ripple-wave-modal/
├── demo.html
├── style.css
└── README.md
```

## Usage

1. Open `demo.html` in your browser.
2. Click **Open Modal**.
3. Customize the CSS variables as needed.

## CSS Variables

- `--primary`
- `--background`
- `--modal`
- `--text`
- `--duration`

## Browser Support

- Chrome
- Firefox
- Edge
- Safari
