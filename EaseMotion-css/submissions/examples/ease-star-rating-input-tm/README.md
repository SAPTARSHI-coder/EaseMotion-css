# Star Rating Input Component

**Issue:** [#71811](https://github.com/SAPTARSHI-coder/EaseMotion-css/issues/71811)

Interactive star rating with hover preview using pure CSS sibling selectors.

## Design Tokens

| Token | Default |
|-------|---------|
| `--tm-star-size` | `2.5rem` |
| `--tm-star-filled` | `#f59e0b` |
| `--tm-star-hover` | `#fbbf24` |
| `--tm-star-empty` | `#334155` |
| `--tm-star-gap` | `0.25rem` |

## Classes

- `.star-row` — interactive rating group
- `.star` — individual star (&#9733; for filled, &#9734; for empty)
- `.star-display` — read-only variant
