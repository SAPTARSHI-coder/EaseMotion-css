ease-accordion CSS color-mix() Demo

Look at the hover states and badges:

The translucent badge background, the badge border, the bright badge text, and the button hover/active states are all computed dynamically by the browser using color-mix() from a single base color variable.

To change the theme, you only need to change --ease-base-color once!

✨ Computed Emerald Theme

Emerald Card

Hover over the button below. The darker hover color is mixed on the fly by blending Emerald with 15% black in the sRGB color space.

🌹 Computed Rose Theme

Rose Card

The badge background here is just the Rose base color mixed with 85% transparency. The border is the base color at 40% opacity.

⚡ Computed Amber Theme

Amber Card

No need to define --amber-light or --amber-darker in your CSS ever again. The browser does the math natively.
