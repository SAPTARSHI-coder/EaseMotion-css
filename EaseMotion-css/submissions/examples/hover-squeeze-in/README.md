# Hover Squeeze In

A button compresses horizontally then springs back, like a squeeze.

## Features
- Keyframe squeeze sequence
- Crisp scale pulse
- Retains text clarity
- Pure CSS

## Usage
```html
<button class="hsi-btn">Squeeze me</button>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
