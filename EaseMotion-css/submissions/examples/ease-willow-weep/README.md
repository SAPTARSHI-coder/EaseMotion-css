# 🌿 Willow Weep – Willow Branches Droop and Sway

> A calming weeping willow component where branches droop and sway with 4 seasons (Spring, Summer, Autumn, Winter), wind control (0-100%), and organic branch physics.

---

## 📖 Description

The **Willow Weep** component creates a calming weeping willow experience where branches droop and sway with organic motion. Built with vanilla HTML, CSS, and JavaScript, it features 4 seasons (Spring, Summer, Autumn, Winter), wind control (0-100%), and recursive branch generation for a realistic tree experience.

### 🎯 Core Features

- **Weeping willow** – branches droop and sway with organic physics
- **4 seasons** – Spring, Summer, Autumn, Winter with unique colors
- **Wind control** – adjust wind from 0-100%
- **Recursive branches** – realistic branch structure with depth (5 levels)
- **Leaves** – seasonal leaves on terminal branches
- **Branch counter** – tracks number of branches
- **Interactive controls** – slider, season buttons, keyboard shortcuts
- **Responsive design** – adapts to different screen sizes

| Method | Action |
|--------|--------|
| **Slider** | Adjust Wind (0-100%) |
| **Buttons** | Season selection |
| **Keyboard** | `R` – Reset |

### ✨ Willow Experience

When interacting:
1. **Branches sway** – drooping branches move with wind
2. **Wind applies** – controls sway intensity
3. **Season applies** – changes colors
4. **Leaves rustle** – seasonal leaves appear
5. **Status updates** – shows current state

### 💡 Why Use This Component?

- Perfect for nature scenes, meditation apps, or calming interfaces
- Realistic weeping willow with organic motion
- Self-contained – no external dependencies or frameworks
- Easy to customize (colors, wind behavior, branch structure)
- 4 seasons for variety
- Wind control for customization

### 🛠️ Technologies Used

- **HTML5** – semantic structure with Canvas
- **CSS3** – gradients, backdrop-filter, transforms
- **JavaScript (ES6)** – Canvas API, requestAnimationFrame, recursive tree generation

### 🎨 Design Philosophy

This component embodies **EaseMotion CSS's animation-first philosophy** through:

- **Organic motion** – branches sway naturally
- **Recursive structure** – realistic tree growth
- **Seasonal colors** – dynamic color changes
- **Visual feedback** – status updates, counter, controls
- **Calming atmosphere** – nature-inspired visuals
- **Human-readable classes** – `.willow-controls`, `.season-btn`, `.willow-text`

### 🔧 Customization Options

| Property | Location | Default |
|----------|----------|---------|
| Seasons | `seasons` object | 4 seasons |
| Wind range | `windSlider` | 0-100% |
| Branch depth | `maxDepth` | 5 |
| Branch length | `length` | 60px |
| Droop amount | `droop` | 0.3-0.6 |
