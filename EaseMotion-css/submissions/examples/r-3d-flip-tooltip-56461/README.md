# CSS 3D-Flip Tooltip

A modern **3D-Flip Tooltip** built using pure HTML5 and CSS3 for Gaming Hub layouts. The tooltip flips into view using a smooth 3D rotation while remaining lightweight, responsive, and accessible.

---

## ✨ Features

- Pure HTML5 & CSS3
- 3D flip tooltip animation
- Gaming-inspired interface
- Responsive layout
- CSS Custom Properties
- Lightweight and performant
- Accessible semantic HTML
- Keyboard focus support
- `prefers-reduced-motion` support
- No JavaScript required

## 🚀 Usage

1. Copy the component into your project.
2. Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

3. Open `demo.html` in your browser.
