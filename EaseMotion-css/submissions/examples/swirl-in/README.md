# Swirl In Animations

**What does this do?**
Provides dynamic `swirl-in` entrance animations that simultaneously combine deep rotation (`rotate(540deg)`), extreme scaling, and opacity transitions to create a swirling/tornado effect.

**How is it used?**
Apply the utility classes to the elements you want to swirl into view:
```html
<div class="swirl-in-fwd-ag">Swirls forward from a scaled-down state</div>
<div class="swirl-in-bck-ag">Swirls backward from a scaled-up state</div>
```

**Why is it useful?**
Combining multiple transformation properties (scale, rotate, opacity) creates highly energetic, eye-catching entrances, perfect for revealing hero graphics, badges, or celebratory popups.
