\# Quantum Particle Collider Component



A scientific subatomic particle accelerator component featuring high-speed orbiting particles, counter-rotating magnetic rings, and a glowing collision nucleus built for EaseMotion CSS.



\## Location

\- Directory: `submissions/examples/quantum-particle-collider-ij/`



\## Files Included

\- `demo.html`: Interactive preview window showcasing the particle collider simulation.

\- `style.css`: Scoped orbital styling and keyframe rules (`ease-collider-spin-cw`, `ease-collider-spin-ccw`, `ease-collider-flash`).

\- `README.md`: Documentation for the component submission.
