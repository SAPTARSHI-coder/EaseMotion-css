# CSS Ripple-Wave Drawer

A lightweight, responsive drawer interaction for minimalist technology interfaces.

The component uses pure HTML and CSS to create a sliding navigation drawer with layered ripple-wave effects during the reveal animation.

## Features

- Pure HTML and CSS
- No JavaScript or external dependencies
- Layered ripple-wave reveal animation
- Smooth drawer slide-in transition
- Responsive desktop, tablet, and mobile layouts
- Interactive navigation links
- Keyboard focus states
- CSS custom properties for easy customization
- `prefers-reduced-motion` support
- Self-contained demo that works without a server
