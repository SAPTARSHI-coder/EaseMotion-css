## 🚀 Usage
1. Clone or copy the files into your project.
2. Open `index.html` in your browser.
3. Hover over the button to see the metallic sheen animation.

---

## 🛠️ Customization
- **Sheen speed** → Adjust `animation: sheen 3s` for faster/slower effect.
- **Sheen angle** → Change `rotate(25deg)` for different reflection angles.
- **Colors** → Modify gradient stops for custom metallic looks.
- **Button size** → Adjust padding and font-size in `.sheen-btn`.

---

## 📖 Accessibility
- Large button with clear text.
- Smooth motion avoids harsh flicker.
