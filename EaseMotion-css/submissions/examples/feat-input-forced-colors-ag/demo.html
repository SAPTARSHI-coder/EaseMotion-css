Input: Forced Colors Support

How to test: Open browser DevTools, press Ctrl+Shift+P (or Cmd+Shift+P), type "Emulate CSS forced-colors", and select "forced-colors: active". Alternatively, enable Windows High Contrast Mode.
Interactive Input
This component fully supports forced-colors mode. Shadows are replaced by high-contrast system borders, and all colors adapt to CanvasText and Highlight variables to ensure 100% readability.
Disabled State
In forced-colors mode, disabled elements use the GrayText system color instead of relying on opacity.
