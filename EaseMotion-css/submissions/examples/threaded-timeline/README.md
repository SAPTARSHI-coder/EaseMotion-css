# Threaded Timeline

Threaded Timeline is an experimental timeline component that replaces conventional timeline cards with a single continuous visual thread.

Each event is represented by a small node connected to the same thread, creating the feeling of one continuous story.

## ✨ Features

- Continuous SVG timeline thread
- Interactive event nodes
- Dynamic event details
- Thread deformation
- Active event stitching effect
- Keyboard accessibility
- Pointer interaction
- Touch support
- Responsive layout
- Reduced-motion support
- Dependency-free
- Vanilla JavaScript
