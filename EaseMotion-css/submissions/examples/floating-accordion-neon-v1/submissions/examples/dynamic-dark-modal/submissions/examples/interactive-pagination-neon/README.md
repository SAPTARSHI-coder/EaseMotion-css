# Interactive Pagination with Neon Styling

A responsive CSS-only pagination component featuring a futuristic neon design with glowing hover effects and active page highlighting.

## Features

- Pure HTML & CSS
- Responsive layout
- Neon glow hover animation
- Active page indicator
- Previous & Next navigation buttons
- Circular pagination buttons
- Accessible navigation using `<nav>`
- No JavaScript required

## Folder Structure

```
interactive-pagination-neon/
├── demo.html
├── style.css
└── README.md
```

## Technologies

- HTML5
- CSS3
- Flexbox
- CSS Transitions
- Responsive Design

## Purpose

This component provides a reusable neon-themed pagination interface suitable for blogs, documentation sites, dashboards, portfolios, and admin panels while following the lightweight philosophy of EaseMotion CSS.
