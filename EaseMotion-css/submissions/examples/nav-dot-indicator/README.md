# Nav Dot Indicator

A glowing dot hops between navigation items in sequence.

## Features
- Hopping indicator dot
- Sequential travel
- Glow trail
- Pure CSS

## Usage
```html
<nav class="ndi-nav"><a href="#" class="ndi-item">One</a><i class="ndi-dot"></i></nav>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
