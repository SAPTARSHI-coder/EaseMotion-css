# Ease WebGL/SVG Distortion Fluid Glitch Headline (`ease-liquid-distorted-glitch-headline`)

Applies SVG displacement filters to distort headline typography into liquid waves on hover pointer movement.

## Features
- SVG filter turbulence wave distortion
- Interactive frequency acceleration on hover mousemove
- Chromatic aberration RGB split keyframes
- Hardware-accelerated text rendering
- Accessible fallback title markup
