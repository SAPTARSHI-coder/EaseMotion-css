# Neumorphic Soft Shadow Card

A smooth and accessible card component featuring a soft neumorphic shadow style using pure HTML and Vanilla CSS.

No JavaScript or external dependencies are required.

## Features

- Pure HTML and Vanilla CSS
- Neumorphic soft-shadow styling
- Raised card elevation
- Soft light and dark shadow layers
- Smooth hover interaction
- Interactive button with pressed state
- Responsive design
- Dark-mode compatible
- Hardware-accelerated transforms
- Keyboard focus styling
- Reduced-motion support
- No external dependencies
