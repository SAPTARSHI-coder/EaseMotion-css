# Lightbox Card

A gallery tile that expands into a full-screen lightbox overlay using only the CSS :target selector.

## Features
- Click a tile to open a true full-screen lightbox
- Dismissible with the :target pseudo-class, no JavaScript
- Cross-fade transition between states

## Usage
```html
<a class="tile" href="#lb-1">Open</a>
<div class="lightbox" id="lb-1">...</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
