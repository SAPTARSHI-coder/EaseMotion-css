# Status Code Badge

A small API status badge that pulses with a soft ring and a color per state.

## Features
- Colored dot with a ping ring
- Badge label keeps its monospace look
- Ring pulse indicates a live check

## Usage
```html
<span class="sc-badge sc-ok"><span class="sc-dot"></span>200 OK</span>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
