# Liquid Fill Animated Text Utility

1. **What does this do?**  
   Creates a smooth, continuous wave/liquid gradient animation inside typography elements using text clipping.

2. **How is it used?**  
   Apply the `.ease-liquid-fill` class to any text or heading element:
   ```html
   <h1 class="ease-liquid-fill">Liquid Fill Effect</h1>
   ```

3. **Why is it useful?**  
   Enhances modern landing pages, hero titles, badges, and loading indicators with dynamic liquid motion typography while maintaining lightweight CSS performance.
