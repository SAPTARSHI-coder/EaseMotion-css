# Holographic Product Card

A futuristic, responsive product card built with pure HTML and CSS.

The component uses layered gradients, holographic lighting, hover
refraction, depth movement and accessible reduced-motion support.

## Features

- Pure HTML and CSS
- No JavaScript required
- Holographic lighting effect
- Hover-based light refraction
- 3D-inspired card movement
- Animated product orb
- Responsive design
- Keyboard-accessible CTA
- `prefers-reduced-motion` support
- Customizable CSS custom properties
- Lightweight implementation
