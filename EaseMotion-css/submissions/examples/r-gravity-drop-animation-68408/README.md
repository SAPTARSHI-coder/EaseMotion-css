# CSS Gravity Drop Animation

A pure CSS gravity-inspired entrance animation where elements fall into position and settle with a natural bounce.

## Features

- Pure HTML and CSS
- No JavaScript required
- Gravity-inspired falling motion
- Natural bounce and settling effect
- Staggered card entrance
- Responsive layout
- Customizable CSS variables
- Lightweight keyframe animation
- `prefers-reduced-motion` support
