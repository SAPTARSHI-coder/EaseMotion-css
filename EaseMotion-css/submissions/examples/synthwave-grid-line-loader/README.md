# Synthwave Grid Line Loader

A futuristic **Synthwave Grid Line Loader** built using pure HTML and
Vanilla CSS.

This component creates an animated retro-futuristic loading effect using
CSS perspective, gradients, transforms, shadows, and keyframe animations.

## ✨ Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Responsive design
- Synthwave-inspired animated grid
- Perspective-based motion
- Animated horizon glow
- Pulsating neon sun
- Dark-mode friendly
- Hardware-accelerated transforms
- `prefers-reduced-motion` support
- High-contrast support
- Accessible loading status
