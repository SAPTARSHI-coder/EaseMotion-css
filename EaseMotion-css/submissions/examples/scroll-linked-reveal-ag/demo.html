How it works

Using the modern CSS @supports (animation-timeline: view()) directive, these utilities bind CSS animations directly to scroll progress. In unsupported browsers, elements gracefully fall back to full opacity with no shift, keeping the site fully accessible.

ℹ️

Browser Compatibility Notice

Scroll-linked animations are supported in modern Chrome, Edge, Opera, and other Chromium-based browsers. Safari and Firefox will display the content normally (visible by default) as a progressive fallback.
