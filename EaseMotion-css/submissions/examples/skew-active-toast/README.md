# CSS Skew-Active Toast

A modern pure CSS animated toast notification component created for **EaseMotion CSS**.

This component uses skew transformations, glassmorphism styling, and smooth CSS animations to create an active notification effect suitable for product catalog layouts.

## ✨ Features

- Pure HTML & CSS implementation
- Skew entrance animation
- Hover skew reset interaction
- Glassmorphism UI style
- Smooth pulse glow effect
- Fully responsive design
- Supports reduced motion accessibility
