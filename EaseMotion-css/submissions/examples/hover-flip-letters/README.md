# Hover Flip Letters

Each letter of a word flips 180 degrees in turn on hover.

## Features
- Per-letter 3D flip
- Staggered cascade delay
- Backface hidden
- Pure CSS

## Usage
```html
<div class="hfl-word"><span style="--i:0">H</span></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
