# Letter From Envelope Open

## What does this do?

An envelope flap opens, then a letter rises into view.

## How is it used?

```html
<label class="envelope"><input type="checkbox"/><div class="envelope__letter">Invite</div></label>
```

Open `demo.html` in a browser to try it.

## Why is it useful?

Classic storytelling microinteraction for invites and mail UI.
