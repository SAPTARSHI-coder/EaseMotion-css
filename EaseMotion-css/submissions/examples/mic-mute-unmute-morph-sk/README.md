# Mic Mute Unmute Icon Morph

## What does this do?

A microphone control that morphs between unmuted and muted slash states.

## How is it used?

```html
<label class="mic"><input type="checkbox"/><span class="mic__icon"></span></label>
```

Open `demo.html` in a browser to try it.

## Why is it useful?

Essential call-control microinteraction with clear pressed/muted feedback.
