# Interactive Demo Navigation Component

A responsive demo header and navigation component featuring a dedicated `Home` anchor link to seamlessly return to the hero section from anywhere on the page.

## Features
- Dedicated `Home` navigation item linked to `#home`.
- Smooth scrolling integration (`scroll-behavior: smooth`).
- Responsive sticky navbar with dark theme styling.
- Zero dependencies — pure HTML and CSS.

## Usage
Open `demo.html` directly in any web browser.
