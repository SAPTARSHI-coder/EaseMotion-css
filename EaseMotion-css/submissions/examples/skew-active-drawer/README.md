# CSS Skew-Active Drawer

A responsive navigation drawer with skew hover and active state effects built using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Skew hover animation
- Active navigation state
- Responsive layout
- CSS Custom Properties
- Accessible structure
- prefers-reduced-motion support
