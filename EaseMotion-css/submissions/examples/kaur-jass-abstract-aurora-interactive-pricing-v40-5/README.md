# Abstract Aurora Interactive Pricing Component (v40.5)

An interactive, responsive, glassmorphic pricing component featuring an abstract animated CSS aurora background and dynamic billing logic.

## 🌟 Features

- **Abstract Aurora Background**: Pure CSS fluid blob animations running in the background.
- **Dynamic Billing Switch**: Interactive Monthly vs. Annual toggle with animated price recalculations and a discount badge.
- **Glassmorphism Styling**: Backdrop filters, modern gradients, and border-glow hover effects.
- **Mobile Responsive**: Flex/Grid layout that adapts effortlessly from mobile viewports to desktop monitors.
- **Accessible & Accessible-First**: Focus states, clean markup, and `prefers-reduced-motion` fallbacks.
