# Minimalist Sliding Tab Selector with Smooth Spring Physics

A modern dark-mode sliding tab selector built with HTML, CSS, and vanilla JavaScript.

## Features

- Minimalist dark-mode design
- Smooth spring-inspired sliding indicator
- Responsive mobile layout
- Keyboard-accessible tabs
- ARIA tab semantics
- Hover and focus states
- Reduced-motion accessibility support
- No external dependencies
