# Micro Ripple Input

An input whose background ripples from the cursor point whenever you focus it.

## Features
- Ripple originates at the click point
- Ripple fades as the border lights
- Bottom border slides across on focus

## Usage
```html
<div class="mr-wrap">
  <input class="mr-input" placeholder="Type something&hellip;" />
  <span class="mr-ripple"></span>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
