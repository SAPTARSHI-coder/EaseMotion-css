# Web Paint API Houdini Custom Ripple Worklet

## Overview
GPU-accelerated liquid ripple rendering component using the CSS Painting API (`CSS.paintWorklet`).

## Structure
- `paint-worklet.js` — Houdini paint worklet script
- `demo.html` — Houdini button demo
- `style.css` — `@property` keyframe declarations
- `README.md` — Documentation
