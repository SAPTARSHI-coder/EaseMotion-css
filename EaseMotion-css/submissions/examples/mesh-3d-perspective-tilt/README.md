# CSS 3D Perspective Tilt

A smooth, responsive, and reusable **3D Perspective Tilt** component built using pure HTML and vanilla CSS.

It combines layered mesh gradients with CSS 3D transforms to create a floating perspective effect without JavaScript or external libraries.

## Features

- Pure HTML and vanilla CSS
- 3D perspective transforms
- Layered mesh gradients
- Smooth hover transitions
- Responsive layout
- Dark-mode compatible
- Hardware-accelerated transforms
- Reduced-motion support
- No JavaScript dependencies
- Works by opening `demo.html` directly in a browser

## Preview

The demo contains:

- A primary 3D perspective mesh card
- Layered gradient depth
- Grid overlay for additional depth
- Supporting perspective card variations
- Responsive behavior for smaller screens
