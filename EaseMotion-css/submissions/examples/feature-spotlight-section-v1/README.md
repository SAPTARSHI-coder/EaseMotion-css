# CSS Feature Spotlight Section

A modern and reusable Feature Spotlight Section built using pure HTML and
vanilla CSS.

## ✨ Features

- Pure HTML and CSS
- Responsive layout
- Modern glassmorphism design
- Animated feature presentation
- CSS gradient effects
- Smooth hover interactions
- Keyboard-accessible buttons
- Visible focus states
- Dark-mode friendly
- `prefers-reduced-motion` support
- No JavaScript
- No external dependencies
