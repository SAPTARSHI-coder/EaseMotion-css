# Glassmorphism Blur Toggle #603

A smooth, accessible, and performant **pure CSS toggle switch** featuring **Glassmorphism Blur styling**.  
Built with **HTML + Vanilla CSS** — no external JavaScript required.

---

## ✨ Features
- Glassmorphism blur background with glowing accent
- Smooth hardware-accelerated transitions
- Accessible with `aria-label`
- Dark mode compatible
- Pure CSS implementation (no JS)

---

## 📂 Project Structure
## 🚀 Usage
1. Clone or copy the files into your project.
2. Open `index.html` in your browser.
3. Toggle the switch to see the blur + glow animation.

---

## 🛠️ Customization
- **Size** → Adjust `width` and `height` in `.toggle`.
- **Blur strength** → Modify `backdrop-filter: blur(8px)` for stronger/weaker blur.
- **Colors** → Change `background` and glow values for custom themes.
- **Dark mode** → Uses `prefers-color-scheme: dark` media query.

---

## 📸 Demo Preview
The toggle animates with a glowing blur effect when switched **ON**, and a frosted glass look when **OFF**.

## 📖 Accessibility
- Uses `aria-label` for screen readers.
