# CSS Wavy Image Border

A responsive image component featuring an animated, wavy gradient border created entirely with CSS.

## Features

- Animated wavy border
- CSS-only implementation
- Responsive image layout
- Gradient border animation
- Smooth image hover effect
- Semantic figure and image markup
- Descriptive image alternative text
- Reduced-motion support
- No JavaScript required

## Files

- `demo.html` — Interactive image demonstration
- `style.css` — Wavy border and component styling
- `README.md` — Feature documentation

## Usage

Place an image inside the `wave-frame` container:

```html
<div class="wave-frame">
  <div class="image-wrap">
    <img
      src="image.jpg"
      alt="Description of the image"
    >
  </div>
</div>
