# CSS Sunflower

A decorative animated sunflower created entirely with HTML and CSS.

The component demonstrates how CSS transforms, gradients, keyframes,
and pseudo-elements can be combined to create a flower animation
without JavaScript.

## Features

- Pure HTML and CSS
- No JavaScript
- Rotating sunflower petals
- Animated stem sway
- Animated leaf movement
- CSS gradients for natural-looking colors
- Responsive design
- Dark atmospheric background
- Reduced-motion accessibility support
- Lightweight and dependency-free

## Files

- `demo.html` — Sunflower markup and component structure
- `style.css` — Complete styling and animations

## Animation

The petals rotate continuously using a CSS keyframe animation:

```css
@keyframes flower-rotate {
  from {
    transform: translateX(-50%) rotate(0deg);
  }

  to {
    transform: translateX(-50%) rotate(360deg);
  }
}
