# Neumorphic SaaS Loader

A modern, responsive loading component built using pure HTML and CSS.

This component combines a soft neumorphic interface with a modern SaaS-inspired loading animation.

## ✨ Features

- Pure HTML and CSS
- No JavaScript required
- Neumorphic UI styling
- Animated circular loader
- Animated loading dots
- Animated progress indicator
- Responsive design
- Mobile friendly
- Accessible loading state
- `prefers-reduced-motion` support
- Modern SaaS-inspired visual design
- Lightweight and easy to customize
