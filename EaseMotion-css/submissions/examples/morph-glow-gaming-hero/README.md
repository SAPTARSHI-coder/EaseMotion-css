# 🎮 Morph-Glow Gaming Hero Section

A modern **Gaming Hub Hero Section** built with **pure HTML and CSS** featuring morphing glow effects, glassmorphism cards, responsive layouts, and accessibility support.

---

## ✨ Features

- 🎮 Modern gaming-inspired hero section
- 🌈 Morphing animated glow background
- 💡 Glowing circular highlight behind the hero image
- 🪟 Glassmorphism statistic and floating cards
- 🚀 Smooth hover animations and transitions
- 🎨 CSS Custom Properties for easy theme customization
- 📱 Fully responsive design
- ♿ Supports `prefers-reduced-motion`
- 🚫 No JavaScript or external frameworks

## 🎨 CSS Custom Properties

The design uses CSS variables for easy customization.

```css
:root{
    --bg:#08111f;
    --bg2:#111c34;

    --primary:#7c3aed;
    --secondary:#06b6d4;
    --accent:#22c55e;

    --text:#ffffff;
    --muted:#cbd5e1;

    --glass:rgba(255,255,255,.08);
    --border:rgba(255,255,255,.12);

    --radius:22px;
}
```

You can modify these values to create your own gaming theme.
