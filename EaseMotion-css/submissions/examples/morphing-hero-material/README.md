# Morphing Hero Section - Material Design

A responsive hero section combining Material Design principles
with fluid CSS morphing animations and expressive visual depth.

## ✨ Features

- Fully responsive
- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Material-inspired visual hierarchy
- Animated morphing background shapes
- Animated gradient heading
- Floating visual card
- CSS orbital rings
- Responsive navigation
- CTA buttons
- Feature information strip
- Hover states
- Keyboard focus states
- Reduced-motion support
