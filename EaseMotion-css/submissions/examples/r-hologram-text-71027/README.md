# CSS Hologram Text

A futuristic CSS-only hologram text effect featuring scanlines, RGB interference, flickering, and glowing text.

## Features

- Pure CSS implementation
- Animated scanline effect
- Cyan and pink chromatic interference
- Futuristic text glow
- Subtle hologram flicker
- Responsive typography
- Animated signal indicator
- Reduced-motion support
- No JavaScript required

## Files

- `demo.html` — Interactive hologram text demonstration
- `style.css` — Hologram effects and component styling
- `README.md` — Feature documentation

## Usage

Add the `hologram` class and provide the displayed text through `data-text`:

```html
<h1 class="hologram" data-text="HOLOGRAM">
  HOLOGRAM
</h1>
