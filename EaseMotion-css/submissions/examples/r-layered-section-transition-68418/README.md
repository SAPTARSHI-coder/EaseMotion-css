# CSS Layered Section Transition

A pure CSS section transition that uses layered backgrounds and `clip-path` shapes to create a dynamic visual transition between sections.

## Features

- Pure HTML and CSS
- Layered section backgrounds
- CSS `clip-path` transitions
- Smooth decorative motion
- Responsive desktop and mobile layouts
- Semantic HTML structure
- Keyboard-accessible CTA
- `prefers-reduced-motion` support
- No JavaScript required
