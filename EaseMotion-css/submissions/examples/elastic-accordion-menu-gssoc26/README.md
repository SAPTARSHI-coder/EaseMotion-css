# Elastic Bouncing Accordion Menu Component

A pure HTML `<details>`/`<summary>` accordion menu featuring elastic spring micro-interactions, chevron rotations, and backdrop filter styling.

## What does this do?
Renders an expandable FAQ/accordion menu component with spring-bouncing keyframe transitions upon expansion.

## How is it used?
1. Open `demo.html` to click details items and observe spring transitions.
2. Incorporate `.accordion-item` elements into FAQ sections or documentation pages.
3. Import `style.css` for spring expand keyframes and chevron transitions.

## Why is it useful?
Semantic HTML `<details>` provides native accessibility out of the box. Enhancing it with CSS spring keyframe animations ensures smooth 60fps interaction without JS script handlers.
