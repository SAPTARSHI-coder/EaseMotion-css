### Is your feature request related to a problem?
EaseMotion CSS lacks a retro synthwave/outrun-themed component. The neon grid floor is an iconic visual style popular in gaming, music, and portfolio sites. A pure CSS implementation would showcase advanced 3D perspective techniques.

### Describe the solution you'd like
Add a new folder `neon-grid-floor` featuring:
1. **3D Perspective Grid** using `rotateX(75deg)` and `perspective`.
2. **Animated Grid Lines** moving towards the viewer.
3. **Striped Sun** with pulsing glow.
4. **Mountain Silhouettes** using CSS border triangles.
5. **Twinkling Stars** with staggered delays.
6. **Neon Pillars** with glow effects.
7. **Horizon Glow** line.
8. **Hover Interaction** to speed up grid.

### Alternatives considered
- WebGL/Three.js grid (requires JavaScript)
- SVG-based grid (less 3D depth)

Pure CSS approach is lightweight and demonstrates advanced perspective techniques.
