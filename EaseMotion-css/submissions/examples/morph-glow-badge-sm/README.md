# Morph-Glow Badge

A pure CSS Morph-Glow Badge designed for fintech dashboard interfaces.

The badge combines a subtle glow, smooth shape morphing, and a highlight
sweep to create a polished status indicator without JavaScript.

## Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Smooth border-radius morphing
- Hover and keyboard-focus glow
- Animated highlight sweep
- Multiple status variants
- Responsive layout
- CSS custom properties for customization
- `prefers-reduced-motion` support
- Suitable for fintech dashboards and status indicators
