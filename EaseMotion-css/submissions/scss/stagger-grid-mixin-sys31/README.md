# SCSS Staggered Grid Delay Calculation Mixin

## Overview
SCSS mixin partial using `@for` loops to auto-generate `:nth-child` animation delay rules.

## Structure
- `_stagger.scss` — Stagger mixin partial
- `demo.html` — Staggered list showcase
- `style.css` — Compiled CSS rules
- `README.md` — Documentation
