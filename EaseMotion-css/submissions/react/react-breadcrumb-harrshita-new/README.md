
# React Breadcrumb New Component

This component provides a React wrapper for the `ease-breadcrumb` CSS utility.

## Usage

```jsx
import { EaseBreadcrumbNew } from './EaseBreadcrumbNew';

function Demo() {
  return (
    <EaseBreadcrumbNew className="custom-utility">Hello EaseMotion!</EaseBreadcrumbNew>
  );
}
```

The component forwards refs, spreads extra props, and merges any custom `className` you provide with the core `ease-breadcrumb` class.
