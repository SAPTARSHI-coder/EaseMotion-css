# EaseAlertBanner

A dismissible alert banner React component with a slide-out exit transition.

## Usage

```jsx
import EaseAlertBanner from "./EaseAlertBanner";

<EaseAlertBanner type="success" message="Saved" onDismiss={{...}} />
```

## Description

Use cases: site-wide announcements, success confirmations, error notifications.

Props: type: 'info'|'success'|'warning'|'error', message: string, onDismiss: ()=>void.
