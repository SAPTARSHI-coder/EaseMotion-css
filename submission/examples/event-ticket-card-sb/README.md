# Event Ticket Card

A modern, responsive event ticket card built using pure HTML and CSS.

## What It Does

This component presents event information in a realistic digital-ticket layout.

It includes:

- Event category
- Confirmation status
- Event title and description
- Date and time
- Venue information
- Decorative QR-code section
- Ticket number
- Ticket-style perforation
- Hover animation
- Responsive mobile layout

## How to Use

1. Copy the `demo.html` and `style.css` files into the same directory.
2. Open `demo.html` directly in a web browser.
3. Customize the event title, date, time, venue, and ticket number as required.

No server, JavaScript, CDN, or external framework is required.

## Why It Is Useful

The Event Ticket Card can be used for:

- Conference websites
- Workshop registrations
- Concert pages
- Event booking platforms
- Meetup pages
- Digital ticket interfaces
- Event dashboards

The component provides a reusable ticket-style UI while keeping the implementation lightweight and dependency-free.

## Features

- Pure HTML and CSS
- Zero dependencies
- Responsive design
- CSS hover animation
- Accessible semantic structure
- Mobile-friendly layout
- Self-contained demo
- Works by opening the HTML file directly
