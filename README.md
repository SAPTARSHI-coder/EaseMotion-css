# Modern Responsive Landing Page

This submission provides a modern, responsive landing page example built entirely with EaseMotion CSS and a few custom styles for layout.

## 1. What does this do?

This submission demonstrates how to build a beautiful and animated landing page using EaseMotion's utility classes. It includes a hero section, a features grid, a call-to-action, and a footer, all responsive and enhanced with subtle animations.

## 2. How is it used?

The landing page is a self-contained example. The HTML structure in `demo.html` uses classes from the EaseMotion CSS framework for layout, components, and animations.

**Example Snippet (Hero Section):**
```html
<section class="hero ease-center ease-fade-in">
  <div class="container">
    <h1 class="ease-slide-up">Build UIs with Expressive Motion</h1>
    <p class="ease-slide-up ease-delay-200">
      A zero-dependency, animation-first CSS framework for faster, more
      beautiful interfaces.
    </p>
    <a href="#cta" class="ease-btn ease-btn-primary ease-btn-lg ease-btn-pill ease-hover-grow ease-delay-300">
      Get Started Now
    </a>
  </div>
</section>
```

## 3. Why is it useful?

This example serves as a practical, real-world showcase of EaseMotion CSS. It helps new users understand how to combine animation (`ease-fade-in`, `ease-slide-up`), layout (`ease-center`, `ease-grid`), and component (`ease-card`, `ease-btn`) classes to build a complete, polished page. It reinforces the framework's philosophy of being human-readable and animation-first.
