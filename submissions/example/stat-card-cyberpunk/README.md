# Responsive Stat Metric Card - Cyberpunk

A responsive stat metric card component featuring a cyberpunk-inspired
visual design.

The component is implemented using pure HTML and CSS with no JavaScript
dependencies.

## Features

- Pure CSS implementation
- Zero JavaScript dependencies
- Cyberpunk visual styling
- Responsive mobile, tablet, and desktop layouts
- EaseMotion CSS variables
- Reusable design tokens
- Smooth hover and state transitions
- Progress indicators
- Status indicators
- Accessible progressbar semantics
- Visible keyboard focus styles
- `prefers-reduced-motion` support
- `forced-colors` support
- No external dependencies
