# Bouncing Spring Dropdown

A smooth, playful dropdown menu featuring a **Bouncing Spring** animation.

Built entirely with HTML and vanilla CSS, with no JavaScript or external dependencies.

## ✨ Features

- Pure HTML and CSS
- No JavaScript required
- Spring-style dropdown entrance
- Subtle overshoot and settle animation
- Staggered menu item animations
- Smooth hover and focus interactions
- Native `<details>` / `<summary>` interaction
- Dark-mode friendly design
- Responsive layout
- Hardware-friendly CSS transforms
- `prefers-reduced-motion` support
- Accessible focus indicators
- Dependency-free
