# Pure CSS Magnetic Pull Tabs Component

## Description
This component implements an interactive, hardware-accelerated magnetic tab navigation interface optimized for minimalist tech aesthetic layouts. It operates with zero dependency on JavaScript for state transitions.

## Key Features
- **Zero JavaScript Runtime**: Active tabs are controlled entirely by native CSS component sibling selectors via radio buttons.
- **Custom Properties Exposed**: Easing equations, magnetic snap durations, and pull scale factors can be configured directly inside the `:root` pseudo-class.
- **Full Keyboard Accessibility**: Fully selectable via traditional layout indexing using standard browser focus states.
