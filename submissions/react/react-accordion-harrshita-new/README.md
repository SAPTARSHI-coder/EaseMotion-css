
# React Accordion New Component

This component provides a React wrapper for the `ease-accordion` CSS utility.

## Usage

```jsx
import { EaseAccordionNew } from './EaseAccordionNew';

function Demo() {
  return (
    <EaseAccordionNew className="custom-utility">Hello EaseMotion!</EaseAccordionNew>
  );
}
```

The component forwards refs, spreads extra props, and merges any custom `className` you provide with the core `ease-accordion` class.
