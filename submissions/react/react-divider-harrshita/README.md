# React Divider Integration

This is a React functional component wrapper for the `ease-divider` class.

## Usage

```jsx
import { EaseDivider } from './EaseDivider';

function App() {
  return (
    <EaseDivider className="custom-utility">
      Hello EaseMotion!
    </EaseDivider>
  );
}
```

Provides automatic ref forwarding, prop spreading, and strict styling encapsulation.
