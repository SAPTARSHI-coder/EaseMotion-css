# React Icon Integration

This is a React functional component wrapper for the `ease-icon` class.

## Usage

```jsx
import { EaseIcon } from './EaseIcon';

function App() {
  return (
    <EaseIcon className="custom-utility">
      Hello EaseMotion!
    </EaseIcon>
  );
}
```

Provides automatic ref forwarding, prop spreading, and strict styling encapsulation.
