# EaseToggleSwitch

A controlled toggle switch React component with an ARIA-correct role and animated knob.

## Usage

```jsx
import EaseToggleSwitch from "./EaseToggleSwitch";

<EaseToggleSwitch checked onChange={{(v) => console.log(v)}} label="Notify" />
```

## Description

Use cases: settings toggles, preference switches, boolean controls.

Props: checked: boolean, onChange: (v:boolean)=>void, label: string, disabled: boolean.
