
# React Badge New Component

This component provides a React wrapper for the `ease-badge` CSS utility.

## Usage

```jsx
import { EaseBadgeNew } from './EaseBadgeNew';

function Demo() {
  return (
    <EaseBadgeNew className="custom-utility">Hello EaseMotion!</EaseBadgeNew>
  );
}
```

The component forwards refs, spreads extra props, and merges any custom `className` you provide with the core `ease-badge` class.
