# EaseTabsSwitcher

A segmented tabs React component whose active pill animates between the tabs.

## Usage

```jsx
import EaseTabsSwitcher from "./EaseTabsSwitcher";

<EaseTabsSwitcher tabs={{[...]}} active="home" onChange={{...}} />
```

## Description

Use cases: settings pages, profile views, content sections.

Props: tabs: {id:string, label:string}[], active: string, onChange: (id:string)=>void.
