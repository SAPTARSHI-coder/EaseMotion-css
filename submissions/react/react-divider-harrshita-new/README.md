
# React Divider New Component

This component provides a React wrapper for the `ease-divider` CSS utility.

## Usage

```jsx
import { EaseDividerNew } from './EaseDividerNew';

function Demo() {
  return (
    <EaseDividerNew className="custom-utility">Hello EaseMotion!</EaseDividerNew>
  );
}
```

The component forwards refs, spreads extra props, and merges any custom `className` you provide with the core `ease-divider` class.
