
# React Avatar New Component

This component provides a React wrapper for the `ease-avatar` CSS utility.

## Usage

```jsx
import { EaseAvatarNew } from './EaseAvatarNew';

function Demo() {
  return (
    <EaseAvatarNew className="custom-utility">Hello EaseMotion!</EaseAvatarNew>
  );
}
```

The component forwards refs, spreads extra props, and merges any custom `className` you provide with the core `ease-avatar` class.
