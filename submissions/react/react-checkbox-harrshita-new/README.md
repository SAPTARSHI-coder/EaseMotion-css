
# React Checkbox New Component

This component provides a React wrapper for the `ease-checkbox` CSS utility.

## Usage

```jsx
import { EaseCheckboxNew } from './EaseCheckboxNew';

function Demo() {
  return (
    <EaseCheckboxNew className="custom-utility">Hello EaseMotion!</EaseCheckboxNew>
  );
}
```

The component forwards refs, spreads extra props, and merges any custom `className` you provide with the core `ease-checkbox` class.
