# React Avatar Integration

This is a React functional component wrapper for the `ease-avatar` class.

## Usage

```jsx
import { EaseAvatar } from './EaseAvatar';

function App() {
  return (
    <EaseAvatar className="custom-utility">
      Hello EaseMotion!
    </EaseAvatar>
  );
}
```

Provides automatic ref forwarding, prop spreading, and strict styling encapsulation.
