# EaseDropdownMenu

A controlled dropdown menu React component that opens with a scale-in transition.

## Usage

```jsx
import EaseDropdownMenu from "./EaseDropdownMenu";

<EaseDropdownMenu trigger="Menu" items={{[...]}} align="left" />
```

## Description

Use cases: overflow menus, user profile menus, action pickers.

Props: trigger: ReactNode, items: {label:string, onClick:()=>void}[], align: 'left'|'right'.
