
# React Pagination New Component

This component provides a React wrapper for the `ease-pagination` CSS utility.

## Usage

```jsx
import { EasePaginationNew } from './EasePaginationNew';

function Demo() {
  return (
    <EasePaginationNew className="custom-utility">Hello EaseMotion!</EasePaginationNew>
  );
}
```

The component forwards refs, spreads extra props, and merges any custom `className` you provide with the core `ease-pagination` class.
