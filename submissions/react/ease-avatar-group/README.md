# EaseAvatarGroup

An overlapping avatar-group React component that spreads the avatars on hover.

## Usage

```jsx
import EaseAvatarGroup from "./EaseAvatarGroup";

<EaseAvatarGroup users={{[...]}} max={4} size="md" />
```

## Description

Use cases: collaboration lists, team rosters, comment threads.

Props: users: {name:string, src?:string}[], max: number, size: 'sm'|'md'|'lg'.
