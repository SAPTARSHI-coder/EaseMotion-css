# React Alert Integration

This is a React functional component wrapper for the `ease-alert` class.

## Usage

```jsx
import { EaseAlert } from './EaseAlert';

function App() {
  return (
    <EaseAlert className="custom-utility">
      Hello EaseMotion!
    </EaseAlert>
  );
}
```

Provides automatic ref forwarding, prop spreading, and strict styling encapsulation.
