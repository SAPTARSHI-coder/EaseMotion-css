
# React Dropdown New Component

This component provides a React wrapper for the `ease-dropdown` CSS utility.

## Usage

```jsx
import { EaseDropdownNew } from './EaseDropdownNew';

function Demo() {
  return (
    <EaseDropdownNew className="custom-utility">Hello EaseMotion!</EaseDropdownNew>
  );
}
```

The component forwards refs, spreads extra props, and merges any custom `className` you provide with the core `ease-dropdown` class.
