
# React Icon New Component

This component provides a React wrapper for the `ease-icon` CSS utility.

## Usage

```jsx
import { EaseIconNew } from './EaseIconNew';

function Demo() {
  return (
    <EaseIconNew className="custom-utility">Hello EaseMotion!</EaseIconNew>
  );
}
```

The component forwards refs, spreads extra props, and merges any custom `className` you provide with the core `ease-icon` class.
