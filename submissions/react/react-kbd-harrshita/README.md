# React Kbd Integration

This is a React functional component wrapper for the `ease-kbd` class.

## Usage

```jsx
import { EaseKbd } from './EaseKbd';

function App() {
  return (
    <EaseKbd className="custom-utility">
      Hello EaseMotion!
    </EaseKbd>
  );
}
```

Provides automatic ref forwarding, prop spreading, and strict styling encapsulation.
