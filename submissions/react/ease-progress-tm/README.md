# EaseProgressBar

An animated progress bar React component that fills from 0 to a target value with a smooth CSS transition.

## Usage

```jsx
import EaseProgressBar from "./EaseProgressBar";

<EaseProgressBar value={75} showLabel accent="cool" />
```

## Description

Use cases: file upload progress, multi-step form completion, loading state.

Props: value: number (0-100), showLabel: boolean, accent: 'warm'|'cool'|'forest'|'rose'|'amber'|'violet'|'teal'|'ruby'|'graphite'|'gold'.
