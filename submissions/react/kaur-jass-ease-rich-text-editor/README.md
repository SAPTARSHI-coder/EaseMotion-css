# EaseRichTextEditor React Component

A modern, highly responsive React rich text editor component featuring live state tracking, custom toolbar controls, and dynamic HTML markup export.

## 🌟 Highlights

- **React State Managed**: Driven by React hooks (`useRef`, `useState`, `useEffect`).
- **Rich Formatting Controls**: Bold, Italic, Underline, Strikethrough, Alignment, Lists, and Blockquotes.
- **HTML Markup Inspector**: Built-in toggleable code drawer with one-click clipboard copying.
- **Fully Responsive**: Adaptive flex wrapping for toolbars across mobile, tablet, and desktop viewports.
