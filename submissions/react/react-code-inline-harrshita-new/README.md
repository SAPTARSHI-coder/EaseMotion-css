
# React CodeInline New Component

This component provides a React wrapper for the `ease-code-inline` CSS utility.

## Usage

```jsx
import { EaseCodeInlineNew } from './EaseCodeInlineNew';

function Demo() {
  return (
    <EaseCodeInlineNew className="custom-utility">Hello EaseMotion!</EaseCodeInlineNew>
  );
}
```

The component forwards refs, spreads extra props, and merges any custom `className` you provide with the core `ease-code-inline` class.
