# React Button Integration

This is a React functional component wrapper for the `ease-button` class.

## Usage

```jsx
import { EaseButton } from './EaseButton';

function App() {
  return (
    <EaseButton className="custom-utility">
      Hello EaseMotion!
    </EaseButton>
  );
}
```

Provides automatic ref forwarding, prop spreading, and strict styling encapsulation.
