# EaseTooltip

A reusable tooltip React component that positions itself above, below, left, or right of its child on hover or focus.

## Usage

```jsx
import EaseTooltip from "./EaseTooltip";

<EaseTooltip text="Save" position="top" />
```

## Description

Use cases: form helper hints, icon-button labels, truncated text reveal.

Props: text: string, position: 'top'|'bottom'|'left'|'right', delay: number (ms).
