# EaseAccordion

An accessible accordion React component with a smooth height transition between expanded and collapsed panels.

## Usage

```jsx
import EaseAccordion from "./EaseAccordion";

<EaseAccordion items={{[...]}} defaultOpen="1" />
```

## Description

Use cases: FAQ lists, settings panels, content disclosure. The smooth height transition avoids the jump of a fixed-height panel.

Props: items: {id, title, body}[], defaultOpen: id, multi: boolean.
