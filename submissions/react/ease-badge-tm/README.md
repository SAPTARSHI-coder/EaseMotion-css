# EaseBadge

A status badge React component that renders a label with an optional pulsing status dot.

## Usage

```jsx
import EaseBadge from "./EaseBadge";

<EaseBadge label="Online" status="online" pulse />
```

## Description

Use cases: notification badges, online indicators, status labels.

Props: label: string, status: 'online'|'busy'|'offline', pulse: boolean.
