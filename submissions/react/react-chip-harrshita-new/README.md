
# React Chip New Component

This component provides a React wrapper for the `ease-chip` CSS utility.

## Usage

```jsx
import { EaseChipNew } from './EaseChipNew';

function Demo() {
  return (
    <EaseChipNew className="custom-utility">Hello EaseMotion!</EaseChipNew>
  );
}
```

The component forwards refs, spreads extra props, and merges any custom `className` you provide with the core `ease-chip` class.
