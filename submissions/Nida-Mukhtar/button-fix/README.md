# Ghost Button Showcase 👻

This submission fixes the issue where a ghost button becomes completely invisible when a user hovers their mouse cursor over it.

## 🛠️ The Fix
The bug was caused by a lack of color contrast on the button's hover state. I resolved this by applying explicit CSS styling to ensure the background color fills up and the text color shifts dynamically to a highly visible, contrasting color upon mouse hover.

## 📂 Submission Structure
* `index.html` - Contains the structural mockup of the single ghost button.
* `style.css` - Houses the custom styling rules fixing the visibility bug on hover.
