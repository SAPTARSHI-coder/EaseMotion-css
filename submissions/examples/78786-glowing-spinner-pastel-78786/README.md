# Glowing Spinner — Pastel

## Issue

EaseMotion CSS issue #78786.

## Overview

A soft pastel loading spinner with a gradient ring and subtle glow.

## Features

- Lightweight CSS animation
- Responsive sizing
- Status semantics
- Reduced-motion fallback
- No external assets

## Usage

Open `demo.html` and reuse `.spinner` beside a visible loading message. Change the ring colors in `:root` to match another design system.

## Accessibility

The spinner uses a status role and accessible label. Reduced-motion users receive a static indicator.
