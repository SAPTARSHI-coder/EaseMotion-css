# Causal Consistency Ledger

An advanced EaseMotion example for monitoring distributed Ledger Reledgers, ordering debt, retry pressure, and Retention margin recovery.

## Features

- Interactive controls for ledger risk, ordering debt, retry pressure, and Retention margin health.
- Animated radar, Ordering lanes, recovery metrics, Reledger timeline, decision matrix, and audit ledger.
- State-driven stable, watch, Ledger, and recovered modes.
- Responsive CSS-only dashboard built with `demo.html`, `style.css`, and this `README.md`.
