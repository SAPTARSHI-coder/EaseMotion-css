🐛 Bug Fix: Connection Status

The offline status bar above now correctly pulses using ease-kf-pulse. Previously, the component referenced the non-existent keyframe name ease-pulse, causing the animation to fail silently and the bar to remain static.

The one-line fix (components/connection-status.css)
- animation: ease-pulse 2s infinite; /* ❌ undefined keyframe */ + animation: ease-kf-pulse 2s infinite; /* ✅ correct keyframe */

The @keyframes ease-kf-pulse rule is already defined in core/animations.css. This fix simply corrects the reference so the animation plays as intended.
