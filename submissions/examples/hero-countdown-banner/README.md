# Hero Countdown Banner

A CSS hero countdown banner with animated timer digits and pulsing glow effect.

## Features

- Full-width hero banner with countdown timer display
- Blinking colon separator animation
- Pulsing glow effect on timer blocks
- Radial gradient background glow
- CSS custom properties for easy theming
- Accessible with `prefers-reduced-motion` support
- Pure CSS — no JavaScript required

## Customization

```css
:root {
  --hcb-white: #ffffff;
  --hcb-bg: #0f172a;
  --hcb-text: #f8fafc;
  --hcb-muted: #94a3b8;
  --hcb-amber: #f59e0b;
}
```

## Usage

```html
<link rel="stylesheet" href="style.css">
```

## Files

- `demo.html` — Demo page with hero banner and countdown timer
- `style.css` — All styles and animations
