# Floating Action Button (FAB)

Expandable speed dial quick actions menu with smooth CSS motion transitions.

## Features
- Speed dial expansion animation
- Main action icon rotation (+) to (x)
- Hover action tooltips
- Full keyboard and aria accessibility

## Usage

```html
<link rel="stylesheet" href="style.css" />

<div class="ease-fab-container">
  <div class="ease-fab-actions">
    <button class="ease-fab-action">Action 1</button>
  </div>
  <button class="ease-fab-main">+</button>
</div>
```
