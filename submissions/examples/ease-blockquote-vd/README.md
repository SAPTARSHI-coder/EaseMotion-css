# Ease Blockquote

## What does this do?

A styled blockquote component for highlighting important quotations with an optional author and decorative quote indicator.

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<blockquote class="ease-blockquote">
    <span class="quote-mark">“</span>

    <p>
        Great design is not just what it looks like,
        but how smoothly it works.
    </p>

    <cite>— EaseMotion CSS</cite>
</blockquote>
```

### Features

- Quote text
- Optional author
- Decorative quote indicator
- Responsive layout
- Subtle entrance animation
- Hover interaction
- Pure CSS
- No JavaScript required

## Why is it useful?

Blockquotes are commonly used in documentation, blogs, articles, testimonials, and editorial content to visually highlight important quotations.

This component provides a clean and reusable quotation pattern with subtle animation while following the animation-first philosophy of EaseMotion CSS.
