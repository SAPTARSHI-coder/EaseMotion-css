# Gradient Animated Text Component

Add ease-gradient-animated-text-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|---------|
| `--gat-accent` | `#6366f1` |
| `--gat-accent2` | `#ec4899` |
| `--gat-size` | `clamp(2.5rem,7vw,4.5rem)` |
| `--gat-weight` | `900` |

## Technique

`background-size: 300%` with animated `background-position` creates the flowing gradient effect.
