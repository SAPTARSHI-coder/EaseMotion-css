# Neumorphic Soft UI Audio Player

## 1. What does this do?
The Neumorphic Soft UI Audio Player provides a tactile soft-embossed music widget complete with animated spinning vinyl art, dual inset shadow progress bars, and soft neumorphic control buttons.

## 2. How is it used?
Link `style.css` in your HTML markup and use the `.player-card` container along with `.neu-btn` elements for interactive control states.

## 3. Why is it useful?
Delivers a realistic tactile physical UI aesthetic for music streaming applications, podcasts, media dashboards, and creative portfolio projects.
