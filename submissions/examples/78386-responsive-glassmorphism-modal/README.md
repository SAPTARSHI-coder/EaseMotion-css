# Responsive Modal with Glassmorphism Styling

A responsive CSS-only modal component featuring a translucent
Glassmorphism interface, backdrop blur, layered borders, subtle
animations, and a clean responsive layout.

## Features

- Responsive modal dialog
- CSS-only open and close interaction
- `:target` based modal state
- Glassmorphism surface
- Frosted backdrop
- Backdrop blur
- Translucent gradients
- Layered highlights
- Responsive modal content
- Responsive action buttons
- Status/details section
- Hover and focus states
- Keyboard-focusable controls
- `role="dialog"`
- `aria-modal="true"`
- `aria-labelledby`
- `prefers-reduced-motion` support
- No JavaScript
- No external dependencies

## Files

- `demo.html`
- `style.css`

## Usage

Open `demo.html` directly in a browser.
