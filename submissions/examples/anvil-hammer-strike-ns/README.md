# Anvil Hammer Strike

## What does this do?
Renders a self-contained CSS-only `ease-anvil-hammer-strike` demo: Blacksmith hammer striking an anvil with spark burst.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-anvil-hammer-strike`. No build step or JavaScript is required for the effect.

```html
<section class="ease-anvil-hammer-strike">
  <div class="ease-anvil-hammer-strike__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
