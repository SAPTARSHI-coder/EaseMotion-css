# 3D Perspective Tilt Product Showcase Card with Light Reflections

### Glassmorphic Style

A premium **Glassmorphic 3D Product Showcase Card** created using **HTML5** and **CSS3**. This component combines modern glassmorphism, smooth 3D perspective tilt, animated light reflections, and responsive design to create an elegant product presentation.

---

## ✨ Features

- Glassmorphism UI
- 3D perspective tilt animation
- Animated light reflection effect
- Responsive mobile-first layout
- Gradient CTA button
- Product depth hover animation
- CSS variables for easy customization
- Pure HTML & CSS implementation
- Reduced motion accessibility support

## 🚀 Usage

1. Navigate to the component folder.
2. Keep `demo.html` and `style.css` together.
3. Open `demo.html` in any modern browser.
4. Hover over the card to experience the 3D tilt and animated reflection effects.

No installation or external libraries are required.
