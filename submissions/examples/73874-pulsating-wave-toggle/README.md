# Pulsating Wave Toggle (#73874)

A pure HTML & Vanilla CSS toggle featuring a continuous pulsating wave ripple animation.

## Features
- **Aesthetic:** Continuous radial ripple pulsating outwards from the active toggle thumb.
- **Pure CSS:** Zero JavaScript dependencies; relies strictly on CSS state selectors and keyframes.
- **Performance:** Hardware-accelerated transitions using `transform`, `opacity`, and `will-change`.
- **Accessibility:** Includes `:focus-visible` outline rings and `@media (prefers-reduced-motion: reduce)` support.
