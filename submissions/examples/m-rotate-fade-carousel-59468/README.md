# CSS Rotate-Fade Carousel for SaaS Showcase Layouts

A modern **Rotate-Fade Carousel** built using pure HTML and CSS. The carousel features elegant rotate-and-fade entrance animations, premium glassmorphism styling, responsive layouts, and lightweight hover interactions for SaaS landing pages and product showcases.

## ✨ Features

- Pure HTML5 & CSS3
- Rotate-fade entrance animation
- Glassmorphism carousel cards
- Responsive layout
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
