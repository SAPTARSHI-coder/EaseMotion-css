# 3D Perspective Tilt Toggle (#73872)

A pure HTML & Vanilla CSS toggle featuring a dynamic 3D perspective tilt effect on interactive states.

## Features
- **Aesthetic:** Depth-enhanced 3D track tilting using CSS `perspective` and `rotateX`/`rotateY`.
- **Pure CSS:** Zero JavaScript dependencies; relies on standard HTML checkbox state selectors.
- **Performance:** Hardware-accelerated 3D transforms using `transform` and `will-change`.
- **Accessibility:** Includes `:focus-visible` focus ring support and `@media (prefers-reduced-motion: reduce)` media query integration.
