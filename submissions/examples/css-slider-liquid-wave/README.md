# CSS Slider: Liquid Wave Fill Variation

A responsive and accessible pure CSS slider featuring a
smooth animated Liquid Wave Fill effect.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript
- No external dependencies
- Animated liquid fill
- Layered wave animation
- Smooth CSS transitions
- CSS Scroll Snap
- Responsive layout
- Dark-mode friendly
- Hardware-friendly CSS transforms
- Keyboard-accessible navigation
- Reduced-motion support
