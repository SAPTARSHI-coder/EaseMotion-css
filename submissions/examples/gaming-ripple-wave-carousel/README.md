# CSS Ripple-Wave Carousel for Gaming Hub Layouts

A modern **Gaming Hub Carousel** built entirely with **HTML5 and CSS3**. This showcase demonstrates futuristic **Ripple-Wave** hover animations with neon accents, glassmorphism cards, responsive layouts, and accessibility support without requiring JavaScript.

---

## ✨ Features

- 🎮 Gaming showcase carousel
- 🌊 Ripple-Wave hover animation
- 🌈 Neon gradient accents
- 💎 Glassmorphism game cards
- 🏷 Featured game highlight
- 📱 Fully responsive
- ⚡ Pure HTML5 & CSS3
- 🎯 CSS Custom Properties
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

## 🚀 Getting Started

1. Open `demo.html` in any modern browser.
2. Hover over the game cards to trigger the ripple-wave effect.
3. Explore the featured game card and responsive layout.
4. Customize colors, spacing, and animation timing using CSS variables.

## 🎨 CSS Custom Properties

```css
:root{
    --bg:#040816;
    --surface:rgba(15,23,42,.88);
    --primary:#00e5ff;
    --secondary:#8b5cf6;
    --text:#ffffff;
    --muted:#cbd5e1;
    --border:rgba(255,255,255,.08);
```
