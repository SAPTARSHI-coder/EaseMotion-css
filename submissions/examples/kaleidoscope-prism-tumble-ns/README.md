# Kaleidoscope Prism Tumble

## What does this do?
Renders a self-contained CSS-only `ease-kaleidoscope-prism-tumble` demo: Kaleidoscope prism cells tumbling mirrored motifs.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-kaleidoscope-prism-tumble`. No build step or JavaScript is required for the effect.

```html
<section class="ease-kaleidoscope-prism-tumble">
  <div class="ease-kaleidoscope-prism-tumble__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
