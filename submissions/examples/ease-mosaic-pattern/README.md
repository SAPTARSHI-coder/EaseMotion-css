# Mosaic Pattern · Mosaic Tiles Shift Color 🟦

An interactive mosaic pattern where tiles shift colors in a beautiful, flowing animation. Watch the mosaic transform with smooth color transitions!

## Features

- 🟦 **Mosaic Grid** – Tiled pattern with color shifting
- 🎨 **Color Shift** – Smooth tile color transitions
- 🎚️ **Speed Control** – Adjust shift speed (1-10)
- 🎚️ **Tile Size Control** – Adjust tile size (4-12)
- ⏸️ **Pause/Resume** – Toggle animation
- 🔄 **Reset** – Reset to initial pattern
- ✨ **Glow Effects** – Subtle tile glow
- 📱 **Touch Support** – Works on mobile devices

## How to Use

1. Click **SHIFT** or press **Space** to shift tile colors
2. Watch the mosaic transform with smooth transitions
3. Adjust **Speed** for shift pace
4. Adjust **Size** for tile density
5. Press **RESET** or **R** to reset
6. Press **PAUSE** or **P** to pause/resume animation

## Controls

| Action | Method |

## Technical Details

- **Grid:** Dynamic tile grid based on size
- **Colors:** HSL-based with position variation
- **Animation:** Smooth cubic ease-out interpolation
- **Performance:** 60fps with requestAnimationFrame

## Customization

You can easily customize:
- **Colors:** Modify the color palette
- **Speed:** Adjust slider range (1-10)
- **Tile Size:** Adjust slider range (4-12)
- **Grid:** Change grid dimensions
- **Glow:** Adjust glow intensity
