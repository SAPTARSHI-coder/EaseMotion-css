# CSS Ripple Background Section

A responsive CSS-only background section featuring multiple ripple
circles that continuously radiate outward.

## Features

- Pure HTML and CSS
- No JavaScript required
- Multiple animated ripple circles
- Responsive design
- Accessible content structure
- Keyboard-accessible button
- `prefers-reduced-motion` support
- No external dependencies
