# Badge Focus Visible

**Closes #59916**

## Description

Adds a visible keyboard focus indicator for interactive badge components.

## Usage

```css
.ease-badge:focus-visible,
.em-badge:focus-visible{
    outline:2px solid currentColor;
    outline-offset:2px;
}
```
