# CSS Slide-Up Modal

A responsive **Slide-Up Modal** built using pure HTML5 and CSS3 for Gaming Hub layouts. The modal smoothly slides upward into view using CSS keyframe animations without JavaScript.

---

## ✨ Features

- Pure HTML5 & CSS3
- Smooth slide-up animation
- Gaming-inspired UI
- Responsive layout
- CSS Custom Properties
- Keyboard-accessible checkbox toggle
- `prefers-reduced-motion` support
- No JavaScript required
