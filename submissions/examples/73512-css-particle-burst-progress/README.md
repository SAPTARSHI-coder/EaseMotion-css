# CSS Particle Burst Progress

Issue #73512 uses CSS pseudo-elements to create a lightweight particle-like burst around a progress indicator.

## Features

- Particle burst accents
- Animated progress entrance
- Accessible progressbar semantics
- Responsive sizing
- Reduced-motion support
- No JavaScript or external assets

## Usage

Open `demo.html` and adjust the `--value` custom property.

## Files

- `demo.html` — progress markup
- `style.css` — particle, fill, and accessibility styling
- `README.md` — documentation
