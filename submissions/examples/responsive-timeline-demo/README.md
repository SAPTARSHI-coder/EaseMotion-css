# Responsive Timeline Demo

## Description

This example demonstrates a responsive vertical timeline built for EaseMotion CSS.

## Features

- Five timeline entries
- Date and milestone information
- Alternating desktop layout
- Single-column mobile layout
- Timeline indicators
- Hover interactions
- Responsive design
