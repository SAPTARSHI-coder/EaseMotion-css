# 🌅 Sunset Gradient – Sky Shifts Through Sunset Colors

> An interactive sunset gradient component where the sky shifts through beautiful sunset colors with 4 palettes (Sunset, Aurora, Fire, Ocean), progress control (0-100%), and auto-animation.

---

## 📖 Description

The **Sunset Gradient** component creates a beautiful sunset experience where the sky shifts through sunset colors with smooth gradients. Built with vanilla HTML, CSS, and JavaScript, it features 4 palettes (Sunset, Aurora, Fire, Ocean), progress control (0-100%), and auto-animation for a relaxing experience.

### 🎯 Core Features

- **Sunset gradient** – sky shifts through sunset colors with smooth gradients
- **4 palettes** – Sunset, Aurora, Fire, Ocean
- **Progress control** – adjust progress from 0-100%
- **Sun animation** – sun moves across the sky with glow
- **Cloud effects** – floating clouds with varying opacity
- **Time display** – shows current time of day
- **Auto-animation** – automatic cycling through sunset
- **Interactive controls** – slider, palette buttons, keyboard shortcuts
- **Responsive design** – adapts to different screen sizes

### 🌅 Color Palettes

| Palette | Description | Times |
|---------|-------------|-------|
| **Sunset** | Classic sunset colors | Night → Dusk → Sunset → Golden Hour → Day |
| **Aurora** | Northern lights colors | Night → Dawn → Morning → Day → Bright |
| **Fire** | Warm fire colors | Dark → Ember → Flame → Blaze → Inferno |
| **Ocean** | Cool ocean colors | Deep → Twilight → Blue → Cyan → Light |

### ⌨️ Interaction Options

| Method | Action |
|--------|--------|
| **Slider** | Adjust Progress (0-100%) |
| **Buttons** | Palette selection, Auto, Reset |
| **Keyboard** | `Space` – Auto · `R` – Reset |

### ✨ Sunset Experience

When interacting:
1. **Sky shifts** – gradient transitions through colors
2. **Progress applies** – controls time of day
3. **Palette applies** – changes color scheme
4. **Sun moves** – sun tracks across the sky
5. **Time updates** – shows current time name
6. **Status updates** – shows current state

### 💡 Why Use This Component?

- Perfect for meditation apps, relaxation tools, or calming interfaces
- Beautiful sunset gradient with smooth transitions
- Self-contained – no external dependencies or frameworks
- Easy to customize (palettes, colors, time names)
- 4 palettes for variety
- Progress control for customization

### 🛠️ Technologies Used

- **HTML5** – semantic structure with Canvas
- **CSS3** – gradients, backdrop-filter, transforms
- **JavaScript (ES6)** – Canvas API, requestAnimationFrame, color interpolation

### 🎨 Design Philosophy

This component embodies **EaseMotion CSS's animation-first philosophy** through:

- **Smooth gradients** – colors transition seamlessly
- **Sun movement** – sun tracks across the sky
- **Visual feedback** – status updates, time display, controls
- **Calming atmosphere** – beautiful sunset colors
- **Human-readable classes** – `.sunset-controls`, `.palette-btn`, `.sunset-text`

### 🔧 Customization Options

| Property | Location | Default |
|----------|----------|---------|
| Palettes | `palettes` object | 4 palettes |
| Progress range | `progressSlider` | 0-100% |
| Time names | `times` array | 5 per palette |
| Sun size | `sunRadius` | 6% of canvas |
| Cloud count | `cloudData` | 5 clouds |
