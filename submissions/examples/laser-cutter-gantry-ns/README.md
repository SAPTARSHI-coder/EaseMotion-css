# Laser Cutter Gantry

## What does this do?
Renders a self-contained CSS-only `ease-laser-cutter-gantry` demo: Laser cutter gantry tracing a cut path with beam glow.

## How is it used?
Open `demo.html` in a browser. The animated face uses classes like `ease-laser-cutter-gantry`, `ease-laser-cutter-gantry__arm`, and `ease-laser-cutter-gantry__core`. No build step or JavaScript is required for the motion.

```html
<section class="ease-laser-cutter-gantry">
  <div class="ease-laser-cutter-gantry__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
