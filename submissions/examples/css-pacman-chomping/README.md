# CSS Pac-Man Chomping

A lightweight Pac-Man animation created entirely with HTML and CSS.

## Features

* Pure CSS animation
* No JavaScript
* Pac-Man chomping effect
* Animated movement across a row of dots
* Responsive design
* Reduced-motion support
* Accessible semantic markup

## Files

* `demo.html` - Demo markup for the Pac-Man animation
* `style.css` - Pac-Man, dot, movement, and responsive animations

## Usage

Open `demo.html` in any modern browser.

No dependencies or build tools are required.

## Accessibility

The animation uses semantic HTML and decorative animation elements are hidden from assistive technologies with `aria-hidden`.

The demo also respects the `prefers-reduced-motion` media query. When reduced motion is enabled, the animations are disabled.

## Animation

The Pac-Man character is created using CSS shapes and pseudo-elements. CSS keyframes control:

* Pac-Man movement
* Pac-Man vertical bobbing
* Dot disappearance and reappearance
* Responsive behavior
