🎬 Animation Details

How the Animation Works

The floating label animation is triggered by two CSS pseudo-classes:

/* Label floats when input is focused */ .ease-input-field:focus + .ease-input-label /* Label floats when input has content (not showing placeholder) */ .ease-input-field:not(:placeholder-shown) + .ease-input-label /* Animation transforms */ transform: translateY(-24px) scale(0.75); transition: all 300ms cubic-bezier(0.4, 0, 0.2, 1);

What Happens

  1. Scale Down: Label scales from 1 to 0.75 (25% smaller)
  2. Translate Up: Label moves 24px upward to the border area
  3. Smooth Duration: 300ms animation for a polished feel
  4. Stays Floated: Remains floated while input has content
  5. Returns: Label floats back down when input is cleared
