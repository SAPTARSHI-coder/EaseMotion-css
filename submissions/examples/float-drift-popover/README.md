# CSS Float Drift Popover

A responsive popover component featuring a smooth floating drift animation using only HTML and CSS.

## Features

- Pure HTML & CSS
- Float drift animation
- Responsive design
- Hover interaction
- Lightweight implementation
- No JavaScript required
- Supports `prefers-reduced-motion`

## Folder Structure

```
float-drift-popover/
├── demo.html
├── style.css
└── README.md
```

## Usage

Open `demo.html` in any modern browser.

## Customization

You can customize:

- Background color
- Shadow
- Animation duration
- Border radius
- Width
- Typography

## Accessibility

- Semantic HTML
- Responsive layout
- Reduced motion support
