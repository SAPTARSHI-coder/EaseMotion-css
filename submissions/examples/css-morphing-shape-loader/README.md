# CSS Loader: Morphing Shape

A smooth, responsive and accessible loader created entirely with
HTML and vanilla CSS.

## ✨ Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Fluid morphing animation
- Dynamic border-radius transformation
- Rotation and scaling effects
- Glass-like inner core
- Responsive layout
- Dark-mode compatible
- GPU-friendly CSS transforms
- Reduced-motion support
- High-contrast support
- Accessible loading status
