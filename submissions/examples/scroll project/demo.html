Scroll Progress Bar

A lightweight, pure CSS & minimal JS progress tracker for long-form content.

Scroll progress indicators provide instant visual feedback to readers regarding their current position within a document or container. As you scroll down this panel, watch the accent bar at the very top smoothly expand to match your reading progress.

Design Considerations

By sticking the indicator to the top viewport edge using position: fixed or position: sticky, the user retains context regardless of page length. Utilizing CSS custom properties and hardware-accelerated transforms (transform: scaleX(...)) ensures smooth 60fps performance without causing expensive layout re-paints.

Key Benefits

  • Dependency-Free: Driven completely by native modern browser APIs.
  • High Performance: Optimized via CSS transforms for silky visual updates.
  • Accessible: Non-intrusive container marked as aria-hidden="true" to stay invisible to screen readers.

Implementation Overview

The calculation maps current scroll offset against the total scrollable height: 

const progress = (scrollTop / (scrollHeight - clientHeight)) * 100;

This value is directly injected into a CSS custom variable --scroll-percentage, leaving animation and modern rendering responsibilities cleanly inside CSS.

Keep scrolling down to test the end-state transition when the bottom of the content container is reached.

Conclusion

Whether added to documentation sites, long blog posts, or interactive dashboards, a scroll progress bar elevates reading UX with minimal overhead.
