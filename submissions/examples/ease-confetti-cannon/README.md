# Confetti Cannon · Confetti Shoots Out 🎉

An interactive confetti cannon that shoots colorful confetti with realistic physics, particle effects, and celebration sounds. Perfect for celebrations!

## Features

- 🎉 **Confetti Cannon** – Shoots colorful confetti
- 🎨 **20 Colors** – Vibrant confetti palette
- 🎚️ **Count Control** – Adjust confetti count (20-150)
- 🎚️ **Spread Control** – Adjust spread width (1-10)
- 🔊 **Sound Effects** – Celebration sounds
- ⏸️ **Pause/Resume** – Toggle animation
- 🗑️ **Clear** – Clear all confetti
- 🔄 **Reset** – Reset everything
- 📊 **Counter** – Tracks pieces and total fired

## How to Use

1. Click **FIRE** or press **Space** to shoot confetti
2. Click on the canvas to fire more
3. Adjust **Count** for more/less confetti
4. Adjust **Spread** for wider/narrower burst
5. Click **CLEAR** or press **C** to clear all
6. Press **RESET** or **R** to reset
7. Press **PAUSE** or **P** to pause/resume animation

## Technical Details

- **Particle System:** 20-150 particles per burst
- **Physics:** Gravity, drag, rotation, wobble
- **Shapes:** Rectangles, circles, triangles
- **Performance:** 60fps with requestAnimationFrame

## Customization

You can easily customize:
- **Count:** Adjust slider range (20-150)
- **Spread:** Adjust slider range (1-10)
- **Colors:** Modify COLORS array
- **Physics:** Adjust gravity, drag, decay
- **Shapes:** Add/remove shape types

## Browser Support

Works in all modern browsers:
- Chrome, Firefox, Safari, Edge
- Audio requires Web Audio API support

## Run Locally

Simply open `index.html` in your browser – no server required!
