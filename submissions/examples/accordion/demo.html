By transitioning grid-template-rows from 0fr to 1fr, we can smoothly animate the height of an element from 0 to auto without using JavaScript to calculate pixel heights. This is a modern CSS feature that eliminates the need for max-height hacks!

The animation physics itself is 100% pure CSS utilizing CSS Grid. The only JavaScript required is a tiny script to toggle the is-active class on the parent element when the user clicks the header button.

For full production accessibility, you should add aria-expanded to the button and aria-hidden to the content, toggling them alongside the class. This demo focuses on the CSS animation implementation.
