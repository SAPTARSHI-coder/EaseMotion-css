# CSS Slide-Up Hero Section for Product Catalog Layouts

A modern **Slide-Up Hero Section** built using only HTML and CSS for product catalog landing pages. The layout features smooth entrance animations, floating product highlights, responsive design, and accessibility support.

---

## Features

- 🚀 Pure HTML & CSS
- 📱 Fully Responsive
- ✨ Smooth Slide-Up Entrance Animation
- 🎯 Floating Product Cards
- 🎨 Modern Product Showcase Layout
- ⚡ Lightweight & Easy to Customize
- ♿ Supports `prefers-reduced-motion`
- 🌐 No JavaScript Required
