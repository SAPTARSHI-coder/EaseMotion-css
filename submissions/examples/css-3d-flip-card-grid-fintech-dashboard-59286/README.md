# CSS 3D-Flip Card Grid for Fintech Dashboard Layouts

A modern **3D-Flip Card Grid** built using pure HTML and CSS for fintech dashboards, banking portals, investment platforms, and analytics interfaces.

## Features

* Pure HTML5 & CSS3
* Smooth 3D flip animation
* Interactive front and back card views
* Fintech-inspired responsive grid
* CSS custom properties for easy customization
* No JavaScript required
* Lightweight and performance optimized
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over a card to view its back face.
3. Customize content and colors using the CSS variables in `:root`.
4. Duplicate `.card` elements to add more dashboard widgets.
