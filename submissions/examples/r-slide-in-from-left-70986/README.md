# CSS Slide In from Left

A responsive CSS-only scroll reveal animation that smoothly slides elements into view from the left side.

## Features

- Pure CSS implementation
- Slide-in-from-left entrance animation
- Scroll-triggered animation using CSS scroll-driven animations
- Fallback animation for unsupported browsers
- Responsive across screen sizes
- Reduced-motion support
- Forced-colors support
- Visible keyboard focus state
- No JavaScript required

## Files

- `demo.html` — Interactive demonstration
- `style.css` — Component styling
- `README.md` — Documentation

## Usage

Add the `slide-card` class to an element:

```html
<article class="slide-card">
  <span class="number">01</span>

  <div>
    <h3>Clean Motion</h3>
    <p>
      Content smoothly enters from the left side of the viewport.
    </p>
  </div>
</article>
