# Coupling Knuckle Lock

## What does this do?
Renders a self-contained CSS-only `ease-coupling-knuckle-lock` demo: Knuckle coupler closing on the pin.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-coupling-knuckle-lock`. No build step or JavaScript is required for the effect.

```html
<section class="ease-coupling-knuckle-lock">
  <div class="ease-coupling-knuckle-lock__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
