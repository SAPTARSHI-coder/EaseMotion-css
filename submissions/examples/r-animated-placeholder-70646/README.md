# CSS Animated Placeholder

A pure CSS animated placeholder component for EaseMotion CSS.

The placeholder smoothly slides upward and shrinks when the input receives
focus or when the user has entered a value.

## Features

- Pure CSS implementation
- No JavaScript required
- Smooth focus animation
- Floating label remains visible after entering text
- Responsive layout
- Keyboard accessible
- Visible focus states
- Supports `prefers-reduced-motion`
- Semantic HTML labels and form controls

## Files

- `demo.html` — Component demonstration
- `style.css` — Complete styling and animation
