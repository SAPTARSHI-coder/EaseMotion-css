# Clinometer Bubble Tilt

## What does this do?
Renders a self-contained CSS-only `ease-clinometer-bubble-tilt` demo: Clinometer vial bubble seeking level as the frame tilts.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-clinometer-bubble-tilt`. No build step or JavaScript is required for the effect.

```html
<section class="ease-clinometer-bubble-tilt">
  <div class="ease-clinometer-bubble-tilt__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
