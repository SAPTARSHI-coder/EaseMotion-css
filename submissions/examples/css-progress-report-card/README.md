# CSS Progress Report Card

A modern, responsive student progress report card built using pure HTML and CSS.

This component is designed for the EaseMotion CSS library and demonstrates
animated progress indicators, subject-grade cards, responsive layouts,
accessible semantics, and reduced-motion support without JavaScript.

## ✨ Features

- Pure HTML and CSS
- No JavaScript
- Responsive design
- Animated progress bars
- Animated card entrance
- Subject-specific visual indicators
- Grade badges
- Overall performance summary
- Hover interactions
- Accessible progressbar semantics
- Keyboard-friendly native HTML structure
- `prefers-reduced-motion` support
- Mobile, tablet, and desktop layouts
- No external dependencies
