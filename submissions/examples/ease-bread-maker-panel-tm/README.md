# Bread Maker Panel

Closes #74807

Bread machine control panel with a 2-column mode grid (Basic, Whole Wheat, French, Sweet, Gluten Free, Rapid), countdown timer, and progress bar.

## Technique

Each mode is a button-like div. Active mode gets a yellow gradient. Progress bar uses a horizontal linear-gradient. Warm beige color palette gives the appliance a friendly kitchen feel.
