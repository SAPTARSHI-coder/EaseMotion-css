# CSS-only Carousel - Glassmorphism

A glassmorphism carousel component for issue #78874. It uses radio controls, keyboard-focusable labels, frosted slides, animated depth layers, and responsive thumbnails with no JavaScript.

## Features

- CSS-only slide switching with radio inputs
- Frosted glass panels, depth shadows, and animated aurora sheen
- Keyboard focus indicators and reduced-motion support
- Responsive mobile layout
