# CSS Mesh Gradient: Liquid Wave Fill

## Overview

A fluid mesh-gradient variation built from layered wave surfaces and blurred color fields. The movement is entirely CSS-driven.

## Features

- Liquid wave contours
- Independent background blobs
- Dark-mode-friendly palette
- Responsive layout
- Focus-visible interaction styling
- Reduced-motion support
- No JavaScript or external assets

## Files

- `demo.html` — semantic demo structure
- `style.css` — gradient layers and responsive animation
- `README.md` — documentation

## Accessibility

Decorative layers are marked as hidden from assistive technology. The link remains keyboard accessible and has a visible focus ring. Reduced-motion preferences disable continuous animation.
