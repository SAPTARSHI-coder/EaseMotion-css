# CSS Rotate-Fade Accordion

A responsive accordion component with a smooth rotate-and-fade entrance animation built using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Rotate-Fade entrance animation
- Responsive layout
- Native `<details>` accordion
- Accessible
- Supports `prefers-reduced-motion`

## Files

```
demo.html
style.css
README.md
```

## Usage

Open `demo.html` directly in any modern browser.

## Customization

Edit colors, spacing, animation duration and border radius in `style.css`.

## Accessibility

- Keyboard accessible
- Native HTML elements
- Reduced motion support
