# CSS Elastic-Slide Navbar

A modern **Elastic-Slide Navbar** built using pure HTML5 and CSS3 for Gaming Hub layouts. The navigation features a smooth elastic sliding indicator that follows hovered menu items while remaining lightweight, responsive, and accessible.

---

## ✨ Features

- Pure HTML5 & CSS3
- Elastic sliding navigation indicator
- Gaming-inspired navbar
- Fully responsive
- CSS Custom Properties
- Lightweight and performant
- Accessible semantic HTML
- `prefers-reduced-motion` support
- No JavaScript required

## 🚀 Usage

1. Copy the component into your project.
2. Link the stylesheet:

```html

```

3. Open `demo.html` in your browser.
