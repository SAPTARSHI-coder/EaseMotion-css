# Shimmer-Sweep Drawer for Minimalist Tech Layouts


## Overview

A modern CSS-only drawer component featuring a smooth shimmer sweep animation with a minimalist glassmorphism design.


## Features

- Pure HTML and CSS implementation
- Animated shimmer sweep effect
- Glassmorphism UI styling
- Smooth entrance animation
- Responsive layout
- No JavaScript dependency
- Accessibility support
