# Mole Whack

A whack-a-mole grid where moles pop up from their holes and duck back down.

## Features
- Moles spring up and sink with squash physics
- Three-hole grid with dirt mounds
- Staggered timing keeps every hole busy

## Usage
```html
<div class="mw-grid">
  <div class="mw-hole"><div class="mw-mole"></div><div class="mw-dirt"></div></div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
