# Morphing Tooltip with Minimalist styling (#78841)

A responsive tooltip component featuring spring morphing transforms (`cubic-bezier`), clean dark mode palette tokens, keyboard accessibility handling, and zero JavaScript overhead.

## Features
- **Spring Morphing Transition:** Smooth GPU-accelerated scaling and elasticity effects on trigger hover or keyboard focus.
- **Accessible Design:** Uses native `<button>` markup with proper `aria-describedby` and `role="tooltip"` attributes.
- **Minimalist Aesthetic:** Subdued background colors (`#0f172a`, `#1e293b`), sky blue accents (`#38bdf8`), and subtle glowing box shadows.

## File Hierarchy
- `style.css` - Custom CSS tokens, morphing transform states, cubic-bezier timing curves, and media query breakpoints.
- `demo.html` - Semantic HTML structure showcasing the interactive morphing tooltip component.
- `README.md` - Technical specification and architecture overview.
