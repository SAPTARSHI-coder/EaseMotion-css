# Elastic ripple icon button

An icon button that scales down briefly and then springs outward with an elastic ease on click.

## How to view

Open `demo.html` in any modern browser. The demo is fully self-contained — no CDN, no framework, no JavaScript.

## How to use

Copy `style.css` into your project's stylesheet. Every class used in the demo is namespaced with `elasticrippleiconbuttonv2-` to avoid collisions.

## Why this is useful for EaseMotion CSS

Toolbar / app pattern; the elastic motion confirms the click.
