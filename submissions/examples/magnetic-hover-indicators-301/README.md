# Ease Advanced Liquid Glass Navigation

A modern liquid-glass navigation component with a magnetic
hover indicator and pointer-following interactions.

## Features

- Liquid glass navigation
- Glassmorphism effect
- Backdrop blur
- Magnetic hover indicator
- Smooth indicator movement
- Pointer-following navigation items
- Active navigation state
- Responsive mobile navigation
- Animated ambient background
- Reduced-motion support
- No external libraries
