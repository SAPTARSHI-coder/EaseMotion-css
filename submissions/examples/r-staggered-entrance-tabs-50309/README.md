# CSS Staggered Entrance Tabs

A modern **Staggered Entrance Tabs** component built using pure HTML5 and CSS3 for responsive dashboard layouts. Tabs appear with a staggered entrance animation and switch content without JavaScript.

---

## ✨ Features

- Pure HTML5 & CSS3
- Staggered entrance animation
- Responsive dashboard layout
- Keyboard accessible using radio inputs
- CSS Custom Properties
- No JavaScript required
- `prefers-reduced-motion` support
