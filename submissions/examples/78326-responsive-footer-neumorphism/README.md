# Responsive Footer with Neumorphism Styling

A fully responsive footer component built with HTML and CSS,
featuring a modern neumorphic interface.

## Features

- Fully responsive layout
- HTML and CSS only
- No JavaScript
- Neumorphic raised and inset surfaces
- Brand section with social links
- Responsive navigation columns
- Newsletter subscription area
- Interactive buttons and links
- Keyboard-friendly focus states
- Mobile-first responsive adjustments
- Reduced-motion accessibility support

## Files

- `demo.html`
- `style.css`

## Layout

The footer contains:

1. Brand and social section
2. Explore links
3. Resources links
4. Company links
5. Newsletter subscription area
6. Terms, privacy, and copyright information

## Design

The component uses:

- Soft gray neumorphic surfaces
- Raised shadows
- Inset input surfaces
- Blue accent gradients
- Rounded cards and controls
- Subtle hover elevation
- Responsive spacing and typography

## Technologies

- HTML5
- CSS3
