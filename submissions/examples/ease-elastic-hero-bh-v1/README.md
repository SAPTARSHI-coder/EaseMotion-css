# ease-elastic-hero-bh

CSS Elastic-Slide Hero Section for Gaming Hub Layouts.

## What does this do?
A captivating hero section with elastic/slide animations that create a dynamic gaming atmosphere.

## How is it used?
```html
<section class="ease-elastic-hero">
  <div class="ease-hero-content">
    <h1>Gaming Hub</h1>
    <p>Enter the arena</p>
    <a href="#" class="ease-hero-btn">Play Now</a>
  </div>
</section>
```

## Features
- Elastic slide-in animations for content
- Gaming-themed gradient background
- Animated particle effects
- CTA button with hover effects
- Staggered animation timing
- Fully responsive
- Reduced motion support

## CSS Custom Properties
- `--ease-hero-primary`: Primary accent color
- `--ease-hero-secondary`: Secondary accent
- `--ease-hero-bg`: Background gradient
