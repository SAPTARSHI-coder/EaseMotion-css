# Bounce-Pulse Card Grid

## 1. What does this do?
Cyberpunk neon card grid with bounce-pulse animation.

## 2. How is it used?
Apply `.ease-bounce-pulse-card` to grid items.

## 3. Why is it useful?
- Creates playful bounce effect for card grids
- Cyberpunk neon aesthetic with glowing accents
- Engages users with dynamic entrance animations
