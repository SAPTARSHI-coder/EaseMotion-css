# Solar Flare Radial Glass Effect

A smooth and performant pure CSS glassmorphism UI inspired by the radiant glow of a solar flare.

## Features

- Pure HTML and Vanilla CSS
- Solar Flare Radial visual style
- Glassmorphism card
- Layered radial gradients
- Animated ambient glow
- Smooth CSS transitions
- Dark mode compatible
- Light mode support
- Responsive design
- Hardware-friendly transforms
- Accessible focus states
- `prefers-reduced-motion` support
- No JavaScript
- No external libraries
