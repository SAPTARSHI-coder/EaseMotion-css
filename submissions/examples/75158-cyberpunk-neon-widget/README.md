# Cyberpunk Neon Dashboard Widget

A futuristic **pure CSS Dashboard Widget** featuring a
Cyberpunk Neon visual style for the EaseMotion CSS component
collection.

Implemented for **Issue #75158**.

## ✨ Features

- Cyberpunk Neon dashboard aesthetic
- Responsive KPI metric cards
- Animated progress indicators
- Network activity visualization
- Neon security threat meter
- System event stream
- Resource utilization matrix
- Live system status indicator
- Smooth CSS transitions
- Hardware-friendly CSS animations
- Dark-mode compatible design
- Responsive desktop/tablet/mobile layouts
- Reduced-motion support
- Pure HTML and Vanilla CSS
- No external JavaScript
- No third-party dependencies

## 🎨 Style

**Category:** Dashboard Widgets

**Style:** Cyberpunk Neon

The component combines dark surfaces, neon cyan/pink/purple
accents, glowing borders, progress indicators, system logs,
and futuristic monitoring elements.
