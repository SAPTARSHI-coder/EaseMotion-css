# CSS Float-Drift Card Grid

## Overview

A responsive gaming-inspired card grid featuring smooth float-drift animations using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Responsive grid layout
- Float-drift hover effect
- CSS custom properties
- Accessible with `prefers-reduced-motion`
- Easy to customize

## Folder Structure

```text
float-drift-card-grid/
├── demo.html
├── style.css
└── README.md
```

## Usage

1. Open `demo.html` in your browser.
2. Customize the CSS variables.
3. Integrate into your project.

## CSS Variables

- `--primary`
- `--bg`
- `--card`
- `--text`
- `--duration`

## Browser Support

- Chrome
- Firefox
- Edge
- Safari
