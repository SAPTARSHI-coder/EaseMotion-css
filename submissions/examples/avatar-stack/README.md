# Avatar Stack

Overlapping profile circles that spread apart on hover to reveal every member.

## Features
- Negative-margin overlap creates a tight cluster
- Hover fans the stack apart with spring physics
- Trailing counter chip completes the group

## Usage
```html
<div class="as-stack">
  <div class="as-avatar a1">AN</div>
  <div class="as-avatar a2">RM</div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
