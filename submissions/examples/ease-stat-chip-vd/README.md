# Ease Stat Chip

## What does this do?

A small statistic chip displaying an icon, value, and label with a subtle hover effect.

---

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<div class="stat-chip">

    <div class="stat-icon">↗</div>

    <div class="stat-info">
        <strong>2,450</strong>
        <span>Visitors</span>
    </div>

</div>
```

### Features

- Icon support
- Statistic value
- Label
- Hover lift animation
- Responsive layout
- Lightweight and reusable

---

## Why is it useful?

Statistic chips are commonly used in dashboards and analytics interfaces to display important metrics in a compact format.

This component provides a simple, reusable statistic pattern with subtle interaction while following the animation-first philosophy of EaseMotion CSS.
