# Floating Elevation Hover

1. What does this do? Creates a smooth interaction where an element gracefully floats upward on hover while casting a wide, diffused shadow underneath, simulating physical elevation from the surface.
2. How is it used? Apply `.floating-elevation` to a card, button, or container element.
3. Why is it useful? Creating depth and hierarchy on hover makes interfaces feel tactile and responsive. This utility provides a polished, multi-layered `box-shadow` combined with a smooth `translateY` for an instantly satisfying micro-interaction.
