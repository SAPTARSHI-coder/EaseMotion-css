# Chart Bars Stacked

Segmented stacked bars grow while their parts pulse together.

## Features
- Stacked segment bars
- Growth with pulse
- Category labeling
- Pure CSS

## Usage
```html
<div class="cbs-col" style="--h:64%"><i class="cbs-a" style="--p:50%"></i></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
