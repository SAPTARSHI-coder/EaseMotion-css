# CSS Float-Drift Stepper for SaaS Showcase Layouts

A modern **Float-Drift Stepper** built using pure HTML5 and CSS3 for SaaS showcase layouts. This component provides a smooth product journey visualization with floating animations, step indicators, glassmorphism styling, and responsive behavior.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Smooth float-drift animations
* SaaS onboarding workflow showcase
* Animated step cards
* Active and inactive step states
* Floating motion effects
* Gradient progress connectors
* Glassmorphism UI design
* Responsive desktop, tablet, and mobile layouts
* CSS Custom Properties for easy customization
* Smooth transitions and keyframe animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. View the SaaS development journey stepper.
3. Hover over steps for interactive floating effects.
4. Customize colors, spacing, shadows, and animations using CSS variables inside `:root`.

## CSS Custom Properties

```css
:root{
  --bg:#eef4ff;
  --surface:rgba(255,255,255,.92);
  --primary:#2563eb;
  --secondary:#06b6d4;
  --accent:#8b5cf6;
  --text:#111827;
  --muted:#64748b;
  --shadow:0 20px 55px rgba(37,99,235,.18);
  --radius:28px;
}
```
