# Animated Gradient Text Component

A pure CSS animated gradient text utility for hero headings and typography callouts.

## Features
- **Background Clip Gradient:** Pure CSS `-webkit-background-clip: text` implementation.
- **Seamless Flow:** 200% background-size loop translation for continuous shimmer.
- **Zero JavaScript:** Fully responsive animation using pure CSS keyframes.

## File Structure
- `demo.html` - Heading structure with shimmer text utility.
- `style.css` - Text gradient clipping and keyframe wave rules.
