# CSS Float-Drift Feature Grid for Fintech Dashboard Layouts

A modern fintech dashboard feature grid component featuring smooth floating drift animations built completely with pure HTML and CSS.

This component is designed for financial dashboards, analytics platforms, and SaaS products where animated feature cards are required without JavaScript.


## ✨ Features

- 💳 Fintech dashboard feature cards
- 🌊 Smooth float-drift animation
- 🎨 Glassmorphism inspired UI
- ⚡ Pure HTML and CSS implementation
- 📱 Fully responsive grid layout
- 🔄 CSS keyframe animations
- 🌀 Smooth hover interactions
- ♿ prefers-reduced-motion accessibility support
- 🚀 Lightweight and framework-free

## 🚀 Usage

1. Open `demo.html` directly in your browser.

2. View the animated fintech feature cards.

3. Customize CSS variables inside `style.css` according to your branding.


## 🎨 CSS Custom Properties

The component uses CSS variables for easy customization:

```css
:root {

    --bg:#020617;
    --card:#0f172a;
    --primary:#22d3ee;
    --secondary:#8b5cf6;
    --text:#f8fafc;
    --muted:#94a3b8;

}

Modify these values to create your own dashboard theme.

Animations are minimized for users who prefer reduced motion.
