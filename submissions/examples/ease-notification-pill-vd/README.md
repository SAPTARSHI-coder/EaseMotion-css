# Ease Notification Pill

## What does this do?

A compact notification badge that displays unread counts such as **3**, **12**, or **99+** with a subtle pulse animation.

---

## How is it used?

Open `demo.html` in any modern browser.

Example:

```html
<div class="notification-pill">
    99+
</div>
```

### Features

- Rounded notification badge
- Supports values from single digits to **99+**
- Pulse animation
- Multiple color variants
- Responsive layout

---

## Why is it useful?

Notification badges are widely used in messaging apps, dashboards, admin panels, and social platforms. This lightweight component provides a reusable, animation-first way to display unread counts while matching the EaseMotion CSS philosophy.
