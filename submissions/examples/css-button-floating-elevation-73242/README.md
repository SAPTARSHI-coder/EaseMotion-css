# CSS Button: Floating Elevation Variation #10

A modern floating elevation button built entirely with HTML and CSS. The component creates a depth effect using layered shadows and smooth upward movement on hover, giving the illusion of a floating interactive element.

## Features

- Pure HTML & CSS
- Floating elevation hover effect
- Smooth hardware-accelerated transitions
- Dark mode friendly design
- Accessible keyboard focus states
- Responsive layout
- No JavaScript required

## Usage

```html
<button class="floating-btn">
    Get Started
</button>
