# 🔋 Battery Indicator – Charges Up Like a Battery

> A dynamic battery indicator that charges up with a smooth, animated fill effect, complete with wave animation, color-coded status, and interactive controls.

---

## 📖 Description

The **Battery Indicator** is a dynamic UI component that simulates a battery charging up with a smooth, animated fill effect. The battery fills from 0% to 100% with a satisfying animation, featuring a wave effect on the liquid surface, color-coded fill levels (red → yellow → blue → green), and a pulsing lightning bolt icon. The component includes Charge, Drain, and Reset controls, as well as keyboard shortcuts.

The component uses JavaScript with `requestAnimationFrame` for smooth animations. The battery level updates in real-time with easing for a natural feel. The color changes based on the charge level, providing clear visual feedback at a glance.

Perfect for battery indicators, power displays, energy apps, and any application where you want to show charge status with a polished, animated interface. The Battery Indicator transforms a simple status display into an engaging, interactive experience.
