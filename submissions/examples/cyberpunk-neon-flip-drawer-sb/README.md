# Cyberpunk Neon Flip Drawer

## 1. What does this do?
A cyberpunk neon styled drawer with 3D flip entrance animation effect.

## 2. How is it used?
Apply `.ease-flip-drawer` class to drawer element.

## 3. Why is it useful?
- Creates dynamic, futuristic cyberpunk aesthetic
- 3D flip entrance animation
- Engaging drawer experience
