# CSS Accordion — Pulsating Wave

A responsive and accessible accordion featuring a subtle pulsating wave
effect when an item is opened.

## Features

- Pure HTML and CSS
- No JavaScript
- Native `<details>` / `<summary>` accessibility
- Pulsating wave animation
- Smooth transitions
- Responsive design
- Dark mode support
- Reduced-motion support
- Keyboard accessible
- Hardware-friendly CSS animations
