# CSS Slider: Pulsating Wave Variation

A responsive, accessible, and performant pure CSS slider featuring
animated pulsating wave effects.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript
- No external dependencies
- Pulsating wave animation
- Smooth CSS transitions
- CSS Scroll Snap
- Responsive layout
- Dark-mode compatible
- Hardware-friendly transforms
- Keyboard-accessible navigation
- Visible focus indicators
- Reduced-motion support
