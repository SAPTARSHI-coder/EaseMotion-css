# CSS Battery Animation (#70959)

A smooth, fluid battery charging and draining animation component built with pure CSS keyframes and glowing gradients.

## Features
- Pure CSS fluid width scaling and color transition between charging (green) and low-battery states (red).
- Shimmer wave overlay effect simulating active power flow.
- Fully responsive card layout with built-in accessibility support (`role="progressbar"`).
- Automatic motion safety reduction using `prefers-reduced-motion`.
