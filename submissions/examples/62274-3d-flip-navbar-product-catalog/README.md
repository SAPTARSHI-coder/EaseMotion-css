# CSS 3D-Flip Navbar for Product Catalog Layouts

A modern **3D-Flip Navbar** built using pure HTML5 and CSS3 for product catalog layouts. The component provides an interactive navigation bar with elegant 3D flip animations, responsive behavior, glassmorphism styling, and accessibility support.

## Features

* Pure HTML5 & CSS3
* 3D-Flip navigation animation
* CSS-only responsive mobile menu
* Product Catalog navigation layout
* Glassmorphism navbar design
* Brand logo, navigation links, search button, cart button, and CTA button
* Smooth CSS transitions with 3D transforms (`rotateX` & `perspective`)
* Responsive desktop, tablet, and mobile layout
* CSS Custom Properties
* No JavaScript required
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over navigation links to experience the 3D Flip animation.
3. Resize the browser to view the responsive mobile navigation.
4. Customize colors, spacing, border radius, and animation timing using the CSS variables defined in `:root`.
