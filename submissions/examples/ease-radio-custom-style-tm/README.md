# Custom Radio Component

Add ease-radio-custom-style-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|---------|
| `--crd-accent` | `#6366f1` |
| `--crd-radius` | `10px` |
| `--crd-shadow` | `0 4px 16px rgba(0,0,0,.3)` |

## Technique

Hidden radio + `:checked` drives dot fill with spring `scale` animation for the inner dot.
