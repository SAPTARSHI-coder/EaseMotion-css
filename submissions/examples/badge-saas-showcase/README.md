# Ease CSS Blur-Entrance Badge for SaaS Showcase Layouts

A modern CSS-only blur-entrance badge designed for SaaS
landing pages, product announcements, feature releases and
modern showcase interfaces.

The component creates an elegant entrance effect where the
badge starts blurred and slightly displaced, then smoothly
settles into focus.

## Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Blur-to-focus entrance animation
- Subtle scale animation
- Vertical entrance movement
- Animated ambient glow
- Interactive hover state
- Animated badge icon
- Arrow interaction
- SaaS showcase layout
- Responsive desktop design
- Responsive tablet design
- Responsive mobile design
- Keyboard focus support
- `prefers-reduced-motion` support
- CSS custom properties
- Lightweight implementation
