# Horizontal Card Variant (`ease-card-horizontal`)

## What does this do?
Provides a sleek side-by-side image and text card component with smooth hover animations and full responsive mobile collapsing.

## How is it used?
Wrap your image and content containers in an element featuring the `ease-card-horizontal` class:
```html
<article class="ease-card-horizontal">
  <div class="card-img-holder">...</div>
  <div class="card-content">...</div>
</article>
```

## Why is it useful?
Expands EaseMotion's UI component library with a widely requested editorial and e-commerce layout, resolving issue #56094 with zero external dependencies.
