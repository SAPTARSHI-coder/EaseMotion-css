# Animated Treeview - Dark Mode

A responsive animated treeview component with a dark mode
visual style, implemented using pure HTML and CSS.

The component provides a focused dark interface with subtle
motion, glowing accents, nested navigation, and accessible
expand/collapse controls.

## Features

- Dark mode visual design
- Animated tree expansion
- Nested tree structure
- Smooth hover transitions
- Glowing accent states
- Active item highlighting
- Responsive layout
- Keyboard-accessible controls
- Visible focus states
- `prefers-reduced-motion` support
- Zero external JavaScript dependencies
