# Origami Paper Fold Tooltip

A smooth CSS-only tooltip inspired by the folds and layered
geometry of an origami paper sheet.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript required
- Origami-inspired folded corner
- Animated paper fold layers
- Smooth tooltip reveal
- Hover and keyboard focus support
- Dark mode compatible
- Responsive layout
- Reduced-motion support
- Hardware-friendly transform animations
