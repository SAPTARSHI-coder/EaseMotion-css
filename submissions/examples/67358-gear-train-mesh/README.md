# Ease Gear Train Mesh

A CSS-only animated gear train component that demonstrates synchronized clock-style gears meshing together.

## Features

- Real-world mechanical gear animation
- Pure HTML and CSS
- Multiple rotating gears
- Synchronized motion system
- Industrial themed control panel
- Responsive layout
- Reduced motion support


## Usage

Add:

```html
<div class="ease-gear-train-mesh">
</div>
