# CSS Isometric Keyboard

A striking 3D isometric representation of keyboard keys utilizing CSS 3D transforms (`rotateX`, `rotateZ`) and layered `box-shadow` for deep volume.

## Features
- Isometric perspective via `rotateX(60deg) rotateZ(-45deg)` applied to the container.
- Deep 3D extrusion built using stacked `box-shadow` offsets.
- Realistic key press physics via `:active` translating the key down and compressing the shadow.
