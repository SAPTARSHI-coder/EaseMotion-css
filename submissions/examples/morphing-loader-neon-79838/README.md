# Morphing Loader with Neon Styling

A responsive neon loader featuring morphing shapes, glowing effects, and continuous rotation animation.

## Features

- Morphing geometric animation
- Neon gradient glow
- Infinite rotating motion
- Fully responsive
- Pure HTML and CSS

## Files

- demo.html
- style.css

## Usage

Open `demo.html` in any modern browser.

## Customization

You can customize:

- Neon colors
- Morphing speed
- Rotation speed
- Glow intensity
- Loader size
