Aurora Borealis

A serene, drifting Northern Lights background effect powered entirely by CSS gradients, blur filters, and transform animations.

High Performance Glassmorphism

Because the aurora blobs are animated using hardware-accelerated transform properties, this complex visual effect runs incredibly smoothly on modern GPUs without relying on heavy JavaScript canvas loops.

This card utilizes a CSS backdrop-filter to create a frosted glass effect that perfectly compliments the drifting lights behind it.
