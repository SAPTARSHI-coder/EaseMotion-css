# Metallic Sheen Form

A polished and responsive form component featuring a **Metallic Sheen** visual style, created using pure HTML and Vanilla CSS.

## ✨ Features

- Metallic gradient styling
- Smooth hover and focus transitions
- Animated metallic highlights
- Responsive layout
- Dark mode support
- Keyboard accessible form controls
- Visible focus states
- Custom checkbox styling
- Reduced-motion support
- Hardware-friendly CSS transforms
- No JavaScript required
- No external dependencies
