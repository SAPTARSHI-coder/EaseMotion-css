# CSS Glitch-Flicker Stepper

A lightweight CSS-only stepper designed for minimalist technology interfaces.

The component uses a subtle glitch-flicker animation on the current step while maintaining a clean vertical progress structure.

## Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Four-step workflow
- Active, current, and pending states
- CSS glitch-flicker animation
- Responsive desktop, tablet, and mobile layouts
- CSS custom properties
- Semantic ordered list structure
- Keyboard-friendly visual states
- `prefers-reduced-motion` support
