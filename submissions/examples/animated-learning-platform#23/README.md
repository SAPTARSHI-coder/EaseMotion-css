# Animated Online Learning Platform

A vibrant **Online Learning Platform UI** built with **EaseMotion CSS**. Features course cards with progress bars, video thumbnails with play buttons, instructor profiles, category filters, achievement badges, and recommended courses.

## ✨ Features

- **📊 Learning Progress Overview**: Gradient banner with weekly goal progress bar and stats
- **🎬 Course Cards**: Video thumbnails with play button overlay, duration, and progress tracking
- **📈 Progress Bars**: Animated fill bars showing course completion percentage
- **👨‍🏫 Instructor Info**: Avatar and name display for each course
- **⭐ Ratings & Reviews**: Star ratings with student counts
- **🏷️ Category Filters**: Horizontally scrollable pills with active states
- **🏅 Achievement Badges**: Unlocked/locked achievement display
- **💰 Pricing Display**: Current price with original price strikethrough
- **🎬 Staggered Entrance**: All sections slide up sequentially
- **📱 Fully Responsive**: Adapts from multi-column to single-column layout

## 🧩 EaseMotion Classes Used

| Class | Purpose |
|-------|---------|
| `ease-fade-in` | Fades in the main page and footer |
| `ease-slide-up` | Slides sections up on entrance |
| `ease-delay-100` to `ease-delay-700` | Creates cascading staggered sequence |
| `ease-card` | Base card structure |
| `ease-hover-lift` | Lift effect on all cards |
| `ease-hover-grow` | Scale effect on buttons, pills, achievements |
| `ease-center` | Centers play buttons and icons |
| `ease-grid` + `ease-grid-cols-*` | Responsive grid layouts |
| `ease-gap-4` | Spacing between grid items |

## 🚀 How to Use

1. Open `demo.html` in any modern browser
2. Watch all sections slide in with staggered animations
3. Observe the **progress bars fill** on load
4. Hover over course cards to see image zoom and lift effects
5. Hover over play buttons to see them scale and change color
6. Click category pills to see active state changes
7. Resize to mobile to see the responsive layout
