# Zoom-In Feature Grid

A lightweight CSS-only feature grid designed for gaming hub layouts.

## Features

- Pure HTML and CSS
- Zoom-in hover animation
- Responsive grid layout
- Keyboard-friendly focus interaction
- CSS custom properties
- No JavaScript or external libraries
- Reduced-motion accessibility support

## Files

- `demo.html` - HTML showcase
- `style.css` - CSS animations and responsive styles

## Usage

Link the stylesheet in your HTML:

```html
<link rel="stylesheet" href="style.css">
