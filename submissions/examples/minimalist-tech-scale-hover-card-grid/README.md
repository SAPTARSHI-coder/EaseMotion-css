# CSS Scale-Hover Card Grid

A lightweight, responsive card grid for minimalist technology-focused interfaces.

The component uses pure HTML and CSS to create smooth scale, lift, border-glow, and focus interactions when users hover over or navigate to cards.

## Features

- Pure HTML and CSS
- Smooth scale and lift hover effect
- Subtle border and glow transitions
- Keyboard-friendly focus states
- Responsive 3-column, 2-column, and 1-column layouts
- Hardware-friendly CSS transforms
- No JavaScript required
- Supports `prefers-reduced-motion`
- Customizable through CSS custom properties
- Works directly by opening `demo.html`
