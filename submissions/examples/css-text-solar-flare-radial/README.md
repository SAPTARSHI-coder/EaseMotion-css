# CSS Text: Solar Flare Radial

A smooth, accessible, and performant **Pure CSS text animation** featuring a **Solar Flare Radial** effect. The animation combines glowing radial gradients, warm solar-inspired colors, and subtle pulsing motion to create an eye-catching hero text without using JavaScript.

## ✨ Features

- ☀️ Solar flare inspired radial glow
- 🌟 Animated pulsing light effect
- 🔥 Warm orange, yellow, and gold color palette
- 🎨 Pure HTML & Vanilla CSS
- ⚡ Hardware-accelerated animations
- 📱 Fully responsive
- 🌙 Dark mode compatible
- ♿ Supports `prefers-reduced-motion`
- 🚫 No JavaScript or external libraries

## Usage

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

Example:

```html
<h1 class="solar-text">
    SOLAR FLARE
</h1>
```
