# 3D Perspective Tilt Product Showcase Card with Light Reflections

### Neumorphic Finish

A modern **3D Perspective Tilt Product Showcase Card** built using **HTML5** and **CSS3**. The component combines a neumorphic design, perspective tilt effects, animated light reflections, and responsive interactions to create a premium product presentation experience.

---

## ✨ Features

- 3D perspective hover animation
- Neumorphic card design
- Animated light reflection sweep
- Product image depth effect
- Gradient CTA button
- Responsive mobile-first layout
- CSS variables for easy customization
- Pure HTML & CSS implementation
- Reduced motion accessibility support

## 🚀 Usage

1. Open the component folder.
2. Keep `demo.html` and `style.css` together.
3. Open `demo.html` in any modern browser.
4. Hover over the product card to view the 3D tilt and animated light reflection.

No installation or external libraries are required.
