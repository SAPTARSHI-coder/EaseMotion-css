# CSS Particle Effect: 3D Perspective Tilt

A pure CSS particle effect featuring layered particles moving inside a 3D perspective space with smooth tilt animations.

## Features

- Pure HTML and Vanilla CSS
- No external JavaScript
- CSS 3D perspective transforms
- Smooth perspective tilt animation
- Layered particles with different Z-depths
- Hardware-accelerated transforms
- Responsive design
- Dark-mode friendly styling
- Reduced-motion accessibility support

## Files

- `demo.html` — 3D particle effect demo
- `style.css` — Styles, 3D transforms, and animations
- `README.md` — Documentation

## Accessibility

Decorative particles use `aria-hidden="true"` and animations respect the user's `prefers-reduced-motion` preference.
