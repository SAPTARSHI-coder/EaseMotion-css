# CSS Rotating Words Hero (#70437)

A hero headline component featuring words that smoothly rotate through multiple text options, created entirely with pure CSS.

## Features
- **Semantic Structure:** Uses accessible `<main>` markup with screen-reader friendly container attributes.
- **Pure CSS Keyframes:** Continuous word rotation animation driven by CSS keyframe transforms and cubic-bezier easing.
- **Responsive Layout:** Perfectly scales across mobile and desktop viewports.

## File Hierarchy
- `style.css` - Component design, variables, and word-rotation keyframes.
- `demo.html` - Semantic markup and accessible structure.
- `README.md` - Technical specification and architecture overview.
