# Dynamic Carousel with Dark Mode Styling

A responsive CSS-only dynamic carousel designed around a polished dark-mode visual system.

## Features

- Responsive horizontal carousel
- Dark mode styling
- CSS scroll snapping
- Anchor-based slide navigation
- Previous and next controls
- Slide navigation dots
- Progress indicator
- Hover and focus interactions
- Animated decorative visuals
- Responsive desktop, tablet and mobile layouts
- Keyboard-friendly controls
- Reduced-motion accessibility support
- Pure HTML and CSS
- No JavaScript dependency

## Files

- `demo.html` — carousel markup and content
- `style.css` — complete styling, responsive behavior and animation

## Usage

Open `demo.html` directly in a browser.

The carousel can be integrated into other projects by copying the component markup and its corresponding CSS.

## Interaction

The carousel uses CSS scroll snapping and anchor links to navigate between slides without JavaScript.

## Accessibility

Keyboard focus states are provided for interactive controls and `prefers-reduced-motion` is respected.
