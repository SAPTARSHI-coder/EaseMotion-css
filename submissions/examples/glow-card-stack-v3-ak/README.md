# glow-card-stack-v3-ak

Pure CSS 3D floating stacked cards hover fan-out effect — no JavaScript required.

## How to use

```html
<div class="ease-card-stack-v3">
  <div class="ease-card-stack-item-v3">Top</div>
  <div class="ease-card-stack-item-v3">Middle</div>
  <div class="ease-card-stack-item-v3">Bottom</div>
</div>
