# glow-divider-v6-ak

Pure CSS animated glowing gradient line divider component — no JavaScript required.

## How to use

```html
<hr class="ease-glowing-divider-v6" />

<!-- Divider with Badge -->
<div class="ease-glowing-divider-text-v6">
  <span class="ease-glowing-divider-badge-v6">OR</span>
</div>
