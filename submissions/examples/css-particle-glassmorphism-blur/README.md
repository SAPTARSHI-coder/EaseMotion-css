# CSS Particle Effect: Glassmorphism Blur

A smooth and accessible pure CSS particle effect featuring a modern glassmorphism blur style.

## Features

- Pure HTML and Vanilla CSS
- No external JavaScript
- Multiple floating particles
- Glassmorphism blur effect
- Smooth CSS transitions and animations
- Dark mode compatible
- Responsive design
- Hardware-accelerated transforms
- Reduced-motion accessibility support

## Files

- `demo.html` — Particle effect demo
- `style.css` — Styles, glassmorphism effect, and animations
- `README.md` — Documentation

## Accessibility

Decorative particles use `aria-hidden="true"` and animations respect the user's `prefers-reduced-motion` preference.
