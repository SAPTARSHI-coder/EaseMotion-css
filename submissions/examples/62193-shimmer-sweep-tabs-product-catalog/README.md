# CSS Shimmer-Sweep Tabs for Product Catalog Layouts

A modern **Shimmer-Sweep Tabs** component built using pure HTML5 and CSS3 for product catalog layouts. The component features responsive category tabs with elegant shimmer-sweep animations, animated content switching, glassmorphism styling, and accessibility support.

## Features

* Pure HTML5 & CSS3
* Shimmer-Sweep tab animation
* Product category tabs
* CSS-only tab switching using radio buttons
* Responsive product showcase cards
* Glassmorphism container
* Smooth CSS transitions & keyframe animations
* Responsive desktop, tablet, and mobile layout
* CSS Custom Properties
* No JavaScript required
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Click any category tab to switch product sections.
3. Hover over the tabs to experience the shimmer-sweep effect.
4. Customize colors, spacing, typography, and animation timing through the CSS variables defined in `:root`.
