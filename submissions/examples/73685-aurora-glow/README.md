# CSS 3D Effect: Aurora Glow

A smooth, accessible, and performant pure CSS 3D animation inspired by
the flowing colors and luminous movement of an aurora.

## Features

- Pure HTML and Vanilla CSS
- Aurora-inspired glowing visuals
- 3D perspective environment
- Multiple animated light ribbons
- Layered 3D orbit rings
- Central glowing core
- Smooth CSS transitions
- Dark mode compatible
- Light mode support
- Responsive layout
- Hardware-friendly transforms
- Accessible focus states
- `prefers-reduced-motion` support
- No JavaScript
- No external libraries
