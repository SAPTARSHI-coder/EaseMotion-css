# Bourdon Tube Gauge

## What does this do?
Renders a self-contained CSS-only `ease-bourdon-tube-gauge` demo: Bourdon-tube pressure gauge needle sweeping the dial.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-bourdon-tube-gauge`. No build step or JavaScript is required for the effect.

```html
<section class="ease-bourdon-tube-gauge">
  <div class="ease-bourdon-tube-gauge__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
