# Slide-Up Cookie Consent Banner

## Overview

A modern bottom-fixed cookie consent banner designed for EaseMotion CSS. The component slides into view using a smooth entrance animation and provides a clean interface for displaying cookie consent information.

---

## Features

- Bottom-fixed layout
- Slide-up entrance animation
- Glassmorphism design
- Responsive layout
- Modern button styling
- Pure HTML & CSS
- Supports `prefers-reduced-motion`
