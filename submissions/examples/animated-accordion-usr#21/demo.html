EaseMotion CSS is a lightweight, modern CSS animation library that provides smooth, accessible animations for web interfaces. It includes a wide range of pre-built animations like fade, slide, scale, and hover effects.

Getting started is simple! Just include the EaseMotion CSS file in your HTML and add animation classes to your elements. Check our documentation for the complete list of available animations.

Yes! EaseMotion CSS is completely free and open-source under the MIT license. You can use it in personal and commercial projects without any restrictions.

EaseMotion supports all modern browsers including Chrome, Firefox, Safari, and Edge. For older browsers, animations will gracefully degrade without breaking your layout.
