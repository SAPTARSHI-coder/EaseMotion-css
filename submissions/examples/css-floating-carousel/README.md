# Floating Carousel with Glassmorphism styling (#78896)

A responsive floating card carousel featuring modern glassmorphism styling, backdrop filters, and native CSS scroll-snapping built entirely with pure CSS.

## Features
- **Semantic Structure:** Uses accessible `<main>` and `<article>` landmark markup with keyboard support.
- **Glassmorphism Design:** Frosted glass effect leveraging `backdrop-filter: blur()`.
- **Responsive Scroll Snap:** Fluid horizontal container supporting touch swipe and scroll alignment.

## File Hierarchy
- `style.css` - Glassmorphism variables, backdrop filters, and snap layouts.
- `demo.html` - Semantic markup and accessibility attributes.
- `README.md` - Technical specification and architecture overview.
