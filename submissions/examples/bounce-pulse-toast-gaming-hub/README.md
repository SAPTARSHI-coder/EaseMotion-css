# Bounce-Pulse Toast for Gaming Hub

A lightweight CSS-only notification toast designed for modern Gaming Hub layouts.

## Features

- Pure HTML and CSS
- No JavaScript required
- Bounce entrance animation
- Pulsing notification effect
- Animated success icon
- Responsive desktop, tablet, and mobile layout
- CSS custom properties for easy customization
- Accessible `prefers-reduced-motion` support
- Semantic `role="status"` and `aria-live` notification
