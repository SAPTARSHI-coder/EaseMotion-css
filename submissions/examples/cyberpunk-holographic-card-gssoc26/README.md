# Cyberpunk Holographic HUD Card Component

A futuristic Cyberpunk Holographic Card styled with HUD scanlines, glitch text effects, neon glow boundaries, and clipped polygon geometry.

## What does this do?
Renders an interactive Cyberpunk-themed UI card component with custom `clip-path` angular corners, scanline overlay filters, neon chromatic shadows, and 3D hover rotations.

## How is it used?
1. Open `demo.html` in your web browser.
2. Incorporate the `.cyber-card` structure into your web project or gaming dashboard.
3. Import `style.css` to load the cyberpunk color variables and scanline keyframe animations.

## Why is it useful?
Offers a lightweight, GPU-optimized cyberpunk interface component suitable for web3 applications, gaming dashboards, and futuristic landing pages without requiring heavy WebGL/Three.js assets.
