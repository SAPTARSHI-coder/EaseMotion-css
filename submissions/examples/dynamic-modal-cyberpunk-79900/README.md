# Dynamic Modal with Cyberpunk Styling

A futuristic Cyberpunk-inspired Dynamic Modal built using pure HTML and CSS.

## Features

- Cyberpunk neon theme
- Dynamic modal animation
- CSS-only open/close interaction
- Responsive layout
- Glowing effects
- Modern futuristic design

## Files

- demo.html
- style.css

## Usage

Open `demo.html` in a browser.

Click the "Launch Modal" button to display the modal.

## Customization

Modify:

- Neon colors
- Glow intensity
- Border styling
- Animation timing
- Modal dimensions

## Responsive

The component adapts to desktop, tablet, and mobile screens.

## Browser Support

- Chrome
- Firefox
- Edge
- Safari
