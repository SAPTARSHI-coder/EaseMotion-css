# CSS Shimmer-Sweep Tabs for Accessible Web Layouts

A modern **Shimmer-Sweep Tabs** component created using only **HTML5 and CSS3**. This example demonstrates animated tab cards with smooth shimmer effects, glowing borders, responsive layouts, and accessibility support without JavaScript.

---

## ✨ Features

- ✨ Shimmer sweep animation
- 🌈 Animated gradient buttons
- 💎 Glassmorphism card design
- ⚡ Lightweight CSS animations
- 🎯 CSS Custom Properties
- 📱 Fully responsive layout
- 🧩 Pure HTML5 & CSS3
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

---

## 🚀 Usage

1. Open `demo.html` in a browser.
2. Hover over the tab cards to see shimmer effects.
3. Customize colors and animation speed using CSS variables.

:root {

    --accent:#ec4899;
