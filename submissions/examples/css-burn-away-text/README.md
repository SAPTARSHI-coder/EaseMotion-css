# CSS Burn Away Text


A creative text animation where the text burns away from the edges on hover.


## Features

- Pure CSS implementation
- Burn/disintegration animation
- Fire glow effect
- Smooth disappearing motion
- No JavaScript dependency
- Responsive design


## Technologies

- HTML5
- CSS3


## CSS Concepts Used

- Clip-path
- Keyframe animations
- Text shadows
- Filters
- Transform effects


## Accessibility

- Semantic HTML
- Hover animation does not affect readability
- No additional controls required
