# CSS Skew-Active Dropdown for Product Catalog Layouts

A stylish dropdown navigation component featuring skew-based hover animations built entirely with HTML and CSS. Suitable for modern product catalog layouts and category menus.

## ✨ Features

- Pure HTML5 & CSS3
- Skew-active hover interaction
- Smooth dropdown reveal
- Responsive layout
- CSS Custom Properties
- Keyboard accessible using `:focus-within`
- `prefers-reduced-motion` support
- No JavaScript required
