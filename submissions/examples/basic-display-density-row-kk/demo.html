Basic Display Density Row

Simple layout density choices for dashboards.

A CSS-only settings row for choosing compact, comfortable, or spacious interface density in admin and dashboard screens.

CP
Compact

Shows more rows with tighter spacing for power users.

32 px rows Data heavy Available
CF
Comfortable

Balanced spacing for everyday dashboard workflows.

44 px rows Default Selected
SP
Spacious

Adds more breathing room for touch-friendly interfaces.

56 px rows Touch UI Available
