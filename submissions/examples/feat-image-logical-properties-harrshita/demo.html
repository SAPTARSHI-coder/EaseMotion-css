ease-image Logical Properties (RTL/LTR Support)

Perfect Internationalization without extra CSS:

By using Logical Properties (like margin-inline-end instead of margin-right), we create components that automatically adapt to Right-to-Left (RTL) languages like Arabic or Hebrew without writing a single line of override CSS.

Notice how the blue border, the icon spacing, and the red badge automatically mirror themselves perfectly in the RTL container.
