# CSS Skew-Active Popover (Checkout)

A pure CSS popover component designed for E-Commerce Checkout Layouts. It utilizes a striking 3D skew-and-rotate entrance animation, perfect for interactive elements like promo code inputs.

## Features
- Pure CSS and HTML (No JavaScript required).
- State management handled purely through a hidden checkbox and the `~` sibling selector.
- Engaging 3D `perspective`, `rotateX`, and `skewY` CSS transformations for an energetic popover entrance.
- Animated chevron indicator that rotates gracefully on toggle.
- Clean and modern e-commerce checkout styling.
- Fully responsive across desktop, tablet, and mobile viewports.
- Fully accessible with `prefers-reduced-motion` support ensuring degraded, safe animations.

## Usage
Open `demo.html` in your browser. Click on the "Apply Promo Code" button to toggle the popover. The hidden popover will smoothly untwist and fade down into view.

## Files
- `demo.html`: The HTML structure for the checkout UI, the popover toggle button, and the hidden checkbox state.
- `style.css`: The styling, perspective setup, and CSS transformations for the 3D skew-active entrance transitions.
