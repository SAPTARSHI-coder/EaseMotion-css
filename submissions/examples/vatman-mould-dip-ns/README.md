# Vatman Mould Dip

## What does this do?
Renders a self-contained CSS-only `ease-vatman-mould-dip` demo: Vatman dipping the mould into the vat.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-vatman-mould-dip`. No build step or JavaScript is required for the effect.

```html
<section class="ease-vatman-mould-dip">
  <div class="ease-vatman-mould-dip__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
