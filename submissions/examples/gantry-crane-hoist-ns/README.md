# Gantry Crane Hoist

## What does this do?
Renders a self-contained CSS-only `ease-gantry-crane-hoist` demo: Shipyard gantry crane hoist lowering a container.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-gantry-crane-hoist`. No build step or JavaScript is required for the effect.

```html
<section class="ease-gantry-crane-hoist">
  <div class="ease-gantry-crane-hoist__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
