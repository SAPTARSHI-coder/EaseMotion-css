# Morph Glow Card Grid
A modern, responsive portfolio card grid built using **HTML** and **CSS**. The project features morphing glass cards, animated glowing borders, smooth hover interactions, and gradient backgrounds to create a premium portfolio showcase without using JavaScript.

## ✨ Features
- Responsive card grid layout
- Pure HTML & CSS implementation
- Glassmorphism-inspired design
- Animated glowing borders
- Smooth hover and floating animations
- Gradient image placeholders
- Accessible focus states
- `prefers-reduced-motion` support
- Modern typography using Inter font
- Mobile-friendly design

## 🚀 Getting Started

1. Clone the repository.

```bash
git clone https://github.com/<your-username>/EaseMotion-css.git
```

2. Navigate to the project folder.

```bash
cd EaseMotion-css
```

3. Open `demo.html` in your browser.

No installation or build tools are required.
