# 🌿 Fern Frond – Fern Uncurls Like a Fiddlehead

> An interactive fern component where a fiddlehead frond slowly uncurls with 4 varieties (Classic, Fern, Fiddle, Maidenhair), uncurl control (0-100%), and organic leaf growth.

---

## 📖 Description

The **Fern Frond** component creates a beautiful fern experience where a fiddlehead frond slowly uncurls with organic motion. Built with vanilla HTML, CSS, and JavaScript, it features 4 varieties (Classic, Fern, Fiddle, Maidenhair), uncurl control (0-100%), and organic leaf growth for a calming nature experience.

### 🎯 Core Features

- **Fiddlehead uncurling** – fern frond uncurls with organic motion
- **4 varieties** – Classic, Fern, Fiddle, Maidenhair with unique colors
- **Uncurl control** – adjust uncurl from 0-100%
- **Organic leaves** – leaves grow along the stem with variety
- **Bud state** – shows closed bud when uncurled
- **Interactive controls** – slider, buttons, keyboard shortcuts
- **Responsive design** – adapts to different screen sizes

### ⌨️ Interaction Options

| Method | Action |
|--------|--------|
| **Slider** | Adjust Uncurl (0-100%) |
| **Buttons** | Uncurl, Reset |
| **Keyboard** | `Space` or `U` – Uncurl · `R` – Reset |

### ✨ Fern Experience

When uncurling:
1. **Frond uncurls** – stem spirals outward
2. **Uncurl applies** – controls uncurl progress
3. **Leaves grow** – leaves appear along the stem
4. **Variety applies** – changes colors and leaf shape
5. **Status updates** – shows current state

### 🛠️ Technologies Used

- **HTML5** – semantic structure with Canvas
- **CSS3** – gradients, backdrop-filter, transforms
- **JavaScript (ES6)** – Canvas API, requestAnimationFrame, organic generation

### 🎨 Design Philosophy

This component embodies **EaseMotion CSS's animation-first philosophy** through:

- **Organic motion** – uncurls with natural movement
- **Leaf growth** – leaves appear gradually
- **Visual feedback** – status updates, uncurl display, controls
- **Calming atmosphere** – nature-inspired visuals
- **Human-readable classes** – `.fern-controls`, `.variety-btn`, `.fern-text`

### 🔧 Customization Options

| Property | Location | Default |
|----------|----------|---------|
| Varieties | `varieties` object | 4 varieties |
| Uncurl range | `uncurlSlider` | 0-100% |
| Stem points | `numPoints` | 60 |
| Leaf count | `leaves` | 30-40 |
