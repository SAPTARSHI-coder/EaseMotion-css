# Command Palette Overlay

Spotlight-style CMD+K command search modal with shortcuts and backdrop blur.

## Usage
```html
<link rel="stylesheet" href="style.css" />
<div class="ease-cmd-overlay ease-cmd-visible">
  <div class="ease-cmd-modal">
    <input class="ease-cmd-input" placeholder="Search..." />
  </div>
</div>
```
