# Morph-Glow Progress Bar for Product Catalog Layouts

A modern **Pure CSS Morph-Glow Progress Bar** designed for **Product Catalog Layouts**. The component showcases animated progress indicators with a glowing morph effect, making product statistics and completion values visually engaging without JavaScript.

---

## ✨ Features

- Pure HTML & CSS
- Smooth Morph-Glow animation
- Responsive design
- Product catalog inspired layout
- CSS Custom Properties
- Accessible with `prefers-reduced-motion`
- Lightweight and reusable

---

## Files

- demo.html
- style.css

---

## CSS Custom Properties

```css
:root{
  --duration:.9s;
  --easing:cubic-bezier(.22,.61,.36,1);

  --glow:#38bdf8;
  --glow2:#0ea5e9;

  --radius:30px;
}
```

These variables allow customization of:

- Animation duration
- Animation easing
- Glow colors
- Border radius

Open `demo.html` directly in any modern browser.

No JavaScript or build tools are required.
