# Dynamic SaaS Modern Accordion

A clean and responsive Dynamic Accordion component designed in a modern SaaS visual style.

## Features

- Modern SaaS-inspired UI
- Native HTML accordion interaction
- Smooth open and close transitions
- Animated expand/collapse indicator
- Numbered accordion items
- Responsive design
- Mobile-friendly layout
- Keyboard accessible
- Visible focus state
- Reduced-motion support
- No JavaScript
- No external UI libraries
