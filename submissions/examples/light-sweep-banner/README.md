# Light Sweep Banner

A banner ribbon with a diagonal light that continuously sweeps across its surface.

## Features
- Diagonal light band glides forever
- Gradient ribbon with a folded edge
- Shine peaks where the band passes

## Usage
```html
<div class="ls-ribbon">&#9733; LIMITED DROP &#9733;</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
