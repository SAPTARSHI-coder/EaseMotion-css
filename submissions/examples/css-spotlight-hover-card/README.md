# CSS Spotlight Hover Card

A modern spotlight hover card created using HTML and CSS.

## Features

* Pure CSS implementation
* Animated hover interaction
* Spotlight-style visual effect
* Responsive design
* Keyboard focus support
* Semantic HTML
* No JavaScript
* Reduced-motion support

## Files

* `demo.html` - Demo markup
* `style.css` - Spotlight card styling and responsive behavior

## Usage

Open `demo.html` in any modern browser to view the spotlight hover card.

## Accessibility

The card uses semantic HTML, a descriptive ARIA label, keyboard focus support, and `:focus-visible` styling. The demo also respects `prefers-reduced-motion` for users who prefer reduced animation.
