How It Works

Parallax Speed Multipliers & Depth

In standard web pages, elements scroll up at a 1:1 speed ratio. By applying positive or negative translation offsets linked to the scroll position, we alter this speed ratio to construct a convincing illusion of three-dimensional depth.

Background (Moon & Sky) Translates down (+45%). Scrolls 55% slower. Feels infinitely far away.
Middleground Mountains Translates down (+20%). Scrolls 20% slower. Sits mid-depth.
Foreground Ridge Translates up (-5%). Scrolls 5% faster. Feels close and tactile.

Feature Matrix

Interactive Elements Revealed by View Timelines

As you scroll down, these bento-style information cards are triggered dynamically by your scroll viewport position, scaling and fading in via view() timelines.

⚡

Pure CSS Scroll Progress

The progress bar at the top of the viewport scales on the X-axis tracking the root document. No scroll event listeners, no layout recalculations, and zero script dependencies. Runs entirely on the browser's compositor thread.

animation-timeline: scroll(root)
📐

Bounded Ranges

Animations can be restricted to specific regions of the page using animation-range. The hero parallax maps only to the first 100vh of scroll, locking cleanly in place once scrolled past.

animation-range: 0px 100vh
👁

View Timelines

Unlike global scroll positions, view() maps animation progress to the intersection of individual elements with the scrollport, providing lightweight reveal-on-scroll functionality.

animation-timeline: view()
♿

Accessibility & Reduced Motion

We respect user OS-level preference for reduced motion. By querying prefers-reduced-motion: reduce, scroll-linked translations and rotations are gracefully disabled, providing a stable, premium static presentation.

@media (prefers-reduced-motion)
Implementation Details

Sleek Syntax & Architecture

Learn how simple it is to build a scroll-driven parallax using pure CSS scroll timelines and range limits.

style.css
/* 1. Define the parallax keyframes with varying translateY multipliers */
@keyframes parallax-bg {
  to { transform: translateY(45%); }
}
@keyframes parallax-mid {
  to { transform: translateY(20%); }
}

/* 2. Bind animations to scroll timeline and bound scroll offset ranges */
.layer-sky {
  animation: parallax-bg linear both;
  animation-timeline: scroll();
  animation-range: 0px 100vh;
}

.layer-mountain-mid {
  animation: parallax-mid linear both;
  animation-timeline: scroll();
  animation-range: 0px 100vh;
}

/* 3. Handle accessibility gracefully */
@media (prefers-reduced-motion: reduce) {
  .parallax-layer {
    animation: none !important;
    animation-timeline: none !important;
    transform: none !important;
  }
}
