# Jacquard Shuttle Lift

## What does this do?
Renders a self-contained CSS-only `ease-jacquard-shuttle-lift` demo: Jacquard loom shuttle lifting through warp threads.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-jacquard-shuttle-lift`. No build step or JavaScript is required for the effect.

```html
<section class="ease-jacquard-shuttle-lift">
  <div class="ease-jacquard-shuttle-lift__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
