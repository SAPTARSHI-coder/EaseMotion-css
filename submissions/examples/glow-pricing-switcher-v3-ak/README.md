# glow-pricing-switcher-v3-ak

Pure CSS animated pricing plan switcher toggle — no JavaScript required.

## How to use

```html
<div class="ease-pricing-switcher-v3">
  <input type="radio" name="p" id="m" checked />
  <label for="m" class="ease-pricing-option-label-v3">Monthly</label>
  <input type="radio" name="p" id="y" />
  <label for="y" class="ease-pricing-option-label-v3">Annual</label>
  <span class="ease-pricing-switcher-glider-v3"></span>
</div>
