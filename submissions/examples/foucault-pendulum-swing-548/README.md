# Foucault Pendulum Swing Particle Effect

A pure CSS particle effect featuring a swinging Foucault Pendulum with glowing sand particles dropping from the bob and a slow 3D precession rotation.

## Usage

```html
<div class="foucault-container">
  <div class="floor"></div>
  <div class="rotate-plane">
    <div class="pendulum">
      <div class="string"></div>
      <div class="bob"></div>
      <div class="particle p1"></div>
      <div class="particle p2"></div>
      <div class="particle p3"></div>
      <div class="particle p4"></div>
      <div class="particle p5"></div>
      <div class="particle p6"></div>
    </div>
  </div>
</div>
```

## Why is it useful?

It provides a smooth, hardware-accelerated 3D animated particle effect purely with HTML and CSS, perfect for physics-based loaders, splash screens, or dark mode aesthetic focal points without needing any external JavaScript libraries, fitting EaseMotion's zero-dependency philosophy.
