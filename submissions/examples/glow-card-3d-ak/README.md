# glow-card-3d-ak

Pure CSS 3D glassmorphism hover card with radial backlight aura expansion — no JavaScript required.

## How to use

```html
<div class="ease-3d-glow-card">
  <h3 class="ease-3d-glow-card__title">Title</h3>
  <p class="ease-3d-glow-card__desc">Description text.</p>
</div>

<!-- Color Variants -->
<div class="ease-3d-glow-card ease-3d-glow-card--emerald">...</div>
<div class="ease-3d-glow-card ease-3d-glow-card--rose">...</div>
