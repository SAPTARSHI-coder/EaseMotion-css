# Glassmorphism Badge Component

A frosted glass status badge component featuring a continuous radar pulse animation utility for live indicators.

## Features
- **Frosted Glass Styling:** CSS `backdrop-filter` backdrop effect with translucent border outlines.
- **Radar Pulse Utility:** Keyframe animation expanding radar ring effect for status indicators.
- **Pure CSS:** Zero JavaScript dependencies.

## File Structure
- `demo.html` - Status badge markup variants.
- `style.css` - Component variables, backdrop filters, and radar pulse keyframes.
