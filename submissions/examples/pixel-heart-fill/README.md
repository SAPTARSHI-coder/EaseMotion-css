# Pixel Heart Fill

An 8-bit heart that fills pixel by pixel and beats with a retro glow.

## Features
- Box-shadow pixel grid forms a heart
- Fill cascades from bottom to top
- Beat pulse keeps the retro vibe

## Usage
```html
<div class="ph-heart"></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
