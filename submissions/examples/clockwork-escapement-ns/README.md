# Clockwork Escapement

## What does this do?
Renders a self-contained CSS-only `ease-clockwork-escapement` demo: Anchor escapement ticking against an escape wheel.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-clockwork-escapement`. No build step or JavaScript is required for the effect.

```html
<section class="ease-clockwork-escapement">
  <div class="ease-clockwork-escapement__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
