# Torus Knot · 3D Knot Rotates and Morphs 🌀

An interactive 3D torus knot with realistic rotation, morphing shapes, and vibrant colors. Watch the knot transform and rotate in 3D space!

## Features

- 🌀 **3D Torus Knot** – Mathematical 3D knot
- 🔄 **Rotation** – Smooth 3D rotation
- 🎨 **Colorful** – Rainbow gradient colors
- 🎚️ **Speed Control** – Adjust rotation speed (1-10)
- 🎚️ **Complexity Control** – Adjust knot complexity (3-8)
- ⏸️ **Pause/Resume** – Toggle animation
- 🔄 **Reset** – Reset knot
- ✨ **Glow Effects** – Node glow and line glow

## How to Use

1. Click **MORPH** or press **Space** to transform the knot
2. Watch it rotate and morph in 3D space
3. Adjust **Speed** for rotation pace
4. Adjust **Complexity** for knot intricacy
5. Press **RESET** or **R** to reset
6. Press **PAUSE** or **P** to pause/resume animation

## Controls

## Technical Details

- **3D Rendering:** Perspective projection
- **Rotation:** 3-axis rotation (X, Y, Z)
- **Morphing:** Smooth interpolation
- **Performance:** 60fps with requestAnimationFrame

## Customization

You can easily customize:
- **Colors:** Modify color generation
- **Complexity:** Adjust slider range (3-8)
- **Speed:** Modify rotation speed
- **Points:** Change number of vertices
- **Knot:** Modify p and q parameters
