# Float-Drift Popover

A lightweight, minimalist CSS popover with a subtle floating and horizontal drift animation, designed for modern technology-focused interfaces.

## Features

- Pure HTML and CSS
- No JavaScript or external dependencies
- Smooth float and drift keyframe animation
- Minimalist dark technology-inspired design
- Responsive across desktop, tablet, and mobile
- CSS custom properties for easy customization
- Accessible `prefers-reduced-motion` support
- Keyboard-focusable trigger
- Lightweight implementation

## Files

- `demo.html` — Showcase page and popover markup
- `style.css` — Complete styling, responsive layout, and animations

## Usage

Copy the popover structure from `demo.html` and include `style.css` in your project.

<link rel="stylesheet" href="style.css">
