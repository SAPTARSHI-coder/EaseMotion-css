# Ease Fluid Magnetic Navbar Component (`ease-magnetic-navbar`)

A macOS-inspired **Fluid Magnetic Navbar** component featuring cursor magnetic attraction vectors, fluid sliding indicator pill physics, and glassmorphism backdrop styling.

---

## ⚡ Features

- **Magnetic Cursor Attraction**: Navigation buttons calculate cursor proximity vectors and physically pull toward the pointer.
- **Fluid Sliding Indicator**: Animated background pill indicator smoothly morphs width and position using cubic-bezier spring physics.
- **Glassmorphism Styling**: Frosted glass background container with dynamic backdrop blur and border aura shadows.
- **Icon + Label Layout**: Integrated SVG icons with clean typography.
- **Responsive Dock Fallback**: Collapses gracefully to icon-only mode on mobile viewports.
