# Custom Morphing Cursor Pointer Trail Effect for Portfolios

A modern, minimalist custom cursor component built using **HTML, CSS, and JavaScript**. The component replaces the default mouse pointer with a smooth morphing cursor and animated trail, creating a premium portfolio browsing experience.

---

## Features

- Smooth custom cursor animation
- Morphing cursor on interactive elements
- Animated pointer trail
- Glassmorphism inspired cards
- Responsive portfolio landing page
- Pure HTML, CSS and JavaScript
- No external JavaScript libraries required

## Responsive Design

The component is fully responsive.

On smaller screens:

- Custom cursor is automatically disabled
- Native cursor is restored
- Layout adjusts for mobile devices

## Customization

You can easily customize the component through CSS variables.

```css
:root{

--accent:#5B7CFA;

--bg:#f7f8fc;

--text:#121212;

--surface:rgba(255,255,255,.65);

}
```

You may also adjust:

- Cursor size
- Cursor animation speed
- Trail duration
- Card border radius
- Shadow intensity
- Glass blur effect
