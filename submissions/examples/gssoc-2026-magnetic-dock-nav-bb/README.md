# Magnetic Dock Navigation Bar Showcase

A macOS-inspired **Magnetic Dock Navigation Bar** with fluid scale physics, active indicator pills, and glassmorphic styling.

## 🌟 Key Features

- **Fluid Magnification**: Scale transition with spring curve (`cubic-bezier(0.34, 1.56, 0.64, 1)`).
- **Tooltip Overlay**: Floating contextual tooltips on dock item hover.
- **Active Indicator Pill**: Subtle indicator dot reflecting active workspace state.

## 🚀 Usage

Open `demo.html` in your browser.
