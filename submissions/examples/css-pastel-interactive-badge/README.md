# Interactive Badge with Pastel Styling (#78639)

A soft, aesthetic pastel badge component featuring smooth hover elevation shifts and a glowing indicator dot.

## Features
- **Pastel Palette:** Soft rose tones providing a warm, friendly UI accent.
- **Interactive Elevation:** Smooth hover translations and subtle shadow depth.
- **Fully Responsive:** Centered flex container adapting seamlessly to all screen widths.

## File Hierarchy
- `style.css` - Custom properties, badge layout metrics, and interactive hover states.
- `demo.html` - Semantic markup demonstrating interactive badge integration with ARIA attributes.
- `README.md` - Technical specification and architecture overview.
