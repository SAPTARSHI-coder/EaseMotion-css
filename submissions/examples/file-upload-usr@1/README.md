# Animated File Upload Submission

## 1. What does this do?
It provides a modern, animated file upload component with drag-and-drop functionality, file preview, progress tracking, and smooth animations. Perfect for forms, profile pictures, and document submission.

## 2. How is it used?
The component includes a drop zone for drag-and-drop, a browse button for file selection, file list with previews (images show thumbnails, other files show icons), progress bar for upload tracking, and action buttons to clear or upload files.

## 3. Why is it useful?
- Essential component for forms and file submission
- Smooth drag-and-drop with visual feedback (border color change, scale animation)
- File preview with image thumbnails and file type icons
- Real-time upload progress with animated progress bar
- File size validation (max 10MB)
- Remove individual files with smooth animation
- Clear all files with staggered animation
- Beautiful bounce animation on upload icon
- Fully accessible with ARIA labels
- Includes `prefers-reduced-motion` support for accessibility
- Mobile-responsive design
- Easy to customize file types, sizes, and styles
- Maintainer can easily standardize this as `.ease-file-upload-[YOUR_INITIALS]` in the core library.
