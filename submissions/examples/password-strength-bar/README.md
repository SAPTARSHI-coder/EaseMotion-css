# Password strength bar

An input whose accent bar grows and shifts colour from red to amber to green as the password gets stronger.

## How to view

Open `demo.html` in any modern browser. The demo is fully self-contained — no CDN, no framework, no JavaScript.

## How to use

Copy `style.css` into your project's stylesheet. Every class used in the demo is namespaced with `passwordstrengthbar-` to avoid collisions.

## Why this is useful for EaseMotion CSS

Signup form pattern; the live meter helps the user pick a strong password without leaving the page.
