# Shimmer-Sweep Tooltip for Minimalist Tech Layouts

## Overview

A lightweight pure CSS tooltip component featuring a smooth shimmer sweep animation.

Designed for modern minimalist tech interfaces, dashboards, and UI showcases.

## Features

- Pure HTML and CSS implementation
- No JavaScript required
- Glassmorphism tooltip design
- Smooth shimmer sweep animation
- Responsive layout
- Hover interaction
- Accessible reduced motion support
