# Notification Toast Component

**Issue:** [#71809](https://github.com/SAPTARSHI-coder/EaseMotion-css/issues/71809)

Slide-in notification toast with success/error/warning/info variants.

## Design Tokens

| Token | Default |
|-------|---------|
| `--tm-toast-success` | `#10b981` |
| `--tm-toast-error` | `#ef4444` |
| `--tm-toast-warning` | `#f59e0b` |
| `--tm-toast-info` | `#6366f1` |
| `--tm-toast-radius` | `10px` |

## Variants

- `.toast` (default/info)
- `.toast.success`
- `.toast.error`
- `.toast.warning`
