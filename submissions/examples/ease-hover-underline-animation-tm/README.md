# Hover Underline Animation Component

Add ease-hover-underline-animation-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|---------|
| `--hua-accent` | `#6366f1` |
| `--hua-accent2` | `#ec4899` |

## Technique

`::after` pseudo-element with `scaleX` transform creates animated underline on hover.
