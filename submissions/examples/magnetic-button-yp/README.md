# Magnetic Button

## What does this do?

This submission provides an interactive magnetic button that subtly moves toward the user's cursor when it comes within a defined proximity. The effect creates a smooth and engaging call-to-action while maintaining a clean, lightweight implementation.

## How is it used?

```html
<button class="magnetic-button">
    <span>Get Started</span>
</button>
```

## Why is it useful?

Magnetic interactions are commonly used in modern landing pages and product websites to draw attention to important actions. This example demonstrates how a premium cursor-following effect can be achieved with minimal JavaScript and CSS while remaining easy to customize and integrate.

- HTML
- CSS
