# Scorpion Crossbow Draw

## What does this do?
Renders a self-contained CSS-only `ease-scorpion-crossbow-draw` demo: Roman scorpion crossbow draw and loose.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-scorpion-crossbow-draw`. No build step or JavaScript is required for the effect.

```html
<section class="ease-scorpion-crossbow-draw">
  <div class="ease-scorpion-crossbow-draw__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
