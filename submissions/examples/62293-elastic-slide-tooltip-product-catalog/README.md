# CSS Elastic-Slide Tooltip for Product Catalog Layouts

A modern, responsive **Elastic-Slide Tooltip** component built using only HTML5 and CSS3 for the EaseMotion CSS collection.

## Features

- Elastic slide tooltip animation
- Four tooltip positions (Top, Right, Bottom, Left)
- Smooth cubic-bezier transitions
- Pure HTML & CSS
- Fully responsive layout
- Product catalog showcase
- Accessible structure
- Supports `prefers-reduced-motion`
- Easy customization using CSS variables

## CSS Variables

| Variable | Description |
|----------|-------------|
| --primary | Primary color |
| --secondary | Secondary accent |
| --bg | Page background |
| --card | Card color |
| --text | Text color |
| --radius | Border radius |
| --shadow | Card shadow |
| --duration | Animation duration |
| --elastic | Elastic easing |
