# Ease Zoom-In Checkout Grid

A responsive e-commerce checkout card grid showcasing smooth zoom-in hover interactions using pure HTML and CSS.

---

## Features

- Pure HTML & CSS
- Responsive card grid
- Smooth zoom-in hover animation
- Gradient hover overlay
- Accessible design
- `prefers-reduced-motion` support
- Mobile-friendly layout
- Modern checkout UI

## Usage

Open `demo.html` in any modern browser.

No JavaScript or external dependencies are required.
