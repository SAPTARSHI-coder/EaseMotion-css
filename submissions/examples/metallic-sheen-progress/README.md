# Metallic Sheen Progress Bar

A polished, responsive and accessible progress bar featuring a
realistic **Metallic Sheen** visual effect.

This component is created entirely with **HTML and Vanilla CSS**,
with no JavaScript or external dependencies.

## ✨ Features

- Metallic gradient finish
- Animated reflective sheen
- Smooth progress transitions
- Responsive design
- Dark-mode friendly
- Pure HTML + CSS
- Hardware-accelerated animations
- Accessible `progressbar` semantics
- ARIA support
- Reduced-motion support
- Hover interaction
- CSS custom property based progress control
- No JavaScript required
