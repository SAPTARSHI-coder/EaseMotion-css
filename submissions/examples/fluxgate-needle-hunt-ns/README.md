# Fluxgate Needle Hunt

## What does this do?
Renders a self-contained CSS-only `ease-fluxgate-needle-hunt` demo: Fluxgate magnetometer sensing coil hunt with a hunting null needle.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-fluxgate-needle-hunt`. No build step or JavaScript is required for the effect.

```html
<section class="ease-fluxgate-needle-hunt">
  <div class="ease-fluxgate-needle-hunt__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
