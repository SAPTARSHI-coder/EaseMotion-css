# CSS Rotate-Fade Toast for Minimalist Tech Layouts


A modern toast notification component built using pure HTML and CSS with a smooth rotate-fade entrance animation.


## Features

- Pure CSS animation
- No JavaScript required
- Glassmorphism design
- Rotate + fade entrance effect
- Smooth hover interaction
- Responsive layout
- Accessible reduced motion support
