Engineering Details

How it works

Pure CSS Geometry The circular jaws are formed using round CSS borders and colored border segments.
Performance Optimized Uses transform animations only, which execute on the GPU compositor thread without triggering layout reflows.
ARIA Compliant Utilizes role="progressbar" along with descriptive aria-label tags to keep loaders accessible to screen readers.
Reduced Motion Fully honors system-level vestibular accessibility flags by pausing all loops immediately via prefers-reduced-motion.
