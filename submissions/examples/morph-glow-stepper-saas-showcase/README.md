# CSS Morph-Glow Stepper for SaaS Showcase Layouts

A modern **Morph-Glow Stepper** built using pure HTML and CSS for EaseMotion CSS.

## Features

- Morphing glowing step indicators
- Smooth keyframe animations
- Animated connector lines
- Responsive layout
- Glassmorphism UI
- CSS Custom Properties
- Pure HTML & CSS
- No JavaScript
- Accessible
- Supports prefers-reduced-motion
