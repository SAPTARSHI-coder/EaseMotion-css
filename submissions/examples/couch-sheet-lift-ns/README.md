# Couch Sheet Lift

## What does this do?
Renders a self-contained CSS-only `ease-couch-sheet-lift` demo: Couching the wet sheet onto felt.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-couch-sheet-lift`. No build step or JavaScript is required for the effect.

```html
<section class="ease-couch-sheet-lift">
  <div class="ease-couch-sheet-lift__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
