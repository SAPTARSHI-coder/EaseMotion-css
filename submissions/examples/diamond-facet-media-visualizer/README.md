# Diamond Facet Edge Media Visualizer

A pure CSS audio and media visualizer featuring a geometric **Diamond Facet Edge** design.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript or external dependencies
- Animated diamond facet layers
- CSS media controls
- Playback progress indicator
- Animated audio bars
- Responsive layout
- Dark-mode friendly design
- Keyboard-focusable controls
- `prefers-reduced-motion` support
- Hardware-friendly CSS transforms and opacity animations
