# CSS Fade-In Hero Section for Fintech Dashboard Layouts

A modern fintech hero section component featuring smooth fade-in animations, gradient effects, and a responsive dashboard preview.

This component is built using pure HTML and CSS without any external dependencies.

## ✨ Features

- 🌟 Smooth fade-in hero animations
- 📊 Fintech dashboard preview card
- 🎨 Modern gradient typography
- ⚡ Pure HTML and CSS implementation
- 📱 Fully responsive layout
- ✨ Smooth hover interactions
- ♿ Accessibility support with `prefers-reduced-motion`
- 💎 Glassmorphism dashboard design

## 🚀 Usage

1. Clone the EaseMotion CSS repository.

2. Navigate to the component folder:


submissions/examples/ease-css-fade-in-hero-section-fintech-dashboard-layouts/


3. Open `demo.html` in your browser.

No frameworks or external libraries are required.

## 🎨 CSS Custom Properties

The component uses CSS variables for easy customization:

```css
:root {
    --bg: #050816;
    --primary: #00f5ff;
    --secondary: #8b5cf6;
    --green: #22c55e;
    --text: #f8fafc;
    --muted: #94a3b8;
}

You can modify these variables to match your product branding.
