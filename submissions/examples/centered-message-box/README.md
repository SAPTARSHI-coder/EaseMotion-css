# Centered Message Box (#75275)

A clean, reusable CSS-only centered message box utility for empty states, success alerts, and dashboard notifications.

## Features
- **Aesthetic:** Centered container layout with subtle border contrast and balanced typography.
- **Pure CSS:** Zero JavaScript dependencies; relies purely on modern CSS flexbox centering.
- **Performance:** Lightweight, non-blocking rendering.
- **Accessibility:** Readable contrast ratios and semantic HTML structure.
