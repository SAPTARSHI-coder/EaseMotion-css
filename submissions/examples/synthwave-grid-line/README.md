# Synthwave Grid Line Loader

A smooth and visually engaging pure CSS loader inspired by retro-futuristic synthwave grid aesthetics.

## ✨ Features

- Pure HTML and Vanilla CSS
- Synthwave-inspired grid animation
- Animated perspective grid floor
- Neon horizon glow
- Rotating loading rings
- Smooth CSS animations
- Dark-mode friendly design
- Responsive layout
- Hardware-accelerated transforms
- `prefers-reduced-motion` support
- No external libraries or JavaScript
