# Elastic-Slide Card Grid

## 1. What does this do?
Cyberpunk neon card grid with elastic slide-in animation.

## 2. How is it used?
Apply `.ease-elastic-slide-card` to grid items.

## 3. Why is it useful?
- Cyberpunk neon aesthetic with elastic bounce animation
- Creates engaging entrance effects for card grids
- Enhances visual appeal of layout showcases
