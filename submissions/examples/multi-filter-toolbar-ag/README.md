# Multi-Filter Toolbar

A responsive **Multi-Filter Toolbar** built using pure HTML5 and CSS3 for admin dashboards, tables, and card layouts.

## ✨ Features

- Pure HTML5 & CSS3
- Responsive toolbar
- Search input with focus glow
- Active filter pills
- Result count badge
- Grid/List toggle buttons
- CSS Custom Properties
- `prefers-reduced-motion` support
- No external libraries
