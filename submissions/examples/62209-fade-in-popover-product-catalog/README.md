# CSS Fade-In Popover for Product Catalog Layouts

A modern **Fade-In Popover** built using pure HTML5 and CSS3 for product catalog layouts. The component provides responsive product quick-view popovers with smooth fade-in animations, glassmorphism styling, and accessibility support.

## Features

* Pure HTML5 & CSS3
* Fade-In popover animation
* Product quick-view popover
* Glassmorphism popover design
* Arrow indicator
* Product title, price, description, stock status, and CTA button
* Smooth CSS transitions & keyframe animations
* Responsive desktop, tablet, and mobile layout
* CSS Custom Properties
* No JavaScript required
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over the **Quick View** button to display the popover.
3. Customize colors, spacing, shadows, and animation timing using the CSS variables in `:root`.
4. Integrate the popover into any product catalog or e-commerce interface.
