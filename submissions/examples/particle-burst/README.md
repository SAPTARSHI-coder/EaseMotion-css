# Particle Burst

A pure CSS sci-fi HUD interaction featuring a lightweight radial particle
burst effect for the EaseMotion CSS animation collection.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript or external dependencies
- Sci-fi / cyberpunk HUD styling
- Radial particle burst interaction
- Smooth GPU-friendly transforms and opacity animations
- Keyboard focus support
- Responsive layout
- Dark-mode friendly color palette
- `prefers-reduced-motion` accessibility support
