# Animated Real Estate Property Showcase

An elegant **Real Estate Property Showcase** built with **EaseMotion CSS**. Features property cards with image galleries, price display, location info, property features, agent contact, and luxury-themed design.

## ✨ Features

- **🏠 Property Cards**: Image hover zoom, badges, photo counts
- **💰 Price Display**: Prominent pricing with status indicators
- **📍 Location Info**: Address display with map pin icon
- **🛏️ Property Features**: Beds, baths, sqft, and amenities
- **👤 Agent Info**: Avatar and name display
- **🔍 Advanced Search**: Tabs, location, type, and price filters
- **📊 Stats Section**: Company metrics with icons
- **🎬 Staggered Entrance**: All sections slide up sequentially
- **📱 Fully Responsive**: 3-column → 2-column → 1-column layout

## 🧩 EaseMotion Classes Used

| Class | Purpose |
|-------|---------|
| `ease-fade-in` | Fades in the main page and footer |
| `ease-slide-up` | Slides sections up on entrance |
| `ease-delay-100` to `ease-delay-600` | Creates cascading staggered sequence |
| `ease-card` | Base card structure |
| `ease-hover-lift` | Lift effect on cards |
| `ease-hover-grow` | Scale effect on buttons |
| `ease-center` | Centers search button content |
| `ease-grid` + `ease-grid-cols-*` | Responsive grid layouts |
| `ease-gap-4` | Spacing between grid items |
| `ease-btn` + `ease-btn-primary` | Styled CTA buttons |

## 🚀 How to Use

1. Open `demo.html` in any modern browser
2. Watch all sections slide in with staggered animations
3. Hover over property cards to see image zoom and lift effects
4. Hover over favorite buttons to see color change
5. Test the search tabs and filter chips
6. Resize to mobile to see responsive layout

## 🎨 Design Highlights

- **Luxury Typography**: Cormorant Garamond for headings, Jost for body
- **Gold Accent**: Premium gold color scheme for luxury feel
- **Image Hover Zoom**: Property images scale on card hover
- **Badge System**: Featured, New Listing, Open House badges
- **Gradient CTA**: Dark gradient section with property image
