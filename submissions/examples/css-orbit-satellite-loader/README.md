# CSS Orbit Satellite Loader

A lightweight loading spinner featuring a satellite orbiting a planet, created entirely with HTML and CSS.

## Features

* Pure CSS animation
* No JavaScript
* Animated satellite orbit
* Planet pulse effect
* Responsive design
* Keyboard focus support
* Accessible loading status
* Reduced-motion support

## Files

* `demo.html` - Demo markup
* `style.css` - Loader animation, orbit, satellite, and responsive styling

## Usage

Open `demo.html` in any modern browser.

The loader displays a planet with a satellite continuously orbiting around it.

## Accessibility

The loader uses a semantic `role="status"` with an accessible loading label. Decorative visual elements are hidden from assistive technologies using `aria-hidden`.

The demo also supports keyboard focus and respects `prefers-reduced-motion` for users who prefer reduced animation.
