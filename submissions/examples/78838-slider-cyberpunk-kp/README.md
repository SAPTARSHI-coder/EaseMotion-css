# Glassmorphism Slider - Cyberpunk

A cyberpunk glassmorphism range slider for issue #78838. It includes a frosted control surface, neon rail, animated fill, tick marks, value badge, focus states, and reduced-motion support.

## Features

- Native range input with custom CSS styling
- Frosted glass panel and neon cyberpunk track
- Hover, focus, active, and responsive states
- Pure HTML and CSS, no external assets
