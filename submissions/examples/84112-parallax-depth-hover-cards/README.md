# CSS Parallax Depth Hover Cards

A self-contained CSS example demonstrating a subtle parallax depth effect
for interactive cards.

## Overview

This example creates a layered depth effect when the user hovers over
a card. The card, decorative background elements, and foreground content
use different transform depths and transition speeds to create a subtle
three-dimensional interaction.

The effect is implemented entirely with HTML and CSS and does not require
JavaScript or external libraries.

## Features

- Pure CSS parallax depth effect
- Smooth hover interaction
- Layered foreground and background elements
- 3D perspective transforms
- Responsive card layout
- No JavaScript required
- No external dependencies
- Reduced-motion support using `prefers-reduced-motion`
