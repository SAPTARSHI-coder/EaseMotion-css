Glass Navbar

A sticky navbar where backdrop-filter: blur() intensifies as you scroll. Powered by @property + animation-timeline: scroll(). The blur, background opacity, and border all respond fluidly. Zero JavaScript.

Scroll to see the glass effect
How It Works

The navbar tracks scroll progress using animation-timeline: scroll(root) and feeds it into @property-registered custom properties that control the glass effect in real-time.

◆

Dynamic Blur

--nav-blur starts at 0px and smoothly increases to 20px as you scroll down. The backdrop reacts instantly.

◆

Progressive Opacity

--nav-bg-opacity transitions from 0 to 0.8, making the navbar background gradually solid as you descend.

◆

Border Reveal

--nav-border-opacity draws a subtle bottom border that only appears after the user has scrolled past the hero.

◆

@property Powered

Three custom properties registered as <length> and <number> types enable smooth interpolation.

Observe the Effect

Scroll up and down. Watch the navbar transform from transparent to a frosted glass surface — the blur intensifies progressively, not in a single binary step.

Traditional approaches use JavaScript scroll event listeners to add or remove CSS classes at fixed scroll offsets. This creates abrupt, binary transitions. The scroll-driven approach here uses animation-timeline: scroll(root) which provides a continuous 0-to-1 progress value — enabling truly fluid transitions.

CSS APIs Used

The modern CSS primitives powering the scroll-driven glass navbar
API Role Support
@property Registers typed custom properties for smooth interpolation of blur, opacity, and border values Chrome 85+, Safari 16.4+, Firefox 128+
animation-timeline: scroll() Links animation progress to the scroll position of the root scroller Chrome 115+, Safari 18+
backdrop-filter Applies a frosted glass blur to the area behind the navbar Chrome 76+, Safari 9+, Firefox 103+
position: sticky Keeps the navbar pinned to the viewport top during scroll All modern browsers
animation-range Defines the scroll range where the animation is active Chrome 115+, Safari 18+

In browsers without animation-timeline support, the navbar defaults to a fully transparent state — still functional but without the progressive glass effect. The navigation remains usable everywhere.
