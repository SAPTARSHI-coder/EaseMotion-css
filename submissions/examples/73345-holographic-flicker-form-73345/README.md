# CSS Holographic Flicker Form

Issue #73345 implements a holographic form with spectral gradients and controlled CSS flicker.

## Features

- Animated spectrum gradient
- Soft holographic sweep
- Native controls
- Keyboard focus styles
- Responsive layout
- Reduced-motion support

## Accessibility

All controls remain semantic and keyboard accessible. Decorative flicker and sweep animations stop for reduced-motion users.

## Files

- `demo.html` — form demonstration
- `style.css` — holographic effects and responsive rules
- `README.md` — documentation
