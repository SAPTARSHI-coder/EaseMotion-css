# CSS Ripple-Wave Drawer for Fintech Dashboard Layouts

A modern **Ripple-Wave Drawer** built using pure HTML and CSS for fintech dashboards, banking portals, admin interfaces, and analytics platforms.

## Features

* Pure HTML5 & CSS3
* Ripple-wave hover animation
* CSS-only drawer navigation
* Responsive layout
* Fintech-inspired UI
* CSS custom properties
* No JavaScript required
* Supports `prefers-reduced-motion`

## Folder Structure

```text
59277-ripple-wave-drawer-fintech-dashboard-v2/
├── demo.html
├── style.css

```

## Usage

1. Open `demo.html` in any modern browser.
2. Click the menu button to open or close the drawer.
3. Customize the navigation links and branding.
4. Modify the theme colors using the CSS variables in `:root`.
