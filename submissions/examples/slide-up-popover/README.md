# CSS Slide-Up Popover

## Overview

A responsive gaming-inspired popover that smoothly slides upward into view using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Slide-Up animation
- Responsive layout
- CSS Custom Properties
- Accessible (`prefers-reduced-motion`)
- No JavaScript

## Folder Structure

```text
slide-up-popover/
├── demo.html
├── style.css
└── README.md
```

## Usage

1. Open `demo.html`.
2. Hover over the button.
3. Customize the CSS variables as needed.

## CSS Variables

- `--primary`
- `--background`
- `--surface`
- `--text`
- `--duration`

## Browser Support

- Chrome
- Firefox
- Edge
- Safari
