# 🔊 Echo Chamber

An interactive visual echo chamber that transforms pointer and keyboard
interactions into expanding, glowing ripple effects.

Each interaction creates an echo that expands outward and produces a
secondary reflected ripple, creating the visual feeling of sound without
audio playback.

## Features

- Click-generated echoes
- Expanding ripple rings
- Visual boundary reflection
- Glowing ripple trails
- Multiple simultaneous echoes
- Live echo counter
- Adjustable echo strength
- Clear functionality
- Spacebar interaction
- Responsive chamber
- Keyboard accessibility
- Reduced-motion support
- CSS-driven animations
- No external dependencies
