# Glassmorphic Pricing Tier Card Component

A modern 3D Glassmorphic Pricing Card with high-performance CSS blur filters, interactive tilt physics, shimmer highlights, and responsive layouts.

## What does this do?
This component renders an interactive pricing tier card featuring frosted glass backdrop effects (`backdrop-filter`), smooth hover elevation with 3D perspective transforms, and vibrant gradient glow styling.

## How is it used?
1. Open `demo.html` in any modern web browser.
2. Link `style.css` to incorporate the custom CSS rules into your web application or marketing page.
3. Customize the CSS custom properties (`--glass-bg`, `--glass-border`, `--accent-glow`) in `:root` to match your application's brand identity.

## Why is it useful?
Pricing cards are a core SaaS element. Utilizing native CSS hardware-accelerated animations (`transform`, `backdrop-filter`, `opacity`) provides a premium, responsive aesthetic with high 60fps performance without relying on heavy external JavaScript libraries.
