# CSS Floating Labels Cluster

### What does this do?
This component creates a visually engaging cluster of floating tags or labels that gently drift and arrange themselves organically using pure CSS animations.

### How is it used?
Apply the `.floating-labels-cluster` class to a container element and `.floating-label` to the individual child tags inside it.

```html
<div class="floating-labels-cluster" role="list" aria-label="Tags cluster">
    <a href="#" class="floating-label" role="listitem">Web Design</a>
    <a href="#" class="floating-label" role="listitem">CSS</a>
    <a href="#" class="floating-label" role="listitem">JavaScript</a>
</div>
```

### Why is it useful?
It provides an interactive and dynamic way to display tags, categories, or keywords without relying on heavy JavaScript libraries, which aligns perfectly with EaseMotion's philosophy of delivering lightweight, performant, and pure CSS solutions.
