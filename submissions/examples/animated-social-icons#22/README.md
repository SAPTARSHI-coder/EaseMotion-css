# Animated Social Icons

Modern animated social media icons built with pure HTML and CSS. Includes hover gradient effects, lift animation, staggered entrance, and responsive layout.

## Features

- Pure HTML and CSS implementation.
- Animated hover gradient effects.
- Staggered entrance animation.
- Modern glassmorphism icon buttons.
- Responsive layout.
- Supports `prefers-reduced-motion`.

## Usage

Copy the HTML structure from `demo.html` and link `style.css`.

```html
<ul class="social-list">
  <li class="social-item">
    <a href="#" class="social-link github" aria-label="GitHub">
      <!-- SVG icon -->
    </a>
    <span class="social-label">GitHub</span>
  </li>
</ul>
