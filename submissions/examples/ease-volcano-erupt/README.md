# Volcano Erupt · Lava Explodes on Click 🌋

An interactive volcano eruption with lava explosions, fire particles, and atmospheric volcanic effects. Make the volcano erupt with power!

## Features

- 🌋 **Volcano Eruption** – Lava explodes on click
- 🎚️ **Power Control** – Adjust eruption power (1-10)
- 🎚️ **Lava Control** – Adjust lava count (20-100)
- 🔊 **Sound Effects** – Eruption sounds
- ⏸️ **Pause/Resume** – Toggle animation
- 🔄 **Reset** – Reset volcano
- 📊 **Counter** – Tracks eruptions

## How to Use

1. Click **ERUPT** or press **Space** to make the volcano erupt
2. Click on the canvas to erupt more
3. Adjust **Power** for eruption intensity
4. Adjust **Lava** for particle count
5. Press **RESET** or **R** to reset
6. Press **PAUSE** or **P** to pause/resume animation

## Controls

| Action | Method |

## Technical Details

- **Lava Physics:** Gravity, drag, trails
- **Ash Physics:** Gravity, wobble
- **Glow:** Ambient glow particles
- **Performance:** 60fps with requestAnimationFrame

## Customization

You can easily customize:
- **Power:** Adjust slider range (1-10)
- **Lava:** Adjust slider range (20-100)
- **Colors:** Modify lava and volcano colors
- **Physics:** Adjust gravity and speed
- **Sound:** Adjust volume and frequency

## Browser Support

Works in all modern browsers:
- Chrome, Firefox, Safari, Edge
- Audio requires Web Audio API support

## Run Locally

Simply open `index.html` in your browser – no server required!
