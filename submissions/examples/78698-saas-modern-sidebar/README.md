# SaaS Modern Sidebar

A responsive SaaS-style dashboard sidebar built with pure HTML and CSS.

## Features

- Modern SaaS dashboard styling
- Responsive desktop and mobile layout
- CSS-only mobile sidebar toggle
- Active navigation state
- Workspace selector
- Upgrade plan card
- User profile section
- Notification indicator
- Responsive dashboard preview
- Keyboard-friendly interactive elements
- Visible focus states
- Reduced-motion support
- No JavaScript or external dependencies

## Files

- `demo.html`
- `style.css`

## Usage

Open `demo.html` in a browser.

The mobile sidebar is controlled using a native checkbox and CSS selectors,
so no JavaScript is required.

## Structure

The component contains:

- Brand section
- Workspace selector
- Primary navigation
- Management navigation
- Upgrade card
- User profile
- Responsive mobile navigation

## Technologies

- HTML5
- Vanilla CSS

## Accessibility

The component uses semantic navigation, labels for controls, descriptive
ARIA labels, and `prefers-reduced-motion` support.
