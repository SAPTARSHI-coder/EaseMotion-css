# Morphing Shape Floating Badge with Gradient Transition Effects

A vibrant floating badge featuring animated morphing shapes, colorful gradients, floating motion, and hover transitions built using pure HTML, CSS and JavaScript.

## Features

- Vibrant animated gradients
- Morphing border-radius animation
- Floating motion
- Hover glow effect
- Responsive layout
- Pure HTML, CSS & JavaScript

## Folder Structure

```
ease-anim-morphing-shape-floating-badge-with-gradient-transition-effects-86/
├── README.md
├── demo.html
├── style.css
└── script.js
```

## Usage

Open `demo.html` in your browser.

Customize colors, gradients and animation speed inside `style.css`.
