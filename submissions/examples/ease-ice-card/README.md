# ❄️ Ice Card – Frost Forms and Melts on Hover

> A chilly, wintery card where frost forms and melts on hover, creating a beautiful ice-crystal effect.

---

## 📖 Description

The **Ice Card** is a winter-themed UI component where frost forms and melts on hover. When you hover over the card, frost crystals emerge and expand with a rotating, scaling animation, while a melting effect flows from the bottom. The card features a cool blue color palette, frost-crystal shapes, and a shimmering ice effect.

The component uses CSS animations with `transform` and `keyframes` to create the frost formation and melting effects. Each frost crystal has a unique position and animation delay, creating an organic, spreading frost pattern. The melt effect adds a dynamic, flowing element that completes the ice theme.

Perfect for winter-themed interfaces, cold-weather brands, ski resorts, and any application where you want to create a cool, frosty interaction. The Ice Card transforms a simple card into a chilly, magical experience.
