# CSS Slider: Origami Paper Fold

A smooth, accessible, and performant pure CSS slider inspired by
the folding and unfolding motion of origami paper.

## Features

- Pure HTML and Vanilla CSS
- Origami paper-inspired visual design
- 3D paper folding transitions
- Layered paper-card presentation
- CSS-only slider navigation
- Smooth perspective transformations
- Folded corner effects
- Paper crease details
- Animated depth and shadows
- Dark mode compatible
- Light mode support
- Responsive layout
- `prefers-reduced-motion` support
- No JavaScript
- No external libraries
