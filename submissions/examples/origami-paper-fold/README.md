# 🌊 EaseMotion CSS

> A modern, highly performant, and fully accessible pure CSS animation and component library built with zero JavaScript dependencies.

## ✨ Features

* **Zero JavaScript:** Built entirely with native HTML5 and modern Vanilla CSS.
* **Hardware Accelerated:** Optimized using `transform` and `opacity` properties for buttery-smooth 60 FPS performance.
* **Fully Responsive:** Adapts seamlessly across mobile, tablet, and desktop viewports.
* **Accessibility First:** Native support for keyboard focus-visible states and `@media (prefers-reduced-motion: reduce)`.
* **Glassmorphism & Dark Mode:** Immersive dark mode styling paired with modern backdrop filters and custom properties.
