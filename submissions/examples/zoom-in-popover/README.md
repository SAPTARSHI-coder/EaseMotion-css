# CSS Zoom-In Popover

A responsive portfolio popover featuring a smooth zoom-in animation built with pure HTML and CSS.

## Features

- Pure HTML & CSS
- Smooth zoom-in hover effect
- Responsive design
- Accessible with prefers-reduced-motion
- No JavaScript required

## Files

```
demo.html
style.css
README.md
```

## Usage

Open `demo.html` in your browser.

## Customization

- Card size
- Background overlay
- Animation duration
- Border radius
- Colors
- Typography

## Browser Support

Works in all modern browsers supporting CSS transitions.
