# CSS Neon-Trace Button

A reusable pure CSS button component featuring a continuously moving neon border trace and glow interaction.

## Features

- Pure HTML and CSS
- Animated neon border trace
- Multiple accent color variants
- Hover and keyboard focus states
- Responsive layout
- No JavaScript required
- Smooth GPU-friendly transforms
- `prefers-reduced-motion` support
- Suitable for CTAs, navigation, landing pages, and dashboards
