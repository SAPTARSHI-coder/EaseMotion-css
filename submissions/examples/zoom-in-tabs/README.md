# Zoom-In Tabs

A responsive **Zoom-In Tabs** component built using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Smooth zoom hover effect
- Responsive design
- Keyboard accessible
- `prefers-reduced-motion` support
- No JavaScript required

## Folder Structure

```
zoom-in-tabs/
├── demo.html
├── style.css
└── README.md
```

## Usage

Open `demo.html` in any modern browser.
