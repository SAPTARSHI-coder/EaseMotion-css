# Particle Burst Action Button

A modern **neumorphic CTA button** with an interactive particle burst animation.

## Preview

The component provides a visually rich call-to-action button that creates a burst of particles when clicked.

## Features

* Neumorphic UI design
* Interactive particle burst effect
* Smooth hover animation
* Click feedback animation
* Responsive mobile-first layout
* CSS custom properties
* Keyboard focus support
* Reduced-motion accessibility support
* No external dependencies

## Files

particle-burst-action-button/

## Installation

No installation or dependencies are required.

Simply place the component inside:

```text
submissions/examples/ease-advanced-particle-burst-action-button-for-high-conversion-cta-triggers-44/
```

Then open `demo.html` in a modern web browser.

## Usage

The button can be used as a call-to-action element on landing pages, marketing sections, product pages, and interactive dashboards.

The particle animation is generated dynamically using JavaScript when the button is clicked.

## Customization

The main colors and neumorphic shadows can be customized through the CSS variables at the beginning of `style.css`.

```css
:root {
    --bg: #e8edf3;
    --accent: #5967ff;
    --accent-light: #7d88ff;
}
```

Change these values to match the design system of your project.
