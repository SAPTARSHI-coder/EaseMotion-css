# Weather Forecast · Weather Changes on Interaction 🌤️

An interactive weather forecast with dynamic weather changes, atmospheric effects, and real-time transitions. Click to change the weather!

## Features

- 🌤️ **7 Weather Types** – Sunny, Rainy, Snowy, Windy, Stormy, Cloudy, Foggy
- 🎨 **Dynamic Effects** – Particles, sky colors, and icons
- 🎚️ **Speed Control** – Adjust animation speed (1-10)
- 🎚️ **Particle Control** – Adjust particle count (50-400)
- ⏸️ **Pause/Resume** – Toggle animation
- 🔄 **Reset** – Reset to sunny
- 📱 **Touch Support** – Works on mobile devices

## How to Use

1. Click **CHANGE** or press **Space** to change the weather
2. Click on the canvas to change weather
3. Adjust **Speed** for animation pace
4. Adjust **Particles** for effect density
5. Press **RESET** or **R** to reset
6. Press **PAUSE** or **P** to pause/resume animation

## Controls

| Action | Method |
|--------|--------|
| Change Weather | Change button / Space / Click canvas |
| Reset | Reset button / R key |
| Pause/Resume | Pause button / P key |
| Speed | Speed slider |
| Particles | Particles slider |
