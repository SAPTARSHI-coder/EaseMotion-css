# Detonator Placer Arm

## What does this do?
Renders a self-contained CSS-only `ease-detonator-placer-arm` demo: Detonator placer arm dropping a fog signal.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-detonator-placer-arm`. No build step or JavaScript is required for the effect.

```html
<section class="ease-detonator-placer-arm">
  <div class="ease-detonator-placer-arm__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
