# Parallax Sidebar with Material Design Styling

Responsive sidebar component inspired by Material Design principles with layered gradient backgrounds, elevation effects and subtle parallax visuals.

## Features

- Responsive layout
- Material Design shadows
- Gradient sidebar styling
- Smooth hover interactions
- Mobile-friendly design
- Pure HTML and CSS
