# Compare Table Column Highlight Hover State

A responsive comparison table component featuring column hover highlighting for improved readability and interaction.

## Features

- Responsive comparison table
- Hover highlight effect
- Clean modern styling
- Mobile-friendly layout
- Easy customization

## Files

- demo.html – Component demo
- style.css – Styling
- README.md – Documentation

## Usage

Open `demo.html` in a browser.

Hover over table columns to view the highlight effect.

## Responsive Design

The table supports horizontal scrolling on smaller screens for better usability.
