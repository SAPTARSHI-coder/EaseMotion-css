# glow-popover-menu-v5-ak

Pure CSS animated glowing popover menu component — no JavaScript required.

## How to use

```html
<div class="ease-popover-wrapper-v5">
  <button class="ease-popover-trigger-v5">Options</button>

  <ul class="ease-popover-menu-v5">
    <li class="ease-popover-item-v5"><a href="#">Item 1</a></li>
    <li class="ease-popover-item-v5"><a href="#">Item 2</a></li>
  </ul>
</div>
