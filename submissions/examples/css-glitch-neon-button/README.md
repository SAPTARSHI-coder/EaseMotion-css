# CSS Product Color Variant Selector

A responsive product color variant selector built using pure HTML and CSS.

## Features

- 🎨 Circular color variant selectors
- ✨ Animated selection state
- 🖼️ Product preview changes based on selected color
- 📱 Responsive design
- 🌙 Light and dark mode support
- ♿ Keyboard-accessible color selection
- 🚫 No JavaScript required
- 🎨 CSS custom properties for easy theming

## Demo

Open `demo.html` directly in a web browser.

No server or build tools are required.
