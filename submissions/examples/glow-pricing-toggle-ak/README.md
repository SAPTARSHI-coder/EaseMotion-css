# glow-pricing-toggle-ak

Pure CSS animated monthly/yearly billing toggle switch — no JavaScript required.

## How to use

```html
<div class="ease-billing-toggle-wrapper">
  <span class="ease-billing-option ease-billing-monthly">Monthly</span>

  <label class="ease-billing-switch">
    <input type="checkbox" checked />
    <span class="ease-billing-slider"></span>
  </label>

  <span class="ease-billing-option ease-billing-yearly">
    Yearly <span class="ease-discount-badge">Save 20%</span>
  </span>
</div>
