# ease-glass-card-bh

Pure CSS glassmorphism cards with animated gradient aura.

## What does this do?
Creates modern glass-effect cards with beautiful animated gradient backgrounds that create an ethereal glow.

## How is it used?
```html
<div class="ease-glass-card-bh">
  <h3>Card Title</h3>
  <p>Card content goes here.</p>
</div>
```

## Why is it useful?
Provides a premium, modern UI aesthetic with frosted glass effects and dynamic gradient animations.
