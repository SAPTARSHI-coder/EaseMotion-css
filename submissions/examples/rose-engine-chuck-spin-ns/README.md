# Rose Engine Chuck Spin

## What does this do?
Renders a self-contained CSS-only `ease-rose-engine-chuck-spin` demo: Rose engine chuck oscillating cut.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-rose-engine-chuck-spin`. No build step or JavaScript is required for the effect.

```html
<section class="ease-rose-engine-chuck-spin">
  <div class="ease-rose-engine-chuck-spin__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
