# Dynamic Slider — Cyberpunk

## Issue

EaseMotion CSS issue #78794.

## Overview

A responsive cyberpunk range control with neon accents and a clear selected value.

## Features

- Native range input
- Neon track and thumb
- Responsive layout
- Keyboard focus support
- Reduced-motion consideration

## Usage

Open `demo.html` and reuse the range input styling for numeric controls. Keep the visual percentage aligned with the input value when adding dynamic behavior.

## Accessibility

The slider has a visible label and focus indicator and retains the browser's native range semantics.
