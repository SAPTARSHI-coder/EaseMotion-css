# Dynamic Slider with Cyberpunk Styling

A responsive cyberpunk-inspired slider component for EaseMotion CSS.

The component is built with pure HTML and CSS and requires no
JavaScript.

## Features

- Responsive layout
- Cyberpunk visual design
- Neon cyan, purple and pink accents
- Interactive native range slider
- Custom slider thumb
- Glowing track effects
- Futuristic telemetry panel
- Animated scanline and status indicator
- Keyboard focus support
- Reduced-motion accessibility support
- No external libraries

## Files

- `demo.html` — component markup
- `style.css` — complete styling

## Usage

Open `demo.html` in a browser.

The slider uses the native HTML `<input type="range">`
control so it remains keyboard accessible and works without
JavaScript.

## Customization

Edit the CSS variables at the top of `style.css` to change:

- Background colors
- Neon colors
- Borders
- Glow intensity
- Typography

## Accessibility

The component includes:

- An accessible slider label
- Native keyboard interaction
- Visible `:focus-visible` styling
- Responsive layout
- Reduced-motion support
