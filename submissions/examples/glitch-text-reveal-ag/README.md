# Glitch Text Reveal

1. What does this do? A stylized, cyberpunk-inspired text glitch effect on hover that rapidly shifts text slices and flashes cyan and magenta drop shadows.
2. How is it used? Apply `.text-glitch` to a text element and ensure its `data-text` attribute matches the inner text.
3. Why is it useful? It pushes the boundaries of what pure CSS can do for typography animations, abstracting complex clip-path animations into a simple, single class.
