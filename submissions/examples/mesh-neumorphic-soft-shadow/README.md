# Neumorphic Soft Shadow Mesh Gradient

A smooth 3D perspective mesh gradient using a neumorphic soft-shadow
visual style.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript required
- Soft neumorphic shadows
- Multi-layer mesh gradients
- Smooth hover transitions
- 3D perspective effect
- Dark mode support
- Responsive design
- Reduced-motion support
- Keyboard-accessible button
- Hardware-friendly CSS transforms

## Files

- `demo.html` — Standalone demonstration
- `style.css` — Complete CSS implementation

## Usage

Link the stylesheet in your HTML:

```html
<link rel="stylesheet" href="style.css">
