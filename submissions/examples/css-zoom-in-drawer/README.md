# CSS Zoom-In Drawer

A responsive navigation drawer with a smooth zoom-in animation built using only HTML and CSS.

## Features

- Pure HTML & CSS
- Zoom-in drawer animation
- Responsive design
- No JavaScript required
- Accessible checkbox toggle
- Supports `prefers-reduced-motion`

## Files

```
demo.html
style.css
README.md
```

## Customization

Change drawer width:

```css
.drawer{
    width:240px;
}
```

Change animation speed:

```css
transition:transform .4s ease;
```

Change theme color:

```css
.menu-btn{
    background:#2563eb;
}
```
