# Hydrometer Float Bob

## What does this do?
Renders a self-contained CSS-only `ease-hydrometer-float-bob` demo: Hydrometer float bobbing to a density equilibrium.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-hydrometer-float-bob`. No build step or JavaScript is required for the effect.

```html
<section class="ease-hydrometer-float-bob">
  <div class="ease-hydrometer-float-bob__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
