# Dashboard shimmer skeleton

A dashboard card whose placeholder blocks shimmer with a moving gradient while data is loading.

## How to view

Open `demo.html` in any modern browser. The demo is fully self-contained — no CDN, no framework, no JavaScript.

## How to use

Copy `style.css` into your project's stylesheet. Every class used in the demo is namespaced with `dashboardcardshimmerskeleton-` to avoid collisions.

## Why this is useful for EaseMotion CSS

Loading-state pattern; the shimmer signals 'data is on its way'.
