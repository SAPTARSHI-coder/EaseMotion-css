Basic Release Channel Row

Release channel rows for product rollout dashboards.

A CSS-only row component for showing channel name, version, audience, rollout share, and lifecycle status in one compact interface.

ST
Stable channel

Default release path for all production workspaces.

v4.8.2 100% Stable
BT
Beta channel

Early access build enabled for opted-in teams.

v4.9.0 18% Beta
LG
Legacy channel

Deprecated release path kept only for rollback safety.

v3.12.7 2% Legacy

HTML Usage

<article class="basic-release-channel-row">
  <span class="channel-mark is-stable" aria-hidden="true">ST</span>
  <div class="channel-copy">
    <strong>Stable channel</strong>
    <p>Default release path for all production workspaces.</p>
  </div>
  <span class="channel-version">v4.8.2</span>
  <span class="channel-rollout">100%</span>
  <span class="channel-state is-stable">Stable</span>
</article>
