# Form Input Validation Styles

## 1. What does this do?
Adds animated validation feedback for form inputs.

## 2. How is it used?
```html
<input class="ease-input ease-input-error">
<input class="ease-input ease-input-success">
<input class="ease-input ease-input-focus-glow">
```

## 3. Why is it useful?
Animated validation feedback improves user experience with clear visual cues.
