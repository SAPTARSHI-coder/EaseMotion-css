## Form Input Validation Styles 

C1. What does this do?
Adds animated validation feedback for form inputs.

C2. How is it used?
```\n<input class="ease-input ease-input-error">\n<input class="ease-input ease-input-success">\n<input class="ease-input ease-input-focus-glow">```

C3. Why is it useful?
Animated validation feedback improves user experience with clear visual cues.
