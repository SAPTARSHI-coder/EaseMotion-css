\# Plasma Energy Shield Component



A futuristic sci-fi energy barrier component featuring counter-rotating concentric rings, a glowing core vortex, and interactive system overcharge controls built for EaseMotion CSS.



\## Location

\- Directory: `submissions/examples/plasma-energy-shield-ij/`



\## Files Included

\- `demo.html`: Interactive preview window showcasing the plasma shield animation.

\- `style.css`: Scoped glowing border designs and keyframe rules (`ease-shield-rotate-cw`, `ease-shield-rotate-ccw`, `ease-shield-pulse`).

\- `README.md`: Documentation for the component submission.
