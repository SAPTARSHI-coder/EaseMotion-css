# CSS Shimmer Sweep Modal

A responsive modal component featuring a smooth shimmer sweep animation built with pure HTML and CSS.

## Features

- Pure HTML & CSS
- Responsive layout
- Shimmer sweep effect
- Smooth entrance animation
- Accessible
- No JavaScript
- Supports `prefers-reduced-motion`

## Files

```
demo.html
style.css
README.md
```

## Usage

Open `demo.html` in any modern browser.

## Customization

Modify the following values inside `style.css`:

- Background colors
- Animation duration
- Border radius
- Shadow
- Width
- Typography

## Accessibility

- Responsive design
- Reduced motion support
- Semantic HTML
