# Star Rating (cv variant)

## What does this do?
A collection of animated star rating components with 4 style variants (Classic, Glow, Interactive, Animated), 3 sizes, and 3 color themes. Perfect for reviews, testimonials, product ratings, and feedback forms.

## How is it used?

### Basic Usage:

```html
<div class="ease-rating-cv ease-rating-cv-classic" data-rating="5">
    <span class="ease-rating-cv-star">★</span>
    <span class="ease-rating-cv-star">★</span>
    <span class="ease-rating-cv-star">★</span>
    <span class="ease-rating-cv-star">★</span>
    <span class="ease-rating-cv-star">★</span>
</div>

<div class="ease-rating-cv ease-rating-cv-classic" data-rating="4">
    <span class="ease-rating-cv-star">★</span>
    <span class="ease-rating-cv-star">★</span>
    <span class="ease-rating-cv-star">★</span>
    <span class="ease-rating-cv-star">★</span>
    <span class="ease-rating-cv-star ease-rating-cv-empty">★</span>
</div>

<!-- Classic (default gold stars) -->
<div class="ease-rating-cv ease-rating-cv-classic">...</div>

<!-- Glow (pulsing golden glow) -->
<div class="ease-rating-cv ease-rating-cv-glow">...</div>

<!-- Interactive (hover to rate) -->
<div class="ease-rating-cv ease-rating-cv-interactive">...</div>

<!-- Animated (fills in sequence on load) -->
<div class="ease-rating-cv ease-rating-cv-animated">...</div>

<!-- Small (16px) -->
<div class="ease-rating-cv ease-rating-cv-classic ease-rating-cv-sm">...</div>

<!-- Medium (24px - default) -->
<div class="ease-rating-cv ease-rating-cv-classic">...</div>

<!-- Large (32px) -->
<div class="ease-rating-cv ease-rating-cv-classic ease-rating-cv-lg">...</div>

<!-- Gold (default) -->
<div class="ease-rating-cv ease-rating-cv-classic">...</div>

<!-- Purple -->
<div class="ease-rating-cv ease-rating-cv-classic ease-rating-cv-purple">...</div>

<!-- Red -->
<div class="ease-rating-cv ease-rating-cv-classic ease-rating-cv-red">...</div>
