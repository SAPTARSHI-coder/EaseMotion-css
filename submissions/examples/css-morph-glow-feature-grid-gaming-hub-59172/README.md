# CSS Morph-Glow Feature Grid for Gaming Hub Layouts

A futuristic **Morph-Glow Feature Grid** built using pure HTML and CSS for gaming hubs, esports dashboards, and modern landing pages.

## Features

* Pure HTML5 & CSS3
* Morph Glow hover animation
* Neon gaming-inspired design
* Responsive feature grid
* CSS custom properties
* No JavaScript required
* Lightweight and easy to customize
* Supports `prefers-reduced-motion`

## Folder Structure

```text
css-morph-glow-feature-grid-gaming-hub-59172/
├── demo.html
├── style.css
└── README.md
```

## Usage

1. Open `demo.html` in any modern browser.
2. Edit feature titles, icons, and descriptions.
3. Customize colors using the CSS variables in `:root`.
