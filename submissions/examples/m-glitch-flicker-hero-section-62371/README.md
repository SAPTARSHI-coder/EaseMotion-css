# CSS Glitch-Flicker Hero Section for Product Catalog Layouts

A modern **Glitch-Flicker Hero Section** built using pure HTML and CSS. The component features subtle glitch and flicker animations, responsive hero layout, CSS custom properties, and lightweight styling for futuristic product catalog landing pages.

## ✨ Features

- Pure HTML5 & CSS3
- Glitch + Flicker animation
- Responsive hero section
- Glassmorphism product card
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
