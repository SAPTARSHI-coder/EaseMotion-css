# CSS Shimmer Sweep Carousel for Fintech Dashboard Layouts

A modern **Shimmer Sweep Carousel** built with pure HTML and CSS for fintech dashboards, analytics portals, banking products, and financial showcase layouts.

## Features

* Pure HTML5 & CSS3
* Smooth shimmer sweep hover animation
* Fintech-inspired card design
* Fully responsive layout
* CSS custom properties for easy customization
* No JavaScript required
* Lightweight and performance optimized
* Supports `prefers-reduced-motion`

## Folder Structure

```text
59206-shimmer-sweep-carousel-fintech-dashboard/
├── demo.html
├── style.css
└── README.md
```

## Usage

1. Open `demo.html` in a browser.
2. Customize the card content.
3. Modify colors using the CSS variables in `:root`.
4. Duplicate `.card` elements to add more carousel items.
