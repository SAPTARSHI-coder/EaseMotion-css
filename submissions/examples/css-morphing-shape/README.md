# CSS 3D Morphing Shape

A pure CSS 3D animation that continuously morphs a shape using changing border-radius values, 3D transforms, rotation, gradients, shadows, and CSS keyframes.

## Features

- Pure HTML and vanilla CSS
- No JavaScript
- No external libraries
- 3D perspective and depth
- Continuously morphing shape
- Smooth rotation
- Layered glow and shadows
- Responsive design
- Dark-mode compatible styling
- Hardware-friendly CSS transforms
- Reduced-motion support

## Usage

Open `demo.html` directly in a modern browser.

The animation can be reused by copying the `.morph-shape` structure and the related CSS into another project.

## Accessibility

The animated shape is decorative and is marked with `aria-hidden="true"`. The main content uses semantic HTML and a descriptive heading. The animation respects `prefers-reduced-motion` for users who prefer reduced motion.

## EaseMotion CSS

This component fits the EaseMotion CSS library by demonstrating a reusable animation-first 3D visual pattern. It creates organic shape transitions using only CSS border-radius, transforms, perspective, and keyframes without JavaScript.
