# Glowing Toggle - Dark Mode

A smooth and responsive dark-mode toggle built using pure HTML and Vanilla CSS.

## Features

- Glowing toggle interaction
- Smooth dark-mode transition
- Pure HTML and CSS
- No JavaScript or external dependencies
- Responsive design
- Keyboard focus support
- Reduced-motion accessibility support
- Works directly by opening `demo.html`
