# CSS Mega Menu Navigation

A responsive, full-width mega menu navigation built entirely with HTML and CSS.

The component provides categorized navigation columns with smooth hover transitions, submenu reveal animations, responsive layouts, and keyboard-friendly focus states.

## Features

- Pure HTML and CSS
- No JavaScript or external dependencies
- Full-width mega dropdown navigation
- Multiple categorized menu columns
- Smooth menu reveal animation
- Hover and focus interactions
- Responsive desktop, tablet, and mobile layouts
- Semantic navigation markup
- Keyboard-accessible navigation links
- Visible focus indicators
- `prefers-reduced-motion` support
- CSS custom properties for easy customization

## Files

- `demo.html` — Standalone demonstration page
- `style.css` — Complete mega menu implementation
