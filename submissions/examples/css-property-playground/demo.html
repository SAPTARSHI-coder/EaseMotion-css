@property Playground

@property registers custom properties with syntax, inheritance, and initial-value — making them animatable and transitionable. Without it, CSS can't interpolate unknown values.

1. Animated Gradient Border

Register --angle as <angle> to animate a conic gradient border.

Gradient Border

Hover to speed up. @property --angle makes the rotation smooth.

@property --angle {
  syntax: '<angle>';
  initial-value: 0deg;
  inherits: false;
}

.card {
  border-image: conic-gradient(
    from var(--angle),
    #6c63ff, #f06292, #6c63ff
  ) 1;
  animation: rotate 3s linear infinite;
}
@keyframes rotate {
  to { --angle: 360deg; }
}

2. Color Transition

Register --hue as <number> to animate through the color spectrum.

Hue Rotate

The entire color palette shifts smoothly through the spectrum.

@property --hue {
  syntax: '<number>';
  initial-value: 260;
  inherits: false;
}

.card {
  --h: var(--hue);
  background: hsl(var(--h) 70% 60%);
  animation: hue-cycle 5s linear infinite;
}
@keyframes hue-cycle {
  to { --hue: 620; }
}

3. Animated Number Counter

Register --num as <integer> to animate discrete numbers from 0 to any value.

@property --num {
  syntax: '<integer>';
  initial-value: 0;
  inherits: false;
}

.counter::after {
  counter-reset: num var(--num);
  content: counter(num);
  animation: count-up 2s ease-out forwards;
  animation-timeline: view();
}

@keyframes count-up {
  to { --num: var(--to); }
}

4. Per-Axis Transforms

Register --x and --y as <length-percentage> to animate position axes independently.

Orbit Card

X and Y animated separately via registered properties. No transform string manipulation needed.

@property --x {
  syntax: '<length-percentage>';
  initial-value: 0%;
  inherits: false;
}
@property --y {
  syntax: '<length-percentage>';
  initial-value: 0%;
  inherits: false;
}

.card {
  translate: var(--x) var(--y);
  animation: x-move 3s ease-in-out infinite,
             y-move 2s ease-in-out infinite;
}
@keyframes x-move {
  50% { --x: 40%; }
}

5. Animated Gradient Text

Register --gradient-pos as <length-percentage> for smooth gradient text animation.

CSS is powerful without JavaScript

Zero JavaScript. Pure CSS.

Show CSS 
@property --gradient-pos {
  syntax: '<length-percentage>';
  initial-value: 0%;
  inherits: false;
}

.gradient-text {
  background: linear-gradient(
    to right,
    #6c63ff var(--gradient-pos),
    #f06292
  );
  -webkit-background-clip: text;
  -webkit-text-fill-color: transparent;
  animation: gradient-flow 3s ease-in-out infinite alternate;
}

6. Glass Card with Animated Glow

Register --glow as <number> to pulse a box-shadow glow smoothly.

Glass Card 1

Pulsing glow effect via @property --glow

Glass Card 2

Staggered for a wave effect

Glass Card 3

Each card independently animated

Show CSS 
@property --glow {
  syntax: '<number>';
  initial-value: 0;
  inherits: false;
}

.glass-card {
  box-shadow: 0 0 calc(var(--glow) * 30px) rgb(108 99 255 / calc(var(--glow) * 0.4));
  animation: glow-pulse 3s ease-in-out infinite alternate;
}
@keyframes glow-pulse {
  to { --glow: 1; }
}
