# CSS Reveal Text on Scroll

A pure CSS scroll-driven text reveal animation where individual words progressively appear as they enter the viewport.

## Features

- Pure HTML and CSS
- No JavaScript required
- Uses CSS scroll-driven animations
- Uses `animation-timeline: view()`
- Words reveal progressively as they enter the viewport
- Smooth opacity, blur, translation, and scale transitions
- Responsive layout
- CSS custom properties
- Light and dark mode support
- Reduced-motion support
