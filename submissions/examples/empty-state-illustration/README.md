# CSS Empty State Illustration

A responsive and accessible empty-state component built using pure HTML and CSS.

## Features

- Pure CSS implementation
- Responsive layout
- Friendly empty-state illustration
- Call-to-action button
- Keyboard accessible CTA
- Visible keyboard focus state
- Reduced-motion support
- No JavaScript or external dependencies

## Usage

Copy the HTML structure from `demo.html` and include `style.css` in your project.

```html
<link rel="stylesheet" href="style.css">
