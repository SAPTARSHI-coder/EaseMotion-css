# CSS Cassette Player


A CSS-only animated retro cassette player with spinning reels and playback controls.


## Overview

`ease-cassette-player` recreates a classic cassette player interface using pure CSS animations.


## Features

- Pure CSS implementation
- No JavaScript dependency
- Animated cassette reels
- Retro music player design
- Responsive layout
- Reduced motion accessibility support
