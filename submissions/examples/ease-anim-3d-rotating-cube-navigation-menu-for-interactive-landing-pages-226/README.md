# 3D Rotating Cube Navigation Menu for Interactive Landing Pages (Cyberpunk Theme)

A futuristic cyberpunk navigation component featuring an interactive rotating 3D cube menu with glowing neon effects and smooth animations.

## Features

- 3D rotating cube navigation
- Cyberpunk neon theme
- Smooth hover animations
- Responsive design
- Pure HTML, CSS & JavaScript
- Lightweight and customizable

## Folder Structure

```
ease-anim-3d-rotating-cube-navigation-menu-for-interactive-landing-pages-226/
├── README.md
├── demo.html
├── style.css
└── script.js
```

## Usage

Open `demo.html` in your browser.

Customize colors, cube size and animation speed inside `style.css`.

## Technologies

- HTML5
- CSS3
