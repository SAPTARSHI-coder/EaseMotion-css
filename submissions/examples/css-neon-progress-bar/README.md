# CSS-only Progress Bar with Neon Styling (#78893)

A sleek progress bar component featuring vibrant neon cyan glow effects and smooth pulsing keyframes built entirely with pure CSS.

## Features
- **Semantic Structure:** Uses accessible progressbar role attributes and ARIA tracking.
- **Pure CSS Neon Glow:** Custom box-shadow glows and gradient fills driven by keyframe animations.
- **Responsive Layout:** Cleanly framed inside a modern card component scaling across all devices.

## File Hierarchy
- `style.css` - Component styling, neon glow keyframes, and layout variables.
- `demo.html` - Semantic markup and accessibility attributes.
- `README.md` - Technical specification and architecture overview.
