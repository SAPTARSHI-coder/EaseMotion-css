# CSS Morph-Glow Modal

A responsive modal with a morphing glow border animation created using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Responsive layout
- Morph glow animation
- Smooth transitions
- Accessible with `prefers-reduced-motion`
- Easy customization using CSS variables

## Files

- demo.html
- style.css

## Usage

Open `demo.html` in any modern browser.

## CSS Variables

```css
:root{
  --bg:#0f172a;
  --card:#1e293b;
  --accent:#38bdf8;
  --text:#fff;
}
```
