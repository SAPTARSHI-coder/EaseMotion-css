# Text Entrance Animation Utilities (`ease-text-*`)

## What does this do?
Provides dedicated typography entrance animations including Gaussian blur-in, geometric clip-path reveal, and dynamic tracking split-fade effects.

## How is it used?
Attach the text animation classes directly to headings, hero slogans, or block-level typography:
```html
<h1 class="ease-text-blur-in">Smooth Entrance Slogan</h1>
<h2 class="ease-text-clip-reveal">Precision Wipe Slogan</h2>
```

## Why is it useful?
Fulfills issue #56090 by equipping developers with expressive typographic micro-animations that deliver high-impact visual openings without JavaScript.
