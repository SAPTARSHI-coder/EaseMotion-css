# CSS Neon Glow Card

A dark-themed card component featuring an animated neon glow border effect using CSS box-shadow keyframes.

## Features

- Pure CSS implementation
- Animated neon glow effect
- Responsive design
- Keyboard accessible
- No JavaScript required
- Lightweight and reusable

## Usage

```html
<div class="neon-card">
  <h2>Neon Glow Card</h2>
  <p>Your content goes here.</p>
</div>
```

## How It Works

The component uses CSS `@keyframes` animations to continuously animate multiple `box-shadow` layers, creating a glowing neon border effect around the card.

## Why It Fits EaseMotion CSS

This component adds a visually engaging animated card effect that developers can easily integrate into portfolios, landing pages, dashboards, and feature sections without relying on external libraries or JavaScript.
