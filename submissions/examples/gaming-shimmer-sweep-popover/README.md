# CSS Shimmer-Sweep Popover for Gaming Hub Layouts

A modern **Gaming Hub Popover** showcasing a smooth **Shimmer-Sweep** animation built entirely with **HTML5 and CSS3**. The component demonstrates an interactive hover popover with a sweeping light effect, making it ideal for gaming dashboards, feature highlights, and promotional cards.

---

## Features

- ✨ Shimmer-Sweep hover animation
- 🎮 Gaming Hub inspired interface
- 💡 Interactive popover component
- 📱 Fully responsive design
- ⚡ Pure HTML5 & CSS3 (No JavaScript)
- 🎨 CSS Custom Properties
- ♿ `prefers-reduced-motion` support
- 🚀 Lightweight and easy to customize

## Usage

1. Open `demo.html` in any modern web browser.
2. Hover over any gaming card.
3. The popover will appear with a smooth shimmer sweep animation.
