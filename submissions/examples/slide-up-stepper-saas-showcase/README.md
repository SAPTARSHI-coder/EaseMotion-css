# Slide-Up Stepper Submission

## 1. What does this do?
This submission adds a SaaS-friendly slide-up stepper showcase built with pure HTML and CSS. The layout highlights onboarding or launch workflows using a polished vertical stepper and motion-aware transitions.

## 2. How is it used?
- Open `demo.html` in a browser.
- `style.css` contains the visual design for the stepper, hero section, and responsive layout.
- Use EaseMotion classes like `ease-slide-up`, `ease-delay-100`, `ease-fade-in`, and `ease-hover-scale` to animate content without JavaScript.

## 3. Why is it useful?
- Demonstrates a modern SaaS onboarding stepper with clear progression and strong visual hierarchy.
- Fully responsive across desktop and mobile viewports.
- Supports `prefers-reduced-motion` so the experience remains accessible for motion-sensitive users.

## 4. Developer note
This showcase can be integrated into the core library as a reusable stepper component with official utility classes such as `.ease-stepper-card` or `.ease-stepper-marker`.
