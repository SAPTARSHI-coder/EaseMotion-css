# Morphing Navbar - Neumorphism

A responsive morphing navigation bar built with pure HTML and CSS.
The component combines soft neumorphic surfaces with smooth
micro-interactions and a responsive mobile navigation menu.

## ✨ Features

- Pure HTML and CSS
- Fully responsive
- Neumorphic design
- Morphing hover interactions
- Smooth navigation transitions
- Animated brand mark
- Interactive navigation links
- Responsive mobile menu
- CSS-only hamburger menu
- Accessible navigation label
- Keyboard-friendly controls
- Reduced-motion support
- No JavaScript dependency
