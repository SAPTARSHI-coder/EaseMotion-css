# Fire Cursor Spark Trail

1. What does this do?
It creates a fast cursor trail where warm sparks follow the pointer and burst on click, then degrade to a static state when reduced-motion is preferred.
2. How is it used?
Include `demo.html` and move the mouse; click to trigger larger burst clusters (`.spark`) created in the `#spark-layer` container.
3. Why is it useful?
It gives high-energy visual feedback for creative interfaces while respecting motion sensitivity through `prefers-reduced-motion`.
