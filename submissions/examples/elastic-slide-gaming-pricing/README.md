# 🎮 Elastic-Slide Gaming Pricing Table

A modern **Elastic-Slide Pricing Table** built with **pure HTML and CSS** for the EaseMotion CSS project. Each pricing card features a smooth elastic slide panel that reveals additional plan details on hover, making it ideal for gaming platforms, esports memberships, SaaS products, and subscription-based websites.

---

## ✨ Features

- 🎮 Gaming-inspired pricing table
- 🎯 Elastic slide-up information panel
- 🌈 Modern glassmorphism design
- ⭐ Featured "Most Popular" plan
- 🎨 CSS Custom Properties for easy customization
- 📱 Fully responsive layout
- ♿ Supports `prefers-reduced-motion`
- 🚫 Pure HTML & CSS (No JavaScript)

## 🚀 Getting Started

1. Download or clone the project.
2. Navigate to the `elastic-slide-gaming-pricing` folder.
3. Open `demo.html` in your preferred browser.
4. Hover over a pricing card to reveal the elastic slide panel.

---

## 🎨 CSS Custom Properties

Customize the appearance using the variables defined in `:root`:

```css
:root{
    --bg:#08111f;
    --bg-secondary:#111c34;

    --primary:#7c3aed;
    --secondary:#06b6d4;
    --accent:#22c55e;

    --text:#ffffff;
    --muted:#cbd5e1;

    --glass:rgba(255,255,255,.08);
    --border:rgba(255,255,255,.12);

    --radius:22px;
}
```
