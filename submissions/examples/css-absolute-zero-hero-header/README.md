# CSS Absolute Zero Hero Header

A futuristic **Pure CSS Hero Header** inspired by an "Absolute Zero" theme. It combines glassmorphism, floating ambient glows, animated gradient typography, and responsive layout into a reusable hero section.

## Features

- ❄️ Absolute Zero inspired blue theme
- 🧊 Glassmorphism card
- ✨ Animated gradient heading
- 🌌 Floating ambient glow effects
- 📱 Responsive design
- 🌙 Dark mode compatible
- ⚡ Hardware accelerated animations
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript

## Folder Structure

## Usage

```html
<link rel="stylesheet" href="style.css">
```

```html
<header class="hero">
    <div class="glass-panel">
        <h1 class="hero-title">ABSOLUTE ZERO</h1>
    </div>
</header>
```
