# CSS Absolute Zero Hero Header

## Overview

A high-impact hero header created with pure HTML and CSS.

The design combines fluid typography, layered gradients, glassmorphism
surfaces, floating elements, orbit lines, and subtle motion to create a
modern futuristic hero presentation.

## Features

- Fluid responsive typography
- Gradient text effects
- Glassmorphism layers
- Floating animated elements
- Decorative orbit lines
- Animated status indicator
- Responsive navigation
- Responsive mobile layout
- Pure HTML and CSS
- No JavaScript or external dependencies
- `prefers-reduced-motion` support

## Files

- `demo.html` — Self-contained hero demonstration
- `style.css` — Complete hero styling and animations
- `README.md` — Documentation
