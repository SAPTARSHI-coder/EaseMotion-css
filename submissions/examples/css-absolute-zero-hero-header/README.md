# CSS Absolute Zero Hero Header

A cinematic hero header built with pure HTML and CSS.

## Features

- Fluid responsive typography using `clamp()`
- Masked gradient typography
- Glassmorphism navigation and floating cards
- Animated gradient glows
- Floating UI elements
- Rotating orbital elements
- Smooth hover interactions
- Responsive mobile layout
- Reduced-motion support
- No JavaScript or external libraries required

## Files

- `demo.html` — semantic HTML structure for the hero experience
- `style.css` — all styling, animation, responsive behavior, and visual effects

## Concepts Used

### Fluid Typography

The hero heading scales smoothly across viewport sizes using CSS `clamp()`.

### Glassmorphism

Navigation actions and floating information cards use translucent backgrounds, borders, and `backdrop-filter`.

### Floating Motion

Keyframe animations create subtle movement for the ambient glows, orbital rings, and floating cards.

### Masked Typography

The primary heading uses CSS background clipping to create a layered metallic and neon gradient effect.

## Technologies

- HTML5
- CSS3
- CSS Custom Properties
- CSS Animations
- CSS Gradients
- Backdrop Filter
