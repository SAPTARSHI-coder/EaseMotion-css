# Responsive Footer — Retro

A fully responsive footer with a retro pixel-inspired visual
style built using pure HTML and CSS.

Implemented for issue #79725.

## Features

- Responsive footer layout
- Retro/pixel-inspired styling
- Four-column desktop layout
- Two-column tablet layout
- Single-column mobile layout
- Neon accent colors
- Hover link indicators
- Interactive social buttons
- Keyboard focus-visible support
- Reduced-motion support
- No JavaScript
- No external dependencies
