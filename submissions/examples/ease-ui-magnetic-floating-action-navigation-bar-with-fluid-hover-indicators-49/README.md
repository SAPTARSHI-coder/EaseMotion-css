# Magnetic Floating Action Navigation Bar with Fluid Hover Indicators

### Dark Mode Variant

A modern **Floating Action Navigation Bar** built with **HTML5** and **CSS3**. It features a dark glass-inspired interface, magnetic hover interactions, fluid hover indicator, and responsive mobile-first design.

---

## ✨ Features

- Dark mode interface
- Magnetic hover animation
- Fluid hover indicator
- Responsive mobile-first layout
- Smooth hover transitions
- CSS Variables
- Keyboard accessibility
- `prefers-reduced-motion` support
- Pure HTML & CSS
