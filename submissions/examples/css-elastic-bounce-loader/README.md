# CSS Elastic Bounce Loader

A loader with geometric shapes that squash, stretch, and bounce in a highly elastic sequence.

## Features
- Intricate physics simulation combining `translateY` with dynamic `scaleX`/`scaleY` adjustments inside `@keyframes` to create squash and stretch effects.
- Fine-tuned momentum using a custom `cubic-bezier` timing function.
- Synchronized cascading movement achieved through incremental `animation-delay` offsets.
