# Sliding Highlight Tab

A lightweight tab-style navigation interaction with a smooth highlight
reveal for active, hovered, and focused tabs.

## What does it do?

The component provides:

- Active tab highlighting.
- Smooth highlight reveal.
- Hover interaction.
- Keyboard focus interaction.
- Subtle tab movement.
- Responsive layout.
- Reduced-motion support.
- No JavaScript.
- No external libraries or assets.

## How do I use it?

Add the `ease-highlight-tabs` class to a navigation container:

```html
<nav class="ease-highlight-tabs" aria-label="Example navigation">
  <a href="#overview" class="active">Overview</a>
  <a href="#activity">Activity</a>
  <a href="#projects">Projects</a>
  <a href="#settings">Settings</a>
</nav>
```
