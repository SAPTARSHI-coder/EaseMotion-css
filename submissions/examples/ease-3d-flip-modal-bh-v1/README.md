# ease-3d-flip-modal-bh

Pure CSS 3D-flip modal for fintech dashboards.

## Features
- 3D flip hover effect
- Modal variants
- Responsive design
- Accessibility support

## Usage
```html
<div class="ease-modal ease-modal-3d-flip">Content</div>
```

## CSS Classes
- `.ease-modal` - Base modal
- `.ease-modal-3d-flip` - 3D flip effect
