# CSS Slide-Up Progress Bar

A smooth, pure CSS slide-up progress bar designed for product catalog layouts, revealing inventory status or progress on hover.

## Features
- Pure CSS and HTML (no external JavaScript required).
- Elegant slide-up entrance animation using CSS transitions.
- Smooth width animation for the progress fill.
- Fully responsive design.
- Supports `prefers-reduced-motion` for accessibility.

## Usage
Simply open `demo.html` in your browser. Hover over the product card to see the progress bar smoothly slide up into view and fill to the designated percentage.

## Files
- `demo.html`: The HTML structure for the product card and progress bar.
- `style.css`: The styling and animations.
