# CSS Skew-Active Card Grid for E-Commerce Checkout Layouts

A modern **Skew-Active Card Grid** built using pure HTML and CSS. The component features elegant skew-to-normal hover animations, premium glassmorphism styling, responsive layouts, and reusable cards for e-commerce checkout pages.

## ✨ Features

- Pure HTML5 & CSS3
- Skew-active hover animation
- Glassmorphism card design
- Responsive grid layout
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
