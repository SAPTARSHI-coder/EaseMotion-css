# CSS Morph-Glow Stepper

A lightweight, responsive stepper component featuring a subtle morphing glow effect, designed for minimalist tech interfaces.

## Features

- Pure HTML and CSS
- No JavaScript or external dependencies
- Smooth morph-glow animation on the active step
- Interactive hover and focus states
- Responsive desktop, tablet, and mobile layouts
- CSS custom properties for easy customization
- Accessible `prefers-reduced-motion` support
- Semantic ordered-list structure for the workflow steps
