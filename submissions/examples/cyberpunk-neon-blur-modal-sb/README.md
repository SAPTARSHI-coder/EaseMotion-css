# Cyberpunk Neon Blur Modal

## 1. What does this do?
A cyberpunk neon styled modal with blur-to-sharp entrance animation effect.

## 2. How is it used?
Apply `.ease-blur-modal` class to modal element.

## 3. Why is it useful?
- Creates dramatic, mysterious cyberpunk aesthetic
- Blur-to-sharp reveal animation
- Eye-catching modal entrance
