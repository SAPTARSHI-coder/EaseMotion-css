# CSS 3D-Flip Tabs for Accessible Web Layouts

A modern **3D-Flip Tabs** component built completely with **HTML5 and CSS3**. This showcase demonstrates interactive tab cards with smooth 3D rotation, glassmorphism styling, responsive layouts, and accessibility support without using JavaScript.

---

## ✨ Features

- 🔄 Smooth 3D flip animation
- 🎨 Modern glassmorphism design
- 💫 Perspective-based CSS transforms
- 🖱️ Hover interaction
- ⌨️ Keyboard focus support
- ⚡ Lightweight CSS animations
- 🎯 CSS Custom Properties
- 📱 Fully responsive layout
- 🧩 Pure HTML5 & CSS3
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

## 🚀 Usage

1. Open `demo.html` in any modern browser.
2. Hover over any tab card to trigger the 3D flip effect.
3. Use keyboard navigation to focus cards.
4. Customize colors and dimensions using CSS variables.
