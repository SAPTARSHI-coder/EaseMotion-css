# Diamond Facet Edge Progress Bar

A smooth and modern CSS progress bar featuring a **Diamond Facet Edge** visual effect.

This component is created using only **HTML and Vanilla CSS**, with no JavaScript or external libraries.

## ✨ Features

- Pure HTML and CSS
- Diamond facet edge styling
- Smooth progress animation
- Responsive design
- Dark mode support
- Hardware-accelerated transforms
- Accessible progressbar semantics
- Reduced-motion support
- No external dependencies
