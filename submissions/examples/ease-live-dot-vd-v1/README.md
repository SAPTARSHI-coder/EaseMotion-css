# Ease Live Dot

## What does this do?

A reusable live status indicator with a pulsing dot and live label.

---

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<div class="live-status">
    <span class="live-dot"></span>
    <span>Live</span>
</div>
```

### Features

- Pulsing status dot
- Live label
- Rounded pill design
- Smooth CSS animation
- Responsive layout
- No JavaScript required

---

## Why is it useful?

Live indicators are commonly used for live streams, monitoring dashboards, broadcasts, and real-time interfaces.

This component provides a lightweight status indicator with subtle animation while following the animation-first philosophy of EaseMotion CSS.
