# CSS Sticky Stacked Cards

A dynamic scrolling experience where content cards stack neatly on top of each other as the user scrolls down, driven entirely by CSS positioning.

## Features
- Pure CSS scroll stacking logic utilizing `position: sticky`.
- Incremental `top` values for each card to create an overlapped visual offset when stacked.
- Deep `box-shadow` on the top edge of the cards to enhance the 3D stacking depth.
