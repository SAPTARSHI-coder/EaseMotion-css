# CSS-only Cyberpunk Footer

A fully responsive cyberpunk-inspired footer built using only HTML and CSS.

## What does this do?

This component provides a futuristic footer layout with:

- Neon cyan and pink accents
- Cyberpunk-inspired grid background
- Animated neon top border
- Futuristic brand mark
- System online status indicator
- Responsive navigation columns
- Hover glow interactions
- CSS-only animations
- Responsive mobile, tablet, and desktop layouts
- Reduced-motion accessibility support

No JavaScript or external libraries are required.
