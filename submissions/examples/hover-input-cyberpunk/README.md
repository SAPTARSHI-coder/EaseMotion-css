# Cyberpunk Hover Input Field

A responsive CSS-only input field featuring a cyberpunk-inspired hover and focus effect.

## Features

- Cyberpunk-inspired design
- Smooth hover animation
- Focus state styling
- Glowing neon effects
- Fully responsive
- No JavaScript required

## Technologies

- HTML5
- CSS3

## Usage

Open `index.html` in any modern web browser.
