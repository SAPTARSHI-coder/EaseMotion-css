# Brewing Hydrometer

## What does this do?
Renders a self-contained CSS-only `ease-brewing-hydrometer` demo: Hydrometer bobbing in wort as specific gravity settles.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-brewing-hydrometer`. No build step or JavaScript is required for the effect.

```html
<section class="ease-brewing-hydrometer">
  <div class="ease-brewing-hydrometer__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
