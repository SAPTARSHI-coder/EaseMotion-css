# Animated Cookie Banner - Material Design

A responsive cookie consent banner inspired by Material Design principles,
implemented entirely with HTML and CSS.

## Features

- Pure CSS implementation
- Material Design inspired elevation
- Animated banner entrance
- Material-style filled, outlined, and text buttons
- Smooth hover and active interactions
- Responsive desktop, tablet, and mobile layouts
- Accessible keyboard focus states
- `prefers-reduced-motion` support
- No JavaScript dependencies
- No external libraries
