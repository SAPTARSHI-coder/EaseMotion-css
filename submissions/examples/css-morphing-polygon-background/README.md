# CSS Morphing Polygon Background

A pure CSS low-poly mesh background with slowly morphing polygon shapes.

## What it does

This example creates a dynamic background using multiple polygon layers.
Each polygon gradually changes its position, scale, rotation, and shape
to produce a slowly morphing low-poly mesh effect.

## Features

- Pure CSS implementation
- No JavaScript
- Uses `clip-path: polygon()`
- Smooth CSS keyframe animations
- Responsive design
- Glass-style foreground content
- Respects `prefers-reduced-motion`
