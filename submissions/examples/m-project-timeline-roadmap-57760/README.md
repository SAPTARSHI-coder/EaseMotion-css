# Project Timeline Roadmap

A responsive **Project Timeline Roadmap** built using pure HTML5 and CSS3. The component presents project milestones in a clean vertical timeline with animated indicators and modern cards.

## ✨ Features

- Pure HTML5 & CSS3
- Vertical animated roadmap
- Pulsing milestone indicators
- Responsive timeline layout
- Hover elevation effects
- CSS Custom Properties
- `prefers-reduced-motion` support
- No JavaScript required
