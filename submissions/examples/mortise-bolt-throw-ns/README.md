# Mortise Bolt Throw

## What does this do?
Renders a self-contained CSS-only `ease-mortise-bolt-throw` demo: Mortise bolt throwing into the keep.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-mortise-bolt-throw`. No build step or JavaScript is required for the effect.

```html
<section class="ease-mortise-bolt-throw">
  <div class="ease-mortise-bolt-throw__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
