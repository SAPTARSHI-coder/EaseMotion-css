# Responsive Drawer with Dark Mode Styling

A responsive off-canvas navigation drawer built with pure HTML and CSS for the EaseMotion CSS collection.

## ✨ Features

- Responsive dark-mode interface
- Pure HTML and CSS implementation
- No JavaScript dependencies
- Smooth drawer entrance and exit transitions
- Backdrop overlay
- Keyboard-focus friendly controls
- Hover interactions for navigation items
- Responsive desktop, tablet, and mobile layouts
- `prefers-reduced-motion` support
- CSS custom properties for easy customization
- Dark UI with subtle borders, gradients, and glow effects

## 🎨 Design

The component uses a dark interface with:

- Deep navy-black backgrounds
- Soft indigo accent colors
- Elevated dark surfaces
- Subtle borders
- Rounded navigation elements
- Responsive off-canvas drawer behavior
