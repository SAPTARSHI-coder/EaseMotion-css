# Tooltip Collection

A reusable collection of pure CSS tooltips with fade and directional slide animations.

## Features

- Pure HTML and CSS
- No JavaScript required
- Fade tooltip
- Slide Top tooltip
- Slide Bottom tooltip
- Slide Left tooltip
- Slide Right tooltip
- Keyboard accessible
- Responsive design
- Customizable CSS variables
- Reduced-motion support

## Files

- `demo.html` - Tooltip demonstration
- `style.css` - Tooltip styles and animations

## Usage

Add the `tooltip` class and provide the tooltip text using `data-tooltip`.

```html
<button class="tooltip tooltip-top" data-tooltip="Hello!">
  Hover Me
</button>
