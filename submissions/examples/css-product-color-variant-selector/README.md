# CSS Product Color Variant Selector

A lightweight, pure CSS product color variant selector for EaseMotion CSS.

## Features

- Pure HTML and CSS
- No JavaScript required
- Circular color variant selectors
- CSS-only product color switching
- Smooth variant transition
- Keyboard accessible radio controls
- Responsive layout
- Light and dark mode support
- `prefers-reduced-motion` support
- CSS custom properties for easy customization

## Files

- `demo.html` — Standalone demonstration page
- `style.css` — Component styles and animations
