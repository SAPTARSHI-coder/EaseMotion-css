# glow-toast-ak

Pure CSS animated notification toast banner with bottom progress timer line — no JavaScript required.

## How to use

```html
<div class="ease-toast">
  <span class="ease-toast__icon">🔔</span>
  <div class="ease-toast__content">
    <span class="ease-toast__title">Title</span>
    <span class="ease-toast__desc">Description</span>
  </div>
  <div class="ease-toast__timer"></div>
</div>
