# CSS Underwater Bubble Field

> Pure CSS underwater bubble animation for EaseMotion CSS.

## Issue

#68610

## Description

A responsive underwater scene featuring bubbles that continuously rise
from the bottom of the viewport.

The animation uses multiple depth layers to create a realistic sense
of underwater movement without JavaScript.

## Features

- Pure HTML and CSS
- No JavaScript
- Multiple bubble sizes
- Multiple animation speeds
- Randomized-looking animation delays
- Depth-based visual layering
- Bubble highlights
- Horizontal bubble wobble
- Animated underwater light rays
- Animated sea floor
- Responsive layout
- Reduced-motion accessibility support
