# Paint Splash Ring

A painterly ring of color dots that splatters outward and slowly re-forms.

## Features
- Dots scatter from the ring on hover
- Each droplet keeps its paint color
- Blob shadows sell the wet look

## Usage
```html
<div class="ps-ring">
  <div class="ps-dot d1"></div>
  <div class="ps-dot d5"></div>
  <div class="ps-center">splash</div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
