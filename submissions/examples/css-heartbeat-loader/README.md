# CSS Heartbeat Loader

A responsive EKG-style heartbeat loading indicator built entirely with HTML and CSS.

## Features

- Pure CSS animation
- No JavaScript required
- EKG/heartbeat-style waveform
- Smooth continuous animation
- Responsive design
- Light and dark mode support
- CSS custom properties for easy theming
- Reduced-motion accessibility support
- Semantic HTML
- Loading status with ARIA attributes
