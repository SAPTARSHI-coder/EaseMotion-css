# Ease Fire Bellows Hearth

A CSS-only animated hearth bellows component for EaseMotion CSS.

## Overview

`ease-fire-bellows-hearth` represents a traditional hearth bellows system where oxygen flow increases the movement of dancing flames.

## Features

- Pure CSS animation
- No JavaScript dependency
- Real-world motion metaphor
- Animated flames
- Bellows compression effect
- Responsive layout
- Reduced motion accessibility support

<div class="ease-fire-bellows-hearth">
</div>
