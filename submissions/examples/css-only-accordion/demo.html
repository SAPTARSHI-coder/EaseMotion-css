Pure CSS • Accessible • Smooth

What is EaseMotion?
EaseMotion is a comprehensive UI library dedicated to smooth, CSS-only animations and accessible components. It removes the need for complex JavaScript for interactive elements, focusing purely on modern web standards.
How does the animation work?
By combining native HTML5 <details> and <summary> elements with modern CSS Grid grid-template-rows: 0fr to 1fr interpolation, we achieve a beautifully smooth height transition without any scripting.
Is it fully accessible?
Absolutely. Since it relies on semantic HTML tags, it automatically benefits from native keyboard navigation (using Tab, Space, and Enter keys) and proper screen reader support straight out of the box.
Can I customize the styling easily?
Yes! The component is built with CSS variables and clean, modular classes. You can easily tweak colors, border radii, shadows, and animation easing functions to perfectly match your brand's unique design system.
