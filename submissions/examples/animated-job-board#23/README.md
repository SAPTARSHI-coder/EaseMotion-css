# Animated Job Board / Job Listing

A professional **Job Board Interface** built with **EaseMotion CSS**. Features job cards with company logos, salary display, job type badges, filter sidebar, search functionality, and apply buttons.

## ✨ Features

- **💼 Job Cards**: Company logos, job titles, locations, and tags
- **💰 Salary Display**: Prominent salary ranges with color coding
- **🏷️ Job Type Badges**: Full-time, Part-time, Remote, Hybrid, On-site
- **🎯 Filter Sidebar**: Job type, experience level, work mode, salary range
- **🔍 Advanced Search**: Keyword and location search with popular tags
- **⭐ Featured Jobs**: Highlighted job cards with special badges
- **🔥 Urgent Hiring**: Red-bordered cards for urgent positions
- **🎬 Staggered Entrance**: All sections slide in sequentially
- **📱 Fully Responsive**: Sidebar collapses on mobile

## 🧩 EaseMotion Classes Used

| Class | Purpose |
|-------|---------|
| `ease-fade-in` | Fades in the main page and footer |
| `ease-slide-up` | Slides sections up on entrance |
| `ease-slide-in-left` | Slides filter sidebar from left |
| `ease-delay-100` to `ease-delay-600` | Creates cascading staggered sequence |
| `ease-card` | Base card structure |
| `ease-hover-lift` | Lift effect on job cards |
| `ease-hover-grow` | Scale effect on buttons |
| `ease-center` | Centers search button content |
| `ease-btn` + `ease-btn-primary` | Styled CTA buttons |

## 🚀 How to Use

1. Open `demo.html` in any modern browser
2. Watch all sections slide in with staggered animations
3. Hover over job cards to see lift effects
4. Test the filter checkboxes and salary slider
5. Hover over save and apply buttons
6. Notice featured and urgent job card styles
7. Resize to mobile to see responsive layout

## 🎨 Design Highlights

- **Professional Theme**: Clean, corporate blue color scheme
- **Company Logos**: Real company logos via Clearbit API
- **Badge System**: Color-coded tags for job types and levels
- **Filter UI**: Custom checkboxes with animated checkmarks
- **Special Cards**: Featured (gold border) and Urgent (red border) styles
