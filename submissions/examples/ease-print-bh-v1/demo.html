Article: Understanding CSS Print Styles

This article demonstrates how print-friendly utility classes work. Notice how the navigation, buttons, and animations are hidden when printing, while the print-only footer appears.

Why Print Styles Matter

Web pages often contain navigation menus, call-to-action buttons, and animated elements that serve no purpose on paper. In fact, they can make printed documents look unprofessional.

🖨️ Demo Box - This animated box is hidden when printing

Press Ctrl+P (or Cmd+P) to see the print preview!

Solution

Use the .ease-print-hide class on elements that should not appear in print, and .ease-print-only on elements that should only appear when printing. 

<nav class="ease-print-hide">...</nav>
<footer class="ease-print-only">Printed from example.com</footer>
