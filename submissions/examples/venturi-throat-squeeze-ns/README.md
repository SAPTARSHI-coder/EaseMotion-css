# Venturi Throat Squeeze

## What does this do?
Renders a self-contained CSS-only `ease-venturi-throat-squeeze` demo: Venturi throat accelerating flow then recovering pressure.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-venturi-throat-squeeze`. No build step or JavaScript is required for the effect.

```html
<section class="ease-venturi-throat-squeeze">
  <div class="ease-venturi-throat-squeeze__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
