# Ease Tag Pill

## What does this do?

A rounded tag label component with multiple color variants and a subtle hover animation.

---

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<span class="tag-pill blue">
    JavaScript
</span>
```

### Available variants

```html
<span class="tag-pill blue">JavaScript</span>
<span class="tag-pill green">Frontend</span>
<span class="tag-pill purple">Design</span>
<span class="tag-pill orange">Open Source</span>
```

### Features

- Rounded pill design
- Multiple color variants
- Hover lift animation
- Responsive wrapping
- Lightweight and reusable

---

## Why is it useful?

Tag pills are commonly used for categories, topics, filters, skills, and content labels.

This component provides a simple and reusable category label with subtle motion while following the animation-first philosophy of EaseMotion CSS.
