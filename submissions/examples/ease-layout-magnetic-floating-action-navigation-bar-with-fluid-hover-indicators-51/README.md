# Magnetic Floating Action Navigation Bar

### Glassmorphic Style

A modern floating navigation bar built using **HTML5** and **CSS3** featuring a glassmorphism interface, fluid hover indicators, smooth animations, and a responsive layout.

---

## ✨ Features

- Glassmorphism floating navigation
- Fluid hover indicator
- Gradient highlight effect
- Smooth hover animations
- Fully responsive design
- CSS Variables
- Mobile-first layout
- Accessibility-friendly (`prefers-reduced-motion`)
- Pure HTML & CSS
