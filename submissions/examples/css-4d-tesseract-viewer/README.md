# CSS 4D Tesseract Viewer

A mind-bending projection of a 4-dimensional hypercube (tesseract) onto a 3D space, created purely with nested HTML elements and complex CSS `transform-style: preserve-3d` animations.

## Features
- Pure CSS `preserve-3d` nested elements
- Multi-axis 3D continuous rotation
- Inner cube 3D scaling simulating 4D spatial movement
- Neon glow effects using `box-shadow` and `border`
