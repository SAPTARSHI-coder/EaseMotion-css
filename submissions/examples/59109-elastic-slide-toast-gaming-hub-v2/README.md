# CSS Elastic-Slide Toast for Gaming Hub Layouts

A modern **Elastic-Slide Toast** built using pure HTML and CSS for gaming hubs, esports dashboards, achievement notifications, and in-game alerts.

## Features

* Pure HTML5 & CSS3
* Elastic-slide entrance animation
* Gaming-inspired toast notifications
* Multiple toast variants (Success, Warning, Info)
* Fully responsive layout
* CSS custom properties
* No JavaScript required
* Supports `prefers-reduced-motion`

## Folder Structure

## Usage

1. Open `demo.html` in any modern browser.
2. Duplicate a `.toast` element to create additional notifications.
3. Customize colors through the CSS variables in `:root`.
4. Update the icons, headings, and descriptions for your project.
