# Morphing Sidebar with Cyberpunk Styling

A responsive cyberpunk-inspired sidebar built using only HTML and CSS.

The component combines a futuristic dark interface, neon cyan and pink
accents, morphing transitions, animated status indicators, and responsive
navigation behavior.

## Features

- Fully responsive
- Cyberpunk visual styling
- Morphing desktop sidebar
- Collapsible desktop navigation
- Mobile off-canvas sidebar
- CSS-only interactions
- Neon status indicators
- Animated navigation hover states
- Terminal-style status panel
- Responsive profile section
- Reduced-motion support
- No external dependencies

## Files

- `demo.html`
- `style.css`

## Component Details

The sidebar includes:

- NEON//OS branding
- System status indicator
- Main navigation
- System navigation
- Terminal information panel
- User profile section
- Responsive mobile menu

## Desktop Interaction

On larger screens, the sidebar can be compressed into a compact
icon-only navigation using the menu control.

The content area automatically adjusts its width and spacing.

## Mobile Interaction

On screens below the desktop breakpoint:

- Sidebar stays hidden by default
- Menu button appears
- Sidebar slides into view
- Close button is displayed
- Navigation remains fully usable

## Styling

The component uses:

- Dark layered surfaces
- Neon cyan and pink accents
- Soft glow effects
- Gradient borders
- CSS transforms
- CSS transitions
- CSS keyframe animations

## Accessibility

- Uses semantic `<nav>` and `<aside>` elements
- Native keyboard-focusable controls
- Accessible labels for toggle controls
- `:focus-visible` styles
- Reduced-motion support
