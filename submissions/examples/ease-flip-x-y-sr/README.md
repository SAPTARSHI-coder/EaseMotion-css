# 3D Flip Utility Demo

1. What does this do?
It demonstrates rotateX/rotateY flip effects and hover-triggered flip variants for card-style interactions.
2. How is it used?
Add classes like `flip-x-card`, `flip-y-card`, `hover-flip-x`, and `hover-flip-y` to elements in the demo; hover/focus the trigger container to see the interactive flip.
3. Why is it useful?
It gives a clean, accessibility-aware motion primitive for dramatic card reveals that can be reused by the EaseMotion framework.
