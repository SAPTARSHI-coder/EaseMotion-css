# 🌌 Nebula Card – Cosmic Nebula Clouds Swirl Within

> A stunning, space-themed card where cosmic nebula clouds swirl within on hover, creating a beautiful, celestial effect.

---

## 📖 Description

The **Nebula Card** is a stunning, space-themed UI component where cosmic nebula clouds swirl within on hover. When you hover over the card, colorful nebula clouds come to life, swirling and flowing across the surface like celestial gas clouds in deep space. The effect creates a beautiful, cosmic visual experience reminiscent of Hubble Telescope images.

The component uses CSS animations with `transform` and `keyframes` to create the swirling nebula effect. Each cloud has a unique color, position, and animation speed, creating a realistic, organic nebula pattern. Twinkling stars add to the cosmic atmosphere, completing the space experience.

Perfect for space-themed interfaces, astronomy websites, sci-fi projects, and any application where you want to create a stunning, cosmic interaction. The Nebula Card transforms a simple card into a beautiful, celestial experience.
