# Galvanometer Coil Swing

## What does this do?
Renders a self-contained CSS-only `ease-galvanometer-coil-swing` demo: Galvanometer coil swinging against a restoring spring.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-galvanometer-coil-swing`. No build step or JavaScript is required for the effect.

```html
<section class="ease-galvanometer-coil-swing">
  <div class="ease-galvanometer-coil-swing__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
