# Cyberpunk Shimmer-Sweep Tabs

A modern **Cyberpunk Shimmer-Sweep Tabs** component built entirely with **HTML5** and **CSS3**. This showcase demonstrates CSS-only tabs with a futuristic neon design, animated shimmer effects, glassmorphism styling, and responsive behavior—without any JavaScript.

---

## ✨ Features

- ⚡ Pure HTML5 & CSS3
- 🌈 Cyberpunk neon theme
- ✨ Animated shimmer-sweep effect
- 🪟 Glassmorphism-inspired design
- 🎯 CSS-only tab switching (no JavaScript)
- 📱 Fully responsive layout
- ♿ Keyboard accessible
- 🎨 Easy customization with CSS Custom Properties
- 🚀 Lightweight and dependency-free
- 🌙 Supports `prefers-reduced-motion`

## 🚀 Usage

1. Open `demo.html` in any modern web browser.
2. Click any tab to switch between content sections.
3. Hover over a tab to view the shimmer animation.

No JavaScript or external libraries are required.

## 🎨 CSS Custom Properties

The design can be customized using the following CSS variables:

| Variable | Description |
|----------|-------------|
| `--bg` | Background color |
| `--surface` | Glassmorphism container background |
| `--primary` | Primary neon color |
| `--secondary` | Secondary neon color |
| `--accent` | Accent color |
| `--text` | Primary text color |
| `--muted` | Secondary text color |
| `--radius` | Border radius |
| `--speed` | Transition duration |

Example:

```css
:root{
    --primary:#00f5ff;
    --secondary:#b026ff;
}
```
