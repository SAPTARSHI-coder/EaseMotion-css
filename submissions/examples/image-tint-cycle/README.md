# Image Tint Cycle

A grayscale image cycles through vibrant color tints.

## Features
- Color tint cycling
- Grayscale base
- Hue rotation
- Pure CSS

## Usage
```html
<div class="itc-img"></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
