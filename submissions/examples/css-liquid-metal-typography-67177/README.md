# CSS Liquid Metal Typography

What does this do?
Creates a highly reflective, 3D metallic text effect utilizing sweeping linear-gradient overlays, `-webkit-text-fill-color: transparent`, and severe contrast filters.

How is it used?
Apply the `.liquid-metal` class to a text element and supply the `data-text` attribute for the pseudo-element reflection. It works best on dark backgrounds and with heavy font weights.

```html
<h1 class="liquid-metal" data-text="LIQUID METAL">LIQUID METAL</h1>
```

Why is it useful?
It provides a premium, high-impact aesthetic for headings or hero sections without relying on WebGL or external image assets, aligning perfectly with EaseMotion's philosophy of pure, high-performance CSS.
