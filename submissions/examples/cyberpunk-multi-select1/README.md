# Cyberpunk Multi-Select Dropdown

An animated, zero-JS cyberpunk-themed multi-select dropdown component built using pure CSS and standard HTML form controls.

## Features
- **Zero JS Dependencies**: State management handled entirely using CSS input state selectors (`:checked`).
- **Cyberpunk Aesthetic**: High-contrast dark backgrounds, neon accents, glow effects, and cut-corner geometric styling (`clip-path`).
- **Accessibility**: Includes `@media (prefers-reduced-motion: reduce)` rules to instantly remove motion effects for users with reduced motion settings enabled.
- **EaseMotion Tokens**: Built using `--easemotion-transition-base` and `--easemotion-glow-blur`.

## Usage
Include `style.css` in your project and structure the HTML using the `.cyber-dropdown-wrapper` structure.
