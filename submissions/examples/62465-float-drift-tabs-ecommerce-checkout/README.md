# CSS Float-Drift Tabs for E-Commerce Checkout Layouts

A modern **Float-Drift Tabs** component built using pure HTML5 and CSS3 for e-commerce checkout interfaces. The component provides floating animated navigation tabs with smooth content transitions, responsive layouts, and accessibility support.

## Features

* Pure HTML5 & CSS3
* Float-Drift tab animation
* Multi-step checkout workflow
* Cart, Shipping, Payment & Review tabs
* Responsive design
* Glassmorphism-inspired interface
* CSS Custom Properties
* Smooth keyframe animations
* No JavaScript required
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in a modern browser.
2. Customize the checkout tabs and content.
3. Modify colors through the CSS variables defined in `:root`.
4. Integrate into any e-commerce checkout page.
