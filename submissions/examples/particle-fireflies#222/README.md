# Particle Fireflies 🌙✨

A magical nighttime meadow scene with 20 glowing fireflies floating and pulsing, a glowing moon, tree silhouettes, and swaying grass. Built entirely with pure CSS animations.

## Features
- **20 Fireflies**: Each with independent float paths and glow pulsing.
- **Dual Animations**: Fireflies combine `fireflyFloat` (movement) and `fireflyGlow` (brightness) simultaneously.
- **Glowing Moon**: With craters and pulsing radial glow.
- **Tree Silhouettes**: CSS shapes creating a forest backdrop.
- **Swaying Grass**: Blades that sway with staggered delays.
- **Hover Interaction**: Fireflies speed up on hover.
- **Zero JavaScript**: All animations are pure CSS.

## Customization
Edit CSS variables in `:root`:
- `--firefly-color` / `--firefly-glow`: Change firefly colors.
- `--moon-color` / `--moon-glow`: Adjust moon appearance.
- `--sky-top` / `--sky-bottom`: Change sky gradient.
- `--tree-color` / `--ground-color`: Adjust landscape colors.

## Browser Support
Works in all modern browsers. Uses CSS animations, `box-shadow` glow, and `border-radius`.
