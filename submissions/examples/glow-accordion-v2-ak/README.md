# glow-accordion-v2-ak

Pure CSS animated glowing neon border accordion drawer component — no JavaScript required.

## How to use

```html
<div class="ease-accordion-v2">
  <input type="checkbox" id="item1" class="ease-accordion-checkbox-v2" />
  <div class="ease-accordion-item-v2">
    <label for="item1" class="ease-accordion-header-v2">
      <span>Header</span>
      <span class="ease-accordion-icon-v2">▼</span>
    </label>
    <div class="ease-accordion-drawer-v2">
      <div class="ease-accordion-body-v2">Content</div>
    </div>
  </div>
</div>
