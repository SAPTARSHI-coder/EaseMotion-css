# Velvet Smooth Transition Progress Bar

A polished and accessible CSS progress component featuring a
velvet-inspired gradient, smooth transitions, subtle glow, and
shimmer animation.

## Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Smooth progress transitions
- Velvet gradient styling
- Subtle shimmer animation
- Soft glow effect
- Responsive design
- Native HTML `<progress>` element
- Accessible labels
- Dark mode support
- Reduced-motion support
- Hardware-friendly CSS transforms
- Chrome, Edge, Safari and Firefox support

## Preview

The component provides a smooth visual progress indicator suitable
for dashboards, portfolio websites, project tracking interfaces,
loading states and modern UI systems.
