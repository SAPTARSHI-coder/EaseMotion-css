CSS Chalk Board Text

Text styled as chalk writing on a blackboard — pure CSS.

Demo

Usage

<!-- Include the Google Font in your CSS or HTML -->
<style>
  @import url('https://fonts.googleapis.com/css2?family=Cabin+Sketch:wght@400;700&display=swap');
</style>

<!-- HTML Structure -->
<div class="chalkboard" role="img" aria-label="Blackboard">
  <div class="chalk-text">Hello World</div>
</div>
