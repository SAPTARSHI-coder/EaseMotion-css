# Circuit Breaker Half Open

Circuit Breaker Half Open is an advanced CSS animation that shows a service moving from open failure protection into a cautious half-open probe window. It visualizes guarded traffic, probe success, and gradual recovery with pure HTML and CSS.

## Features

- Responsive service-resilience dashboard
- Animated breaker gate, probe packets, and health meters
- Reduced-motion support
- Semantic demo structure with accessible labels
