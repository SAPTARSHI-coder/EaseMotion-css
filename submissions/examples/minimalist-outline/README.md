# CSS Modal: Minimalist Outline

A clean, accessible and responsive modal component built entirely
with semantic HTML and Vanilla CSS.

## Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Minimalist outline design
- Thin border system
- Subtle shadow
- Smooth opening animation
- Responsive layout
- Dark mode support
- Accessible dialog semantics
- Keyboard focus indicators
- Reduced-motion support
