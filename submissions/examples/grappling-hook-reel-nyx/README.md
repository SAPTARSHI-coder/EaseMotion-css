# Grappling Hook Reel

## What does this do?
Renders a self-contained CSS-only `ease-grappling-hook-reel` demo: Grappling hook flying then reeling back on cable.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-grappling-hook-reel`. No build step or JavaScript is required for the effect.

```html
<section class="ease-grappling-hook-reel">
  <div class="ease-grappling-hook-reel__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
