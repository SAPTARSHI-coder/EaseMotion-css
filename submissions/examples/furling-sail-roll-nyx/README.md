# Furling Sail Roll

## What does this do?
Renders a self-contained CSS-only `ease-furling-sail-roll` demo: Jib sail furling tightly around the forestay.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-furling-sail-roll`. No build step or JavaScript is required for the effect.

```html
<section class="ease-furling-sail-roll">
  <div class="ease-furling-sail-roll__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
