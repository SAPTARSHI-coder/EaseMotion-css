# Enigma Rotor Step

## What does this do?
Renders a self-contained CSS-only `ease-enigma-rotor-step` demo: Enigma rotor stepping at the notch.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-enigma-rotor-step`. No build step or JavaScript is required for the effect.

```html
<section class="ease-enigma-rotor-step">
  <div class="ease-enigma-rotor-step__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
