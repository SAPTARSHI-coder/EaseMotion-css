# CSS Portfolio Growth Chart

A pure CSS animated investment portfolio growth chart with an upward line, animated area fill, and data-point markers.

## Features

- Pure HTML and CSS
- Animated chart line drawing
- Animated portfolio area fill
- Responsive layout
- No JavaScript required
- Accessible chart labeling
- Supports `prefers-reduced-motion`

Include the stylesheet:
