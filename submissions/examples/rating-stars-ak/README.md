# rating-stars-ak

Pure CSS interactive star rating component with glowing hover effects — no JavaScript required.

## How to use

```html
<div class="ease-rating-stars">
  <input type="radio" name="rating" id="star5" />
  <label for="star5" class="ease-rating-star-label">★</label>

  <input type="radio" name="rating" id="star4" />
  <label for="star4" class="ease-rating-star-label">★</label>
  ...
</div>
