# Blur-Entrance Card Grid

A modern, responsive fintech dashboard card grid featuring a smooth
CSS blur-entrance animation.

## Features

- Pure HTML and CSS
- Blur + fade entrance animation
- Staggered card animation delays
- Responsive 3-column and 2-column layouts
- Mobile-friendly single-column layout
- Hover elevation and highlight effect
- Animated mini portfolio chart
- CSS custom properties for easy customization
- No JavaScript or external frameworks
- `prefers-reduced-motion` accessibility support
- Lightweight and performant
