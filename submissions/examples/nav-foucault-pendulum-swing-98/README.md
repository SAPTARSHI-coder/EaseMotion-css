# CSS Nav: Foucault Pendulum Swing Variation

A smooth, pure CSS navigation featuring a 3D pendulum swing animation on hover, inspired by the Foucault pendulum.

## Usage

```html
<nav class="foucault-nav">
    <ul class="foucault-list">
        <li class="foucault-item"><a href="#" class="foucault-link">Home</a></li>
        <li class="foucault-item"><a href="#" class="foucault-link">About</a></li>
    </ul>
</nav>
```

## Why is it useful?

This navigation effect provides a premium, interactive experience with hardware-accelerated 3D CSS transforms and smooth cubic-bezier timing functions, aligning with EaseMotion's philosophy of lightweight, dynamic, and engaging UI elements.
