# Synthwave Grid Line Media Visualizer

A responsive pure CSS media visualizer featuring a retro-futuristic
Synthwave Grid Line design.

## Features

- Pure HTML and Vanilla CSS
- Synthwave-inspired perspective grid
- Animated CSS equalizer bars
- Neon visual effects
- Animated status indicator
- Media control interface
- Responsive layout
- Dark-mode friendly design
- No JavaScript
- No external dependencies
- `prefers-reduced-motion` accessibility support
