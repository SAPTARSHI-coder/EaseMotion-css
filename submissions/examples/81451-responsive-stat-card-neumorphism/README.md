# Responsive Stat Card — Neumorphism

A responsive neumorphic statistics card component created
with pure HTML and CSS for EaseMotion CSS issue #81451.

## Features

- Soft neumorphic visual design
- Responsive stat card grid
- Desktop, tablet and mobile layouts
- Three reusable stat-card variants
- Revenue, task and user statistics examples
- Trend indicators
- Animated progress bars
- Smooth hover elevation
- Soft inset and outer shadows
- Accent colors using CSS custom properties
- `prefers-reduced-motion` support
- Zero JavaScript dependencies
