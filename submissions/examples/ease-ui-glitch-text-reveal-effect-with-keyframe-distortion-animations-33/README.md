# Glitch Text Reveal Effect with Keyframe Distortion Animations

## Overview

A futuristic dark mode glitch text animation component featuring
RGB distortion layers, keyframe animations, and interactive reveal
effects.

Built using pure HTML, CSS, and JavaScript.

## Features

- ⚡ Cyber glitch text animation
- 🌈 RGB color distortion effect
- 🎬 Keyframe-based text displacement
- 🌙 Dark mode futuristic design
- ✨ Interactive reveal animation
- 📱 Responsive layout
- 🖥️ Pure CSS animation effects

## Usage

1. Open `demo.html` in a browser.
2. Click the reveal button.
3. Experience the glitch distortion effect.
