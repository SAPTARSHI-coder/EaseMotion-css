# glow-float-input-v4-ak

Pure CSS animated floating label input field with neon border focus — no JavaScript required.

## How to use

```html
<div class="ease-float-input-wrapper-v4">
  <input type="text" class="ease-float-input-v4" placeholder=" " id="inp" />
  <label for="inp" class="ease-float-label-v4">Label Text</label>
</div>
