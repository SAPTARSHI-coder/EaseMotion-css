Issue #70325 · Sticky Header

A header that changes character as you scroll.

The compact state is created with CSS scroll-driven animation. The layout stays useful at the top and becomes lighter after the page gains scroll progress.

Implementation notes

A reusable CSS pattern

The demo uses native anchors, a sticky header, and scroll-linked CSS animation. Browsers without scroll-driven animation still receive the full navigation and readable expanded header.
