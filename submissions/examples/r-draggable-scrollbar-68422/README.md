# CSS Draggable Scrollbar

A custom CSS scrollbar showcase with a styled draggable thumb, responsive layout, and accessible scrolling behavior.

## Features

- Pure HTML and CSS
- Custom scrollbar track and thumb
- Native draggable scrollbar interaction
- Hover and active thumb states
- Keyboard-focusable scroll container
- Smooth scrolling
- Responsive design
- `prefers-reduced-motion` support
- CSS custom properties for easy customization
- No JavaScript required
