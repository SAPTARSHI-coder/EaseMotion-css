# Pulse ring avatar status

An avatar with a soft live-status ring that pulses outward to indicate the user is online.

## How to view

Open `demo.html` in any modern browser. The demo is fully self-contained — no CDN, no framework, no JavaScript.

## How to use

Copy `style.css` into your project's stylesheet. Every class used in the demo is namespaced with `pulseringavatarstatus-` to avoid collisions.

## Why this is useful for EaseMotion CSS

Presence / contact-list pattern; the pulse reads as 'live'.
