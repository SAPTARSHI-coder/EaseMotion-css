# CSS-only Cyberpunk Sidebar

A demo project showcasing a **cyberpunk neon sidebar** built entirely with HTML and CSS.

## Features
- Neon glowing sidebar with logo and navigation links.
- Hover effects with glowing text and background.
- Futuristic cyberpunk color palette (cyan, magenta, yellow).
- Responsive flex layout with sidebar + main content.

## Files
- `demo.html` → Structure with sidebar and content area.
- `style.css` → Neon glow styles, hover effects, and layout.
- `README.md` → Documentation and usage instructions.

## Usage
1. Open `demo.html` in your browser.
2. Observe the glowing sidebar with neon hover effects.
3. Customize links, colors, and logo text for your own project.

## Customization Ideas
- Add icons or SVGs for more cyberpunk flair.
- Use CSS variables for easier theme swapping.
- Extend into a full dashboard layout with cards and widgets.
- Add background animations (grid lines, glitch effects) for immersion.
