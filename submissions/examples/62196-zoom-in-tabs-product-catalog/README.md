# CSS Zoom-In Tabs for Product Catalog Layouts

A modern **Zoom-In Tabs** component built with pure HTML5 and CSS3 for the EaseMotion CSS showcase collection.

The component provides animated product category tabs with smooth zoom interactions, responsive product cards, and a clean product catalog layout without JavaScript.

---

## Features

- Pure HTML5 & CSS3
- Zoom-In tab animation
- Interactive product cards
- Smooth hover transitions
- Responsive product catalog
- CSS Custom Properties
- Modern SaaS-inspired UI
- No JavaScript required
- Accessibility support with `prefers-reduced-motion`
