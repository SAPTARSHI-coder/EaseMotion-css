# Note Sticky Rotate

A wall of sticky notes that tilt, lift and flutter as you brush past them.

## Features
- Notes rest at playful angles
- Hover straightens and lifts a note
- Pinned shadow adds the sticky feel

## Usage
```html
<div class="ns-wall">
  <div class="ns-note ns-y">Ship the demo today</div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
