# CSS Morph-Glow Badge

A modern badge component featuring a morphing glow animation using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Morph + glow animation
- Responsive layout
- Accessible with `prefers-reduced-motion`
- No JavaScript required
- Lightweight and customizable

## Files

```text
demo.html
style.css
README.md
```

## Usage

Open `demo.html` in any modern browser and hover over the badges.

## Customization

- Badge colors
- Glow intensity
- Animation duration
- Border radius
- Typography

## Browser Support

Works in all modern browsers supporting CSS animations and transitions.
