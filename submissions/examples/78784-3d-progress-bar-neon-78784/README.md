# 3D Progress Bar — Neon

## Issue

EaseMotion CSS issue #78784.

## Overview

A responsive neon progress bar with a subtle three-dimensional treatment.

## Features

- Perspective depth
- Gradient progress fill
- Accessible progress semantics
- Responsive layout
- Reduced-motion support

## Usage

Open `demo.html`. Adjust `.fill` width and the `aria-valuenow` value together when using the component for a different progress value.

## Accessibility

The progress element uses the ARIA progressbar pattern and exposes minimum, maximum, and current values. Motion is disabled for reduced-motion users.
