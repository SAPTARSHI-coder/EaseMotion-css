Cyberpunk Code Terminal

A developer code block component featuring CRT scanline overlays, neon cursor typing flicker animation, and a instant copy-to-clipboard state trigger.

easemotion-config.scss — bash 
// EaseMotion Cyberpunk SCSS Configuration
@use 'easemotion' with (
  $theme-mode: 'cyberpunk-neon',
  $hardware-accel: true,
  $primary-glow: #00ffcc,
  $scanlines: true
);

.terminal-block {
  animation: neon-pulse 2s infinite ease-in-out;
  box-shadow: 0 0 20px rgba(0, 255, 204, 0.4);
}
