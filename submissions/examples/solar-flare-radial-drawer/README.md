# Solar Flare Radial Drawer

A smooth and visually rich pure CSS drawer inspired by the intense radial energy of a solar flare.

## Features

- Pure HTML and Vanilla CSS
- No external JavaScript
- Solar flare inspired radial glow
- Smooth drawer entrance and exit
- Animated energy core and radial orbits
- Interactive navigation items
- Dark mode friendly design
- Responsive layout
- Hardware-accelerated transforms
- Reduced-motion accessibility support
- Backdrop overlay for better focus
