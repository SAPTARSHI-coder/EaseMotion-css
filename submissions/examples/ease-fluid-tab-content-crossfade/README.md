# Ease Fluid Tab Content Crossfade Container

A responsive tab component with smooth transitions between content panels.

## Features

- Fluid height animation using CSS Grid (`grid-template-rows: 0fr → 1fr`)
- Cross-fade and slide transition between tab panels
- Sliding active tab indicator
- Semantic HTML with ARIA roles
- Keyboard navigation using Left and Right Arrow keys
- Responsive layout
- Built with HTML, CSS, and Vanilla JavaScript

## Folder Structure

```
ease-fluid-tab-content-crossfade/
├── demo.html
├── style.css
└── README.md
```

## Usage

1. Open `demo.html` in any modern web browser.
2. Click a tab or use the **Left** and **Right** arrow keys to switch between panels.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## Accessibility

- `role="tablist"`
- `role="tab"`
- `role="tabpanel"`
- `aria-selected`
- `aria-controls`
- `aria-labelledby`
- Keyboard navigation support
