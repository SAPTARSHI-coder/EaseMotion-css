
---

## 🚀 Usage
1. Clone or copy the files into your project.
2. Open `demo.html` in your browser.
3. Hover or click on pagination links to see glowing effects.

---

## 🛠️ Customization
- **Colors** → Change `color` and `box-shadow` values in `.pagination a`.
- **Active state** → Adjust `.active` styles for current page.
- **Spacing** → Modify `gap` in `.pagination`.

---

## 📖 Accessibility
- Uses `role="navigation"` and `aria-label="Pagination"` for screen readers.
- Focus styles ensure keyboard navigation works.
