# Kinetic Typography Split-Text Reveal

A high-end motion graphics text reveal effect commonly used on award-winning agency websites.

## Features
- Staggered Delays: Uses inline CSS variables to stagger the entrance of each character.
- Cubic Bezier Easing: Employs a custom spring-like easing curve for a premium feel.
- Hardware Acceleration: Uses transform and opacity exclusively for buttery smooth 60fps rendering.

## Usage
Include the HTML and CSS in your project. Hover over the container to trigger the reveal.
