# CSS Pure Tree

A responsive spring tree that grows and blooms using only
HTML and CSS.

## ✨ Features

- Pure HTML and CSS
- No JavaScript
- Animated tree growth
- Animated branches
- Leaves bloom onto the tree
- Spring-colored flowers appear progressively
- Falling leaves
- Animated sunlight
- Responsive design
- Hover-to-pause interaction
- Keyboard focus support
- Reduced-motion support
- No external dependencies
