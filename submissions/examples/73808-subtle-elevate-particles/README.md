# CSS Particle Effect: Subtle Elevate

A smooth, accessible, and performant pure CSS particle effect featuring a
subtle elevation animation.

## Features

- Pure HTML and Vanilla CSS
- Subtle floating particle animation
- Smooth CSS transitions
- Soft elevation effect
- Hardware-accelerated transforms
- Dark mode support
- Responsive design
- Accessible keyboard focus state
- `prefers-reduced-motion` support
- No JavaScript
- No external libraries
