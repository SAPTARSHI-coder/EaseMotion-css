# Interactive Infinite Carousel with Gradient Glow

A pure CSS implementation of an infinite sliding carousel featuring a ambient gradient glow backdrop and smooth interactive hover/focus state transitions.

## Features
- **Zero JavaScript:** Built entirely with CSS animations and layout primitives.
- **EaseMotion Design Tokens:** Integrates motion variables for timing and easing curves.
- **Interactive Controls:** Auto-pauses smoothly on mouse hover or element keyboard focus.
- **Accessibility Ready:** Disables infinite scrolling and falls back to native snap scrolling under `prefers-reduced-motion: reduce`.
- **Responsive:** Adapts card sizing seamlessly from mobile to desktop screen sizes.
