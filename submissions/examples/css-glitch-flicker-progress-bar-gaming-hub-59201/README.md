# CSS Glitch-Flicker Progress Bar for Gaming Hub Layouts

A futuristic **Glitch-Flicker Progress Bar** built with pure HTML and CSS for gaming dashboards, esports platforms, player statistics, and cyberpunk-inspired interfaces.

## Features

* Pure HTML5 & CSS3
* Glitch flicker animation
* Animated scan-line effect
* Neon gaming theme
* Multiple color variants
* Responsive design
* No JavaScript required
* Supports `prefers-reduced-motion`

## Folder Structure

```text
css-glitch-flicker-progress-bar-gaming-hub-59201/
├── demo.html
├── style.css
└── README.md
```

## Usage

1. Open `demo.html` in any modern browser.
2. Change progress values using the `--progress` CSS variable.
3. Customize colors using the variables in `:root`.
