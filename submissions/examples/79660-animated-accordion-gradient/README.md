# Animated Accordion — Gradient

A responsive accordion component featuring gradient styling,
smooth expand/collapse transitions, interactive states, and
accessible native HTML controls.

Implemented for issue #79660.

## Features

- Modern gradient visual style
- Smooth accordion expansion
- Native HTML `<details>` and `<summary>`
- Interactive hover states
- Rotating expand/collapse icon
- Gradient active indicator
- Responsive mobile layout
- Keyboard accessible
- Reduced-motion support
- CSS-only implementation
- No external dependencies
