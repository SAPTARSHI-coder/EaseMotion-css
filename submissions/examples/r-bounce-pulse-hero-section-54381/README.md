# CSS Bounce-Pulse Hero Section

A modern **Bounce-Pulse Hero Section** built using pure HTML5 and CSS3 for accessible web layouts. The component features an eye-catching bounce-pulse animation, responsive two-column layout, customizable CSS variables, and accessibility support without requiring JavaScript.

---

## ✨ Features

- Pure HTML5 & CSS3
- Bounce-pulse hero animation
- Responsive two-column layout
- Modern call-to-action buttons
- CSS Custom Properties
- Lightweight and performant
- Accessible semantic HTML
- `prefers-reduced-motion` support
- No JavaScript required

## 🚀 Usage

1. Copy the component into your project.
2. Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

3. Open `demo.html` in your preferred browser.
