# CSS Fade-In Tooltip for SaaS Showcase Layouts

A modern SaaS-style tooltip component featuring a smooth fade-in animation effect built completely with pure HTML and CSS.

This component is designed for SaaS dashboards, product showcases, and landing pages where lightweight animated interactions are required without JavaScript.


## ✨ Features

- 💬 Modern SaaS tooltip UI
- ✨ Smooth fade-in reveal animation
- 🎨 Glassmorphism inspired design
- ⚡ Pure HTML and CSS implementation
- 📱 Fully responsive layout
- 🔄 CSS transition based animation
- ♿ prefers-reduced-motion accessibility support
- 🚀 Lightweight and framework-free

## 🚀 Usage

1. Open `demo.html` directly in your browser.

2. Hover over the feature card to reveal the tooltip.

3. Customize CSS variables inside `style.css` according to your branding.


## 🎨 CSS Custom Properties

The component uses CSS variables for easy customization:

```css
:root {

    --bg:#020617;
    --card:#0f172a;
    --primary:#38bdf8;
    --secondary:#8b5cf6;
    --text:#f8fafc;
    --muted:#94a3b8;

}

Modify these values to create your own theme.

♿ Accessibility

The component supports reduced motion preferences.

Implemented using:

@media(prefers-reduced-motion:reduce)

Animations are minimized for users who prefer reduced motion.
