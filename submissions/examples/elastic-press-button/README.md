# Elastic Press Button

A lightweight tactile button interaction that compresses slightly when pressed
and smoothly springs back after release.

## What does it do?

The component provides:

- Subtle press compression.
- Elastic return animation.
- Hover elevation.
- Keyboard focus support.
- Mouse and touch compatibility through native button states.
- Responsive layout.
- Reduced-motion support.
- No external libraries or assets.

## How do I use it?

Create a button with the `elastic-button` class:

```html
<button class="elastic-button" type="button">
  <span>Press me</span>
</button>
```
