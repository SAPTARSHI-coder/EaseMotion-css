# CSS Glassmorphism Alert Box

A modern glassmorphism-inspired alert component built entirely with HTML and CSS.

## Features

- Frosted glass background
- Animated entrance
- Hover elevation effect
- Success, Warning & Error variants
- Accessible ARIA roles
- Responsive layout
- Pure HTML & CSS
- No JavaScript

## Files

```
css-glassmorphism-alert-box/
├── demo.html
├── style.css
└── README.md
```

## Technologies

- HTML5
- CSS3
- Flexbox
- Backdrop Filter
- CSS Animations

## Purpose

Provides a reusable glassmorphism alert component suitable for dashboards, forms, notifications, and modern web interfaces while following EaseMotion CSS's animation-first philosophy.
