# glow-toast-banner-v3-ak

Pure CSS animated notification toast banner with bottom progress timer line — no JavaScript required.

## How to use

```html
<div class="ease-toast-v3">
  <span class="ease-toast-icon-v3">🔔</span>
  <div class="ease-toast-content-v3">
    <span class="ease-toast-title-v3">Title</span>
    <span class="ease-toast-desc-v3">Description</span>
  </div>
  <div class="ease-toast-timer-v3"></div>
</div>
