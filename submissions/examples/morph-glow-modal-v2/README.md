# CSS Morph-Glow Modal

A responsive modal component featuring a morph and glow entrance animation using only HTML and CSS.

## Features

- Pure HTML & CSS
- Morph + glow animation
- No JavaScript
- Responsive design
- CSS Custom Properties
- Accessible structure
- prefers-reduced-motion support

## CSS Variables

```css
:root{
  --primary:#4f46e5;
  --secondary:#8b5cf6;
  --background:rgba(0,0,0,.6);
  --duration:.45s;
  --radius:18px;
}
```
