# CSS Shimmer-Sweep Hero Section for Product Catalog Layouts

A modern **Hero Section** featuring a shimmering light sweep animation built entirely with HTML and CSS. Perfect for showcasing featured products or landing pages in product catalog layouts.

## ✨ Features

- Pure HTML5 & CSS3
- Shimmer sweep hover animation
- Responsive hero layout
- Glassmorphism hero card
- Gradient CTA buttons
- CSS Custom Properties
- Lightweight and reusable
- `prefers-reduced-motion` support
- No JavaScript required
