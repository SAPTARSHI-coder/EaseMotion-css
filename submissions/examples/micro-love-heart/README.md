# Micro Love Heart

A tiny like button whose heart bursts with a ripple every time you hover it.

## Features
- Heart scales with a springy pop
- Ripple ring expands outward
- Sparkle dots scatter on tap

## Usage
```html
<div class="ml-btn">&#10084;&#65039;</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
