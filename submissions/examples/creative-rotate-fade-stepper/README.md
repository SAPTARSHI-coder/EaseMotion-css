# CSS Rotate-Fade Stepper for Creative Portfolio Layouts

A modern **Creative Portfolio Stepper** featuring elegant **Rotate-Fade** animations built entirely with **HTML5 and CSS3**. This example demonstrates an animated vertical stepper with smooth entrance effects, responsive layouts, CSS custom properties, and accessibility support—without requiring JavaScript.

---

## ✨ Features

- 🎨 Creative Portfolio inspired layout
- 🔄 Rotate-Fade entrance animation
- 📍 Vertical timeline stepper
- 🔢 Gradient numbered indicators
- 🪟 Glassmorphism step cards
- ⚡ Pure HTML5 & CSS3 (No JavaScript)
- 📱 Fully responsive across desktop, tablet, and mobile
- 🎯 CSS Custom Properties for easy customization
- ♿ Accessibility support with `prefers-reduced-motion`
- 🚀 Lightweight and performance-friendly

## 🚀 Getting Started

1. Open `demo.html` in any modern browser.
2. View the Rotate-Fade animation as each step enters.
3. Hover over step cards for interactive elevation.
4. Customize colours, spacing and animation timing through the CSS variables.

## 🎨 CSS Custom Properties

```css
:root{

    --text:#ffffff;
    --muted:#cbd5e1;
```
