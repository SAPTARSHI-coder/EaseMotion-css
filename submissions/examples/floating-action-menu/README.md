# Floating Action Menu

A CSS-only floating action menu with a radial/floating entrance animation.

## Features

- Pure CSS implementation
- No JavaScript required
- Radial action entrance
- Smooth scale and movement animation
- Animated menu toggle button
- Responsive design
- Keyboard focus indicator
- Reduced-motion support
- CSS custom properties for customization

## Files

- `demo.html` — Demo markup
- `style.css` — Component styles and animations
- `README.md` — Documentation
