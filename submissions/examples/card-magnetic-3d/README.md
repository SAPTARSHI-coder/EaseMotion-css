# Card Magnetic 3D

A card tilts in 3D on hover following an imaginary cursor.

## Features
- 3D tilt
- Hover lift
- Depth shadow
- Pure CSS

## Usage
```html
<div class="cm3d-card">...</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
