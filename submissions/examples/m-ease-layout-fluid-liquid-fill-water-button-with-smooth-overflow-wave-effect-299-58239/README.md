# Fluid Liquid Fill Water Button with Smooth Overflow Wave Effect (Glassmorphic Style)

A modern **Glassmorphic Liquid Fill Water Button** built using pure HTML and CSS. The component combines frosted glass aesthetics with animated liquid waves and smooth overflow fill effects for elegant interactive buttons.

## ✨ Features

- Pure HTML5 & CSS3
- Glassmorphism design
- Animated liquid fill effect
- Smooth overflow wave animation
- Responsive layout
- CSS Custom Properties
- `prefers-reduced-motion` support
- No JavaScript required
