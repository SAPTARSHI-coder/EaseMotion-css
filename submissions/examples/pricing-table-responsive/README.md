# Responsive Pricing Table

## Description

This submission fixes an issue where pricing table columns overflow or become compressed on tablet-sized screens. The layout now adapts smoothly across desktop, tablet, and mobile devices using responsive Flexbox.

## Features

- Prevents pricing card overflow
- Tablet-friendly responsive layout
- Mobile-first design
- Equal spacing between cards
- Pure CSS implementation

## Usage

```html
<div class="pricing-table">
  <div class="pricing-card">
    <h2>Basic</h2>
    <p class="price">$9/month</p>
    <button>Select Plan</button>
  </div>
</div>
```

## Benefits

- Eliminates horizontal scrolling
- Improves readability on tablets
- Keeps pricing cards aligned
- Lightweight and easy to integrate
