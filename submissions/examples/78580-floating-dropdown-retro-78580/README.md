# Floating Retro Dropdown

## Overview

Issue #78580 demonstrates a responsive floating navigation panel with retro styling.

## Features

- Responsive navigation grid
- Lifted panel depth
- Native keyboard focus
- Reduced-motion support
- Pure HTML and vanilla CSS

## Usage

Open `demo.html` to view the component and reuse the menu structure in another page.

## Files

- `demo.html` — semantic navigation example
- `style.css` — layout, depth, responsive rules, and motion handling
- `README.md` — documentation
