# CSS Glitch-Flicker Accordion for Fintech Dashboard Layouts

A futuristic fintech dashboard accordion component featuring glitch and flicker animation effects built completely with pure HTML and CSS.

This component is designed for fintech dashboards, cybersecurity panels, and modern SaaS interfaces where interactive animated content sections are required without JavaScript.


## ✨ Features

- ⚡ Glitch-flicker animation effects
- 📂 Interactive CSS-only accordion
- 💳 Fintech dashboard inspired UI
- 🎨 Cyberpunk glassmorphism design
- 🔄 Smooth CSS transitions
- ⚡ Pure HTML and CSS implementation
- 📱 Fully responsive layout
- ♿ prefers-reduced-motion accessibility support
- 🚀 Lightweight and framework-free

## 🚀 Usage

1. Open `demo.html` directly in your browser.

2. Click accordion headers to expand content sections.

3. Customize CSS variables inside `style.css` according to your theme.


## 🎨 CSS Custom Properties

The component uses CSS variables for easy customization:

```css
:root {

    --bg:#020617;
    --card:#0f172a;
    --primary:#22d3ee;
    --accent:#f43f5e;
    --text:#f8fafc;
    --muted:#94a3b8;

}

Update these values to match your dashboard branding.
