# Origami Paper Fold Text Animation

A paper-inspired text animation created using pure HTML and Vanilla CSS.

This component recreates the visual effect of folding and unfolding
origami paper while keeping the implementation lightweight and
JavaScript-free.

## ✨ Features

- Origami-inspired 3D folding animation
- Individual letter animation
- Paper-like gradient shading
- Dynamic fold highlights
- Smooth CSS transitions
- 3D transforms and perspective
- Dark-mode compatible
- Responsive design
- Accessible text structure
- `prefers-reduced-motion` support
- Hardware-friendly transforms
- No JavaScript
- No external dependencies

## 🛠️ Technologies

- HTML5
- CSS3
- CSS Custom Properties
- CSS 3D Transforms
- CSS Animations
- CSS Gradients
- CSS Media Queries
