# Cybernetic Matrix Digital Rain Background Canvas Overlay (Cyberpunk Theme)

A futuristic **Cyberpunk-themed Matrix Digital Rain Background** built using pure HTML and CSS. It combines animated neon rain, glowing UI cards, and responsive layouts suitable for dashboards, landing pages, and sci-fi interfaces.

## ✨ Features

- Pure HTML5 & CSS3
- Cyberpunk digital rain animation
- Glassmorphism content panel
- Neon glowing status cards
- Gradient CTA buttons
- CSS Custom Properties
- Responsive layout
- `prefers-reduced-motion` support
- No JavaScript required
