# CSS Slide-Up Carousel

A responsive CSS-only Slide-Up Carousel designed for e-commerce checkout layouts.

## Features

- Pure HTML & CSS
- No JavaScript
- Responsive layout
- Smooth slide-up animation
- Keyboard accessible using :focus-within
- Uses CSS Custom Properties
- Easy to customize

## Files

- demo.html
- style.css

## Custom Variables

```css
--duration
--radius
--shadow
--accent
```
