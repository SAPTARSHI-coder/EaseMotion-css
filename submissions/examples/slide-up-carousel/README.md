# CSS Slide-Up Carousel

A pure CSS carousel designed for E-Commerce Checkout Layouts, featuring a stylish slide-up entrance animation when switching between address cards or payment options.

## Features
- Pure CSS and HTML (No JavaScript required).
- Radio-button hack utilized for fully functional state management.
- Smooth CSS transitions using `translateY` for a slide-up effect with a spring-like cubic-bezier curve.
- Clean and modern e-commerce checkout styling.
- Fully responsive across desktop, tablet, and mobile viewports.
- Honors the `prefers-reduced-motion` accessibility standard.

## Usage
Open `demo.html` in your browser. Click on the pagination indicators below the card to transition smoothly between different checkout options using the slide-up animation.

## Files
- `demo.html`: The HTML structure for the checkout UI and the radio-input state management.
- `style.css`: The styling, flexbox properties, and CSS transformations for the slide-up carousel logic.
