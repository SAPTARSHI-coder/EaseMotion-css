# Dynamic Timeline — Cyberpunk

A responsive timeline component with a futuristic Cyberpunk visual
style, created for EaseMotion CSS issue #81376.

## Features

- Cyberpunk-inspired dark interface
- Neon cyan, magenta, lime and yellow accents
- Animated timeline entrance
- Glowing timeline markers
- Scanline overlay
- Grid-based futuristic background
- Interactive hover states
- Responsive desktop, tablet and mobile layout
- Reduced-motion support
- Pure HTML and CSS
- No JavaScript dependencies
