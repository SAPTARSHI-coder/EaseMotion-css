# Neon Badge Notification Component

Add ease-neon-badge-notification-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|---------|
| `--nb-red` | `#ef4444` |
| `--nb-yellow` | `#f59e0b` |
| `--nb-green` | `#10b981` |
| `--nb-blue` | `#3b82f6` |
| `--nb-shadow-red` | `0 0 8px rgba(239,68,68,0.6)` |

## Technique

`@keyframes` pulse animation on box-shadow creates neon glow effect.
