# Enlarger Focus Bellows

## What does this do?
Renders a self-contained CSS-only `ease-enlarger-focus-bellows` demo: Photo enlarger bellows expanding while focus ring turns.

## How is it used?
Open `demo.html` in a browser. The animated face uses classes like `ease-enlarger-focus-bellows`, `ease-enlarger-focus-bellows__arm`, and `ease-enlarger-focus-bellows__core`. No build step or JavaScript is required for the motion.

```html
<section class="ease-enlarger-focus-bellows">
  <div class="ease-enlarger-focus-bellows__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
