# Slot Machine

A casino-style reel that spins its symbols into place whenever you hover the lever.

## Features
- Reels tumble with a vertical blur effect
- Winner row gets a glowing payline
- Lever arm slides on hover

## Usage
```html
<div class="sm-machine">
  <div class="sm-reels"><div class="sm-reel"><i>&#127791;</i></div></div>
  <div class="sm-lever"></div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
