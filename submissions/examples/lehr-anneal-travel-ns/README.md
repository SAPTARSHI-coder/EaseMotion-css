# Lehr Anneal Travel

## What does this do?
Renders a self-contained CSS-only `ease-lehr-anneal-travel` demo: Lehr belt carrying glass through the anneal curve.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-lehr-anneal-travel`. No build step or JavaScript is required for the effect.

```html
<section class="ease-lehr-anneal-travel">
  <div class="ease-lehr-anneal-travel__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
