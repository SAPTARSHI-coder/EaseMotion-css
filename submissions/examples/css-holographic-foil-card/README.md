# CSS Holographic Foil Card

A stunning 3D rotating trading card featuring a dynamic holographic foil effect. This uses multiple layers of `linear-gradient` and `mix-blend-mode` that shift colors fluidly to simulate light reflecting off a metallic surface.

## Features

- **Pure CSS**: No JavaScript or images required.
- **Holographic Foil**: Uses animated `linear-gradient` and `color-dodge` blend mode to create a mesmerizing rainbow metallic effect.
- **3D Rotation**: Employs `transform-style: preserve-3d` and infinite rotation keyframes for a true 3D spatial feel.
- **Dynamic Glare**: A moving radial gradient that simulates a light source reflecting off the card's surface.
