# 🕉️ Mandala Nav – Symmetrical Pattern Unfolds Outward

---

## 📖 Description

The **Mandala Nav** is a spiritual, meditative navigation component where a symmetrical mandala pattern unfolds outward on hover or click. Eighteen petals arranged in two concentric rings radiate outward from a central Om symbol, creating a beautiful, harmonious mandala pattern. The petals unfold with staggered delays, mimicking the meditative unfolding of a mandala.

The component uses CSS transforms and trigonometric positioning to arrange the petals in a symmetrical pattern. Two rings of petals (6 inner, 12 outer) unfold with staggered delays for organic, meditative motion. The center button morphs from an Om symbol to a close icon when open, and each petal has a unique spiritual tooltip.

Perfect for spiritual websites, meditation apps, yoga brands, and any application where you want to create a harmonious, sacred navigation experience. The Mandala Nav transforms a simple menu into a meditative, symmetrical pattern.
