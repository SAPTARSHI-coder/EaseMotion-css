# Glow Testimonial Card

A modern testimonial card with a neon glow aesthetic built using **EaseMotion CSS**. The component combines glassmorphism, a glowing gradient border, and smooth entrance animations to create an eye-catching testimonial section.

## Features

- ✨ Neon glow hover effect
- 🎨 Glassmorphism-inspired design
- 🚀 Uses EaseMotion CSS animation classes
- 📱 Fully responsive
- ♿ Accessible semantic HTML
- 🚫 Pure HTML & CSS (no JavaScript)

## Folder Structure


glow-testimonial-card/
├── demo.html
├── style.css
└── README.md

## Usage

Open `demo.html` in a browser after including the EaseMotion CSS framework.

The component uses EaseMotion utility classes together with custom CSS for the neon styling.

## EaseMotion Classes Used

- `ease-fade-in`
- `ease-slide-up`
- `ease-hover-glow`

## Customization

You can easily customize:

- Glow colors
- Background color
- Border radius
- Avatar image
- Testimonial content
- Typography
- Animation timing

by editing the CSS variables in `style.css`.

## Accessibility

- Semantic HTML structure
- Meaningful `alt` text for images
- Responsive layout for mobile and desktop
- Keyboard-friendly with no JavaScript dependency
