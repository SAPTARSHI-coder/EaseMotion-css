# glow-toast-banner-v7-ak

Pure CSS animated notification toast banner with bottom progress timer line — no JavaScript required.

## How to use

```html
<div class="ease-toast-v7">
  <span class="ease-toast-icon-v7">🔔</span>
  <div class="ease-toast-content-v7">
    <span class="ease-toast-title-v7">Title</span>
    <span class="ease-toast-desc-v7">Description</span>
  </div>
  <div class="ease-toast-timer-v7"></div>
</div>
