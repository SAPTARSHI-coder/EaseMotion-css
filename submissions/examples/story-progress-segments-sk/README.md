# Story Progress Segment Bar

## What does this do?

A multi-segment story progress rail that fills the active segment over time.

## How is it used?

```html
<div class="stories"><div class="stories__progress"><span class="seg is-done"></span><span class="seg is-active"></span><span class="seg"></span></div></div>
```

Open `demo.html` in a browser to try it.

## Why is it useful?

Familiar media progress pattern for stories and onboarding carousels.
