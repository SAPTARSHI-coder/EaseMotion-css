# Gradient Shimmer Tabs

A modern pure CSS tabs and segmented control featuring a vibrant **Gradient Shimmer** effect with animated gradients and smooth interactions.

## Features

- Pure HTML & CSS
- Animated gradient shimmer effect
- Smooth CSS transitions
- Responsive segmented control
- Dark mode compatible
- Hardware-accelerated animations
- Accessible radio-button implementation
- No JavaScript required

- `demo.html`
- `style.css`
