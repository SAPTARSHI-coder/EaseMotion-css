# Minimalist Outline Tabs

A modern pure CSS tabs and segmented control featuring a clean **Minimalist Outline** design with subtle interactions and responsive behavior.

## Features

- Pure HTML & CSS
- Minimal outlined styling
- Smooth CSS transitions
- Responsive segmented control
- Dark mode compatible
- Hardware-accelerated animations
- Accessible radio-button implementation
- No JavaScript required

- `demo.html`
- `style.css`
