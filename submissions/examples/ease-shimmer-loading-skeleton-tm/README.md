# Shimmer Loading Skeleton Component

**Issue:** [#71805](https://github.com/SAPTARSHI-coder/EaseMotion-css/issues/71805)

Animated skeleton loader with shimmer effect for content placeholders.

## Design Tokens

| Token | Default |
|-------|---------|
| `--tm-shimmer-bg` | `#1e293b` |
| `--tm-shimmer-speed` | `1.8s` |
| `--tm-shimmer-radius` | `8px` |
| `--tm-shimmer-highlight` | `#334155` |

## Classes

- `.shimmer-card` — skeleton card wrapper
- `.shimmer-line` — animated line placeholder
- `.shimmer-line.w-60` / `.w-80` — width variants
- `.shimmer-line.avatar` — circular avatar placeholder
