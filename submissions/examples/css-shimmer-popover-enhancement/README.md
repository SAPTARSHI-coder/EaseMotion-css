# CSS Shimmer Sweep Popover

A modern, responsive **CSS-only popover** featuring a smooth shimmer sweep animation, glassmorphism styling, and elegant transitions. Built using only **HTML and CSS** with no JavaScript required.

---

## ✨ Features

- 🎨 Pure HTML & CSS
- ✨ Smooth shimmer sweep animation
- 🌟 Modern glassmorphism design
- 📱 Fully responsive
- ♿ Keyboard accessible (`:focus-visible`)
- 🎯 Hover-triggered popover
- ⚡ Lightweight with zero JavaScript
- 🎛️ Easily customizable using CSS variables
- 🌙 Modern dark theme

---

css-shimmer-sweep-popover/

---

## 🚀 Usage

1. Clone or download the project.
2. Open `demo.html` in your browser.
3. Hover over or focus on the trigger button to reveal the popover.

---

## 🎨 Customization

The component uses CSS custom properties for quick customization.

```css
:root{
    --bg: #0f172a;
    --popover-bg: #1e293b;
    --accent: #38bdf8;
    --radius: 22px;
    --duration: .45s;
}
```

You can modify these variables to create different themes without changing the component structure.
