# Morphing Gradient Badge

A responsive CSS-only badge featuring an animated gradient background, morphing border-radius, and hover shine effect.

## Features

- Animated gradient
- Morphing shape animation
- Hover interaction
- Fully responsive
- CSS-only implementation
- No JavaScript required
- Reduced-motion support
