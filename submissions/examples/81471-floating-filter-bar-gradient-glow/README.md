# Floating Filter Bar - Gradient Glow

A responsive floating filter bar featuring a luminous
gradient-glow visual style, glass-like surfaces, smooth
interactions, active filter chips, and responsive controls.

## Features

- Pure HTML and CSS
- Floating filter bar design
- Gradient glow styling
- Search input
- Category selection
- Sorting selection
- Clear and apply actions
- Active filter chips
- Responsive layout
- Animated background glow
- Smooth hover and active states
- Keyboard focus states
- `prefers-reduced-motion` support
- No JavaScript dependencies
- No external libraries
