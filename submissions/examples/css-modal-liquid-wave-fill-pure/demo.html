Pure CSS Modal: Liquid Fill

An organic, JavaScript-free modal utilizing the checkbox hack. Features rotating CSS "squircles" masked by `overflow: hidden` to simulate a rising liquid wave.

Fluid Dynamics

This modal utilizes CSS shape masking. Two large, rotating squares with a `border-radius: 40%` are positioned below the modal. When triggered, they translate upwards. The intersection of their rotation creates the illusion of organic, sloshing liquid.
