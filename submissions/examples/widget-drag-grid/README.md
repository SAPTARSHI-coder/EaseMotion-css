# CSS Widget Drag Grid 🧩


A pure CSS widget dashboard layout with draggable style cards and placeholder zones.


## Features

- Pure CSS implementation
- Dashboard style widgets
- Drag interaction styling
- Placeholder drop zones
- Hover animations
- Responsive layout
- Accessibility friendly


## Technologies

- HTML5
- CSS3
