# CSS Skew Active Tooltip

## Overview

A pure HTML and CSS tooltip featuring a skew animation for gaming-style layouts.

## Features

- Pure HTML & CSS
- Responsive
- Smooth transitions
- Accessible
- Supports prefers-reduced-motion

## Folder Structure

```text
skew-active-tooltip/
│── demo.html
│── style.css
└── README.md
```

## Usage

1. Open `demo.html`
2. Hover over the button.
3. Customize the colors and animation.

## CSS Variables

- `--primary`
- `--secondary`
- `--tooltip-bg`
- `--text`
- `--duration`

## Accessibility

- Keyboard-friendly structure
- Reduced motion support
