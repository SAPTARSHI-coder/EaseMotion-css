# Simple Divider Line Utility

## What it does

This submission creates a minimal CSS-only divider line utility for separating sections, settings groups, cards, and content blocks.

## How to use it

Add the divider element wherever a visual separator is needed:

```html
<div class="simple-divider"></div>
```

## Why it fits EaseMotion CSS

It fits EaseMotion CSS because it is human-readable, composable, and useful across many layouts. It is a small utility that can improve structure in dashboards, forms, cards, and content sections.

## Included features

- Minimal horizontal divider utility
- Soft variation included in the demo
- Practical section layout example
- Responsive demo layout
- Pure HTML and CSS implementation

- `demo.html` - self-contained demo that opens directly in a browser
