# Rattleback Spin Reverse

## What does this do?
Renders a self-contained CSS-only `ease-rattleback-spin-reverse` demo: Asymmetric rattleback spinning then self-reversing direction.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-rattleback-spin-reverse`. No build step or JavaScript is required for the effect.

```html
<section class="ease-rattleback-spin-reverse">
  <div class="ease-rattleback-spin-reverse__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
