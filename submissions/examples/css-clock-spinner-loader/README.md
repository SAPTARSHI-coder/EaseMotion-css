# CSS Clock Spinner Loader

A CSS-only clock-face spinner loader featuring animated hour and minute hands rotating continuously to create a lightweight loading indicator.

## Features

- 🕐 Clock-face inspired loading animation
- ⚡ Pure CSS implementation with no JavaScript
- 🔄 Continuously animated hour and minute hands
- 🎨 CSS custom properties for easy theming
- 🌓 Supports light and dark color schemes
- 📱 Responsive design for different screen sizes
- ♿ Includes accessible loading semantics
- 🚫 No external dependencies
- ♿ Respects the user's reduced-motion preference
