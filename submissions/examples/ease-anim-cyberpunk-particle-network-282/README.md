# Particle Constellation Background Network with CSS & Canvas

### Cyberpunk Theme

A modern cyberpunk-inspired particle constellation background built using **HTML5 Canvas**, **CSS3**, and **JavaScript**. The component features animated particles connected by glowing neon lines with a futuristic glass-inspired interface overlay.

---

## ✨ Features

- Animated particle constellation network
- HTML5 Canvas rendering
- Cyberpunk neon theme
- Responsive layout
- Glowing hover effects
- Gradient action button
- Modern CSS variables
- Pure HTML, CSS & JavaScript
- Reduced motion accessibility support

## 🚀 Usage

1. Open the component folder.
2. Keep `demo.html` and `style.css` in the same directory.
3. Open `demo.html` in any modern browser.
4. The particle animation starts automatically.

No external libraries or installation are required.
