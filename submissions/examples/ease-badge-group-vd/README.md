# Ease Badge Group

## What does this do?

A horizontal group of rounded badges with multiple color variants and a subtle hover animation.

---

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<div class="badge-group">
    <span class="badge blue">JavaScript</span>
    <span class="badge green">Frontend</span>
    <span class="badge purple">Design</span>
</div>
```

### Features

- Multiple badges
- Rounded design
- Multiple color variants
- Hover animation
- Responsive wrapping
- Lightweight and reusable

---

## Why is it useful?

Badge groups are commonly used for filters, categories, skills, tags, and labels.

This component provides a simple and reusable way to display multiple badges while adding subtle interaction feedback in line with the animation-first philosophy of EaseMotion CSS.
