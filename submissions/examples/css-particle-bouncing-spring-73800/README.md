# CSS Particle Effect - Bouncing Spring

A pure CSS particle effect that simulates bouncing spring motion through staggered animated particles. Designed for smooth performance, responsiveness, and modern UI experiences.

## Features

- Pure HTML and CSS
- Bouncing spring animation
- Hardware-accelerated transforms
- Dark mode friendly
- Responsive layout
- Accessible implementation
- No JavaScript required

## Usage

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

Add the component:

```html
<div class="spring-container">
  <span class="particle p1"></span>
  <span class="particle p2"></span>
</div>
```

## Customization

- Modify particle colors in `.p1`–`.p8`
- Adjust bounce height in `@keyframes bounceSpring`
- Change animation duration for different spring effects
