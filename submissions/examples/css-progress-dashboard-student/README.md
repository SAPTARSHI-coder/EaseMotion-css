# CSS Progress Dashboard for Student

A responsive student progress dashboard built using pure HTML and CSS.

## Features

- Animated subject progress bars
- Overall progress indicator
- Responsive layout
- Pure CSS implementation
- No JavaScript or external libraries
- Accessible progressbar semantics
- Keyboard-friendly static interface
- Reduced-motion support
- Works by opening `demo.html` directly in a browser
