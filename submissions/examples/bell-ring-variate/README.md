
---

## 🚀 Usage
1. Clone or copy the files into your project.
2. Open `demo.html` in your browser.
3. Hover or focus on the bell to see it ring.

---

## 🛠️ Customization
- **Ring intensity** → Adjust rotation degrees in `@keyframes ring`.
- **Duration** → Change `animation: ring 1s` for faster/slower sway.
- **Size** → Modify `font-size` in `.bell-btn`.
- **Color** → Customize `color` for different themes.

---

## 📖 Accessibility
- Uses `aria-label="Notifications"` for screen readers.
- Animation triggers on both hover and focus for keyboard accessibility.
