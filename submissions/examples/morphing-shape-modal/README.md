# CSS Modal: Morphing Shape

A smooth, accessible, and performant pure CSS modal featuring a
**Morphing Shape** visual effect.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript required
- Animated organic shapes
- Dynamic border-radius morphing
- Smooth modal entrance animation
- Gradient animation
- Dark-mode-friendly design
- Responsive layout
- Hardware-accelerated transforms
- Accessible dialog structure
- Keyboard focus indicators
- Reduced-motion support
- No external dependencies
