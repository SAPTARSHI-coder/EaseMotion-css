# CSS 3D Tilt Card Component

A reusable **CSS-only 3D Tilt Card** that creates a subtle perspective hover effect for product cards, portfolio items, profile cards, and feature sections.

## ✨ Features

- Pure HTML5 & CSS3
- CSS perspective and 3D transforms
- Smooth hover lift animation
- Glass-style gradient overlay
- Responsive layout
- CSS Custom Properties
- `prefers-reduced-motion` support
- No JavaScript required
