# Ripple Wave Click Water

A lightweight CSS animation that creates a smooth water-like ripple wave effect.

## Features

- Smooth expanding ripple effect
- Uses `transform` and `opacity` for efficient animation
- Configurable duration and timing
- Supports `prefers-reduced-motion`
- No JavaScript required
- Lightweight and reusable

## Class

```html
<span class="ease-anim-ripple-wave-click-water"></span>
