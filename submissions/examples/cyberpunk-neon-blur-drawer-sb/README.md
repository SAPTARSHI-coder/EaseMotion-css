# Cyberpunk Neon Blur Drawer

## 1. What does this do?
A cyberpunk neon styled drawer with blur-to-sharp entrance animation effect.

## 2. How is it used?
Apply `.ease-blur-drawer` class to drawer element.

## 3. Why is it useful?
- Creates dramatic, mysterious cyberpunk aesthetic
- Blur-to-sharp reveal animation
- Smooth entrance with accessibility support
