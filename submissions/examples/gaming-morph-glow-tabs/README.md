# CSS Morph-Glow Tabs for Gaming Hub Layouts

A modern **Gaming Hub Tabs** component built entirely with **HTML5 and CSS3**. This showcase demonstrates futuristic **Morph-Glow** tab animations with neon effects, glassmorphism panels, responsive layouts, and accessibility support without requiring JavaScript.

---

## ✨ Features

- 🎮 Gaming dashboard tabs
- ✨ Morph-Glow active tab animation
- 🌈 Neon gradient highlights
- 💎 Glassmorphism content panel
- 📊 Responsive stat cards
- 📱 Fully responsive
- ⚡ Pure HTML5 & CSS3
- 🎯 CSS Custom Properties
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

## 🚀 Getting Started

1. Open `demo.html` in any modern browser.
2. Explore the futuristic gaming tab interface.
3. Hover over tabs and cards to experience the Morph-Glow effects.
4. Customize colors, spacing, and animations using CSS variables.

## 🎨 CSS Custom Properties

```css
:root{
    --bg:#050816;
    --surface:rgba(15,23,42,.88);
    --primary:#00e5ff;
    --secondary:#8b5cf6;
    --text:#ffffff;
    --muted:#cbd5e1;
    --border:rgba(255,255,255,.08);
    --radius:22px;
}
```
