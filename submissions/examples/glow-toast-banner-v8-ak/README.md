# glow-toast-banner-v8-ak

Pure CSS animated notification toast banner with bottom progress timer line — no JavaScript required.

## How to use

```html
<div class="ease-toast-v8">
  <span class="ease-toast-icon-v8">🔔</span>
  <div class="ease-toast-content-v8">
    <span class="ease-toast-title-v8">Title</span>
    <span class="ease-toast-desc-v8">Description</span>
  </div>
  <div class="ease-toast-timer-v8"></div>
</div>
