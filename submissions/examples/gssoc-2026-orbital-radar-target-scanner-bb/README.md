# Orbital Radar Target Scanner - GSSoC 2026

An orbital sonar radar scanner display featuring 360-degree conic gradient sweep animations and delayed blip ping pulses.

## 1. What does this do?
It renders a circular tactical radar HUD display featuring continuous rotary sweep lines and target ping indicators.

## 2. How is it used?
Link `style.css` in your HTML file and copy `.radar-screen` containing `.sweep-hand` and `.ping` elements.

## 3. Why is it useful?
It brings authentic sci-fi radar telemetry animations to gaming web applications, map widgets, and security dashboards.
