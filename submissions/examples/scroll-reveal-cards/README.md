# Scroll-Reveal Cards

A pure CSS scroll-reveal card component for EaseMotion CSS.

## Features

- Scroll-based entrance animation
- Fade + movement effect
- Left, right and upward reveal variants
- Pure CSS implementation
- No JavaScript required
- Responsive layout
- Reduced-motion accessibility support
- Customizable animation parameters

## Available Classes

### Reveal Up

```html
<article class="card reveal reveal-up">
    <h2>Title</h2>
    <p>Content</p>
</article>
