# CSS Skew-Active Pricing Table for Product Catalog Layouts

A modern **Skew-Active Pricing Table** built using pure HTML and CSS. The component features elegant skew-hover interactions, responsive pricing cards, CSS custom properties, and lightweight styling for modern product catalog pages.

## ✨ Features

- Pure HTML5 & CSS3
- Skew-active hover animation
- Responsive pricing table
- Glassmorphism design
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
