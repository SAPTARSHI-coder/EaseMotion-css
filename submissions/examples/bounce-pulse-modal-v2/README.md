# CSS Bounce Pulse Modal

A responsive modal component featuring a smooth bounce and pulse entrance animation using only HTML and CSS.

## Features

- Pure HTML & CSS
- Bounce-Pulse entrance animation
- Responsive layout
- Accessible structure
- No JavaScript
- Supports `prefers-reduced-motion`

## Folder Structure

```
bounce-pulse-modal/
├── demo.html
├── style.css
└── README.md
```

## Usage

Open `demo.html` in any modern browser.

## Customization

You can modify:

- Modal width
- Animation duration
- Colors
- Border radius
- Shadows
- Button styles

## Accessibility

- Responsive design
- Reduced motion support
- Semantic HTML
- Keyboard-friendly checkbox toggle
