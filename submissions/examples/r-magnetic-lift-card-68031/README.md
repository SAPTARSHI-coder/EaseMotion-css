# CSS Magnetic-Lift Card

A lightweight, reusable card interaction for EaseMotion CSS that creates a smooth magnetic lift effect using only HTML and CSS.

## Features

- Pure HTML and CSS
- Smooth magnetic lift on hover
- Keyboard-friendly focus interaction
- Configurable CSS custom properties
- Layered glow effect
- Responsive card grid
- No JavaScript required
- `prefers-reduced-motion` support
- Works for product cards, feature cards, portfolios, and dashboards
