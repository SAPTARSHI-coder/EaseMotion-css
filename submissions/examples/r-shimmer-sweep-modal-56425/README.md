# CSS Shimmer-Sweep Modal

A modern **Shimmer-Sweep Modal** built using pure HTML5 and CSS3 for Gaming Hub layouts. The modal opens smoothly while a shimmering light sweeps across the surface, creating a premium gaming interface.

---

## ✨ Features

- Pure HTML5 & CSS3
- Shimmer sweep animation
- Gaming-inspired modal
- Fully responsive
- CSS Custom Properties
- Lightweight and performant
- No JavaScript required
- Accessible structure
- `prefers-reduced-motion` support
