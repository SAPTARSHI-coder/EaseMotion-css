# Spinning Wheel

A conic-gradient prize wheel that spins to a stop on hover with a bouncing pointer.

## Features
- Conic-gradient segments in brand colors
- Wheel spins with a decelerating ease
- Pointer bounces while the wheel turns

## Usage
```html
<div class="sw-holder">
  <div class="sw-pin"></div>
  <div class="sw-wheel"></div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
