# Interactive Treeview - Cyberpunk

A responsive interactive treeview component featuring a
cyberpunk-inspired visual design.

The component is implemented using pure HTML and CSS without
external JavaScript dependencies.

## Features

- Cyberpunk visual styling
- Interactive expandable tree branches
- Nested file and folder structure
- Neon cyan and pink accents
- Glowing hover states
- Active tree item highlighting
- Smooth state transitions
- Responsive layout
- Keyboard-accessible controls
- Visible focus indicators
- `prefers-reduced-motion` support
- Zero external JavaScript dependencies
