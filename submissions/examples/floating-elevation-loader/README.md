# Floating Elevation Loader

A smooth, modern CSS loader featuring a floating elevation effect.

This component is built using pure HTML and Vanilla CSS with no JavaScript or external dependencies.

## ✨ Features

- Pure HTML and CSS
- Smooth floating elevation animation
- Dynamic shadow that responds to elevation
- Rotating inner loading indicator
- Light and dark mode support
- Responsive design
- Hardware-accelerated transforms
- `prefers-reduced-motion` accessibility support
- No JavaScript
- No external dependencies
