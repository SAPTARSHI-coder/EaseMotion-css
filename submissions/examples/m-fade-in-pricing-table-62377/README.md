# CSS Fade-In Pricing Table for Product Catalog Layouts

A modern **Fade-In Pricing Table** built using pure HTML and CSS. The component features elegant fade-in hover effects, responsive pricing cards, CSS custom properties, and lightweight styling suitable for modern product catalog pages.

## ✨ Features

- Pure HTML5 & CSS3
- Fade-in hover effect
- Responsive pricing table
- Glassmorphism card design
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
