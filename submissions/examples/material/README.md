# Material Audio Player Widget

A lightweight, accessible, zero-JS audio player component styled following Material Design guidelines and utilizing EaseMotion tokens.

## Features
* **Zero JavaScript:** Pure HTML5 and CSS implementation.
* **Material Design:** Compliant with surface elevations, rounded containers, and standard color variables.
* **Responsive:** Fully fluid sizing matching mobile, tablet, and desktop viewports.
* **Accessibility:** Built-in `prefers-reduced-motion` media query overrides for smooth transition properties.

## Usage
Include `style.css` in your project and structure your markup using the `.audio-player-card` and standard `<audio controls>` classes provided in `demo.html`.
