Floating Back to Top Button

Pure CSS floating back-to-top button featuring smooth scroll acceleration, arrow lift micro-animations, and accessible focus rings.

Section 1: Smooth Scroll Physics

EaseMotion CSS provides zero-JS scroll navigation components leveraging native CSS scroll-behavior: smooth for 60fps compositor performance.

Section 2: Floating Button Elevation

The floating action button remains fixed at the bottom right corner, animating upwards on hover with spring easing dynamics.

Section 3: Reduced Motion Compliance

Built-in media query overrides automatically disable keyframe transitions when prefers-reduced-motion: reduce is active in system settings.
