# CSS Button - Laser Ray Trace

A futuristic Laser Ray Trace button component built entirely with HTML and CSS. It features animated laser sweep effects, glowing neon borders, and hardware-accelerated hover interactions.

## Features

- Pure HTML & CSS
- Laser ray sweep animation
- Neon glow hover effects
- Dark mode friendly
- Responsive layout
- Accessible implementation
- Hardware accelerated transitions
- No JavaScript required

## Usage

Include the stylesheet and apply the button class:

```html
<button class="laser-btn">
  Launch Sequence
</button>
```

## Why it fits EaseMotion CSS

This component focuses on animation-first interaction design with smooth motion, visual feedback, accessibility, and zero dependencies while remaining easy to integrate into modern interfaces.
