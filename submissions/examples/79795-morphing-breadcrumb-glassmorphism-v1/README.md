# Morphing Breadcrumb - Glassmorphism

A responsive breadcrumb navigation component combining glassmorphism styling with subtle morphing interactions.

## Features

- Glassmorphism interface
- Smooth morphing hover effect
- Responsive layout
- Pastel-inspired visual treatment
- Active/current breadcrumb state
- Keyboard focus support
- No external dependencies

## Files

- `demo.html` - Component markup
- `style.css` - Component styling

## Usage

Open `demo.html` directly in a browser to preview the component.

## Responsive Behavior

The breadcrumb wraps naturally on smaller screens and simplifies labels on very narrow devices while keeping the current page visible.

## Accessibility

The navigation uses an accessible breadcrumb label, current-page state, and visible keyboard focus styles.
