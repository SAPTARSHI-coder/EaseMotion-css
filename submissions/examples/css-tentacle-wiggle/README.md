# CSS Tentacle Wiggle

A playful animated tentacle effect created entirely with HTML and CSS.

## Features

- Smooth wiggle animation
- Multiple staggered tentacles
- Responsive layout
- Pure CSS keyframes
- Lightweight implementation
- No JavaScript

## Files

```
css-tentacle-wiggle/
├── demo.html
├── style.css
└── README.md
```

## Technologies

- HTML5
- CSS3
- Flexbox
- CSS Keyframes
- Gradients

## Purpose

Provides a fun decorative animation suitable for underwater themes, games, playful interfaces, loading screens, and creative UI demonstrations.
