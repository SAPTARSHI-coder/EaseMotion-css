    # Testimonial Cards Submission

## 1. What does this do?
It provides a modern, responsive testimonial card component for displaying customer reviews with smooth hover animations and clean typography.

## 2. How is it used?
Wrap each testimonial in the `.testimonial-card` class and combine it with EaseMotion utilities like `ease-hover-lift` and staggered delays (`ease-delay-100`, `ease-delay-200`).

## 3. Why is it useful?
- Testimonials are essential for building trust on business websites.
- Demonstrates hover interactions (`ease-hover-lift`) with staggered entrance animations.
- Clean, modern design with gradient accents.
- Fully responsive grid layout.
- Fully accessible: respects `prefers-reduced-motion` to prevent unwanted movement.
- Maintainer can easily standardize this as `.ease-testimonial-[YOUR_INITIALS]` in the core library.
