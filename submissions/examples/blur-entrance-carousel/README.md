# CSS Blur-Entrance Carousel

A sleek, pure CSS carousel designed for E-Commerce Checkout Layouts, leveraging CSS `filter: blur()` to create a smooth, modern entrance animation when toggling between active cards.

## Features
- Pure CSS and HTML (No JavaScript required).
- State management handled purely through hidden radio buttons.
- Distinctive blur-and-fade entrance effect using `filter: blur()` and `opacity`.
- Interactive indicators that rotate smoothly on selection.
- Clean and modern e-commerce checkout styling.
- Fully responsive across all device sizes.
- Honors the `prefers-reduced-motion` accessibility standard.

## Usage
Open `demo.html` in your browser. Click on the square pagination indicators below the card to switch between different checkout options, watching the cards fade and un-blur seamlessly into focus.

## Files
- `demo.html`: HTML structure for the checkout component utilizing radio buttons.
- `style.css`: Pure CSS styles containing the layout rules and blur transition logic.
