# Radial Circular Progress Indicator with Animated Percentage Counter

## Overview

A dark mode radial progress indicator component with animated percentage
counter and smooth circular SVG transitions.

Built using pure HTML, CSS, and JavaScript.

## Features

- 🌑 Dark mode UI
- 🔄 Circular SVG progress animation
- 🔢 Animated percentage counter
- ✨ Neon glow effects
- 🎨 Gradient styling
- 📱 Responsive design
- ⚡ Smooth transitions

## Usage

1. Open `demo.html` in browser.
2. Click "Start Progress".
3. Watch the animated progress counter.
