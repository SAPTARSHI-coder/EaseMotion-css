# Tuning Fork Hum

## What does this do?
Renders a self-contained CSS-only `ease-tuning-fork-hum` demo: Tuning fork tines humming with visible vibration nodes.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-tuning-fork-hum`. No build step or JavaScript is required for the effect.

```html
<section class="ease-tuning-fork-hum">
  <div class="ease-tuning-fork-hum__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
