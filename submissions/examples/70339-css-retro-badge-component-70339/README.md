# CSS Retro Badge Component

Issue #70339 demonstrates a vintage badge shape using layered borders, gradients, and a subtle press interaction.

## Features

- Pure HTML and vanilla CSS
- Circular badge construction
- Worn-print texture using gradients
- Hover and keyboard focus state
- Responsive sizing
- Reduced-motion support

The badge contains semantic text and a visible focus state. Decorative movement is limited to a small transform and can be disabled through `prefers-reduced-motion`.

## Files

- `demo.html` — semantic badge example
- `style.css` — badge geometry and responsive rules
- `README.md` — documentation
