# glow-accordion-ak

Pure CSS animated glowing neon border accordion component — no JavaScript required.

## How to use

```html
<div class="ease-glow-accordion">
  <input type="checkbox" id="item1" class="ease-glow-accordion-checkbox" />
  <div class="ease-glow-accordion-item">
    <label for="item1" class="ease-glow-accordion-header">
      <span>Header</span>
      <span class="ease-glow-accordion-icon">▼</span>
    </label>
    <div class="ease-glow-accordion-drawer">
      <div class="ease-glow-accordion-body">Content</div>
    </div>
  </div>
</div>
