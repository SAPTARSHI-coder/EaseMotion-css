# Chisel Mallet Tap

## What does this do?
Renders a self-contained CSS-only `ease-chisel-mallet-tap` demo: Wood chisel advancing with each mallet tap.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-chisel-mallet-tap`. No build step or JavaScript is required for the effect.

```html
<section class="ease-chisel-mallet-tap">
  <div class="ease-chisel-mallet-tap__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
