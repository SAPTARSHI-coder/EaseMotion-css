# bouncing-loader-ak

Pure CSS animated 3D bouncing wave loader dots — no JavaScript required.

## How to use

```html
<div class="ease-bounce-loader">
  <span class="ease-bounce-dot"></span>
  <span class="ease-bounce-dot"></span>
  <span class="ease-bounce-dot"></span>
  <span class="ease-bounce-dot"></span>
</div>

<!-- Color Variants -->
<div class="ease-bounce-loader ease-bounce-loader--cyan">...</div>
<div class="ease-bounce-loader ease-bounce-loader--gold">...</div>
