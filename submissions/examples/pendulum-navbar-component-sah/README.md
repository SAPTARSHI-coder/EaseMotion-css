# Pendulum Navbar Component (`#54697`)

## What does this do?
Equips website header navigation links with a delightful oscillating pendulum active indicator that swings with gravitational physics on hover.

## How is it used?
Structure navigation item anchors inside an `ease-navbar-pendulum` container configured with inner pendulum spans:
```html
<nav class="ease-navbar-pendulum">
  <a href="#" class="nav-item">Home <span class="pendulum"></span></a>
</nav>
```

## Why is it useful?
Solves issue #54697 by delivering unique interactive charm to top-level app routing headers.
