# Solar Flare Radial Form

Implementation for EaseMotion issue #73366.

## Features

- Pure HTML and vanilla CSS
- Layered radial solar glow
- Native range control
- Responsive form layout
- Visible focus states
- Reduced-motion support

The flare is a decorative CSS gradient positioned behind the form controls. The form itself remains semantic and independent from the animation.

Open `demo.html` to preview the component and adjust the radial colors or pulse duration in `style.css`.
