Release Timeline

v3.0 — Motion Engine Rewrite

Aug 2026

Replaced the keyframe pipeline with a Web Animations-based engine, cutting idle CPU by 40% and enabling playhead scrubbing on every utility.

Added a curated set of spring curves (`snappy`, `soft`, `bouncy`) and a visual spring picker so designers can tune motion without writing cubic-bezier by hand.

Introduced the atomic `.em-*` class API and a bundler plugin that tree-shakes unused utilities down to a single KB for production builds.

Jun 2025

First stable release: 60 animation utilities, zero dependencies, full CSS variable theming, and an interactive playground for previewing every effect.
