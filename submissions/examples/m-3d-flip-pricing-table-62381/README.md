# CSS 3D-Flip Pricing Table for Product Catalog Layouts

A modern **3D-Flip Pricing Table** built using pure HTML and CSS. The component features elegant 3D flip hover interactions, responsive pricing cards, CSS custom properties, and lightweight styling for modern product catalog pages.

## ✨ Features

- Pure HTML5 & CSS3
- 3D flip hover animation
- Responsive pricing table
- Glassmorphism design
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
