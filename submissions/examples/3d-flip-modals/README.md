# CSS 3D-Flip Modal

A responsive **3D Flip Modal** built using pure HTML and CSS for creative portfolio layouts.

## Features

- Pure HTML & CSS
- 3D flip animation
- Responsive design
- Smooth transitions
- Accessible with `prefers-reduced-motion`
- Easy customization using CSS variables

## Files

- demo.html
- style.css

## Usage

Open `demo.html` in any modern browser.

## CSS Variables

```css
:root{
  --bg:#0f172a;
  --card:#1e293b;
  --accent:#38bdf8;
  --text:#ffffff;
}
```
