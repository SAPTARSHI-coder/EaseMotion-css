# Hand Crank Generator

## What does this do?
Renders a self-contained CSS-only `ease-hand-crank-generator` demo: Hand-crank dynamo lighting a bulb with RPM.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-hand-crank-generator`. No build step or JavaScript is required for the effect.

```html
<section class="ease-hand-crank-generator">
  <div class="ease-hand-crank-generator__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
