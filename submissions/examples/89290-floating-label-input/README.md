# Floating Label Input Component

A pure CSS interactive input field featuring a floating label animation when focused or populated.

## Features
- **Pure CSS Activation:** Uses `:placeholder-shown` and `:focus` selectors to detect field activity.
- **Smooth Scaling:** 60fps label float animation with subtle scale and color transitions.
- **Zero JavaScript:** Native HTML input behavior without event listeners.

## File Structure
- `demo.html` - Form input markup structure.
- `style.css` - Floating label positioning and transform state transitions.
