# CSS Author Bio Box

A responsive author profile card built entirely with HTML and CSS.

## Features

- Author avatar
- Online status indicator
- Author name and verification badge
- Role and biography
- Social links
- Hover animations
- Responsive mobile layout
- Keyboard-accessible links
- Reduced-motion support
- Forced-colors support
- No JavaScript required

## Usage

Include `style.css` and copy the author card markup from `demo.html`.

Replace the placeholder author information and social URLs with
your own content.
