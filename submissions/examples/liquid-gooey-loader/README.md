# Liquid Gooey Loader Animation

An advanced loading spinner that creates an organic, liquid-like surface tension effect when its internal elements collide and separate.

## Features
- SVG Filter Integration: Uses feGaussianBlur and feColorMatrix applied via CSS filter.
- Complex Orchestration: Multiple child elements animated independently while the parent container rotates.

## Usage
Include both the HTML structure and the hidden SVG element on your page. The CSS handles the rotation and transformation of the dots to trigger the fluid merging effect.
