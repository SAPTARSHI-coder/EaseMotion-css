# Aquatint Grain Dust

## What does this do?
Renders a self-contained CSS-only `ease-aquatint-grain-dust` demo: Aquatint resin grain dust settling.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-aquatint-grain-dust`. No build step or JavaScript is required for the effect.

```html
<section class="ease-aquatint-grain-dust">
  <div class="ease-aquatint-grain-dust__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
