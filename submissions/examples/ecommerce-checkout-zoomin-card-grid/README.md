# CSS Zoom-In Card Grid for E-Commerce Checkout Layouts

A responsive **Zoom-In Card Grid** created with pure HTML and CSS for modern E-Commerce Checkout interfaces.

## Features

- Pure HTML & CSS
- Responsive Card Grid
- Smooth Zoom-In Animation
- CSS Custom Properties
- Accessible Structure
- Supports `prefers-reduced-motion`
- No JavaScript Required

## Folder Structure

```
ecommerce-checkout-zoomin-card-grid/
│── demo.html
│── style.css
└── README.md
```

## Usage

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

Then use the card grid structure from `demo.html`.

## CSS Variables

```css
--bg
--card
--primary
--text
--shadow
--radius
--duration
--delay
--scale
```

Modify these variables to customize colors, spacing, animation speed, and scaling.
