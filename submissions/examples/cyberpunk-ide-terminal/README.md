# 💻 Cyberpunk Interactive IDE Code Terminal

A modern **Cyberpunk Interactive IDE Code Terminal** built using **pure HTML and CSS**. It mimics a professional code editor with macOS-style window controls, line numbers, syntax highlighting, and an animated blinking block cursor.

---

## ✨ Features

- 💻 Cyberpunk-inspired IDE interface
- 🔴🟡🟢 macOS-style traffic light window controls
- 🔢 Line number gutter
- 🎨 Tokenized syntax highlighting
- ⌨️ Blinking block cursor animation
- 🌙 Dark theme interface
- 📱 Fully responsive
- ♿ Supports `prefers-reduced-motion`
- 🚫 No JavaScript required

## Usage

1. Open `demo.html` in a modern web browser.
2. The terminal interface is displayed automatically.
3. Edit the sample code or customize the colors in `style.css`.
