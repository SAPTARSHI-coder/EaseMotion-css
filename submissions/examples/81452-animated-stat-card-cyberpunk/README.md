# Animated Stat Card — Cyberpunk

A responsive cyberpunk-themed statistics card created with
pure HTML and CSS for EaseMotion CSS issue #81452.

## Features

- Futuristic cyberpunk visual style
- CSS-only animations
- Responsive stat card layout
- Cyan, pink and lime accent variants
- Animated scanline effect
- Animated progress meters
- Neon glow effects
- Hover elevation and interaction
- Subtle text flicker
- System-status indicators
- Responsive typography
- `prefers-reduced-motion` support
- Zero JavaScript dependencies
