# CSS Morph-Glow Feature Grid

A modern **CSS Morph-Glow Feature Grid** built entirely with **HTML5** and **CSS3**. This showcase demonstrates a responsive feature grid with smooth morphing cards, subtle glow effects, and a clean minimalist tech aesthetic—all without JavaScript.

---

## ✨ Features

- 🚀 Pure HTML5 & CSS3
- ✨ Morph + glow hover animation
- 🎴 Responsive feature card grid
- 💻 Minimalist tech-inspired design
- 📱 Fully responsive layout
- ♿ Keyboard-friendly focus styles
- 🎨 Easy customization using CSS Custom Properties
- 🌙 Supports `prefers-reduced-motion`
- ⚙️ No JavaScript or external libraries

## 🚀 Usage

1. Open `demo.html` in a modern web browser.
2. Hover over a feature card to see the morph and glow animation.
3. Navigate with the keyboard to view accessible focus styles.
4. Customize colors, spacing, and sizing through the CSS custom properties.

---

## 🎨 CSS Custom Properties

| Variable | Description |
|----------|-------------|
| `--bg` | Page background color |
| `--surface` | Card background |
| `--primary` | Primary accent color |
| `--secondary` | Secondary accent color |
| `--text` | Primary text color |
| `--muted` | Secondary text color |
| `--border` | Card border color |
| `--radius` | Border radius |
| `--shadow` | Card shadow |
| `--transition` | Transition timing |

Example:

```css
:root{
    --primary:#2563eb;
    --secondary:#38bdf8;
}
```
