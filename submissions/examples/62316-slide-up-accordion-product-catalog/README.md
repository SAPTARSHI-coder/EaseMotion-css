# CSS Slide-Up Accordion for Product Catalog Layouts

A modern **Slide-Up Accordion** component built completely with pure HTML5 and CSS3 for product catalog layouts.

This component provides an elegant product showcase experience with smooth slide-up animations, expandable product sections, glassmorphism cards, and responsive design.

---

## ✨ Features

- Pure HTML5 and CSS3 implementation
- No JavaScript dependency
- Product catalog accordion layout
- Smooth slide-up reveal animation
- CSS-only accordion interaction
- Modern glassmorphism design
- Hover elevation effects
- Gradient action buttons
- Responsive across devices
- CSS custom properties support
- Lightweight animations
- `prefers-reduced-motion` accessibility support

## 🚀 Usage

1. Open `demo.html` in a modern browser.
2. Click on product sections to expand details.
3. Customize the component using CSS variables.
