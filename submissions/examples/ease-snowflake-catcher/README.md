# ❄️ Snowflake Catcher – Catch Unique Snowflakes

> An interactive snowflake catcher component where you catch unique snowflakes with 4 collections (Classic, Crystal, Frost, Rainbow), size control (1-10), and collection tracking.

---

## 📖 Description

The **Snowflake Catcher** component creates a magical snowflake catching experience where you collect unique snowflakes with your cursor. Built with vanilla HTML, CSS, and JavaScript, it features 4 collections (Classic, Crystal, Frost, Rainbow), size control (1-10), and collection tracking for a fun winter experience.

### 🎯 Core Features

- **Snowflake catching** – catch unique snowflakes with your cursor
- **4 collections** – Classic, Crystal, Frost, Rainbow
- **Size control** – adjust catcher size from 1-10
- **Unique snowflakes** – each snowflake has unique pattern
- **Collection tracking** – tracks number caught
- **Interactive controls** – slider, collection buttons, keyboard shortcuts
- **Responsive design** – adapts to different screen sizes

### ❄️ Collections

| Collection | Icon | Colors | Description |
|------------|------|--------|-------------|
| **Classic** | ❄️ | White/Silver | Classic snowflakes |
| **Crystal** | 💎 | Purple | Crystal snowflakes |
| **Frost** | 🌨️ | Green | Frost snowflakes |
| **Rainbow** | 🌈 | Multi-color | Rainbow snowflakes |

### ⌨️ Interaction Options

| Method | Action |
|--------|--------|
| **Mouse** | Move cursor to catch snowflakes |
| **Touch** | Drag on mobile to catch snowflakes |
| **Slider** | Adjust Size (1-10) |
| **Keyboard** | `R` – Reset |

### ✨ Snowflake Experience

When catching:
1. **Snowflakes fall** – unique snowflakes drift down
2. **Cursor catches** – move cursor to catch them
3. **Collection applies** – changes snowflake colors
4. **Size applies** – controls catcher radius
5. **Status updates** – shows current state

### 🛠️ Technologies Used

- **HTML5** – semantic structure with Canvas
- **CSS3** – gradients, backdrop-filter, transforms
- **JavaScript (ES6)** – Canvas API, requestAnimationFrame, particle system

### 🎨 Design Philosophy

This component embodies **EaseMotion CSS's animation-first philosophy** through:

- **Organic motion** – snowflakes fall naturally
- **Unique patterns** – each snowflake is different
- **Visual feedback** – status updates, counter, controls
- **Magical atmosphere** – snowflakes and collections
- **Human-readable classes** – `.catcher-controls`, `.collection-btn`, `.catcher-text`

### 🔧 Customization Options

| Property | Location | Default |
|----------|----------|---------|
| Collections | `collections` object | 4 collections |
| Size range | `sizeSlider` | 1-10 |
| Snowflake count | `generateSnowflakes()` | 15-25 |
| Snowflake size | `size` | 5-17px |
