# CSS Diagonal Card Grid

Issue: #68364

## Description

A responsive CSS-only card grid where alternate cards are vertically
offset to create a diagonal visual pattern.

## Features

- Pure CSS
- Responsive layout
- Hover animation
- Keyboard accessible content
- Reduced-motion support
- No JavaScript dependencies

## Files

- `demo.html` - Demo markup
- `style.css` - Component styles

## Usage

Link the stylesheet and use the `.diagonal-grid` and `.card` classes
in your HTML.

## Accessibility

The component uses semantic `<article>` elements and supports
`prefers-reduced-motion`.

## Browser Support

Uses standard CSS Grid, transitions, and media queries supported
by modern browsers.
