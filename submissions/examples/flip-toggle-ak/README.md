# flip-toggle-ak

Pure CSS 3D flipping card toggle switch — no JavaScript required.

## How to use

```html
<label class="ease-flip-toggle">
  <input type="checkbox" />
  <span class="ease-flip-toggle-inner">
    <span class="ease-flip-toggle-front">OFF</span>
    <span class="ease-flip-toggle-back">ON</span>
  </span>
</label>

<!-- Color Variant -->
<label class="ease-flip-toggle ease-flip-toggle--emerald">...</label>
