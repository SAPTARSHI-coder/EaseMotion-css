# CSS Glitch-Flicker Carousel (Checkout)

A highly stylized, pure CSS carousel designed for E-Commerce Checkout Layouts, featuring an aggressive glitch/flicker entrance animation for switching cards.

## Features
- Pure CSS and HTML (No JavaScript required).
- State management handled purely through hidden radio buttons.
- Features `flicker-in` keyframe animations when active cards mount.
- Includes a continuous `glitch-anim` for typography with cyan and red text-shadow splitting.
- Modern dark-mode cyberpunk checkout styling.
- Fully responsive across all device sizes.
- Honors the `prefers-reduced-motion` accessibility standard by disabling flicker effects.

## Usage
Open `demo.html` in your browser. Click on the rectangular pagination indicators below the card to switch between different checkout options, watching the cards flicker into existence.

## Files
- `demo.html`: HTML structure for the checkout component utilizing radio buttons and glitch elements.
- `style.css`: Pure CSS styles containing the layout rules, `keyframes`, and glitch logic.
