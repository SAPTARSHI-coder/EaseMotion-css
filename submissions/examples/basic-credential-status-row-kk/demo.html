Basic Credential Status Row

Compact credential rows for verification and account panels.

This CSS-only utility aligns a credential marker, verification copy, helper text, and state label for profile and admin review sections.

ID
Identity verification

Government ID has been reviewed and approved.

Verified
EDU
Education proof

Student credential is waiting for manual review.

Review
ORG
Organization email

Workspace domain confirmation has not been completed.

Pending

HTML Usage

<div class="basic-credential-status-row">
  <span class="credential-marker" aria-hidden="true">ID</span>
  <div class="credential-copy">
    <strong>Identity verification</strong>
    <p>Government ID has been reviewed and approved.</p>
  </div>
  <span class="credential-state is-verified">Verified</span>
</div>
