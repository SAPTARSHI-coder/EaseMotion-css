# Animated Progress Bar (`ease-progress`)

A clean, responsive progress bar whose fill width animates smoothly using CSS transitions, featuring an optional shimmer/striped animation variant for active loading states.

## Features
- **CSS Custom Variable Control**: Set fill percentage easily via `--progress`.
- **Smooth Animation**: Transitions width smoothly on state changes.
- **Striped Shimmer Variant**: Optional looping linear-gradient keyframe effect for active progress.
