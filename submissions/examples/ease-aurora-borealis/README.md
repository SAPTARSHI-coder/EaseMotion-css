# 🌌 Aurora Borealis – Dancing Aurora Lights Ripple Across Screen

> A mesmerizing aurora borealis component where dancing lights ripple across the screen with 4 color palettes (Classic, Fire, Ice, Rainbow), intensity control (0-100%), and organic wave animation.

---

## 📖 Description

The **Aurora Borealis** component creates a mesmerizing northern lights experience where dancing lights ripple across the screen with organic wave motion. Built with vanilla HTML, CSS, and JavaScript, it features 4 color palettes (Classic, Fire, Ice, Rainbow), intensity control (0-100%), and organic wave animation for an immersive celestial experience.

### 🎯 Core Features

- **Aurora lights** – dancing lights ripple with organic wave motion
- **4 color palettes** – Classic (green/blue/purple/pink), Fire (red/orange/gold), Ice (blue/cyan), Rainbow (multi-color)
- **Intensity control** – adjust intensity from 0-100% affecting wave amplitude and glow
- **Wave system** – 3-7 waves with individual speed, amplitude, and phase
- **Star effects** – twinkling stars and mountain silhouettes
- **Wave counter** – tracks number of aurora waves
- **Interactive controls** – slider, palette buttons, keyboard shortcuts
- **Responsive design** – adapts to different screen sizes

| Method | Action |
|--------|--------|
| **Slider** | Adjust Intensity (0-100%) |
| **Buttons** | Palette selection |
| **Keyboard** | `R` – Reset |

### ✨ Aurora Experience

When interacting:
1. **Lights dance** – aurora waves ripple across the screen
2. **Intensity applies** – controls wave amplitude and glow
3. **Palette applies** – changes aurora colors
4. **Stars twinkle** – background stars add atmosphere
5. **Status updates** – shows current state

### 🛠️ Technologies Used

- **HTML5** – semantic structure with Canvas
- **CSS3** – gradients, backdrop-filter, transforms
- **JavaScript (ES6)** – Canvas API, requestAnimationFrame, wave system

### 🎨 Design Philosophy

This component embodies **EaseMotion CSS's animation-first philosophy** through:

- **Organic motion** – aurora waves ripple with natural movement
- **Wave effects** – multiple layers with individual properties
- **Visual feedback** – status updates, counter, controls
- **Atmospheric experience** – night sky, stars, mountain silhouettes
- **Human-readable classes** – `.aurora-controls`, `.palette-btn`, `.aurora-text`

### 🔧 Customization Options

| Property | Location | Default |
|----------|----------|---------|
| Palettes | `palettes` object | 4 palettes |
| Intensity range | `intensitySlider` | 0-100% |
| Wave count | `generateAurora()` | 3-7 |
| Wave speed | `speed` | 0.2-0.8 |
| Wave amplitude | `amplitude` | 20-80px |
