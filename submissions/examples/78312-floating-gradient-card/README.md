# Floating Card with Gradient Styling

A responsive floating card component featuring layered gradients,
depth effects, glowing accents, and smooth hover interactions.

## Features

- Floating 3D-inspired card appearance
- Gradient border treatment
- Layered shadow and depth effects
- Decorative glow elements
- Interactive hover animation
- Responsive mobile layout
- Keyboard focus state
- Reduced-motion accessibility support
- Pure HTML and CSS
- No JavaScript dependency

## Files

- `demo.html` — component markup and demonstration content
- `style.css` — complete component styling and responsive behavior

## Usage

Open `demo.html` directly in a browser to view the component.

The card content, badge, tags, and action link can be replaced with
project-specific content without changing the component structure.

## Responsive Behavior

The component adapts its spacing, typography, card dimensions,
and action controls for tablet and mobile screen sizes.
