# Glowing Glassmorphism Badge

A modern responsive badge component created using pure HTML and CSS.

The component combines glassmorphism, animated glow effects, and a status indicator to create a polished SaaS-style UI element.

## ✨ Features

- Pure HTML and CSS
- No JavaScript required
- Glassmorphism effect
- Animated glowing border
- Animated status indicator
- Hover interaction
- Animated shine effect
- Responsive design
- Mobile friendly
- Accessible status label
- Reduced-motion support
- Lightweight implementation
