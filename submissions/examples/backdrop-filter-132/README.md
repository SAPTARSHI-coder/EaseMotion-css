# Spotlight Cursor Following Search Input Bar

A modern neumorphic search input component featuring a cursor-following
spotlight, backdrop blur, keyboard shortcut, interactive suggestions,
and responsive mobile-first styling.

## Features

- Cursor-following spotlight effect
- Neumorphic search interface
- Backdrop-filter blur
- Search suggestions
- Clear search button
- `Ctrl + K` / `Cmd + K` keyboard shortcut
- Escape key support
- Responsive mobile layout
- Reduced-motion accessibility support
- Vanilla HTML, CSS and JavaScript
- No external dependencies
