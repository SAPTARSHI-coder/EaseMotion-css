# Animated Carousel — Minimalist

A responsive CSS-only animated carousel with a clean minimalist design.

## Features

- CSS-only animation
- Responsive
- Horizontal scrolling
- Hover interaction
- Scroll snap
- Reduced-motion support
- No JavaScript
- No dependencies
