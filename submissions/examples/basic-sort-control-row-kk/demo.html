Basic Sort Control Row

Compact sort rows for table and filter panels.

A CSS-only row component for showing sort options, active state, direction, and helper text inside lists, tables, and dashboards.

DT
Date created

Show newest records first

Desc Active
AZ
Name

Sort items alphabetically

Asc Available
HI
Priority

Bring urgent items to the top

Desc Priority

HTML Usage

<article class="basic-sort-control-row is-active">
  <span class="sort-icon is-date" aria-hidden="true">DT</span>
  <div class="sort-copy">
    <strong>Date created</strong>
    <p>Show newest records first</p>
  </div>
  <span class="sort-direction">Desc</span>
  <span class="sort-state is-active">Active</span>
</article>
