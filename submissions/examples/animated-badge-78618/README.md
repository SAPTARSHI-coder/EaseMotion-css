# Animated Badge

Responsive Material Design inspired badge showcase for issue #78618.

## Structure

- `demo.html` — semantic badge examples.
- `style.css` — responsive styling and animation states.

## Features

- Compact status and notification badges.
- Material-inspired elevation and spacing.
- Hover and keyboard focus states.
- Responsive sizing.
- Reduced-motion support.
- No JavaScript dependency.

## Usage

Open `demo.html` in a browser. Replace the sample labels and counts with application data while keeping the semantic structure and accessible labels.

## Accessibility

Interactive badges use native links or buttons and include visible keyboard focus. Motion is disabled when the user prefers reduced motion.
