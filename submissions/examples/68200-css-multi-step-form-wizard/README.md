# CSS Multi-step Form Wizard

## Overview

A multi-step form wizard built as a pure HTML and CSS EaseMotion example. It presents a clear progression through form steps with progress indicators, grouped fields, validation-style states, and responsive layouts.

## Features

- Multi-step progress indicator
- Grouped form sections
- Active and completed step states
- Responsive form layout
- Hover and keyboard focus states
- CSS-only presentation
- Reduced-motion support

## Files

- `demo.html` — semantic form wizard structure and sample fields
- `style.css` — layout, step indicator, field states, responsive behavior, and motion

## Usage

Open `demo.html` in a modern browser. The example has no external dependencies and requires no build process.

## Accessibility

The form uses semantic controls with visible focus states. The stylesheet also honors `prefers-reduced-motion` so animation is minimized when requested by the operating system.
