# CSS Hover Pagination

A demo project showcasing **animated pagination buttons** with hover effects.

## Features
- Pagination links styled as buttons.
- Gradient hover animation sliding in from the left.
- Active page highlighted with neon glow.
- Smooth transitions for modern UI.

## Files
- `demo.html` → Structure with pagination links.
- `style.css` → Styling and hover animations.
- `README.md` → Documentation and usage instructions.

## Usage
1. Open `demo.html` in your browser.
2. Hover over pagination buttons to see the animated gradient effect.
3. Customize colors, sizes, and active states for your own project.

## Customization Ideas
- Add icons (◀ ▶) for previous/next navigation.
- Use CSS variables for easy theme swapping.
- Integrate with JavaScript to dynamically update active page.
- Extend into a full pagination component for blogs or dashboards.
