# Ease Gimbal Gyro Stabilize

A CSS-only animated gimbal gyro stabilization component.

## Feature

- Three-axis gimbal motion simulation
- Smooth CSS keyframe animations
- Real-world control panel UI
- Responsive design
- No JavaScript required
- Reduced motion accessibility support


## Usage

Include:

```html
<div class="ease-gimbal-gyro-stabilize">
</div>
