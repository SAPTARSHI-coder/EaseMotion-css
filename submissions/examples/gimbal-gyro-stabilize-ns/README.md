# Gimbal Gyro Stabilize

## What does this do?
Renders a self-contained CSS-only `ease-gimbal-gyro-stabilize` demo: Three-axis gimbal keeping a platform level.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-gimbal-gyro-stabilize`. No build step or JavaScript is required for the effect.

```html
<section class="ease-gimbal-gyro-stabilize">
  <div class="ease-gimbal-gyro-stabilize__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
