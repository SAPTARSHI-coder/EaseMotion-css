# 3D-Flip Drawer

A modern **CSS-only 3D Flip Drawer** for gaming dashboards and application layouts. The navigation panel flips into view using a smooth 3D perspective animation, creating an immersive experience without any JavaScript.

---

## 📂 Folder Structure

```
3d-flip-drawer/
│── demo.html
│── style.css
└── README.md
```

---

## ✨ Features

- 🎮 Gaming Hub inspired UI
- 🔄 Smooth 3D Flip drawer animation
- 💯 Pure HTML & CSS
- 🚫 No JavaScript required
- 📱 Fully responsive
- ♿ Supports `prefers-reduced-motion`
- 🎨 CSS Custom Properties
- ⚡ Lightweight and easy to customize

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/SAPTARSHI-coder/EaseMotion-css.git
```

Open the example folder:

```
submissions/examples/3d-flip-drawer/
```

Launch:

```
demo.html
```

using any modern web browser.

    --secondary:#00d4ff;

## ♿ Accessibility

Supports:

```css
@media (prefers-reduced-motion: reduce)
```

to disable animations for users who prefer reduced motion.

## 🎯 Animation

The drawer combines:

- Perspective Transform
- RotateY Flip Effect
- Smooth Cubic-Bezier Transition
- Opacity Transition

This creates a polished 3D navigation drawer suitable for modern gaming dashboards and application interfaces.
