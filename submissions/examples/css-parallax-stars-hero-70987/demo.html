Cosmic Parallax

Pure CSS 3D parallax effect on scroll. No JavaScript required. Experience true depth with layered performance-optimized transforms.

Below the Fold

The stars scroll at different speeds to create a depth illusion, known as the parallax effect. By utilizing the perspective property on the container and translateZ on the layers, the browser inherently handles the scroll speeds based on the 3D position of the elements. This is vastly more performant than listening to scroll events in JavaScript.
