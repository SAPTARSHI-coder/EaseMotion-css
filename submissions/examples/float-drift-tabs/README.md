# CSS Float-Drift Tabs

A lightweight tab component featuring a subtle floating drift animation for creative portfolio layouts.

## Features

- Pure HTML & CSS
- Float drift hover animation
- Responsive layout
- CSS-only tab switching
- Accessible with `prefers-reduced-motion`
- No JavaScript required

## Files

```
demo.html
style.css
README.md
```

## Usage

Open `demo.html` in any modern browser.

## Customization

- Tab colors
- Animation duration
- Border radius
- Typography
- Layout width

## Browser Support

Compatible with all modern browsers supporting CSS animations and transitions.
