# 🛰️ Signal Bloom

Signal Bloom is an interactive communication signal visualization
built with vanilla HTML, CSS, and JavaScript.

Click the central transmitter to send a signal. The signal expands as
concentric rings and produces a bloom of particles before fading into
the environment.

## Features

- Central signal transmitter
- Expanding signal rings
- Particle bloom
- Signal strength control
- Multiple signal frequencies
- Transmission counter
- Frequency-reactive animation speed
- Keyboard-accessible transmitter
- Clear functionality
- Responsive design
- Smooth CSS animations
- No external dependencies
