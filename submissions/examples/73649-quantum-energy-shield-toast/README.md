# Quantum Energy Shield Toast

A futuristic notification toast featuring a quantum energy shield
visual effect using pure HTML and Vanilla CSS.

## Features

- Animated quantum energy shield
- Multiple rotating energy rings
- Pulsing energy core
- Floating energy particles
- Soft cyan energy glow
- Smooth entrance animation
- Subtle hover elevation
- Dark mode support
- Light mode support
- Responsive design
- Accessible notification semantics
- Keyboard focus support
- Reduced-motion support
- No JavaScript or external dependencies

## Preview

The component presents a notification protected by a layered
quantum energy field. Rotating shield rings, a pulsing energy core,
and floating particles create the futuristic shield effect.
