# CSS Accordion: Metallic Sheen Variation

A premium accordion component featuring a metallic sheen effect, animated reflective gradients, and smooth content reveal transitions built entirely with HTML and CSS.

## Features

- Pure HTML & CSS
- Metallic sheen animated surface
- Smooth accordion expansion
- Responsive design
- Accessible native `<details>` implementation
- Dark mode friendly
- Hardware accelerated animations

## Files

- demo.html
- style.css

## Usage

```html
<details class="accordion">
    <summary>Accordion Title</summary>
    <div class="content">
        Accordion content here.
    </div>
</details>
