# Ease Action Chip

## What does this do?

A compact chip containing an icon and action label for quick interface actions.

---

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<button class="action-chip">
    <span class="action-icon">+</span>
    <span>Add Item</span>
</button>
```

### Features

- Icon support
- Action label
- Rounded design
- Hover animation
- Click feedback
- Responsive layout
- Lightweight and reusable

---

## Why is it useful?

Action chips are useful for quick actions such as adding items, sharing content, downloading files, or triggering other common interface actions.

This component provides a simple reusable action pattern with subtle interaction feedback while following the animation-first philosophy of EaseMotion CSS.
