# CSS Fade-In Progress Bar for Fintech Dashboard Layouts

A lightweight fintech dashboard showcase featuring animated CSS
Fade-In Progress Bars.

The progress indicators combine opacity, vertical movement, horizontal
scaling and a subtle highlight sweep to create a smooth entrance effect.

## Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Fade-in progress animation
- Smooth upward entrance
- Horizontal scale reveal
- Subtle highlight sweep
- CSS custom properties
- Responsive dashboard layout
- Fintech-focused UI
- Semantic HTML
- ARIA progressbar support
- Reduced-motion support
- Desktop, tablet and mobile layouts
