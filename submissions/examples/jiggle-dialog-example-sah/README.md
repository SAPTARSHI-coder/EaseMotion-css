# Jiggle Dialog Notification Example (`#54668`)

## What does this do?
Provides an attention-demanding jiggling kinetic dialog box entrance designed to instantly signify important confirmation steps or error checks.

## How is it used?
Attach `ease-dialog-jiggle` directly to modal dialogue containers:
```html
<div class="ease-dialog-jiggle">
  <h3>Critical Confirmation</h3>
</div>
```

## Why is it useful?
Solves issue #54668 by delivering intuitive physical feedback that ensures users never miss critical warning overlays.
