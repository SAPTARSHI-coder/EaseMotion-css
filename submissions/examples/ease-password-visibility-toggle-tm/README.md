# Password Visibility Toggle Component

**Issue:** [#71854](https://github.com/SAPTARSHI-coder/EaseMotion-css/issues/71854)

Password input with eye icon toggle using pure CSS.

## Design Tokens

| Token | Default |
|-------|--------|
| `--pv-focus` | `#6366f1` |
| `--pv-radius` | `10px` |
| `--pv-shadow` | `0 4px 20px rgba(99,102,241,.2)` |

## Note

Eye button needs a tiny JS click handler to toggle `type`.
