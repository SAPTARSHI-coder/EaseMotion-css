Smooth CSS Accordion

High-performance accordion component featuring smooth grid-template-rows height transitions with zero JavaScript.

What is EaseMotion CSS? +

EaseMotion CSS is a human-readable, animation-first CSS framework with a zero-config motion engine. It requires zero external dependencies and prioritizes 60fps GPU compositor performance.

How does smooth height transition work without JS? +

Modern CSS supports animating grid-template-rows: 0fr to grid-template-rows: 1fr. This enables smooth height expansion for dynamic text without hardcoding max-height pixel values.

Is it accessible and reduced-motion compliant? +

Yes! Native <details> elements provide complete keyboard navigation support, and `@media (prefers-reduced-motion)` automatically removes animations for users requiring reduced motion.
