# CSS Elastic-Slide Stepper for SaaS Showcase Layouts

A modern **Elastic-Slide Stepper** built using pure HTML5 and CSS3 for SaaS showcase layouts. This component creates a smooth step-based journey experience with elastic sliding transitions, animated indicators, and a responsive SaaS interface.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Elastic sliding step transitions
* Spring-like CSS animation effects
* SaaS workflow showcase component
* Animated step navigation controls
* Floating feature icons
* Glassmorphism container design
* Smooth CSS transitions and keyframe animations
* Responsive layout for desktop, tablet, and mobile
* CSS Custom Properties for easy customization
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Click the numbered step buttons to move through the SaaS journey.
3. Experience the elastic sliding transition between steps.
4. Customize colors, spacing, shadows, and animation values using CSS variables inside `:root`.
