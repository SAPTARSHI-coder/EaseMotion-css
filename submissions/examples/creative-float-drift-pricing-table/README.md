# CSS Float-Drift Pricing Table for Creative Portfolio Layouts

A modern **Creative Portfolio Pricing Table** built entirely with **HTML5 and CSS3**. This showcase demonstrates elegant **Float-Drift** card animations with glassmorphism styling, responsive layouts, and accessibility-friendly interactions without requiring JavaScript.

---

## ✨ Features

- 🎨 Creative Portfolio inspired pricing cards
- 🎈 Float-Drift animation
- ✨ Smooth hover interactions
- 🌈 Gradient CTA buttons
- 🪟 Glassmorphism cards
- 📱 Fully responsive
- ⚡ Pure HTML5 & CSS3
- 🎯 CSS Custom Properties
- ♿ `prefers-reduced-motion` support
- 🚀 No JavaScript required

## 🚀 Getting Started

1. Open `demo.html` in any modern browser.
2. Watch the floating pricing cards animate smoothly.
3. Hover over the cards for enhanced visual effects.
4. Customize colors, spacing, and animations using CSS variables.
