# Typing Dots Loader

1. What does this do? Creates a chat-style typing indicator featuring three sequentially bouncing dots paired with a blinking terminal-style caret line.
2. How is it used? Apply `.typing-loader` to a container `div` and place three `span.dot` elements inside it.
3. Why is it useful? Loading states are ubiquitous in modern web applications. A chat-style typing loader adds a human, conversational feel to loading times, while achieving the effect smoothly entirely in CSS keeps the application highly performant.
