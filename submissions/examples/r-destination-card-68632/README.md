# CSS Destination Card

A responsive travel destination card built with pure HTML
and CSS.

## Features

- Pure CSS implementation
- No JavaScript required
- Responsive destination card
- Full-bleed destination image
- Image overlay
- Location pin
- Featured badge
- Rating badge
- Destination title and description
- Animated image zoom on hover
- Animated location marker
- CTA interaction
- Keyboard focus support
- Reduced-motion support
