# Elastic Spring Pop Bounce

A reusable CSS keyframe animation utility that creates an elastic spring-like pop and bounce effect.

## Features

- Smooth elastic spring motion
- Pop and bounce effect
- Uses `transform` and `opacity`
- Configurable duration and timing
- Supports `prefers-reduced-motion`
- No JavaScript required
- Lightweight and reusable

## Usage

Apply the animation class to any element:

```html
<div class="ease-anim-elastic-spring-pop-bounce">
  Content
</div>
