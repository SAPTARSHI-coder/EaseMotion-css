# Ease Icon Button

## What does this do?

A reusable circular icon button with hover lift and active press animations, suitable for toolbars, floating action buttons, and navigation controls.

---

## How is it used?

Open `demo.html` in any modern browser.

Example:

```html
<button class="icon-button">
    ★
</button>
```

### Features

- Circular icon button
- Hover lift animation
- Active press effect
- Multiple color variants
- Responsive layout
- Lightweight and reusable

---

## Why is it useful?

Icon buttons are widely used in toolbars, floating action buttons, navigation menus, and dashboards. This component provides a clean, reusable, animation-first interaction that aligns with the EaseMotion CSS philosophy.
