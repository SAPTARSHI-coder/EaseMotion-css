# Ease Icon Button

## What does this do?

A compact button containing only an icon, with multiple sizes, hover animation, focus styling, and accessible labels.

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<button class="icon-button" aria-label="Settings">
    ⚙
</button>
```

### Available sizes

Small:

```html
<button class="icon-button small" aria-label="Search">
    ⌕
</button>
```

Default:

```html
<button class="icon-button" aria-label="Settings">
    ⚙
</button>
```

Large:

```html
<button class="icon-button large" aria-label="Add">
    +
</button>
```

### Features

- Icon-only button
- Multiple sizes
- Hover animation
- Active state
- Keyboard focus state
- Accessible `aria-label` support
- Responsive sizing
- Pure CSS
- No JavaScript required

## Why is it useful?

Icon buttons are commonly used in toolbars, navigation interfaces, compact controls, dashboards, and application actions where space is limited.

This component provides a simple and reusable icon-only button with clear interaction feedback while following the animation-first philosophy of EaseMotion CSS.
