# Ease Highlighter Tool

A modern and responsive text highlighter component built using **HTML**, **CSS**, and **JavaScript**. It allows users to highlight selected text with multiple colors, remove highlights, clear all highlights, and copy the editor content.

## Features

- Highlight selected text with multiple colors
- Four built-in highlight colors
- Remove text formatting/highlights
- Clear all highlights
- Copy editor content to clipboard
- Responsive design
- Glassmorphism-inspired interface
- Smooth hover animations
- Editable text area

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)

## Usage

1. Open `index.html` in any modern web browser.
2. Select any text inside the editor.
3. Click a highlight color to apply it.
4. Use **Remove Highlight** to remove formatting.
5. Use **Clear All** to remove every highlight.
6. Click **Copy Text** to copy the editor content.
