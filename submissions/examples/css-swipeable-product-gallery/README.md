# CSS Swipeable Product Gallery

A responsive swipeable product image gallery built with HTML and CSS.

## Features

- Horizontal touch scrolling
- CSS scroll snapping
- Navigation dots
- Responsive design
- Keyboard focus support
- Accessible image alt text
- Reduced-motion support
- No JavaScript required

## Files

- `demo.html` — Gallery demonstration
- `style.css` — Component styling

## Usage

Open `demo.html` in a modern browser.

On mobile devices, swipe horizontally between product images.

The navigation dots can also be used to jump between slides.

## Accessibility

The gallery includes:

- Semantic `main`, `section`, `figure`, and `nav` elements
- Descriptive image `alt` text
- Keyboard-focusable gallery area
- Accessible navigation labels
- `prefers-reduced-motion` support

## Browser Support

Works in modern browsers that support:

- CSS Scroll Snap
- CSS Flexbox
- `prefers-reduced-motion`
- Smooth scrolling
