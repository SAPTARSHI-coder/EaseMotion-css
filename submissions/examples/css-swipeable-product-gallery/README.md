# CSS Swipeable Product Gallery (#70954)

Mobile-first swipeable product image gallery with active dot pagination built entirely with CSS.

## Features
- **Touch & Mouse Swipe:** Driven by native `scroll-snap-type: x mandatory` and `scroll-snap-align: start` for smooth swipe performance.
- **Dot Indicators:** Radio button state synced with CSS `:checked` selectors and custom labels for active slide indicators.
- **Pure CSS Solution:** Zero JavaScript required for layout, snapping, transitions, or navigation.
- **Accessible & Responsive:** Screen-reader friendly radio group labels, keyboard focus support, and flexible max-width container sizing.

## Structure
- `style.css` - Component variables, scroll snap layout, hide scrollbars, and pagination styles.
- `demo.html` - Complete interactive demo featuring SVG product mock views and dot controls.
