# CSS Scale-Hover Modal for Product Catalog Layouts

A modern, responsive product catalog modal built using pure HTML and CSS. The modal smoothly scales into view while the trigger button features a subtle hover-scale animation for an engaging user experience.

## Features

- Pure HTML5 & CSS3
- Scale-hover modal animation
- Smooth transitions
- Fully responsive layout
- Modern product card design
- CSS Custom Properties for easy customization
- No JavaScript required
- Accessible with `prefers-reduced-motion` support
