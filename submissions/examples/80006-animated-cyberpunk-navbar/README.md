# Animated Cyberpunk Navbar

A responsive animated navigation bar inspired by futuristic cyberpunk interfaces.

## Features

- Fully responsive navigation
- Cyberpunk-inspired neon styling
- Cyan and pink glow effects
- Animated navigation underline
- Mobile hamburger menu
- CSS-only mobile menu interaction
- Animated system status indicator
- Responsive hero section
- Hover and focus-friendly interactions
- Reduced-motion support
- No external dependencies

## Files

- `demo.html` - Component markup and demo page
- `style.css` - Complete styling and animations

## Usage

<link rel="stylesheet" href="style.css">
