# CSS Rotate-Fade Navbar for E-Commerce Checkout Layouts

A modern **Rotate-Fade Navbar** built using pure HTML and CSS. The navigation bar features elegant rotate-fade hover animations, premium glassmorphism styling, responsive layouts, and lightweight interactions suitable for e-commerce checkout pages.

## ✨ Features

- Pure HTML5 & CSS3
- Rotate-fade hover animation
- Glassmorphism navbar
- Responsive checkout layout
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
