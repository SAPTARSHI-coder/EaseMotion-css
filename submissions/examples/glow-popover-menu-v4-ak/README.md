# glow-popover-menu-v4-ak

Pure CSS animated glowing popover menu component — no JavaScript required.

## How to use

```html
<div class="ease-popover-wrapper-v4">
  <button class="ease-popover-trigger-v4">Options</button>

  <ul class="ease-popover-menu-v4">
    <li class="ease-popover-item-v4"><a href="#">Item 1</a></li>
    <li class="ease-popover-item-v4"><a href="#">Item 2</a></li>
  </ul>
</div>
