# Material Design Animated Card

A responsive animated card component inspired by Material Design principles.

## Features

- Material-inspired elevation
- Smooth hover animation
- Animated visual element
- Light sweep interaction
- Three visual card variations
- Responsive CSS Grid layout
- Accessible semantic markup
- Keyboard-visible focus state
- Reduced-motion support
- Pure HTML and Vanilla CSS
- No external dependencies

## Files

- `demo.html`
- `style.css`

## Usage

Open `demo.html` directly in a browser.

The component can be reused by copying the `.material-card`
markup and related CSS styles into another project.

## Technologies

- HTML5
- Vanilla CSS

## Accessibility

The cards use semantic `<article>` elements, descriptive links,
focus-visible states, and `prefers-reduced-motion` support.

## Responsive Behavior

- Desktop: three-column layout
- Tablet: two-column layout
- Mobile: single-column layout
