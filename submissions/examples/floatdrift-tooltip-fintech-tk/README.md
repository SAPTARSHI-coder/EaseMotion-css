# Float-Drift Tooltip (Fintech Dashboard)

## What does this do?

A modern fintech dashboard tooltip component featuring a gentle floating animation that reveals additional financial insights on hover. Built entirely with HTML and CSS.

---

## Features

- Float-drift tooltip animation
- Glassmorphism tooltip design
- Soft fintech blue color palette
- Hover-triggered interaction
- Responsive layout
- Pure HTML & CSS (No JavaScript)
- Supports `prefers-reduced-motion`

---

## Files

- `demo.html` — Component showcase
- `style.css` — Component styling and animations
- `README.md` — Documentation
