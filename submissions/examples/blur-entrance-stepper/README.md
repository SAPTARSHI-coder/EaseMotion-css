# CSS Blur-Entrance Stepper

A responsive stepper component featuring a smooth blur entrance animation for creative portfolio layouts.

## Features

- Pure HTML & CSS
- Blur entrance animation
- Responsive layout
- CSS Custom Properties
- Lightweight
- Accessible with `prefers-reduced-motion`

## Folder Structure

```
blur-entrance-stepper/
├── demo.html
├── style.css
└── README.md
```

## Usage

```html
<div class="step active">
    <div class="circle">1</div>
    <span>Plan</span>
</div>
```

Include:

```html
<link rel="stylesheet" href="style.css">
```
