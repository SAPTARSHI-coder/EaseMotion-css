# Text Aurora Shift

Aurora ribbons drift across dark lettering in a slow color shift.

## Features
- Aurora ribbon gradient
- Slow drift shift
- Dark glossy lettering
- Pure CSS

## Usage
```html
<h1 class="tas-text">AURORA</h1>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
