# Cyberpunk Neon Card Grid

A modern **CSS Zoom-In Card Grid** inspired by cyberpunk interfaces with glowing neon accents, smooth hover animations, and responsive layouts.

This example is built entirely with **HTML5** and **CSS3**—no JavaScript required.

---

## Features

- Responsive CSS Grid layout
- Smooth zoom-in hover animation
- Neon cyan & magenta glow effects
- Glassmorphism-inspired card design
- Animated glowing border
- Pure HTML & CSS
- CSS Custom Properties
- `prefers-reduced-motion` support
- Mobile friendly

---

## Usage

1. Open `demo.html` in a modern web browser.
2. Hover over any card to view the zoom and neon glow animation.
3. Customize colors using the CSS variables defined in `:root`.
