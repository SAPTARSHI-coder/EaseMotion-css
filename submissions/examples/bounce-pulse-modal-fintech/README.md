# CSS Bounce-Pulse Modal for Fintech Dashboard

A modern fintech dashboard showcase featuring a CSS-only Bounce-Pulse Modal.

The component uses pure HTML and CSS without JavaScript or external
frameworks.

## Features

- CSS-only modal interaction
- Bounce entrance animation
- Pulse-ring animation
- Smooth transitions
- Responsive dashboard
- Responsive modal
- Fintech dashboard styling
- CSS custom properties
- Accessible dialog semantics
- Reduced-motion support
- No JavaScript dependencies
- No external UI frameworks
