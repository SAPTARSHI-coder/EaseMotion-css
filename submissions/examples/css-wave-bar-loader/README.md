# CSS Wave Bar Loader

A lightweight CSS-only wave bar loader made with five animated bars.

## Features

- Pure CSS animation
- Five bars moving in a synchronized wave pattern
- No JavaScript required
- Responsive design
- Supports light and dark color schemes
- Uses CSS custom properties for easy theming
- Accessible loading status
- Works by opening `demo.html` directly in a browser

## Usage

Add the loader markup to your HTML:

```html
<div class="wave-loader" role="status" aria-label="Loading">
  <span class="wave-bar"></span>
  <span class="wave-bar"></span>
  <span class="wave-bar"></span>
  <span class="wave-bar"></span>
  <span class="wave-bar"></span>
</div>
