# Floating Hero Section — Minimalist

A clean, responsive Floating Hero Section created for EaseMotion CSS.

The component uses minimalist typography, generous whitespace,
subtle monochrome surfaces, floating cards, and restrained motion
to create a focused hero experience.

## Features

- Minimalist visual design
- Floating hero composition
- Responsive navigation
- Responsive hero layout
- Large editorial typography
- Monochrome design tokens
- Floating project preview
- Abstract CSS artwork
- Floating information cards
- Availability indicator
- Subtle background grid
- Decorative floating orbs
- Hover elevation interactions
- Smooth CTA interactions
- Keyboard-visible focus states
- `prefers-reduced-motion` support
- Pure HTML and CSS
- Zero external JavaScript dependencies
- No external assets required
