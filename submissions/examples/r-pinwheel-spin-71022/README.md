# CSS Pinwheel Spin Animation

A colorful pinwheel that continuously spins using pure CSS animation, creating the visual effect of a pinwheel moving in the wind.

## Features

- Pure CSS implementation
- Four colorful pinwheel blades
- Continuous 360-degree rotation
- Wind-inspired background effects
- Animated status indicator
- Responsive across screen sizes
- Reduced-motion support
- No JavaScript required

## Files

- `demo.html` — Interactive pinwheel demonstration
- `style.css` — Pinwheel structure, styling, and animations
- `README.md` — Feature documentation

## Usage

The pinwheel is constructed from CSS elements:

```html
<div class="pinwheel" role="img" aria-label="Animated colorful spinning pinwheel">
  <div class="blade blade-one"></div>
  <div class="blade blade-two"></div>
  <div class="blade blade-three"></div>
  <div class="blade blade-four"></div>
  <div class="hub"></div>
</div>
