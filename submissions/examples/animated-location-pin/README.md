# CSS Animated Location Pin

A location pin built with **EaseMotion CSS**. It's features are smooth drop-and-bounce entrance animation, an animated landing shadow, and an interactive hover effect — with absolutely no JS.

## ✨ Features

- **No JS used**: Pure HTML and CSS implementation.
- **Drop and bounce animation**: The location pin drops into position and smoothly bounces before settling.
- **shadow**: A soft shadow animates beneath the pin as it lands.
- **Hover response**: The pin slightly zooms out when hovered for an interactive experience.
- **Responsive design**: The pin adapts to different screen sizes.
- **Keyboard accessible**: Uses a native `<button>` element with an accessible label and visible focus state.
- **Reduced motion**: Respects the user's `prefers-reduced-motion` settings.
