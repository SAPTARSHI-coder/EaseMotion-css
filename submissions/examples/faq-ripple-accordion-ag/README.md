# FAQ Ripple Accordion

A modern **Accordion-Style Interactive FAQ** built with semantic HTML and pure CSS. The component features smooth grid-based height expansion, rotating chevrons, category badges, and a ripple feedback effect without JavaScript.

---

## ✨ Features

- Pure HTML5 & CSS3
- Semantic `<details>` and `<summary>`
- Grid-based accordion animation (`grid-template-rows`)
- Ripple click feedback
- Chevron rotation animation
- Category pill badges
- Responsive layout
- CSS Custom Properties
- `prefers-reduced-motion` support
- No JavaScript required
