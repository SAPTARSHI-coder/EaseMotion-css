# Solar Flare Radial Bento Card

A futuristic bento grid component inspired by solar flares,
radial light and space interfaces.

This component is built entirely with HTML and Vanilla CSS.

## Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Solar flare radial visual effects
- Responsive bento grid
- Smooth hover transitions
- Animated solar glow
- Energy indicator
- Temperature visualization
- Status indicator
- Radial orbit animation
- Dark mode compatible
- Hardware-friendly CSS animations
- Reduced-motion accessibility support
