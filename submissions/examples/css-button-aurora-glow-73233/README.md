# CSS Button - Aurora Glow

A modern Aurora Glow button built entirely with HTML and CSS. The component features animated gradient lighting, glowing shadows, and smooth interactions while remaining lightweight and accessible.

## Features

- Pure HTML & CSS
- Aurora Glow styling
- Animated gradient glow effect
- Smooth hover interactions
- Keyboard accessible
- Responsive design
- Dark mode friendly
- Hardware accelerated animations
- No JavaScript required

## Usage

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

Use the button:

```html
<button class="aurora-btn">
  Aurora Glow
</button>
```

## Why it fits EaseMotion CSS

This component provides a reusable animation-first button pattern that combines visual appeal with performance. It follows EaseMotion CSS principles by being lightweight, accessible, and dependency-free.
