# Glitch-Flicker Badge

A lightweight, responsive CSS Glitch-Flicker Badge designed for fintech dashboard interfaces.

## Features

- Pure HTML and CSS
- No JavaScript or external dependencies
- Subtle glitch and flicker animation
- Animated status indicator
- Responsive on desktop, tablet, and mobile
- CSS custom properties for easy customization
- Supports `prefers-reduced-motion`
- Suitable for live transaction, payment, system, or account status indicators
