# CSS Button: Minimalist Outline Variation

A clean, responsive, CSS-only button collection featuring a minimalist
outline visual style.

## ✨ Features

- Pure HTML and Vanilla CSS
- Multiple button variants
- Smooth hover transitions
- Subtle elevation on interaction
- Border and background transitions
- Responsive layout
- Keyboard-friendly native buttons
- Visible focus states
- Dark-mode compatible styling
- Reduced-motion support
- No external dependencies

## 🎨 Variations

The demo includes:

- Primary
- Secondary
- Success
- Warning
- Danger
- Ghost

Each button keeps the visual treatment lightweight while using its accent
color mainly through borders and hover backgrounds.
