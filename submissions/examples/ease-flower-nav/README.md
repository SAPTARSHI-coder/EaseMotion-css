# 🌸 Flower Nav – Petals Open Like a Blooming Flower

> A beautiful, organic navigation where petals open like a blooming flower on hover or click, creating a natural, garden-inspired effect.

---

## 📖 Description

The **Flower Nav** is a beautiful, organic navigation component where petals open like a blooming flower on hover or click. Eight petals radiate outward from a central button, each with a unique color and icon, creating a stunning, garden-inspired effect. The petals open with staggered delays, mimicking the natural unfolding of a flower.

The component uses CSS transforms and trigonometric positioning to arrange the petals in a circular pattern. Each petal has a unique angle and distance, and opens with a staggered delay for organic, natural motion. The center button morphs from a seedling to a close icon when open.

Perfect for nature-themed interfaces, garden websites, creative portfolios, and any application where you want to create a beautiful, organic navigation experience. The Flower Nav transforms a simple menu into a blooming, natural interaction.
