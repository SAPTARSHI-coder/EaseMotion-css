# Basic Section Container

## What it does

This submission creates a simple CSS-only section container utility for grouping related content inside a clean rounded surface.

## How to use it

Wrap any related content in the container class:

```html
<section class="basic-section-container">
  <h2>Section Title</h2>
  <p>Content goes here.</p>
</section>
```

## Why it fits EaseMotion CSS

It fits EaseMotion CSS because it is human-readable, composable, and useful across many interfaces. It works well in forms, dashboards, cards, settings pages, and content sections.

- Generic rounded section container utility
- Muted variation included in the demo
