# Glowing Toggle with Material Design Styling

A responsive toggle switch that combines Material Design principles with glowing active-state effects.

## Features

- Material Design inspired appearance
- Smooth toggle animation
- Glowing active state
- Fully responsive layout
- Pure HTML and CSS

## Files

- demo.html
- style.css

## Usage

Open `demo.html` in a browser.

## Customization

You can modify:
- Glow colors
- Toggle dimensions
- Animation speed
- Background and card styling
