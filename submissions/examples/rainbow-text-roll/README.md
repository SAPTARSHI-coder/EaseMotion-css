# Rainbow Text Roll

A headline whose letters cycle through the rainbow with a rolling gradient fill.

## Features
- Each letter picks a rainbow hue
- Gradient rolls across the whole line
- Hue shift keeps the colors alive

## Usage
```html
<h2 class="rr-text">COLOR YOUR WORLD</h2>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
