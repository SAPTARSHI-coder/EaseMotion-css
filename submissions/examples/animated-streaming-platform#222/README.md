## 📋 Issue Description

### Is your feature request related to a problem?
The `submissions/examples/` directory lacks a **video streaming platform** example that showcases hero banners, content carousels, progress indicators, and genre browsing. Streaming platforms like Netflix are among the most popular UI patterns.

### Describe the solution you'd like
I would like to add an **Animated Streaming Platform** example that demonstrates:
- **Hero banner**: Featured content with gradient overlay
- **Continue watching**: Progress bars showing completion
- **Trending row**: Ranked movie cards with hover overlays
- **Genre grid**: Color-coded category browsing
- **Staggered entrance**: Sequential reveal of sections

### Why is this useful?
Streaming platforms combine many UI patterns. This example will show developers how to:
1. Build hero banners with gradient overlays
2. Create content cards with hover play overlays
3. Implement progress indicators for watch status
4. Design genre browsing with color-coded categories
5. Compose a streaming interface with EaseMotion
