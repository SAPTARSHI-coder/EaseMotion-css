# CSS Skew-Active Tabs for Gaming Hub Layouts

A modern **Gaming Hub Tabs** component featuring **Skew-Active** animations built entirely with **HTML5 and CSS3**. This example demonstrates futuristic skewed navigation tabs with neon glow effects, glassmorphism styling, responsive layouts, and accessibility support—without requiring JavaScript.

---

## ✨ Features

- 🎮 Gaming Hub inspired interface
- ⚡ Skew-Active tab animation
- 🌈 Neon active tab highlight
- 🪟 Glassmorphism content panel
- ✨ Smooth hover interactions
- 📱 Fully responsive
- ⚙️ Pure HTML5 & CSS3 (No JavaScript)
- 🎯 CSS Custom Properties
- ♿ `prefers-reduced-motion` support
- 🚀 Lightweight and easy to customize

## 🚀 Getting Started

1. Open `demo.html` in your browser.
2. Explore the skewed gaming tabs.
3. Hover over tabs to view interactive effects.
4. Customize colors, spacing and animations using CSS variables.
