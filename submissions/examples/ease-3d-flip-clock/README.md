# 🕐 3D Flip Clock – Flips Like Old Clock Digits

> A nostalgic, retro 3D flip clock that displays the current time with digits flipping like an old mechanical clock.

---

## 📖 Description

The **3D Flip Clock** component creates a nostalgic, retro flip clock that displays the current time with digits flipping like an old mechanical clock. Each digit card flips with a 3D perspective animation, simulating the classic flip clock mechanism. The clock updates every second, with the seconds digits flipping in real-time.

The component uses CSS 3D transforms with `perspective` and `rotateX` animations to create the flip effect. Each digit card consists of top and bottom halves that flip independently, creating a realistic mechanical motion. The clock features a dark retro theme, blinking separators, and a vintage aesthetic.

Perfect for retro-themed websites, dashboards, countdown timers, and any application where you want a nostalgic, vintage time display. The 3D Flip Clock transforms a simple time display into a charming, interactive piece of nostalgia.
