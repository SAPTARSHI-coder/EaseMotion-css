# Ease Progress Bar

## What does this do?

A horizontal progress bar for displaying completion progress with animated filling and multiple sizes.

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<div class="progress-bar">
    <span class="progress-fill" style="width: 70%;"></span>
</div>
```

### Available sizes

```html
<div class="progress-bar small">
    <span class="progress-fill" style="width: 70%;"></span>
</div>

<div class="progress-bar">
    <span class="progress-fill" style="width: 70%;"></span>
</div>

<div class="progress-bar large">
    <span class="progress-fill" style="width: 70%;"></span>
</div>
```

### Features

- Percentage-based progress
- Animated progress fill
- Multiple sizes
- Responsive width
- Pure CSS
- No JavaScript required

## Why is it useful?

Progress bars are commonly used for uploads, tasks, onboarding flows, project completion, and other interfaces where users need visual feedback about progress.

This component provides a clean and reusable progress indicator with a smooth fill animation while following the animation-first philosophy of EaseMotion CSS.
