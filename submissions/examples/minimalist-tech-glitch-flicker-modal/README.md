# Glitch-Flicker Modal

A lightweight CSS/HTML modal effect designed for minimalist technology interfaces.

## Features

- Pure HTML and CSS
- Futuristic glitch-flicker entrance animation
- Scanline visual treatment
- Responsive modal layout
- CSS custom properties for easy customization
- Keyboard-focus friendly controls
- `prefers-reduced-motion` support
- No JavaScript or external dependencies
