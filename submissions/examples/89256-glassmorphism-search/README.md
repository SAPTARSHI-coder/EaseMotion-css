# Glassmorphism Search Bar Component

An interactive input search bar component featuring frosted glass styling and width-expansion focus transitions.

## Features
- **Glassmorphism Backdrop:** Translucent styling built using CSS `backdrop-filter`.
- **Focus Expansion:** Smooth 60fps width expansion and glow effect on active input focus.
- **Pure CSS:** Zero JavaScript dependencies.

## File Structure
- `demo.html` - Search input container and icon structure.
- `style.css` - Component styling and focus transition rules.
