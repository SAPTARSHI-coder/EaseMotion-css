# Absolute Zero Hero Header

## What does this do?

Absolute Zero is a futuristic, cinematic hero header that combines oversized typography, glass-like controls, an orbital visual system, ambient lighting, and CSS motion effects.

## How is it used?

Include `style.css` in the HTML page and place the hero markup inside the page body.

```html
<link rel="stylesheet" href="style.css">

<section class="absolute-zero-hero">
    <header class="hero-nav">
        <a href="#" class="hero-brand">
            <span class="brand-mark"></span>
            <span>ABSOLUTE<span>ZERO</span></span>
        </a>
    </header>

    <div class="hero-content">
        <p class="hero-eyebrow">
            A NEW STATE OF MOTION
        </p>

        <h1>
            <span class="title-outline">ENTER</span>
            <span class="title-solid">THE</span>
            <span class="title-accent">ZERO.</span>
        </h1>
    </div>
</section>
