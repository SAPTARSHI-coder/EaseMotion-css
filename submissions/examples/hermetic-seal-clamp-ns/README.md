# Hermetic Seal Clamp

## What does this do?
Renders a self-contained CSS-only `ease-hermetic-seal-clamp` demo: Lab hermetic clamp sealing a vacuum flange.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-hermetic-seal-clamp`. No build step or JavaScript is required for the effect.

```html
<section class="ease-hermetic-seal-clamp">
  <div class="ease-hermetic-seal-clamp__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
