# Ease Hermetic Seal Clamp

A CSS-only animated laboratory hermetic seal clamp that demonstrates the
mechanical sealing of a vacuum flange.

The component uses pure HTML and CSS to create a recognizable laboratory
equipment control with animated clamp arms, vacuum pressure, a sealing ring,
status indicators, and a control dial.

## Features

- Pure HTML and CSS
- No JavaScript required
- Laboratory vacuum flange visual
- Animated clamp arms
- Hermetic sealing animation
- Vacuum pressure gauge
- Animated control dial
- Status indicators
- Responsive design
- CSS custom properties
- `prefers-reduced-motion` support
