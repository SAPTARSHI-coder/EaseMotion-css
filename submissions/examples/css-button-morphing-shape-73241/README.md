# CSS Button - Morphing Shape

A modern Morphing Shape button built entirely with HTML and CSS. The component dynamically changes its shape through animated border-radius transitions, creating a unique interactive effect while maintaining accessibility and performance.

## Features

- Pure HTML & CSS
- Morphing Shape styling
- Animated shape transformation
- Smooth hover interactions
- Responsive design
- Keyboard accessible
- Dark mode compatible
- Hardware accelerated transitions
- No JavaScript required

## Usage

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

Use the button:

```html
<button class="morph-btn">
  Explore
</button>
```

## Why it fits EaseMotion CSS

This component embraces EaseMotion CSS's animation-first philosophy by transforming a standard button into a dynamic interactive element using only CSS transitions and shape morphing effects.
