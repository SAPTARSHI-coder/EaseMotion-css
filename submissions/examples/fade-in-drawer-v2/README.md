# CSS Fade-In Drawer

A responsive drawer component featuring a smooth fade-in and slide animation using only HTML and CSS.

## Features

- Pure HTML & CSS
- Fade + Slide entrance animation
- Responsive layout
- Accessible navigation
- prefers-reduced-motion support
- CSS Custom Properties
