# Cornish Beam Pump

## What does this do?
Renders a self-contained CSS-only `ease-cornish-beam-pump` demo: Cornish beam pump nodding on the outdoor stroke.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-cornish-beam-pump`. No build step or JavaScript is required for the effect.

```html
<section class="ease-cornish-beam-pump">
  <div class="ease-cornish-beam-pump__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
