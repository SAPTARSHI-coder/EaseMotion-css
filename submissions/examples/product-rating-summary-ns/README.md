# CSS Product Rating Summary (#70996)

A clean, responsive product rating summary card featuring an overall score display, star rating icons, and animated star distribution breakdown progress bars.

## Features
- Pure CSS keyframe scale expansion (`scaleX`) for bar charts with staggered entrance delays.
- Responsive layout with mobile stacking support.
- Fully accessible with `role="progressbar"`, `aria-valuenow`, `aria-valuemin`, and `aria-valuemax`.
- Built-in `prefers-reduced-motion` safety fallbacks.
