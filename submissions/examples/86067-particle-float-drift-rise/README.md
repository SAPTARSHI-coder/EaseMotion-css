# Particle Float Drift Rise

A reusable CSS keyframe animation utility for creating floating particles that gently drift horizontally while rising upward.

## Features

- Floating particle effect
- Gentle horizontal drift
- Continuous upward movement
- Configurable duration and timing
- Uses `transform` and `opacity`
- No JavaScript required
- Supports `prefers-reduced-motion`

## Usage

Add the animation class to an element:

```html
<span class="ease-anim-particle-float-drift-rise"></span>
