# Animated Button - Cyberpunk

A responsive **CSS-only animated button** inspired by cyberpunk interfaces and neon futuristic UI.

## ✨ Features

- Pure HTML and CSS
- No JavaScript
- Neon cyan and pink accents
- Cyberpunk-inspired clipped button shape
- Hover glow effect
- Animated glitch sweep
- Interactive arrow animation
- Focus-visible keyboard state
- Responsive on mobile and desktop
- Reduced-motion accessibility support
- No external dependencies
