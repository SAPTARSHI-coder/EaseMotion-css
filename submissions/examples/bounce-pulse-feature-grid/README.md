# CSS Bounce-Pulse Feature Grid for Responsive Dashboard Layouts

A modern **Bounce-Pulse Feature Grid** component built using only **HTML5 and CSS3**.

This example showcases animated feature cards with bouncing icons, pulse glow effects, responsive layouts, and accessibility support without JavaScript.

---

## ✨ Features

- 🎯 Animated feature cards
- ⚡ Bounce icon animation
- 💡 Pulse glow effects
- 🎨 Gradient UI styling
- 📱 Responsive dashboard layout
- 🚀 Smooth CSS transitions
- 🎯 CSS Custom Properties
- ♿ `prefers-reduced-motion` support
- 🚫 Zero JavaScript dependency

## 🚀 Usage

1. Open `demo.html` in any modern browser.
2. Hover over feature cards to see interactive animations.
3. Customize colors and effects using CSS variables.
