# Off-Canvas Sidebar Component

An interactive slide-in drawer component using CSS `:checked` pseudo-class toggles and smooth GPU-accelerated translate transforms.

## Features
- **Zero JavaScript:** Toggled using the native HTML checkbox pattern (`:checked`).
- **Smooth GPU Animation:** Uses `transform: translateX()` for high-performance 60fps sliding transitions.
- **Backdrop Blur Mask:** Dimmed, frosted overlay mask for focusing context on open.

## File Structure
- `demo.html` - Pure CSS sidebar and trigger markup.
- `style.css` - Translate transforms, backdrop masks, and item layout styles.
