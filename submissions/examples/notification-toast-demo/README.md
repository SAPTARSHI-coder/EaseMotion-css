# Notification Toast Demo

## Description

This example demonstrates an interactive notification toast component using EaseMotion CSS.

## Notification Types

- Success
- Error
- Warning
- Information

## Features

- Interactive toast notifications
- Animated entrance
- Animated exit
- Close button
- Automatic dismissal
- Responsive design
- Accessible notification container
