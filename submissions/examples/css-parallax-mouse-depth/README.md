# CSS Parallax Mouse Depth

A CSS-only parallax depth component that creates a layered 3D
interaction when the user hovers over the card.

## Features

- Pure HTML and CSS
- No JavaScript
- 3D perspective effect
- Multiple depth layers
- Smooth hover transitions
- Responsive design
- Accessible heading and link
- Visible keyboard focus state
- Reduced-motion support
- Works by opening `demo.html` directly
