# CSS Glowing Orbs Float

A pure CSS animated background featuring multiple glowing orbs that slowly float around the viewport.

## Features

- Pure HTML and CSS
- No JavaScript required
- Multiple floating glowing orbs
- Responsive design
- Smooth CSS animations
- Reduced-motion support

## Files

- `demo.html` — Demo page
- `style.css` — Styling and animations
- `README.md` — Component documentation

## Customization

You can customize the orb colors and animation durations directly in `style.css`.

## Accessibility

The decorative orbs use `aria-hidden="true"` and the animation respects `prefers-reduced-motion`.
