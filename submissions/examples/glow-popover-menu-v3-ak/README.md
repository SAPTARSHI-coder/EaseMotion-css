# glow-popover-menu-v3-ak

Pure CSS animated glowing popover menu component — no JavaScript required.

## How to use

```html
<div class="ease-popover-wrapper-v3">
  <button class="ease-popover-trigger-v3">Options</button>

  <ul class="ease-popover-menu-v3">
    <li class="ease-popover-item-v3"><a href="#">Item 1</a></li>
    <li class="ease-popover-item-v3"><a href="#">Item 2</a></li>
  </ul>
</div>
