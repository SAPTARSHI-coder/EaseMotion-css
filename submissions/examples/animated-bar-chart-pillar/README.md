# Animated bar chart pillar

A bar chart whose columns grow from 0 to their target height on first paint with a soft ease.

## How to view

Open `demo.html` in any modern browser. The demo is fully self-contained — no CDN, no framework, no JavaScript.

## How to use

Copy `style.css` into your project's stylesheet. Every class used in the demo is namespaced with `animatedbarchartpillar-` to avoid collisions.

## Why this is useful for EaseMotion CSS

Dashboard pattern; the growth tells the user the data has loaded.
