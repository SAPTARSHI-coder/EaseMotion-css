# CSS Skew-Active Navbar

A responsive navigation bar featuring a smooth skew active-state animation built with pure HTML and CSS.

## Features

- Pure HTML & CSS
- Skew active/hover animation
- Fully responsive
- Keyboard accessible
- Supports `prefers-reduced-motion`
- No JavaScript required

## Folder Structure

```text
skew-active-navbar/
├── demo.html
├── style.css
└── README.md
```

## Usage

Open `demo.html` in any modern browser.

## Customization

- Navbar background color
- Active highlight color
- Transition duration
- Font size
- Padding and spacing

## Accessibility

- Keyboard focus support
- Responsive layout
- Reduced motion support
