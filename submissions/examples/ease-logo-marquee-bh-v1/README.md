# ease-logo-marquee-bh

Pure CSS infinite auto-scrolling logo marquee component.

## What does this do?
Creates an infinite horizontal scrolling marquee of logos/brand images that continuously moves without JavaScript.

## How is it used?
```html
<div class="ease-marquee-bh">
  <div class="ease-marquee-track-bh">
    <!-- logos -->
  </div>
</div>
```

## Why is it useful?
Perfect for showcasing client logos, partner brands, or technology stacks with a dynamic, engaging presentation.
