# Neon Music Player

This submission demonstrates a modern music player card built with
**EaseMotion CSS**. It includes an animated album disc, progress bar, player
controls, playlist items, hover effects, and custom neon styling.

## 🌟 Features

- **Music player card** with album art, track title, and artist name.
- **Animated album disc** created with pure CSS.
- **Progress bar** using CSS variables.
- **Player controls** with hover grow and glow effects.
- **Playlist section** with active track styling.
- **Staggered entrance animation** using `ease-slide-up`, `ease-fade-in`, and delay utilities.
- **Responsive layout** for mobile and desktop.
- **Reduced motion support** for users who prefer less animation.

## 📁 Files

- `demo.html` — interactive music player demo
- `style.css` — original neon music player styling
- `README.md` — documentation for this submission

## 🛠️ How to Run

1. Open `demo.html` in your browser.
2. Watch the player card and playlist items animate on load.
3. Hover over the buttons to see hover grow and glow effects.
4. Resize the browser window to check responsive behavior.
