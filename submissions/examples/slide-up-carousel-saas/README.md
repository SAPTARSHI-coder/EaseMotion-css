# CSS Slide-Up Carousel for SaaS Showcase Layouts

A responsive SaaS showcase carousel created with pure HTML and CSS.

The component uses a smooth slide-up entrance animation combined with
subtle scaling, blur reduction and staggered content animations.

## Features

- Pure HTML and CSS
- No JavaScript
- No external libraries
- CSS-only carousel navigation
- Slide-up entrance animation
- Scale and blur transitions
- SaaS analytics showcase
- Team workspace showcase
- Cloud security showcase
- Responsive desktop layout
- Responsive tablet layout
- Responsive mobile layout
- CSS custom properties
- Keyboard-friendly navigation
- Visible focus states
- `prefers-reduced-motion` support
