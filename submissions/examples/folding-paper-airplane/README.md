# CSS Folding Paper Airplane ✈️


A pure CSS animated paper airplane that folds its wings and flies across the screen.


## Features

- Pure CSS implementation
- Folding wing animation
- Flying motion effect
- Responsive design
- Reduced motion accessibility support


## Technologies

- HTML5
- CSS3


## Folder Structure


folding-paper-airplane/

├── demo.html
├── style.css
└── README.md



## Usage

Open `demo.html` in a browser.
