# Bento Grid Interactive Dashboard Layout

## Overview

A compact mobile-first dashboard UI component built using CSS Grid
and Flexbox. It provides a modern bento-style layout with animated
cards and responsive behavior.

## Features

- 🧩 Modern Bento Grid Layout
- 📱 Mobile-first responsive design
- 🎨 Glassmorphism dashboard cards
- ✨ Smooth hover elevation effects
- 📊 Animated analytics visualization
- ⚡ Pure HTML, CSS and JavaScript
- ♿ Reduced motion accessibility support

## Usage

Open `demo.html` in any modern browser.

Customize:
- Card content inside HTML
- Theme variables inside CSS
- Animations according to your needs
