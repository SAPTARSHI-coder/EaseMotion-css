# CSS Crowdfunding Card

A responsive crowdfunding project card featuring a funding progress bar, project statistics, and a call-to-action button.

## Features

- Pure CSS implementation
- Animated funding progress bar
- Responsive card layout
- Hover elevation effect
- Project statistics section
- Modern crowdfunding UI design

## Usage

```html
<div class="crowdfunding-card">
  <div class="progress-bar">
    <div class="progress-fill"></div>
  </div>
</div>
```

Include:

```html
<link rel="stylesheet" href="style.css">
```

## Why It Fits EaseMotion CSS

This component provides a reusable crowdfunding/project showcase card with smooth animations and modern styling, making it useful for startup, fundraising, and campaign-based interfaces.
