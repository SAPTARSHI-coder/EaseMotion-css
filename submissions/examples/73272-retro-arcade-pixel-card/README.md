# Retro Arcade Pixel Card

A responsive pure CSS card component inspired by classic retro arcade interfaces and pixel-art aesthetics.

## ✨ Features

- Retro arcade visual styling
- Pixel-inspired UI elements
- Chunky arcade borders
- Layered pixel shadows
- Neon hover effects
- Responsive card grid
- Dark-mode compatible
- Light-mode compatible
- Keyboard-accessible buttons and links
- Visible focus states
- Reduced-motion support
- Hardware-friendly CSS transforms
- No JavaScript
- No external dependencies
