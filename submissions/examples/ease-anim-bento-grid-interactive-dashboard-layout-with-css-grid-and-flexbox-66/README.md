# Bento Grid Interactive Dashboard Layout

## Cyberpunk Theme

A futuristic cyberpunk-style bento dashboard component built using pure HTML,
CSS, and JavaScript.

The component combines CSS Grid, Flexbox, neon effects, and micro animations
to create an interactive dashboard experience.

## Features

- ⚡ Cyberpunk neon interface
- 📊 Bento grid dashboard layout
- 🧊 Glassmorphism panels
- ✨ Interactive 3D hover tilt
- 🌈 Gradient glow effects
- 📱 Responsive design
- 🔥 Animated analytics visualization

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over dashboard cards.
3. Experience the animated cyberpunk interface.
