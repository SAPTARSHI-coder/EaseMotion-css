Pure CSS Scroll-Driven Header Morphing

Experience a 120fps hardware-accelerated hero header that dynamically morphs, shrinks, and docks into a sleek glassmorphic top bar as you scroll — 100% zero JavaScript.

Native CSS Support

This demo uses animation-timeline: scroll(root) with progressive fallback for older browsers.

Key Advantages

⚡

120fps Performance

Completely decouples scroll rendering from main-thread JS execution, delivering jitter-free 120fps animations on mobile and high-refresh displays.

🎨

Fluid Glassmorphism

Seamlessly interpolates backdrop blur, background transparency, padding, height, and border styles across scroll offsets.

🛡️

Zero JS Dependencies

No scroll event listeners, no requestAnimationFrame loops, no layout recalculations, and zero runtime dependencies.

How The Morph Works

01

Hero State (0px Scroll)

Header renders in expanded hero mode with 120px height, generous padding, large logo, and transparent backdrop.

02

Interpolation Range (0px - 250px)

Native browser scroll engine maps current scroll offset directly to @keyframes headerMorph percentage.

03

Docked State (250px+ Scroll)

Header seals into a compact 60px sticky glass navbar with 16px backdrop blur, elevated shadow, and sleek borders.

CSS Implementation

.ease-header-morph {
  position: sticky;
  top: 0;
  animation: headerMorph linear both;
  animation-timeline: scroll(root);
  animation-range: 0px 250px;
}

@keyframes headerMorph {
  from {
    height: 120px;
    backdrop-filter: blur(0px);
    background: rgba(15, 23, 42, 0.3);
  }
  to {
    height: 60px;
    backdrop-filter: blur(16px);
    background: rgba(15, 23, 42, 0.85);
  }
}
