# CSS Slide-Up Card Grid for Fintech Dashboard Layouts

A responsive fintech dashboard card grid featuring a smooth CSS-only
slide-up entrance animation.

## Features

- Pure HTML and CSS
- Slide-up card entrance animation
- Staggered animation delays
- Hover elevation effect
- Animated accent indicator
- Responsive desktop, tablet, and mobile layouts
- CSS custom properties for easy customization
- No JavaScript or external frameworks
- Accessible reduced-motion support
- Lightweight and performant

## Preview

The component displays six financial metric cards:

- Total Balance
- Monthly Revenue
- Expenses
- Investments
- Transactions
- Portfolio Growth

Each card enters the viewport with a smooth upward motion and opacity
transition.
