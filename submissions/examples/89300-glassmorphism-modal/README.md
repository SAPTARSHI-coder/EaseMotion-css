# Glassmorphism Modal Component

A sleek dialog overlay featuring backdrop blur filters and pop-in entrance keyframe transitions.

## Features
- **Frosted Backdrop Filter:** Utilizes `backdrop-filter: blur()` for ambient background blurring.
- **Micro-Interaction Pop:** Smooth entrance scaling and translate keyframes.
- **Zero JavaScript:** Fully responsive modal presentation structure using pure CSS.

## File Structure
- `demo.html` - Modal dialog structure with header, body, and action buttons.
- `style.css` - Overlay backdrop filters and modal entrance animation rules.
