# Zoom-In Creative Portfolio Card Grid (`#54526`)

## What does this do?
Creates a deeply engaging gallery showcase where hovered project tiles zoom forward toward the camera while automatically dimming sibling elements.

## How is it used?
Structure feature article boxes inside an `ease-grid-zoom` responsive layout container:
```html
<div class="ease-grid-zoom">
  <article class="zoom-card">...</article>
</div>
```

## Why is it useful?
Solves issue #54526 by bringing spotlight cinematic focus to individual showcase projects inside crowded design grids.
