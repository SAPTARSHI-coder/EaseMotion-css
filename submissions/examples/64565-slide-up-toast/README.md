# Slide-Up Toast

A modern pure CSS animated toast notification created for **EaseMotion CSS**.

This component demonstrates a minimalist tech style toast message with smooth slide-up animation and glassmorphism effects.

## ✨ Features

- Pure HTML & CSS implementation
- Smooth slide-up animation
- Glassmorphism UI design
- Minimalist tech layout
- Responsive design
- Lightweight and performant
- No JavaScript dependency
- CSS keyframe animations
- `prefers-reduced-motion` support
