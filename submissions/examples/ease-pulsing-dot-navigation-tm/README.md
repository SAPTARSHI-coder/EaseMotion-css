# Pulsing Dot Navigation Component

Add ease-pulsing-dot-navigation-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|--------|
| `--pd-accent` | `#6366f1` |
| `--pd-size` | `12px` |
| `--pd-gap` | `12px` |
| `--pd-trans` | `0.3s` |

## Technique

`box-shadow` pulse animation on active dot creates expanding ring effect. `:hover` scales dots up.
