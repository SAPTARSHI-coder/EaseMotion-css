# Fluid Liquid Fill Water Button with Smooth Overflow Wave Effect

### Dark Mode Variant

A modern **Dark Mode Fluid Water Button** built with **HTML5** and **CSS3**. The component features a smooth liquid fill animation with an overflowing rotating wave effect, subtle glow, and responsive design—all without JavaScript.

---

## ✨ Features

- Smooth liquid fill hover animation
- Rotating overflow wave effect
- Dark mode UI
- Responsive design
- Gradient water fill
- CSS-only implementation
- Modern CSS variables
- Rounded pill button
- Keyboard accessible
- Reduced motion support

## 🚀 Usage

1. Navigate to the component folder.
2. Keep `demo.html` and `style.css` in the same directory.
3. Open `demo.html` in any modern browser.
4. Hover over the button to see the animated liquid fill effect.

No external libraries or installation are required.
