# Cyberpunk Broken Neon Sign

A gritty, flickering neon sign effect that simulates a failing electrical ballast, built purely with CSS.

## Features
- **Neon Glow:** Created by stacking multiple layers of `text-shadow` with varying blur radii and colors to achieve a bright, glowing tube effect.
- **Flicker Animations:** Uses complex `@keyframes` with sudden opacity and color drops, targeting specific letters to simulate electrical faults and broken neon gas.
- **Gritty Background:** A subtle repeating linear gradient over a radial gradient background gives the illusion of a brick wall or dark alleyway behind the sign.

## Structure
- `demo.html`: The HTML structure separating individual letters into `<span>` tags to allow for independent flickering animations.
- `style.css`: The stylesheet defining the glowing shadows, typography, and precise keyframe timings.

## How to run
Open `demo.html` in your web browser and watch the neon lights flicker!
