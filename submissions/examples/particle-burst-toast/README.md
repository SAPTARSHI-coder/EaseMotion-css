# Particle Burst Toast

A visually expressive notification toast featuring a lightweight
particle-burst effect created entirely with CSS.

## Features

- Particle burst animation
- Multiple simultaneous particles
- Soft particle glow
- Smooth toast entrance
- Subtle hover elevation
- Dark mode support
- Light mode support
- Responsive layout
- Accessible notification semantics
- Keyboard focus support
- Reduced-motion support
- No external dependencies

## Preview

The toast creates a radial burst of small glowing particles around the
notification. The particles expand outward, fade away, and continuously
repeat to create an energetic notification effect.
