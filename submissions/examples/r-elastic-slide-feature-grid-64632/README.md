
# CSS Elastic-Slide Feature Grid

A responsive pure HTML/CSS feature grid designed for minimalist technology layouts.

## Features

- Pure HTML and CSS
- Elastic slide hover interaction
- Responsive grid layout
- No JavaScript or external libraries
- Customizable CSS variables
- Accessible reduced-motion support

## Usage

Link `style.css` from `demo.html` and use the `.feature-grid` and `.feature-card` classes.

## Customization

The main animation and color values can be changed through the CSS custom properties in `:root`.

## Accessibility

The component includes `prefers-reduced-motion` support to minimize motion for users who request reduced animations.
