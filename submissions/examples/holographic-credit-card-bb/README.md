# Holographic 3D Credit Card Component

## What does this do?
This component renders an interactive 3D credit card interface with continuous iridescent rainbow glare sweeps, metallic chip texturing, floating perspective transform animation, and subtle hover interaction.

## How is it used?
Include `style.css` in your webpage and embed the `.holo-card-container` HTML snippet into checkout pages, fintech dashboards, or wallet UIs.

## Why is it useful?
- Premium visual aesthetic ideal for fintech and e-commerce applications.
- Hardware-accelerated CSS 3D perspective and `mix-blend-mode` effects.
- Lightweight, self-contained, zero-dependency pure CSS code.
