# Interactive Accordion with Cyberpunk Styling

A responsive cyberpunk-inspired interactive accordion built using pure HTML and CSS.

The component uses native HTML `details` and `summary` elements, providing interactive expand/collapse behavior without external JavaScript.

## ✨ Features

- Cyberpunk visual styling
- Neon cyan and pink glow effects
- Interactive accordion states
- Pure HTML and CSS
- Zero external JavaScript dependencies
- Fully responsive
- Native semantic accordion structure
- Smooth state transitions
- CSS design tokens
- `prefers-reduced-motion` support
- Keyboard-friendly native controls
