# glow-accordion-v9-ak

Pure CSS animated glowing neon border accordion drawer component — no JavaScript required.

## How to use

```html
<div class="ease-accordion-v9">
  <input type="checkbox" id="item1" class="ease-accordion-checkbox-v9" />
  <div class="ease-accordion-item-v9">
    <label for="item1" class="ease-accordion-header-v9">
      <span>Header</span>
      <span class="ease-accordion-icon-v9">▼</span>
    </label>
    <div class="ease-accordion-drawer-v9">
      <div class="ease-accordion-body-v9">Content</div>
    </div>
  </div>
</div>
