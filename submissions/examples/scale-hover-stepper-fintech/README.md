# CSS Scale-Hover Stepper for Fintech Dashboard Layouts

A responsive, CSS-only transaction stepper designed for modern fintech
dashboard interfaces.

The component uses subtle scale, translation, rotation and shadow
effects to create an interactive stepper without JavaScript.

## Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Interactive scale-hover steps
- Keyboard focus support
- Completed, active and upcoming states
- Animated connectors
- Responsive desktop layout
- Responsive tablet layout
- Responsive mobile layout
- CSS custom properties
- Semantic HTML
- Reduced-motion support
