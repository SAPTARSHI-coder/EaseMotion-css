# Responsive Timeline

## Description

This submission fixes an issue where timeline items overlap or become misaligned on smaller screens. The layout now adapts using responsive Flexbox and media queries to keep timeline items properly spaced and easy to read.

## Features

- Prevents timeline item overlap
- Responsive mobile-friendly layout
- Proper spacing and alignment
- Handles long content gracefully
- Pure CSS implementation

## Usage

```html
<div class="timeline">
  <div class="timeline-item">
    <div class="timeline-dot"></div>

    <div class="timeline-content">
      <h3>2026</h3>
      <p>Timeline description...</p>
    </div>
  </div>
</div>
```

## Benefits

- Eliminates overlapping timeline items
- Improves readability on mobile devices
- Maintains consistent spacing
- Lightweight and easy to integrate
```
