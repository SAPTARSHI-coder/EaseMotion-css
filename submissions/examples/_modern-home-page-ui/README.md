# Modern Home Page UI

A responsive modern home page UI contribution for
EaseMotion CSS.

## Description

This contribution enhances the web page UI with a modern
responsive layout, animated hero section, feature cards,
interactive elements and a clear call-to-action section.

The implementation uses HTML and CSS along with existing
EaseMotion CSS animation utilities.

## Features

- Responsive navigation bar
- Animated hero section
- CSS-based animated visual
- Feature cards with hover interactions
- Interactive button showcase
- Responsive mobile layout
- Keyboard focus states
- Reduced-motion accessibility support
- No JavaScript dependency
- No external images

## Files

- `demo.html` - Home page structure
- `style.css` - Custom styling, animations and responsive layout
- `README.md` - Contribution documentation

## Technologies

- HTML5
- CSS3
- EaseMotion CSS

## CSS Concepts Used

- Flexbox
- CSS Grid
- CSS gradients
- CSS transitions
- CSS keyframe animations
- Pseudo-elements
- Media queries
- Responsive design
- Accessibility with `prefers-reduced-motion`

## EaseMotion Integration

The page uses existing EaseMotion utility classes for
animations and hover interactions while custom CSS handles
the page layout and visual design.

## Accessibility

The page provides visible keyboard focus states and supports
the `prefers-reduced-motion` media query for users who prefer
reduced animation.

## Preview

Open `demo.html` in a modern browser to view the contribution.
