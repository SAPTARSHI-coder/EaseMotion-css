# CSS Diamond Cut Card

A decorative card component featuring diamond-cut angled corners,
geometric facet decorations, and a polished gemstone-inspired visual style.

## Features

- Pure HTML and CSS
- Diamond-cut angled corners
- CSS-generated facet decorations
- Interactive hover animation
- Responsive design
- Keyboard-accessible link
- No JavaScript
- No external dependencies
- Reduced-motion support

## Files

- `demo.html` — Component demonstration
- `style.css` — Component styling and animations
- `README.md` — Documentation
