# Subtle Elevate Media Visualizer

A smooth, minimal audio and media visualizer inspired by a subtle elevated UI style.

The component uses pure HTML and Vanilla CSS with no external JavaScript or dependencies.

## Features

- Subtle elevated card appearance
- CSS-only audio visualizer bars
- Smooth hover and interaction transitions
- Media playback controls
- Playback progress indicator
- Volume indicator
- Dark-mode friendly design
- Responsive layout
- Keyboard-visible focus states
- `prefers-reduced-motion` support
- No external dependencies
