# Synthwave Grid Line Glass Effect

A futuristic glassmorphism UI component inspired by synthwave aesthetics, created using pure HTML and Vanilla CSS.

## ✨ Features

- Pure HTML and Vanilla CSS
- Glassmorphism effect
- Synthwave-inspired grid lines
- Futuristic horizon effect
- Smooth hover transitions
- Dark-mode compatible
- Hardware-accelerated transforms
- Responsive design
- Keyboard-accessible button
- Reduced-motion support
- No JavaScript
- No external libraries
