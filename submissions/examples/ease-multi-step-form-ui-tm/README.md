# Multi-Step Form UI Component

Add ease-multi-step-form-ui-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|--------|
| `--mf-accent` | `#6366f1` |
| `--mf-done` | `#10b981` |
| `--mf-radius` | `10px` |
| `--mf-trans` | `0.35s` |

## Note

Radio inputs drive step visibility. JS handles navigation between steps.
