# Skew-Active Tabs (Fintech Dashboard)

## What does this do?

A modern fintech dashboard tab component featuring subtle skew animations for the active navigation tab. Built entirely with HTML and CSS for lightweight and interactive dashboard interfaces.

---

## Features

- Skew-active animation for the selected tab
- Smooth hover transitions
- Glassmorphism dashboard design
- Responsive layout
- Fintech-inspired blue color palette
- Financial overview cards
- Pure HTML & CSS (No JavaScript)
- Supports `prefers-reduced-motion`

---
