# Nav Tab Rotate

Active nav tabs flip with a 3D rotation marking selection.

## Features
- 3D tab flip
- Active highlight
- Sequential flip
- Pure CSS

## Usage
```html
<a href="#" class="ntr-tab" style="--i:3">Blog</a>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
