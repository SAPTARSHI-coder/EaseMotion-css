# CSS Breaking News Ticker

A responsive breaking-news ticker built using pure HTML and CSS.

This component is designed for the EaseMotion CSS library and provides
a lightweight animated news bar without JavaScript or external libraries.

## Features

- Pure HTML and CSS
- Smooth infinite scrolling animation
- Responsive layout
- Pause animation on hover
- Pause animation on keyboard focus
- Animated live indicator
- CSS-only responsive behavior
- Keyboard accessible
- `prefers-reduced-motion` support
- No JavaScript dependencies
- No external libraries
- Modern CSS animations
- Mobile-friendly design
