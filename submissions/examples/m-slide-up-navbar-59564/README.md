# CSS Slide-Up Navbar for SaaS Showcase Layouts

A modern **Slide-Up Navbar** built using pure HTML and CSS. The navigation bar smoothly slides upward into view while using a premium glassmorphism design suitable for SaaS landing pages, dashboards, and admin interfaces.

## ✨ Features

- Pure HTML5 & CSS3
- Smooth slide-up entrance animation
- Glassmorphism navbar
- Responsive layout
- Gradient CTA button
- CSS Custom Properties
- `prefers-reduced-motion` support
- No JavaScript required
