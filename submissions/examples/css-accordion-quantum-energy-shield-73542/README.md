# CSS Quantum Energy Shield Accordion

A futuristic accordion component inspired by quantum energy shields and sci-fi interfaces.

## Features

- Pure HTML & CSS
- Quantum energy glow effects
- Animated shield border
- Smooth accordion interaction
- Dark mode compatible
- Responsive design
- Accessible native details/summary implementation

## Usage

```html
<details class="quantum-accordion">
    <summary>Accordion Title</summary>
    <div class="content">
        Accordion content goes here.
    </div>
</details>
