Basic Setting Toggle Row

Clean preference rows for settings and account panels.

This CSS-only utility aligns a setting title, helper text, and a visual toggle control for compact preference sections.

HTML Usage

<label class="basic-setting-toggle-row">
  <span class="setting-copy">
    <strong>Email notifications</strong>
    <span>Receive updates when activity happens.</span>
  </span>
  <input type="checkbox" checked />
  <span class="toggle-track" aria-hidden="true"></span>
</label>
