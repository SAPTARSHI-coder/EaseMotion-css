# 3D Input Field - Neumorphism

A responsive neumorphic input field featuring soft 3D shadows, inset focus effects, and a matching action button.

## Features

- Pure HTML & CSS
- Responsive layout
- Neumorphism styling
- 3D inset input effect
- Accessible label
- Keyboard friendly
- Smooth hover and focus transitions
- No JavaScript required
