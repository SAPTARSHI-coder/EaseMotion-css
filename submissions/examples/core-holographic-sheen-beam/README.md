# EaseMotion: Holographic Sheen Beam

A high-performance, CSS-only keyframe animation utility that applies a sweeping holographic light beam effect across container elements.

## Installation

Ensure `core/animations.css` is imported into your main stylesheet or build pipeline.

## Usage

Add the `.ease-anim-holographic-sheen-beam` class to any container element. 

*Note: The utility class automatically applies `position: relative` and `overflow: hidden` to the target element to contain the beam.*

```html
<button class="ease-anim-holographic-sheen-beam">
    Premium Checkout
</button>
