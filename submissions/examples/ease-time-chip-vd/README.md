# Ease Time Chip

## What does this do?

A small rounded pill component for displaying a time or duration with a clock icon.

---

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<div class="time-chip">
    <span class="time-icon">◷</span>
    <span>10:30 AM</span>
</div>
```

### Examples

```html
<div class="time-chip">
    <span class="time-icon">◷</span>
    <span>10:30 AM</span>
</div>

<div class="time-chip">
    <span class="time-icon">◷</span>
    <span>45 min</span>
</div>

<div class="time-chip">
    <span class="time-icon">◷</span>
    <span>2h 15m</span>
</div>
```

### Features

- Rounded pill design
- Clock icon
- Time and duration support
- Hover animation
- Responsive layout
- Lightweight and reusable

---

## Why is it useful?

Time chips are commonly used in schedules, calendars, media cards, event listings, and duration displays.

This component provides a simple and reusable time display with subtle interaction feedback while following the animation-first philosophy of EaseMotion CSS.
