# CSS Shimmer-Sweep Drawer

A modern navigation drawer featuring a smooth shimmer sweep animation using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Animated shimmer sweep effect
- Responsive layout
- Accessible navigation
- CSS Custom Properties
- prefers-reduced-motion support
- No JavaScript required

:root{

  --text:#ffffff;

}
