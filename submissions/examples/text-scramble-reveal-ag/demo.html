Pure CSS Scramble Reveal Design

CSS keyframes do not provide a random generator, but we can simulate cursor and code decryption effects using deterministic tracks:

  • Vertical Track Alignment: Spans are stacked inside a flex-direction: column wrapper. The container limits visible height using overflow: hidden so only one character is visible at a time.
  • Step-by-Step Translation: Using steps(5) inside the animation-timing-function, the browser jumps instantly from one line to the next rather than performing a smooth scroll, creating a digital "glitchy" text transition.
  • Delayed Stagger: Characters are staggered using incremental inline delay calculations (e.g. 0.05s increments) to resolve letters sequentially from left to right.
  • No Content Loss: In Firefox, Safari, or older browsers without nested flex structures, the default state of translating -83.333% (the 6th element) is loaded, presenting flat readable text immediately.
