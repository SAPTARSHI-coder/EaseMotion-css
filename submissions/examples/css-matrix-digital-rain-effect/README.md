# CSS Matrix Digital Rain

A cascading digital rain effect inspired by the Matrix, utilizing intense `text-shadow` trails and vertical animations across staggered, delayed columns.

## Features
- Classic hacker aesthetic using heavily glowing `text-shadow` on a dark background.
- Cascading terminal fade simulated using a directional `linear-gradient` mapped to `-webkit-mask-image`.
- Individualized column timing controlled entirely via inline CSS custom variables (`--delay`, `--duration`, `--offset`).
