# 🎮 Rotate-Fade Gaming Stepper

A modern **Rotate-Fade Stepper** built with **pure HTML and CSS** for the **EaseMotion CSS** project. This component presents a four-step gaming journey with smooth rotate-and-fade hover animations, glowing connectors, glassmorphism cards, and a fully responsive layout.

---

## ✨ Features

- 🎮 Gaming-themed stepper component
- 🔄 Rotate + fade hover animation
- 🌈 Gradient glowing connectors
- 💎 Glassmorphism step cards
- ⭐ Active step highlighting
- 🎨 CSS Custom Properties for easy customization
- 📱 Fully responsive design
- ♿ Accessibility support with `prefers-reduced-motion`
- 🚫 Pure HTML & CSS (No JavaScript)

---

## 🚀 Usage

1. Open `demo.html` in a modern web browser.
2. Ensure `style.css` is in the same folder.
3. Hover over a step card to see the rotate-and-fade animation.
4. Customize colors and spacing through the CSS variables.

---
