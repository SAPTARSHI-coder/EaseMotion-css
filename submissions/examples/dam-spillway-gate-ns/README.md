# Dam Spillway Gate

## What does this do?
Renders a self-contained CSS-only `ease-dam-spillway-gate` demo: Dam spillway radial gate lifting to release water.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-dam-spillway-gate`. No build step or JavaScript is required for the effect.

```html
<section class="ease-dam-spillway-gate">
  <div class="ease-dam-spillway-gate__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
