# CSS Blueprint Card

A technical blueprint-style card with drafting grids, measurement guides, component labels, and subtle CSS motion.

## Features

- Blueprint grid background
- Measurement annotations
- Technical labels and revision marker
- Responsive component layout
- Native semantic content
- Reduced-motion support
- No JavaScript or dependencies

## Files

- `demo.html` — blueprint card structure and component notes
- `style.css` — grid, measurements, artwork, animation, responsive rules, and accessibility styling

## Accessibility

The blueprint artwork is decorative while the actual card information is regular semantic text. Reduced-motion users receive the same information without decorative animation.
