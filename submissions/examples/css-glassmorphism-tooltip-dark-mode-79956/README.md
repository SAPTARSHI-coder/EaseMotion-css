# Glassmorphism Tooltip with Dark Mode Styling

A modern tooltip component featuring glassmorphism effects, dark mode aesthetics, smooth transitions, and responsive design using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Glassmorphism UI design
- Dark mode compatible
- Smooth fade and slide animations
- Responsive layout
- Accessible hover interaction
- No JavaScript required

## Files

- demo.html
- style.css

## Usage

```html
<div class="tooltip-wrapper">
    <button class="tooltip-trigger">
        Hover Me
    </button>

    <span class="tooltip">
        Tooltip content
    </span>
</div>
```

## Why it fits EaseMotion CSS

This component showcases elegant motion, subtle transitions, modern glass effects, and reusable styling while remaining lightweight, responsive, and accessible.
