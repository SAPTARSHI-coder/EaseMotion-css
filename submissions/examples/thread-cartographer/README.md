# Thread Cartographer

Thread Cartographer is an experimental interactive map component where users
can physically "thread" a route through a collection of landmarks.

Instead of representing relationships with conventional graph edges, the
component uses the metaphor of a physical thread being pulled across a paper
map.

The route progressively reveals hidden relationships between discovered
landmarks.

## ✨ Features

- Interactive paper map
- Hand-drawn cartographic aesthetic
- Multiple landmarks
- Nearest-landmark detection
- Pointer-following exploration cursor
- Drag-to-create routes
- Landmark snapping
- Persistent thread path
- Hidden relationship discovery
- Dynamic coordinates
- Dynamic route distance
- Dynamic route complexity
- Discovered landmark list
- Route reset
- Responsive layout
- Mouse support
- Touch support
- Pointer Events
- Reduced-motion support
- No external dependencies
