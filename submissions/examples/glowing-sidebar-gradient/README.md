# Glowing Sidebar with Gradient Styling

A modern and responsive CSS-only sidebar featuring glowing gradient effects,
interactive navigation items, and a dark futuristic interface.

## ✨ Features

- Responsive sidebar layout
- Gradient glowing effects
- Interactive navigation items
- Active navigation indicator
- Modern dark UI
- Responsive mobile navigation
- No JavaScript required
- Pure HTML and CSS
