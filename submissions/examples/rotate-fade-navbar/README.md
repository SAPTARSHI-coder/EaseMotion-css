# CSS Rotate-Fade Navbar

A pure CSS animated navigation bar with rotate and fade entrance effects.

## Features

- Pure HTML and CSS
- Smooth rotate-fade animation
- Responsive mobile layout
- Hover interactions
- No JavaScript required
- Accessible reduced-motion support

## Usage

Place this folder inside:

submissions/examples/rotate-fade-navbar/

Open `demo.html` in any browser.

```css
--animation-speed: 0.6s;
