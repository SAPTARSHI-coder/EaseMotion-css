# Responsive Floating Label Input — Material Design

A responsive floating label input component inspired by Material Design.

The component is built using pure HTML and CSS without external JavaScript
dependencies.

## Features

- Material Design inspired styling
- Floating labels
- Responsive layout
- Smooth focus transitions
- Hover states
- Native HTML validation
- Keyboard accessible
- Visible focus indicators
- Textarea support
- Error state
- `prefers-reduced-motion` support
- No JavaScript dependency
- No external libraries
