# Ease Kubernetes Persistent Volume Claim Map

## Overview

A responsive Kubernetes storage component for visualizing relationships between workloads, PersistentVolumeClaims, and PersistentVolumes.

## Features

- Workload to PVC mapping
- PVC to PersistentVolume binding visualization
- Bound and pending claim states
- Storage class information
- Volume utilization indicators
- Animated storage binding paths
- Cluster storage capacity overview
- Responsive topology layout
- Hover interactions
- Pure HTML and CSS

## Folder Structure

- `demo.html`
- `style.css`
- `README.md`

## Usage

Open `demo.html` in any modern browser.

## Browser Support

- Chrome
- Firefox
- Edge
- Safari

## Why EaseMotion CSS?

The component provides a reusable storage topology interface for understanding Kubernetes PVC bindings, volume allocation, and capacity health through animated visual relationships.
