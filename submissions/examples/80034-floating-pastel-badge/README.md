# Floating Pastel Badge (Variant B)

A clean and responsive floating badge component with a soft pastel aesthetic.

## Features

- Soft pastel visual design
- Floating animation
- Hover interaction
- Multiple pastel badge variants
- Fully responsive layout
- CSS-only implementation
- No JavaScript required
- No external dependencies
- Reduced-motion support
