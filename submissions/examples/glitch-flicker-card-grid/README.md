# CSS Glitch Flicker Card Grid

A responsive card grid featuring a glitch-inspired hover animation and flickering light effect.

## Features

- Pure HTML & CSS
- Responsive Grid Layout
- Glitch Hover Animation
- Flicker Sweep Effect
- CSS Custom Properties
- Accessible with prefers-reduced-motion
- No JavaScript Required

## Files

```
demo.html
style.css
README.md
```

## CSS Variables

```css
--bg
--card
--text
--accent
--radius
--duration
```

## Usage

Open `demo.html` in your browser.

Hover over cards to view the glitch flicker animation.

## Accessibility

Supports:

- prefers-reduced-motion
- Responsive layouts
- Keyboard-friendly structure
