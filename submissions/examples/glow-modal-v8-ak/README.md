# glow-modal-v8-ak

Pure CSS animated glowing pop-in modal window component — no JavaScript required.

## How to use

```html
<input type="checkbox" id="m" class="ease-modal-checkbox-v8" />
<label for="m" class="ease-modal-trigger-v8">Open Modal</label>

<div class="ease-modal-overlay-v8">
  <div class="ease-modal-dialog-v8">
    <h3 class="ease-modal-title-v8">Title</h3>
    <p class="ease-modal-desc-v8">Content</p>
    <label for="m" class="ease-modal-close-v8">Close</label>
  </div>
</div>
