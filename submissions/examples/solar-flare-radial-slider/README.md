# Solar Flare Radial Slider

A smooth and responsive pure CSS slider inspired by the radial energy and glowing motion of a solar flare.

## Features

- Pure HTML and vanilla CSS
- No JavaScript
- Solar flare radial visual effect
- Smooth slide transitions
- 3D-inspired depth
- Radial gradients and animated rings
- Responsive design
- Dark-mode friendly
- Hardware-accelerated transforms
- Keyboard-friendly native controls
- `prefers-reduced-motion` support
