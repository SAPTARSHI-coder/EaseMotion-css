# CSS Blur-Entrance Accordion

A responsive fintech dashboard accordion featuring a smooth blur-and-slide
entrance animation using pure HTML and CSS.

## Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Native `<details>` and `<summary>` accordion
- Blur entrance animation
- Slide and scale transition
- Smooth expand/collapse behavior
- Responsive desktop, tablet and mobile layouts
- Financial dashboard styling
- Keyboard accessible
- `prefers-reduced-motion` support
- CSS custom properties for customization
