# 3D Tooltip with Neon Styling

A responsive CSS-only 3D tooltip component with a futuristic neon visual style.

## ✨ Features

- Pure HTML and CSS
- No JavaScript or external dependencies
- 3D perspective animation
- Neon cyan and pink glow effects
- Top, right, bottom, and left tooltip variants
- Hover and keyboard focus interaction
- Responsive design
- Mobile-friendly tooltip positioning
- Accessible `role="tooltip"` markup
- `aria-describedby` support
- Reduced-motion support
- Works with modern browsers
