# Pulsating Wave

A smooth 3D pulsating wave animation created using pure HTML and Vanilla CSS.

## ✨ Features

- Pure HTML and CSS
- 3D perspective effect
- Multiple expanding wave layers
- Smooth pulsating animation
- Rotating 3D presentation
- Glowing center core
- Dark and light mode support
- Hardware-accelerated transforms
- Responsive design
- Reduced-motion accessibility support
- No JavaScript
- No external dependencies
