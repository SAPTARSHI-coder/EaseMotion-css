# Isometric 3D Stacking Cards

A modern neumorphic UI component featuring interactive isometric 3D
stacking cards with smooth hover elevation.

## Features

- Neumorphic design
- Interactive 3D mouse-follow effect
- Hover elevation
- Responsive mobile layout
- Smooth CSS transitions
- Pure HTML, CSS and JavaScript
- No external dependencies
- Reduced-motion accessibility support
