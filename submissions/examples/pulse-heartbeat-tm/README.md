# Pulse heartbeat indicator

1. What does this do? A small dot that thumps twice (like a heartbeat) on a 1.4 second cycle, with a soft outward ripple.

2. How is it used? Add `hb-dot-tm` to a `<span>`. Modifiers: `hb-dot-ok-tm` (green), `hb-dot-warn-tm` (amber), `hb-dot-lg-tm` / `hb-dot-sm-tm` (size).

3. Why is it useful? It signals "live" or "needs attention" without the constant, attention-grabbing pulse of a typical loading spinner.
