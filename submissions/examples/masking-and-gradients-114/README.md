# Shimmering Metallic Foil Text Effect

A futuristic Cyberpunk-themed text effect featuring animated metallic
gradients, CSS masking, neon highlights and shimmer animation.

## ✨ Features

- Animated metallic foil gradient
- Dynamic shimmer/refraction effect
- Cyberpunk neon styling
- CSS gradient text masking
- Hover glow interaction
- Responsive design
- Reduced-motion accessibility support
- No external dependencies
