# Hologram Metric Cards

This submission demonstrates a futuristic metric card UI built with **EaseMotion CSS**.
It includes animated circular progress rings, hover lift effects, staggered entrance
animation, and custom hologram styling.

## 🌟 Features

- **Circular progress rings** built with pure CSS `conic-gradient`.
- **Staggered entrance animation** using `ease-slide-up` and delay utilities.
- **Hover lift effect** using `ease-hover-lift`.
- **Button hover animation** using `ease-hover-grow`.
- **Custom hologram sweep animation** using original CSS keyframes.
- **Responsive grid layout** for desktop, tablet, and mobile.
- **Accessible progress values** using `role="progressbar"` and ARIA attributes.
- **Reduced motion support** for users who prefer less animation.

## 📁 Files

- `demo.html` — interactive hologram metric card demo
- `style.css` — original hologram and ring styling
- `README.md` — documentation for this submission

## 🛠️ How to Run

1. Open `demo.html` in your browser.
2. Watch the cards enter with staggered animation.
3. Hover over the cards to see the lift effect.
4. Hover over the buttons to see the grow effect.
5. Resize the browser window to check responsive behavior.
