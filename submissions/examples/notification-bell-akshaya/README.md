# Animated Notification Bell

A reusable notification bell component for EaseMotion CSS with a CSS
bell swing animation, pulsing notification badge, and interactive
notification dropdown.

The component uses CSS for visual animations and lightweight vanilla
JavaScript for interaction.

## Features

- Animated notification bell
- Bell swing animation
- Pulsing notification badge
- Automatic badge hiding when count reaches zero
- Interactive dropdown panel
- Read and unread notification states
- Light mode support
- Dark mode support
- Keyboard accessible
- ARIA attributes for notification state
- Reduced-motion support
- Responsive mobile layout
- No third-party dependencies
