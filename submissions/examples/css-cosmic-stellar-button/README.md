# CSS Cosmic Stellar Button

A futuristic button featuring a deep space cosmic glow utilizing highly blurred, continuously rotating gradient pseudo-elements.

## Features
- Infinite rotating nebula border created by sweeping a `conic-gradient` via `transform: rotate`.
- Outer space glow effect achieved by duplicating the conic gradient and applying an intense `filter: blur(20px)`.
- Interactive core that turns transparent on hover to reveal the cosmic energy underneath the text.
