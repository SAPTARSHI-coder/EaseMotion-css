# CSS Skew-Active Progress Bar

A responsive **Skew-Active Progress Bar** built using pure HTML5 and CSS3 for dashboard layouts. The progress bars animate with a skewed fill effect and a subtle shimmer to highlight active progress.

---

## ✨ Features

- Pure HTML5 & CSS3
- Skewed animated progress fill
- Shimmer sweep effect
- Responsive dashboard layout
- CSS Custom Properties
- Multiple progress examples
- Lightweight and performant
- `prefers-reduced-motion` support
- No JavaScript required
