# Product Catalog Blur-Entrance Toast

A lightweight, pure HTML/CSS Blur-Entrance Toast designed for modern
product catalog and e-commerce layouts.

## Features

- Pure HTML and CSS
- No JavaScript or external frameworks
- Smooth blur-and-fade entrance animation
- CSS-only toast dismissal
- Product catalog showcase
- Animated visual product cards
- Responsive desktop, tablet, and mobile layout
- CSS custom properties for customization
- Keyboard-friendly focus states
- `prefers-reduced-motion` support
