# CSS Float-Drift Stepper for Responsive Dashboard Layouts

A modern **Float-Drift Stepper** component built using only **HTML5 and CSS3**.

This example showcases a dashboard stepper with smooth floating animations, glassmorphism cards, gradient indicators, responsive layouts, and accessibility support without JavaScript.

---

## ✨ Features

- 🌊 Smooth float-drift animation
- 📌 Step-based dashboard layout
- 💡 Interactive glow effects
- 🎨 Gradient step indicators
- ⚡ Pure CSS implementation
- 📱 Fully responsive design
- 🎯 CSS Custom Properties
- ♿ `prefers-reduced-motion` support
- 🚫 Zero JavaScript dependency

## 🚀 Usage

1. Open `demo.html` in any modern browser.
2. View the animated stepper component.
3. Hover over cards for interactive effects.
4. Customize colors through CSS variables.
