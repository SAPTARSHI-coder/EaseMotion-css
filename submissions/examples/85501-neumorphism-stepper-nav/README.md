# Glowing Stepper Nav – Neumorphism

A modern **Glowing Stepper Navigation** component built with **pure HTML and CSS**, combining soft **Neumorphism** styling with subtle glow effects, smooth transitions, and a fully responsive layout.

## Features

- 🎨 Soft neumorphic interface
- ✨ Glowing active step indicator
- ✅ Completed step highlighting
- 📱 Fully responsive (desktop, tablet, mobile)
- 🌈 CSS Custom Properties for easy theming
- 🎯 Smooth hover and focus transitions
- ♿ Accessible markup using `aria-current="step"`
- 🎭 Supports `prefers-reduced-motion`
- 🚫 No JavaScript required

## Customization

You can easily customize the appearance by editing the CSS variables in `:root`:

- Primary glow color
- Accent color
- Background color
- Surface elevation
- Shadow intensity
- Border radius
- Animation timing
