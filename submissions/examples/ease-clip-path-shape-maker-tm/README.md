# Clip Path Shape Maker Component

Add ease-clip-path-shape-maker-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|--------|
| `--cp-accent` | `#6366f1` |
| `--cp-radius` | `12px` |
| `--cp-shadow` | `0 8px 32px rgba(0,0,0,.4)` |

## Technique

`clip-path` CSS property creates geometric shapes by clipping the element's visible area.
