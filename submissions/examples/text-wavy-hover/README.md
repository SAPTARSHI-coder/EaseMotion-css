# Text Wavy Hover

Letters form a wave as the pointer glides across the heading.

## Features
- Per-letter wave by position
- Pointer-tracked with CSS var
- Smooth translateY cascade
- Pure CSS

## Usage
```html
<div class="twh-word"><span style="--i:0">W</span></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
