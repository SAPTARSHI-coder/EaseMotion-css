# Ease Advanced Gesture-Driven Mobile Bottom Sheet

A gesture-driven mobile bottom sheet with velocity-aware snapping,
rubber-band resistance and spring-style transitions.

## Features

- Drag-to-open bottom sheet
- Drag-to-close bottom sheet
- Touch and mouse support
- Pointer Events API
- Velocity-aware gesture detection
- Spring-style snapping
- Rubber-band resistance
- Expanded and collapsed states
- Click outside to close
- Escape key support
- Keyboard arrow support
- Responsive mobile-first layout
- Reduced-motion support
- No external dependencies
