# CSS Spring Physics Tabs for SaaS Showcase

A pure CSS animated tabs component designed for modern SaaS showcase
interfaces.

The component combines spring-inspired hover interactions, animated tab
content transitions, and a responsive SaaS dashboard presentation.

## Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Spring-inspired interactions
- Animated content panels
- Responsive SaaS showcase layout
- Keyboard focus support
- Reduced-motion support
- Customizable CSS animation variables
- Self-contained browser demo

## Demo

Open `demo.html` directly in a browser.

No server, build tool, or package installation is required.
