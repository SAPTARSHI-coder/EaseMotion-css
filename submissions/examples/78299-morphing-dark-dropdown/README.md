# Morphing Dropdown with Dark Mode Styling

A responsive CSS-only dropdown component featuring a dark-mode interface and smooth morphing interactions.

## Features

- Dark-mode visual design
- Smooth morphing dropdown animation
- Pure HTML and CSS
- No JavaScript dependency
- Responsive layout
- Hover interaction
- Keyboard focus support
- Accessible focus-visible states
- Reduced-motion support
- Modern shadows, borders and gradients

## Files

- `demo.html` — component markup and demo
- `style.css` — complete styling and animations

## Usage

Open `demo.html` directly in a browser to preview the component.

The dropdown opens on hover and keyboard focus, making it usable without JavaScript.

## Accessibility

The component includes visible keyboard focus styles and respects the user's `prefers-reduced-motion` setting.
