# Fluid Morphing Blob Mask

1. What does this do? Continuously morphs the `border-radius` of an element to create an organic, fluid, liquid-like blob effect.
2. How is it used? Apply `.fluid-blob-morph` to any block element, container, or image.
3. Why is it useful? Organic shapes are very popular in modern web design. Providing a utility class that instantly turns a rigid box into a breathing, animated shape gives developers an advanced design token out-of-the-box.
