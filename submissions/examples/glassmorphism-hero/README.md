# CSS Glassmorphism Hero

A modern responsive hero section featuring a frosted glass content card over a blurred background.

## ✨ Features

- Pure HTML and CSS
- Glassmorphism UI
- Frosted glass effect
- Responsive layout
- Animated hero entrance
- Floating background effects
- Gradient typography
- Interactive buttons
- Keyboard-accessible focus states
- Reduced-motion support
- Backdrop-filter fallback
- No JavaScript required
- Dark-mode friendly design
