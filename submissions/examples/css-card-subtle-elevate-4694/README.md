# Subtle Elevate Card

### What does this do?
This submission provides a smooth, hardware-accelerated "subtle elevate" hover effect for cards, fully compatible with dark mode.

### How is it used?
Apply the `.subtle-elevate-card-4694` class to your card container element:
```html
<div class="subtle-elevate-card-4694">
  <h2>Card Title</h2>
  <p>Card content goes here.</p>
</div>
```

### Why is it useful?
It creates a tactile, premium user experience with performant, hardware-accelerated transitions that gracefully adapt to both light and dark themes, perfectly aligning with EaseMotion CSS's focus on smooth, high-quality micro-interactions.
