CSS-Only · @property · No JavaScript

ease-spotlight-card

A radial gradient "spotlight" that sweeps across dark cards on hover — built entirely in CSS using @property, radial-gradient, and mix-blend-mode: overlay. No JavaScript. No libraries.

✦

@property Power

CSS registered custom properties let the browser interpolate --x and --y as <percentage> values — enabling silky gradient animation without a single line of JS.

⬡

mix-blend-mode Overlay

The spotlight pseudo-element uses mix-blend-mode: overlay so the glow softly reveals card content rather than blowing it out — just like a real studio spotlight.

Browser Support & Limitations: @property is supported in Chrome 85+, Edge 85+, Firefox 128+, and Safari 16.4+. On unsupported browsers the spotlight gracefully falls back to a subtle center-glow on hover — no layout breaking, no JavaScript error. Because true pixel-perfect mouse tracking requires a mousemove event, the CSS-only technique sweeps --x and --y via @keyframes, producing a convincing orbital animation rather than direct cursor follow.
