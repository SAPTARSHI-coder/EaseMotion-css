# Hover Blur Sharp

A row of items are slightly blurred; the hovered one snaps into focus.

## Features
- Blur siblings with focus-sharp hover
- Smooth scale emphasis
- Gallery-style interplay
- Pure CSS

## Usage
```html
<div class="hbs-item">A</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
