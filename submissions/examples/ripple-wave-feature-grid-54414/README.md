# Ripple Wave Feature Grid

A lightweight feature grid built with pure HTML and CSS. Each card displays a smooth ripple-wave animation on hover, creating an engaging yet accessible user experience.

## Features

- Pure HTML5 & CSS3
- Ripple-wave hover animation
- Responsive CSS Grid layout
- Smooth hover transitions
- CSS custom properties for customization
- No JavaScript required
- Supports `prefers-reduced-motion`

## CSS Custom Properties

```css
--primary
--background
--surface
--text
--muted
--shadow
--radius
--animation-speed
```

## Accessibility

Animations are automatically disabled for users who enable **Reduce Motion**, while maintaining the layout and usability.

## Browser Support

Compatible with modern browsers supporting CSS Grid, animations, custom properties, and media queries.
