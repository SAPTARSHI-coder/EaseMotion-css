# CSS Text: Velvet Smooth Transition

An elegant text animation featuring silky gradient movement and gentle floating motion for a refined visual experience.

## Features

- Pure HTML & CSS
- Velvet-inspired gradient animation
- Smooth transition effects
- Hardware accelerated
- Responsive typography
- Dark mode compatible
- Accessible implementation

## Usage

```html
<h1 class="velvet-text">
    Velvet Motion
</h1>
```

## Files

- demo.html
- style.css

## EaseMotion CSS

This animation focuses on fluid motion and visual elegance while remaining lightweight, reusable, and fully CSS-powered.
