# Responsive Navbar with Dark Mode

1. **What does this do?**
   This component provides a fully responsive navigation bar with a built-in dark mode toggle that switches CSS variables for seamless theme transition.

2. **How is it used?**
   Include the `<nav class="navbar ease-navbar-dm">` container at the top of your document. It contains a `.nav-logo`, a `.nav-menu` for links, and a `.theme-toggle` button for switching themes.

3. **Why is it useful?**
   It provides a highly requested, modern UI pattern (responsive menu + dark mode) aligning with EaseMotion's philosophy of accessible, easily integrable components.
