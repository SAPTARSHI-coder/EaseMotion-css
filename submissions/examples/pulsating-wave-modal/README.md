# CSS Modal: Pulsating Wave

A smooth, accessible, and performant modal component featuring a
**Pulsating Wave** visual effect using only HTML and Vanilla CSS.

## Features

- Pure HTML and CSS
- No JavaScript required
- Pulsating wave animations
- Layered expanding waves
- Smooth modal entrance animation
- Animated glow effect
- Responsive design
- Dark-mode-friendly appearance
- Hardware-accelerated transforms
- Accessible dialog structure
- Keyboard focus indicators
- Reduced-motion support
- No external dependencies
