# CSS 3D Perspective Tilt Form

Issue #73343 demonstrates a dimensional form using CSS perspective and controlled transforms.

## Features

- Perspective depth
- Subtle hover tilt
- Native form controls
- Responsive layout
- Visible focus states
- Reduced-motion fallback

## Accessibility

The form remains semantic and keyboard accessible. Transform motion is disabled when reduced motion is preferred.

## Files

- `demo.html` — form demonstration
- `style.css` — perspective and interaction styling
- `README.md` — documentation
