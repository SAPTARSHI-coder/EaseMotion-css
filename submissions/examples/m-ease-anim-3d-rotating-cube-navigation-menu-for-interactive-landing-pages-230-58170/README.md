# 3D Rotating Cube Navigation Menu (Vibrant Gradient Version)

A modern **3D Rotating Cube Navigation Menu** featuring vibrant gradient faces, glowing effects, and smooth CSS animations. Built using pure HTML and CSS for the EaseMotion CSS examples collection.

## ✨ Features

- Pure HTML5 & CSS3
- Animated 3D rotating cube
- Vibrant gradient UI
- Glassmorphism cube faces
- Gradient glow background
- Responsive layout
- CSS Custom Properties
- `prefers-reduced-motion` support
- No JavaScript required
