ease-accordion-expand

An accordion that smoothly expands and collapses panels using grid-template-rows height transitions.

EaseMotion CSS is a curated, animation-first CSS framework. Contributors submit raw HTML/CSS demos; the maintainer standardizes them into the framework.

The panel animates grid-template-rows from 0fr to 1fr, so it grows to its natural content height without measuring it in JavaScript.
