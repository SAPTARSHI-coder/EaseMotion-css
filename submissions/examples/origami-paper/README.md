
---

## 🚀 Usage
1. Clone or copy the files into your project.
2. Open `index.html` in your browser.
3. Watch the paper fold animation with smooth blur effects.

---

## 🛠️ Customization
- **Fold angles** → Adjust degrees in `@keyframes fold`.
- **Duration** → Change `animation: fold 4s` for faster/slower folding.
- **Paper size** → Modify `.paper` width/height for different dimensions.
- **Blur strength** → Tweak `backdrop-filter` values for stronger/weaker frosted look.

---

## 📖 Accessibility
- Large visual element for clear visibility.
- Smooth motion avoids harsh flicker.
