# Fire Bellows Hearth

## What does this do?
Renders a self-contained CSS-only `ease-fire-bellows-hearth` demo: Hearth bellows feeding oxygen to dancing flames.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-fire-bellows-hearth`. No build step or JavaScript is required for the effect.

```html
<section class="ease-fire-bellows-hearth">
  <div class="ease-fire-bellows-hearth__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
