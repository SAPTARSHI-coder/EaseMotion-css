\# Button Loading State Component (`ease-btn-loading-ak`)



A modern, responsive pure CSS button loading state component featuring smooth spinners and pulse animations built for \*\*EaseMotion CSS\*\*.



\## Features

\- \*\*Keyframe Spinner \& Pulse\*\*: Smooth infinite rotation spinners and pulsing states for asynchronous action flows.

\- \*\*Custom CSS Variables\*\*: Control timing parameters, background colors, and easing curves globally via `--btn-timing`, `--btn-bg`, and `--btn-easing`.

\- \*\*Keyboard \& Accessibility Ready\*\*: Fully complies with `@media (prefers-reduced-motion: reduce)`.

\- \*\*Zero JavaScript Dependencies\*\*: Powered completely by high-performance native CSS classes and animations.



\## Quick Usage

1\. Place this folder under:

&#x20;  `submissions/examples/button-loading-state-ak/`
