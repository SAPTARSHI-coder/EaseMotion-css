# Particle Burst Dropdown

A smooth, interactive dropdown menu featuring a **Particle Burst** animation.

The component uses pure HTML and vanilla CSS with no JavaScript or external dependencies.

## ✨ Features

- Pure HTML and CSS
- No JavaScript required
- Animated particle burst when opened
- Multiple particle directions
- Smooth dropdown transition
- Staggered menu item entrance
- Interactive hover states
- Native `<details>` / `<summary>` interaction
- Dark-mode friendly styling
- Responsive layout
- Hardware-friendly CSS transforms
- `prefers-reduced-motion` support
- Accessible focus indicators
- Dependency-free
