# Woodcut Baren Press

## What does this do?
Renders a self-contained CSS-only `ease-woodcut-baren-press` demo: Woodcut baren circular press strokes.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-woodcut-baren-press`. No build step or JavaScript is required for the effect.

```html
<section class="ease-woodcut-baren-press">
  <div class="ease-woodcut-baren-press__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
