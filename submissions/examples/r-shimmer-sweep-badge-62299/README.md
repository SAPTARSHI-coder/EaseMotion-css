# CSS Shimmer-Sweep Badge

A lightweight pure CSS shimmer-sweep badge designed for product catalog
layouts.

## Features

- Pure HTML and CSS
- No JavaScript dependencies
- Smooth shimmer-sweep animation
- Glassmorphism product card
- Responsive desktop, tablet, and mobile layout
- Interactive product card and button states
- Accessible keyboard focus styles
- `prefers-reduced-motion` support
