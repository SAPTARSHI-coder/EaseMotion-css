# Biometric Retinal Scanner HUD Component

## What does this do?
This component provides a futuristic, high-tech biometric retinal scanner Heads-Up Display (HUD) interface built purely with CSS keyframe animations and HTML5. It features dual counter-rotating scan rings, vertical laser scanning sweep, and glowing telemetry meters.

## How is it used?
Include `style.css` in your webpage and insert the `.hud-container` markup structure where security authorization UI or futuristic authentication widgets are required.

## Why is it useful?
- Pure CSS performance (hardware-accelerated transforms and opacity transitions).
- Zero JavaScript overhead for visual rendering.
- Highly customizable HUD telemetry theme using standard CSS custom properties (`--hud-cyan`, `--hud-green`).
