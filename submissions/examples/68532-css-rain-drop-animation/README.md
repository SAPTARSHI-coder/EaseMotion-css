# CSS Rain Drop Animation

## Overview

A pure CSS weather scene with staggered raindrops and landing ripple rings.

## Features

- Multiple independently delayed raindrops
- Variable falling speeds
- CSS cloud layers
- Ripple effects at ground level
- Responsive scene sizing
- Reduced-motion support
- No JavaScript or external assets

## Files

- `demo.html` — rain scene structure
- `style.css` — drops, clouds, ripples, animation timing, and responsive rules
- `README.md` — documentation

## Accessibility

The animated decoration is hidden from assistive technology with `aria-hidden`, while the scene has a meaningful accessible label. Reduced-motion users receive a non-animated presentation.
