Outline Layout Shift Fix

Solving the incredibly common UI bug where adding a border on hover awkwardly expands the element, causing surrounding layouts and sibling elements to dynamically jitter and shift.

The Border Jitter (Buggy)

Hover over the cards below. Because adding a border: 4px solid increases the physical box model size, all adjacent elements are violently shoved out of the way!

The Outline Solution (Fixed)

By using the outline property instead of border, the highlight is drawn outside the element's box model without affecting layout calculations, completely eliminating jitter.
