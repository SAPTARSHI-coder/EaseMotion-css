# CSS Countdown Timer

A responsive countdown timer UI built with HTML and CSS.

## Features

- Pure HTML and CSS
- No JavaScript required
- Displays days, hours, minutes and seconds
- Responsive layout
- Light and dark mode support
- Hover animation
- Reduced-motion support
- Semantic HTML and accessibility-friendly labels
- CSS custom properties for easy theming
