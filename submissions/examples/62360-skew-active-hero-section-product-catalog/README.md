# CSS Skew-Active Hero Section for Product Catalog Layouts

A modern **Skew-Active Hero Section** component built using pure HTML5 and CSS3 for product catalog showcase layouts. This component creates an engaging hero experience with skew transformations, smooth hover interactions, animated product visuals, and responsive behavior.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Modern product catalog hero layout
* Skew transform active animation
* Smooth hover transition effects
* Animated product showcase card
* Glassmorphism UI styling
* Gradient glow background effects
* Interactive CTA buttons
* Responsive desktop, tablet, and mobile layouts
* CSS Custom Properties for easy customization
* Lightweight keyframe animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over the product card to see the skew-active interaction.
3. Customize colors, shadows, spacing, and animation values using CSS variables inside `:root`.

## CSS Custom Properties

```css
:root{
  --bg:#eef4ff;
  --surface:rgba(255,255,255,.92);
  --primary:#2563eb;
  --secondary:#06b6d4;
  --accent:#8b5cf6;
  --text:#111827;
  --muted:#64748b;
  --shadow:0 30px 80px rgba(37,99,235,.2);
  --radius:30px;
}
```
