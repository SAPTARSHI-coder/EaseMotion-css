# CSS Nav: Neumorphic Soft Shadow Variation

A pure CSS navigation component featuring a soft neumorphic visual
language with tactile shadows, inset surfaces, smooth interactions,
and responsive behavior.

## ✨ Features

- Neumorphic soft-shadow navigation
- Raised and inset visual states
- Active navigation state
- Smooth hover interactions
- Keyboard focus states
- Responsive navigation layout
- Dark-mode compatible styling
- Subtle depth visualization
- Reduced-motion support
- Hardware-friendly CSS transforms
- No JavaScript
- No external dependencies

## 🎨 Design

The component uses paired light and dark shadows to create a tactile
interface without relying on heavy borders.

The main visual techniques include:

- Raised surfaces
- Inset surfaces
- Soft directional shadows
- Subtle gradients
- Rounded navigation controls
- Layered depth visualization

## 🧭 Navigation

The navigation includes:

- Home
- Components
- Patterns
- About
- Get Started

The active navigation item uses an inset shadow treatment to create
a pressed/tactile appearance.

## ♿ Accessibility

The component includes:

- Semantic `<nav>` markup
- Descriptive navigation label
- Native anchor elements
- Keyboard navigation
- Visible `:focus-visible` states
- Reduced-motion support
- Accessible brand label

## 📱 Responsive Behavior

The component adapts across screen sizes.

Large screens use a horizontal navigation layout.

Medium screens allow navigation links to occupy a dedicated row.

Small screens hide secondary link labels and preserve their icons
to maintain a compact navigation layout.

## ⚡ Performance

The visual effects use CSS transitions and transforms rather than
JavaScript-driven animation loops.

No animation library is required.

## 🛠️ Technologies

- HTML5
- Vanilla CSS
