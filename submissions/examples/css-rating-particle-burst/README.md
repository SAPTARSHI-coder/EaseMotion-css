# CSS Rating Component: Particle Burst

A responsive **Pure CSS Rating Component** featuring a **Particle Burst** interaction. Selecting or hovering over a star creates a glowing burst-inspired animation using only HTML and CSS.

## Features

- ⭐ Interactive 5-star rating
- ✨ Particle burst animation
- 🎨 Pure HTML & Vanilla CSS
- 📱 Responsive layout
- 🌙 Dark mode compatible
- ⚡ Hardware-accelerated transforms
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript

## Folder Structure

## Usage

```html
<link rel="stylesheet" href="style.css">
```

```html
<div class="rating">
    <!-- Star inputs and labels -->
</div>
```
