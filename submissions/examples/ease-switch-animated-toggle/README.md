# EaseMotion CSS – Animated Toggle Switch

## Overview

The **Ease Switch Animated Toggle Component** is a lightweight, CSS-only toggle switch inspired by modern iOS and Material Design switches. It uses a native HTML checkbox with pure CSS animations, making it accessible, responsive, and easy to integrate into any project.

No JavaScript or external libraries are required.

---

## Features

- 🎯 Pure CSS implementation
- ✨ Smooth thumb sliding animation
- 🎨 Animated background color transition
- ♿ Accessible native checkbox
- 🚫 No JavaScript required
- 📱 Responsive design
- 🔧 Easy to customize
- 💡 Lightweight and reusable

## HTML Usage

```html
<label class="ease-switch">
    <input type="checkbox">
    <span class="switch-track">
        <span class="switch-thumb"></span>
    </span>
</label>
```

---

## CSS Classes

| Class | Description |
|--------|-------------|
| `.ease-switch` | Wrapper for the toggle switch |
| `.switch-track` | Background track of the switch |
| `.switch-thumb` | Sliding circular thumb |
