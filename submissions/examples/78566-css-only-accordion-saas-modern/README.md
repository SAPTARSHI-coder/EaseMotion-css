# CSS-only Accordion with SaaS Modern Styling

A clean and responsive accordion component designed for modern SaaS interfaces.

## Features

- CSS-only accordion interaction
- Native HTML `details` and `summary`
- Modern SaaS-inspired visual design
- Clean borders and subtle shadows
- Responsive desktop, tablet, and mobile layouts
- Smooth open-state animation
- Keyboard focus styling
- Reduced-motion support
- No external dependencies
- Easy to customize

## Usage

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css" />
