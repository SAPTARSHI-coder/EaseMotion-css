# Holographic Flicker Loader

A polished CSS-only loading animation featuring a holographic
flicker effect with rotating gradients, glowing layers, and a
moving scan line.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript
- No external dependencies
- Holographic gradient animation
- Flickering glow effect
- Animated scan line
- Responsive design
- Light and dark mode compatible
- Hardware-friendly transforms
- Accessible loading status
- Reduced-motion support
