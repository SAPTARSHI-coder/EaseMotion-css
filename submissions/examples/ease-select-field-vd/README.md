# Ease Select Field

## What does this do?

A styled select field with a custom dropdown indicator, focus state, and responsive design.

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<div class="select-wrapper">
    <select id="country">
        <option value="">Select a country</option>
        <option>India</option>
        <option>United States</option>
    </select>

    <span class="select-arrow">⌄</span>
</div>
```

### Features

- Label
- Select control
- Custom dropdown indicator
- Hover state
- Focus state
- Responsive design
- Pure CSS
- No JavaScript required

## Why is it useful?

Styled select fields are commonly used in forms, filters, settings pages, and configuration interfaces.

This component provides a clean and reusable select field with subtle interaction feedback while following the animation-first philosophy of EaseMotion CSS.
