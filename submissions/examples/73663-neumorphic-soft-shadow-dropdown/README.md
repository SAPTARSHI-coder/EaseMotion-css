# CSS Dropdown: Neumorphic Soft Shadow

A pure HTML and Vanilla CSS dropdown featuring a tactile
**Neumorphic Soft Shadow** visual style.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript
- Semantic `<details>` and `<summary>` interaction
- Soft dual-shadow neumorphic design
- Raised and pressed states
- Smooth dropdown reveal animation
- Interactive hover and active states
- Keyboard-friendly controls
- Visible focus states
- Responsive layout
- Light and dark mode support
- Reduced-motion support
