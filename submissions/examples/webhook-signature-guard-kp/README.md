# Webhook Signature Guard

An advanced EaseMotion example for monitoring distributed Guard Reguards, verify debt, retry pressure, and Timestamp margin recovery.

## Features

- Interactive controls for guard risk, verify debt, retry pressure, and Timestamp margin health.
- Animated radar, Webhook lanes, recovery metrics, Reguard timeline, decision matrix, and audit ledger.
- State-driven stable, watch, Guard, and recovered modes.
- Responsive CSS-only dashboard built with `demo.html`, `style.css`, and this `README.md`.
