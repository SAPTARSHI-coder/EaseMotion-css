# Glowing Progress Bar

Documentation showcase for issue #78666.

## Files

- `demo.html` — accessible live example.
- `style.css` — component styling and responsive behavior.

## Features

- Glowing progress indicator.
- Semantic progress markup.
- Responsive layout.
- Keyboard-friendly controls.
- Reduced-motion support.

## Usage

Open `demo.html` directly in a browser. Adjust the progress value in the markup to demonstrate different completion states.
