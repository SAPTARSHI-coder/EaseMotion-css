# Hover Border Radius Morph

1. **What does this do?**
   Smoothly changes an element from a smaller border radius to a larger rounded shape when it is hovered.

2. **How is it used?**
   Apply the `.hover-radius-morph` class to an element you want to morph on hover.

   ```html
   <div class="hover-radius-morph">
     Hover Me
   </div>
   ```

3. **Why is it useful?**
   It provides a simple, readable, and composable hover interaction that fits EaseMotion CSS's animation-first philosophy.
