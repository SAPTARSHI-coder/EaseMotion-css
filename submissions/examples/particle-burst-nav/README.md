# Particle Burst Navigation

A smooth and interactive navigation component featuring a
particle burst effect built entirely with HTML and vanilla CSS.

## ✨ Features

- 🎨 Particle burst hover effect
- ⌨️ Keyboard accessible
- 🌙 Automatic dark mode support
- 📱 Responsive navigation
- ⚡ GPU-friendly CSS transforms
- ♿ Reduced-motion support
- 🚫 No JavaScript
- 🚫 No external dependencies
