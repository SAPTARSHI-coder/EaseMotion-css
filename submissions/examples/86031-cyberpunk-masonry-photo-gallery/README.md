# Cyberpunk Masonry Photo Gallery

A responsive cyberpunk-themed masonry photo gallery with customizable
CSS variables and accessible image markup.

## Features

- Responsive masonry layout
- Cyberpunk neon theme
- CSS custom property theming
- Hover effects
- Responsive breakpoints
- Semantic `<figure>` and `<figcaption>` elements
- Descriptive image alt text
- Reduced-motion support

## HTML Usage

```html
<main class="gallery" aria-label="Cyberpunk photo gallery">
  <figure class="gallery-item">
    <img
      src="image.jpg"
      alt="Cyberpunk city architecture"
    >
    <figcaption>Neon District</figcaption>
  </figure>
</main>
