# CSS Slide-Up Tooltip for SaaS Showcase Layouts

A modern **Slide-Up Tooltip** component built using pure HTML and CSS. The tooltip smoothly slides upward into view while using a clean glassmorphism design, making it ideal for SaaS dashboards, admin panels, and product showcases.

## ✨ Features

- Pure HTML5 & CSS3
- Slide-up entrance animation
- Glassmorphism tooltip
- Responsive layout
- Smooth hover transitions
- CSS Custom Properties
- `prefers-reduced-motion` support
- No JavaScript required
