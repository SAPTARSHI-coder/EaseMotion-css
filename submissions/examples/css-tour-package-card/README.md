# CSS Tour Package Card (#70809)

A responsive tour package card component featuring highlights, price, and duration, designed with zero JavaScript.

## Features
- **Semantic Structure:** Uses `<article>` with accessibility support and keyboard navigation.
- **Pure CSS Styling:** Modern layout using CSS variables, custom flex alignments, and smooth hover transformations.
- **Responsive Design:** Fluid layout suitable for all display viewports.

## File Hierarchy
- `style.css` - Layout, typography, and card styling.
- `demo.html` - Semantic markup and accessible structure.
- `README.md` - Technical specification and architecture overview.
