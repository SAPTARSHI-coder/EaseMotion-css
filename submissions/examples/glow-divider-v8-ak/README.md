# glow-divider-v8-ak

Pure CSS animated glowing gradient line divider component — no JavaScript required.

## How to use

```html
<hr class="ease-glowing-divider-v8" />

<!-- Divider with Badge -->
<div class="ease-glowing-divider-text-v8">
  <span class="ease-glowing-divider-badge-v8">OR</span>
</div>
