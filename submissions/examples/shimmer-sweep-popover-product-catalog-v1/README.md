# CSS Shimmer-Sweep Popover for Product Catalog Layouts

A modern **Shimmer-Sweep Popover** component built with pure HTML5 and CSS3 for the EaseMotion CSS project. The popover reveals product information with a smooth shimmer sweep animation, creating an elegant interactive shopping experience.

---

## ✨ Features

- Pure HTML5 & CSS3
- Smooth shimmer sweep animation
- Modern glassmorphism popover
- Responsive product catalog layout
- CSS custom properties for easy customization
- Hover interactions with smooth transitions
- Supports `prefers-reduced-motion`
- No JavaScript required
