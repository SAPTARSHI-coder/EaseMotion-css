# CSS Bounce-Pulse Hero Section for Product Catalog Layouts

A modern **Bounce-Pulse Hero Section** built using pure HTML and CSS. The component combines gentle bounce and pulse animations with a responsive hero layout for showcasing featured products.

## ✨ Features

- Pure HTML5 & CSS3
- Bounce + Pulse animations
- Responsive hero section
- Glassmorphism product card
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
