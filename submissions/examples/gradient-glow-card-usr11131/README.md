# Gradient Glow Card Submission

## 📝 Description
A visually striking card component featuring an animated gradient border and seamless hover interactions. This submission demonstrates how custom CSS animations can beautifully complement EaseMotion's utility classes (like `ease-hover-lift` and `ease-fade-in`).

## 🎯 Proposed Integration
- **Proposed Class Name:** `ease-card-glow-[YOUR_INITIALS]` (e.g., `ease-card-glow-am`)
- **Track:** `submissions/examples/`

## ✨ Features
- Animated gradient border using pure CSS `@keyframes`.
- Dark-mode optimized aesthetic.
- Utilizes existing EaseMotion classes for composition.
- ♿ Includes `prefers-reduced-motion` media query for accessibility compliance.

## 🚀 How to Test
1. Open `demo.html` in any modern web browser.
2. Observe the continuous gradient animation.
3. Hover over the card to see the combined effect of the custom glow and EaseMotion's `ease-hover-lift`.
