# Quantum Energy Shield Badges & Chips

A pure CSS implementation of smooth, accessible, and performant badges and chips featuring a futuristic **Quantum Energy Shield** styling.

## What it does

Provides status badges and interactive action chips with a dark-mode compatible, sci-fi energy shield aesthetic. Features include:
- Neon glowing borders and inset shadows.
- Translucent backdrop filters (`backdrop-filter: blur`).
- Hardware-accelerated hover scaling and pulsating animations.
- Scanner beam effects simulating a protective energy field.

## How to use it

1. Include the styles from `style.css` in your project.
2. Use the provided HTML structure. 
   
For a **Status Badge**:
```html
<span class="badge badge-quantum-blue" role="status" aria-label="Status: Active">Active</span>
```

For an **Action Chip**:
```html
<button class="chip chip-quantum" aria-label="Activate Shields">
  <span class="chip-icon">🛡️</span> Activate Shields
</button>
```

## Why it fits EaseMotion CSS

These components use advanced CSS features (`backdrop-filter`, complex `box-shadow` layering, and hardware-accelerated CSS animations) to deliver a high-quality visual experience without relying on external JavaScript. It aligns perfectly with the goal of providing ready-to-use, performant, and beautifully animated UI components.
