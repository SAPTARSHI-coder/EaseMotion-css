# CSS Accordion Reveal Animation

A pure CSS animation that reveals content using an accordion-style stretch effect. Elements expand vertically before settling into their final position, creating an engaging entrance animation.

## Features

- Pure HTML and CSS
- Accordion-style reveal effect
- Smooth staggered animations
- Responsive layout
- Lightweight and reusable
- No JavaScript required

## Usage

```html
<div class="reveal-card">
  <h2>Title</h2>
  <p>Content</p>
</div>
```

Include:

```html
<link rel="stylesheet" href="style.css">
```

## Customization

- Adjust reveal duration in `accordionReveal`
- Modify animation delays
- Change colors and shadows
- Use on cards, sections, panels, or dashboards

## Why it fits EaseMotion CSS

This submission demonstrates a reusable CSS-only entrance animation pattern that developers can apply to cards, content blocks, feature sections, and dashboards to create polished user experiences.
