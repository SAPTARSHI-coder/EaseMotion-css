# 3D-Flip Dropdown for Gaming Hub

A responsive gaming dropdown featuring a smooth CSS 3D flip entrance effect.

The component is built entirely with HTML and CSS and requires no JavaScript or external framework.

## Features

- Pure HTML and CSS
- CSS 3D perspective animation
- Flip-down dropdown entrance
- Smooth hover interactions
- Keyboard focus support
- Responsive design
- CSS custom properties
- No external dependencies
- `prefers-reduced-motion` support
- Suitable for gaming dashboards and navigation hubs
