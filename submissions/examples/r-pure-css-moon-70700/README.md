# CSS Pure CSS Moon

A glowing moon created entirely with HTML and CSS.

## Issue

#70700 — CSS Pure CSS Moon

## Description

This example creates a moon with surface craters and a soft atmospheric glow using pure CSS.

## Features

- Pure HTML and CSS
- No JavaScript
- CSS-created moon and craters
- Soft animated moon glow
- Twinkling background stars
- Responsive layout
- Accessible moon description
- Reduced-motion support
- No external dependencies

## Files

- `demo.html` — Demo markup
- `style.css` — Complete styling and animations

## How to Use

Open `demo.html` directly in a modern browser.

## CSS Techniques Used

- `radial-gradient()`
- `linear-gradient()`
- `box-shadow`
- `border-radius`
- CSS custom properties
- `@keyframes`
- Responsive media queries
- `prefers-reduced-motion`

## Accessibility

The moon includes an accessible description using an ARIA label. Decorative stars and the horizon are hidden from assistive technologies.

The animation is disabled when the user has enabled reduced motion preferences.

## Browser Support

Works in modern browsers supporting standard CSS gradients, animations, custom properties, and responsive media queries.
