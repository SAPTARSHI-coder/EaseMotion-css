# ✨ Mana Pool – Fill & Drain

> A dynamic mana pool component with fill and drain mechanics, visual state feedback, and keyboard shortcuts.

---

## 📖 Description

This project provides a fully functional mana pool UI that simulates a magic/resource system. The mana pool starts at 100% and can be **drained** or **filled** through button clicks or keyboard shortcuts. The component features:

- **Visual feedback** – smooth transitions, low-mana pulsing warning, and high-mana glowing effect
- **State awareness** – bar changes color and animation based on mana levels
- **Keyboard shortcuts** – quick interaction without mouse
- **Clamped values** – mana stays within 0–100 range

---

## 🚀 How to Use

1. Clone or download the repository.
2. Open `index.html` in any modern web browser.
3. Interact with the mana pool using:
   - **On-screen buttons** – click to drain, fill, or reset.
   - **Keyboard shortcuts**:
     - Press `D` → Drain 20
     - Press `F` → Fill 15
     - Press `R` → Reset to 100
