# Dynamic Loader with Material Design styling (#85828)

A dynamic Material Design spinner loader component featuring smooth SVG stroke dasharray and rotation animations built entirely with pure CSS.

## Features
- **Semantic Structure:** Uses accessible container elements with screen-reader friendly states.
- **Pure CSS Animation:** Combines infinite rotation with stroke-dasharray keyframe path scaling.
- **Responsive Layout:** Cleanly framed inside a centered modern card layout.

## File Hierarchy
- `style.css` - Keyframe animations, spinner styling, and color variables.
- `demo.html` - Semantic markup and accessibility attributes.
- `README.md` - Technical specification and architecture overview.
