# 3D-Flip Toast Product Catalog

A lightweight product catalog showcase featuring a CSS 3D-Flip Toast
interaction.

The component uses pure HTML and CSS with no JavaScript or external
frameworks.

## Features

- Pure HTML and CSS
- CSS 3D perspective
- 3D flip transition
- Keyframe animation
- Smooth transitions
- Responsive product catalog
- Desktop, tablet, and mobile layouts
- Keyboard focus support
- Visible focus states
- CSS custom properties
- `prefers-reduced-motion` support
- No external dependencies
