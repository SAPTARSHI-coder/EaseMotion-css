# CSS Bounce-Pulse Tooltip for Fintech Dashboard Layouts

A modern fintech dashboard tooltip component featuring smooth bounce-pulse animations, glowing financial cards, and responsive UI styling using pure HTML and CSS.

This component creates interactive financial insight cards without JavaScript or external dependencies.

## ✨ Features

- 💰 Fintech dashboard card design
- 🔄 Smooth bounce-pulse tooltip animation
- ✨ Animated floating information panels
- 🎨 Gradient glow effects
- 💎 Glassmorphism UI styling
- ⚡ Pure HTML and CSS implementation
- 📱 Fully responsive layout
- 🔄 Smooth CSS transitions
- ♿ Accessibility support with `prefers-reduced-motion`

## 🚀 Usage

1. Clone the EaseMotion CSS repository.

2. Navigate to:


submissions/examples/ease-css-bounce-pulse-tooltip-fintech-dashboard-layouts/


3. Open `demo.html` in any modern browser.

No JavaScript, frameworks, or external libraries are required.

## 🎨 CSS Custom Properties

The component uses CSS variables for easy customization:

```css
:root {
    --bg:#050816;
    --primary:#00f5ff;
    --secondary:#8b5cf6;
    --green:#22c55e;
    --text:#f8fafc;
    --muted:#94a3b8;
}

Update these variables to customize colors and branding.
