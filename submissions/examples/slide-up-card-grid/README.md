# CSS Slide-Up Card Grid

A responsive card grid featuring a smooth slide-up entrance animation using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Slide-up entrance animation
- Responsive card grid
- Hover elevation effect
- CSS Custom Properties
- No JavaScript required
- Supports `prefers-reduced-motion`

## Folder Structure

```
slide-up-card-grid/
├── demo.html
├── style.css
└── README.md
```

## CSS Variables

```css
--bg
--card
--text
--accent
--radius
--duration
```

## Usage

1. Open `demo.html`.
2. Cards slide into view on page load.
3. Hover over cards for an elevated interaction.

## Accessibility

- Responsive layout
- Semantic HTML
- `prefers-reduced-motion` support
