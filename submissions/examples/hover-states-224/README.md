# Interactive Heatmap Grid

A responsive and interactive heatmap grid component with neumorphic styling,
hover tooltips, activity levels, and mobile-friendly layout.

## Features

- Interactive heatmap cells
- Hover tooltip states
- Keyboard accessible cells
- Four activity intensity levels
- Neumorphic UI
- Responsive mobile-first layout
- Smooth hover animations
- Reduced-motion support
- No external libraries
