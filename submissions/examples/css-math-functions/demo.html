round()

Rounds a value to the nearest multiple of a step with control over the rounding strategy: nearest, up, down, or to-zero.

Rounding Strategy Comparison

round(nearest, 10px, 347px) → 350px

Rounds to the nearest step multiple — traditional mathematical rounding.

round(up, 12px, 114px) → 120px

Always rounds up — useful for ensuring minimum spacing or fitting content.

round(down, 8px, 29px) → 24px

Always rounds down — perfect for grid-tiling without overflow.

round(to-zero, 10px, 64px) → 60px

Rounds toward zero — same as down for positive values.

mod()

Returns the remainder after division with the same sign as the divisor. Creates infinite cyclic patterns without JavaScript.

rem()

Returns the remainder with the same sign as the dividend. Use when the dividend sign should dictate the result — useful for symmetrical polar layouts.
