# Neon Hover Buttons

A reusable collection of neon-style buttons with smooth glow animations
using pure CSS.

## Features

- Pure HTML and CSS
- No JavaScript
- Neon glow effect
- Multiple color variants
- Smooth hover animation
- Keyboard accessible
- Responsive design
- Reduced-motion support
- Customizable CSS variables

## Files

- `demo.html` - Button demonstration
- `style.css` - Button styles and animations
- `README.md` - Documentation
