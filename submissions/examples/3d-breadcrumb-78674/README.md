# 3D Breadcrumb

Material-inspired 3D breadcrumb navigation showcase for issue #78674.

## Files

- `demo.html` — semantic breadcrumb navigation.
- `style.css` — depth, separators, and responsive spacing.

## Features

- Semantic navigation landmark.
- Current-page indication.
- Layered 3D appearance.
- Keyboard-visible focus.
- Responsive wrapping.

The breadcrumb uses ordinary links, making the navigation functional even without visual effects.
