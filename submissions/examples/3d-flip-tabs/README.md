# CSS 3D Flip Tabs

A modern 3D Flip Tabs component designed for Gaming Hub layouts using pure HTML and CSS.

## Features

- Pure HTML & CSS
- 3D flip transition effect
- Responsive design
- CSS custom properties
- No JavaScript required
- Accessible with prefers-reduced-motion

## Folder Structure

```
3d-flip-tabs/
├── demo.html
├── style.css
└── README.md
```

## Usage

Open `demo.html` directly in a browser.

Click the tabs to view the 3D flip transition.

## CSS Variables

Customize:

- `--bg`
- `--surface`
- `--primary`
- `--text`
- `--duration`
