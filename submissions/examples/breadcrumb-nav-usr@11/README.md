# Animated Breadcrumb Navigation Submission

## 1. What does this do?
It provides a modern, animated breadcrumb navigation component with 4 different style variants (default, arrow, pill, minimal) and smooth entrance animations. Perfect for e-commerce, blogs, and documentation sites.

## 2. How is it used?
Wrap your breadcrumb links in a `<nav>` with `.breadcrumb-nav` class and an `<ol>` with `.breadcrumb-list`. Add `.breadcrumb-item` for each item and `.breadcrumb-current` for the active page. Use style variants like `.breadcrumb-arrow`, `.breadcrumb-pill`, or `.breadcrumb-minimal`.

## 3. Why is it useful?
- Essential navigation component for showing page hierarchy
- 4 different style variants for different design needs
- Smooth staggered entrance animations (fade, slide, scale)
- Fully accessible with proper ARIA labels and semantic HTML
- Hover effects with smooth transitions
- Mobile-responsive design
- Includes `prefers-reduced-motion` support for accessibility
- Easy to customize and extend
- Maintainer can easily standardize this as `.ease-breadcrumb-[YOUR_INITIALS]` in the core library.
