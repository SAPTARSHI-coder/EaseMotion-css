# Battering Ram Swing

## What does this do?
Renders a self-contained CSS-only `ease-battering-ram-swing` demo: Battering ram pendulum swing impact.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-battering-ram-swing`. No build step or JavaScript is required for the effect.

```html
<section class="ease-battering-ram-swing">
  <div class="ease-battering-ram-swing__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
