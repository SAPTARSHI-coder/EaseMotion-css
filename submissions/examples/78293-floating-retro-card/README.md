# Floating Card with Retro Styling

A responsive floating card component inspired by retro arcade,
synthwave, and classic 80s visual aesthetics.

## Features

- Pure HTML and CSS
- Retro synthwave visual style
- Layered 3D-style shadows
- Floating card animation
- Neon-inspired color palette
- Retro sun, mountains, and grid artwork
- Interactive button states
- Responsive layout
- Keyboard focus support
- Reduced-motion accessibility support
- No JavaScript dependency

## Files

- `demo.html` — component markup and demo
- `style.css` — complete styling and responsive behavior

## Usage

Open `demo.html` directly in a browser.

The card content, labels, button text, and links can be
customized for different applications.

## Responsive Behavior

The card scales with the viewport and switches from a
horizontal content layout to a stacked layout on smaller
screens.

The artwork also scales to maintain the retro composition
across desktop, tablet, and mobile devices.

## Accessibility

The component includes:

- Semantic article markup
- Descriptive page heading
- Keyboard-visible button focus
- Reduced-motion support through `prefers-reduced-motion`
