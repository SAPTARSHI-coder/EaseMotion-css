# Animated Loader with Pastel Styling (#78773)

A smooth, lightweight animated loader component featuring soft pastel tones and pure CSS keyframe animations.

## Features
- **Smooth Keyframe Animation:** Fluid scaling and opacity transitions with zero JavaScript overhead.
- **Soft Pastel Palettes:** Warm, accessible color scheme designed for modern UI workflows.
- **Fully Responsive:** Centered flex layout adapting seamlessly across device viewports.

## File Hierarchy
- `style.css` - Keyframe definitions, dot styling, and layout positioning.
- `demo.html` - Semantic markup demonstrating loader embedding with ARIA accessibility.
- `README.md` - Technical specification and architecture overview.
