# CSS Scale-Hover Dropdown for Product Catalog Layouts

A responsive dropdown component with smooth scale-hover animations built entirely using HTML and CSS. Designed for modern product catalog navigation interfaces.

## ✨ Features

- Pure HTML5 & CSS3
- Scale-hover interaction
- Smooth dropdown transition
- Responsive layout
- CSS Custom Properties
- Keyboard accessible using `:focus-within`
- `prefers-reduced-motion` support
- No JavaScript required
