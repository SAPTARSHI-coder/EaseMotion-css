# CSS Card with Gradient Shine

A modern card component featuring a diagonal gradient shine sweep animation on hover. The shine effect moves smoothly across the card surface, creating an engaging and premium visual interaction using only CSS.

## Features

- Pure CSS implementation
- Diagonal shine sweep animation on hover
- Responsive design
- Smooth transitions
- No JavaScript required
- Keyboard accessible
- Easy customization

## Usage

### HTML

```html
<div class="shine-card" tabindex="0">
  <h2>Gradient Shine Card</h2>
  <p>
    Hover over this card to see a smooth diagonal shine effect sweep
    across the surface.
  </p>
</div>
