# CSS Blur-Entrance Drawer for Product Catalog Layouts

A modern product catalog drawer built using only HTML and CSS. The drawer smoothly slides in from the right while removing an initial blur effect, creating an elegant product preview experience.

## Features

- Pure HTML & CSS
- Blur entrance drawer animation
- Responsive product grid
- Smooth transitions
- Accessible structure
- No JavaScript required
- CSS Custom Properties
- prefers-reduced-motion support
