# Diamond Facet Edge Particle Effect

What does this do?
This adds a smooth, hardware-accelerated 3D rotating diamond with facet edges that emits glowing particles, optimized for dark mode.

How is it used?
```html
<div class="diamond-container">
    <div class="particle p1"></div>
    <!-- Add more particles as needed -->
    <div class="diamond-facet"></div>
</div>
```

Why is it useful?
It provides a premium, lightweight, and visually striking particle animation without relying on JavaScript, aligning with EaseMotion's philosophy of pure, high-performance CSS interactions.
