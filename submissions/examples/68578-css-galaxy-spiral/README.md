# CSS Galaxy Spiral

## Overview

A dependency-free rotating galaxy scene built with CSS gradients, pseudo-elements, and transforms.

## Features

- Layered spiral arms
- CSS star fields
- Glowing galaxy core
- Orbital rings
- Responsive composition
- Reduced-motion support
- No external images or JavaScript

## Files

- `demo.html` — galaxy scene and descriptive content
- `style.css` — stars, spiral layers, animation, responsive layout, and accessibility rules

## Accessibility

The galaxy is decorative and marked accordingly. Descriptive text remains in normal document flow. Reduced-motion preferences disable the continuous animation.

## Usage

Open `demo.html` directly in a modern browser.
