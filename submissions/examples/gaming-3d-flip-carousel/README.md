# CSS 3D-Flip Carousel for Gaming Hub Layouts

A modern **Gaming Hub Carousel** built entirely with **HTML5 and CSS3**. This showcase demonstrates elegant **3D Flip** card animations with a neon gaming theme, responsive layouts, and accessibility support without requiring JavaScript.

---

## ✨ Features

- 🎮 Gaming Hub inspired carousel
- 🔄 CSS 3D Flip animation
- 🌈 Neon gradient accents
- 💎 Glassmorphism cards
- 🚀 Animated glowing icons
- 📱 Fully responsive
- ⚡ Pure HTML5 & CSS3
- 🎯 CSS Custom Properties
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

## 🚀 Getting Started

1. Open `demo.html` in any modern browser.
2. Hover over a card to trigger the 3D flip animation.
3. Explore the neon gaming UI and responsive layout.
4. Customize colors and animation timing using CSS variables.
