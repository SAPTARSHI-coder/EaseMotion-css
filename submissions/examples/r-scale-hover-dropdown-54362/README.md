# CSS Scale-Hover Dropdown

A modern **Scale-Hover Dropdown** built using pure HTML5 and CSS3 for accessible web layouts. The component features a smooth scale-hover dropdown animation, responsive navigation, and accessibility support without requiring JavaScript.

---

## ✨ Features

- Pure HTML5 & CSS3
- Scale-hover dropdown animation
- Smooth hover and keyboard interactions
- Responsive navigation layout
- CSS Custom Properties
- Lightweight and performant
- Accessible semantic HTML
- `prefers-reduced-motion` support
- No JavaScript required

## 🚀 Usage

1. Copy the component into your project.
2. Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

3. Open `demo.html` in your preferred browser.
