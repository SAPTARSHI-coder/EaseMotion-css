# EaseMotion CSS — Neumorphic Soft UI Controls (`ease-neumorphic-soft-ui-ik`)

Tactile neumorphic soft UI buttons, toggle switches, and icon controls (`ease-neu-btn`, `ease-neu-toggle`) featuring dual-shadow convex and inset box-shadow press transitions.

Submitted by: **@Ishita-Katiyar-06** (`-ik`)

---

## 1. What does this do?

Provides a set of tactile neumorphic soft UI component classes (`ease-neu-btn`, `ease-neu-toggle`, `ease-neu-icon-btn`) that transition smoothly between extruded surface shadows and inset pressed trough states.

---

## 2. How is it used?

Apply the neumorphic classes directly to buttons and form controls:

```html
<!-- Neumorphic Soft Button -->
<button class="ease-neu-btn">
  <span>Press Action</span>
</button>

<!-- Neumorphic Toggle Switch -->
<label class="ease-neu-toggle">
  <input type="checkbox" checked>
  <span class="toggle-slider"></span>
</label>
```

---

## 3. Why does it fit EaseMotion CSS?

EaseMotion CSS supports diverse modern design aesthetics. The Neumorphic Soft UI component set delivers realistic 3D tactile feedback using pure CSS dual box-shadow calculations with zero JavaScript runtime overhead.
