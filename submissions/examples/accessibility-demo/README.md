# EaseMotion CSS - WCAG 2.1 AA Light Theme Accessibility

An accessibility-focused light theme demonstration for EaseMotion CSS.

This implementation focuses on improving accessibility, keyboard
navigation, color contrast, screen-reader support, high-contrast mode,
and reduced-motion preferences.

---

## Features

- WCAG 2.1 AA focused light theme
- Accessible color contrast
- Keyboard navigation
- Visible keyboard focus indicators
- Skip-to-content navigation
- Semantic HTML
- Screen-reader-friendly structure
- ARIA live status announcements
- Windows forced-colors support
- Reduced-motion support
- Accessible form controls
- Responsive layout
- Minimum 44px interactive targets
- No external JavaScript dependencies
