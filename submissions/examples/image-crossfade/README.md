# Image Crossfade

Two images dissolve into one another in a slow crossfade loop.

## Features
- Opacity crossfade
- Staggered layer timing
- Equal geometry
- Pure CSS

## Usage
```html
<div class="icf-layer" style="--c:#ff7a7a"></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
