# Ease Tabs

## What does this do?

A horizontal tab navigation component with an animated active indicator.

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<div class="tabs">
    <button class="tab active">Overview</button>
    <button class="tab">Analytics</button>
    <button class="tab">Settings</button>
</div>
```

### Features

- Multiple tabs
- Active state
- Animated active indicator
- Hover interaction
- Responsive wrapping
- Pure CSS
- Lightweight and reusable

## Why is it useful?

Tabs are commonly used for dashboards, settings pages, documentation, and content navigation.

This component provides a clean navigation pattern with a subtle animated indicator while following the animation-first philosophy of EaseMotion CSS.
