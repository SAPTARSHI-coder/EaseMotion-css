# CSS Breathing Gradient Orb

A large ambient gradient orb that slowly expands and contracts using pure CSS animation.

## Features

- Pure HTML and CSS
- Slow breathing animation
- Multi-layer gradient composition
- Soft ambient glow
- Rotating gradient lighting
- Responsive sizing
- Reduced-motion support
- No JavaScript
- No external assets or libraries

Include the stylesheet:
