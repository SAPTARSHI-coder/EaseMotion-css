Accordion to auto

interpolate-size: allow-keywords enables smooth height transitions to auto.

What is interpolate-size?

A CSS property that tells the browser to allow interpolation to keyword values like auto, min-content, and fit-content. Without it, browsers can only animate to numeric values.

Why was this impossible before?

Browsers need a concrete starting and ending value to calculate intermediate frames. auto is a keyword representing a computed value — the browser couldn't interpolate through it. interpolate-size: allow-keywords tells the browser to resolve auto to its computed pixel value before animating.

Does this work with flex/grid?

Yes! It works with height, width, flex-basis, and any property that accepts sizing keywords. Combine with calc-size() for even more control.
