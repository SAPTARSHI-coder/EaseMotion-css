# Animated Navbar with Gradient styling (#78830)

A responsive, zero-JavaScript floating navbar component featuring an animated mesh gradient border, glassmorphic backdrop filtering, soft link hover pills, and interactive CTA buttons.

## Features
- **Infinite Gradient Animation:** Continuous 300% background gradient shifting animation along the navbar perimeter border.
- **Glassmorphic Surface:** Embedded backdrop blur filter (`backdrop-filter: blur(16px)`) with semi-transparent dark container backgrounds.
- **Interactive State Indicators:** Soft gradient link backgrounds with scale-transform transitions on hover/focus.
- **Fully Responsive & Accessible:** Flexible flexbox layout, aria navigation landmarks, and clean high-contrast text ratios.

## File Hierarchy
- `submissions/examples/css-animated-navbar-gradient/style.css` - Gradient keyframe animations, glassmorphism styles, responsive media queries, and design tokens.
- `submissions/examples/css-animated-navbar-gradient/demo.html` - Semantic HTML5 markup displaying the floating gradient navbar component.
