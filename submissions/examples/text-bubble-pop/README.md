# Text Bubble Pop

Each word pops in as a speech bubble then settles.

## Features
- Bubble pop entrance
- Staggered per word
- Speech-tail accent
- Pure CSS

## Usage
```html
<span style="--i:0">Hello</span>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
