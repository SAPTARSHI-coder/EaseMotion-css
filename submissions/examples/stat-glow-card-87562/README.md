# Stat Glow Card (#87562)

An illuminated KPI dashboard card featuring ambient multi-layered box-shadow glow pulses and synchronized breathing text animations.

## Features
- **Ambient Glow Pulse:** Multi-layer radial and box-shadow keyframe cycling creating a smooth breathing back-glow effect.
- **Synchronized Metric Scale:** Number display gently expands and intensifies in brightness in sync with the border luminescence.
- **Interactive States:** Hover accelerates the glow frequency and elevates card elevation.
- **Accessibility:** Fully supports `@media (prefers-reduced-motion: reduce)` by disabling breathing pulse animations.

## Usage
Include `style.css` in your project and wrap KPI metrics in `.glow-kpi-card`.
