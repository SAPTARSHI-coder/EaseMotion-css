# Read More Toggle State Test Submission

## Overview

This submission demonstrates edge-case testing for a Read More / Read Less text toggle component.

## Included

- Demo component
- Component styling
- Vitest-compatible example test file

## Test Coverage

- Default collapsed state
- Expanded state
- Empty string
- Short text
- Null input
- Undefined input
- Invalid values

## Usage

```bash
vitest read-more.test.js
```

The submission is packaged under `submissions/examples/` to comply with the repository contribution policy while illustrating the intended test coverage.
