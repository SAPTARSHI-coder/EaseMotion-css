# glow-popover-menu-v8-ak

Pure CSS animated glowing popover menu component — no JavaScript required.

## How to use

```html
<div class="ease-popover-wrapper-v8">
  <button class="ease-popover-trigger-v8">Options</button>

  <ul class="ease-popover-menu-v8">
    <li class="ease-popover-item-v8"><a href="#">Item 1</a></li>
    <li class="ease-popover-item-v8"><a href="#">Item 2</a></li>
  </ul>
</div>
