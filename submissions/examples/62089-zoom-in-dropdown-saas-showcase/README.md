# CSS Zoom-In Dropdown for SaaS Showcase Layouts

A modern **Zoom-In Dropdown** component created using **pure HTML5 and CSS3** for EaseMotion CSS. The dropdown opens with a smooth zoom animation and is ideal for SaaS dashboards, product navigation, feature menus, and admin panels.

---

## Features

- Pure HTML & CSS
- Smooth Zoom-In dropdown animation
- Glassmorphism-inspired design
- Responsive layout
- Hover interactions
- CSS Custom Properties
- No JavaScript required
- Accessible keyboard focus styles
- `prefers-reduced-motion` support
