# CSS Skew-Active Accordion for Product Catalog Layouts

A modern, lightweight product catalog accordion that uses a subtle skew transformation to highlight the active product. The component is built entirely with HTML and CSS and requires no JavaScript or external dependencies.

## Features

- Pure HTML and CSS
- No JavaScript required
- CSS-only accordion interaction using radio inputs
- Skew transformation on the active accordion item
- Smooth expand and collapse transitions
- Responsive product catalog layout
- CSS custom properties for easy customization
- Keyboard-friendly focus states
- `prefers-reduced-motion` accessibility support
- Works directly in a browser without a build step
