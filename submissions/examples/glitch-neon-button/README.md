# CSS Glitch Neon Button

A lightweight, responsive neon button with a CSS-only glitch animation effect.

This component is built using pure HTML and CSS and does not require JavaScript or external libraries.

## Features

- Pure HTML and CSS
- Neon glow effect
- Glitch animation using pseudo-elements
- Hover interaction
- Keyboard focus support
- Responsive design
- Light and dark mode support
- CSS custom properties for easy customization
- `prefers-reduced-motion` accessibility support
- No JavaScript dependencies
