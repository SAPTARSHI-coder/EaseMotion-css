# CSS Truncated Breadcrumb

A responsive breadcrumb component that collapses middle navigation items
into an ellipsis on smaller screens using pure CSS.

## Issue

This contribution addresses:

**Issue #68385 - [FEATURE] CSS Truncated Breadcrumb**

## Features

- Pure CSS implementation
- No JavaScript required
- Responsive design
- Middle breadcrumb items collapse on smaller screens
- Ellipsis indicates hidden navigation levels
- Current page is marked with `aria-current="page"`
- Semantic `<nav>` and `<ol>` structure
- Keyboard-friendly links
- Hover states
- Text overflow handling
- Reduced-motion support
