# CSS Pulse-Ring Progress Bar

A responsive **Pulse-Ring Progress Bar** built using pure HTML5 and CSS3 for dashboard layouts. Each progress bar features an animated pulse ring at its leading edge to emphasize active progress.

---

## ✨ Features

- Pure HTML5 & CSS3
- Animated pulse-ring indicator
- Responsive dashboard layout
- Multiple progress examples
- CSS Custom Properties
- Lightweight
- No JavaScript required
- `prefers-reduced-motion` support
