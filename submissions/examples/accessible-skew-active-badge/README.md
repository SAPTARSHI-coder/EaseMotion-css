# CSS Skew-Active Badge for Accessible Web Layouts

A modern **Accessible Web Badge** component built entirely with **HTML5 and CSS3**. This showcase demonstrates elegant **Skew-Active** badge interactions with glassmorphism styling, responsive layouts, and accessibility-friendly animations without requiring JavaScript.

---

## ✨ Features

- ♿ Accessible badge design
- 🔷 Skew hover interaction
- ⭐ Active badge state
- 🪟 Glassmorphism styling
- ⚡ Pure HTML5 & CSS3
- 📱 Fully responsive
- 🎯 CSS Custom Properties
- 🚀 Lightweight implementation
- ♿ `prefers-reduced-motion` support
- No JavaScript required

## 🚀 Getting Started

1. Open `demo.html` in any modern browser.
2. Hover over the badges to view the skew animation.
3. Customize colors, spacing, and animation timing using CSS variables.
