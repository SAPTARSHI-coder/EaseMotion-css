# Infinite Seamless Logo Carousel Slider with Pause-on-Hover (Neumorphic Finish)

A premium **Infinite Logo Carousel Slider** built using HTML and CSS featuring a seamless scrolling animation, neumorphic styling, soft shadows, and pause-on-hover interaction.

## Features

- Infinite seamless scrolling
- Pause animation on hover
- Modern neumorphic UI
- Responsive layout
- Smooth CSS animations
- Lightweight & reusable
- Pure HTML & CSS

## Folder Structure

```
ease-advanced-infinite-seamless-logo-carousel-slider-with-pause-on-hover-164/
├── demo.html
├── style.css
└── README.md
```

## Usage

Open `demo.html` in any modern browser.

Customize colors, spacing, animation speed, and logo items inside `style.css`.
