# CSS Fade-In Badge for Product Catalog Layouts

A modern **Fade-In Badge** component built using pure HTML and CSS for product catalog interfaces. Badges smoothly fade into view, highlight product status, and enhance product visibility while remaining lightweight and responsive.

## Features

- Pure HTML5 & CSS3
- Smooth fade-in badge animation
- Product status badges (New, Sale, Hot)
- Responsive product cards
- Easy customization with CSS
- Supports `prefers-reduced-motion`
- No JavaScript required

## Usage

1. Open `demo.html`.
2. Replace the demo content with your own products.
3. Change badge text and colors as needed.

## Customization

You can modify:

- Badge colors
- Animation duration
- Border radius
- Card shadow
- Button colors
- Product images
