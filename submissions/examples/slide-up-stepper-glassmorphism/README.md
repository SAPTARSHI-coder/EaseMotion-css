# 🚀 CSS Slide-Up Stepper for Glassmorphism UI Layouts


## 🎯 Overview

The **CSS Slide-Up Stepper** is a modern animated stepper component built using pure HTML and CSS.

It uses a glassmorphism design style with smooth slide-up entrance animations to create an elegant progress navigation experience.

No JavaScript or external libraries are required.


## ✨ Features

- Pure HTML5 + CSS3 implementation
- Modern glassmorphism UI design
- Smooth slide-up entrance animation
- Responsive layout for all screen sizes
- Lightweight and framework independent
- CSS custom properties for easy customization
- Hover interaction effects
- Accessibility support with `prefers-reduced-motion`
