# CSS Bounce-Pulse Modal for E-Commerce Checkout Layouts

A modern **Bounce-Pulse Modal** built using pure HTML and CSS. The component features energetic bounce-pulse animations, premium glassmorphism styling, responsive layouts, and smooth interactions for e-commerce checkout confirmation dialogs.

## ✨ Features

- Pure HTML5 & CSS3
- Bounce-pulse entrance animation
- Glassmorphism modal
- Responsive layout
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
