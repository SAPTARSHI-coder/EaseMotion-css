# 3D Perspective Tilt Bento Card

A responsive pure CSS bento grid featuring layered 3D perspective,
depth, and smooth tilt interactions.

## Features

- Pure HTML and Vanilla CSS
- CSS perspective-based 3D transforms
- Smooth hover tilt interaction
- Layered depth using `translateZ()`
- Responsive bento grid
- Dark-mode friendly design
- No JavaScript
- No external dependencies
- `prefers-reduced-motion` accessibility support
