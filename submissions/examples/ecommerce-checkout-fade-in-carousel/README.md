# CSS Fade-In Carousel for E-Commerce Checkout Layouts

A lightweight Pure HTML & CSS Fade-In Carousel designed for modern e-commerce checkout pages.

## Features

- Pure HTML & CSS
- Fade-In entrance animation
- Responsive layout
- Accessible structure
- CSS Custom Properties
- prefers-reduced-motion support
- No JavaScript required
