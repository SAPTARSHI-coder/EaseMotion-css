# Foucault Pendulum Swing Modal

A smooth and accessible CSS modal inspired by the swinging motion of a Foucault pendulum.

## Features

- Pure HTML and Vanilla CSS
- No external JavaScript
- Native HTML Popover API
- Foucault pendulum-inspired animation
- Smooth modal entrance animation
- Dark mode support
- Responsive design
- Reduced-motion accessibility support
- Hardware-accelerated transforms

## Usage

Open `index.html` in a modern browser.

The modal can be opened using the **Open Modal** button and closed using the **Close** button.
