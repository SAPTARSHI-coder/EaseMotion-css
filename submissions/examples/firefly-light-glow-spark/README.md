# Firefly Light Glow Spark

A subtle firefly-inspired glowing spark animation for EaseMotion CSS.

## Features

- Firefly-style glowing motion
- Smooth pulsing effect
- Configurable duration
- Configurable timing function
- Uses transform and opacity
- Supports reduced-motion preferences

## Usage

```html
<div class="ease-anim-firefly-light-glow-spark"></div>
