# Quantity Stepper

A plus/minus stepper with a spinning numeric readout and pressed feedback.

## Features
- Rounded stepper with tactile button states
- Readout spins when the value changes
- Disabled look at the floor value

## Usage
```html
<div class="qs-stepper">
  <button class="qs-btn minus">&#8722;</button>
  <div class="qs-value">2</div>
  <button class="qs-btn plus">&#43;</button>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
