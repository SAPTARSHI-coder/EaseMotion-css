# Bioluminescent Floating Dock Nav v3

## 1. What does this do?
The Bioluminescent Floating Dock Nav component provides a floating pill-shaped navigation bar with elastic magnification hover physics and bioluminescent neon glowing active indicators.

## 2. How is it used?
Incorporate the nav markup at the bottom or top of modern desktop/mobile web applications for sleek quick-action navigation.

## 3. Why is it useful?
It offers a macOS-inspired dock magnification effect combined with organic bioluminescent glowing hover states using pure CSS cubic-bezier transitions.
