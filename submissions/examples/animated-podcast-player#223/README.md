# Animated Podcast Player

A sleek **Podcast Player Interface** built with **EaseMotion CSS**. Features podcast artwork with play overlay, animated audio waveform, episode list with progress bars, and platform subscription buttons.

## ✨ Features

- **🎙️ Podcast Artwork**: Play button overlay with hover effect
- **📊 Audio Waveform**: Animated bars that pulse continuously
- **🎵 Now Playing Badge**: Equalizer animation with pulse effect
- **🎧 Episode List**: Progress bars and play buttons
- **⏯️ Player Controls**: Play/pause, skip, speed, volume
- **📱 Platform Buttons**: Apple Podcasts, Spotify, YouTube, RSS
- **🎬 Staggered Entrance**: All sections slide up sequentially
- **📱 Fully Responsive**: Desktop → tablet → mobile layout

## 🧩 EaseMotion Classes Used

| Class | Purpose |
|-------|---------|
| `ease-fade-in` | Fades in the main page and footer |
| `ease-slide-up` | Slides sections up on entrance |
| `ease-delay-100` to `ease-delay-500` | Creates cascading staggered sequence |
| `ease-card` | Base card structure |
| `ease-hover-lift` | Lift effect on cards |
| `ease-hover-grow` | Scale effect on buttons |
| `ease-center` | Centers play button overlay |
| `ease-btn` + `ease-btn-primary` | Styled subscribe button |
| `ease-pulse` | **Looping pulse** on now playing badge and play button |

## 🚀 How to Use

1. Open `demo.html` in any modern browser
2. Watch all sections slide in with staggered animations
3. Observe the **pulsing now playing badge** with equalizer bars
4. Watch the **waveform bars pulse** continuously
5. Hover over episode items to reveal play buttons
6. Hover over podcast artwork to see play overlay
7. Resize to mobile to see responsive layout
