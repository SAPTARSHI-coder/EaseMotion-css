# Aurora Glow Particle Effect

A smooth and performant pure CSS particle effect inspired by soft aurora lights and atmospheric glowing particles.

## Features

- Pure HTML and Vanilla CSS
- Aurora-inspired glowing background
- Floating particle animation
- Smooth CSS transitions
- Multiple layered glow effects
- Dark mode compatible
- Light mode support
- Responsive layout
- Hardware-friendly `transform` animations
- Accessible reduced-motion support
- No JavaScript required
- No external libraries or dependencies
