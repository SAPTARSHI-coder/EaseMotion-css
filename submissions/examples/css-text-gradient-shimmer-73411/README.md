# CSS Text: Gradient Shimmer

A modern text animation featuring a continuously moving gradient shimmer effect.

## Features

- Pure HTML & CSS
- Animated gradient text
- Smooth shimmer motion
- Hardware accelerated
- Responsive typography
- Dark mode compatible
- Accessible implementation

## Usage

```html
<h1 class="gradient-shimmer">
    Gradient Shimmer
</h1>
```

## Files

- demo.html
- style.css

## EaseMotion CSS

This effect combines motion and visual polish while remaining lightweight, reusable, and fully CSS-powered, making it a perfect fit for EaseMotion CSS.
