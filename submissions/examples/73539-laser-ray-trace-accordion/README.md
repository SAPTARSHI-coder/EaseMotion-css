# Laser Ray Trace Accordion

A futuristic CSS-only accordion featuring a moving Laser Ray Trace
around active panels.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript required
- Native `<details>` and `<summary>` interaction
- Animated laser border trace
- Smooth expand/collapse transition
- Animated plus/minus indicator
- Dark mode compatible
- Responsive design
- Hardware-friendly transforms and opacity
- Keyboard accessible
- Reduced-motion support
