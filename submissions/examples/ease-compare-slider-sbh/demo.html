ease-compare-slider

A before/after image comparison slider.

A draggable slider that reveals a "before" image underneath an "after" image using clip-path, controlled by a native <input type="range"> for full accessibility and zero custom drag logic. Keyboard-operable, touch-friendly, one line of JS.

Day / Night

Drag the handle, or tab to it and use the arrow keys.

Edited / Original

Both images use inline SVG data URIs so the demo runs with no external assets.
