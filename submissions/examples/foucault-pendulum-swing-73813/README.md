# Foucault Pendulum Swing

A pure CSS particle effect inspired by the graceful motion of a Foucault pendulum.

## Features

- Pure HTML and CSS
- No JavaScript or external dependencies
- Smooth pendulum swing animation
- Subtle floating particle effects
- Dark-mode friendly design
- Hardware-friendly CSS transforms
- Respects `prefers-reduced-motion`
- Responsive layout
