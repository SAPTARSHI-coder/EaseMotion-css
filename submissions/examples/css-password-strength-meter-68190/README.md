# CSS Password Strength Meter

A pure CSS password strength indicator featuring animated colored segments that visually represent password strength levels.

## Features

- Pure CSS implementation
- Animated strength segments
- Responsive design
- Accessible form controls
- Light and dark mode support
- CSS custom properties for easy theming

## Files

- `demo.html` – Demonstration page
- `style.css` – Component styling and animations

## Usage

Open `demo.html` in a browser to view the password strength meter.

## Customization

Modify the CSS variables inside `:root` to change:

- Colors
- Border styles
- Backgrounds
- Typography
- Animation timing

## Accessibility

- Semantic form elements
- ARIA labels included
- Keyboard accessible input field
- High-contrast color states
