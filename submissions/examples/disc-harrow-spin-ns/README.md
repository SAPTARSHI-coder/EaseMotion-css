# Disc Harrow Spin

## What does this do?
Renders a self-contained CSS-only `ease-disc-harrow-spin` demo: Farm disc harrow blades spinning through soil.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-disc-harrow-spin`. No build step or JavaScript is required for the effect.

```html
<section class="ease-disc-harrow-spin">
  <div class="ease-disc-harrow-spin__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
