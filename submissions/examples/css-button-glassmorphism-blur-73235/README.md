# CSS Button - Glassmorphism Blur

A modern Glassmorphism Blur button built entirely with HTML and CSS. The design combines a frosted glass appearance, backdrop blur, and subtle lighting effects to create a clean and futuristic user interface element.

## Features

- Pure HTML & CSS
- Glassmorphism Blur styling
- Frosted glass appearance
- Backdrop blur effect
- Smooth hover interactions
- Responsive design
- Keyboard accessible
- Dark mode friendly
- Hardware accelerated animations
- No JavaScript required

## Usage

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

Use the button:

```html
<button class="glass-btn">
  Glass Button
</button>
```

## Why it fits EaseMotion CSS

This component provides a reusable glassmorphism button pattern that is lightweight, visually appealing, accessible, and built entirely with CSS, aligning with EaseMotion CSS's animation-first philosophy.
