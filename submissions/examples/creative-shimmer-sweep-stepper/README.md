# CSS Shimmer-Sweep Stepper for Creative Portfolio Layouts

A modern **Shimmer-Sweep Stepper** built completely with **HTML5 and CSS3**. This showcase demonstrates a creative step navigation component with animated shimmer effects, glowing active states, glassmorphism cards, responsive layouts, and accessibility support without requiring JavaScript.

---

## ✨ Features

- ✨ Shimmer-sweep animation effect
- 🔢 Multi-step progress navigation
- 🌈 Gradient active step styling
- 💎 Glassmorphism UI cards
- 🔥 Glowing active indicators
- ⚡ Smooth CSS transitions
- 🎯 CSS Custom Properties
- 📱 Fully responsive layout
- 🧩 Pure HTML5 & CSS3
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

## 🚀 Getting Started

1. Open `demo.html` in any modern browser.
2. View the shimmer stepper component.
3. Hover over steps to see interactive effects.
4. Customize colors, spacing, and animation timing using CSS variables.
