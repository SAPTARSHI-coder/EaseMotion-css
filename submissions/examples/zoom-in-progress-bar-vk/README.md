# Zoom-In Progress Bar for Responsive Dashboard Layouts

A modern, responsive progress bar component built using pure HTML and CSS. The progress bars feature a smooth zoom-in animation while filling, providing an engaging visual indicator suitable for dashboard interfaces.

---

## Features

- Pure HTML5 and CSS3 (No JavaScript)
- Smooth zoom-in progress bar animation
- Responsive dashboard layout
- Easy customization with CSS custom properties
- Lightweight and performant
- Supports `prefers-reduced-motion`

---

## Folder Structure

```
zoom-in-progress-bar-vk/
```

---

## Usage

1. Open `demo.html` in any modern browser.
2. The progress bars animate automatically with a smooth zoom-in effect.
3. Modify the progress widths and colors to suit your project.

---

## CSS Custom Properties

The following CSS variables can be customized:

```css
:root {
    --primary: #6366f1;
    --secondary: #4f46e5;
    --background: #f4f6fb;
    --surface: #ffffff;
    --text: #1f2937;

    --radius: 14px;
    --duration: 0.8s;

    --shadow: 0 12px 30px rgba(0, 0, 0, 0.12);
}
```
