# Shimmer Skeleton Loader Component

A content placeholder component with a continuous light sweep animation for pending load states.

## Features
- **Skeleton Layout Utility:** Flexible shapes for avatars, titles, and body lines.
- **Pure CSS Wave Sweep:** Translating linear gradient overlay keyframes.
- **Zero JS:** Works automatically without JavaScript controllers.

## File Structure
- `demo.html` - Card placeholder markup using skeleton classes.
- `style.css` - Component sizes and gradient wave keyframes.
