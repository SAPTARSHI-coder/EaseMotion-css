Modern CSS Technique

Mask
Scroll Reveal

Text and images that reveal themselves through animated CSS masks driven by scroll position. Combining mask-image, @property, and animation-timeline for cinematic reveal effects. Zero JavaScript.

Technique 1

Horizontal
Wipe Reveal

A mask-image with linear-gradient(to right, black X%, transparent) where X is controlled by a scroll-driven custom property. As the user scrolls, the mask expands from left to right, gradually revealing the text. The @property rule registers --mask-progress as a <percentage> so the browser can smoothly interpolate the mask position.

Technique 2

Gradient
Fade Reveal

A radial gradient mask that starts as a tiny dot and expands to fill the entire element. The mask size is driven by scroll position through a registered @property. This creates a spotlight-style text reveal that feels cinematic and dramatic.

Technique 3

Diagonal
Stripe Reveal

An angled linear gradient mask that sweeps diagonally across the text block. The mask angle and position combine with scroll progress to create a dynamic curtain-like reveal. Each word appears to be drawn onto the page as you scroll.

Technique 4

Image
Blind Reveal

CSS masks work on images too. Here a decorative gradient image has a mask animated from fully transparent to fully opaque as the user scrolls past. The image itself is a CSS gradient — no external assets — making this a fully self-contained effect.

Technique 5

Texture
Reveal Card

A card component that reveals itself through a combination of mask and opacity, both driven by scroll position. The card slides up with a gradient mask that gradually dissolves from transparent to opaque — a premium reveal effect.

CSS APIs Used

The modern CSS primitives powering these mask reveal effects
API Role Support
mask-image Defines a luminance or alpha mask that controls which parts of an element are visible Chrome 1+, Firefox 53+, Safari 15.4+ (webkit prefix)
@property Registers custom properties with typed syntax for smooth interpolation Chrome 85+, Edge 85+, Safari 16.4+, Firefox 128+
animation-timeline: view() Drives animation from element visibility within scroll container Chrome 115+, Edge 115+, Safari 18+
animation-range Controls when an animation starts and ends within its timeline Chrome 115+, Edge 115+, Safari 18+

In browsers without scroll-driven animation support, static fallback values display the full content without masking — ensuring readability everywhere. The mask effects degrade gracefully to standard opacity transitions where supported.
