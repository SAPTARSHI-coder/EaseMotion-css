# Dashpot Dampen Slide

## What does this do?
Renders a self-contained CSS-only `ease-dashpot-dampen-slide` demo: Dashpot piston damping a sliding mass to rest.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-dashpot-dampen-slide`. No build step or JavaScript is required for the effect.

```html
<section class="ease-dashpot-dampen-slide">
  <div class="ease-dashpot-dampen-slide__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
