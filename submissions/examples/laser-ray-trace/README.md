# CSS Modal: Laser Ray Trace

A futuristic, smooth, and accessible modal component featuring a
**Laser Ray Trace** visual effect.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript required
- Animated laser rays
- Animated laser border
- Scanning laser line
- Smooth modal entrance animation
- Dark-mode-friendly design
- Responsive layout
- Hardware-accelerated transforms
- Accessible dialog markup
- Visible keyboard focus states
- Reduced-motion support
- No external dependencies
