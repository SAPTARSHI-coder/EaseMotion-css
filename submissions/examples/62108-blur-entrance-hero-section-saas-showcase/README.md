# CSS Blur-Entrance Hero Section for SaaS Showcase Layouts

A modern **Blur-Entrance Hero Section** built using pure HTML5 and CSS3 for SaaS showcase layouts. This component creates a premium landing page experience with smooth blur reveal animations, glassmorphism dashboard UI, animated background effects, and responsive design.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Smooth blur-to-clear entrance animation
* Modern SaaS hero section layout
* Glassmorphism dashboard preview
* Animated gradient background blobs
* Interactive CTA buttons
* Floating analytics dashboard card
* Responsive design for desktop, tablet, and mobile
* CSS Custom Properties for easy customization
* Smooth CSS transitions and keyframe animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. View the blur entrance animation when the hero section loads.
3. Hover over buttons for interactive effects.
4. Customize colors, shadows, spacing, and animations through CSS variables inside `:root`.

## CSS Custom Properties

```css
:root{
  --bg:#050816;
  --surface:rgba(255,255,255,.1);
  --primary:#2563eb;
  --secondary:#06b6d4;
  --accent:#8b5cf6;
  --text:#f8fafc;
  --muted:#94a3b8;
  --shadow:0 25px 70px rgba(37,99,235,.25);
  --radius:26px;
}
```
