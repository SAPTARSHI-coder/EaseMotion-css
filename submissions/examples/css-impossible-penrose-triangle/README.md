# CSS Impossible Penrose Triangle

A mind-bending optical illusion of the impossible Penrose triangle, animated to rotate infinitely. Created entirely using pure CSS 3D transforms.

## Features

- **Pure CSS**: No JavaScript, WebGL, or Canvas.
- **Isometric Projection**: Uses mathematically precise `rotateX(54.736deg) rotateZ(45deg)` to create a perfect isometric view.
- **Optical Illusion**: By carefully positioning three 3D rectangular prisms and using overlapping `z-index` with specific colors, the impossible triangle is formed when viewed from the correct angle.
- **Infinite Rotation**: The container rotates to break and reform the illusion seamlessly.
