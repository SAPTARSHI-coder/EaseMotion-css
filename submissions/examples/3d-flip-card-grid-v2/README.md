# CSS 3D Flip Card Grid

## Overview

A responsive gaming-inspired 3D flip card grid built using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Responsive Grid Layout
- 3D Flip Hover Animation
- CSS Custom Properties
- Accessible (`prefers-reduced-motion`)
- Easy to Customize

## Folder Structure

```text
3d-flip-card-grid/
├── demo.html
├── style.css
└── README.md
```

## Usage

1. Open `demo.html` in your browser.
2. Customize the CSS variables.
3. Integrate the component into your project.

## CSS Variables

- `--primary`
- `--background`
- `--card`
- `--text`
- `--duration`

## Browser Support

- Chrome
- Firefox
- Edge
- Safari
