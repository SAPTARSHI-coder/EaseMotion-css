# CSS Mesh Gradient: Neumorphic Soft Shadow

A smooth, accessible, and performant pure CSS gradients & mesh featuring **Neumorphic Soft Shadow** styling.

## What does this do?
This component creates a visually stunning neumorphic element combined with a subtle mesh gradient effect for realistic depth. It features smooth hardware-accelerated transitions and full dark mode compatibility without any external JavaScript.

## How is it used?
```html
<div class="mesh-neumorphic">
  <h2>Neumorphic</h2>
</div>
```

## Why is it useful?
It provides a premium, modern, and tactile look to UI elements. By combining soft mesh gradients with neumorphic shadows, it creates a sense of physicality and depth, aligning perfectly with EaseMotion's smooth and modern aesthetics.
