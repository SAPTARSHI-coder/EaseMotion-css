# Dynamic Accordion Table Row Expander for Data Tables

### Glassmorphic Style

A modern **Glassmorphic Accordion Table** built with **HTML5** and **CSS3**. It provides expandable table rows with smooth animations, responsive layout, and accessibility-friendly interactions.

---

## ✨ Features

- Glassmorphism design
- Expandable accordion rows
- Smooth open/close animation
- Responsive mobile-first layout
- Hover elevation effects
- CSS Variables for customization
- Keyboard accessibility
- `prefers-reduced-motion` support
- Pure HTML & CSS implementation
