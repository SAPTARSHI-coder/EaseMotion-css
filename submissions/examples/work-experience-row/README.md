# CSS Work Experience Row

A clean and responsive work experience component designed for resumes, portfolios, and professional profile pages.

## Features

- Pure HTML and CSS
- Responsive timeline layout
- Work experience date range
- Job title and company name
- Work type badge
- Experience summary
- Bullet-point responsibilities
- Technology/skill tags
- Hover animation
- Accessible semantic HTML
- Reduced-motion support
- Mobile-friendly design

## Files

- `demo.html` — Demo page containing the work experience component.
- `style.css` — Styling, responsive layout, timeline, and animations.

## Usage
