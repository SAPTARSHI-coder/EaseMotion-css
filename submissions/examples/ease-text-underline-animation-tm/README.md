# Text Underline Animation Component

Add ease-text-underline-animation-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|---------|
| `--tu-accent` | `#6366f1` |
| `--tu-accent2` | `#ec4899` |
| `--tu-size` | `1.125rem` |

## Technique

`width: 0 → 100%` on `::after` pseudo-element creates the sweep underline effect.
