# CSS 3D-Flip Stepper for Creative Portfolio Layouts

A modern **3D-Flip Stepper** component built completely with **HTML5 and CSS3**. This showcase demonstrates interactive portfolio steps with smooth 3D flip transformations, glassmorphism styling, glowing effects, responsive layouts, and accessibility support without requiring JavaScript.

---

## ✨ Features

- 🔄 Smooth 3D flip animation
- 🎨 Front and back step cards
- 💎 Glassmorphism design
- ✨ Glow effects
- 🌈 Gradient indicators
- ⚡ CSS transform animations
- 🎯 CSS Custom Properties
- 📱 Fully responsive layout
- 🧩 Pure HTML5 & CSS3
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

## 🚀 Getting Started

1. Open `demo.html` in any modern browser.
2. Hover over the step cards to trigger the 3D flip effect.
3. Customize colors, spacing, and animation timing using CSS variables.
