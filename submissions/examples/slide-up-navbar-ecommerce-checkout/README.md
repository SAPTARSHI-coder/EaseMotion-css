# Slide-Up Navbar for E-Commerce Checkout

A responsive e-commerce checkout showcase featuring a CSS-only Slide-Up
Navbar for quick checkout navigation.

## Features

- Pure HTML and CSS
- No JavaScript
- No external frameworks
- Smooth slide-up navbar animation
- Responsive checkout layout
- Mobile-focused bottom navigation
- CSS custom properties
- Smooth hover and focus interactions
- Sticky desktop order summary
- Keyboard-accessible navigation
- `prefers-reduced-motion` support
