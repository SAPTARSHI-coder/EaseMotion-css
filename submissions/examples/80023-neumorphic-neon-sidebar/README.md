# Neumorphic Neon Sidebar (V1)

A responsive sidebar component that combines neumorphic depth with
modern neon accents.

The component is designed as a standalone HTML/CSS example and does
not require JavaScript, frameworks, or external dependencies.

## Features

- Neumorphic layered shadows
- Subtle neon green accent
- Active navigation state
- Hover interactions
- Notification badge
- Profile section
- Responsive tablet layout
- Mobile-friendly navigation
- Keyboard focus states
- Reduced-motion support
- No external dependencies
