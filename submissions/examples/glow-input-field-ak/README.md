# glow-input-field-ak

Pure CSS animated floating label input field with neon border focus — no JavaScript required.

## How to use

```html
<div class="ease-float-input-wrapper">
  <input type="text" class="ease-float-input" placeholder=" " id="input1" />
  <label for="input1" class="ease-float-label">Label Text</label>
</div>
