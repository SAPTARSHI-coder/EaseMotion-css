# Neumorphic Carousel

A responsive and modern carousel component built with semantic HTML and CSS.

This component uses a soft neumorphic visual language with layered shadows,
rounded surfaces, responsive layouts, and smooth slide transitions.

## Features

- Responsive across desktop, tablet, and mobile screens
- Neumorphic raised-surface design
- CSS-only slide navigation
- Smooth slide transitions
- No external JavaScript dependencies
- Semantic HTML structure
- Accessible navigation labels
- Keyboard-focusable carousel controls
- `prefers-reduced-motion` support
- Clean and reusable CSS
- Responsive feature cards
