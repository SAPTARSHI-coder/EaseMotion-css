# Hover Carousel - Material Design

A responsive Material Design inspired Hover Carousel built using pure HTML and CSS.

## Features

- Material Design card layout
- Hover elevation animation
- Image zoom interaction
- Smooth content reveal
- Responsive grid carousel
- Pure HTML/CSS

## Files

- demo.html
- style.css

## Usage

Open `demo.html` in a browser.

## Responsive

The carousel automatically adapts to tablets and mobile devices.

## Customization

Modify:

- Card shadow
- Hover animation
- Border radius
- Overlay content
- Grid spacing

## Browser Support

- Chrome
- Firefox
- Edge
- Safari
