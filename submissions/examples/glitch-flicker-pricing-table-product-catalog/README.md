# CSS Glitch-Flicker Pricing Table

A modern futuristic pricing table created using pure HTML and CSS.

This component demonstrates glitch effects, flickering animations, hover interactions, and responsive pricing cards without using JavaScript or external libraries.

## ✨ Features

- Pure HTML & CSS implementation
- Glitch text animation effect
- Flicker overlay animation
- Smooth hover elevation effect
- Neon futuristic UI design
- Responsive layout for desktop, tablet, and mobile
- Accessible reduced motion support using `prefers-reduced-motion`

♿ Accessibility

The component supports:

to disable animations for users who prefer reduced motion.
