# CSS Elastic-Slide Toast

A lightweight fintech dashboard toast notification created using pure HTML and CSS.

The toast enters from the right side with an elastic slide effect.

## Features

- Pure HTML and CSS
- No JavaScript
- No external libraries
- Elastic slide entrance animation
- Responsive dashboard layout
- Desktop, tablet, and mobile support
- Accessible status notification
- Reduced-motion support
