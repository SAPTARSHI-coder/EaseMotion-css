# Liquid Wave Fill Dashboard Widget

A dynamic **pure CSS Dashboard Widget** featuring a
Liquid Wave Fill visual style for the EaseMotion CSS
component collection.

Implemented for **Issue #75165**.

## ✨ Features

- Liquid Wave Fill dashboard design
- Animated water-like wave surfaces
- Primary reservoir capacity visualization
- Current flow-rate widget
- Multiple liquid tank indicators
- CSS efficiency ring
- 24-hour flow activity visualization
- System alerts panel
- Smooth CSS transitions
- Lightweight CSS animations
- Dark-mode compatible design
- Responsive desktop, tablet, and mobile layouts
- Reduced-motion support
- Pure HTML and Vanilla CSS
- No external JavaScript
- No third-party dependencies

## 🎨 Style

**Category:** Dashboard Widgets

**Style:** Liquid Wave Fill

The component uses animated wave surfaces,
liquid-filled containers, glowing flow indicators,
dark aquatic colors, and CSS-generated data
visualizations to create a fluid dashboard experience.
