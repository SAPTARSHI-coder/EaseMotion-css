# 3D Origami Fold Card Grid - GSSoC 2026

An origami-inspired 3D folding card grid component that simulates tactile paper unfolding mechanisms on mouse hover.

## 1. What does this do?
It renders feature cards that split horizontally and fold outward in 3D space when hovered, revealing detailed content underneath.

## 2. How is it used?
Include `style.css` in your HTML file and wrap your content inside `.origami-card` structures with `.fold-top` and `.fold-bottom` elements.

## 3. Why is it useful?
It creates high-engagement interactive feature showcases with tactile depth using hardware-accelerated CSS 3D transforms.
