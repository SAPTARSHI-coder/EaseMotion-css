# CSS Skew-Active Card Grid for Gaming Hub Layouts

A modern **Skew-Active Card Grid** component built using only **HTML5 and CSS3**.

This example creates a gaming hub style interface with animated skew interactions, glowing cards, gradient effects, responsive grid layout, and accessibility support without JavaScript.

---

## ✨ Features

- 🎮 Gaming dashboard card layout
- ⚡ Skew-based hover interaction
- 🔥 Animated glow effects
- 🎨 Gradient card indicators
- 🌐 Fully responsive grid
- 🧩 Pure HTML & CSS
- 🎯 CSS Custom Properties
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript dependency

## 🚀 Usage

1. Open `demo.html` in any modern browser.
2. Hover over cards to activate skew animation.
3. Customize colors using CSS variables.
4. Integrate the component into gaming dashboards or portfolio layouts.
