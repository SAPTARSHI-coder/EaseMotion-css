Footer Light Mode Fix

Toggle between dark and light mode to see the fix

The Bug

Footer text disappeared in light mode because:

  • Footer only used @media (prefers-color-scheme: light) — no [data-theme] support
  • .ease-footer-description color was not overridden in light mode
  • .ease-footer-logo color was not overridden in light mode

The Fix

  • Added [data-theme="light"] selectors alongside media queries
  • Added missing .ease-footer-description light mode color
  • Added missing .ease-footer-logo light mode color
  • Added missing .ease-footer-newsletter light mode styles
