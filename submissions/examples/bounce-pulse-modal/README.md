# CSS Bounce-Pulse Modal

A responsive modal with a bounce entrance animation and pulse hover effect built using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Bounce entrance animation
- Pulse hover effect
- Responsive layout
- Lightweight and reusable
- Supports `prefers-reduced-motion`

## Files

- demo.html
- style.css

## Usage

Open `demo.html` directly in any modern browser.
