# CSS 3D-Flip Drawer for Product Catalog Layouts

A modern **pure HTML & CSS** product catalog showcasing a **3D Flip Drawer** interaction. Each product card flips in 3D on hover to reveal a drawer containing detailed product information and quick action buttons—without using JavaScript.

---

## ✨ Features

- Pure HTML5 & CSS3
- Smooth 3D flip drawer animation
- Hardware-accelerated CSS transforms
- Responsive product catalog
- Modern gradient UI
- CSS Custom Properties
- Accessible with `prefers-reduced-motion`
- No JavaScript required
- Lightweight and reusable

## 🚀 Usage

1. Navigate to:

```text
submissions/examples/62243-3d-flip-drawer-product-catalog/
```

2. Open **demo.html** in any modern browser.

3. Hover over a product card to experience the 3D flip drawer animation.

## 🎨 CSS Custom Properties

```css
:root{
    --bg:#0f172a;
    --card:#1e293b;
    --drawer:#111827;
    --primary:#6366f1;
    --secondary:#06b6d4;
    --text:#f8fafc;
    --muted:#cbd5e1;
    --radius:22px;
    --shadow:0 22px 60px rgba(0,0,0,.35);
    --transition:.6s cubic-bezier(.4,0,.2,1);
}
```

Customize these variables to change:

- Theme colors
- Drawer appearance
- Card radius
- Animation speed
- Shadows
- Typography
