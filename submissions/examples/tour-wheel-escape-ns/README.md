# Tour Wheel Escape

## What does this do?
Renders a self-contained CSS-only `ease-tour-wheel-escape` demo: CSS-only motion metaphor for tour wheel escape.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-tour-wheel-escape`. No build step or JavaScript is required for the effect.

```html
<section class="ease-tour-wheel-escape">
  <div class="ease-tour-wheel-escape__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
