# Gradient Shimmer - CSS 3D Effect

A smooth and accessible 3D Gradient Shimmer effect built entirely with
HTML and Vanilla CSS.

## ✨ Features

- Pure HTML and CSS
- Smooth 3D hover interaction
- Animated gradient shimmer
- Hardware-accelerated transforms
- Dark mode support
- Keyboard accessibility
- Reduced-motion support
- Responsive design
- No JavaScript
- No external dependencies

## 🎨 Effect

The card combines subtle 3D elevation with an animated gradient shimmer.
When the user hovers over or focuses the card, it gently moves forward and
upward while the gradient highlight passes across the surface.

## 🛠️ Technologies

- HTML5
- CSS3
- CSS Transforms
- CSS Transitions
- CSS Animations
- CSS Media Queries

## 🚀 Usage

Open `index.html` in a modern browser.

No installation or build process is required.

## ♿ Accessibility

The component includes:

- Keyboard focus support
- Visible focus indication

- Semantic HTML
- Responsive layout
