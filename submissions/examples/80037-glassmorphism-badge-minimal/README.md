# CSS-only Glassmorphism Badge (Minimal)

A lightweight and responsive glassmorphism badge component built
with pure HTML and CSS.

## Features

- Pure HTML and CSS
- No JavaScript
- Minimal glassmorphism design
- Transparent layered surfaces
- Backdrop blur
- Multiple badge color variants
- Subtle hover lift animation
- Animated glass highlight
- Soft ambient glow
- Responsive wrapping
- Keyboard focus support
- Reduced-motion support

## Files

- `demo.html` — component markup and demo variants
- `style.css` — complete styling and responsive behavior

## Usage

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
