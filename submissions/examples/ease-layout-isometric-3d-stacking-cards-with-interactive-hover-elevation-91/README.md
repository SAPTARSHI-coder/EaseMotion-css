# Isometric 3D Stacking Cards with Interactive Hover Elevation (Glassmorphic Style)

A modern Glassmorphic card stack featuring layered isometric cards with smooth hover elevation and elegant depth effects using pure HTML and CSS.

## Features

- Glassmorphism design
- Isometric stacked cards
- Interactive hover elevation
- Smooth transitions
- Responsive layout
- Pure HTML & CSS

## Folder Structure

```
ease-layout-isometric-3d-stacking-cards-with-interactive-hover-elevation-91/
├── demo.html
├── style.css
└── README.md
```

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over the stack to see the elevation animation.
3. Customize colors and spacing in `style.css`.

- HTML5
- CSS3
