# ✨ Stardust – Sparkly Stardust Particles Follow Interaction

> A magical stardust component where sparkly particles follow your cursor with twinkling, glowing effects, 20+ colors, and real-time particle tracking.

---

## 📖 Description

The **Stardust** component creates a magical stardust experience where sparkly particles follow your cursor with twinkling, glowing effects. Built with vanilla HTML, CSS, and JavaScript, it features 20+ colors, sparkle control (0-100%), density control (1-10), and particle physics for an enchanting celestial experience.

### 🎯 Core Features

- **Stardust particles** – sparkly particles follow cursor with twinkling effects
- **20+ colors** – gold, pink, blue, purple, green color palette
- **Sparkle control** – adjust sparkle intensity from 0-100%
- **Density control** – adjust particle density from 1-10 (30-210 particles)
- **Particle effects** – twinkling, glowing, 4-point star highlights, fading trails
- **Particle counter** – tracks number of particles in real-time
- **Interactive controls** – sliders with real-time value display, keyboard shortcuts
- **Responsive design** – adapts to different screen sizes

### ⌨️ Interaction Options

| Method | Action |
|--------|--------|
| **Mouse** | Move cursor over display to scatter stardust |
| **Touch** | Drag on mobile to scatter stardust |
| **Sliders** | Adjust Sparkle (0-100%) and Density (1-10) |
| **Keyboard** | `R` – Reset |

### ✨ Stardust Experience

When interacting:
1. **Particles follow** – stardust particles trail behind cursor
2. **Sparkle applies** – controls twinkle intensity and particle size
3. **Density applies** – controls particle count
4. **Colors shimmer** – particles have vibrant, varied colors
5. **Status updates** – shows interaction state

### 🛠️ Technologies Used

- **HTML5** – semantic structure with Canvas
- **CSS3** – gradients, backdrop-filter, transforms
- **JavaScript (ES6)** – Canvas API, requestAnimationFrame, particle system

### 🎨 Design Philosophy

This component embodies **EaseMotion CSS's animation-first philosophy** through:

- **Organic motion** – particles follow with smooth, natural movement
- **Particle effects** – twinkling, glowing, star highlights
- **Visual feedback** – status updates, counter, controls
- **Magical atmosphere** – sparkly colors and cosmic background
- **Human-readable classes** – `.stardust-controls`, `.stardust-text`

### 🔧 Customization Options
