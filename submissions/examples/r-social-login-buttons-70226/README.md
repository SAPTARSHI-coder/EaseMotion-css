# CSS Social Login Buttons

A clean, responsive, and accessible social login button component built with pure HTML and vanilla CSS.

## Features

- Google, GitHub, and Apple login buttons
- Brand-inspired styling
- Smooth hover and press animations
- Responsive layout
- Dark mode support using `prefers-color-scheme`
- Keyboard accessible with visible focus states
- Reduced-motion support
- No JavaScript
- No external libraries or dependencies
- Hardware-friendly CSS transforms

## Files

- `demo.html` - Demo page containing the social login buttons
- `style.css` - Complete styling and animations

## Usage

Open `demo.html` directly in a browser.

The buttons are implemented as semantic HTML `<button>` elements, making them keyboard accessible and easy to connect to an authentication flow.

## Accessibility

The component includes:

- Semantic buttons
- Descriptive `aria-label` attributes
- Keyboard focus states with `:focus-visible`
- Decorative SVG icons hidden from assistive technology
- `prefers-reduced-motion` support
- Responsive text and layout

## Customization

You can customize the component by changing:

- Button border radius
- Button spacing
- Background gradients
- Animation duration
- Card dimensions
- Typography
- Light and dark mode colors

## Technologies

- HTML5
- CSS3
- CSS Transitions
- CSS Media Queries
- CSS `prefers-color-scheme`
- CSS `prefers-reduced-motion`

## Browser Support

Works in modern browsers that support standard CSS transitions, media queries, SVG, and `:focus-visible`.
