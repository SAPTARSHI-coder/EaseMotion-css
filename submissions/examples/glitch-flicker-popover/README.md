# CSS Glitch Flicker Popover

## Overview

A gaming-inspired popover with a glitch flicker animation built entirely using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Responsive Popover
- Glitch Flicker Animation
- CSS Custom Properties
- Accessible (`prefers-reduced-motion`)
- No JavaScript Required

## Folder Structure

```text
glitch-flicker-popover/
├── demo.html
├── style.css
└── README.md
```

## Usage

1. Open `demo.html`.
2. Hover over the button.
3. Customize the CSS variables as needed.

## CSS Variables

- `--primary`
- `--background`
- `--surface`
- `--text`
- `--duration`

## Browser Support

- Chrome
- Firefox
- Edge
- Safari
