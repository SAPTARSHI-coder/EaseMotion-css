# Gradient Shimmer Button

A polished pure CSS button collection featuring a **Gradient Shimmer** visual style with flowing gradients and animated highlight sweeps.

## ✨ Features

- Animated gradient backgrounds
- Smooth shimmer sweep effect
- Multiple button variants
- Hover elevation
- Active-state feedback
- Responsive layout
- Dark-mode compatible
- Light-mode compatible
- Keyboard-accessible buttons
- Visible focus states
- Reduced-motion support
- Hardware-friendly CSS transforms
- No JavaScript
- No external dependencies

## 🎨 Variants

- Primary
- Outline
- Neon
- Soft
