# CSS Skew-Active Popover

A responsive portfolio popover featuring a smooth skew-to-normal hover animation using only HTML and CSS.

## Features

- Pure HTML & CSS
- Smooth skew-active hover animation
- Responsive layout
- Accessible with `prefers-reduced-motion`
- No JavaScript required
- Easy to customize

## Files

```
demo.html
style.css
README.md
```

## Usage

Open `demo.html` in any modern browser.

## Customization

- Card dimensions
- Background overlay
- Skew angle
- Animation duration
- Colors
- Typography

## Browser Support

Compatible with all modern browsers supporting CSS transforms and transitions.
