# glow-popover-menu-v10-ak

Pure CSS animated glowing popover menu component — no JavaScript required.

## How to use

```html
<div class="ease-popover-wrapper-v10">
  <button class="ease-popover-trigger-v10">Options</button>

  <ul class="ease-popover-menu-v10">
    <li class="ease-popover-item-v10"><a href="#">Item 1</a></li>
    <li class="ease-popover-item-v10"><a href="#">Item 2</a></li>
  </ul>
</div>
