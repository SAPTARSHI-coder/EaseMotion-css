# CSS Skew-Active Carousel

A pure CSS carousel designed for E-Commerce Checkout Layouts, featuring a stylish skew and scale transition when switching between active payment cards.

## Features
- Pure CSS and HTML (No JS frameworks required).
- Radio-button hack utilized for fully functional state management.
- Smooth CSS transitions using `skewY`, `scale`, and `translateX`.
- Elegant card stacking effect for inactive elements.
- Fully responsive across desktop, tablet, and mobile viewports.
- Supports `prefers-reduced-motion` accessibility standard.

## Usage
Simply open `demo.html` in your browser. Click on the payment cards or the pagination indicators at the bottom to transition smoothly between them.

## Files
- `demo.html`: The HTML structure for the checkout UI and the radio-input state management.
- `style.css`: The styling, flexbox properties, and CSS transformations for the skew-active carousel logic.
