# Interactive Carousel with Neon Styling (#78804)

A high-tech interactive carousel component featuring glassmorphic panel styling, cyan neon glow hover highlights, and smooth scroll-snap navigation.

## Features
- **Glassmorphic Container:** Frosted background blur effects paired with sleek dark mode aesthetics.
- **Neon Hover Illumination:** Dynamic border glow changes and shadow accents upon slide interaction.
- **Scroll-Snap Architecture:** Smooth native horizontal scrolling behavior with hidden scrollbar rails.

## File Hierarchy
- `style.css` - Custom properties, scroll-snap rules, neon glow variables, and media queries.
- `demo.html` - Semantic markup demonstrating carousel slide integration and pagination controls.
- `README.md` - Technical specification and architecture overview.
