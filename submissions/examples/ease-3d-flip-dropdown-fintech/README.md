# 3D-Flip Dropdown for Fintech Dashboard

A lightweight, responsive CSS 3D-Flip Dropdown designed for modern fintech
dashboard interfaces.

## Features

- Pure HTML and CSS
- No JavaScript required
- 3D rotateX flip animation
- Smooth elastic settling effect
- Native `<details>` and `<summary>` interaction
- Keyboard accessible
- Responsive across desktop, tablet and mobile
- CSS custom properties for customization
- Hover and focus states
- `prefers-reduced-motion` support
- No external dependencies
