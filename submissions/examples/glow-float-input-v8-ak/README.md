# glow-float-input-v8-ak

Pure CSS animated floating label input field with neon border focus — no JavaScript required.

## How to use

```html
<div class="ease-float-input-wrapper-v8">
  <input type="text" class="ease-float-input-v8" placeholder=" " id="inp" />
  <label for="inp" class="ease-float-label-v8">Label Text</label>
</div>
