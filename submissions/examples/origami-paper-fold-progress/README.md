# Origami Paper Fold Progress Bar

A smooth and accessible CSS-only progress bar inspired by the
**Origami Paper Fold** visual style.

## Features

- Pure HTML and Vanilla CSS
- Origami-inspired folded edges
- Smooth progress transition
- Subtle paper-shine animation
- Glassmorphism-inspired presentation
- Responsive design
- Dark-mode friendly
- Accessible progressbar semantics
- Supports `prefers-reduced-motion`
- No JavaScript
- No external dependencies

## Preview

The component displays a progress bar with a folded-paper visual effect,
a percentage indicator, and a subtle animated shine.
