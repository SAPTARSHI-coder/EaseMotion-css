# Morphing Shape Floating Badge with Gradient Transition Effects

A premium neumorphic floating badge featuring animated morphing blobs, soft shadows, floating effects, gradient transitions, and interactive hover animations built with pure HTML, CSS and JavaScript.

## Features

- Neumorphic UI
- Morphing animated blob
- Floating animation
- Gradient transition effects
- Interactive hover animation
- Responsive layout
- Pure HTML, CSS & JavaScript

## Folder Structure

```
ease-advanced-morphing-shape-floating-badge-with-gradient-transition-effects-84/
├── README.md
├── demo.html
├── style.css
└── script.js
```

## Usage

Open `demo.html` in your browser.

Customize gradients, colors and shadows inside `style.css`.
