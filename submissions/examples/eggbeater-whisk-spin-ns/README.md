# Eggbeater Whisk Spin

## What does this do?
Renders a self-contained CSS-only `ease-eggbeater-whisk-spin` demo: Hand eggbeater gears spinning twin whisks.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-eggbeater-whisk-spin`. No build step or JavaScript is required for the effect.

```html
<section class="ease-eggbeater-whisk-spin">
  <div class="ease-eggbeater-whisk-spin__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
