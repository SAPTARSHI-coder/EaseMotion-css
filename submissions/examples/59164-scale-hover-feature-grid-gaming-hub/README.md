# CSS Scale-Hover Feature Grid for Gaming Hub Layouts

A modern **Scale-Hover Feature Grid** built using pure HTML and CSS for gaming hubs, esports platforms, game launchers, and community portals.

## Features

* Pure HTML5 & CSS3
* Smooth scale-hover card animation
* Responsive feature grid
* Gaming-inspired UI
* CSS custom properties
* No JavaScript required
* Supports `prefers-reduced-motion`

## Folder Structure

```text
59164-scale-hover-feature-grid-gaming-hub/
├── demo.html
├── style.css
└── README.md
```

## Usage

1. Open `demo.html` in any modern browser.
2. Duplicate feature cards to expand the grid.
3. Customize colors using the CSS variables defined in `:root`.
4. Replace icons and text to suit your gaming project.
