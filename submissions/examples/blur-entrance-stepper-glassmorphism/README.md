# Blur Entrance Stepper - Glassmorphism UI


A modern pure CSS Blur-Entrance Stepper component designed for Glassmorphism UI layouts.

## Features

- Pure HTML and CSS implementation
- Smooth blur entrance animation
- Glassmorphism card design
- Responsive layout
- No JavaScript required
- Lightweight and performant
- Supports reduced motion accessibility


## Usage

Copy the `demo.html` and `style.css` files into your project.

Include stylesheet:
