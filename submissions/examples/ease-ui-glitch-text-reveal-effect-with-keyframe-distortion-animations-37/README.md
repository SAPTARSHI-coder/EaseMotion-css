# Glitch Text Reveal Effect with Keyframe Distortion Animations

## Overview

A minimalist clean UI component featuring a futuristic
glitch text reveal animation using CSS keyframe distortion.

Built with pure HTML, CSS and JavaScript without external
libraries.

## Features

- ⚡ Glitch text distortion animation
- 🎨 Clean minimalist design
- ✨ RGB split style effect
- 🎭 CSS keyframe based animation
- 📱 Responsive layout
- 🖱️ Interactive reveal trigger button
- ♿ Reduced motion support

## Usage

Open `demo.html` in a modern browser.

You can customize:

- Glitch colors
- Animation speed
- Text content
- Distortion intensity
