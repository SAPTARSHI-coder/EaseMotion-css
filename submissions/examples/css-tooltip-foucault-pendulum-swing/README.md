# CSS Tooltip – Foucault Pendulum Swing

A pure HTML and CSS tooltip inspired by the motion of a Foucault pendulum. The tooltip gently swings while remaining smooth, lightweight, and fully responsive.

## Features

- Foucault pendulum swing animation
- Glassmorphism tooltip
- Pure HTML & CSS
- Hardware-accelerated transforms
- Responsive layout
- Dark mode compatible
- No JavaScript required
