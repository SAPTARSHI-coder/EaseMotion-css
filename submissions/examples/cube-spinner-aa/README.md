# Pure CSS 3D Cube Spinner

**What does this do?**
Provides a 3D animated cube loading spinner using purely CSS transforms and keyframes.

**How is it used?**
Include the `.cube-loader` wrapper and the 6 `.cube-face` child elements exactly as structured in the demo. 

**Why is it useful?**
It utilizes advanced CSS `transform-style: preserve-3d` and multi-axis rotations to create a lightweight, hardware-accelerated loading indicator without SVG or JavaScript.
