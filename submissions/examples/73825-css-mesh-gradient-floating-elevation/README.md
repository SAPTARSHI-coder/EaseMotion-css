# CSS Mesh Gradient: Floating Elevation

## Overview

A layered mesh gradient that creates the impression of floating depth through slow vertical movement, blur, and translucent color fields.

## Features

- Floating gradient layers
- Independent motion speeds
- Dark-mode-friendly presentation
- Responsive layout
- Focus-visible link styling
- Reduced-motion support
- No JavaScript

## Files

- `demo.html` — demonstration markup
- `style.css` — mesh, animation, responsive, and accessibility styles
- `README.md` — documentation

## Accessibility

The gradient layers are decorative. The page link remains keyboard accessible, and reduced-motion preferences disable continuous movement.
