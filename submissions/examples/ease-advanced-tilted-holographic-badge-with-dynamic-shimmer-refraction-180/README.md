# Tilted Holographic Badge with Dynamic Shimmer Refraction

A premium **Tilted Holographic Badge** built using pure HTML and CSS featuring a neumorphic finish, animated shimmer refraction, glowing holographic gradients, and smooth hover interactions.

---

## ✨ Features

- Neumorphic card design
- Tilted holographic badge
- Dynamic shimmer refraction animation
- Animated gradient border
- Floating glow effect
- Smooth hover interactions
- Responsive layout
- Pure HTML & CSS
- Lightweight and reusable

## 🚀 Usage

1. Download or clone this project.
2. Open `demo.html` in your browser.
3. Customize colors, text, and gradients in `style.css`.
