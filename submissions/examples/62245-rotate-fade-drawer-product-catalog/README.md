# CSS Rotate-Fade Drawer for Product Catalog Layouts

A modern **Rotate-Fade Drawer** built using pure HTML5 and CSS3 for product catalog layouts. The component provides a responsive side drawer with smooth rotate-and-fade animations for displaying product details, using only HTML and CSS.

## Features

* Pure HTML5 & CSS3
* Rotate-Fade drawer animation
* CSS-only drawer toggle (checkbox technique)
* Responsive product catalog layout
* Glassmorphism drawer interface
* Product image, description, pricing, rating, stock status, and CTA button
* Smooth CSS transitions & keyframe animations
* CSS Custom Properties for easy customization
* Responsive across desktop, tablet, and mobile devices
* No JavaScript required
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in a modern browser.
2. Click the **Quick View** button to open the Rotate-Fade Drawer.
3. Click the **✕** button or overlay to close the drawer.
4. Customize colors, spacing, shadows, and animation duration using the CSS variables defined in `:root`.
