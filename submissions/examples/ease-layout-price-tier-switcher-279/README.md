# Interactive Price Comparison Card Tier Switcher Component

### High-Contrast Accessibility Edition

A modern **Interactive Price Comparison Card Tier Switcher** built with **HTML5** and **CSS3**. The component features a high-contrast accessible interface, animated tier switcher, responsive pricing cards, and smooth hover interactions while maintaining excellent readability.

---

## ✨ Features

- High-contrast accessible design
- Interactive tier switcher
- Responsive pricing cards
- Featured plan highlight
- Smooth hover animations
- Modern CSS variables
- Mobile-first responsive layout
- Keyboard accessibility
- Pure HTML & CSS implementation
- `prefers-reduced-motion` support

## 🚀 Usage

1. Open the component folder.
2. Keep `demo.html` and `style.css` in the same directory.
3. Launch `demo.html` in any modern browser.
4. Use the tier switcher to explore the pricing plans and interact with the cards.

No installation or third-party libraries are required.
