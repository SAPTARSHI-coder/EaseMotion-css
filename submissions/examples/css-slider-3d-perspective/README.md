# CSS Slider: 3D Perspective Tilt Variation

A responsive and accessible CSS-only slider featuring
three-dimensional perspective, depth, and tilt effects.

## Features

- Pure HTML and vanilla CSS
- 3D perspective tilt effect
- CSS transforms and transitions
- CSS Scroll Snap navigation
- Responsive desktop and mobile layout
- Hardware-friendly transforms
- Dark-mode compatible design
- Keyboard-accessible navigation
- Visible focus indicators
- Reduced-motion support
- No JavaScript dependencies
