# Fade-In Accordion - Minimalist Tech Layout

A pure HTML and CSS based animated accordion component created for EaseMotion CSS.

## ✨ Features

- Smooth fade-in accordion animation
- Minimalist tech inspired UI
- Pure HTML + CSS implementation
- No JavaScript required
- Glassmorphism styling
- Responsive layout
- Accessibility support with prefers-reduced-motion
