# Retro Terminal Boot Sequence

## What does this do?

A BIOS-style boot log with staggered line reveals and a blinking caret.

## How is it used?

```html
<pre class="boot"><span class="boot__line">POST memory check ...... OK</span></pre>
```

Open `demo.html` in a browser to try it.

## Why is it useful?

Expressive developer-themed entrance motion in a compact demo.
