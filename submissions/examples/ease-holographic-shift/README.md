# 🌈 Holographic Shift – Colors Shift Like Holographic Film

> A mesmerizing holographic component where colors shift like iridescent film with 4 palettes (Rainbow, Sunset, Aurora, Neon), shift control (0-100%), and particle effects.

---

## 📖 Description

The **Holographic Shift** component creates a mesmerizing holographic experience where colors shift like iridescent film with particle effects. Built with vanilla HTML, CSS, and JavaScript, it features 4 color palettes (Rainbow, Sunset, Aurora, Neon), shift control (0-100%), and particle physics for an immersive iridescent experience.

### 🎯 Core Features

- **Holographic particles** – particles shift colors like holographic film
- **4 palettes** – Rainbow, Sunset, Aurora, Neon
- **Shift control** – adjust color shift from 0-100%
- **Particle effects** – trails, glow, sparkle cross
- **Particle counter** – tracks number of particles
- **Interactive controls** – slider, palette buttons, keyboard shortcuts
- **Responsive design** – adapts to different screen sizes

### 🌈 Color Palettes

| Palette | Colors | Description |
|---------|--------|-------------|
| **Rainbow** | Red/Orange/Yellow/Green/Blue/Purple/Pink | Classic holographic rainbow |
| **Sunset** | Red/Orange/Gold/Pink/Purple/Blue | Warm sunset holographic |
| **Aurora** | Green/Blue/Purple/Pink/Gold | Aurora holographic |
| **Neon** | Pink/Purple/Blue/Green/Yellow/Orange | Neon holographic |

### ⌨️ Interaction Options

| Method | Action |
|--------|--------|
| **Mouse** | Move cursor to shift colors |
| **Touch** | Drag on mobile to shift colors |
| **Slider** | Adjust Shift (0-100%) |
| **Buttons** | Palette selection |
| **Keyboard** | `R` – Reset |

### ✨ Holographic Experience

When interacting:
1. **Particles follow** – particles follow cursor
2. **Shift applies** – controls color shifting speed
3. **Palette applies** – changes color scheme
4. **Colors shift** – particles shift through colors
5. **Status updates** – shows current state

### 🛠️ Technologies Used

- **HTML5** – semantic structure with Canvas
- **CSS3** – gradients, backdrop-filter, transforms
- **JavaScript (ES6)** – Canvas API, requestAnimationFrame, particle system

### 🎨 Design Philosophy

This component embodies **EaseMotion CSS's animation-first philosophy** through:

- **Iridescent effects** – colors shift through palettes
- **Particle systems** – glowing, shifting particles
- **Visual feedback** – status updates, counter, controls
- **Futuristic atmosphere** – holographic colors and glow
- **Human-readable classes** – `.holographic-controls`, `.palette-btn`, `.holographic-text`

### 🔧 Customization Options

| Property | Location | Default |
|----------|----------|---------|
| Palettes | `palettes` object | 4 palettes |
| Shift range | `shiftSlider` | 0-100% |
| Particle count | `generateParticles()` | 80-120 |
| Particle size | `size` | 2-8px |
