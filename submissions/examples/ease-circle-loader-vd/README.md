# Ease Circle Loader

## What does this do?

A circular loading spinner built entirely with CSS and available in multiple sizes.

---

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<div class="circle-loader medium"></div>
```

### Available sizes

```html
<div class="circle-loader small"></div>
<div class="circle-loader medium"></div>
<div class="circle-loader large"></div>
```

### Features

- Infinite rotation
- Multiple sizes
- Pure CSS
- Responsive sizing
- Lightweight implementation
- No JavaScript required

---

## Why is it useful?

Circular loaders are commonly used for page loading, button states, API requests, and other asynchronous operations.

This component provides a lightweight CSS-only loading indicator with continuous animation while following the animation-first philosophy of EaseMotion CSS.
