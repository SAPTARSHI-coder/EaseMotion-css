# CSS Glowing Gradient Border

A highly polished card with a multi-colored, spinning neon gradient border achieved via a rotating `@property` angle and `conic-gradient`.

## Features
- Hardware-accelerated smooth spinning using CSS `@property` custom variables.
- Layered pseudo-elements (`::before` and `::after`) providing both a sharp border and a diffused `blur()` glow.
- Elegant `conic-gradient` color stops seamlessly blending into transparency.
