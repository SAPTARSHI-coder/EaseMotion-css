# CSS Aurora Glow Form

Issue #73338 demonstrates a smooth Aurora Glow form using pure HTML and vanilla CSS.

## Features

- Layered aurora gradients
- Native form controls
- Clear hover and focus states
- Responsive two-column layout
- Reduced-motion fallback
- No external JavaScript

## Accessibility

Every control has a visible label and keyboard focus treatment. The glow is decorative and stops when reduced motion is requested.

## Usage

Open `demo.html` in a modern browser and reuse the form structure. Theme colors are controlled by CSS custom properties.

## Files

- `demo.html` — accessible form example
- `style.css` — aurora visuals and responsive styling
- `README.md` — documentation
