# Origami Paper Fold Particle Effect

## What does this do?
This creates a smooth, accessible, and performant pure CSS particle effect featuring origami paper fold styling with 3D transformations.

## How is it used?
Include the `origami-container` and its `origami-particle` children in your HTML and import the `style.css` file.

```html
<div class="origami-container">
    <div class="origami-particle p1"></div>
    <div class="origami-particle p2"></div>
    <!-- more particles -->
</div>
```

## Why is it useful?
It provides a lightweight, pure HTML/CSS, hardware-accelerated 3D particle animation perfect for backgrounds or loading screens, fully supporting dark mode natively without external JavaScript dependencies, aligning with EaseMotion's philosophy.
