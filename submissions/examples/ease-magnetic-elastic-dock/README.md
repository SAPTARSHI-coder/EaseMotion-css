# Ease Magnetic Elastic Dock with Velocity Spring Physics (`ease-magnetic-elastic-dock`)

macOS-style dock where icons magnify using a Gaussian curve and adjacent icons pull magnetically toward the pointer with spring physics.

## Features
- Gaussian curve magnification algorithm based on pointer proximity
- Spring elasticity physics for smooth overshoot animations
- Frosted glass container with dynamic backdrop blur
- Active application indicator light keyframes
- Touch gesture support for mobile devices
