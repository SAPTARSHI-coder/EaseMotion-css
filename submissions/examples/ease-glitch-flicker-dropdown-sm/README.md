# CSS Glitch-Flicker Dropdown

A pure HTML and CSS dropdown component designed for gaming hub interfaces.

The component combines a responsive dropdown menu with a lightweight
glitch-flicker animation, cyan/red offset layers, hover transitions, and
keyboard-friendly focus states.

## Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Glitch-flicker interaction
- CSS keyframe animations
- Hover and keyboard focus support
- Responsive on desktop, tablet, and mobile
- Customizable CSS variables
- `prefers-reduced-motion` support
- Lightweight and easy to reuse
