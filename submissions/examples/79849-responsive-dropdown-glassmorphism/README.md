# Responsive Glassmorphism Dropdown

A modern and responsive dropdown component built with pure HTML and CSS.

Created for EaseMotion CSS issue #79849.

## Features

- Glassmorphism UI
- Fully responsive layout
- Pure HTML and CSS
- No JavaScript required
- Native `<details>` and `<summary>` interaction
- Frosted glass effect using `backdrop-filter`
- Smooth dropdown animation
- Hover and focus states
- Keyboard-friendly interaction
- Responsive typography
- Mobile-friendly touch targets
- Accessible focus indicators
- Reduced-motion support
- No external dependencies

## Preview

The component contains:

- A glassmorphic dropdown trigger
- Navigation items
- Item descriptions
- Notification badge
- New-message indicator
- Divider
- Animated chevron
- Responsive mobile layout
