# Animated Progress Indicators

A lightweight CSS-only collection of animated progress indicators for displaying skill levels, completion percentages, loading states, and other progress-based information.

## Features

- Pure HTML and CSS
- Smooth progress animation
- Responsive design
- Multiple progress levels
- No JavaScript required
- Supports reduced-motion preferences
- Easy to customize

## Files

- `demo.html` - Example implementation
- `style.css` - Animation and styling
- `README.md` - Documentation

## Usage

Add the following structure to your HTML:

```html
<div class="progress">
  <div class="progress-fill html"></div>
</div>
