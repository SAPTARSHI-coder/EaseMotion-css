# CSS Blur-Entrance Tooltip for Accessible Web Layouts

A modern **Blur-Entrance Tooltip** component built completely with **HTML5 and CSS3**. This showcase demonstrates interactive tooltip elements with smooth blur entrance animations, glassmorphism styling, glowing effects, responsive layouts, and accessibility support without requiring JavaScript.

---

## ✨ Features

- 🌫️ Blur entrance animation
- 💎 Glassmorphism tooltip design
- 🌈 Gradient trigger buttons
- ✨ Glow effects
- 🎯 CSS Custom Properties
- ⚡ Smooth CSS transitions
- 📱 Fully responsive layout
- 🧩 Pure HTML5 & CSS3
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

## 🚀 Getting Started

1. Open `demo.html` in any modern browser.
2. Hover over the buttons to display tooltips.
3. Customize colors, spacing, and animation timing using CSS variables.
