# CLS Dynamic Form Audit

A CSS-only audit component for identifying and demonstrating layout-shift risks in dynamic form interfaces.

## Features

- CLS score visualization
- Layout stability indicators
- Dynamic form audit panel
- Reserved validation-message area
- Stable input dimensions
- Consistent form spacing
- Responsive layout
- No JavaScript required

## Files

- `demo.html` — standalone demonstration
- `style.css` — component styling
- `README.md` — documentation

## Usage

Open `demo.html` directly in a browser.

The component can also be reused by including:

```html
<link rel="stylesheet" href="style.css">
