# CSS Shimmer-Sweep Badge for Fintech Dashboard Layouts

A modern **Shimmer-Sweep Badge** component built using pure HTML5 and CSS3 for fintech dashboard layouts. This component provides animated status indicators with a smooth light sweep effect, glassmorphism cards, and responsive dashboard styling.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Fintech dashboard badge design
* Smooth shimmer sweep animation
* Animated status indicators
* Gradient badge styles
* Glassmorphism metric cards
* Hover shimmer acceleration
* Multiple badge states:

  * Active
  * Verified
  * Pending
  * Premium
  * Secure
  * Growth
* Responsive dashboard layout
* CSS Custom Properties support
* Lightweight keyframe animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. View the animated fintech status badges.
3. Hover over badges to trigger faster shimmer effects.
4. Customize colors, spacing, and animation speed using CSS variables.

## CSS Custom Properties

  --surface:rgba(255,255,255,.85);
  --primary:#2563eb;

}
