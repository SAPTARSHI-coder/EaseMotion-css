# CSS Neon-Frame Modal

A modern **Neon-Frame Modal** built using pure HTML5 and CSS3 for Gaming Hub layouts. The modal features an animated neon border with a smooth entrance animation while remaining lightweight, responsive, and accessible.

---

## ✨ Features

- Pure HTML5 & CSS3
- Animated neon frame
- Gaming-inspired UI
- Responsive layout
- CSS Custom Properties
- No JavaScript required
- Accessible checkbox toggle
- `prefers-reduced-motion` support
