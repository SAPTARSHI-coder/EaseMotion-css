# Interactive Material Button

A responsive CSS-only interactive button component inspired by Material Design principles.

## Features

- Material Design inspired styling
- Primary button
- Secondary button
- Outlined button
- CSS-only ripple effect
- Hover elevation
- Press animation
- Keyboard focus support
- Fully responsive
- Reduced-motion support
- No JavaScript required
