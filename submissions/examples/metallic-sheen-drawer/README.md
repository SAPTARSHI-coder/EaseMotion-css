# CSS Drawer: Metallic Sheen Variation

A smooth and responsive drawer/sidebar component featuring a metallic sheen visual style using pure HTML and vanilla CSS.

## Features

- Pure HTML and CSS
- Metallic gradient surface
- Animated reflective sheen
- Subtle elevation on hover
- Responsive layout
- Dark interface styling
- Keyboard-accessible navigation
- Visible focus states
- Reduced-motion support
- No external dependencies

## Usage

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
