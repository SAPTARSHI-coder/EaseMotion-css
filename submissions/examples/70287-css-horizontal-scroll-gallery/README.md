# CSS Horizontal Scroll Gallery

A pure CSS horizontal scrolling gallery component.

## Features

- Pure CSS implementation
- Smooth horizontal scrolling
- Scroll snap behaviour
- Responsive card layout
- Hover animations
- No JavaScript dependency

## Usage

Copy `demo.html` and `style.css` into your project.

## Technologies

- HTML5
- CSS3

## Accessibility

- Semantic HTML structure
- Proper section labels
- Keyboard friendly native scrolling
