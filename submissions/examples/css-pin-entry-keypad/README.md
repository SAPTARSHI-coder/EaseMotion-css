# CSS PIN Entry Keypad

A responsive PIN entry keypad built with HTML and CSS.

## Features

- Responsive 3 × 4 keypad layout
- Number buttons from 0–9
- Clear and delete action buttons
- Hover and press animations
- Keyboard-focus accessibility
- Visible focus indicators
- Reduced-motion support
- No JavaScript required for the visual component

## Files

- `demo.html` — Component markup and demo page
- `style.css` — Component styling and animations

## Usage
