# DOM Event Cleanup Component

A responsive CSS-only component representing safe DOM event cleanup when a component is destroyed.

## Features

- Clean event cleanup status interface
- Registered and removed event indicators
- Event listener status cards
- Memory leak status
- Responsive layout
- Smooth hover interactions
- Reduced-motion support
- No JavaScript or external dependencies

## Events Represented

The demo visually represents cleanup for:

- `click`
- `scroll`
- `resize`
- `mouseenter`

## Usage

Open `demo.html` directly in a browser.

No server or build process is required.
