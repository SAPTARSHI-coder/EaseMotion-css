# Neumorphic Carousel Usage Guide

## Overview

The Neumorphic Carousel is a responsive carousel component that uses
soft shadows, raised surfaces, and subtle interactions to create a
clean neumorphic interface.

The component is available in:

`submissions/examples/neumorphic-carousel/`

## Files

The example contains:

- `demo.html` — standalone demo that can be opened directly in a browser.
- `style.css` — CSS styles for the carousel.
- `README.md` — component-level documentation.

## Features

- Responsive carousel layout
- Neumorphic card design
- Soft raised and inset shadows
- Smooth hover transitions
- Horizontal scrolling
- Keyboard focus support
- Dark mode support
- Reduced-motion support
- No external dependencies
