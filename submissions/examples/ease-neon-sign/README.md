# 💡 Neon Sign – Flickering Neon Sign Effect

> A vibrant neon sign component with flickering effects, 5 colors (Pink, Blue, Green, Red, Purple), flicker control (0-100%), and glowing particle effects.

---

## 📖 Description

The **Neon Sign** component creates a vibrant neon sign experience with flickering effects and glowing particles. Built with vanilla HTML, CSS, and JavaScript, it features 5 colors (Pink, Blue, Green, Red, Purple), flicker control (0-100%), and glow particles for an authentic neon atmosphere.

### 🎯 Core Features

- **Neon sign** – vibrant neon sign with glow effects
- **5 colors** – Pink, Blue, Green, Red, Purple
- **Flicker control** – adjust flicker intensity from 0-100%
- **Glow particles** – 50 floating glow particles
- **Brightness display** – shows current brightness level
- **Interactive controls** – slider, color buttons, keyboard shortcuts
- **Responsive design** – adapts to different screen sizes

### ✨ Neon Experience

When interacting:
1. **Sign glows** – neon sign lights up
2. **Flicker applies** – controls flicker intensity
3. **Color applies** – changes neon color
4. **Particles glow** – floating particles illuminate
5. **Brightness updates** – shows current level
6. **Status updates** – shows current state

- Perfect for cyberpunk themes, night club interfaces, or vibrant experiences

### 🛠️ Technologies Used

- **HTML5** – semantic structure with Canvas
- **CSS3** – gradients, backdrop-filter, transforms
- **JavaScript (ES6)** – Canvas API, requestAnimationFrame, particle system

### 🎨 Design Philosophy

This component embodies **EaseMotion CSS's animation-first philosophy** through:

- **Glow effects** – vibrant neon glow with shadows
- **Flicker effects** – organic flickering patterns
- **Particle systems** – floating glow particles
- **Visual feedback** – status updates, brightness, controls
- **Vibrant atmosphere** – neon colors and glow
- **Human-readable classes** – `.neon-controls`, `.color-btn`, `.neon-text`

### 🔧 Customization Options

| Property | Location | Default |
|----------|----------|---------|
| Colors | `colorConfigs` object | 5 colors |
| Flicker range | `flickerSlider` | 0-100% |
| Particle count | `generateGlowParticles()` | 50 |
| Glow intensity | `brightness` | 0-1 |
