# ease-elastic-modal-bh

Pure CSS elastic-slide modal for fintech dashboards.

## Features
- Elastic slide hover effect
- Modal variants
- Responsive design
- Accessibility support

## Usage
```html
<div class="ease-modal ease-modal-elastic">Content</div>
```

## CSS Classes
- `.ease-modal` - Base modal
- `.ease-modal-elastic` - Elastic slide effect
