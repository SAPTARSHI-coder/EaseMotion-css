# CSS Achievement Badge Unlock

A pure CSS achievement badge animation featuring an unlock effect,
shine animation, floating badge, and celebratory confetti.

## Features

- Pure CSS implementation
- No JavaScript required
- Achievement badge unlock animation
- Shine/fanfare effect
- Confetti celebration
- Responsive design
- Accessible badge description
- Reduced-motion support

## Files

- `demo.html` - Demonstration page
- `style.css` - Badge styling and animations

## Accessibility

The badge uses an accessible label through:

```html
<div
  class="badge"
  role="img"
  aria-label="Achievement unlocked: Star Performer"
>
