# Morph-Glow Progress Bar

A minimalist, tech-inspired progress bar with a morphing glow effect powered by pure CSS.

## Usage

```html
<div class="progress-wrapper">
    <div class="progress-bar morph-glow-active"></div>
</div>
```

## Why is it useful?

This component provides a sleek and futuristic visual indicator for loading states or progression. It aligns perfectly with modern minimalist and tech-focused design layouts while maintaining accessibility through `prefers-reduced-motion` support.
