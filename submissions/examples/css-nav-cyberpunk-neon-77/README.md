# Cyberpunk Neon Navigation

A smooth, accessible, and performant pure CSS navigation featuring Cyberpunk Neon styling with glitch hover effects.

## Usage

```html
<nav class="cyber-nav">
    <ul class="cyber-nav-list">
        <li class="cyber-nav-item"><a href="#" class="cyber-nav-link" data-text="HOME">HOME</a></li>
        <li class="cyber-nav-item"><a href="#" class="cyber-nav-link" data-text="ABOUT">ABOUT</a></li>
        <li class="cyber-nav-item"><a href="#" class="cyber-nav-link" data-text="WORK">WORK</a></li>
        <li class="cyber-nav-item"><a href="#" class="cyber-nav-link" data-text="CONTACT">CONTACT</a></li>
    </ul>
</nav>
```

## Why it's useful

It provides a high-energy, futuristic cyberpunk aesthetic using only CSS, which aligns perfectly with EaseMotion's philosophy of delivering premium, dynamic, and hardware-accelerated pure CSS animations without relying on heavy JavaScript.
