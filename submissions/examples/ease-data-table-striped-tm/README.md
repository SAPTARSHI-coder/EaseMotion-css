# Data Table Striped Component

Add ease-data-table-striped-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|---------|
| `--dtb-accent` | `#6366f1` |
| `--dtb-green` | `#10b981` |
| `--dtb-radius` | `10px` |
| `--dtb-shadow` | `0 4px 20px rgba(0,0,0,.3)` |

## Technique

`nth-child(even)` creates zebra striping. `tr:hover td` highlights entire row.
