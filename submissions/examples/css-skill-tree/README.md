# CSS Skill Tree

A responsive skill tree component built using pure HTML and CSS.

## Features

- Pure HTML and CSS
- Unlocked and locked skill states
- Branching connector lines
- Hover interactions
- Responsive layout
- Accessible semantic structure
- Keyboard-friendly focus states
- `prefers-reduced-motion` support
- No JavaScript required
