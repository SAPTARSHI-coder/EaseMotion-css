# Animated Material Design Sidebar (Lite)

## Overview

A responsive and animated sidebar inspired by Material Design principles.

This component provides a clean navigation experience with smooth
transitions, active navigation states, a profile section, and a
responsive mobile drawer.

## Features

- Responsive Material-inspired sidebar
- Smooth entrance animation
- Animated hover and active states
- Mobile-friendly navigation drawer
- Profile section with avatar
- Clean typography and spacing
- Lightweight HTML, CSS, and JavaScript
- No external dependencies
