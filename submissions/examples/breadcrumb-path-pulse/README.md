# Breadcrumb Path Pulse

A CSS-only breadcrumb navigation example with staggered path markers, animated connectors, and a highlighted active page state.

## Features

- Staggered breadcrumb entrance using custom properties.
- Connector pulse that travels across the navigation path on hover or focus.
- Accessible semantic `nav` markup with `aria-current` on the active destination.
- Responsive wrapping and reduced-motion support.

## Files

- `demo.html` - semantic breadcrumb structure and demo shell.
- `style.css` - layout, connector pulse animation, active crumb styling, and responsive behavior.

## How to Use

Open `demo.html` in a browser and hover over or focus the breadcrumb trail to see the active path pulse.
