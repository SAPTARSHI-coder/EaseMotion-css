# Chimney Sweep Brush

## What does this do?
Renders a self-contained CSS-only `ease-chimney-sweep-brush` demo: Chimney sweep brush ascending a flue with soot fall.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-chimney-sweep-brush`. No build step or JavaScript is required for the effect.

```html
<section class="ease-chimney-sweep-brush">
  <div class="ease-chimney-sweep-brush__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
