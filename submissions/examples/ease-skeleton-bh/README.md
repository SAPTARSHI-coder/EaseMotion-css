# ease-skeleton-bh

Pure CSS skeleton loading shimmer component.

## What does this do?
Creates skeleton loading placeholders with smooth shimmer animation.

## How is it used?
```html
<div class="ease-skeleton-bh ease-skeleton-text-bh"></div>
<div class="ease-skeleton-bh ease-skeleton-avatar-bh"></div>
<div class="ease-skeleton-bh ease-skeleton-card-bh"></div>
```

## Why is it useful?
Provides visual feedback during content loading states.
