# 🔊 Solar Flare Radial Toast

A smooth and performant pure CSS toast notification inspired by the
intense radial energy of a solar flare.

## ✨ Features

- Pure HTML and CSS
- No JavaScript required
- Solar flare radial glow
- Animated energy sweep
- Rotating radial rays
- Glass-inspired notification surface
- Smooth entrance animation
- Subtle floating effect
- CSS-only show/hide interaction
- Dark mode compatible
- Responsive design
- Hardware-accelerated transforms
- Reduced-motion accessibility support

## 🎨 Style

**Category:** Notifications & Toasts  
**Variation:** Solar Flare Radial

The component combines layered radial gradients, animated glow effects,
blur, and CSS transforms to create a solar-flare-inspired notification.

## 🛠️ Technologies

- HTML5
- CSS3
- CSS Custom Properties
- CSS Animations
- CSS Gradients
- Backdrop Filter

## 🚀 Usage

Open `demo.html` in a modern browser.

Use the **Toggle Notification** control to display the toast.

The close button uses a CSS checkbox interaction, so no JavaScript is
required.

## ♿ Accessibility

The component includes:

- Semantic notification markup
- `role="status"`
- `aria-live="polite"`
- Keyboard-focusable controls
- Visible focus styles
- `prefers-reduced-motion` support
- Screen-reader-only dismissal text

## 🌙 Dark Mode

The component automatically adapts to the user's preferred color scheme
using `prefers-color-scheme`.

## 📱 Responsive Design

The toast adapts to smaller screens and maintains readable spacing and
content sizing on mobile devices.
