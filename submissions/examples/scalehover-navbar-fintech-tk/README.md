# Scale-Hover Navbar (Fintech Dashboard)

## What does this do?

A responsive fintech dashboard navigation bar featuring smooth scale-hover interactions, an animated underline indicator, and a clean glassmorphism-inspired design. Built entirely with HTML and CSS.

---

## Features

- Scale-hover animation for navigation links
- Animated underline effect
- Glassmorphism navbar
- Search bar
- Notification badge
- User profile section
- Responsive layout
- Pure HTML & CSS (No JavaScript)
- Supports `prefers-reduced-motion`

---

- `demo.html` — Component showcase
