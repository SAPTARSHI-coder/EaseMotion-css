# Archimedes Screw Lift

## What does this do?
Renders a self-contained CSS-only `ease-archimedes-screw-lift` demo: Archimedes screw water lift spiral.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-archimedes-screw-lift`. No build step or JavaScript is required for the effect.

```html
<section class="ease-archimedes-screw-lift">
  <div class="ease-archimedes-screw-lift__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
