# CSS Glowing Orbit Button

A pure CSS button with a luminous border point that continuously orbits the action on hover and keyboard focus.

## Features

- Pure CSS animation
- Hover and `:focus-visible` support
- Responsive sizing
- Semantic link control
- Reduced-motion handling
- No JavaScript or dependencies

## Files

- `demo.html` — semantic interactive example
- `style.css` — orbit animation, button styling, responsive rules, and accessibility states

## Usage

Open `demo.html` in a modern browser.

## Accessibility

The control is a native link with a visible keyboard focus ring. Motion is removed when `prefers-reduced-motion` is enabled.
