# Tornado Spin · Tornado Forms and Spins 🌪️

An interactive tornado formation with spinning debris, funnel cloud, and atmospheric storm effects. Watch the tornado form and spin!

## Features

- 🌪️ **Tornado Formation** – Funnel cloud forms and spins
- 🎚️ **Speed Control** – Adjust spin speed (1-10)
- 🎚️ **Debris Control** – Adjust debris count (20-80)
- ⏸️ **Pause/Resume** – Toggle animation
- 🔄 **Start/Stop** – Control tornado
- 🔄 **Reset** – Reset tornado
- 📊 **Counter** – Tracks spins

## How to Use

1. Click **SPIN** or press **Space** to form the tornado
2. Click **STOP** or press **Space** again to stop
3. Adjust **Speed** for spin pace
4. Adjust **Debris** for particle count
5. Press **RESET** or **R** to reset
6. Press **PAUSE** or **P** to pause/resume animation

## Controls

| Action | Method |
|--------|--------|
| Spin/Stop | Spin/Stop button / Space / Click canvas |
| Reset | Reset button / R key |
| Pause/Resume | Pause button / P key |
| Speed | Speed slider |
| Debris | Debris slider |
