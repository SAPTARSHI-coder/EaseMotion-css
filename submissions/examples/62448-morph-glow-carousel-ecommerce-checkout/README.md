# CSS Morph-Glow Carousel for E-Commerce Checkout Layouts

A modern **Morph-Glow Carousel** built using pure HTML5 and CSS3 for e-commerce checkout interfaces. The component showcases featured products with morphing glow effects, glassmorphism styling, and responsive layouts without requiring JavaScript.

## Features

* Pure HTML5 & CSS3
* Morph-Glow animation effect
* Featured product carousel layout
* Glassmorphism cards
* Responsive desktop, tablet, and mobile design
* CSS Custom Properties
* Smooth hover interactions
* No JavaScript required
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Customize product cards and pricing.
3. Adjust colors using the CSS variables in `:root`.
4. Integrate the component into an e-commerce checkout or product showcase page.
