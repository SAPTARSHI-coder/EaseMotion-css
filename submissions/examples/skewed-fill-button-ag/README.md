# Skewed Fill Button

1. What does this do? Provides a dynamic button hover effect where a solid background color slides in diagonally from the left, filling the button completely while transitioning the text color for high contrast.
2. How is it used? Apply `.skewed-fill-btn` to a `button` element and wrap its inner text inside a `span`.
3. Why is it useful? Interactive buttons are critical for engaging UIs. Providing a highly polished, diagonal fill transition natively in CSS adds a modern, aggressive micro-interaction that fits perfectly with EaseMotion's dependency-free philosophy.
