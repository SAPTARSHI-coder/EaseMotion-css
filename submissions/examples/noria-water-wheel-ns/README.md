# Noria Water Wheel

## What does this do?
Renders a self-contained CSS-only `ease-noria-water-wheel` demo: Noria water wheel bucket lift.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-noria-water-wheel`. No build step or JavaScript is required for the effect.

```html
<section class="ease-noria-water-wheel">
  <div class="ease-noria-water-wheel__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
