# Glass Weather Widget

This submission demonstrates a modern weather widget built with
**EaseMotion CSS**. It includes a glass-style weather card, animated details,
hover lift effect, and responsive layout.

## 🌟 Features

- **Weather card UI** with location, temperature, condition, and summary.
- **Metric cards** for humidity, wind, and UV index.
- **Hourly forecast row** with simple responsive cards.
- **Staggered entrance animation** using `ease-slide-up` and delay utilities.
- **Hover lift effect** using `ease-hover-lift`.
- **Glass-style visual design** created with custom CSS.
- **Responsive layout** for mobile and desktop.
- **Reduced motion support** for users who prefer less animation.

## 📁 Files

- `demo.html` — interactive weather widget demo
- `style.css` — original glass weather styling
- `README.md` — documentation for this submission

## 🛠️ How to Run

1. Open `demo.html` in your browser.
2. Watch the weather panel and forecast cards animate on load.
3. Hover over the main card to see the lift effect.
4. Resize the browser window to check responsive behavior.

## 🧩 EaseMotion Classes Used

- `ease-center`
- `ease-card`

- `ease-slide-up`
- `ease-delay-100`
- `ease-delay-200`
