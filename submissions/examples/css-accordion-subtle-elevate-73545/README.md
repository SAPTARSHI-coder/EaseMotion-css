# CSS Accordion: Subtle Elevate Variation

A clean and modern accordion component featuring subtle elevation effects, smooth transitions, and responsive design built entirely with HTML and CSS.

## Features

- Pure HTML & CSS
- Subtle elevation styling
- Smooth expand/collapse animation
- Accessible native accordion behavior
- Responsive layout
- Dark mode compatible
- Hardware accelerated transitions

## Files

- demo.html
- style.css

## Usage

```html
<details class="accordion">
  <summary>Accordion Title</summary>
  <div class="content">
    Accordion content goes here.
  </div>
</details>
