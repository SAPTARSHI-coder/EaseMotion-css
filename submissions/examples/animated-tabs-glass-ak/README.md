\# Glassmorphism UI Jello-Hover Tabs Component (`ease-tabs-glass-ak`)



A glassmorphism UI-styled pure CSS animated tabs component featuring a smooth jello-hover interaction transition built for \*\*EaseMotion CSS\*\*.



\## Features

\- \*\*Jello-Hover Interaction\*\*: Leverages spring-based cubic-bezier scales and subtle rotations for lively frosted panel states.

\- \*\*Custom CSS Variables\*\*: Control timing parameters and jello easing curves globally via `--tabs-timing` and `--tabs-jello-easing`.

\- \*\*Keyboard Accessible\*\*: Fully supports standard focus states and accessibility guidelines.

\- \*\*Zero JavaScript Dependencies\*\*: Powered entirely by native CSS classes and custom properties.



\## Quick Usage

1\. Place this folder under:

&#x20;  `submissions/examples/animated-tabs-glass-ak/`

2\. Open `demo.html` in any browser to review the glassmorphism interactive tabs.
