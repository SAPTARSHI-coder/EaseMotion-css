# CSS Bouncing Word Text

Issue #70337 demonstrates a staggered word entrance where each word bounces into place using CSS keyframes.

## Features

- Pure HTML and vanilla CSS
- Per-word staggered timing
- Spring-like entrance easing
- Responsive typography
- Reduced-motion fallback

The words remain real text nodes inside a semantic heading. The visual animation is decorative, and the complete phrase is exposed through `aria-label`.

Open `demo.html` to view the pattern and reuse the spans for short display headings.

## Files

- `demo.html` — semantic demonstration
- `style.css` — staggered animation and responsive layout
- `README.md` — documentation
