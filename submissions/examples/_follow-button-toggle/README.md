# Follow Button Toggle

## What does it do?

This example creates an animated Follow/Following button using only HTML and CSS.

## How is it used?

Click the button to switch between the Follow and Following states. The button can also be focused and activated using the keyboard.

## Why is it useful?

This CSS-only component can be used in social media profiles, community platforms, user profiles, and other interfaces where users need to follow or unfollow someone.
