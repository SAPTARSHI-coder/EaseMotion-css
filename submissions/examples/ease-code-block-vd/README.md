# Ease Code Block

## What does this do?

A compact code block component for displaying formatted code snippets with a language label and copy action area.

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<div class="code-block">
    <div class="code-header">
        <span class="code-language">HTML</span>
        <button class="copy-button" type="button">Copy</button>
    </div>

    <pre><code>&lt;button&gt;Click me&lt;/button&gt;</code></pre>
</div>
```

## Features

- Code content
- Language label
- Copy action area
- Dark styling
- Responsive horizontal overflow
- Hover interaction
- Pure CSS styling

## Why is it useful?

Code blocks are commonly used in documentation, developer portals, tutorials, and technical websites.

This component provides a clean and reusable code presentation pattern with a compact header and responsive overflow while following the animation-first philosophy of EaseMotion CSS.
