# Interactive Bento Grid Spotlight Reveal (EaseMotion CSS)

An interactive bento grid component featuring asymmetric card spans, hover radial spotlight gradient glows, and glassmorphism styling built with HTML5 and CSS3.

## 1. What does this do?
This component renders a modern Web3/SaaS bento grid layout. Hovering over individual tiles activates a radial spotlight gradient glow (`radial-gradient` overlay), while card surfaces elevate with smooth hardware-accelerated CSS lift transitions (`transform: translateY(-6px)`).

## 2. How is it used?
Link `style.css` in your HTML file and construct your bento tile elements within `.bento-grid` as demonstrated in `demo.html`.

## 3. Why is it useful?
- **Modern Dashboard & Feature Grid UI**: Elevates landing page feature showcases with Apple/Vercel-inspired bento grid design patterns.
- **Pure CSS Performance**: Zero JavaScript dependencies for high 60fps rendering using CSS Grid and hardware-accelerated hover states.
- **Responsive Layout**: Seamlessly reflows from multi-column asymmetric layouts to single-column mobile views.
