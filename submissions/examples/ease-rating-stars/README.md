# Ease Rating Stars

An interactive, accessible star-rating component with smooth hover animations and persistent selection.

##  Overview
The `ease-rating-stars` component provides an intuitive 5-star rating interface. Stars fill with color and scale up smoothly when hovered or focused, and retain their filled state upon selection.

##  Files Included
- `demo.html`: Minimal semantic HTML markup for the rating control.
- `style.css`: Modern CSS styling featuring smooth flexbox layout and interactive transitions.

##  Key Features
- **Smooth Scaling:** Stars scale up smoothly (`1.25x`) on hover.
- **Directional Fill:** Hovering over any star highlights it and all preceding stars.
- **Persistent State:** Selected rating stays active and fixed after user click.
- **Zero Dependencies:** Built purely using CSS and HTML.
