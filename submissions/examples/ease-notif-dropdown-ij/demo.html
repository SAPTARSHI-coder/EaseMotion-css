Component Specifications

🔔

Spring Bell Physics

Uses `:checked` CSS selector combined with cubic-bezier elastic spring keyframes for tactile bell animation.

🎯

Zero-JS Tab Filtering

Leverages sibling radio combinators (`#filter-unread:checked ~ .notif-list`) to filter notifications instantly in CSS.

✨

Glassmorphism UI

Backdrop-filter blur layer with subtle multi-border reflections and dark/light adaptive color gradients.

♿

Accessibility First

Full keyboard navigation support, focus-visible outlines, contrast ratios > 4.5:1, and reduced motion safety.
