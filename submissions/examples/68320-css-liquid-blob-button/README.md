# CSS Liquid Blob Button

## Overview

A fluid CSS button whose layered shapes morph and merge on hover.

## Features

- Organic border-radius animation
- Layered blob surfaces
- Hover and focus states
- Responsive button grid
- Reduced-motion support
- No JavaScript dependency

## Files

- `demo.html` — button examples and component anatomy
- `style.css` — liquid shapes, transitions, colors, and responsive rules

## Usage

Open `demo.html` in a modern browser.
