# Micro Menu Hamburger

A hamburger icon whose three lines fold themselves into a close arrow.

## Features
- Top line tilts into an X half
- Middle line folds away
- Bottom line swings up to join

## Usage
```html
<div class="mmh-btn">
  <span class="mmh-line"></span>
  <span class="mmh-line"></span>
  <span class="mmh-line"></span>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
