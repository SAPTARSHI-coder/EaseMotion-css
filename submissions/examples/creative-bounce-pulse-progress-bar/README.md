# CSS Bounce-Pulse Progress Bar for Creative Portfolio Layouts

A modern **Bounce-Pulse Progress Bar** built completely with **HTML5 and CSS3**. This showcase demonstrates animated progress indicators with smooth bounce effects, pulse animations, gradient styling, glassmorphism cards, responsive layouts, and accessibility support without requiring JavaScript.

---

## ✨ Features

- 🔄 Bounce-Pulse animation effect
- 📊 Animated progress indicators
- 🌈 Gradient progress styling
- 💎 Glassmorphism progress cards
- ✨ Smooth glow effects
- ⚡ CSS keyframe animations
- 🎯 CSS Custom Properties
- 📱 Fully responsive layout
- 🧩 Pure HTML5 & CSS3
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

## 🚀 Getting Started

1. Open `demo.html` in any modern browser.
2. View the animated progress bars.
3. Hover over cards to trigger additional interactions.
4. Customize colors, spacing, and animation timing using CSS variables.
