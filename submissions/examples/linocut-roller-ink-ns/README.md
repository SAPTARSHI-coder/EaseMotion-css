# Linocut Roller Ink

## What does this do?
Renders a self-contained CSS-only `ease-linocut-roller-ink` demo: Linocut ink roller charging the block.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-linocut-roller-ink`. No build step or JavaScript is required for the effect.

```html
<section class="ease-linocut-roller-ink">
  <div class="ease-linocut-roller-ink__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
