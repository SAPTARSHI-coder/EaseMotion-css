# Gamepad Controller View

Closes #74801

Stylized gamepad controller with directional pad, brand logo + analog stick, and the classic colored A/B/X/Y face buttons.

## Technique

3-column grid layout for the controller body. D-pad is a 3x3 grid with buttons in cardinal positions. Face buttons arranged in a diamond pattern using grid placement. Each button has a 3D press effect on `:active`.
