How the reveal works

1

Wrapper clips the swap

.hover-reveal-text is position: relative with overflow: hidden, so anything sliding outside its own height is simply cut off.

2

Secondary text waits below

.secondary-text starts position: absolute; top: 100%; opacity: 0 — parked just under the visible area, invisible until hover.

3

Both animate on :hover

On hover, the primary text slides up out of view while the secondary text slides from top: 100% to top: 0 — a single synchronized transition, no keyframes needed.

Copy-ready markup

HTML 
<span class="hover-reveal-text">
  <span class="primary-text">Hover Me</span>
  <span class="secondary-text">Welcome!</span>
</span>

Submission checklist

  • ✓
    CSS-only — no JavaScript is used or required for the reveal itself.
  • ✓
    Keyboard accessible — the reveal also triggers on :focus-within, not just mouse hover.
  • ✓
    Works inside buttons, cards, and links without extra wrapper markup or layout changes to the parent.
  • ✓
    Respects prefers-reduced-motion by shortening the transition instead of removing the effect entirely.
