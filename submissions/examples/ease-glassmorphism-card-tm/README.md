# Glassmorphism Card Component

Add ease-glassmorphism-card-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|--------|
| `--gc-blur` | `16px` |
| `--gc-radius` | `16px` |
| `--gc-border` | `1px solid rgba(255,255,255,0.1)` |
| `--gc-accent` | `#6366f1` |

## Technique

`backdrop-filter: blur()` on the overlay creates the frosted glass effect over the background image.
