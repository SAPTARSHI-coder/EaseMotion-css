# Glassmorphism Blur Mesh Gradient

A pure CSS mesh-gradient component featuring a modern glassmorphism blur effect.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript
- No external dependencies
- Layered mesh gradients
- Glassmorphism blur effect
- Smooth hover transitions
- Animated gradient movement
- Floating decorative orbs
- Responsive design
- Dark-mode friendly visual style
- Hardware-accelerated transforms
- Reduced-motion accessibility support
- Keyboard-accessible button focus state

## Preview

The demo creates a translucent glass card over a layered mesh-gradient
background. Multiple radial gradients create the colorful mesh while
`backdrop-filter` produces the glassmorphism blur effect.
