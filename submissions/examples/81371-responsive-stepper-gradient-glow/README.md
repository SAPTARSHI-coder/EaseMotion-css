# Responsive Stepper — Gradient Glow

A responsive stepper component with a modern Gradient Glow visual
style created for EaseMotion CSS issue #81371.

## Features

- Gradient glow progress line
- Completed, active and upcoming states
- Animated active marker
- Gradient progress indicator
- Soft glowing accents
- Smooth hover elevation
- Responsive desktop, tablet and mobile layout
- Reduced-motion support
- Pure HTML and CSS
- No JavaScript dependencies
