# CSS Shimmer-Sweep Modal for SaaS Showcase Layouts

A modern **Shimmer-Sweep Modal** built using pure HTML and CSS. The modal features a smooth shimmer sweep highlight animation with elegant glassmorphism styling, responsive layout, and accessibility support without requiring JavaScript.

## ✨ Features

- Pure HTML5 & CSS3
- Shimmer sweep animation
- Glassmorphism modal
- Responsive layout
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
