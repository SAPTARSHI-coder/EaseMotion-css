# Glass Activity Feed

This submission demonstrates a modern activity feed UI built with
**EaseMotion CSS**. It includes glass-style cards, staggered entrance
animation, hover lift effects, and responsive layout.

## 🌟 Features

- **Activity feed cards** with avatar, text, meta information, and badge.
- **Staggered entrance animation** using `ease-slide-up` and delay utilities.
- **Hover lift effect** using `ease-hover-lift`.
- **Glass-style cards** created with custom CSS.
- **Responsive layout** for mobile and desktop.
- **Accessible semantic markup** using article, header, section, and footer.
- **Reduced motion support** for users who prefer less animation.

## 📁 Files

- `demo.html` — interactive activity feed demo
- `style.css` — original glass feed styling
- `README.md` — documentation for this submission

## 🛠️ How to Run

1. Open `demo.html` in your browser.
2. Watch the feed items enter with staggered animation.
3. Hover over the cards to see the lift effect.
4. Resize the browser window to check mobile responsiveness.

## 🧩 EaseMotion Classes Used

- `ease-center`
- `ease-card`
- `ease-fade-in`
- `ease-slide-up`
- `ease-delay-100`
- `ease-delay-200`
- `ease-delay-300`
- `ease-delay-400`
