# Storage usage cylinder

A cylindrical storage indicator whose fill rises and falls as capacity changes.

## How to view

Open `demo.html` in any modern browser. The demo is fully self-contained — no CDN, no framework, no JavaScript.

## How to use

Copy `style.css` into your project's stylesheet. Every class used in the demo is namespaced with `storageusagecylinderfill-` to avoid collisions.

## Why this is useful for EaseMotion CSS

Quota / disk pattern; the cylinder makes the value feel physical.
