# Hover Toggle with Gradient

A highly responsive and smooth theme toggle switch component designed using pure HTML and CSS.

## Features
- Pure CSS implementation using the Checkbox Hack
- Smooth icon transitioning (scale and rotate)
- Dynamic hover gradient background effect
- `has()` selector used for page background demonstration
- Fully accessible with focus states

## Usage

Include `demo.html` and `style.css` in your project. The background gradient changes its opacity dynamically on hover.
