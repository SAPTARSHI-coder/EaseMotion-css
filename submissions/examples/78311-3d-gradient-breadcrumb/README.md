# 3D Breadcrumb with Gradient Styling

A responsive breadcrumb navigation component featuring layered 3D depth,
gradient borders, elevated navigation items, and interactive states.

## Features

- 3D layered breadcrumb styling
- Gradient border and surface
- Responsive layout
- Interactive hover effects
- Keyboard focus states
- Current-page indicator
- Mobile-friendly wrapping
- Pure HTML and CSS
- No JavaScript dependency
- Reduced-motion support

## Files

- `demo.html` — breadcrumb markup and demo content
- `style.css` — complete component styling and responsive behavior

## Usage

Open `demo.html` in a browser to preview the component.

The breadcrumb links can be replaced with application-specific routes
while keeping the same structure and styling.

## Responsive Behavior

The breadcrumb automatically wraps on smaller screens and switches to a
compact layout on mobile devices.
