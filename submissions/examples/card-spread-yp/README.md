# Card Spread & Stack Component

A modern interactive card component that smoothly transitions between a stacked layout and a horizontal spread view. Built with HTML, CSS, and lightweight JavaScript, it provides a clean and engaging way to showcase multiple cards with smooth animations and intuitive interactions.

## Features

* Interactive stack and spread layout
* Smooth transition animations
* Hover preview effect before spreading
* Drag, swipe, and wheel scrolling support
* Interactive checklist items
* Fully responsive design
* Modern UI with dot-grid background and soft shadows
* Lightweight and self-contained
* Easy to customize

## Use Cases

This component is suitable for:

* Feature showcases
* Product highlights
* Service cards
* Portfolio sections
* Team members
* Dashboard widgets
* Interactive landing pages

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over the card stack to preview the animation.
3. Click the **Spread Cards** button (or the stack) to expand the cards.
4. Drag, swipe, or use the mouse wheel to navigate through the spread cards.
5. Click checklist items to toggle their completed state.

No build tools or frameworks are required.
