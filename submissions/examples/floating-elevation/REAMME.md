# Floating Elevation Glass Effect

A modern glassmorphism UI component featuring a floating elevation effect,
soft depth, translucent surfaces, and smooth CSS-powered interactions.

## Features

- Floating elevation effect
- Glassmorphism styling
- Layered shadows for depth
- Translucent glass surface
- Backdrop blur
- Animated ambient lighting
- Smooth hover elevation
- Responsive design
- Dark-mode friendly
- Hardware-accelerated transforms
- Keyboard-accessible button
- Reduced-motion support
- Pure HTML and Vanilla CSS
- No JavaScript
- No external dependencies

## Preview

The component creates a floating glass card with:

- Soft background lighting
- Elevated shadow
- Translucent glass surface
- Depth-based hover animation
- Interactive statistics
- Glass-style action button
