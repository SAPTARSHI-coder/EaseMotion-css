# CSS Modal: Floating Elevation

A smooth, accessible and performant modal component featuring a
**Floating Elevation** visual style.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript required
- Layered elevation effect
- Floating entrance animation
- Subtle idle floating animation
- Multi-layer shadows
- Ambient glow beneath the modal
- Dark-mode-friendly design
- Responsive layout
- Hardware-accelerated transforms
- Accessible focus states
- Reduced-motion support
- No external dependencies
