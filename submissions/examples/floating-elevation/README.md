# Floating Elevation Card

A smooth, accessible, and performant CSS card component featuring a layered Floating Elevation interaction using pure HTML and vanilla CSS.

## ✨ Features

- Pure HTML and CSS
- Smooth elevation on hover
- Layered depth shadows
- Subtle 3D `translate3d()` movement
- Keyboard accessible focus states
- Dark mode support
- Responsive card grid
- Reduced-motion support
- High-contrast / forced-colors support
- No JavaScript
- No external dependencies
