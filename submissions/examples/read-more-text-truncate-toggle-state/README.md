# Read More Text Truncate Toggle State

A lightweight Read More / Read Less text component built with HTML, CSS, and JavaScript.

## Features

- Expand and collapse long text
- Smooth transition animation
- Responsive card layout
- Simple and easy to customize
- Accessible button-based interaction

## Files

```

read-more-text-truncate-toggle-state/
├── demo.html
├── style.css
└── README.md

```

## Usage

1. Open `demo.html` in your browser.
2. Click **Read More** to expand the content.
3. Click **Read Less** to collapse it again.

## Technologies

- HTML5
- CSS3
- JavaScript (Vanilla)

## Preview

- Default state displays truncated text.
- Clicking the button toggles between expanded and collapsed content.
