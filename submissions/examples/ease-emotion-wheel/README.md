# 😊 Emotion Wheel – Emojis Orbit and Select on Click

> A fun, interactive emotion selector where emojis orbit around a center and can be selected on click, creating an engaging mood-picking experience.

---

## 📖 Description

The **Emotion Wheel** is a fun, interactive emotion selector where emojis orbit around a center and can be selected on click. When opened, eight emotion emojis radiate outward from the center with a smooth, staggered animation. You can click any emoji to select it, drag the wheel to rotate it, and the selected emotion is displayed at the bottom. The center button shows the currently selected emotion.

The component uses CSS transforms and JavaScript to create the orbital effect. Each emotion has a unique angle and appears with a staggered delay. The wheel can be rotated by dragging, and the nearest emotion snaps into place when released. Keyboard shortcuts (1-8) allow quick selection.

Perfect for mood trackers, feedback forms, interactive polls, and any application where you want to make emotion selection fun and engaging. The Emotion Wheel transforms a simple selection into a playful, interactive experience.
