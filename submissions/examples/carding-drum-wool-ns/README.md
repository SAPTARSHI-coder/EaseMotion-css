# Carding Drum Wool

## What does this do?
Renders a self-contained CSS-only `ease-carding-drum-wool` demo: Textile carding drum teasing wool fibers apart.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-carding-drum-wool`. No build step or JavaScript is required for the effect.

```html
<section class="ease-carding-drum-wool">
  <div class="ease-carding-drum-wool__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
