# CSS Glass Effect: Pulsating Wave

A pure CSS glassmorphism component featuring continuously
expanding and fading wave rings.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript
- No external dependencies
- Glassmorphism surface
- Animated expanding wave rings
- Central pulsating glow
- Animated signal meter
- Smooth hover elevation
- Responsive layout
- Dark-mode friendly
- Hardware-accelerated transforms
- Reduced-motion support
