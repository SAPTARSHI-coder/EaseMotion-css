# Neumorphic Retro Hero

A responsive hero section created for EaseMotion issue #79697. The component combines soft neumorphic depth with restrained retro accents, clear hierarchy, and accessible interaction states.

## Overview

This hero is designed as a reusable landing-page introduction for portfolios, product pages, dashboards, and promotional websites. It provides a strong heading, supporting content, actions, and visual depth without JavaScript or external UI libraries.

## Features

- Responsive hero layout for desktop, tablet, and mobile screens
- Soft neumorphic surface treatment
- Retro-inspired visual accents
- Clear primary and secondary calls to action
- Visible keyboard focus states
- Touch-friendly spacing and controls
- Flexible content structure
- Pure HTML and vanilla CSS
- No runtime dependencies
- Reduced-motion friendly transitions

## Structure

- `README.md` documents the component and integration details.
- `demo.html` contains the complete demonstration markup.
- `style.css` contains the layout, visual treatment, states, and responsive rules.

## Usage

Open `demo.html` in a modern browser to preview the component. For integration, copy the hero markup into your page and include `style.css`. Replace the heading, supporting copy, action labels, and links with project-specific content.

## Responsive Behavior

The desktop layout uses available horizontal space to establish a strong visual hierarchy. At smaller widths, the content stacks naturally, controls remain easy to tap, and spacing is reduced without removing important information.

## Accessibility

The component uses semantic headings and native links for predictable browser and keyboard behavior. Interactive controls retain visible focus styling, and important content remains readable at smaller viewport sizes.

## Customization

Adjust spacing, typography, surface shadows, border treatment, accent values, and breakpoints in `style.css`. The markup can be reused with different copy and links without changing the underlying layout approach.

## Performance

The demo does not require JavaScript, external component libraries, or a build process. The visual treatment is handled by CSS, keeping the component straightforward to integrate.

## Browser Support

The example uses standard HTML and modern CSS features supported by current evergreen browsers. No framework or bundler is required to preview the demo.
