# Organic Morphing Blob Background Animation

## What does this do?
Adds a smooth, fluid, organic "blob" animation component. By animating complex `border-radius` values using keyframes, it creates a shape that looks like a floating liquid droplet or lava-lamp bubble.

## How is it used?
```html
<div class="ease-blob-container">
    <div class="ease-blob"></div>
    <div class="ease-blob-content">
        <!-- Content goes here -->
    </div>
</div>
```

## Why does it fit EaseMotion CSS?
It provides a high-quality, pure CSS micro-animation that feels highly organic and visually engaging. It requires absolutely no JavaScript and relies entirely on CSS `border-radius` keyframing, fitting perfectly within the animation-first philosophy.

## Tech Stack
- HTML
- CSS (No JavaScript)
