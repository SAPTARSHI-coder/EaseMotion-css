# Foucault Pendulum Swing Toast

A smooth and visually engaging notification toast inspired by the motion of a Foucault pendulum.

This component is implemented entirely with semantic HTML and vanilla CSS, without JavaScript or external dependencies.

## Features

- Pure HTML and CSS
- Foucault pendulum-inspired swinging animation
- Smooth CSS transitions
- Hardware-accelerated transforms
- Accessible notification semantics
- Native keyboard-friendly dismiss button
- Visible keyboard focus state
- Responsive design
- Dark mode support
- Light mode support
- `prefers-reduced-motion` support
- No JavaScript required
- No external dependencies
