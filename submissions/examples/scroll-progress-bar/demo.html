Scroll-Driven Reading Progress Bar

Experience a perfectly smooth, JavaScript-free reading indicator.

Why use pure CSS?

Historically, progress bars tied to scroll required JS `window.addEventListener('scroll', ...)` which can cause performance bottlenecks and janky rendering on low-end devices.

With modern CSS `animation-timeline: scroll()`, the browser handles the animation on the compositor thread, guaranteeing ultra-smooth 120fps performance without writing a single line of JavaScript.

Keep scrolling down to see the effect...

How it works

The implementation is elegant and minimal:

1. Create a fixed `.ease-progress-bar` positioned at the top.
2. Set `transform-origin: 0% 50%` so it scales from the left.
3. Animate `transform: scaleX()` from 0 to 1.
4. Bind the animation to the document root scroll using `animation-timeline: scroll(root)`.

Almost there...

Graceful Degradation

By wrapping the scroll-driven animation inside a `@supports (animation-timeline: scroll())` block, we ensure that older browsers simply ignore the rule, avoiding broken or half-implemented visual states.
