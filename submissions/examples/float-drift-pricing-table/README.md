# CSS Float-Drift Pricing Table

A responsive gaming-focused pricing table featuring a subtle floating drift
animation built entirely with HTML and CSS.

## Features

- Pure HTML and CSS
- No JavaScript or external libraries
- Smooth float-drift animation
- Three responsive pricing cards
- Featured/popular plan
- Hover and focus interactions
- CSS custom properties
- Responsive desktop, tablet, and mobile layouts
- `prefers-reduced-motion` accessibility support
- Semantic HTML structure
