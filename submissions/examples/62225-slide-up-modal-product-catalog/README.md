# CSS Slide-Up Modal for Product Catalog Layouts

A modern **Slide-Up Modal** built using pure HTML5 and CSS3 for product catalog layouts. The component provides a responsive product quick-view modal with smooth slide-up animations, glassmorphism styling, and accessibility support.

## Features

* Pure HTML5 & CSS3
* Slide-Up modal animation
* Product quick-view modal
* Glassmorphism modal design
* Backdrop overlay
* Product image, price, features and CTA buttons
* Smooth CSS transitions & keyframe animations
* Responsive desktop, tablet, and mobile layout
* CSS Custom Properties
* No JavaScript required
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Click **Quick View Product** to open the modal.
3. Close the modal using the close button or by clicking outside the modal.
4. Customize colors, spacing, animation speed, and typography through the CSS variables in `:root`.

## Accessibility

* Fully responsive
* Supports `prefers-reduced-motion`
* Semantic HTML structure
