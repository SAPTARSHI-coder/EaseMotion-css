# Glowing Neon Outline Input Field with Animated Floating Label (Cyberpunk Theme)

A futuristic **Cyberpunk-inspired input field** featuring glowing neon borders, animated floating labels, glassmorphism styling, and smooth focus interactions using pure HTML and CSS.

## ✨ Features

- Pure HTML5 & CSS3
- Neon glowing outline animation
- Animated floating labels
- Glassmorphism login panel
- Responsive layout
- CSS Custom Properties
- Cyberpunk color palette
- Smooth hover and focus transitions
- `prefers-reduced-motion` support
- No JavaScript required

## Usage

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

Use the input component:

```html
<div class="input-group">
    <input type="text" id="username" placeholder=" " required>
    <label for="username">Username</label>
    <span class="line"></span>
</div>
```
