# CSS Morph-Glow Feature Grid for Creative Portfolio Layouts

A modern **Creative Portfolio Feature Grid** built entirely with **HTML5 and CSS3**. This showcase demonstrates elegant **Morph-Glow** animations with glowing borders, glassmorphism styling, responsive layouts, and accessibility support without requiring JavaScript.

---

## ✨ Features

- 🎨 Creative Portfolio inspired feature grid
- ✨ Morph-Glow animation
- 🌈 Animated gradient glow
- 💎 Glassmorphism cards
- 🚀 Floating feature icons
- 📱 Fully responsive
- ⚡ Pure HTML5 & CSS3
- 🎯 CSS Custom Properties
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

## 🚀 Getting Started

1. Open `demo.html` in your browser.
2. Explore the Morph-Glow feature cards.
3. Hover over the cards to view enhanced glow effects.
4. Customize colors, spacing, and animation timing using CSS variables.
