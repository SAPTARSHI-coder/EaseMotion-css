ClayUI

Soft, Bouncy & 3D

Note: Built with 100% pure CSS (Zero JS). Utilizes the Checkbox Hack pattern to manage the popover state globally.

This variant embodies the Claymorphism aesthetic:

  • 3D Extrusion: Uses an outer drop shadow combined with dual inner shadows (one light, one dark) to create a soft, clay-like 3D effect.
  • Very Rounded Corners: Pill-shapes and circles dominate the design language.
  • Bouncy Physics: Employs a custom spring-like cubic-bezier(0.34, 1.56, 0.64, 1) curve to make the popover playfully bounce open.
