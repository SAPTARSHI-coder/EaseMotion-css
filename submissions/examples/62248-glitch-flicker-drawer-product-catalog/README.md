# CSS Glitch-Flicker Drawer for Product Catalog Layouts

A modern **Glitch-Flicker Drawer** built using pure HTML and CSS for product catalog interfaces. The drawer features a neon glitch title, animated navigation links, smooth slide-in motion, and accessibility support.

## Features

- Pure HTML5 & CSS3
- Glitch flicker heading animation
- Smooth slide-in drawer transition
- Neon hover effects
- Fully responsive layout
- CSS custom properties friendly
- Keyboard accessible checkbox toggle
- Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html`.
2. Click the **Products** button.
3. Explore the animated drawer navigation.

You can modify:
