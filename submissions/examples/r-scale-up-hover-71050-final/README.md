# CSS Scale Up on Hover

A responsive CSS-only interaction that smoothly scales an element on hover and keyboard focus while adding a soft shadow and glow.

## Features

- Pure CSS implementation
- Smooth scale-up effect
- Soft shadow and glow
- Keyboard accessible
- Visible focus state
- Responsive across screen sizes
- Reduced-motion support
- No JavaScript required

## Files

- `demo.html` — Interactive demonstration
- `style.css` — Component styles
- `README.md` — Feature documentation

## Usage

Apply the `scale-card` class to an interactive element:

```html
<a class="scale-card" href="#">
  <span class="content">
    <span class="card-title">Scale Up</span>
    <span class="card-text">Hover or focus this card</span>
  </span>
</a>
