# Parallax Neumorphism Progress Bar

A responsive progress bar component combining neumorphic UI styling with subtle parallax-inspired animation.

## Features

- Neumorphic design
- Responsive progress bar
- Animated progress entrance
- Parallax-style highlight movement
- Glowing progress indicator
- Animated progress knob
- Completion percentage
- Project statistics
- Responsive mobile layout
- Reduced-motion support
- No external dependencies

## Files

- `demo.html` - Demo markup
- `style.css` - Component styling and animations
