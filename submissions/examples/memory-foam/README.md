# 🫧 Memory Foam

Memory Foam is an interactive liquid surface that temporarily remembers user interactions as glowing bubbles.

Every click creates a bubble that floats upward, grows, wobbles, and eventually disappears.

When bubbles move close together, they are connected by subtle glowing lines.

## ✨ Features

- Interactive bubble creation
- Click and touch support
- Multiple simultaneous bubbles
- Smooth bubble growth
- Floating animation
- Horizontal wobble
- Bubble glow
- Bubble connection lines
- Automatic bubble expiration
- Real-time active bubble counter
- Reset functionality
- Keyboard shortcuts
- Responsive canvas
- No external dependencies

## 🎮 Interaction

| Input | Action |
| --- | --- |
| Click | Create bubble |
| Touch | Create bubble |
| Space | Create center bubble |
| R | Clear bubbles |
| Create Bubble | Create bubble |
| Clear | Remove all bubbles |
