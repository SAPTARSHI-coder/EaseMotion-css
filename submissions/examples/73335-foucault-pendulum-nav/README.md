# Foucault Pendulum Navigation

A smooth, responsive navigation component inspired by the swinging motion of a **Foucault Pendulum**, implemented entirely with HTML and Vanilla CSS.

## ✨ Features

- Pendulum-inspired hover animation
- Animated active navigation indicator
- Smooth CSS transitions
- Responsive mobile navigation
- Pure HTML and Vanilla CSS
- Dark-mode compatible
- Keyboard-friendly interaction
- Visible focus states
- Reduced-motion support
- Hardware-friendly transform animations
- No JavaScript
- No external dependencies
