# CSS Blur-Entrance Hero Section for Product Catalog Layouts

A modern and responsive hero section built using **pure HTML and CSS** for the EaseMotion CSS project. The design features a smooth blur-entrance animation, glassmorphism effects, responsive layout, and accessibility support without requiring JavaScript.

---

## ✨ Features

- Pure HTML5 & CSS3 implementation
- Smooth blur-entrance animation
- Modern glassmorphism UI
- Product showcase card
- Responsive desktop, tablet, and mobile layouts
- CSS custom properties for easy customization
- Hover interactions with smooth transitions
- `prefers-reduced-motion` accessibility support
- No external JavaScript required

## 🎨 CSS Custom Properties

```css
    --secondary:#8a7dff;
    --accent:#00d9ff;

    --bg:#0f172a;
    --card:rgba(255,255,255,.08);

    --text:#ffffff;
    --muted:#cbd5e1;

    --radius:22px;
}
```
