# 💎 Geode Ring – Concentric Crystal Rings Expand

> An interactive geode ring component where concentric crystal rings expand outward with 5 crystal types (Amethyst, Citrine, Emerald, Rose, Sapphire), expansion control (0-100%), and crystal cluster effects.

---

## 📖 Description

The **Geode Ring** component creates an interactive geode ring experience where concentric crystal rings expand outward with crystal cluster effects. Built with vanilla HTML, CSS, and JavaScript, it features 5 crystal types (Amethyst, Citrine, Emerald, Rose, Sapphire), expansion control (0-100%), and crystal cluster effects for a mesmerizing experience.

### 🎯 Core Features

- **Concentric rings** – crystal rings expand outward
- **5 crystal types** – Amethyst, Citrine, Emerald, Rose, Sapphire
- **Expansion control** – adjust expansion from 0-100%
- **Crystal clusters** – crystals on each ring
- **Ring counter** – tracks number of rings
- **Interactive controls** – slider, crystal buttons, keyboard shortcuts
- **Responsive design** – adapts to different screen sizes

### ⌨️ Interaction Options

| Method | Action |
|--------|--------|
| **Slider** | Adjust Expansion (0-100%) |
| **Buttons** | Expand (+15%), Reset |
| **Keyboard** | `E` – Expand · `R` – Reset |

### ✨ Ring Experience

When expanding:
1. **Rings grow** – concentric rings expand outward
2. **Expansion applies** – controls ring size
3. **Crystal applies** – changes ring colors
4. **Clusters appear** – crystals form on rings
5. **Status updates** – shows current state

### 🛠️ Technologies Used

- **HTML5** – semantic structure with Canvas
- **CSS3** – gradients, backdrop-filter, transforms
- **JavaScript (ES6)** – Canvas API, requestAnimationFrame, ring system

### 🎨 Design Philosophy

This component embodies **EaseMotion CSS's animation-first philosophy** through:

- **Organic expansion** – rings grow outward
- **Crystal effects** – glowing crystal clusters
- **Visual feedback** – status updates, counter, controls
- **Magical atmosphere** – crystal colors and glow
- **Human-readable classes** – `.geodering-controls`, `.crystal-btn`, `.geodering-text`

### 🔧 Customization Options

| Property | Location | Default |
|----------|----------|---------|
| Crystal types | `crystalData` object | 5 types |
| Expansion range | `expandSlider` | 0-100% |
| Ring count | `generateRings()` | 5-11 |
| Ring max size | `maxRadius` | 60-150px |
