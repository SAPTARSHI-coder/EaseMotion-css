# CSS Plasma Ball Animation

A mesmerizing plasma globe animation utilizing `mix-blend-mode`, high-contrast filters, and complex radial gradients to simulate electrical discharge.

## Features
- CSS `mix-blend-mode: screen` and filters for glow
- Keyframe animations for stretching and rotating plasma tendrils
- No SVG or Canvas, pure CSS
