# CSS Morph-Glow Drawer for Fintech Dashboard Layouts

A modern **Morph-Glow Drawer** built using pure HTML and CSS for fintech dashboards, banking portals, admin panels, and analytics platforms.

## Features

* Pure HTML5 & CSS3
* Morph-glow hover animation
* CSS-only navigation drawer
* Responsive sidebar layout
* Fintech-inspired glassmorphism design
* CSS custom properties for easy customization
* No JavaScript required
* Supports `prefers-reduced-motion`

## Folder Structure

```text
css-morph-glow-drawer-fintech-dashboard-59278/
├── demo.html

```

## Usage

1. Open `demo.html` in any modern browser.
2. Click the menu button to toggle the drawer.
3. Customize colors through the CSS variables in `:root`.
4. Update navigation items to fit your application.
