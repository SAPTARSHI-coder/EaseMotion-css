# Glitch Flicker Modal (Fintech Dashboard)

## What does this do?

A modern fintech-style modal with a glitch flicker animation, glassmorphism effect, scan-line animation, and responsive layout for security alerts or transaction confirmations.

---

## Features

- Glitch flicker entrance animation
- Glassmorphism design
- Animated scan line
- Responsive layout
- Dark theme
- Close on:
  - Close button
  - Outside click
  - Escape key
- Supports `prefers-reduced-motion`

---

## Usage

```html
<button class="open-btn">
Open Transaction Alert
</button>

<div class="modal-overlay show">
    <div class="glitch-modal">
        ...
    </div>
</div>
```

---

## Why is it useful?

Fintech dashboards frequently display transaction confirmations, fraud alerts, verification dialogs, and payment notifications. This component provides an attractive and reusable modal with modern visual effects while remaining lightweight and responsive.
