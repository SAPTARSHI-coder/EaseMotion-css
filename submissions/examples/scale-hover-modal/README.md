# CSS Scale Hover Modal

A responsive modal with a smooth scale-hover interaction built using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Smooth scale entrance animation
- Hover scaling effect
- Responsive layout
- No JavaScript required
- Supports `prefers-reduced-motion`

## Folder Structure

```
scale-hover-modal/
├── demo.html
├── style.css
└── README.md
```

## Usage

Open `demo.html` in any modern browser.

## Customization

Modify the following in `style.css`:

- Modal width
- Scale values
- Animation duration
- Colors
- Border radius
- Shadows
- Button styles

## Accessibility

- Responsive across desktop, tablet and mobile
- Semantic HTML
- Keyboard-friendly checkbox toggle
- Reduced motion support
