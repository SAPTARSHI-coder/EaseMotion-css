# CSS Northern Lights Curtain

A flowing, pure CSS aurora borealis animation with multiple moving gradients.

## Usage

```html
<div class="curtain-container" aria-label="Northern lights flowing in the sky" role="img">
  <div class="northern-lights layer-1"></div>
  <div class="northern-lights layer-2"></div>
  <div class="northern-lights layer-3"></div>
</div>
```

## Why is it useful?

This component provides a stunning, high-performance visual background effect entirely in CSS, bypassing the need for WebGL or JavaScript canvas libraries, while maintaining responsiveness and accessibility.
