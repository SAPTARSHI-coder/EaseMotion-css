# Floating Retro Dropdown

A fun, highly responsive dropdown menu styled after classic 8-bit games and retro operating systems, complete with a constant floating animation.

## Features
- Pure CSS implementation using `hover` and `focus-within`
- Authentic retro aesthetics (pixel fonts, hard shadows, thick borders)
- Constant keyframe floating animation for the dropdown menu
- Interactive button press animations
- 8-bit style hover indicators (►)
- Accessible keyboard navigation (using `focus-within`)

## Usage
Include `demo.html` and `style.css` in your project. Ensure the Google Fonts (`Press Start 2P` and `Space Mono`) are loaded properly for the authentic retro look.
