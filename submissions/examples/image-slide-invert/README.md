# Image Slide Invert

An image slides in while an inverted ghost trails behind it.

## Features
- Slide-in reveal
- Inverted ghost trail
- Layered motion
- Pure CSS

## Usage
```html
<div class="isi-ghost"></div><div class="isi-img"></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
