# CSS Morph-Glow Badge for SaaS Showcase Layouts

A modern **Morph-Glow Badge** component built using pure HTML and CSS. The badges feature smooth morphing corners, glowing hover effects, and responsive SaaS-inspired card layouts.

## ✨ Features

- Pure HTML5 & CSS3
- Morph + Glow badge animation
- Responsive SaaS card layout
- Smooth hover transitions
- CSS Custom Properties
- `prefers-reduced-motion` support
- No JavaScript required
