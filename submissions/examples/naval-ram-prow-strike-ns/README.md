# Naval Ram Prow Strike

## What does this do?
Renders a self-contained CSS-only `ease-naval-ram-prow-strike` demo: Trireme naval ram prow strike.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-naval-ram-prow-strike`. No build step or JavaScript is required for the effect.

```html
<section class="ease-naval-ram-prow-strike">
  <div class="ease-naval-ram-prow-strike__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
