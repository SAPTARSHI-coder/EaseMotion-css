# Glass Navbar

**What does this do?**

Creates a modern navigation bar with centered navigation links, a glassmorphism effect, and sticky positioning while scrolling.

**How is it used?**

```html
<nav class="navbar">
  <a href="#" class="logo">EaseMotion</a>

  <ul class="nav-links">
    <li><a href="#" class="active">Home</a></li>
    <li><a href="#">Components</a></li>
    <li><a href="#">Examples</a></li>
    <li><a href="#">Docs</a></li>
  </ul>

  <a href="#" class="nav-btn">Get Started</a>
</nav>
```
