# ease-blur-popover-bh

Pure CSS blur-entrance popover for fintech dashboards.

## Features
- Blur entrance hover effect
- Popover variants
- Responsive design
- Accessibility support

## Usage
```html
<div class="ease-popover ease-popover-blur">Content</div>
```

## CSS Classes
- `.ease-popover` - Base popover
- `.ease-popover-blur` - Blur entrance effect
