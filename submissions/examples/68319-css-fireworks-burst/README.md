# CSS Fireworks Burst

## Overview

A CSS-only fireworks celebration composed from timed particle bursts and launch streaks.

## Features

- Multiple staggered bursts
- Radial particle motion
- Glow and depth layers
- Responsive presentation
- Reduced-motion support
- No JavaScript dependency

## Files

- `demo.html` — fireworks scene and supporting content
- `style.css` — particle, launch, glow, timing, and responsive styles

## Usage

Open `demo.html` in a modern browser.
