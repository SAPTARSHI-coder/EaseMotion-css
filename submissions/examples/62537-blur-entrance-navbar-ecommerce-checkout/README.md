# CSS Blur-Entrance Navbar for E-Commerce Checkout Layouts

A modern **Blur-Entrance Navbar** created with pure HTML5 and CSS3 for e-commerce checkout pages. The component features a glassmorphism design, animated entrance effects, checkout progress steps, and a responsive layout.

## Features

* Pure HTML5 & CSS3
* Blur-Entrance animation
* Glassmorphism navbar
* Checkout progress indicator
* Search box
* Secure checkout badge
* Shopping cart badge
* Fully responsive
* CSS Custom Properties
* No JavaScript required
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in a modern browser.
2. Customize checkout steps, branding, and colors.
3. Modify CSS variables inside `:root`.
4. Integrate the component into any checkout or payment interface.
