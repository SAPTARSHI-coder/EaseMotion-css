# CSS Rotate Fade Modal

## Overview

A responsive gaming-inspired modal featuring a smooth rotate-and-fade entrance animation built using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Responsive Modal Layout
- Rotate Fade Animation
- CSS Custom Properties
- Accessible (`prefers-reduced-motion`)
- No JavaScript Required

## Folder Structure

```text
rotate-fade-modal/
├── demo.html
├── style.css
└── README.md
```

## Usage

1. Open `demo.html` in your browser.
2. Click **Open Modal**.
3. Customize the CSS variables to match your project.

## CSS Variables

- `--primary`
- `--background`
- `--modal`
- `--text`
- `--duration`

## Browser Support

- Chrome
- Firefox
- Edge
- Safari
