# CSS Bounce-Pulse Tooltip for SaaS Showcase Layouts

A modern **Bounce-Pulse Tooltip** built using pure HTML and CSS. The tooltip combines a playful bounce animation with a subtle pulse effect to create an engaging interaction for SaaS dashboards, admin panels, and product showcases.

## ✨ Features

- Pure HTML5 & CSS3
- Bounce-pulse tooltip animation
- Glassmorphism tooltip styling
- Responsive layout
- Smooth hover transitions
- CSS Custom Properties
- `prefers-reduced-motion` support
- No JavaScript required
