# CSS Polaroid Hover Pop

A Polaroid-style photo card that moves forward and rotates
slightly when hovered or focused.

## Features

- Pure HTML and CSS
- Polaroid-inspired layout
- CSS-generated scenic photo
- Hover pop animation
- Keyboard focus interaction
- Responsive sizing
- Reduced-motion support
- No JavaScript
- No external assets

## Accessibility

The Polaroid is implemented as an accessible link with a
descriptive label and visible keyboard focus state.

Reduced-motion preferences are respected.

## Customization

Change the `.photo` gradients, caption text, rotation values,
and card colors to create different Polaroid styles.
