# CSS Wave Ocean

A lightweight animated ocean scene created entirely with HTML and CSS.

## Features

- Pure CSS animation
- No JavaScript
- Layered animated waves
- Gently bobbing boat
- Moving clouds
- Responsive design
- Keyboard focus support
- Reduced-motion support

## Files

- `demo.html` - Demo markup
- `style.css` - Ocean scene animation and responsive styling

## Usage

Open `demo.html` in any modern browser.

No build tools or dependencies are required.

## Accessibility

The scene uses semantic HTML and provides an accessible description
for the animated boat.

The boat can receive keyboard focus, and
`prefers-reduced-motion` is respected for users who prefer reduced animation.

## Animation

The animation is created using CSS:

- `@keyframes` for wave movement
- `@keyframes` for boat bobbing
- `@keyframes` for cloud movement
- CSS transforms for smooth motion
- CSS media queries for responsive behavior
