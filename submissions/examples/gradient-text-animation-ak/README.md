# Gradient Text Animation

A pure CSS gradient text animation that smoothly moves a colorful gradient across the text.

## Features

- Pure HTML and CSS
- No JavaScript
- No external libraries
- Smooth infinite animation
- Responsive design

## Files

- `demo.html` - HTML structure
- `style.css` - Styling and animation

## How to Run

Open `demo.html` directly in a modern web browser.

## Technologies

- HTML5
- CSS3

## CSS Concepts Used

- `linear-gradient()`
- `background-clip`
- `background-size`
- `@keyframes`
- CSS `animation`
- Media queries
