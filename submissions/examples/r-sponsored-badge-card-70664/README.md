v# CSS Sponsored Badge Card

A responsive promotional card with a sponsored badge, promoted label, supporting content, metadata, and a call-to-action.

The component uses pure HTML and CSS and does not require JavaScript or external libraries.

## Features

- Pure HTML and CSS
- No JavaScript
- Responsive layout
- Sponsored badge
- Promoted label
- Animated decorative visual
- Gradient card visual
- Hover interaction
- Accessible CTA
- Keyboard focus styling
- Reduced-motion support
- Mobile-friendly design
- No external dependencies
