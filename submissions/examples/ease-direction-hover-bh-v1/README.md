# ease-direction-hover-bh

Pure CSS direction-aware hover effect.

## What does this do?
Creates hover effects that respond to the direction from which the user enters the element (top, right, bottom, left).

## How is it used?
```html
<div class="ease-direction-hover-bh" data-direction="left">
  Hover me from different directions
</div>
```

## Why is it useful?
Adds subtle, intelligent hover interactions that feel natural and responsive to user behavior.
