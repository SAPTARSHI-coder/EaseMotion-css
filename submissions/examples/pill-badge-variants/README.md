# CSS Pill Badge Variants

A collection of simple and reusable pill-shaped badges built entirely with CSS.

Part of the EaseMotion CSS component library.

## Features

- Pure CSS
- No JavaScript required
- Default variant
- Success variant
- Warning variant
- Danger variant
- Responsive design
- Light and dark mode support
- CSS custom properties for customization
- Reduced-motion support
- Small hover animation

## Available Variants

### Default

```html
<span class="pill-badge pill-default">
  Default
</span>
