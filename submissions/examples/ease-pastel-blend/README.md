# Pastel Blend · Soft Pastel Colors Blend 🌈

An interactive pastel color blending animation featuring soft, dreamy transitions and gentle particle effects. Watch as pastel colors flow and blend in a soothing, meditative dance.

## Features

- 🌈 **Soft Color Blending** – Pastel colors blend smoothly and organically
- 🎨 **3 Custom Colors** – Choose any three pastel colors
- ✨ **Gentle Particles** – 80 soft particles with pulsing glow
- 🌊 **Flowing Movement** – Particles drift with organic motion
- 🎮 **Speed Control** – Adjust animation speed (1-10)
- ⏸️ **Pause/Resume** – Toggle animation with Space or button
- 🔄 **Reset** – Reset particle positions
- 🎨 **Dreamy Aesthetic** – Soft, calming visual experience

## How to Use

1. Watch pastel colors blend in a gentle, flowing dance
2. Use the **Color Pickers** to change the three pastel colors
3. Colors blend and transition smoothly across the canvas
4. Press **Space** or click **PAUSE** to pause/resume animation
5. Adjust **Speed** slider to control animation pace
6. Press **R** or click **RESET** to reset particle positions

## Technical Details

- **Particle System:** 80 particles with color interpolation
- **Color Blending:** RGB interpolation between 3 colors
- **Movement:** Organic drift with sinusoidal wobble
- **Animation:** Pulsing size and opacity
- **Performance:** 60fps with requestAnimationFrame

## Customization

You can easily customize:
- **Particle Count:** Modify `NUM_PARTICLES` (80)
- **Particle Size:** Adjust `size` range (20-80px)
- **Movement Speed:** Modify `vx` and `vy` values
- **Opacity Range:** Adjust `opacity` values
- **Colors:** Change default color picker values
