ease-combobox-aria-live

Autocomplete combobox with live announcements.

Fixes the bug where screen readers stayed silent when the options list expanded. This combobox announces the result count via an aria-live="polite" status region, announces the selected option, and exposes full WAI-ARIA combobox semantics (role="combobox", aria-expanded, aria-controls, aria-activedescendant, role="listbox"/option). Type to filter below.
