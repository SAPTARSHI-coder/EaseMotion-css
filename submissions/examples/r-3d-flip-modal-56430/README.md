# CSS Glitch-Flicker Modal

A futuristic **Glitch-Flicker Modal** created using pure HTML5 and CSS3 for Gaming Hub layouts. It combines a cyberpunk glitch heading with subtle flickering effects while remaining responsive and accessible.

---

## ✨ Features

- Pure HTML5 & CSS3
- Glitch heading animation
- Flickering cyberpunk effect
- Responsive design
- CSS Custom Properties
- Lightweight
- Keyboard-accessible modal
- `prefers-reduced-motion` support
- No JavaScript required
