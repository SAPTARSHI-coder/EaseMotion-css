# Jig Sieve Pulse

## What does this do?
Renders a self-contained CSS-only `ease-jig-sieve-pulse` demo: Jig sieve pulsing a hutchwater bed.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-jig-sieve-pulse`. No build step or JavaScript is required for the effect.

```html
<section class="ease-jig-sieve-pulse">
  <div class="ease-jig-sieve-pulse__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
