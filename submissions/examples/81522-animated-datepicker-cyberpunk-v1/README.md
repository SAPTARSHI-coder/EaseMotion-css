# Animated Datepicker with Cyberpunk Styling

A futuristic animated datepicker component built with semantic HTML
and pure CSS for the EaseMotion CSS collection.

## Features

- Pure HTML and CSS
- Zero external JavaScript dependencies
- Native browser date picker
- Cyberpunk-inspired visual design
- Neon cyan and magenta accents
- Animated panel entrance
- Animated scan line
- Neon focus states
- Terminal-style status indicator
- Animated cursor
- Interactive button effects
- Fully responsive
- Keyboard accessible
- Native browser validation
- `prefers-reduced-motion` support
