# Floating Datepicker with Retro Pixel Styling (#81526)

A retro game-boy inspired floating datepicker component engineered with hard box shadows, pixel borders, monospace typography, pure CSS focus-within hover expansion, and `prefers-reduced-motion` compliance.

## Features
- **Retro Pixel Aesthetic:** Inspired by 8-bit handheld UI aesthetics using solid 4px outlines and offset box shadows.
- **Pure CSS Floating Mechanics:** Activates smoothly on hover or `:focus-within` keyboard navigation without requiring external JS frameworks.
- **Accessibility & Motion Guards:** Fully responsive across screen viewports and respects `prefers-reduced-motion`.

## File Hierarchy
- `style.css` - Custom retro palette tokens, pixelated box-shadow rules, grid alignment, and media queries.
- `demo.html` - Clean ARIA-labelled html markup demonstrating interactive focus states.
- `README.md` - Technical overview and usage guidelines.
