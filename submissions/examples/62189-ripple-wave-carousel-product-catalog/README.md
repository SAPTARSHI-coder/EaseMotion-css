# CSS Ripple-Wave Carousel for Product Catalog Layouts

A modern **Ripple-Wave Carousel** built using pure HTML5 and CSS3 for product catalog layouts. The component showcases products in a responsive CSS-only carousel with elegant ripple-wave animations, glassmorphism styling, and accessibility support.

## Features

* Pure HTML5 & CSS3
* CSS-only carousel using radio buttons
* Ripple-Wave hover animation
* Product Catalog showcase
* Responsive product cards
* Smooth CSS transitions & keyframe animations
* Glassmorphism carousel container
* Animated navigation indicators
* CSS Custom Properties for easy customization
* Fully responsive across desktop, tablet, and mobile devices
* No JavaScript required
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Select any navigation dot to switch between product slides.
3. Hover over product cards to experience the Ripple-Wave animation.
4. Customize colors, spacing, border radius, shadows, and animation timing using the CSS variables defined in `:root`.

## CSS Custom Properties

```css
:root{
  --bg:#eef4ff;
  --surface:rgba(255,255,255,.9);
  --primary:#2563eb;
  --secondary:#06b6d4;
  --text:#111827;
  --muted:#64748b;
  --shadow:0 18px 42px rgba(37,99,235,.18);
  --radius:24px;
}
```
