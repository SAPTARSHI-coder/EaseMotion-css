# CSS Solar Flare Radial Navigation

## Overview

Issue #73337 implements a solar-flare-inspired navigation using pure HTML and vanilla CSS.

## Features

- Radial glow decoration
- Warm gradient typography
- Hover and focus states
- Responsive navigation layout
- Reduced-motion support
- No external JavaScript

## Accessibility

Navigation items are normal links with visible keyboard focus. The radial animation is decorative and stops for reduced-motion users.

## Usage

Open `demo.html` and reuse the `.nav` structure. Theme values are centralized in `:root` for easy customization.

## Files

- `demo.html` — navigation demonstration
- `style.css` — solar flare visuals and interaction states
- `README.md` — implementation notes
