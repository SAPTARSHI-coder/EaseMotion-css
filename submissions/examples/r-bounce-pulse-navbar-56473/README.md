# CSS Bounce-Pulse Navbar

A modern **Bounce-Pulse Navbar** built using pure HTML5 and CSS3 for Gaming Hub layouts. Navigation links perform a smooth bounce-pulse animation on hover while remaining lightweight, responsive, and accessible.

---

## ✨ Features

- Pure HTML5 & CSS3
- Bounce-pulse hover animation
- Gaming-inspired navigation bar
- Fully responsive
- CSS Custom Properties
- Lightweight and performant
- Accessible semantic HTML
- `prefers-reduced-motion` support
- No JavaScript required

## 🚀 Usage

1. Copy the component into your project.
2. Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

3. Open `demo.html` in any modern browser.
