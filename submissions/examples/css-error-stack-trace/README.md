# CSS Error Stack Trace

A styled error stack trace component with collapsible stack frames.

## Features

- Pure HTML and CSS
- Collapsible stack frames using native `<details>` and `<summary>`
- Responsive layout
- No JavaScript required
- Displays error type, message, status code, source files, and code snippets
- Keyboard accessible native disclosure controls

## Usage

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
