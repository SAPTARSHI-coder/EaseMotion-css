# CSS Circular Progress Loader

## Description

A pure CSS circular progress loader inspired by SVG-style progress rings. The loader continuously rotates using CSS animations and can be used as a loading indicator in dashboards, forms, and applications.

## Features

- Pure CSS implementation
- Circular progress ring animation
- Smooth infinite rotation
- Responsive design
- No JavaScript required
