# Glowing Rating — Gradient Glow

A responsive rating component with animated gradient glow
styling, created for EaseMotion CSS issue #81447.

## Features

- Gradient glow visual treatment
- Animated decorative glow orbs
- Glowing star rating
- 4.8/5 rating display
- Satisfaction progress meter
- Hover elevation effect
- Interactive star hover states
- Responsive desktop, tablet and mobile layouts
- CSS custom properties
- `prefers-reduced-motion` support
- Zero JavaScript dependencies
