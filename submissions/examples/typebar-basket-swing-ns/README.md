# Typebar Basket Swing

## What does this do?
Renders a self-contained CSS-only `ease-typebar-basket-swing` demo: Typebar swinging up to the platen.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-typebar-basket-swing`. No build step or JavaScript is required for the effect.

```html
<section class="ease-typebar-basket-swing">
  <div class="ease-typebar-basket-swing__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
