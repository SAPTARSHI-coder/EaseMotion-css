# Animated Checkbox Ripple

A premium, interactive custom checkbox featuring a subtle "pop" animation, an SVG-like drawn checkmark, and a radial ripple effect that bursts outward upon checking.

### Usage
```html
<label class="custom-checkbox">
  <input type="checkbox" name="agree">
  <span class="checkmark"></span>
  <span class="label-text">I agree to the terms</span>
</label>
```

### Why is it useful?
Default browser checkboxes lack modern interactivity. This pure CSS component completely replaces the default input while maintaining accessibility (via `focus-visible`), and delivers immediate, satisfying visual feedback using multiple simultaneous keyframe animations (draw, pop, ripple).
