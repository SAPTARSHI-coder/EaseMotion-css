# Aurora Glow Card

A smooth, accessible, and performant pure CSS card featuring a mesmerizing Aurora Glow styling on hover.

### Usage

```html
<div class="aurora-glow-card-4694">
  <div class="aurora-glow-card-4694-content">
    <h2 class="aurora-glow-card-4694-title">Aurora Glow</h2>
    <p class="aurora-glow-card-4694-desc">Hover over this card to reveal a mesmerizing aurora-inspired background glow, creating a smooth and elegant visual experience.</p>
  </div>
</div>
```

### Why is it useful?

This card effect brings a dynamic, visually striking element to modern web interfaces while remaining lightweight and fully CSS-driven, aligning perfectly with EaseMotion's philosophy of accessible and performant aesthetics.
