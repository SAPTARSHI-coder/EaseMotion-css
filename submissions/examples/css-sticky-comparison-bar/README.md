# CSS Sticky Comparison Bar

A responsive CSS-only sticky comparison bar for displaying two selected products side by side.

The component stays fixed near the bottom of the viewport, making it easy for users to review and compare selected products while browsing a product catalog.

## Features

- Pure CSS implementation
- No JavaScript required
- Sticky/floating comparison bar
- Two-product comparison layout
- Responsive design for smaller screens
- Light and dark mode support
- CSS custom properties for easy theming
- Smooth hover and transition effects
- Accessible semantic HTML structure
- Works without a server
