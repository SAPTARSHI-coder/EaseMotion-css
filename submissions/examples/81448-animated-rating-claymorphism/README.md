# Animated Rating — Claymorphism

A playful animated rating component using a soft
claymorphism/neumorphic visual language.

Created for EaseMotion CSS issue #81448.

## Features

- Claymorphism-inspired soft UI
- Five interactive rating controls
- Pure CSS hover rating preview
- Animated decorative clay shapes
- Animated rating meter
- Soft inner and outer shadows
- Tactile button interactions
- Responsive desktop, tablet and mobile layouts
- Keyboard focus-visible support
- `prefers-reduced-motion` support
- Zero JavaScript dependencies
