# CSS Mesh Gradient: Particle Burst Variation

### What does this do?
This submission adds a smooth, hardware-accelerated mesh gradient background combined with an animated, expanding particle burst effect.

### How is it used?
```html
<div class="mesh-container">
    <div class="particle-burst"></div>
    <div class="content">
        <!-- Your content here -->
    </div>
</div>
```

### Why is it useful?
It provides a visually striking, premium background effect using pure vanilla CSS and HTML, ensuring high performance via hardware acceleration and full dark mode compatibility, which aligns perfectly with EaseMotion's goal of offering lightweight, beautiful UI components.
