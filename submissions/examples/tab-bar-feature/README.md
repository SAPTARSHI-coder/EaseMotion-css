
---

## 🚀 Usage
1. Clone or copy the files into your project.
2. Open `demo.html` in your browser.
3. Click or focus on tabs to see the Material Design styling.

---

## 🛠️ Customization
- **Colors** → Adjust `color` and `background` for different themes.
- **Indicator width** → Modify `.tab.active::after` width for different underline styles.
- **Responsive layout** → Adjust media queries for custom breakpoints.

---

## 📖 Accessibility
- Uses `role="tablist"` and `role="tab"` for screen readers.
- `aria-selected` indicates the active tab.
- Keyboard focus supported.
