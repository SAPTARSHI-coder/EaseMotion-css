# CSS Glitch-Flicker Pricing Table for Creative Portfolio Layouts

A modern **Creative Portfolio Pricing Table** built using **pure HTML5 and CSS3**. This showcase features futuristic **Glitch-Flicker** animations, RGB neon glow effects, glassmorphism pricing cards, responsive layouts, and accessibility support without JavaScript.

---

## ✨ Features

- ⚡ Glitch-Flicker animation
- 💳 Modern pricing table
- 💎 Glassmorphism cards
- 🌈 RGB neon glow
- ⭐ Featured pricing plan
- 🚀 Smooth hover interactions
- 📱 Fully responsive
- 🎨 CSS Custom Properties
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

## 🚀 Getting Started

1. Open `demo.html` in your browser.
2. Hover over pricing cards to see the Glitch-Flicker animation.
3. Customize colors, shadows, and animation timing using CSS variables.

---

## 🎨 CSS Variables

```css
:root{
    --bg:#050816;
    --surface:rgba(15,23,42,.88);
    --primary:#00e5ff;
    --secondary:#ff2ea6;
    --text:#ffffff;
    --muted:#cbd5e1;
    --border:rgba(255,255,255,.08);
    --radius:24px;
}
```
