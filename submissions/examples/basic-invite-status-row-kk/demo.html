Basic Invite Status Row

Invitation rows for team and workspace settings.

A CSS-only row component for showing invite recipient, assigned role, helper copy, and invitation state in member management panels.

AC
maya@example.com

Accepted the invitation and joined the workspace.

Admin Accepted
PN
dev@example.com

Invitation email sent and waiting for response.

Editor Pending
EX
ops@example.com

Invite link expired before the user joined.

Viewer Expired

HTML Usage

<article class="basic-invite-status-row">
  <span class="invite-icon is-accepted" aria-hidden="true">AC</span>
  <div class="invite-copy">
    <strong>maya@example.com</strong>
    <p>Accepted the invitation and joined the workspace.</p>
  </div>
  <span class="invite-role">Admin</span>
  <span class="invite-state is-accepted">Accepted</span>
</article>
