
---

## 🚀 Usage
1. Clone or copy the files into your project.
2. Open `demo.html` in your browser.
3. The carousel will auto-scroll with glowing retro styling.

---

## 🛠️ Customization
- **Animation speed** → Adjust `animation: scroll 12s` for faster/slower carousel.
- **Colors** → Change neon glow colors in `box-shadow` and `text-shadow`.
- **Item count** → Add/remove `.carousel-item` elements.

---

## 📖 Accessibility
- Uses `role="region"` and `aria-label="Retro glowing carousel"` for screen readers.
- Auto-scrolling ensures continuous motion without user input.
