# Accordion Expandable FAQ Grid with Smooth Height Transitions (Glassmorphic Style)

A modern Glassmorphic FAQ Grid built using HTML, CSS, and JavaScript featuring smooth expand/collapse transitions, elegant hover effects, responsive design, and reusable components.

## Features

- Glassmorphism UI
- Smooth accordion animation
- Responsive FAQ grid
- Hover interactions
- Modern gradient background
- Pure HTML, CSS & JavaScript
- Easy customization

## Folder Structure

```
ease-layout-accordion-expandable-faq-grid-with-smooth-height-transitions-147/
├── demo.html
├── style.css
├── script.js
└── README.md
```

## Usage

Open `demo.html` in any browser.

Modify FAQ items, colors, spacing, and animations in the CSS.
