# CSS Pixelate Reveal Text

A CSS-only animated text reveal component for EaseMotion CSS.

## Overview

`ease-pixelate-reveal-text` creates a pixelated text effect where characters start blurry and fragmented before becoming sharp and readable.

## Features

- Pure CSS animation
- No JavaScript dependency
- Pixel-to-focus reveal effect
- Responsive design
- Accessible reduced motion support
- Smooth transition animation
