# Minimalist Outline Card

A clean, accessible, responsive and performant **Minimalist
Outline Card** built using pure HTML and vanilla CSS.

## ✨ Features

- Pure HTML and CSS
- No JavaScript
- Minimalist outline design
- Subtle hover elevation
- Animated border highlight
- Lightweight accent interaction
- Responsive layout
- Dark mode support
- Light mode support
- Keyboard accessible
- Visible focus states
- Reduced-motion support
- No external dependencies

## 🎨 Design

The component focuses on a restrained visual language:

- Thin borders
- Generous spacing
- Strong typography
- Minimal accent color
- Subtle elevation
- Clean interaction states

The design avoids excessive gradients and animations so the
component remains suitable for professional interfaces.

## ♿ Accessibility

The component provides:

- Semantic HTML
- Descriptive link labeling
- Keyboard navigation
- `:focus-visible` styling
- High-visibility focus indicator
- Reduced-motion support using
  `prefers-reduced-motion`

Decorative SVG content is hidden from assistive technology
using `aria-hidden`.

## ⚡ Performance

The component does not require JavaScript.

Animations primarily use:

- `transform`
- `opacity`
- `box-shadow`

The component does not rely on continuous JavaScript
event listeners or external libraries.
