# Advanced Particle Burst Button

An advanced interactive button featuring a canvas-based particle burst,
basic physics simulation, and button recoil.

The component is designed as an EaseMotion showcase example.

## Features

- Canvas-based particle rendering
- Physics-inspired particle movement
- Radial particle burst
- Gravity simulation
- Velocity and friction
- Particle rotation
- Particle fading
- Button recoil animation
- Hover interaction
- Glow effects
- Responsive layout
- Keyboard-accessible button
- `:focus-visible` support
- `prefers-reduced-motion` support
- No external libraries
