# Fog Unveil · Fog Clears to Show Content 🌫️

An interactive fog unveiling effect where atmospheric fog clears to reveal hidden content beneath. Watch the mist dissolve and discover what's hidden!

## Features

- 🌫️ **Atmospheric Fog** – Realistic fog particles with drift
- 🌤️ **Clear Animation** – Fog smoothly clears to reveal content
- 🎨 **Hidden Content** – Beautiful landscape with mountains, sun, and trees
- 🎮 **Density Control** – Adjust fog density (1-10)
- ⏸️ **Pause/Resume** – Toggle animation
- 🔄 **Reset** – Reset fog to full density
- 🌅 **Reveal Effect** – Content fades in as fog clears
- 📱 **Touch Support** – Works on mobile devices

## How to Use

1. Click **CLEAR FOG** or press **C** to start the fog clearing animation
2. Watch the fog slowly dissipate
3. Hidden content emerges as the fog clears
4. Press **RESET FOG** or **R** to reset to full fog
5. Adjust **Fog Density** slider for thicker or thinner fog
6. Press **Space** or click **PAUSE** to pause/resume animation

## Technical Details

- **Fog Particles:** 80-120 particles with drift and pulsing
- **Clear Animation:** Progressive fog dissipation
- **Content:** Generated landscape image
- **Density Control:** Adjustable fog opacity
- **Performance:** 60fps with requestAnimationFrame

## Customization

You can easily customize:
- **Particle Count:** Modify `numParticles` range (80-120)
- **Clear Speed:** Adjust `clearProgress += 0.003`
- **Fog Density:** Modify slider range (1-10)
- **Content:** Change `generateHiddenContent()` function
- **Colors:** Adjust fog and content colors

## Browser Support
