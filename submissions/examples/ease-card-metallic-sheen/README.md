# Metallic Sheen Card

This is a smooth, hardware-accelerated pure CSS card featuring a metallic sheen effect, designed with dark mode compatibility and a premium aesthetic.

## What does this do?
It creates a card with a sleek metallic border gradient and a dynamic shine effect that sweeps across the card when hovered.

## How is it used?
```html
<div class="metallic-card">
    <div class="metallic-card-content">
        <h2>Metallic Sheen</h2>
        <p>Experience the smooth, hardware-accelerated metallic shine on hover.</p>
    </div>
</div>
```

## Why is it useful?
It provides a premium, eye-catching metallic aesthetic without relying on external libraries or JavaScript, making it perfect for highlighting premium features or pricing tiers while maintaining excellent performance and native dark mode compatibility.
