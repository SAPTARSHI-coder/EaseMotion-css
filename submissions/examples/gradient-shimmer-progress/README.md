# Gradient Shimmer Progress

A smooth and modern CSS progress bar featuring an animated gradient shimmer effect.

Built using only **HTML and Vanilla CSS**, with no JavaScript or external libraries.

## ✨ Features

- 🎨 Animated gradient shimmer
- 📊 Multiple progress levels
- 🌙 Automatic dark mode support
- ♿ Accessible progressbar semantics
- ⚡ Hardware-friendly CSS animations
- 📱 Fully responsive
- 🧘 Reduced-motion support
- 🧊 Glassmorphism-inspired interface
- 🚫 No JavaScript
- 🚫 No external dependencies
