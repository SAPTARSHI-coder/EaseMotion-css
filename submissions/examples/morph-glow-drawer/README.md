# CSS Morph Glow Drawer

## Overview

A responsive gaming-inspired drawer with a morph glow animation built using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Responsive Drawer
- Morph Glow Animation
- CSS Custom Properties
- Accessible (`prefers-reduced-motion`)
- No JavaScript Required

## Folder Structure

```text
morph-glow-drawer/
├── demo.html
├── style.css
└── README.md
```

## Usage

1. Open `demo.html` in any browser.
2. Click the menu button to open the drawer.
3. Customize the CSS variables.

## CSS Variables

- `--primary`
- `--background`
- `--drawer`
- `--text`
- `--duration`

## Browser Support

- Chrome
- Firefox
- Edge
- Safari
