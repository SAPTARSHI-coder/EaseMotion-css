# Animated Login / Authentication Form

A modern, accessible login form built with **EaseMotion CSS**. It features smooth staggered entrance animations, interactive hover states, and pure CSS floating labels—requiring absolutely zero JavaScript.

## ✨ Features

- **Zero JavaScript**: Pure CSS animations and interactions (including floating labels).
- **Staggered Entrance**: Form elements slide up sequentially using `.ease-slide-up` and `.ease-delay-*` classes, creating a premium loading feel.
- **Floating Labels**: Inputs use the `:placeholder-shown` CSS pseudo-class to animate labels smoothly when focused or filled.
- **Animated Background**: Decorative background blobs use `.ease-float` to create a subtle, ambient motion effect.
- **Interactive Hover**: The submit button lifts and grows (`.ease-hover-lift`, `.ease-hover-grow`), while social buttons scale (`.ease-hover-scale`).
