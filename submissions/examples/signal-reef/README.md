# Signal Reef

Signal Reef is an immersive underwater data visualization component
where distributed system signals are represented as living coral
structures inside an animated underwater environment.

Instead of presenting signals as conventional bars or cards, the
component turns the data into an interactive visual ecosystem.

## Features

- Interactive signal coral
- Signal-specific data
- Hover telemetry tooltip
- Click-to-open detail panel
- Dynamic signal values
- Signal health states
- Animated bubbles
- Moving fish
- Underwater particles
- Animated water currents
- Responsive layout
- Reset functionality
- Vanilla JavaScript
- No external dependencies
- No separate JavaScript file
