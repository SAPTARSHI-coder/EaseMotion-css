# CSS Slide-Up Tabs for Product Catalog Layouts

A responsive **Slide-Up Tabs** component built using pure HTML and CSS. Users can switch between product categories with smooth slide-up transitions, making it ideal for modern e-commerce product catalogs.

---

## Features

- Pure HTML & CSS
- Animated Slide-Up tab transitions
- Responsive product grid
- Category switching without JavaScript
- Smooth hover effects
- CSS Custom Properties
- Accessible structure
- prefers-reduced-motion support
- Cross-browser compatible
