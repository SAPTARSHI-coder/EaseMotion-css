# Floating Audio Player Widget · Glassmorphism
A responsive floating audio-player interface with a glassmorphism visual treatment.

## Features
* Floating glassmorphism player
* Responsive mobile, tablet, and desktop layout
* Semantic HTML controls
* Keyboard-focusable controls
* Progress and volume indicators
* Smooth hover and interaction transitions
* Reduced-motion support through `prefers-reduced-motion`
* No JavaScript dependencies

## Files
* `demo.html` — component markup and demo content
* `style.css` — glassmorphism styling, responsive layout, and animations

## Usage
Open `demo.html` directly in a modern browser.
The demo is intentionally UI-focused and does not include JavaScript audio playback logic.

## Accessibility
The component includes:
* Accessible button labels
* Visible keyboard focus states
* Semantic progressbar markup
* `prefers-reduced-motion` support

## Browser Support
Designed for modern Chrome, Firefox, Safari, and Edge browsers.
