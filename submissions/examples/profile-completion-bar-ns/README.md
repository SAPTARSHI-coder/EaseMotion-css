# CSS Profile Completion Bar (#70995)

A responsive profile completion card featuring an animated progress bar, shimmering shine effects, and actionable improvement checklist items.

## Features
- Pure CSS scale transformation load animation (`scaleX`) with smooth cubic-bezier easing.
- Continuous animated shimmer gradient overlay across the progress track.
- Actionable task items supporting completed and pending status styling.
- Full accessibility support via semantic `role="progressbar"`, `aria-valuenow`, and motion safety fallbacks (`prefers-reduced-motion`).
