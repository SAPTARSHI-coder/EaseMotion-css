# Ease Magnetic Particle Cursor Trail

An interactive custom cursor with glowing particle effects, smooth cursor following, hover scaling and click animations.

## Features

- Smooth magnetic cursor
- Particle trail
- Hover enlargement
- Click animation
- Touch device detection
- Lightweight

## Folder Structure

ease-magnetic-particle-cursor-trail/
├── demo.html
├── style.css
├── script.js
└── README.md

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

## Usage

Open `demo.html` in a web browser.
