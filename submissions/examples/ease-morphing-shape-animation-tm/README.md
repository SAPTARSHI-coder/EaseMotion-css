# Morphing Shape Animation Component

Add ease-morphing-shape-animation-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|---------|
| `--ms-shape1` | `#6366f1` |
| `--ms-shape2` | `#ec4899` |
| `--ms-shape3` | `#10b981` |
| `--ms-size` | `120px` |
| `--ms-speed` | `6s ease-in-out infinite` |

## Technique

Multiple layered blobs with different `border-radius` keyframe sequences at offset delays create the organic morphing blob effect.
