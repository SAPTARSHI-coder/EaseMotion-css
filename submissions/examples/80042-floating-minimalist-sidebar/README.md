# Floating Minimalist Sidebar (Pro)

A clean and responsive floating sidebar built for modern dashboards,
workspace applications, and productivity interfaces.

## Features

- Floating card-style sidebar
- Minimalist visual language
- Responsive desktop, tablet, and mobile layouts
- Active navigation state
- Hover interactions
- Keyboard focus states
- Notification badges
- Pro upgrade panel
- User profile section
- Responsive dashboard preview
- Pure HTML and CSS
- No JavaScript dependency
- Reduced-motion accessibility support

## Files

- `demo.html` — complete sidebar and dashboard demonstration
- `style.css` — component styles and responsive behavior
