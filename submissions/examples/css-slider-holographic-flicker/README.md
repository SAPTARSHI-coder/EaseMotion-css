# CSS Slider: Holographic Flicker Variation

A responsive, accessible, and performant pure CSS slider
featuring a futuristic Holographic Flicker effect.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript
- No external dependencies
- Animated holographic gradients
- Flickering light effect
- Animated scanlines
- Moving holographic shine
- CSS Scroll Snap
- Responsive design
- Keyboard-accessible navigation
- Focus-visible states
- Reduced-motion support
- Dark-mode friendly
- Hardware-friendly CSS transforms
