# CSS Elastic-Slide Carousel for Accessible Web Layouts

A modern **Elastic-Slide Carousel** component created using only **HTML5 and CSS3**. This showcase demonstrates elastic entrance animations, smooth card transitions, responsive layouts, and accessibility support without JavaScript.

---

## ✨ Features

- 🌀 Elastic slide entrance animation
- 🎴 Animated carousel cards
- ⚡ Smooth CSS transitions
- 💎 Glassmorphism UI design
- 🎯 CSS Custom Properties
- 📱 Fully responsive layout
- 🧩 Pure HTML5 & CSS3
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

## 🚀 Usage

1. Open `demo.html` in a modern browser.
2. View the elastic entrance animation.
3. Hover over cards for interactive effects.
4. Customize colors and animations using CSS variables.
