# CSS Liquid Fill Button

A pure CSS button with a smooth liquid wave fill animation on hover and keyboard focus.

## Features

- Pure HTML and CSS
- No JavaScript required
- Animated liquid wave effect
- Smooth fill transition
- Hover and keyboard focus support
- Responsive design
- CSS custom properties for theming
- Light and dark mode support
- Reduced-motion support
- Native accessible `<button>` element
