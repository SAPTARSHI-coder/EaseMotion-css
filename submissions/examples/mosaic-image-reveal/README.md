# CSS Mosaic Image Reveal


A pure CSS animated mosaic image reveal component for EaseMotion CSS.


## Overview

`css-mosaic-image-reveal` reveals an image by animating multiple mosaic tiles.


## Features

- Pure CSS implementation
- No JavaScript dependency
- Mosaic tile animation
- Smooth reveal effect
- Responsive layout
- Reduced motion accessibility support


## Animation

Uses CSS keyframes:

```css
@keyframes tile_reveal
