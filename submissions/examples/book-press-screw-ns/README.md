# Book Press Screw

## What does this do?
Renders a self-contained CSS-only `ease-book-press-screw` demo: Antique book press screw descending onto stacked pages.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-book-press-screw`. No build step or JavaScript is required for the effect.

```html
<section class="ease-book-press-screw">
  <div class="ease-book-press-screw__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
