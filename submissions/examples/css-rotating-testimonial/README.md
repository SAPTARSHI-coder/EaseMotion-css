# CSS Rotating Testimonial

A pure HTML and CSS rotating testimonial component that cycles through customer quotes using CSS keyframe animations.

## Features

- Automatic rotating testimonials
- Smooth fade and slide animation
- Responsive design
- Accessible semantic markup
- Pure HTML & CSS
- No JavaScript required

## Folder Structure

```
css-rotating-testimonial/
├── demo.html
├── style.css
└── README.md
```

## Technologies

- HTML5
- CSS3
- CSS Keyframes
- CSS Animations
- Responsive Design

## Purpose

Provides a lightweight rotating testimonial component for landing pages, portfolios, SaaS websites, and product showcases while following EaseMotion CSS's animation-first philosophy.
