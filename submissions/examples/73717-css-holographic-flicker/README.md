# CSS Glass Effect: Holographic Flicker

A smooth and performant pure CSS glassmorphism effect featuring a subtle **Holographic Flicker** aesthetic.

## Features

- Pure HTML and Vanilla CSS
- Glassmorphism UI
- Holographic color movement
- Subtle flicker animation
- Animated light streaks
- Soft radial glow
- Smooth CSS transitions
- Dark mode compatible
- Light mode support
- Responsive layout
- Hardware-accelerated transforms
- Accessible keyboard focus states
- `prefers-reduced-motion` support
- No external JavaScript
- No external libraries

## Demo

Open `demo.html` in a modern browser to view the effect.
