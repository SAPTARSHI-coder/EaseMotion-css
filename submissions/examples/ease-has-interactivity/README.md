# CSS `:has()` Parent Selector Interactivity (`ease-has-interactivity`)

Implements and showcases parent container styling using the modern CSS `:has()` pseudo-class across 30 foundational UI component patterns without using JavaScript.

## Covered Components
1. Accordion (`:has(details[open])`)
2. Alert (`:has(.btn-close:focus)`)
3. Avatar (`:has(img:hover)`)
4. Badge (`:has(.badge-active)`)
5. Breadcrumb (`:has(a:hover)`)
6. Button (`:has(button:active)`)
7. Card (`:has(input:checked)`)
8. Carousel (`:has(input:checked)`)
9. Checkbox (`:has(input:checked)`)
10. Chip (`:has(.chip-remove:hover)`)
11. Code Block (`:has(button:active)`)
12. Code Inline (`:has(code:hover)`)
13. Dialog (`:has(dialog[open])`)
14. Divider (`:has(hr:hover)`)
15. Drawer (`:has(input:checked)`)
16. Dropdown (`:has(select:focus)`)
17. Form (`:has(input:invalid:focus)`)
18. Icon (`:has(svg:hover)`)
19. Image (`:has(img:hover)`)
20. Input (`:has(input:focus)`)
21. Kbd (`:has(kbd)`)
22. Link (`:has(a:hover)`)
23. List (`:has(li:hover)`)
24. Loader (`:has(.spinner)`)
25. Menu (`:has(.menu-item:hover)`)
26. Modal (`:has(.modal-trigger:checked)`)
27. Navbar (`:has(.nav-link:hover)`)
28. Pagination (`:has(.page-active)`)
29. Popover (`:has(.popover-target:focus)`)
30. Progress (`:has(progress[value="100"])`)
