# CSS `:has()` Parent Selector Interactivity (`ease-has-interactivity`)

Implements parent container interactive styling using the native CSS `:has()` pseudo-class across 30 UI components without requiring JavaScript.

## Features
- **Zero-JS Interactivity**: Parent components adapt styles dynamically based on child states (`:checked`, `:focus`, `:hover`, `[open]`).
- **Performance Optimized**: Eliminates event listener overhead.
