# CSS Morph-Glow Hero Section for Product Catalog Layouts

A modern **Morph-Glow Hero Section** built using pure HTML and CSS. The component features a smooth morphing glow animation, responsive hero layout, CSS custom properties, and lightweight styling for modern product catalog landing pages.

## ✨ Features

- Pure HTML5 & CSS3
- Morph + Glow animation
- Responsive hero section
- Glassmorphism product card
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
