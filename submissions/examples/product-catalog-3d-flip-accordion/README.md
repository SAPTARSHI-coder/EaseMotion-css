# 3D-Flip Accordion for Product Catalogs

A lightweight, pure HTML/CSS **3D-Flip Accordion** designed for modern product catalog layouts.

The component uses CSS 3D transforms to create a smooth flip-style accordion interaction while keeping the implementation dependency-free.

## Features

- Pure HTML and CSS
- No JavaScript or external frameworks
- CSS 3D flip animation
- Smooth accordion expansion and collapse
- Product-focused catalog layout
- Responsive across desktop, tablet, and mobile
- Hover interactions
- CSS custom properties for customization
- Keyboard-friendly focus-visible states
- `prefers-reduced-motion` accessibility support
- Lightweight and reusable
