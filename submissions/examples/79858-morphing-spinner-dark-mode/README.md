# Morphing Spinner - Dark Mode

A responsive morphing loading spinner built with pure HTML and CSS,
featuring a modern dark-mode visual style.

## ✨ Features

- Fully responsive
- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Dark mode aesthetic
- Fluid morphing animation
- Multiple animated rings
- Animated loading indicator
- Soft neon glow
- Responsive sizing
- Reduced-motion support
- Accessible loading state
