# Aurora Glow Accordion

A polished CSS-only accordion inspired by the atmospheric colors and
soft lighting of the aurora borealis.

## Features

- Pure HTML5 and vanilla CSS
- No JavaScript
- No external dependencies
- Native `<details>` / `<summary>` interaction
- Aurora gradient effects
- Glassmorphism-inspired surfaces
- Smooth open/close transitions
- Responsive design
- Keyboard accessible
- Visible focus states
- `prefers-reduced-motion` support
- Dark-mode friendly
- Hardware-friendly CSS effects
