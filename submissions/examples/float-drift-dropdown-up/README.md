# Float Drift Dropdown for Creative Portfolio Layouts

A modern **glassmorphism-inspired dropdown menu** built using **pure HTML and CSS**. This component is designed for creative portfolio websites and features a smooth float-drift animation with a responsive layout.

## ✨ Features

- 🎨 Modern Glassmorphism UI
- 🚀 Smooth Float-Drift Animation
- 📱 Fully Responsive Design
- 🎯 Pure HTML & CSS (No JavaScript)
- ♿ Keyboard Accessible (`:focus-within`)
- 🌈 Gradient Hero Section
- 💜 Animated Hover Effects
- 🧊 Backdrop Blur Dropdown
- ⚡ Lightweight & Easy to Customize
