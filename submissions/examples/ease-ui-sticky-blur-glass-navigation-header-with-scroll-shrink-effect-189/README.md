# Sticky Blur Glass Navigation Header with Scroll Shrink Effect (Minimalist Clean Edition)

A modern, responsive navigation header featuring glassmorphism, smooth scroll animations, and a clean minimalist design.

## Features

- Sticky glass navigation bar
- Scroll shrink animation
- Glassmorphism effect with backdrop blur
- Gradient CTA button
- Animated navigation hover effects
- Responsive mobile navigation
- Animated hamburger menu
- Modern hero section
- CSS variables for easy customization
- Pure HTML, CSS and JavaScript

## Folder Structure

```
ease-ui-sticky-blur-glass-navigation-header-with-scroll-shrink-effect-189/

```

## Usage

1. Open `demo.html` in any modern browser.
2. Modify colors using the CSS variables in `style.css`.
3. Integrate the component into your project as needed.
