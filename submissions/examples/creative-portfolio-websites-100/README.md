# Neumorphic Parallax Depth Card Grid

A responsive portfolio card grid combining neumorphic UI,
3D depth and interactive parallax movement.

## Features

- Neumorphic design
- Interactive 3D card tilt
- Smooth hover transitions
- Responsive grid
- Mobile friendly
- No external dependencies
- Reduced-motion support
