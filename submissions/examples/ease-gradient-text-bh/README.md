# ease-gradient-text-bh

Pure CSS animated gradient text mask utility.

## What does this do?
Creates text with animated gradient colors that shift and flow, creating eye-catching headlines.

## How is it used?
```html
<h1 class="ease-gradient-text-bh">Animated Text</h1>
```

## Why is it useful?
Adds visual interest to headings and important text elements without JavaScript.
