# glow-notification-badge-ak

## How to use

```html
<div class="ease-alert-tag">
  <span>Messages</span>
  <span class="ease-alert-count">3</span>
</div>

<!-- Variant -->
<div class="ease-alert-tag ease-alert-tag--primary">...</div>
