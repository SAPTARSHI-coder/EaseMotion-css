# Ease Label Badge

## What does this do?

A small colored label badge for categories, tags, and status labels.

---

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<span class="label-badge blue">Design</span>
```

### Available variants

```html
<span class="label-badge blue">Design</span>
<span class="label-badge green">Active</span>
<span class="label-badge orange">Popular</span>
<span class="label-badge purple">Featured</span>
```

### Features

- Rounded badge
- Multiple color variants
- Hover animation
- Responsive layout
- Lightweight and reusable

---

## Why is it useful?

Label badges are commonly used for categories, tags, statuses, and featured content.

This component provides a simple reusable label pattern with subtle interaction feedback while following the animation-first philosophy of EaseMotion CSS.
