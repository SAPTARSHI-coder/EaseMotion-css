# CSS Liquid Pour Loader

A CSS-only liquid pouring and filling animation that can be used as
a loading indicator.

## Features

- Pure HTML and CSS
- No JavaScript required
- Animated pouring stream
- Container filling animation
- Animated liquid surface
- Responsive layout
- Accessible loading status
- Supports `prefers-reduced-motion`
- Lightweight implementation
