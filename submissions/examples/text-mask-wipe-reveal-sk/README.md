# Text Mask Wipe Reveal

## What does this do?

A headline reveal using a moving mask wipe, with reduced-motion fallback.

## How is it used?

```html
<h1 class="wipe-reveal">Motion made readable</h1>
```

Open `demo.html` in a browser to try it.

## Why is it useful?

Polished typography entrance for heroes without glitch aesthetics.
