# Pomodoro Timer

A focus timer ring that ticks down 25 minutes with a pulsing center label.

## Features
- SVG-free ring via conic gradient mask
- Center digits pulse on each second
- Session dot indicates the mode

## Usage
```html
<div class="pt-timer">
  <div class="pt-inner">25:00<small>focus</small></div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
