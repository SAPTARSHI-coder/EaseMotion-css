# Ice Cream Soft Serve

## What does this do?
Renders a self-contained CSS-only `ease-ice-cream-soft-serve` demo: Soft-serve swirl rising from a cone with soft morphing peaks.

## How is it used?
Open `demo.html` in a browser. The animated face uses classes like `ease-ice-cream-soft-serve`, `ease-ice-cream-soft-serve__arm`, and `ease-ice-cream-soft-serve__core`. No build step or JavaScript is required for the motion.

```html
<section class="ease-ice-cream-soft-serve">
  <div class="ease-ice-cream-soft-serve__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
