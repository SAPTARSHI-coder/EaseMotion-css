# CSS Fluid Blob Background

Soft organic blob shapes slowly float, morph, overlap, and merge using CSS animation.

## Files

- `demo.html` — accessible demonstration content
- `style.css` — blob layers, morphing animation, responsive rules, and reduced-motion support

## Usage

Open `demo.html` in a modern browser. No JavaScript or dependencies are required.

## Accessibility

The decorative blob layer is hidden from assistive technology and animation respects `prefers-reduced-motion`.
