# Velvet Smooth Neumorphic UI

A pure CSS neumorphic UI component featuring a soft **Velvet Smooth Transition**
style for EaseMotion CSS.

## Features

- Pure HTML and Vanilla CSS
- Soft neumorphic depth
- Smooth velvet-like transitions
- Interactive hover and active states
- Responsive layout
- Dark mode support
- Keyboard focus states
- `prefers-reduced-motion` support
- No JavaScript
- No external dependencies
