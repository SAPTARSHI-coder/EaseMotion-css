# Zoom-In Creative Portfolio Tabs (`#54466`)

## What does this do?
Provides an immersive portfolio tab switching layout where newly selected section panels zoom forward toward the viewer out of scaled recessed horizon depth.

## How is it used?
Organize content panes inside an `ease-tabs-zoom` parent container:
```html
<div class="ease-tabs-zoom">
  <div class="viewport">
    <div class="zoom-panel active">...</div>
  </div>
</div>
```

## Why is it useful?
Solves issue #54466 by instilling spotlight cinematic depth transitions into multi-tab creative studio galleries.
