# Minimalist Outline Form

A smooth, accessible, and performant pure CSS form featuring **Minimalist Outline** styling.

## Usage

```html
<form class="minimalist-form">
    <div class="input-group">
        <input type="text" id="name" required placeholder=" ">
        <label for="name">Full Name</label>
        <div class="outline-highlight"></div>
    </div>
    <!-- Add other fields similarly -->
    <button type="submit" class="submit-btn">Send Message</button>
</form>
```

## Why is it useful?

This component provides an elegant, hardware-accelerated animated floating label effect using pure HTML and vanilla CSS. It supports dark mode automatically and offers smooth transitions to enhance user interaction without relying on external JavaScript.
