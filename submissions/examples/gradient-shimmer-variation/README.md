## 🚀 Usage
1. Clone or copy the files into your project.
2. Open `index.html` in your browser.
3. Hover over the badge to see the shimmer animation.

---

## 🛠️ Customization
- **Gradient colors** → Adjust `linear-gradient` stops for different palettes.
- **Shimmer speed** → Change `animation: shimmer 3s` for faster/slower effect.
- **Badge size** → Adjust padding and font-size in `.shimmer-badge`.
- **Shadow depth** → Modify `box-shadow` values for stronger/weaker elevation.

---

## 📖 Accessibility
- Large, clear text for readability.
- Smooth motion avoids harsh flicker.
