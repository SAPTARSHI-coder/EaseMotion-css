# CSS Retro Arcade Pixel Progress

Issue #73513 creates a pixel-inspired progress bar with stepped CSS animation and arcade styling.

## Features

- Pixel-inspired visuals
- Stepped fill animation
- Accessible progressbar semantics
- Responsive presentation
- Reduced-motion support
- Pure CSS implementation

## Usage

Open `demo.html` and modify `--value` to change the progress amount.

## Files

- `demo.html` — semantic progress structure
- `style.css` — arcade styling and animation
- `README.md` — documentation
