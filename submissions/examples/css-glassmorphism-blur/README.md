# CSS 3D Glassmorphism Blur

A pure CSS 3D glassmorphism component combining translucent surfaces, backdrop blur, soft borders, layered depth, glowing background orbs, and smooth floating animation.

## Features

- Pure HTML and vanilla CSS
- No JavaScript
- No external libraries
- Glassmorphism blur effect
- CSS 3D perspective
- Translucent layered surfaces
- Animated background orbs
- Smooth floating motion
- Responsive design
- Dark-mode compatible
- Hardware-friendly transforms
- `backdrop-filter` fallback
- Reduced-motion support

## Usage

Open `demo.html` directly in a modern browser.

The component can be reused by copying the `.glass-card` structure and related CSS into another project.

## Accessibility

Decorative elements use `aria-hidden="true"`. The component uses semantic HTML with a descriptive heading. Motion is disabled when the user has enabled `prefers-reduced-motion`.

## Browser Support

The component uses `backdrop-filter` for the glass blur effect and includes a fallback for browsers that do not support it.

## EaseMotion CSS

This component fits EaseMotion CSS by providing a reusable animation-first 3D UI pattern using only HTML and vanilla CSS. It demonstrates glassmorphism, perspective, depth, blur, translucency, and smooth motion without JavaScript.
