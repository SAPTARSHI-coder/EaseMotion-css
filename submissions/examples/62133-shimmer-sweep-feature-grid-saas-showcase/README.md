# CSS Shimmer-Sweep Feature Grid for SaaS Showcase Layouts

A modern **Shimmer-Sweep Feature Grid** built using pure HTML5 and CSS3 for SaaS showcase layouts. This component displays SaaS features with elegant shimmer light effects, glassmorphism cards, smooth hover interactions, and a responsive grid system.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Shimmer-Sweep hover animation
* Animated gradient highlight effect
* SaaS feature showcase cards
* Feature icons with smooth transformations
* Glassmorphism card design
* Responsive CSS Grid layout
* Smooth CSS transitions and keyframe animations
* CSS Custom Properties for easy customization
* Lightweight and performant animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over feature cards to view the shimmer sweep animation.
3. Customize colors, spacing, shadows, and animation duration using CSS variables inside `:root`.

## CSS Custom Properties

```css
:root{
  --bg:#eef4ff;
  --surface:rgba(255,255,255,.9);
  --primary:#2563eb;
  --secondary:#06b6d4;
  --accent:#8b5cf6;
  --text:#111827;
  --muted:#64748b;
  --shadow:0 18px 45px rgba(37,99,235,.18);
  --radius:24px;
}
```
