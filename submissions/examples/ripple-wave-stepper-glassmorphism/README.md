# Ripple-Wave Stepper for Glassmorphism UI

A modern animated stepper component built using pure HTML and CSS.

## Features

- Pure CSS implementation
- Glassmorphism design
- Ripple-wave animation effect
- Smooth transitions
- Responsive layout
- No JavaScript dependency
- Accessibility support
