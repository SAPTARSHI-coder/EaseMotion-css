# CSS Keyboard Key Component

A reusable CSS keyboard key component with a realistic press animation.

## Features

- Pure HTML and CSS
- Realistic 3D keyboard-key appearance
- Press animation using `:active`
- Keyboard accessible
- Visible focus state
- Responsive design
- Reduced-motion support
- No JavaScript required

## Files

- `demo.html` – Component demonstration
- `style.css` – Component styles

## Usage

Add the following HTML:

```html
<button class="key" type="button" aria-label="Press Enter key">
  Enter
</button>
