# Floating Aura Avatar Profile Ring

A modern glassmorphic profile component featuring a floating avatar,
rotating dual-gradient aura rings, online status indicator, animated
micro-interactions, and responsive styling.

## Component

**Issue:** #58111

**Style:** Glassmorphic Style

**Category:** Layout Grids & Cards

**Track:** GSSoC-26 / ECSoC26-L2

## Features

- Rotating dual-gradient aura rings
- Glassmorphism profile card
- Floating avatar animation
- Online status indicator
- Interactive Connect button
- Smooth hover elevation
- Responsive mobile layout
- CSS custom properties
- Keyboard focus support
- Reduced-motion accessibility support
- No external dependencies
