# Gaming Profile Card

This submission demonstrates a modern gaming profile card built with
**EaseMotion CSS**. It includes animated entrance effects, hover motion,
XP progress bar, gamer stats, badges, and responsive layout.

## 🌟 Features

- **Gamer profile card** with banner, avatar, username, and level badge.
- **Online status badge** for player availability.
- **XP progress bar** using CSS variables.
- **Gamer stats** for rank, wins, and playtime.
- **Badge chips** for achievements.
- **Action buttons** with hover grow effect.
- **Staggered entrance animation** using `ease-slide-up` and delay utilities.
- **Hover lift effect** using `ease-hover-lift`.
- **Responsive layout** for mobile and desktop.
- **Reduced motion support** for users who prefer less animation.

## 📁 Files

- `demo.html` — interactive gaming profile card demo
- `style.css` — original gaming card styling
- `README.md` — documentation for this submission

## 🛠️ How to Run

1. Open `demo.html` in your browser.
2. Watch the gamer card animate on page load.
3. Hover over the card to see the lift effect.
4. Hover over the buttons to see the grow effect.
5. Resize the browser window to check responsive behavior.
