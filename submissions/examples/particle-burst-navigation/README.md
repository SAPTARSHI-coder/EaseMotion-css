# Particle Burst Navigation

A polished and accessible navigation component featuring a
smooth particle burst interaction using pure HTML and vanilla CSS.

## ✨ Features

- Particle burst hover animation
- Keyboard focus interaction
- Smooth staggered particle transitions
- Hardware-friendly CSS transforms
- Responsive navigation
- Dark theme compatible
- Reduced-motion support
- Semantic HTML
- No JavaScript
- No external libraries
