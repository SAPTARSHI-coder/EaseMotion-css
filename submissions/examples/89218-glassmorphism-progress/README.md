# Glassmorphism Progress Bar Component

A sleek progress bar component featuring translucent track styling and a fluid entrance fill animation.

## Features
- **Glassmorphism Aesthetic:** Translucent track with backdrop blur.
- **Fluid Animation:** Pure CSS cubic-bezier growth effect.
- **Pure CSS:** Zero JavaScript dependencies.

## File Structure
- `demo.html` - Minimal progress bar structure.
- `style.css` - Component track styling and growth keyframes.
