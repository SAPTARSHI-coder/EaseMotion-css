# Floating Label Input with Glassmorphism Styling

> Issue: [#81508](https://github.com/SAPTARSHI-coder/EaseMotion-css/issues/81508) / [#80961](https://github.com/SAPTARSHI-coder/EaseMotion-css/issues/80961)

A responsive, glassmorphic floating label input component with smooth state animations.

---

## ✨ Features & Architectural Highlights

- **Zero-JS State Management:** Pure CSS floating label transitions powered by `:focus` and `:not(:placeholder-shown)`.
- **Glassmorphism Aesthetics:** `backdrop-filter: blur(16px)` with translucent borders and soft ambient glow.
- **Accessible & Responsive:** Adapts to all screen sizes with `@media (prefers-reduced-motion: reduce)` support.

---

## 🚀 Usage

1. Include `style.css` in your HTML `<head>`:
   ```html
   <link rel="stylesheet" href="style.css" />
   ```
2. Use the HTML structure provided in `demo.html`.
