# Smoke Dissolve Fade Rise

A lightweight CSS motion preset that creates a smoke-like rising and dissolving effect.

## Features

- Smooth upward movement
- Gradual fade/dissolve effect
- Configurable duration
- Configurable timing function
- Uses transform and opacity
- Supports prefers-reduced-motion

## Usage

```html
<div class="ease-anim-smoke-dissolve-fade-rise">
    Smoke
</div>
