# CSS Scale-Hover Badge for Fintech Dashboard Layouts

A modern **Scale-Hover Badge** component built using pure HTML5 and CSS3 for fintech dashboard layouts. This component provides a clean financial indicator interface with animated circular badges, smooth scaling effects, glassmorphism cards, and responsive behavior.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Fintech dashboard indicator design
* Smooth scale-hover badge animation
* Floating badge motion effects
* Glassmorphism metric cards
* Gradient status badges
* Financial performance indicators
* Hover elevation interactions
* Responsive grid layout
* CSS Custom Properties support
* Lightweight keyframe animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over badges to see smooth scale animations.
3. Customize colors, shadows, spacing, and animation behavior using CSS variables.
