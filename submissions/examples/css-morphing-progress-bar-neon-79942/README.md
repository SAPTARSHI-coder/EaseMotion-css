# Morphing Progress Bar with Neon Styling

A responsive progress bar component featuring animated neon gradients, morphing shapes, glowing effects, and smooth motion built entirely with HTML and CSS.

## Features

- Pure HTML & CSS
- Neon glow effects
- Morphing shape animation
- Animated gradient flow
- Responsive design
- Lightweight and reusable
- No JavaScript required

## Files

- demo.html
- style.css

## Usage

```html
<div class="progress-bar">
  <div class="progress-fill"></div>
</div>
```

## Why it fits EaseMotion CSS

This component showcases fluid motion, engaging neon visuals, lightweight implementation, and reusable animation patterns while maintaining responsiveness and accessibility.
