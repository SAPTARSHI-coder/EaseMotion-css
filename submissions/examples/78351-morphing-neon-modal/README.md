# Morphing Modal with Neon Styling

A responsive futuristic modal component built with HTML and CSS.

The design combines neon cyan and pink accents, layered glow effects,
animated borders, morphing entrance transitions, and a dark futuristic
interface.

## Features

- Fully responsive
- Neon-inspired visual design
- Morphing entrance animation
- Animated ambient glow
- Neon border and scanline
- Responsive modal layout
- Hover interactions
- Keyboard focus states
- Reduced-motion support
- No external dependencies

## Files

- `demo.html`
- `style.css`

## Component Structure

The demo contains:

- Modal stage
- Open system button
- Modal dialog
- Status information
- Action buttons
- Feature cards
- Responsive specification cards

## Styling

The modal uses:

- Dark layered surfaces
- Cyan and pink neon accents
- Soft glow effects
- Gradient lighting
- Rounded morphing geometry
- CSS transforms
- CSS keyframe animations

## Responsiveness

The component adapts to smaller viewports by:

- Scaling typography
- Reducing modal padding
- Stacking modal information blocks
- Making action buttons full width
- Converting feature cards into a single column
- Converting the specification grid into two columns

## Accessibility

- Uses semantic dialog markup
- Provides an accessible dialog heading
- Buttons use native HTML controls
- Includes visible keyboard focus styles
- Supports `prefers-reduced-motion`

## Technologies

- HTML5
- CSS3
