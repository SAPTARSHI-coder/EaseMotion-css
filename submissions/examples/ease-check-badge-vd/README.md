# Ease Check Badge

## What does this do?

A rounded verification badge with a checkmark icon and multiple color variants.

---

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<span class="check-badge verified">
    <span class="check-icon">✓</span>
    Verified
</span>
```

### Available variants

```html
<span class="check-badge verified">
    <span class="check-icon">✓</span>
    Verified
</span>

<span class="check-badge trusted">
    <span class="check-icon">✓</span>
    Trusted
</span>

<span class="check-badge complete">
    <span class="check-icon">✓</span>
    Complete
</span>
```

### Features

- Rounded badge
- Checkmark icon
- Multiple color variants
- Hover animation
- Icon scale animation
- Responsive layout

---

## Why is it useful?

Verification badges are commonly used for verified profiles, completed actions, trusted accounts, and status displays.

This component provides a lightweight and reusable badge pattern with subtle interaction feedback while following the animation-first philosophy of EaseMotion CSS.
