# CSS Zoom-In Modal for Creative Portfolio Layouts

A lightweight, responsive, and accessible **CSS-only Zoom-In Modal** built for EaseMotion CSS. This example demonstrates how to create a modern portfolio preview modal using only HTML and CSS, with smooth transitions and no JavaScript.

## Features

- 🎨 Pure HTML & CSS implementation
- ⚡ Smooth zoom-in and fade animations
- 📱 Fully responsive design
- ♿ Accessibility-friendly structure
- 🌙 Supports `prefers-reduced-motion`
- 🛠 Easy customization using CSS custom properties
- 🚀 No external libraries or JavaScript required

## CSS Custom Properties

The following variables can be customized in `style.css`:

| Variable | Description |
| -------- | ----------- |
| `--bg-color` | Page background color |
| `--surface` | Modal background color |
| `--primary` | Primary accent color |
| `--primary-dark` | Hover color for primary buttons |
| `--text` | Primary text color |
| `--muted` | Secondary text color |
| `--border` | Border color |
| `--overlay` | Modal overlay background |
| `--radius` | Border radius |
| `--shadow` | Modal shadow |
| `--duration` | Animation duration |
| `--timing` | Transition timing function |

## Usage

1. Open `demo.html` in a modern web browser.
2. Click the **View Project** button.
3. The portfolio modal smoothly zooms into view.
4. Click the **×** button or **Close** button to dismiss the modal.

## Responsive Design

- Desktop: Two-column portfolio layout.
- Tablet: Optimized spacing and sizing.
- Mobile: Single-column layout with stacked actions.
