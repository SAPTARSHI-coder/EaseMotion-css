# Ease Copy Chip

## What does this do?

A compact chip component that displays short text (such as an API key, invite code, or token) with a copy button. Clicking the button copies the text to the clipboard and briefly displays a **"Copied ✓"** confirmation with a subtle fade animation.

---

## How is it used?

Open `demo.html` in any modern browser.

Example:

```html
<div class="copy-chip">
    <span>API-7X92-QW81</span>
    <button>Copy</button>
</div>
```

### Features

- Compact rounded chip
- Copy-to-clipboard functionality
- "Copied ✓" feedback
- Smooth fade animation
- Responsive layout
- Lightweight and reusable

---

## Why is it useful?

Copy chips are commonly used for API keys, coupon codes, invite links, access tokens, and short identifiers. This component provides a clean, reusable, animation-first interaction that fits well within dashboards, documentation pages, developer tools, and admin interfaces, aligning with the EaseMotion CSS philosophy.
