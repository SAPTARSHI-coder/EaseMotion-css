# ☀️ Solar Flare – Sun-Like Flare Erupts on Click

> An explosive solar flare component where sun-like plasma eruptions burst with fiery particles, featuring 4 flare types (Classic, Plasma, Blue, White), intensity control (0-100%), and size control (0-100%).

---

## 📖 Description

The **Solar Flare** component creates an explosive solar flare experience where sun-like plasma eruptions burst with fiery particles. Built with vanilla HTML, CSS, and JavaScript, it features 4 flare types (Classic, Plasma, Blue, White), intensity control (0-100%), size control (0-100%), and particle physics for an immersive stellar experience.

### 🎯 Core Features

- **Solar flare eruption** – explosive plasma bursts on click
- **4 flare types** – Classic (gold/orange/red), Plasma (pink/magenta/orange), Blue (blue/purple), White (white/silver)
- **Intensity control** – adjust flare intensity from 0-100%
- **Size control** – adjust flare size from 0-100%
- **Particle effects** – glowing trails, plasma particles, and flare glow
- **Flare counter** – tracks number of flares erupted
- **Interactive controls** – sliders, buttons, keyboard shortcuts
- **Responsive design** – adapts to different screen sizes

### ☀️ Flare Types

| Type | Colors | Description |
|------|--------|-------------|
| **Classic** | Gold/Orange/Red | Traditional solar flare |
| **Plasma** | Pink/Magenta/Orange | Plasma energy flare |
| **Blue** | Blue/Purple | Cool blue flare |
| **White** | White/Silver | Bright white flare |

### ⌨️ Interaction Options

| Method | Action |
|--------|--------|
| **Click** | Click on display to erupt flare |
| **Buttons** | Erupt, Reset |
| **Keyboard** | `Space` or `E` – Erupt · `R` – Reset |

### ✨ Flare Experience

When erupting:
1. **Flare bursts** – plasma particles explode outward
2. **Intensity applies** – controls particle count and speed
3. **Size applies** – controls flare spread radius
4. **Type applies** – changes particle colors
5. **Counter updates** – flare count increments
6. **Status updates** – shows eruption state

- **HTML5** – semantic structure with Canvas
- **CSS3** – gradients, backdrop-filter, transforms

### 🎨 Design Philosophy

This component embodies **EaseMotion CSS's animation-first philosophy** through:

- **Explosive motion** – particles burst outward with energy
- **Particle effects** – glowing trails and plasma particles
- **Visual feedback** – status updates, counter, controls
- **Stellar atmosphere** – sun glow and space background
- **Human-readable classes** – `.solar-controls`, `.solar-text`

### 🔧 Customization Options

| Property | Location | Default |
|----------|----------|---------|
| Flare types | `flareTypes` array | 4 types |
| Intensity range | `intensitySlider` | 0-100% |
| Size range | `sizeSlider` | 0-100% |
| Particle count | `count` | 30-80 |
| Particle size | `size` | 2-8px |
