# Shimmer-Sweep Progress Bar

A pure HTML and CSS animated Shimmer-Sweep Progress Bar designed for modern Gaming Hub layouts.

## Features

- Pure HTML and CSS
- Animated progress growth
- Continuous shimmer sweep effect
- Responsive design
- Gaming dashboard appearance
- Hover interactions
- Accessible progressbar semantics
- `prefers-reduced-motion` support
- No JavaScript or external libraries
