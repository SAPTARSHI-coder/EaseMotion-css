# CSS Morph-Glow Feature Grid

A responsive feature grid for glassmorphism interfaces with animated
morphing glow shapes and subtle hover interactions.

## Features

- Pure HTML and CSS
- No JavaScript dependencies
- Glassmorphism styling
- Morphing ambient glow animation
- Smooth hover elevation
- Responsive grid layout
- Semantic HTML structure
- `prefers-reduced-motion` support
