# CSS Ripple-Wave Modal for E-Commerce Checkout Layouts

A lightweight, responsive Ripple-Wave Modal designed for e-commerce
checkout interfaces.

This EaseMotion CSS example uses only HTML and CSS. No JavaScript,
framework, or external dependency is required.

## Features

- Pure HTML and CSS
- CSS-only modal interaction
- Ripple-wave expansion animation
- Smooth modal entrance animation
- Animated confirmation icon
- Responsive across desktop, tablet, and mobile
- CSS custom properties for easy customization
- Backdrop blur effect
- Accessible reduced-motion support
- No external libraries or JavaScript
