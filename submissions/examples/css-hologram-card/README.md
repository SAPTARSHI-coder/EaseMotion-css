# CSS Hologram Card

A futuristic holographic card component created using pure CSS.

## Features

- Animated holographic interference pattern
- Rotating gradient effect
- Scanning light animation
- 3D hover interaction
- Responsive design
- Keyboard accessibility


## Technologies

- HTML5
- CSS3


## Use Cases

- Gaming UI
- Portfolio cards
- Futuristic dashboards
- Sci-fi landing pages


## Accessibility

- Semantic article element
- Keyboard focus support
- ARIA label included
