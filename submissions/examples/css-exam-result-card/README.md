# CSS Exam Result Card

A responsive CSS-only exam result card displaying a student's score,
percentage, grade, and pass/fail status.

## Features

- Pure CSS implementation
- Responsive design
- Score and percentage display
- Grade and result status
- Animated performance progress bar
- Accessible progress indicator
- Reduced-motion support
- No JavaScript
- No external dependencies

## Files

- `demo.html` — Standalone demonstration
- `style.css` — Component styles

## How to Use

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
