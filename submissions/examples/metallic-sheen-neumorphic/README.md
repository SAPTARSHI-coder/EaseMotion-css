# Metallic Sheen Neumorphic UI

A pure CSS neumorphic UI component featuring a polished metallic sheen,
soft elevation, smooth interactions, responsive styling, and dark mode
support.

## Features

- Pure HTML and vanilla CSS
- Metallic gradient surface
- Animated light-sheen effect
- Soft neumorphic shadows
- Smooth hover and active states
- Responsive layout
- Dark mode support
- `prefers-reduced-motion` support
- Keyboard-friendly focus states
- No JavaScript
- No external dependencies

## Files

- `demo.html` — standalone demonstration
- `style.css` — component styles

## Usage

Add the component structure to your HTML:

```html
<section class="metal-card">
  <div class="metal-icon">◈</div>

  <p class="eyebrow">NEUMORPHIC UI</p>

  <h1>Metallic Sheen</h1>

  <p class="description">
    A polished neumorphic surface with a subtle metallic highlight.
  </p>

  <div class="actions">
    <button class="metal-button primary">
      Explore
    </button>

    <button class="metal-button secondary">
      Details
    </button>
  </div>
</section>
