# ease-avatar-status-ring

Avatar with an animated rotating gradient ring, useful as a "live" or active-status indicator.

## Usage

```html
<div class="ease-avatar-ring">
  <img src="avatar.jpg" alt="...">
</div>
```

## Notes

- The white `border` on the `img` creates the visual gap between avatar and ring — adjust its color to match your background.
- Swap the `conic-gradient` colors to signal different statuses (e.g. red/orange for "recording").

## Browser support

All modern browsers with `conic-gradient` support.
