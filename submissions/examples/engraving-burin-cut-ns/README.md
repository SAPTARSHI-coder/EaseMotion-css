# Engraving Burin Cut

## What does this do?
Renders a self-contained CSS-only `ease-engraving-burin-cut` demo: Engraving burin cutting a bright metal furrow.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-engraving-burin-cut`. No build step or JavaScript is required for the effect.

```html
<section class="ease-engraving-burin-cut">
  <div class="ease-engraving-burin-cut__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
