# Battery Charge

A phone-style battery whose charge level climbs and blinks at the tip.

## Features
- Fill rises with a segmented striped texture
- Battery cap and body drawn with pure CSS
- Critical-low style flips color below a threshold

## Usage
```html
<div class="bc-battery"><div class="bc-fill"></div></div>
<p class="bc-pct">84%</p>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
