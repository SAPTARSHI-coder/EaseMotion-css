# CSS FLIP Animation Demo

## Overview

A visual demonstration of the First, Last, Invert, Play animation concept using CSS 3D transforms and state transitions.

## Features

- Three interactive FLIP examples
- 3D card perspective
- Front/back transform states
- Keyboard focus support
- Responsive card layout
- Reduced-motion support
- No JavaScript dependency

## Files

- `demo.html` — semantic examples and explanatory content
- `style.css` — perspective, transforms, transitions, responsive rules, and accessibility styling

## Accessibility

Cards are real links so they can receive keyboard focus. Focus states remain visible, and reduced-motion preferences shorten the visual transition.

## Usage

Open `demo.html` directly in a modern browser.
