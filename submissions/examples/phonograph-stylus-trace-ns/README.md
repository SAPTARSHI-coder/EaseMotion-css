# Phonograph Stylus Trace

## What does this do?
Renders a self-contained CSS-only `ease-phonograph-stylus-trace` demo: Phonograph stylus tracing a groove under tonearm sway.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-phonograph-stylus-trace`. No build step or JavaScript is required for the effect.

```html
<section class="ease-phonograph-stylus-trace">
  <div class="ease-phonograph-stylus-trace__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
