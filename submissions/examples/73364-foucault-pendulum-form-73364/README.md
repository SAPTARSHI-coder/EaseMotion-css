# Foucault Pendulum Form

Implementation for EaseMotion issue #73364.

## Features

- Pure HTML and vanilla CSS
- Scientific observatory-inspired interface
- Decorative pendulum dial animation
- Responsive form layout
- Native controls and visible focus
- Reduced-motion fallback

The pendulum is decorative and does not communicate form state. The animation is isolated from the form content so the document remains stable.

Open `demo.html` to preview the component and adjust the brass palette or animation duration in `style.css`.
