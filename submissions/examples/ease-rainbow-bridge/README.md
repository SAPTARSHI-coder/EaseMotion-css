# Rainbow Bridge · Rainbow Arches Across 🌈

An interactive rainbow bridge arching across the canvas with vibrant colors, shimmering effects, and atmospheric glow. Watch the rainbow appear!

## Features

- 🌈 **Rainbow Bridge** – Colorful arching bridge
- 🎚️ **Speed Control** – Adjust animation speed (1-10)
- 🎚️ **Band Control** – Adjust number of bands (5-12)
- ⏸️ **Pause/Resume** – Toggle animation
- 🔄 **Reset** – Reset bridge
- ✨ **Shimmer Effects** – Glowing particles
- 🌟 **Pots of Gold** – End cap effects

## How to Use

1. Click **ARCH** or press **Space** to create the rainbow
2. Click again or press **Space** to reset
3. Adjust **Speed** for animation pace
4. Adjust **Bands** for rainbow complexity
5. Press **RESET** or **R** to reset
6. Press **PAUSE** or **P** to pause/resume animation

## Controls

| Action | Method |
|--------|--------|
| Arch/Reset | Arch button / Space / Click canvas |
| Reset | Reset button / R key |
| Pause/Resume | Pause button / P key |

## Technical Details

- **Rainbow:** Arc-based with multiple bands
- **Animation:** Smooth arch progress
- **Shimmer:** Particle system with glow
- **Performance:** 60fps with requestAnimationFrame

## Customization

You can easily customize:
- **Speed:** Adjust slider range (1-10)
- **Bands:** Adjust slider range (5-12)
- **Colors:** Modify rainbow palette
- **Arc:** Adjust arch radius
- **Glow:** Modify glow intensity
