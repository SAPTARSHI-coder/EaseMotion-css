# Slide-Up Drawer

A modern **CSS-only Slide-Up Drawer** for gaming dashboards and application layouts. The drawer smoothly slides up from the bottom of the screen, creating a clean and immersive navigation experience using only HTML and CSS.

---

## 📂 Folder Structure

```
slide-up-drawer/
│── demo.html
│── style.css
└── README.md
```

## ✨ Features

- 🎮 Gaming Hub inspired interface
- ⬆️ Smooth Slide-Up drawer animation
- 💯 Pure HTML & CSS
- 🚫 No JavaScript required
- 📱 Fully responsive design
- ♿ Supports `prefers-reduced-motion`
- 🎨 CSS Custom Properties
- ⚡ Lightweight and easy to customize
- 🌈 Modern gradient styling
- 📦 Easy integration into existing projects

## ♿ Accessibility

Supports:

```css
@media (prefers-reduced-motion: reduce)
```

to disable animations for users who prefer reduced motion.

## 🎯 Animation Overview

The drawer animation combines:

- Bottom Slide-Up Transition
- Opacity Fade
- Cubic-Bezier Easing
- Smooth Hover Effects
- Floating Hero Illustration

This creates a modern bottom-sheet style navigation suitable for gaming dashboards and application layouts.
