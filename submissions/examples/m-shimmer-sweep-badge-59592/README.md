# CSS Shimmer-Sweep Badge for SaaS Showcase Layouts

A modern **Shimmer-Sweep Badge** component built using pure HTML and CSS. The badges feature an elegant shimmer animation that sweeps across each badge on hover, making them ideal for SaaS dashboards, feature highlights, and product showcases.

## ✨ Features

- Pure HTML5 & CSS3
- Shimmer sweep hover animation
- Responsive SaaS card layout
- Smooth CSS transitions
- CSS Custom Properties
- `prefers-reduced-motion` support
- No JavaScript required
