# CSS Slide-Up Tooltip for Product Catalog Layouts

A modern **Slide-Up Tooltip** built using pure HTML5 and CSS3 for product catalog layouts. The component provides interactive product tooltips with smooth slide-up animations, responsive glassmorphism cards, and accessibility support.

## Features

* Pure HTML5 & CSS3
* Slide-Up tooltip animation
* Hover-triggered product information
* Glassmorphism product cards
* Smooth CSS transitions & keyframe animations
* Responsive desktop, tablet, and mobile layout
* CSS Custom Properties
* No JavaScript required
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over the action button to display the tooltip.
3. Customize colors, spacing, and animations using the CSS variables in `:root`.
4. Integrate the component into any product catalog or e-commerce layout.
