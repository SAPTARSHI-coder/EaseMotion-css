# CSS Rotate-Fade Accordion for SaaS Showcase Layouts

A modern **Rotate-Fade Accordion** component built using pure HTML5 and CSS3 for SaaS showcase layouts. This component provides smooth 3D rotation entrance animations, expandable content sections, glassmorphism styling, and responsive behavior.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* CSS-only accordion interaction
* Smooth rotate-fade entrance animation
* 3D rotation content reveal effect
* SaaS FAQ / knowledge hub layout
* Expandable information sections
* Animated accordion icons
* Glassmorphism card design
* Smooth hover interactions
* Responsive desktop, tablet, and mobile layouts
* CSS Custom Properties for easy customization
* Lightweight keyframe animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Click accordion headers to expand or collapse sections.
3. Customize colors, shadows, spacing, and animations using CSS variables inside `:root`.

## CSS Custom Properties

```css
:root{
  --bg:#eef4ff;
  --surface:rgba(255,255,255,.92);
  --primary:#2563eb;
  --secondary:#06b6d4;
  --accent:#8b5cf6;
  --text:#111827;
  --muted:#64748b;
  --shadow:0 25px 60px rgba(37,99,235,.18);
  --radius:26px;
}
```
