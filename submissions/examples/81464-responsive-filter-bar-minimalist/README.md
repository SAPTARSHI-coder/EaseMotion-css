# Responsive Filter Bar — Minimalist

A clean and responsive filter bar component designed around a
minimalist visual language.

Built for EaseMotion CSS issue #81464.

## Features

- Minimalist visual design
- Responsive filter controls
- Search input
- Category filter chips
- Active filter state
- Sorting dropdown
- Clear filters action
- Subtle hover transitions
- Focus-visible accessibility states
- Responsive component layout
- `prefers-reduced-motion` support
- Zero JavaScript dependencies

Include `style.css` and use the markup from `demo.html`.

  ...
