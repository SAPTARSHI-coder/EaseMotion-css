# Chip Tag Component

Add ease-chip-tag-component-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|---------|
| `--ctc-accent` | `#6366f1` |
| `--ctc-red` | `#ef4444` |
| `--ctc-green` | `#10b981` |
| `--ctc-yellow` | `#f59e0b` |
| `--ctc-radius` | `20px` |

## Technique

`display: inline-flex` + `gap` for chip layout. Hover lifts with `translateY`.
