# Interactive Pagination with Dark Mode

A modern, responsive pagination component built using pure HTML and CSS.

## ✨ Features

- Responsive design
- Modern dark mode styling
- Interactive hover effects
- Active page state
- Previous and next navigation buttons
- Keyboard focus support
- Mobile-friendly layout
- No JavaScript or external dependencies

## 🛠️ Technologies

- HTML5
- CSS3
