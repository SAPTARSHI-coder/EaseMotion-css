# CSS Icon Morph Button

A CSS-only animated button that smoothly morphs one icon into another when the user hovers over or focuses the button.

## Features

- Pure HTML and CSS
- No JavaScript required
- Smooth icon morph animation
- Works with mouse hover
- Works with keyboard focus
- Responsive layout
- Accessible button markup
- Visible keyboard focus state
- Supports `prefers-reduced-motion`

## Demo

Open `demo.html` in a modern browser.

Hover over the **Add Item** button or use the `Tab` key to focus it.

The plus icon smoothly transforms into a check mark.
