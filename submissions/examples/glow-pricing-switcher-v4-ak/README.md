# glow-pricing-switcher-v4-ak

Pure CSS animated pricing plan switcher toggle — no JavaScript required.

## How to use

```html
<div class="ease-pricing-switcher-v4">
  <input type="radio" name="p" id="m" checked />
  <label for="m" class="ease-pricing-option-label-v4">Monthly</label>
  <input type="radio" name="p" id="y" />
  <label for="y" class="ease-pricing-option-label-v4">Annual</label>
  <span class="ease-pricing-switcher-glider-v4"></span>
</div>
