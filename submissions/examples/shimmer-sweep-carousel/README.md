# CSS Shimmer Sweep Carousel

A responsive gaming carousel with a smooth shimmer sweep hover animation using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Responsive layout
- Shimmer sweep hover effect
- CSS Custom Properties
- No JavaScript
- Accessible with `prefers-reduced-motion`

## Files

```
demo.html
style.css
README.md
```

## Usage

```html
<link rel="stylesheet" href="style.css">
```

Use the following structure:

```html
<div class="carousel">
    <div class="card">
        <img src="image.jpg" alt="">
        <h3>Game Title</h3>
    </div>
</div>
```

## Custom Properties

```css
--bg
--card
--text
--radius
--speed
```
