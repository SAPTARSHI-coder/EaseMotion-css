# Blur-Entrance Carousel for Minimalist Tech Layouts

A modern pure CSS carousel component created for EaseMotion CSS.

This component showcases a smooth blur entrance animation with a minimalist technology-inspired glass UI design.

## ✨ Features

- Pure HTML + CSS implementation
- Blur entrance animation effect
- Glassmorphism card styling
- Smooth hover interactions
- Responsive layout
- No JavaScript dependency
- Accessible reduced motion support
