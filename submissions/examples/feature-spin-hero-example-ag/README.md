
# Spin Hero (Error State)

A simple hero section demonstrating a smooth spin animation when hovered.

## Features

- Smooth 360° spin effect
- Responsive layout
- Semantic HTML
- Accessible structure
- Supports `prefers-reduced-motion`
- Lightweight and beginner-friendly

## Files

```
feature-spin-hero-example-ag/
├── demo.html
├── style.css
└── README.md
```

## Usage

Open `demo.html` in your browser and hover over the hero card to see the spin animation.

## Accessibility

- Semantic HTML structure
- `aria-label` on the hero section
- Decorative icon marked with `aria-hidden`
- Motion disabled when users prefer reduced motion

## Use Cases

- Error pages
- Empty states
- Status pages
- Interactive UI examples
