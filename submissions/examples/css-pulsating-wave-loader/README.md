# Pulsating Wave Loader

A smooth and responsive CSS-only loading animation featuring a
pulsating wave effect.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript or external dependencies
- Smooth staggered wave animation
- Responsive design
- Light and dark mode support
- Accessible loading status
- `prefers-reduced-motion` support
- Hardware-friendly CSS transforms
- Mobile-friendly layout
