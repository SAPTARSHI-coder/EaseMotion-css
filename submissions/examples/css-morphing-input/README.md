# CSS Morphing Input

An animated input field that smoothly changes shape using pure CSS.

## Features

- Pure CSS implementation
- Smooth shape morphing animation
- Focus based transformation
- Gradient glow effect
- Responsive design
- No JavaScript dependency


## Technologies

- HTML5
- CSS3


## Use Cases

- Search bars
- Login forms
- Modern dashboards
- Creative UI designs


## Accessibility

- Proper label using aria-label
- Keyboard accessible input
- Semantic HTML
