# Liquid Wave Waveform Audio Visualizer Bar Component

## Overview

A modern glassmorphic audio waveform visualizer component
built using pure HTML, CSS and JavaScript.

It creates animated liquid wave bars with a premium
glass UI appearance.

## Features

- 🌊 Animated waveform visualization
- 🪟 Glassmorphism card design
- ✨ Gradient neon wave bars
- ▶ Play/Pause interaction
- 📱 Responsive mobile-first layout
- 🎨 Modern blur effects
- ♿ Reduced motion accessibility support
- ⚡ No external dependencies

## Usage

Open `demo.html` in any modern browser.

Customize:
- Wave colors from CSS variables
- Animation speed
- Number of waveform bars
