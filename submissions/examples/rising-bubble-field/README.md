# Rising Bubble Ambient Field

A lightweight CSS ambient background made using animated floating bubbles.

## Features

- Pure HTML & CSS
- No JavaScript
- Responsive layout
- Glass-like translucent bubbles
- Multiple bubble sizes
- Blur depth layers
- Lightweight animation
- Accessible reduced motion support
- Battery saver (`prefers-reduced-data`) optimization

## Folder Structure

```
rising-bubble-field/
├── demo.html
├── style.css
└── README.md
```

## Accessibility

Supports:

- `prefers-reduced-motion`
- `prefers-reduced-data`

## Preview

Open `demo.html` in any modern browser.
