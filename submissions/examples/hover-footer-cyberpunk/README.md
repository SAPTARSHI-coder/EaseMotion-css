# Cyberpunk Hover Footer

A responsive footer component built with pure HTML and CSS, featuring a futuristic cyberpunk aesthetic with neon hover effects.

## ✨ Features

* Responsive design
* Cyberpunk-inspired UI
* Neon hover effects
* Animated system status indicator
* Glitch-style branding
* CSS-only animations
* Mobile-friendly layout
* No JavaScript or external dependencies

## 🛠️ Technologies

* HTML5
* CSS3
* CSS Flexbox
* CSS Grid
* CSS Animations
* Media Queries

## 📁 Files

```text
hover-footer-cyberpunk/
├── index.html
├── style.css
└── README.md
```

## 🚀 Usage

1. Open `index.html` in a browser.
2. Hover over the navigation links.
3. Resize the browser window to test the responsive layout.

## 🎨 Design

The component uses a dark futuristic interface with cyan and pink neon accents. Navigation items animate on hover with glowing text, an indicator arrow, and an animated underline.

## 📱 Responsive Behavior

The footer automatically adapts to smaller screens. On mobile devices, the footer sections stack vertically and navigation links wrap to fit the available width.
