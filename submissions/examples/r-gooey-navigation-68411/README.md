# CSS Gooey Navigation

A pure CSS navigation component featuring a fluid gooey highlight that moves between navigation items.

## Features

- Pure HTML and CSS
- Animated gooey navigation blob
- Hover and keyboard focus interactions
- Responsive desktop and mobile layouts
- CSS `:has()` based interaction
- Customizable colors and animation timing
- Semantic navigation markup
- Visible keyboard focus state
- `prefers-reduced-motion` support
- No JavaScript required
