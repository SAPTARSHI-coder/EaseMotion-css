# Custom Morphing Cursor Pointer Trail Effect for Portfolios

A modern portfolio component featuring a custom morphing cursor with smooth trailing animation and a high-contrast accessible design.

## Features

- Custom morphing cursor
- Smooth pointer trail
- Cursor morphs over buttons, links, and cards
- Click ripple animation
- High-contrast accessibility theme
- Responsive portfolio layout
- Pure HTML, CSS and Vanilla JavaScript

## Folder Structure

```
ease-layout-custom-morphing-cursor-pointer-trail-effect-for-portfolios-271/
├── demo.html
├── style.css
├── script.js
└── README.md
```

## Usage

1. Open `demo.html` in a browser.
2. Move the cursor to experience the morphing effect.
3. Hover over cards, buttons, and links.
4. Customize colors using CSS variables.
