# CSS Expanding Textarea

A demo project showcasing an **auto-expanding textarea** using HTML, CSS, and JavaScript.

## Features
- Textarea grows automatically as you type more lines.
- Smooth resizing with no scrollbars.
- Styled with focus effects for better UX.
- Responsive and clean design.

## Files
- `demo.html` → Structure and JavaScript logic for auto-expansion.
- `style.css` → Styling for the container, textarea, and focus effects.
- `README.md` → Documentation and usage instructions.

## Usage
1. Open `demo.html` in your browser.
2. Start typing into the textarea.
3. The textarea will expand vertically to fit the content.

## Customization Ideas
- Adjust `max-height` in CSS to limit expansion.
- Add animations for smoother height transitions.
- Use different border colors for validation states (success/error).
- Integrate with forms for comments, notes, or chat inputs.
