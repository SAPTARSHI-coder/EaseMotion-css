# CSS Sleep Tracker Arc

A CSS-only sleep tracking visualization featuring an animated circular
sleep arc with deep sleep, light sleep and awake segments.

## Features

- Pure HTML and CSS
- No JavaScript
- Responsive layout
- Animated sleep arc
- Deep sleep visualization
- Light sleep visualization
- Awake segment
- Sleep quality indicator
- Glassmorphism card design
- Hover interactions
- CSS-only animations
- Reduced-motion accessibility support
- Semantic HTML structure
- ARIA labels for visualization and progress information
