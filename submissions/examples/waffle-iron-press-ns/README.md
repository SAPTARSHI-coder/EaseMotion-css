# Waffle Iron Press

## What does this do?
Renders a self-contained CSS-only `ease-waffle-iron-press` demo: Waffle iron lid pressing closed with grid imprint reveal.

## How is it used?
Open `demo.html` in a browser. The animated face uses classes like `ease-waffle-iron-press`, `ease-waffle-iron-press__arm`, and `ease-waffle-iron-press__core`. No build step or JavaScript is required for the motion.

```html
<section class="ease-waffle-iron-press">
  <div class="ease-waffle-iron-press__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
