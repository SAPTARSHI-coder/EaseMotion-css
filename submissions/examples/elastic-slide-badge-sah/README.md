# Elastic-Slide Creative Portfolio Badge (`#54577`)

## What does this do?
Creates a sleek dual-state profile qualification badge that elastically slides out hidden accomplishment metrics across an animated spring track when hovered.

## How is it used?
Configure primary and sliding text spans inside an `ease-badge-elastic` component wrapper:
```html
<div class="ease-badge-elastic blue">
  <span class="front">Title</span>
  <span class="slide">Details</span>
</div>
```

## Why is it useful?
Solves issue #54577 by enriching creative portfolio resumes and developer profiles with compact, interactive storytelling widgets.
