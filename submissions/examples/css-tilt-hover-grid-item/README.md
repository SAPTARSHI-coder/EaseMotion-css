# CSS Tilt Hover Grid Item

A modern grid layout featuring cards that tilt in 3D perspective on hover while casting dynamic shadows.

## Features

- Pure CSS implementation
- 3D tilt hover effect
- Dynamic shadow depth
- Responsive grid layout
- Smooth transitions
- No JavaScript required

## Usage

```html
<div class="grid">
  <div class="card">
    <h3>Title</h3>
    <p>Description</p>
  </div>
</div>
```

## Files

- `demo.html` – Demo page
- `style.css` – Styling and animations

## Why it fits EaseMotion CSS

This component showcases advanced hover interactions and depth effects using modern CSS transforms. It provides developers with a reusable interactive card pattern that enhances visual engagement while remaining lightweight and dependency-free.
