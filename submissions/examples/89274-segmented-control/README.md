# Animated Segmented Control Component

A multi-option tabbed switch component featuring smooth active indicator highlight transitions.

## Features
- **Pill Highlight Transitions:** Smooth background gradient transitions for selected options.
- **Micro-Interactions:** Subtle background hover feedback for non-selected options.
- **Zero Dependencies:** Pure CSS implementation with no external scripts.

## File Structure
- `demo.html` - Segmented container and button layout.
- `style.css` - Component wrapper styling and active state gradient highlights.
