# 🖋️ Calligraphy – Elegant Script Writes Itself

> An interactive calligraphy component where elegant script writes itself with 4 styles (Elegant, Flourish, Bold, Italic) and adjustable speed.

---

## 📖 Description

The **Calligraphy** component creates a beautiful calligraphy experience where elegant script writes itself on the canvas. Built with vanilla HTML, CSS, and JavaScript, it features 4 calligraphy styles, adjustable speed (1-10), and organic stroke rendering.

### 🎯 Core Features

- **Self-writing script** – elegant calligraphy writes itself on the canvas
- **4 styles** – Elegant (classic), Flourish (ornate), Bold (thick), Italic (slanted)
- **Speed control** – adjust writing speed from 1-10
- **Random phrases** – 12 elegant calligraphy phrases
- **Character counter** – tracks total characters written
- **Organic strokes** – varying thickness and pressure
- **Interactive controls** – style buttons, speed slider, keyboard shortcuts
- **Responsive design** – adapts to different screen sizes

### ⌨️ Interaction Options

| Method | Action |
|--------|--------|
| **Click** | Click on display to write |
| **Buttons** | Write, Clear |
| **Keyboard** | `Space` or `W` – Write · `C` – Clear |

### ✨ Calligraphy Experience

When writing:
1. **Script appears** – elegant lines write themselves
2. **Style applies** – selected style affects stroke character
3. **Speed applies** – controls writing pace
4. **Organic strokes** – varying thickness and pressure
5. **Counter updates** – character count increments
6. **Status updates** – shows writing state

### 🛠️ Technologies Used

- **HTML5** – semantic structure with Canvas
- **CSS3** – gradients, backdrop-filter, transforms
- **JavaScript (ES6)** – Canvas API, requestAnimationFrame, animation system

### 🎨 Design Philosophy

This component embodies **EaseMotion CSS's animation-first philosophy** through:

- **Self-writing animation** – script reveals itself elegantly
- **Organic strokes** – varying thickness and pressure
- **Style variety** – 4 distinct calligraphic styles
- **Visual feedback** – status updates, counter, controls
- **Artistic atmosphere** – elegant script and paper texture
- **Human-readable classes** – `.calligraphy-controls`, `.style-btn`, `.calligraphy-text`

### 🔧 Customization Options

| Property | Location | Default |
|----------|----------|---------|
| Styles | `.style-btn` elements | 4 styles |
| Speed range | `speedSlider` | 1-10 |
| Phrases | `sampleTexts` array | 12 phrases |
| Stroke size | `size` variable | Font size × 0.6 |
| Animation steps | `steps` calculation | 10-100 steps |
