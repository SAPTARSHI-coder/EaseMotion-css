# Fade-In Tabs (Fintech Dashboard)

## What does this do?

A modern fintech dashboard tab component featuring smooth fade-in animations for active navigation tabs. Built entirely with HTML and CSS for lightweight dashboard interfaces.

---

## Features

- Fade-in animation for the active tab
- Smooth opacity transitions
- Glassmorphism dashboard design
- Responsive layout
- Fintech-inspired color palette
- Financial overview cards
- Pure HTML & CSS (No JavaScript)
- Supports `prefers-reduced-motion`

---

- `demo.html` — Component showcase
