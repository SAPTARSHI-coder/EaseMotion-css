# CSS Bounce-Pulse Dropdown for Fintech Dashboard Layouts

A modern fintech dashboard dropdown component featuring smooth bounce-pulse animations, glassmorphism styling, and interactive menu cards built completely with HTML and CSS.

This component provides an animated financial dashboard navigation experience without JavaScript or external dependencies.

## ✨ Features

- 🔽 Modern fintech dropdown interface
- 💫 Smooth bounce-pulse entrance animation
- 💳 Dashboard account overview design
- ✨ Glassmorphism UI styling
- 📊 Financial menu cards
- 🎨 Gradient glow effects
- ⚡ Pure HTML and CSS implementation
- 📱 Fully responsive layout
- 🔄 CSS keyframe animations and transitions
- ♿ Accessibility support with `prefers-reduced-motion`

## 🚀 Usage

1. Clone the EaseMotion CSS repository.

2. Navigate to:


submissions/examples/ease-css-bounce-pulse-dropdown-fintech-dashboard-layouts/


3. Open `demo.html` in your browser.

No JavaScript, frameworks, or external libraries are required.

## 🎨 CSS Custom Properties

The component uses CSS variables for easy customization:

```css
:root {
    --bg:#050816;
    --primary:#00f5ff;
    --secondary:#8b5cf6;
    --green:#22c55e;
    --text:#f8fafc;
    --muted:#94a3b8;
}

Update these variables to match your fintech dashboard branding.
