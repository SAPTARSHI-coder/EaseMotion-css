This contribution adds a Blur on hover to the submissions/examples/_blur-on-hover directory.

Included File:
1. demo.html
2. style.css
3. README.md

Features
🔍 Blur-on-hover interaction
🎯 Hovered card stays perfectly sharp
🌫️ Non-hovered cards become blurred
🔎 Hovered card slightly enlarges
✨ Smooth transitions
🎨 Clean modern dark UI
⚡ Pure HTML + CSS
🚫 No JavaScript
📱 Easy to adapt for responsive layouts
Great for team cards, portfolios, product cards, galleries, and navigation menus.
