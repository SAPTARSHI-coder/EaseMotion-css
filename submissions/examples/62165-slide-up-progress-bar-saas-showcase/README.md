# CSS Slide-Up Progress Bar for SaaS Showcase Layouts

A modern **Slide-Up Progress Bar** built using pure HTML5 and CSS3 for SaaS showcase layouts. This component creates an animated progress dashboard with smooth upward motion, gradient progress indicators, percentage badges, and responsive glassmorphism styling.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Smooth slide-up progress animation
* SaaS performance tracking interface
* Animated progress fill bars
* Floating percentage badges
* Gradient progress indicators
* Glassmorphism dashboard card
* Launch readiness status indicator
* Responsive desktop, tablet, and mobile layouts
* CSS Custom Properties for easy customization
* Smooth transitions and keyframe animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. View the animated SaaS progress dashboard.
3. Customize colors, shadows, spacing, and animation timing using CSS variables inside `:root`.

## CSS Custom Properties

```css
:root{
  --bg:#eef4ff;
  --surface:rgba(255,255,255,.92);
  --primary:#2563eb;
  --secondary:#06b6d4;
  --accent:#8b5cf6;
  --success:#22c55e;
  --text:#111827;
  --muted:#64748b;
  --shadow:0 20px 55px rgba(37,99,235,.18);
  --radius:28px;
}
```
