# infinite-orbit-ak

Pure CSS animated orbiting satellites surrounding a central core — no JavaScript required.

## How to use

```html
<div class="ease-orbit-system">
  <div class="ease-orbit-core">⚛️</div>

  <div class="ease-orbit-ring">
    <div class="ease-orbit-item"><span>🚀</span></div>
    <div class="ease-orbit-item"><span>🎨</span></div>
    <div class="ease-orbit-item"><span>⚡</span></div>
    <div class="ease-orbit-item"><span>🔮</span></div>
  </div>
</div>
