# CSS Time Block Scheduler

A responsive time block scheduler built entirely with CSS. It provides a clean daily planning layout with visually distinct schedule blocks for organizing tasks and activities.

## Features

- Pure CSS implementation
- Responsive scheduler layout
- Color-coded activity blocks
- Hover and focus animations
- Keyboard accessible
- Mobile-friendly design
- No JavaScript required

## Usage

```html
<div class="time-row">
  <div class="time">09:00</div>
  <div class="block focus">Deep Work Session</div>
</div>
```

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

## Available Classes

- `.work`
- `.focus`
- `.break`
- `.personal`
- `.study`
