# CSS Morph-Glow Stepper

A pure CSS, lightweight, and modern morph-glow stepper designed for product catalog layouts and checkout flows.

## Features
- Pure CSS and HTML (No JS frameworks needed)
- Smooth keyframe animations with morphing border radius and glow effects
- Responsive design for mobile, tablet, and desktop
- Modern aesthetics tailored for EaseMotion design standards

## Usage

Simply open `demo.html` in your browser to view the component.
The layout relies on standard Flexbox and CSS Custom Properties for easy theming.

## Files
- `demo.html`: The HTML structure for the stepper component.
- `style.css`: The styling and keyframe animations for the morph-glow effect.
