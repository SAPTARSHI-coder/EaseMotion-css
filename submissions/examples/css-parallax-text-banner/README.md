# CSS Parallax Text Banner

A responsive text banner that creates a layered parallax scrolling effect
using modern CSS features without JavaScript.

## Issue

This contribution addresses:

**Issue #68403 - [FEATURE] CSS Parallax Text Banner**

## Features

- Pure CSS implementation
- No JavaScript required
- Scroll-driven animation
- Text and background move at different rates
- Responsive design
- Decorative animated layers
- Accessible semantic structure
- Reduced-motion support
- No external libraries
