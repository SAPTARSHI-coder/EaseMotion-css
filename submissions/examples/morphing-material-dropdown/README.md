# Morphing Material Dropdown

A responsive Material Design inspired dropdown component with a smooth morphing animation, interactive menu items, and subtle elevation effects.

## ✨ Features

- Smooth morphing dropdown animation
- Material Design inspired styling
- Interactive hover states
- Animated dropdown arrow
- Smooth menu item transitions
- Responsive on mobile and desktop
- Reduced-motion support
- Pure HTML and CSS
- No JavaScript or external libraries

## 🛠️ Technologies

- HTML5
- CSS3

## 📁 Folder Structure

```text
morphing-material-dropdown/
├── index.html
├── style.css
└── README.md
````

## 🚀 Usage

Open `index.html` in any modern browser.

Hover over the dropdown to reveal the available options.

## 🎨 Customization

You can customize:

* Dropdown width
* Border radius
* Colors
* Shadow
* Animation duration
* Menu items
* Hover effects

## 📱 Responsive Design

The component adapts to different screen sizes using responsive CSS and a mobile breakpoint.

## ♿ Accessibility

The dropdown uses a semantic `<button>` for the control and respects the user's `prefers-reduced-motion` setting.
