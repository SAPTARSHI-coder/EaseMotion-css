# CSS Scale-Hover Badge for Accessible Web Layouts

A modern **Scale-Hover Badge** component built completely with **HTML5 and CSS3**. This showcase demonstrates animated badges with smooth scaling effects, glowing hover interactions, gradient styling, responsive layouts, and accessibility support without requiring JavaScript.

---

## ✨ Features

- 🔍 Smooth scale-hover animation
- 🌈 Gradient badge styling
- ✨ Glow pulse effects
- 💎 Glassmorphism card layout
- ⚡ Smooth CSS transitions
- 🎯 CSS Custom Properties
- 📱 Fully responsive design
- 🧩 Pure HTML5 & CSS3
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

## 🚀 Getting Started

1. Open `demo.html` in any modern browser.
2. Hover over the badges to see scale animations.
3. Customize colors, spacing, and animation timing using CSS variables.
