# Infinity Figure-8 Path Loader

## What does this do?

A lemniscate/infinity-orbit loader using offset-path and offset-distance, with dual orbs and a soft trail.

## How is it used?

```html
<div class="infinity" role="status" aria-label="Loading">
  <span class="infinity__orb infinity__orb--a"></span>
  <span class="infinity__orb infinity__orb--b"></span>
</div>
```

Open `demo.html` in a browser to try it.

## Why is it useful?

Path-based loaders expand the catalog beyond border spinners and demonstrate modern CSS motion primitives.
