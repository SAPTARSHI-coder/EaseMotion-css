# CSS Mesh Gradient: Morphing Shape

## Overview

An organic mesh-gradient variation using animated border radii, transforms, blur, and layered color fields.

## Features

- Morphing organic shapes
- Independent animation layers
- Dark-mode-friendly palette
- Responsive composition
- Keyboard-visible focus state
- Reduced-motion support
- Pure HTML and Vanilla CSS

## Files

- `demo.html` — semantic demonstration
- `style.css` — mesh styling and animation
- `README.md` — implementation notes

## Accessibility

The visual layers are decorative and excluded from the accessibility tree. The page link remains keyboard accessible and reduced-motion preferences disable decorative motion.
