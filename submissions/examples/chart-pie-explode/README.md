# Chart Pie Explode

Pie wedges slide out from centre and settle back in a loop.

## Features
- Wedge explode offset
- Multi-colour segments
- Rotating assembly
- Pure CSS

## Usage
```html
<div class="cpe-wedge" style="--r:0deg;--c:#ff7a7a"></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
