# 3D Sidebar

Gradient 3D sidebar navigation showcase for issue #78585.

## Files

- `demo.html` — semantic navigation structure.
- `style.css` — depth, gradient surfaces, and responsive layout.

## Features

- Layered 3D visual treatment.
- Semantic navigation.
- Hover and focus states.
- Collapsed mobile presentation.
- Reduced-motion fallback.

The example uses CSS transforms and shadows only, with no JavaScript dependency.
