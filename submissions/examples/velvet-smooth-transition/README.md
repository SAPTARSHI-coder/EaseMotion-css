# Velvet Smooth Transition

A smooth and accessible pure CSS media UI featuring a soft "velvet" visual style and fluid transitions.

## Features

- Pure HTML and Vanilla CSS
- Smooth hover and focus transitions
- Dark-mode friendly design
- Hardware-friendly transforms
- Responsive layout
- `prefers-reduced-motion` support
- No external JavaScript or dependencies
