# Responsive Card — Retro

A responsive retro-inspired card component with layered depth,
pixel-style decorative details, and interactive CSS states.

Implemented for issue #79695.

## Features

- Retro arcade-inspired styling
- Responsive card layout
- Pixel-style visual section
- Layered hard shadows
- Hover depth effect
- Animated progress bar
- Interactive CTA
- CSS-only implementation
- No JavaScript
- No external dependencies
- Reduced-motion support
