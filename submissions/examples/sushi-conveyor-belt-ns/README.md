# Sushi Conveyor Belt

## What does this do?
Renders a self-contained CSS-only `ease-sushi-conveyor-belt` demo: Sushi plates gliding along a continuous conveyor belt loop.

## How is it used?
Open `demo.html` in a browser. The animated face uses classes like `ease-sushi-conveyor-belt`, `ease-sushi-conveyor-belt__arm`, and `ease-sushi-conveyor-belt__core`. No build step or JavaScript is required for the motion.

```html
<section class="ease-sushi-conveyor-belt">
  <div class="ease-sushi-conveyor-belt__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
