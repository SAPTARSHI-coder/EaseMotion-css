# CSS App Download Footer

A lightweight, responsive, pure-CSS footer component containing App Store and Google Play badges with smooth motion micro-interactions.

## Features

- **Zero JavaScript:** Built entirely with pure CSS and HTML.
- **Fully Responsive:** Adapts seamlessly from mobile stacked views to desktop row layouts.
- **Accessible (a11y):** Built with semantic HTML, SVG icon hiding (`aria-hidden`), screen reader labels (`aria-label`), and customized `:focus-visible` states for keyboard navigation.
- **EaseMotion Micro-Interactions:** Includes smooth hover elevation and active press feedback.
