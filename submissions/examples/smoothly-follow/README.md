\# 🌀 Smoothly Follow



An interactive component where a glowing element smoothly follows your cursor with fluid, organic motion, leaving a luminous trail of particles.



\## Features

\- \*\*Adjustable Speed\*\* (1–20x)

\- \*\*Element Size\*\* (30–120px)

\- \*\*Trail Length\*\* (0–30)

\- \*\*Color Control\*\* (Hue 0–360°)

\- \*\*Controls\*\*: Pause, Reset, Toggle Trail

\- \*\*Keyboard Shortcuts\*\*: Space (Pause), R (Reset), T (Toggle Trail)



\## How to Use

Open `demo.html` in any modern browser. Move your mouse or finger (on touch devices) to see the magic.



\## Technologies

Pure HTML, CSS (with CSS Variables), and JavaScript.
