# Basic Caption Text

## What it does

This submission creates a simple CSS-only caption text utility for small supporting text shown below charts, images, cards, media blocks, and content sections.

## How to use it

Apply the class directly to a caption paragraph:

```html
<p class="basic-caption-text">This chart shows the weekly growth trend.</p>
```

## Why it fits EaseMotion CSS

It fits EaseMotion CSS because it is human-readable, composable, and useful across many interfaces. It works well in cards, content sections, media blocks, and lightweight documentation layouts.

## Included features

- Small caption text utility
- Practical chart and media examples
- Readable muted supporting copy
- Responsive demo layout
- Pure HTML and CSS implementation
