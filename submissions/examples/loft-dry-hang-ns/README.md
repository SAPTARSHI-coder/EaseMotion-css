# Loft Dry Hang

## What does this do?
Renders a self-contained CSS-only `ease-loft-dry-hang` demo: Loft drying hanging spurs of paper.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-loft-dry-hang`. No build step or JavaScript is required for the effect.

```html
<section class="ease-loft-dry-hang">
  <div class="ease-loft-dry-hang__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
