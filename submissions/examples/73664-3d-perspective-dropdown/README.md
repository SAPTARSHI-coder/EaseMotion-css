# CSS Dropdown: 3D Perspective Tilt

A pure CSS dropdown featuring a layered **3D Perspective Tilt**
visual treatment with smooth depth transitions.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript
- Native `<details>` and `<summary>` interaction
- 3D perspective transformations
- Smooth dropdown reveal animation
- Subtle hover tilt effects
- Responsive design
- Light and dark mode support
- Keyboard-friendly interaction
- Visible focus states
- Reduced-motion support
- Hardware-friendly CSS transforms
