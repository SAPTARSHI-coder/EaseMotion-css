# Cookie Consent Bar Component

Add ease-cookie-consent-bar-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|---------|
| `--ccb2-accent` | `#6366f1` |
| `--ccb2-radius` | `12px` |
| `--ccb2-shadow` | `0 -4px 24px rgba(0,0,0,.3)` |

## Note

`position: fixed; bottom: 0` pins the bar to the bottom of the viewport. Pure CSS styling.
