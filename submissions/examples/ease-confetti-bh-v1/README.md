# ease-confetti-bh

Pure CSS confetti burst animation on click.

## What does this do?
Creates a celebratory confetti burst effect when triggered, perfect for success states and celebrations.

## How is it used?
```html
<button class="ease-confetti-trigger-bh">
  <span class="ease-confetti-bh"></span>
  Click Me
</button>
```

## Why is it useful?
Adds celebratory feedback for user actions like form submissions, achievements, or successful completions.
