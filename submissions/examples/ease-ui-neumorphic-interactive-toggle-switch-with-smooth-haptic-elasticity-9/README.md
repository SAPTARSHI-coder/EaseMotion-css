# Neumorphic Interactive Toggle Switch with Smooth Haptic Elasticity 9

### Dark Mode Variant

A modern dark-mode neumorphic toggle switch built using pure HTML and CSS. It features soft shadows, smooth haptic-inspired elastic animations, responsive behavior, and accessibility-friendly interactions.

---

## ✨ Features

- Dark mode neumorphic design
- Smooth elastic toggle animation
- Haptic-inspired motion effect
- Responsive layout
- Soft neumorphic shadows
- Modern CSS variables
- Keyboard accessible
- Reduced motion support
- Pure HTML & CSS implementation

## 🚀 Usage

1. Open the component folder.
2. Ensure `demo.html` and `style.css` are in the same directory.
3. Open `demo.html` in any modern browser.

No installation or external libraries are required.
