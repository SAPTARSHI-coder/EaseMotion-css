# Siphon Recorder Pen

## What does this do?
Renders a self-contained CSS-only `ease-siphon-recorder-pen` demo: Siphon recorder pen tracing the cable signal.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-siphon-recorder-pen`. No build step or JavaScript is required for the effect.

```html
<section class="ease-siphon-recorder-pen">
  <div class="ease-siphon-recorder-pen__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
