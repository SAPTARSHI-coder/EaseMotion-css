# Floating Vertical Timeline — Material Design

A pure CSS floating vertical timeline inspired by Material Design principles such as elevated surfaces, rounded containers, clear hierarchy, meaningful color, and subtle motion.

## Features

- Material-inspired visual design
- Floating timeline cards
- Elevation-based hover states
- Circular numbered timeline markers
- Completed, current, and upcoming states
- Progress indicator
- Responsive desktop, tablet, and mobile layouts
- Smooth state transitions
- `prefers-reduced-motion` support
- Semantic timeline structure
- Pure HTML and CSS
- No JavaScript

## Design Tokens

The component uses CSS custom properties for its visual system:

```css
:root {
  --material-background: #f7f9fc;
  --material-surface: #ffffff;
  --material-primary: #6750a4;
  --material-primary-container: #eaddff;
  --material-text: #1d1b20;
  --material-muted: #625f66;
  --material-outline: #cac4d0;
}
