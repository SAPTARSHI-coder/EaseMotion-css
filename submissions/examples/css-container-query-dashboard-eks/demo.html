How it works

Each card below is a container query container. When a card is in a narrow sidebar vs a wide grid cell, its internal layout, typography, and structure adapt — not based on viewport size, but on the container's own width.

  • @container — Cards change from vertical to horizontal layout at 400px container width
  • light-dark() — All colors use native light-dark() for automatic dark mode
  • oklch() — Modern perceptually-uniform color space for badges and accent colors
