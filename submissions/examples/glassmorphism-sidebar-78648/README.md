# Glassmorphism Sidebar

Neon glassmorphism sidebar navigation showcase for issue #78648.

## Files

- `demo.html` — accessible navigation structure.
- `style.css` — translucent panel, glow, and responsive states.

## Features

- Glassmorphism panel.
- Neon accent treatment.
- Semantic navigation.
- Focus-visible states.
- Responsive mobile layout.
- Reduced-motion support.

The sidebar uses CSS layout and transitions without requiring JavaScript.
