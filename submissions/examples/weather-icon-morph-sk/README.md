# Weather Icon Morph Set

## What does this do?

Radio-driven weather icons for sun, cloud, rain, and storm states.

## How is it used?

```html
<div class="weather"><input type="radio" name="wx"/><div class="weather__icon"></div></div>
```

Open `demo.html` in a browser to try it.

## Why is it useful?

Reusable morph kit for forecast UIs without large illustration assets.
