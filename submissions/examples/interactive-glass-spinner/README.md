# Interactive Glassmorphism Spinner

A modern responsive loading spinner created using pure HTML and CSS.

## Features

- Glassmorphism UI
- Animated loading spinner
- Animated progress indicator
- Smooth card entrance animation
- Hover and focus interactions
- Fully responsive
- Pure HTML and CSS
- No JavaScript required
- Reduced-motion accessibility support

## Preview

The component displays a glass-style loading card with an animated
three-dot spinner, loading progress bar, and processing button.
