# Morph-Glow Carousel (Fintech Dashboard)

## What does this do?

A modern fintech dashboard carousel featuring cards with a smooth morphing glow effect. Built entirely with HTML and CSS, the component combines glassmorphism styling with subtle hover animations to highlight financial metrics.

---

## Features

- Morph-glow hover animation
- Glassmorphism card design
- Fintech-inspired dashboard UI
- Smooth hover transitions
- Responsive layout
- Pure HTML & CSS (No JavaScript)
- Supports `prefers-reduced-motion`

---

## Files

- `demo.html` — Component showcase
- `style.css` — Component styling and animations
- `README.md` — Documentation
