# Ripple Wave Hero

A minimalist, responsive hero section built with pure HTML and CSS. It uses lightweight CSS animations to create a smooth ripple-wave effect suitable for modern technology-focused layouts.

## ✨ Features

- Pure HTML and CSS implementation
- Animated ripple-wave background
- Smooth CSS keyframe animations
- Fully responsive across desktop, tablet, and mobile
- Customizable using CSS custom properties
- Accessible focus states
- Supports `prefers-reduced-motion`
- No JavaScript or external frameworks required
