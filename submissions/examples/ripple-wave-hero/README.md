# Ripple-Wave Hero Section

A responsive glassmorphism hero section featuring layered ripple waves that expand continuously around the content using pure CSS.

## Usage

Open `demo.html` directly in a browser. The ripple effect is generated by four decorative `<span>` elements inside `.hero__waves` and animated with the `ripple` keyframes.

```html
<section class="hero" aria-labelledby="hero-title">
  <div class="hero__waves" aria-hidden="true">
    <span></span>
    <span></span>
    <span></span>
    <span></span>
  </div>
  <div class="hero__content">
    <h1 id="hero-title">Build boldly.<br><span>Move naturally.</span></h1>
  </div>
</section>
```

## Features

- Pure HTML and CSS with no JavaScript or external frameworks.
- Four staggered ripple waves driven by CSS `@keyframes`.
- Glassmorphism surface with layered gradients and blur.
- Responsive typography and layout for desktop, tablet, and mobile.
- Semantic heading structure and keyboard-visible button focus states.
- Decorative animation is marked `aria-hidden` so it is ignored by assistive technology.
- `prefers-reduced-motion: reduce` disables the ripple and interaction animations.

## Why it fits EaseMotion

The ripple animation adds movement without JavaScript and uses staggered, lightweight transforms and opacity changes. The effect remains decorative, responsive, and easy to disable for users who prefer reduced motion, matching EaseMotion's focus on expressive but practical CSS motion.
