# Glowing Treeview — Neumorphism

A responsive glowing treeview component built with pure
HTML and CSS for EaseMotion CSS issue #81425.

## Features

- Neumorphic soft UI
- Glowing accent interactions
- Expandable and collapsible folders
- Nested tree structure
- Smooth hover transitions
- Animated chevron indicators
- Glowing file and folder icons
- Online status indicator
- Item count badges
- Keyboard focus support
- Responsive desktop, tablet, and mobile layouts
- Reduced-motion support
- No external JavaScript dependencies
