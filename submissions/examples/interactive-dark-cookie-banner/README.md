# Interactive Cookie Banner with Dark Mode Styling

A modern interactive cookie consent banner designed for dark-mode interfaces.

The component combines a dark UI, subtle gradients, soft borders, controlled glow effects, interactive preference switches, and responsive layouts while remaining completely CSS-only.

## Features

- Dark mode visual design
- Modern SaaS-inspired interface
- Interactive cookie preference switches
- Essential cookie status indicator
- Analytics preference
- Personalization preference
- Accept all action
- Reject optional action
- Customize action
- Cookie settings panel
- Subtle hover interactions
- Smooth state transitions
- Decorative animated cookie visual
- Responsive desktop, tablet, and mobile layouts
- Keyboard accessible controls
- Visible `:focus-visible` states
- `prefers-reduced-motion` support
- Semantic HTML structure
- Pure HTML and CSS
- Zero external JavaScript dependencies
- No external assets or libraries
