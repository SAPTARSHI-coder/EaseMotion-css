# Liquid Wave Waveform Audio Visualizer Bar

A modern neumorphic audio visualizer component with an animated liquid-wave
waveform effect.

## Features

- CSS-only animated waveform
- Neumorphic card design
- Gradient waveform bars
- Smooth animation
- Responsive design
- Play button interaction styling
- Reduced-motion accessibility support
- No external dependencies
