# CSS Shimmer-Sweep Progress Bar

A lightweight pure CSS progress bar with a glassmorphism presentation and
animated shimmer-sweep effect.

## Features

- Pure HTML and CSS
- No JavaScript dependencies
- Glassmorphism UI
- Smooth progress-fill animation
- Continuous shimmer sweep
- Responsive layout
- Semantic progressbar markup
- `prefers-reduced-motion` support
- Customizable CSS properties
