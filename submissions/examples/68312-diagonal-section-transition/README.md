# Diagonal Section Transition

## Overview

A pure HTML and CSS demonstration of a diagonal section transition. The example uses layered sections, clipped edges, gradients, and transform-based motion to create a smooth transition between content areas without JavaScript.

## Features

- Responsive diagonal section layout
- CSS-only transition effects
- Layered visual depth
- Hover and focus states
- Keyboard-friendly interactive elements
- Responsive behavior for smaller screens
- Reduced-motion support

## Files

- `demo.html` — semantic structure and demo content
- `style.css` — layout, visual styling, transitions, responsive rules, and animation

## Usage

Open `demo.html` in a modern browser. No build step, package installation, or JavaScript runtime is required.

## Accessibility

The demo includes visible focus states and a `prefers-reduced-motion` media query so users who request reduced motion receive a less animated presentation.
