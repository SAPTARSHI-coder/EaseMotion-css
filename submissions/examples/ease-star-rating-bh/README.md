# ease-star-rating-bh

Pure CSS interactive star rating component.

## What does this do?
Creates interactive star rating components with hover and selection effects.

## How is it used?
```html
<div class="ease-star-rating-bh">
  <input type="radio" name="rating" id="star5" value="5">
  <label for="star5">★</label>
</div>
```

## Why is it useful?
Provides a beautiful star rating UI for product reviews and ratings.
