# Lock Unlock Icon Morph

## What does this do?

A padlock icon whose shackle morphs open/closed on toggle.

## How is it used?

```html
<label class="lock-toggle"><input type="checkbox"/><span class="lock"></span></label>
```

Open `demo.html` in a browser to try it.

## Why is it useful?

Communicates security state instantly as a crisp microinteraction.
