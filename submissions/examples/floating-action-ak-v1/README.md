# floating-action-ak

Pure CSS expandable floating action button (FAB) speed dial menu — no JavaScript required.

## How to use

```html
<div class="ease-fab-container">
  <button class="ease-fab-trigger" aria-label="Toggle menu">+</button>

  <ul class="ease-fab-menu">
    <li><a href="#" class="ease-fab-action">🔗</a></li>
    <li><a href="#" class="ease-fab-action">⭐</a></li>
    <li><a href="#" class="ease-fab-action">✏️</a></li>
  </ul>
</div>
