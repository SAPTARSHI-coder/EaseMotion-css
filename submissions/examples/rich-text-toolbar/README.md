# CSS Rich Text Toolbar

A responsive rich text editor toolbar created using HTML and CSS.

## Features

- Bold, italic, underline and link toolbar buttons
- Responsive design
- Keyboard accessible controls
- Focus-visible states
- Editable content area
- Pure HTML and CSS
- Reduced-motion support

## Files

- `demo.html` - Component markup
- `style.css` - Component styling

## Usage

Open `demo.html` in a browser to view the component.

## Accessibility

The toolbar uses ARIA labels and the editor uses appropriate textbox semantics.
Keyboard focus is clearly visible for interactive controls.

## Technologies

- HTML5
- CSS3
