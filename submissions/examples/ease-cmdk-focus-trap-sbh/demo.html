ease-cmdk-focus-trap

Command palette with a real keyboard focus trap.

Fixes the bug where the command palette overlay let Tab move focus to elements behind the backdrop. This example traps focus inside the dialog while it is open: Tab / Shift+Tab cycle only among the palette's controls, the backdrop is inert, and focus is restored to the trigger when the palette closes. Press Ctrl+K (or the button) to open it.
