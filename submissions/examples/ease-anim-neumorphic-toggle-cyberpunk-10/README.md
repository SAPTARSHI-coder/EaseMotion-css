# Neumorphic Interactive Toggle Switch with Smooth Haptic Elasticity 10

### Cyberpunk Theme

A futuristic neumorphic toggle switch inspired by cyberpunk aesthetics. Built using pure HTML and CSS, this component combines neon glow effects, elastic micro-interactions, and responsive design while maintaining accessibility and smooth performance.

---

## ✨ Features

- Cyberpunk neon theme
- Neumorphic UI design
- Smooth haptic-inspired elastic animation
- Animated glow effects
- Responsive layout
- Keyboard accessibility
- Reduced motion support
- Pure HTML & CSS implementation

## 🚀 Usage

1. Open the component folder.
2. Ensure `demo.html` and `style.css` are in the same directory.
3. Open `demo.html` in any modern web browser.

No installation or external dependencies are required.
