# Animated Tooltip Component

A zero-dependency, CSS-only animated tooltip component designed for the **EaseMotion CSS** framework.

## ✨ Features
- **Zero JavaScript**: Pure CSS implementation using `:hover` and `:focus` states.
- **Animation-First**: Uses smooth `ease-out` cubic-bezier transitions for a polished, natural feel.
- **Design Token Compatible**: Leverages EaseMotion CSS variables (`--ease-duration-fast`, `--ease-radius-sm`, etc.) for seamless theming.
- **Accessible**: Triggers on both `hover` and `focus`, making it keyboard-navigable.

## 🚀 Usage

1. Add the `ease-tooltip` class to any inline or inline-block element.
2. Add the `data-tooltip` attribute with your desired text.
