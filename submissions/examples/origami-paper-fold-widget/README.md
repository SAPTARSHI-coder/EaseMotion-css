# Origami Paper Fold Widget

A clean and elegant **Origami Paper Fold** dashboard widget built entirely with HTML and CSS. Inspired by folded paper aesthetics, the widget features layered corners, subtle depth, and smooth hover interactions while remaining lightweight and accessible.

## Features

- 📄 Origami-inspired folded paper design
- ✨ Smooth hover animations using CSS transforms
- 🎨 Soft layered shadows and folded corner effects
- 🌙 Dark-mode compatible preview background
- 📱 Fully responsive layout
- ⚡ Hardware-accelerated animations
- ♿ Supports `prefers-reduced-motion`
- 🚫 No JavaScript or external libraries required

## Files

```
origami-paper-fold-widget/
├── demo.html
├── style.css
└── README.md
```

## Usage

1. Open `demo.html` in any modern browser.
2. Ensure `style.css` is located in the same directory.
3. Hover over the widget to see the origami fold animation.

## Customization

You can easily customize:

- Background paper colors
- Fold corner size
- Shadow intensity
- Border radius
- Typography
- Hover animation duration
- Widget dimensions
