# Status indicator dot pulse

A coloured dot whose halo pulses to indicate online, degraded, or offline service state.

## How to view

Open `demo.html` in any modern browser. The demo is fully self-contained — no CDN, no framework, no JavaScript.

## How to use

Copy `style.css` into your project's stylesheet. Every class used in the demo is namespaced with `statusindicatordotpulse-` to avoid collisions.

## Why this is useful for EaseMotion CSS

Server health / status page pattern; the pulse reads at a glance.
