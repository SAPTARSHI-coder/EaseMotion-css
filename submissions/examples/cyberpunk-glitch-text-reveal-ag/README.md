# Cyberpunk Glitch Text Reveal

1. What does this do? Creates a high-energy text entrance animation where the letters briefly skew, separate into RGB color channels, and glitch into position before snapping to sharp focus.
2. How is it used? Apply `.glitch-text-reveal` to a heading or text element.
3. Why is it useful? Futuristic UI aesthetics are highly popular. Providing a hardware-accelerated glitch effect for hero text without requiring external JavaScript libraries is a massive win for modern web design.
