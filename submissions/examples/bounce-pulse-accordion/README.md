# Bounce-Pulse Accordion

A lightweight, responsive CSS Bounce-Pulse Accordion designed for fintech dashboard layouts.

This component uses only HTML and CSS. No JavaScript or external frameworks are required.

## Features

- Pure HTML and CSS
- Native `<details>` and `<summary>` accordion behavior
- Bounce animation when an accordion item opens
- Subtle pulse-ring effect
- Smooth content entrance animation
- Responsive on desktop, tablet, and mobile
- Keyboard accessible
- `prefers-reduced-motion` support
- CSS custom properties for easy customization
- No external dependencies
