# 3D Navbar with Gradient

## What does this do?
A responsive, gradient-styled navigation bar that features a smooth 3D tilting effect and depth translation on hover.

## How is it used?
```html
<div class="navbar-container">
  <nav class="navbar-3d">
    <a href="#" class="nav-brand">BrandName</a>
    <ul class="nav-links">
      <li><a href="#" class="nav-link">Link 1</a></li>
      <li><a href="#" class="nav-link">Link 2</a></li>
    </ul>
  </nav>
</div>
```

## Why is it useful?
It provides a highly interactive and premium feel to standard navigation headers, fitting perfectly with EaseMotion's philosophy of dynamic and fluid web interfaces without requiring any JavaScript.
