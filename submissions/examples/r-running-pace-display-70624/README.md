# CSS Running Pace Display

A responsive running pace display featuring an animated CSS shoe icon
and running statistics.

## Features

- Pure HTML and CSS
- Animated running shoe icon
- Current pace display
- Distance, time, and calorie statistics
- Animated pace progress bar
- Responsive design
- Accessible semantic structure
- Reduced-motion support
- No JavaScript required

## Files

- `demo.html` - Component markup
- `style.css` - Complete styling and animations

## Usage

Open `demo.html` in any modern browser.

## Accessibility

The running statistics use semantic text content and the decorative
shoe animation is hidden from assistive technologies with
`aria-hidden="true"`.

A `prefers-reduced-motion` media query disables the animations for
users who prefer reduced motion.

## Browser Support

Designed for modern browsers supporting CSS animations, gradients,
transforms, and media queries.
