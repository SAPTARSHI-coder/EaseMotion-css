# CSS Slide-Up Card Grid for Product Catalog Layouts

A modern **pure HTML & CSS Slide-Up Card Grid** showcasing product cards with elegant slide-up overlays, smooth hover transitions, and responsive layouts.

## Features

- Pure HTML5 & CSS3
- No JavaScript required
- Smooth slide-up overlay animation
- Responsive product grid
- Modern card UI
- CSS Custom Properties
- Accessibility friendly
- Supports `prefers-reduced-motion`

```css
    --bg:#eef2ff;
    --radius:22px;

```

## Usage

1. Open `demo.html`
2. Hover over any product card.
3. The information panel smoothly slides upward.
4. Customize colors using CSS variables.

## Responsive

- Desktop
- Tablet
- Mobile

## Accessibility

Supports reduced motion via

```css
@media (prefers-reduced-motion: reduce)
```
