# Animated Tab Switcher

A responsive **CSS-only Animated Tab Switcher** built using HTML radio buttons and CSS. The component provides smooth tab transitions, a sliding underline indicator, and responsive behavior without requiring JavaScript.

## Features

- CSS-only implementation
- Smooth content transitions
- Sliding underline indicator
- Responsive design
- Keyboard-friendly tab navigation
- Lightweight and easy to customize
- No JavaScript required

## Folder Structure

```
animated-tab-switcher/
├── demo.html
├── style.css
└── README.md
```

## Usage

1. Open `demo.html` in any modern browser.
2. Include `style.css` in your project.
3. Customize the tab labels and content as needed.

## Customization

You can easily modify:

- Number of tabs
- Active indicator color
- Font styles
- Animation duration
- Transition effects
- Border radius
- Shadow and spacing
