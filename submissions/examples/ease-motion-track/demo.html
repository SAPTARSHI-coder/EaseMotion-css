EaseMotion Utility

Pure CSS Motion Track

Animate DOM elements smoothly along complex, curved vector paths using modern CSS Motion Path (offset-path and offset-rotate).

Key Utility Properties

Utilizes offset-path: path(...) for standard vector paths and offset-rotate: auto so elements continuously align with the path angle.

Usage Example

Apply .ease-motion-track directly to any element. <div class="rocket ease-motion-track"></div>
