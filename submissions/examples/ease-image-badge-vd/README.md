# Ease Image Badge

## What does this do?

A responsive image thumbnail with a small badge overlay and smooth zoom animation on hover.

---

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<div class="image-card">

    <img
        src="image.jpg"
        alt="Example image"
    >

    <span class="image-badge">
        Featured
    </span>

</div>
```

### Features

- Image thumbnail
- Badge overlay
- Rounded corners
- Image zoom on hover
- Badge hover animation
- Responsive layout

---

## Why is it useful?

Image badges are commonly used in galleries, portfolios, product listings, and media cards to highlight content such as "Featured", "New", or "Popular".

This component provides a lightweight and reusable image pattern with subtle motion while following the animation-first philosophy of EaseMotion CSS.
