# 3D Flip Card Component

## Description
A highly interactive, CSS-only 3D Flip Card component built for the EaseMotion framework. 
This component demonstrates how to achieve complex 3D rotation and perspective using only CSS (`transform-style: preserve-3d` and `perspective`), adhering to the framework's zero-dependency, zero-JS philosophy.

## Usage
Simply hover over the card in the `demo.html` file to see the 3D flip animation in action.

## Technologies Used
- HTML5
- CSS3 (3D Transforms, Transitions)
- EaseMotion Framework utility classes
