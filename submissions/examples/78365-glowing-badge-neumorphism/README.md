# Glowing Badge with Neumorphism Styling

A responsive badge component combining soft neumorphic depth with
subtle glowing and hover effects.

## Features

- Fully responsive
- HTML and CSS only
- No JavaScript
- Neumorphic card surfaces
- Glowing badge effects
- Multiple badge variants
- Animated status indicator
- Shimmer hover effect
- Smooth hover elevation
- Responsive grid layout
- Reduced-motion accessibility support

## Badge Variants

The demo includes:

- Featured
- Online
- Pro
- New

Each badge uses its own accent color while preserving the same
neumorphic interaction pattern.

## Files

- `demo.html`
- `style.css`

## Technologies

- HTML5
- CSS3

## Accessibility

The component includes:

- Semantic HTML
- Descriptive labels
- Responsive text sizing
- `prefers-reduced-motion` support
