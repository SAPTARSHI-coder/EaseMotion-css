# Ease User Presence

## What does this do?

A compact user presence component displaying an avatar with an online or offline status indicator.

---

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<div class="presence-card">
    <div class="avatar-wrapper">
        <div class="avatar">V</div>
        <span class="presence-dot online"></span>
    </div>

    <div class="user-info">
        <h3>Vidheendu</h3>
        <p>Online</p>
    </div>
</div>
```

### Features

- User avatar
- Online/offline indicator
- Online pulse animation
- Hover animation
- Responsive layout
- Lightweight and reusable

---

## Why is it useful?

User presence indicators are commonly used in messaging applications, collaboration tools, team dashboards, and profile lists.

This component provides a simple and reusable way to show user availability with subtle motion while following the animation-first philosophy of EaseMotion CSS.
