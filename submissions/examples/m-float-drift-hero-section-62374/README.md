# CSS Float-Drift Hero Section for Product Catalog Layouts

A modern **Float-Drift Hero Section** built using pure HTML and CSS. The component features a gentle floating animation, responsive hero layout, CSS custom properties, and lightweight styling for product catalog landing pages.

## ✨ Features

- Pure HTML5 & CSS3
- Float-Drift animation
- Responsive hero section
- Glassmorphism product card
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
