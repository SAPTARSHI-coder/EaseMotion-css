# CSS Job Listing Card

A responsive job listing card built with pure HTML and CSS.

## Features

- Company logo and company information
- Job title and category
- Location and employment type
- Skill tags
- Salary and experience information
- Animated hover interaction
- Responsive layout
- Keyboard-accessible apply link
- Reduced-motion support
- High-contrast support
- No JavaScript required

## Files

- `demo.html` — Component markup
- `style.css` — Component styling
- `README.md` — Documentation

## Usage

Open `demo.html` in a browser to view the component.

## Accessibility

The component uses semantic HTML, descriptive link text, visible keyboard focus, reduced-motion support, and forced-colors support.
