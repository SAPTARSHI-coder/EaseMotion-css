# Morphing Gradient Button

A modern responsive button component featuring a smooth morphing border-radius animation and animated gradient styling.

## ✨ Features

- Smooth morphing hover animation
- Animated gradient background
- Shine effect on hover
- Lift and scale interaction
- Responsive design
- Accessible link-based button
- Pure HTML and CSS
- No JavaScript or external libraries

## 🛠️ Technologies

- HTML5
- CSS3

## 📁 Folder Structure

```text
morphing-gradient-button/
├── index.html
├── style.css
└── README.md
````

## 🚀 Usage

Open `index.html` in any modern browser.

Hover over the **Get Started** button to see the morphing gradient effect.

## 🎨 Customization

You can customize the component by changing:

* Gradient colors
* Border radius
* Animation speed
* Button size
* Shadow intensity
* Hover scale

Example:

```css
.morph-button {
    background: linear-gradient(
        135deg,
        #7c3aed,
        #ec4899,
        #f97316
    );
}
```

## 📱 Responsive Design

The button automatically adapts to smaller screens using CSS media queries.

## ♿ Accessibility

The button uses a semantic `<a>` element for navigation and maintains readable text with sufficient contrast.
