# Particle Burst Form

A smooth, accessible, and responsive form component featuring a **Particle Burst** visual style using pure HTML and Vanilla CSS.

## ✨ Features

- Particle-inspired decorative effects
- Interactive particle burst around the submit button
- Animated focus effects on form controls
- Name, email, subject, and message fields
- Accessible checkbox control
- Smooth CSS transitions
- Responsive design
- Automatic dark mode support
- Keyboard-friendly focus states
- `prefers-reduced-motion` support
- Hardware-friendly CSS transforms
- No JavaScript
- No external dependencies
