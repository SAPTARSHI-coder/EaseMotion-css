# CSS Circular Nav Menu

A sleek hamburger button that smoothly expands into a full-screen navigation menu utilizing fluid `clip-path: circle()` transitions.

## Features
- Full-screen reveal animation powered by CSS `clip-path: circle()` morphing.
- Elegant hamburger menu icon transformation into a closing 'X' using CSS rotations and translates.
- Staggered link reveal animations utilizing `nth-child()` and `transition-delay`.
