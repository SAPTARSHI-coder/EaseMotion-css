# Velvet Smooth Transition Background

A smooth, accessible, and performant pure CSS background animation featuring a soft **Velvet Smooth Transition** visual style.

## Features

- Pure HTML and Vanilla CSS
- Smooth flowing gradient transitions
- Soft blurred ambient orbs
- Velvet-inspired visual treatment
- Subtle glass-like content surface
- Smooth hover interaction
- Responsive layout
- Dark mode compatible
- Hardware-accelerated transforms
- Accessible semantic structure
- `prefers-reduced-motion` support
- No external JavaScript
- No external libraries
