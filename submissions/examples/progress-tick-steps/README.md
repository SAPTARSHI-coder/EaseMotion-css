# Progress Tick Steps

Checkmarks pop into place across steps as the progress advances.

## Features
- Pop-in checkmarks
- Staggered step sequence
- Trailing highlight
- Pure CSS

## Usage
```html
<div class="pts-step" style="--i:0"><span></span><p>Copy</p></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
