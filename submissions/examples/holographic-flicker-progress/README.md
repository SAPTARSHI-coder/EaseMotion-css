# Holographic Flicker Progress

A futuristic progress bar built using pure HTML and Vanilla CSS.

This component is part of the EaseMotion CSS collection and demonstrates a
holographic visual effect with animated gradients, subtle flickering,
light sweeps, and responsive styling.

## Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Holographic gradient animation
- Subtle flicker effect
- Animated light sheen
- Glare sweep animation
- Responsive design
- Accessible progressbar semantics
- Dark-mode friendly
- Hardware-accelerated animations
- Reduced-motion support
- Lightweight implementation

## Preview

The component displays a horizontal progress indicator with a futuristic
holographic appearance.

## Usage

Include the HTML structure:

```html
<div
  class="progress-track"
  role="progressbar"
  aria-label="Project completion"
  aria-valuemin="0"
  aria-valuemax="100"
  aria-valuenow="72"
>
  <div class="progress-fill"></div>
  <div class="progress-glare"></div>
</div>
