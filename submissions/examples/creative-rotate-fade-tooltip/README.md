# CSS Rotate-Fade Tooltip for Accessible Web Layouts

A modern **Rotate-Fade Tooltip** component built completely with **HTML5 and CSS3**. This showcase demonstrates interactive tooltips with smooth rotate entrance animations, fade transitions, glassmorphism styling, responsive behaviour, and accessibility support without requiring JavaScript.

---

## ✨ Features

- 🔄 Rotate entrance animation
- 🌫️ Smooth fade transition
- 💎 Glassmorphism tooltip design
- 🎨 Gradient action buttons
- ✨ Hover and focus interactions
- ⚡ Lightweight CSS animations
- 🎯 CSS Custom Properties
- 📱 Fully responsive layout
- 🧩 Pure HTML5 & CSS3
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

## 🚀 Getting Started

1. Open `demo.html` in any modern browser.
2. Hover over the buttons to display tooltips.
3. Use keyboard focus to access tooltip interactions.
4. Customize styles using CSS variables.
