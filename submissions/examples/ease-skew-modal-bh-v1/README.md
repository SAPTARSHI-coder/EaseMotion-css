# ease-skew-modal-bh

Pure CSS skew-active modal for fintech dashboards.

## Features
- Skew hover effect
- Modal variants
- Responsive design
- Accessibility support

## Usage
```html
<div class="ease-modal ease-modal-skew">Content</div>
```

## CSS Classes
- `.ease-modal` - Base modal
- `.ease-modal-skew` - Skew effect
