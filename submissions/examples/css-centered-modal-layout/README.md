# CSS Centered Modal Layout

A responsive centered modal layout with a blurred and dimmed page
background, implemented entirely with HTML and CSS.

## Features

- Pure CSS implementation
- No JavaScript required
- Centered modal layout
- Blurred page background
- Dimmed overlay
- CSS-only open and close behavior using URL fragments
- Responsive design
- Close button
- Primary and secondary actions
- Keyboard-focusable links
- Visible focus indicators
- ARIA dialog attributes
- Reduced-motion support

## Files

- `demo.html` — Standalone demonstration
- `style.css` — Complete component styling

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
