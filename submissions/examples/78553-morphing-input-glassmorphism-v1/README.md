# Morphing Input Field with Glassmorphism

A responsive input field component combining a floating/morphing label with a modern glassmorphism interface.

## Features

- Glassmorphism input surfaces
- Morphing floating labels
- Smooth focus transitions
- Focus border glow
- Input icons
- Responsive desktop, tablet, and mobile layouts
- Native HTML form controls
- Keyboard-accessible fields
- Reduced-motion support
- No external dependencies
- `backdrop-filter` fallback
