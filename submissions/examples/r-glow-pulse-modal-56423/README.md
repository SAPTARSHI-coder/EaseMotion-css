# CSS Glow-Pulse Modal

A modern **Glow-Pulse Modal** built using pure HTML5 and CSS3 for Gaming Hub layouts. The modal opens with a smooth glowing pulse animation while remaining lightweight, responsive, and accessible.

---

## ✨ Features

- Pure HTML5 & CSS3
- Glow pulse entrance animation
- Gaming-inspired modal
- Fully responsive
- CSS Custom Properties
- Lightweight and performant
- Accessible structure
- No JavaScript required
- `prefers-reduced-motion` support
