# CSS Shimmer-Sweep Feature Grid for Creative Portfolio Layouts

A modern **Creative Portfolio Feature Grid** built using **pure HTML5 and CSS3**. The design features elegant glassmorphism cards with a shimmering light sweep animation, smooth hover interactions, responsive layouts, and accessibility support without JavaScript.

---

## ✨ Features

- ✨ Shimmer Sweep hover animation
- 🎨 Creative portfolio inspired layout
- 💎 Glassmorphism feature cards
- 🌈 Gradient icon accents
- 🚀 Smooth hover transitions
- 📱 Fully responsive
- 🎨 CSS Custom Properties
- ♿ `prefers-reduced-motion` support
- 🚫 Pure HTML & CSS

## 🚀 Getting Started

1. Open `demo.html` in any modern browser.
2. Hover over feature cards to view the shimmer sweep effect.
3. Customize colors, spacing, animation speed, and shadows using CSS variables.

---

## 🎨 CSS Variables

```css
:root{
    --bg:#f6f8fc;
    --surface:rgba(255,255,255,.78);
    --primary:#6366f1;
    --secondary:#06b6d4;
    --text:#111827;
    --muted:#6b7280;
    --border:rgba(99,102,241,.12);
    --radius:22px;
}
```
