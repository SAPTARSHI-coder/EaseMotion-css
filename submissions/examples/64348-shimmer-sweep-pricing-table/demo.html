Motion system

Light, not noise.

The shimmer is a single CSS pseudo-element translated across the card with a short keyframe animation. It only runs when the card receives hover or focus, so the page stays calm while idle.

Notes

Built to be adapted.

Can the shimmer color change?

Yes. The highlight uses a custom property, so its opacity and tint can be adjusted without changing the component structure.

Does it require JavaScript?

No. Hover and keyboard focus trigger the interaction through CSS pseudo-classes and keyframes.

What happens with reduced motion?

The moving highlight and decorative animations are disabled with the prefers-reduced-motion media query.
