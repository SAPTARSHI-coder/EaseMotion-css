# CSS Rotating Drum Text


A 3D rotating drum text reveal animation built completely with CSS.


## Features

- Pure CSS implementation
- 3D cylindrical text rotation
- Smooth reveal animation
- Gradient typography
- Responsive design
- No JavaScript dependency


## Technologies

- HTML5
- CSS3


## CSS Concepts Used

- Perspective
- Transform rotateX()
- Keyframe animation
- Gradient text
- Responsive media queries


## Accessibility

- Semantic HTML structure
- No interaction dependency
- Keyboard friendly
