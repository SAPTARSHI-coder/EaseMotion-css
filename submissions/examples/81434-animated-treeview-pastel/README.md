# Animated Treeview — Pastel

A responsive animated treeview component featuring a soft
pastel visual style, built with pure HTML and CSS for
EaseMotion CSS issue #81434.

## Features

- Soft pastel visual design
- Interactive expandable tree structure
- Native HTML `<details>` and `<summary>` controls
- Smooth expand and collapse animations
- Folder and file states
- Hover interactions
- Keyboard focus support
- Responsive desktop, tablet and mobile layouts
- Reduced-motion support
- No JavaScript dependencies
