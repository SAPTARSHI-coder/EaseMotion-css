# CSS Lottery Ticket Card

A responsive lottery ticket-style card featuring a CSS-generated foil texture and interactive hover/focus effects.

## Features

- Pure HTML and CSS
- Lottery ticket visual design
- CSS-generated foil texture
- Scratch-area styling
- Perforated ticket stub
- Ticket number and price information
- Responsive layout
- Hover and keyboard focus states
- Reduced-motion support
- No JavaScript
- No external assets

## Usage

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
