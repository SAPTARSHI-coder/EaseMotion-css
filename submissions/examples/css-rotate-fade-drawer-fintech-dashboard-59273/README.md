# CSS Rotate-Fade Drawer for Fintech Dashboard Layouts

A modern **Rotate-Fade Drawer** built with pure HTML and CSS for fintech dashboards, banking portals, analytics platforms, and admin interfaces.

## Features

* Pure HTML5 & CSS3
* Smooth rotate-fade drawer animation
* CSS-only toggle (No JavaScript)
* Responsive drawer layout
* Modern fintech-inspired UI
* CSS custom properties for easy customization
* Lightweight and performance optimized
* Supports `prefers-reduced-motion`

## Folder Structure

```text
css-rotate-fade-drawer-fintech-dashboard-59273/
├── demo.html
├── style.css
└── README.md
```

## Usage

1. Open `demo.html` in any modern browser.
2. Click the **Dashboard** button to open and close the drawer.
3. Customize colors using the CSS variables in `:root`.
4. Edit navigation links according to your project.
