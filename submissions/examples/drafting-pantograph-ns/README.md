# Ease Drafting Pantograph

A CSS-only animated pantograph component created for EaseMotion CSS.

## Overview

`ease-drafting-pantograph` represents a drafting pantograph where connected arms move in parallel to scale and reproduce drawings.

## Features

- Pure CSS animation
- No JavaScript dependency
- Mechanical drafting motion
- Animated arm linkage
- Scaling drawing effect
- Responsive layout
- Reduced motion support
