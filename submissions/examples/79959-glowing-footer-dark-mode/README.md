# Glowing Footer - Dark Mode

A modern, fully responsive footer built with pure HTML and CSS.
The component combines dark mode styling with glowing neon accents,
subtle borders and smooth micro-interactions.

## ✨ Features

- Pure HTML and CSS
- Fully responsive
- Dark mode design
- Glowing neon accents
- Responsive multi-column layout
- Newsletter subscription field
- Social media links
- Interactive footer links
- Animated logo
- Focus states
- Reduced-motion support
- No JavaScript dependency
