# Escapement Rack Step

## What does this do?
Renders a self-contained CSS-only `ease-escapement-rack-step` demo: Escapement rack stepping one unit.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-escapement-rack-step`. No build step or JavaScript is required for the effect.

```html
<section class="ease-escapement-rack-step">
  <div class="ease-escapement-rack-step__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
