# CSS Morphing Blob Button

A modern button component that morphs into an organic blob shape on hover using CSS border-radius animations.

## Features

- Pure CSS implementation
- Smooth blob morphing animation
- Hover and focus effects
- Responsive design
- No JavaScript required
- Easy customization

## Usage

Open `demo.html` in any modern browser to see the component in action.

## Accessibility

- Keyboard accessible
- Focus-visible support
- Semantic button element

## Files

- `demo.html` – Demo implementation
- `style.css` – Styling and animations
