# Animated Breadcrumb with Pastel styling (#78867)

An interactive, animated breadcrumb navigation component featuring soft pastel highlights, hover glow effects, and pill-shaped link containers built entirely with pure CSS.

## Features
- **Semantic Structure:** Uses accessible `<nav>` and `<ol>` markup with proper `aria-current="page"` attributes.
- **Pastel Glow Aesthetics:** Soft mint green active indicators coupled with soft pink hover state animations.
- **Responsive Wrap:** Flex layout with wrap support ensuring smooth rendering on mobile viewports.

## File Hierarchy
- `style.css` - Component styles, pastel color variables, and transition effects.
- `demo.html` - Accessible HTML structure and breadcrumb hierarchy.
- `README.md` - Technical specification and architecture overview.
