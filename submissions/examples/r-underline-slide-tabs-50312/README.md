# CSS Underline-Slide Tabs

A modern **Underline-Slide Tabs** component built using pure HTML5 and CSS3 for Responsive Dashboard layouts. The active tab features a smooth underline-slide animation while content transitions elegantly without JavaScript.

---

## ✨ Features

- Pure HTML5 & CSS3
- Underline slide animation
- Responsive dashboard layout
- Keyboard accessible using radio inputs
- CSS Custom Properties
- No JavaScript required
- `prefers-reduced-motion` support
