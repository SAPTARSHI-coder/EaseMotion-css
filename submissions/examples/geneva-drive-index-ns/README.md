# Geneva Drive Index

## What does this do?
Renders a self-contained CSS-only `ease-geneva-drive-index` demo: Geneva drive indexing a wheel in discrete steps.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-geneva-drive-index`. No build step or JavaScript is required for the effect.

```html
<section class="ease-geneva-drive-index">
  <div class="ease-geneva-drive-index__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
