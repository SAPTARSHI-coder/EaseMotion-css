# glow-toast-banner-v2-ak

Pure CSS animated notification toast banner with bottom progress timer line — no JavaScript required.

## How to use

```html
<div class="ease-toast-v2">
  <span class="ease-toast-icon-v2">🔔</span>
  <div class="ease-toast-content-v2">
    <span class="ease-toast-title-v2">Title</span>
    <span class="ease-toast-desc-v2">Description</span>
  </div>
  <div class="ease-toast-timer-v2"></div>
</div>
