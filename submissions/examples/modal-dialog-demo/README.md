# Responsive Modal Dialog Demo

## Description

This example demonstrates a responsive and accessible modal dialog using EaseMotion CSS and minimal JavaScript.

## Features

- Open and close modal
- Responsive design
- Modal overlay
- Close button
- Close when clicking outside the modal
- Escape-key support
- Accessible dialog attributes
- Smooth opening and closing transitions
