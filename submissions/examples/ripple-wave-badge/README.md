# CSS Ripple-Wave Badge

A lightweight CSS-only badge component featuring a ripple-wave hover animation for accessible web layouts.

## Features

- Pure HTML & CSS
- Ripple-wave hover effect
- Responsive design
- Accessible with `prefers-reduced-motion`
- No JavaScript required
- Easy to customize

## Files

```text
demo.html
style.css
README.md
```

## Usage

Open `demo.html` in a modern browser and hover over the badges.

## Customization

- Badge colors
- Ripple animation speed
- Border radius
- Typography
- Spacing

## Browser Support

Compatible with all modern browsers supporting CSS animations and pseudo-elements.
