# Neumorphic Button with Neon Styling

A responsive button component that combines soft neumorphic depth with vibrant neon glow effects.

## Features

- Neumorphic design
- Neon hover glow
- Smooth transitions
- Responsive layout
- Pure HTML/CSS
- Lightweight and customizable

## Files

- demo.html
- style.css

## Usage

```html
<button class="neon-btn">
  Neon Action
</button>
```

Open `demo.html` in any modern browser.

## Customization

You can easily modify:

- Neon glow color
- Button size
- Border radius
- Background color
- Shadow intensity
