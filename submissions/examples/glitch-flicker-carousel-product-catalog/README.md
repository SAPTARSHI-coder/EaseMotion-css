# CSS Glitch-Flicker Carousel for Product Catalog Layouts

A modern **Glitch-Flicker Carousel** built using only HTML and CSS for the EaseMotion CSS library. The design features animated product cards with futuristic glitch effects, scan-line shimmer, hover elevation, and responsive layouts suitable for SaaS and product showcase websites.

---

## Features

- Pure HTML5 & CSS3
- Glitch flicker animation
- Scan-line shimmer overlay
- Responsive product grid
- Smooth hover transitions
- Gradient CTA buttons
- Floating card animation
- CSS Custom Properties
- No JavaScript required
- Accessible with `prefers-reduced-motion`
