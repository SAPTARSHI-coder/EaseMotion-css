# 🧂 Salt Crystal – Salt-Like Crystals Grow on Surface

> An interactive salt crystal component where salt-like crystals grow on a surface with 5 colors (White, Pink, Blue, Purple, Gold), growth control (0-100%), and faceted crystal shapes.

---

## 📖 Description

The **Salt Crystal** component creates an interactive salt crystal experience where salt-like crystals grow on a surface with faceted shapes. Built with vanilla HTML, CSS, and JavaScript, it features 5 colors (White, Pink, Blue, Purple, Gold), growth control (0-100%), and faceted crystal shapes for a satisfying growth experience.

### 🎯 Core Features

- **Salt crystals** – faceted crystals grow on the surface
- **5 colors** – White, Pink, Blue, Purple, Gold
- **Growth control** – adjust growth from 0-100%
- **Faceted shapes** – 3-5 facet crystals with highlights
- **Crystal counter** – tracks number of crystals
- **Interactive controls** – slider, buttons, keyboard shortcuts
- **Responsive design** – adapts to different screen sizes

### ✨ Crystal Experience

When growing:
1. **Crystals grow** – faceted crystals expand on the surface
2. **Growth applies** – controls crystal size and count
3. **Color applies** – changes crystal color
4. **Crystals form** – new crystals appear
5. **Status updates** – shows current state

### 💡 Why Use This Component?

- Perfect for crystal shops, geology apps, or magical interfaces
- Satisfying crystal growth with faceted shapes

### 🛠️ Technologies Used

- **HTML5** – semantic structure with Canvas
- **CSS3** – gradients, backdrop-filter, transforms
- **JavaScript (ES6)** – Canvas API, requestAnimationFrame, particle system

### 🎨 Design Philosophy

This component embodies **EaseMotion CSS's animation-first philosophy** through:

- **Organic growth** – crystals grow naturally
- **Faceted shapes** – realistic crystal geometry
- **Visual feedback** – status updates, counter, controls
- **Crystal atmosphere** – sparkling, faceted crystals
- **Human-readable classes** – `.salt-controls`, `.color-btn`, `.salt-text`

### 🔧 Customization Options

| Property | Location | Default |
|----------|----------|---------|
| Colors | `colorConfigs` object | 5 colors |
| Growth range | `growthSlider` | 0-100% |
| Crystal count | `generateCrystals()` | 15-30 |
| Crystal size | `size` | 3-13px |
| Facets | `facets` | 3-5 |
