# CSS 3D Perspective Tilt Text Animation

A pure CSS typography hover effect that renders typography on a 3D perspective plane with realistic layered extrusion shadows and forward depth elevation.

## 🎯 Features
- **Pure CSS/HTML:** Zero JavaScript dependencies.
- **Hardware-Accelerated 3D Transforms:** Utilizes `perspective`, `transform-style: preserve-3d`, `rotateX`, `rotateY`, and `translateZ` for buttery 60fps rendering.
- **Dynamic Extruded Shadows:** Multi-layered text shadows dynamically shift depth and glow when elevated.
- **Dark Mode Compatible:** Tailored with high-contrast glowing accents optimized for dark backgrounds.
- **Accessible & Responsive:** Adapts via `clamp()` typography, supports keyboard `:focus-visible`, and disables motion transforms under `@media (prefers-reduced-motion: reduce)`.
