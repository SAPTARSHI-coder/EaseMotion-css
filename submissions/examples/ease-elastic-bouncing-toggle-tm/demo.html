Add CSS Elastic Bouncing Toggle for Web Layouts

A pure CSS component for the EaseMotion library.

Overview

A toggle switch featuring a playful, elastic bounce physics animation using spring-based cubic-bezier easing. This component uses no JavaScript and is built entirely with CSS custom properties and keyframe animations. It adapts to the surrounding design system via CSS variable overrides.

Toggle me

Usage

Copy the style.css file into your project and include it via a <link> tag. Apply the appropriate CSS classes to your HTML elements as shown in the demo above.

Customize colors and timing by overriding the CSS custom properties on a parent element or :root.

Accessibility

This component respects prefers-reduced-motion to disable animations for users who have enabled the motion reduction preference in their operating system.

Interactive variants use semantic HTML elements and support keyboard navigation with appropriate focus indicators.

Customization

All visual properties are exposed as CSS custom properties:

  • --elastic-bounce-toggle-primary — primary brand color
  • --elastic-bounce-toggle-duration-base — animation duration
  • --elastic-bounce-toggle-easing-spring — easing function
