# Gallery Caption

A photo grid whose captions slide up and overlay each image on hover.

## Features
- Responsive grid of framed artwork tiles
- Caption bar slides up on hover with a soft gradient
- Consistent, calm motion language

## Usage
```html
<div class="gc-item">
  <div class="art"></div>
  <div class="cap">Caption</div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
