# CSS Slide-Up Hero Section for SaaS Showcase Layouts

A modern **Slide-Up Hero Section** component built using pure HTML5 and CSS3 for SaaS showcase layouts. This component provides smooth entrance animations, a clean landing page structure, animated dashboard preview, and responsive behavior.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Modern SaaS landing page hero design
* Smooth slide-up entrance animation
* Animated dashboard preview card
* Glassmorphism UI styling
* Gradient glow background effects
* Interactive CTA buttons
* Responsive desktop, tablet, and mobile layouts
* CSS Custom Properties for easy customization
* Lightweight keyframe animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. View the slide-up animation effect on page load.
3. Customize colors, spacing, shadows, and animation values using CSS variables inside `:root`.

## CSS Custom Properties

```css
:root{
  --bg:#eef4ff;
  --surface:rgba(255,255,255,.92);
  --primary:#2563eb;
  --secondary:#06b6d4;
  --accent:#8b5cf6;
  --text:#111827;
  --muted:#64748b;
  --shadow:0 30px 80px rgba(37,99,235,.2);
  --radius:30px;
}
```
