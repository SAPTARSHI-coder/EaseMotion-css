# CSS Skew-Active Stepper

A lightweight, responsive stepper component that uses a subtle skew transformation to visually emphasize the active workflow stage.

The component is designed for minimalist technology interfaces and is implemented entirely with HTML and CSS.

## Features

- Pure HTML and CSS
- No JavaScript or external dependencies
- Skewed step cards for a modern tech aesthetic
- Distinct active-step styling
- Smooth hover and focus interactions
- Animated active marker
- Responsive desktop, tablet, and mobile layouts
- CSS custom properties for customization
- Semantic ordered-list structure
- `prefers-reduced-motion` support
