# CSS Blur-Entrance Tabs

A responsive CSS-only tabs component featuring a smooth blur entrance animation for creative portfolio layouts.

## Features

- Pure HTML & CSS
- Blur entrance animation
- CSS-only tab switching
- Responsive layout
- Accessible with `prefers-reduced-motion`
- No JavaScript required

## Files

```text
demo.html
style.css
README.md
```

## Usage

Open `demo.html` in any modern browser.

## Customization

- Tab colors
- Animation duration
- Blur amount
- Typography
- Container width

## Browser Support

Compatible with all modern browsers supporting CSS animations, filters, and transitions.
