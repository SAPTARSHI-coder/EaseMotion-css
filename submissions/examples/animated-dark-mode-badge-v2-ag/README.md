# Animated Dark Mode Badge (V2)

**What does this do?**
This is a sleek, responsive dark mode badge with a smooth gradient background, hover lift effect, icon rotation, and an animated shine sweep.

**How is it used?**
Use the `.dark-mode-badge` class on a container with `.icon`, `.text`, and `.glow` children.
```html
<div class="dark-mode-badge">
  <span class="icon">🌙</span>
  <span class="text">Dark Mode</span>
  <span class="glow"></span>
</div>
```

**Why is it useful?**
It provides a premium, interactive component suitable for modern dark-themed UIs, perfectly aligning with EaseMotion's philosophy of clean and engaging micro-interactions.
