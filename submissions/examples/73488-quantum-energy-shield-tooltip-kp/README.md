# Quantum Energy Shield Tooltip

A CSS tooltip variation for issue #73488. The trigger projects a shield field, the tooltip blooms with layered energy rings, and small particles orbit the label to create a quantum-protection interaction.

## Features

- Hover and keyboard focus tooltip reveal
- Animated shield rings, orbiting particles, shimmer border, and reduced-motion support
- Responsive accessible demo using pure HTML and CSS
- No JavaScript and no external assets

## Usage

Open `demo.html` in a browser and hover or focus the shield trigger.
