# CSS Slide-Up Carousel for Product Catalog Layouts

A modern **Slide-Up Carousel** built with pure HTML and CSS for EaseMotion CSS. Product information smoothly slides upward on hover, creating an elegant product showcase suitable for SaaS websites, e-commerce platforms, and product catalogs.

---

## Features

- Pure HTML5 & CSS3
- Smooth slide-up hover animation
- Responsive product cards
- Floating card animation
- Gradient CTA buttons
- CSS Custom Properties
- Modern product catalog layout
- Mobile-friendly design
- No JavaScript required
- Accessibility support with `prefers-reduced-motion`

## Accessibility

Supports:

```css
@media (prefers-reduced-motion: reduce)
```

to reduce animations for users who prefer minimal motion.
