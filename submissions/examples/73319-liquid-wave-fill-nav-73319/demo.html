Liquid Wave Fill

Hover or focus a navigation link to reveal a fluid wave that rises beneath the label while the surrounding layout remains completely stable.

LIQUID STUDY

Fluid link surfaces

Each interactive surface contains a decorative pseudo-element that expands from below. The text stays above the wave through stacking order, so the effect never obscures the link label.

Flow One Low tide Flow Two Rising tide Flow Three Full current
INTERACTION NOTES

Movement without reflow

The wave uses transforms instead of layout properties. This keeps surrounding content in the same position while the animated surface changes shape underneath the link.

Transform based

Scaling the decorative layer provides the main motion without changing document flow.

Keyboard ready

Native anchors retain normal keyboard behavior and receive a visible focus indicator.

Motion aware

The transition is removed when the user prefers reduced motion.

FINAL SURFACE

A reusable navigation pattern

The component is intentionally built with semantic HTML and vanilla CSS so the interaction can be adapted to a navigation bar, tab row, filter menu, or compact action group.
