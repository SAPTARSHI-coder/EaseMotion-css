# Liquid Wave Fill Navigation

## Overview

Issue #73319 demonstrates navigation links with a fluid fill that rises from the bottom on interaction.

## Features

- Pure HTML and vanilla CSS
- Transform-based liquid surface
- Responsive navigation
- Native keyboard focus
- Dark-mode compatible styling
- Reduced-motion support

## Files

- `demo.html` — navigation and content
- `style.css` — liquid fill and responsive rules
- `README.md` — documentation
