# Dynamic Pagination with Gradient Styling

A responsive pagination component featuring vibrant gradient effects, smooth hover interactions, and modern UI aesthetics.

## Features

- Pure HTML & CSS
- Fully responsive layout
- Gradient active-state styling
- Smooth hover animations
- Accessible navigation structure
- Lightweight and reusable

## Files

- demo.html
- style.css

## Usage

```html
<nav class="pagination">
  <a href="#" class="page-btn">1</a>
  <a href="#" class="page-btn active">2</a>
  <a href="#" class="page-btn">3</a>
</nav>
