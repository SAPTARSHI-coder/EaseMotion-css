# CSS-only Loader with SaaS Modern Styling

A responsive SaaS-inspired loading indicator built entirely with HTML and CSS.

## Features

- CSS-only implementation
- Smooth infinite rotation animation
- Modern SaaS design
- Responsive layout
- Lightweight and reusable
- No JavaScript required

## Files

- demo.html
- style.css

## Usage

Open `demo.html` in any modern browser.

## Customization

Modify:

- Loader size
- Border thickness
- Accent color
- Animation speed
- Background color

Example:

```css
.loader{
  border-top:6px solid #06b6d4;
}
```
