# Magnetic Glitch Hero Header - EaseMotion CSS

A high-impact Cyberpunk style Magnetic Glitch Hero Header UI component featuring keyframe clipping glitch animations and spring physics button hover interactions.

## 1. What does this do?
This component renders an interactive hero header featuring pseudo-element text clipping glitch effects alongside glowing magnetic CTA buttons.

## 2. How is it used?
Link `style.css` in your HTML document and structure your header markup:

```html
<link rel="stylesheet" href="style.css">

<header class="hero-section">
  <h1 class="glitch-title" data-text="HEADING TEXT">HEADING TEXT</h1>
  <button class="btn btn-primary">Action</button>
</header>
```

## 3. Why is it useful?
- **Zero JS Glitch:** Pure CSS `@keyframes` text clipping delivers seamless 60 FPS performance without canvas overhead.
- **Responsive Layout:** Automatically stacks CTA buttons and scales typography gracefully across viewport breakpoints.
- **Cyberpunk Aesthetics:** Engineered with neon glow filters and modern display palettes.
