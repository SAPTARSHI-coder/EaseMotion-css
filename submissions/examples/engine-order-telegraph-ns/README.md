# Engine Order Telegraph

## What does this do?
Renders a self-contained CSS-only `ease-engine-order-telegraph` demo: Ship engine-order telegraph handle swinging to FULL.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-engine-order-telegraph`. No build step or JavaScript is required for the effect.

```html
<section class="ease-engine-order-telegraph">
  <div class="ease-engine-order-telegraph__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
