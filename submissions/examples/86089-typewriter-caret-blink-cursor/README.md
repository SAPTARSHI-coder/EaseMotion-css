# Typewriter Caret Blink Cursor

A reusable CSS animation utility that creates a blinking typewriter cursor.

## Features

- Blinking caret animation
- CSS Custom Properties
- Configurable duration
- Configurable timing function
- Accessibility support
- Pure CSS
- No JavaScript

## CSS Variables

```css
--ease-typewriter-caret-duration: 0.8s;
--ease-typewriter-caret-timing: step-end;
```

## Animation

```css
.ease-anim-typewriter-caret-blink-cursor
```

Applies the reusable blinking cursor animation.

## Accessibility

Includes a `prefers-reduced-motion` media query to disable animation for users who prefer reduced motion.
