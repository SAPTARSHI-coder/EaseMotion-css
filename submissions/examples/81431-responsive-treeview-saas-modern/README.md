# Responsive Treeview - SaaS Modern

A responsive treeview component featuring a clean,
modern SaaS dashboard aesthetic.

The component is built with pure HTML and CSS and does not
require any external JavaScript dependency.

## Features

- Modern SaaS dashboard styling
- Responsive file tree
- Expandable and collapsible folders
- Nested tree structure
- Smooth hover transitions
- Active file state
- Status indicators
- Clean borders and subtle shadows
- Responsive desktop, tablet, and mobile layouts
- Keyboard-accessible tree controls
- Visible focus states
- `prefers-reduced-motion` support
- Zero external JavaScript dependencies
