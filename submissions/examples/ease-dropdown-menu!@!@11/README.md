# Animated Button Collection Submission

## 1. What does this do?
It provides a comprehensive collection of animated buttons showcasing different styles (primary, secondary, outline, gradient, icon) combined with various EaseMotion hover animations (scale, lift, grow, pulse).

## 2. How is it used?
Apply the base `.btn` class along with a style variant (`.btn-primary`, `.btn-secondary`, `.btn-outline`, `.btn-gradient-*`, `.btn-icon`) and combine with EaseMotion hover utilities like `ease-hover-scale`, `ease-hover-lift`, `ease-hover-grow`, or `ease-pulse`.

## 3. Why is it useful?
- Buttons are fundamental UI components used in every website.
- Demonstrates how EaseMotion hover animations can enhance button interactions.
- Multiple style variants for different use cases.
- Fully accessible with proper focus states.
- Includes `prefers-reduced-motion` support for accessibility.
- Mobile-responsive design.
- Maintainer can easily standardize this as `.ease-btn-[YOUR_INITIALS]` in the core library.
