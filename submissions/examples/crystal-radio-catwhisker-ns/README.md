# Crystal Radio Catwhisker

## What does this do?
Renders a self-contained CSS-only `ease-crystal-radio-catwhisker` demo: Crystal radio catwhisker probing a galena crystal.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-crystal-radio-catwhisker`. No build step or JavaScript is required for the effect.

```html
<section class="ease-crystal-radio-catwhisker">
  <div class="ease-crystal-radio-catwhisker__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
