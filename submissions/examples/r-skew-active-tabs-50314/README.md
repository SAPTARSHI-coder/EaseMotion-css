# CSS Skew-Active Tabs

A modern **Skew-Active Tabs** component built using pure HTML5 and CSS3 for Responsive Dashboard layouts. Active tabs feature a skewed appearance with smooth transitions while maintaining responsiveness and accessibility.

---

## ✨ Features

- Pure HTML5 & CSS3
- Skew-active tab animation
- Responsive dashboard layout
- Keyboard accessible using radio inputs
- CSS Custom Properties
- Smooth transitions
- No JavaScript required
- `prefers-reduced-motion` support
