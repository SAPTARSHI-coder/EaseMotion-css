# CSS Tooltip: Gradient Shimmer Variation

A smooth, accessible, and lightweight tooltip component featuring a **Gradient Shimmer** visual style.

## ✨ Features

- Pure HTML and Vanilla CSS
- No JavaScript or external dependencies
- Animated gradient shimmer effect
- Smooth tooltip transitions
- Hover and keyboard focus support
- Top, bottom, left, and right positions
- Responsive layout
- Dark-mode compatible
- Hardware-friendly CSS transforms
- `aria-describedby` and `role="tooltip"`
- `prefers-reduced-motion` support
