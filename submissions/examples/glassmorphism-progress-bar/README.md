# Dynamic Progress Bar – Glassmorphism

A responsive glassmorphism-inspired animated progress bar built using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Responsive layout
- Glassmorphism UI
- Animated progress fill
- Smooth gradient shimmer
- No JavaScript

## Usage

```html
<div class="progress-bar">
    <div class="progress-fill"></div>
</div>
```
