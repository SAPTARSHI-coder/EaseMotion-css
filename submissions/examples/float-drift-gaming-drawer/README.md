# CSS Float-Drift Drawer for Gaming Hub Layouts

A modern pure CSS animated drawer component designed for gaming dashboard interfaces.

The component uses smooth floating motion, glassmorphism styling, hover interactions, and responsive layouts without requiring JavaScript.

---

## ✨ Features

- 🎮 Gaming dashboard drawer UI
- 🌊 Smooth Float-Drift animation
- 🧊 Glassmorphism design
- ⚡ CSS-only implementation
- 🎨 Custom CSS variables
- 📱 Responsive layout support
- 🚫 No JavaScript dependency
- ♿ Reduced motion accessibility support

## 🚀 Usage

1. Open `demo.html` in any modern browser.
2. The animated gaming drawer will load automatically.
3. Customize animation values using CSS variables.

---

## 🎨 CSS Custom Properties

The animation can be customized through variables:

```css
:root {

    --float-distance:18px;

    --float-duration:4s;

    --transition:.35s;

}
```

### Change Floating Height

```css
--float-distance:30px;
```

### Change Animation Speed

```css
--float-duration:6s;
```
