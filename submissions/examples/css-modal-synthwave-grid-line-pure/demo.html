Pure CSS Modal: Synthwave Grid

A retro-futuristic, JavaScript-free modal utilizing the checkbox hack. Features a 3D animated perspective grid, glowing neon borders, and a stark cybernetic aesthetic.

SYSTEM_READY

The background utilizes a pseudo-3D CSS trick. A standard `linear-gradient` grid is drawn, then rotated 80 degrees on the X-axis within a perspective container. An infinite `@keyframes` animation translates the grid forward, simulating movement through a cybernetic landscape.
