# CSS Multi-color Progress Bar

A demo project showcasing a **multi-color progress bar** built with HTML, CSS, and JavaScript.

## Features
- Progress bar with a radiant multi-color gradient fill.
- Smooth transition animation when progress updates.
- Buttons to increase progress by 10% or 25%, and reset.
- Responsive, centered layout with glowing container.

## Files
- `demo.html` → Structure and JavaScript logic for progress updates.
- `style.css` → Styling for the progress bar, gradient fill, and controls.
- `README.md` → Documentation and usage instructions.

## Usage
1. Open `demo.html` in your browser.
2. Click **+10%** or **+25%** to increase progress.
3. Click **Reset** to reset progress to zero.
4. Watch the bar fill with a multi-color gradient.

## Customization Ideas
- Change gradient colors in `.progress-fill` for different themes.
- Adjust transition speed for faster/slower updates.
- Add labels or milestones along the bar.
- Integrate with real API data to reflect actual progress.
