# Firefly Light Glow Spark SCSS Animation

A reusable SCSS mixin pattern for the Firefly Light Glow Spark animation.

## Features

- Reusable SCSS mixin
- Configurable animation duration
- Configurable timing function
- Smooth firefly-style pulsing glow
- Uses `transform` and `opacity`
- Supports `prefers-reduced-motion`

## Usage

Import the SCSS file:

```scss
@use "firefly-light-glow-spark";
