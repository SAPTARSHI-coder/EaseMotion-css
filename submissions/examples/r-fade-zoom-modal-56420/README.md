# CSS Fade-Zoom Modal

A modern **Fade-Zoom Modal** built using pure HTML5 and CSS3 for Gaming Hub layouts. The modal fades and zooms smoothly into view while remaining lightweight, responsive, and accessible.

---

## ✨ Features

- Pure HTML5 & CSS3
- Fade-zoom entrance animation
- Gaming-inspired interface
- Fully responsive
- CSS Custom Properties
- Lightweight and performant
- Keyboard-accessible checkbox toggle
- `prefers-reduced-motion` support
- No JavaScript required

## 🚀 Usage

1. Copy the component into your project.
2. Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

3. Open `demo.html` in any modern browser.
