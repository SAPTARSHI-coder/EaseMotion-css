# Vitest Unit Spec — Scroll Progress Scroll Offset Calc

A comprehensive Vitest unit specification for **Scroll Progress Scroll Offset Calc**.

## Features

- 📜 Scroll progress event calculation & DOM width binding
- 📊 Percentage text label updating
- 🛡 Division-by-zero protection (`maxScroll <= 0`)
- 🧹 Scroll event listener cleanup on destroy()
