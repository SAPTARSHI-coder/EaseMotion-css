# CSS Slider: Neumorphic Soft Shadow Variation

A responsive and accessible slider featuring a soft neumorphic
design created entirely with HTML and vanilla CSS.

## Features

- Pure HTML and CSS
- Neumorphic soft-shadow styling
- Responsive slider layout
- CSS Scroll Snap navigation
- Smooth CSS transitions
- Light and dark mode support
- Keyboard-accessible navigation
- Visible focus indicators
- Reduced-motion support
- No JavaScript dependencies
- Hardware-friendly CSS transitions
