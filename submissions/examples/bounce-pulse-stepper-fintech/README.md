# CSS Bounce-Pulse Stepper for Fintech Dashboard Layouts

A responsive fintech transaction stepper built entirely with HTML and
CSS.

The component demonstrates a Bounce-Pulse interaction for the active
transaction stage while completed stages use success indicators and
future stages remain visually subdued.

## Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Vertical transaction stepper
- Bounce animation for active step
- Pulsing active-step ring
- Animated connector lines
- Completed, active and upcoming states
- Responsive desktop layout
- Responsive tablet layout
- Responsive mobile layout
- CSS custom properties
- Semantic HTML
- Accessible step structure
- Reduced-motion support
