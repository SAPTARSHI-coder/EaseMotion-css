# CSS Icon Only Sidebar

## Description

A pure CSS icon-only sidebar navigation component that expands on hover and reveals text labels alongside icons.

## Features

- Pure CSS implementation
- Icon-only compact sidebar
- Expands smoothly on hover
- Responsive layout
- Keyboard accessible navigation
- Supports light and dark mode
- Uses CSS custom properties for easy theming

## Usage

```html
<nav class="sidebar">
  <ul class="nav-links">
    <li>
      <a href="#">
        <span class="icon">🏠</span>
        <span class="label">Home</span>
      </a>
    </li>
  </ul>
</nav>
