# CSS Elastic-Slide Stepper for Creative Portfolio Layouts

A modern **Elastic-Slide Stepper** built completely with **HTML5 and CSS3**. This showcase demonstrates a smooth step navigation component with elastic animations, animated connectors, glassmorphism styling, responsive layouts, and accessibility support without requiring JavaScript.

---

## ✨ Features

- 🪄 Elastic slide animation effects
- 🔢 Multi-step progress visualization
- 🌈 Gradient active step styling
- 💎 Glassmorphism UI cards
- ⚡ Smooth CSS transitions
- 🎯 CSS Custom Properties
- 📱 Fully responsive layout
- 🧩 Pure HTML5 & CSS3
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

## 🚀 Getting Started

1. Open `demo.html` in any modern browser.
2. View the elastic stepper animation.
3. Hover over the steps to trigger interactive effects.
4. Customize colors, spacing, and animation speed using CSS variables.
