# CSS Skew-Active Modal for E-Commerce Checkout Layouts

A responsive, lightweight Skew-Active Modal designed for
e-commerce checkout interfaces.

The component uses only HTML and CSS and requires no JavaScript
or external dependencies.

## Features

- Pure HTML and CSS
- CSS-only modal interaction
- Skew-based modal entrance animation
- Smooth transform transitions
- Responsive desktop, tablet, and mobile layouts
- CSS custom properties
- Decorative skew animation
- Accessible reduced-motion support
- No external libraries
