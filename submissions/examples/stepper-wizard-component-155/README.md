# Multi-Step Animated Progress Stepper Wizard

A modern glassmorphic multi-step progress stepper wizard designed for onboarding flows, account setup, checkout processes, and multi-stage forms.

## ✨ Features

- Four-step animated progress indicator
- Glassmorphism design
- Frosted glass surfaces
- Gradient and neon accents
- Previous/Next navigation
- Completed-step indicators
- Animated progress lines
- Interactive preference cards
- Responsive design
- Keyboard focus states
- Reduced-motion support
- No external dependencies

## 🚀 Usage

Navigate to the component directory:

```bash
cd submissions/examples/ease-layout-multi-step-animated-progress-stepper-wizard-component-155
```

Open `demo.html` in a modern browser.

No package installation or build process is required.

## 🧭 Steps

The wizard contains four stages:

1. **Account** — Enter basic account information.
2. **Profile** — Add profile details.
3. **Customize** — Select workspace preferences.
4. **Finish** — View the completion state.

Use the **Continue** and **Previous** buttons to navigate between steps.

## 🎨 Customization

The main theme values are controlled through CSS variables.

```css
:root {
  --bg: #070914;
  --primary: #7c5cff;
  --secondary: #21d4fd;
  --success: #42f5a7;
}
```

You can change these values to create different color themes.

## ♿ Accessibility

The component includes:

* Semantic HTML
* Accessible progress navigation
* `aria-label`
* `aria-labelledby`
* `aria-live` progress updates
* Visible keyboard focus indicators
* High readability
* Reduced-motion support

Users who prefer reduced motion will have decorative animations and transitions minimized.

## 📱 Responsive

The component adapts to desktop, tablet, and mobile screen sizes.

On smaller screens, the stepper can scroll horizontally and form fields switch to a single-column layout.
