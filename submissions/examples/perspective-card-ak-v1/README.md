# perspective-card-ak

Pure CSS 3D perspective tilt card with internal layer parallax depth — no JavaScript required.

## How to use

```html
<div class="ease-perspective-card">
  <div class="ease-perspective-card__icon">🚀</div>
  <h3 class="ease-perspective-card__title">Title</h3>
  <p class="ease-perspective-card__desc">Description text.</p>
</div>

<!-- Direction Variants -->
<div class="ease-perspective-card ease-perspective-card--right">...</div>
<div class="ease-perspective-card ease-perspective-card--up">...</div>
