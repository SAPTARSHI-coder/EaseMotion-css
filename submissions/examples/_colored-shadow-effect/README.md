README.md

Features
🌈 Colored shadow — uses vibrant purple/blue shadows instead of standard black.
💡 Neon glow — creates a modern glowing-card appearance.
🖱️ Hover enhancement — shadow becomes stronger when the cursor enters.
🚀 Smooth transition — uses CSS transitions for fluid movement.
📦 Reusable — works with cards, buttons, images, logos, and containers.
⚡ Pure CSS — no JavaScript required.
🎨 Customizable colors — easily change the rgba() shadow colors.
