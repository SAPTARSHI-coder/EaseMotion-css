# ease-carousel-bh

Pure CSS snapping carousel component.

## What does this do?
Creates a horizontal carousel with CSS scroll-snap for smooth item-by-item scrolling.

## How is it used?
```html
<div class="ease-carousel-bh">
  <div class="ease-carousel-track-bh">
    <div class="ease-carousel-item-bh">Slide 1</div>
    <div class="ease-carousel-item-bh">Slide 2</div>
  </div>
</div>
```

## Why is it useful?
Provides smooth carousel functionality without JavaScript.
