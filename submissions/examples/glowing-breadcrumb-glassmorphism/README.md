# Glowing Breadcrumb with Glassmorphism Styling

A modern breadcrumb navigation component featuring a glassmorphism container with glowing interactive navigation items.

## Features

- Pure HTML & CSS
- Glassmorphism background
- Neon glow hover effects
- Responsive layout
- Current page highlight
- Accessible breadcrumb navigation
- No JavaScript required

## Folder Structure

```
glowing-breadcrumb-glassmorphism/
├── demo.html
├── style.css
└── README.md
```

## Technologies

- HTML5
- CSS3
- Flexbox
- Glassmorphism
- CSS Transitions
- Responsive Design

## Purpose

A reusable breadcrumb component suitable for dashboards, documentation, admin panels, portfolios, and modern web applications while following the lightweight philosophy of EaseMotion CSS.
