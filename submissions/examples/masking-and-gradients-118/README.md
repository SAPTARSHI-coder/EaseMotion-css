# Shimmering Metallic Foil Text Effect

A modern and vibrant metallic foil text effect built using pure HTML and CSS.

The component combines animated gradients, CSS masking, text clipping, glow effects, and smooth motion to create a premium shimmering typography effect.

## ✨ Features

- Metallic foil typography
- Animated shimmer/refraction effect
- CSS gradient animation
- CSS masking
- Gradient text clipping
- Vibrant purple, pink, blue, and cyan accents
- Hover glow effect
- Replay animation button
- Pause/resume animation
- Responsive design
- Reduced-motion accessibility support
- No external dependencies
