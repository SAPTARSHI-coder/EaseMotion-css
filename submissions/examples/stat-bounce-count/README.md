# Stat Bounce Count (#87567)

An interactive statistics counter component where numeric digits animate and bounce smoothly into position as numbers increment.

## Features
- **Elastic Digit Bounce:** Custom CSS `@keyframes` with `cubic-bezier` overshoot curves delivering fluid spring bounces.
- **Dynamic Increment Engine:** Lightweight JavaScript counter loop triggering staggered bounce animations per digit.
- **Multiple Metric Cards:** Pre-styled statistic cards displaying formatted active metrics, growth indicators, and trigger buttons.
- **Responsive & Accessible:** Clean dark-mode dashboard cards with reduced motion compliance.

## Usage
Include `style.css` in your project and wrap statistic displays with the `.stat-card` and `.digit-bounce` classes.
