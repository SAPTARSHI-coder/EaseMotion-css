# Minimalist Zen Task Manager (v40.5)

A mindful, minimalist task management component designed with warm neutral tones, interactive state tracking, smooth progress bars, and local storage persistence.

## 🌟 Features

- **Mindful & Minimalist UI**: Clean typography and subtle ambient background gradients.
- **Interactive Progress Bar**: Live progress tracking that dynamically calculates completed focus items.
- **Local Persistence**: Tasks are saved automatically in your browser's local storage.
- **Accessible & Responsive**: Keyboard navigability, clean screen-reader aria labels, and mobile-first CSS styling.
