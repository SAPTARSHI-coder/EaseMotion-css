# Derrick Pumpjack

## What does this do?
Renders a self-contained CSS-only `ease-derrick-pumpjack` demo: Oil pumpjack walking-beam nodding on a derrick.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-derrick-pumpjack`. No build step or JavaScript is required for the effect.

```html
<section class="ease-derrick-pumpjack">
  <div class="ease-derrick-pumpjack__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
