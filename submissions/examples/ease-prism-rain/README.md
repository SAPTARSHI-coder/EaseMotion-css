# 🌈 Prism Rain – Rainbow Drops Fall Like Rain

> A magical prism rain component where colorful rainbow drops fall like rain with 4 palettes (Rainbow, Pastel, Neon, Sunset), intensity control (0-100%), and glowing particle effects.

---

## 📖 Description

The **Prism Rain** component creates a magical prism rain experience where colorful rainbow drops fall like rain with glowing effects. Built with vanilla HTML, CSS, and JavaScript, it features 4 palettes (Rainbow, Pastel, Neon, Sunset), intensity control (0-100%), and particle effects for an enchanting experience.

### 🎯 Core Features

- **Prism rain** – colorful rainbow drops fall like rain with glow
- **4 palettes** – Rainbow, Pastel, Neon, Sunset
- **Intensity control** – adjust rain intensity from 0-100%
- **Particle effects** – glowing drops with trails
- **Drop counter** – tracks number of active drops
- **Interactive controls** – slider, palette buttons, keyboard shortcuts
- **Responsive design** – adapts to different screen sizes

### 🌈 Color Palettes

| Palette | Colors | Description |
|---------|--------|-------------|
| **Rainbow** | Red/Orange/Yellow/Green/Blue/Purple/Pink | Classic rainbow |
| **Pastel** | Soft pastel colors | Gentle, soft hues |
| **Neon** | Bright neon colors | Vibrant, glowing |
| **Sunset** | Warm sunset colors | Golden and warm |

### ⌨️ Interaction Options

| Method | Action |
|--------|--------|
| **Slider** | Adjust Intensity (0-100%) |
| **Buttons** | Palette selection |
| **Keyboard** | `R` – Reset |

### ✨ Prism Rain Experience

When interacting:
1. **Drops fall** – colorful rain falls with glow
2. **Intensity applies** – controls drop count and speed
3. **Palette applies** – changes color scheme
4. **Drops glow** – each drop has glow and trail
5. **Counter updates** – drop count in real-time
6. **Status updates** – shows current state

- Perfect for magical interfaces, fantasy themes, or enchanting experiences

### 🛠️ Technologies Used

- **HTML5** – semantic structure with Canvas
- **CSS3** – gradients, backdrop-filter, transforms
- **JavaScript (ES6)** – Canvas API, requestAnimationFrame, particle system

### 🎨 Design Philosophy

This component embodies **EaseMotion CSS's animation-first philosophy** through:

- **Organic motion** – drops fall with natural rain physics
- **Particle effects** – glowing drops with trails
- **Visual feedback** – status updates, counter, controls
- **Magical atmosphere** – rainbow colors and glow
- **Human-readable classes** – `.prism-controls`, `.palette-btn`, `.prism-text`

### 🔧 Customization Options

| Property | Location | Default |
|----------|----------|---------|
| Palettes | `palettes` object | 4 palettes |
| Intensity range | `intensitySlider` | 0-100% |
| Drop count | `generateDrops()` | 20-80 |
| Drop size | `size` | 1.5-5px |
| Trail length | `trail` | 8 steps |
