# Ease Empty State

## What does this do?

A minimal empty state component featuring an icon, title, description, and action button for situations where there is no content to display.

---

## How is it used?

Open `demo.html` in any modern browser.

Example:

```html
<div class="empty-state">
    <div class="icon">📂</div>
    <h2>No Files Found</h2>
    <p>Your description here.</p>
    <button>Upload File</button>
</div>
```

### Features

- Floating icon animation
- Title and description
- Primary action button
- Responsive layout
- Lightweight and reusable

---

## Why is it useful?

Empty state components improve user experience by clearly communicating when no content is available while encouraging the next action. This reusable component is suitable for dashboards, search results, file managers, and onboarding screens, aligning with EaseMotion CSS's animation-first philosophy.
