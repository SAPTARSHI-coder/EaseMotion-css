# Beacon Morse Flash

## What does this do?
Renders a self-contained CSS-only `ease-beacon-morse-flash` demo: Coastal signal beacon flashing a Morse code pattern.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-beacon-morse-flash`. No build step or JavaScript is required for the effect.

```html
<section class="ease-beacon-morse-flash">
  <div class="ease-beacon-morse-flash__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
