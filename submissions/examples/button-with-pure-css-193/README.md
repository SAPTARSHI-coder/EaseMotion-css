# Ripple Wave Ripple Click Canvas Effect Button

A modern dark-mode ripple wave button created with pure HTML and CSS.

## Features

- Dark mode UI
- Ripple wave animation
- Expanding ring effect
- Gradient button styling
- Glassmorphism-inspired container
- Hover and active interactions
- Responsive design
- Keyboard focus support
- Reduced-motion accessibility support
- No JavaScript
- No external dependencies
