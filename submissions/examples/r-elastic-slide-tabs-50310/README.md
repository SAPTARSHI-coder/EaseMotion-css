# CSS Elastic Slide Tabs

A responsive **Elastic Slide Tabs** component built using pure HTML5 and CSS3 for Responsive Dashboard layouts. The active indicator slides smoothly with an elastic animation while tab content transitions elegantly without JavaScript.

---

## ✨ Features

- Pure HTML5 & CSS3
- Elastic sliding active indicator
- Responsive dashboard layout
- Keyboard accessible using radio inputs
- CSS Custom Properties
- Smooth content transitions
- No JavaScript required
- `prefers-reduced-motion` support
