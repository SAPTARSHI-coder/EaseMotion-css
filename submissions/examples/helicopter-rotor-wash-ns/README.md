# Helicopter Rotor Wash

## What does this do?
Renders a self-contained CSS-only `ease-helicopter-rotor-wash` demo: Helicopter main rotor spinning with downwash rings.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-helicopter-rotor-wash`. No build step or JavaScript is required for the effect.

```html
<section class="ease-helicopter-rotor-wash">
  <div class="ease-helicopter-rotor-wash__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
