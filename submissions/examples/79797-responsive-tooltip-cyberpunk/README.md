# Responsive Tooltip with Cyberpunk Styling

A responsive CSS tooltip component featuring a futuristic cyberpunk visual style with neon cyan, pink, and purple accents.

## Features

- Responsive layout
- Hover and keyboard-focus tooltip interaction
- Neon cyberpunk visual styling
- Glowing borders and shadows
- Accessible tooltip semantics
- Additional responsive feature tooltips
- Reduced-motion support
- No JavaScript required

## Files

- `demo.html` — Component markup and demo content
- `style.css` — Complete responsive styling

## Usage

Open `demo.html` in a modern browser.

The main tooltip appears when the trigger is hovered or focused.

## Browser Support

Works in modern browsers supporting:

- CSS Grid
- CSS custom properties
- `backdrop-filter`
- CSS transitions
- Media queries
