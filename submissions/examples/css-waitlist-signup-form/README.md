# CSS Waitlist Signup Form

A responsive waitlist signup component featuring an animated
waitlist position counter and confirmation state.

## Features

- Pure HTML and CSS
- Responsive waitlist signup form
- Animated waitlist position
- Animated progress indicator
- Confirmation message
- Accessible form controls
- Keyboard navigation
- Visible focus states
- Semantic HTML
- ARIA live status
- Reduced-motion support
- No JavaScript dependencies
