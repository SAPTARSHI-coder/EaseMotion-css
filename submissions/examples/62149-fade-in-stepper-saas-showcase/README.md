# CSS Fade-In Stepper for SaaS Showcase Layouts

A clean and modern **Fade-In Stepper** built using pure HTML5 and CSS3 for SaaS showcase layouts. This component provides a step-based product journey experience with smooth fade transitions, animated navigation indicators, and a responsive glassmorphism interface.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Smooth fade-in step transitions
* CSS-only step navigation
* SaaS onboarding workflow showcase
* Animated step indicators
* Modern glassmorphism card design
* Feature icons with gradient styling
* Responsive layout for desktop, tablet, and mobile
* CSS Custom Properties for easy customization
* Smooth keyframe animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Click the numbered step buttons to switch between SaaS journey stages.
3. Experience the smooth fade-in animation between different steps.
4. Customize colors, shadows, spacing, and animations through CSS variables.

## CSS Custom Properties

```css
:root{
  --bg:#eef4ff;
  --surface:rgba(255,255,255,.92);
  --primary:#2563eb;
  --secondary:#06b6d4;
  --accent:#8b5cf6;
  --text:#111827;
  --muted:#64748b;
  --shadow:0 18px 45px rgba(37,99,235,.18);
  --radius:26px;
}
```
