# Glowing Filter Bar — SaaS Modern

A responsive, animated filter bar designed with a clean SaaS
visual language and implemented entirely with HTML and CSS.

## Overview

This component provides a modern resource-filtering interface
with:

- Search input
- Category filter chips
- Active filter glow
- Checkbox-style filter toggles
- Sort selector
- Clear-all action
- Animated accent glow
- Resource preview cards
- Responsive layouts

The implementation does not require JavaScript.
