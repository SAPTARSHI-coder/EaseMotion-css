# Ease Info Row

## What does this do?

A compact information row containing an icon, title, and supporting description.

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<div class="info-row">
    <div class="info-icon">✓</div>

    <div class="info-content">
        <strong>Secure Authentication</strong>
        <span>Your account is protected with secure login.</span>
    </div>
</div>
```

### Features

- Icon
- Title
- Description
- Hover state
- Smooth hover animation
- Responsive layout
- Pure CSS
- No JavaScript required

## Why is it useful?

Information rows are commonly used in settings pages, feature lists, dashboards, account pages, and configuration interfaces where related information needs to be displayed compactly.

This component provides a clean and reusable information layout with subtle hover feedback while following the animation-first philosophy of EaseMotion CSS.
