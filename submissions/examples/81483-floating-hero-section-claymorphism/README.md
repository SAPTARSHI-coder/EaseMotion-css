# Floating Hero Section - Claymorphism

A responsive floating hero section featuring a soft claymorphism
visual language with layered shadows, rounded surfaces, playful
shapes, and subtle CSS motion.

## Features

- Pure HTML and CSS
- Claymorphism-inspired UI
- Soft 3D depth using layered shadows
- Floating decorative shapes
- Animated hero visual
- Smooth hover interactions
- Responsive navigation
- Responsive hero layout
- Feature card section
- CSS-only decorative elements
- Keyboard focus states
- `prefers-reduced-motion` support
- No JavaScript dependencies
- No external libraries
