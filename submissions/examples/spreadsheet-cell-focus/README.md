# Spreadsheet Cell Focus

A grid of cells where the hovered column and row highlight and the active cell glows.

## Features
- Row and column tints cross to focus
- Active cell pops with a border glow
- Header cells slide on hover

## Usage
```html
<div class="sc2-grid">
  <div class="sc2-cell sc2-head">Q1</div>
  <div class="sc2-cell">1,240</div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
