# Liquid Wave Fill Toast

A smooth, accessible, and performant CSS toast notification featuring a Liquid Wave Fill visual style.

## Features

- Liquid wave-inspired visual effect
- Smooth wave transitions
- Subtle hover elevation
- Hardware-accelerated transforms
- Dark mode support
- Responsive layout
- Accessible toast semantics
- Keyboard-accessible close button
- Reduced-motion support
- Pure HTML and Vanilla CSS
- No external dependencies

## Files

- `demo.html` - Toast notification markup
- `style.css` - Complete component styling

## Usage

Open `demo.html` directly in a modern browser.

No JavaScript, frameworks, build tools, or external libraries are required.

## Accessibility

The component includes:

- `role="status"`
- `aria-live="polite"`
- `aria-atomic="true"`
- Accessible close button
- Visible keyboard focus state
- `prefers-reduced-motion` support

## Styling

The Liquid Wave Fill effect is created entirely with CSS pseudo-elements, gradients, border-radius, and GPU-friendly transforms.

The toast also responds automatically to the user's preferred color scheme.

## Technologies

- HTML5
- Vanilla CSS
