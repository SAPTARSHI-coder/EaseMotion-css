# Notification Toasts Example

This submission showcases a fully functional **Notification Toast System** enhanced with **EaseMotion CSS** animations. It demonstrates how to combine dynamic JavaScript DOM manipulation with EaseMotion's utility classes for smooth, professional UI feedback.

## ✨ Features
- **Dynamic Toast Generation**: JavaScript creates toasts on the fly with different states (Success, Warning, Error).
- **EaseMotion Animations**: 
  - `ease-slide-in-right`: Smooth, snappy entrance animation from the right side of the screen.
  - `ease-duration-fast`: Responsive timing perfect for transient notifications.
  - `ease-hover-lift`: Subtle interactive feedback when hovering over the toast or trigger buttons.
  - `ease-fade-in` & `ease-slide-up`: Staggered entrance for the demo container elements.
- **Auto-dismiss**: Toasts automatically fade out and remove themselves from the DOM after 4 seconds.

## 🚀 How to Use
1. Open `demo.html` in any modern web browser.
2. Click the "Success", "Warning", or "Error" buttons to trigger the respective toast notifications.
3. Observe the smooth `ease-slide-in-right` animation and the auto-dismiss behavior.
4. You can also manually close a toast by clicking the "×" button.

## 📂 Files
- `demo.html`: The standalone, responsive HTML demonstration with embedded trigger logic.
- `style.css`: Custom styling for the toast layout, state colors, and typography.
