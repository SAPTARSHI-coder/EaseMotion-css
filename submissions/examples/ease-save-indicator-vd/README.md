# Ease Save Indicator

## What does this do?

A compact status indicator for displaying "Saved" and "Saving..." states with an animated dot.

---

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<div class="save-indicator saved">
    <span class="save-dot"></span>
    <span>Saved</span>
</div>
```

For the saving state:

```html
<div class="save-indicator saving">
    <span class="save-dot"></span>
    <span>Saving...</span>
</div>
```

### Features

- Saved state
- Saving state
- Status text
- Animated dot
- Smooth CSS animation
- Responsive layout
- No JavaScript required

---

## Why is it useful?

Save indicators are commonly used in editors, forms, documents, and applications with autosave functionality.

This component provides a lightweight visual way to communicate save status while following the animation-first philosophy of EaseMotion CSS.
