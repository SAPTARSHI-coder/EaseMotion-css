# Infinite Seamless CSS Marquee

A perfectly smooth, infinitely looping marquee ticker built entirely in CSS without layout thrashing.

## Features
- Zero Jumps: Seamlessly loops by shifting the track exactly 50%.
- Hardware Accelerated: Uses will-change to run on the GPU.
- Interactive: Pauses smoothly on hover.

## Usage
Add your content inside the content wrapper and then duplicate that exact wrapper div.
