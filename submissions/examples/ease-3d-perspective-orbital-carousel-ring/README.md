# Ease 3D Perspective Orbital Carousel Ring (`ease-3d-perspective-orbital-carousel-ring`)

Angled 3D orbital ring of feature cards rotating around a central focal point.

## Features
- 3D spatial orbital rotation ring (`rotateX(30deg)`)
- Dynamic card scale and opacity depth fading for back-facing items
- Click-to-focus card elevation to center stage
- Drag-to-rotate inertia physics loop
- Fully responsive stage scaling
