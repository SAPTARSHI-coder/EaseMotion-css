# 🌀 Labyrinth Nav – Items Reveal Path Like a Maze

> An interactive, puzzle-like navigation where items reveal a path like a maze on hover, creating a mysterious, exploratory experience.

---

## 📖 Description

The **Labyrinth Nav** is an interactive, puzzle-like navigation component where items reveal a path like a maze on hover. When you hover over a navigation item, a glowing path emerges, revealing the item's path designation and creating a sense of discovery and exploration. The effect mimics the feeling of navigating through a labyrinth or maze.

The component uses CSS animations with gradient glows and border effects to create the path reveal. Each item has a unique path label that appears on hover, adding to the mysterious, exploratory feel. The grid layout with subtle maze-like walls completes the labyrinth aesthetic.

Perfect for puzzle-themed interfaces, gaming websites, mystery brands, and any application where you want to create an exploratory, discovery-based navigation experience. The Labyrinth Nav transforms a simple menu into a mysterious, maze-like interaction.
