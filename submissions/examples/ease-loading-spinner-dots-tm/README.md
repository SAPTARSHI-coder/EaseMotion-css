# Loading Spinner Dots Component

Add ease-loading-spinner-dots-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|---------|
| `--lsd-accent` | `#6366f1` |
| `--lsd-accent2` | `#ec4899` |
| `--lsd-size` | `12px` |
| `--lsd-speed` | `0.8s` |

## Technique

`translateY` keyframes with staggered `animation-delay` create the bouncing dot cascade.
