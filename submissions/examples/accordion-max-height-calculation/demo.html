Dynamic Accordion Example

Accurate CSS transitions using JavaScript scrollHeight calculation.

CSS cannot natively animate to height: auto smoothly. By using JavaScript to calculate the actual pixel height (scrollHeight) of an item when clicked, we can dynamically assign max-height for a precise, hardware-accelerated transition.

If you hardcode max-height: 1000px on a element that is only 100px tall, the CSS transition timing breaks. The element expands almost instantly and takes a long time to start closing because it has to transition all the way down from 1000px.
