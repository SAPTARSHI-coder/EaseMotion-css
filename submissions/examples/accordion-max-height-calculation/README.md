# Accordion Toggle Smooth Max-Height Calculation

## Overview

This submission adds automated Vitest unit tests for validating accordion max-height calculations used during expand/collapse animations.

## Test Coverage

- Expanded state
- Collapsed state
- Zero height
- Large heights
- Decimal heights
- Negative values
- Null input
- Undefined input
- String input
- Object input
- Toggle behavior
- Repeated calculations

## Demo

Open `demo.html` directly in any browser.

## Run Tests

```bash
npx vitest run submissions/examples/accordion-max-height-calculation/accordion-max-height.test.js
```
