# 🌸 Cherry Blossom – Petals Float Gracefully Down

> A peaceful cherry blossom component where petals float gracefully down with wind control (0-10), density control (1-10), and 4 petal colors.

---

## 📖 Description

The **Cherry Blossom** component creates a serene cherry blossom experience where petals float gracefully down through the air. Built with vanilla HTML, CSS, and JavaScript, it features wind control (0-10), density control (1-10), 4 petal colors, and organic petal animation.

### 🎯 Core Features

- **Floating petals** – organic petals drift down with gentle motion
- **Wind control** – adjust wind from 0-10 affecting petal drift
- **Density control** – adjust petal density from 1-10 (10-90 petals)
- **4 petal colors** – soft pink shades for variety
- **Petal counter** – tracks number of petals in the scene
- **Background** – sky gradient with clouds and cherry blossom tree silhouette
- **Interactive controls** – sliders, keyboard shortcuts
- **Responsive design** – adapts to different screen sizes

### ⌨️ Interaction Options

| Method | Action |
|--------|--------|
| **Sliders** | Adjust Wind (0-10) and Density (1-10) |
| **Button** | Reset |
| **Keyboard** | `R` – Reset |

### ✨ Cherry Blossom Experience

When interacting:
1. **Petals float** – organic petals drift down gracefully
2. **Wind applies** – controls petal drift and speed
3. **Density applies** – controls number of petals
4. **Counter updates** – petal count in real-time
5. **Status updates** – shows current state

### 💡 Why Use This Component?

- Perfect for meditation apps, relaxation tools, or calming interfaces
- Peaceful cherry blossom experience with graceful motion
- Self-contained – no external dependencies or frameworks
- Easy to customize (colors, density, wind behavior)
- Wind and density controls for customization

### 🛠️ Technologies Used

- **HTML5** – semantic structure with Canvas
- **CSS3** – gradients, backdrop-filter, transforms
- **JavaScript (ES6)** – Canvas API, requestAnimationFrame, particle system

### 🎨 Design Philosophy

This component embodies **EaseMotion CSS's animation-first philosophy** through:

- **Organic motion** – petals float with natural, graceful movement
- **Particle effects** – soft, organic petal shapes
- **Visual feedback** – status updates, counter, controls
- **Calming atmosphere** – soft pink colors and gentle motion
- **Human-readable classes** – `.sakura-controls`, `.sakura-text`

### 🔧 Customization Options

| Property | Location | Default |
|----------|----------|---------|
| Petal colors | `petalColors` array | 4 colors |
| Wind range | `windSlider` | 0-10 |
| Density range | `densitySlider` | 1-10 |
| Petal count | `densitySlider` | 10-90 |
| Petal size | `Petal.size` | 5-13px |
