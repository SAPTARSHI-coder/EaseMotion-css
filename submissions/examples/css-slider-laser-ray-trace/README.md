# CSS Slider: Laser Ray Trace Variation

A futuristic pure CSS slider featuring animated
laser rays that continuously trace the boundaries
of each slider card.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript
- No external dependencies
- Animated laser edge tracing
- Glowing ray effect
- CSS Scroll Snap
- Smooth transitions
- Responsive design
- Dark-mode compatible
- Keyboard-accessible navigation
- Reduced-motion support
- Hardware-friendly transforms
