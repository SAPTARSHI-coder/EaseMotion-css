# CSS Stock Ticker Widget (#71011)

A pure CSS infinite sliding stock market ticker featuring live price indicators, color-coded gain/loss badges, and up/down arrow icons.

## Features
- Continuous horizontal animation utilizing CSS `@keyframes` with zero JavaScript.
- Automatic hover & focus state pausing (`animation-play-state: paused`) for user readability.
- Embedded SVG up/down directional indicators.
- Responsive layout with gradient edge masks for smooth visual transitions.
- Standardized BEM structure (`ease-stock-ticker`).
- Supports accessibility guidelines including screen reader roles and `prefers-reduced-motion`.
