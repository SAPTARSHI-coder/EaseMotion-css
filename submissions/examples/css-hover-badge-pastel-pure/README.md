# Hover Badge with Pastel Styling

A collection of soft, playful, and highly interactive badge components built using pure HTML and CSS.

## Features
- Carefully curated Pastel color palettes (Pink, Mint, Blue, Yellow) for a soft, approachable aesthetic
- Spring-like hover animations utilizing `cubic-bezier` for both the badge container and inner icons
- Dynamic colored drop-shadows on hover that match the text color of the specific badge
- Optional sub-components included: numeric counters and pulsing status dot indicators
- Fully responsive pill-shaped layout

## Usage
Include `demo.html` and `style.css` in your project. Apply the `.pastel-badge` class along with a specific color variant class (e.g., `.badge-pink`) to your anchor or span tags.
