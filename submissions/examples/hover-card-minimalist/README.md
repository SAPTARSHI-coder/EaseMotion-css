# Minimalist Hover Cards

A responsive collection of minimalist profile hover cards built with
pure HTML and CSS.

## Features

- Pure HTML and CSS
- No JavaScript
- Responsive layout
- Minimalist UI
- Smooth hover animation
- Keyboard focus support
- Animated avatar interaction
- Animated arrow interaction
- Subtle gradient glow
- Reduced-motion support
- Mobile-friendly
