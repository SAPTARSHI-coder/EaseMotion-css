# CSS 3D Effect: Particle Burst

A smooth, accessible, and performant pure CSS 3D particle burst animation inspired by expanding particle explosions and dimensional motion.

## Features

- Pure HTML and Vanilla CSS
- 3D particle burst animation
- CSS `perspective` and `translate3d`
- Layered glowing particle system
- Smooth CSS transitions and animations
- Dark mode compatible
- Responsive layout
- Hardware-friendly transforms
- Accessible focus states
- `prefers-reduced-motion` support
- No external JavaScript
- No external libraries
