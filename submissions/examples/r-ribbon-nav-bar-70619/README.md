# CSS Ribbon Nav Bar

A responsive ribbon-style navigation bar created using pure HTML and CSS.

## Features

- Pure CSS implementation
- Folded ribbon-style navigation
- Hover interaction
- Active navigation state
- Keyboard focus support
- Responsive layout
- Mobile-friendly navigation
- Reduced-motion support
- No JavaScript required

## Files

- `demo.html` — Example markup and navigation structure
- `style.css` — Complete styling and responsive behavior
- `README.md` — Documentation

## Usage

Open `demo.html` in a modern browser.

The component can be copied into an existing project by including the
navigation markup and `style.css`.

## Accessibility

The navigation uses:

- Semantic `<nav>` markup
- `aria-label` for navigation context
- `aria-current="page"` for the active item
- Visible `:focus-visible` styles
- Responsive text and layout
- `prefers-reduced-motion` support

## Browser Support

Works in modern browsers supporting:

- CSS Grid
- CSS Flexbox
- CSS gradients
- CSS pseudo-elements
- CSS media queries
- `prefers-reduced-motion`
