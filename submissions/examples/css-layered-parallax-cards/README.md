# CSS Layered Parallax Cards

A set of interactive cards that tilt on hover to reveal deeply layered parallax internal elements.

## Features
- Hardware accelerated 3D volume initialized using `transform-style: preserve-3d`.
- Deep, immersive parallax separation created by projecting individual child nodes across the Z-axis via `transform: translateZ()`.
- Dynamic perspective stretching on hover by increasing the depth distance between layers.
