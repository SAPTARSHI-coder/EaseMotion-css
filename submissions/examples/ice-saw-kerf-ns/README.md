# Ice Saw Kerf

## What does this do?
Renders a self-contained CSS-only `ease-ice-saw-kerf` demo: Ice harvest saw cutting a kerf across a frozen block.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-ice-saw-kerf`. No build step or JavaScript is required for the effect.

```html
<section class="ease-ice-saw-kerf">
  <div class="ease-ice-saw-kerf__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
