# CSS Contact Card

A responsive business contact card built using pure HTML and CSS.

## Features

- Pure HTML and CSS
- Responsive design
- Avatar section
- Name and professional title
- Description
- Social/contact links
- Hover animation
- Accessible focus states
- Reduced-motion support
- No JavaScript required

## Files

- `demo.html` – Contact card demonstration
- `style.css` – Component styles

## Usage

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
