# ❄️ Snow Globe – Snow Swirls When Shaken

> A magical snow globe component where snow swirls when shaken with 4 scenes (Winter, Magic, Aurora, Golden), shake control (0-100%), and 100-150 six-point snowflakes.

---

## 📖 Description

The **Snow Globe** component creates a magical snow globe experience where snow swirls when shaken with organic motion. Built with vanilla HTML, CSS, and JavaScript, it features 4 scenes (Winter, Magic, Aurora, Golden), shake control (0-100%), and 100-150 six-point snowflakes for a delightful experience.

### 🎯 Core Features

- **Snow globe** – snow swirls when shaken with organic motion
- **4 scenes** – Winter, Magic, Aurora, Golden with unique colors
- **Shake control** – adjust shake from 0-100%
- **Snowflakes** – 100-150 six-point snowflakes
- **Globe effects** – glass reflection and base
- **Interactive controls** – slider, scene buttons, keyboard shortcuts
- **Responsive design** – adapts to different screen sizes

### ❄️ Scenes

| Scene | Icon | Colors | Description |

| **Golden** | 🌟 | Gold | Golden scene |

### ⌨️ Interaction Options

| Method | Action |
|--------|--------|
| **Slider** | Adjust Shake (0-100%) |
| **Buttons** | Shake, Reset |
| **Keyboard** | `Space` or `S` – Shake · `R` – Reset |

### ✨ Snow Globe Experience

When shaking:
1. **Snow swirls** – snowflakes dance in the globe
2. **Shake applies** – controls snow movement
3. **Scene applies** – changes color scheme
4. **Snow settles** – flakes drift down
5. **Status updates** – shows current state

- Perfect for winter themes, holiday interfaces, or magical experiences
- Delightful snow globe with swirling snow

### 🛠️ Technologies Used

- **HTML5** – semantic structure with Canvas
- **CSS3** – gradients, backdrop-filter, transforms
- **JavaScript (ES6)** – Canvas API, requestAnimationFrame, particle system

### 🎨 Design Philosophy

This component embodies **EaseMotion CSS's animation-first philosophy** through:

- **Organic motion** – snow swirls naturally
- **Particle effects** – six-point snowflakes
- **Glass effects** – reflection and glow
- **Visual feedback** – status updates, counter, controls
- **Magical atmosphere** – scenes and snow
- **Human-readable classes** – `.snowglobe-controls`, `.scene-btn`, `.snowglobe-text`

### 🔧 Customization Options

| Property | Location | Default |
|----------|----------|---------|
| Scenes | `scenes` object | 4 scenes |
| Shake range | `shakeSlider` | 0-100% |
| Snow count | `generateSnowflakes()` | 100-150 |
| Snowflake size | `size` | 1-4px |
