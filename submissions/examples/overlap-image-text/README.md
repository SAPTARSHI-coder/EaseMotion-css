# CSS Overlap Image Text

A creative image-and-typography composition where large text overlaps an abstract landscape using CSS positioning and `clip-path`.

## Features

- Pure HTML and CSS
- Creative text/image overlap
- CSS `clip-path` shapes
- Abstract landscape generated with CSS
- Responsive layout
- Hover and focus interactions
- Accessible semantic structure
- Keyboard-friendly focus behavior
- Reduced-motion support
- No JavaScript
- No external images or libraries
