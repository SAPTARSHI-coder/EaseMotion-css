# CSS 3D-Flip Dropdown for SaaS Showcase Layouts

A modern **3D-Flip Dropdown** component built using pure HTML5 and CSS3 for SaaS showcase layouts. This component provides an interactive dropdown experience with 3D flip transformations, glassmorphism styling, smooth transitions, and responsive behavior.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* CSS-only dropdown interaction
* Smooth 3D flip animation
* Perspective-based transformations
* SaaS navigation showcase UI
* Glassmorphism dropdown cards
* Animated gradient states
* Smooth rotateX transitions
* Interactive resource links
* Responsive desktop, tablet, and mobile layouts
* CSS Custom Properties for easy customization
* Smooth keyframe animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Click dropdown cards to trigger the 3D flip effect.
3. Customize colors, shadows, radius, and animation timing using CSS variables inside `:root`.

## CSS Custom Properties

```css
:root{
  --bg:#eef4ff;
  --surface:rgba(255,255,255,.92);
  --primary:#2563eb;
  --secondary:#06b6d4;
  --accent:#8b5cf6;
  --text:#111827;
  --muted:#64748b;
  --shadow:0 20px 55px rgba(37,99,235,.18);
  --radius:26px;
}
```
