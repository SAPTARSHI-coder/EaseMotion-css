ease-accordion

An accordion that animates to auto height.

Expandable panels on native <details>/<summary>, enhanced with a smooth height animation via the CSS grid-template-rows: 0fr → 1fr trick and a rotating chevron — since <details> alone snaps open/closed. No JS.

FAQ

What is EaseMotion CSS?

A lightweight, animation-first CSS component library. It ships small, composable utility classes for the interactions designers rebuild on every project — spinners, sticky headers, accordions, and more — without pulling in a full framework.

Do I need JavaScript?

No. This accordion leans on the native <details> element for open/close state, so toggle logic, keyboard support, and screen-reader semantics come for free. The only JavaScript anywhere in EaseMotion is the occasional single-boolean scroll listener.

How does the height animation work?

CSS can't animate height: auto directly. The classic workaround is to wrap the content in a grid container and animate grid-template-rows from 0fr to 1fr. The browser interpolates the row track, so the panel slides open smoothly to whatever its natural height is.

Is it accessible?

Yes. Because it's built on <details>/<summary>, the panel is operable with the keyboard (Enter/Space to toggle, Tab to move), and assistive tech announces the expanded/collapsed state automatically. The chevron is decorative and hidden from screen readers.

Can multiple panels stay open at once?

Yes. Unlike a classic accordion built with JS, independent <details> elements each manage their own state, so any number can be open simultaneously. If you want single-open behavior, that's the one place you'd add a tiny script — or leave it out and let users compare answers.
