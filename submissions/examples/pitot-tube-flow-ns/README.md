# Pitot Tube Flow

## What does this do?
Renders a self-contained CSS-only `ease-pitot-tube-flow` demo: Pitot tube dynamic pressure rising with airflow.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-pitot-tube-flow`. No build step or JavaScript is required for the effect.

```html
<section class="ease-pitot-tube-flow">
  <div class="ease-pitot-tube-flow__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
