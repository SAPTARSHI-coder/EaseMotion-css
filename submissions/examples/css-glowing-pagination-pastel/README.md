# Glowing Pagination with Pastel styling (#78889)

An interactive glowing pagination component featuring soft pastel neon accents, active gradients, and focus animations built entirely with pure CSS.

## Features
- **Semantic Structure:** Accessible `<nav>` and unordered list markup with clear ARIA labels.
- **Pastel Glow Aesthetic:** Soft purple and pink gradients with delicate neon glow box shadows.
- **Responsive Layout:** Flexbox arrangement that adapts fluidly across all display sizes.

## File Hierarchy
- `style.css` - Component variables, pastel glow effects, and state transitions.
- `demo.html` - Semantic structure and accessibility attributes.
- `README.md` - Technical specification and architecture overview.
