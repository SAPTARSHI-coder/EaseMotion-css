# CSS Pulsating Wave Progress

Issue #73505 demonstrates a progress bar with a calm animated wave and subtle pulsating fill.

## Features

- Moving wave overlay
- Pulsating progress fill
- Accessible progressbar semantics
- Responsive sizing
- Reduced-motion support
- No JavaScript or external dependencies

## Usage

Open `demo.html`. Set the `--value` property on the progress fill to change the percentage.

## Files

- `demo.html` — progress structure
- `style.css` — wave, pulse, responsive, and accessibility styling
- `README.md` — documentation
