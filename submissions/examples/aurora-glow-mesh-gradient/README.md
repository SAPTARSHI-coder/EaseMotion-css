# Aurora Glow Mesh Gradient

A smooth CSS-only mesh gradient component inspired by the soft luminous colors and flowing movement of an aurora.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript or external dependencies
- Layered mesh-gradient blobs
- Smooth animated aurora movement
- Animated gradient heading
- Neumorphic-inspired depth and shadows
- Responsive layout
- Dark and light color-scheme support
- Keyboard-accessible buttons
- Visible `:focus-visible` states
- `prefers-reduced-motion` support
- Hardware-friendly transforms and opacity animations
