# CSS Split Text Button

A pure CSS button animation where the main label slides away and reveals a secondary label on hover.

## Features

- Pure CSS implementation
- Smooth text transition effect
- Keyboard accessible
- Responsive design
- Customizable colors and sizing
- No JavaScript required

## Usage

```html
<button class="split-btn">
  <span class="primary">Download</span>
  <span class="secondary">Get File</span>
</button>
```

## Customization

Modify the CSS variables:

```css
:root {
  --primary-color: #2563eb;
  --secondary-color: #1e40af;
}
```
