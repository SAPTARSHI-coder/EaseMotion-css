# 3D Perspective Tilt Card

A smooth and interactive card component featuring a pure CSS 3D perspective tilt effect.

The component uses only HTML and Vanilla CSS. No JavaScript or external dependencies are required.

## Features

- Pure HTML and Vanilla CSS
- 3D perspective tilt on hover
- Smooth X/Y rotation
- Layered elevation and shadows
- Subtle depth using `translateZ()`
- Responsive design
- Dark-mode compatible
- Hardware-accelerated transforms
- Keyboard-friendly focus styling
- Reduced-motion support
- No external dependencies
