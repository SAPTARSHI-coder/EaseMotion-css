# Neon Glowing Text Input

A modern, highly interactive text input with a floating label and an animated multi-color neon glow effect upon focus.

### Usage
```html
<div class="input-wrapper">
  <input type="text" id="neon-input" class="neon-input" placeholder=" " autocomplete="off" />
  <label for="neon-input" class="neon-label">Enter Username</label>
  <div class="neon-border"></div>
</div>
```

### Why is it useful?
This component introduces a vibrant, cyberpunk-inspired aesthetic. The floating label enhances accessibility while the animated gradient background and box-shadow provide immediate, deeply satisfying visual feedback when a user focuses on the input. This perfectly aligns with EaseMotion's goal of offering premium, WOW-factor micro-interactions.
