# Glowing Dark Sidebar

Issue #79696 demonstrates a responsive dark sidebar with restrained glow accents.

## Features

- Dark visual system
- Responsive navigation
- Focus-visible links
- Compact status panels
- Pure HTML and vanilla CSS

## Usage

Open demo.html to preview the component. Link style.css when integrating the sidebar into another page.

## Responsive behavior

The two-column workspace changes to a single-column layout on smaller screens and the sidebar becomes part of the normal document flow.

## Accessibility

Navigation uses native links and visible keyboard focus.
