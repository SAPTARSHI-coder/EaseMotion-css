# Loading Spinner Variants

A collection of lightweight CSS-only loading spinner animations for web interfaces.

## Features

- Pure HTML and CSS
- No JavaScript
- Multiple spinner variants
- Smooth animations
- Responsive design
- Reduced-motion support
- Easy to customize

## Spinner Variants

### 1. Ring

A rotating circular loader.

### 2. Dots

Three animated dots with staggered movement.

### 3. Pulse

A circular loader that continuously scales and fades.

### 4. Square

A rotating square loader.
