# CSS Pixel Dissolve Button

A pure CSS button animation that creates a pixel-dissolve effect when the button is pressed.

## Features

- Pure HTML and CSS
- No JavaScript required
- Pixel-style dissolve animation
- Interactive hover state
- Responsive design
- Keyboard focus styling
- `prefers-reduced-motion` support

## Usage

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
<button class="pixel-button" type="button">
  <span>Click Me</span>
</button>
