# Responsive Tab Bar with SaaS Modern Styling

A clean and responsive SaaS-inspired tab bar built using pure HTML and CSS.

The component provides a modern navigation experience with active states, subtle motion, responsive behavior, and reusable EaseMotion-style design tokens.

## ✨ Features

- Modern SaaS visual style
- Responsive tab navigation
- Active tab indicator
- Smooth hover interactions
- Keyboard focus styling
- Scrollable tabs on smaller screens
- Responsive content area
- Status indicator
- CSS custom properties for design tokens
- Zero external JavaScript dependencies
- `prefers-reduced-motion` support
