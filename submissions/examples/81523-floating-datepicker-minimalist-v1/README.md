# Floating Datepicker with Minimalist Styling

A clean and responsive floating datepicker component built with
semantic HTML and pure CSS.

## Features

- Pure HTML and CSS
- Zero external JavaScript dependencies
- Native browser date picker
- Floating label
- Minimalist visual design
- Smooth focus and hover transitions
- Responsive desktop, tablet, and mobile layouts
- Keyboard accessible
- Native browser validation
- `prefers-reduced-motion` support
- No external libraries
