# CSS Skew Active Modal

A responsive modal component with a smooth skew-active entrance animation using only HTML and CSS.

## Features

- Pure HTML & CSS
- Responsive design
- Skew entrance animation
- Hover interactions
- Smooth transitions
- No JavaScript
- Supports `prefers-reduced-motion`

## Folder Structure

```
skew-active-modal/
├── demo.html
├── style.css
└── README.md
```

## Usage

Open `demo.html` in any modern browser.

## Customization

Modify the following CSS values:

- Modal width
- Background colors
- Animation timing
- Border radius
- Shadow
- Typography

## Accessibility

- Semantic HTML
- Responsive layout
- Reduced motion support
