# CSS Confetti Pop Button v2

A pure CSS animated confetti burst button component.

## Features

- 🎉 CSS-only confetti animation
- ✨ Multiple confetti shapes
- 🖱️ Hover interaction
- 📱 Responsive design
- ♿ Accessible button markup

## Usage

Open `demo.html` in your browser.

## Files

- `demo.html` - Component structure
- `style.css` - Animation and styling
