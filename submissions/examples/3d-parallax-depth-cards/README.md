# Multi-layer 3D Parallax Depth Cards

A CSS-only optical illusion card that separates content into multiple Z-planes, creating a parallax effect when the parent element is tilted.

## Features
- True 3D Rendering: Employs transform-style preserve-3d.
- Layer Separation: Individual layers pushed apart using translateZ.

## Usage
Structure your layers inside the card container. The scene wrapper provides the perspective necessary for the 3D effect.
