# Animated Social Share Buttons (`ease-social-share-xyz`)

A zero-dependency, CSS-only animated social share buttons component designed for the **EaseMotion CSS** framework. Perfect for content sharing with smooth animations, platform-specific colors, and ripple effects.

> **Note:** The `xyz` suffix is my unique contributor identifier as per the repository's Contribution Policy Update to prevent naming conflicts.

## ✨ Features
- **Zero JavaScript**: Pure CSS implementation using CSS animations and transitions.
- **Animation-First**: Smooth fade-in, hover lift, icon rotation, and ripple effects using EaseMotion timing tokens.
- **Design Token Compatible**: Leverages `--ease-duration-normal`, `--ease-out`, and color tokens for seamless theming.
- **Multiple Layouts**: Horizontal, vertical, circular icon-only, and floating sticky bar.
- **Platform-Specific Colors**: Twitter, Facebook, LinkedIn, Instagram, YouTube, TikTok, WhatsApp, Email, and Copy Link.
- **Share Counts**: Optional share count badges.
- **Ripple Effect**: Material Design-inspired ripple on click.
- **Tooltips**: Optional tooltips on hover.
- **Staggered Reveals**: Buttons animate in sequence.
- **Floating Bar**: Sticky sidebar for long-form content.
- **Accessible**: Proper ARIA labels and keyboard navigation support.
- **Reduced Motion Safe**: Respects `prefers-reduced-motion` OS settings.
