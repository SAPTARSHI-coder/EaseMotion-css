# Cube Rotate Gallery

Six faces of a 3D cube rotate continuously, showcasing a mini gallery.

## Features
- True CSS 3D cube construction
- Continuous rotation animation
- Gradient faces with labels
- Pause on hover

## Usage
```html
<div class="crg-cube"><div class="crg-face">A</div></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
