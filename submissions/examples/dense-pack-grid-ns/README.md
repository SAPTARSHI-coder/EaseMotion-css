# CSS Dense Pack Grid (#71032)

A zero-JS CSS Grid layout utilizing `grid-auto-flow: dense` and auto-fill tracks to build gapless, masonry-style responsive layout grids.

## Features
- Pure CSS grid layout packing (`grid-auto-flow: dense`).
- Reusable column and row span utilities (`ease-dense-card--wide`, `ease-dense-card--tall`, `ease-dense-card--large`).
- Responsive layout rules for mobile viewports.
- Keyboard accessible cards (`tabindex="0"`, focus rings, `role="article"`).
- `prefers-reduced-motion` animation safeguards.
