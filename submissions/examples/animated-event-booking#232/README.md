# Animated Event/Ticket Booking

A vibrant **Event Booking Interface** built with **EaseMotion CSS**. Features event cards with date overlays, countdown timer, ticket availability, category filters, and a featured event spotlight.

## ✨ Features

- **🎪 Event Cards**: Images with date overlays, type badges, and favorites
- **⏰ Countdown Timer**: Live countdown to featured event with pulse effect
- **🎟️ Ticket Info**: Availability and pricing display
- **📅 Date Overlays**: Calendar-style date badges on event images
- **🏷️ Category Filters**: Event type quick filters
- **⭐ Featured Event**: Large spotlight with full details
- **🎬 Staggered Entrance**: All sections slide up sequentially
- **📱 Fully Responsive**: 3-column → 2-column → 1-column layout

## 🧩 EaseMotion Classes Used

| Class | Purpose |
|-------|---------|
| `ease-fade-in` | Fades in the main page and footer |
| `ease-slide-up` | Slides sections up on entrance |
| `ease-delay-100` to `ease-delay-500` | Creates cascading staggered sequence |
| `ease-card` | Base card structure |
| `ease-hover-lift` | Lift effect on cards |
| `ease-hover-grow` | Scale effect on buttons |
| `ease-center` | Centers search button content |
| `ease-grid` + `ease-grid-cols-3` | Responsive event grid |
| `ease-gap-4` | Spacing between grid items |
| `ease-btn` + `ease-btn-primary` | Styled CTA buttons |
| `ease-pulse` | **Looping pulse** on hero badge and countdown |

## 🚀 How to Use

1. Open `demo.html` in any modern browser
2. Watch all sections slide in with staggered animations
3. Observe the pulsing hero badge and countdown timer
4. Hover over event cards to see image zoom and lift effects
5. Hover over favorite buttons to see color change
6. Test the quick category filters
7. Resize to mobile to see responsive layout
