# Mobile Bottom Navigation

## What does this do?

Creates a modern mobile-style floating bottom navigation bar with colorful active states and glassmorphism styling.

---

## How is it used?

Open `demo.html` directly in any browser.

```html
<nav class="bottom-nav">

    <button class="nav-item active">

        ...

    </button>

</nav>
```

---

## Why is it useful?

Bottom navigation is one of the most common navigation patterns in modern mobile applications. This standalone example demonstrates a colorful floating navigation bar with responsive styling using only HTML and CSS.
