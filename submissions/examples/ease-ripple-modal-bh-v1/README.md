# ease-ripple-modal-bh

Pure CSS ripple-wave modal for fintech dashboards.

## Features
- Ripple wave hover effect
- Modal variants
- Responsive design
- Accessibility support

## Usage
```html
<div class="ease-modal ease-modal-ripple">Content</div>
```

## CSS Classes
- `.ease-modal` - Base modal
- `.ease-modal-ripple` - Ripple wave effect
