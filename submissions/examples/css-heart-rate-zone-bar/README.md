# CSS Heart Rate Zone Bar (#70970)

A responsive, color-coded heart rate zone indicator bar built entirely with CSS.

## Features
- **Color-Coded Segments:** Five distinct zones (Very Light, Light, Aerobic, Hard, Peak) with CSS variables.
- **Dynamic Pin Marker:** Pulsing active BPM location marker positioned along the intensity spectrum.
- **Pure CSS Execution:** Zero JavaScript required for styling, layout, or animations.
- **Accessible ARIA Standards:** Includes `role="progressbar"`, `aria-valuenow`, `aria-valuetext`, and live region support.

## Structure
- `style.css` - Component variables, zone colors, progress segment layout, and marker pulse keyframes.
- `demo.html` - HTML document showcasing heart rate metric display, segmented bar, and legend breakdown.
