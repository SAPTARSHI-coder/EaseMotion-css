# Pulse Button Component (`#54703`)

## What does this do?
Transforms standard action buttons into eye-catching focal points by projecting an animated concentric outward pulse waveform.

## How is it used?
Attach `ease-btn-pulse` directly to your primary conversion buttons:
```html
<button class="ease-btn-pulse primary">Deploy App</button>
```

## Why is it useful?
Solves issue #54703 by driving click-through rates and drawing user attention to high-priority call-to-action controls without scripts.
