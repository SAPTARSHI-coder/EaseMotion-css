
---

## 🚀 Usage
1. Clone or copy the files into your project.
2. Open `demo.html` in your browser.
3. The bell icon shows a bouncing red dot for notifications.

---

## 🛠️ Customization
- **Dot size** → Adjust `width` and `height` in `.notification-dot`.
- **Colors** → Change `background` for different alert styles.
- **Animation speed** → Modify `animation: bounce 1.2s` for faster/slower bounce.

---

## 📖 Accessibility
- Uses `aria-label="Notifications"` for screen readers.
- Dot marked with `aria-hidden="true"` to avoid redundancy.
- Keyboard focus supported.
