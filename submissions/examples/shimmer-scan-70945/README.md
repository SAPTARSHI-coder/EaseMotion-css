# CSS Shimmer Scan

Diagonal shimmer scan line that sweeps repeatedly across UI cards, security passes, and loading placeholders.

## 1. What does this do?
Sweeps a high-tech diagonal light beam across card elements using pure CSS keyframe gradients to simulate active security scanning, futuristic reflections, or continuous processing states.

## 2. How is it used?
Add `.shimmer-scan-beam` inside a `.shimmer-scan-card` container:

```html
<article class="shimmer-scan-card laser-cyan">
  <div class="shimmer-scan-beam"></div>
  <div class="card-body">
    <h2 class="card-title">Biometric ID Access</h2>
    <p>Security clearance active...</p>
  </div>
</article>
```

## 3. Why is it useful?
Cyberpunk UI themes, security status cards, and premium Fintech membership badges require futuristic scanning reflections. This pure CSS pattern provides continuous diagonal scan sweeps without JavaScript overhead.
