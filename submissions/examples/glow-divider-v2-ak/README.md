# glow-divider-v2-ak

Pure CSS animated glowing gradient line divider component — no JavaScript required.

## How to use

```html
<hr class="ease-glowing-divider-v2" />

<!-- Divider with Badge -->
<div class="ease-glowing-divider-text-v2">
  <span class="ease-glowing-divider-badge-v2">OR</span>
</div>
