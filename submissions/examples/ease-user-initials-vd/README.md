# Ease User Initials

## What does this do?

A circular avatar component that displays user initials with multiple color variants and a subtle hover animation.

---

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<div class="user-initials blue">VD</div>
```

### Available variants

```html
<div class="user-initials blue">VD</div>
<div class="user-initials green">AK</div>
<div class="user-initials purple">JS</div>
<div class="user-initials orange">RM</div>
```

### Features

- Circular avatar
- User initials
- Multiple color variants
- Hover animation
- Responsive sizing
- Lightweight CSS

---

## Why is it useful?

Initials avatars are commonly used as fallbacks when profile images are unavailable. They can be used in team lists, comments, dashboards, messaging interfaces, and profile sections.

This component provides a simple and reusable avatar fallback with subtle interaction feedback while following the animation-first philosophy of EaseMotion CSS.
