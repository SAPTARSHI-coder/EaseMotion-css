# Animated Carousel

Neon responsive carousel showcase for issue #78638.

## Files

- `demo.html` — semantic slide content and navigation controls.
- `style.css` — neon surfaces, animation, and responsive scrolling.

## Features

- Responsive slide layout.
- Scroll snapping.
- Neon visual treatment.
- Hover depth and focus states.
- Reduced-motion support.

The core carousel remains usable with native horizontal scrolling and does not require JavaScript for presentation.
