# Ruling Engine Groove

## What does this do?
Renders a self-contained CSS-only `ease-ruling-engine-groove` demo: Ruling engine diamond cutting fine diffraction grooves.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-ruling-engine-groove`. No build step or JavaScript is required for the effect.

```html
<section class="ease-ruling-engine-groove">
  <div class="ease-ruling-engine-groove__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
