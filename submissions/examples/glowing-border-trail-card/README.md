# Glowing border trail card

A card whose border has a moving neon light that travels continuously around the perimeter.

## How to view

Open `demo.html` in any modern browser. The demo is fully self-contained — no CDN, no framework, no JavaScript.

## How to use

Copy `style.css` into your project's stylesheet. Every class used in the demo is namespaced with `glowingbordertrailcard-` to avoid collisions.

## Why this is useful for EaseMotion CSS

Feature highlight pattern; the travelling light signals an active / featured state.
