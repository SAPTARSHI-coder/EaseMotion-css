# Interactive Spinner with Dark Mode Styling

A responsive CSS-only spinner component designed for dark interfaces.

## Features

- Dark mode first visual design
- Animated rotating spinner
- Pulsing spinner core
- Three color variations
- Interactive state controls
- Responsive layout
- Hover and focus states
- Accessible loading status
- Reduced-motion support
- Pure HTML and Vanilla CSS
- No JavaScript or external dependencies

## Files

- `demo.html`
- `style.css`

## Usage

Open `demo.html` directly in a browser.

The spinner can be reused in dashboards, forms, asynchronous actions,
data loading states, and other dark-themed interfaces.

## Technologies

- HTML5
- Vanilla CSS

## Accessibility

The primary spinner uses `role="status"` and an accessible loading label.
Interactive controls are native buttons with visible keyboard focus states.

The component also respects `prefers-reduced-motion`.

## Responsive Behavior

The layout changes from a horizontal loading panel to a stacked mobile
layout on smaller screens.
