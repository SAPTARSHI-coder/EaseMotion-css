# Ease Dynamic Variable Font Weight & Axis Distortion Hero (`ease-kinetic-variable-font-distortion`)

Uses variable fonts (`font-variation-settings`) to dynamically stretch, bolden, and slant typography letters relative to pointer velocity.

## Features
- Real-time variable font axis manipulation (`font-variation-settings`)
- Velocity-based font weight and width stretching
- Smooth spring return animation when pointer stops
- Monospace or Sans-Serif variable font support
- Accessible fallback typography
