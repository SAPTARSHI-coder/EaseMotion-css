# Ease Battery Indicator

## What does this do?

A visual battery level indicator with low, medium, and full states.

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<div class="battery medium">
    <div class="battery-level"></div>
</div>
```

### Available states

Low:

```html
<div class="battery low">
    <div class="battery-level"></div>
</div>
```

Medium:

```html
<div class="battery medium">
    <div class="battery-level"></div>
</div>
```

Full:

```html
<div class="battery full">
    <div class="battery-level"></div>
</div>
```

### Features

- Battery level visualization
- Low state
- Medium state
- Full state
- Animated fill
- Hover interaction
- Responsive sizing
- Pure CSS
- No JavaScript required

## Why is it useful?

Battery indicators are useful for device dashboards, system monitoring interfaces, hardware controls, and applications that display device power levels.

This component provides a simple and reusable battery visualization with smooth fill animation while following the animation-first philosophy of EaseMotion CSS.
