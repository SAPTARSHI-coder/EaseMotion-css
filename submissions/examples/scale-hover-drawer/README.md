# CSS Scale Hover Drawer

## Overview

A responsive gaming-inspired drawer featuring smooth scale-hover interactions built using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Responsive Drawer Layout
- Scale Hover Navigation Links
- CSS Custom Properties
- Accessible (`prefers-reduced-motion`)
- No JavaScript Required

## Folder Structure

```text
scale-hover-drawer/
├── demo.html
├── style.css
└── README.md
```

## Usage

1. Open `demo.html` in your browser.
2. Toggle the drawer using the menu button.
3. Customize the CSS variables as needed.

## CSS Variables

- `--primary`
- `--background`
- `--drawer`
- `--text`
- `--duration`

## Browser Support

- Chrome
- Firefox
- Edge
- Safari
