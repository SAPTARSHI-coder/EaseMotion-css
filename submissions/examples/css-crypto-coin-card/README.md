# CSS Crypto Coin Card (#70800)

A cryptocurrency asset card featuring current price metrics, change indicators, and an embedded SVG trend chart, designed completely without JavaScript.

## Features
- **Semantic Structure:** Uses `<article>` with complete accessibility attributes and keyboard navigation support.
- **Pure CSS Styling:** Modern card architecture utilizing CSS variables, flex alignments, and smooth hover elevation states.
- **Responsive Layout:** Fluidly scales across all screen dimensions.

## File Hierarchy
- `style.css` - Layout, styling, and card color schemes.
- `demo.html` - Semantic markup and accessible vector integration.
- `README.md` - Technical specification and architecture overview.
