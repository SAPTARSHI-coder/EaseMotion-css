About this component

Design decisions

Zero JavaScript Entrance animations and hover effects are driven entirely by CSS keyframes and transitions.
Accessible Each block uses semantic role and aria-label attributes. Icons are hidden from assistive technology with aria-hidden.
Themeable All colors are CSS custom properties scoped to each variant via class-level variable overrides — no !important needed.
Reduced motion The prefers-reduced-motion media query disables all animation for users who request it.
