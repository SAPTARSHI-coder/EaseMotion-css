# Magnetic Glow Button

A smooth and interactive **Magnetic Glow** button created using pure HTML and vanilla CSS for EaseMotion CSS.

## Features

- Pure HTML and CSS
- Smooth hover animation
- Soft magnetic glow effect
- Button lift and scale interaction
- Active press animation
- Keyboard accessible
- Dark mode compatible
- Responsive design
- Reduced-motion support
- No JavaScript or external dependencies

## Usage

Add the button to your HTML:

```html
<button class="magnetic-glow-btn" type="button">
    <span>Get Started</span>
</button>
