# CSS Background: Synthwave Grid Line

A retro-futuristic synthwave background animation created entirely with
HTML and vanilla CSS.

## Features

- Pure HTML and Vanilla CSS
- No external JavaScript
- Animated perspective grid
- Retro synthwave sun
- Neon-style grid glow
- CSS perspective transforms
- Smooth hardware-accelerated animation
- Responsive layout
- Dark-mode friendly color palette
- `prefers-reduced-motion` accessibility support

## Files

- `demo.html` — Demo markup
- `style.css` — Synthwave background and animation styles
- `README.md` — Documentation

## How It Works

The effect combines CSS gradients, repeating grid patterns, perspective
transforms, glow effects, and a continuous vertical animation to create
a retro-futuristic synthwave environment.

## Accessibility

The decorative background elements are marked with `aria-hidden="true"`.
The grid animation is disabled when the user has enabled
`prefers-reduced-motion`.
