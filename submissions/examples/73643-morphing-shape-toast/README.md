# Morphing Shape Toast

A smooth and visually polished notification/toast component featuring a
dynamic **Morphing Shape** effect using pure HTML and Vanilla CSS.

## ✨ Features

- Pure HTML and CSS
- No JavaScript required
- Dynamic morphing border-radius animation
- Animated decorative gradient shapes
- Smooth hover interactions
- Responsive design
- Light and dark mode support
- Hardware-accelerated transforms
- Accessible semantic markup
- Keyboard-friendly close control
- Visible focus states
- `prefers-reduced-motion` support
- No external dependencies

## 🎨 Style

**Morphing Shape**

The toast continuously changes its border geometry while decorative
background shapes smoothly morph and move to create a fluid visual effect.
