# CSS Animated Burger to Arrow

A pure CSS hamburger menu icon that smoothly transforms into a back arrow.

## Features

- Pure HTML and CSS
- No JavaScript required
- Smooth burger-to-arrow animation
- Keyboard accessible
- Responsive design
- Dark mode support
- Reduced-motion support
- Uses CSS custom properties for easy customization
