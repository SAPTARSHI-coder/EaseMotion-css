# Skew-Active Feature Grid

A lightweight CSS-only feature grid designed for Gaming Hub layouts.

## Features

- Pure HTML and CSS
- Skew animation on hover and focus
- Responsive desktop, tablet, and mobile layouts
- Keyboard-friendly focus interaction
- CSS custom properties
- No JavaScript or external libraries
- `prefers-reduced-motion` support

## Files

- `demo.html` - HTML showcase page
- `style.css` - Styling, animation, and responsive layout

## Usage

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
