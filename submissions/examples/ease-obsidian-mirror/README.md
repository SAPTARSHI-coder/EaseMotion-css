# 🪞 Obsidian Mirror – Smooth Black Mirror Reflects with Distortion

> A mystical obsidian mirror component where a smooth black surface reflects with distortion and shimmer effects, with distortion control (0-100%), shimmer control (0-100%), and particle reflections.

---

## 📖 Description

The **Obsidian Mirror** component creates a mystical obsidian mirror experience where a smooth black surface reflects with distortion and shimmer effects. Built with vanilla HTML, CSS, and JavaScript, it features distortion control (0-100%), shimmer control (0-100%), and particle reflections for a mysterious experience.

### 🎯 Core Features

- **Obsidian mirror** – smooth black mirror with distortion effects
- **Distortion control** – adjust distortion from 0-100%
- **Shimmer control** – adjust shimmer from 0-100%
- **Particle reflections** – floating reflection particles
- **Reflection counter** – tracks number of reflections
- **Interactive controls** – sliders, keyboard shortcuts
- **Responsive design** – adapts to different screen sizes

### 🪞 Mirror Effects

| Effect | Description |
|--------|-------------|
| **Distortion** | Mirror surface ripples and warps |
| **Shimmer** | Light reflections sparkle |
| **Reflections** | Particles float on surface |
| **Glow** | Subtle edge luminescence |

### ⌨️ Interaction Options

| Method | Action |
|--------|--------|
| **Sliders** | Adjust Distortion (0-100%) and Shimmer (0-100%) |
| **Keyboard** | `R` – Reset |

### ✨ Mirror Experience

When interacting:
1. **Mirror distorts** – surface ripples and warps
2. **Distortion applies** – controls warp intensity
3. **Shimmer applies** – controls light reflections
4. **Particles float** – reflections on surface
5. **Status updates** – shows current state

### 💡 Why Use This Component?

- Perfect for mystical interfaces, fantasy themes, or magical experiences
- Mysterious obsidian mirror with distortion effects

### 🛠️ Technologies Used

- **HTML5** – semantic structure with Canvas
- **CSS3** – gradients, backdrop-filter, transforms
- **JavaScript (ES6)** – Canvas API, requestAnimationFrame, particle system

### 🎨 Design Philosophy

This component embodies **EaseMotion CSS's animation-first philosophy** through:

- **Distortion effects** – mirror ripples organically
- **Shimmer effects** – light reflections sparkle
- **Particle effects** – floating reflections
- **Visual feedback** – status updates, counter, controls
- **Mystical atmosphere** – dark mirror with glow
- **Human-readable classes** – `.obsidian-controls`, `.obsidian-text`

### 🔧 Customization Options

| Property | Location | Default |
|----------|----------|---------|
| Distortion range | `distortionSlider` | 0-100% |
| Shimmer range | `shimmerSlider` | 0-100% |
| Particle count | `generateParticles()` | 30 |
| Mirror radius | `radius` | 30% of canvas |
