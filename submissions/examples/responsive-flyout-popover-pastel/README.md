# Responsive Flyout Popover — Pastel
A responsive flyout popover component built with pure HTML and CSS,
featuring a soft pastel visual style and EaseMotion-compatible design tokens.

## Features
- Pure HTML and CSS
- Zero JavaScript dependencies
- Responsive across mobile, tablet, and desktop
- Pastel visual styling
- Smooth hover and popover transitions
- Keyboard-accessible native `<details>` interaction
- Visible `:focus-visible` states
- `prefers-reduced-motion` support
- EaseMotion-style CSS custom properties
- No external dependencies
