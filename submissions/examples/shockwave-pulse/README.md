# CSS Shockwave Pulse

A pure CSS shockwave pulse animation featuring expanding rings from a central point.

## Features

- Pure HTML and vanilla CSS
- No JavaScript required
- Smooth expanding shockwave rings
- Responsive design
- Hardware-friendly CSS animations
- Dark-mode friendly styling
- Accessible markup
- Respects `prefers-reduced-motion`

## Files

- `demo.html` – Animation markup and demo content
- `style.css` – Complete animation and responsive styling

## Usage

Include the stylesheet in your HTML:

```html
<link rel="stylesheet" href="style.css">
