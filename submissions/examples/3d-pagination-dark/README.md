# 3D Pagination with Dark Mode

A responsive 3D pagination component built using pure HTML and CSS.

## Features

- Dark mode design
- 3D button effect
- Hover animation
- Active page styling
- Press/click animation
- Keyboard focus support
- Fully responsive
- No JavaScript or external libraries required

## Technologies

- HTML5
- CSS3

## Folder Structure

```text
3d-pagination-dark/
├── index.html
├── style.css
└── README.md
````

## How to Use

1. Open `index.html` in a browser.
2. The pagination component will be displayed.
3. Customize the page numbers inside `index.html`.
4. Modify `style.css` to customize the appearance.

## Preview

The component provides a dark-themed pagination interface with raised 3D buttons, hover effects, and an active page indicator.

## Responsive Design

The component adapts to smaller screen sizes using CSS media queries.

## Accessibility

* Semantic buttons are used for pagination controls.
* Previous and next buttons include accessible labels.
* Keyboard focus is clearly visible.

## Contribution

This component is contributed to the EaseMotion-css project as part of the GSSoC 2026 contribution.
