# Button Ice Glow

A frosted button glows icy blue and lifts with a soft shadow.

## Features
- Frosted glass face
- Icy glow pulse
- Lift on hover
- Pure CSS

## Usage
```html
<button class="big-btn">Ice</button>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
