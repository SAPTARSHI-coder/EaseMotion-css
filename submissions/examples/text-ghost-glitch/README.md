# Text Ghost Glitch

A ghost of the title detaches and glitches with a glitchy duplicate.

## Features
- Ghost duplicate layer
- Offset glitch jitter
- Colour-shift echoes
- Pure CSS

## Usage
```html
<h2 class="tgg-title">Ghost</h2>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
