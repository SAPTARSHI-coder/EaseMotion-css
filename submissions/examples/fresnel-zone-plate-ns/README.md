# Fresnel Zone Plate

## What does this do?
Renders a self-contained CSS-only `ease-fresnel-zone-plate` demo: Fresnel zone plate focusing concentric diffraction rings.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-fresnel-zone-plate`. No build step or JavaScript is required for the effect.

```html
<section class="ease-fresnel-zone-plate">
  <div class="ease-fresnel-zone-plate__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
