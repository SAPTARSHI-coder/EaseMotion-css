# Animated Skeleton Loader Component

A lightweight placeholder skeleton component featuring a linear shimmer animation for loading states.

## Features
- **Pure CSS Animation:** Smooth 60fps shimmer effect without extra scripts.
- **Human-Readable Classes:** Utility classes for text lines, headings, and avatars.
- **Dark Mode Friendly:** Matches standard dark UI color schemes seamlessly.

## File Structure
- `demo.html` - Demo layout showing an avatar + line skeleton card.
- `style.css` - Skeleton shape definitions and shimmer keyframe animation.
