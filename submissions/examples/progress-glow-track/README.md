# Progress Glow Track

A progress bar fills while a glow head travels ahead of the fill.

## Features
- Fill + glow head
- Trailing comet
- Rounded capsule
- Pure CSS

## Usage
```html
<div class="pgt-fill"></div><div class="pgt-head"></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
