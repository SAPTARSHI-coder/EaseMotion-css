# Floating Toast Notification Component

A temporary feedback alert banner featuring smooth entrance animations and an animated progress drain bar.

## Features
- **Slide Entrance:** Smooth entrance animation using scale and translate transforms.
- **Progress Drain Utility:** Timed keyframe animation indicating remaining display duration.
- **Pure CSS:** Zero JavaScript dependencies.

## File Structure
- `demo.html` - Toast notification markup structure.
- `style.css` - Component styling and progress keyframes.
