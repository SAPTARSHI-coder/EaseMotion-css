What is EaseMotion?

EaseMotion is a collection of dependency-free HTML and CSS interface examples you can drop straight into a project.

Do I need JavaScript?

No. Every example is pure HTML and CSS, using the native details element for interactions where helpful.

Is it responsive?

Yes. Examples use fluid sizing and clamp values so they adapt gracefully from phones to wide desktops.
