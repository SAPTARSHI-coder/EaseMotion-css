# Brush Stroke · Dynamic Brush Stroke on Canvas 🎨

An interactive dynamic brush stroke painting tool with realistic brush effects, color blending, and texture. Drag to paint with expressive, fluid brush strokes that mimic real painting techniques!

## Features

- 🎨 **Dynamic Brush Strokes** – Realistic brush effects with texture
- 🖌️ **Color Control** – Pick any color with color picker
- 📏 **Size Control** – Adjust brush size (2-40px)
- ✨ **Organic Texture** – Brush strokes have natural variation
- 🎨 **Color Blending** – Colors shift dynamically within strokes
- 🎮 **Speed Control** – Adjust animation speed (1-10)
- ⏸️ **Pause/Resume** – Toggle animation with button or Space
- 🗑️ **Clear** – Clear canvas with C key or button
- 🔄 **Reset** – Reset to clean state
- 📱 **Touch Support** – Works on mobile devices

## How to Use

1. **Drag** on the canvas to paint with dynamic brush strokes
2. Use the **Color Picker** to change brush color
3. Adjust **Size** slider for different brush thickness
4. Watch brush strokes have organic texture and variation
5. Press **C** or click **CLEAR** to clear the canvas
6. Press **Space** or click **PAUSE** to pause/resume animation
7. Press **R** or click **RESET** to reset

## Technical Details

- **Stroke System:** Points-based stroke with dynamic rendering
- **Brush Texture:** Multi-dot pattern with size and color variation
- **Color Manipulation:** HSL color shifting within strokes
- **Animation:** Strokes evolve with time-based effects
- **Performance:** 60fps with requestAnimationFrame

## Customization

You can easily customize:
- **Brush Size:** Adjust slider range (2-40)
- **Stroke Variation:** Modify sizeVar and hueShift values
- **Texture Density:** Change steps in draw method
- **Colors:** Modify default color and gradient
- **Animation Speed:** Adjust speed slider range

## Browser Support
