# Windlass Drum Haul

## What does this do?
Renders a self-contained CSS-only `ease-windlass-drum-haul` demo: Anchor windlass drum hauling chain.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-windlass-drum-haul`. No build step or JavaScript is required for the effect.

```html
<section class="ease-windlass-drum-haul">
  <div class="ease-windlass-drum-haul__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
