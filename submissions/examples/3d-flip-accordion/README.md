# CSS 3D-Flip Accordion

A modern, lightweight accordion component designed for fintech dashboard
layouts.

The component uses semantic HTML and pure CSS 3D transforms to create a
smooth flip animation when accordion content is opened.

## Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- CSS 3D flip animation
- Rotating accordion indicator
- Responsive across desktop, tablet, and mobile
- CSS custom properties
- Native `<details>` and `<summary>` elements
- Keyboard accessible
- `prefers-reduced-motion` support
- Fintech dashboard styling
