# CSS 3D-Flip Progress Bar for Fintech Dashboard Layouts

A modern fintech dashboard showcase featuring reusable 3D-flip progress
indicators created entirely with HTML and CSS.

The component uses CSS 3D transforms, perspective and keyframe
animations to create a card-flip effect while the progress bar reveals
its target percentage.

## Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- CSS 3D transforms
- Perspective-based flip animation
- Animated progress reveal
- Flip-front and flip-back faces
- Financial KPI cards
- Transaction activity panel
- Financial health indicator
- Responsive desktop layout
- Responsive tablet layout
- Responsive mobile layout
- CSS custom properties
- Semantic HTML
- ARIA progressbar attributes
- Reduced-motion support
