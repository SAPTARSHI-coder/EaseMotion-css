# glow-pricing-switch-ak

Pure CSS animated pricing plan switcher toggle — no JavaScript required.

## How to use

```html
<div class="ease-pricing-switcher">
  <input type="radio" name="pricing" id="m" checked />
  <label for="m" class="ease-pricing-option-label">Monthly</label>

  <input type="radio" name="pricing" id="y" />
  <label for="y" class="ease-pricing-option-label">Annual</label>

  <span class="ease-pricing-switcher-glider"></span>
</div>
