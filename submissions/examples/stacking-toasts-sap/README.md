# Stacking Notification Toasts

A modern, glassmorphism-inspired notification toast container that beautifully slides in and stacks multiple notifications on the screen.

### Usage
```html
<div class="toast-container">
  <div class="toast toast-success" style="--toast-index: 1;">
    <!-- Content here -->
  </div>
</div>
```

### Why is it useful?
It provides a premium, native-feeling notification system out of the box with highly polished cubic-bezier animations, staggered entry effects, and responsive stacking, perfectly aligning with EaseMotion's focus on dynamic and premium micro-interactions.
