# glow-float-input-v7-ak

Pure CSS animated floating label input field with neon border focus — no JavaScript required.

## How to use

```html
<div class="ease-float-input-wrapper-v7">
  <input type="text" class="ease-float-input-v7" placeholder=" " id="inp" />
  <label for="inp" class="ease-float-label-v7">Label Text</label>
</div>
