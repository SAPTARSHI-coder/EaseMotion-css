# Floating Tab Bar with Pastel Styling

A responsive floating tab bar built using pure HTML and CSS.

The component uses a soft pastel visual style with rounded navigation items, subtle shadows, hover transitions, and a glass-like floating surface.

## Features

- Fully responsive
- Pure HTML and CSS
- No JavaScript required
- Pastel color palette
- Floating rounded navigation
- Smooth hover transitions
- Keyboard focus support
- `prefers-reduced-motion` support
- Mobile-friendly layout
- Uses CSS custom properties for easy customization
