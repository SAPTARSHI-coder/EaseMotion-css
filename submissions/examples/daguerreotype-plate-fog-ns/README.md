# Daguerreotype Plate Fog

## What does this do?
Renders a self-contained CSS-only `ease-daguerreotype-plate-fog` demo: Daguerreotype plate fog clearing to image.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-daguerreotype-plate-fog`. No build step or JavaScript is required for the effect.

```html
<section class="ease-daguerreotype-plate-fog">
  <div class="ease-daguerreotype-plate-fog__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
