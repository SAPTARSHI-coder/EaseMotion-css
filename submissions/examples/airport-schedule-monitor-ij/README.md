# Ease Airport Schedule Monitor (#74831)

An animated, fully-rendered split-flap style airport flight schedule monitor component built using pure HTML and Vanilla CSS.

## Features
- **Real UI Component:** Authentic flight board monitor featuring departure header, status indicators, and flight rows.
- **Pure CSS:** Zero JavaScript dependencies; uses keyframe CSS text-shadow and opacity pulsing.
- **Performance:** Hardware-accelerated animations running smoothly at 60 FPS.
- **Accessibility:** Built with semantic table structure and `@media (prefers-reduced-motion: reduce)` media query integration.
