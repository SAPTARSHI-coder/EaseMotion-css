# CSS Slot Machine Reels

A CSS-only slot machine animation featuring three vertically spinning reels that stop at different times.

## Features

- Pure CSS animation
- Three independently timed reels
- Smooth spinning and stopping effect
- Responsive layout
- No JavaScript required
- Supports `prefers-reduced-motion`
- Self-contained demo

## Usage

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
<div class="reels">
  <div class="reel-window">
    <div class="reel reel-one">
      <span>🍒</span>
      <span>🍋</span>
      <span>🔔</span>
    </div>
  </div>
</div>
