# Cryptograph Disc Align

## What does this do?
Renders a self-contained CSS-only `ease-cryptograph-disc-align` demo: Cryptograph discs lining up a substitution.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-cryptograph-disc-align`. No build step or JavaScript is required for the effect.

```html
<section class="ease-cryptograph-disc-align">
  <div class="ease-cryptograph-disc-align__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
