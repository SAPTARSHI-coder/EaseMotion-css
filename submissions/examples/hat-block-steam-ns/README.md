# Hat Block Steam

## What does this do?
Renders a self-contained CSS-only `ease-hat-block-steam` demo: Millinery hat block steaming a felt crown to shape.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-hat-block-steam`. No build step or JavaScript is required for the effect.

```html
<section class="ease-hat-block-steam">
  <div class="ease-hat-block-steam__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
