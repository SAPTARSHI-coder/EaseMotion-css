# Foucault Knife Edge

A CSS-only animated interpretation of a Foucault knife-edge test, showing a sweeping shadow across a reflective mirror figure.

## ✨ Features

- Pure HTML and CSS
- No JavaScript
- Animated knife-edge shadow sweep
- Layered CSS gradients
- Responsive instrument-style layout
- CSS custom properties for easy customization
- `prefers-reduced-motion` support
- No external dependencies
