# Glassmorphic Pricing Table Tier Toggle (EaseMotion CSS)

An interactive SaaS pricing table component featuring glassmorphism cards, interactive billing cycle switches (Monthly/Annual), discount pill highlights, and featured tier glow effects constructed with HTML5 and CSS3.

## 1. What does this do?
This component presents a subscription pricing grid. It includes a custom glassmorphism toggle switch (`.toggle-switch`), a featured card highlight with floating "MOST POPULAR" badges, and smooth hover lift animations (`transform: translateY(-8px)`).

## 2. How is it used?
Link `style.css` in your HTML application and wrap pricing options within `.pricing-grid` and `.pricing-card` as shown in `demo.html`.

## 3. Why is it useful?
- **High-Converting SaaS UI**: Elevates landing page subscription conversion rates with modern glassmorphism aesthetic standards.
- **Pure CSS Hardware Acceleration**: Smooth hover transitions and custom toggle switch physics rendered with native CSS3 without heavy JavaScript dependencies.
- **Fully Responsive**: Automatically reorganizes into a single-column layout on mobile viewports.
