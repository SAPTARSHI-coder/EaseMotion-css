# Shadow Drop Hover Effects

**What does this do?**
Provides two hover animations (`shadow-drop-center` and `shadow-drop-bottom`) that smoothly expand an element's `box-shadow` while slightly translating the element to create a realistic 3D elevation illusion.

**How is it used?**
Apply the utility classes to interactive cards, buttons, or tiles:
```html
<div class="shadow-drop-center-ag">Elevates uniformly</div>
<div class="shadow-drop-bottom-ag">Elevates with a drop-shadow below</div>
```

**Why is it useful?**
Elevation is a key principle in modern UI design (like Material Design). These animations provide a smooth, performant, and realistic interaction cue for clickable surfaces.
