# Dice Cube

A rolling 3D die that tumbles across its faces and settles with pips facing up.

## Features
- Six pip faces in true 3D space
- Tumbling multi-axis rotation
- Dot grid uses radial-gradient pips

## Usage
```html
<div class="dc-scene"><div class="dc-cube">
  <div class="dc-face f1"></div>
  <div class="dc-face f6"></div>
</div></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
