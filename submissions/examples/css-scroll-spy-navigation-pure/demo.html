Scroll-Spy Navigation

A pure CSS table-of-contents navigation that highlights the active section in real-time as you scroll, using modern animation-timeline: view().

Introduction

Scroll down to see the navigation on the left update automatically.

Architecture

Each section registers a named view timeline using the view-timeline-name CSS property.

Implementation

The navigation links bind their background-color animation to the specific view timeline of the section they point to. When the section enters the viewport, the CSS animation triggers, highlighting the link.

Conclusion

This allows for complex interactive UI patterns entirely without JavaScript scroll event listeners.
