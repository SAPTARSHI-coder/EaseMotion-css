# Fire Eater · Flames on Stage 🔥

An interactive fire eater performance with flames, sparks, and theatrical fire effects. Breathe fire onto the stage!

## Features

- 🔥 **Fire Effects** – Realistic flames and sparks
- 🎚️ **Intensity Control** – Adjust flame intensity (1-10)
- 🎚️ **Flame Control** – Adjust flame count (20-80)
- 🔊 **Sound Effects** – Roaring fire sounds
- ⏸️ **Pause/Resume** – Toggle animation
- 🔄 **Reset** – Reset performance
- 📊 **Counter** – Tracks breaths

## How to Use

1. Click **BREATHE** or press **Space** to breathe fire
2. Click on the canvas to breathe more
3. Adjust **Intensity** for flame size
4. Adjust **Flames** for particle count
5. Press **RESET** or **R** to reset
6. Press **PAUSE** or **P** to pause/resume animation

## Technical Details

- **Particle System:** Flames, sparks, embers
- **Physics:** Gravity, turbulence, decay
- **Sound:** Web Audio API effects
- **Performance:** 60fps with requestAnimationFrame

## Customization

You can easily customize:
- **Intensity:** Adjust slider range (1-10)
- **Flames:** Adjust slider range (20-80)
- **Colors:** Modify fire colors
- **Physics:** Adjust gravity, turbulence
- **Sound:** Adjust volume and frequency

## Browser Support

Works in all modern browsers:
- Chrome, Firefox, Safari, Edge
- Audio requires Web Audio API support

## Run Locally

Simply open `index.html` in your browser – no server required!
