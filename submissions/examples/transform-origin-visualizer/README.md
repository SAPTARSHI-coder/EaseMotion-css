# CSS Transform Origin Visualizer

An interactive beginner-friendly demo that demonstrates how the CSS
`transform-origin` property affects the point around which an element rotates.

## Features

- Rotating element
- Visible transform-origin marker
- Preset transform-origin positions
- Current `transform-origin` value display
- Replay rotation button
- Responsive layout
- No external dependencies

## Available Presets

- `center`
- `top left`
- `top right`
- `bottom left`
- `bottom right`

## How It Works

The demo changes the `transform-origin` property of the element and
uses a CSS rotation animation to make the effect visible.

The red marker represents the selected point around which the element rotates.

## Technologies

- HTML
- CSS
- Vanilla JavaScript

## Running the Demo

Open `demo.html` directly in a web browser.

No installation, build process, or external dependencies are required.
