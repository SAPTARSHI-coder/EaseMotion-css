This contribution adds a CSS Video Overlay Hero to the submissions/examples/css-video-overlay-hero-eranmol directory.

What is included?
demo.html
style.css
README.md

Features
Full-screen hero section with looping video background
Dark gradient overlay on top of the video
Responsive text content with tag, heading, subtitle, and CTA buttons
Subtle fade-up entrance animation on content
Pure CSS — no JavaScript
Accessible with ARIA banner role and labels
Works in Chrome, Firefox, Edge, and Safari
