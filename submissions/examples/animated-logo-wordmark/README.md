# CSS Animated Logo Wordmark

A pure CSS animated logo wordmark with a letter-by-letter reveal effect.

## Features

- Pure CSS animation
- No JavaScript required
- Letter-by-letter reveal
- Responsive design
- Accessible semantic HTML
- Supports `prefers-reduced-motion`
- Lightweight and easy to customize
