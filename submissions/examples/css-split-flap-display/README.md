# CSS Split-flap Display


A classic airport departure board inspired split-flap text animation built using pure CSS.


## Features

- Split flap board UI
- Mechanical flip animation
- Text and number display
- Responsive design
- No JavaScript required


## Technologies

- HTML5
- CSS3


## CSS Concepts Used

- 3D transforms
- RotateX animation
- Keyframes
- Delay based animations
- Perspective effects


## Accessibility

- Semantic HTML structure
- aria-label added for display meaning
