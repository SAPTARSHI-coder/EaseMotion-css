# Animated Modal Component

An accessible modal dialog featuring a frosted glass overlay and CSS scale entrance transitions.

## Features
- **Zero JavaScript:** State toggled purely via CSS hidden checkbox pattern (`:checked`).
- **Frosted Glass Overlay:** Uses `backdrop-filter: blur()` for background defocusing.
- **Smooth Zoom Entrance:** Scale animation applied on display state toggle.

## File Structure
- `demo.html` - Modal structure and pure CSS checkbox trigger markup.
- `style.css` - Backdrop filters, scale transforms, and layout styling rules.
