# CSS Fade-In Dropdown for Gaming Hub Layouts

A modern **Fade-In Dropdown** built using pure HTML and CSS for gaming hubs, esports portals, game launchers, and community navigation menus.

## Features

* Pure HTML5 & CSS3
* Smooth fade-in dropdown animation
* Responsive navigation bar
* Gaming-inspired UI
* CSS custom properties
* No JavaScript required
* Supports `prefers-reduced-motion`

## Folder Structure

```text
59116-fade-in-dropdown-gaming-hub/
├── demo.html
├── style.css
└── README.md
```

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over the **Games** menu to reveal the dropdown.
3. Customize menu items and colors using the CSS variables in `:root`.
4. Integrate the component into your gaming website navigation.
