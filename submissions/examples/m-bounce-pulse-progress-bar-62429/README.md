# CSS Bounce-Pulse Progress Bar for Product Catalog Layouts

A modern **Bounce-Pulse Progress Bar** built using pure HTML and CSS. The component features a smooth bounce-pulse animation, responsive layout, CSS custom properties, and lightweight styling for product catalog interfaces.

## ✨ Features

- Pure HTML5 & CSS3
- Bounce-pulse progress animation
- Responsive layout
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
