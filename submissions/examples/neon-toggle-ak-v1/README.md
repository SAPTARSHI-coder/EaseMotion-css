# neon-toggle-ak

## How to use

```html
<label class="ease-neon-switch">
  <input type="checkbox" />
  <span class="ease-neon-slider"></span>
</label>

<!-- Color Variants -->
<label class="ease-neon-switch ease-neon-switch--cyan">...</label>
<label class="ease-neon-switch ease-neon-switch--emerald">...</label>
