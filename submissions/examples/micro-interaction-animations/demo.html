✨ Micro-Interaction Animations

Hover or click to see the magic ✨

❌

Shake

Horizontal shake — great for errors, form validation, or "wrong" feedback.

❤️

Heartbeat

Subtle pulsing — perfect for like buttons, favorites, or notifications.

⬇️

Bounce

Vertical bouncing — draws attention for scroll indicators, call-to-action buttons, or alerts.

📦 How to Use

<div class="em-shake">Shake me!</div>
<div class="em-heartbeat">❤️ Pulse me!</div>
<div class="em-bounce">⬇️ Bounce me!</div>

💡 Add .em-shake, .em-heartbeat, or .em-bounce to any element. The animations run once by default and return to their original state cleanly.

🔄 For infinite animations, use the .infinite modifier class: .em-shake.infinite
