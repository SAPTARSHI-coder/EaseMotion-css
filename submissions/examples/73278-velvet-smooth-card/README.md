# CSS Card: Velvet Smooth Transition Variation

A polished card component featuring smooth, soft, and responsive
transitions inspired by velvet surfaces.

## ✨ Features

- Velvet-inspired visual styling
- Smooth hover transitions
- Subtle card elevation
- Ambient glow effects
- Multiple visual variations
- Responsive layout
- Dark-mode compatible
- Keyboard-accessible links
- Visible focus states
- Reduced-motion support
- Hardware-friendly CSS transforms
- No JavaScript
- No external dependencies

## 🎨 Design

The component combines:

- Soft gradients
- Layered shadows
- Ambient glow
- Smooth elevation
- Subtle scaling
- Refined cubic-bezier transitions

The goal is to provide a premium card interaction without
introducing unnecessary complexity.

## 🧩 Variations

The demo includes three visual styles:

1. Velour
2. Satin
3. Luxe

All variations reuse the same component structure while changing
their color treatment.

## ⚡ Interaction

Cards smoothly elevate when hovered.

```css
.velvet-card:hover {
  transform:
    translateY(-8px)
    scale(1.008);
}
