# Rotate-Fade Progress Bar

A lightweight, responsive CSS-only Rotate-Fade Progress Bar designed for
product catalog layouts.

## Features

- Pure HTML and CSS
- No JavaScript required
- No external dependencies
- Smooth rotate-fade entrance animation
- Animated gradient movement
- Responsive design
- CSS custom properties
- Semantic progressbar markup
- `prefers-reduced-motion` support
- Works by opening `demo.html` directly
