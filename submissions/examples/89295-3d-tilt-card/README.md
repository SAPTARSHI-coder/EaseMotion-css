# 3D Tilt Card Component

An interactive card component utilizing CSS perspective and 3D transforms for hover depth effects.

## Features
- **3D Transform Depth:** Combines `perspective`, `rotateX`, and `rotateY` for realistic card tilt.
- **Layered Z-Index Translation:** Content elements utilize `translateZ` for multi-layered depth.
- **Zero JavaScript:** Pure CSS interactive hover animation.

## File Structure
- `demo.html` - 3D card markup layout.
- `style.css` - Perspective rules, 3D transform properties, and hover states.
