# Bounce-Pulse Badge

A lightweight CSS Bounce-Pulse Badge designed for fintech dashboard interfaces.

## Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Smooth bounce animation
- Subtle pulse effect
- Animated status icon
- Responsive design
- CSS custom properties
- Accessible reduced-motion support
- Suitable for payment and transaction statuses
