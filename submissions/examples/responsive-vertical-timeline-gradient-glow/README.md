# Responsive Vertical Timeline with Gradient Glow
A responsive vertical timeline featuring gradient glow effects, animated
milestones, glass-inspired cards, and responsive layouts.

## Features
- Responsive vertical timeline
- Gradient glowing timeline connector
- Glowing milestone markers
- Smooth card hover transitions
- Mobile, tablet, and desktop layouts
- Pure HTML and CSS
- No JavaScript dependencies
- Uses CSS custom properties/design tokens
- Supports `prefers-reduced-motion`

## Files
- `demo.html` — Timeline markup and content
- `style.css` — Complete component styling
- `README.md` — Documentation

## Usage
Open `demo.html` directly in a modern browser.
No build step or JavaScript dependency is required.

## Accessibility
The component includes a
`prefers-reduced-motion: reduce` media query to minimize transitions
for users who request reduced motion.
The timeline uses semantic `<section>` and `<article>` elements and
provides an accessible `aria-label` for the timeline.
