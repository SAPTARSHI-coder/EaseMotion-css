# CSS Zoom-In Drawer for Product Catalog Layouts

A modern **Zoom-In Drawer** built using pure HTML5 and CSS3 for product catalog layouts. The component provides a responsive side drawer with a smooth zoom-in animation for displaying detailed product information using only HTML and CSS.

## Features

* Pure HTML5 & CSS3
* Zoom-In drawer animation
* CSS-only drawer toggle (checkbox technique)
* Responsive product catalog layout
* Glassmorphism drawer interface
* Product image, description, pricing, rating, stock status, and CTA button
* Overlay backdrop with smooth fade effect
* Smooth CSS transitions & keyframe animations
* CSS Custom Properties for easy customization
* No JavaScript required
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Click the **Quick View** button to open the Zoom-In Drawer.
3. Click the **✕** button to close the drawer.
4. Customize colors, spacing, animation duration, and shadows using the CSS variables defined in `:root`.
