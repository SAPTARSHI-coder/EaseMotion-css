# Interactive Skill Progress Bar

## What it does
A sleek, modern progress bar component that fills smoothly on load, featuring a continuous diagonal light-shimmer animation flowing across its bar for a high-end visual effect.

## How to use it
    ```html
    <div class="skill-container">
  <div class="skill-info">
    <span class="skill-name">Frontend Engineering</span>
    <span class="skill-percentage">90%</span>
  </div>
  <div class="skill-bar-track">
    <div class="skill-bar-fill shimmer-effect" style="width: 90%;"></div>
  </div>
</div>


## Why it fits EaseMotion CSS
It delivers a polished, engaging way to present metrics and skill proficiency levels using lightweight, hardware-accelerated CSS animations and clean structure.
