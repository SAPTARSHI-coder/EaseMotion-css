# Glowing Navbar - Material Design

A responsive glowing navigation bar built with pure HTML and CSS,
combining Material Design-inspired elevation, surfaces and interaction
states with a modern luminous visual style.

## ✨ Features

- Pure HTML and CSS
- No JavaScript dependency
- Fully responsive
- Material-inspired surface design
- Elevated navigation container
- Glowing active navigation state
- Interactive hover states
- Keyboard focus states
- Responsive mobile navigation
- CTA button with glow feedback
- Ambient background lighting
- Reduced-motion support
- CSS custom properties for easy customization
