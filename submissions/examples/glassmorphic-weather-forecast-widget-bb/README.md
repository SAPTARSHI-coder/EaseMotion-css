# Glassmorphic Weather Forecast Widget Component

## What does this do?
This component provides a sleek, modern glassmorphic weather forecast widget with animated sun pulse, drifting atmospheric clouds, live temperature readout, and interactive 3-day forecast pills.

## How is it used?
Include `style.css` in your project and copy the `.weather-widget` HTML structure into your application's dashboard or sidebar area.

## Why is it useful?
- Uses CSS backdrop-filter blur for real glassmorphism aesthetics.
- Hardware-accelerated keyframe animation loop for smooth weather visual effects.
- Clean responsive layout crafted with modern CSS custom properties.
