# CSS Tag Filter Buttons

A lightweight, responsive tag filtering component built using pure HTML and CSS.

This submission addresses **EaseMotion CSS Issue #68640**.

## Features

- Pure HTML and CSS
- No JavaScript required
- Radio-button based filtering
- Animated active filter states
- Hover effects
- Responsive layout
- Keyboard accessible controls
- `prefers-reduced-motion` support
- CSS custom properties for easy customization
