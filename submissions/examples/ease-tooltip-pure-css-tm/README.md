# Tooltip Component

**Issue:** [#71856](https://github.com/SAPTARSHI-coder/EaseMotion-css/issues/71856)

Pure CSS tooltip that appears on hover with arrow pointer.

## Design Tokens

| Token | Default |
|-------|--------|
| `--tt-accent` | `#6366f1` |
| `--tt-radius` | `8px` |
| `--tt-font` | `0.8rem` |
| `--tt-shadow` | `0 4px 16px rgba(0,0,0,.4)` |
