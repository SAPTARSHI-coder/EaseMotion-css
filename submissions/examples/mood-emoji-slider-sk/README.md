# Mood Sentiment Emoji Slider

## What does this do?

A mood slider that scales/rotates an emoji and shifts hue from --mood.

## How is it used?

```html
<label class="mood"><span class="mood__face">😐</span><input type="range"/></label>
```

Open `demo.html` in a browser to try it.

## Why is it useful?

Makes feedback forms more engaging with variable-driven motion.
