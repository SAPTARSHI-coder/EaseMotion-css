# CSS Mesh Gradient: Pulsating Wave

## Overview

A pure CSS mesh gradient built around slow, breathing wave motion. Blurred radial layers and morphing translucent shapes create a soft animated surface without JavaScript or external assets.

## Features

- Pulsating radial gradient layers
- Morphing translucent wave shapes
- Dark-mode-friendly contrast
- Responsive composition
- Hardware-friendly transforms and opacity animation
- Keyboard-visible link focus
- Reduced-motion support

## Files

- `demo.html` — semantic demonstration markup
- `style.css` — mesh layers, animation, responsive rules, and accessibility behavior
- `README.md` — implementation notes

## Usage

Open `demo.html` in a modern browser. No build tool or dependency is required.

## Accessibility

Decorative gradient layers are hidden from assistive technology. The visible link has a clear focus indicator. `prefers-reduced-motion` disables the continuous decorative animation.
