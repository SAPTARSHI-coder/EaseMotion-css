CSS Grid Accordion

Historically, CSS cannot animate the height property from 0 to auto. Developers had to use JavaScript to calculate the pixel height or use hacky max-height transitions. Using CSS Grid's grid-template-rows solves this natively.

We set the wrapper element to display: grid and transition the grid-template-rows property from 0fr to 1fr.

When the row is 0fr, the grid track has zero height. When it expands to 1fr, it takes up the intrinsic height of its content.
