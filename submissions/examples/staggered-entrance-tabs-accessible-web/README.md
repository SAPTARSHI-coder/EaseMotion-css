# Staggered Entrance Tabs for Accessible Web Layouts

A responsive CSS-first Tabs component featuring a smooth staggered entrance
animation for accessible web interfaces.

## Features

- Pure CSS animation for the visual transition
- Responsive layout
- Keyboard-accessible tabs
- Semantic `tab`, `tablist`, and `tabpanel` roles
- Arrow Left / Arrow Right keyboard navigation
- Home and End keyboard navigation
- Visible keyboard focus states
- Reduced-motion support
- Customizable animation through CSS custom properties
- No external dependencies
