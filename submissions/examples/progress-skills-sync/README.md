
---

## 🚀 Usage
1. Clone or copy the files into your project.
2. Open `demo.html` in your browser.
3. The progress bars will display skill proficiency with percentages.

---

## 🛠️ Customization
- **Colors** → Adjust gradient values in `.progress-bar`.
- **Animation speed** → Modify `transition: width 0.6s ease`.
- **Skill levels** → Change `style="width:XX%"` and text inside `.progress-bar`.

---

## 📖 Accessibility
- Uses `aria-valuenow`, `aria-valuemin`, and `aria-valuemax` for screen readers.
- Clear labels for each skill.
