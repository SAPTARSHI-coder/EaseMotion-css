# Diamond Facet Edge Toggle (#73889)

A pure HTML & Vanilla CSS toggle featuring a geometric, diamond-faceted design with hardware-accelerated transitions and reduced-motion support.

## Features
- **Design Concept:** Diamond/polygon clipped facets with metallic borders and glowing accent states.
- **Pure CSS:** Built entirely with HTML checkbox pseudo-states and zero JavaScript dependencies.
- **Performance:** Hardware-accelerated CSS animations relying on `transform`, `opacity`, and `filter`.
