# Float-Drift Badge

A lightweight, pure CSS Float-Drift Badge for modern fintech dashboard layouts.

The component creates a subtle vertical drifting motion while preserving
readability and usability. It requires no JavaScript or external libraries.

## Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Smooth floating/drifting animation
- Success, warning, and information variants
- CSS custom properties for customization
- Hover/focus interaction
- Responsive layout
- `prefers-reduced-motion` support
- Suitable for fintech dashboards and SaaS interfaces
