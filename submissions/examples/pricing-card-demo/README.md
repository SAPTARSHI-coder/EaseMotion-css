# Responsive Pricing Card Demo

## Description

This example demonstrates a responsive pricing section using EaseMotion CSS.

The demo contains three pricing plans:

- Basic
- Pro
- Enterprise

## Features

- Responsive three-column layout
- Mobile-friendly design
- Pricing information
- Feature lists
- Call-to-action buttons
- Hover animations
- Highlighted popular plan
