# CSS-only Input Field — Neumorphism

A responsive CSS-only input field component featuring a soft
neumorphic interface for EaseMotion CSS.

Implemented for issue #79773.

## Features

- Neumorphic input styling
- Inset input shadows
- Raised icon controls
- Focus-within interaction
- Responsive form layout
- Text, email and textarea fields
- CSS-only implementation
- No JavaScript
- No external dependencies
- Reduced-motion support
