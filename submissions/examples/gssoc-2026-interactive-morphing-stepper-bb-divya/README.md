# Interactive Morphing Stepper Process Bar

## GSSoC 2026

This component provides an interactive multi-step progress indicator
for forms, onboarding flows, checkout processes and similar interfaces.

## Features

- Animated active step node
- Glowing pulse animation
- Completed step checkmarks
- Liquid progress fill
- Clickable step navigation
- Previous and Next controls
- Keyboard-accessible buttons
- Responsive design
- Reduced-motion support
