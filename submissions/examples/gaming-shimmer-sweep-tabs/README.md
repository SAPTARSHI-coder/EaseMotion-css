# CSS Shimmer-Sweep Tabs for Gaming Hub Layouts

A modern **Gaming Hub Tabs** component featuring a smooth **Shimmer-Sweep** animation built entirely with **HTML5 and CSS3**. This example demonstrates interactive tab navigation with animated shimmer highlights, responsive layouts, and accessibility support—without requiring JavaScript.

---

## ✨ Features

- 🎮 Gaming Hub inspired interface
- 📑 CSS-only tab navigation
- ✨ Shimmer-Sweep animation on active tab
- 🎨 Modern gradient styling
- ⚡ Pure HTML5 & CSS3 (No JavaScript)
- 📱 Fully responsive across desktop, tablet, and mobile
- 🎯 CSS Custom Properties for easy customization
- ♿ Accessibility support with `prefers-reduced-motion`
- 🚀 Lightweight and performance-friendly

## 🚀 Getting Started

1. Open `demo.html` in any modern web browser.
2. Click the tabs to switch between different Gaming Hub sections.
3. Observe the shimmer animation on the active tab.
4. Customize colors, spacing, and animation timing using the CSS variables.

:root{
