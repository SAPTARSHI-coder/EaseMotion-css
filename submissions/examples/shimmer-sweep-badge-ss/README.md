# Shimmer Sweep Badge

A lightweight, responsive badge component featuring a smooth shimmer sweep animation for creative portfolio layouts. Built entirely with HTML and CSS, this showcase demonstrates modern motion effects without requiring JavaScript.

## Features

- Pure HTML5 and CSS3
- Smooth CSS keyframe shimmer sweep animation
- Responsive portfolio card layout
- Image hover zoom effect
- CSS Custom Properties for easy customization
- Keyboard-accessible focus styles
- Supports `prefers-reduced-motion`
- Lightweight and performance-friendly

## Folder Structure

```text
submissions/

    └── shimmer-sweep-badge/

```

## Usage

1. Copy the `shimmer-sweep-badge` folder into `submissions/examples/`.
2. Ensure the EaseMotion CSS library is correctly linked in `demo.html`.
3. Open `demo.html` directly in a modern browser.
4. Apply the shimmer badge class to any element you want to highlight.

## CSS Custom Properties

| Variable | Description |
|----------|-------------|
| `--bg-color` | Page background color |
| `--surface` | Card background color |
| `--text-color` | Primary text color |
| `--muted-color` | Secondary text color |
| `--accent` | Primary button color |
| `--accent-hover` | Button hover color |
| `--badge-start` | Badge gradient start color |
| `--badge-end` | Badge gradient end color |
| `--shadow` | Card shadow |
| `--radius` | Border radius |
| `--transition` | Global transition timing |
