# Interactive Datepicker with Glassmorphism Styling

> Issue: [#81520](https://github.com/SAPTARSHI-coder/EaseMotion-css/issues/81520) / [#11439](https://github.com/SAPTARSHI-coder/EaseMotion-css/issues/11439)

A responsive, interactive datepicker component with frosted glass optics and pure CSS date selection.

---

## ✨ Features & Architectural Highlights

- **Zero-JS Date Selection:** Native HTML radio inputs (`<input type="radio">`) paired with `:checked` styling for state selection.
- **Glassmorphism Design System:** Frosted `backdrop-filter: blur(20px)` card UI with subtle border highlights.
- **Accessible & Responsive:** Adapts across devices with `@media (prefers-reduced-motion: reduce)` support.

---

## 🚀 Usage

1. Include `style.css` in your HTML `<head>`:
   ```html
   <link rel="stylesheet" href="style.css" />
   ```
2. Use the HTML structure provided in `demo.html`.
