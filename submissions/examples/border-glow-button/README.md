# Border Glow Button

A dark button whose border lights up and pulses with an outer glow on hover.

## Features
- Animated border glow using layered box-shadows
- Text brightens and border tints violet
- Pulse breathing makes the glow feel alive

## Usage
```html
<button class="bgc-btn" type="button">Feel the Glow</button>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
