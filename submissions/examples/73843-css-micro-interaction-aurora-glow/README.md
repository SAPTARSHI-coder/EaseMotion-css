# CSS Micro-interaction: Aurora Glow

## Overview

A compact button interaction with a soft aurora halo that becomes more vivid on hover and keyboard focus.

## Features

- Layered conic-gradient glow
- Hover elevation
- Native button semantics
- Visible keyboard focus
- Responsive layout
- Reduced-motion support
- Pure HTML and Vanilla CSS

## Files

- `demo.html` — semantic control and supporting content
- `style.css` — glow layers and interaction states
- `README.md` — documentation

## Accessibility

The main action is a native button. Decorative glow layers are not exposed as content, and reduced-motion preferences remove animated transitions.
