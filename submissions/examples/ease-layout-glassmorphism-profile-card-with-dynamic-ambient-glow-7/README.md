# Glassmorphism Profile Card with Dynamic Ambient Glow 7
### High-Contrast Accessibility Edition

A modern glassmorphism-inspired profile card built with semantic HTML and pure CSS. This component combines a high-contrast interface, dynamic ambient glow effects, responsive layout, and accessibility-focused interactions for a clean and premium user experience.

---

## ✨ Features

- Modern glassmorphism design
- High-contrast accessibility-friendly color palette
- Dynamic ambient glow background
- Responsive layout for desktop and mobile
- Gradient avatar ring with online status indicator
- Interactive statistic cards
- Animated skill chips
- Primary and secondary action buttons
- Keyboard focus support (`:focus-visible`)
- Reduced motion support (`prefers-reduced-motion`)
- Pure HTML & CSS (no frameworks)

## 🚀 Usage

1. Open the project folder.
2. Keep `demo.html` and `style.css` in the same directory.
3. Open `demo.html` in any modern web browser.

No installation or dependencies are required.
