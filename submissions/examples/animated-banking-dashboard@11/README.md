# Animated Banking Dashboard

A premium **Banking Dashboard** built with **EaseMotion CSS**. Features a 3D credit card with shine effect, balance overview, spending charts, savings goals, transaction history, and upcoming bills.

## ✨ Features

- **💳 3D Credit Card**: Animated shine effect with hover tilt
- **💰 Balance Overview**: Total balance with account breakdown
- **⚡ Quick Actions**: Send, receive, pay bills, exchange buttons
- **📊 Spending Chart**: Weekly bar chart with tooltips
- **🎯 Savings Goals**: Progress bars with color-coded goals
- **📋 Transactions**: Categorized transaction list with icons
- **📅 Upcoming Bills**: Bill payment cards with due dates
- **🎬 Staggered Entrance**: All sections slide up sequentially
- **📱 Fully Responsive**: Multi-column to single column adaptation

## 🧩 EaseMotion Classes Used

| Class | Purpose |
|-------|---------|
| `ease-fade-in` | Fades in the main page and footer |
| `ease-slide-up` | Slides sections up on entrance |
| `ease-delay-100` to `ease-delay-800` | Creates cascading staggered sequence |
| `ease-card` | Base card structure |
| `ease-hover-lift` | Lift effect on all cards |
| `ease-hover-grow` | Scale effect on buttons |
| `ease-center` | Centers notification button |
| `ease-grid` + `ease-grid-cols-3` | Responsive grid layouts |
| `ease-gap-4` | Spacing between grid items |
| `ease-pulse` | **Looping pulse** on notification dot |

## 🚀 How to Use

1. Open `demo.html` in any modern browser
2. Watch all sections slide in with staggered animations
3. Observe the **credit card shine** animation
4. Hover over the credit card to see 3D tilt effect
5. See the **spending bars grow** with hover tooltips
6. Notice the **pulsing notification** dot
7. Resize to mobile to see the responsive layout
