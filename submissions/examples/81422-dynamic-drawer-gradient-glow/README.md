# Dynamic Drawer with Gradient Glow Styling

## Overview

A responsive Dynamic Drawer component implemented using pure HTML and CSS.

The component uses gradient backgrounds, glowing visual effects, smooth
transitions, interactive navigation states, and responsive layouts to create
a modern dynamic drawer experience.

## Features

- Pure HTML and CSS implementation
- No external JavaScript dependencies
- Gradient glow visual styling
- Animated drawer entrance and exit
- Interactive navigation hover states
- Active navigation state
- Ambient background glow effects
- Responsive desktop, tablet, and mobile layouts
- CSS custom properties for reusable design tokens
- Accessible focus-visible states
- `prefers-reduced-motion` support
- Semantic navigation and drawer structure
