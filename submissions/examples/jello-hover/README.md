# Jello Hover Effects

**What does this do?**
Provides two playful hover animations (`jello-horizontal` and `jello-vertical`) that distort an element's skew property to simulate a wobbling, gelatinous effect when interacted with.

**How is it used?**
Apply the utility classes to any interactive element like buttons or cards:
```html
<button class="jello-horizontal-ag">Hover me (Horizontal wobble)</button>
<div class="jello-vertical-ag">Hover me (Vertical wobble)</div>
```

**Why is it useful?**
It provides highly engaging, playful micro-interactions that make UIs feel more physical and responsive, which is great for gamified interfaces or primary call-to-action buttons.
