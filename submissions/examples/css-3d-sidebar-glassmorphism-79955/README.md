# 3D Sidebar with Glassmorphism Styling

A modern sidebar component featuring glassmorphism effects, subtle 3D perspective depth, smooth hover interactions, and responsive layouts built entirely with HTML and CSS.

## Features

- Pure HTML & CSS
- Glassmorphism design
- 3D perspective effect
- Responsive layout
- Smooth hover animations
- Dark mode compatible
- No JavaScript required

## Files

- demo.html
- style.css

## Usage

```html
<aside class="glass-sidebar">
  <div class="logo">EaseMotion</div>

  <nav>
    <a href="#" class="active">Dashboard</a>
    <a href="#">Analytics</a>
    <a href="#">Settings</a>
  </nav>
</aside>
```

## Why it fits EaseMotion CSS

This component combines elegant motion, glassmorphism aesthetics, subtle 3D interactions, and responsive behavior while remaining lightweight, reusable, and accessibility-friendly.
