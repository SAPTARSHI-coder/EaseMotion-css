# Responsive Avatar with Neon Styling

A responsive neon-themed avatar component created using pure HTML and CSS.

## Features

- Neon cyan and purple visual styling
- Animated glowing avatar rings
- Online status indicator
- Responsive avatar sizing
- Responsive profile layout
- Hover glow interaction
- Multiple avatar size examples
- Accessible image role and status label
- Reduced-motion accessibility support
- Pure HTML and CSS
- No JavaScript dependency

## Files

- `demo.html` — avatar component markup
- `style.css` — component styling, animation, and responsive behavior

## Responsive Behavior

On desktop, the avatar and profile information are displayed side-by-side.

On smaller screens, the layout automatically switches to a vertical
arrangement for improved readability and usability.

## Usage

Open `demo.html` in a browser to preview the component.

The avatar letter can be replaced with an image or other content while
keeping the same styling structure.
