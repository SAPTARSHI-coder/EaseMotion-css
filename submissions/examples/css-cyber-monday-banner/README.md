# CSS Cyber Monday Banner (#70797)

A high-impact promotional sale banner featuring an animated text glitch effect and static countdown blocks, built entirely with pure CSS.

## Features
- **Semantic Structure:** Uses accessible `<main>` landmark containers and screen-reader friendly typography layout.
- **Pure CSS Glitch Animation:** Custom `@keyframes` driving text shadow offsets and skew transformations.
- **Responsive Design:** Flexbox layout that scales fluidly across desktop and mobile screens.

## File Hierarchy
- `style.css` - Keyframe animations, glowing box shadows, and grid layouts.
- `demo.html` - Semantic markup and accessibility attributes.
- `README.md` - Technical specification and architecture overview.
