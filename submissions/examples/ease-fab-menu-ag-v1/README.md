# CSS Floating Action Menu

A floating action button that expands into a radial menu on click — pure CSS, no JavaScript.

## 🚀 Demo
Open `demo.html` in your browser.

## ✨ Features
- Click-triggered radial expansion using the checkbox hack
- Smooth scale + translate transitions
- No JavaScript dependencies
- Easy to add/remove menu items

## 📁 Files
- `demo.html` — Demo page showing the menu
- `style.css` — FAB and radial menu styles
- `README.md` — This file

## 🛠️ Usage
```html
<div class="fab-menu">
  <input type="checkbox" class="fab-menu__toggle" id="fabToggle">
  <label for="fabToggle" class="fab-menu__button">+</label>
  <a href="#" class="fab-menu__item">✉</a>
  <a href="#" class="fab-menu__item">📷</a>
</div>
```
