# CSS Rotate-Fade Badge for Product Catalog

A lightweight, responsive product catalog example featuring a reusable
CSS Rotate-Fade Badge animation.

The badge enters with a combined rotation, scale, and fade effect and
responds to product-card hover interactions.

## Features

- Pure HTML and CSS
- No JavaScript
- No external frameworks
- Rotate and fade entrance animation
- Hover interaction
- Responsive product grid
- CSS custom properties
- `prefers-reduced-motion` support
- Works by opening `demo.html` directly
