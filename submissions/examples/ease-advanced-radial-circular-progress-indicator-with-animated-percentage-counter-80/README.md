# Radial Circular Progress Indicator with Animated Percentage Counter

### Compact Mobile-First Edition

A modern **Radial Circular Progress Indicator** built with **HTML5** and **CSS3** featuring an animated circular progress ring, responsive mobile-first layout, and accessibility-friendly interactions.

---

## ✨ Features

- Animated circular progress
- Percentage counter
- Compact mobile-first design
- Responsive layout
- CSS variables
- Smooth hover effects
- `prefers-reduced-motion` support
- Pure HTML & CSS
