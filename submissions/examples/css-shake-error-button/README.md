# CSS Shake Error Button

A CSS-only button component that shakes horizontally to indicate an error state or invalid action.

## Features

- Pure CSS implementation
- Horizontal shake animation
- Responsive design
- Accessible button element
- CSS custom properties for easy theming
- Supports light and dark modes

## Usage

Include the stylesheet and use the button class:

```html
<button class="shake-btn">
  Invalid Action
</button>
