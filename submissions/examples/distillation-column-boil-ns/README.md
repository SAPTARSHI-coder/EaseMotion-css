# Distillation Column Boil

## What does this do?
Renders a self-contained CSS-only `ease-distillation-column-boil` demo: Distillation column trays boiling and refluxing.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-distillation-column-boil`. No build step or JavaScript is required for the effect.

```html
<section class="ease-distillation-column-boil">
  <div class="ease-distillation-column-boil__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
