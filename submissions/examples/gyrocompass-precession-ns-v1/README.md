# Gyrocompass Precession

A pure CSS animated visualization of a gyrocompass, combining a continuously spinning gyro rotor with a slower azimuth precession of the compass card.

## ✨ Features

- Pure HTML and CSS
- No JavaScript
- Animated gyro rotor
- Slow compass-card precession
- Instrument-inspired interface
- CSS custom properties
- Responsive layout
- `prefers-reduced-motion` support
- No external dependencies
