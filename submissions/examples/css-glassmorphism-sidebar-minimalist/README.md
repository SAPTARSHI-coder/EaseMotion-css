# CSS Glassmorphism Sidebar - Minimalist

A high-performance, responsive pure CSS sidebar component featuring frosted glassmorphism styling and clean minimalism, built entirely with vanilla CSS.

## 🚀 Features

- **Zero JavaScript Required:** Built using native CSS flex layouts, backdrop blur filters, and hardware-accelerated transitions.
- **Glassmorphism Aesthetic:** Semi-transparent panel surfaces with `backdrop-filter: blur(25px)` and delicate highlights.
- **Fully Responsive & Accessible:** Fluidly stacks on mobile viewports. Includes proper keyboard focus states and `@media (prefers-reduced-motion: reduce)` support.

## 🛠️ Usage

Copy the HTML structure from `demo.html` and link the styles from `style.css`.
