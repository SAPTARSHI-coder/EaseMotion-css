# Retro Arcade Pixel Navigation

A responsive navigation component inspired by classic **Retro Arcade Pixel** interfaces, built entirely with HTML and Vanilla CSS.

## ✨ Features

- Retro arcade visual language
- Pixel-inspired borders and hard shadows
- CRT-style scanlines
- Arcade-style navigation labels
- Active and hover states
- Scoreboard section
- Responsive CSS-only mobile menu
- Dark-mode compatible
- Keyboard-accessible navigation
- Visible focus states
- Reduced-motion support
- No JavaScript
- No external dependencies
