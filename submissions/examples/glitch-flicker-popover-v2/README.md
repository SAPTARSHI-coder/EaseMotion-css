# CSS Glitch-Flicker Popover

A lightweight Pure HTML & CSS popover with a glitch flicker entrance animation.

## Features

- Pure HTML & CSS
- Responsive layout
- Accessible
- CSS Custom Properties
- prefers-reduced-motion support
- No JavaScript

## Files

```
demo.html
style.css
README.md
```

## CSS Variables

```css
--bg
--card
--text
--accent
--shadow
--radius
--duration
```

## Usage

Open `demo.html` in any browser.

Hover over the button to display the popover with the glitch flicker effect.

## Accessibility

- Responsive
- Keyboard friendly structure
- Motion reduction support
- High contrast colors
