# Air Hockey Puck

## What does this do?
Renders a self-contained CSS-only `ease-air-hockey-puck` demo: Air-hockey puck ricocheting across a glowing table.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-air-hockey-puck`. No build step or JavaScript is required for the effect.

```html
<section class="ease-air-hockey-puck">
  <div class="ease-air-hockey-puck__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
