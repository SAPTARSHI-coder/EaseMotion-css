# Dynamic Slider - Pastel Styling

A responsive pastel-themed dynamic slider built using pure HTML, CSS, and JavaScript.

## Features

- Pastel gradient track
- Dynamic value display
- Glass-like card layout
- Mobile responsive
- Lightweight implementation

## Files

- demo.html
- style.css

## Usage

Open `demo.html` in a browser.
Adjust the slider to see the value update dynamically.

## Customization

- Change pastel colors in the slider gradient.
- Modify slider range values.
- Adjust card styling and spacing.
