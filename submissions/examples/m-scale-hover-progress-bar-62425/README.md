# CSS Scale-Hover Progress Bar for Product Catalog Layouts

A modern **Scale-Hover Progress Bar** built using pure HTML and CSS. The component features an elegant scale-hover animation, responsive layout, CSS custom properties, and lightweight styling for product catalog interfaces.

## ✨ Features

- Pure HTML5 & CSS3
- Scale-hover progress animation
- Responsive layout
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
