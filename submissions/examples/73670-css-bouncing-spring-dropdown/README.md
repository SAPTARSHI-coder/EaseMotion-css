# CSS Dropdown: Bouncing Spring Variation

## Overview

A responsive and accessible dropdown component created using pure HTML
and vanilla CSS.

The component uses the native HTML `<details>` and `<summary>` elements
for interaction and CSS keyframes to create a smooth spring-inspired
opening animation.

## Features

- Pure HTML and CSS
- No JavaScript required
- Native accessible dropdown behavior
- Bouncing spring opening animation
- Staggered menu item entrance
- Smooth hover interactions
- Dark mode compatible
- Responsive design
- Hardware-friendly CSS transforms
- Reduced-motion support

## Technologies

- HTML5
- CSS3
- CSS Keyframes
- CSS Transforms
- CSS Media Queries
- Native Details/Summary

## Usage

Open `demo.html` in a modern browser.

Click the **Explore options** dropdown to view the spring animation.

## Accessibility

The component uses semantic `<details>` and `<summary>` elements,
providing native keyboard interaction without JavaScript.

The implementation also supports:

- Visible keyboard focus states
- `prefers-reduced-motion`
- Semantic links
- Screen-reader friendly structure
