# CSS Watermark Stamp

A lightweight, responsive watermark/stamp overlay created using pure CSS.

This component was created for EaseMotion CSS issue #68322.

## Features

- Pure HTML and CSS
- No JavaScript required
- Rotated watermark effect
- Multiple stamp variants
- Responsive card layout
- Light and dark mode support
- CSS custom properties for easy theming
- Subtle CSS animation
- Reduced-motion support
- Decorative watermark hidden from assistive technologies

## Included Variants

- APPROVED
- DRAFT
- FEATURED
