# Float Drift Badge

A lightweight gaming-themed floating badge built with pure HTML and CSS.

## Features

- Floating drift animation
- Neon glow effect
- Responsive layout
- Hover interaction
- Pure HTML & CSS
- Accessibility support with prefers-reduced-motion

## Folder

```
submissions/examples/float-drift-badge/
```

## Files

- demo.html
- style.css
- README.md

## CSS Custom Properties

```css
--bg
--card
--primary
--secondary
--text
```

## Responsive

Works on:

- Desktop
- Tablet
- Mobile

## Accessibility

Supports

```css
@media (prefers-reduced-motion: reduce)
```

to disable animations for users who prefer reduced motion.
