# CSS Elastic-Slide Stepper for Fintech Dashboard Layouts

A modern **Elastic-Slide Stepper** built using pure HTML and CSS. It provides an elegant onboarding progress component with smooth elastic-slide animations, glassmorphism styling, and a fully responsive layout for fintech dashboards.

## ✨ Features

- Pure HTML5 & CSS3
- Elastic-slide entrance animation
- Glassmorphism stepper cards
- Responsive layout
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
