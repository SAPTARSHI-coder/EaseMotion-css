# CSS 3D Flip Credit Card

An interactive, realistic 3D credit card component. When hovered, the card smoothly flips 180 degrees on the Y-axis to reveal the magnetic strip and CVC code on the back.

## Features
- CSS 3D transforms using `rotateY`
- Elements stacked with `backface-visibility: hidden`
- Elastic bounce animation via `cubic-bezier` transitions
