# Bell Tower Clapper

## What does this do?
Renders a self-contained CSS-only `ease-bell-tower-clapper` demo: Cathedral bell swinging with clapper strike pulse.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-bell-tower-clapper`. No build step or JavaScript is required for the effect.

```html
<section class="ease-bell-tower-clapper">
  <div class="ease-bell-tower-clapper__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
