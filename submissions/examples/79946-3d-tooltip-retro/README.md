# 3D Tooltip - Retro Styling

A responsive CSS-only 3D tooltip component inspired by retro arcade and
pixel-era interfaces.

## ✨ Features

- Pure HTML and CSS
- No JavaScript dependency
- Fully responsive
- Hover interaction
- Keyboard focus interaction
- 3D tooltip entrance effect
- Layered tooltip depth
- Retro arcade styling
- Pixel-inspired shadows
- Neon cyan, pink and yellow palette
- Animated background grid
- Decorative star field
- Reduced-motion support
