# Float-Drift Card Grid for E-Commerce Checkout

A responsive e-commerce checkout showcase featuring a lightweight
CSS-only Float-Drift animation applied to product cards.

## Features

- Pure HTML and CSS
- No JavaScript
- No external frameworks
- Responsive product card grid
- Smooth floating/drifting card animation
- Different animation delays for natural movement
- Hover interaction pauses the floating animation
- Product card elevation on hover
- CSS decorative glow effect
- CSS custom properties
- Keyboard-accessible button and navigation
- `prefers-reduced-motion` support
- Desktop, tablet and mobile layouts
