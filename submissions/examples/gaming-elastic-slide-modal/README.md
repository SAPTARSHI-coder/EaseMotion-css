# CSS Elastic-Slide Modal for Gaming Hub Layouts

A modern **Gaming Hub Modal** featuring a smooth **Elastic-Slide** entrance animation built entirely with **HTML5 and CSS3**. The modal delivers an engaging user experience without requiring JavaScript, making it lightweight, responsive, and easy to integrate.

---

## Features

- 🎮 Gaming Hub inspired interface
- ✨ Elastic-Slide modal animation
- 🪟 Modal overlay with smooth backdrop
- ⚡ Pure HTML5 & CSS3 (No JavaScript)
- 📱 Fully responsive design
- 🎨 CSS Custom Properties for customization
- ♿ `prefers-reduced-motion` support
- 🚀 Lightweight and easy to integrate

## Usage

1. Open `demo.html` in any modern web browser.
2. Click the **Launch Tournament** button.
3. The modal opens with an elastic-slide animation.
4. Close the modal using the **×** button.
