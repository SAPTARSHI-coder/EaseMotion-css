# Skeleton Pulse Loading Shimmer Placeholder for Card Grids

A modern **Compact Mobile-First** skeleton loading component built with pure **HTML & CSS**. It simulates loading product cards using smooth shimmer and pulse animations while maintaining a clean, responsive layout.

## ✨ Features

- Compact mobile-first layout
- Smooth shimmer loading animation
- Pulse effect for realistic placeholders
- Responsive CSS Grid
- Modern CSS variables
- Lightweight and dependency-free
- Easy to customize
- Pure HTML & CSS

## 📁 Project Structure

```
ease-advanced-skeleton-pulse-loading-shimmer-placeholder-for-card-grids-64/
│── demo.html
│── style.css
└── README.md
```

## 🚀 Usage

1. Navigate to the project folder.
2. Open `demo.html` in any modern browser.
3. Customize colors, spacing, and animations in `style.css`.

## 🎨 Customization

You can edit the CSS variables inside `:root`:

- Background colors
- Skeleton colors
- Border radius
- Shadow intensity
- Animation speed
- Grid spacing
