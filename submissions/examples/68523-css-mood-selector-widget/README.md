# CSS Mood Selector Widget

## Overview

A friendly mood-selection component with an expressive face, mood choices, hover states, and accessible button labels.

## Features

- Emoji mood choices
- Animated face presentation
- Selected state styling
- Responsive choice grid
- Native keyboard-focus behavior
- Reduced-motion support
- Pure HTML and CSS

## Files

- `demo.html` — mood widget markup
- `style.css` — face styling, controls, states, motion, and responsive layout
- `README.md` — documentation

## Accessibility

Mood choices are native buttons with accessible labels and visible focus rings. Decorative facial elements are hidden from assistive technology.
