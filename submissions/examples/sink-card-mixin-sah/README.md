# Tactile Sink Card Animation Mixin (`#54692`)

## What does this do?
Provides a deeply rewarding tactile card interaction that depresses containers inwards down into the page background with recessed inner shadowing when clicked.

## How is it used?
Attach the `ease-card-sink` class directly to interactive modular preview cards:
```html
<article class="ease-card-sink">
  <h3>Interactive Module</h3>
</article>
```

## Why is it useful?
Solves issue #54692 by diversifying user interface tactile responses beyond customary floating hover expansions.
