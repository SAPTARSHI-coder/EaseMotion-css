# glow-accordion-v4-ak

Pure CSS animated glowing neon border accordion drawer component — no JavaScript required.

## How to use

```html
<div class="ease-accordion-v4">
  <input type="checkbox" id="item1" class="ease-accordion-checkbox-v4" />
  <div class="ease-accordion-item-v4">
    <label for="item1" class="ease-accordion-header-v4">
      <span>Header</span>
      <span class="ease-accordion-icon-v4">▼</span>
    </label>
    <div class="ease-accordion-drawer-v4">
      <div class="ease-accordion-body-v4">Content</div>
    </div>
  </div>
</div>
