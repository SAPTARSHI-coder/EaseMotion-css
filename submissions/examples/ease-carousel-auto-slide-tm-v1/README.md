# Carousel Auto Slide Component

Add ease-carousel-auto-slide-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|---------|
| `--cas-accent` | `#6366f1` |
| `--cas-radius` | `12px` |
| `--cas-shadow` | `0 8px 32px rgba(0,0,0,.4)` |

## Technique

CSS `animation` on `translateX` track. Three slides at 33.333% each, cycling every 9s.
