# Chaos Backpressure Valve

An advanced CSS animation that visualizes a chaos-tested backpressure valve. Request streams surge into a pressure chamber, valve shutters modulate admission, overflow packets drain into a cooldown lane, and recovery rings stabilize the system.

## Features

- CSS-only chaos/backpressure system visualization
- Pressure chamber, adaptive valve, overflow drain, and recovery metrics
- Responsive accessible demo markup
- Expanded generated timing samples for advanced animation coverage
