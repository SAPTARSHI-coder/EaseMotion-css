# Subtle Elevate Card

A smooth, accessible, and performant pure CSS card featuring a **Subtle Elevate** interaction style.

## Features

- Pure HTML and Vanilla CSS
- Gentle hover elevation
- Smooth CSS transitions
- Hardware-accelerated transform
- Keyboard focus support
- Dark mode support
- Reduced-motion support
- Responsive layout
- No external JavaScript

## Files

- `demo.html` — Card markup and demo
- `style.css` — Complete styling and animations

## Usage

Open `demo.html` directly in a modern browser.

## Accessibility

The card supports keyboard focus and includes a visible focus indicator. Users who prefer reduced motion are provided with a static interaction through `prefers-reduced-motion`.
