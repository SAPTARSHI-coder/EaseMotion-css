# CSS Rotate-Fade Popover for Product Catalog Layouts

A modern product catalog component featuring a **Rotate-Fade Popover** animation built entirely with HTML5 and CSS3. The popover smoothly rotates and fades into view when users hover over a product card, providing additional product information without JavaScript.

## Features

- Pure HTML5 & CSS3
- Rotate + Fade popover animation
- Responsive product grid
- Modern UI design
- CSS Custom Properties
- Lightweight and reusable
- No JavaScript required
- Supports `prefers-reduced-motion`
