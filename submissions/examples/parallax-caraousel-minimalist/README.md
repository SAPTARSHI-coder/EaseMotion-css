## 🚀 Usage
1. Clone or copy the files into your project.
2. Open `demo.html` in your browser.
3. The carousel will auto-slide with parallax background styling.

---

## 🛠️ Customization
- **Animation speed** → Adjust `animation: slide 12s` for faster/slower carousel.
- **Images** → Replace `background-image` URLs in `.carousel-item`.
- **Parallax depth** → Modify `background-attachment` and `background-position`.

---

## 📖 Accessibility
- Uses `role="region"` and `aria-label="Minimalist parallax carousel"`.
- Auto-sliding ensures continuous motion without user input.
