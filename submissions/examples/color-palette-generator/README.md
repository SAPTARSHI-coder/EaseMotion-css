# CSS Color Palette Generator

A responsive, CSS-only color palette display featuring harmony labels and HEX color values.

## Features

- Pure HTML and CSS
- Five-color harmony palette
- Primary, secondary, analogous, complementary, and accent labels
- HEX values for every color
- Responsive layout
- Hover and focus states
- Accessible color descriptions
- Reduced-motion support
- No JavaScript
- No external libraries
