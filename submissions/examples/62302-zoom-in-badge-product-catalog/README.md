# CSS Zoom-In Badge for Product Catalog Layouts

A modern **Zoom-In Badge** component built using pure HTML5 and CSS3 for product catalog showcase layouts. This component adds attractive animated badges with smooth zoom entrance effects, interactive product cards, and responsive design.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Modern product catalog card layout
* Smooth zoom-in badge animation
* Animated product labels
* Hover scale effects
* Glassmorphism product cards
* Gradient badge styling
* Interactive CTA buttons
* Responsive desktop, tablet, and mobile layouts
* CSS Custom Properties for easy customization
* Lightweight keyframe animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. View the animated product badges on page load.
3. Hover over product cards to see zoom and elevation effects.
4. Customize colors, shadows, spacing, and animation values using CSS variables inside `:root`.
