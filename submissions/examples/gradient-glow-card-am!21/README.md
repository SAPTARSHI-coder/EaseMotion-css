# Gradient Glow Card Submission

## 1. What does this do?
It creates a visually striking card component featuring an animated gradient border and seamless hover interactions, demonstrating how custom CSS can beautifully complement EaseMotion's utility classes.

## 2. How is it used?
Simply include the `glow-card` class along with EaseMotion utilities like `ease-hover-lift` and `ease-fade-in`. 
```html
<div class="glow-card ease-hover-lift">
  <div class="card-content">
    <!-- content -->
  </div>
</div>
