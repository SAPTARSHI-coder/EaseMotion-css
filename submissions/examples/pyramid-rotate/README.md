# Pyramid Rotate

A tetrahedron-style pyramid spins slowly, showing three shaded faces.

## Features
- 3D pyramid from four faces
- Continuous slow spin
- Face gradients create depth
- Pure CSS

## Usage
```html
<div class="pyr-face" style="--i:0"></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
