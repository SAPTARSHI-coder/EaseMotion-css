# CSS Split Action Button

A compound action control with a primary action and a visually separated secondary menu trigger.

## Features

- Split primary and secondary actions
- Clear visual grouping
- Hover and focus states
- Responsive sizing
- Keyboard-friendly controls
- Reduced-motion support
- No JavaScript required for the visual demo

## Files

- `demo.html` — semantic button structure
- `style.css` — layout, states, separators, and responsive styling

## Accessibility

Both controls are independently focusable and have accessible labels. Visible focus indicators remain available for keyboard users.
