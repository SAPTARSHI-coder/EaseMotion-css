# CSS 3D Bouncing Spring

A pure CSS 3D bouncing spring animation featuring a glowing spring, bouncing ball, perspective depth, and a futuristic platform.

## Features

- Pure HTML and vanilla CSS
- No JavaScript or external libraries
- 3D perspective transforms
- Smooth spring-like bouncing motion
- Responsive design
- Dark-mode friendly styling
- Hardware-accelerated transforms
- Reduced-motion support

## Usage

Open `demo.html` directly in a modern browser.

The component can be reused by copying the HTML structure and linking `style.css`.

## Accessibility

The demo uses semantic HTML, a descriptive section label, meaningful text content, and `prefers-reduced-motion` support.

## EaseMotion CSS

This component provides a reusable CSS-only animation pattern that demonstrates spring physics-inspired motion, 3D transforms, glowing effects, and smooth transitions.
