# Discount Badge

A corner-striped badge that pulses to draw the eye to a seasonal sale.

## Features
- Diagonal stripes with a crisp clipping path
- Pulsing glow to attract attention
- Works over any product image

## Usage
```html
<div class="db-scene">
  <span class="db-badge">-40%</span>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
