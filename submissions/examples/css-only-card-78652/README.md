# CSS-only Card

Minimalist responsive card showcase for issue #78652.

## Files

- `demo.html` — semantic article/card content.
- `style.css` — layout, spacing, borders, and interaction states.

## Features

- No JavaScript dependency.
- Semantic content structure.
- Minimal visual hierarchy.
- Hover and keyboard focus treatment.
- Responsive sizing.

The card can be reused for articles, products, profiles, or dashboard summaries.
