# Shear Molten Cut

## What does this do?
Renders a self-contained CSS-only `ease-shear-molten-cut` demo: Shears cutting a molten gob from the gather.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-shear-molten-cut`. No build step or JavaScript is required for the effect.

```html
<section class="ease-shear-molten-cut">
  <div class="ease-shear-molten-cut__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
