# Image Lightbox Submission

## 1. What does this do?
It provides a beautiful, animated image lightbox component with smooth zoom and fade transitions, navigation controls, keyboard shortcuts, and touch/swipe support. Perfect for photo galleries, portfolios, and product showcases.

## 2. How is it used?
Create a gallery grid with `.gallery-item` elements containing images. Click any image to open the lightbox modal. Use navigation buttons or arrow keys to browse images. Press Escape or click outside to close. On mobile, swipe left/right to navigate.

## 3. Why is it useful?
- Essential component for photo galleries and portfolios
- Smooth zoom and fade animations when opening
- Navigation buttons with hover effects
- Keyboard shortcuts (Arrow keys, Escape)
- Touch/swipe gestures for mobile devices
- Image counter showing current position
- Caption display for each image
- Backdrop blur effect for better focus
- Fully responsive design
- Accessible with ARIA labels and `prefers-reduced-motion` support
- Easy to customize styles and animations
- Maintainer can easily standardize this as `.ease-lightbox-[YOUR_INITIALS]` in the core library.
