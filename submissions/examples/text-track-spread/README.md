# Text Track Spread

Letter-spacing widens and narrows rhythmically, like breathing type.

## Features
- Letter-spacing pulse
- Opacity whisper
- Cinematic easing
- Pure CSS

## Usage
```html
<h2 class="tts-title">Breathing type</h2>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
