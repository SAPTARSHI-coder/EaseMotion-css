# CSS Send Arrow Animate

A demo project showcasing a **send button with animated arrow** using HTML, CSS, and JavaScript.

## Features
- Button with text and arrow icon.
- Arrow animates to the right when clicked, simulating a "send" action.
- Neon glow styling with hover scaling.
- Reset animation after 1.5 seconds.

## Files
- `demo.html` → Structure with button and JavaScript click handler.
- `style.css` → Styling for button, glow effects, and arrow animation.
- `README.md` → Documentation and usage instructions.

## Usage
1. Open `demo.html` in your browser.
2. Click the **Send** button.
3. Watch the arrow animate to the right, simulating a send action.
4. The animation resets automatically after 1.5 seconds.

## Customization Ideas
- Replace the arrow with an SVG icon for smoother animation.
- Add a "sent" confirmation message after animation.
- Change glow colors for different themes.
- Extend with actual form submission logic.
