# 3D Breadcrumb — Minimalist

A responsive 3D breadcrumb navigation component built with
pure HTML and CSS for EaseMotion CSS.

Implemented for issue #79722.

## Features

- Minimalist visual design
- Subtle 3D depth
- CSS-only interaction
- Responsive layout
- Hover elevation effect
- Pressed interaction state
- Keyboard focus styling
- Semantic breadcrumb navigation
- Reduced-motion support
- No external dependencies
