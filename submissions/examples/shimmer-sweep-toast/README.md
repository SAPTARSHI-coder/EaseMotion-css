# Shimmer-Sweep Toast

A lightweight CSS-only toast notification designed for fintech dashboard layouts.

The component combines a clean notification card with a subtle animated shimmer that sweeps across the toast.

## Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Smooth shimmer-sweep animation
- Fade-in entrance animation
- Responsive desktop, tablet, and mobile layouts
- Accessible status notification
- Keyboard-friendly close button
- Visible keyboard focus state
- `prefers-reduced-motion` support
- Easy to customize
