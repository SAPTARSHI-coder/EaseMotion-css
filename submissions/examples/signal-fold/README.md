# Signal Fold

Signal Fold is an interactive data visualization component built around the metaphor of a folded information sheet.

Instead of presenting metrics as separate cards, the component connects them into a single continuous surface.

Each section behaves like a fold.

When the user interacts with a section, the fold opens and reveals additional information.
