# 🧊 Frost Bloom

Frost Bloom is an interactive crystalline growth component where frost patterns grow outward from user interaction points.

Each click or touch creates a new frost seed.

From the seed, multiple primary crystal branches grow outward.

Some primary branches generate secondary branches, creating organic frost structures that resemble ice crystals forming naturally on cold glass.

---

## ✨ Features

- 🧊 Interactive frost seeds
- ❄️ Organic crystal branching
- 🌱 Progressive growth
- 💠 Multiple simultaneous blooms
- ✨ Ice glow
- 🌫️ Glass-like background
- 🎚️ Growth speed
- 🎚️ Frost density
- 📊 Bloom counter
- 🔄 Clear functionality
- 🖱️ Pointer interaction
- ⌨️ Keyboard shortcuts
- 📱 Responsive layout
