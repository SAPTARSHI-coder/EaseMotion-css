# CSS Cinematic Letter Box

A pure CSS cinematic letterbox effect where black bars slide into view when the user hovers over or focuses on the scene.

## Features

- Pure HTML and CSS
- No JavaScript
- Cinematic top and bottom letterbox bars
- Smooth CSS transitions
- Hover interaction
- Keyboard focus support
- Responsive design
- Accessible semantic structure
- `prefers-reduced-motion` support
- Works without external libraries
