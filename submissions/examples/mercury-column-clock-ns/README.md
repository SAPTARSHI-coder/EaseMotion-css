# Mercury Column Clock

## What does this do?
Renders a self-contained CSS-only `ease-mercury-column-clock` demo: Mercury column clock level rise.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-mercury-column-clock`. No build step or JavaScript is required for the effect.

```html
<section class="ease-mercury-column-clock">
  <div class="ease-mercury-column-clock__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
