# CSS Toast: Bouncing Spring

A playful and smooth pure CSS notification/toast featuring a
**Bouncing Spring** visual style.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript or external dependencies
- Spring-inspired entrance animation
- Smooth overshoot and settling motion
- Accessible status notification
- Keyboard-accessible dismiss button
- Dark mode compatibility
- Responsive design
- Reduced-motion support
- Hardware-friendly transform and opacity animation
