# Floating Action Button

A compact floating action button with a subtle lift, scale, and shadow
transition.

## What does it do?

The component provides:

- Elevated floating appearance.
- Smooth lift on hover.
- Subtle scale transition.
- Animated action icon.
- Keyboard focus interaction.
- Responsive presentation.
- Reduced-motion support.
- No JavaScript.
- No external libraries or assets.

## How do I use it?

Add the `ease-floating-action` class to an anchor or interactive element:

```html
<a class="ease-floating-action" href="#create">
  <span class="ease-floating-action__icon" aria-hidden="true">+</span>
  <span class="ease-floating-action__label">Add item</span>
</a>
```
