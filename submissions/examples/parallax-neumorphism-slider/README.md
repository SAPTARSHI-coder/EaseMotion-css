# Parallax Neumorphism Slider

A responsive CSS-only Parallax Slider designed with a soft Neumorphism-inspired interface.

## ✨ Features

- Pure HTML and CSS
- No JavaScript
- Responsive design
- Neumorphic outer interface
- Smooth slide transitions
- CSS-only navigation
- Layered parallax-style decorative elements
- Interactive navigation indicators
- Mobile-friendly layout
- Reduced-motion support
