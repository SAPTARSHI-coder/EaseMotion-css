# Morphing Shape Navigation

## Overview

Issue #73320 demonstrates navigation links that morph between geometric and organic silhouettes during interaction.

## Features

- Pure HTML and vanilla CSS
- Animated border-radius changes
- Responsive navigation
- Native keyboard focus
- Hardware-friendly transforms
- Reduced-motion support

## Files

- `demo.html` — navigation and content
- `style.css` — morphing interaction and layout
- `README.md` — documentation
