# Dial Indicator Probe

## What does this do?
Renders a self-contained CSS-only `ease-dial-indicator-probe` demo: Machinist dial indicator needle twitching on contact.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-dial-indicator-probe`. No build step or JavaScript is required for the effect.

```html
<section class="ease-dial-indicator-probe">
  <div class="ease-dial-indicator-probe__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
