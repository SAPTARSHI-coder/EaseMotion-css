# Glassmorphism Blur Toggle (#73870)

A pure HTML & Vanilla CSS toggle featuring frosted glass backdrop filtering and smooth sliding transitions.

## Features
- **Aesthetic:** Translucent glassmorphism effect using `backdrop-filter: blur(8px)`.
- **Pure CSS:** Zero JavaScript dependencies; relies strictly on CSS state selectors.
- **Performance:** Hardware-accelerated transitions using `transform` and `backdrop-filter`.
- **Accessibility:** Keyboard focus navigation support and `@media (prefers-reduced-motion: reduce)` media query integration.
