# CSS Glitch-Flicker Stepper for Product Catalog Layouts

A futuristic **Glitch-Flicker Stepper** component built using pure HTML5 and CSS3 for product catalog showcase layouts. This component combines glitch text effects, animated step indicators, dark UI styling, and smooth transitions to create an engaging product discovery experience.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Glitch-flicker heading animation
* Multi-step product catalog flow
* Animated step indicators
* Cyberpunk-inspired visual style
* Smooth entrance animations
* Gradient step circles
* Interactive hover movement
* Responsive desktop, tablet, and mobile layouts
* CSS Custom Properties for easy customization
* Smooth keyframe animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Explore the animated product catalog stepper.
3. Customize colors, spacing, shadows, and animations using CSS variables inside `:root`.

## CSS Custom Properties

```css
:root{
  --bg:#080b18;
  --surface:rgba(255,255,255,.08);
  --primary:#00e5ff;
  --secondary:#8b5cf6;
  --danger:#ff0055;
  --text:#f8fafc;
  --muted:#94a3b8;
  --shadow:0 25px 60px rgba(0,229,255,.18);
  --radius:24px;
}
```
