# Icon Button Set Component

Add ease-icon-button-set-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|---------|
| `--ibs-accent` | `#6366f1` |
| `--ibs-red` | `#ef4444` |
| `--ibs-green` | `#10b981` |
| `--ibs-radius` | `10px` |

## Note

Hover transforms each button independently with color and lift effects.
