# CSS Fire Text Effect

A lightweight animated fire text effect created entirely with HTML and CSS.

## ✨ Features

- Pure CSS animation
- No JavaScript
- Multiple animated glow layers
- Fire-like flickering effect
- Responsive typography
- Hover-to-pause interaction
- Keyboard focus support
- Reduced-motion accessibility support
- No external dependencies
