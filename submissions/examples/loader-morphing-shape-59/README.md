# Morphing Shape Loader

A smooth, accessible, and performant pure CSS loader featuring a morphing shape style, utilizing complex border-radius animations.

## Usage

```html
<div class="ease-loader-morphing-shape-59" aria-label="Loading" role="status"></div>
```

## Why is it useful?

It provides an organic, visually appealing loading indicator that is hardware-accelerated and fully dark mode compatible without relying on any external JavaScript or SVGs, fitting perfectly into the lightweight philosophy of EaseMotion CSS.
