# Magnet Snap Pull Gravity SCSS Animation

A reusable SCSS animation mixin that creates a magnetic snap and gravity-inspired motion.

## Features

- Magnetic pull effect
- Snap-back motion
- Configurable duration
- Configurable timing function
- Uses transform and opacity
- Supports prefers-reduced-motion

## Usage

Import the mixin:

```scss
@use "magnet-snap-pull-gravity";
