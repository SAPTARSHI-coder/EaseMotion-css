# CSS Micro-interaction: Neumorphic Soft Shadow

## Overview

A tactile neumorphic button using opposing light and dark shadows to communicate raised, hover, and pressed states.

## Features

- Raised neumorphic surface
- Hover elevation
- Pressed inset state
- Native button semantics
- Strong keyboard focus ring
- Responsive layout
- Reduced-motion support
- Pure HTML and Vanilla CSS

## Files

- `demo.html` — semantic control and notes
- `style.css` — shadow states and responsive styling
- `README.md` — documentation

## Accessibility

The control is a native button. Focus is indicated with an explicit outline so keyboard users do not depend on shadow changes alone. Reduced-motion preferences minimize transitions.
