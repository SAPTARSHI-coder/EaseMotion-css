# CSS Zoom-In Card Grid for SaaS Showcase Layouts

## Overview

A modern SaaS showcase card grid built with pure HTML and CSS.
The component uses smooth zoom-in animations, responsive CSS Grid layout,
and accessibility-friendly motion handling.

## Features

- 🚀 SaaS product showcase cards
- 🔍 Smooth CSS zoom-in hover effect
- 🎨 Gradient UI styling
- 📱 Fully responsive layout
- ⚡ Lightweight pure CSS animations
- ♿ prefers-reduced-motion support
- 🧩 CSS Grid based architecture

## Usage

1. Open `demo.html` in your browser.
2. Hover over cards to view zoom animations.
3. Customize CSS variables for colors and styling.
