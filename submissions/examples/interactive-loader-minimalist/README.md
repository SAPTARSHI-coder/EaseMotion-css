
---

## 🚀 Usage
1. Clone or copy the files into your project.
2. Open `demo.html` in your browser.
3. The loader will spin continuously, with a color change on hover.

---

## 🛠️ Customization
- **Loader size** → Adjust `width` and `height` in `.loader`.
- **Colors** → Change `border-top-color` for default and hover states.
- **Speed** → Modify `animation: spin 1s linear infinite` for faster/slower rotation.

---

## 📖 Accessibility
- Uses `role="status"` and `aria-label="Loading content"` for screen readers.
- Hover interaction provides visual feedback.
