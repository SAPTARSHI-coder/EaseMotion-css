This contribution adds a Long Shadow Text Effect to the submissions/examples/_long-shadow-text-effect directory.

Included File:
1. demo.html
2. style.css
3. README.md

Features
🌑 Long diagonal shadow
🎨 Multiple layered text-shadow values
💥 Bold 3D-style appearance
⚡ Pure HTML + CSS
🚫 No JavaScript
📱 Responsive font sizing with clamp()
🔧 Easy to control shadow length and direction
Great for hero headings, posters, logos, landing pages, and creative portfolios.
