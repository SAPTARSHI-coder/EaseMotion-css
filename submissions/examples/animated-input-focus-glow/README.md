# ease-input-focus-glow

Soft glowing ring animation on form input focus.

## Usage

```html
<input class="ease-input" type="text" placeholder="Type here">
```

## Notes

- Glow color is `rgba(59, 130, 246, 0.25)` — swap the RGB values to match your brand color.
- Works on `input`, `textarea`, and `select` elements alike.

## Browser support

All modern browsers.
