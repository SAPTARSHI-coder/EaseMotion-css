# CSS Integration Partner Badge

A responsive integration partner badge built entirely with HTML and CSS.

## Features

- Pure CSS implementation
- Partner logo treatment
- Verified partner indicator
- Animated connection status
- Hover shine animation
- Responsive design
- Keyboard-friendly semantic markup
- Reduced-motion support
- Forced-colors support
- No JavaScript required

## Usage

Include the HTML markup from `demo.html` and link `style.css`.

The component can be customized by changing the partner name,
logo letter, colors, and connection status.
