# Entropy Dial

Entropy Dial is an interactive system-stability visualization component
that represents the transition between order, uncertainty, and chaos.

Instead of displaying system health using conventional cards or charts,
the component uses a circular instrument combined with animated particles,
a dynamic gauge, and live telemetry.

## Features

- Interactive entropy slider
- Circular entropy gauge
- Stable / Uncertain / Critical states
- Dynamic system stability metric
- Dynamic noise metric
- Dynamic recovery-time metric
- Animated environmental particles
- Event stream
- Reset functionality
- Responsive layout
- Accessible range input
- Pure HTML, CSS, and vanilla JavaScript
- No external JavaScript dependencies
- No separate JavaScript file
