# Blur-Entrance Popover

A lightweight, pure CSS/HTML popover designed for minimalist tech interfaces.

## Features

- Smooth blur, fade, and scale entrance animation
- Pure HTML and CSS
- No JavaScript or external frameworks
- Responsive across desktop, tablet, and mobile
- Customizable CSS custom properties
- `prefers-reduced-motion` accessibility support
- Self-contained browser demo

## Usage

Add the popover structure to your HTML:

```html
<div class="popover-wrap">
  <button class="popover-trigger">
    System Details
  </button>

  <div class="popover-panel">
    Popover content
  </div>
</div>
