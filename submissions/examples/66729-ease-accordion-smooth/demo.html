Ease Accordion Smooth

A smooth, animated pure CSS accordion component leveraging CSS Grid height transitions (`grid-template-rows: 0fr → 1fr`), chevron rotation, and glassmorphic card containers — 100% JavaScript free.

🚀 How does pure CSS Grid height animation work? ›

Traditionally, animating `height: auto` in pure CSS was impossible without hardcoding fixed pixel heights or using JavaScript. By animating `grid-template-rows: 0fr` to `1fr`, CSS Grid allows smooth, dynamic height transitions regardless of content length.
