# Ease Glass Blower Punty

A CSS-only animated glassblower punty component showing a rotating heated glass gather.

## Features

- Real-world glass blowing motion metaphor
- Pure HTML and CSS
- Rotating punty animation
- Glowing molten glass effect
- Themed industrial control panel
- Responsive design
- Reduced motion accessibility support
