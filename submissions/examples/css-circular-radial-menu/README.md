# CSS Circular Radial Menu

A responsive circular/radial navigation menu built entirely with HTML and CSS.

## Features

- Pure HTML and CSS
- No JavaScript or external dependencies
- Expands navigation items outward from a central control
- Smooth radial transform animation
- Staggered menu-item entrance
- Responsive desktop, tablet, and mobile layouts
- Native keyboard-accessible `<details>` / `<summary>` interaction
- Keyboard-focusable navigation links
- Semantic navigation with ARIA labels
- `prefers-reduced-motion` support
- CSS custom properties for easy customization
