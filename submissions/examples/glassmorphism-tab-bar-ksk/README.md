# Glassmorphism Tab Bar with Material Design Styling

> Issue: [#79863](https://github.com/SAPTARSHI-coder/EaseMotion-css/issues/79863) / [#85636](https://github.com/SAPTARSHI-coder/EaseMotion-css/issues/85636)

A modern, responsive tab bar combining Material Design 3 pill indicators with glassmorphism backdrop blurs.

---

## ✨ Features & Architectural Highlights

- **Pure CSS Tab State:** Uses native radio buttons (`:checked`) for zero-JS tab panel toggling.
- **Material You + Glass Optics:** Combines Material Design 3 rounded pills with `backdrop-filter: blur()`.
- **Accessible & Responsive:** Adapts to all viewports with full `prefers-reduced-motion` compliance.

---

## 🚀 Usage

1. Include `style.css` in your HTML `<head>`:
   ```html
   <link rel="stylesheet" href="style.css" />
   ```
2. Use the HTML structure provided in `demo.html`.
