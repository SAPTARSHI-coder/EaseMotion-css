# CSS Cyber Glitch Button

A futuristic button featuring a rapid, slicing glitch effect utilizing `clip-path` animations on overlapping pseudo-elements.

## Features
- Dynamic text slicing utilizing `clip-path: polygon()` inside complex `@keyframes`.
- RGB split effect achieved by offsetting `left` positions and utilizing intense red/blue `text-shadow`.
- Hover interaction that stabilizes the button into a solid neon state while suppressing the pseudo-element glitches.
