
# ✨ Magnetic Pull Tooltip
A modern **CSS-only Magnetic Pull Tooltip** component featuring smooth hover interactions, floating animations, glassmorphism, and responsive design. This component creates the illusion of a tooltip being gently attracted to the cursor using only HTML and CSS—no JavaScript required.

---

## 🌟 Features

- 🎯 Pure HTML & CSS (No JavaScript)
- 🧲 Magnetic pull hover effect
- ✨ Smooth floating animation
- 🌈 Animated glowing border
- 💎 Modern glassmorphism design
- 🌊 Ripple-style entrance animation
- 💡 Soft lighting and shine effects
- 📱 Fully responsive layout
- ♿ Keyboard accessible (`:focus-visible`)
- 🎨 Easy customization using CSS variables

## 🎨 Customization

The component uses CSS custom properties for easy customization.

```css
:root {
    --primary: #8b5cf6;
    --secondary: #2dd4bf;
    --bg: #10131a;
    --text: #f8fafc;
    --duration: 0.45s;
    --radius: 16px;
}
```

Modify these values to match your preferred design and color palette.
