# CSS DNA Strand Progress (#70967)

An innovative scientific progress indicator featuring a double helix DNA strand representation that fills with dual-tone glowing color gradients sequentially.

## Features
- Pure CSS staggered entrance loading animations and continuous twisting wave motion.
- Dual-tone glowing strand nodes and connecting base rungs.
- Fully accessible via semantic `role="progressbar"`, `aria-valuenow`, and screen reader labels.
- Built-in `prefers-reduced-motion` safety overrides.
