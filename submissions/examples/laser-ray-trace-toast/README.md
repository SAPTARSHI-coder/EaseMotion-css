# Laser Ray Trace Toast

A futuristic notification toast featuring animated laser-ray tracing
effects using pure HTML and Vanilla CSS.

## Features

- Animated laser ray traces
- Radial ray animation
- Moving laser sweep
- Soft neon glow
- Smooth entrance animation
- Subtle hover elevation
- Dark mode support
- Light mode support
- Responsive design
- Accessible notification semantics
- Keyboard focus support
- Reduced-motion support
- No JavaScript or external dependencies

## Preview

The component creates a futuristic toast notification surrounded by
animated laser rays. Multiple rays trace outward while a subtle laser
sweep moves across the notification surface.
