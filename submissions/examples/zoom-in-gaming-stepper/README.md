# 🎮 Zoom-In Gaming Stepper

A modern **Zoom-In Stepper** built with **pure HTML and CSS** for the **EaseMotion CSS** project. The component showcases a four-step gaming journey with smooth zoom-in hover effects, glowing connectors, glassmorphism cards, and a fully responsive layout.

---

## ✨ Features

- 🎮 Gaming-themed stepper component
- 🔍 Smooth zoom-in hover animation
- 🌈 Gradient connectors between steps
- 💎 Glassmorphism step cards
- ⭐ Active step highlighting
- 🎨 CSS Custom Properties for easy customization
- 📱 Fully responsive design
- ♿ Accessibility support with `prefers-reduced-motion`
- 🚫 Pure HTML & CSS (No JavaScript)

---

## 📂 Folder Structure

```text
zoom-in-gaming-stepper/
├── demo.html
├── style.css
└── README.md
```

---

## 🚀 Usage

1. Open `demo.html` in a modern web browser.
2. Keep `style.css` and `README.md` in the same folder.
3. Hover over any step card to see the zoom-in animation.
4. Customize colors, spacing, and typography using the CSS variables.

---
