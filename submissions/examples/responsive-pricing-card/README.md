# Responsive Pricing Card Demo

A modern, mobile-responsive pricing card component designed for **EaseMotion CSS**. Demonstrates entry animations, responsive grid switching, interactive pricing toggle, and subtle card hover states.

##  Features

- **Responsive Grid:** Uses CSS Grid with `repeat(auto-fit, minmax(...))` to adapt fluidly from mobile to desktop screens.
- **EaseMotion Utility Usage:**
  - `ease-fade-in`: Fades in section header seamlessly on load.
  - `ease-slide-up`: Entrance animations with staggered delays for cards.
  - `ease-hover-grow`: Interactive elevation and scale effect on hover.
- **Interactive Toggle:** Seamless JS toggle for switching between monthly and annual pricing rates.
- **Dark Glassmorphic UI:** Modern dark mode styling utilizing backdrop filters and custom CSS variables.
