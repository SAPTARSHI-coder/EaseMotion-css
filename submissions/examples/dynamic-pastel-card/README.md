# Dynamic Pastel Card

A responsive and interactive card component created with pure HTML and CSS for EaseMotion CSS.

## ✨ Features

- Soft pastel visual design
- Dynamic hover interactions
- Floating decorative elements
- Layered depth and shadows
- Smooth spring-style transitions
- Responsive across desktop, tablet, and mobile
- Pure HTML and CSS
- No JavaScript dependencies
- Keyboard-friendly action link
- `prefers-reduced-motion` support

## 🎨 Design

The component uses a soft pastel palette built around:

- Pink
- Lavender
- Baby blue
- Soft yellow
- Mint green

The card combines these colors with subtle gradients, glass-like surfaces, rounded corners, and layered shadows.
