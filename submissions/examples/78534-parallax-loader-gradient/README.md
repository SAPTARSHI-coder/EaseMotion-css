# Parallax Loader with Gradient Styling

A responsive CSS-only parallax loader featuring layered depth,
animated gradients, glowing effects, and smooth loading animations.

## Features

- Pure HTML and CSS
- No JavaScript
- Layered parallax effect
- Animated gradient surfaces
- Glowing loader effects
- Rotating orbit elements
- Animated loading indicator
- Responsive layout
- Mobile-friendly design
- Reduced-motion support
- Lightweight implementation

## Files

- `demo.html` — loader markup and component demonstration
- `style.css` — complete styling, animation, and responsive behavior

## Usage

<link rel="stylesheet" href="style.css">
