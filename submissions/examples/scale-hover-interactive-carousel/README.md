# CSS Scale-Hover Interactive Carousel for Accessible Web Layouts

A modern **Scale-Hover Interactive Carousel** component built using only **HTML5 and CSS3**. This showcase demonstrates smooth scaling interactions, responsive carousel cards, animated hover states, and accessibility support without JavaScript.

---

## ✨ Features

- 🔍 Smooth scale hover animation
- 🎴 Interactive carousel cards
- 🌈 Animated gradient glow border
- 💎 Glassmorphism UI design
- ⚡ Lightweight CSS transitions
- 🎯 CSS Custom Properties
- 📱 Fully responsive layout
- 🧩 Pure HTML5 & CSS3
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

## 🚀 Usage

1. Open `demo.html` in a modern browser.
2. Hover over cards to activate scale effects.
3. Customize colours and animations using CSS variables.
