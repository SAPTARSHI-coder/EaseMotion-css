Reading Progress Bookmark

Scroll down the article page. The blue ribbon bookmark on the right will slide down in sync with your scroll depth, visually mapping your progress using CSS Scroll-Driven animations.

1. The Power of Scroll-Driven Timelines

Until recently, tracking a user's reading position required registering listener callbacks to window scroll events. This classic approach introduced performance issues: handlers ran on the main thread, occasionally dropping frames, leading to visual lag.

Today, modern CSS specifications support native scroll() timelines. This feature allows us to tie the progress of a keyframe animation timeline directly to the scrollbar offsets of a container or the viewport root itself.

"Scroll-driven animations run smoothly on the browser compositor thread, independent of main thread scripting operations."

2. Crafting the Bookmark Component

Our bookmark indicator combines layout structures with geometric clipping. A clip-path polygon forms the typical ribbon cutout bottom edge cleanly without complex multi-element border hacks.

Positioned fixed on the screen, the ribbon shifts vertically down the page frame. We scale the translateY value relative to the root scroll viewport height, so the bookmark starts at the very top and lands exactly at the bottom when the reader reaches the footer bounds.

3. Modern Browser Features & Accessibility

CSS scroll timelines are supported across standard modern browsers. For browsers that do not support it, the bookmark safely falls back to a clean static accent block positioned at the top of the reading sheet.

Users with vestibular system preferences often flag high rates of moving page elements. To keep our article readable, we deploy strict overrides under prefers-reduced-motion media wrappers to anchor the bookmark ribbon statically, ensuring a clean and steady reader layout.

4. Summary of benefits

By eliminating scripts from position calculations:

  • CPU idle times are prolonged on mobile viewports.
  • Main-thread execution is reserved for interactive tasks.
  • Clean, modular, and maintainable CSS tokens shape the layout.

This allows writers and engineers to easily theme, customize, and style these visual indicators to match any brand design system dynamically.
