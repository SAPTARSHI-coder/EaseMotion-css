# Animated Feature Cards Submission

## 1. What does this do?
It provides a modern, responsive feature card component with smooth hover animations, gradient accents, and interactive elements, perfect for showcasing product features on landing pages and SaaS websites.

## 2. How is it used?
Wrap each feature in the `.feature-card` class and combine it with EaseMotion utilities like `ease-hover-lift` and staggered delays (`ease-delay-100`, `ease-delay-200`, etc.). Add icons, headings, descriptions, and optional links.

## 3. Why is it useful?
- Feature cards are essential for SaaS websites, landing pages, and product documentation.
- Demonstrates smooth hover animations with gradient top border reveal.
- Icon rotation and scale effects on hover for visual interest.
- Animated underline effect on links.
- Fully responsive grid layout.
- Includes `prefers-reduced-motion` support for accessibility.
- Maintainer can easily standardize this as `.ease-feature-[YOUR_INITIALS]` in the core library.
