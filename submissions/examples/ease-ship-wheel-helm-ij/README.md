# ease-ship-wheel-helm
A ship's helm with a six-spoke brass wheel that turns steadily, a compass rose with a swinging needle, and a course lamp that blinks at the header.
## Run
Open `demo.html` directly in a browser to watch the helm turn.
## Notes
- The wheel rotates a full turn every fourteen seconds.
- The compass needle sways while the brass hub pulses with a warm glow.
