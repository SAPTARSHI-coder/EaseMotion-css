# Glassmorphism Task Kanban Board

## 1. What does this do?
The Glassmorphism Task Kanban Board renders a responsive project management dashboard column layout with glass visual effects, status tags, badge counters, and interactive card hover elevations.

## 2. How is it used?
Link `style.css` in your project document and use the `.kanban-container` structure along with `.kanban-column` and `.kanban-card` elements for task management UI.

## 3. Why is it useful?
Provides an aesthetic modern interface for task tracking, SaaS dashboards, developer productivity tools, and project management applications.
