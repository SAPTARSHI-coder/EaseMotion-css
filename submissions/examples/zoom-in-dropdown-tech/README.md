# Zoom-In Dropdown for Minimalist Tech

A pure CSS dropdown menu featuring a sleek zoom-in and slide-down animation suitable for minimalist tech layouts.

## Usage

```html
<div class="ease-dropdown">
  <button class="ease-btn">Options</button>
  <ul class="ease-dropdown-menu">
    <li><a href="#">Account Settings</a></li>
    <li><a href="#">API Keys</a></li>
    <li><a href="#">Billing</a></li>
    <li><a href="#">Logout</a></li>
  </ul>
</div>
```

## Why is it useful?

This component provides a lightweight, visually appealing dropdown with smooth transitions that respects `prefers-reduced-motion` settings, perfectly aligning with EaseMotion's goal of performant, accessible UI patterns.
