# Interactive Heatmap Grid Showcase

A modern glassmorphic heatmap component featuring interactive hover tooltips, activity levels, responsive layout, and accessibility-focused styling.

## Features

- Glassmorphic UI design
- Interactive heatmap cells
- Tooltip information on hover
- Five activity intensity levels
- Responsive mobile layout
- Smooth hover elevation
- Live activity indicator
- Pure HTML and CSS
- No external dependencies
- Reduced-motion support
- Semantic HTML structure
