# CSS Ripple Wave Progress Bar

A modern animated progress bar featuring a ripple-wave effect, designed for creative portfolio websites using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Ripple wave animation
- Responsive design
- CSS Custom Properties
- Accessible with `prefers-reduced-motion`
- No JavaScript required

## Files

```
demo.html
style.css
README.md
```

## Usage

```html
<div class="progress-bar">
    <div class="progress-fill" style="--progress:85%;">
        <span>85%</span>
    </div>
</div>
```

## Custom Properties

```css
--bg
--track
--fill
--text
--radius
--duration
```
