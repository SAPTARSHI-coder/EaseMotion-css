# CSS Rotate-Fade Tooltip for SaaS Showcase Layouts

A modern **Rotate-Fade Tooltip** built using pure HTML and CSS. The tooltip smoothly rotates and fades into view with elegant glassmorphism styling, making it perfect for SaaS dashboards, admin panels, landing pages, and product showcases.

## ✨ Features

- Pure HTML5 & CSS3
- Rotate + fade tooltip animation
- Glassmorphism tooltip design
- Responsive layout
- Smooth hover transitions
- CSS Custom Properties
- `prefers-reduced-motion` support
- No JavaScript required
