# CSS Slide-Up Tabs for Gaming Hub Layouts

A modern **Gaming Hub Tabs** component featuring smooth **Slide-Up** content transitions built entirely with **HTML5 and CSS3**. This example demonstrates interactive CSS-only tab navigation with animated content panels, responsive layouts, and accessibility support—without requiring JavaScript.

---

## ✨ Features

- 🎮 Gaming Hub inspired interface
- 📑 CSS-only tab navigation
- ⬆️ Smooth Slide-Up animation
- 🎨 Modern gradient active tabs
- ⚡ Pure HTML5 & CSS3 (No JavaScript)
- 📱 Fully responsive across desktop, tablet, and mobile
- 🎯 CSS Custom Properties for easy customization
- ♿ Accessibility support with `prefers-reduced-motion`
- 🚀 Lightweight and performance-friendly

## 🚀 Getting Started

1. Open `demo.html` in any modern web browser.
2. Select different tabs to switch between Gaming Hub sections.
3. Watch the content smoothly slide into view.
4. Customize colors, spacing, and animation timing through the CSS variables.

## 🎨 CSS Custom Properties

```css
:root{
    --bg:#0f172a;
    --panel:#1e293b;
    --primary:#38bdf8;
    --secondary:#8b5cf6;
    --text:#ffffff;
    --muted:#cbd5e1;
    --radius:18px;
    --transition:.35s ease;
}
```
