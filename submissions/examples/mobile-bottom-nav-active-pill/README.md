# Mobile bottom nav pill

A mobile bottom navigation bar with a glowing pill that slides to the active item.

## How to view

Open `demo.html` in any modern browser. The demo is fully self-contained — no CDN, no framework, no JavaScript.

## How to use

Copy `style.css` into your project's stylesheet. Every class used in the demo is namespaced with `mobilebottomnavactivepill-` to avoid collisions.

## Why this is useful for EaseMotion CSS

App shell pattern; the pill gives a strong active affordance.
