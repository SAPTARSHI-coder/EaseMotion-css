# CSS Animated Cloud Upload

A pure CSS cloud upload component featuring an animated upload arrow and progress indicator.

## Features

- Pure HTML and CSS
- No JavaScript required
- Animated cloud glow
- Animated upload arrow
- Progress indicator
- Responsive layout
- CSS custom properties
- Accessible progress semantics
- `prefers-reduced-motion` support
