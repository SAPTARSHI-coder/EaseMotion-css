# Flip Coin Card

A 3D card that flips over on hover to reveal a playful coin face on the back.

## Features
- True 3D flip with preserve-3d
- Front shows a gleaming coin edge
- Back spells a pun in gold

## Usage
```html
<div class="fc-card">
  <div class="fc-face fc-front">&#169;&#189;</div>
  <div class="fc-face fc-back">tails</div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
