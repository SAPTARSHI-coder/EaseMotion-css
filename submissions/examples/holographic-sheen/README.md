# Holographic Sheen Animation

## Overview

This submission demonstrates a reusable **Holographic Sheen** hover animation created with pure CSS. A shimmering light sweeps across the card to create a holographic visual effect.

## Features

- Pure CSS implementation
- Animated holographic light sweep
- CSS keyframes
- Configurable timing using CSS variables
- Accessible `prefers-reduced-motion` support
- Responsive demo

## Customization

```css
--ease-duration: 900ms;
--ease-timing: ease-in-out;
```

## Demo

Open `demo.html` directly in any modern browser.
