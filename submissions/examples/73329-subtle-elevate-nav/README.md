# Subtle Elevate Navigation

A clean and responsive navigation component inspired by **Subtle Elevate** styling, implemented using pure HTML and Vanilla CSS.

## ✨ Features

- Soft elevation on hover
- Restrained shadows and borders
- Clear active navigation state
- Smooth transitions
- Responsive CSS-only mobile menu
- Dark-mode compatible
- Keyboard-friendly navigation
- Visible focus states
- Reduced-motion support
- No JavaScript
- No external dependencies
