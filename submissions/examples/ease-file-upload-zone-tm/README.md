# File Upload Zone Component

Add ease-file-upload-zone-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|---------|
| `--fuz-accent` | `#6366f1` |
| `--fuz-radius` | `12px` |
| `--fuz-shadow` | `0 4px 20px rgba(0,0,0,.3)` |

## Note

CSS handles drag-over visual state. Tiny JS handles file selection events.
