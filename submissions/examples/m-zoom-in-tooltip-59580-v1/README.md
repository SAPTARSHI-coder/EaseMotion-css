# CSS Zoom-In Tooltip for SaaS Showcase Layouts

A modern **Zoom-In Tooltip** component built using pure HTML and CSS. The tooltip smoothly scales into view with a glassmorphism design, making it ideal for SaaS dashboards, admin panels, landing pages, and product showcases.

## ✨ Features

- Pure HTML5 & CSS3
- Zoom-in tooltip animation
- Glassmorphism styling
- Responsive layout
- Smooth hover transitions
- CSS Custom Properties
- `prefers-reduced-motion` support
- No JavaScript required
