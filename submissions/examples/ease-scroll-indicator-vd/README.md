# Ease Scroll Indicator

## What does this do?

A visual horizontal indicator for showing a user's scroll or reading progress.

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<div class="scroll-indicator">
    <span class="scroll-progress"></span>
</div>
```

To change the progress value, update the width:

```css
.scroll-progress {
    width: 65%;
}
```

### Features

- Progress indicator
- Animated movement
- Horizontal layout
- Responsive width
- Hover interaction
- Pure CSS
- No JavaScript required

## Why is it useful?

Scroll indicators are useful for articles, documentation, tutorials, and long-form content where users need visual feedback about their reading or scroll progress.

This component provides a simple and reusable progress pattern with a smooth entrance animation while following the animation-first philosophy of EaseMotion CSS.
