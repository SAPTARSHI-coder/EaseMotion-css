# CSS Fade-In Hero Section for Gaming Hub Layouts

A modern **Fade-In Hero Section** component built using pure HTML5 and CSS3 for gaming hub layouts. This component creates an immersive gaming landing experience with smooth fade animations, neon-inspired visuals, glassmorphism styling, and responsive behavior.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Gaming-themed hero showcase layout
* Smooth fade-in entrance animation
* Neon gradient glow effects
* Glassmorphism gaming card
* Animated floating game avatar
* Interactive CTA buttons
* Hover elevation effects
* Player and game statistics section
* Responsive desktop, tablet, and mobile layouts
* CSS Custom Properties for easy customization
* Lightweight keyframe animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. View the fade-in animation effect on page load.
3. Hover over the gaming card and buttons for interactive effects.
4. Customize colors, shadows, spacing, and animations using CSS variables inside `:root`.

## CSS Custom Properties

```css
:root{
  --bg:#050816;
  --surface:rgba(255,255,255,.08);
  --primary:#8b5cf6;
  --secondary:#06b6d4;
  --accent:#ec4899;
  --text:#f8fafc;
  --muted:#94a3b8;
  --shadow:0 30px 80px rgba(139,92,246,.35);
  --radius:32px;
}
```
