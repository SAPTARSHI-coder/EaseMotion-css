# Interactive Skill Badge Matrix

A responsive **Skill Badge Matrix** built with pure HTML5 and CSS3.

## Features

- Pure HTML5 & CSS3
- CSS `conic-gradient()` progress rings
- Glassmorphism cards
- Hover glow and shimmer animation
- Category filter pills
- Responsive grid layout
- CSS Custom Properties
- `prefers-reduced-motion` support
