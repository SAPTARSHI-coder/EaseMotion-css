# CSS Elastic-Slide Modal for Product Catalog Layouts

A modern **HTML5 & CSS3** product catalog showcasing an **Elastic-Slide Modal** animation. Clicking **Quick View** opens a responsive modal with a smooth elastic slide effect, detailed product information, and action buttons—all without JavaScript.

---

## ✨ Features

- Pure HTML5 & CSS3
- Elastic slide modal animation
- Responsive product catalog
- Modern gradient interface
- CSS Custom Properties
- No JavaScript required
- Accessible with `prefers-reduced-motion`
- Lightweight and reusable
