# CSS Volumetric Light Rays

A stunning cinematic text effect featuring rotating "God Rays" shining from behind a solid foreground element. 

## Features

- **Pure CSS**: Completely achieved using CSS gradients and blend modes.
- **Conic Gradients**: Utilizes `repeating-conic-gradient` to create the distinct beams of light.
- **Mix Blend Mode**: Uses `mix-blend-mode: screen` so the rays interact with the background naturally.
- **CSS Masking**: A `radial-gradient` mask is applied to the rays to fade them out perfectly at the edges and center.
