# CSS Shimmer-Sweep Modal for E-Commerce Checkout Layouts

A modern **Shimmer-Sweep Modal** built using pure HTML and CSS. The component features an elegant shimmer-sweep animation, premium glassmorphism styling, responsive layouts, and smooth interactions for e-commerce checkout confirmation dialogs.

## ✨ Features

- Pure HTML5 & CSS3
- Shimmer-sweep animation
- Glassmorphism modal
- Responsive layout
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
