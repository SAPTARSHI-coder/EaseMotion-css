Touch Sticky Hover Fix

Resolving the frustrating mobile UI bug where CSS :hover animations become permanently "stuck" active after a user taps an element on a touchscreen device.

The Sticky Hover (Buggy)

If you view this on a touchscreen device (or simulate one in DevTools) and tap the button below, it will remain permanently scaled and red, even after you move your finger away!

The Media Query Fix (Fixed)

By wrapping the hover state in an interaction media query, the hover animation only applies if the device actually has a fine-pointing device (like a mouse).

How to test this locally:

Open your browser's Developer Tools (F12) and toggle the "Device Toolbar" to simulate a mobile phone (e.g., iPhone 14). Tap the buttons to see the difference.
