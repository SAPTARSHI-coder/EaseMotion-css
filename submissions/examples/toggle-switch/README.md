# Animated Toggle Switch

A modern, pure-CSS animated toggle switch using a hidden checkbox hack. It features smooth background color transitions and an elastic bounce effect for the knob using a custom `cubic-bezier` timing function.

## Features
- Pure CSS, zero JavaScript required
- Accessible via hidden checkbox and ARIA labels
- Modern `cubic-bezier` knob animation
- Smooth transition states

## Usage

```html
<label class="toggle-switch">
  <input type="checkbox">
  <span class="toggle-slider"></span>
</label>
```

Include the `style.css` in your project to apply the animations.
