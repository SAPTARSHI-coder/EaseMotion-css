# Quota Admission Gate

An advanced CSS animation that visualizes multi-tenant quota admission control. Tenant request streams flow toward an admission gate, capacity rings pulse under pressure, overflow traffic is throttled, and recovery meters settle back into a fair operating band.

## Features

- Animated admission gate with quota pressure rings
- Tenant lanes, throttle lane, and recovery readouts
- Responsive single-page demo
- CSS-only motion with expanded generated timing samples for stress coverage

## Files

- `demo.html` - accessible demo markup
- `style.css` - animation, layout, and generated quota timing samples
