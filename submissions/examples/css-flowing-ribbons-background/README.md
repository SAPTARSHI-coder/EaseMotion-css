# CSS Flowing Ribbons Background

A pure CSS animated background featuring colorful flowing ribbons that slowly twist and move across the screen.

## Features

- Pure CSS implementation
- Smooth ribbon-flow animations
- Responsive full-screen layout
- Lightweight and reusable
- No JavaScript required

## Usage

Include the HTML structure and stylesheet:

```html
<div class="background">
  <span class="ribbon ribbon1"></span>
  <span class="ribbon ribbon2"></span>
  <span class="ribbon ribbon3"></span>
  <span class="ribbon ribbon4"></span>
</div>
