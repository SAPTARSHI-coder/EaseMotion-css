# Minimalist Outline Form

A clean, accessible, and responsive form component featuring a **Minimalist Outline** design using pure HTML and Vanilla CSS.

## ✨ Features

- Minimalist outline-based design
- Smooth hover and focus transitions
- Clean input, select, textarea, and checkbox controls
- Responsive layout
- Automatic dark mode support
- Keyboard-friendly interactions
- Visible focus states
- Reduced-motion support
- Hardware-friendly CSS transitions
- No JavaScript
- No external dependencies
