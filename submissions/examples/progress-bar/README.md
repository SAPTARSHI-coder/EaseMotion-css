# CSS Animated Progress Bar

A demo project showcasing an **animated progress bar** using HTML, CSS, and JavaScript.

## Features
- Smoothly animated progress fill.
- Gradient colors for a vibrant look.
- Buttons to start and reset progress.
- Responsive, centered layout with glowing container.

## Files
- `demo.html` → Structure and JavaScript logic for progress updates.
- `style.css` → Styling for the progress bar, gradient fill, and controls.
- `README.md` → Documentation and usage instructions.

## Usage
1. Open `demo.html` in your browser.
2. Click **Start** to animate the progress bar filling up.
3. Click **Reset** to reset progress to zero.
4. Customize gradient colors and animation speed for your own theme.

## Customization Ideas
- Add milestones or labels along the bar.
- Trigger progress updates based on API responses.
- Use CSS keyframes for looping animations.
- Integrate into dashboards, loaders, or game UIs.
