# CSS Dropdown: Metallic Sheen Variation #419

A pure CSS dropdown menu featuring a sleek metallic sheen effect and smooth hardware-accelerated transitions.

## Usage

```html
<div class="dropdown-container">
  <button class="dropdown-trigger ease-dropdown-sheen-419">Options <span class="caret"></span></button>
  <ul class="dropdown-menu ease-dropdown-menu-sheen-419">
    <li><a href="#">Settings</a></li>
    <li><a href="#">Profile</a></li>
    <li><a href="#">Logout</a></li>
  </ul>
</div>
```

## Why is it useful?
This component provides a premium, interactive metallic appearance suitable for modern and dark-mode-friendly interfaces without requiring any JavaScript. It uses hardware-accelerated 3D transforms (`rotateX`) and subtle gradient sheen animations, perfectly aligning with EaseMotion's philosophy of performant, CSS-only animations.
