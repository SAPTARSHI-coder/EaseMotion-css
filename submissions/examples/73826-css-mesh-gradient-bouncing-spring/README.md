# CSS Mesh Gradient: Bouncing Spring

## Overview

A playful mesh-gradient variation using spring-like overshoot and rebound to make the color fields feel tactile.

## Features

- Elastic gradient movement
- Independent color layers
- Soft blurred depth
- Responsive layout
- Keyboard-visible focus state
- Reduced-motion support
- Pure HTML and Vanilla CSS

## Files

- `demo.html` — semantic example
- `style.css` — gradient layers and spring animation
- `README.md` — documentation

## Accessibility

Decorative shapes are hidden from assistive technology. The navigation link remains keyboard accessible. `prefers-reduced-motion` disables the animation.
