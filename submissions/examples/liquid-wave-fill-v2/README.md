# Liquid Wave Fill Progress

A smooth and modern **Liquid Wave Fill** progress bar built using only
HTML and vanilla CSS.

This component is designed for the EaseMotion CSS library and focuses on
fluid motion, accessibility, responsive behavior, and lightweight
implementation.

## ✨ Features

- Pure HTML and CSS
- No JavaScript
- Animated liquid-wave effect
- Smooth progress transitions
- Multiple progress values
- Responsive design
- Dark mode support
- Light mode support
- Hardware-accelerated transforms
- Accessible progressbar semantics
- `prefers-reduced-motion` support
- No external dependencies
