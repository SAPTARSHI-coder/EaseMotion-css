# Expand on Hover Card

## What it does

This submission creates a CSS-only card effect where the card slightly lifts and scales on hover while revealing extra supporting content. It helps keep the default layout clean while still allowing more detail to appear interactively.

## How to use it

Apply the card class to a container and place the revealed section inside:

```html
<div class="expand-card">
  <h3>Project Card</h3>
  <p class="extra-info">More details appear on hover.</p>
</div>
```

## Why it fits EaseMotion CSS

It fits EaseMotion CSS because it is human-readable, animation-first, and composable. The effect is easy to reuse across portfolio cards, product cards, article previews, and compact dashboard tiles.

## Included features

- Smooth scale-and-lift hover motion
- Hidden supporting content reveal
- Two visual card variations in the demo
- Responsive grid layout
- Pure HTML and CSS implementation
