# CSS Morphing Menu Button

A pure CSS morphing menu button created for the EaseMotion CSS library.

The component demonstrates smooth transitions between three visual states:

- Hamburger / Menu
- Close / X
- Back Arrow

No JavaScript or external libraries are required.

## ✨ Features

- Pure HTML and Vanilla CSS
- Three morphing states
- Smooth CSS transitions
- Hardware-accelerated transforms
- Responsive design
- Dark mode support
- Reduced-motion support
- Keyboard-accessible state controls
- No external dependencies
- Uses semantic HTML
- Lightweight implementation
