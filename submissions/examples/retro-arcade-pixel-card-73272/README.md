# Retro Arcade Pixel Card

A pure CSS card featuring a retro arcade 8-bit style with pixelated borders, a scanline image effect, and a CSS-drawn pixel avatar. 

### Usage

```html
<div class="ease-retro-card-ag">
    <!-- Card content here -->
</div>
```

### Why is this useful?
It brings nostalgic arcade aesthetics into modern web design, using pure CSS for pixel art, scanlines, and hover states, perfect for gaming or retro-themed sections in EaseMotion CSS.
