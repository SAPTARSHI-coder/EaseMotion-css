# CSS Accordion: Gradient Shimmer Variation

A modern accordion component featuring an animated gradient shimmer effect, smooth reveal transitions, and responsive accessibility-friendly design built entirely with HTML and CSS.

## Features

- Pure HTML & CSS
- Animated gradient shimmer effect
- Smooth accordion expansion
- Native accessible details/summary structure
- Responsive design
- Dark mode compatible
- Hardware accelerated animations

## Files

- demo.html
- style.css

## Usage

```html
<details class="accordion">
    <summary>Accordion Title</summary>
    <div class="content">
        Accordion content goes here.
    </div>
</details>
```

## Why it fits EaseMotion CSS

This component adds an elegant shimmer-based visual style to the EaseMotion CSS accordion collection while maintaining accessibility, responsiveness, performance, and a pure CSS implementation.
