# Segmented slider control

A 3-option segmented control whose active block slides between the three options on click.

## How to view

Open `demo.html` in any modern browser. The demo is fully self-contained — no CDN, no framework, no JavaScript.

## How to use

Copy `style.css` into your project's stylesheet. Every class used in the demo is namespaced with `segmentedslidercontrol-` to avoid collisions.

## Why this is useful for EaseMotion CSS

Compact selector pattern; the sliding block gives strong visual continuity.
