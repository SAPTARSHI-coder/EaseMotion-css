# Pulsating Wave Card

A responsive pure CSS card component featuring a **Pulsating Wave** visual treatment with layered expanding rings and soft ambient illumination.

## ✨ Features

- Pulsating concentric wave animation
- Animated glowing center
- Multiple visual variations
- Smooth hover elevation
- Responsive card grid
- Dark-mode compatible
- Light-mode compatible
- Keyboard-accessible links
- Visible focus states
- Reduced-motion support
- Hardware-friendly CSS transforms
- No JavaScript
- No external dependencies
