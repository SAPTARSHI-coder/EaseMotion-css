# Interactive Tab Bar — Material Design

A responsive interactive tab bar inspired by Material Design,
implemented using pure HTML and CSS.

Implemented for EaseMotion CSS issue #79731.

## Features

- Material Design inspired interface
- CSS-only tab switching
- No JavaScript
- Responsive layout
- Active tab indicator
- Hover states
- Focus-visible accessibility state
- Ripple-like click interaction
- Smooth content transitions
- Mobile-friendly tab layout
- Reduced-motion support
- No external dependencies
