# Hover-fill star rating

A 5-star rating row that fills each star from left to right as the cursor crosses the row.

## How to view

Open `demo.html` in any modern browser. The demo is fully self-contained — no CDN, no framework, no JavaScript.

## How to use

Copy `style.css` into your project's stylesheet. Every class used in the demo is namespaced with `starratinghoverfillv2-` to avoid collisions.

## Why this is useful for EaseMotion CSS

Common review input; hover-preview lets the user confirm the rating before clicking.
