# Rotate Lift Card Hover Utility

A lightweight CSS utility that gently lifts and rotates a card on hover, creating a modern and engaging interaction suitable for portfolios, dashboards, pricing cards, feature sections, and product showcases.

The animation combines a subtle upward movement with a slight rotation and enhanced shadow, giving UI cards a polished and interactive feel without relying on JavaScript.

---

## Features

- Smooth rotate and lift hover animation
- Soft shadow enhancement on hover
- Pure HTML and CSS implementation
- No JavaScript required
- Lightweight and reusable utility
- Modern card design
- Responsive layout
- Accessible with `prefers-reduced-motion` support
- Easy to customize for different projects

## Usage

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

Add the utility class to your card:

```html
<div class="rotate-lift-card-hover-utility-ag">
    <h3>Hover Me</h3>
    <p>Interactive card animation.</p>
</div>
```

## Customization

You can easily customize the utility by modifying:

- Border radius
- Padding
- Font sizes

## Animation

The hover interaction combines several subtle effects:

- Card lifts upward smoothly
- Slight rotation adds depth
- Shadow becomes larger and softer
- Smooth transition creates a polished micro-interaction

The result is a lightweight animation suitable for modern interfaces.

---

## Accessibility

This utility respects user accessibility preferences.

Supported feature:

- `prefers-reduced-motion`

Users who prefer reduced motion will automatically receive a static version without animations.
