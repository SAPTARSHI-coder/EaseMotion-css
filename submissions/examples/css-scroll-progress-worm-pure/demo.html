Scroll Progress Worm

Scroll down the page to watch the worm crawl along the path. Powered entirely by the modern CSS animation-timeline: scroll() feature. No JavaScript required.

Phase 1: Discovery

Scroll down to advance the progress worm. The stroke-dashoffset is mathematically linked to the scroll position of the root document.

Phase 2: Planning

Because it's tied to the scroll timeline, if you scroll back up, the worm crawls backward seamlessly. This provides a highly physical, interactive feel.

Phase 3: Development

We use a large `stroke-dasharray` gap so that the stroke appears as a short segment (a worm) rather than a continuously growing line.

Phase 4: Testing

This technique works with any SVG path, allowing for complex curves, loops, and custom progress indicators that break out of standard straight-line designs.
