# Astrolabe Rete Rotate

## What does this do?
Renders a self-contained CSS-only `ease-astrolabe-rete-rotate` demo: Medieval astrolabe rete plate rotating over the tympan.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-astrolabe-rete-rotate`. No build step or JavaScript is required for the effect.

```html
<section class="ease-astrolabe-rete-rotate">
  <div class="ease-astrolabe-rete-rotate__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
