# glow-accordion-v8-ak

Pure CSS animated glowing neon border accordion drawer component — no JavaScript required.

## How to use

```html
<div class="ease-accordion-v8">
  <input type="checkbox" id="item1" class="ease-accordion-checkbox-v8" />
  <div class="ease-accordion-item-v8">
    <label for="item1" class="ease-accordion-header-v8">
      <span>Header</span>
      <span class="ease-accordion-icon-v8">▼</span>
    </label>
    <div class="ease-accordion-drawer-v8">
      <div class="ease-accordion-body-v8">Content</div>
    </div>
  </div>
</div>
