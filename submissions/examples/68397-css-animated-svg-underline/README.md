# CSS Animated SVG Underline

A heading treatment where an SVG path draws beneath the text on hover and focus.

## Features

- SVG path underline
- CSS-driven draw animation
- Hover and keyboard focus states
- Responsive typography
- Reduced-motion support
- No JavaScript

## Files

- `demo.html` — heading and inline SVG structure
- `style.css` — path animation and component styling

## Accessibility

The heading remains normal text and the interactive demo is keyboard focusable with a visible focus state. Reduced motion disables the draw transition.
