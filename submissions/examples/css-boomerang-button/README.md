# CSS Boomerang Button


A creative animated button where the text flies away and returns like a boomerang on hover.


## Features

- Pure CSS animation
- Text flying effect
- Smooth boomerang return motion
- Gradient hover shine
- Responsive design
- Keyboard accessible


## Technologies

- HTML5
- CSS3


## Animation Used

- CSS Keyframes
- Transform transitions
- Pseudo-elements


## Accessibility

- Native button element
- Focus-visible state
- Keyboard friendly
