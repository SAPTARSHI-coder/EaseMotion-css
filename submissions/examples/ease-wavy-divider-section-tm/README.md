# Wavy Divider Section Component

Add ease-wavy-divider-section-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|--------|
| `--wds-s1` | `#1e293b` |
| `--wds-s2` | `#334155` |
| `--wds-s3` | `#6366f1` |

## Technique

Inline SVG paths with `preserveAspectRatio="none"` create smooth curved transitions between colored sections.
