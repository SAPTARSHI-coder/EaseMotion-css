# Sparkler · Sparkler Writes in Light ✨

An interactive sparkler that writes in light with glowing trails, sparks, and magical effects. Draw with a virtual sparkler!

## Features

- ✨ **Sparkler Writing** – Write with glowing light
- 🖊️ **Freehand Drawing** – Drag to draw
- 🎚️ **Length Control** – Adjust trail length (20-200)
- 🎚️ **Sparks Control** – Adjust spark count (5-30)
- ⏸️ **Pause/Resume** – Toggle animation
- 🗑️ **Clear** – Clear drawing
- 🔄 **Reset** – Reset everything
- ✨ **Spark Effects** – Glowing sparks and trails

## How to Use

1. **Drag** on the canvas to write with the sparkler
2. Watch sparks fly from the tip
3. Adjust **Length** for trail duration
4. Adjust **Sparks** for spark density
5. Click **CLEAR** or press **C** to clear
6. Press **RESET** or **R** to reset
7. Press **PAUSE** or **P** to pause/resume animation

## Controls

| Action | Method |

## Technical Details

- **Drawing:** Freehand with trail points
- **Sparks:** Particle system with physics
- **Trail:** Fading glow effect
- **Performance:** 60fps with requestAnimationFrame

## Customization

You can easily customize:
- **Length:** Adjust slider range (20-200)
- **Sparks:** Adjust slider range (5-30)
- **Colors:** Modify spark colors
- **Trail:** Adjust fade speed
- **Physics:** Modify gravity and speed

## Browser Support

Works in all modern browsers:
- Chrome, Firefox, Safari, Edge
- Touch support for mobile devices

## Run Locally

Simply open `index.html` in your browser – no server required!
