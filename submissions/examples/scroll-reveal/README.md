# Scroll Reveal Animation Utilities

A collection of reusable CSS utilities for revealing elements as they
enter the viewport.

## Features

- Pure CSS implementation
- No JavaScript required
- Six reveal animation variants
- Responsive
- Customizable using CSS custom properties
- Supports reduced-motion preferences
- Easy to add to existing projects

### Fade
