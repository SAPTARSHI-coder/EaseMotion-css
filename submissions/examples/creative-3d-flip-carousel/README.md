# CSS 3D-Flip Carousel for Accessible Web Layouts

A modern **3D-Flip Carousel** component built completely with **HTML5 and CSS3**. This showcase demonstrates interactive 3D card flipping, smooth transitions, responsive layouts, and accessibility support without JavaScript.

---

## ✨ Features

- 🔄 3D flip card animation
- 🎴 Interactive carousel cards
- 🌐 CSS perspective effects
- 💎 Glassmorphism design
- ⚡ Smooth CSS transitions
- 🎯 CSS Custom Properties
- 📱 Fully responsive layout
- 🧩 Pure HTML5 & CSS3
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

## 🚀 Usage

1. Open `demo.html` in a modern browser.
2. Hover over cards to trigger the 3D flip effect.
3. Customize colors and animations using CSS variables.
