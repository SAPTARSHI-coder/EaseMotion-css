# CSS Interactive Pricing Cards

Modern pricing cards that dynamically elevate, scale up, and emit a soft glow when hovered. The "recommended" PRO tier stands out naturally via default scaling and gradient backgrounds.

## Features
- Dynamic layout using Flexbox
- `transform: translateY() scale()` on hover for depth
- Custom-colored `box-shadow` glowing effects for each tier
- Distinctive PRO tier highlighting
