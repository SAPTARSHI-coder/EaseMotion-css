# CSS Bounce-Pulse Card Grid for Product Catalog Layouts

A modern **Bounce-Pulse Card Grid** built using pure HTML5 and CSS3 for product catalog layouts. The component features responsive product cards with engaging bounce-pulse hover animations, glassmorphism styling, and accessibility support.

## Features

* Pure HTML5 & CSS3
* Bounce-Pulse hover animation
* Responsive product card grid
* Glassmorphism product cards
* Product badges, images, descriptions, ratings, prices, and CTA buttons
* Smooth CSS transitions & keyframe animations
* Responsive desktop, tablet, and mobile layout
* CSS Custom Properties
* No JavaScript required
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over any product card to trigger the bounce-pulse animation.
3. Customize colors, typography, spacing, and animation timing through the CSS variables defined in `:root`.
4. Integrate the component into any product catalog or e-commerce website.
