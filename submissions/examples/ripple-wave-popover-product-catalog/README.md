# CSS Ripple-Wave Popover for Product Catalog Layouts

A modern **Ripple-Wave Popover** component built with pure HTML5 and CSS3 for the EaseMotion CSS project. The popover appears with a smooth ripple-wave animation on hover, providing an elegant way to display product information.

---

## ✨ Features

- Pure HTML5 & CSS3
- Smooth ripple-wave popover animation
- Modern glassmorphism popover
- Responsive product catalog layout
- CSS custom properties for easy customization
- Hover interactions with smooth transitions
- Accessible with `prefers-reduced-motion`
- No JavaScript required
