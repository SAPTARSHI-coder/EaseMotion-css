# Glass Harmonica Rim

## What does this do?
Renders a self-contained CSS-only `ease-glass-harmonica-rim` demo: Glass harmonica rim singing under wet fingers.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-glass-harmonica-rim`. No build step or JavaScript is required for the effect.

```html
<section class="ease-glass-harmonica-rim">
  <div class="ease-glass-harmonica-rim__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
