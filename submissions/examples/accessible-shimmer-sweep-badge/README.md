# CSS Shimmer-Sweep Badge for Accessible Web Layouts

A modern **Accessible Web Badge** component built entirely with **HTML5 and CSS3**. This showcase demonstrates elegant **Shimmer-Sweep** animations with glassmorphism styling, responsive layouts, and accessibility-friendly interactions without requiring JavaScript.

---

## ✨ Features

- ♿ Accessibility-focused badge design
- ✨ Shimmer-Sweep hover animation
- 🌈 Multiple badge variants
- 🪟 Glassmorphism styling
- ⚡ Pure HTML5 & CSS3
- 📱 Fully responsive
- 🎯 CSS Custom Properties
- 🚀 Lightweight implementation
- ♿ `prefers-reduced-motion` support
- No JavaScript required

## 🚀 Getting Started

1. Open `demo.html` in a modern browser.
2. Hover over any badge to view the Shimmer-Sweep animation.
3. Customize colors, spacing, and animation speed using CSS variables.
