# Glassmorphism Navbar Component

A floating navbar featuring frosted backdrop blur styling and animated link underline indicators.

## Features
- **Frosted Glass Header:** Sticky floating layout with CSS `backdrop-filter: blur()`.
- **Expanding Underline Indicator:** Smooth `width` expansion keyframe effect on hover and active state.
- **Zero JavaScript:** Pure CSS layout and interactive animations.

## File Structure
- `demo.html` - Navigation bar markup structure with logo, menu items, and CTA button.
- `style.css` - Backdrop filters, flex alignment, and pseudo-element underline transitions.
