# Zoom-In Modal

A lightweight, CSS-only Zoom-In Modal designed for E-Commerce Checkout Layouts.

## Features

- Pure HTML and CSS
- No JavaScript
- No external frameworks
- Smooth zoom-in modal animation
- CSS `:target` interaction
- Responsive checkout layout
- Responsive modal on mobile devices
- CSS custom properties for customization
- Accessible form labels and controls
- `prefers-reduced-motion` support
- Backdrop blur effect
- Keyboard-friendly links and form controls
