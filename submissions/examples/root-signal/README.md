# 🌱 Root Signal

Root Signal is an interactive growing garden component built around gradual organic motion.

Every interaction plants a new glowing stem that grows upward before settling into a continuous sway.

## ✨ Features

- Click-to-plant interaction
- Animated plant growth
- Organic swaying motion
- Randomized plant height
- Randomized plant hue
- Glowing leaves
- Ground texture
- Moonlight atmosphere
- Real-time plant counter
- Reset functionality
- Keyboard controls
- Responsive design
- No external dependencies

## 🎮 Interaction

| Input | Action |
| --- | --- |
| Click ground | Plant |
| Space | Plant |
| R | Clear garden |
| Plant | Add random plant |
| Clear | Remove all plants |

## 🌱 Growth System

Each plant receives:

- Position
- Height
- Color hue

The plant begins at zero scale and grows vertically using a smooth CSS animation.

After growing, it continuously sways around its bottom anchor point.

## 🎨 Visual Design

The component uses a dark forest environment with:

- Moonlight
- Glowing plants
- Textured soil
- Subtle green gradients
- Organic movement

The goal is to make the garden feel alive even when the user stops interacting.

## 💡 Customization

Developers can customize:

- Plant height
- Plant colors
- Growth duration
- Sway amount
- Ground texture
- Moon size
- Number of generated plants

## 🎯 Why It Fits EaseMotion CSS

Root Signal demonstrates gradual, organic motion.

The component does not instantly reveal the result of an interaction. Instead, the visual object grows from nothing into a complete plant.

This provides:

- Smooth transitions
- Organic motion
- Interaction feedback
- Layered animation
- Continuous ambient movement
