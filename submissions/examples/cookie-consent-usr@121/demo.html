About This Component

This cookie consent banner demonstrates smooth slide-in animations, expandable preference sections, toggle switches, and persistent user preferences using localStorage.

Features

  • ✅ Multiple banner positions (bottom, top, center modal)
  • ✅ Smooth slide-in/slide-out animations
  • ✅ Expandable cookie preferences
  • ✅ Individual cookie category toggles
  • ✅ Persistent user preferences (localStorage)
  • ✅ Accept all / Reject all / Customize options
  • ✅ Cookie policy link
  • ✅ Fully accessible with ARIA labels
  • ✅ Mobile-responsive design
  • ✅ Respects prefers-reduced-motion
