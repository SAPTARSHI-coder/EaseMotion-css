# Pulsating Wave Card

A smooth, accessible, and performant pure CSS card featuring a pulsating wave effect.

## What does this do?
Creates an animated card component with rotating waves that creates a pulsating effect, fully responsive and dark mode compatible.

## How is it used?
```html
<div class="pulsating-wave-card">
    <div class="card-content">
        <h2>Card Title</h2>
        <p>Card description goes here.</p>
    </div>
    <div class="wave"></div>
    <div class="wave wave2"></div>
    <div class="wave wave3"></div>
</div>
```

## Why is it useful?
It provides a visually appealing, modern card component without any JavaScript, fitting perfectly with EaseMotion's philosophy of pure, high-performance CSS animations.
