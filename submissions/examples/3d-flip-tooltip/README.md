# CSS 3D-Flip Tooltip

A lightweight HTML and CSS showcase demonstrating a **3D Flip Tooltip** for creative portfolio layouts. The tooltip flips into view with a smooth CSS transform while remaining responsive and accessible.

---

## Features

- Pure HTML5 & CSS3
- No JavaScript required
- Smooth 3D flip animation
- Fade-in effect
- Responsive CSS Grid layout
- Keyboard accessible
- Supports `prefers-reduced-motion`
- Easy customization with CSS variables

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over or tab to a portfolio card.
3. The tooltip flips into view with a 3D animation.

---

## CSS Custom Properties

| Variable | Description |
|----------|-------------|
| `--tooltip-bg` | Tooltip background color |
| `--tooltip-color` | Tooltip text color |
| `--flip-duration` | Animation duration |
| `--perspective` | 3D perspective depth |
| `--card-radius` | Card border radius |
| `--shadow` | Card shadow |

## Why it fits EaseMotion CSS

This example follows EaseMotion CSS principles by providing a lightweight, reusable animation built entirely with HTML and CSS. It is responsive, customizable through CSS variables, accessible, and requires no JavaScript.
