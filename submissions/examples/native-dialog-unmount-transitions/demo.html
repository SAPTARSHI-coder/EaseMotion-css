💡 How @starting-style & allow-discrete Revolutionize Unmount Animations

Historically, animating elements when removing them from the DOM or closing a <dialog> required setTimeout() hacks, state machines, or JavaScript animation libraries to delay hiding display: none.

With EaseMotion's native transition utilities, modern browsers interpolate top-layer elements and display discretely while matching @starting-style during mounting:

/* EaseMotion Native Dialog Unmount Utility Pattern */ dialog.ease-dialog-bounce { opacity: 1; transform: scale(1) translateY(0); /* Enables smooth unmount transitions when closing [open] state */ transition: display 0.4s allow-discrete, overlay 0.4s allow-discrete, opacity 0.4s cubic-bezier(0.34, 1.56, 0.64, 1), transform 0.4s cubic-bezier(0.34, 1.56, 0.64, 1); } /* Starting state BEFORE the element renders into DOM / top-layer */ @starting-style { dialog.ease-dialog-bounce[open] { opacity: 0; transform: scale(0.8) translateY(-30px); } }
