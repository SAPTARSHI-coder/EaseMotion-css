# CSS Float-Drift Feature Grid for Responsive Dashboard Layouts

A modern **Float-Drift Feature Grid** component built using only **HTML5 and CSS3**.

This example showcases floating feature cards with smooth drift animations, glowing backgrounds, responsive dashboard layouts, and accessibility support without JavaScript.

---

## ✨ Features

- 🌊 Floating drift animations
- 🎴 Interactive feature cards
- 💫 Animated glow effects
- 🎨 Gradient UI styling
- ⚡ Smooth CSS transitions
- 📱 Responsive dashboard layout
- 🎯 CSS Custom Properties
- ♿ `prefers-reduced-motion` support
- 🚫 Zero JavaScript dependency

---

## 🚀 Usage

1. Open `demo.html` in any modern browser.
2. Hover over feature cards to view floating interactions.
3. Customize colors and animations using CSS variables.
