# Glowing Neon Outline Input Field with Animated Floating Label (Glassmorphic Style)

A modern **Glassmorphic Neon Input Form** featuring animated floating labels, glowing focus effects, and translucent glass UI built entirely with HTML and CSS.

## ✨ Features

- Pure HTML5 & CSS3
- Glassmorphism design
- Animated floating labels
- Neon outline glow on focus
- Responsive layout
- CSS Custom Properties
- `prefers-reduced-motion` support
- No JavaScript required
