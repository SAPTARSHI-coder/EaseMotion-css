# CSS Ripple-Wave Stepper for Product Catalog Layouts

A modern **Ripple-Wave Stepper** built using pure HTML and CSS. The component features elegant ripple-wave animations, responsive layouts, CSS custom properties, and lightweight styling for product catalog workflows.

## ✨ Features

- Pure HTML5 & CSS3
- Ripple-wave animation
- Responsive stepper layout
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
