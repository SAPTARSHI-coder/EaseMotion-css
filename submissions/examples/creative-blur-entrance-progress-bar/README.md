# CSS Blur-Entrance Progress Bar for Creative Portfolio Layouts

A modern **Creative Portfolio Progress Bar** built entirely with **HTML5 and CSS3**. This showcase demonstrates elegant **Blur-Entrance** animations with smooth gradient progress bars, glassmorphism cards, responsive layouts, and accessibility support without requiring JavaScript.

---

## ✨ Features

- 🎨 Creative portfolio progress bars
- 🌫️ Blur-Entrance animation
- ✨ Animated gradient progress fill
- 💎 Glassmorphism skill cards
- 📊 Skill percentage indicators
- 📱 Fully responsive
- ⚡ Pure HTML5 & CSS3
- 🎯 CSS Custom Properties
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

## 🚀 Getting Started

1. Open `demo.html` in any modern browser.
2. Watch the skill cards animate into view with a blur-entrance effect.
3. Explore the glowing gradient progress bars.
4. Customize colors, spacing, and animation timing using CSS variables.
