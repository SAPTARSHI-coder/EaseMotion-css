# 💎 Crystal Button – Facets Shimmer Like a Cut Gemstone

> A luxurious, sparkling button with faceted shimmer effects like a cut gemstone, creating a premium, elegant interaction.

---

## 📖 Description

The **Crystal Button** is a luxurious UI component with faceted shimmer effects like a cut gemstone. When hovered, the button sparkles with multiple shine lines and glowing facets, creating a premium, elegant effect reminiscent of a high-quality crystal or diamond. The button features three shimmering light rays, four glowing facets, and a sparkling border.

The component uses CSS animations with `transform` and `keyframes` to create the shimmering and facet effects. The shine lines sweep across the button with staggered delays, while the facets pulse with a soft glow. The button also features a gradient border that shimmers, completing the luxurious crystal aesthetic.

Perfect for premium brands, luxury products, jewelry websites, and any application where you want to create a sophisticated, elegant interaction. The Crystal Button transforms a simple hover into a sparkling, premium experience.
