# Morphing Floating Action Button (FAB) Overlay

A FAB that seamlessly expands into a full-screen navigation menu using the CSS checkbox hack.

## Features
- No JavaScript: Completely driven by CSS pseudo-classes.
- Radial Expansion: The overlay expands radially from the button's exact position.
- Staggered Entrance: Menu items cascade in cleanly using transition delays.

## Usage
Utilize the provided HTML template. The checkbox must precede the menu overlay elements.
