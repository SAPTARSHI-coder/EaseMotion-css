# Animated Interactive Bento Grid

A stunning, modern **Bento Grid layout** built with **EaseMotion CSS**. This component showcases a responsive grid with varying card sizes, staggered entrance animations, and interactive hover effects.

## ✨ Features

- **📐 Bento Grid Layout**: Uses CSS Grid with varying card sizes (1x1, 2x1, 1x2, 2x2) for a modern, asymmetrical design
- **🎬 Staggered Animations**: Each card enters sequentially using `ease-slide-up` with progressive delays (`ease-delay-400` to `ease-delay-1600`)
- **🖱️ Interactive Hover**: Cards lift and scale using `ease-hover-lift` and custom hover transforms
- **📊 Mini Chart Visualization**: Animated bar chart inside the analytics card
- **👥 Avatar Stack**: Overlapping user avatars with hover expansion effect
- **🌐 Ambient Background**: Floating gradient glows add depth to the dark theme
- **📱 Fully Responsive**: Adapts from 4 columns → 3 columns → 2 columns → 1 column

## 🧩 EaseMotion Classes Used

| Class | Purpose |
|-------|---------|
| `ease-center` | Centers header and footer content |
| `ease-fade-in` | Fades in the main page wrapper and footer |
| `ease-slide-up` | Slides cards up on entrance |
| `ease-delay-400` to `ease-delay-1600` | Creates cascading staggered animation sequence |
| `ease-hover-lift` | Lift effect on card hover |
| `ease-btn` + `ease-btn-primary` | Styled CTA button |
| `ease-hover-grow` | Scale effect on CTA button |

## 🚀 How to Use

1. Open `demo.html` in any modern browser
2. Watch all 12 cards animate in with a beautiful staggered effect
3. Hover over any card to see the lift and scale animation
4. Resize the browser to see the responsive grid adaptation
5. Check out the mini chart animation in the analytics card
