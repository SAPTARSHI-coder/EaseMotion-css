# Slide-Up Toast

A lightweight CSS-only Slide-Up Toast component designed for fintech dashboard layouts.

## Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Smooth slide-up entrance animation
- Fintech dashboard styling
- Responsive on desktop, tablet, and mobile
- Hover interaction for the close control
- `prefers-reduced-motion` support
- Easy CSS customization
