# CSS Bouncing Ball Physics

A lightweight physics-inspired bouncing ball animation built entirely
with semantic HTML and modern Vanilla CSS.

## ✨ Features

- Pure HTML and CSS
- No JavaScript
- No external libraries
- Physics-inspired bounce motion
- Squash and stretch effect
- Dynamic shadow scaling
- Platform glow effect
- Responsive design
- Dark-mode friendly
- Reduced-motion support
- High-contrast support
- GPU-friendly transforms
- Uses CSS custom properties
- Mobile optimized
