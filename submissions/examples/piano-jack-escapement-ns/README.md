# Piano Jack Escapement

## What does this do?
Renders a self-contained CSS-only `ease-piano-jack-escapement` demo: Piano jack escapement letting the hammer fly free.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-piano-jack-escapement`. No build step or JavaScript is required for the effect.

```html
<section class="ease-piano-jack-escapement">
  <div class="ease-piano-jack-escapement__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
