# Pattern Lock Dot Grid

## What does this do?

A 3x3 pattern lock visual with selectable nodes and success/error states.

## How is it used?

```html
<div class="pattern-lock"><button class="dot" type="button"></button></div>
```

Open `demo.html` in a browser to try it.

## Why is it useful?

Sequenced selection feedback for auth chrome demos.
