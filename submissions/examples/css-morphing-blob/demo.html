The Math of Organic Refraction

To create a fluid, organic shape that doesn't feel like a standard circle or square, we leverage the **8-point border-radius syntax** combined with staggered keyframes, scale oscillations, and slow rotations.

📐
8-Point Border-Radius By splitting horizontal and vertical border-radii using a slash (e.g. 30% 70% 70% 30% / 30% 30% 70% 70%), we generate asymmetric, curved liquid drops rather than uniform circles.
🔄
Staggered Rotation & Counter-Rotation Overlaying multiple blobs rotating in opposite directions (e.g. one clockwise at 20s, one counter-clockwise at 30s) yields a complex fluid illusion.
✨
Layered Refraction Refinement Refraction depth is created by applying a high-end glassmorphic card on top of the morphing blobs, using backdrop-filter: blur(15px).

Implementation Details

Clean CSS Architecture

Below is the exact CSS code block for the main morphing blob. Self-contained, responsive, and GPU-accelerated.

style.css
/* 1. Define the 8-point border-radius shifting keyframes */
@keyframes morph-blob {
  0%, 100% {
    border-radius: 42% 58% 70% 30% / 45% 45% 55% 55%;
    transform: rotate(0deg) scale(1);
  }
  33% {
    border-radius: 70% 30% 52% 48% / 60% 40% 60% 40%;
    transform: rotate(120deg) scale(1.04);
  }
  66% {
    border-radius: 30% 70% 40% 60% / 40% 60% 40% 60%;
    transform: rotate(240deg) scale(0.96);
  }
}

/* 2. Bind the morphing animation to the element */
.blob-main {
  width: 260px;
  height: 260px;
  background: linear-gradient(135deg, #6366f1, #9d4edd);
  animation: morph-blob 15s ease-in-out infinite;
  will-change: border-radius, transform;
}

/* 3. Handle system prefers-reduced-motion preferences */
@media (prefers-reduced-motion: reduce) {
  .blob-element {
    animation: none !important;
    transform: none !important;
    border-radius: 50% !important;
  }
}
