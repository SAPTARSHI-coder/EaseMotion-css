# 🌱 Dandelion Puff – Seeds Blow Away on Click

> An interactive dandelion component where seeds blow away on click with 5 colors (White, Pink, Gold, Purple, Blue), wind control (0-100%), and floating particle effects.

---

## 📖 Description

The **Dandelion Puff** component creates a magical dandelion experience where seeds blow away on click. Built with vanilla HTML, CSS, and JavaScript, it features 5 colors (White, Pink, Gold, Purple, Blue), wind control (0-100%), and floating seed effects for an enchanting experience.

### 🎯 Core Features

- **Dandelion puff** – seeds blow away on click with floating animation
- **5 colors** – White, Pink, Gold, Purple, Blue
- **Wind control** – adjust wind from 0-100% affecting seed drift
- **Seed physics** – floating seeds with wobble and rotation
- **Seed counter** – tracks number of seeds
- **Auto-regeneration** – dandelion regrows when all seeds are gone
- **Interactive controls** – slider, color buttons, keyboard shortcuts
- **Responsive design** – adapts to different screen sizes

| Method | Action |
|--------|--------|

| **Keyboard** | `Space` – Blow · `R` – Reset |

### ✨ Dandelion Experience

When interacting:
1. **Seeds float** – seeds drift away with wind
2. **Wind applies** – controls seed drift speed
3. **Color applies** – changes seed color
4. **Seeds scatter** – organic floating motion
5. **Counter updates** – seed count in real-time
6. **Regenerates** – dandelion regrows

### 🛠️ Technologies Used

- **HTML5** – semantic structure with Canvas
- **CSS3** – gradients, backdrop-filter, transforms
- **JavaScript (ES6)** – Canvas API, requestAnimationFrame, particle system

### 🎨 Design Philosophy

This component embodies **EaseMotion CSS's animation-first philosophy** through:

- **Organic motion** – seeds float naturally
- **Particle effects** – floating seeds with wobble
- **Visual feedback** – status updates, counter, controls
- **Magical atmosphere** – floating seeds and glow
- **Human-readable classes** – `.dandelion-controls`, `.color-btn`, `.dandelion-text`

### 🔧 Customization Options

| Property | Location | Default |
|----------|----------|---------|
| Colors | `colorConfigs` object | 5 colors |
| Wind range | `windSlider` | 0-100% |
| Seed count | `generateSeeds()` | 40-70 |
| Seed speed | `speed` | 0.5-2.5 |
| Seed size | `size` | 1-3px |
