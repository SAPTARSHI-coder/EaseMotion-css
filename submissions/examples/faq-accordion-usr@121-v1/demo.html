EaseMotion CSS is a lightweight, modern CSS animation library that provides smooth, accessible animations for web interfaces. It includes a wide range of pre-built animations like fade, slide, scale, and hover effects that can be easily applied to any HTML element using simple class names.

The library focuses on performance and accessibility, respecting users' motion preferences while delivering beautiful visual experiences.

Getting started is simple! Just include the EaseMotion CSS file in your HTML:

<link rel="stylesheet" href="easemotion.min.css">

Then add animation classes to your elements. For example, use ease-fade-in for fade animations or ease-slide-up for slide effects. Check our documentation for the complete list of available animations.

EaseMotion supports all modern browsers including Chrome, Firefox, Safari, and Edge. We use standard CSS animations and transforms that have excellent browser support.

For older browsers, animations will gracefully degrade without breaking your layout. The library also respects the prefers-reduced-motion media query for users who prefer less animation.
