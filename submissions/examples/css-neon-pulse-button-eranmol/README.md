# CSS Neon Pulse Button

A neon-styled button with an outer ring that pulses outward on hover using pure CSS keyframe animations.

## Preview

Open `demo.html` in your browser and hover over the button to see the pulse effect.

## Features

- Pure CSS — no JavaScript
- Two stacked pulse rings with staggered timing
- Neon glow text-shadow on hover
- Works on any dark background

## Usage

```html
<div class="neon-btn-wrap">
  <button class="neon-btn">Hover Me</button>
  <span class="pulse-ring"></span>
  <span class="pulse-ring pulse-ring-2"></span>
</div>
```

```html
<link rel="stylesheet" href="style.css" />
```
