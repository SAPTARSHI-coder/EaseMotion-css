# Floating Slider — Dark Mode

A responsive floating slider component with a dark visual system,
soft elevation, and polished range-control interactions.

Implemented for issue #79693.

## Features

- Dark mode visual styling
- Floating card treatment
- Native range slider
- Dynamic value display
- Gradient progress indicator
- Elevated slider thumb
- Hover and focus states
- Responsive layout
- CSS-only visual styling
- Reduced-motion support
