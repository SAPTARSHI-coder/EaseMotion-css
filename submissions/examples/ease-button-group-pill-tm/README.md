# Button Group Pill Component

Add ease-button-group-pill-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|---------|
| `--bgp-accent` | `#6366f1` |
| `--bgp-radius` | `8px` |
| `--bgp-shadow` | `0 4px 16px rgba(0,0,0,.3)` |

## Note

Border-collapse technique creates seamless connected buttons. `.active` class highlights selected.
