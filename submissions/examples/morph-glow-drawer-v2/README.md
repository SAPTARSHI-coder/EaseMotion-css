# CSS Morph Glow Drawer

A responsive navigation drawer featuring a morphing glow animation built using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Responsive drawer layout
- Morph glow animation
- Smooth transitions
- Mobile friendly
- No JavaScript
- Accessible with `prefers-reduced-motion`

## Folder Structure

```
morph-glow-drawer/
├── demo.html
├── style.css
└── README.md
```

## Usage

Open `demo.html` in any modern browser.

## Customization

Modify these properties in `style.css`:

- Drawer width
- Glow color
- Background color
- Transition duration
- Border radius
- Typography

## Accessibility

Supports:

- Reduced Motion (`prefers-reduced-motion`)
- Keyboard accessible checkbox toggle
- Responsive layout

## Browser Support

- Chrome
- Firefox
- Edge
- Safari
