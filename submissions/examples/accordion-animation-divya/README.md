# Smooth Accordion Animation

A lightweight accordion component with smooth expand and collapse animations using HTML, CSS, and JavaScript.

## Features

- Smooth open/close animation
- Rotating indicator icon
- Responsive design
- Lightweight
- Easy to customize

## Technologies

- HTML5
- CSS3
- JavaScript

```
│── demo.html
│── style.css
│── script.js
└── README.md
```
