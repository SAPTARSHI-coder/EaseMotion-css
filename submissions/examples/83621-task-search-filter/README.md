# Task Search & Filter UI

A responsive task search and filter interface built with HTML and CSS only.

## Features

- Search input for task titles
- All, Pending, and Completed filter controls
- Clear visual indication for the active filter
- Responsive layout for desktop and mobile screens
- Keyboard-friendly focus states
- Accessible labels and ARIA attributes
- Reduced-motion support
- No JavaScript or external dependencies

## Files

- `demo.html` — standalone demo page
- `style.css` — component styling
- `README.md` — documentation

## Usage

Open `demo.html` directly in a browser. No build tools, server, or installation are required.

## Accessibility

The component includes semantic HTML, labelled form controls, visible keyboard focus states, ARIA attributes for filter controls, and support for `prefers-reduced-motion`.

## Note

The component demonstrates the search and filtering interface using HTML and CSS only, as required by the issue.
