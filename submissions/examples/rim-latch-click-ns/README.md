# Rim Latch Click

## What does this do?
Renders a self-contained CSS-only `ease-rim-latch-click` demo: Rim latch clicking against the strike.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-rim-latch-click`. No build step or JavaScript is required for the effect.

```html
<section class="ease-rim-latch-click">
  <div class="ease-rim-latch-click__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
