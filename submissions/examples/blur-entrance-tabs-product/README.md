# CSS Blur-Entrance Tabs for Product Catalog Layouts

A modern **Blur-Entrance Tabs** component built entirely with **HTML and CSS** for product catalog interfaces. The active tab content smoothly appears with a blur-to-clear entrance animation, creating an engaging browsing experience without JavaScript.

---

## ✨ Features

- Pure HTML & CSS
- Blur entrance animation
- Product catalog tab interface
- Smooth transitions
- Fully responsive layout
- CSS Custom Properties
- Hover effects
- Accessible with `prefers-reduced-motion`
- No JavaScript required

## 🚀 Usage

1. Copy the folder into:

```
submissions/examples/blur-entrance-tabs-product/
```

2. Open `demo.html` in any modern browser.

3. Switch between tabs to view the animated product categories.

## 🎨 CSS Custom Properties

```css
:root{
    --primary:#4f46e5;
    --secondary:#7c3aed;
    --bg:#eef2ff;
    --card:#ffffff;
    --text:#1f2937;
    --radius:18px;
    --shadow:0 18px 40px rgba(0,0,0,.12);
    --transition:.45s ease;
}
```

Customize:

- Primary & secondary colors
- Border radius
- Shadows
- Transition timing
- Background colors
