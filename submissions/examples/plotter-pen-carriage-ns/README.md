# Plotter Pen Carriage

## What does this do?
Renders a self-contained CSS-only `ease-plotter-pen-carriage` demo: Plotter pen carriage drawing axis-aligned strokes.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-plotter-pen-carriage`. No build step or JavaScript is required for the effect.

```html
<section class="ease-plotter-pen-carriage">
  <div class="ease-plotter-pen-carriage__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
