# CSS Aurora Text Effect

A lightweight animated aurora text effect created entirely with HTML and CSS.

## Features

- Pure CSS animation
- No JavaScript
- Flowing aurora gradient
- Animated gradient text
- Responsive design
- Decorative aurora background
- Reduced-motion support
- Semantic HTML

## Files

- `demo.html` - Demo markup
- `style.css` - Aurora text animation and responsive styling

## Usage

Open `demo.html` in any modern browser.

No build tools or external dependencies are required.

## Accessibility

The demo uses semantic HTML and provides a descriptive heading
for the aurora text.

The animation also respects
`prefers-reduced-motion` for users who prefer reduced animation.

## Animation

The effect is created using CSS features including:

- `linear-gradient()`
- `background-clip`
- CSS `@keyframes`
- `transform`
- `filter`
- Responsive media queries
