# CSS Blur-Entrance Tabs for Accessible Web Layouts

A modern **Blur-Entrance Tabs** component created using only **HTML5 and CSS3**. This showcase provides smooth blur-based entrance animations, glassmorphism cards, responsive layouts, and accessibility support without JavaScript.

---

## ✨ Features

- 🌫️ Smooth blur entrance animation
- 🎴 Animated tab cards
- 💎 Glassmorphism UI style
- ⚡ Lightweight CSS animations
- 🎯 CSS Custom Properties
- 📱 Fully responsive layout
- 🧩 Pure HTML5 & CSS3
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

## 🚀 Usage

1. Open `demo.html` in any modern browser.
2. Observe the blur entrance animation.
3. Hover over cards for interactive effects.
4. Customize the component using CSS variables.
