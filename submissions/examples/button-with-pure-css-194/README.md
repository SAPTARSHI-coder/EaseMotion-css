# Cyberpunk Ripple Wave Button

A cyberpunk-themed ripple wave interaction button built entirely with HTML and CSS.

This component is designed for the EaseMotion CSS micro-animation collection.

## ✨ Features

- Pure HTML and CSS
- Cyberpunk visual style
- Neon cyan and magenta accents
- Expanding ripple wave animation
- Animated system status indicator
- Cyberpunk corner decorations
- Hover elevation
- Interactive arrow
- Keyboard focus support
- High-contrast focus indicator
- Responsive mobile layout
- Reduced-motion accessibility support
- No external dependencies
