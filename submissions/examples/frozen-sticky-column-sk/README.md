# Frozen Sticky Table Column

## What does this do?

A wide table with a sticky first column and scroll shadow cue.

## How is it used?

```html
<div class="table-scroll"><table><th class="sticky-col">Name</th></table></div>
```

Open `demo.html` in a browser to try it.

## Why is it useful?

Essential data-UI affordance for horizontally overflowing tables.
