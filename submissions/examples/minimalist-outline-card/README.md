# Minimalist Outline Card

A clean and modern **Minimalist Outline Card** built using pure HTML and
Vanilla CSS.

This component is designed for the EaseMotion CSS collection and focuses
on subtle interactions, accessibility, responsive behavior, and
performance-friendly animations.

## ✨ Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Minimalist outline design
- Smooth hover interaction
- Animated border highlight
- Subtle card elevation
- Dark mode support
- Responsive design
- Keyboard accessible
- Reduced-motion support
- Hardware-accelerated transforms
- Semantic HTML structure
- Modern CSS custom properties
