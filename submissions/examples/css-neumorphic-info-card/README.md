# CSS Neumorphic Info Card

A soft neumorphic information card featuring raised and inset shadow effects, hover interactions, and responsive design.

## Features

- Pure CSS implementation
- Neumorphic raised card design
- Inset hover effect
- Responsive layout
- Keyboard accessible
- CSS custom properties
- Light and dark mode support
- No JavaScript required

## Usage

```html
<div class="card">
  <div class="icon">ℹ️</div>
  <h2>Project Insights</h2>
  <p>Track project performance and progress.</p>
  <button>Learn More</button>
</div>
```
