# Dropdown Menu Component

A smooth, modern hover dropdown menu component built with hand-crafted, dependency-free CSS for the EaseMotion CSS gallery.

## Features
- **Fluid Micro-Interactions:** Combines opacity transitions with a smooth vertical slide using custom `cubic-bezier` easing.
- **Pure CSS:** Operates entirely on CSS hover states without needing JavaScript.
- **Modern Look:** Dark theme optimized with clean borders, subtle shadows, and highlighting states.
