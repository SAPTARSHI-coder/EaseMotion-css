# CSS Ripple-Wave Accordion

A lightweight CSS-only Ripple-Wave Accordion designed for modern fintech dashboard layouts.

## Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Native `<details>` and `<summary>` accordion
- CSS ripple-wave opening effect
- Smooth content animation
- Responsive desktop, tablet, and mobile layouts
- Keyboard accessible
- Focus-visible support
- Reduced-motion support
- CSS custom properties
