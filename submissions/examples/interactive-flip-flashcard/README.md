# Interactive Flip Flashcard Component

A modern neumorphic flip flashcard component designed for
educational websites, quizzes, learning platforms, and study apps.

## Features

- Smooth 3D flip animation
- Neumorphic UI design
- Hover-to-flip interaction
- Keyboard focus support
- Responsive mobile-first layout
- CSS-only animation
- No external dependencies
- Reduced-motion accessibility support
- Customizable colors and shadows

## Preview

The card displays a question on the front side.

Hover or focus the card to rotate it and reveal the answer.
