# CSS Slide-Up Navbar

## Overview

A responsive gaming-inspired navigation bar with a smooth slide-up hover animation built using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Responsive layout
- Smooth slide-up hover animation
- CSS Custom Properties
- Accessible with `prefers-reduced-motion`
- Easy to customize

## Folder Structure

```text
slide-up-navbar/
├── demo.html
├── style.css
└── README.md
```

## Usage

1. Open `demo.html` in any browser.
2. Customize the CSS variables.
3. Integrate into your project.

## CSS Variables

- `--primary`
- `--bg`
- `--text`
- `--duration`

## Browser Support

- Chrome
- Firefox
- Edge
- Safari
