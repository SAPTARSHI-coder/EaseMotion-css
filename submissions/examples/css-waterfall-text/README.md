# CSS Waterfall Text

A pure CSS waterfall text animation where individual letters fall into
position sequentially.

## Features

- Pure HTML and CSS
- No JavaScript
- Sequential letter animation
- 3D transform effect
- Responsive typography
- Accessible semantic structure
- Reduced-motion support
- Mobile-friendly
- Lightweight and easy to reuse

## Preview

The animation displays the word "Waterfall" with each character entering
from above and settling into position with a subtle bounce effect.
