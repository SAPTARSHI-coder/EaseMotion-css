# Interactive Spinner - Glassmorphism

A responsive loading spinner designed with a modern glassmorphism UI.

## Features

- Glassmorphism design
- Smooth rotating animation
- Responsive layout
- Pure HTML and CSS
- No JavaScript required

## Files

- `index.html` - Component structure
- `style.css` - Styling and animation

## Usage

Open `index.html` in any modern browser.

## Technologies

- HTML5
- CSS3
- CSS Animations
- Backdrop Filter
