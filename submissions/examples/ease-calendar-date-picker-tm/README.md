# Calendar Date Picker Component

Add ease-calendar-date-picker-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|---------|
| `--cdp-accent` | `#6366f1` |
| `--cdp-radius` | `12px` |
| `--cdp-shadow` | `0 4px 24px rgba(0,0,0,.3)` |

## Note

CSS Grid 7-column layout for the calendar. Today is highlighted with `--cdp-accent`.
