# Scale Hover Badge

A modern pure CSS animated badge component created for **EaseMotion CSS**.

This component demonstrates a product catalog layout with interactive scale hover effects and stylish badges.

## ✨ Features

- Pure HTML & CSS implementation
- Smooth scale hover animation
- Product catalog inspired layout
- Modern glassmorphism design
- Responsive across devices
- Lightweight and performant
- No JavaScript dependency
- CSS transitions and animations
- `prefers-reduced-motion` support
