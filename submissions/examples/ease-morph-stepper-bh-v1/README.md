# ease-morph-stepper-bh

Pure CSS morph-glow stepper component.

## What does this do?
Creates animated steppers with morphing and glowing animation effects.

## How is it used?
```html
<div class="ease-stepper-bh ease-morph-stepper-bh">
  <div class="ease-step-bh active">1</div>
  <div class="ease-step-bh">2</div>
  <div class="ease-step-bh">3</div>
</div>
```

## Why is it useful?
Creates visually striking step indicators for multi-step forms and processes.
