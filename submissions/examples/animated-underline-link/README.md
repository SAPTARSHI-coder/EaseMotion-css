# CSS Animated Underline Link

A pure CSS collection of animated underline effects for links.

Part of the EaseMotion CSS component library.

## Features

- Pure CSS
- No JavaScript required
- Multiple underline reveal animations
- Responsive layout
- Keyboard accessible
- Light and dark mode support
- Customizable CSS variables
- Reduced-motion support

## Available Styles

The demo includes six styles:

1. Slide from Left
2. Reveal from Center
3. Slide from Right
4. Grow Effect
5. Double Underline
6. Gradient Underline
