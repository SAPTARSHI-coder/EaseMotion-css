# Aurora Glow

A smooth and lightweight Aurora Glow background animation created entirely with HTML and vanilla CSS.

## Features

- Pure HTML and CSS
- No JavaScript or external dependencies
- Smooth animated aurora gradients
- Dark and light mode support
- Hardware-friendly `transform` animations
- Responsive layout
- Respects `prefers-reduced-motion`
