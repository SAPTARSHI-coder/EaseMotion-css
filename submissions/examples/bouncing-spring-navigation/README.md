# Bouncing Spring Navigation

A smooth, playful and accessible navigation component featuring
a spring-inspired bouncing interaction using pure HTML and
vanilla CSS.

## ✨ Features

- Bouncing spring hover effect
- Spring-inspired easing curves
- Animated navigation icons
- Animated indicator dot
- Keyboard accessible
- Visible focus states
- Responsive design
- Dark mode support
- Reduced-motion support
- Hardware-friendly transforms
- No JavaScript
- No external dependencies
