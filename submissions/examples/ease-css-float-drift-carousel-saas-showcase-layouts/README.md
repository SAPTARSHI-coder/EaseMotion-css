# CSS Float-Drift Carousel for SaaS Showcase Layouts

A modern SaaS carousel component featuring smooth floating drift animations built completely with pure HTML and CSS.

This component is designed for SaaS landing pages, dashboards, and product showcases where lightweight animated cards are required without JavaScript.


## ✨ Features

- 🌊 Smooth float-drift card animation
- 🌀 Continuous CSS floating movement
- 🎨 Modern glassmorphism UI
- 💻 SaaS product showcase layout
- ⚡ Pure HTML and CSS implementation
- 📱 Fully responsive design
- 🔄 CSS keyframe animations
- ♿ prefers-reduced-motion accessibility support
- 🚀 Lightweight and framework-free

## 🚀 Usage

1. Open `demo.html` directly in your browser.

2. View the floating carousel cards.

3. Customize CSS variables inside `style.css` according to your branding.


## 🎨 CSS Custom Properties

The component uses CSS variables for easy customization:

```css
:root {

    --bg:#020617;
    --card:#0f172a;
    --primary:#38bdf8;
    --secondary:#8b5cf6;
    --text:#f8fafc;
    --muted:#94a3b8;

}

Update these values to create your own theme.

The component supports reduced motion preferences.

Implemented using:

@media(prefers-reduced-motion:reduce)

Animations are minimized for users who prefer reduced motion.
