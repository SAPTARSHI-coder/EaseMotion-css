ease-anchor-tooltip

A zero-JavaScript tooltip driven purely by the native CSS Anchor Positioning API. No Floating UI. No Popper.js. No event listeners.

Live demo — hover the button
Native CSS Anchor Positioned!

Scroll down — the tooltip stays anchored to the button without any JS

Minimal HTML needed 
<button class="ease-anchor-btn">
  Hover Me
</button>

<div class="ease-anchor-tooltip">
  Tooltip content here
</div>
/* style.css — the magic */
.ease-anchor-btn    { anchor-name: --ease-btn; }
.ease-anchor-tooltip {
  position:        absolute;
  position-anchor: --ease-btn;
  left:            anchor(center);
  top:             calc(anchor(bottom) + 8px);
  translate:       -50% 0;
}
⚡

Zero JS

No event listeners, no requestAnimationFrame, no external libraries.

🧲

Native Anchor

Browser resolves anchor() coordinates directly in the layout engine.

🔁

Scroll-Safe

Tooltip follows the anchor through scrolling without recalculation code.

🎨

Pure CSS

Hover state driven by the + adjacent-sibling combinator only.
