# Animated Timeline — Retro Pixel

A responsive timeline component with a Retro Pixel visual style,
created for EaseMotion CSS issue #81380.

## Features

- Retro pixel-inspired interface
- Animated timeline entrance
- Animated timeline nodes
- CRT-style scanline overlay
- Grid-based retro background
- Hard pixel shadows
- Glowing accent colors
- Smooth hover interactions
- Responsive desktop, tablet and mobile layout
- Reduced-motion support
- Pure HTML and CSS
- No JavaScript
