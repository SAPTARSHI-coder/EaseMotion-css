# Thermoscope Rise

## What does this do?
Renders a self-contained CSS-only `ease-thermoscope-rise` demo: Thermoscope fluid column rising with heat.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-thermoscope-rise`. No build step or JavaScript is required for the effect.

```html
<section class="ease-thermoscope-rise">
  <div class="ease-thermoscope-rise__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
