# CSS Rotate Fade Progress Bar

A modern progress bar featuring a rotating fade indicator for creative portfolio layouts using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Rotate + Fade animation
- Responsive layout
- CSS Custom Properties
- Accessible with `prefers-reduced-motion`
- No JavaScript required

## Files

```
demo.html
style.css
README.md
```

## Usage

```html
<div class="progress-track">
    <div class="progress-fill" style="--progress:75%;">
        <span>75%</span>
    </div>
</div>
```

## Custom Properties

```css
--bg
--track
--fill
--text
--radius
--duration
```
