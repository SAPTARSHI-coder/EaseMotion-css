# ease-fade-stepper-bh

CSS Fade-In Stepper Component for Gaming Hub Layouts.

## What does this do?
A multi-step progress indicator with fade-in transitions between steps, designed for gaming-themed interfaces.

## How is it used?
```html
<div class="ease-fade-stepper">
  <div class="ease-step active">Step 1</div>
  <div class="ease-step">Step 2</div>
  <div class="ease-step">Step 3</div>
</div>
```

## Features
- Smooth fade-in transitions between steps
- Gaming-inspired dark theme with neon accents
- Progress line connector between steps
- Active state highlighting
- Fully responsive
- Reduced motion support

## CSS Custom Properties
- `--ease-stepper-primary`: Primary accent color (default: #6366f1)
- `--ease-stepper-secondary`: Secondary accent (default: #8b5cf6)
- `--ease-stepper-bg`: Background color (default: #1e1b4b)
