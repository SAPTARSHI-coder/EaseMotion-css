# Shared-Axis Page Transition

## What does this do?

Radio-driven pages demonstrating shared-axis X slide+fade transitions.

## How is it used?

```html
<div class="axis-demo"><input type="radio" name="page"/><section class="page">A</section></div>
```

Open `demo.html` in a browser to try it.

## Why is it useful?

Intentional navigation motion beyond generic fades.
