# Animated Audio Player Widget

A responsive, animated audio player component featuring a soft
Claymorphism visual style.

The component is implemented using pure HTML and CSS with no
JavaScript dependencies.

## Features

- Claymorphism UI
- Animated album artwork
- Animated waveform visualization
- Smooth progress bar
- Animated playback controls
- EaseMotion CSS variables
- Reusable design tokens
- Responsive layout
- Mobile, tablet and desktop support
- Keyboard focus states
- `prefers-reduced-motion` support
- Forced-colors accessibility support
- Zero JavaScript dependencies
