# Animated Team Section

A modern animated team section component built with pure HTML and CSS. It includes smooth entrance animations, hover effects, gradient avatars, and responsive grid layout.

## Features

- Pure HTML and CSS implementation.
- Animated team cards with staggered entrance.
- Gradient avatar design.
- Hover lift and glow effects.
- Responsive grid layout.
- Supports `prefers-reduced-motion`.

## Usage

Copy the HTML structure from `demo.html` and link `style.css`.

```html
<section class="team-grid">
  <article class="team-card">
    <div class="team-avatar">A</div>
    <h2>Aarav Sharma</h2>
    <p class="team-role">Frontend Developer</p>
    <p class="team-desc">Short description here.</p>

    <div class="team-tags">
      <span>HTML</span>
      <span>CSS</span>
      <span>UI</span>
    </div>
  </article>
</section>
