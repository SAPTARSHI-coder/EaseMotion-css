\# Ease Magnetic Hover



\## Description



Ease Magnetic Hover is a lightweight CSS-only hover effect that gives an element a subtle magnetic-style interaction.



When the user hovers over the element, it smoothly lifts upward, scales slightly, and gains a soft shadow. This creates a responsive interaction without JavaScript.



\## Usage



Add the class to any suitable interactive element:



```html

<button class="ease-magnetic-hover">

&#x20;   Explore More

</button>
