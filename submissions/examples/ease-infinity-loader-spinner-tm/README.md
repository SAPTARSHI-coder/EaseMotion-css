# Infinity Loader Spinner Component

Add ease-infinity-loader-spinner-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|--------|
| `--il-accent` | `#6366f1` |
| `--il-accent2` | `#ec4899` |
| `--il-size` | `80px` |
| `--il-speed` | `1.5s` |

## Technique

Three concentric rings with different speeds and directions create the infinity-like spin effect.
