# Critical CSS Extraction Benchmark

A responsive CSS-only performance dashboard representing critical CSS extraction for faster above-the-fold loading.

## Features

- Critical CSS size visualization
- Full CSS bundle size
- Above-the-fold loading metrics
- First Paint performance indicator
- Critical CSS extraction pipeline
- Performance budget thresholds
- Optimization status
- Responsive layout
- Smooth hover interactions
- Reduced-motion support
- No external dependencies

## Performance Metrics

The dashboard represents:

| Metric | Value |
|---|---:|
| Critical CSS | 8.4 KB |
| Full Bundle | 42 KB |
| CSS Reduction | 80% |
| First Paint | 0.8s |

## Performance Budget

| Metric | Target |
|---|---:|
| Critical CSS | ≤ 15 KB |
| First Paint | ≤ 1.5s |
| CSS Bundle | ≤ 100 KB |

## How to Use

Open `demo.html` directly in a browser.

No server, JavaScript, package installation, or external library is required.
