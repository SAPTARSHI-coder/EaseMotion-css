# CSS Aurora Border Button


A futuristic button with animated aurora borealis inspired border effects using pure CSS.


## Features

- Animated gradient border
- Aurora color movement
- Glow hover effect
- Responsive design
- No JavaScript required


## Technologies

- HTML5
- CSS3


## CSS Concepts Used

- Pseudo elements
- Gradient animation
- Background positioning
- Transform transitions
- Box shadows


## Accessibility

- Native button element used
- Keyboard accessible by default
