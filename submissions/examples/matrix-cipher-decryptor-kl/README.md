

\# Matrix Cipher Decryptor Component



A cybersecurity-themed decryption component featuring counter-rotating decoding wheels, a glowing central key node, and glassmorphism interface controls built for EaseMotion CSS.



\## Location

\- Directory: `submissions/examples/matrix-cipher-decryptor-kl/`



\## Files Included

\- `demo.html`: Interactive preview window showcasing the matrix cipher decryptor simulation.

\- `style.css`: Scoped decryptor styling and keyframe rules (`ease-cipher-spin-cw`, `ease-cipher-spin-ccw`, `ease-cipher-pulse`).

\- `README.md`: Documentation for the component submission.
