# Quantum Energy Shield Button

A futuristic pure CSS button component featuring a Quantum Energy Shield visual style with glowing shield graphics, animated energy effects, smooth transitions, and responsive behavior.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript
- No external libraries
- Quantum energy shield styling
- Neon cyan, blue, and purple accents
- Smooth hover transitions
- Animated energy core
- Rotating quantum border effect
- Responsive design
- Dark-mode compatible
- Keyboard focus support
- `prefers-reduced-motion` support
