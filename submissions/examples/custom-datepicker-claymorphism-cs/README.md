# Custom Datepicker Calendar — Claymorphism
A responsive datepicker calendar concept using a soft claymorphism visual style and EaseMotion-inspired motion variables.

## Features
- Pure HTML and CSS
- No JavaScript dependencies
- Claymorphism-inspired layered shadows
- Animated calendar entrance
- Interactive button hover and press states
- Visible keyboard focus states
- Responsive layout for smaller screens
- `prefers-reduced-motion` support
- Uses configurable `--ease-duration` and `--ease-timing` variables
