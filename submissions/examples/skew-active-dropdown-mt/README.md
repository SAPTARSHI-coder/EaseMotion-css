# CSS Skew-Active Dropdown

A modern, minimalist tech-style dropdown component featuring a sleek skew transformation and smooth reveal animations. Designed for performant, JavaScript-free interactions using pure CSS hover and focus states.

## Usage

```html
<div class="dropdown-container">
    <button class="dropdown-trigger">
        Options <span class="arrow">▼</span>
    </button>
    <ul class="dropdown-menu">
        <li class="dropdown-item"><a href="#">Dashboard</a></li>
        <li class="dropdown-item"><a href="#">Settings</a></li>
        <li class="dropdown-item"><a href="#">Profile</a></li>
        <li class="dropdown-item"><a href="#">Logout</a></li>
    </ul>
</div>
```

## Why is it useful?

This component perfectly aligns with EaseMotion's philosophy by providing a highly interactive, fluid animation without relying on JavaScript. The skew effect adds a distinct "tech" aesthetic while maintaining strict accessibility through keyboard navigation support (`focus-within`) and `prefers-reduced-motion` considerations.
