# Neumorphic Soft Shadow Navigation

A smooth, accessible, and performant pure CSS navigation featuring Neumorphic Soft Shadow styling.

### Usage

```html
<nav class="nav-neumorphic-73315">
  <ul class="nav-list">
    <li class="nav-item"><a href="#" class="nav-link active">Home</a></li>
    <li class="nav-item"><a href="#" class="nav-link">About</a></li>
    <li class="nav-item"><a href="#" class="nav-link">Services</a></li>
    <li class="nav-item"><a href="#" class="nav-link">Contact</a></li>
  </ul>
</nav>
```

### Why is it useful?

This navigation component uses pure CSS for neumorphic "soft UI" styling with smooth hardware-accelerated transitions. It supports dark mode out-of-the-box using `@media (prefers-color-scheme: dark)`, providing a modern, tactile interface for web applications while maintaining high performance.
