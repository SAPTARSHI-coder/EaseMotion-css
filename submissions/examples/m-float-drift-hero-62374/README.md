# CSS Float-Drift Hero Section for Product Catalog Layouts

A modern **Float-Drift Hero Section** built using pure HTML and CSS. The component features floating animated decorative shapes, responsive layouts, CSS custom properties, and lightweight styling for modern product catalog landing pages.

## ✨ Features

- Pure HTML5 & CSS3
- Float-drift background animation
- Responsive hero section
- CSS Custom Properties
- Modern gradient design
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
