# CSS Undo Button with Timer

A reusable Undo notification component with a circular CSS countdown indicator.

## ✨ Features

- Pure HTML and CSS
- Circular countdown animation
- Smooth notification entrance animation
- Responsive design
- Keyboard accessible button
- Visible focus state
- Reduced-motion support
- No external dependencies
- No JavaScript required for the visual demonstration
