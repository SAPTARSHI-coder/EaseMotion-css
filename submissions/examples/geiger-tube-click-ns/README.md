# Geiger Tube Click

## What does this do?
Renders a self-contained CSS-only `ease-geiger-tube-click` demo: Geiger tube ionization pulses flashing on a counter.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-geiger-tube-click`. No build step or JavaScript is required for the effect.

```html
<section class="ease-geiger-tube-click">
  <div class="ease-geiger-tube-click__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
