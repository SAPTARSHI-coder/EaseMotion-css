# CSS Countdown Launch Hero

A responsive, CSS-only coming-soon hero section featuring a large countdown-style timer and launch progress animation.

## Features

- Pure HTML and CSS
- No JavaScript required
- Responsive across screen sizes
- Large countdown-style timer
- Animated separators
- Animated launch progress bar
- Decorative background effects
- Accessible semantic structure
- Reduced-motion support

## Preview

The component displays:

- Launch announcement
- Large heading
- Countdown-style timer
- Days, hours, minutes and seconds
- Launch preparation progress
- Animated background effects
