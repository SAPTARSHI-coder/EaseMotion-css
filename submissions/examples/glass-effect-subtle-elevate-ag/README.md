# Glass Effect: Subtle Elevate Variation

A pure CSS glassmorphism UI card featuring a smooth, subtle elevate animation on hover.

## Usage

```html
<div class="glass-card-ag glass-elevate-ag">
  <h2>Title</h2>
  <p>Content goes here.</p>
</div>
```

## Why is it useful?

It provides a modern, lightweight, and performant (hardware-accelerated) glassmorphism container that gracefully adapts to both light and dark modes, adhering to the smooth animation philosophy of EaseMotion CSS.
