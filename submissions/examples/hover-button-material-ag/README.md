# Material Design Hover Button

## What does this do?
A fully responsive, pure CSS button that implements Material Design elevation shadows, hover overlays, and active states.

## How is it used?
Apply the `material-hover-btn` class to any `<button>` or `<a>` element. For an outlined version, append the `material-hover-btn-outlined` class.

```html
<button class="material-hover-btn">Contained Button</button>
<button class="material-hover-btn material-hover-btn-outlined">Outlined Button</button>
```

## Why is it useful?
It provides a high-quality, recognizable Material Design interaction using only CSS. It aligns perfectly with EaseMotion's philosophy by using smooth CSS transitions for `box-shadow`, `transform`, and `opacity` to create a tactile and satisfying user experience without relying on JavaScript for ripple effects.
