# Spotlight Follow Hero

A hero backdrop with a moving spotlight beam that sweeps across the stage.

## Features
- Conic gradient beam pivots like a lantern
- Warm light pool on the hero floor
- Headline sits in the beam's path

## Usage
```html
<div class="stage">
  <div class="sf-beam"></div>
  <div class="sf-light"></div>
  <div class="sf-hero"><h2>Step into the light</h2></div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
