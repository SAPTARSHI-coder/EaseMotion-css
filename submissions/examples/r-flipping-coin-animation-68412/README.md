# CSS Flipping Coin Animation

A pure CSS 3D coin component that flips between heads and tails when hovered or focused.

## Features

- Pure HTML and CSS
- No JavaScript required
- CSS 3D transforms
- Front and back coin faces
- Hover interaction
- Keyboard focus interaction
- Subtle floating idle animation
- Responsive sizing
- Customizable CSS properties
- `prefers-reduced-motion` support
