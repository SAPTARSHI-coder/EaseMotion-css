# CSS Color Mode Toggle

A smooth and responsive light/dark color mode toggle built using pure CSS.

## Issue

This contribution addresses:

**Issue #68371 - [FEATURE] CSS Color Mode Toggle Button**

## Features

- Pure CSS implementation
- No JavaScript required
- Smooth light/dark theme transition
- Animated toggle knob
- Sun and moon indicators
- Keyboard accessible
- Visible keyboard focus state
- Responsive design
- Reduced-motion support
- Works on desktop and mobile screens
