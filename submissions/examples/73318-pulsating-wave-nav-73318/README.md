# Pulsating Wave Navigation

## Overview

Issue #73318 implements a navigation with an expanding wave that adds rhythm without distracting from the links.

## Features

- Pure HTML and vanilla CSS
- Transform-based wave pulse
- Responsive navigation
- Native keyboard focus
- Dark-mode compatible styling
- Reduced-motion support

## Files

- `demo.html` — semantic navigation and sections
- `style.css` — pulse effect and responsive rules
- `README.md` — documentation
