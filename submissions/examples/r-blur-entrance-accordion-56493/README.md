# CSS Blur-Entrance Accordion

A modern **Blur-Entrance Accordion** built using pure HTML5 and CSS3 for Gaming Hub layouts. The accordion smoothly appears with a blur entrance animation while remaining lightweight, responsive, and accessible.

---

## ✨ Features

- Pure HTML5 & CSS3
- Blur entrance animation
- Gaming-inspired accordion
- Responsive layout
- CSS Custom Properties
- Lightweight and performant
- Accessible semantic HTML using `<details>` and `<summary>`
- `prefers-reduced-motion` support
- No JavaScript required

## 🚀 Usage

1. Copy the component into your project.
2. Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

3. Open `demo.html` in your browser.
