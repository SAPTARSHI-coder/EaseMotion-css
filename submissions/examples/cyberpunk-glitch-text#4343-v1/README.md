# Cyberpunk Glitch Text 🔮⚡

A high-impact cyberpunk glitch text effect featuring RGB channel separation, clip-path slicing, scanline overlays, flickering neon elements, and floating data fragments. Pure CSS — zero JavaScript.

## Features
- **RGB Channel Separation**: Red and Cyan pseudo-element layers with independent glitch animations.
- **Clip-Path Slicing**: Dynamic `clip-path: inset()` keyframes create horizontal slice distortions.
- **Scanline Overlay**: Repeating gradient simulates CRT monitor scanlines.
- **Glitch Bars**: Horizontal neon bars that flash across the screen at random intervals.
- **Data Fragments**: Floating cyberpunk-themed text snippets with independent animations.
- **Corner Brackets**: Pulsing HUD-style frame corners.
- **Neon Flicker**: Realistic text flicker using opacity keyframes.

## Customization
Edit CSS variables in `:root`:
- `--glitch-color-1` / `--glitch-color-2`: RGB separation colors.
- `--neon-green`: Accent color for scanlines and fragments.
- `--glitch-speed`: Control glitch animation speed.
- `--bg-dark`: Background color.

## Browser Support
Works in all modern browsers. Uses `clip-path`, `attr()`, and CSS custom properties.
