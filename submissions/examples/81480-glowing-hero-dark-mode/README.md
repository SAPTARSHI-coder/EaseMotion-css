# Glowing Hero Section — Dark Mode

A modern responsive hero section featuring a dark-mode
visual system, glowing gradients, animated orbital rings,
floating information cards, and subtle ambient lighting.

Implemented as a pure HTML and CSS component for EaseMotion CSS.

## Features

- Pure HTML and CSS
- Dark mode styling
- Glowing gradient effects
- Animated orbital rings
- Animated central glow
- Floating information cards
- Ambient background orbs
- Responsive navigation
- Responsive hero layout
- Responsive statistics section
- Smooth hover interactions
- CSS entrance animations
- CSS custom properties/design tokens
- Keyboard focus states
- `prefers-reduced-motion` support
- Zero external JavaScript dependencies
