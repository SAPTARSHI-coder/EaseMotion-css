# Responsive Glassmorphism Tab Bar

A responsive tab navigation component featuring translucent glass surfaces,
background blur, subtle borders, and interactive states.

## Features

- Glassmorphism visual style
- Responsive horizontal tab layout
- Mobile-friendly horizontal scrolling
- Active tab state
- Hover and focus interactions
- Frosted glass effect with `backdrop-filter`
- Responsive metric content section
- Semantic navigation markup
- Keyboard-visible focus state
- Reduced-motion support
- Pure HTML and Vanilla CSS
- No JavaScript or external dependencies

## Files

- `demo.html`
- `style.css`

## Usage

Open `demo.html` directly in a browser.

The tab items are regular links, making the component easy to adapt to
different pages or sections.

## Technologies

- HTML5
- Vanilla CSS

## Accessibility

The component uses semantic `<nav>` markup, visible keyboard focus states,
descriptive labels, and `prefers-reduced-motion` support.

## Responsive Behavior

- Desktop: full-width tab bar
- Tablet: horizontally scrollable tabs when necessary
- Mobile: compact tabs with horizontal scrolling
