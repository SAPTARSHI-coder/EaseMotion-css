Frequently Asked Questions

Everything you need to know about EaseMotion CSS.

What is EaseMotion CSS?

EaseMotion CSS is an animation-first CSS framework that lets you add motion to any HTML element using a simple em="" attribute or utility classes. It is built for composability and works with any framework or vanilla HTML.

How do I install EaseMotion CSS?

Add the CDN link to your <head>:

<link rel="stylesheet"
href="https://cdn.jsdelivr.net/npm/easemotion-css@latest/easemotion.min.css">

Or install via npm: npm install easemotion-css

Does it work with React, Vue, or Svelte?

Yes! EaseMotion CSS is framework-agnostic — it works with any JavaScript framework that renders HTML. Just import the stylesheet and use the classes as className (React) or class (Vue/Svelte).

Is EaseMotion CSS accessible?

Absolutely. All animations respect prefers-reduced-motion. When the user enables "Reduce Motion" in their OS settings, all animations are automatically suppressed.

Can I contribute to EaseMotion CSS?

Yes! See the CONTRIBUTING.md guide. All submissions go inside the submissions/ directory — never modify core/ or components/ directly.
