# CSS Zoom-In Feature Grid

A responsive, pure CSS/HTML feature grid designed for fintech dashboard
showcases.

The component uses a subtle zoom-in interaction to make individual feature
cards feel interactive while keeping the interface lightweight and accessible.

## Features

- Pure HTML and CSS
- No JavaScript required
- Smooth zoom-in hover effect
- Hover and keyboard focus support
- Responsive three-column grid
- Tablet and mobile layouts
- CSS custom properties
- Lightweight implementation
- `prefers-reduced-motion` support
- Semantic HTML structure
