# Animated Avatar - Dark Mode

A responsive animated avatar component built using pure HTML and CSS.

This component uses CSS-generated shapes, gradients, animations and
glowing effects to create a modern dark-mode profile interface without
external images or JavaScript.

## ✨ Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Fully responsive
- Dark-mode interface
- Animated avatar
- Animated orbital rings
- Glowing avatar effect
- Live online indicator
- Animated eye blink
- Floating avatar movement
- Responsive profile statistics
- CSS-generated avatar artwork
- Reduced-motion support
- Mobile-friendly layout
