# EaseMotion CSS Gallery & Core Engine

EaseMotion is a lightweight, high-performance CSS animation gallery and utility collection designed for modern web applications. 

## Project Structure
All community contributions and feature submissions are safely organized under the `submissions/` directory:
- `submissions/examples/neon-toggle-switch/` - Interactive cyberpunk neon toggle switch component.
- `submissions/examples/lightning-flash-burst-spark/` - Hardware-accelerated 60 FPS core animation pattern.

## Guidelines for Contributions
1. **Isolated Pathing:** All files for a new component or animation must reside strictly within their dedicated subdirectory inside `submissions/examples/`.
2. **No External Dependencies:** Demos should remain standalone using pure HTML and CSS/SCSS where possible.
3. **Performance First:** Animations must prioritize hardware-accelerated properties (`transform`, `opacity`) and include accessibility support (`prefers-reduced-motion`).
