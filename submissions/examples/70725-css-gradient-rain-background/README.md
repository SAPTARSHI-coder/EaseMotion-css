# CSS Gradient Rain Background

A colorful CSS rain field with gradient drops falling over a dark atmospheric background.

## Features

- Pure CSS falling drops
- Staggered durations and delays
- Responsive layout
- Decorative animation layer
- Accessible content above the effect
- Reduced-motion support

## Files

- `demo.html` — semantic preview and notes
- `style.css` — rain grid, gradients, animation, responsive behavior, and accessibility rules

## Usage

Open `demo.html` directly in a modern browser.

## Accessibility

The animated drops are decorative and hidden from assistive technology. The main content remains ordinary semantic HTML, and reduced-motion users receive a static background.
