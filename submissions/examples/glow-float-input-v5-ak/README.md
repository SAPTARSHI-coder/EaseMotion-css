# glow-float-input-v5-ak

Pure CSS animated floating label input field with neon border focus — no JavaScript required.

## How to use

```html
<div class="ease-float-input-wrapper-v5">
  <input type="text" class="ease-float-input-v5" placeholder=" " id="inp" />
  <label for="inp" class="ease-float-label-v5">Label Text</label>
</div>
