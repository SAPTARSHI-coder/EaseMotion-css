# Text Shift Gradient

A responsive EaseMotion text component that uses a moving gradient background,
text clipping, and subtle hue rotation to create continuously shifting headline
text.

## Files

- `demo.html` provides three dependency-free gradient text examples.
- `style.css` contains the animated gradient, hover and focus states,
  responsive layout, and reduced-motion fallback.

## Accessibility

The examples are keyboard-focusable buttons with visible focus outlines. The
animation is disabled for users who prefer reduced motion.
