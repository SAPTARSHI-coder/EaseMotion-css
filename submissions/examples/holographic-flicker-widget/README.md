# Holographic Flicker Dashboard Widget

A futuristic dashboard widget featuring a **Holographic Flicker** visual style using pure HTML and Vanilla CSS.

## Features

- 🌈 Holographic gradient effects
- ✨ Flickering holographic core
- 🔄 Animated holographic rings
- 📊 Dashboard statistics
- 📈 Animated performance indicator
- 🌙 Automatic dark mode support
- ⚡ Hardware-accelerated animations
- ♿ Accessible semantic HTML
- 📴 Reduced-motion support
- 📱 Responsive design
- 🚫 No JavaScript or external dependencies
