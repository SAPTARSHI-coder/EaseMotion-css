# CSS Circular Countdown

A polished CSS-only circular countdown component for EaseMotion CSS.

The component uses modern CSS features to create a smooth animated
circular progress arc without JavaScript or external dependencies.

## ✨ Features

- Pure CSS implementation
- Smooth circular progress animation
- Responsive sizing
- Modern conic-gradient based design
- CSS custom properties
- Accessible timer semantics
- Reduced-motion support
- Forced-colors support
- No JavaScript
- No external dependencies
- Easy to customize
- Works across modern browsers
