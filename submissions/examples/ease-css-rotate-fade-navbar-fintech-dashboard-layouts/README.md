# CSS Rotate-Fade Navbar for Fintech Dashboard Layouts

A modern fintech dashboard navigation component featuring smooth rotate and fade entrance animations built completely with pure HTML and CSS.

This component provides a lightweight animated navbar experience for fintech dashboards, SaaS applications, and financial platforms without requiring JavaScript or external libraries.


## ✨ Features

- 🔄 Smooth rotate-fade navbar entrance animation
- 💳 Fintech dashboard inspired layout
- 🎨 Glassmorphism navigation design
- ⚡ Pure HTML and CSS implementation
- 🌈 Gradient buttons and modern UI effects
- 📱 Fully responsive navbar layout
- ✨ Hover interactions
- ♿ prefers-reduced-motion accessibility support
- 🚀 Lightweight and framework-free

## 🚀 Usage

1. Open `demo.html` directly in your browser.

2. View the animated fintech dashboard navbar.

3. Customize CSS variables inside `style.css` according to your brand theme.


## 🎨 CSS Custom Properties

The component uses CSS variables for easy customization:

```css
:root {

    --bg:#020617;
    --card:#0f172a;
    --primary:#38bdf8;
    --secondary:#8b5cf6;
    --accent:#22c55e;
    --text:#f8fafc;
    --muted:#94a3b8;

}

Modify these variables to create your own dashboard theme.
