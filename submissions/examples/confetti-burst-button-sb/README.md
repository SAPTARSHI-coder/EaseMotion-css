# Confetti Burst Button Submission

## 1. What does this do?
Creates an interactive button that triggers a colorful confetti burst animation on click.

## 2. How is it used?
Apply the `.ease-confetti-btn` class to any button element.

## 3. Why is it useful?
- Adds celebratory feedback for successful actions
- Lightweight CSS-only implementation
- Accessible: respects reduced motion preferences
