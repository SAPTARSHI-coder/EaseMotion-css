# CSS Progress – Velvet Smooth Transition

A modern animated progress bar component featuring elegant velvet-smooth filling animations using pure HTML and CSS.

## Features

- Smooth velvet-style fill animation
- Gradient progress indicator
- Glassmorphism container
- Responsive layout
- Hardware-accelerated CSS animation
- Pure HTML & CSS
- Dark mode friendly
