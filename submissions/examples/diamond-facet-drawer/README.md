# Diamond Facet Edge Drawer

A smooth, accessible, and performant pure CSS drawer featuring a
**Diamond Facet Edge** visual style.

The component combines geometric edge facets, subtle lighting,
layered depth, and a smooth hardware-friendly slide transition.

No JavaScript or external dependencies are required.

## ✨ Features

- Pure HTML and vanilla CSS
- No JavaScript
- No external dependencies
- Diamond-inspired faceted drawer edge
- Smooth slide-in transition
- Hardware-friendly `transform` animation
- Layered shadows and depth
- Backdrop blur and fade
- Staggered navigation reveal
- Hover and focus states
- Responsive drawer sizing
- Dark-mode-friendly design
- `prefers-reduced-motion` support
