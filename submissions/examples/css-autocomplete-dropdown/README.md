# CSS Autocomplete Dropdown

A responsive CSS-styled autocomplete dropdown component with smooth reveal animation, hover states, keyboard accessibility, and light/dark mode support.

## Features

- Pure CSS implementation
- Smooth dropdown animation
- Hover and focus interactions
- Responsive layout
- Keyboard accessible suggestion items
- Light and dark mode support
- Uses CSS custom properties for easy theming

## Files

- `demo.html` – Component demo
- `style.css` – Styling and animations
- `README.md` – Documentation
