# Morph Card Entrance & Exit Pair Component

## 1. What does this component do?

Provides a complete entrance and exit morphing animation pair for UI cards (`.ease-morph-card-enter` and `.ease-morph-card-exit`). Allows cards to morph seamlessly between standard rounded rectangle card state and pill/circle state.

## 2. How is it used?

```html
<!-- Morph Entrance (Card -> Pill) -->
<div class="morph-card ease-morph-card-enter">Card Content</div>

<!-- Morph Exit (Pill -> Card) -->
<div class="morph-card ease-morph-card-exit">Card Content</div>
```

## 3. Why does it fit EaseMotion CSS?

Completes the morph card animation set by offering both entrance and exit variants, enabling smooth state transitions for expandable cards and modal triggers.

## 4. Demo Instructions

Open `demo.html` in any web browser and use the **Morph In** and **Morph Out** buttons to test the paired card morph transitions.
