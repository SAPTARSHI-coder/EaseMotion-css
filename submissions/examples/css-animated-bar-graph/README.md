# CSS Animated Bar Graph

A responsive horizontal bar graph built with HTML and modern CSS.

The component uses CSS scroll-driven animations to animate each
bar as it enters the viewport.

## ✨ Features

- Pure HTML and CSS
- No JavaScript
- Scroll-driven bar animation
- Responsive layout
- Accessible progressbar semantics
- Semantic HTML structure
- CSS custom properties
- Modern `animation-timeline: view()`
- Reduced-motion support
- Browser fallback
- Mobile-friendly design
- Smooth hover interactions
- Professional dashboard-style UI
