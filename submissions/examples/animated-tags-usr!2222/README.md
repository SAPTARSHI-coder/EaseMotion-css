# Animated Tag/Chip Component Submission

## 1. What does this do?
It provides a modern, interactive tag/chip component with multiple style variants (default, outlined, colored, removable, filter, with icons) and smooth hover animations. Perfect for filters, categories, skills, and labels.

## 2. How is it used?
Wrap your tags in a `.tag-container` and use `.tag` class for each tag. Add variants like `.tag-outlined`, `.tag-success`, `.tag-removable`, `.tag-filter`, or `.tag-with-icon`. Use JavaScript for interactive functionality (remove, filter toggle).

## 3. Why is it useful?
- Essential component for filters, categories, skills, and labels
- 6 different style variants for different use cases
- Smooth hover animations with scale and lift effects
- Removable tags with close button animation
- Interactive filter tags with active states
- Tags with icon/emoji support
- Fully accessible with ARIA labels
- Includes `prefers-reduced-motion` support for accessibility
- Mobile-responsive design
- Easy to customize colors and styles
- Maintainer can easily standardize this as `.ease-tag-[YOUR_INITIALS]` in the core library.
