# Glassmorphism Accordion Component

A collapsible FAQ/accordion component featuring translucent glass backdrop effects and icon rotation animations.

## Features
- **Semantic Markup:** Built using native `<details>` and `<summary>` elements.
- **Glassmorphism Backdrop:** Frosted glass styling with backdrop blur filters.
- **Pure CSS Animation:** Keyframe opacity transitions and CSS transform icon toggles.

## File Structure
- `demo.html` - Minimal accordion structure.
- `style.css` - Component styling and rotation animations.
