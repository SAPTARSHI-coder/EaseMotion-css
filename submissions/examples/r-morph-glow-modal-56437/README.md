# CSS Morph-Glow Modal

A modern **Morph-Glow Modal** built using pure HTML5 and CSS3 for Gaming Hub layouts. The modal smoothly morphs into view with a glowing effect while remaining lightweight, responsive, and accessible.

---

## ✨ Features

- Pure HTML5 & CSS3
- Morph-glow opening animation
- Gaming-inspired UI
- Fully responsive
- CSS Custom Properties
- Lightweight and performant
- Accessible structure
- `prefers-reduced-motion` support
- No JavaScript required

## 🚀 Usage

1. Copy the component into your project.
2. Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

3. Open `demo.html` in any modern browser.
