
---

## 🚀 Usage
1. Clone or copy the files into your project.
2. Open `demo.html` in your browser.
3. The loader will animate with bouncing dots.

---

## 🛠️ Customization
- **Dot size** → Adjust `width` and `height` in `.loader span`.
- **Colors** → Change `background` color in `.loader span`.
- **Speed** → Modify `animation: bounce 0.6s` for faster/slower bounce.

---

## 📖 Accessibility
- Uses `role="status"` and `aria-label="Loading content"` for screen readers.
- Sequential animation provides visual feedback.
