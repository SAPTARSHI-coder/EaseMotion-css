# CSS Balloon Inflate Loader

A pure CSS loading animation where a balloon inflates and gently floats upward.

## Features

- Pure HTML and CSS
- No JavaScript
- Balloon inflation animation
- Floating motion
- Animated balloon string
- Dynamic ground shadow
- Animated loading dots
- Responsive design
- Accessible loading status
- `prefers-reduced-motion` support
- No external dependencies
