
---

## 🚀 Usage
1. Clone or copy the files into your project.
2. Open `index.html` in your browser.
3. Hover or focus on the button to see the tooltip appear with a blur effect.

---

## 🛠️ Customization
- **Blur strength** → Adjust `backdrop-filter: blur(8px)` for stronger/weaker frosted look.
- **Duration** → Change `transition: 0.3s` for faster/slower reveal.
- **Tooltip position** → Modify `bottom: 120%` or `left: 50%` for placement.
- **Colors** → Customize background and text colors for different themes.

---

## 📖 Accessibility
- Uses `aria-describedby` for screen readers.
- Tooltip appears on both hover and focus for keyboard accessibility.
