# Dynamic Accordion Table Row Expander for Data Tables

### Compact Mobile-First Edition

A modern accordion-style table row expander built with pure HTML and CSS. This component provides smooth expand/collapse animations, a compact mobile-first layout, glassmorphism-inspired styling, and accessibility-friendly interactions for responsive data tables.

---

## ✨ Features

- Compact mobile-first layout
- Smooth accordion expand/collapse animation
- Glassmorphism-inspired card design
- Responsive table layout
- CSS-only implementation (no JavaScript)
- Keyboard-accessible interactions
- Modern CSS variables
- Reduced motion support

## 🚀 Usage

1. Open the component folder.
2. Keep `demo.html` and `style.css` in the same directory.
3. Open `demo.html` in any modern browser.

No external libraries or installation are required.
