# CSS Slide-Up Hero Section

A responsive SaaS hero section featuring a smooth CSS Slide-Up entrance animation.

- Pure HTML and CSS
- No JavaScript required
- Slide-Up entrance animation
- Animated SaaS dashboard preview
- Responsive desktop, tablet, and mobile layouts
- Interactive CTA buttons
- CSS custom properties
- Accessible reduced-motion support
- Self-contained demo
