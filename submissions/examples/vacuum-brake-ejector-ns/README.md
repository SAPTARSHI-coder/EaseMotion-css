# Vacuum Brake Ejector

## What does this do?
Renders a self-contained CSS-only `ease-vacuum-brake-ejector` demo: Vacuum brake ejector pulling the train pipe down.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-vacuum-brake-ejector`. No build step or JavaScript is required for the effect.

```html
<section class="ease-vacuum-brake-ejector">
  <div class="ease-vacuum-brake-ejector__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
