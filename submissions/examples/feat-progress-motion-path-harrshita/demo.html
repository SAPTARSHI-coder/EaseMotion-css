Complex Path Animation without JavaScript:

The glowing dot is animated perfectly along a bezier curve using the CSS offset-path property. The animation simply transitions offset-distance from 0% to 100%.

Notice the arrow inside the dot: offset-rotate: auto automatically calculates the tangent of the curve and rotates the element so it always faces "forward", completely natively!
