# CSS Slide-Up Navbar

A responsive navigation bar featuring a smooth slide-up hover animation created using only HTML and CSS.

## Features

- Pure HTML & CSS
- Slide-up hover animation
- Responsive layout
- Keyboard accessible
- Supports `prefers-reduced-motion`
- Lightweight and customizable

## Folder Structure

```text
slide-up-navbar/
├── demo.html
├── style.css
└── README.md
```

## Usage

Open `demo.html` in any modern browser.

## Customization

- Navbar background
- Accent color
- Animation speed
- Font size
- Spacing

## Accessibility

- Keyboard focus support
- Reduced motion support
- Responsive on desktop, tablet, and mobile
