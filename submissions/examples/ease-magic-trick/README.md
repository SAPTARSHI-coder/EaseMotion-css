# Magic Trick · Object Appears/Disappears 🎩

An interactive magic trick where objects appear and disappear with magical effects, sparkles, and mystery. Watch the magic happen!

## Features

- 🎩 **Magic Trick** – Object appears and disappears
- ✨ **Sparkle Effects** – Burst of sparkles
- 🌀 **Magic Swirl** – Particle swirl effect
- 🔊 **Sound Effects** – Magical sounds
- 🎚️ **Speed Control** – Adjust animation speed (1-10)
- 🎚️ **Magic Level** – Adjust magic intensity (1-10)
- ⏸️ **Pause/Resume** – Toggle animation
- 🔄 **Reset** – Reset trick

## How to Use

1. Click **APPEAR** or press **A** to make the object appear
2. Click **DISAPPEAR** or press **D** to make it disappear
3. Press **Space** to toggle appear/disappear
4. Adjust **Speed** for animation pace
5. Adjust **Magic** for effect intensity
6. Press **RESET** or **R** to reset
7. Press **PAUSE** or **P** to pause/resume animation

## Technical Details

- **Magic System:** Appear/disappear with effects
- **Particles:** Sparkles and magic swirl
- **Sound:** Web Audio API effects
- **Performance:** 60fps with requestAnimationFrame

## Customization

You can easily customize:
- **Speed:** Adjust slider range (1-10)
- **Magic:** Adjust slider range (1-10)

- **Particles:** Modify particle counts

## Browser Support
