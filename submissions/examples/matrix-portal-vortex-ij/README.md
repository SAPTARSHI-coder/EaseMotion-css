\# Matrix Portal Vortex Component



A sci-fi dimensional gateway component featuring counter-rotating energy rings, a glowing central vortex core, and glassmorphism interface controls built for EaseMotion CSS.



\## Location

\- Directory: `submissions/examples/matrix-portal-vortex-ij/`



\## Files Included

\- `demo.html`: Interactive preview window showcasing the portal vortex animation.

\- `style.css`: Scoped vortex styling and keyframe rules (`ease-portal-spin-cw`, `ease-portal-spin-ccw`, `ease-portal-pulse`).

\- `README.md`: Documentation for the component submission.
