# Custom Checkbox Component

Add ease-checkbox-custom-style-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|---------|
| `--ccb-accent` | `#6366f1` |
| `--ccb-radius` | `10px` |
| `--ccb-shadow` | `0 4px 16px rgba(0,0,0,.3)` |

## Technique

Hidden checkbox + `:checked` sibling selector animates the custom box fill and checkmark opacity. Zero JS.
