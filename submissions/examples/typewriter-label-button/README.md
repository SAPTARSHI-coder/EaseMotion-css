# CSS Typewriter Label Button

A pure CSS typewriter button component for EaseMotion CSS.

The button reveals its label character-by-character when the user
hovers over it or focuses it using the keyboard.

## Features

- Pure HTML and CSS
- No JavaScript
- Typewriter-style character reveal
- Blinking cursor effect
- Hover interaction
- Keyboard focus support
- Responsive layout
- Accessible screen-reader label
- `prefers-reduced-motion` support
- Multiple visual variants
- No external dependencies
