# 3D Rotating Cube Navigation Menu (Dark Mode Variant)

A modern **3D Rotating Cube Navigation Menu** built using pure HTML and CSS. The component showcases an animated cube with navigation faces, making it suitable for landing pages, portfolios, and futuristic dashboards.

## ✨ Features

- Pure HTML5 & CSS3
- 3D rotating cube animation
- Dark mode UI
- Glassmorphism cube faces
- Hover interaction
- Responsive layout
- CSS Custom Properties
- `prefers-reduced-motion` support
- No JavaScript required
