EaseMotion Accordion Component

A native, pure CSS-only fluid expansion experience using the CSS Grid technique.

What is the CSS Grid height trick? ↓
Historically, transitioning height from 0 to auto was impossible in pure CSS. By utilizing grid-template-rows: 0fr transitioning to 1fr, we can compute the dynamic inner height explicitly and animate it flawlessly without a single line of JavaScript.
Is it accessible? ↓
Yes! Because it relies entirely on native <details> and <summary> tags, it maintains perfect keyboard focus navigation, screen-reader semantics, and built-in toggle behaviors right out of the box.
Does it support prefers-reduced-motion? ↓
Absolutely. The underlying utility styles actively listen to system accessibility parameters and automatically clamp transition times to 0.01ms if a user prefers reduced motion.
