# Accordion Timeline Journey Showcase

A modern **Accordion Timeline Journey** component built using **pure HTML and CSS**. It presents milestones in a clean vertical timeline with glowing active nodes, glassmorphism cards, and smooth hover animations.

---

## ✨ Features

- 📍 Vertical milestone timeline
- ✨ Glowing active timeline node
- 🪟 Glassmorphism cards
- 📂 Native HTML accordion using `<details>` and `<summary>`
- 🚀 Smooth hover offset animation
- 📱 Fully responsive
- ♿ Supports `prefers-reduced-motion`
- 🎨 Pure HTML & CSS (No JavaScript)

## Usage

1. Open `demo.html` in any modern browser.
2. Click a timeline heading to expand or collapse its content.
3. Customize colors and spacing using the CSS variables in `style.css`.

---

## CSS Variables

```css
:root{
    --bg:#08111f;
    --card:rgba(255,255,255,.08);
    --border:rgba(255,255,255,.15);
    --text:#ffffff;
    --muted:#cbd5e1;
    --primary:#4f9dff;
    --glow:#60a5fa;
}
```
