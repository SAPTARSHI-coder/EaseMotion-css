# Ease Profile Ring

## What does this do?

A circular profile avatar with an animated outer status ring and an online indicator.

---

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<div class="profile-ring">
    <div class="avatar">V</div>
    <span class="status-dot"></span>
</div>
```

### Features

- Circular avatar
- Animated outer ring
- Online status dot
- Responsive layout
- Lightweight and reusable

---

## Why is it useful?

Profile rings are commonly used in user profiles, chat applications, collaboration tools, and team interfaces to communicate user presence.

This component provides a lightweight profile pattern with subtle animation while following the animation-first philosophy of EaseMotion CSS.
