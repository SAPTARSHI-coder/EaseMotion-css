# Online Presence Status Dots

## What does this do?

Avatar presence indicators for online, away, busy, and offline states.

## How is it used?

```html
<div class="presence"><img alt=""/><span class="presence__dot presence__dot--online"></span></div>
```

Open `demo.html` in a browser to try it.

## Why is it useful?

Essential chat/collab primitive with shape+color redundancy.
