# Fade-In Card Grid

A responsive card grid featuring a clean fade-in entrance animation built using only HTML and CSS.

## Features

- Pure HTML & CSS
- Fade-in entrance animation
- Responsive grid layout
- Lightweight
- Accessible
- Supports `prefers-reduced-motion`

## Folder Structure

```
fade-in-card-grid/
├── demo.html
├── style.css
└── README.md
```

## Usage

Include the stylesheet.

```html
<link rel="stylesheet" href="style.css">
```

Example card.

```html
<div class="card">
    <h2>Title</h2>
    <p>Description</p>
</div>
```

## Customization

You can easily modify:

- Background color
- Shadow
- Border radius
- Animation duration
- Grid spacing

## Browser Support

- Chrome
- Firefox
- Edge
- Safari
