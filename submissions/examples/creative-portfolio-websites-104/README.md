# Parallax Depth Scroll Card Grid

A responsive creative portfolio card grid with subtle 3D depth,
hover parallax and smooth transitions.

## Features

- Responsive card grid
- 3D tilt/parallax interaction
- Smooth hover transitions
- Modern dark portfolio design
- Mobile-first responsive layout
- No external dependencies
- Reduced-motion support
