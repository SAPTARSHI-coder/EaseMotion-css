# Morph Glow Stepper

A responsive stepper component built with pure HTML and CSS. The active step uses a morphing shape combined with a soft glow animation to create a modern visual highlight while remaining lightweight and accessible.

## Features

- Pure HTML5 & CSS3
- Morph + glow keyframe animation
- Responsive layout
- CSS custom properties
- Active and completed step styling
- No JavaScript required
- Supports `prefers-reduced-motion`

## CSS Custom Properties

```css
--primary
--completed
--inactive
--background
--text
--step-size
--animation-speed
```

## Accessibility

Animations are automatically disabled when users enable **Reduce Motion**, while preserving the component's layout and functionality.

## Browser Support

Compatible with all modern browsers supporting CSS animations, custom properties, Flexbox, and media queries.
