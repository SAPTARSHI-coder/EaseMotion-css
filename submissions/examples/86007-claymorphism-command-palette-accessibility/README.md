# Claymorphism Command Palette Search — Accessibility Setup

An accessible Claymorphism-inspired command palette pattern for
applications that provide quick access to frequently used commands.

## Features

- Semantic HTML structure
- Native keyboard-accessible buttons
- Accessible search input
- Visible `:focus-visible` states
- Keyboard shortcut documentation
- Responsive layout
- CSS custom property overrides
- Reduced-motion support
- Screen-reader-friendly supporting text
