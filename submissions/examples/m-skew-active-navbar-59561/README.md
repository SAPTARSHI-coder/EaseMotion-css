# CSS Skew-Active Navbar for SaaS Showcase Layouts

A modern **Skew-Active Navbar** built using pure HTML and CSS. The navigation bar features a skew entrance animation with active navigation highlighting, premium glassmorphism styling, and a fully responsive SaaS layout.

## ✨ Features

- Pure HTML5 & CSS3
- Skew-active navigation animation
- Glassmorphism navbar
- Responsive layout
- Active navigation indicator
- Gradient CTA button
- CSS Custom Properties
- `prefers-reduced-motion` support
- No JavaScript required
