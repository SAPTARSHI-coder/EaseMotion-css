# 🎨 Pixelate Button – Dissolves into Pixels on Hover

> A stunning, glitchy button that dissolves into colorful pixels on hover and reforms on leave, creating a digital, pixelated effect.

---

## 📖 Description

The **Pixelate Button** is a visually striking UI component that dissolves into colorful pixels on hover and reforms on leave. When you hover over the button, it breaks apart into a grid of animated pixels that scatter outward, creating a glitchy, digital effect. When you move the mouse away, the pixels gather back together and reform into the original button.

The component uses HTML Canvas with JavaScript to create the pixel grid. Each pixel has random offsets, colors, and animation delays, creating an organic, chaotic pixelation effect. The button content fades out as the pixels appear, and the pixels glow slightly for a digital, neon feel.

Perfect for tech-themed interfaces, gaming websites, creative portfolios, and any application where you want to create a striking, memorable interaction. The Pixelate Button transforms a simple hover into a stunning visual experience.
