# Dip Pen Ink Stroke

## What does this do?
Renders a self-contained CSS-only `ease-dip-pen-ink-stroke` demo: Dip pen nib drawing an ink stroke with blot control.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-dip-pen-ink-stroke`. No build step or JavaScript is required for the effect.

```html
<section class="ease-dip-pen-ink-stroke">
  <div class="ease-dip-pen-ink-stroke__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
