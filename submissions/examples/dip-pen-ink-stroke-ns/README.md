# Ease Dip Pen Ink Stroke

A CSS-only animated dip pen writing component for EaseMotion CSS.

## Features

- Pure HTML and CSS
- No JavaScript dependency
- Realistic writing interface
- Animated pen movement
- Ink stroke reveal effect
- Ink blot animation
- Responsive design
- Reduced motion support
