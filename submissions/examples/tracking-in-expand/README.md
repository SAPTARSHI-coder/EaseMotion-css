# Tracking In Expand

**What does this do?**
Adds a typographic entrance animation that expands text outward by transitioning from a tightly squeezed `letter-spacing` to normal spacing while fading in.

**How is it used?**
Apply the utility class to any text element (e.g., headings or hero text):
```html
<h1 class="tracking-in-expand-ag">Elegance</h1>
```

**Why is it useful?**
It provides an elegant, minimalist text reveal effect that is heavily used in luxury brand landing pages and editorial layouts. It requires no JavaScript to execute.
