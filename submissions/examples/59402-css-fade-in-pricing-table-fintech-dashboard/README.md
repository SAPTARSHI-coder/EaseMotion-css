# CSS Fade-In Pricing Table for Fintech Dashboard Layouts

A pure CSS Fade-In pricing matrix featuring ambient radial glow highlights, subtle opacity transitions, and dark glassmorphic styling for fintech applications.

## Key Features

- **Ambient Fade-In Backdrops:** Glowing radial background spotlights fade into focus (`opacity: 0` to `opacity: 1`) on card hover.
- **Pure CSS Billing Selector:** Smooth radio-group toggle switching between Monthly and Annual billing without JavaScript dependencies.
- **Micro Fade Transitions:** Feature lists and action buttons fade to high contrast upon card selection.
- **Responsive & Accessible:** Fully responsive 3-column layout with `@media (prefers-reduced-motion: reduce)` support.

## Customization

```css
:root {
    --bg-main: #0b0e14;
    --accent-blue: #60a5fa;
    --accent-indigo: #818cf8;
}
```
