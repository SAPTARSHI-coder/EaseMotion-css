# CSS Shooting Star Loader

A pure CSS loading animation where multiple shooting stars travel across a
star-filled background while content is loading.

## Features

- Pure CSS implementation
- No JavaScript required
- Multiple shooting stars
- Continuous looping animation
- Responsive layout
- Lightweight implementation
- Accessible loading container
- Reduced-motion support
- Works without a build system

## Files

- `demo.html` — Standalone demonstration
- `style.css` — Complete component styling

## How to Use

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
