# CSS Scale-Hover Popover for SaaS Showcase

A modern SaaS product showcase featuring pure CSS scale-hover popovers.

This example is built for EaseMotion CSS and requires no JavaScript or external
frameworks.

## Features

- Pure HTML and CSS
- Scale + translate popover animation
- Smooth hover interactions
- Keyboard-friendly `:focus-within` support
- Responsive desktop, tablet and mobile layouts
- CSS custom properties for easy customization
- Accessible focus states
- `prefers-reduced-motion` support
- No JavaScript dependencies
- Lightweight and performant
