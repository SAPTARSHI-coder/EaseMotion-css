# Newton Rings Interference

## What does this do?
Renders a self-contained CSS-only `ease-newton-rings-interference` demo: Newton rings interference pattern pulsing on a lens contact.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-newton-rings-interference`. No build step or JavaScript is required for the effect.

```html
<section class="ease-newton-rings-interference">
  <div class="ease-newton-rings-interference__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
