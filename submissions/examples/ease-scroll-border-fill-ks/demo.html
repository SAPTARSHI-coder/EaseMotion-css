Scroll-Driven Border Fill

Each card's conic-gradient border fills progressively as it scrolls into view. Pure CSS — @property + view-timeline + conic-gradient. Scroll down to see the effect.

⚡

Instant Performance

Zero JavaScript. Every animation is driven by the browser's compositor thread using view-timeline, ensuring butter-smooth 60fps border fills.

🌎

Progressive Enhancement

Browsers without scroll-driven animation support gracefully fall back to a static outlined border. No broken layouts, no missing content.

👁

Full Accessibility

Respects prefers-reduced-motion, prefers-contrast, forced-colors, and provides keyboard focus indicators on every card.

🎨

CSS Custom Properties

Every color, size, and timing variable is exposed as a CSS custom property. Re-theme the entire component by overriding a handful of tokens.

🛠

Dark & Light Mode

Automatically adapts to your system preference via prefers-color-scheme. Colors stay accessible in both modes.

📚

Print Ready

Print styles strip animations and convert to clean bordered cards with break-inside: avoid to prevent content splitting.
