# Elastic Bounce Dropdown Select Menu

A modern neumorphic dropdown select component with a smooth elastic
bounce effect and keyboard navigation.

## Features

- Neumorphic design
- Smooth elastic opening animation
- Hover interactions
- Keyboard navigation
- Arrow Up / Down navigation
- Enter to select
- Escape to close
- Responsive design
- CSS-only visual styling
- Reduced-motion support
