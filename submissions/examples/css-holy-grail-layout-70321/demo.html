Holy Grail Layout

A classic header / sidebar / main / aside / footer composition built with CSS Grid. No JavaScript, fully responsive, and keyboard navigable.

Why this layout?

The holy grail pattern keeps primary content first in source order while flanking it with navigation and related links. Here the main column is rendered between the two sidebars without extra wrappers.

Responsive behavior

Below 768px the grid collapses into a single stacked column so the header, navigation, main content, asides, and footer reflow on small screens. The tabindex="-1" on main allows skip-link focus.
