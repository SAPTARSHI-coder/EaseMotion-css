# Dynamic Stepper Nav – Claymorphism

A modern **Dynamic Stepper Navigation** component inspired by **Claymorphism**, built using only HTML and CSS.

## Features

- 🎨 Claymorphism UI
- 📱 Fully responsive layout
- ✨ Smooth hover transitions
- 📊 Animated progress bar
- 🎯 Active and completed step indicators
- ♿ Accessible markup using `aria-current`
- 🌙 CSS Custom Properties
- 🚫 No JavaScript
- ⚡ `prefers-reduced-motion` support
