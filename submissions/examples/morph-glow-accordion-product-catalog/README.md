# Morph-Glow Accordion Product Catalog

A lightweight product catalog showcase featuring a responsive CSS
Morph-Glow Accordion interaction.

The component uses semantic HTML and pure CSS without JavaScript or
external frameworks.

## Features

- Pure HTML and CSS
- Native `<details>` and `<summary>` accordion
- Morphing accordion controls
- Glow effect on the active accordion
- Smooth CSS transitions
- CSS keyframe animation
- Responsive product cards
- Desktop, tablet and mobile layouts
- Keyboard-accessible native accordion
- Visible focus states
- CSS custom properties
- `prefers-reduced-motion` support
- No external dependencies
