# CSS Float-Drift Accordion

A lightweight accordion component with a gentle floating animation built using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Floating drift animation
- Responsive layout
- Uses native `<details>` and `<summary>`
- Accessible
- Supports `prefers-reduced-motion`

## Files

```
demo.html
style.css
README.md
```

## Usage

Open `demo.html` directly in any modern browser.

## Customization

Modify colors, spacing, animation duration, and border radius inside `style.css`.

## Accessibility

- Native HTML accordion
- Keyboard accessible
- Reduced motion support
