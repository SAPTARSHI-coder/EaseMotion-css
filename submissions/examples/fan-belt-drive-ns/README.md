# Fan Belt Drive

## What does this do?
Renders a self-contained CSS-only `ease-fan-belt-drive` demo: Industrial fan belt driving a pulley with stretch.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-fan-belt-drive`. No build step or JavaScript is required for the effect.

```html
<section class="ease-fan-belt-drive">
  <div class="ease-fan-belt-drive__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
