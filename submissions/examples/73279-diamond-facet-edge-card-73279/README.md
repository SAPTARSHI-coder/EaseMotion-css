# Diamond Facet Edge Card

## Overview

Issue #73279 demonstrates a geometric card using diamond facet edges, subtle highlights, and smooth CSS transitions.

## Features

- Pure HTML and vanilla CSS
- Clipped geometric decoration
- Smooth transform transitions
- Dark-mode compatible colors
- Native keyboard focus
- Reduced-motion support

## Files

- `demo.html` — card structure and content
- `style.css` — facet geometry and interaction
- `README.md` — documentation
