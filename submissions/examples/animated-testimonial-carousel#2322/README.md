# Animated Testimonial Carousel/Reviews

An elegant **Testimonial/Reviews Section** built with **EaseMotion CSS**. Features rating summary with animated bars, featured quote spotlight, review cards grid, company logos, and CTA section.

## ✨ Features

- **⭐ Rating Summary**: Overall rating with animated distribution bars
- **💬 Featured Quote**: Large spotlight testimonial with author info
- **📝 Review Cards**: Grid of customer reviews with verified badges
- **👍 Helpful Buttons**: Interactive feedback buttons
- **🏢 Company Logos**: Trusted-by company display
- **🔍 Filter Tabs**: Review filtering options
- **🎬 Staggered Entrance**: All sections slide up sequentially
- **📱 Fully Responsive**: 3-column → 2-column → 1-column layout

## 🧩 EaseMotion Classes Used

| Class | Purpose |
|-------|---------|
| `ease-fade-in` | Fades in the main page and footer |
| `ease-slide-up` | Slides sections up on entrance |
| `ease-delay-100` to `ease-delay-700` | Creates cascading staggered sequence |
| `ease-card` | Base card structure |
| `ease-hover-lift` | Lift effect on cards |
| `ease-hover-grow` | Scale effect on buttons and logos |
| `ease-grid` + `ease-grid-cols-3` | Responsive review grid |
| `ease-gap-4` | Spacing between grid items |
| `ease-btn` + `ease-btn-primary` | Styled CTA buttons |
| `ease-pulse` | **Looping pulse** on header badge |

## 🚀 How to Use

1. Open `demo.html` in any modern browser
2. Watch all sections slide in with staggered animations
3. Observe the **rating bars filling** with animation
4. Hover over review cards to see lift effects
5. Test the filter tabs and helpful buttons
6. Hover over company logos for scale effect
7. Resize to mobile to see responsive layout
