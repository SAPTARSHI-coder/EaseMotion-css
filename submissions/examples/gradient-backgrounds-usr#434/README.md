# Animated Gradient Backgrounds Collection Submission

## 1. What does this do?
It provides a collection of beautiful, pure CSS animated gradient backgrounds including mesh gradients, aurora effects, animated blobs, wave animations, particle effects, and animated gradient text. Perfect for modern websites, landing pages, and creative portfolios.

## 2. How is it used?
Each gradient background is a standalone component. Add the appropriate class to your container:
- `.mesh-gradient` - Multi-color animated mesh
- `.aurora-gradient` - Northern lights effect (requires 3 `.aurora-layer` divs)
- `.blob-gradient` - Morphing blob shapes (requires 4 `.blob` divs)
- `.wave-gradient` - Rotating wave patterns (requires 3 `.wave` divs)
- `.particle-gradient` - Floating particles (requires `.particles` container with `.particle` spans)
- `.animated-gradient-text` - Text with flowing gradient

## 3. Why is it useful?
- 6 different animated background styles
- Pure CSS animations (no JavaScript required)
- GPU-accelerated for smooth performance
- Easily customizable colors and speeds
- Perfect for hero sections and landing pages
- Modern, trendy design patterns
- Fully responsive
- Accessible with `prefers-reduced-motion` support
- Lightweight and performant
- Maintainer can easily standardize these as `.ease-gradient-bg-[YOUR_INITIALS]` variants in the core library.
