# Shift Basket Raise

## What does this do?
Renders a self-contained CSS-only `ease-shift-basket-raise` demo: Shift basket raising the lowercase type.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-shift-basket-raise`. No build step or JavaScript is required for the effect.

```html
<section class="ease-shift-basket-raise">
  <div class="ease-shift-basket-raise__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
