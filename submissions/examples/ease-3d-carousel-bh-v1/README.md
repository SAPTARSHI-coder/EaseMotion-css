# ease-3d-carousel-bh

Advanced 3D Carousel with Inertial Drag and Depth Parallax.

## What does this do?
Creates a 3D carousel with perspective, depth parallax, and smooth transitions.

## How is it used?
```html
<div class="ease-3d-carousel">
  <div class="ease-3d-carousel-item">Slide 1</div>
  <div class="ease-3d-carousel-item">Slide 2</div>
</div>
```

## Features
- 3D perspective transform
- Depth parallax effect
- Smooth transitions
- CSS-only implementation
