# Aurora Glow Navigation

**What does this do?**
This is a smooth, accessible, and performant pure CSS navigation menu featuring an animated aurora glow effect on hover.

**How is it used?**
Use the `ease-nav-aurora` class on the container `<nav>` element, and `ease-nav-item` on the child anchor tags `<a>`.

```html
<nav class="ease-nav-aurora">
  <a href="#" class="ease-nav-item active">Home</a>
  <a href="#" class="ease-nav-item">About</a>
  <a href="#" class="ease-nav-item">Services</a>
  <a href="#" class="ease-nav-item">Contact</a>
</nav>
```

**Why is it useful?**
It provides a visually stunning, modern, and highly engaging user experience using pure CSS without relying on heavy JavaScript, fitting perfectly with EaseMotion's philosophy of performant and visually striking UI elements.
