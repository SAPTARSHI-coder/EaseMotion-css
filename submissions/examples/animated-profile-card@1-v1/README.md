# Animated Profile Card

This submission demonstrates how to build a modern, interactive animated profile card using **EaseMotion CSS**.

## Features
- **Entrance Animations**: Uses `ease-fade-in` and staggered `ease-slide-up` with delay utilities (`ease-delay-100` to `ease-delay-600`) for a smooth, cascading load-in sequence.
- **Hover Effects**: The card lifts with a shadow using `ease-hover-lift`, and the profile picture scales up on hover with `ease-hover-grow`.
- **EaseMotion Components**: Utilizes the built-in `ease-card` and `ease-btn ease-btn-primary` classes for structure and styling.
- **Flexbox Utilities**: Stats are perfectly aligned using `ease-flex`, `ease-justify-between`, and `ease-gap-4`.

## How to use
1. Open `demo.html` in your browser.
2. Observe the staggered entrance animations when the page loads.
3. Hover over the card to see the lift effect, and hover over the avatar/button to see the scale effect.

## Technologies Used
- HTML5
- Custom CSS
- EaseMotion CSS (CDN)
