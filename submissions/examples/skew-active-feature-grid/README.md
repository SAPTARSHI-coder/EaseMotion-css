# CSS Skew-Active Feature Grid

A responsive, pure HTML/CSS feature grid for fintech dashboard layouts.

The component uses a subtle skew transformation on hover and keyboard focus
to create an active, modern interaction without JavaScript.

## Features

- Pure HTML and CSS
- No JavaScript required
- Skew-active hover interaction
- Smooth CSS transitions
- Responsive feature grid
- Desktop, tablet, and mobile layouts
- Keyboard focus support
- CSS custom properties
- `prefers-reduced-motion` support
- Semantic HTML
