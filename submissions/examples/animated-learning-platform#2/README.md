## 📋 Issue Description

### Is your feature request related to a problem?
The `submissions/examples/` directory lacks an **education/learning platform** example that showcases course cards with progress tracking, video thumbnails, gamification elements (streaks, XP), and category filtering. Learning platforms are extremely popular and would serve as a valuable reference for developers.

### Describe the solution you'd like
I would like to add an **Animated Learning Platform Dashboard** example that demonstrates:
- **Course cards with progress**: Video thumbnails, progress bars, instructor info
- **Gamification**: Streak badges with pulse animation, XP display, weekly goals
- **Category filtering**: Filter pills with active states
- **Play overlays**: Video thumbnail hover effects
- **Stats dashboard**: Learning metrics with icons
- **Staggered entrance**: Sequential reveal of all sections

### Why is this useful?
Learning platforms combine many advanced UI patterns. This example will show developers how to:
1. Build course cards with progress visualization
2. Implement gamification elements (streaks, XP, goals)
3. Create video thumbnail hover effects with play overlays
4. Design category filter systems
5. Compose a complete dashboard layout with EaseMotion
