# Neumorphic Soft Shadow Accordion

A responsive and accessible CSS accordion featuring a soft neumorphic
shadow effect.

## Features

- Pure HTML and CSS
- No JavaScript
- Responsive design
- Neumorphic soft-shadow styling
- Keyboard accessible
- Dark-mode compatible structure
- Reduced-motion support

## Files

- `demo.html` – Accordion demo
- `style.css` – Styling and animations

## Usage

Open `demo.html` in any modern browser.

## Accessibility

The component uses semantic `<details>` and `<summary>` elements,
providing built-in keyboard interaction and accessibility support.
