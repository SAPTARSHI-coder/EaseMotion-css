# Pendulum Chip Swinging Interaction (`#54679`)

## What does this do?
Provides interactive filter tags that swing back and forth with realistic pendulum gravity easing from a top suspension pivot when hovered.

## How is it used?
Attach `ease-chip-pendulum` alongside optional color theme tokens to chip elements:
```html
<button class="ease-chip-pendulum blue">Swinging Chip</button>
```

## Why is it useful?
Solves issue #54679 by delivering playful physics-driven visual feedback for tag categorization menus.
