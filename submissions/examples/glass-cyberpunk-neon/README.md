# Cyberpunk Neon Glass

A futuristic glassmorphism UI component featuring cyberpunk neon styling,
translucent surfaces, glowing accents, and smooth CSS interactions.

## ✨ Features

- Pure HTML and Vanilla CSS
- Glassmorphism design
- Cyberpunk neon styling
- Cyan and pink neon accents
- Smooth hover transitions
- Animated scan line
- Glowing status indicator
- Responsive layout
- Dark-mode friendly
- Hardware-accelerated transforms
- Keyboard focus states
- Reduced-motion accessibility support
- No JavaScript
- No external dependencies
