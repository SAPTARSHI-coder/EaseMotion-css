# Glowing Timeline — Gradient Glow

A responsive timeline component built with pure HTML and CSS
for EaseMotion CSS issue #81383.

## Features

- Gradient glow timeline
- Luminous timeline nodes
- Animated pulse rings
- Smooth hover interactions
- Elevated timeline cards
- Responsive desktop, tablet and mobile layout
- CSS-only implementation
- Reduced-motion support
- No JavaScript
- No external dependencies
