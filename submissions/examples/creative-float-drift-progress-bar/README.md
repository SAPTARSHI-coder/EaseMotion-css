# CSS Float-Drift Progress Bar for Creative Portfolio Layouts

A modern **Float-Drift Progress Bar** component built completely with **HTML5 and CSS3**. This showcase demonstrates animated progress indicators with floating drift effects, smooth loading transitions, gradient styling, responsive layouts, and accessibility support without requiring JavaScript.

---

## ✨ Features

- 🌊 Floating drift animation
- 📊 Animated progress indicators
- ✨ Moving shimmer effect
- 💎 Glassmorphism progress cards
- 🌈 Gradient progress fills
- ⚡ Smooth CSS transitions
- 🎯 CSS Custom Properties
- 📱 Fully responsive layout
- 🧩 Pure HTML5 & CSS3
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

## 🚀 Getting Started

1. Open `demo.html` in any modern browser.
2. View the animated progress bars.
3. Hover over cards to experience floating drift effects.
4. Customize colors, sizes, and animation timing using CSS variables.
