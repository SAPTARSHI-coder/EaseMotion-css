# Dark Glass Morph

A frosted-glass panel whose backdrop blur shimmers as light passes behind it.

## Features
- Frosted backdrop-filter glass
- Ambient gradient shifts behind the panel
- Border sheen catches the light

## Usage
```html
<div class="dm-scene">
  <div class="dm-blob dm-b1"></div>
  <div class="dm-blob dm-b2"></div>
  <div class="dm-glass">GLASS</div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
