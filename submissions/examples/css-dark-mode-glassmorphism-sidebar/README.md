# Glassmorphism Sidebar with Dark Mode Styling (#78609)

A dark-mode glassmorphic sidebar component featuring deep frosted glass backgrounds, backdrop blur filters, and vibrant indigo-purple gradient glow accents.

## Features
- **Dark Glassmorphism:** Deep translucent slate background filled with CSS `backdrop-filter: blur(24px)` blurring.
- **Glowing Accents:** Indigo-to-purple gradient branding paired with active state inner borders and subtle glows.
- **Fully Responsive:** Automatically collapses into a compact icon-only rail layout on smaller viewports.

## File Hierarchy
- `style.css` - Custom properties, frosted glass metrics, sticky viewport rules, and media queries.
- `demo.html` - Semantic markup demonstrating sidebar integration with ARIA accessibility roles.
- `README.md` - Technical specification and architecture overview.
