# CSS Fade-In Hero Section for Product Catalog Layouts

A responsive product catalog hero section built with pure HTML5 and CSS3 for the EaseMotion CSS project. The design features a smooth fade-in animation, glassmorphism styling, responsive layouts, and accessibility support without requiring JavaScript.

---

## ✨ Features

- Pure HTML5 & CSS3
- Smooth fade-in entrance animation
- Modern glassmorphism interface
- Responsive hero layout
- Product showcase card
- CSS custom properties for customization
- Hover effects and smooth transitions
- Supports `prefers-reduced-motion`
- No JavaScript required
