# Diamond Facet Edge Neumorphic UI

A pure CSS neumorphic interface featuring a diamond-inspired facet edge design.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript or external dependencies
- Soft neumorphic depth and shadows
- Diamond facet edge highlights
- Smooth hover and active transitions
- Responsive layout
- Dark mode support
- `prefers-reduced-motion` support
- Hardware-friendly CSS transforms

Open `demo.html` directly in any modern browser.
