# Badge, Tag, Avatar & Progress Demo

Demonstrates EaseMotion CSS badge, tag, avatar, and progress bar components.

## Features
- Badges in 5 variants (primary, success, warning, danger, neutral)
- Tags with outlined and removable styles
- Avatars in 3 sizes with color variants
- Progress bars with color states
