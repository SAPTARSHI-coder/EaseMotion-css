# Harvest Moon · Large Orange Moon Rises 🌕

An interactive harvest moon rising with large orange moon, atmospheric glow, and serene night effects. Watch the magnificent harvest moon rise!

## Features

- 🌕 **Harvest Moon** – Large orange moon rises
- 🎚️ **Speed Control** – Adjust rise speed (1-10)
- 🎚️ **Glow Control** – Adjust glow intensity (1-10)
- ⏸️ **Pause/Resume** – Toggle animation
- 🔄 **Reset** – Reset to night
- ✨ **Fireflies** – Glowing firefly particles
- 🌟 **Stars** – Twinkling night stars

## How to Use

1. Click **RISE** or press **Space** to watch the moon rise
2. Click again or press **Space** to reset to night
3. Adjust **Speed** for rise pace
4. Adjust **Glow** for brightness
5. Press **RESET** or **R** to reset
6. Press **PAUSE** or **P** to pause/resume animation

## Controls

| Action | Method |
|--------|--------|
| Rise/Reset | Rise button / Space / Click canvas |
| Reset | Reset button / R key |
| Pause/Resume | Pause button / P key |
| Speed | Speed slider |
