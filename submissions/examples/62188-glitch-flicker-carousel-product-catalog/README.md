# CSS Glitch-Flicker Carousel for Product Catalog Layouts

A modern **Glitch-Flicker Carousel** built using pure HTML and CSS for EaseMotion CSS. The cards feature animated glitch effects, flickering visuals, glowing borders, and responsive layouts suitable for product catalog showcases.

---

## Features

- Pure HTML5 & CSS3
- Glitch hover animation
- Flicker lighting effect
- Animated glowing border
- Responsive product cards
- Smooth transitions
- CSS Custom Properties
- No JavaScript required
- Accessible with `prefers-reduced-motion`
