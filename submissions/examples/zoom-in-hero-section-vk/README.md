# Zoom-In Hero Section

A responsive hero section with a smooth zoom-in entrance animation built using pure HTML and CSS.

## Features

- Zoom-in entrance animation
- Responsive layout
- Pure HTML & CSS
- CSS custom properties
- Keyboard accessible buttons
- `prefers-reduced-motion` support
- No JavaScript required

## Usage

Open `demo.html` directly in a browser.

## Folder Structure

```
zoom-in-hero-section-vk/
├── demo.html
├── style.css
└── README.md
```

## Customization

Update the CSS custom properties in `:root` to change colors, spacing, and animation timing.

## Accessibility

- Semantic HTML5
- Keyboard focus styles
- Motion reduction support
- Responsive across desktop, tablet, and mobile

- Edge
