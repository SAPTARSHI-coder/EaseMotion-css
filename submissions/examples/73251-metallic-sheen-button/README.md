# Metallic Sheen Button

A polished pure CSS button collection featuring a **Metallic Sheen** visual treatment with animated reflective gradients and smooth interaction states.

## ✨ Features

- Metallic gradient surfaces
- Animated reflective sheen
- Multiple metallic finishes
- Smooth hover transitions
- Subtle elevation effects
- Active-state feedback
- Responsive layout
- Dark-mode compatible
- Light-mode compatible
- Keyboard-accessible buttons
- Visible focus states
- Reduced-motion support
- Hardware-friendly CSS transforms
- No JavaScript
- No external dependencies

## 🎨 Variants

- Chrome
- Steel
- Titanium
- Silver
- Graphite
- Platinum
