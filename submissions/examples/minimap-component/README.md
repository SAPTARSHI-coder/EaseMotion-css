# CSS Minimap Component

A pure CSS minimap UI component with player indicator, explored area, and map markers.

## Features

- Game-style minimap design
- Animated player position
- Explored and hidden areas
- Map markers
- Responsive layout
- Pure CSS implementation

## Files

- demo.html
- style.css

## Usage

Open `demo.html` in your browser.
