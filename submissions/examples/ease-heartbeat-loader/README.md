# 💓 Heartbeat Loader – Pulses Like an EKG Heartbeat

> A medical, vital-sign loading animation where a heart pulses like an EKG heartbeat, creating a rhythmic, life-affirming visual experience.

---

## 📖 Description

The **Heartbeat Loader** is a medical, vital-sign loading animation where a heart pulses like an EKG heartbeat. The animation features a pulsing heart icon, an EKG line that draws itself, a moving dot at the end of the line, expanding pulse rings, and a BPM (beats per minute) label that updates dynamically. The effect creates a rhythmic, life-affirming visual experience reminiscent of a hospital heart monitor.

The component uses CSS animations with `transform` and `keyframes` to create the heartbeat effect. The heart pulses with a double-beat rhythm, the EKG line draws itself with a stroke-dashoffset animation, and pulse rings expand outward. The BPM number updates randomly to simulate real heart rate variability.

Perfect for medical-themed interfaces, health apps, fitness brands, and any application where you want to create a vital-sign, heartbeat loading animation. The Heartbeat Loader transforms a simple loading indicator into a life-affirming, medical experience.
