# CSS Magnetic Hover Button

A lightweight, pure CSS magnetic-style hover button for interactive modern interfaces.

## Features

- Pure HTML and CSS
- Magnetic-style hover movement using CSS transforms
- Smooth hover and focus transitions
- Responsive design
- Keyboard accessible
- Visible focus state
- Customizable CSS properties
- Supports `prefers-reduced-motion`
- No JavaScript or external dependencies
