# Card Stack Component

A modern interactive card stack component featuring smooth card cycling animations, layered card transitions, custom illustrations, and a clean responsive design. Built with HTML, CSS, and lightweight JavaScript, it provides an engaging way to showcase content while maintaining a simple and reusable structure.


## Features

* Smooth card stack cycling animation
* Interactive click-to-cycle card navigation
* Layered stacked card layout
* Custom SVG illustrations
* Interactive like button with animated feedback
* Modern typography and ambient background effects
* Responsive design
* Lightweight and self-contained
* Easy to customize

## Use Cases

This component is suitable for:

* Feature showcases
* Product highlights
* Team profiles
* Testimonials
* Portfolio sections
* Interactive landing pages
* Dashboard widgets

## Usage

1. Open `demo.html` in any modern browser.
2. Click the active card or navigation arrow to cycle through the stack.
3. Interact with the like button to view the animated feedback.

No build tools or frameworks are required.
