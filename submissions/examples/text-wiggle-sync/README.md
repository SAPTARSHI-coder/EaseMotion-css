# Text Wiggle Sync

Letters wiggle in a coordinated wave that travels the whole word.

## Features
- Coordinated wave
- Per-letter stagger
- Playful easing
- Pure CSS

## Usage
```html
<div class="tws-word"><i>W</i><i>i</i></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
