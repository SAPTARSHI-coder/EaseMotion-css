# EV Charging Handshake

## What does this do?
Renders a self-contained CSS-only `ease-ev-charging-handshake` demo: EV charge port handshake with connector latch and energy flow.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-ev-charging-handshake`. No build step or JavaScript is required for the effect.

```html
<section class="ease-ev-charging-handshake">
  <div class="ease-ev-charging-handshake__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
