# CSS Animated Yo-yo

A playful CSS-only yo-yo animation that bounces up and down on a string.

## Features

- Pure CSS animation
- No JavaScript
- Responsive design
- Continuous bouncing motion
- Rotating yo-yo
- Animated string
- Accessible semantic markup
- `prefers-reduced-motion` support
- No external dependencies

## Files

- `demo.html` - Demo page
- `style.css` - Yo-yo styling and animations

## How It Works

The yo-yo is constructed using CSS elements and pseudo-independent
elements rather than images or JavaScript.

CSS `@keyframes` control:

- Vertical bouncing
- Yo-yo rotation
- String extension and contraction

## Usage

Open `demo.html` in a modern web browser.

No installation or build process is required.

## Accessibility

The demo uses semantic HTML and includes an accessible description
for the animated yo-yo.

Users who prefer reduced motion are provided with a reduced-motion
experience through `prefers-reduced-motion`.
