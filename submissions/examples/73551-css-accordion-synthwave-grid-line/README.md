# Synthwave Grid Line Accordion

Pure HTML and Vanilla CSS implementation for issue #73551.

## Features

- Retro synthwave grid background
- Neon border treatment
- Native disclosure controls
- Smooth indicator and content transitions
- Responsive layout
- Visible keyboard focus
- Reduced-motion support
- No JavaScript dependencies

## Accessibility

The accordion uses native `details` and `summary` elements. Focus remains visible and reduced-motion preferences disable animation while preserving the content.

## Usage

Open `demo.html` directly in a modern browser. The component requires no build tooling or external assets.
