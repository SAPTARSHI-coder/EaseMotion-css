# Neon Pulse Button

This submission adds a new CSS animation featuring a neon pulse button.

## Description
A modern, cyberpunk-style button that has a glowing neon drop-shadow. On hover, the button pulses slightly (scaling up and down) and increases its glow intensity, creating an interactive and eye-catching effect.

## Usage
Open `demo.html` in your browser to see the animation in action.

## Features
- Pure CSS implementation
- Custom `@keyframes` for pulsing effect
- Advanced `box-shadow` usage for neon glow
- Smooth `transition` for hover state
