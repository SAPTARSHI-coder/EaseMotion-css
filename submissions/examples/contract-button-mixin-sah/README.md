# Tactile Contract Button Mixin (`#54699`)

## What does this do?
Provides a deeply rewarding inward compression animation that simulates physical switch damping when pressed.

## How is it used?
Attach the `ease-btn-contract` utility directly to button controls:
```html
<button class="ease-btn-contract primary">Tactile Button</button>
```

## Why is it useful?
Solves issue #54699 by expanding interaction diversity beyond traditional hover expansions with responsive mechanical compression.
