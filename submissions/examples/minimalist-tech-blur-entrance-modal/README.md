# Blur Entrance Modal

A minimalist CSS-only modal component featuring a smooth blur, opacity, and scale entrance animation.

## Features

- Pure HTML and CSS
- No JavaScript required
- Blur-based entrance animation
- Smooth opacity and scale transitions
- Responsive layout
- CSS custom properties for easy customization
- `prefers-reduced-motion` support
- Self-contained demo
