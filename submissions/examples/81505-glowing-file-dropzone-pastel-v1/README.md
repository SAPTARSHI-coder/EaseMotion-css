# Glowing File Dropzone with Pastel Styling

A responsive, CSS-only file dropzone featuring a soft pastel visual system,
subtle glow effects, smooth interactions, and accessible motion preferences.

## Features

- Pure HTML and CSS implementation
- No external JavaScript dependencies
- Pastel gradient and glow styling
- Drag-and-drop inspired visual treatment
- Keyboard-accessible file selection
- Responsive across mobile, tablet, and desktop
- Smooth hover and focus transitions
- `prefers-reduced-motion` support
- Modern browser friendly
