# Interactive Rating Star System with Micro-Bounce Animation (Cyberpunk Theme)

A modern cyberpunk-inspired interactive star rating component built with pure HTML, CSS, and JavaScript.

## Features

- ⭐ Interactive 5-star rating
- 🎨 Cyberpunk neon theme
- ✨ Micro-bounce hover animation
- 🌈 Animated gradient background
- 📊 Dynamic progress bar
- 💬 Live rating messages
- 📱 Fully responsive
- 🚀 No external libraries

## Folder Structure

```
ease-anim-interactive-rating-star-system-with-micro-bounce-animation-258/

└── README.md
```

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over the stars to preview ratings.
3. Click a star to select your rating.
4. Click **Submit Rating** to confirm.
