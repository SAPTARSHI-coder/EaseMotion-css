# CSS Glitch-Flicker Feature Grid for SaaS Showcase Layouts

A modern responsive feature grid built with **pure HTML and CSS** featuring a smooth glitch-flicker hover animation.

## Features

- Pure HTML5 & CSS3
- Responsive feature grid
- Glitch sweep hover animation
- Flicker border effect
- CSS Custom Properties
- SaaS landing page ready
- No JavaScript
- Supports prefers-reduced-motion
