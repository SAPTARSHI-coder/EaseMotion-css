# Loading Dots Cascade

Dots cascade up and fall back in a rhythmic wave.

## Features
- Vertical bounce cascade
- Independent per-dot timing
- Trailing effect
- Pure CSS

## Usage
```html
<span class="ldc-dot" style="--i:0"></span>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
