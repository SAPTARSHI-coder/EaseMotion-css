# Cache Stampede Shield

An advanced EaseMotion example for monitoring distributed Shield Reshields, coalesce debt, retry pressure, and Refresh margin recovery.

## Features

- Interactive controls for hot-key load, coalesce debt, retry pressure, and Refresh margin health.
- Animated radar, Cache lanes, recovery metrics, Reshield timeline, decision matrix, and audit ledger.
- State-driven stable, watch, Shield, and recovered modes.
- Responsive CSS-only dashboard built with `demo.html`, `style.css`, and this `README.md`.
