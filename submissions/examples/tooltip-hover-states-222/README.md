# Interactive Heatmap Grid Showcase

A vibrant gradient interactive heatmap component with smooth hover states and accessible tooltips.

## Features

* Interactive heatmap grid
* Vibrant gradient color levels
* Tooltip information on hover
* Keyboard focus support
* Responsive mobile layout
* Glassmorphism-inspired card design
* Neon gradient effects
* Accessible ARIA labels
* Reduced-motion support
* Pure HTML, CSS and JavaScript
* No external dependencies

## Files

```text
ease-anim-interactive-heatmap-grid-showcase-with-tooltip-hover-states-222/

```

## Usage

Open `demo.html` directly in a modern web browser.

```text
Open demo.html → Hover over a heatmap cell → View activity tooltip
```

## Customization

The visual appearance can be customized using the CSS variables in `style.css`.

```css
:root {
    --gradient-1: #ff2bd6;
    --gradient-2: #7c3cff;
    --gradient-3: #00e5ff;
    --gradient-4: #5cff8d;
}
```

The activity values can be modified in the JavaScript section of `demo.html`.

## Accessibility

The component includes:

* Semantic buttons for interactive cells
* ARIA grid roles
* Descriptive accessible labels
* Keyboard focus states
* `prefers-reduced-motion` support
