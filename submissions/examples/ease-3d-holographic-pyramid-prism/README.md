# Ease 3D Spatial Holographic Pyramid Prism Projection (`ease-3d-holographic-pyramid-prism`)

Projects 4 mirrored spatial perspectives onto a 3D glass pyramid to simulate a physical hologram display.

## Features
- 4-sided 3D spatial glass pyramid stage (`rotateX`, `rotateY`)
- Synchronized multi-angle object rotation
- Specular glass reflection and neon laser glow
- Interactive rotation drag controls
- Low CPU footprint hardware acceleration
