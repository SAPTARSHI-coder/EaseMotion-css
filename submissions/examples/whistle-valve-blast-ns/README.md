# Whistle Valve Blast

## What does this do?
Renders a self-contained CSS-only `ease-whistle-valve-blast` demo: Whistle valve dumping a steam blast.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-whistle-valve-blast`. No build step or JavaScript is required for the effect.

```html
<section class="ease-whistle-valve-blast">
  <div class="ease-whistle-valve-blast__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
