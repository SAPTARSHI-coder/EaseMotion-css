# CSS Origami Fold Reveal

An interactive 3D paper folding effect. When hovering over the folded element, the top and bottom sections flip open smoothly on their hinges to reveal hidden content inside.

## Features
- 3D CSS transforms using `perspective` and `transform-style: preserve-3d`
- Custom `transform-origin` to create paper hinge mechanics
- Hardware-accelerated transitions
