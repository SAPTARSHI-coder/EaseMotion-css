# CSS Exam Result Card

A responsive CSS-only exam result card displaying a student's score,
percentage, grade, marks, and pass/fail status.

## Features

- Pure HTML and CSS
- No JavaScript
- Exam score and percentage display
- Animated circular score indicator
- Grade display
- Pass status indicator
- Animated performance progress bar
- Student and subject information
- Responsive design
- Accessible progress bar
- Reduced-motion support

## Files

- `demo.html` — Component demonstration
- `style.css` — Complete styling and animations
- `README.md` — Documentation
