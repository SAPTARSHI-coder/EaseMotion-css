# Wave Pill Reactive Status Badge Mixin (`#54686`)

## What does this do?
Produces an engaging status badge configured with internal undulating shimmer waves that pass continuously across the pill surface.

## How is it used?
Attach `ease-pill-wave` alongside your preferred color variant class to pill indicators:
```html
<span class="ease-pill-wave cyan">Operational Status</span>
```

## Why is it useful?
Solves issue #54686 by giving live metrics and important notification tags an eye-catching, lively shimmer effect without scripts.
