# Floating Animation Utility

## Overview
A reusable CSS animation utility that makes elements gently float up and down in a continuous loop. It is suitable for hero sections, icons, buttons, badges, and decorative UI elements.

## Files Included

- `demo.html` – Demonstrates the floating animation.
- `style.css` – Contains the floating animation keyframes and utility class.

## Usage

```html
<div class="ease-float">
  🚀 Launch Your Project
</div>
```

## CSS

```css
.ease-float {
  animation: float 3s ease-in-out infinite;
}
```

## Why it fits EaseMotion CSS

This utility is lightweight, reusable, human-readable, and follows the animation-first philosophy of EaseMotion CSS.
