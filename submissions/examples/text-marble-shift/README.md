# Text Marble Shift

Marble veins drift across glossy lettering in a slow organic loop.

## Features
- Marble-vein background
- Slow drifting shift
- Glossy lettering
- Pure CSS

## Usage
```html
<h1 class="tms-text">MARBLE</h1>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
