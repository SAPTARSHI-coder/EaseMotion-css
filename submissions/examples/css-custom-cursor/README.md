# CSS Custom Cursor

A custom cursor component built using pure CSS. The cursor features a circular pointer with a trailing glow effect and interactive hover states for links and buttons.

## Features

- Pure CSS implementation
- Smooth cursor animation
- Hover scaling effects
- Responsive design
- Accessible fallback cursor
- Lightweight and easy to customize

## How to Use

Include the stylesheet and apply the provided classes:

```html
<div class="cursor"></div>
<div class="cursor-trail"></div>
```

## Why it fits EaseMotion CSS

This component adds an engaging interaction effect commonly used in modern portfolios, landing pages, and creative websites while remaining lightweight and dependency-free.
