# Dynamic Spinner – Cyberpunk

A futuristic cyberpunk-inspired loading spinner built using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Responsive
- Neon glowing rings
- Continuous rotating animation
- No JavaScript

## Usage

```html
<div class="cyber-spinner">
    <span></span>
    <span></span>
    <span></span>
</div>
```
