# CSS Workout Split Card (#70844)

A pure CSS weekly workout split planner card featuring day tiles, targeted muscle group badges, rest day styling, and program summary metrics.

## Features
- **Pure CSS Layout:** Responsive CSS Grid layout mapping out weekly training splits.
- **Categorized Target Badges:** Color-coded target tags for Push, Pull, Legs, Upper, and Rest days.
- **Accessibility & Responsiveness:** Designed with semantic list markup, ARIA regional labels, interactive hover elevation, and `@media (prefers-reduced-motion: reduce)` fallbacks.

## File Hierarchy
- `style.css` - Grid layout, color-coded muscle badges, hover states, and responsive breakpoints.
- `demo.html` - Structured HTML representation of the weekly workout schedule.
- `README.md` - Technical specification and documentation.
