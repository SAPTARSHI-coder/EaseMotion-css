Basic Comparison Detail Row

Compact before-and-after rows for reviews and summaries.

This CSS-only utility displays a detail label with two short values, making changes easier to scan in audit panels, reports, and settings reviews.

Plan Starter -> Pro
Status Pending -> Approved
Storage 10 GB -> 50 GB

HTML Usage

<div class="basic-comparison-detail-row">
  <span class="detail-label">Plan</span>
  <span class="detail-value">Starter</span>
  <span class="detail-arrow" aria-hidden="true">-&gt;</span>
  <strong class="detail-value-new">Pro</strong>
</div>
