# Loader Sliding Bar

A loading bar slides left and right, growing and shrinking.

## Features
- Sliding grow-shrink
- Rounded bar
- Track background
- Pure CSS

## Usage
```html
<div class="lsb-track"><div class="lsb-bar"></div></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
