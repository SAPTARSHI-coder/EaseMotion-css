# User Activity Feed Demo

## Purpose

This example demonstrates how existing EaseMotion CSS animation classes can be used to build a modern responsive user activity feed.

---

## Components

- Responsive activity feed
- User avatar
- Activity description
- Timestamp
- Animated feed items

---

## Folder Structure

```
submissions/examples/activity-feed-demo/
├── demo.html
├── style.css
└── README.md
```

---

## How to Run

1. Open `demo.html` in a web browser.
2. View the responsive activity feed.
3. Observe the animations applied using EaseMotion CSS.

---

## Features

- Modern activity feed layout
- Six sample activity cards
- Mobile-friendly responsive design
- Uses existing EaseMotion CSS animation classes
