# CSS Slide-Up Popover for Creative Portfolio Layouts

A lightweight and modern **CSS-only Slide-Up Popover** showcase example built for EaseMotion CSS.

This example demonstrates a creative portfolio interaction component using only HTML and CSS. It provides a smooth slide-up animation, responsive layout, customizable styling, and accessibility support without using JavaScript.

## Features

- Pure HTML & CSS implementation
- Smooth slide-up transition animation
- Lightweight and performant design
- Fully responsive across desktop, tablet, and mobile
- No JavaScript or external dependencies required
- Customizable using CSS custom properties
- Accessible with `prefers-reduced-motion` support
- Suitable for creative portfolio layouts
