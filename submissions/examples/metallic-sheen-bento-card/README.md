# Metallic Sheen Bento Card

A responsive bento grid component inspired by polished metal,
chrome surfaces and reflective materials.

The component is built entirely with HTML and Vanilla CSS.

## Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Metallic gradient surfaces
- Animated reflective light sweep
- Hover elevation
- Chrome-inspired details
- Responsive bento grid
- Dark mode friendly design
- Hardware-friendly CSS transforms
- Reduced-motion support
