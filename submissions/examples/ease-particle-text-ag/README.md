# ease-particle-text

## What does this do?

Applies a particle-inspired text effect by clipping a repeating radial-gradient dot pattern to text and animating its position, creating a drifting particle texture inside the letterforms.

## How is it used?

```html
<h1 class="particle-text">EASEMOTION</h1>
```

Optional modifier classes:

```html
<h1 class="particle-text particle-text-lg">HELLO</h1>
<h1 class="particle-text particle-text-cool">FROSTED</h1>
```

## Why is it useful?

Particle typography gives hero sections, portfolios, landing pages, and experimental interfaces a distinctive, animated focal point while staying lightweight, composable, and dependency-free — it's a single class stacked onto any heading, in keeping with EaseMotion CSS's human-readable, animation-first approach.
