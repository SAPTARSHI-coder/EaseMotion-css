# Retro Nixie Tube Clock Display

A pure HTML & CSS retro Nixie tube clock component inspired by vintage gas-discharge displays.

## Features

- Domed glass tube effect
- Orange glowing digits
- Wire mesh overlay
- Animated blinking colon
- Cathode flicker animation
- Responsive design
- Pure HTML & CSS
- No JavaScript required

Provides an authentic vintage Nixie tube clock component suitable for retro dashboards, steampunk interfaces, game UIs, and animation showcases.
