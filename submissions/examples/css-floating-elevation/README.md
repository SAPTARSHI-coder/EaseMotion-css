# CSS 3D Floating Elevation

A pure CSS 3D floating card animation that creates a smooth elevation effect using perspective, transforms, shadows, glow, and continuous vertical motion.

## Features

- Pure HTML and vanilla CSS
- No JavaScript or external libraries
- CSS 3D perspective
- Smooth floating elevation animation
- Subtle rotation and depth
- Layered shadows and glow
- Responsive layout
- Dark-mode friendly styling
- Hardware-accelerated transforms
- Reduced-motion support

## Usage

Open `demo.html` directly in a modern browser.

The component can be reused by copying the `.floating-card` HTML structure and linking `style.css`.

## Accessibility

The component uses semantic HTML, descriptive text, an accessible section structure, and `prefers-reduced-motion` support for users who prefer reduced animation.

## EaseMotion CSS

This component fits the EaseMotion CSS animation library by providing a reusable CSS-only 3D motion pattern. It demonstrates floating elevation, perspective depth, smooth transforms, and visual feedback without JavaScript.
