# 🌀 Kaleidoscope Loader – Symmetrical Patterns Rotate

> A mesmerizing, psychedelic loading animation where symmetrical patterns rotate like a kaleidoscope, creating a hypnotic, colorful visual experience.

---

## 📖 Description

The **Kaleidoscope Loader** is a mesmerizing, psychedelic loading animation where symmetrical patterns rotate like a kaleidoscope. Twelve colorful segments pulse in a circular pattern, while ornamental dots orbit around the center, creating a hypnotic, colorful visual experience. The animation features a pulsing center, rotating segments with staggered pulses, and orbiting dots, all wrapped in a glowing aura.

The component uses CSS animations with `transform` and `keyframes` to create the kaleidoscope effect. Twelve segments pulse with staggered delays, while dots orbit with smooth, continuous motion. The entire assembly rotates slowly, creating a mesmerizing, psychedelic effect.

Perfect for creative portfolios, music apps, psychedelic themes, and any application where you want to create a colorful, hypnotic loading animation. The Kaleidoscope Loader transforms a simple loading indicator into a mesmerizing visual experience.
