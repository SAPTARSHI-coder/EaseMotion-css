# Interactive Price Comparison Card Tier Switcher

A responsive neumorphic pricing component with three pricing tiers and an interactive monthly/yearly price switcher.

## Features

* Monthly and yearly pricing toggle
* Three pricing tiers
* Neumorphic UI design
* Smooth hover animations
* Responsive mobile layout
* Pure HTML, CSS and JavaScript
* No external dependencies

## Files

```text
ease-advanced-interactive-price-comparison-card-tier-switcher-component-280/
├── demo.html
├── style.css
└── README.md
```

## Usage

Open `demo.html` directly in any modern web browser.

No installation or build process is required.

## Customization

Edit the pricing values, plan names, features, and colors directly in `demo.html` and `style.css`.

## Accessibility

The component uses semantic HTML, readable text, sufficient spacing, and responsive layouts for different screen sizes.
