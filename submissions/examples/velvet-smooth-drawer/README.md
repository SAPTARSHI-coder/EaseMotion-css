# Velvet Smooth Transition Drawer

A smooth and elegant CSS-only side drawer featuring a **Velvet Smooth Transition** effect.

The component uses pure HTML and vanilla CSS with no JavaScript or external dependencies.

## ✨ Features

- Pure HTML and CSS
- No JavaScript required
- Smooth side-to-side drawer transition
- Soft backdrop and blur effect
- Layered shadows for depth
- Subtle velvet-inspired color palette
- Staggered navigation item entrance
- Smooth hover interactions
- Keyboard-focusable controls
- Responsive layout
- Dark-mode-friendly design
- Hardware-friendly transforms
- `prefers-reduced-motion` support
- Dependency-free
