EaseMotion SCSS

Flex Direction Column

A reusable helper for creating clean vertical flex layouts with configurable gaps and alignment.

01

Column Layout

Items are automatically arranged vertically using flex-direction: column.

02

Centered Content

The helper can control both cross-axis and main-axis alignment.

03

Stretch Alignment

Items can stretch across the available container width.

Mixin Usage

@include flex-column(
  $speed-medium,
  center,
  flex-start
);

The mixin provides configurable gap, align-items and justify-content values.
