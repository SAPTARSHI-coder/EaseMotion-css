# CSS Blur-Entrance Pricing Table for Fintech Dashboard Layouts

A modern fintech pricing table component featuring smooth blur entrance animations, glassmorphism cards, and responsive pricing layouts built completely with HTML and CSS.

This component provides a premium pricing showcase experience without JavaScript or external dependencies.

## ✨ Features

- 💳 Modern fintech pricing cards
- 🌫️ Smooth blur entrance animation
- 📊 Pricing comparison layout
- ⭐ Featured plan highlight
- ✨ Glassmorphism UI design
- 🎨 Gradient glow effects
- ⚡ Pure HTML and CSS implementation
- 📱 Fully responsive layout
- 🔄 CSS transitions and keyframe animations
- ♿ Accessibility support with `prefers-reduced-motion`

## 🚀 Usage

1. Clone the EaseMotion CSS repository.

2. Navigate to:


submissions/examples/ease-css-blur-entrance-pricing-table-fintech-dashboard-layouts/


3. Open `demo.html` in your browser.

No JavaScript, frameworks, or external libraries are required.

## 🎨 CSS Custom Properties

The component uses CSS variables for easy customization:

```css
:root {
    --bg:#050816;
    --primary:#00f5ff;
    --secondary:#8b5cf6;
    --green:#22c55e;
    --text:#f8fafc;
    --muted:#94a3b8;
}

Update these variables to match your fintech dashboard branding.
