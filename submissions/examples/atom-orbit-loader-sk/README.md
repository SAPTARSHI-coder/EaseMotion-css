# Atom Electron Orbit Loader

## What does this do?

A nucleus with tilted elliptical electron orbits at staggered speeds.

## How is it used?

```html
<div class="atom" role="status"><span class="atom__nucleus"></span><span class="atom__orbit"></span></div>
```

Open `demo.html` in a browser to try it.

## Why is it useful?

Distinct processing metaphor for science/tech loading states.
