\# Stellar Gravitational Well Component



An astrophysics simulation component featuring counter-rotating accretion disks, a light-absorbing event horizon core, and glassmorphism interface controls built for EaseMotion CSS.



\## Location

\- Directory: `submissions/examples/stellar-gravitational-well-kl/`



\## Files Included

\- `demo.html`: Interactive preview window showcasing the stellar gravitational well simulation.

\- `style.css`: Scoped gravitational well styling and keyframe rules (`ease-well-spin-cw`, `ease-well-spin-ccw`, `ease-well-pulse`).

\- `README.md`: Documentation for the component submission.
