# Animated Badge with Pastel Styling

A responsive animated badge component built with pure HTML and CSS.

## Features

- Soft pastel visual design
- Multiple badge color variants
- Animated status dots
- Gradient shine effect
- Smooth hover interaction
- Floating status badge
- Responsive mobile layout
- Keyboard focus support
- Reduced-motion accessibility support
- No JavaScript dependency

## Files

- `demo.html` — component markup and demo
- `style.css` — complete styling, animations, and responsive behavior

## Usage

Open `demo.html` directly in a browser.

The badge labels and colors can be customized through the
HTML classes and CSS variables.

## Responsive Behavior

The badge collection changes to a two-column layout on small
screens and a single-column layout on very narrow devices.
