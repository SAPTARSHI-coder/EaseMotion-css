Pure CSS Modal: Floating Elevation

A serene, JavaScript-free modal utilizing the checkbox hack. Features infinite `@keyframes` to create a gentle hovering effect, simulating physical detachment from the background.

Elevated State

Notice the shadow. As the modal translates upwards on the Y-axis, the drop shadow expands in blur radius and decreases in opacity. As it translates downwards, the shadow tightens and darkens, perfectly mimicking real-world physics.
