# CSS Blur-Entrance Popover for E-Commerce Checkout Layouts

A modern **Blur-Entrance Popover** component built using pure HTML5 and CSS3 for e-commerce checkout interfaces. The component displays product offers and checkout information with a smooth blur entrance animation, responsive design, and accessibility support.

## Features

* Pure HTML5 & CSS3
* Blur-Entrance popover animation
* Glassmorphism card design
* Product offer popover
* Smooth hover interactions
* Responsive desktop, tablet, and mobile layout
* CSS Custom Properties
* No JavaScript required
* Supports `prefers-reduced-motion`

## Folder Structure

## Usage

1. Open `demo.html` in a modern browser.
2. Hover over the **View Offer** button to display the popover.
3. Customize the colors using the CSS variables in `:root`.
4. Integrate the component into any e-commerce checkout or product page.
