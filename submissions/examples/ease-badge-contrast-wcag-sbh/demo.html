ease-badge-contrast-wcag

WCAG AA-compliant colored badges.

Fixes the issue where white text on light colored badges (warning / info / success) failed the minimum WCAG AA contrast ratio of 4.5:1. This example provides two AA-passing styles for every semantic color: a filled badge (darkened background + white text) and a subtle badge (soft tint + dark text). Every pair is verified ≥ 4.5:1.

Filled — darkened background, white text

Primary Success Warning Danger Info

Backgrounds darkened so white text clears 4.5:1 (e.g. warning #92400e → 7.09:1, was #f59e0b → 2.15:1).

Subtle — soft tint, dark text

Primary Success Warning Danger Info

Dark text on light tints — all ≥ 14:1.
