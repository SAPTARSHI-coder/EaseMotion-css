# Elastic Bounce Dropdown Select Menu with Custom Keyboard Navigation

A high-contrast accessible dropdown menu featuring elastic bounce animations, keyboard navigation, strong focus states, and responsive design using pure HTML, CSS and JavaScript.

## Features

- High-contrast accessibility theme
- Elastic dropdown animation
- Keyboard accessible
- Visible focus indicators
- Responsive layout
- Pure HTML, CSS & JavaScript

## Folder Structure

```
ease-layout-elastic-bounce-dropdown-select-menu-with-custom-keyboard-navigation-111/
├── README.md
├── demo.html
├── style.css
└── script.js
```

## Usage

Open `demo.html` in your browser.

Modify colors and animation timing inside `style.css`.

- HTML5
