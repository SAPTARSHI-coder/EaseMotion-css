# ease-morph-menu-bh

Morphing SVG Menu Button with Elastic Transition.

## What does this do?
A hamburger menu icon that morphs into an X with elastic animation.

## How is it used?
```html
<button class="ease-morph-menu">
  <svg>...</svg>
</button>
```

## Features
- SVG-based morphing animation
- Elastic transition effect
- CSS-only implementation
