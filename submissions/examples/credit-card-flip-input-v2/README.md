# Credit card flip input

A payment card widget that flips 180 degrees when the CVV field receives focus.

## How to view

Open `demo.html` in any modern browser. The demo is fully self-contained — no CDN, no framework, no JavaScript.

## How to use

Copy `style.css` into your project's stylesheet. Every class used in the demo is namespaced with `creditcardflipinputv2-` to avoid collisions.

## Why this is useful for EaseMotion CSS

Checkout pattern; the flip signals the move to the back of the card without a page change.
