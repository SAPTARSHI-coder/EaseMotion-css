# ease-shimmer-text

## Description

Adds an animated shimmer effect that sweeps across text using a moving gradient, creating an elegant highlight animation for headings and important UI elements.

---

## Features

- Pure CSS
- Lightweight
- Infinite shimmer animation
- Responsive
- Easy customization

---

## Usage

```html
<h1 class="ease-shimmer-text">
    EaseMotion CSS
</h1>
```

---

## Browser Support

- Chrome ✅
- Firefox ✅
- Edge ✅
- Safari ✅ (uses `-webkit-background-clip`)

---

## Customization

Animation speed

```css
animation: shimmer 2.5s linear infinite;
```

Gradient colors

```css
background: linear-gradient(
90deg,
#475569,
#ffffff,
#475569
);
```

Font size

```css
font-size:64px;
```
