# CSS Glitch-Flicker Accordion

A lightweight, responsive accordion component with a glitch-flicker
animation designed for modern fintech dashboard interfaces.

Built entirely with HTML and CSS.

## Features

- Pure HTML and CSS
- No JavaScript required
- Uses native HTML `<details>` and `<summary>`
- Glitch-flicker opening animation
- Animated accordion icon
- Responsive dashboard layout
- CSS custom properties
- Smooth transitions
- Accessible keyboard interaction
- `:focus-visible` support
- `prefers-reduced-motion` support
- Mobile, tablet, and desktop friendly
- No external dependencies
