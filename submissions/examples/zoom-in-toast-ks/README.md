# CSS Zoom-In Toast

A minimalist toast notification showcase created for EaseMotion CSS.

This example demonstrates a smooth zoom-in entrance animation using only
HTML and CSS.

## Features

- Pure HTML and CSS
- Smooth zoom-in entrance animation
- Lightweight `transform` and `opacity` animation
- Minimalist technology-inspired design
- Responsive on desktop, tablet, and mobile
- Accessible status notification
- Keyboard-friendly close button
- `prefers-reduced-motion` support
- Customizable CSS variables
- No JavaScript or external framework required
