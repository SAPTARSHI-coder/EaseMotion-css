# Coin Flip

A 3D coin that spins on its edge and settles on heads or tails with a little bounce.

## Features
- True 3D edge flip with perspective
- Heads and tails faces with radial sheen
- Springy landing bounce

## Usage
```html
<div class="cf-coin">
  <div class="cf-face cf-heads">&#169;&#189;</div>
  <div class="cf-face cf-tails">&copy;</div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
