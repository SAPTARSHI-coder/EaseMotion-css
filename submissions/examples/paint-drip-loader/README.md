# CSS Paint Drip Loader

A colorful paint dripping loader created using pure HTML and vanilla CSS.

## Features

- Pure HTML and CSS
- No JavaScript required
- Animated gradient paint bar
- Multiple animated paint drips
- Responsive design
- Smooth CSS animations
- Accessible loading status
- Supports `prefers-reduced-motion`
- No external dependencies
