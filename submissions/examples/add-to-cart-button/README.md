# Add to Cart Button

A cart button that morphs into a success state with a bouncing checkmark on hover.

## Features
- Morphing states from idle to added
- Bouncing checkmark once confirmed
- Clean ripple feedback on interaction

## Usage
```html
<button class="ac-btn">
  <span class="cart-icon">&#128722;</span> Add to Cart
  <span class="check"><i>&#10003;</i></span>
</button>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
