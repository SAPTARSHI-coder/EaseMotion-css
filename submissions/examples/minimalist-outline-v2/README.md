# Minimalist Outline 3D Effect

A clean and modern 3D UI effect created using pure HTML and Vanilla CSS.

## ✨ Features

- Pure HTML and CSS
- Minimalist outline design
- Smooth 3D hover interaction
- Dark-mode compatible
- Hardware-accelerated transforms
- Responsive layout
- Reduced-motion support
- No JavaScript or external libraries
