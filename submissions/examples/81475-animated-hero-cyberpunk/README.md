# Animated Hero Section — Cyberpunk

A responsive cyberpunk hero section built with pure HTML and CSS,
featuring neon lighting, animated orbital graphics, glitch effects,
and futuristic interface styling.

## What does this do?

This component creates a futuristic animated hero section with
a cyberpunk visual language, including neon cyan and magenta
accents, a rotating digital core, telemetry indicators,
glitch-style typography, and responsive layouts.

## How is it used?

Place the markup from `demo.html` in a page and include the
provided `style.css`.

The main hero wrapper is:

```html
<section class="cyber-hero">
  ...
</section>
