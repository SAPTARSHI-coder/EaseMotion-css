# CSS Checklist with Subtasks

A responsive and accessible checklist component built using pure HTML and CSS.

This component provides a parent task structure with expandable subtasks,
animated interactions, custom checkboxes, progress visualization, and
responsive behavior.

## Issue

GitHub Issue: #68617

## Features

- Pure HTML and CSS
- No JavaScript required
- Expandable and collapsible task groups
- Nested subtasks
- Custom CSS checkboxes
- Animated progress indicator
- Completion states
- Hover animations
- Keyboard-friendly native controls
- Visible focus states
- Responsive design
- Reduced-motion accessibility support
- Glassmorphism-inspired UI
