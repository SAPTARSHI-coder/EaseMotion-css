# Cyberpunk Elastic Slide Popover

A modern **Cyberpunk Neon Popover** built entirely with **HTML and CSS**. The component features an elastic slide animation, glassmorphism styling, neon glow effects, responsive layout, and accessibility support without requiring JavaScript.

---

## ✨ Features

- 🎨 Pure HTML5 & CSS3
- ⚡ Elastic slide-in animation
- 🌈 Cyberpunk neon theme
- 🪟 Glassmorphism popover panel
- 📱 Fully responsive
- ♿ Keyboard accessible
- 🌙 CSS Custom Properties for easy customization
- 🚀 Lightweight with no external dependencies
- 🎯 Supports `prefers-reduced-motion`

## 🚀 Usage

Open `demo.html` in any modern web browser.

Hover over or focus on the **Open Control Panel** button to display the elastic slide popover.

## 🎨 CSS Custom Properties

The component uses CSS variables for easy customization.

| Variable | Description |
|----------|-------------|
| `--bg-color` | Background color |
| `--surface-color` | Popover background |
| `--primary-color` | Primary neon cyan |
| `--secondary-color` | Purple glow |
| `--accent-color` | Pink accent |
| `--success-color` | Online status indicator |
| `--text-color` | Main text color |
| `--muted-text` | Secondary text |
| `--border-radius` | Border radius |
| `--transition-speed` | Transition duration |

Example:

```css
:root{
    --primary-color:#00f5ff;
    --secondary-color:#b026ff;
}
```
