# 🏜️ Sand Card – Sand Shifts and Settles Like a Zen Garden

> A calming, meditative card where sand grains shift and settle like a zen garden on hover, creating a peaceful, organic effect.

---

## 📖 Description

The **Sand Card** is a calming, meditative UI component where sand grains shift and settle like a zen garden on hover. When you hover over the card, tiny sand grains drift and settle into new positions, while gentle ripples expand across the surface. The effect creates a peaceful, organic experience reminiscent of raking sand in a zen garden.

The component uses CSS animations with `transform` and `keyframes` to create the grain shifting and ripple effects. Each grain has a unique position and animation delay, creating an organic, natural movement. The ripples expand and contract, adding to the meditative atmosphere.

Perfect for wellness apps, meditation tools, spa brands, and any application where you want to create a calming, peaceful interaction. The Sand Card transforms a simple card into a meditative, zen experience.
