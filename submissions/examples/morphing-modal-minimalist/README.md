# Morphing Modal - Minimalist

A smooth, responsive and accessible CSS-only modal with a minimalist visual style.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript
- No external dependencies
- Smooth morphing entrance animation
- Responsive layout
- Dark mode support
- Reduced-motion support
- Keyboard-focus styling
- Hardware-friendly CSS transforms and opacity transitions
- Works by opening `demo.html` directly in a browser

## Demo

Open `demo.html` directly in your browser.

Click **Open Modal** to see the modal smoothly transform into view.

## Usage

Add the modal trigger:

```html
<a class="open-modal" href="#morphing-modal">
  Open Modal
</a>
