# CSS Glitch Flicker Navbar

## Overview

A responsive gaming-inspired navigation bar featuring a glitch flicker animation using only HTML and CSS.

## Features

- Pure HTML & CSS
- Responsive layout
- CSS keyframe animations
- CSS custom properties
- Accessible (`prefers-reduced-motion`)
- Easy to customize

## Folder Structure

```text
glitch-flicker-navbar/
├── demo.html
├── style.css
└── README.md
```

## Usage

1. Open `demo.html`.
2. Customize the CSS variables.
3. Integrate the navbar into your project.

## CSS Variables

- `--primary`
- `--background`
- `--text`
- `--duration`

## Browser Support

- Chrome
- Firefox
- Edge
- Safari
