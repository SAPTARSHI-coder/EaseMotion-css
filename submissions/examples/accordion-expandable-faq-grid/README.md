# Accordion Expandable FAQ Grid

A modern, responsive FAQ accordion component with a soft **Neumorphic Finish** and smooth height transitions.

## Features

- Neumorphic UI design
- Responsive two-column FAQ grid
- Mobile-first layout
- Smooth expand and collapse animation
- Dynamic height calculation
- Hover elevation effect
- Accessible accordion buttons
- `aria-expanded` support
- Keyboard-friendly controls
- Reduced-motion support
- Pure HTML, CSS, and JavaScript
- No external dependencies
