# Safety Lamp Flame

## What does this do?
Renders a self-contained CSS-only `ease-safety-lamp-flame` demo: Safety lamp flame testing firedamp.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-safety-lamp-flame`. No build step or JavaScript is required for the effect.

```html
<section class="ease-safety-lamp-flame">
  <div class="ease-safety-lamp-flame__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
