# Fade-In Toast

A lightweight, responsive CSS-only toast notification designed for fintech dashboard layouts.

The component uses a smooth fade-in and upward entrance animation when the page loads.

## Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Smooth fade-in animation
- Responsive across desktop, tablet, and mobile
- Accessible status notification
- Keyboard-friendly close button
- Visible focus state
- `prefers-reduced-motion` support
- Easy to customize
