# Sidebar Lock Cam

## What does this do?
Renders a self-contained CSS-only `ease-sidebar-lock-cam` demo: Sidebar lock cam retracting the fence.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-sidebar-lock-cam`. No build step or JavaScript is required for the effect.

```html
<section class="ease-sidebar-lock-cam">
  <div class="ease-sidebar-lock-cam__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
