# Floating Tab Bar with Pastel Styling

A modern, responsive floating tab bar featuring a soft pastel color
palette, subtle neumorphic depth, and glass-inspired transparency.

## Features

- Floating navigation design
- Soft pastel color palette
- Responsive desktop and mobile layouts
- Glass-like translucent surface
- Neumorphic shadows
- Smooth hover interactions
- Active tab state
- Keyboard focus support
- No external dependencies
- Reduced-motion support

## Technologies

- HTML5
- CSS3
