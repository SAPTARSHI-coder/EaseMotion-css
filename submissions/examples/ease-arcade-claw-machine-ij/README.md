# ease-arcade-claw-machine
A claw crane machine with a swinging claw, a glass prize bin of plush toys, and a coin console that drops a grab every loop.
## Run
Open `demo.html` directly in a browser to watch the claw swing and grab.
## Notes
- The claw sweeps left and right while the magnet pulses red at the grab point.
- The plush prizes wobble and the DROP button pulses in the console.
