# 💎 Geode Crack – Geode Cracks Open to Reveal Crystals

> An interactive geode component where a geode cracks open to reveal sparkling crystals with 5 crystal types (Amethyst, Quartz, Rose, Citrine, Emerald), crack control (0-100%), and particle effects.

---

## 📖 Description

The **Geode Crack** component creates a dramatic geode cracking experience where a geode opens to reveal sparkling crystals. Built with vanilla HTML, CSS, and JavaScript, it features 5 crystal types (Amethyst, Quartz, Rose, Citrine, Emerald), crack control (0-100%), and particle effects for a satisfying experience.

### 🎯 Core Features

- **Geode cracking** – geode cracks open to reveal crystals
- **5 crystal types** – Amethyst, Quartz, Rose, Citrine, Emerald
- **Crack control** – adjust crack from 0-100%
- **Particle effects** – sparkling crystal particles
- **Crystal counter** – tracks number of crystals
- **Interactive controls** – slider, crystal buttons, keyboard shortcuts
- **Responsive design** – adapts to different screen sizes

### ⌨️ Interaction Options

| Method | Action |
|--------|--------|
| **Slider** | Adjust Crack (0-100%) |
| **Buttons** | Crack Open, Reset |
| **Keyboard** | `Space` or `C` – Crack · `R` – Reset |

### ✨ Geode Experience

When cracking:
1. **Geode cracks** – shell splits open
2. **Crack applies** – controls opening progress
3. **Crystals appear** – sparkling crystals emerge
4. **Particles burst** – crystal particles scatter
5. **Status updates** – shows current state

### 💡 Why Use This Component?

- Perfect for treasure reveals, crystal shops, or magical experiences
- Dramatic geode cracking with sparkling crystals
- Self-contained – no external dependencies or frameworks
- Easy to customize (crystals, colors, crack behavior)
- 5 crystal types for variety
- Crack control for customization

### 🛠️ Technologies Used

- **HTML5** – semantic structure with Canvas
- **CSS3** – gradients, backdrop-filter, transforms
- **JavaScript (ES6)** – Canvas API, requestAnimationFrame, particle system

### 🎨 Design Philosophy

This component embodies **EaseMotion CSS's animation-first philosophy** through:

- **Dramatic reveal** – geode cracks open
- **Particle effects** – sparkling crystals
- **Visual feedback** – status updates, counter, controls
- **Magical atmosphere** – crystal colors and glow
- **Human-readable classes** – `.geode-controls`, `.crystal-btn`, `.geode-text`

### 🔧 Customization Options

| Property | Location | Default |
|----------|----------|---------|
| Crystal types | `crystalData` object | 5 types |
| Crack range | `crackSlider` | 0-100% |
| Particle count | `createCrystalParticles()` | 30 |
| Crystal size | `size` | 2-7px |
