# ease-3d-flip-popover-bh

Pure CSS 3D-flip popover for fintech dashboards.

## Features
- 3D flip hover effect
- Popover variants
- Responsive design
- Accessibility support

## Usage
```html
<div class="ease-popover ease-popover-3d-flip">Content</div>
```

## CSS Classes
- `.ease-popover` - Base popover
- `.ease-popover-3d-flip` - 3D flip effect
