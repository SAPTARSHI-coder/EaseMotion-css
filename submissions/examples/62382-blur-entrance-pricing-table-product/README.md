# CSS Blur-Entrance Pricing Table for Product Catalog Layouts

A modern **Blur-Entrance Pricing Table** built entirely with **HTML5 and CSS3**. The layout showcases multiple pricing plans with elegant blur entrance animations, glassmorphism styling, responsive behavior, and accessibility support.

---

## ✨ Features

- Pure HTML5 & CSS3
- Blur Entrance Animation
- Glassmorphism Cards
- Featured Pricing Plan
- Hover Lift Effects
- Fully Responsive
- Modern Product Catalog Pricing UI
- CSS Custom Properties
- No JavaScript Required
- Supports `prefers-reduced-motion`
