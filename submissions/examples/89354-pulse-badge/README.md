# Pulse Badge Component

A live status badge component featuring continuous radiating pulse ring animations.

## Features
- **Radiating Ring Keyframes:** Expanding scale and opacity keyframes on pseudo-elements.
- **Color Variants:** Out-of-the-box support for `success` and `warning` status colors.
- **Zero JavaScript:** Pure CSS animation loop with zero dependencies.

## File Structure
- `demo.html` - Status badge markup layout.
- `style.css` - Pulse ring keyframes and variant styling rules.
