## 📋 Issue Description

### Is your feature request related to a problem?
The `submissions/examples/` directory lacks a **social media feed** example that showcases story circles, post cards, engagement interactions, and user suggestion patterns. Social feeds are among the most common UI patterns and would serve as a highly practical reference.

### Describe the solution you'd like
I would like to add an **Animated Social Media Feed** example that demonstrates:
- **Story circles**: Gradient ring borders with viewed states
- **Post cards**: Text and image posts with engagement actions
- **Like/Save states**: Interactive button states
- **User suggestions**: Follow buttons with mutual connections
- **Trending topics**: Hashtag list with post counts
- **Profile card**: User stats with gradient cover
- **Staggered entrance**: Sequential reveal of feed elements

### Why is this useful?
Social media feeds combine many interactive UI patterns. This example will show developers how to:
1. Build story circles with gradient borders
2. Create post cards with multiple content types
3. Implement like/save button states
4. Design user suggestion components
5. Compose a complete social feed layout with EaseMotion
