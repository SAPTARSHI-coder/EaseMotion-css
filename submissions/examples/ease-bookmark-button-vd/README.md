# Ease Bookmark Button

## What does this do?

A circular bookmark toggle button with an active state, hover effect, and click feedback animation.

---

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<button class="bookmark-button active" aria-label="Bookmark">
    <span class="bookmark-icon">★</span>
</button>
```

### Features

- Bookmark icon
- Active state
- Hover effect
- Click animation
- Responsive sizing
- Lightweight CSS implementation

---

## Why is it useful?

Bookmark buttons are commonly used for saving articles, posts, products, documentation, and other content.

This component provides a simple reusable bookmark control with subtle interaction feedback while following the animation-first philosophy of EaseMotion CSS.
