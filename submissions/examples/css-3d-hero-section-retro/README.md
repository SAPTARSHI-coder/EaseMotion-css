# 3D Hero Section with Retro styling (#78883)

A fully responsive synthwave-inspired 3D hero section featuring continuous perspective background grid distortion, 3D multi-layered text shadow extrusions, and tactile 3D action buttons built using pure CSS.

## Features
- **Semantic Structure:** Accessible HTML5 landmark tags (`<main>`, `<h1>`) with proper focus indicators.
- **Synthwave Perspective Grid:** CSS `perspective()` and `rotateX()` transformations combined with `mask-image` linear gradients.
- **3D Retro Typography:** Layered text shadows combining hot pink and cyan glow offset effects.

## File Hierarchy
- `style.css` - Component variables, perspective grid calculations, text shadow extrusions, and button depth rules.
- `demo.html` - Accessible HTML structure showcasing the hero component.
- `README.md` - Technical specification and architecture overview.
