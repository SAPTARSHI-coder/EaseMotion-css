# ease-shimmer-stepper-bh

CSS Shimmer-Sweep Stepper Component for Gaming Hub Layouts.

## What does this do?
A multi-step progress indicator with a smooth shimmer/sweep animation effect moving through the steps.

## How is it used?
```html
<div class="ease-shimmer-stepper">
  <div class="ease-shimmer-step active">1</div>
  <div class="ease-shimmer-step">2</div>
  <div class="ease-shimmer-step">3</div>
</div>
```

## Features
- Shimmer sweep animation between steps
- Gaming-inspired neon glow effects
- Progress indicator with animated fill
- Step completion states
- Fully responsive
- Reduced motion support

## CSS Custom Properties
- `--ease-shimmer-primary`: Primary accent color
- `--ease-shimmer-secondary`: Secondary accent
- `--ease-shimmer-bg`: Background color
