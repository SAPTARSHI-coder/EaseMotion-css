# Elastic Slide Stepper

A modern pure CSS animated stepper created for **EaseMotion CSS**.

This component demonstrates a glassmorphism inspired step progress UI with elastic slide animations.

## ✨ Features

- Pure HTML & CSS implementation
- Glassmorphism UI design
- Elastic slide animation
- Smooth step transitions
- Animated progress indicator
- Responsive layout
- Lightweight and performant
- No JavaScript dependency
- Accessible motion support
- `prefers-reduced-motion` support
