# Pricing Plan Toggle

A CSS-only pricing selector example with an animated billing toggle, staggered plan cards, and highlighted feature rows.

## Features

- Sliding toggle indicator with hover and focus states.
- Two responsive plan cards with a featured plan treatment.
- Staggered card entrance and feature row reveal animations.
- Reduced-motion support for accessibility.

## Files

- `demo.html` - pricing selector markup with billing buttons and plan cards.
- `style.css` - layout, toggle motion, plan card states, responsive styling, and reduced-motion fallback.

## How to Use

Open `demo.html` in a browser and interact with the billing buttons or plan cards to preview the motion states.
