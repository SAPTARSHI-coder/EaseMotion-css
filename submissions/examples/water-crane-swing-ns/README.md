# Water Crane Swing

## What does this do?
Renders a self-contained CSS-only `ease-water-crane-swing` demo: Water crane swinging over the tender.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-water-crane-swing`. No build step or JavaScript is required for the effect.

```html
<section class="ease-water-crane-swing">
  <div class="ease-water-crane-swing__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
