# CSS Elastic Slide Drawer

A responsive navigation drawer featuring an elastic sliding animation built entirely with HTML and CSS.

## Features

- Pure HTML & CSS
- Elastic slide opening animation
- Responsive design
- Lightweight implementation
- Smooth hover effects
- No JavaScript required
- Supports `prefers-reduced-motion`

## Folder Structure

```
elastic-slide-drawer/
├── demo.html
├── style.css
└── README.md
```

## Usage

Open `demo.html` in any modern browser.

## Customization

Modify the following values inside `style.css`:

- Drawer width
- Animation timing
- Colors
- Border radius
- Typography
- Spacing

## Accessibility

- Keyboard-friendly checkbox toggle
- Responsive layout
- Reduced motion support
