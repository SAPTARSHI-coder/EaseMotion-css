# Neumorphic Smart Home Thermostat Dial Component

## What does this do?
This component renders an interactive soft-UI neumorphic smart home thermostat widget featuring realistic extruding and inset box-shadows, an orbiting indicator dot, and tactile mode selector buttons.

## How is it used?
Include `style.css` in your document and integrate the `.thermostat-card` markup into IoT dashboards, smart home controls, or mobile app interfaces.

## Why is it useful?
- Clean soft neumorphic aesthetic with dual directional light and dark shadows.
- Smooth CSS keyframe orbit animation for status indicators.
- Pure CSS implementation with zero external framework dependencies.
