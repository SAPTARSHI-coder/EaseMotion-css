This contribution adds a Multi-Layer Shadow Effect to the submissions/examples/_multi-layer-shadow-effect directory.

What is included?
demo.html
style.css
README.md

Features
🪄 Multiple shadow layers — combines 5 shadows for realistic depth.
🧊 3D floating appearance — makes the card appear elevated.
🖱️ Hover elevation — card rises when hovered.
🌫️ Soft realistic shadows — different blur and opacity levels create depth.
⚡ Pure CSS — no JavaScript.
🎨 Customizable — adjust offset, blur, spread, and opacity independently.
📱 Responsive design.
