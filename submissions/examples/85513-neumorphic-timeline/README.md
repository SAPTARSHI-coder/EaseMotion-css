# Animated Vertical Timeline — Neumorphism

A responsive vertical timeline component using a soft neumorphic visual style and pure CSS animations.

The design uses raised and inset surfaces, soft shadows, rounded cards, animated timeline markers, and a progress indicator.

## Features

- Neumorphic UI styling
- Animated timeline markers
- Active timeline state
- Progress indicator
- Raised and inset CSS shadows
- Completed, current, and upcoming states
- Smooth hover transitions
- Responsive desktop, tablet, and mobile layouts
- CSS custom properties for theming
- `prefers-reduced-motion` support
- Semantic HTML
- Pure HTML and CSS
- No JavaScript
