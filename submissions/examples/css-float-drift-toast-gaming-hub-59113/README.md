# CSS Float-Drift Toast for Gaming Hub Layouts

A modern **Float-Drift Toast** component built using pure HTML and CSS for gaming dashboards, notifications, achievements, and system alerts.

## Features

* Pure HTML5 & CSS3
* Smooth float-drift animation
* Gaming-inspired notification design
* Multiple toast variants
* Fully responsive
* No JavaScript required
* Lightweight and customizable
* Supports `prefers-reduced-motion`

## Folder Structure

```text
css-float-drift-toast-gaming-hub-59113/
├── demo.html
├── style.css
└── README.md
```

## Usage

1. Open `demo.html` in any modern browser.
2. Edit the toast title, message, and icon.
3. Customize colors using the CSS variables in `:root`.
