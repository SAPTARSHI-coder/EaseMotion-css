# Floating Elevation Navigation

## Overview

Issue #73321 demonstrates a navigation that appears to float above the page through transform and shadow changes.

## Features

- Pure HTML and vanilla CSS
- Transform-based elevation
- Layered shadow depth
- Responsive navigation
- Native keyboard focus
- Reduced-motion support

## Files

- `demo.html` — semantic navigation and content
- `style.css` — elevation effect and responsive rules
- `README.md` — documentation
