# 🔮 Prism Button – Splits Light into Rainbow Colors

> A stunning, prismatic button that splits light into rainbow colors on hover, creating a beautiful, light-refracting effect.

---

## 📖 Description

The **Prism Button** is a stunning UI component that splits light into rainbow colors on hover. When you hover over the button, colorful beams of light burst outward from the center, creating a beautiful prismatic effect that mimics light refracting through a prism. The effect features five rainbow-colored beams that spread in different directions with staggered delays.

The component uses CSS animations with `transform` and `keyframes` to create the spectrum beams. Each beam has a unique color (red, pink, purple, blue, green) and travels in a different direction with a scaling and rotating animation. The button also features a glowing rainbow border and a subtle spinning shine overlay.

Perfect for creative portfolios, tech brands, music apps, and any application where you want to create a stunning, colorful interaction. The Prism Button transforms a simple hover into a beautiful, light-filled experience.
