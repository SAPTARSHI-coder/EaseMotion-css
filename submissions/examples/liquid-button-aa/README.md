# Animated Liquid Button Component

**What does this do?**
Provides a pure CSS interactive button with a fluid, liquid-like background animation on hover.

**How is it used?**
Apply the `.liquid-button` class to an anchor or button tag, and include the inner `span` and `.liquid` div as shown in the demo.

**Why is it useful?**
It leverages CSS border-radius manipulation and infinite keyframe rotations to simulate fluid dynamics without utilizing JavaScript or WebGL, adhering to EaseMotion's CSS-first capabilities.
