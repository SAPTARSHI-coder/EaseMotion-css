# CSS Scale-Hover Pricing Table for Accessible Web Layouts

A modern **Pricing Table** built entirely with **HTML5 and CSS3**. This showcase demonstrates elegant **Scale-Hover** card animations, responsive layouts, glassmorphism styling, and accessibility support without requiring JavaScript.

---

## ✨ Features

- 💳 Modern pricing table
- 📈 Scale-Hover card animation
- ⭐ Featured "Pro" plan
- 💎 Glassmorphism design
- 🌈 Gradient CTA buttons
- 📱 Fully responsive
- ⚡ Pure HTML5 & CSS3
- 🎯 CSS Custom Properties
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

## 🚀 Getting Started

1. Open `demo.html` in any modern browser.
2. Hover over the pricing cards to experience the scale animation.
3. Compare plans and explore the responsive layout.
4. Customize colors, spacing, and animation timing using CSS variables.
