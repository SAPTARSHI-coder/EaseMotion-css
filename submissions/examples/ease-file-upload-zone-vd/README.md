# Ease File Upload Zone

## What does this do?

A styled file upload area with an upload icon, hover interaction, and responsive layout.

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<div class="upload-zone">
    <div class="upload-icon">↑</div>

    <h2>Upload your file</h2>
    <p>Drag and drop your file here or choose a file</p>

    <label class="upload-button">
        Choose File
        <input type="file">
    </label>
</div>
```

### Features

- File upload area
- Upload icon
- File selection control
- Hover animation
- Visual upload state
- Responsive layout
- Pure CSS styling
- No JavaScript required

## Why is it useful?

File upload zones are commonly used for document uploads, profile forms, content management systems, and file management interfaces.

This component provides a clean and reusable upload area with subtle hover and interaction animations while following the animation-first philosophy of EaseMotion CSS.
