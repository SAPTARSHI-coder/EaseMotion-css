# CSS Elastic Slide Tooltip for E-Commerce Checkout Layouts

A sleek, modern pure CSS tooltip component designed specifically for e-commerce checkout layouts. It features an elastic slide-and-scale animation on hover.

## Features
- Pure CSS implementation, zero JavaScript
- Highly customizable and modular
- Elastic bouncy slide-in animation utilizing a custom `cubic-bezier` function
- Responsive and fits into modern dashboard and e-commerce aesthetics
- Easy drop-in integration

## File Structure
- `demo.html` - Contains the HTML structure for the tooltip integrated into an e-commerce checkout context.
- `style.css` - Contains the base styles and the elastic slide tooltip animation logic.

## Usage
Simply copy the HTML structure for `.tooltip-wrapper` and its contents into your project, and include the associated CSS styles for `.tooltip-wrapper`, `.info-icon`, and `.tooltip-content`.
