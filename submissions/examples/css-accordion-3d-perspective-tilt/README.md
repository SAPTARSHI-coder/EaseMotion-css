# CSS Accordion – 3D Perspective Tilt

A responsive, accessible accordion featuring a subtle 3D perspective tilt
interaction using pure HTML and Vanilla CSS.

## Features

- Pure HTML & CSS
- No JavaScript
- Native `<details>` and `<summary>`
- 3D perspective tilt interaction
- Smooth transitions
- Responsive layout
- Dark-mode friendly
- Hardware-accelerated transforms
- Keyboard accessible
- `prefers-reduced-motion` support

## Files

- `demo.html` – Component demonstration
- `style.css` – Accordion styles and 3D effects

## Accessibility

The component uses native disclosure elements for keyboard interaction
and semantic accessibility.

Visible `:focus-visible` styling is included for keyboard users.

Reduced-motion preferences are respected through
`prefers-reduced-motion`.

## Usage

Copy the `<details>` elements from `demo.html` and the corresponding
CSS into your project.

## Browser Support

Designed for modern browsers supporting:

- CSS transforms
- CSS perspective
- CSS custom properties
- CSS Grid
- `<details>` / `<summary>`
