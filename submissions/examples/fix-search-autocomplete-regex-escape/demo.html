SearchAutocomplete RegExp Escape Fix

This example demonstrates how escaping user input before creating a RegExp prevents unexpected matching behavior and reduces the risk of Regular Expression Denial of Service (ReDoS).

Vulnerable Code

const parts = text.split(
    new RegExp(`(${highlight})`, "gi")
);

Safe Implementation

const escapeRegExp = (str) =>
    str.replace(/[.*+?^${}()|[\]\\]/g, "\\$&");

const escapedHighlight = escapeRegExp(highlight);

const parts = text.split(
    new RegExp(`(${escapedHighlight})`, "gi")
);

Benefits

  • Escapes regex metacharacters
  • Prevents regex injection
  • Reduces ReDoS risk
  • Preserves expected search highlighting
