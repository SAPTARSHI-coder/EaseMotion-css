# CSS Scale Hover Drawer

A responsive navigation drawer built with pure HTML and CSS featuring smooth scale-hover interactions.

## Features

- Pure HTML & CSS
- Responsive drawer layout
- Scale hover effect
- No JavaScript required
- Keyboard accessible
- Supports `prefers-reduced-motion`

## Files

```
demo.html
style.css
README.md
```

## Customization

Change drawer width:

```css
.drawer{
    width:240px;
}
```

Change primary color:

```css
.menu-btn{
    background:#2563eb;
}
```

Change hover scale:

```css
transform:scale(1.08);
```
