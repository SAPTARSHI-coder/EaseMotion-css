# Holographic Flicker Button (#73238)

A pure HTML & Vanilla CSS button component featuring a hardware-accelerated Holographic Flicker animation.

## Features
- **Aesthetic:** Holographic sweep gradient with flickering border and shadow effects.
- **Pure CSS:** Zero JavaScript required; uses CSS pseudo-elements and keyframe animations.
- **Performance:** GPU-accelerated using `transform`, `opacity`, and `will-change`.
- **Accessibility:** Supports `:focus-visible` focus rings and `@media (prefers-reduced-motion: reduce)` media queries.
