# Responsive Rating — Neumorphism

A responsive neumorphic rating component built with pure
HTML and CSS for EaseMotion CSS issue #81438.

## Features

- Soft neumorphic visual design
- Interactive 1–5 star rating
- Responsive rating controls
- Smooth hover transitions
- Selected rating state
- Press interaction
- Keyboard focus support
- Responsive desktop, tablet, and mobile layouts
- Reduced-motion support
- No external JavaScript dependencies
