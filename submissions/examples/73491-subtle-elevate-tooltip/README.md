# CSS Tooltip: Subtle Elevate Variation

A smooth, accessible, and lightweight tooltip component featuring a **Subtle Elevate** visual style.

## ✨ Features

- Pure HTML and Vanilla CSS
- No JavaScript or external dependencies
- Smooth elevation effect
- Hover and keyboard focus support
- Top, bottom, left, and right tooltip positions
- Responsive layout
- Dark-mode compatible
- Hardware-friendly CSS transforms
- `aria-describedby` and `role="tooltip"`
- `prefers-reduced-motion` support
