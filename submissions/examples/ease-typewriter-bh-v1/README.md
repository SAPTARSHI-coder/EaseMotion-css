# ease-typewriter-bh

Pure CSS typewriter text reveal animation.

## What does this do?
Provides an animated typewriter effect where text appears character by character, simulating typing.

## How is it used?
```html
<span class="ease-typewriter-bh">Your text here</span>
```

## Why is it useful?
Creates engaging text reveal animations for headlines, captions, and storytelling effects without JavaScript.
