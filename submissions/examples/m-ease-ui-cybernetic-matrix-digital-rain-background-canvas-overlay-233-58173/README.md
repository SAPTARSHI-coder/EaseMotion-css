# Cybernetic Matrix Digital Rain Background Canvas Overlay (Dark Mode Variant)

A modern **Dark Mode Cybernetic Matrix** background featuring animated digital rain, glowing system status cards, and a glassmorphism content panel. Built using pure HTML and CSS.

## ✨ Features

- Pure HTML5 & CSS3
- Animated Matrix digital rain
- Dark mode interface
- Glassmorphism content panel
- Glowing online status indicators
- Responsive layout
- CSS Custom Properties
- `prefers-reduced-motion` support
- No JavaScript required
