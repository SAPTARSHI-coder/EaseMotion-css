ease-native-theme-card

A CSS light-dark() component that flips between light and dark using only the browser's native color resolution engine — no JavaScript, no @media duplication.

CSS Baseline 2024

Native Theme Engine

This card adapts its background, text, borders, and shadows to the active color scheme using the light-dark() CSS function. No JavaScript event listeners — the browser resolves colors natively the moment color-scheme changes on any ancestor element.

How it works

/* 1. Declare color-scheme on the root */ :root { color-scheme: light dark; } /* 2. Checkbox sibling combinator flips the scheme */ .theme-checkbox:checked ~ .ease-theme-wrapper { color-scheme: dark; } /* 3. Card colors adapt automatically — no JS */ .ease-native-theme-card { background: light-dark(#ffffff, #1e293b); color: light-dark(#0f172a, #f8fafc); border: 1px solid light-dark(#e2e8f0, #334155); box-shadow: 0 10px 25px -5px light-dark(rgba(0,0,0,0.1), rgba(0,0,0,0.5)); }
