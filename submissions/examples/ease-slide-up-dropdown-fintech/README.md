# Ease Slide-Up Dropdown – Fintech Dashboard

A lightweight, responsive CSS Slide-Up Dropdown component designed for modern fintech dashboard interfaces.

## Features

- Pure HTML and CSS
- No JavaScript or external frameworks
- Smooth slide-up interaction
- Hover and keyboard focus support
- Animated arrow indicator
- Responsive dashboard layout
- Fintech-inspired visual design
- CSS custom properties for easy customization
- `prefers-reduced-motion` accessibility support
- Works across desktop, tablet, and mobile devices
