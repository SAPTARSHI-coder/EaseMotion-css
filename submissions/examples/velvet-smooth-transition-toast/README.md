# Velvet Smooth Transition Toast

A soft and elegant notification toast inspired by velvet surfaces,
featuring smooth transitions, subtle lighting, and a rich layered
appearance.

## Features

- Velvet-inspired visual styling
- Smooth entrance transition
- Soft ambient background lighting
- Interactive hover transition
- Subtle depth and glow
- Responsive design
- Dark mode support
- Light mode support
- Accessible notification semantics
- Keyboard focus support
- Reduced-motion support
- Pure HTML and Vanilla CSS
- No external dependencies

## Preview

The toast uses layered gradients, soft shadows, translucent surfaces,
and smooth transforms to create a luxurious velvet-inspired interface.
