# Animated Vertical Timeline

A sleek, responsive vertical timeline component built with **EaseMotion CSS**. Perfect for showcasing company history, project roadmaps, or personal career milestones with engaging, directional animations.

## ✨ Features

- **Alternating Layout**: Cards elegantly alternate between the left and right sides of a central vertical line.
- **Directional Entrances**: Left cards use `.ease-slide-left` and right cards use `.ease-slide-right` for a dynamic reveal.
- **Glowing Nodes**: Timeline dots use `.ease-pulse` to create a continuous, eye-catching glowing effect.
- **Staggered Delays**: Uses `.ease-delay-*` classes so the timeline builds itself sequentially, guiding the user's eye.
- **Fully Responsive**: Automatically collapses into a clean, single-column left-aligned layout on mobile devices.
