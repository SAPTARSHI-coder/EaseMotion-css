# Fire Cursor

1. What does this do? It creates a cursor trail where each move emits warm-colored particle sparks with a smooth fade-out effect.
2. How is it used? Open `demo.html` in a browser and move the mouse; click on the page for a burst and hover the button for a smaller burst.
3. Why is it useful? It gives creators a simple, high-impact cursor effect example without JS libraries or external assets, useful for creative portfolio-style interactions.
