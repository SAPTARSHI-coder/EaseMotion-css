# Password Strength Meter Component

Add ease-typing-password-strength-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|--------|
| `--psm-red` | `#ef4444` |
| `--psm-yellow` | `#f59e0b` |
| `--psm-green` | `#10b981` |
| `--psm-radius` | `10px` |

## Note

CSS handles all visuals. Tiny JS updates strength class based on password criteria.
