# Soldering Iron Tip

## What does this do?
Renders a self-contained CSS-only `ease-soldering-iron-tip` demo: Soldering iron tip heating with flux smoke and solder bead.

## How is it used?
Open `demo.html` in a browser. The animated face uses classes like `ease-soldering-iron-tip`, `ease-soldering-iron-tip__arm`, and `ease-soldering-iron-tip__core`. No build step or JavaScript is required for the motion.

```html
<section class="ease-soldering-iron-tip">
  <div class="ease-soldering-iron-tip__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
