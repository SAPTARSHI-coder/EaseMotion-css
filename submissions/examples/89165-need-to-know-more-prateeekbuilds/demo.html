Frequently Asked Questions

Everything you need to know about EaseMotion CSS, contributing workflow, and curated PR guidelines.

EaseMotion CSS is curated by Saptarshi Sadhu. Contributors do not edit the framework's core/ or components/ source directly. Instead, you submit standalone HTML + CSS demos inside submissions/examples/your-feature-name/.

The maintainer reviews each submission, standardizes class names to ease-*, optimizes the CSS, and promotes it to core. This ensures 100% stability, uniform design language, and zero regressions.

  • submissions/examples/ — Standard HTML/CSS demos (contains demo.html, style.css, README.md).
  • submissions/react/ — React component showcases (YourComponent.jsx and README.md).
  • submissions/scss/ — Reusable SCSS mixin partials (_your-mixin.scss and README.md).
  • submissions/docs/ — Documentation showcases and core engine demonstrations.
⚠️ Strict Rule: Never place feature directories directly under submissions/ root. PRs doing so are automatically closed.

When an issue is claimed with /claim, contributors receive an exclusive 24-hour assignment window to submit a working Pull Request. If 24 hours pass without a linked PR, the automated bot unassigns the issue and opens it up for the community.

Additionally, each contributor is limited to a maximum of 25 active concurrent issue assignments to ensure fair opportunities for everyone.

Cubic-Bezier Easing Tokens

EaseMotion uses mathematical spring curves to create natural, responsive motion profiles that simulate real-world momentum and elasticity.

cubic-bezier(0.34, 1.56, 0.64, 1)
--ease-spring cubic-bezier(0.175, 0.885, 0.32, 1.275)
--ease-smooth cubic-bezier(0.16, 1, 0.3, 1)

GPU Compositing & will-change

Never animate top, left, width, or height to prevent costly CPU layout recalculations and repaint cycles.

The `em=""` Syntax Architecture

The v1.2 motion engine tokenizes declarative strings into typed Abstract Syntax Trees for dynamic DOM compilation.

HTML Attribute em="bounce-in dur:400ms delay:100ms"
↓
Compiler AST { name: 'bounce-in', dur: '400ms', delay: '100ms' }
Accessibility WCAG AAA

Reduced Motion Contract

Every animation class must gracefully degrade for users sensitive to vestibular motion disorders.

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
