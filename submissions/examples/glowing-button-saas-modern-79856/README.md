# Glowing Button with SaaS Modern Styling

A modern SaaS-inspired glowing button component built with pure HTML and CSS.

## Features

- SaaS modern design
- Gradient glow effect
- Smooth hover animations
- Responsive layout
- Pure HTML/CSS
- Lightweight implementation

## Files

- demo.html
- style.css

## Usage

Open `demo.html` in your browser.

## Customization

Modify:

- Gradient colors
- Glow intensity
- Border radius
- Typography
- Button size

## Browser Support

- Chrome
- Firefox
- Edge
- Safari
