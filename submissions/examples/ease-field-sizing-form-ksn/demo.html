Browser support

As of 2026, field-sizing: content is supported in Chrome 123+, Edge 123+, and Opera 109+. Safari support is tracked in the WebKit feature tracker. Firefox support is tracked in Bug 1832409. Unsupported browsers simply show fixed default widths — the form remains fully functional.

This submission demonstrates field-sizing: content — a 2024 CSS feature for EaseMotion CSS. All resizing behavior is pure CSS — zero JavaScript required.
