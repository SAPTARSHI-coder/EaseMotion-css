# CSS Rotate-Fade Pricing Table for SaaS Showcase Layouts

A modern **Rotate-Fade Pricing Table** component built using pure HTML5 and CSS3 for SaaS showcase layouts. This component provides animated pricing cards with 3D rotation entrance effects, smooth hover interactions, glassmorphism styling, and responsive behavior.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Smooth rotate-fade entrance animation
* SaaS pricing comparison layout
* Starter, Professional, and Enterprise plans
* Featured pricing card highlight
* Animated pricing badges
* Glassmorphism card design
* Gradient CTA buttons
* Hover scale and elevation effects
* Responsive pricing grid
* CSS Custom Properties for easy customization
* Lightweight keyframe animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. View pricing cards with rotate-fade entrance animations.
3. Customize colors, shadows, spacing, and animations using CSS variables inside `:root`.
