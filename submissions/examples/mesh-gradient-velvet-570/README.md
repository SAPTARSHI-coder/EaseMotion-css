# CSS Mesh Gradient: Velvet Smooth Transition

This component provides a pure CSS, hardware-accelerated mesh gradient with smooth velvet-like color transitions.

## Usage

```html
<div class="mesh-gradient-container">
  <div class="mesh-velvet-gradient">
    <!-- Your content here -->
  </div>
</div>
```

## Why is it useful?

It offers a visually stunning, performant, and dark-mode compatible background solution without relying on JavaScript or external libraries, perfectly aligning with EaseMotion CSS's focus on lightweight, smooth, and accessible animations.
