# Basic Label Value Pair

## What it does

This submission adds a simple CSS-only label and value pair utility for compact metadata rows.

It works well in profile cards, settings summaries, dashboard details, project info panels, account pages, and small content sections.

## How to use it

Add the class to a row containing a label and a value:

```html
<div class="basic-label-value-pair">
  <span>Status</span>
  <strong>Ready for review</strong>
</div>
```

## Why it fits EaseMotion CSS

It fits EaseMotion CSS because it is human-readable, composable, and easy to combine with cards, forms, settings pages, and dashboard panels. The utility solves a common frontend layout need without requiring JavaScript or external libraries.

## Included features

- Label and value alignment
- Muted label styling
- Strong value styling
- Divider support between rows
- Responsive stacked layout on small screens
- Pure HTML and CSS implementation
