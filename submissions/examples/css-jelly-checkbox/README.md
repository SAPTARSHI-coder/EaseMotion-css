# CSS Jelly Checkbox

A custom, interactive checkbox input that squishes, stretches, and snaps back like jelly when clicked.

## Features
- Pure CSS keyframe animations for the "jelly" squish physics
- SVG path drawing animation using `stroke-dashoffset`
- Fully functional hidden `<input type="checkbox">` controlling the state via the `+` sibling selector
