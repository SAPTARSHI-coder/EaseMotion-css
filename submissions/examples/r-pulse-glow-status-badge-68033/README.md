# CSS Pulse Glow Status Badge

A lightweight status badge with a glowing indicator and subtle CSS pulse animation.

## Features

- Pure HTML and CSS
- No JavaScript required
- Multiple status variants
- Animated glow ring
- Responsive layout
- Customizable CSS properties
- `prefers-reduced-motion` support

## Usage

```html
<span class="pulse-badge pulse-badge--success">
  <span class="pulse-badge__indicator" aria-hidden="true"></span>
  Online
</span>
