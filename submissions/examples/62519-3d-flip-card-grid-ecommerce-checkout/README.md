# CSS 3D-Flip Card Grid for E-Commerce Checkout Layouts

A modern **3D-Flip Card Grid** built with pure HTML5 and CSS3 for e-commerce checkout interfaces. Each product card features a smooth 3D flip animation that reveals checkout information and purchase actions.

## Features

* Pure HTML5 & CSS3
* 3D flip card animation
* Glassmorphism card design
* Responsive product grid
* Checkout details on reverse side
* Product badges
* Smooth hover transitions
* CSS Custom Properties
* No JavaScript required
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in a modern browser.
2. Replace product icons with images if needed.
3. Customize colors via the CSS variables in `:root`.
4. Modify pricing, checkout information, and product badges.
5. Integrate into any e-commerce or checkout interface.
