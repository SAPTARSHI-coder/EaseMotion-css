# Ease — Fluid Accordion (ease-fluid-accordion-content-crossfade) — Geethika

What does this do?  
A simple, nestable accordion example that animates height with CSS Grid and fades inner content for a smooth reveal.

How to use
1. Put `demo.html` and `style.css` in the same folder.
2. Open `demo.html` in a browser — it runs without a server.
3. Use the HTML structure shown in `demo.html`. To allow multiple open panels add `data-allow-multiple="true"` to the `.ease-accordion`.

Why this fits EaseMotion CSS  
Lightweight, animation-first example that shows a practical pattern (grid auto-height + content crossfade). Accessible by default (buttons + aria attrs).

Testing & notes
- Tested: Chrome, Firefox.
