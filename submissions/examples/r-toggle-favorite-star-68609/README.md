# CSS Toggle Favorite Star

An interactive favorite star toggle built entirely with HTML
and CSS.

## Features

- Pure CSS toggle
- Gold star fill on selection
- Rotation and pop animation
- Hover interaction
- Keyboard accessible checkbox
- Visible focus state
- Reduced-motion support
- No JavaScript required

## Usage

The hidden checkbox controls the visual state through the
CSS `:checked` selector.

## Accessibility

The checkbox has an accessible label and supports keyboard
interaction without JavaScript.
