# Micro Press 3D

A physical-feeling button that sinks into the page on press and pops back out.

## Features
- Hard-shadow gives a 3D extruded look
- Press pushes the button down
- Shadow flattens as it compresses

## Usage
```html
<button class="mp-btn">PRESS ME</button>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
