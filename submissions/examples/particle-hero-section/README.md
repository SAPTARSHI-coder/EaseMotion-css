# CSS Particle Hero Section

A pure CSS animated particle hero section featuring floating particles, gradient styling, and a modern landing page layout.

## ✨ Features

- Pure CSS particle animation
- No JavaScript dependency
- Responsive hero section
- Modern gradient background
- Animated floating particles
- Accessible structure
- Reduced motion support for better accessibility

## 🚀 Demo

Open `demo.html` in your browser to view the animation.

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Animations
- CSS Gradients
- Media Queries
