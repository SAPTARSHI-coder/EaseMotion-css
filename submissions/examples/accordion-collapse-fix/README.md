# Accordion Collapse Fix

## Description

This example demonstrates an improved accordion layout using semantic HTML (`<details>` and `<summary>`). It provides clean styling, responsive behavior, and a better user experience for expandable content.

## Features

- Semantic HTML
- Responsive layout
- Clean accordion styling
- Smooth visual appearance
- Pure HTML & CSS

## Usage

```html
<details>
    <summary>Section Title</summary>

    <div class="content">
        Accordion content...
    </div>
</details>
```

## Files

- demo.html
- style.css
- README.md

## Note

This example focuses on improving the accordion layout and styling. Automatically closing previously opened sections requires JavaScript or a different interaction pattern, which is outside the scope of a pure CSS submission.
