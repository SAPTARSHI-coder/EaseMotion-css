# Shimmer-Sweep Stepper for Minimalist Tech Layouts

## Overview

A modern pure CSS stepper component designed for minimalist technology interfaces.

This component provides a vertical workflow timeline with smooth shimmer sweep effects, glowing step indicators, and responsive design without using JavaScript.

---

## Features

- ✨ Pure HTML & CSS implementation
- 🌈 Shimmer sweep hover animation
- 🔵 Glowing step indicators
- ⚡ Smooth fade-in transitions
- 📱 Fully responsive layout
- 🚀 Lightweight and framework-free
- ♿ Supports prefers-reduced-motion
