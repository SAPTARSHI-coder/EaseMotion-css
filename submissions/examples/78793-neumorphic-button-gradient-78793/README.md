# Neumorphic Button — Gradient

## Issue

EaseMotion CSS issue #78793.

## Overview

A tactile button combining neumorphic depth with a controlled gradient surface.

## Features

- Raised and pressed states
- Gradient surface
- Visible keyboard focus
- Responsive sizing
- Reduced-motion support

## Usage

Open `demo.html` and reuse `.neo-button` for primary actions. Keep the focus outline when adapting the visual style.

## Accessibility

The control is a native button with a visible focus state and does not depend on hover to communicate its purpose.
