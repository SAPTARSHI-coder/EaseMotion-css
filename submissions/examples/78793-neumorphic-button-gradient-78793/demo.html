Soft Gradient Button

A tactile neumorphic control with a restrained gradient surface, pressed state, and accessible focus ring.

PRIMARY ACTION

Start a new session

The raised surface is created with paired shadows while the gradient supplies a subtle color transition.

Hover, focus, or press a button to see the tactile surface change.

DESIGN NOTES

Tactile without excess

Depth

Paired shadows create a raised surface while the border keeps its edge defined.

Gradient

A subtle gradient adds dimension without reducing text contrast.

Focus

A dedicated focus outline keeps keyboard interaction visible beyond the soft shadows.

USAGE

Keep actions obvious

Neumorphic surfaces work best when the control shape and label remain strong enough to communicate affordance without relying only on shadow depth.
