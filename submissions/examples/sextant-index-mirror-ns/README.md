# Sextant Index Mirror

## What does this do?
Renders a self-contained CSS-only `ease-sextant-index-mirror` demo: Sextant index mirror bringing horizon and star together.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-sextant-index-mirror`. No build step or JavaScript is required for the effect.

```html
<section class="ease-sextant-index-mirror">
  <div class="ease-sextant-index-mirror__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
