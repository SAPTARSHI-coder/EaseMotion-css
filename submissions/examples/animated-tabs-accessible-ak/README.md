\# Accessible Web Jello-Hover Tabs Component (`ease-tabs-accessible-ak`)



An accessible web-styled pure CSS animated tabs component featuring a smooth jello-hover interaction transition built for \*\*EaseMotion CSS\*\*.



\## Features

\- \*\*Jello-Hover Interaction\*\*: Leverages spring-based cubic-bezier scales and subtle rotations for lively accessible tab states.

\- \*\*WCAG \& Focus Standards\*\*: Enhanced focus outlines, high-contrast typography, and strict keyboard navigation support.

\- \*\*Custom CSS Variables\*\*: Control timing parameters and jello easing curves globally via `--tabs-timing` and `--tabs-jello-easing`.

\- \*\*Zero JavaScript Dependencies\*\*: Powered entirely by native CSS classes and custom properties.



\## Quick Usage

1\. Place this folder under:

&#x20;  `submissions/examples/animated-tabs-accessible-ak/`

2\. Open `demo.html` in any browser to review the accessible interactive tabs.
