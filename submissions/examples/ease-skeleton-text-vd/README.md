# Ease Skeleton Text

## What does this do?

An animated skeleton placeholder for text content while data is loading.

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<div class="skeleton skeleton-line"></div>
<div class="skeleton skeleton-line medium"></div>
<div class="skeleton skeleton-line small"></div>
```

### Available sizes

```html
<div class="skeleton skeleton-line large"></div>
<div class="skeleton skeleton-line"></div>
<div class="skeleton skeleton-line medium"></div>
<div class="skeleton skeleton-line small"></div>
```

### Features

- Multiple text widths
- Shimmer animation
- Multiple sizes
- Responsive layout
- Pure CSS
- No JavaScript required

## Why is it useful?

Skeleton text placeholders are commonly used in dashboards, content-heavy applications, articles, profiles, and other interfaces while text data is loading.

This component provides a lightweight loading-state pattern with a smooth shimmer animation while following the animation-first philosophy of EaseMotion CSS.
