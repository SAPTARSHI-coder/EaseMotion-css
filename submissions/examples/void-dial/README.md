# Void Dial

Void Dial is an experimental radial interface component inspired by mysterious scientific instruments and spatial navigation systems.

Instead of behaving like a conventional knob, the component combines multiple independently rotating rings, radial markers, a pointer-controlled aperture, and dynamic coordinate information.

## ✨ Features

- Multi-ring radial interface
- Independently rotating rings
- Pointer-controlled aperture
- Dynamic coordinate readout
- Pointer direction ray
- Radial tick system
- Orbit markers
- Interactive lighting
- Responsive design
- Touch support
- Reduced-motion support
- Dependency-free
- Vanilla JavaScript
