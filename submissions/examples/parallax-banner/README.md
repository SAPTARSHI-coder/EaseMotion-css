# Parallax Banner

A layered hero banner where the background stays pinned while content scrolls over it.

## Features
- background-attachment: fixed creates a true parallax feel
- Glassy hero card floating above the artwork
- Fully responsive banner treatment

## Usage
```html
<div class="pb-banner">
  <div class="pb-hero">
    <h2>Title</h2>
    <a class="pb-cta" href="#">Explore</a>
  </div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
