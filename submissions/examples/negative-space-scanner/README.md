# Negative Space Scanner

Negative Space Scanner is an experimental architectural-style UI component based
on the idea that empty space can be treated as a measurable object.

Instead of scanning visible structures, the component detects the spaces between
them.

A vertical scanning beam follows the user's pointer and activates negative-space
regions as it passes through them.

## ✨ Features

- Interactive scanning beam
- Negative-space detection
- Dynamic void highlighting
- Void labels
- Area calculation
- Detection counter
- Scanner position indicator
- Blueprint-inspired visual system
- Responsive layout
- Touch support
- Pointer Events
- Reduced-motion support
- Dependency-free
- Vanilla JavaScript
