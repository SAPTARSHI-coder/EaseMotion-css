# Animated Datepicker with Material Design Styling

A responsive Material Design-inspired datepicker component built with
semantic HTML and pure CSS for EaseMotion CSS.

## Features

- Pure HTML and CSS
- Zero external JavaScript dependencies
- Material Design-inspired visual language
- Elevated surface/card
- Purple Material-style primary color
- Floating label date input
- Animated focus states
- Animated selected date
- Calendar grid preview
- Month navigation controls
- Ripple-inspired button interaction
- Responsive desktop, tablet, and mobile layouts
- Keyboard-accessible controls
- Native date validation
- `prefers-reduced-motion` support
