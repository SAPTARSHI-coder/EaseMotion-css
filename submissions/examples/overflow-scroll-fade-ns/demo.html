Overflow Scroll Fade

Scrollable container with smooth top and bottom pure CSS gradient edge fades.

  • 1. System Update Complete

    Version 2.4.0 has been deployed. Features include optimized rendering pipelines and enhanced component primitives.

  • 2. Pure CSS Implementation

    Zero JavaScript required. Edge gradients are driven smoothly via composited CSS mask gradients.

  • 3. Accessible Keyboard Navigation

    The container is focusable via Tab navigation, allowing keyboard users to scroll with Arrow keys, Page Up/Down, or Spacebar.

  • 4. Responsive & Fluid

    Adapts seamlessly across mobile viewports, high-density retina displays, and full-screen desktop applications.

  • 5. Custom Scrollbar Styling

    Includes non-intrusive scrollbar thumb styles that complement dark and light theme palettes.

  • 6. High Contrast Mode Support

    Gracefully disables gradient masking under high contrast / forced-colors modes to maintain strict accessibility compliance.
