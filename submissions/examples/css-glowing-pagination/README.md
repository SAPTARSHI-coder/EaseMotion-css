# Glowing Pagination with Material Design (#78898)

An interactive glowing pagination component featuring Material Design styling and smooth focus animations built entirely with pure CSS.

## Features
- **Semantic Markup:** Uses accessible `<nav>` and unordered list semantics with ARIA labels.
- **Pure CSS Styling:** Soft neon box shadows, active gradients, and responsive layout.
- **Responsive Design:** Automatically wraps and adapts across mobile and desktop devices.

## File Hierarchy
- `style.css` - Component variables, glowing box shadows, and state transitions.
- `demo.html` - Semantic structure and accessibility attributes.
- `README.md` - Technical specification and architecture overview.
