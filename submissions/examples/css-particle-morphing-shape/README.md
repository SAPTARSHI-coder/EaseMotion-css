# CSS Particle Effect: Morphing Shape

A smooth pure CSS particle effect featuring organic shapes that continuously morph between different forms.

## Features

- Pure HTML and Vanilla CSS
- No external JavaScript
- Smooth shape morphing using CSS `border-radius`
- Multiple independently animated particles
- Smooth CSS transitions
- Hardware-accelerated transforms
- Responsive across screen sizes
- Dark-mode friendly styling
- Reduced-motion accessibility support

## Files

- `demo.html` — Morphing particle demo
- `style.css` — Particle styling and animations
- `README.md` — Documentation

## Accessibility

The particles are decorative and use `aria-hidden="true"`. The animation respects the user's `prefers-reduced-motion` preference.
