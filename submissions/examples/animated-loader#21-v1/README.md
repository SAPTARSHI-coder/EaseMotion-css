# Animated Loader

A collection of modern animated loaders built with pure HTML and CSS. Includes spinner, dots, bars, and pulse loading animations.

## Features

- Pure HTML and CSS implementation.
- Four loader variants: spinner, dots, bars, pulse.
- Smooth loading animations.
- Modern glassmorphism card layout.
- Responsive grid layout.
- Supports `prefers-reduced-motion`.

## Usage

Copy the HTML structure from `demo.html` and link `style.css`.

```html
<div class="loader spinner" role="status" aria-label="Loading"></div>
