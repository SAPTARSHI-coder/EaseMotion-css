# Skew-Active Creative Portfolio Modal (`#54492`)

## What does this do?
Provides an avant-garde geometric dialog window whose action confirmation buttons tilt into bold parallelogram angles during interaction while keeping typography vertical.

## How is it used?
Organize modal dialog boxes inside an `ease-modal-skew` container:
```html
<div class="ease-modal-skew">
  <div class="body">...</div>
</div>
```

## Why is it useful?
Solves issue #54492 by delivering assertive modernist industrial street fashion aesthetics to creative exhibition popups.
