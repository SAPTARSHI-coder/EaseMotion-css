Grid Auto-Fit vs Auto-Fill

Clarifying the most commonly misunderstood CSS Grid layout bug: why grid items unexpectedly stretch or leave blank whitespace on wide screens.

Auto-Fill (Leaves whitespace)

repeat(auto-fill, minmax(150px, 1fr))

If the screen is wide, the browser "fills" the remaining space with invisible grid tracks, leaving the actual items small and bunched to the left.

Auto-Fit (Stretches perfectly)

repeat(auto-fit, minmax(150px, 1fr))

The browser collapses the empty tracks to 0px, allowing the actual items to stretch and "fit" the entire available width evenly.

How to test this locally:

Resize your browser window so it is very wide. Watch how the items in the Auto-Fill grid stay small and leave empty space on the right, while the items in the Auto-Fit grid expand to take up the full width.
