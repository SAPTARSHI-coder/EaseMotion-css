# CSS Status Page Incident Card

A status-page incident component with severity, timeline, and service information.

## Features

- Severity badge
- Incident summary
- Timeline progression
- Service indicators
- Responsive layout
- Accessible status text
- Reduced-motion support

## Files

- `demo.html` — incident structure and timeline
- `style.css` — severity styling, timeline, responsive layout, and motion

## Accessibility

Status labels are written as text rather than relying on color alone. Interactive elements have visible focus states, and reduced-motion preferences are respected.
