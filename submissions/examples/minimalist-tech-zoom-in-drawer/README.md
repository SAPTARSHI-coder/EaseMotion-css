# Zoom-In Drawer

A lightweight CSS-only drawer interaction for minimalist technology layouts.

## Features

- Pure HTML and CSS
- Smooth zoom-in reveal animation
- Fade and scale transition
- Subtle elevation and glow effect
- Responsive across desktop, tablet, and mobile
- No JavaScript or external dependencies
- Customizable CSS custom properties
- `prefers-reduced-motion` support
