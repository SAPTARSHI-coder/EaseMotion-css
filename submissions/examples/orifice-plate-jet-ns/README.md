# Orifice Plate Jet

## What does this do?
Renders a self-contained CSS-only `ease-orifice-plate-jet` demo: Orifice plate jet pulsing through a metering restriction.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-orifice-plate-jet`. No build step or JavaScript is required for the effect.

```html
<section class="ease-orifice-plate-jet">
  <div class="ease-orifice-plate-jet__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
