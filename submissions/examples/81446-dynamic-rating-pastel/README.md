# Dynamic Rating — Pastel Styling

A responsive and interactive rating component with a soft
pastel visual language, implemented using pure HTML and CSS.

Created for EaseMotion CSS issue #81446.

## Features

- Pastel visual styling
- Five-star rating control
- Native radio-based interaction
- Hover preview
- Selected rating state
- Animated visual feedback
- Soft pastel shadows
- Responsive desktop, tablet and mobile layouts
- Keyboard-accessible rating controls
- Visible focus states
- `prefers-reduced-motion` support
- Zero JavaScript dependencies
