# CSS Tour Package Card

A responsive CSS-only tour package card featuring a destination,
highlights, duration, rating, pricing, and an interactive call-to-action.

## Features

- Pure HTML and CSS
- Responsive tour card layout
- Destination visual with CSS-generated artwork
- Tour duration and rating information
- Highlights list
- Pricing section
- Hover animation
- Keyboard-accessible CTA
- Responsive mobile layout
- Reduced-motion support
- No JavaScript required

## Files

- `demo.html` — Demo structure and content
- `style.css` — Complete component styling

## Usage

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
