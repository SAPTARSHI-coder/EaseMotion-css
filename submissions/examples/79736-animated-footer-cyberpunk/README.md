# Animated Footer — Cyberpunk

A responsive animated footer component with a futuristic
cyberpunk visual style, created using pure HTML and CSS.

Implemented for EaseMotion CSS issue #79736.

## Features

- Cyberpunk-inspired dark interface
- Animated neon top border
- Animated system status indicator
- Futuristic grid background
- Moving scanline effect
- Neon hover interactions
- Responsive footer columns
- Mobile-friendly layout
- Reduced-motion support
- Semantic HTML
- No JavaScript
- No external dependencies
