# Neumorphic Neon Sidebar

A dark-themed sidebar that combines the soft 3D look of Neumorphism with the vibrant glowing accents of a Cyberpunk/Neon aesthetic. 

## How is it used?

Add the `neu-neon-sidebar-80023` class to your `<nav>` element. 
The components include a `.sidebar-header` for the logo, `.nav-links` for the menu items, and a `.sidebar-footer` for actions like logout. 
Menu items use `.nav-item` and `.nav-link` with an `.active` class to denote the current page.

```html
<nav class="neu-neon-sidebar-80023">
    <!-- Header -->
    <div class="sidebar-header">
        <div class="logo-glow">...</div>
        <h2>...</h2>
    </div>
    
    <!-- Links -->
    <ul class="nav-links">
        <li class="nav-item active">
            <a href="#" class="nav-link">...</a>
        </li>
    </ul>
</nav>
```

## Why is it useful?

This component brings a highly requested modern aesthetic, blending two popular design trends (Neumorphism and Neon) into a single, cohesive, and responsive navigation component. It fits perfectly into EaseMotion's philosophy of offering beautiful, modern, and engaging UI elements that are easy to drop into any project.
