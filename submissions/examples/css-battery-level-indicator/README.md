# CSS Battery Level Indicator

## Description

A pure CSS battery indicator component that visually represents different battery charge levels using color-coded fill states. The battery smoothly animates from empty to its designated charge level without requiring JavaScript.

## Features

- Pure CSS implementation
- Animated charging effect
- Low, Medium, and Full battery states
- Responsive design
- Light and dark mode support
- Easy customization using CSS variables
- No JavaScript required

## Usage

### HTML

```html
<div class="battery battery-medium">
    <div class="battery-fill"></div>
</div>
