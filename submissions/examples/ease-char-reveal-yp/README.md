# Character Reveal Animation

A lightweight character-by-character text reveal animation built using HTML, CSS, and JavaScript.

Each character is wrapped individually and animated with a staggered delay, creating a smooth entrance effect suitable for headings, hero sections, banners, and landing pages.

---

## Features

- Character-by-character reveal animation
- Smooth staggered timing
- Pure HTML, CSS, and JavaScript
- Lightweight and easy to customize
- Supports multiple text elements
- Preserves spaces between words

---

## Usage

1. Open `demo.html` in any modern web browser.
2. Add the `char-reveal` class to any text element.

Example:

```html
<h1 class="char-reveal">
    EaseMotion CSS
</h1>
```

Customize the animation using CSS variables:

```css
.char-reveal {
    --duration: 0.6s;
    --delay: 0.06s;
    --distance: 30px;
}
```

---

## Why is it useful?

Character reveal animations help draw attention to important text while providing a polished user experience.

They are commonly used for:

- Hero section headings
- Portfolio websites
- Landing pages
- Product showcases
- Marketing websites
- Animated typography

---

## Browser Support

Works in all modern browsers that support CSS animations and JavaScript.
