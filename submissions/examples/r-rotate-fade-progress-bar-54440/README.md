# CSS Rotate-Fade Progress Bar

A modern **Rotate-Fade Progress Bar** built using pure HTML5 and CSS3 for accessible web layouts. The component features smooth rotate-and-fade progress animations, responsive cards, customizable CSS variables, and accessibility support without requiring JavaScript.

---

## ✨ Features

- Pure HTML5 & CSS3
- Rotate-Fade progress animation
- Responsive progress cards
- Smooth gradient progress indicators
- CSS Custom Properties
- Lightweight and performant
- Accessible design
- `prefers-reduced-motion` support
- No JavaScript required

## 🚀 Usage

1. Copy the component into your project.
2. Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

3. Open `demo.html` in your browser.
