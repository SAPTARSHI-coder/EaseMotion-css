# Interactive UI Card Component

A lightweight, accessible, and responsive card component built with pure HTML5 and CSS3. Designed for easy integration into existing design systems and dark-mode user interfaces.

## 🌟 Features

* **Zero External Dependencies:** Built natively using vanilla HTML and CSS.
* **Fully Responsive:** Adapts seamlessly across mobile, tablet, and desktop viewports.
* **Accessibility First (WCAG 2.1 AA):** Includes explicit focus rings (`:focus-visible`), ARIA landmarks, and `@media (prefers-reduced-motion: reduce)` support.
* **Design Token Support:** Easy theme customization via CSS Custom Properties (`--bg-primary`, `--accent-color`, etc.).
