Accessibility Guidelines

Clear, high-contrast slide-right interfaces designed for maximum readability and usability.

Visual Contrast Standards

All text elements must maintain a minimum contrast ratio of 4.5:1 against their backgrounds for normal text, and 3:1 for large text (WCAG Level AA). For optimal readability, we target WCAG Level AAA at 7:1.

  • Avoid using color as the only visual means of conveying information.
  • Ensure links are clearly identifiable through underlines or thick borders.

Screen Reader Compatibility

Semantic HTML is the foundation of screen reader accessibility. Always use native elements like buttons, navs, and main tags before reaching for ARIA attributes.

  • Provide meaningful alt text for all informative images.
  • Ensure heading levels (h1 through h6) are not skipped.

Robust Keyboard Navigation

Interactive elements must be focusable and operable using only a keyboard. Focus indicators must be highly visible and never suppressed without a valid fallback.

  • Use explicit outline offsets to prevent focus rings from blending into borders.
  • Ensure a logical tab order that follows the visual reading flow.
