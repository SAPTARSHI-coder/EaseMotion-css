# Origami Paper Fold Drawer

A smooth and interactive **Origami Paper Fold Drawer** built using only
HTML and Vanilla CSS.

This component is created for **EaseMotion CSS – Issue #73604**.

## ✨ Features

- Pure HTML and CSS
- No JavaScript required
- Origami-inspired paper fold effect
- Smooth drawer opening and closing animation
- Layered paper fold styling
- Responsive design
- Dark mode support
- Hardware-accelerated transforms
- Accessible labels for drawer controls
- `prefers-reduced-motion` support

## 🎨 Style

**Category:** Drawers & Sidebars

**Style:** Origami Paper Fold

The drawer uses layered CSS elements and 3D transforms to create a
paper-folding visual effect while opening.
