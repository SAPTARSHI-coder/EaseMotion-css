# CSS Particle Field Background

A pure CSS implementation of a drifting particle field background animation using `box-shadow` for performance and minimal HTML markup.

### Usage
```html
<div class="particle-container" aria-hidden="true">
  <div class="particles-layer-1"></div>
  <div class="particles-layer-2"></div>
  <div class="particles-layer-3"></div>
</div>
```

### Why is this useful for EaseMotion CSS
This component expands the library's collection of ready-to-use CSS animations by providing a lightweight, JavaScript-free solution for dynamic particle backgrounds. It is completely responsive, themeable, and easy to implement.
