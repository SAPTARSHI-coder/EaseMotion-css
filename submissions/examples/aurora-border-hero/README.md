# Aurora Border Hero

A hero card wrapped in a rotating conic-gradient aurora that spins beneath a dark border mask.

## Features
- Rotating conic gradient border glow
- Dark card body with soft glass sheen
- Inner headline floats above the light

## Usage
```html
<div class="ab-card"><div class="ab-inner">
  <h2>Launch something beautiful</h2>
</div></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
