# CSS Organic Morphing Blobs

A smooth, fluid background consisting of organic blob shapes that morph and merge perfectly together.

## Features
- Pure CSS fluid mechanics utilizing the classic `filter: blur() contrast()` stacking trick to fuse overlapping shapes seamlessly.
- Organic morphing utilizing continuously animating, multi-point `border-radius` values.
- Complex orbit and scale transformations applying a floating behavior to the underlying nodes.
