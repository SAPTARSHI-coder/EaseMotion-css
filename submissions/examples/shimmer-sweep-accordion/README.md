# Shimmer-Sweep Accordion

A lightweight, responsive CSS-only accordion component designed for
modern fintech dashboard interfaces.

## Features

- Pure HTML and CSS
- No JavaScript required
- Shimmer-sweep hover and focus effect
- Native `<details>` and `<summary>` accordion behavior
- Responsive desktop, tablet, and mobile layout
- CSS custom properties for easy customization
- Smooth CSS keyframe animations
- Accessible reduced-motion support
- Fintech dashboard styling
