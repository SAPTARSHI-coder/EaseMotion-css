# 🎮 3D Flip Gaming Pricing Table

A modern **3D Flip Pricing Table** built with **pure HTML and CSS** for the EaseMotion CSS project. Each pricing card flips smoothly on hover to reveal additional information, creating an engaging experience for gaming websites, esports platforms, and digital subscription services.

---

## ✨ Features

- 🎮 Gaming-inspired pricing table
- 🔄 Smooth 3D flip card animation
- 💎 Glassmorphism design
- ⭐ Featured pricing plan
- 🎨 CSS Custom Properties for easy customization
- 📱 Fully responsive layout
- ♿ Accessibility support with `prefers-reduced-motion`
- 🚫 No JavaScript required

---

## 🚀 Usage

1. Open `demo.html` in any modern web browser.
2. Keep `style.css` in the same directory.
3. Hover over a pricing card to view the back side.
4. Customize colors and spacing using the CSS variables.

---

## 🎨 CSS Custom Properties

```css
:root{
    --bg:#08111f;
    --bg-secondary:#111c34;

    --primary:#7c3aed;
    --secondary:#06b6d4;
    --accent:#22c55e;

    --text:#ffffff;
    --muted:#cbd5e1;

    --glass:rgba(255,255,255,.08);
    --border:rgba(255,255,255,.12);

    --radius:22px;
}
```
