# Elastic Bounce Effect Component

Add ease-elastic-bounce-effect-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|--------|
| `--ebe-accent` | `#6366f1` |
| `--ebe-accent2` | `#ec4899` |
| `--ebe-radius` | `12px` |

## Technique

`cubic-bezier(.34,1.56,.64,1)` creates the spring overshoot — no JS animation needed.
