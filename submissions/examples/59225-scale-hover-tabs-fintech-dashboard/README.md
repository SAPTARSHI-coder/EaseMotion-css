# CSS Scale-Hover Tabs for Fintech Dashboard Layouts

A modern **Scale-Hover Tabs** component built using pure HTML5 and CSS3 for fintech dashboard layouts. This component creates an interactive financial dashboard navigation experience with smooth scaling effects, animated tabs, glassmorphism styling, and responsive design.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Fintech dashboard inspired UI
* Interactive scale-hover tabs
* Active tab highlighting
* Smooth hover transitions
* Gradient tab styling
* Glassmorphism dashboard panels
* Financial analytics cards
* Responsive desktop, tablet, and mobile layouts
* CSS Custom Properties support
* Lightweight animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over dashboard tabs to experience scale and elevation effects.
3. Customize colors, shadows, spacing, and animation values using CSS variables inside `:root`.

## CSS Custom Properties

```css
:root{
  --bg:#f8fafc;
  --surface:rgba(255,255,255,.85);
  --primary:#2563eb;
  --secondary:#06b6d4;
  --accent:#8b5cf6;
  --success:#16a34a;
  --text:#111827;
  --muted:#64748b;
  --shadow:0 30px 80px rgba(37,99,235,.2);
  --radius:30px;
}
```
