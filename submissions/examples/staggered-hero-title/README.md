# Staggered Hero Title

A landing-page headline whose words cascade in one by one with a soft rise.

## Features
- Each word animates with its own delay
- Gradient clip text for the accent word
- Subtle blur-to-sharp focus effect

## Usage
```html
<div class="st-hero">
  <span class="st-word">Build</span>
  <span class="st-word accent">smoother</span>
  <span class="st-word">interfaces.</span>
  <a class="st-cta">Get started</a>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
