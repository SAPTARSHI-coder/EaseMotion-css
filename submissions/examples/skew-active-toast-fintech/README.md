# CSS Skew-Active Toast

A lightweight, responsive fintech notification toast built using pure HTML and CSS.

## Features

- Pure HTML and CSS
- No JavaScript or external frameworks
- Skew-based hover interaction
- Smooth entrance animation
- Staggered toast animations
- Hover light sweep effect
- Success, info and warning variants
- Responsive desktop, tablet and mobile layouts
- Keyboard accessible close controls
- `prefers-reduced-motion` support
- CSS custom properties for easy customization
