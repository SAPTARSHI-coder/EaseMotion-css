# glow-accordion-v6-ak

Pure CSS animated glowing neon border accordion drawer component — no JavaScript required.

## How to use

```html
<div class="ease-accordion-v6">
  <input type="checkbox" id="item1" class="ease-accordion-checkbox-v6" />
  <div class="ease-accordion-item-v6">
    <label for="item1" class="ease-accordion-header-v6">
      <span>Header</span>
      <span class="ease-accordion-icon-v6">▼</span>
    </label>
    <div class="ease-accordion-drawer-v6">
      <div class="ease-accordion-body-v6">Content</div>
    </div>
  </div>
</div>
