# CSS Elastic-Slide Navbar for Product Catalog Layouts

A lightweight, responsive navigation bar featuring a pure CSS
Elastic-Slide animation for product catalog interfaces.

## Features

- Pure HTML and CSS
- No JavaScript or external frameworks
- Elastic sliding navigation indicator
- Smooth hover and focus interactions
- CSS custom properties for animation customization
- Responsive desktop, tablet, and mobile layouts
- Keyboard accessible navigation
- `prefers-reduced-motion` support
- Demo works by opening `demo.html` directly
