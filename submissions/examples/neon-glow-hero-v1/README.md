# CSS Neon Glow Hero

A futuristic, responsive Neon Glow Hero section created using pure HTML5
and vanilla CSS3.

## ✨ Features

- Pure HTML and CSS
- No JavaScript
- No external libraries
- Responsive across desktop, tablet, and mobile
- Neon gradient typography
- Animated glowing background
- CSS grid background
- Neon orbit visual
- Floating core animation
- Interactive CTA buttons
- Keyboard-accessible focus states
- `prefers-reduced-motion` support
- Dark UI optimized for modern interfaces
