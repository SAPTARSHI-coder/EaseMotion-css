# CSS Skew-Active Drawer for Gaming Hub Layouts

A modern **Gaming Hub Dashboard** featuring a **CSS Skew-Active Drawer** built entirely with **HTML5 and CSS3**. The example showcases a stylish sidebar navigation where the active menu item uses a skew transformation, gradient highlight, and smooth transitions to create an engaging navigation experience—without requiring JavaScript.

---

## ✨ Features

- 🎮 Gaming Hub inspired dashboard interface
- 📂 Skew-Active navigation drawer
- ✨ Smooth hover transitions
- 🎨 Gradient active navigation highlight
- ⚡ Pure HTML5 & CSS3 (No JavaScript)
- 📱 Fully responsive across desktop, tablet, and mobile
- 🎯 CSS Custom Properties for easy customization
- ♿ Accessibility support with `prefers-reduced-motion`
- 🚀 Lightweight and performance-friendly

## 🎨 CSS Custom Properties

The project uses CSS variables for easy customization.

```css
:root{
    --bg:#0f172a;
    --drawer:#111827;
    --card:#1e293b;
    --primary:#38bdf8;
    --secondary:#8b5cf6;
    --text:#ffffff;
    --muted:#cbd5e1;
    --radius:18px;
    --transition:.35s ease;
}
```

You can easily modify these variables to match your own branding or theme.
