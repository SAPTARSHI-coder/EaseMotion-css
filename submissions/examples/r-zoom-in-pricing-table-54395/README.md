# CSS Zoom-In Pricing Table

A modern **Zoom-In Pricing Table** built using pure HTML5 and CSS3 for accessible web layouts. The component features smooth zoom-in hover effects, responsive pricing cards, customizable CSS variables, and accessibility support without requiring JavaScript.

---

## ✨ Features

- Pure HTML5 & CSS3
- Zoom-in hover animation
- Responsive pricing table layout
- Featured pricing plan
- Gradient call-to-action buttons
- CSS Custom Properties
- Lightweight and performant
- `prefers-reduced-motion` support
- No JavaScript required

## 🚀 Usage

1. Copy the component into your project.
2. Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

3. Open `demo.html` in any modern browser.
