# Card Border Sweep

A reusable card interaction with a subtle highlight that sweeps around the
card border on hover or keyboard focus.

## What does it do?

The component provides:

- Animated border highlight.
- Directional sweep motion.
- Subtle card lift.
- Hover interaction.
- Keyboard focus interaction.
- Responsive layout.
- Reduced-motion support.
- No JavaScript.
- No external libraries or assets.

## How do I use it?

Add the `ease-border-sweep-card` class to a card:

```html
<article class="ease-border-sweep-card">
  <h3>Featured project</h3>
  <p>Explore this interactive project.</p>
</article>
```
