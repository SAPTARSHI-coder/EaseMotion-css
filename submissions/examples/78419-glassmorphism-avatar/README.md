# Responsive Avatar with Glassmorphism Styling

A responsive avatar component with a modern glassmorphism visual style,
soft gradients, profile information, and status indicators.

## Features

- Glassmorphism avatar cards
- Responsive layout
- Large profile avatar
- Multiple avatar variations
- Online, busy, and away status indicators
- Translucent glass surfaces
- Gradient avatar backgrounds
- Soft ambient glow effects
- Smooth hover interactions
- Keyboard-friendly semantic structure
- Reduced-motion support
- Pure HTML and Vanilla CSS
- No JavaScript or external dependencies

## Files

- `demo.html`
- `style.css`

## Usage

Open `demo.html` directly in a browser.

The initials, names, labels, status indicators, and profile metadata can
be customized to match the application where the component is used.

## Technologies

- HTML5
- Vanilla CSS

## Accessibility

Avatar status indicators include accessible labels through `aria-label`.
The page uses semantic headings and descriptive content.

The component also respects the user's `prefers-reduced-motion` preference.

## Responsive Behavior

Desktop screens use a two-column showcase while smaller screens switch
to a single-column layout. Avatar variations also stack vertically on
narrow mobile screens.
