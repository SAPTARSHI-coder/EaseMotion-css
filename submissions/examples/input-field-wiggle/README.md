
---

## 🚀 Usage
1. Clone or copy the files into your project.
2. Open `demo.html` in your browser.
3. Click inside the input field to see the wiggle animation.

---

## 🛠️ Customization
- **Animation speed** → Adjust `animation: wiggle 0.4s` for faster/slower wiggle.
- **Border colors** → Change `border-color` in `:focus`.
- **Input size** → Modify padding and font-size in `input[type="text"]`.

---

## 📖 Accessibility
- Uses `<label>` linked with `for` attribute for screen readers.
- Keyboard navigation supported.
