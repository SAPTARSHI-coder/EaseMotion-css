# CSS-only Flip Book

A lightweight flip-book animation created entirely with HTML and CSS.

## Features

- Pure CSS animation
- No JavaScript
- Responsive design
- 3D page-flip effect
- Semantic HTML
- Reduced-motion support
- Lightweight implementation

## Files

- `demo.html` - Demo markup
- `style.css` - Flip-book animation and responsive styling

## Usage

Open `demo.html` in any modern browser.

No dependencies or build tools are required.

## Accessibility

The demo uses semantic HTML and includes a descriptive section label.

The animation respects the `prefers-reduced-motion` media query. Users who
prefer reduced motion will see the static version without continuous
animation.

## Browser Support

Works in modern browsers that support:

- CSS 3D transforms
- CSS animations
- CSS custom properties
- `prefers-reduced-motion`
