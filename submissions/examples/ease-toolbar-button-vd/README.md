# Ease Toolbar Button

## What does this do?

A reusable toolbar button with an icon, label, hover animation, and active state.

---

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<button class="toolbar-button">
    <span class="icon">✎</span>
    <span>Edit</span>
</button>
```

### Features

- Icon support
- Text label
- Hover animation
- Active state
- Press animation
- Responsive layout
- Lightweight and reusable

---

## Why is it useful?

Toolbar buttons are commonly used in editors, dashboards, navigation controls, and productivity interfaces.

This component provides a simple and reusable toolbar control with subtle interaction feedback while following the animation-first philosophy of EaseMotion CSS.
