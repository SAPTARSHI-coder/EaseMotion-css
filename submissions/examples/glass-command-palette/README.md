# Glass Command Palette

A modern **CSS-only Glassmorphism Command Palette** built with HTML and CSS.

## Features

- ✨ Glassmorphism UI
- 🎨 Gradient background
- 🔍 Search bar design
- 🚀 Smooth fade-in animation
- 🖱 Hover lift effect
- ⌨ Keyboard shortcut badges
- 📱 Responsive layout
- 💯 Pure HTML & CSS (No JavaScript)

## Folder Structure

```
glass-command-palette/
├── demo.html
├── style.css
└── README.md
```

## Preview

The demo showcases a premium command palette inspired by modern applications like VS Code, GitHub, and Linear. It highlights how CSS animations and glassmorphism can be combined to create an elegant user interface without JavaScript.

## Usage

1. Open `demo.html` in your browser.
2. Ensure `style.css` is in the same directory.
3. No installation or dependencies are required.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Animations
- Glassmorphism
- Responsive Design
