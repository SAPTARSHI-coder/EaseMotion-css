# Skew Active Hero Section

A modern pure CSS animated hero section created for **EaseMotion CSS**.

This component demonstrates a minimalist tech layout with skew-based active animation and glassmorphism design.

## ✨ Features

- Pure HTML & CSS implementation
- Minimalist technology hero layout
- Skew active animation
- Glassmorphism card design
- Smooth CSS transitions
- Responsive layout
- Lightweight and performant
- No JavaScript dependency
- `prefers-reduced-motion` support
