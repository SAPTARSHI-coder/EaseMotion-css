# Quantum Energy Shield Navigation

A futuristic responsive navigation component inspired by **Quantum Energy Shield** styling, built entirely with HTML and Vanilla CSS.

## ✨ Features

- Futuristic quantum-energy visual style
- Shield-inspired navigation controls
- Glowing energy accents
- Orbital shield animations
- Active and hover navigation states
- Responsive CSS-only mobile menu
- Dark-mode compatible
- Light-mode compatible
- Keyboard-friendly interactions
- Visible `:focus-visible` states
- Reduced-motion support
- No JavaScript
- No external dependencies
