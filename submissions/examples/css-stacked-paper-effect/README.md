# CSS Stacked Paper Effect

A text container that visually mimics a messy stack of physical paper documents using intricate layered `box-shadow` and slight `rotate` offset angles.

## Features
- Deep layering achieved by placing `::before` and `::after` pseudo-elements behind the main container using `z-index: -1` and `-2`.
- Realistic paper textures simulated using subtle `inset` box shadows.
- Interactive hover effect that expands the stack slightly by amplifying the `rotate` and `translate` offsets.
