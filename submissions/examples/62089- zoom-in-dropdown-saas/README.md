# CSS Zoom-In Dropdown for SaaS Showcase Layouts

A modern **Zoom-In Dropdown Navigation** built with pure HTML and CSS for the EaseMotion CSS library. The dropdown uses smooth zoom animations, glassmorphism styling, responsive layouts, and accessibility-friendly interactions without any JavaScript.

---

## Features

- Pure HTML5 & CSS3
- Zoom-in dropdown animation
- Glassmorphism dropdown menu
- Smooth hover interactions
- Responsive navigation
- Animated CTA button
- CSS Custom Properties
- `prefers-reduced-motion` support
- No JavaScript required
