# Holographic Iridescent Pricing Table

## 1. What does this do?
The Holographic Iridescent Pricing Table component creates SaaS subscription pricing cards featuring animated iridescent gradient borders, featured plan highlights, floating badges, and interactive tier elevation states.

## 2. How is it used?
Link `style.css` in your HTML page and implement the `.pricing-grid` markup structure with optional `.featured` modifier classes.

## 3. Why is it useful?
Provides high-converting pricing page designs for SaaS platforms, cloud software products, developer tooling subscriptions, and membership portals.
