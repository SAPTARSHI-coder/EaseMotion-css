# Dynamic Tab Bar — Gradient

A responsive dynamic tab bar with modern gradient styling,
smooth hover transitions, and accessible navigation for
EaseMotion CSS.

Implemented for issue #79721.

## Features

- Gradient active tab
- Smooth hover elevation
- Gradient hover overlay
- Responsive horizontal scrolling
- Icon-supported tab labels
- Accessible navigation structure
- Keyboard focus states
- CSS-only implementation
- No JavaScript
- No external dependencies
- Reduced-motion support
