# Horizontal Scroll Edge Peek Hint

## What does this do?

A horizontal scroller with edge fade masks, snap, and a bouncing peek hint.

## How is it used?

```html
<div class="peek-row"><div class="peek-row__scroller">...</div></div>
```

Open `demo.html` in a browser to try it.

## Why is it useful?

Teaches overflow without clutter for carousel-style rows.
