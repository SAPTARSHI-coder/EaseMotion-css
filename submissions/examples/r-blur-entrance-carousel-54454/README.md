# CSS Blur-Entrance Carousel

A modern **Blur-Entrance Carousel** built using pure HTML5 and CSS3 for creative portfolio layouts. The component features elegant blur-to-focus entrance animations, responsive portfolio cards, and accessible interactions without requiring JavaScript.

---

## ✨ Features

- Pure HTML5 & CSS3
- Blur-to-focus entrance animation
- Smooth staggered card reveal
- Responsive carousel layout
- CSS Custom Properties
- Lightweight and performant
- Accessible design
- `prefers-reduced-motion` support
- No JavaScript required

## 🚀 Usage

1. Copy the component into your project.
2. Link the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

3. Open `demo.html` in your preferred browser.
