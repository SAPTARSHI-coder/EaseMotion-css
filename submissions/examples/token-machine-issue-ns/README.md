# Token Machine Issue

## What does this do?
Renders a self-contained CSS-only `ease-token-machine-issue` demo: Single-line token machine issuing the staff.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-token-machine-issue`. No build step or JavaScript is required for the effect.

```html
<section class="ease-token-machine-issue">
  <div class="ease-token-machine-issue__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
