# Leyden Jar Spark

## What does this do?
Renders a self-contained CSS-only `ease-leyden-jar-spark` demo: Leyden jar charging then discharging a bright spark.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-leyden-jar-spark`. No build step or JavaScript is required for the effect.

```html
<section class="ease-leyden-jar-spark">
  <div class="ease-leyden-jar-spark__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
