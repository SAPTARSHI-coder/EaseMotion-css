# Interactive Price Comparison Card Tier Switcher Component (Neumorphic Finish)

1. **What does this do?** 
   An advanced Neumorphic pricing table showcasing a modern "soft UI" aesthetic. It features an extruded/inset shadow design, a smooth animated billing cycle switcher (monthly/annually), and state-of-the-art interactive feedback on buttons and lists.

2. **How is it used?** 
   Simply serve or open the `demo.html` in your browser. The file relies entirely on `style.css` (using robust CSS variables for easy theming) and contains lightweight inline Javascript just to handle the toggle switch logic and smooth number transitions. No external libraries are needed.

3. **Why is it useful?** 
   It demonstrates how advanced design trends like Neumorphism can be cleanly implemented while maintaining fluid, animation-first principles. It handles complex box-shadow transitions natively in CSS without sacrificing performance, perfectly aligning with EaseMotion's zero-dependency vision.
