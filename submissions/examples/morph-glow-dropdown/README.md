# Morph-Glow Dropdown for Product Catalog Layouts

A modern animated dropdown component created with pure HTML and CSS.

This component provides a smooth morphing effect with glowing glassmorphism styling, suitable for product catalogs and modern UI layouts.

## ✨ Features

- Pure HTML and CSS implementation
- Morphing border animation
- Glow shadow effects
- Glassmorphism dropdown panel
- Smooth hover interactions
- Responsive design
- No JavaScript required
- Accessible motion support
