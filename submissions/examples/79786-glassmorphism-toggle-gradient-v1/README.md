# Glassmorphism Toggle with Gradient

A modern and fully responsive toggle component featuring a glassmorphism
interface and vibrant gradient styling.

## Features

- Glassmorphism UI
- Gradient active state
- Smooth toggle animation
- Responsive design
- Accessible native checkbox
- Keyboard focus support
- Status text updates
- Decorative background glow
- Backdrop blur effects
- Reduced-motion support
- No external dependencies

## Technologies

- HTML5
- CSS3
- JavaScript
