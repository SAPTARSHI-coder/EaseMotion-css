# Magnetic Field Notes

Magnetic Field Notes is an experimental notebook-style UI component where text behaves like a collection of magnetic objects.

A virtual magnetic field follows the user's pointer and influences nearby notes.

The field can be switched between positive and negative polarity, changing how the notes respond.

## ✨ Features

- Physics-inspired note interaction
- Magnetic attraction
- Magnetic repulsion
- Per-note magnetic strength
- Per-note magnetic charge
- Dynamic field lines
- Interactive polarity switch
- Field strength indicator
- Responsive design
- Touch support
- Pointer Events
- Keyboard accessibility
- Reduced-motion support
- Dependency-free
- Vanilla JavaScript
