# Schlieren Shock Ripple

## What does this do?
Renders a self-contained CSS-only `ease-schlieren-shock-ripple` demo: Schlieren shock ripples shearing through density gradients.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-schlieren-shock-ripple`. No build step or JavaScript is required for the effect.

```html
<section class="ease-schlieren-shock-ripple">
  <div class="ease-schlieren-shock-ripple__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
