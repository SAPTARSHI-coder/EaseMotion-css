# Retro Nixie Tube Clock

## 1. What does this do?
This contribution provides a Retro Nixie Tube Digital Clock display component. It features neon cathode wire filament digits, glass tube enclosures, mesh grid overlays, filament micro-flicker animations, and blinking colon separators.

## 2. How is it used?
Include `style.css` in your HTML and structure your digit tubes within `.clock-display`.

```html
<link rel="stylesheet" href="style.css">

<div class="clock-display">
  <div class="nixie-tube">
    <span class="digit">1</span>
    <span class="grid-overlay"></span>
  </div>
</div>
```

## 3. Why is it useful?
It provides a vintage steampunk and retro-tech aesthetic for digital dashboards, countdown timers, event landing pages, and interactive web projects.
