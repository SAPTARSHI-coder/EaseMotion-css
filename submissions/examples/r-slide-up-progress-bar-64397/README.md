# CSS Slide-Up Progress Bar

A responsive glassmorphism progress bar component with a smooth slide-up
entrance effect for modern UI layouts.

## Features

- Pure HTML and CSS
- No JavaScript dependencies
- Glassmorphism visual style
- Smooth slide-up animation
- Animated progress fills
- Responsive across desktop, tablet, and mobile
- Accessible progressbar semantics
- `prefers-reduced-motion` support
