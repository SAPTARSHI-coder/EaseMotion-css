# CSS Particle Effect: Holographic Flicker

A smooth and accessible pure CSS particle effect featuring colorful holographic particles with subtle flickering motion.

## Features

- Pure HTML and Vanilla CSS
- No external JavaScript
- Multiple floating particles
- Holographic color gradients
- Subtle flicker and glow animation
- Smooth CSS transitions
- Hardware-accelerated transforms
- Responsive design
- Reduced-motion accessibility support

## Files

- `demo.html` — Particle effect demo
- `style.css` — Styles and animations
- `README.md` — Documentation

## Accessibility

Decorative particles use `aria-hidden="true"` and animations respect the user's `prefers-reduced-motion` preference.
