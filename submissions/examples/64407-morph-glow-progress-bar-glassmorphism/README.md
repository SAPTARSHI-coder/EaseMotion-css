# Morph-Glow Progress Bar for Glassmorphism UI Layouts

## Overview

The **Morph-Glow Progress Bar** is a modern CSS-only animated progress component designed for glassmorphism and futuristic tech interfaces.

It uses pure HTML and CSS with smooth glow animations, blur effects, and responsive layouts without requiring JavaScript.

---

## Features

- ✨ Glassmorphism inspired UI
- 🌈 Morphing glow animation effect
- ⚡ Pure HTML & CSS implementation
- 📱 Fully responsive design
- 🎨 Customizable CSS variables
- ♿ Supports `prefers-reduced-motion`
- 🚀 Lightweight and performance friendly
