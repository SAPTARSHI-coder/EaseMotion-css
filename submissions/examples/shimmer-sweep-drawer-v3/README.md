# Shimmer-Sweep Drawer

A lightweight CSS-only Shimmer-Sweep Drawer designed for e-commerce checkout layouts.

## Features

- Pure HTML and CSS
- No JavaScript or external frameworks
- Smooth diagonal shimmer-sweep animation
- Responsive desktop, tablet, and mobile layout
- CSS custom properties for easy customization
- Accessible form controls
- `prefers-reduced-motion` support
- Modern checkout/payment interface
- Lightweight and performant
