# Glowing Breadcrumb with Glassmorphism Styling

A responsive breadcrumb component that combines glassmorphism,
soft neon glow, and smooth hover interactions.

Built with HTML and CSS.

## Features

- Fully responsive breadcrumb
- Glassmorphism container
- Frosted glass effect
- Neon cyan and violet glow
- Interactive hover states
- Current-page styling
- Responsive horizontal scrolling on small screens
- Keyboard focus states
- Reduced-motion accessibility support
- No JavaScript dependency

## Files

- `demo.html` — component markup
- `style.css` — complete component styling

## Usage

Copy the breadcrumb markup from `demo.html` and include
`style.css` in your project.

The component uses semantic navigation markup:

```html
<nav aria-label="Breadcrumb">
  ...
</nav>
