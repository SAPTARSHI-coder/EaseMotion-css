# CSS Isometric Social Icons

A set of social media icons that rest flat, but pop up into vibrant 3D isometric blocks with layered shadow depths upon hovering.

## Features
- Isometric grid projection achieved by applying `rotate(-25deg) skew(25deg)` to the main container.
- Authentic 3D depth created using `::before` and `::after` pseudo-elements skewed along the X and Y axes.
- Dynamic color application and realistic lighting simulated using CSS variables and `filter: brightness()`.
