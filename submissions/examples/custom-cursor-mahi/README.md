# 🖱️ Interactive Custom Cursor Showcase

Welcome to the **Custom Cursor Showcase**—a sleek, modern component built for **EaseMotion CSS** that brings your web pages to life with dynamic, interactive pointer animations using pure CSS and vanilla JavaScript.

---

## ✨ Features & Cursor Styles

Easily switch between different cursor behaviors directly from the interactive control panel:

* 🟢 **Default**: Restores the native system pointer for standard browsing.
* 💫 **Glow**: Implements a vibrant neon aura ring with a glowing core point.
* ☄️ **Trail**: Creates a smooth, multi-particle comet stream that follows your movements.
* 🎯 **Target**: Displays a precision crosshair ring with a center dot for gaming or technical UIs.
* 🪐 **Orbit**: Features animated satellite dots spinning in a continuous orbit around the cursor.
