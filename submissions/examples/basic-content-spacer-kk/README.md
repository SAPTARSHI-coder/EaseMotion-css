# Basic Content Spacer

## What it does

This submission creates a simple CSS-only content spacer utility for adding consistent vertical gaps between grouped content sections.

## How to use it

Place the spacer element between content groups:

```html
<div class="basic-content-spacer"></div>
```

## Why it fits EaseMotion CSS

It fits EaseMotion CSS because it is human-readable, composable, and useful across many interfaces. It works well between cards, text groups, forms, settings sections, and compact content layouts.

## Included features

- Basic vertical spacer utility
- Smaller spacer variation in the demo
- Practical grouped-content example
- Responsive demo layout
- Pure HTML and CSS implementation

## Files

- `demo.html` - self-contained demo that opens directly in a browser
