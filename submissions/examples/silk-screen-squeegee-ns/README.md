# Silk Screen Squeegee

## What does this do?
Renders a self-contained CSS-only `ease-silk-screen-squeegee` demo: Silk screen squeegee pushing ink through mesh.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-silk-screen-squeegee`. No build step or JavaScript is required for the effect.

```html
<section class="ease-silk-screen-squeegee">
  <div class="ease-silk-screen-squeegee__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
