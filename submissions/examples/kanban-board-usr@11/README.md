# Interactive Kanban Board Submission

## 1. What does this do?
It provides a fully interactive Kanban board / task management board with drag-and-drop functionality, task cards with priority levels, categories, due dates, and smooth animations. Perfect for project management tools like Trello, Jira, and Asana.

## 2. How is it used?
The board consists of multiple columns (To Do, In Progress, In Review, Done) with draggable task cards. Users can drag tasks between columns to update their status. Click "Add New Task" to create new tasks with title, description, priority, category, and due date.

## 3. Why is it useful?
- Essential component for project management and task tracking
- Smooth drag-and-drop functionality with visual feedback
- Priority level indicators (high, medium, low) with color coding
- Task categories with color-coded tags
- Due date tracking
- Task assignment with avatar display
- Completed task styling with strikethrough
- Add new task modal with form validation
- Smooth animations and hover effects throughout
- Fully accessible with keyboard support (Escape to close modal)
- Includes `prefers-reduced-motion` support for accessibility
- Mobile-responsive design
- Easy to customize columns, priorities, and categories
- Maintainer can easily standardize this as `.ease-kanban-[YOUR_INITIALS]` in the core library.
