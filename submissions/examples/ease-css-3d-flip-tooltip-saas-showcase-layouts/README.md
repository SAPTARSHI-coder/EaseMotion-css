# CSS 3D-Flip Tooltip for SaaS Showcase Layouts

A modern SaaS-style tooltip component featuring a smooth 3D flip animation built completely with pure HTML and CSS.

This component is designed for SaaS dashboards, product showcases, and landing pages where interactive animated content is required without JavaScript.


## ✨ Features

- 🔄 Smooth 3D flip tooltip animation
- 🚀 Modern SaaS showcase card design
- 🎨 Glassmorphism inspired interface
- ⚡ Pure HTML and CSS implementation
- 📱 Fully responsive layout
- 🌀 CSS transform and perspective effects
- ♿ prefers-reduced-motion accessibility support
- 🚀 Lightweight and framework-free

## 🚀 Usage

1. Open `demo.html` directly in your browser.

2. Hover over the card to trigger the 3D flip animation.

3. Customize CSS variables inside `style.css` according to your brand.


## 🎨 CSS Custom Properties

The component uses CSS variables for easy customization:

```css
:root {

    --bg:#020617;
    --primary:#38bdf8;
    --secondary:#8b5cf6;
    --card:#0f172a;
    --text:#f8fafc;
    --muted:#94a3b8;

}

Update these values to create your own theme.
