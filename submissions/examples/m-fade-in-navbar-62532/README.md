# CSS Fade-In Navbar for E-Commerce Checkout Layouts

A modern **Fade-In Navbar** built using pure HTML and CSS. The navigation bar features a smooth fade-in entrance animation, premium glassmorphism styling, responsive layouts, and lightweight interactions suitable for e-commerce checkout pages.

## ✨ Features

- Pure HTML5 & CSS3
- Fade-in entrance animation
- Glassmorphism navbar
- Responsive checkout layout
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
