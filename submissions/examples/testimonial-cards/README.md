# Testimonial Cards

A responsive testimonial card component with a smooth slide and fade transition.

## Features

- Pure HTML and CSS
- Slide and fade entrance animation
- Responsive layout
- CSS custom properties
- No JavaScript required
- Reduced-motion support
- Easy to customize

## Files

- `demo.html` - Demo page
- `style.css` - Component styles and animations

## Usage

```html
<article class="testimonial-card">
  <div class="avatar">A</div>

  <div class="content">
    <p class="quote">
      "This is a testimonial."
    </p>

    <h2>Alex Johnson</h2>
    <span>Frontend Developer</span>
  </div>
</article>
