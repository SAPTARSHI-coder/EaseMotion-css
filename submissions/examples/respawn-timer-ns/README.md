# CSS Respawn Timer (#70991)

A circular countdown timer component showing respawn seconds using pure SVG stroke animations and CSS steps.

## Features
- Pure CSS circular stroke-dashoffset countdown animation.
- Synchronized pseudo-element number swapping via `steps(10, end)`.
- Fully responsive layout with glowing aura effects.
- Built-in accessibility support (`role="timer"`, `aria-live="polite"`, and `prefers-reduced-motion` safety overrides).
