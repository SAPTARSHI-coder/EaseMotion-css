# CSS Retro CRT Screen Effect

A pure CSS retro CRT display with scanlines, phosphor glow, screen curvature, noise texture, and terminal styling.

## Files

- `demo.html` — semantic monitor demo
- `style.css` — visual effects, animation, responsiveness, and reduced-motion rules

## Usage

Open `demo.html` in a modern browser. No JavaScript or dependencies are required.

## Accessibility

The screen is keyboard focusable, uses semantic content, and respects `prefers-reduced-motion`.
