# Responsive Hero Section — Material Design

A responsive Material Design inspired hero section created for
EaseMotion CSS.

The component combines Material-style elevated surfaces,
clear visual hierarchy, responsive layout, meaningful motion,
and accessible CSS interactions.

## Features

- Material Design inspired visual system
- Responsive hero layout
- Elevated dashboard preview
- Material-style navigation
- Primary pill-shaped CTA
- Secondary text action
- CSS ripple-inspired CTA interaction
- Floating notification card
- Floating productivity metric
- Dashboard statistics
- Project progress indicator
- Team avatar stack
- Quick action controls
- Animated decorative shapes
- Hover elevation effects
- Responsive mobile dashboard
- CSS custom properties/design tokens
- Keyboard focus states
- `prefers-reduced-motion` support
- Zero external JavaScript dependencies
- No external assets required
