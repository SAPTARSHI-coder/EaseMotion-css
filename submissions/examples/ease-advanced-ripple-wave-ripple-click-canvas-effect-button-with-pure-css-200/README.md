# Ripple Wave Ripple Click Canvas Effect Button

## Overview

A modern interactive ripple wave button component inspired by
canvas click effects, built using pure CSS animations and JavaScript.

The component creates a smooth expanding ripple effect from the
exact point where the user clicks.

## Features

- 🌊 Dynamic click ripple animation
- ⚡ Pure CSS keyframe effects
- 🎨 Gradient glassmorphism style
- 📱 Mobile-first responsive design
- 🖱️ Cursor position based ripple origin
- ✨ Smooth hover elevation
- ♿ Reduced motion accessibility support
