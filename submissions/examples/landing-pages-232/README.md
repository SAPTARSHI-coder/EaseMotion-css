# 3D Rotating Cube Navigation Menu

A compact mobile-first 3D rotating cube navigation component created
with pure HTML, CSS and JavaScript.

## Features

- Interactive 3D cube navigation
- Six navigation faces
- Smooth CSS 3D transforms
- Neumorphic-style controls
- Gradient and glow effects
- Responsive mobile layout
- No external dependencies
- Reduced-motion support
