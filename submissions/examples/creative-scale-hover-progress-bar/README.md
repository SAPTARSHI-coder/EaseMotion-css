# CSS Scale-Hover Progress Bar for Creative Portfolio Layouts

A modern **Creative Portfolio Progress Bar** featuring elegant **Scale-Hover** interactions built entirely with **HTML5 and CSS3**. This example showcases animated progress indicators with glassmorphism styling, smooth scaling effects, responsive layouts, and accessibility support—without requiring JavaScript.

---

## ✨ Features

- 🎨 Creative Portfolio inspired design
- 📈 Scale-Hover progress bar animation
- 🌈 Gradient animated progress fills
- 🪟 Glassmorphism card layout
- ⚡ Pure HTML5 & CSS3 (No JavaScript)
- 📱 Fully responsive
- 🎯 CSS Custom Properties
- ♿ Accessibility support with `prefers-reduced-motion`
- 🚀 Lightweight and easy to customize

## 🚀 Getting Started

1. Open `demo.html` in any modern browser.
2. Hover over the progress bars to see the Scale-Hover effect.
3. Customize colors, spacing, and animation timing using the CSS variables.
