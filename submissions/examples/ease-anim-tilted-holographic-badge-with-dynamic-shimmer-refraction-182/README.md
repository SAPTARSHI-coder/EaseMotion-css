# Tilted Holographic Badge with Dynamic Shimmer Refraction

### Vibrant Gradient Version

A modern holographic badge built with **HTML5** and **CSS3** featuring a vibrant gradient finish, animated shimmer refraction, smooth hover interactions, and responsive design.

---

## ✨ Features

- Vibrant holographic gradient
- Dynamic shimmer animation
- Tilted premium badge
- Smooth hover effects
- Responsive layout
- CSS Variables
- Mobile-first design
- `prefers-reduced-motion` support
- Pure HTML & CSS
