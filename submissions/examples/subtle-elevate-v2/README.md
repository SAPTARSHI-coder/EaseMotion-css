# Subtle Elevate - CSS 3D Effect

A smooth and accessible 3D elevation effect built using pure HTML and CSS.

## ✨ Features

- Pure HTML and Vanilla CSS
- Smooth 3D elevation effect
- Hardware-accelerated transforms
- Keyboard accessible
- Dark mode support
- Reduced-motion support
- Responsive design
- No JavaScript
- No external dependencies

## 🎨 Effect

The card gently moves upward and slightly forward when hovered or focused, creating a subtle 3D elevation effect.

## 🛠️ Technologies

- HTML5
- CSS3
- CSS Transforms
- CSS Transitions
- CSS Media Queries

## 🚀 Usage

Open `index.html` in a modern browser.

No installation or build process is required.

## ♿ Accessibility

The component supports:

- Keyboard focus
- Visible focus indication
- `prefers-reduced-motion`
- Semantic HTML
- Responsive layouts
