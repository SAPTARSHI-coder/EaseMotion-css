# CSS Pinterest Grid v2 (#70957)

A robust, modern Pinterest-style variable-height masonry grid component v2 built using native CSS columns and responsive breakpoints without any JavaScript dependencies.

## Features
- Pure CSS multi-column masonry layout (`column-count` and `break-inside: avoid`).
- Fluid responsive reflow across desktop, tablet, and mobile displays.
- Sleek hover elevation cards with custom action buttons.
- Fully accessible layout structure with reduced motion safety overrides.
