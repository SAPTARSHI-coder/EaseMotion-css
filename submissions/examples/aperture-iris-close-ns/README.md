# Aperture Iris Close

## What does this do?
Renders a self-contained CSS-only `ease-aperture-iris-close` demo: Camera iris aperture blades closing to a pinpoint.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-aperture-iris-close`. No build step or JavaScript is required for the effect.

```html
<section class="ease-aperture-iris-close">
  <div class="ease-aperture-iris-close__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
