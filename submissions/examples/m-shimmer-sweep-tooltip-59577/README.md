# CSS Shimmer-Sweep Tooltip for SaaS Showcase Layouts

A modern **Shimmer-Sweep Tooltip** component built using pure HTML and CSS. The tooltip features a shimmering light sweep animation combined with glassmorphism styling for modern SaaS dashboards and landing pages.

## ✨ Features

- Pure HTML5 & CSS3
- Shimmer sweep animation
- Glassmorphism tooltip
- Responsive layout
- Smooth hover transitions
- CSS Custom Properties
- `prefers-reduced-motion` support
- No JavaScript required
