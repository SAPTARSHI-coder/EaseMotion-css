# Shimmering Metallic Foil Text Effect

A neumorphic shimmering metallic foil text effect created using
HTML and CSS.

## Features

- Metallic foil gradient
- Smooth shimmer animation
- Neumorphic card design
- Responsive layout
- CSS-only animation
- No external libraries
- Reduced-motion support

## Files

- `demo.html` - Demo page
- `style.css` - Component styles and animation

## Usage

Open `demo.html` in any modern browser.

To reuse the effect, copy the `.metallic-text` styles
and the related `@keyframes` animation into your project.

## Technologies

- HTML5
- CSS3
- CSS Gradients
- CSS Animations
- Responsive CSS

## Accessibility

The animation automatically stops when the user has enabled
`prefers-reduced-motion`.
