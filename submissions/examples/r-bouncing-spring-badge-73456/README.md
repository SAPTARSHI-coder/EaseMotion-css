# Bouncing Spring Badge

A smooth, responsive, and accessible CSS badge featuring a playful
**Bouncing Spring** interaction.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript required
- Smooth spring-inspired hover interaction
- Responsive design
- Keyboard-friendly focus state
- Dark mode compatible
- Supports `prefers-reduced-motion`
- Hardware-accelerated transforms
- Easy to customize

## Demo

Open `demo.html` directly in any modern browser.

## Usage

Add the badge element:

```html
<span class="spring-badge">New</span>
