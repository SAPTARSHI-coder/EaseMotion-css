# Glowing Neon Outline Input Field with Animated Floating Label

## Overview

A compact mobile-first neon input component with animated floating labels,
glassmorphism styling, and glowing outline effects.

Built using pure HTML, CSS, and JavaScript.

## Features

- ⚡ Neon glowing input borders
- ✨ Animated floating labels
- 🎨 Glassmorphic dark UI
- 🌈 Gradient neon effects
- 📱 Mobile-first responsive design
- 🖱️ Smooth focus transitions
- 🚀 Pure HTML/CSS/JS

## Usage

1. Open `demo.html` in browser.
2. Click on input fields.
3. Experience floating label animations.
