# Loader Dot Wander

A dot wanders through a looped path inside a rounded frame.

## Features
- Wandering dot path
- Looping trail
- Soft glow
- Pure CSS

## Usage
```html
<div class="ldw-dot"></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
