# CSS Elastic-Slide Tooltip for SaaS Showcase Layouts

A modern SaaS-style tooltip component featuring a smooth elastic-slide reveal animation built completely with pure HTML and CSS.

This component is designed for SaaS dashboards, product cards, and showcase layouts where lightweight animated interactions are required without JavaScript.


## ✨ Features

- 🚀 Elastic slide tooltip animation
- 💬 Modern SaaS dashboard style
- 🎨 Glassmorphism inspired UI
- ⚡ Pure HTML and CSS implementation
- 📱 Fully responsive design
- 🔄 CSS transitions and keyframe animations
- ♿ prefers-reduced-motion accessibility support
- 🌐 Framework-free lightweight component


## 📂 Folder Structure

## 🚀 Usage

1. Open `demo.html` directly in your browser.

2. Hover over the dashboard card to display the elastic tooltip.

3. Customize CSS variables inside `style.css` to match your project branding.


## 🎨 CSS Custom Properties

The component uses CSS variables for easy customization:

```css
:root {

    --bg:#020617;
    --card:#0f172a;
    --primary:#38bdf8;
    --secondary:#8b5cf6;
    --text:#f8fafc;
    --muted:#94a3b8;

}

Modify these values to create custom themes.
