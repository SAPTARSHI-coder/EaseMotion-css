# Floating File Dropzone - Neumorphism

A responsive floating file dropzone featuring soft neumorphic depth, layered shadows, smooth interactions, and a clean modern interface.

## ✨ Features

- Floating neumorphic design
- Soft outer and inner shadows
- Responsive desktop, tablet, and mobile layouts
- Pure HTML and CSS
- No JavaScript dependencies
- Interactive file browse control
- Keyboard-accessible file selection
- Visible focus state
- Smooth hover interactions
- Floating status chips
- Animated upload status indicator
- `prefers-reduced-motion` support
- Customizable EaseMotion-style design tokens
