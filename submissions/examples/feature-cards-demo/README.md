# Feature Cards Demo

## Purpose

This example demonstrates how existing EaseMotion CSS animation classes can be used to build responsive feature cards for landing pages and SaaS websites.

---

## Components

- Section Heading
- Six Feature Cards
- Feature Icons
- Feature Titles
- Descriptions
- Learn More Buttons

---

## Folder Structure

```
submissions/examples/feature-cards-demo/
├── demo.html
├── style.css
└── README.md
```

---

## How to Run

1. Open `demo.html` in your browser.
2. Resize the browser window to verify responsiveness.
3. Observe the EaseMotion CSS animations applied to the feature cards.

---

## Features

- Responsive card grid
- Six feature cards
- Modern layout
- Uses existing EaseMotion CSS animation classes
