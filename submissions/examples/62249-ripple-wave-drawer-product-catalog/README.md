# CSS Ripple-Wave Drawer for Product Catalog Layouts

A modern **Ripple-Wave Drawer** built using pure HTML5 and CSS3 for product catalog layouts. The component features a responsive slide-in drawer with a ripple-wave opening animation, glassmorphism styling, product quick-view cards, and accessibility support.

## Features

* Pure HTML5 & CSS3
* Ripple-Wave drawer opening animation
* Responsive slide-in drawer
* Product quick-view panel
* Glassmorphism UI design
* Smooth CSS transitions & keyframe animations
* Responsive desktop, tablet, and mobile layout
* CSS Custom Properties
* No JavaScript required
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Click the **Open Drawer** or **Quick View** button to reveal the drawer.
3. Customize colors, spacing, animation speed, and drawer width using the CSS variables in `:root`.
4. Integrate the drawer into any product catalog or e-commerce interface.
