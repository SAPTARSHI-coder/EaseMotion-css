# CSS Skill Hexagon Chart


A pure CSS hexagonal skill visualization component.


## Overview

`css-skill-hexagon-chart` displays technical skills around a central hexagon using only CSS.


## Features

- Pure CSS implementation
- No JavaScript dependency
- Hexagonal UI design
- Animated skill indicators
- Responsive layout
- Reduced motion accessibility


## Skills Displayed

- CSS
- JavaScript
- React
- Python
- AI/ML
- C++


## Animation

Uses CSS keyframes:

- pulse
- float


## Usage

Useful for:

- Portfolio websites
- Developer profiles
- Resume sections
- Skill dashboards
