# Responsive Filter Bar - Pastel

A responsive filter bar featuring a soft pastel visual
language, clean controls, animated interactions, and
adaptive layouts for desktop, tablet, and mobile screens.

## Features

- Pure HTML and CSS
- Pastel color system
- Responsive filter bar
- Search input
- Category filter
- Price filter
- Sort filter
- Reset and apply actions
- Active filter chips
- Add-filter control
- Responsive preview cards
- Soft hover animations
- Animated pastel background
- Keyboard focus states
- `prefers-reduced-motion` support
- No JavaScript dependencies
- No external libraries
