# Curtain Slide Reveal Animation

## Overview

This submission demonstrates a reusable **Curtain Slide Reveal** animation built entirely with CSS. A colored overlay slides away on hover, revealing the content underneath.

## Features

- Pure CSS animation
- Curtain-style reveal effect
- CSS keyframes
- Configurable timing using CSS custom properties
- Accessible `prefers-reduced-motion` support
- Responsive demo

## Customization

```css
--ease-duration: 700ms;
--ease-timing: ease-in-out;
```

## Demo

Open `demo.html` in any modern browser.
