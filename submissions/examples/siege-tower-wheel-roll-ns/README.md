# Siege Tower Wheel Roll

## What does this do?
Renders a self-contained CSS-only `ease-siege-tower-wheel-roll` demo: Siege tower wheels rolling forward.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-siege-tower-wheel-roll`. No build step or JavaScript is required for the effect.

```html
<section class="ease-siege-tower-wheel-roll">
  <div class="ease-siege-tower-wheel-roll__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
