# Blur-Entrance Carousel (Fintech Dashboard)

## What does this do?

A modern fintech dashboard carousel featuring cards that smoothly appear with a blur-to-clear entrance animation. The component showcases financial metrics using a clean glassmorphism design and responsive layout built entirely with HTML and CSS.

---

## Features

- Smooth blur entrance animation
- Staggered card appearance
- Glassmorphism card design
- Fintech-inspired dashboard UI
- Responsive layout
- Pure HTML & CSS (No JavaScript)
- Supports `prefers-reduced-motion`

---
