# Cyberpunk Neon 3D

A futuristic Cyberpunk Neon 3D animation built using pure HTML and Vanilla CSS.

## Features

- Pure HTML and CSS
- No JavaScript
- 3D transform effects
- Neon cyan, pink, and purple glow
- Animated cyberpunk grid
- Neon scanning line
- Smooth floating animation
- Interactive neon button
- Dark-mode friendly design
- Responsive layout
- Hardware-accelerated animations
- `prefers-reduced-motion` accessibility support

## Preview

The component features a futuristic neon card with:

- 3D floating movement
- Cyberpunk grid background
- Glowing borders
- Neon typography
- Animated scanning line
- Interactive button
