# Blog Card Title Overflow Fix

## Description

This submission fixes an issue where blog card titles overflow or break the layout on smaller screens. Long titles now wrap correctly while maintaining a clean, responsive card layout.

## Features

- Prevents long title overflow
- Responsive blog card layout
- Mobile-friendly typography
- Pure CSS implementation
- Lightweight and reusable

## Usage

```html
<div class="blog-card">
  <h2>Your Blog Title</h2>
  <p>Blog description...</p>
  <button>Read More</button>
</div>
```

## Benefits

- Prevents horizontal scrolling
- Keeps titles readable on all devices
- Improves responsive layout consistency
- Easy to integrate into existing projects
