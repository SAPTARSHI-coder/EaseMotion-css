# Cinematic Film Roll Scrubber

Creates a 3D cylindrical "film roll" effect as the user scrolls horizontally, using pure CSS scroll-driven animations.

## Usage

```html
<div class="ease-film-roll-container">
  <div class="ease-film-roll-track">
    <div class="ease-film-card">...</div>
    <div class="ease-film-card">...</div>
    <div class="ease-film-card">...</div>
  </div>
</div>
```

## Why is it useful?

It provides an immersive, hardware-accelerated 3D carousel effect without requiring any JavaScript scroll event listeners, keeping performance high and integration simple.
