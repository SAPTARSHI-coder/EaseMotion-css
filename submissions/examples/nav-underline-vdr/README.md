# Nav underline
## What does this do?
A horizontal nav where a colored underline grows in on hover and marks the active kink.

## What does this do?
Add class 'nav-underline-vdr' to a '<nav>' xontaining '<a>' links; add class 'active' to the current link.

## Why is it useful?
Simpl, dependency- free way to give visual frrdback on nav links without JavaScript.
