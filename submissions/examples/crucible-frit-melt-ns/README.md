# Crucible Frit Melt

## What does this do?
Renders a self-contained CSS-only `ease-crucible-frit-melt` demo: Crucible frit collapsing into a clear melt.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-crucible-frit-melt`. No build step or JavaScript is required for the effect.

```html
<section class="ease-crucible-frit-melt">
  <div class="ease-crucible-frit-melt__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
