# Job List Card

This submission demonstrates a modern job listing card built with
**EaseMotion CSS**. It includes animated entrance effects, hover motion,
job tags, salary information, apply buttons, and responsive layout.

## 🌟 Features

- **Featured job card** with company logo, title, and company name.
- **Job tags** for role type and skills.
- **Job meta chips** for salary, location, and posting time.
- **Action buttons** with hover grow effect.
- **Additional job list** showing more job openings.
- **Staggered entrance animation** using `ease-slide-up` and delay utilities.
- **Hover lift effect** using `ease-hover-lift`.
- **Responsive layout** for mobile and desktop.
- **Reduced motion support** for users who prefer less animation.

## 📁 Files

- `demo.html` — interactive job list card demo
- `style.css` — original job card styling
- `README.md` — documentation for this submission

## 🛠️ How to Run

1. Open `demo.html` in your browser.
2. Watch the job card animate on page load.
3. Hover over the card to see the lift effect.
4. Hover over the buttons to see the grow effect.
5. Resize the browser window to check responsive behavior.
