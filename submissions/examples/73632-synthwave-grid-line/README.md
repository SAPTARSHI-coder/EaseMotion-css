# Synthwave Grid Line Slider

A smooth CSS-only slider inspired by retro-futuristic synthwave landscapes,
neon horizons, and animated perspective grid lines.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript required
- Synthwave-inspired visual design
- Animated perspective grid floor
- Neon horizon effect
- Smooth slide transitions
- CSS 3D transforms
- Responsive layout
- Dark-mode friendly
- Hardware-accelerated animations
- Reduced-motion accessibility support
