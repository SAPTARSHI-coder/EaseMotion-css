# CSS Glow-Active Tabs

A modern **Glow-Active Tabs** component built using pure HTML5 and CSS3 for Responsive Dashboard layouts. The active tab is highlighted with a glowing effect while the content switches smoothly without JavaScript.

---

## ✨ Features

- Pure HTML5 & CSS3
- Glow active tab effect
- Responsive dashboard layout
- Keyboard accessible using radio inputs
- CSS Custom Properties
- Smooth content transitions
- No JavaScript required
- `prefers-reduced-motion` support
