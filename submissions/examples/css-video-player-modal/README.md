# CSS Video Player Modal

A responsive video player modal built using HTML and CSS for the
EaseMotion CSS library.

## Features

- Pure HTML and CSS implementation
- No JavaScript required
- Full-screen modal overlay
- Responsive video player
- Native HTML5 video controls
- Smooth modal entrance animation
- Animated close button
- Click-outside-to-close behavior
- Keyboard-focusable links and controls
- Accessible labels and dialog semantics
- Reduced-motion support
- Responsive on desktop, tablet, and mobile
