# Staggered Entrance Tabs — E-Commerce Checkout

A pure CSS animated tabs component featuring a smooth staggered entrance
effect, designed for modern E-Commerce Checkout interfaces.

## Features

- Pure HTML and CSS
- No JavaScript required
- Smooth staggered entrance animation
- Responsive layout
- Keyboard-friendly focus states
- Accessible tab structure
- CSS custom properties for animation customization
- Reduced-motion support
- Works by opening `demo.html` directly in a browser

## Preview

The demo presents three checkout stages:

- Shipping
- Payment
- Review

Each panel uses a staggered entrance animation to create a smooth,
progressive reveal.
