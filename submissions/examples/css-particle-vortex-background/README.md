# CSS Particle Vortex Background

A pure CSS animated background that creates a swirling vortex of particles.

## Features

- Pure HTML and CSS
- No JavaScript or external libraries
- Responsive layout
- Continuous particle vortex animation
- CSS custom properties for easy customization
- Respects `prefers-reduced-motion`
- Self-contained browser demo

Include the stylesheet:

<link rel="stylesheet" href="style.css">
