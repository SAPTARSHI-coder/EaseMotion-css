# CSS Shimmer-Sweep Navbar for E-Commerce Checkout Layouts

A modern **Shimmer-Sweep Navbar** built using pure HTML and CSS. The navigation bar features elegant shimmer-sweep hover effects, premium glassmorphism styling, responsive layouts, and smooth interactions suitable for e-commerce checkout pages.

## ✨ Features

- Pure HTML5 & CSS3
- Shimmer-sweep hover animation
- Glassmorphism navbar
- Responsive checkout layout
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
