# CSS Overlap Cards Layout

A creative overlapping card layout built entirely with HTML and CSS.

The cards are layered using CSS positioning, negative margins, transforms, and `z-index` to create a modern depth effect.

## Features

- Pure CSS implementation
- No JavaScript
- Creative overlapping card composition
- Layered visual hierarchy using `z-index`
- Smooth hover interaction
- Responsive layout
- Mobile-friendly stacking
- Reduced-motion support
- No external dependencies
