# CSS ATM Interface Card

A responsive ATM-style banking card built with pure HTML and CSS.

## Features

- ATM-style account interface
- Available balance display
- Account status indicator
- Withdraw, Deposit, Transfer, and Transactions menu
- CSS hover animation
- Keyboard-accessible menu buttons
- Visible `:focus-visible` states
- Responsive layout
- Reduced-motion support
- No JavaScript
- No external dependencies

## Accessibility

The ATM menu uses native `<button>` elements, providing keyboard
navigation without JavaScript.

The interface also includes semantic headings, navigation labels,
descriptive ARIA labels, and visible focus indicators.

## Usage

Open `demo.html` directly in a browser.

The menu items are visual UI examples and do not perform real banking
operations.

## Technologies

- HTML5
- CSS3

## Why It Fits EaseMotion CSS

This example demonstrates a reusable UI pattern with lightweight CSS
hover and focus animations. It provides a practical interface that
developers can use as a starting point for CSS-based banking or
dashboard designs.

No JavaScript or external animation libraries are required.
