# CSS Habit Streak Counter

## Overview

A habit-tracking streak card with a flame indicator, weekly completion grid, and animated completion meter.

## Features

- Current streak summary
- Best streak detail
- Weekly completion grid
- Completed and pending states
- Progress meter
- Responsive layout
- Reduced-motion support
- Semantic content structure

## Files

- `demo.html` — streak content and weekly state
- `style.css` — card layout, states, animations, and responsive styling
- `README.md` — documentation

## Accessibility

The completion grid uses a list structure with text labels for each day. Decorative motion is reduced when requested by the user.
