Best Practices

✓ Combine text-wrap: pretty with orphans

Use both for maximum orphan/widow protection. text-wrap: pretty improves line-breaking quality; orphans and widows set hard minimums.

article p {
  text-wrap: pretty;
  orphans: 3;
  widows: 2;
}

✓ text-wrap: balance is for headlines only

The balance algorithm has a 6-line limit. It's designed for headings and short text — not body paragraphs. Performance degrades on long text.

h1, h2, h3, blockquote {
  text-wrap: balance;
  max-width: 30ch;
}

✓ Set hyphenation character limits

Prevent ugly hyphenation with too-few characters on either side of the break.

body {
  hyphens: auto;
  hyphenate-limit-chars: 7 3 4;
}
