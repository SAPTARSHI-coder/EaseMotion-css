# Cybernetic Matrix Digital Rain Background Canvas Overlay (Vibrant Gradient Version)

A futuristic animated digital rain background with vibrant neon gradients and a glassmorphism information panel.

## Features

- Pure HTML5 & CSS3
- Vibrant animated digital rain
- Glassmorphism content card
- Gradient statistic cards
- Responsive layout
- CSS Custom Properties
- prefers-reduced-motion support
- No JavaScript required
