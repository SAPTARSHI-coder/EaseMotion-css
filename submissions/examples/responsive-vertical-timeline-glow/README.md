# Responsive Vertical Timeline with Gradient Glow

A pure CSS implementation of a responsive vertical roadmap/timeline component featuring an ambient gradient glow spine, interactive node states, and smooth card elevation transitions.

## Features
- **Zero JavaScript:** Built exclusively using standard CSS techniques and layout primitives.
- **EaseMotion Design Tokens:** Uses motion parameters (`--easemotion-duration-fast`, `--easemotion-ease-bounce`) and custom color tokens.
- **Dual Responsive Layout:** Renders as an alternating central spine on desktop viewports and automatically shifts to a left-aligned vertical spine on mobile/tablet viewports.
- **Gradient Glow Backdrop:** Integrates radial background glows and a luminous spine backdrop using CSS filters and gradients.
- **Accessibility Ready:** Includes full focus state support (`:focus-visible`) and disables animation transforms under `prefers-reduced-motion: reduce`.
