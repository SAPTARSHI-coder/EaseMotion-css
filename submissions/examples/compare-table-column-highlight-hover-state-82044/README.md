# Compare Table Column Highlight Hover State

A responsive comparison table demonstrating a column highlight hover interaction.

## Features

- Responsive comparison table
- Hover-based column highlighting
- Smooth visual transition
- Clear separation between feature and plan columns
- Horizontal scrolling on small screens
- No JavaScript or external dependencies

## Files

- `demo.html` - Interactive comparison table
- `style.css` - Component styling
- `README.md` - Documentation

## Usage

Open `demo.html` in a modern browser.

Hover over the Starter, Pro, or Business columns to highlight the selected plan.

## Responsive Behavior

The table maintains its structure on smaller screens and provides horizontal scrolling when the available viewport width is limited.

## Edge Cases

The example accounts for:

- Narrow mobile screens
- Long table content
- Horizontal overflow
- Hovering individual plan cells
- Hovering different columns repeatedly

## Accessibility

The table uses semantic `table`, `thead`, `tbody`, `th`, and `td` elements to preserve the comparison structure for assistive technologies.

## Browser Support

The component uses standard HTML and CSS features supported by modern browsers.
