# CSS Bounce-Pulse Stepper for SaaS Showcase Layouts

A responsive onboarding stepper built using pure HTML and CSS. Each milestone features a bounce-pulse animation that highlights the current step while maintaining accessibility and responsive behavior.

## Features

- Pure HTML & CSS
- Bounce-pulse animated step indicators
- Responsive layout
- Smooth hover effects
- CSS Custom Properties
- Accessible with `prefers-reduced-motion`
- No JavaScript required
