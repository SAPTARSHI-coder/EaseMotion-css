# Hover Vertical Text Shift

1. **What does this do?**
   Smoothly shifts text upward by a few pixels when the element is hovered.

2. **How is it used?**
   Apply the `.hover-text-shift` class to text you want to move upward on hover.

   ```html
   <span class="hover-text-shift">
     Hover Me
   </span>
   ```

3. **Why is it useful?**
   It provides a simple, readable, and composable text interaction that fits EaseMotion CSS's animation-first philosophy.
