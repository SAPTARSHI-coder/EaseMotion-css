# CSS 3D Press Button

A pure CSS button featuring a realistic 3D push-down effect using transforms and layered shadows.

## Features

- Pure CSS implementation
- Interactive press animation
- Responsive design
- Accessible keyboard focus states
- CSS custom properties for easy customization
- Light and dark mode support

## Usage

```html
<button class="press-btn">
  Press Me
</button>
```

## File Structure

```text
css-3d-press-button/
├── demo.html

```

## Customization

```css
:root {
  --button-color: #3b82f6;
  --button-shadow: #1d4ed8;
}
```

## Why It Fits EaseMotion CSS

This component adds a reusable interaction pattern that mimics physical button presses using only CSS, making interfaces feel more responsive and engaging without JavaScript.
