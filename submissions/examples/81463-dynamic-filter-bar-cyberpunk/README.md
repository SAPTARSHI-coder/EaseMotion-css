# Dynamic Filter Bar — Cyberpunk

A responsive, CSS-only filter bar inspired by futuristic
cyberpunk interfaces.

Built for EaseMotion CSS issue #81463.

## Features

- Cyberpunk visual styling
- Neon cyan and magenta accents
- Dynamic filter controls
- Search field
- Category filter chips
- Sort dropdown
- Reset control
- Active-filter status indicator
- Animated system status
- Animated signal indicator
- Interactive hover states
- Responsive desktop, tablet and mobile layouts
- Keyboard focus states
- `prefers-reduced-motion` support
- Zero external JavaScript dependencies

`demo.html`.
