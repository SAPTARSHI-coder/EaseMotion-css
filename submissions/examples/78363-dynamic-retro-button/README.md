# Dynamic Retro Button

A responsive dynamic button component inspired by classic arcade
interfaces and retro game controls.

The component uses layered shadows, animated highlights, tactile
press states, and bold pixel-inspired styling to create an interactive
retro experience.

## Features

- Fully responsive
- Pure HTML and CSS
- Four color variants
- Animated hover highlight
- Tactile active/pressed state
- Keyboard focus styling
- Layered pixel-style shadows
- Retro arcade presentation
- No JavaScript
- No external dependencies
- Reduced-motion support

## Files

- `demo.html`
- `style.css`

## Usage

Basic button:

```html
<button class="dynamic-button dynamic-button--red" type="button">
  <span class="dynamic-button__shine"></span>
  <span class="dynamic-button__icon">▶</span>
  <span class="dynamic-button__text">PLAY NOW</span>
  <span class="dynamic-button__pixel"></span>
</button>
