# Feature Cards Component

**Issue:** [#69807](https://github.com/SAPTARSHI-coder/EaseMotion-css/issues/69807)

A pure CSS responsive feature cards component with smooth animations and dark/light mode.

## Design Tokens

| Token | Value |
|-------|-------|
| `--featcard-primary` | `#6366f1` |
| `--featcard-accent` | `#f59e0b` |
| `--featcard-bg` | `#0f172a` |
| `--featcard-bg-card` | `#1e293b` |
| `--featcard-radius` | `12px` |

## Features

- Responsive 3-column grid layout
- Smooth hover lift effect
- Dark and light mode
- No JavaScript required

## Files

- `style.css` - Component styles
- `demo.html` - Interactive showcase
