# Parallax Tooltip with SaaS Modern Styling

A responsive tooltip component inspired by modern SaaS interfaces, featuring layered depth, subtle parallax-style movement, soft gradients, and smooth CSS-only interactions.

## Features

- Modern SaaS-inspired visual design
- Layered parallax-style depth
- Smooth tooltip reveal animation
- 3D transform effects
- Soft gradients and shadows
- Interactive trigger state
- Fully responsive
- Keyboard accessible
- Visible focus state
- Reduced-motion support
- Pure HTML and CSS
- No external dependencies

## Preview

Open `demo.html` in a modern browser to preview the component.
