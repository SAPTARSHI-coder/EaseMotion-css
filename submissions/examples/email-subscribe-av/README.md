# Email Subscription Card - EaseMotion CSS

A premium, glassmorphism-styled email subscription card built with plain HTML and CSS. Designed as a reusable example component for the EaseMotion CSS repository, showcasing a modern frosted-glass card over a glowing gradient backdrop.

## 🎯 Feature Overview

This example demonstrates a self-contained "newsletter signup" card suitable for landing pages, marketing sections, or footers. It combines a glassmorphism card, gradient accents with a subtle glow, and smooth hover/focus interactions — all without any JavaScript or external frameworks.

## ✨ Features

- Premium glassmorphism card using `backdrop-filter: blur()`
- Modern multi-stop gradient background
- Attractive newsletter heading with an icon badge
- Short, friendly subscription copy
- Accessible email input with a visually hidden label
- Premium gradient "Subscribe" button
- "No spam, unsubscribe anytime" privacy note
- Soft drop shadow combined with a subtle accent glow
- Rounded corners (24px on the card, 14px on form controls)
- Smooth hover and focus animations on the card, input, and button
- Fully responsive layout for desktop, tablet, and mobile
- Built with reusable CSS custom properties (design tokens)

## 🛠 Technologies Used

- HTML5 (semantic `main`, `section`, `form`, accessible labeling)
- CSS3 (Flexbox, CSS custom properties, `backdrop-filter`, media queries)
- Google Fonts: Poppins (heading), Inter (body text)
- No JavaScript, no CSS frameworks

## 📱 Responsive Support

| Device | Behavior |
|---|---|
| 🖥 Desktop | Centered card at a comfortable max-width with full spacing |
| 📟 Tablet | Card width and padding tighten slightly for narrower viewports |
| 📱 Mobile | Card expands to fill the viewport width with reduced padding and font sizes |

## 🚀 How to Run the Demo

1. Make sure `demo.html` and `style.css` are in the same folder.
2. Open `demo.html` in any modern web browser (double-click the file, or right-click and choose "Open with" your browser).
3. Resize the browser window to see the card adapt across desktop, tablet, and mobile widths.
