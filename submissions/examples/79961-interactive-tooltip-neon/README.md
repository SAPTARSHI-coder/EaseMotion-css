# Interactive Tooltip - Neon Styling

A responsive interactive tooltip component with a modern neon-inspired visual style.

The component uses HTML and CSS only and supports hover and keyboard focus interactions without requiring JavaScript.

## ✨ Features

- Pure HTML and CSS
- No external dependencies
- Neon glow effects
- Smooth tooltip animation
- Hover interaction
- Keyboard focus interaction
- Semantic `role="tooltip"`
- `aria-describedby` support
- Multiple neon color variants
- Responsive layout
- Mobile-friendly design
- Visible keyboard focus state
- Reduced-motion support
- Customizable CSS variables
