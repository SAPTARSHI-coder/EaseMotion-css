# CSS Skew-Active Hero Section

A responsive, pure CSS/HTML hero section designed for Product Catalog layouts.

This component uses skew transforms, entrance animations, floating elements,
and hover interactions to create a modern animation-first product showcase.

## Features

- Pure HTML and CSS
- No JavaScript or external frameworks
- Skew-based hero interactions
- Animated hero entrance
- Animated floating product cards
- Hover-based product card movement
- Responsive desktop, tablet, and mobile layouts
- CSS custom properties for easy customization
- Accessible reduced-motion support
- Works by opening `demo.html` directly in a browser
