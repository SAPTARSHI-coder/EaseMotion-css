# Retro Arcade Pixel Drawer

A nostalgic **Retro Arcade Pixel Drawer** built with pure HTML and
Vanilla CSS for EaseMotion CSS.

Implemented for **Issue #73594**.

## ✨ Features

- Retro arcade-inspired pixel interface
- Pure HTML and CSS
- No JavaScript required
- CSS-only drawer interaction
- CRT scanline effect
- Pixel-style navigation
- Arcade score display
- Neon cyan, pink and yellow accents
- Responsive design
- Smooth CSS transitions
- Hardware-friendly transforms
- Dark-mode compatible
- Reduced-motion support

## 🎮 Style

**Category:** Drawers & Sidebars

**Style:** Retro Arcade Pixel

The component recreates the visual language of classic arcade machines
using pixel-like borders, neon colors, scanlines, score panels and
step-based CSS transitions.
