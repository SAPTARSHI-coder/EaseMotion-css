# Hover Rotate Effect

1. **What does this do?**
   Adds a subtle rotation effect when an element is hovered.

2. **How is it used?**
   Apply the `.hover-rotate` class to any element you want to rotate on hover.

   ```html
   <div class="hover-rotate">
     Hover Me
   </div>
   ```

3. **Why is it useful?**
   It provides a simple, readable, and composable hover interaction that fits EaseMotion CSS's animation-first philosophy.
