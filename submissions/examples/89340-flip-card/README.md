# 3D Flip Card Component

An interactive card component featuring a 180-degree 3D flip animation on hover.

## Features
- **3D Perspective Rotation:** Uses `rotateY(180deg)` with `preserve-3d` for seamless flipping.
- **Hidden Backface:** Utilizes `backface-visibility: hidden` for clear double-sided layouts.
- **Zero JavaScript:** Pure CSS hover micro-interaction.

## File Structure
- `demo.html` - Dual-sided card structure markup.
- `style.css` - 3D transforms, backface properties, and gradient styles.
