CSS Magnetic Button

A pure CSS "magnetic attraction" hover effect. The button follows your cursor dynamically using a 3x3 grid of hidden hover triggers and CSS sibling translation rules.

How CSS-Only Magnetic Attraction Works

Without JavaScript coordinates tracking, the button employs a multi-zone grid selector approach to emulate cursor attraction:

  • 3x3 Grid Overlay: The parent <button> is configured as a grid container containing 9 transparent trigger zones overlaying the button's surrounding magnetic field.
  • Sibling Combator Targeting: When a cursor hovers over any of the 9 grid cells (e.g. .zone-tl for top-left), the general sibling selector target (~ .magnetic-button) translates the button in that direction.
  • Organic Physics Feeling: We use EaseMotion's signature spring curve cubic-bezier(0.34, 1.56, 0.64, 1) (our --ease-ease-bounce token) inside the CSS transition properties to create a springy, snapping cursor attraction.
  • Keyboard Navigation & A11y: Fully accessible via keyboard. Tabbing onto the button triggers a high-contrast focus ring around the visual button using :focus-visible.
