# Streak Flame Badge

A habit-streak badge where a flame flickers and the day count glows with it.

## Features
- Flame flickers with layered tongues
- Count badge pulses on the beat
- Glow ring reinforces the streak

## Usage
```html
<div class="sf2-badge">
  <div class="sf2-halo"></div>
  <div class="sf2-flame"></div>
  <span class="sf2-count">30 days</span>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
