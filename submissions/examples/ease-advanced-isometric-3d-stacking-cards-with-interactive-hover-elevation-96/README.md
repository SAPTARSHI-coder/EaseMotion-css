# Isometric 3D Stacking Cards with Interactive Hover Elevation

## Overview

A modern **3D stacking card UI component** featuring isometric perspective,
interactive hover elevation, and glassmorphic styling.

This compact mobile-first component is built using pure HTML, CSS, and
JavaScript without any external dependencies.

## Features

- 🧊 Isometric 3D card stacking effect
- ✨ Interactive hover elevation animation
- 🪟 Glassmorphism UI design
- 🎨 Gradient neon accents
- 📱 Mobile-first responsive layout
- ⚡ Smooth CSS 3D transformations
- 🎯 Depth perspective effects
- ♿ Reduced motion accessibility support
- 🚀 Lightweight and dependency-free

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over cards to experience the 3D elevation effect.
3. Customize colors and animations through CSS variables.

## Customization

You can modify:

- Card gradients
- 3D rotation values
- Hover elevation distance
- Animation timing
- Typography styles
