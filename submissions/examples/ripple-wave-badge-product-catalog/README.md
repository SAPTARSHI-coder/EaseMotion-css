# Ripple-Wave Badge for Product Catalog

A responsive product catalog showcase featuring animated Ripple-Wave badges
using only HTML and CSS.

## Features

- Pure HTML and CSS
- No JavaScript
- No external libraries
- Animated ripple-wave badge
- Multiple badge variants
- Smooth product-card hover effects
- Responsive product grid
- CSS custom properties
- Semantic product markup
- `prefers-reduced-motion` support
- Mobile, tablet and desktop friendly
