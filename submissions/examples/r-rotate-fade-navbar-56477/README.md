# CSS Rotate-Fade Navbar

A modern **Rotate-Fade Navbar** built using pure HTML5 and CSS3 for Gaming Hub layouts. Navigation links smoothly rotate and fade on hover while remaining lightweight, responsive, and accessible.

---

## ✨ Features

- Pure HTML5 & CSS3
- Rotate-fade hover animation
- Gaming-inspired navigation bar
- Fully responsive layout
- CSS Custom Properties
- Lightweight and performant
- Accessible semantic HTML
- `prefers-reduced-motion` support
- No JavaScript required

## 🚀 Usage

1. Copy the component into your project.
2. Link the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

3. Open `demo.html` in any modern browser.
