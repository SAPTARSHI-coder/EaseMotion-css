# ease-avatar-stack

An overlapping avatar/collaborator stack for **EaseMotion CSS**, with hover pop-out and a "+N more" trailing badge.

## Usage

```html
<div class="avatar-stack">
  <img class="avatar-stack-item" src="user1.jpg" alt="User 1">
  <img class="avatar-stack-item" src="user2.jpg" alt="User 2">
  <span class="avatar-stack-item avatar-stack-more">+5</span>
</div>
