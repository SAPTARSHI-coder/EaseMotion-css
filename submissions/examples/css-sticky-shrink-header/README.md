# CSS Sticky Shrink Header

A lightweight, responsive sticky navigation header that progressively shrinks and changes its visual style as the user scrolls.

## Features

- Pure HTML and CSS
- CSS scroll-driven animation using `animation-timeline: scroll()`
- Sticky navigation header
- Smooth header height and shadow transition
- Responsive desktop, tablet, and mobile layouts
- Semantic navigation markup
- Keyboard-accessible links and visible focus states
- `prefers-reduced-motion` support
- No JavaScript or external dependencies
- Fallback behavior for browsers without scroll-driven animation support

## Files

- `demo.html` — Complete standalone demonstration page
- `style.css` — Sticky header styles and scroll-driven animation
