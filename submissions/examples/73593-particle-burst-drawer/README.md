# Particle Burst Drawer

A modern **Particle Burst Drawer** built with pure HTML and Vanilla CSS
for EaseMotion CSS.

Implemented for **Issue #73593**.

## ✨ Features

- Particle burst reveal effect
- Pure HTML and Vanilla CSS
- No JavaScript required
- CSS-only drawer interaction
- Smooth drawer transitions
- Layered particle animations
- Responsive navigation
- Dark-mode friendly color palette
- Hardware-friendly transforms
- `prefers-reduced-motion` support
- Semantic navigation structure

## 🎨 Style

**Category:** Drawers & Sidebars

**Style:** Particle Burst

The component combines a clean modern drawer with an energetic burst
of CSS particles when the navigation opens.
