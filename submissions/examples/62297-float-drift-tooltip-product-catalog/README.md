# CSS Float-Drift Tooltip for Product Catalog Layouts

A lightweight **Float-Drift Tooltip** built using pure HTML and CSS. The tooltip smoothly appears on hover with a floating drift animation, making product information more engaging while maintaining accessibility and responsiveness.

## Features

- Pure HTML5 & CSS3
- Smooth float-drift animation
- Hover-triggered tooltip
- Responsive product layout
- Easy customization using CSS
- No JavaScript required
- Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html`.
2. Hover over the info icon.
3. The tooltip appears with a floating animation.

## Customization

You can modify:

- Tooltip colors
- Animation duration
- Border radius
- Shadow
- Font size
- Product images
