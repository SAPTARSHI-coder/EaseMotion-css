# Retro Arcade Pixel Background

A smooth and performant pure CSS background animation inspired by classic retro arcade visuals.

## Features

- Pure HTML and Vanilla CSS
- Pixel-inspired arcade aesthetic
- Animated perspective grid
- Subtle pixel particles
- Neon glow effects
- Lightweight CSS animations
- Responsive layout
- Dark mode compatible
- Light mode support
- Hardware-friendly transforms
- Accessible focus states
- `prefers-reduced-motion` support
- No external JavaScript or libraries
