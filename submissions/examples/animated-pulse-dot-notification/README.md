# ease-badge

A notification badge component for **EaseMotion CSS** — pulsing dot for "unread" state, or a numeric counter.

## Usage

```html
<div class="badge-wrap">
  🔔
  <span class="badge badge-pulse"></span>
</div>

<div class="badge-wrap">
  🔔
  <span class="badge badge-count">3</span>
</div>
