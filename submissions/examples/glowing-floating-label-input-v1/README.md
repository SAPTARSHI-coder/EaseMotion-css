# Glowing Floating Label Input

A responsive SaaS Modern styled floating label input component built with
pure HTML and CSS.

## Features

- Floating labels
- Glowing focus effect
- SaaS Modern visual style
- Responsive design
- Keyboard accessible
- Visible focus states
- Native HTML validation
- `prefers-reduced-motion` support
- No JavaScript
- No external dependencies
