# Animated Badge with Gradient Styling

A collection of eye-catching, animated gradient border badges built with pure HTML and CSS. Perfect for highlighting "New" features, "Pro" tiers, or "Sale" items.

## Features
- Pure CSS implementation using `conic-gradient` and `@keyframes`
- Smooth, infinite rotating gradient border animation
- Responsive Pill shape utilizing `border-radius: 9999px`
- Multiple color variants configured via CSS classes
- Animation pauses on hover for better readability
- Hover lift interactions with drop shadows

## Usage
Include `demo.html` and `style.css` in your project. The gradient animation is achieved by rotating a pseudo-element behind the main badge content layer. Ensure your badge text container `.badge-content` has a solid background color (usually matching the page background) to mask the center of the gradient.
