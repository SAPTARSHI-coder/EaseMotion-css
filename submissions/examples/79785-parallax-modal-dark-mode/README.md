# Parallax Modal — Dark Mode

A responsive CSS-only modal with layered depth and dark mode
styling for EaseMotion CSS.

Implemented for issue #79785.

## Features

- Dark mode visual system
- Layered parallax depth
- CSS-only modal interaction
- Backdrop overlay
- Smooth opening transition
- Hover depth interactions
- Responsive layout
- Accessible dialog structure
- Reduced-motion support
- No JavaScript
- No external dependencies
