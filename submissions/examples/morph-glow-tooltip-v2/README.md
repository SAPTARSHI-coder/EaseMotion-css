# Morph-Glow Tooltip

A lightweight, responsive CSS-only Morph-Glow Tooltip designed for modern fintech dashboard interfaces.

## Features

- Pure HTML and CSS
- No JavaScript required
- Morphing tooltip entrance animation
- Glow interaction on hover and keyboard focus
- Smooth scale, rotation and blur effects
- Responsive dashboard layout
- CSS custom properties for easy customization
- Keyboard accessible
- Supports `prefers-reduced-motion`
- Works with modern browsers
- Lightweight and framework-independent

## Demo

Open `demo.html` in any modern browser.

The tooltip can be activated by:

- Hovering over the `?` icon
- Focusing the `?` icon using the keyboard
