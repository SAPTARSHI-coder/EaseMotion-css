# ease-ripple-grid-bh

CSS Ripple-Wave Feature Grid for Gaming Hub Layouts.

## What does this do?
A responsive feature grid with ripple-wave animations on hover, creating an immersive gaming experience.

## How is it used?
```html
<div class="ease-ripple-grid">
  <div class="ease-ripple-card">
    <div class="ease-ripple-icon">🎮</div>
    <h3>Gaming</h3>
    <p>Experience immersive gameplay</p>
  </div>
</div>
```

## Features
- Ripple-wave animation on hover
- Gaming-themed card design
- Icon and text content support
- Staggered animation delays
- Fully responsive grid
- Reduced motion support

## CSS Custom Properties
- `--ease-ripple-primary`: Primary accent color
- `--ease-ripple-bg`: Card background
- `--ease-ripple-text`: Text color
