# CSS Modal: Holographic Flicker

A futuristic, accessible, and performant modal component featuring a
holographic flicker effect using only HTML and Vanilla CSS.

## Features

- Pure HTML and CSS
- No JavaScript required
- Holographic flicker animation
- Neon cyan and purple glow
- Animated scan lines
- Gradient color shifting
- Responsive design
- Dark-mode friendly
- Hardware-accelerated transforms
- Accessible dialog markup
- Keyboard focus indicators
- Reduced-motion support
- Backdrop blur effect
