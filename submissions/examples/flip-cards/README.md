# 3D Flip Cards

A CSS-only 3D flip card component with a smooth rotation animation.

## Features

- Pure HTML and CSS
- No JavaScript required
- 3D card rotation
- Front and back card faces
- Smooth hover animation
- Keyboard focus support
- Responsive layout
- Reduced-motion support
- Customizable animation variables

## Files

- `demo.html` - Flip card demonstration
- `style.css` - Card styling and animation
- `README.md` - Documentation

## Usage

Create a flip card using:

```html
<div class="flip-card">
  <div class="flip-card-inner">

    <div class="flip-card-front">
      <h2>Front</h2>
      <p>Hover to flip</p>
    </div>

    <div class="flip-card-back">
      <h2>Back</h2>
      <p>Content on the back side.</p>
    </div>

  </div>
</div>
