# CSS Glitch-Flicker Carousel for SaaS Showcase

A modern SaaS showcase carousel featuring pure CSS glitch, flicker and
transition effects.

This example is designed for EaseMotion CSS and requires no JavaScript or
external framework.

## Features

- Pure HTML and CSS
- CSS-only carousel navigation
- Glitch-style slide transitions
- Flicker animation effects
- Animated dashboard visualization
- Workflow visualization
- Security visualization
- Responsive desktop, tablet and mobile layouts
- CSS custom properties
- Keyboard-accessible controls
- Visible focus states
- `prefers-reduced-motion` support
- No JavaScript dependencies
