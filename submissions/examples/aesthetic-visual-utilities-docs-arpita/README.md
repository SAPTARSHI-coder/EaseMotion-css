# Aesthetic & Visual Utilities Documentation
An interactive documentation showcase for EaseMotion CSS Aesthetic & Visual Utilities. This page replaces static documentation with live previews, responsive cards, usage snippets, and interactive navigation to improve the developer experience.

---

## Features
- Interactive live previews for utility classes
- Responsive documentation layout
- Search bar UI
- Category filter buttons
- Collapsible utility sections
- Utility preview cards
- HTML usage snippets
- Copy Class buttons
- Smooth hover animations
- Pure HTML & CSS (No JavaScript)

---

## Folder Structure
```
aesthetic-visual-utilities-arpita/
│── demo.html
│── style.css
└── README.md
```

---

## How to Use
Open `demo.html` directly in any modern browser.

Each utility section contains:
- Live visual preview
- Utility class name
- HTML usage snippet
- Copy Class button
- Responsive card layout

Example:

```html
<div class="ease-backdrop-blur-md">
    Glass Effect
</div>

<h2 class="ease-gradient-text">
    Gradient Text
</h2>
```

---

## Why is it useful?
Traditional documentation only lists class names, making it difficult to understand their appearance. This interactive documentation provides instant visual feedback through live previews, making utility classes easier to learn, compare, and implement.
