# 3D Toggle with Neumorphism styling (#78886)

A fully responsive 3D toggle switch featuring tactile neumorphic dual-shadow extrusions, smooth spring-animated state shifts, and accessible control traits built entirely with pure CSS.

## Features
- **Semantic & Accessible Markup:** Uses proper `<input type="checkbox">` with `role="switch"` and aria attributes.
- **Neumorphic Soft UI:** Layered inset and outset dual-shadow combinations (`#a3b1c6` and `#ffffff`).
- **Tactile Transitions:** Elastic spring displacement curves for realistic mechanical feel.

## File Hierarchy
- `style.css` - Soft UI variable tokens, inset/outset shadow calculations, and pseudo animations.
- `demo.html` - Accessible HTML structure showcasing 3D switch control.
- `README.md` - Technical documentation and implementation notes.
