# CSS Tab: Diamond Facet Edge

Issue #73574 demonstrates tabs with geometric diamond facets around the active and focused states.

## Requirements covered

- Pure HTML and vanilla CSS
- Smooth CSS transitions
- Responsive segmented control
- Keyboard-visible focus state
- Dark-mode-friendly palette
- Reduced-motion fallback

The facet corners are generated with rotated pseudo-elements, keeping the component asset-free and lightweight.

## Files

- `demo.html` — tab demonstration
- `style.css` — facet geometry, interaction, and responsive rules
- `README.md` — documentation
