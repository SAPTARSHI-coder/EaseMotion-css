Grow, overshoot, settle.

Ease Spring-Scale is a reusable entrance animation that grows an element from a smaller size, slightly overshoots, and naturally settles at full scale.

Motion sequence

Four intentional moments.

  1. 01
    Small start

    Opacity begins low while the element is reduced below its final scale.

  2. 02
    Rapid growth

    The component scales toward its intended size using transform.

  3. 03
    Overshoot

    A tiny increase beyond one creates the spring character.

  4. 04
    Settle

    The element returns to scale one with full opacity.

Drop-in class

Small API.

.spring-scale {
  animation:
    ease-spring-scale
    var(--spring-duration)
    var(--spring-easing)
    var(--spring-delay)
    both;
}

Add the class to arbitrary elements and tune its custom properties locally.

Fine control without JavaScript.
