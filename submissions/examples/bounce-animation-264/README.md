# Interactive Rating Star System

A compact, responsive rating component with interactive stars and a micro-bounce animation.

## Features

* ⭐ Five-star interactive rating
* 🖱️ Hover preview
* 🎯 Click-to-select rating
* ✨ Micro-bounce animation
* 📱 Mobile responsive design
* ♿ Keyboard focus support
* 🎨 Neumorphic visual style
* 🚫 No external libraries

## Folder Structure

```text
ease-advanced-interactive-rating-star-system-with-micro-bounce-animation-264/
├── demo.html
├── style.css
└── README.md
```

## Usage

Open `demo.html` directly in a modern browser.

No installation or dependencies are required.

## How It Works

Hover over the stars to preview a rating.

Click a star to select the rating.

Click **Submit Rating** to display the selected rating.

## Customization

The colors, spacing, animation speed, text, and rating messages can be modified in `style.css` and `demo.html`.

## Accessibility

The rating buttons include accessible labels and visible keyboard focus states.
