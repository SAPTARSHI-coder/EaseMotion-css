# Cybernetic Matrix Digital Rain Background

A futuristic cybernetic matrix digital-rain background component built with
HTML, CSS, and JavaScript Canvas.

## Features

- Animated digital rain effect
- Canvas-based rendering
- Neumorphic UI panel
- Responsive mobile-first design
- Pause and resume animation
- No external dependencies
- Reduced-motion support
