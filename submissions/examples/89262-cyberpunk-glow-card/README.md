# Cyberpunk Glow Card Component

A dark-mode cyberpunk card component featuring continuous rotating conic gradient border glow traces.

## Features
- **Conic Border Trace:** Pure CSS `conic-gradient` spinning border effect.
- **Hover Micro-Interactions:** Subtle lift and neon aura glow on hover.
- **Pure CSS:** Zero JavaScript dependencies.

## File Structure
- `demo.html` - Cyberpunk card layout structure.
- `style.css` - Conic gradient keyframe rotations and dark card styling.
