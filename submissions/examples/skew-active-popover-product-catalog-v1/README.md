# CSS Skew-Active Popover for Product Catalog Layouts

A modern **Skew-Active Popover** component created using pure HTML5 and CSS3 for the EaseMotion CSS project.

This component adds a dynamic skew transformation effect to product cards, creating a smooth and interactive product showcase experience.

---

## ✨ Features

- Pure HTML5 + CSS3 implementation
- Smooth skew transformation animation
- Modern glassmorphism popover design
- Product catalog card layout
- Hover-based interactions
- CSS custom properties support
- Fully responsive design
- No JavaScript dependency
- Accessibility support with `prefers-reduced-motion`

## 🎨 CSS Custom Properties

The component uses CSS variables for easy customization:

```css
:root {

--primary:#4f46e5;
--secondary:#6366f1;
--accent:#06b6d4;

--bg:#0f172a;
--card:#1e293b;

--text:#ffffff;
--muted:#cbd5e1;

--radius:22px;

--transition:.45s ease;

}
```

## 🚀 Usage

1. Open `demo.html` in any modern browser.
2. Customize product content and images.
3. Modify CSS variables to match your theme.
4. Integrate the component into any product showcase page.

## 📱 Responsive Support

The component works smoothly across:

- Desktop screens
- Tablets
- Mobile devices

The layout automatically adjusts using CSS media queries.

---

## ♿ Accessibility

Accessibility features include:

- Semantic HTML structure
- Reduced motion support using:

```css
@media(prefers-reduced-motion:reduce)
```

- Animations are disabled for users who prefer less motion.
