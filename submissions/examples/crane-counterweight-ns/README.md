# Crane Counterweight

## What does this do?
Renders a self-contained CSS-only `ease-crane-counterweight` demo: Tower crane counterweight sliding as the jib slews.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-crane-counterweight`. No build step or JavaScript is required for the effect.

```html
<section class="ease-crane-counterweight">
  <div class="ease-crane-counterweight__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
