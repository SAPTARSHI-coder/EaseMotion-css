# CSS Background: Minimalist Outline

A smooth and performant pure CSS background animation featuring a clean
Minimalist Outline aesthetic.

## Features

- Pure HTML and Vanilla CSS
- Minimalist geometric outline elements
- Smooth floating animations
- Subtle animated grid
- Lightweight CSS-only implementation
- Hardware-friendly `transform` animations
- Dark mode support
- Responsive layout
- Accessible keyboard focus states
- `prefers-reduced-motion` support
- No JavaScript
- No external libraries
