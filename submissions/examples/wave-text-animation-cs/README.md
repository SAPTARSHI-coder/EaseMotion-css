# CSS Wave Text Animation

A lightweight, CSS-only wave text animation for the EaseMotion CSS examples library.

Each character is individually animated with a staggered delay, producing a smooth wave pattern without JavaScript or external dependencies.

## Features

- Pure HTML and CSS
- No JavaScript required
- Per-character wave animation
- CSS custom properties for customization
- Responsive layout
- Light and dark mode support
- `prefers-reduced-motion` support
- Semantic HTML
- Accessible text alternatives
- Keyboard-accessible skip link
- Standalone `demo.html`
