# Animation Frame Rate (60 FPS vs 120 FPS) Smoothness Monitor

A responsive benchmark-style dashboard that compares animation smoothness between 60 FPS and 120 FPS.

## Features

- Pure HTML & CSS
- Responsive layout
- Animated FPS progress bars
- Performance comparison table
- Visual benchmark dashboard

## Files

- demo.html
- style.css

## Usage

Open `demo.html` in any modern browser.
