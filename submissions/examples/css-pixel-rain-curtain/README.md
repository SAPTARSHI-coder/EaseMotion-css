# CSS Pixel Rain Curtain


A pure CSS animated pixel rain curtain effect.


## Features

- Pixel blocks falling animation
- Glowing cyber style effect
- Fully responsive
- No JavaScript required


## Technologies

- HTML5
- CSS3


## CSS Concepts Used

- Keyframe animations
- Transform
- Delay based animation
- Responsive design
- Box shadow glow


## Accessibility

- Decorative animation only
- Text remains readable
- No keyboard interaction required
