# Glassmorphism Blur Card

A smooth, accessible, and responsive card component featuring a modern glassmorphism blur effect using pure HTML and Vanilla CSS.

No JavaScript or external dependencies are required.

## Features

- Pure HTML and Vanilla CSS
- Glassmorphism styling
- Translucent card surface
- `backdrop-filter` blur
- Soft decorative lighting
- Smooth hover elevation
- Interactive button states
- Responsive layout
- Dark-mode compatible
- Hardware-accelerated transforms
- Keyboard focus styling
- Reduced-motion support
- No external dependencies
