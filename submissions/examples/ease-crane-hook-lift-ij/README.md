# ease-crane-hook-lift
A tower crane with a latticed mast, a jib-mounted cable drum, and a hook that hoists a wooden crate across the worksite.
## Run
Open `demo.html` directly in a browser to watch the hook lift.
## Notes
- The hook rides the cable down, picks up the crate, and hoists it clear.
- The cable drum spins while the load badge blinks.
