# Punchcard Loom Feed

## What does this do?
Renders a self-contained CSS-only `ease-punchcard-loom-feed` demo: Punch-card loom feeding perforated pattern cards.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-punchcard-loom-feed`. No build step or JavaScript is required for the effect.

```html
<section class="ease-punchcard-loom-feed">
  <div class="ease-punchcard-loom-feed__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
