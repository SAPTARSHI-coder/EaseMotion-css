# Animated Progress Bar Component

Add ease-progress-bar-animated-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|---------|
| `--apb-accent` | `#6366f1` |
| `--apb-accent2` | `#ec4899` |
| `--apb-accent3` | `#10b981` |
| `--apb-radius` | `4px` |

## Technique

`::after` pseudo-element with `translateX` shimmer animation overlaid on the fill bar.
