# Morphing Navbar

Pastel responsive morphing navigation showcase for issue #78646.

## Files

- `demo.html` — semantic header and navigation.
- `style.css` — shape transitions, spacing, and responsive states.

## Features

- Semantic navigation.
- Pastel surface styling.
- Morphing hover state.
- Keyboard focus treatment.
- Mobile navigation wrapping.
- Reduced-motion fallback.

The navigation remains standard HTML links and requires no JavaScript for its core behavior.
