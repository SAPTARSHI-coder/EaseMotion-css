# Bounce-Pulse Accordion Product Catalog

A lightweight product catalog showcase featuring a responsive CSS
Bounce-Pulse Accordion interaction.

The component is built using semantic HTML and pure CSS without JavaScript or
external frameworks.

## Features

- Pure HTML and CSS
- Native `<details>` and `<summary>` accordion
- Bounce animation when an accordion opens
- Pulse effect around the active accordion badge
- Smooth CSS transitions
- CSS keyframe animations
- Responsive product catalog
- Desktop, tablet and mobile layouts
- Keyboard-accessible native accordion
- Visible focus states
- CSS custom properties
- `prefers-reduced-motion` support
- No external dependencies
