# CSS Float-Drift Progress Bar

A smooth, pure CSS progress bar featuring a float-drift animation with rising bubbles, designed for product catalog layouts, storage usages, or loading indicators.

## Features
- Pure CSS and HTML implementation.
- Smooth width expansion on hover.
- Keyframe-animated drifting bubbles inside the progress fill.
- Fully responsive across all viewports.
- Honors the `prefers-reduced-motion` accessibility standard by disabling animations.

## Usage
Open `demo.html` in your browser. Hover over the product card to see the progress bar fill up and reveal the floating drift bubbles inside the bar.

## Files
- `demo.html`: The HTML structure for the card component.
- `style.css`: The styling, flexbox layouts, and CSS keyframe animations.
