# Donut Chart CSS Component

Add ease-donut-chart-css-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|---------|
| `--dcc-accent` | `#6366f1` |
| `--dcc-accent2` | `#ec4899` |
| `--dcc-accent3` | `#10b981` |
| `--dcc-accent4` | `#f59e0b` |
| `--dcc-radius` | `12px` |

## Technique

`conic-gradient` creates the donut chart rings. Inner circle via `::before` pseudo-element.
