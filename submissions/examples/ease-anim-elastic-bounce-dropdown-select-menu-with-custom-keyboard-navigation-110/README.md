# Elastic Bounce Dropdown Select Menu with Custom Keyboard Navigation

A vibrant dropdown select menu featuring elastic bounce animations, gradient styling, hover effects, and keyboard navigation built with pure HTML, CSS and JavaScript.

## Features

- Vibrant gradient design
- Elastic bounce opening animation
- Keyboard navigation support
- Smooth hover transitions
- Responsive layout
- Pure HTML, CSS & JavaScript

## Folder Structure

```
ease-anim-elastic-bounce-dropdown-select-menu-with-custom-keyboard-navigation-110/
├── README.md
├── demo.html
├── style.css
└── script.js
```

## Usage

Open `demo.html` in your browser.

Customize colors, gradients and animations in `style.css`.
