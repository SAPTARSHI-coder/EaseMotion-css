# CSS Text: Retro Arcade Pixel

A retro gaming inspired text animation featuring pixel-style shadows and arcade aesthetics.

## Features

- Pure HTML & CSS
- Retro arcade styling
- Pixel-inspired text shadows
- Smooth floating animation
- Responsive design
- Dark mode friendly
- Hardware accelerated

## Usage

```html
<h1 class="retro-pixel-text">
    GAME START
</h1>
```

## Files

- demo.html
- style.css
