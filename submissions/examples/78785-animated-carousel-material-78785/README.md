# Animated Carousel — Material

## Issue

EaseMotion CSS issue #78785.

## Overview

A responsive material-inspired card carousel using horizontal scrolling and CSS scroll snapping.

## Features

- Touch-friendly horizontal browsing
- Scroll snapping
- Material-style elevation
- Keyboard focus support
- Reduced-motion support

## Usage

Open `demo.html`. Add or remove `.card` elements as needed. The carousel does not require JavaScript for its basic interaction.

## Accessibility

The carousel can receive keyboard focus, cards use semantic articles, links remain native, and reduced-motion preferences disable transition effects.
