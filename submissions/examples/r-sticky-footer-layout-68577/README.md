# CSS Sticky Footer Layout

A responsive CSS layout that keeps the footer at the bottom of
the viewport when page content is short.

## Features

- Pure HTML and CSS
- Flexbox-based sticky footer
- Footer naturally moves below long content
- Responsive navigation
- Keyboard-accessible links
- Reduced-motion support
