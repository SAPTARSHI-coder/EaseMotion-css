# CSS High Contrast Mode Card

A responsive accessibility-focused card demonstrating strong
contrast, visible borders, keyboard focus states, and support
for forced-colors/high-contrast environments.

## Features

- Pure HTML and CSS
- Responsive layout
- Strong color contrast
- Visible keyboard focus state
- `forced-colors` support
- System color keywords for high contrast environments
- Reduced-motion support
- Semantic HTML
- No JavaScript required
