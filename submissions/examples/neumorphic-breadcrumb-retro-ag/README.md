# Neumorphic Breadcrumb with Retro Styling (ag)

A fully responsive breadcrumb navigation component that blends soft neumorphic UI elements with sharp, high-contrast retro gaming aesthetics (pixel font, cyan/magenta accents).

## Usage

```html
<nav class="breadcrumb-nav-retro-ag" aria-label="Breadcrumb">
    <ol class="breadcrumb-list-retro-ag">
        <li class="breadcrumb-item-retro-ag"><a href="#">Home</a></li>
        <li class="breadcrumb-item-retro-ag"><a href="#">Electronics</a></li>
        <li class="breadcrumb-item-retro-ag"><a href="#">Audio</a></li>
        <li class="breadcrumb-item-retro-ag active" aria-current="page">Retro Headphones</li>
    </ol>
</nav>
```

## Why it's useful

It provides a visually striking navigation element that fits perfectly into the modern revival of retro-futurism while maintaining the accessibility and structural integrity expected in modern web applications.
