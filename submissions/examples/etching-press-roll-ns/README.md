# Etching Press Roll

## What does this do?
Renders a self-contained CSS-only `ease-etching-press-roll` demo: Intaglio etching press roller flattening a plate.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-etching-press-roll`. No build step or JavaScript is required for the effect.

```html
<section class="ease-etching-press-roll">
  <div class="ease-etching-press-roll__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
