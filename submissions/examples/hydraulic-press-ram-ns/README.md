# Hydraulic Press Ram

## What does this do?
Renders a self-contained CSS-only `ease-hydraulic-press-ram` demo: Hydraulic press ram descending onto a workpiece.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-hydraulic-press-ram`. No build step or JavaScript is required for the effect.

```html
<section class="ease-hydraulic-press-ram">
  <div class="ease-hydraulic-press-ram__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
