# Blueprint Ink Roll

## What does this do?
Renders a self-contained CSS-only `ease-blueprint-ink-roll` demo: Diazo blueprint roller spreading cyan ink across paper.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-blueprint-ink-roll`. No build step or JavaScript is required for the effect.

```html
<section class="ease-blueprint-ink-roll">
  <div class="ease-blueprint-ink-roll__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
