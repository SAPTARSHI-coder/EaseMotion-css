# CSS Animated Signature

A responsive animated SVG signature that draws itself using pure CSS.

## Features

- Pure HTML and CSS
- Inline SVG
- CSS stroke-drawing animation
- No JavaScript
- Responsive design
- Accessible SVG title and description
- Reduced-motion support
- High-contrast mode support
- No external dependencies
- Lightweight implementation
