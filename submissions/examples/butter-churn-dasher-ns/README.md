# Butter Churn Dasher

## What does this do?
Renders a self-contained CSS-only `ease-butter-churn-dasher` demo: Butter churn dasher plunging through cream.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-butter-churn-dasher`. No build step or JavaScript is required for the effect.

```html
<section class="ease-butter-churn-dasher">
  <div class="ease-butter-churn-dasher__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
