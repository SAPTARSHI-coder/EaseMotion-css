# Toggle Switch Component

An interactive toggle switch component with smooth GPU-accelerated thumb sliding transitions.

## Features
- **Zero JavaScript:** Toggled natively via hidden HTML `<input type="checkbox">` `:checked` states.
- **Smooth Translation:** Uses `transform: translateX()` for fluid 60fps movement.
- **Glow Focus Accent:** Subtle glowing shadow feedback in the active/checked state.

## File Structure
- `demo.html` - Checkbox input and toggle label markup.
- `style.css` - Track styles, translate transforms, and active color states.
