# CSS Blur Entrance Popover

## Overview

A responsive gaming-inspired popover with a smooth blur entrance animation built using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Responsive Popover
- Blur Entrance Animation
- CSS Custom Properties
- Accessible (`prefers-reduced-motion`)
- No JavaScript Required

## Folder Structure

```text
blur-entrance-popover/
├── demo.html
├── style.css
└── README.md
```

## Usage

1. Open `demo.html`.
2. Hover over the trigger button.
3. Customize the CSS variables to match your project.

## CSS Variables

- `--primary`
- `--background`
- `--surface`
- `--text`
- `--duration`

## Browser Support

- Chrome
- Firefox
- Edge
- Safari
