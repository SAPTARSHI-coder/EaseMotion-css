# CSS Blur Entrance Popover

A modern popover component built entirely with HTML and CSS.

## Features

- Pure CSS
- Blur entrance animation
- Smooth easing
- Responsive layout
- Keyboard accessible
- No JavaScript
- Easy customization using CSS variables

## Files

- demo.html
- style.css

## Customization

```css
:root{
--duration:.45s;
--blur:18px;
--accent:#4f9dff;
}
