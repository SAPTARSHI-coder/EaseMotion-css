# CSS Ink Bleed Text


A pure CSS text animation that creates a wet ink spreading effect.


## Features

- Ink spreading animation
- Soft blur effect
- Paper-like text appearance
- Pure CSS implementation
- Responsive typography
- Reduced motion support


## Technologies

- HTML5
- CSS3 Animations


## Usage

Useful for:

- Creative landing pages
- Typography animations
- Artistic UI sections
- Portfolio designs
