# CSS Accordion — Morphing Shape

A responsive, accessible CSS-only accordion featuring a distinctive
morphing shape animation.

## Features

- Pure HTML + Vanilla CSS
- No JavaScript
- Native `<details>` and `<summary>`
- Morphing border-radius effect
- Animated morphing control icon
- Smooth content expansion
- Responsive design
- Automatic dark mode
- Keyboard accessible
- Reduced-motion support
- No external dependencies
