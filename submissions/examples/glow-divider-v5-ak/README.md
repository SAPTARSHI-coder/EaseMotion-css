# glow-divider-v5-ak

Pure CSS animated glowing gradient line divider component — no JavaScript required.

## How to use

```html
<hr class="ease-glowing-divider-v5" />

<!-- Divider with Badge -->
<div class="ease-glowing-divider-text-v5">
  <span class="ease-glowing-divider-badge-v5">OR</span>
</div>
