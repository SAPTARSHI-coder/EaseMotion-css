# CSS Clock Progress Arc

A CSS-only circular progress component styled as a clock. The clock hand
sweeps around the face to visually represent 75% completion.

## Features

- Pure HTML and CSS
- Animated clock hand
- Circular progress arc
- Clock-style tick marks
- Percentage indicator
- Responsive design
- Accessible progress description
- No JavaScript
- No external dependencies
- Reduced-motion support

## Files

- `demo.html` — Component markup and demonstration
- `style.css` — Complete styling and animations
- `README.md` — Documentation
