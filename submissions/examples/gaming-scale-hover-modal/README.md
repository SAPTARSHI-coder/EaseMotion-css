# CSS Scale-Hover Modal for Gaming Hub Layouts

A modern **Gaming Hub Modal** featuring a smooth **Scale-Hover** animation built entirely with **HTML5 and CSS3**. This example demonstrates an interactive modal dialog with elegant scaling effects, responsive design, and accessibility support—without requiring JavaScript.

---

## ✨ Features

- 🎮 Gaming Hub inspired interface
- 📦 Scale-Hover modal animation
- ✨ Smooth hover and transition effects
- 🎨 Modern gradient styling
- ⚡ Pure HTML5 & CSS3 (No JavaScript)
- 📱 Fully responsive across desktop, tablet, and mobile
- 🎯 CSS Custom Properties for easy customization
- ♿ Accessibility support with `prefers-reduced-motion`
- 🚀 Lightweight and performance-friendly

## 🚀 Getting Started

1. Open `demo.html` in any modern web browser.
2. Click the **Launch Event** button to display the modal.
3. Hover over the feature cards and action button to view the scale effects.
4. Customize colors, spacing, and animations using the CSS variables.
