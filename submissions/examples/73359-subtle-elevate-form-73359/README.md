# Subtle Elevate Form

## Overview

Implementation for EaseMotion issue #73359. The form uses restrained neumorphic elevation to provide depth without visual noise.

## Features

- Pure HTML and vanilla CSS
- Gentle hover elevation
- Pressed button state
- Responsive form grid
- Visible keyboard focus
- Reduced-motion support

## Accessibility

The form uses native controls with visible labels and a strong focus-visible outline. Motion is limited to small decorative translations and can be disabled by user preference.

## Performance

The effect uses CSS shadows and transforms and does not require JavaScript or external assets.

## Usage

Open `demo.html` and adjust the surface, shadow, and accent variables in `style.css` for another theme.

## Issue

EaseMotion CSS issue #73359.
