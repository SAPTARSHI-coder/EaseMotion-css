# glow-chip-ak

Pure CSS interactive glowing tag chip component — no JavaScript required.

## How to use

```html
<span class="ease-glow-chip">
  <span class="ease-glow-chip__icon">⚡</span> Tag Label
</span>

<!-- Color Variants -->
<span class="ease-glow-chip ease-glow-chip--emerald">...</span>
<span class="ease-glow-chip ease-glow-chip--rose">...</span>
<span class="ease-glow-chip ease-glow-chip--cyan">...</span>
