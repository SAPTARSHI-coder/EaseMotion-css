# Toggle Knob Spring

A settings-style toggle whose knob springs across the track with a colored trail.

## Features
- Knob travels with springy overshoot
- Track fills green as it toggles on
- Icon label flips with a tiny rotate

## Usage
```html
<div class="tk-row">
  <span class="tk-switch"><span class="tk-knob"></span></span>
  <span class="tk-label">Auto-save drafts</span>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
