# Morphing Shape Floating Badge with Gradient Transition Effects (Minimalist Clean Edition)

A modern floating badge component with smooth morphing border-radius animations and elegant gradient transitions. Built using pure HTML and CSS with a clean minimalist aesthetic.

## Features

- Minimalist clean design
- Floating animation
- Morphing border-radius
- Gradient transition effects
- Smooth hover interactions
- Responsive layout
- CSS variables
- Pure HTML & CSS

## Files

```
demo.html
style.css
README.md
```

## Usage

1. Open `demo.html` in your browser.
2. Ensure `style.css` is in the same folder.
3. Customize colors, text, and animations as desired.
