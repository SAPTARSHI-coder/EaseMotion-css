# Dynamic Datepicker - Neumorphism

A responsive Datepicker UI with a soft Neumorphism-inspired visual design.

The component is implemented using pure HTML and CSS with no external JavaScript dependencies.

## Features

- Neumorphic visual design
- Responsive calendar grid
- Previous and next month controls
- Selected date state
- Current date indicator
- Hover and active interactions
- Accessible focus-visible states
- Responsive mobile, tablet, and desktop layouts
- `prefers-reduced-motion` support
- No external JavaScript dependencies
