# CSS Blur Entrance Card Grid

A responsive card grid with a smooth blur entrance animation built using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Blur entrance animation
- Responsive card grid
- Hover elevation effect
- CSS Custom Properties
- Accessible with `prefers-reduced-motion`
- No JavaScript required

## Files

```
demo.html
style.css
README.md
```

```css
--bg
--card
--text
--accent
--radius
--duration
```

## Usage

1. Open `demo.html`.
2. Cards animate into view with a blur entrance.
3. Hover over cards for an elevated effect.

## Accessibility

- Supports `prefers-reduced-motion`
- Responsive layout
- Semantic HTML structure
