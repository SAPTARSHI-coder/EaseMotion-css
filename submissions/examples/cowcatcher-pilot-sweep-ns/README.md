# Cowcatcher Pilot Sweep

## What does this do?
Renders a self-contained CSS-only `ease-cowcatcher-pilot-sweep` demo: Pilot beam sweeping the roadbed.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-cowcatcher-pilot-sweep`. No build step or JavaScript is required for the effect.

```html
<section class="ease-cowcatcher-pilot-sweep">
  <div class="ease-cowcatcher-pilot-sweep__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
