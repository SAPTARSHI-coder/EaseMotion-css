\# Plasma Energy Core Component



A futuristic high-energy plasma reactor component featuring counter-rotating electrical arcs, a glowing pulsating purple core, and responsive control panels built for EaseMotion CSS.



\## Location

\- Directory: `submissions/examples/plasma-energy-core-kl/`



\## Files Included

\- `demo.html`: Interactive preview window showcasing the plasma energy core simulation.

\- `style.css`: Scoped plasma styling and keyframe rules (`ease-plasma-spin-cw`, `ease-plasma-spin-ccw`, `ease-plasma-pulse`).

\- `README.md`: Documentation for the component submission.
