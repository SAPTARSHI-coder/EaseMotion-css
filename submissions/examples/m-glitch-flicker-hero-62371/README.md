# CSS Glitch-Flicker Hero Section for Product Catalog Layouts

A modern **Glitch-Flicker Hero Section** built using pure HTML and CSS. The component features cyber-inspired glitch animations, responsive layouts, CSS custom properties, and lightweight styling for product catalog landing pages.

## ✨ Features

- Pure HTML5 & CSS3
- Glitch flicker text animation
- Responsive hero section
- CSS Custom Properties
- Modern gradient background
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
