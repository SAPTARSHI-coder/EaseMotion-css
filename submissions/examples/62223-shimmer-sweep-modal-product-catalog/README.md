# CSS Shimmer-Sweep Modal for Product Catalog Layouts

A premium product modal component featuring a smooth shimmer-sweep animation, elegant hover effects, glowing buttons, and a responsive layout. Built using pure HTML and CSS for the EaseMotion CSS showcase collection.

---

## ✨ Features

- Pure HTML5 & CSS3
- Modern shimmer sweep animation
- Smooth modal entrance effect
- Product showcase layout
- Responsive desktop, tablet & mobile design
- CSS Custom Properties
- Accessible design
- prefers-reduced-motion support
- No JavaScript required
