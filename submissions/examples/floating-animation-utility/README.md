# 🪁 Floating Animation Utility

A lightweight, reusable CSS utility that adds smooth vertical
floating motion to UI elements.

The utility is designed for cards, icons, illustrations, buttons,
hero elements, product images, and other interface components.

## Features

- Pure CSS
- No JavaScript
- Infinite looping animation
- GPU-friendly `transform` animation
- CSS variable customization
- Fast and slow variants
- Large-distance variant
- Responsive
- Reduced-motion support
- No external dependencies

## Basic Usage

Add the `em-float` class to any element:

```html
<div class="em-float">
  Floating Element
</div>
