EaseMotion CSS

Floating Animation

A lightweight, reusable CSS utility for adding a smooth floating motion to cards, icons, illustrations, and UI elements.

Animation Variants

✦

Default

.em-float

Balanced floating motion for general UI elements.

◆

Fast

.em-float-fast

Faster motion for playful icons and attention elements.

●

Slow

.em-float-slow

Gentle motion for hero artwork and backgrounds.

★

Large

.em-float-large

Increased movement distance for prominent elements.

Quick Usage

<div class="em-float">
  Floating Element
</div>

Respects prefers-reduced-motion.
