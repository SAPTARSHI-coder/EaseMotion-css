Under the Hood

Scroll-driven parallax translates scroll velocity into visual depth. By dividing your layout into layers and applying varying keyframe shifts relative to the viewport scroll timeline, elements closer to the "viewer" appear to move faster than elements in the distance.

No Javascript

Runs entirely on the browser's compositor thread using view() timelines for maximum performance.

A11y First

Respects user motion preferences instantly by disabling transforms when prefers-reduced-motion is active.

Smooth Fallbacks

Displays a beautiful static grid in older browsers without layout shifts or content loss.
