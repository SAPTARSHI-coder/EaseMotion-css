# Drag and Drop Zone Component

Add ease-drag-and-drop-zone-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|--------|
| `--dz-border-h` | `#6366f1` |
| `--dz-radius` | `12px` |
| `--dz-transition` | `0.3s` |

## Note

CSS handles visual states. Tiny JS adds/removes `drag-over` class on drag events.
