# Animated Toggle Switches

## Issue

#57925

## Description

A reusable CSS-only animated toggle switch component for creating smooth on/off controls.

## Features

- Smooth toggle animation
- CSS-only implementation
- Rounded and standard variants
- Keyboard accessible checkbox
- Responsive design
- Reduced-motion support
- No JavaScript required

## Files

- `demo.html` - Demo page
- `style.css` - Toggle switch styles and animations

## Usage

```html
<label class="switch">
  <input type="checkbox">
  <span class="slider"></span>
</label>
