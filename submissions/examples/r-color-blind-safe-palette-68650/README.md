# CSS Color Blind Safe Palette

A pure CSS color palette designed to reduce dependence on color alone
when communicating UI states.

## Features

- Pure HTML and CSS
- CSS custom properties
- Color-blind-friendly palette
- Text labels for every color
- Pattern overlays for additional visual distinction
- Responsive grid
- Hover interaction
- Reduced-motion support
- No JavaScript required
