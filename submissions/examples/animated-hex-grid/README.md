# CSS Animated Hex Grid 🔷


A pure CSS animated hexagonal grid component with hover ripple effects.


## Features

- Pure CSS implementation
- Hexagonal grid layout
- Hover glow animation
- Smooth floating motion
- Responsive design
- Reduced motion accessibility support


## Technologies

- HTML5
- CSS3
