# CSS Pulsating Wave Form

Issue #73346 demonstrates a rhythmic form surface using expanding CSS wave rings.

## Features

- Layered pulse rings
- Native range control
- Responsive form layout
- Visible keyboard focus
- Reduced-motion support
- No external JavaScript

## Accessibility

All controls are labeled and remain keyboard accessible. Decorative wave animation stops for reduced-motion users.

## Files

- `demo.html` — semantic form example
- `style.css` — wave animation and responsive styling
- `README.md` — documentation
