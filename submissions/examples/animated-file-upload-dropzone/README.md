# Animated File Upload Dropzone

A visually engaging file upload dropzone example built using EaseMotion CSS animations.

## Features

- Pulsing upload icon
- Drag and drop interaction
- Animated file list entrance
- Smooth progress bar animation
- Bouncy upload success state
- Responsive design

## Files

- `demo.html` - HTML structure
- `style.css` - Styling and animations

## Usage

Open `demo.html` in a browser to view the animated file upload dropzone.
