# Animated File Upload Dropzone

A clean, modern, and fully responsive **File Upload Dropzone** that makes the file submission process engaging and visually rewarding. This example demonstrates how to combine **EaseMotion CSS** for continuous pulsing icons, smooth progress bar fills, and bouncy success checkmarks to create an interactive file upload experience.

## 🚀 Features

- **Pulsing Upload Icon**: The cloud icon uses `ease-pulse` to continuously draw the user's attention to the drop zone.
- **Interactive Drag & Drop**: The drop zone smoothly scales up and changes color when files are dragged over it.
- **Staggered File List**: Uploaded files fade in smoothly using `ease-fade-in-up` as they are added to the list.
- **Smooth Progress Bar**: The progress bar fills smoothly with a custom CSS transition, changing to green upon completion.
- **Bouncy Success Checkmark**: When an upload completes, a green checkmark pops in using `ease-bounce-in` for a satisfying confirmation.
- **Smooth Removal**: Files can be removed with a smooth fade-out and slide-right animation.
- **Fully Responsive**: Adapts gracefully to mobile screens with adjusted padding and layout wrapping.
