# CSS Float-Drift Card Grid for SaaS Showcase Layouts

A modern **Float-Drift Card Grid** built using pure HTML and CSS. The cards feature subtle floating animations, glassmorphism styling, and a responsive layout ideal for SaaS landing pages, dashboards, and product showcases.

## ✨ Features

- Pure HTML5 & CSS3
- Float-drift animation
- Glassmorphism cards
- Responsive grid layout
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
