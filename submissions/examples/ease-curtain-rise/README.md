# Curtain Rise · Curtain Rises to Reveal 🎭

An interactive curtain rise animation with draping fabric, folds, and a dramatic reveal effect. Watch the curtain rise to reveal what's behind!

## Features

- 🎭 **Theatre Curtain** – Realistic draping fabric
- 🎚️ **Speed Control** – Adjust rise/lower speed (1-10)
- 🎚️ **Fold Control** – Adjust number of folds (4-12)
- ⏸️ **Pause/Resume** – Toggle animation
- 🔄 **Reset** – Reset to closed state
- ✨ **Dramatic Reveal** – Curtain rises to reveal stage

## How to Use

1. Click **RISE** or press **Space** to raise the curtain
2. Click **LOWER** or press **Space** again to lower
3. Adjust **Speed** for rise/lower pace
4. Adjust **Folds** for curtain complexity
5. Press **RESET** or **R** to reset
6. Press **PAUSE** or **P** to pause/resume animation

## Technical Details

- **Curtain:** Draping fabric with wave animation
- **Folds:** 4-12 folds with shading
- **Animation:** Smooth rise/lower interpolation
- **Performance:** 60fps with requestAnimationFrame

## Customization
