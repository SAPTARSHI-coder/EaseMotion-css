# Bellows Forge Blast

## What does this do?
Renders a self-contained CSS-only `ease-bellows-forge-blast` demo: Forge bellows pumping blast air into glowing coals.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-bellows-forge-blast`. No build step or JavaScript is required for the effect.

```html
<section class="ease-bellows-forge-blast">
  <div class="ease-bellows-forge-blast__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
