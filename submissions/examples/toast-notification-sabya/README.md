### What does this do?
This component provides reusable, pure CSS animated toast and snackbar notifications with smooth slide-in and fade-out effects across four variants (success, error, warning, info).

### How is it used?
Add the base `.toast` class along with a variant class to your container.

```html
<div class="toast toast-success">
    <span class="toast-icon">✓</span>
    <div class="toast-message">Changes saved successfully!</div>
</div>
