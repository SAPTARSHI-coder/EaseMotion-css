# Glowing Slider with Neon Styling

A responsive neon-inspired range slider featuring glowing effects, animated gradients, interactive value feedback, and a modern dark interface.

## Features

- Neon glowing slider track
- Dynamic progress indicator
- Interactive percentage output
- Glowing slider thumb
- Hover and active states
- Modern dark UI
- Responsive layout
- Smooth micro-interactions
- Keyboard accessible
- Visible focus state
- Reduced-motion support
- Pure HTML, CSS, and minimal JavaScript
- No external dependencies

## Preview

Open `demo.html` in a modern browser to view the component.
