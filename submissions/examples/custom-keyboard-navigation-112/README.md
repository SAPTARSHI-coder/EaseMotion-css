# Elastic Bounce Dropdown Select Menu

A responsive dropdown select menu with a smooth elastic bounce
animation and custom keyboard navigation.

## Features

- Elastic dropdown animation
- Neumorphic mobile-first design
- Keyboard navigation
- Arrow Up / Arrow Down support
- Enter and Space selection
- Escape to close
- Click outside to close
- Responsive design
- Reduced-motion accessibility support
- No external libraries

## Files

- `demo.html` - HTML structure and JavaScript functionality
- `style.css` - Styling and animations

## Keyboard Controls

| Key | Action |
|-----|--------|
| Enter | Open or select |
| Space | Open or select |
| Arrow Down | Next option |
| Arrow Up | Previous option |
| Escape | Close menu |

## Usage

Open `demo.html` in a modern browser.

The component can be reused by copying the dropdown HTML,
CSS, and JavaScript into another project.

## Technologies

- HTML5
- CSS3
- JavaScript
- CSS Transitions
- CSS Animations

## Accessibility

The component uses ARIA attributes and supports keyboard
navigation. It also respects the user's
`prefers-reduced-motion` setting.
