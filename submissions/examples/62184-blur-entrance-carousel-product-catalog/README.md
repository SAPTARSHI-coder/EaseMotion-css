# CSS Blur-Entrance Carousel for Product Catalog Layouts

A modern product carousel showcasing smooth blur-entrance animations, glassmorphism cards, responsive layouts, and elegant hover interactions using only HTML5 and CSS3.

---

## ✨ Features

- Pure HTML5 & CSS3
- Blur entrance animation
- Glassmorphism product cards
- Responsive carousel grid
- Smooth hover interactions
- CSS Custom Properties
- Modern gradient styling
- Accessible design
- prefers-reduced-motion support
- No JavaScript required
