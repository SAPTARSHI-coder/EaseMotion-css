# Glowing Stepper Progress Indicator Component

An interactive multi-step workflow progress bar component with glowing neon step nodes, status indicators, and active pulse keyframe animations.

## What does this do?
Renders step-by-step wizard progress bars with check icons for completed stages, pulsing glowing rings for active stages, and connecting track fills.

## How is it used?
1. Open `demo.html` to preview step state transitions.
2. Incorporate the `.stepper-wrapper` component into multi-step forms or onboarding flows.
3. Import `style.css` to enable step node pulse keyframes and track fill glow effects.

## Why is it useful?
Stepper components guide users through complex flows (checkout, registration, onboarding). Hardware-accelerated CSS keyframe pulses provide visual status feedback cleanly without heavy JS overhead.
