# Animated Pastel Spinner (Lite)

A lightweight and responsive animated loading spinner with a soft pastel visual style.

## Features

- Clean pastel design
- Smooth CSS-only animation
- Fully responsive
- Lightweight implementation
- No JavaScript required
- No external dependencies
- Reduced-motion support
