# File Pill Focus

A file upload styled as a pill that pulses and glows on focus.

## Features
- Pill-shaped label
- Focus glow ring
- Paperclip icon accent
- Pure CSS

## Usage
```html
<label class="fpf-pill" for="f">Choose a file</label><input id="f" type="file" />
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
