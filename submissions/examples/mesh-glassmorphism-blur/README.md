# Glassmorphism Blur Mesh Gradient

A smooth and responsive CSS mesh gradient component featuring a
glassmorphism blur effect.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript required
- Multi-layer radial mesh gradients
- Glassmorphism blur effect
- `backdrop-filter` support
- Smooth hover transitions
- Subtle 3D perspective interaction
- Responsive layout
- Keyboard focus support
- Reduced-motion support
- No external dependencies

## Files

- `demo.html` — Standalone browser demo
- `style.css` — Complete CSS implementation

## Usage

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
