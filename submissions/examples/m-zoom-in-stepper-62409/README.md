# CSS Zoom-In Stepper for Product Catalog Layouts

A modern **Zoom-In Stepper** built using pure HTML and CSS. The component features smooth zoom-in hover interactions, responsive layouts, CSS custom properties, and lightweight styling for product catalog workflows.

## ✨ Features

- Pure HTML5 & CSS3
- Zoom-in hover animation
- Responsive stepper layout
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
