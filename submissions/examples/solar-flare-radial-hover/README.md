# CSS Solar Flare Radial Hover Effect

A high-impact, pure CSS hover effect that creates an expanding, radiant solar corona aura using radial gradients and keyframed blur pulses.

## 🎯 Features
- **Pure CSS/HTML:** Zero JavaScript required.
- **Hardware-Accelerated Glow:** Utilizes pseudo-element layers with `radial-gradient`, `filter: blur()`, and `transform` for efficient GPU rendering.
- **Dark Mode Tuned:** Calibrated warm amber and crimson tones designed for dark interfaces.
- **Accessible & Responsive:** Implements `:focus-visible` outlines, `tabindex="0"`, and disables continuous pulse scaling under `@media (prefers-reduced-motion: reduce)`.
