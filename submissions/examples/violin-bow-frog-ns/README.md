# Violin Bow Frog

## What does this do?
Renders a self-contained CSS-only `ease-violin-bow-frog` demo: Violin bow frog drawing hair across the string.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-violin-bow-frog`. No build step or JavaScript is required for the effect.

```html
<section class="ease-violin-bow-frog">
  <div class="ease-violin-bow-frog__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
