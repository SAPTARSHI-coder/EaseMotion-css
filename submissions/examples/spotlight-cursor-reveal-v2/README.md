# Spotlight cursor reveal

A dark card that reveals a hidden pattern grid under a circular spotlight that follows the cursor.

## How to view

Open `demo.html` in any modern browser. The demo is fully self-contained — no CDN, no framework, no JavaScript.

## How to use

Copy `style.css` into your project's stylesheet. Every class used in the demo is namespaced with `spotlightcursorrevealv2-` to avoid collisions.

## Why this is useful for EaseMotion CSS

Empty-state / locked-content pattern; the spotlight guides the eye to the actionable area.
