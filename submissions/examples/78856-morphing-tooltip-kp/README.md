# Morphing Tooltip - SaaS Modern

A SaaS-style morphing tooltip component for issue #78856. The trigger expands into a contextual help surface with animated status chips, focus support, and reduced-motion handling.

## Features

- Hover and keyboard focus reveal
- Morphing capsule-to-panel tooltip transition
- Animated confidence meter, shimmer border, and status chips
- Pure HTML and CSS with no external assets
