# Animated Accordion & FAQ

A responsive **CSS-only Animated Accordion / FAQ** component built with HTML checkboxes and CSS. It provides smooth expand/collapse animations and a rotating chevron icon without requiring JavaScript.

## Features

- CSS-only implementation
- Smooth expand and collapse animation
- Rotating chevron indicator
- Responsive design
- Beginner-friendly code
- Easy to customize
- No JavaScript required

## Folder Structure

```
animated-accordion-faq/
├── demo.html
├── style.css
└── README.md
```

## Usage

1. Open `demo.html` in any modern browser.
2. Link `style.css` in your project.
3. Modify the FAQ questions and answers as needed.

## Customization

You can customize:

- Colors
- Fonts
- Border radius
- Animation speed
- Icons
- Number of FAQ items
- Spacing
