# Animated Crypto/Finance Dashboard

A sleek **Crypto Dashboard** built with **EaseMotion CSS**. Features portfolio overview with animated chart, crypto price cards with sparklines, holdings list, transaction history, and top market movers.

## ✨ Features

- **📈 Portfolio Chart**: Animated SVG line chart with gradient fill
- **💰 Price Cards**: 4 crypto cards with sparkline animations
- **📊 Sparklines**: SVG line drawings that animate on load
- **💼 Holdings List**: Asset breakdown with USD values
- **📋 Transactions**: Buy/sell/transfer history with icons
- **🚀 Top Movers**: 24h gainers/losers with pulse effect
- **🟢 Market Status**: Pulsing live market indicator
- **🎬 Staggered Entrance**: All sections slide up sequentially
- **📱 Fully Responsive**: 4-column → 2-column → 1-column layout

## 🧩 EaseMotion Classes Used

| Class | Purpose |
|-------|---------|
| `ease-fade-in` | Fades in the main page and footer |
| `ease-slide-up` | Slides sections up on entrance |
| `ease-delay-100` to `ease-delay-700` | Creates cascading staggered sequence |
| `ease-card` | Base card structure |
| `ease-hover-lift` | Lift effect on cards |
| `ease-hover-grow` | Scale effect on buttons |
| `ease-grid` + `ease-grid-cols-4` | Responsive grid layouts |
| `ease-gap-4` | Spacing between grid items |
| `ease-pulse` | **Looping pulse** on market status and top mover |
| `ease-center` | Centers various elements |

## 🚀 How to Use

1. Open `demo.html` in any modern browser
2. Watch all sections slide in with staggered animations
3. Observe the **portfolio chart drawing** and **sparklines animating**
4. Notice the **pulsing market status** indicator
5. Hover over price cards to see lift effects
6. Hover over holdings and transactions
7. Resize to mobile to see responsive layout
