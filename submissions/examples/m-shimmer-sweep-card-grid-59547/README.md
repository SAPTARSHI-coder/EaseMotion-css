# CSS Shimmer-Sweep Card Grid for SaaS Showcase Layouts

A modern **Shimmer-Sweep Card Grid** built using pure HTML and CSS. The cards feature a sleek shimmer sweep hover effect combined with a responsive glassmorphism layout, making them ideal for SaaS landing pages, dashboards, and product showcases.

## ✨ Features

- Pure HTML5 & CSS3
- Shimmer sweep hover animation
- Glassmorphism cards
- Responsive grid layout
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
