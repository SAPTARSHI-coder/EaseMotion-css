# CSS Zoom-In Popover for Accessible Web Layouts

A modern **Zoom-In Popover** component built completely with **HTML5 and CSS3**. This showcase demonstrates interactive popover cards with smooth zoom animations, glowing effects, glassmorphism styling, responsive layouts, and accessibility support without requiring JavaScript.

---

## ✨ Features

- 🔍 Smooth zoom-in popover animation
- 💎 Glassmorphism card design
- 🌈 Gradient button styling
- ✨ Glow effects
- 🎯 CSS Custom Properties
- ⚡ Smooth CSS transitions
- 📱 Fully responsive layout
- 🧩 Pure HTML5 & CSS3
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

## 🚀 Getting Started

1. Open `demo.html` in any modern browser.
2. Hover over the buttons to reveal the popovers.
3. Customize colors, spacing, and animation timing using CSS variables.
