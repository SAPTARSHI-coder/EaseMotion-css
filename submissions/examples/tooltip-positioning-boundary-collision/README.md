# Tooltip Positioning Boundary Collision Check

## Overview

Adds automated Vitest tests for tooltip positioning and boundary collision handling.

## Coverage

- Normal positioning
- Top collision
- Left collision
- Right collision
- Bottom collision
- Exact viewport fit
- Invalid inputs
- Small tooltips
- Large viewport
- Boundary validation

## Demo

Open `demo.html` directly.

## Run

```bash
npx vitest run submissions/examples/tooltip-positioning-boundary-collision/tooltip-boundary.test.js
```

All contribution files remain inside `submissions/`.
