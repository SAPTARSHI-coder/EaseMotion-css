# Payment Method Card

Selectable payment cards with a radio check that slides in and glows when chosen.

## Features
- Radio-driven selection state
- Checkmark sweeps in on the active card
- Focused card lifts and borders brighten

## Usage
```html
<label class="pm-card">
  <input type="radio" name="pay" />
  <span class="pm-radio"></span>
  <span class="pm-meta"><span class="pm-name">Card</span></span>
</label>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
