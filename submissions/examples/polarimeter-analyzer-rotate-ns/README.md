# Polarimeter Analyzer Rotate

## What does this do?
Renders a self-contained CSS-only `ease-polarimeter-analyzer-rotate` demo: Lab polarimeter analyzer rotating over polarized sample.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-polarimeter-analyzer-rotate`. No build step or JavaScript is required for the effect.

```html
<section class="ease-polarimeter-analyzer-rotate">
  <div class="ease-polarimeter-analyzer-rotate__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
