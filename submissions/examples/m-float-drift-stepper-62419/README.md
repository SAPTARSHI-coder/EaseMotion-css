# CSS Float-Drift Stepper for Product Catalog Layouts

A modern **Float-Drift Stepper** built using pure HTML and CSS. The component features smooth floating step animations, responsive layouts, CSS custom properties, and lightweight styling for product catalog workflows.

## ✨ Features

- Pure HTML5 & CSS3
- Float-drift animation
- Responsive stepper layout
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
