# CSS Ripple-Wave Dropdown for Product Catalog Layouts

A modern dropdown component built with pure HTML and CSS featuring a ripple-wave hover animation. Ideal for product catalog navigation and category menus.

## ✨ Features

- Pure HTML5 & CSS3
- Ripple-wave hover animation
- Smooth dropdown transition
- Responsive layout
- CSS Custom Properties
- Keyboard accessible using `:focus-within`
- `prefers-reduced-motion` support
- No JavaScript required
