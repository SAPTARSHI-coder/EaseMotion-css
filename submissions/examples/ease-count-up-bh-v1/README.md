# ease-count-up-bh

CSS-based animated number count-up effect.

## What does this do?
Creates animated number counters that increment when they come into view.

## How is it used?
```html
<div class="ease-count-up-bh" data-target="1000">0</div>
```

## Why is it useful?
Displays statistics and metrics in an engaging, animated way.
