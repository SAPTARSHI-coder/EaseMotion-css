# Synthwave Grid Line Toast

A pure HTML and CSS toast notification inspired by retro-futuristic
synthwave interfaces.

## Features

- Synthwave grid-line visual treatment
- Animated neon scan line
- Glowing notification icon
- Smooth entrance animation
- Responsive layout
- Dark mode compatible
- Light mode support
- Keyboard-focusable close button
- Reduced-motion support
- Hardware-friendly CSS transforms
- No external libraries
- No JavaScript required

## Preview

The component combines a glass-style notification panel with a
perspective synthwave grid and animated neon accents.
