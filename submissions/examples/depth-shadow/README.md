# CSS Depth Shadow Card

A demo project showcasing a **depth shadow card** using HTML and CSS.

## Features
- Multiple layered shadows to simulate depth.
- Smooth hover effect that lifts the card and intensifies shadows.
- Responsive card design with image, text, and CTA button.
- Clean, modern styling.

## Files
- `demo.html` → Structure of the card with image, content, and button.
- `style.css` → Styling for shadows, hover effects, and layout.
- `README.md` → Documentation and usage instructions.

## Usage
1. Open `demo.html` in your browser.
2. Hover over the card to see the depth shadow effect.
3. Customize the card content and button for your own project.

## Customization Ideas
- Adjust shadow layers for stronger or softer depth.
- Add multiple cards in a grid layout.
- Use gradient backgrounds or textured images for variety.
- Integrate with JavaScript for interactive card flipping or expansion.
