# Floating Rating — Dark Mode

A responsive floating rating component with a minimalist dark-mode
visual style, created with pure HTML and CSS for EaseMotion CSS
issue #81444.

## Features

- Minimalist dark-mode interface
- Floating card presentation
- Five-star rating control
- Pure CSS rating interaction
- Keyboard-accessible rating controls
- Focus-visible accessibility state
- Smooth hover transitions
- Subtle floating ambient effects
- Soft glass-like surface
- Warm accent glow
- Responsive typography
- Responsive star controls
- Mobile, tablet and desktop layouts
- `prefers-reduced-motion` support
- Zero JavaScript dependencies
