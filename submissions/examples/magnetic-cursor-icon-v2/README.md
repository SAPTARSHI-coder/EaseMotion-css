# Magnetic cursor icon

An icon that drifts toward the cursor while the cursor is in its hover area, snapping back when it leaves.

## How to view

Open `demo.html` in any modern browser. The demo is fully self-contained — no CDN, no framework, no JavaScript.

## How to use

Copy `style.css` into your project's stylesheet. Every class used in the demo is namespaced with `magneticcursoriconv2-` to avoid collisions.

## Why this is useful for EaseMotion CSS

Marketing hero pattern; the subtle drift draws the eye to the primary action.
