# CSS Ripple-Wave Accordion for SaaS Showcase Layouts

A modern **Ripple-Wave Accordion** component built using pure HTML5 and CSS3 for SaaS showcase layouts. This component provides interactive accordion sections with ripple-wave hover effects, smooth transitions, glassmorphism styling, and responsive behavior.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* CSS-only accordion interaction
* Smooth expand and collapse animation
* Ripple-wave hover effect
* SaaS FAQ / knowledge center layout
* Animated gradient numbering indicators
* Glassmorphism accordion cards
* Smooth hover transitions
* Responsive desktop, tablet, and mobile layouts
* CSS Custom Properties for easy customization
* Smooth keyframe animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Click accordion items to expand the content.
3. Customize colors, shadows, spacing, and animation effects using CSS variables inside `:root`.

## CSS Custom Properties

```css
:root{
  --bg:#eef4ff;
  --surface:rgba(255,255,255,.92);
  --primary:#2563eb;
  --secondary:#06b6d4;
  --accent:#8b5cf6;
  --text:#111827;
  --muted:#64748b;
  --shadow:0 20px 55px rgba(37,99,235,.18);
  --radius:24px;
}
```
