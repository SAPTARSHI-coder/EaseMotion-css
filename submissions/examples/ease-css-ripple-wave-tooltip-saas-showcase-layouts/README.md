# CSS Ripple-Wave Tooltip for SaaS Showcase Layouts

A modern SaaS-style tooltip component featuring a smooth ripple-wave animation effect built completely with pure HTML and CSS.

This component is designed for SaaS dashboards, product showcases, and interactive landing pages where lightweight animated feedback is required without JavaScript.


## ✨ Features

- 🌊 Smooth ripple-wave animation effect
- 💬 Modern SaaS tooltip component
- 🎨 Glassmorphism inspired interface
- ⚡ Pure HTML and CSS implementation
- 📱 Fully responsive layout
- 🔄 CSS transitions and keyframe animations
- ♿ prefers-reduced-motion accessibility support
- 🚀 Lightweight and framework-free

## 🚀 Usage

1. Open `demo.html` directly in your browser.

2. Hover over the feature card to reveal the tooltip.

3. Customize CSS variables inside `style.css` according to your design requirements.


## 🎨 CSS Custom Properties

The component uses CSS variables for easy customization:

```css
:root {

    --bg:#020617;
    --card:#0f172a;
    --primary:#22d3ee;
    --secondary:#8b5cf6;
    --text:#f8fafc;
    --muted:#94a3b8;

}

Update these values to create your own theme.

The component supports reduced motion preferences.

Implemented using:

Animations are minimized for users who prefer reduced motion.
