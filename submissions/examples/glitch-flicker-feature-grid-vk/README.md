# Glitch-Flicker Feature Grid for Accessible Web Layouts

A responsive feature grid built with pure HTML and CSS. Each feature card includes a subtle glitch-flicker hover animation, making it ideal for modern dashboards, landing pages, and accessible web layouts without requiring JavaScript.

---

## Features

- Pure HTML5 and CSS3 (No JavaScript)
- Smooth glitch-flicker hover animation
- Responsive feature grid layout
- Easy customization using CSS custom properties
- Lightweight and performant
- Supports `prefers-reduced-motion`

---

## Folder Structure

```
glitch-flicker-feature-grid-vk/
├── demo.html

```

---

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over a feature card to trigger the glitch-flicker animation.
3. Customize the feature content, colors, spacing, and animation timing to suit your project.

## CSS Custom Properties

```css
:root {
    --primary: #6366f1;
    --secondary: #4f46e5;
    --accent: #06b6d4;

    --background: #f4f7fb;
    --surface: #ffffff;
    --text: #1f2937;
    --muted: #6b7280;

    --radius: 16px;
    --shadow: 0 12px 30px rgba(0, 0, 0, 0.12);

    --duration: 0.35s;
}
```

## Accessibility

- Supports `prefers-reduced-motion` for users who prefer reduced animations.
- Uses semantic HTML5 elements for improved accessibility.
- Fully responsive across desktop, tablet, and mobile devices.
