# CSS Gradient Border Animated
A pure CSS animated gradient border component featuring a continuously rotating multi-color border with subtle animated color effects inside the card.

## Features

*  Continuously rotating gradient border
*  Animated inner color glow effects
*  Customizable gradient colors using CSS variables
*  Responsive across desktop, tablet, and mobile
*  Keyboard-accessible focus states
*  Supports `prefers-reduced-motion`
*  Pure CSS — no JavaScript or external dependencies

## Files

```text
css-gradient-border-animated/
├── demo.html
├── style.css
└── README.md
```

## Usage

Include the stylesheet in your HTML:

```html
<link rel="stylesheet" href="style.css">
```

Then use the component structure provided in `demo.html`.

The appearance can be customized through the CSS variables in `style.css`, including the background, text colors, gradient colors, and animation timing.

## Accessibility

The component includes:

* Semantic HTML structure
* Visible keyboard focus states
* Responsive text sizing
* `prefers-reduced-motion` support to disable animations for users who request reduced motion

## Technologies

* HTML5
* CSS3
* CSS Animations
* CSS Gradients
* CSS Custom Properties
