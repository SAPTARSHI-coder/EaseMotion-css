# CSS Skip to Content Link

## Overview

An accessible skip-to-content link that stays visually hidden until keyboard focus brings it into view.

## Features

- Native anchor navigation
- Focus-triggered entrance animation
- High-contrast focus state
- Semantic main-content target
- Responsive navigation example
- Reduced-motion support
- No JavaScript required

## Files

- `demo.html` — semantic page and skip link
- `style.css` — focus transition, layout, navigation, responsive rules
- `README.md` — documentation

## Accessibility

The skip link appears on keyboard focus and targets the primary `<main>` landmark. This allows keyboard users to bypass repeated navigation without requiring JavaScript.
