# Prism Plans

Prism Plans is a glassmorphism pricing page example for EaseMotion CSS. It includes an animated navigation bar, responsive Basic, Pro, and Enterprise cards, hover lift and zoom effects, and clear feature lists with accessible focus states.

## Preview

Open `demo.html` in a modern browser to see the frosted glass cards, coral and mint visual theme, staggered entrance animations, and responsive mobile layout. Google Fonts are loaded from the document head for the Space Grotesk and DM Sans type pairing.

## Run locally

1. Open the `submissions/examples/animated-pricing-cards-navbar` folder.
2. Double-click `demo.html`, or serve the folder with any local static server.
3. Keep `style.css` beside `demo.html` so the stylesheet loads correctly.
