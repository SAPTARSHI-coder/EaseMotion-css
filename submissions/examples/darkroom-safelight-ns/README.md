# Darkroom Safelight

## What does this do?
Renders a self-contained CSS-only `ease-darkroom-safelight` demo: Darkroom safelight glowing while a print develops.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-darkroom-safelight`. No build step or JavaScript is required for the effect.

```html
<section class="ease-darkroom-safelight">
  <div class="ease-darkroom-safelight__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
