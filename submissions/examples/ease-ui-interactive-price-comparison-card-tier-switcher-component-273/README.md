# Interactive Price Comparison Card Tier Switcher Component (Dark Mode Variant)

1. **What does this do?** 
   A sleek, high-contrast dark mode pricing table. It features deep dark backgrounds, subtle low-opacity borders, and striking neon blue gradients that glow on hover. It includes a functional pill-shaped toggle switch for seamlessly transitioning between monthly and annually billing cycles.

2. **How is it used?** 
   Just use the `demo.html` structure and the accompanying `style.css`. The component utilizes CSS variables for easy theming (so you can easily swap the blue accent for any other color). A small, self-contained JavaScript snippet handles the fast, snappy vertical slide animation when swapping prices.

3. **Why is it useful?** 
   Dark mode is essential for modern web applications. This component provides a robust, state-of-the-art dark theme pricing section that looks incredibly premium, while still adhering to the EaseMotion CSS philosophy of clean code, smooth animations, and zero heavy dependencies.
