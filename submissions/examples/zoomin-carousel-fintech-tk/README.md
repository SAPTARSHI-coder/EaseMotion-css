# Zoom-In Carousel (Fintech Dashboard)

## What does this do?

This component provides a modern **Zoom-In Carousel** for fintech dashboard layouts using pure HTML and CSS. It highlights financial information inside interactive cards where the active card smoothly scales into focus.

---

## Features

- Pure HTML & CSS (No JavaScript)
- Zoom-in focus animation
- Interactive card selection using CSS radio buttons
- Glassmorphism-inspired card design
- Fintech dashboard theme
- Responsive layout
- Supports `prefers-reduced-motion`
- Easy to customize

---

## Files

- `demo.html` — Demo page showcasing the component
- `style.css` — Component styling and animations
- `README.md` — Documentation

---

## Usage

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

Then copy the component markup from `demo.html`.

---
