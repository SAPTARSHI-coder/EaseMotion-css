
---

## 🚀 Usage
1. Clone or copy the files into your project.
2. Open `demo.html` in your browser.
3. The cloud will display with rotating arrows to indicate sync.

---

## 🛠️ Customization
- **Arrow speed** → Adjust `animation: rotate 2s` for faster/slower rotation.
- **Colors** → Change `color` in `.arrow` for different sync states.
- **Cloud size** → Modify `.cloud-sync` width/height for larger or smaller clouds.

---

## 📖 Accessibility
- Uses `role="img"` and `aria-label="Cloud sync animation"` for screen readers.
- Keyboard focus not required since it’s a decorative animation.
