# Parallax Carousel

Showcase for issue #78682.

## Files

- `demo.html` — semantic slide content.
- `style.css` — horizontal layout, depth effects, and responsive behavior.

## Features

- Horizontal scroll carousel.
- Scroll snapping.
- Hover lift effect.
- Responsive card widths.
- Reduced-motion fallback.

Open `demo.html` to view the example.
