# Simple Border Box

## What it does

This submission creates a simple CSS-only border box utility for wrapping small content blocks, settings groups, notes, and grouped section content.

## How to use it

Wrap any small content area with the utility class:

```html
<div class="simple-border-box">
  <p>Content goes here.</p>
</div>
```

## Why it fits EaseMotion CSS

It fits EaseMotion CSS because it is human-readable, composable, and useful across many interfaces. It works well in dashboards, forms, cards, settings panels, and grouped content sections.

## Included features

- Subtle bordered box utility
- Soft variation included in the demo
- Practical grouped-content layout example
- Responsive demo layout
- Pure HTML and CSS implementation
