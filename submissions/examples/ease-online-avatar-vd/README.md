# Ease Online Avatar

## What does this do?

A profile avatar with a small online status indicator and a subtle hover animation.

---

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<div class="online-avatar">
    <div class="avatar">VD</div>
    <span class="online-dot"></span>
</div>
```

### Features

- Circular avatar
- Online status dot
- Rounded design
- Hover animation
- Responsive sizing
- Lightweight and reusable

---

## Why is it useful?

Online avatars are commonly used in chat applications, messaging interfaces, team lists, and collaboration tools to show user availability.

This component provides a simple and reusable avatar with presence feedback while following the animation-first philosophy of EaseMotion CSS.
