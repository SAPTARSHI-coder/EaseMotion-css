# Price Tag Sticker

A die-cut price tag with a ribbon, punched hole and dangling string, gently swaying.

## Features
- Die-cut tag shape with rotated ribbon
- Hole punch and twine for realism
- Gentle idle sway animation

## Usage
```html
<div class="pt-tag">
  <div class="pt-string"></div>
  <div class="pt-card"><p class="pt-price">$19.99</p></div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
