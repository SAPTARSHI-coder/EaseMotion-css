# CSS Morph-Glow Toast for SaaS Showcase Layouts

A modern **Morph-Glow Toast** component built using pure HTML5 and CSS3 for SaaS showcase layouts. This component provides animated notification cards with morphing glow effects, smooth hover interactions, glassmorphism styling, and responsive behavior.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Morphing glow background animation
* Smooth toast entrance animation
* SaaS notification showcase UI
* Success, info, and warning toast variants
* Glassmorphism notification cards
* Animated gradient glow effects
* Smooth scale hover interactions
* Floating notification layout
* Responsive desktop, tablet, and mobile layouts
* CSS Custom Properties for easy customization
* Lightweight keyframe animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over toast cards to view the scale and glow animation.
3. Customize colors, shadows, radius, and animations using CSS variables inside `:root`.

## CSS Custom Properties

```css
:root{
  --bg:#eef4ff;
  --surface:rgba(255,255,255,.92);
  --primary:#2563eb;
  --secondary:#06b6d4;
  --success:#22c55e;
  --warning:#f59e0b;
  --info:#8b5cf6;
  --text:#111827;
  --muted:#64748b;
  --shadow:0 25px 60px rgba(37,99,235,.2);
  --radius:28px;
}
```
