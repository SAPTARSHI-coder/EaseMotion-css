# CSS Expanding Menu Item

A polished, accessible and responsive expanding navigation item
built entirely with HTML and vanilla CSS.

Part of the EaseMotion CSS component collection.

## ✨ Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Hover expansion
- Keyboard focus support
- Smooth spring-like transitions
- Accessible navigation structure
- Responsive layout
- Dark-mode support
- Reduced-motion support
- High-contrast support
- Touch-device handling
- Hardware-friendly transforms
- Inline SVG icons
- Semantic HTML
