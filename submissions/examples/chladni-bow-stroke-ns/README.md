# Chladni Bow Stroke

## What does this do?
Renders a self-contained CSS-only `ease-chladni-bow-stroke` demo: Chladni plate bow stroke forming nodal sand patterns.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-chladni-bow-stroke`. No build step or JavaScript is required for the effect.

```html
<section class="ease-chladni-bow-stroke">
  <div class="ease-chladni-bow-stroke__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
