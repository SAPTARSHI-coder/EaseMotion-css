# EaseMotion CSS - Cyberpunk Neon Fade-In Carousel

A sleek, pure CSS fade-in carousel featuring a cyberpunk neon aesthetic. Built without any JavaScript, utilizing the radio-button hack for state management and smooth CSS transitions.

## Features

- **Pure CSS/HTML:** No JavaScript required.
- **Cyberpunk Theme:** Neon glows, dark backgrounds, and scanline effects.
- **Smooth Fade-In:** Elegant opacity and transform transitions.
- **Fully Responsive:** Adapts seamlessly to desktop, tablet, and mobile screens.
- **Accessible:** Includes `prefers-reduced-motion` support.

## Usage

1. Link the `style.css` in your HTML document.
2. Copy the HTML structure from `demo.html` into your project.
3. Customize the content inside `.ease-slide-content` and adjust the `--cyber-` CSS custom properties in `style.css` to match your exact design needs.

## CSS Custom Properties

- `--cyber-bg`: Background color of the page
- `--cyber-panel`: Background color of the carousel container
- `--cyber-cyan`: Primary neon cyan color
- `--cyber-magenta`: Secondary neon magenta color
- `--cyber-yellow`: Accent neon yellow color
- `--cyber-text`: General text color
- `--cyber-glow-cyan`: Text and box shadow for the cyan neon effect
- `--cyber-glow-magenta`: Text and box shadow for the magenta neon effect
