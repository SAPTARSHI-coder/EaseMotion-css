# Orbit Spinner

A satellite that orbits a glowing core while a counter-rotating dashed ring spins around it.

## Features
- Three independent motion layers: dashed ring, orbiter and glow core
- Reverse rotation keeps the composition balanced and hypnotic
- Sized entirely from one custom property

## Usage
```html
<div class="orb-spinner" role="status" aria-label="Loading">
  <span class="orb-ring"></span>
  <span class="orb-core"></span>
  <span class="orb-sat"></span>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
