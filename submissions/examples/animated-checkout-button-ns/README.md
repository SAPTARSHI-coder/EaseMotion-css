# CSS Animated Checkout Button (#71008)

An interactive, pure CSS checkout button that triggers a sliding shopping cart animation and transitions to an "Order Confirmed!" state upon click.

## Features
- Pure CSS state toggling via checkbox controller.
- Smooth `@keyframes` shopping cart driving animation across the button surface.
- Color and label transformation to feedback state (`#22c55e` success green).
- Clean BEM naming methodology (`ease-checkout`).
- Accessible keyboard activation (`tabindex="0"`, focus indicators, ARIA roles).
- Respects accessibility standards with `prefers-reduced-motion` safety overrides.
