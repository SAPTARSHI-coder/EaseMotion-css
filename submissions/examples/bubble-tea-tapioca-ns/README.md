# Bubble Tea Tapioca

## What does this do?
Renders a self-contained CSS-only `ease-bubble-tea-tapioca` demo: Bubble tea cup with tapioca pearls bobbing and rising.

## How is it used?
Open `demo.html` in a browser. The animated face uses classes like `ease-bubble-tea-tapioca`, `ease-bubble-tea-tapioca__arm`, and `ease-bubble-tea-tapioca__core`. No build step or JavaScript is required for the motion.

```html
<section class="ease-bubble-tea-tapioca">
  <div class="ease-bubble-tea-tapioca__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
