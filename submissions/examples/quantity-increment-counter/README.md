# Quantity increment counter

A plus/minus quantity spinner whose digit text slides up and out on each increment.

## How to view

Open `demo.html` in any modern browser. The demo is fully self-contained — no CDN, no framework, no JavaScript.

## How to use

Copy `style.css` into your project's stylesheet. Every class used in the demo is namespaced with `quantityincrementcounter-` to avoid collisions.

## Why this is useful for EaseMotion CSS

Cart / form input pattern; the slide motion confirms the value change clearly.
