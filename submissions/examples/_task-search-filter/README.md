# Task Search and Filter Component

A lightweight, responsive task search and status filter UI component with interactive filtering (All, Pending, Completed) and search capabilities.

## Features
- Real-time text search filter for task titles.
- Multi-tab status filtering (All, Pending, Completed) with visual active state.
- Dynamic count badges for each category.
- Clean responsive layout for mobile and desktop screens.
- Zero dependencies — pure HTML, CSS, and vanilla JS.

## Usage
Open `demo.html` directly in any standard browser.
