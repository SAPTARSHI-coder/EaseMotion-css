# Task Search and Filter UI Component

A responsive, self-contained UI component providing task title search and status filtering (All, Pending, Completed).

## Features
- **Search Input**: Live filtering by task titles with a clear button.
- **Filter Chips**: Interactive tabs with counters for All, Pending, and Completed states.
- **Responsive Layout**: Adapts between vertical mobile stacking and horizontal desktop alignment.
- **Accessible**: Built with ARIA roles (`tablist`, `tab`, `aria-selected`, and `aria-live`).

## Demo
Simply open `demo.html` in any web browser to test the interactive demo.
