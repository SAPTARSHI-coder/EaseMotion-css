# glow-tooltip-menu-ak

Pure CSS animated glowing popover menu component — no JavaScript required.

## How to use

```html
<div class="ease-popover-wrapper">
  <button class="ease-popover-trigger">Options</button>

  <ul class="ease-popover-menu">
    <li class="ease-popover-item"><a href="#">Link 1</a></li>
    <li class="ease-popover-item"><a href="#">Link 2</a></li>
  </ul>
</div>
