# Particle Burst Slider

A smooth, responsive, and performant **Particle Burst Slider** built with pure HTML and Vanilla CSS.

## ✨ Features

- ✨ Particle burst animation
- 🎨 Modern glowing visual effects
- ⚡ Pure HTML and CSS
- 🚫 No external JavaScript
- 📱 Responsive design
- 🧲 CSS scroll snapping
- 🌙 Dark-mode friendly
- ♿ Accessible navigation
- ⌨️ Keyboard-friendly focus states
- ♿ Reduced-motion support
- 🚀 Lightweight and performant
