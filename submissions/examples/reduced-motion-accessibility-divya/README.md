# Reduced Motion Accessibility

## Description

This component demonstrates how to support users who prefer reduced motion.

It uses the CSS media query:

```css
@media (prefers-reduced-motion: reduce)
```

to automatically minimize or disable animations when the operating system's accessibility setting is enabled.

## Features

- Floating animation
- Hover interaction
- Reduced Motion accessibility support
- Pure HTML & CSS
- Responsive layout

## Accessibility

Users who enable **Reduce Motion** in their operating system will experience:

- No floating animation
- No hover movement
- Minimal transitions
- Improved accessibility
