# Sticky Demo Navigation

A responsive sticky navigation example for EaseMotion CSS.

## Features

- Sticky navigation remains visible while scrolling
- Smooth anchor navigation between sections
- `scroll-margin-top` prevents section headings from being hidden behind the sticky navigation
- Responsive navigation for smaller screens
- Keyboard-focusable navigation links

## Files

- `demo.html` — demo page structure
- `style.css` — styling and responsive behavior
