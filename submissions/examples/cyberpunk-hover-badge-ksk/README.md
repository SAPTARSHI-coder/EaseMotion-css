# Cyberpunk Hover Badges

> Issue: [#79882](https://github.com/SAPTARSHI-coder/EaseMotion-css/issues/79882) / [#74305](https://github.com/SAPTARSHI-coder/EaseMotion-css/issues/74305)

A responsive, neon-glowing cyberpunk badge component with smooth hover transformations and clipped tech edges.

---

## ✨ Features & Architectural Highlights

- **Pure CSS Neon Effects:** Built using `clip-path` polygons, CSS `box-shadow` glows, and `letter-spacing` expansion.
- **Cyberpunk Color Palette:** Cyan, Pink, and Yellow high-contrast neon variants.
- **Accessible & Responsive:** Adapts to viewports with full `prefers-reduced-motion` compliance.

---

## 🚀 Usage

1. Include `style.css` in your HTML `<head>`:
   ```html
   <link rel="stylesheet" href="style.css">
   ```
2. Use the HTML structure provided in `demo.html`.
