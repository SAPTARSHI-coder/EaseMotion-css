# Cyberpunk Bounce-Pulse Tabs

A futuristic **CSS-only tab component** featuring cyberpunk-inspired neon visuals, bounce interactions, pulse animations, and a responsive glassmorphism layout. Built entirely with **HTML5** and **CSS3**, requiring no JavaScript or external libraries.

---

## ✨ Features

- ⚡ Pure HTML5 & CSS3
- 🎨 Cyberpunk neon design
- 💥 Bounce animation on hover
- 🌟 Pulsing glow for active tab
- 🪟 Glassmorphism interface
- 📱 Fully responsive layout
- ♿ Keyboard accessible
- 🌙 CSS Custom Properties for easy theming
- 🚀 No JavaScript required
- 🎯 Supports `prefers-reduced-motion`

## 🚀 Usage

1. Open `demo.html` in any modern web browser.
2. Click on a tab to switch between content panels.
3. Hover over a tab to see the bounce animation and neon glow.

## 🎨 CSS Custom Properties

Customize the appearance using the variables defined in `:root`.

| Variable | Description |
|----------|-------------|
| `--bg-color` | Page background |
| `--surface-color` | Glassmorphism container |
| `--primary-color` | Primary neon color |
| `--secondary-color` | Secondary neon color |
| `--accent-color` | Accent color |
| `--success-color` | Additional highlight color |
| `--text-color` | Primary text |
| `--muted-text` | Secondary text |
| `--border-radius` | Corner radius |
| `--transition-speed` | Animation duration |

Example:

```css
:root{
    --primary-color:#00f5ff;
    --secondary-color:#b026ff;
}
```
