# Ease Rating Stars

## What does this do?

A simple five-star rating display with active states and hover highlighting.

---

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<div class="rating">
    <span class="star active">★</span>
    <span class="star active">★</span>
    <span class="star active">★</span>
    <span class="star active">★</span>
    <span class="star">★</span>
</div>
```

### Features

- Five-star rating
- Active star state
- Hover highlight
- Hover scale animation
- Press feedback
- Responsive layout
- No JavaScript required

---

## Why is it useful?

Star ratings are commonly used in reviews, feedback forms, product cards, and rating interfaces.

This component provides a lightweight CSS-only rating display with subtle interaction feedback while following the animation-first philosophy of EaseMotion CSS.
