# Elastic-Slide Popover for Fintech Dashboard

A lightweight CSS-only Elastic-Slide Popover designed for modern fintech
dashboard interfaces.

## Features

- Pure HTML and CSS
- No JavaScript required
- Elastic slide-in animation
- Smooth scale and translate motion
- Keyboard accessible `<details>` / `<summary>` interaction
- Responsive desktop, tablet, and mobile layouts
- Hover and focus states
- CSS custom properties for easy customization
- `prefers-reduced-motion` accessibility support
- No external dependencies
