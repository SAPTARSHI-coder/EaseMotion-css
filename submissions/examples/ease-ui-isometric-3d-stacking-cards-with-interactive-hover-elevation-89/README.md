# Isometric 3D Stacking Cards with Interactive Hover Elevation

## Overview

A dark mode 3D stacking card component featuring isometric perspective,
interactive hover elevation, and smooth depth animations.

Built with pure HTML, CSS, and JavaScript.

## Features

- 🧊 Isometric 3D card stacking
- ✨ Interactive hover elevation
- 🌑 Dark mode UI
- ⚡ Neon glow effects
- 🎨 Gradient layered cards
- 📱 Responsive design
- 🖱️ Mouse perspective interaction

## Usage

1. Open `demo.html` in browser.
2. Move cursor over the card stack.
3. Experience the 3D perspective movement.
