# Nav Morph Burger

A hamburger icon morphs into a close X with spinning bars.

## Features
- Burger to X morph
- Bar rotation choreography
- Round end caps
- Pure CSS

## Usage
```html
<button class="nmb-btn" aria-label="menu"><i></i></button>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
