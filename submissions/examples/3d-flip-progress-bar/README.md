# CSS 3D-Flip Progress Bar

A fully functional, pure CSS 3D-flip progress bar designed for product catalog layouts, revealing funding status, inventory, or loading progress using a 3D cube rotation on hover.

## Features
- Pure CSS and HTML (no external JavaScript required).
- Smooth 3D perspective transforms and rotations.
- Elegant progress fill animation triggered dynamically via parent hover states.
- Fully responsive design compatible with standard EaseMotion components.
- Supports `prefers-reduced-motion` for accessibility.

## Usage
Open `demo.html` in any modern web browser. Hover over the product card to see the status text smoothly flip in 3D space to reveal the progress bar underneath.

## Files
- `demo.html`: The HTML structure for the 3D flip card component.
- `style.css`: The styling, 3D transforms, and keyframe animations.
