# Zoom-In Navbar for Minimalist Tech Layouts

## Overview

The **Zoom-In Navbar** is a modern CSS navigation component designed for minimalist technology-focused interfaces.

It provides a smooth entrance zoom animation with glassmorphism styling, responsive navigation, and interactive hover effects using only HTML and CSS.

No JavaScript or external dependencies are required.

---

## Features

- ✨ Smooth zoom-in entrance animation
- 🎨 Glassmorphism inspired navbar design
- ⚡ Pure HTML and CSS implementation
- 🖱️ Animated hover scaling effects
- 📱 Responsive mobile layout
- ♿ Supports `prefers-reduced-motion`
- 🚀 Lightweight and performance friendly
