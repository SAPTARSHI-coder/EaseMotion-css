# Interactive Tab Bar with Retro Styling

A responsive Retro-themed Interactive Tab Bar built using pure HTML and CSS.

## Features

- Retro arcade-inspired design
- Interactive tab selection
- CSS-only implementation
- Responsive layout
- Hover glow effects
- Mobile friendly

## Files

- demo.html
- style.css

## Usage

Open `demo.html` in your browser.

## Customization

Modify:

- Tab colors
- Border styles
- Glow effects
- Typography
- Spacing

## Browser Support

- Chrome
- Firefox
- Edge
- Safari
