# Spectroscope Slit Scan

## What does this do?
Renders a self-contained CSS-only `ease-spectroscope-slit-scan` demo: Spectral slit scanning across a dispersed rainbow band.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-spectroscope-slit-scan`. No build step or JavaScript is required for the effect.

```html
<section class="ease-spectroscope-slit-scan">
  <div class="ease-spectroscope-slit-scan__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
