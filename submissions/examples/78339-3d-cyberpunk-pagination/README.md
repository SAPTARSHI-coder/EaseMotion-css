# 3D Pagination with Cyberpunk Styling

A responsive 3D pagination component created for
EaseMotion CSS issue #78339.

## Features

- Cyberpunk-inspired visual design
- 3D pagination interaction
- Neon cyan and pink accents
- CSS-only implementation
- Responsive layout
- Hover animations
- Active page highlight
- Previous and next controls
- Decorative HUD-style panels
- Grid background
- Animated scanline
- Reduced-motion support
- No JavaScript
- No external dependencies

## Design

The component combines:

- Dark futuristic backgrounds
- Neon cyan and pink highlights
- 3D transforms
- Layered shadows
- Glowing borders
- HUD-inspired decorative elements
- Interactive page states

The active pagination button receives a bright cyan glow,
while hover states introduce depth using transforms and
layered shadows.

## Responsive Behavior

Desktop displays the complete cyberpunk interface with
decorative floating system panels.

At smaller widths, the decorative panels are removed to
preserve space.

On mobile devices, the pagination becomes horizontally
scrollable while maintaining accessible page controls.

## Technologies

- HTML5
- CSS3
- Flexbox
- CSS Grid
- CSS Transforms
- CSS Animations
- Media Queries
- Backdrop Filter

## Accessibility

- Semantic navigation element
- `aria-label` for pagination
- `aria-current="page"` for the active page
- Accessible previous/next labels
- Reduced-motion support
