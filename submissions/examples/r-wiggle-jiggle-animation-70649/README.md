# CSS Wiggle Jiggle Animation

A playful CSS-only wiggle and jiggle animation for interactive UI elements.

This example demonstrates how small translations, rotations, and scale
changes can be combined into a lightweight motion effect without JavaScript.

## Features

- Pure CSS implementation
- No JavaScript required
- Playful wiggle and jiggle motion
- Hover interaction
- Keyboard focus interaction
- Responsive design
- Accessible semantic HTML
- Visible focus indicators
- `prefers-reduced-motion` support

## Files

- `demo.html` — Demonstration page
- `style.css` — Component styles and animation
