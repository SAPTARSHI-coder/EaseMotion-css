Getting Started

Include EaseMotion's stylesheet and add utility classes directly in your HTML. No build process or configuration required.

<!-- Link the stylesheet --> <link rel="stylesheet" href="easemotion.min.css" /> <!-- Use classes in your markup --> <div class="ease-fade-in ease-hover-lift"> Hello, EaseMotion! </div>

Installation

Install via npm, or include the CDN link — no bundler needed.

# npm npm install easemotion-css # CDN <link rel="stylesheet" href="https://cdn.easemotion.dev/latest/easemotion.min.css" />

Configuration

Override CSS custom properties at :root to customise durations, easing, and colours globally.

:root { --ease-duration: 400ms; --ease-timing: cubic-bezier(0.4, 0, 0.2, 1); --ease-primary: hsl(221, 83%, 53%); --ease-reduced: no-preference; }

How the Underline Slides

The :checked pseudo-class and ~ sibling selector do all the work.

/* All panels hidden by default */
.tab-panel { opacity: 0; display: none; }

/* Slide the underline indicator using transform */
#tab2:checked ~ .tab-bar .tab-bar__track {
  transform: translateX(100%);  /* moves 1 tab width right */
}

/* Reveal + animate the matching panel */
#tab2:checked ~ .tab-panels .tab-panel--2 {
  display: block;
  animation: panelIn 0.3s ease forwards;
}

/* The animation itself */
@keyframes panelIn {
  from { opacity: 0; transform: translateY(10px); }
  to   { opacity: 1; transform: translateY(0); }
}
