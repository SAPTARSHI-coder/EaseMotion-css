# Interactive Cookie Banner with Neumorphism Styling

A responsive cookie consent component featuring a soft neumorphic interface, interactive controls, accessible focus states, and CSS-only animations.

## Features

- Neumorphic cookie banner
- Soft elevated surfaces
- Interactive hover and active states
- Cookie preference controls
- Neumorphic toggle switches
- Accept and preference actions
- Keyboard-accessible controls
- Responsive desktop, tablet, and mobile layouts
- Pure HTML and CSS
- Zero JavaScript dependencies
- No external assets or libraries
- `prefers-reduced-motion` support
