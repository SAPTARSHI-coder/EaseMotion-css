# CSS Nested Accordion

## Features

- Multi-level nested accordion structure
- Pure CSS implementation using `<details>` and `<summary>`
- Smooth open/close animation
- Indented child accordion sections
- Responsive design
- No JavaScript required

## Usage

Open `demo.html` in any browser to view the component.

## Why it fits EaseMotion CSS

This component provides a reusable nested accordion pattern with smooth CSS-based interactions and animations while remaining lightweight and accessible.
