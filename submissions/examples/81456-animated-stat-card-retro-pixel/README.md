# Animated Stat Card — Retro Pixel

A CSS-only animated statistics card component inspired by
retro arcade dashboards and pixel-based game interfaces.

Built for EaseMotion CSS issue #81456.

## Features

- Retro Pixel visual styling
- Four reusable statistic cards
- Animated stat values
- Animated progress indicators
- Neon green, pink, yellow and blue accents
- Pixel-inspired hard shadows
- CRT scanline overlay
- Pixel grid background
- Hover lift interactions
- Glowing card states
- Pixel corner decorations
- Performance trend indicators
- Responsive grid layout
- Keyboard focus support
- Reduced-motion support
- Zero JavaScript dependencies

Include `style.css` and use the card structure demonstrated
in `demo.html`.
