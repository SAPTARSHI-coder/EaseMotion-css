CSS animation-composition

Control how multiple animations targeting the same property combine. Baseline 2024 — supported in Chrome, Firefox, Safari, and Edge.

Zero JavaScript. Each demo below applies two independent animations to the same element. The only difference between columns is the animation-composition value. Open your browser DevTools to inspect the computed styles.

translate × scale

✖ replace default
animation-composition: replace;
Only the last animation wins. The box moves but never scales.
✔ add new in Baseline 2024
animation-composition: add;
Both animations add together. The box slides AND scales simultaneously.
△ accumulate new in Baseline 2024
animation-composition: accumulate;
Like add, but also combines with the element's base property values.

translateX × translateY

✖ replace default
The ball moves only horizontally — the vertical animation is overwritten.
✔ add new in Baseline 2024
The ball bounces diagonally — horizontal and vertical translations add together.
△ accumulate new in Baseline 2024
Like add, but accumulates relative to the element's starting position.

scale + opacity + translate

✖ replace default
Only the pulse is visible. The float animation is entirely replaced.
✔ add new in Baseline 2024
The orb pulses while floating up and down — both animations composed together.
△ accumulate new in Baseline 2024
Pulse + float + base values all compose. Subtle difference from add in most cases.

How It Works

replace

The default behavior since CSS animations were introduced. When two animations target the same property (e.g. translate), only the last declared animation takes effect. The earlier one is ignored completely. This is why you can't easily layer independent movement animations without composition.

add

Both animation values are added together as they would be for the same property. For additive properties like translate and rotate, this means the transforms stack. For non-additive properties like opacity, the values are simply added.

accumulate

Like add, but also accumulates the animation value on top of the element's underlying (base) property value. Most visible when the element has a non-zero starting transform or when animations iterate.

Real-World Use Cases

Parallax + scroll-reveal

Combine a scroll-driven parallax offset with a fade-in so elements glide into view with depth.

Floating + pulsing UI elements

Give notification badges a gentle float AND a subtle pulse without them fighting each other.

Cursor-follow + idle animation

A cursor trail follows the mouse pointer while also gently swaying when idle, all via compose.

Loading spinners

A spinner rotates continuously while also scaling in from zero on initial load — two independent animations.

Hero section motion

Hero text slides in from the left AND fades up simultaneously — no need to nest extra wrapper divs.

Card entrance with scroll

Cards both fade up (entrance) AND shift based on scroll position (parallax) as independent concerns.
