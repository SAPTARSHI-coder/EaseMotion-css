# Responsive Card with Retro Styling (#78820)

A responsive UI card component featuring neo-brutalist retro design patterns, bold borders, and custom shadow styling.

## Features
- **Fully Responsive:** Adapts fluidly to mobile and desktop viewports.
- **Neo-Brutalist Retro Aesthetics:** Bold vector borders and hard offset box shadows.
- **Pure CSS Implementation:** Lightweight styling with zero JavaScript dependencies.

## File Hierarchy
- `style.css` - Core retro layout, typography, and interactive button states.
- `demo.html` - Semantic markup demonstrating card integration.
- `README.md` - Technical specification and architecture overview.
