# CSS Slider: Bouncing Spring Variation

A responsive pure CSS slider featuring a playful
bouncing spring animation using CSS transforms,
custom easing, and smooth scroll-snap navigation.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript
- No external dependencies
- Bouncing spring animation
- Elastic overshoot effect
- Smooth CSS transitions
- CSS Scroll Snap
- Responsive layout
- Accessible navigation
- Keyboard focus support
- Reduced-motion support
- Dark-mode compatible
- Hardware-accelerated transforms
