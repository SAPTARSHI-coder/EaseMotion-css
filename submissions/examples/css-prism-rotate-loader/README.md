# CSS Prism Rotate Loader


A 3D triangular prism loader created using pure CSS animations.


## Features

- 3D rotating prism effect
- Rainbow reflection glow
- Smooth infinite animation
- Responsive design
- No JavaScript required


## Technologies

- HTML5
- CSS3


## CSS Concepts Used

- transform-style: preserve-3d
- perspective
- clip-path
- keyframe animations
- gradients
- pseudo elements


## Accessibility

- Added role="status"
- Added aria-label for loader
