# Cybernetic Matrix Digital Rain Background Canvas Overlay (Glassmorphic Style)

A modern **Glassmorphic Cybernetic Matrix** component featuring an animated digital rain background, translucent UI cards, and responsive layout built with pure HTML and CSS.

## Features

- Pure HTML5 & CSS3
- Animated Matrix digital rain
- Glassmorphism dashboard card
- Responsive feature grid
- Neon gradient buttons
- CSS Custom Properties
- `prefers-reduced-motion` support
- No JavaScript required
