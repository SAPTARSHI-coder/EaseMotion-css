# Ease 3D-Flip Pricing Table – Fintech Dashboard

A responsive pure CSS 3D-flip pricing table designed for fintech dashboard interfaces.

## Features

- Pure HTML and CSS
- No JavaScript
- 3D card flip using CSS `transform`
- `perspective` and `transform-style: preserve-3d`
- Hover interaction
- Keyboard focus support
- Three pricing plans
- Responsive desktop, tablet, and mobile layouts
- CSS custom properties
- Accessible focus states
- `prefers-reduced-motion` support
