# Rotate-Fade Drawer

A lightweight CSS-only drawer interaction designed for minimalist technology interfaces.

## Features

- Pure HTML and CSS
- Smooth rotate and fade reveal effect
- Subtle 3D perspective transition
- Responsive across desktop, tablet, and mobile
- No JavaScript or external dependencies
- Customizable CSS custom properties
- `prefers-reduced-motion` accessibility support
