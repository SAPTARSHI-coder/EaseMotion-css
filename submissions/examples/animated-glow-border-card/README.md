# Animated Glow Border Card

## What it does
A modern, high-end card component featuring a rotating animated gradient border that creates a continuous luminous glow effect.

## How to use it
```html
<div class="glow-card">
  <div class="glow-card-content">
    <h3>Premium Feature</h3>
    <p>Experience the smooth rotating border glow animation.</p>
  </div>
</div>
```
## Why it fits EaseMotion CSS
It delivers a striking visual border highlight using advanced CSS keyframes, aligning perfectly with the animation-first and modern design philosophy of EaseMotion CSS.
