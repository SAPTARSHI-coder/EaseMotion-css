# Particle Burst Tabs

A modern **CSS-only Tabs & Segmented Control** featuring
a dynamic Particle Burst visual style for the EaseMotion CSS
component collection.

Implemented for **Issue #73566**.

## ✨ Features

- Particle Burst visual effect
- CSS-only tab switching
- Smooth transitions
- Animated particles
- Glowing active states
- Responsive layout
- Dark-mode friendly design
- Hardware-accelerated transforms
- No external JavaScript
- No external dependencies
- Reduced-motion support

## 🎨 Style

**Category:** Tabs & Segmented Control

**Style:** Particle Burst

The component uses animated CSS particles around a central
visual focus to create an energetic burst effect when the
interface is interacted with.
