This contribution adds a Contrast Increase Effect to the submissions/examples/_contrast-increase-effect directory.

What is included?
demo.html
style.css
README.md

Features
Contrast increase: contrast(180%) makes colors more intense.
Smooth transition: Contrast changes gradually on hover.
Hover lift: Card moves upward for extra visual feedback.
Pure CSS: No JavaScript required.
Reusable effect: Can be applied to images, cards, buttons, backgrounds, and other elements.
Adjustable intensity: Change 180% to 120%, 150%, 200%, etc.
