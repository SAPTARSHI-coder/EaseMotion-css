# Liquid Wave Fill Toggle (#73875)

A pure HTML & Vanilla CSS toggle featuring an animated fluid liquid wave filling effect.

## Features
- **Aesthetic:** Rotating liquid wave filling animation across the switch track upon selection.
- **Pure CSS:** Zero JavaScript dependencies; relies strictly on CSS checkbox state selectors.
- **Performance:** Hardware-accelerated transforms utilizing `transform` and `will-change`.
- **Accessibility:** Keyboard focus navigation support and `@media (prefers-reduced-motion: reduce)` media query integration.
