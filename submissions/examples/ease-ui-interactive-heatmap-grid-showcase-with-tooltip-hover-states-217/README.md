# Interactive Heatmap Grid Showcase with Tooltip Hover States (Dark Mode Variant)

A modern dark-themed interactive heatmap grid built using pure HTML and CSS. Each heatmap cell displays a tooltip on hover and features smooth scaling, glowing animations, and responsive behavior.

## Features

- Dark mode interface
- Interactive heatmap grid
- Tooltip hover states
- Smooth hover animations
- Responsive design
- Pure HTML & CSS

## Folder Structure

```
ease-ui-interactive-heatmap-grid-showcase-with-tooltip-hover-states-217/
├── README.md
├── demo.html
└── style.css
```

## Usage

Open `demo.html` in any modern browser.

Customize colors and tooltip styles in `style.css`.
