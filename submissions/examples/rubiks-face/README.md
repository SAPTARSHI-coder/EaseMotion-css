# Rubik's Face

A 3x3 puzzle face whose tiles shimmer and slide on hover like a mini cube face.

## Features
- Nine-tile grid in classic cube colors
- Tiles brighten and shift on hover
- Center tile stays anchored while edges slide

## Usage
```html
<div class="rf-face">
  <div class="rf-cell rf-c1"></div>
  <div class="rf-cell rf-c5"></div>
  <div class="rf-cell rf-c9"></div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
