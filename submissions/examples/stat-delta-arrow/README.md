# Stat Delta Arrow

An arrow jolts upward signalling positive delta beside a stat.

## Features
- Upward jolt arrow
- Colour-coded delta
- Springy overshoot
- Pure CSS

## Usage
```html
<span class="sda-arrow"></span>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
