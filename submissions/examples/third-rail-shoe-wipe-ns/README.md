# Third Rail Shoe Wipe

## What does this do?
Renders a self-contained CSS-only `ease-third-rail-shoe-wipe` demo: Collector shoe wiping the third rail.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-third-rail-shoe-wipe`. No build step or JavaScript is required for the effect.

```html
<section class="ease-third-rail-shoe-wipe">
  <div class="ease-third-rail-shoe-wipe__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
