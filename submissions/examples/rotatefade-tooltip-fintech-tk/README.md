# Rotate-Fade Tooltip (Fintech Dashboard)

## What does this do?

A modern fintech dashboard component featuring interactive tooltips that smoothly rotate and fade into view on hover. The component presents financial insights with a clean glassmorphism design using only HTML and CSS.

---

## Features

- Rotate + Fade tooltip animation
- Glassmorphism tooltip design
- Fintech-inspired dashboard UI
- Smooth hover interactions
- Responsive layout
- Pure HTML & CSS (No JavaScript)
- Supports `prefers-reduced-motion`

---

- `demo.html` — Component showcase
- `style.css` — Component styling and animations
