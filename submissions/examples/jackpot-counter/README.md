# Jackpot Counter

A rolling digit odometer that ticks upward and flashes a jackpot glow.

## Features
- Each digit wheel rolls with vertical stagger
- Gold gradient numbers on a dark reel
- Starburst glow pulses behind the total

## Usage
```html
<div class="jc-holder">
  <div class="jc-glow"></div>
  <div class="jc-display"><span class="jc-digit">7</span></div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
