# Radar Scan Loader

This submission introduces a highly visual "radar scan" loading animation using modern CSS properties. It is an excellent alternative to standard spinners for applications related to searching, scanning, mapping, or security.

## Features

- **Pure CSS**: Completely relies on CSS, requiring no JavaScript or SVGs.
- **`conic-gradient`**: The core of the visual effect is achieved by applying a `conic-gradient` that wraps from transparent (0%) to a solid accent color (100%), creating a sharp leading edge and a fading trailing trail.
- **Infinite Rotation**: The radar sweep effect is generated by simply applying a linear, infinite `@keyframes` rotation to the gradient element.
- **Accessibility**: Includes a `prefers-reduced-motion` media query. If a user has motion sensitivities, the spinning radar sweep is replaced with a gentle, non-disruptive pulsing radial gradient.

## Usage

1. Include `style.css` in your project.
2. Create the HTML structure: a parent `.em-radar-container` containing a child `.em-radar-scan` element.
3. Customize the size and colors by overriding the CSS variables (`--em-radar-size`, `--em-radar-bg`, `--em-radar-accent`) on the `.em-radar-container` class.
