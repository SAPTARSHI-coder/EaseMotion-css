# CSS 3D Flip Drawer

A responsive CSS-only navigation drawer featuring a smooth 3D flip opening animation.

## Features

- Pure HTML & CSS
- 3D flip animation
- Responsive layout
- Accessible checkbox toggle
- No JavaScript
- Supports `prefers-reduced-motion`

## Files

```
demo.html
style.css
README.md
```

## Customization

Modify the drawer width:

```css
.drawer{
    width:240px;
}
```

Change animation duration:

```css
transition:.6s ease;
```

Change colors:

```css
background:#1f2937;
```

## Accessibility

- Keyboard accessible
- Responsive
- Reduced motion support

## Browser Support

Works in all modern browsers.
