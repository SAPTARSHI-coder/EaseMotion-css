# ease-particle-field-bh

CSS Particle Field with Mouse Interaction.

## What does this do?
Creates an animated particle field using CSS pseudo-elements and gradients.

## How is it used?
```html
<div class="ease-particle-field">
  <div class="ease-particle"></div>
  <div class="ease-particle"></div>
</div>
```

## Features
- CSS-only particle animation
- Floating particle effect
- Gradient-based particles
- Hover interaction
