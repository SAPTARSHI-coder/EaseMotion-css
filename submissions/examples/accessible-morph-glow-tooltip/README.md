# CSS Morph-Glow Tooltip for Accessible Web Layouts

A modern **CSS-only Morph-Glow Tooltip component** built for EaseMotion CSS.

This example showcases a creative tooltip design using pure HTML and CSS. It includes smooth morphing transitions, glowing effects, responsive layouts, and accessibility support without requiring JavaScript.

---

## ✨ Features

- 🎨 Pure HTML5 and CSS3 implementation
- 🌈 Morph-Glow animation effect
- ✨ Smooth tooltip entrance animation
- 🌀 Scale and fade transitions
- 💎 Glassmorphism inspired design
- 📱 Fully responsive layout
- 🎛 CSS custom properties support
- 🚫 No JavaScript required
- ♿ `prefers-reduced-motion` accessibility support

## 🚀 Usage

1. Copy the component files into your project.

2. Add the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

3. Open `demo.html` in a modern browser.

4. Hover over the tooltip buttons to view the animation effects.

---

## 🎨 CSS Custom Properties

The component uses CSS variables for simple customization.

```css
:root {

    --bg: #020617;

    --surface: rgba(255,255,255,.08);

    --primary: #8b5cf6;

    --secondary: #06b6d4;

    --glow: rgba(139,92,246,.55);

    --text: #ffffff;

    --muted: #cbd5e1;

    --radius: 24px;

}
```

## ♿ Accessibility

Accessibility features include:

- Semantic HTML structure
- Tooltip role support
- Clear content presentation
- Reduced motion support

The component respects:

```css
@media(prefers-reduced-motion:reduce)
```

Users who prefer reduced motion will experience simplified animations.
