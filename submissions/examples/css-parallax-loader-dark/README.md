# Parallax Loader with Dark Mode Styling (#78813)

A high-performance dark mode loader component utilizing multi-layered counter-spinning orbits and glowing core pulse animations.

## Features
- **Multi-Layer Parallax Motion:** Dual rings spinning in opposite directions with custom cubic-bezier easing.
- **Deep Dark Theme:** Optimized background tones with neon indigo and purple core glow effects.
- **Pure CSS Implementation:** Lightweight setup with zero JavaScript dependencies and full accessibility support.

## File Hierarchy
- `style.css` - Keyframes, orbital layout metrics, and dark mode variables.
- `demo.html` - Semantic markup demonstrating loader component embedding with ARIA roles.
- `README.md` - Technical specification and architecture overview.
