# Morphing Pagination with Material Design

A responsive pagination component inspired by Material Design principles, featuring smooth morphing interactions, rounded controls, elevation, and accessible focus states.

## Features

- Material Design inspired UI
- Smooth morphing hover and active states
- Responsive layout for desktop, tablet, and mobile
- Accessible pagination navigation
- Keyboard-friendly focus states
- Touch-friendly controls
- Pure HTML and CSS
- No external dependencies
- Reduced-motion support

## Preview

Open `demo.html` in any modern browser to view the component.
