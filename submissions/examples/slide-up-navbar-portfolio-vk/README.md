# Slide-Up Navbar for Creative Portfolio Layouts

A responsive navigation bar built with pure HTML and CSS. The navigation links feature a smooth slide-up hover animation, making it suitable for creative portfolios, personal websites, and modern landing pages without requiring JavaScript.

---

## Features

- Pure HTML5 and CSS3 (No JavaScript)
- Smooth slide-up hover animation
- Animated underline effect
- Fully responsive across desktop, tablet, and mobile devices
- Easy customization using CSS custom properties
- Lightweight and performant
- Supports `prefers-reduced-motion`
- Keyboard accessible using `:focus-visible`

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over or focus on the navigation links to see the slide-up animation.
3. Customize the navigation items, colors, spacing, and animation duration to fit your project.

---

## CSS Custom Properties

```css
:root {
    --primary: #4f46e5;
    --secondary: #6366f1;
    --background: #f5f7fb;
    --surface: #ffffff;
    --text: #1f2937;

    --radius: 16px;
    --shadow: 0 10px 25px rgba(0, 0, 0, 0.12);

    --duration: 0.35s;
}
```

## Accessibility

- Supports `prefers-reduced-motion` for users who prefer reduced animations.
- Navigation links are keyboard accessible using `:focus-visible`.
- Built with semantic HTML5 elements.
- Fully responsive across desktop, tablet, and mobile devices.
