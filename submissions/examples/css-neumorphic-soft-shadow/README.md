# CSS 3D Neumorphic Soft Shadow

A pure CSS 3D neumorphic interface component using soft shadows, layered depth, perspective, glow, and smooth floating motion.

## Features

- Pure HTML and vanilla CSS
- No JavaScript
- No external libraries
- Neumorphic soft-shadow styling
- 3D perspective depth
- Smooth floating animation
- Layered light and dark shadows
- Responsive layout
- Dark-mode compatible
- Hardware-friendly transforms
- Reduced-motion support

## Usage

Open `demo.html` directly in a modern browser.

The component can be reused by copying the `.neumorphic-card` HTML structure and the related CSS into another project.

## Accessibility

The decorative icon is hidden from assistive technologies with `aria-hidden="true"`. The main content uses semantic HTML and a descriptive heading. The animation respects `prefers-reduced-motion`.

## EaseMotion CSS

This component fits the EaseMotion CSS library by providing a reusable CSS-only 3D animation pattern. It demonstrates neumorphic depth, soft shadows, elevation, perspective, and smooth motion without JavaScript.
