
---

## 🚀 Usage
1. Clone or copy the files into your project.
2. Open `demo.html` in your browser.
3. Hover over dates to see pastel hover effects.

---

## 🛠️ Customization
- **Colors** → Adjust pastel gradient values in `.datepicker-header` and hover states.
- **Animation speed** → Modify `transition: 0.3s ease`.
- **Grid size** → Change `height` and `font-size` in `.datepicker-grid td`.

---

## 📖 Accessibility
- Supports `prefers-reduced-motion` for users with motion sensitivity.
- Clear ARIA labels for navigation buttons and calendar role.
