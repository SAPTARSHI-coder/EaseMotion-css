# CSS Slider: Aurora Glow Variation

A pure CSS slider/carousel featuring animated Aurora Glow visuals, glassmorphism styling, smooth transitions, and dark-mode friendly design.

## Features

- Pure HTML & CSS
- Aurora Glow aesthetic
- Animated gradient lighting
- Smooth slide transitions
- Responsive layout
- Accessible radio-button navigation
- Dark mode compatible
- Hardware accelerated transforms
- No JavaScript required

## Usage

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

Basic structure:

```html
<input type="radio" name="slide" id="slide1" checked>

<div class="slides">
  <div class="slide">
    Slide Content
  </div>
</div>
```

## Customization

Aurora colors:

```css
:root{
  --aurora1:#00fff0;
  --aurora2:#7b61ff;
  --aurora3:#ff4fd8;
}
```
