# CSS Particle Effect: Retro Arcade Pixel

A smooth, accessible, and performant pure CSS particle effect inspired by
classic retro arcade visuals.

## Features

- Pure HTML and Vanilla CSS
- Retro arcade pixel aesthetic
- Pixel-based particle elements
- Neon glow effects
- Animated scanlines
- Subtle arcade grid
- Lightweight CSS animations
- Hardware-friendly `transform` animations
- Dark mode compatible
- Responsive layout
- Accessible keyboard focus states
- `prefers-reduced-motion` support
- No JavaScript
- No external libraries
