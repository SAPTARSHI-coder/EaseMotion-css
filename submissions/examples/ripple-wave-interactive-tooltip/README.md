# CSS Ripple-Wave Tooltip for Accessible Web Layouts

A modern **Ripple-Wave Tooltip** component built using only **HTML5 and CSS3**.

This example demonstrates animated ripple effects, smooth tooltip transitions, responsive layouts, and accessibility support without requiring JavaScript.

---

## ✨ Features

- 🌊 Ripple wave hover animation
- 💬 Smooth tooltip appearance
- 🎨 Gradient button styling
- ⚡ Pure CSS animations
- 📱 Responsive design
- 🎯 CSS Custom Properties
- ♿ `prefers-reduced-motion` support
- 🚫 Zero JavaScript dependency

---

## 📂 Folder Structure

```
ripple-wave-interactive-tooltip/

├── demo.html

└── README.md
```

---

## 🚀 Usage

1. Open `demo.html` in any modern browser.
2. Hover or focus on the buttons.
3. Tooltip information will appear with ripple animation.
4. Customize colors and animations using CSS variables.

## 🎨 CSS Custom Properties

:root {

    --accent:#ec4899;

Includes:

- Semantic HTML structure
- Keyboard focus support

Users with motion preferences enabled receive a simplified experience using:

```css
@media(prefers-reduced-motion:reduce)
```
