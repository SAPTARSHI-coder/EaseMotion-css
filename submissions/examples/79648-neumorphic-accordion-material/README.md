# Neumorphic Accordion — Material Design

A responsive accordion component combining soft neumorphic
surfaces with clean Material-inspired spacing, typography,
and interaction patterns.

Implemented for issue #79648.

## Features

- Neumorphic surface treatment
- Material-inspired layout
- Native HTML accordion behavior
- Expand/collapse interaction
- Soft raised and pressed states
- Hover feedback
- Keyboard focus support
- Responsive mobile layout
- CSS-only implementation
- No external dependencies
- Reduced-motion support
