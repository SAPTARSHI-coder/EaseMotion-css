# CSS Sticky Section Header

A pure CSS component that keeps section headers fixed at the top while users scroll through grouped content.

## Features

- Pure CSS implementation
- Uses `position: sticky`
- Responsive design
- No JavaScript required
- Clean and reusable structure
- Accessible semantic HTML

## Usage

```html
<section class="section">
  <h2 class="sticky-header">Frontend</h2>

  <div class="item">HTML Basics</div>
  <div class="item">CSS Layouts</div>
  <div class="item">Responsive Design</div>
</section>
