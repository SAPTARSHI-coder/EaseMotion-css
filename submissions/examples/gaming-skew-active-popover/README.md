# CSS Skew-Active Popover for Gaming Hub Layouts

A modern **Gaming Hub Popover** built entirely with **HTML5 and CSS3**. This showcase demonstrates an elegant **Skew-Active Popover** with neon-inspired visuals, glassmorphism styling, smooth hover interactions, responsive layouts, and accessibility support without requiring JavaScript.

---

## ✨ Features

- 🎮 Gaming Hub inspired popover
- 🔷 Skew-Active card layout
- 💬 Hover-triggered popover
- 🌈 Neon gradient accents
- 💎 Glassmorphism design
- 📱 Fully responsive
- ⚡ Pure HTML5 & CSS3
- 🎯 CSS Custom Properties
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

## 🚀 Getting Started

1. Open `demo.html` in your browser.
2. Hover over a game card to reveal the popover.
3. Explore the skewed gaming interface and smooth animations.
4. Customize colors and spacing through CSS variables.
