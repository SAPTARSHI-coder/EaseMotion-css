# CSS Slide-Up Drawer for SaaS Showcase Layouts

## Overview

A modern SaaS showcase component featuring animated slide-up drawers
created with pure HTML and CSS.

The component provides additional information panels that smoothly reveal
when users interact with product cards.

## Features

- 📦 SaaS product showcase cards
- ⬆️ Smooth slide-up drawer animation
- 🎨 Gradient UI design
- ⚡ Pure CSS transitions
- 📱 Responsive layout
- ♿ prefers-reduced-motion support
- 🧩 Lightweight implementation

## Usage

1. Open `demo.html` in a browser.
2. Hover over cards to reveal drawers.
3. Customize colors using CSS variables.
