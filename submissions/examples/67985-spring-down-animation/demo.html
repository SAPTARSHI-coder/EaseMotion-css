Motion sequence

Four intentional moments.

  1. 01
    Hidden start

    Opacity begins at zero while the element sits above its final position.

  2. 02
    Fast descent

    The element moves quickly toward its destination using transform.

  3. 03
    Soft overshoot

    A small positive offset creates the spring character.

  4. 04
    Final settle

    The element returns to its natural position at full opacity.

Drop-in class

Small API.

.spring-down {
  animation:
    ease-spring-down
    var(--spring-duration)
    var(--spring-easing)
    var(--spring-delay)
    both;
}

Only CSS is required. Add the class to any block, inline-block, grid item, or positioned component.
