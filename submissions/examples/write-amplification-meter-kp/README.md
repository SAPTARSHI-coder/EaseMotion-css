# Write Amplification Meter

An advanced EaseMotion example for monitoring distributed Meter Remeters, lsm debt, retry pressure, and Retention margin recovery.

## Features

- Interactive controls for meter risk, lsm debt, retry pressure, and Retention margin health.
- Animated radar, LSM lanes, recovery metrics, Remeter timeline, decision matrix, and audit meter.
- State-driven stable, watch, Meter, and recovered modes.
- Responsive CSS-only dashboard built with `demo.html`, `style.css`, and this `README.md`.
