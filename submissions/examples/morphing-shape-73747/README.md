# CSS Neumorphic Effect: Morphing Shape Variation

Pure CSS neumorphic UI featuring dynamic border-radius morphing keyframes, organic fluid shape transitions, and adaptive haptic shadow depth.

## 1. What does this do?
Morphs an extruded neumorphic vessel container between fluid organic blob, perfect circle, smooth squircle, and pillow diamond states with responsive shadow adaptations without JavaScript.

## 2. How is it used?
Link `style.css` and use pure CSS radio triggers to control morphing states:

```html
<input type="radio" name="shape-mode" id="shape-blob" class="shape-radio" checked>

<div class="morph-stage">
  <div class="morphing-vessel">
    <div class="vessel-inner">ORGANIC BLOB</div>
  </div>
</div>

<label for="shape-blob" class="neumorphic-btn">Organic</label>
```

## 3. Why is it useful?
Delivers eye-catching organic morphing animations for creative brand avatars, UI loaders, interactive buttons, and modern visual cards with dark mode support and reduced motion accessibility.
