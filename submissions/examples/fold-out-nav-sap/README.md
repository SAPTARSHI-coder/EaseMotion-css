# Fold-out Navigation\n\nA fold-out horizontal navigation menu triggered by a pure CSS checkbox hack.\n\n### Usage\n```html\n<div class="nav-wrapper">\n  <input type="checkbox" id="nav-toggle">\n  <label for="nav-toggle" class="nav-btn">☰</label>\n  <ul class="nav-list">\n    <li><a href="#">Home</a></li>\n    <li><a href="#">About</a></li>\n    <li><a href="#">Work</a></li>\n  </ul>\n</div>\n```\n\n### Why is it useful?\nThis component provides a premium aesthetic and smooth micro-interaction that perfectly aligns with EaseMotion's framework-quality design standards. It relies entirely on CSS, making it performant and easy to integrate without JavaScript dependencies.
