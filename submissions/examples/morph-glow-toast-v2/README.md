# Morph-Glow Toast

A lightweight, CSS-only toast notification component with a smooth
morphing glow effect for SaaS showcase layouts.

## Features

- Pure HTML and CSS
- No JavaScript required
- Morphing border-radius animation
- Animated background glow
- Smooth light sweep effect
- Subtle icon animation
- Responsive on desktop, tablet, and mobile
- Keyboard accessible close buttons
- `prefers-reduced-motion` support
- Customizable using CSS custom properties
- Works by opening `demo.html` directly in a browser
