# Modal 3D card flip

A modal that enters with a 180-degree 3D flip on the X axis.

## How to view

Open `demo.html` in any modern browser. The demo is fully self-contained — no CDN, no framework, no JavaScript.

## How to use

Copy `style.css` into your project's stylesheet. Every class used in the demo is namespaced with `modal3dcardflip-` to avoid collisions.

## Why this is useful for EaseMotion CSS

Onboarding / dialog pattern; the 3D flip is a dramatic entrance.
