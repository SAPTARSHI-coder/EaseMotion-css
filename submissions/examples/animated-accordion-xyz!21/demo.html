Animated Accordion Component

Zero JavaScript. Pure CSS smooth expand/collapse animations using native HTML details/summary elements.

Frequently Asked Questions

What is EaseMotion CSS?

EaseMotion CSS is a lightweight, animation-first CSS framework designed to bring smooth, polished interactions to your web projects with zero JavaScript overhead.

Do I need JavaScript to use the accordion?

No! This accordion component is built entirely with pure CSS using the native HTML <details> and <summary> elements. It works perfectly without any JavaScript.

Is this component accessible?

Yes! The accordion uses semantic HTML elements that are natively accessible. It supports keyboard navigation, screen readers, and respects the prefers-reduced-motion setting for users who prefer minimal animations.

Can I customize the animation speed?

Absolutely! The animation uses EaseMotion's design tokens like --ease-duration-normal and --ease-ease. You can override these CSS variables to match your project's timing preferences.

How do I integrate this into my project?

Simply include the EaseMotion CSS framework and the accordion styles. Then use the <details class="ease-accordion-xyz"> structure with your content. Check the README for detailed usage instructions!
