# Minimalist Sliding Tab Selector with Smooth Spring Physics

A compact, mobile-first sliding tab selector built with pure HTML, CSS, and JavaScript.

## Features

- Smooth spring-inspired sliding indicator
- Responsive mobile-first layout
- Keyboard-accessible tab controls
- Dynamic content switching
- Modern minimalist dark UI
- CSS custom properties
- Hover and focus states
- Reduced-motion accessibility support
- No external dependencies
