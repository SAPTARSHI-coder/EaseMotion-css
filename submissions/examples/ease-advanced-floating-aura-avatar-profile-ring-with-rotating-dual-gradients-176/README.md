# Floating Aura Avatar Profile Ring with Rotating Dual Gradients

A modern compact mobile-first profile card featuring animated rotating gradient rings around the avatar.

## Features

- Rotating dual gradient aura rings
- Floating glassmorphism profile card
- Responsive mobile-first layout
- Interactive 3D hover effect
- Animated buttons
- Pure HTML, CSS and Vanilla JavaScript
