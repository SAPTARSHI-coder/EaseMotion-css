# Animated Offcanvas Drawer with Claymorphism
A responsive offcanvas drawer with a soft claymorphism-inspired visual style and smooth CSS transitions.

## Features
* Responsive offcanvas drawer
* Claymorphism-inspired styling
* Smooth open/close transitions
* Pure CSS implementation
* Uses EaseMotion CSS variables and design tokens
* Mobile, tablet, and desktop friendly
* Respects `prefers-reduced-motion`
* No JavaScript dependencies

## Files
* `demo.html` — Demo markup for the offcanvas drawer
* `style.css` — Component styling and animations
* `README.md` — Documentation

## Usage
Open `demo.html` in a modern browser to view the component.
The drawer can be opened and closed using the provided controls. The layout adapts to different viewport sizes.
