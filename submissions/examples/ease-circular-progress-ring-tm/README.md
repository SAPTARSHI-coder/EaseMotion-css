# Circular Progress Ring Component

**Issue:** [#71804](https://github.com/SAPTARSHI-coder/EaseMotion-css/issues/71804)

A pure CSS circular progress ring using `conic-gradient` for animated fill effects.

## Design Tokens

| Token | Default |
|-------|---------|
| `--tm-ring-size` | `160px` |
| `--tm-ring-fill` | `#6366f1` |
| `--tm-ring-track` | `#334155` |
| `--tm-ring-transition` | `1.5s` |

## Variants

- Default (indigo)
- `.cpr-variant-green` (emerald)
- `.cpr-variant-orange` (amber)
