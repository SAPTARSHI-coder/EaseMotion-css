# CSS Fade-In Hero Section for SaaS Showcase Layouts

A modern **Fade-In Hero Section** built with pure HTML and CSS for EaseMotion CSS. The component is designed for SaaS landing pages and features elegant fade-in animations, responsive layouts, glassmorphism cards, and accessibility support.

---

## Features

- Pure HTML5 & CSS3
- Smooth fade-in entrance animations
- Responsive SaaS hero layout
- Interactive CTA buttons
- Glassmorphism dashboard preview
- Hover effects on cards and buttons
- CSS Custom Properties for easy customization
- `prefers-reduced-motion` support
- No JavaScript required

## CSS Custom Properties

```css
:root{
  --bg:#07111f;
  --surface:#13253d;
  --surface-light:#1b3352;
  --primary:#5b8dff;
  --secondary:#67e8f9;
  --text:#ffffff;
  --muted:#b7c7db;
  --shadow:0 20px 45px rgba(0,0,0,.35);
  --radius:22px;
  --transition:.45s ease;
}
```
