# CSS Scale Up on Hover

A smooth CSS-only scale-up interaction that enlarges an element on hover and keyboard focus while adding a soft shadow effect.

## Features

- Pure CSS implementation
- Smooth scale-up animation
- Soft shadow and glow effect
- Keyboard accessible
- Visible focus state
- Responsive design
- Supports reduced-motion preferences
- No JavaScript required

## Files

- `demo.html` — Demo markup
- `style.css` — Component styles and animation

## Usage

Add the `scale-card` class to an interactive element:

```html
<a class="scale-card" href="#">
  <span class="card-content">
    <span class="card-title">Scale Up</span>
    <span class="card-text">Hover or focus this card</span>
  </span>
</a>
