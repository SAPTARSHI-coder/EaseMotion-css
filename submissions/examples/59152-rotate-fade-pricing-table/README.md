# Rotate Fade Pricing Table for Gaming Hub Layouts

A modern **Rotate-Fade Pricing Table** created with pure HTML and CSS for gaming dashboards, esports platforms, and futuristic membership pages.

## Features

- Pure HTML5 & CSS3
- Rotate + Fade hover animation
- Neon gaming UI
- Responsive design
- Three pricing plans
- No JavaScript required
- Accessible with `prefers-reduced-motion`
- Lightweight and customizable

## Folder Structure

```text
59152-rotate-fade-pricing-table/
├── demo.html
├── style.css
└── README.md
```

## Usage

1. Open `demo.html`.
2. Customize plan names, pricing, and features.
3. Modify colors using CSS variables in `:root`.
