# CSS Skew-Active Tabs for SaaS Showcase Layouts

A modern SaaS-style tab navigation component featuring smooth skew transformation effects built completely with pure HTML and CSS.

This component is designed for SaaS dashboards, product showcases, and landing pages where lightweight animated navigation interactions are required without JavaScript.


## ✨ Features

- 📑 Modern SaaS tab navigation UI
- 🔄 Smooth skew active state animation
- 🎨 Gradient hover effects
- ⚡ Pure HTML and CSS implementation
- 📱 Fully responsive layout
- 🌀 CSS transform based animations
- ♿ prefers-reduced-motion accessibility support
- 🚀 Lightweight and framework-free

## 🚀 Usage

1. Open `demo.html` directly in your browser.

2. Hover over the tabs to view the skew animation effect.

3. Customize CSS variables inside `style.css` according to your branding.


## 🎨 CSS Custom Properties

The component uses CSS variables for easy customization:

```css
:root {

    --bg:#020617;
    --card:#0f172a;
    --primary:#38bdf8;
    --secondary:#8b5cf6;
    --text:#f8fafc;
    --muted:#94a3b8;

}

Modify these values to create your own theme.
