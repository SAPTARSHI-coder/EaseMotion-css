# CSS Media Player Controls

A responsive and accessible media player UI built with HTML and CSS.

## Features

- Responsive audio player layout
- Native HTML5 audio controls
- Play, previous and next control buttons
- Volume slider
- Hover animations
- Keyboard focus states
- Accessible labels
- Reduced-motion support
- No JavaScript required for the player UI

## Files

- `demo.html` - Demo page and HTML structure
- `style.css` - Player styling and responsive animations

## Usage

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
