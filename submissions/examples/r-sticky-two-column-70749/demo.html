01

Overview

Sticky two-column layouts are useful when important navigation, filters, summaries, or contextual information should remain visible while users read longer content.

The left panel uses CSS position: sticky so it remains within its parent container while the main content continues naturally.

02

Features

01

Sticky Sidebar

The left column remains visible during page scrolling.

02

Pure CSS

03

Responsive

04

Accessible

Semantic HTML and keyboard-friendly navigation are used.

03

Details

The layout is built with CSS Grid. The sidebar has a smaller flexible column while the content area receives the remaining available width.

CSS technique position: sticky; top: 2rem;

The sticky element remains positioned relative to its nearest scrolling ancestor and stops when the parent container ends.

04

Usage

This pattern works well for documentation pages, product details, dashboards, article layouts, portfolios, settings screens, and project information pages.

1

Place navigation or important information in the sidebar.

2

Apply position: sticky to the sidebar card.

3

Allow the main content to grow naturally.

05

Responsive Design

On smaller screens, the two-column layout changes into a single column. This prevents the sidebar from becoming too narrow and keeps the content comfortable to read.

Sidebar Main Content

The layout uses flexible sizing, relative spacing, and a mobile breakpoint to remain usable across different screen sizes.
