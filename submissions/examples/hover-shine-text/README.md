# Hover Shine Text

A gloss of light sweeps across text when the pointer arrives.

## Features
- Diagonal shine sweep
- Masked to the text glyphs
- Smooth single pass
- Pure CSS

## Usage
```html
<h2 class="hst-title">Shine on hover</h2>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
