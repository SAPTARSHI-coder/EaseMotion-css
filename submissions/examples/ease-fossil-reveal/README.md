# 🪨 Fossil Reveal – Fossil Emerges from Stone

> An interactive fossil reveal component where a fossil emerges from stone with 4 types (Dinosaur, Ammonite, Trilobite, Fern), reveal control (0-100%), and particle effects.

---

## 📖 Description

The **Fossil Reveal** component creates an interactive fossil experience where a fossil emerges from stone with organic motion. Built with vanilla HTML, CSS, and JavaScript, it features 4 fossil types (Dinosaur, Ammonite, Trilobite, Fern), reveal control (0-100%), and particle effects for a satisfying discovery experience.

### 🎯 Core Features

- **Fossil reveal** – fossil emerges from stone with organic motion
- **4 fossil types** – Dinosaur, Ammonite, Trilobite, Fern
- **Reveal control** – adjust reveal from 0-100%
- **Particle effects** – stone particles scatter
- **Fossil details** – organic fossil shapes with texture
- **Interactive controls** – slider, fossil buttons, keyboard shortcuts
- **Responsive design** – adapts to different screen sizes
