# Stereoscope Viewer Slide

## What does this do?
Renders a self-contained CSS-only `ease-stereoscope-viewer-slide` demo: Stereoscope viewer sliding twin photo plates.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-stereoscope-viewer-slide`. No build step or JavaScript is required for the effect.

```html
<section class="ease-stereoscope-viewer-slide">
  <div class="ease-stereoscope-viewer-slide__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
