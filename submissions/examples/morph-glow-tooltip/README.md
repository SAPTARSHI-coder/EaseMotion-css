# CSS Morph-Glow Tooltip

A modern tooltip component featuring a morphing scale animation with a glowing effect, built using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Morph + glow hover animation
- Responsive layout
- Accessible with `prefers-reduced-motion`
- No JavaScript required
- Lightweight and customizable

## Files

```text
demo.html
style.css
README.md
```

## Usage

Open `demo.html` in any modern browser and hover over the button.

## Customization

- Tooltip colors
- Glow intensity
- Animation duration
- Border radius
- Typography

## Browser Support

Compatible with all modern browsers supporting CSS animations and transitions.
