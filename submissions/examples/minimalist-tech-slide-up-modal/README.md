# Slide-Up Modal

A minimalist CSS-only modal component with a smooth slide-up entrance animation for modern tech interfaces.

## Features

- Pure HTML and CSS
- No JavaScript required
- Smooth bottom-to-top slide animation
- Responsive desktop, tablet, and mobile layout
- CSS custom properties for easy customization
- Click-outside and close controls
- `prefers-reduced-motion` support
- Self-contained browser demo
