# CSS Liquid Filling Typography

Bold typography that visually fills up with a colorful liquid using dynamic polygon clipping.

## Features
- Fluid water physics simulated using a complex, keyframed `clip-path: polygon` that rises over time.
- Crisp transparent styling using `-webkit-text-stroke` to define the letter boundaries.
- Flawless overlay achieved with a duplicated `::before` pseudo-element providing the liquid fill.
