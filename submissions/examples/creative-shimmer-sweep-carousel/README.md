# CSS Shimmer-Sweep Carousel for Accessible Web Layouts

A modern **Shimmer-Sweep Carousel** component created using only **HTML5 and CSS3**. This showcase demonstrates animated shimmer effects, smooth card interactions, responsive layouts, and accessibility support without JavaScript.

---

## ✨ Features

- ✨ Shimmer sweep animation
- 🎴 Interactive carousel cards
- 🌈 Animated gradient light effect
- 💎 Glassmorphism UI design
- ⚡ Lightweight CSS animations
- 🎯 CSS Custom Properties
- 📱 Fully responsive layout
- 🧩 Pure HTML5 & CSS3
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

## 🚀 Usage

1. Open `demo.html` in any modern browser.
2. Hover over cards to view interactive effects.
3. Customize colors and animation speed using CSS variables.
