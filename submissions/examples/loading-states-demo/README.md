# Loading States Demo

## Description

This example demonstrates several common loading states that can be used in modern web applications.

## Included Examples

### 1. Loading Spinner

A circular spinner for indicating an ongoing operation.

### 2. Pulsing Indicator

A lightweight pulsing animation suitable for small loading areas.

### 3. Skeleton Card

A skeleton placeholder that can be displayed while content is loading.

### 4. Loading Button

A button state that indicates an operation is currently being processed.

## Features

- Responsive layout
- Multiple loading patterns
- Accessible loading status
- Lightweight implementation
- Beginner-friendly examples
