# CSS Zoom-In Navbar for SaaS Showcase Layouts

A modern **Zoom-In Navbar** built using pure HTML and CSS. The navigation bar enters with a smooth zoom-in animation while featuring a premium glassmorphism design suitable for SaaS landing pages, dashboards, and admin interfaces.

## ✨ Features

- Pure HTML5 & CSS3
- Smooth zoom-in entrance animation
- Glassmorphism navbar
- Responsive layout
- Gradient CTA button
- CSS Custom Properties
- `prefers-reduced-motion` support
- No JavaScript required
