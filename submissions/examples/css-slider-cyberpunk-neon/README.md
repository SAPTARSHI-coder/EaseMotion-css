# CSS Slider: Cyberpunk Neon Variation

A futuristic, responsive CSS slider featuring a cyberpunk neon
visual style using pure HTML and vanilla CSS.

## Features

- Pure HTML and CSS
- Cyberpunk neon styling
- Horizontal CSS slider
- CSS Scroll Snap navigation
- Smooth transitions
- Responsive layout
- Neon glow effects
- Dark-mode-friendly design
- Keyboard-accessible navigation
- Visible focus states
- Reduced-motion support
- No external JavaScript dependencies
