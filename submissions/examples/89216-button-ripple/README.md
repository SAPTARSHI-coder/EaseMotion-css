# Ripple Effect Button Component

A button interaction component featuring a pure CSS radial wave expansion on click/focus.

## Features
- **Pure CSS Ripple:** Expands a translucent wave pseudo-element without external JS scripts.
- **Focus Interaction:** Triggers clean visual feedback upon activation.
- **Modern UI Styling:** Built with smooth gradients and hover micro-animations.

## File Structure
- `demo.html` - Minimal button markup structure.
- `style.css` - Button base rules, overflow clip, and radial keyframe animation.
