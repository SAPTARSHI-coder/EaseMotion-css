# Scale-Hover Toast

A lightweight CSS-only toast notification component designed for fintech dashboard layouts.

The component uses a subtle scale animation when the user hovers over the notification.

## Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Smooth scale-hover animation
- Responsive design
- Fintech dashboard styling
- Keyboard-friendly close button
- Visible focus state
- `prefers-reduced-motion` support
- Easy to customize
