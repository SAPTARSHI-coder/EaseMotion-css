# Card Fan Tilt

Profile cards fan across the screen with alternating tilt angles.

## Features
- Alternating tilt fan
- Rise on hover
- Stacked deck effect
- Pure CSS

## Usage
```html
<div class="cft-card" style="--i:0">A</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
