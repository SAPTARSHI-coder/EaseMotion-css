# Cable Car Grip

## What does this do?
Renders a self-contained CSS-only `ease-cable-car-grip` demo: Cable-car grip clamping onto a moving haul cable.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-cable-car-grip`. No build step or JavaScript is required for the effect.

```html
<section class="ease-cable-car-grip">
  <div class="ease-cable-car-grip__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
