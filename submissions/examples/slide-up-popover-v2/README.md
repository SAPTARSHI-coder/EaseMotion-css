# CSS Slide-Up Popover

A responsive Slide-Up Popover designed for Gaming Hub layouts using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Smooth slide-up animation
- Responsive layout
- CSS Custom Properties
- Accessible (`prefers-reduced-motion`)
- No JavaScript required

## Files

```
slide-up-popover/
├── demo.html
├── style.css
└── README.md
```

## Usage

Open `demo.html` in any browser and hover over the button to view the popover.

## Customization

Modify the CSS variables in `style.css`:

- `--bg`
- `--surface`
- `--primary`
- `--text`
- `--duration`

- Chrome
- Firefox
- Edge
