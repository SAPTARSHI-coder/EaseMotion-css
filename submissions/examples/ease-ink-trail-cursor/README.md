# 🖊️ Ink Trail Cursor – Leaves an Ink Trail That Fades

> An elegant, artistic cursor effect where the cursor leaves a smooth ink trail that fades away, creating a calligraphic, flowing visual experience.

---

## 📖 Description

The **Ink Trail Cursor** is an elegant, artistic cursor effect where the cursor leaves a smooth ink trail that fades away. As you move your mouse, a flowing trail of ink follows behind, gradually fading and dispersing like ink spreading on paper. The effect creates a calligraphic, artistic experience reminiscent of brush painting or fountain pen writing.

The component uses HTML Canvas with JavaScript to create the ink trail effect. Points are added along the cursor path with random sizes and positions, creating a natural, organic ink flow. The trail fades slowly with a subtle glow, and the canvas is cleared with a semi-transparent overlay for a smooth trailing effect.

Perfect for artistic interfaces, creative portfolios, calligraphy brands, and any application where you want to create an elegant, flowing cursor experience. The Ink Trail Cursor transforms a simple cursor into a beautiful, artistic expression.
