# Chart Radar Draw

A radar chart's grid and data polygon draw themselves out.

## Features
- SVG path draw
- Grid + data layers
- Stroke dash timing
- Pure CSS

## Usage
```html
<svg class="crd-svg"><polygon class="crd-data" .../></svg>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
