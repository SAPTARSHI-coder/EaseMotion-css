# CSS Tornado Button

A pure CSS animated button where a mini tornado spins inside the button on hover.

## Features

- Pure CSS animation
- No JavaScript required
- Tornado spiral effect
- Smooth hover interaction
- Responsive design
- Keyboard accessible focus state

## Usage

Open `demo.html` in a browser.

- style.css
