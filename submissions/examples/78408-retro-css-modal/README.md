# CSS-only Retro Modal

A responsive modal component with a retro arcade-inspired visual treatment,
implemented entirely with HTML and Vanilla CSS.

## Features

- CSS-only modal interaction
- Retro arcade-inspired styling
- Pixel-inspired details
- Animated modal entrance
- Backdrop overlay
- Responsive layout
- Keyboard-focus states
- Accessible dialog semantics
- No JavaScript
- No external dependencies
- Reduced-motion support

## Files

- `demo.html`
- `style.css`

## Usage

Open `demo.html` directly in a browser.

The modal opens using a URL fragment:

```text
#retro-modal
