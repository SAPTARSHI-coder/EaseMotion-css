Overview

One navigation, every viewport

The horizontal tab group gives desktop users a compact overview while the mobile breakpoint changes the same links into a readable vertical stack.

Interaction

Clear state hierarchy

Hover, active, and keyboard focus states are intentionally distinct so the current location is easy to identify without relying on motion alone.

Responsive

Touch-ready spacing

Smaller screens receive larger link widths and consistent vertical gaps, keeping labels comfortable to tap even when the viewport is narrow.

Implementation notes

Why this pattern works

  • Semantic links make navigation work before any JavaScript loads.
  • The active state uses contrast and position rather than animation alone.
  • Focus-visible outlines remain available for keyboard navigation.
  • The layout switches direction without changing the document structure.
  • Reduced-motion users are not forced to watch decorative transitions.
