# Parallax Spinner - Cyberpunk Styling

A responsive CSS-only parallax spinner featuring a futuristic cyberpunk interface, animated orbital layers, neon effects, and a simulated data-loading state.

## ✨ Features

- Pure HTML and CSS
- No JavaScript dependency
- Responsive layout
- Cyberpunk visual design
- Multi-layer parallax effect
- Animated orbital rings
- Neon cyan and magenta glow
- Pulsing spinner core
- Animated loading progress bar
- Cyber grid background
- Scanline overlay
- Terminal-style status indicator
- Reduced-motion support
