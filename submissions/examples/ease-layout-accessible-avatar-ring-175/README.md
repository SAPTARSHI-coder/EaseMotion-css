# Floating Aura Avatar Profile Ring with Rotating Dual Gradients

### High-Contrast Accessibility Edition

A modern **Floating Aura Avatar Profile Ring** built with **HTML5** and **CSS3**. This component features rotating dual gradient rings, a floating aura glow, high-contrast styling, and accessibility-focused interactions for profile cards and user dashboards.

---

## ✨ Features

- Rotating dual gradient rings
- Floating aura glow effect
- High-contrast accessible design
- Responsive layout
- Smooth CSS animations
- Keyboard accessibility
- CSS Variables for easy customization
- `prefers-reduced-motion` support
- Pure HTML & CSS implementation

## 🚀 Usage

1. Open the component folder.
2. Keep `demo.html` and `style.css` together.
3. Open `demo.html` in any modern browser.
4. The rotating gradient rings and floating aura animation start automatically.

No external libraries or build tools are required.
