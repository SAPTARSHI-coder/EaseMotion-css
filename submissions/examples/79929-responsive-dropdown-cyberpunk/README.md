# Responsive Dropdown - Cyberpunk

A futuristic, fully responsive dropdown component built with pure
HTML and CSS. It combines cyberpunk-inspired neon effects with a
clean responsive interface.

## ✨ Features

- Pure HTML and CSS
- Fully responsive
- Cyberpunk visual styling
- Neon cyan and magenta accents
- Hover-based dropdown
- Keyboard-friendly focus behavior
- Smooth menu transitions
- Interactive dropdown items
- Custom glowing borders
- Responsive mobile layout
- No JavaScript dependency
- Reduced-motion support
