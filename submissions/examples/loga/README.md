# EaseMotion — Core Animations Engine

EaseMotion is a lightweight, hardware-accelerated CSS animation engine designed for ultra-fluid, modern user interface transitions.

---

## Fold Out Drop Down Utility

The **Fold Out Drop Down** utility applies a 3D perspective fold-out effect designed specifically for dropdown menus, select boxes, popovers, and collapsible navigation panels.

### Quick Start

Include `core/animations.css` (or your bundled stylesheet) in your HTML file and add the utility class to any target element:

```html
<div class="dropdown-menu ease-anim-fold-out-drop-down">
  <ul>
    <li>Option 1</li>
    <li>Option 2</li>
    <li>Option 3</li>
  </ul>
</div>
