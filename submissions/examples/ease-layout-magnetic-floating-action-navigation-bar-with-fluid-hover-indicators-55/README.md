# Magnetic Floating Action Navigation Bar with Fluid Hover Indicators

## Overview

A modern floating navigation component featuring magnetic hover
interactions, fluid active indicators, and high-contrast
accessibility-focused UI.

Built using pure HTML, CSS and JavaScript.

## Features

- 🧲 Magnetic hover movement
- 🌊 Fluid animated indicator
- ♿ High contrast accessibility support
- ⌨️ Keyboard focus support
- 🪟 Glassmorphism navigation design
- 📱 Responsive mobile layout
- ✨ Smooth hover transitions

Open `demo.html` in any modern browser.
