# CSS Scale-Hover Drawer for E-Commerce Checkout Layouts

A modern **Scale-Hover Drawer** built using pure HTML5 and CSS3 for e-commerce checkout experiences. The component provides an elegant checkout drawer with a scale-hover interaction, order summary, coupon section, and responsive design.

## Features

* Pure HTML5 & CSS3
* Scale-hover drawer animation
* Glassmorphism interface
* Shopping cart summary
* Coupon code section
* Payment summary
* Secure checkout button
* Responsive layout
* CSS Custom Properties
* No JavaScript required
* Supports `prefers-reduced-motion`

## Folder Structure

## Usage

1. Open `demo.html` in any modern browser.
2. Customize products, pricing, and checkout details.
3. Modify colors using CSS variables in `:root`.
4. Integrate the drawer into checkout or cart pages.
