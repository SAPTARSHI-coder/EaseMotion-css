# Ease User Badge

## What does this do?

A small circular badge that displays a user's initials as a lightweight avatar fallback.

---

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<div class="user-badge blue">VD</div>
```

### Available color variants

```html
<div class="user-badge blue">VD</div>
<div class="user-badge green">AK</div>
<div class="user-badge purple">JS</div>
<div class="user-badge orange">RM</div>
```

### Features

- Circular badge
- User initials
- Multiple color variants
- Hover animation
- Responsive sizing
- Lightweight CSS

---

## Why is it useful?

User badges are useful as avatar fallbacks when a profile image is unavailable. They can be used in team lists, comments, dashboards, messaging interfaces, and profile sections.

This component keeps the implementation simple while adding subtle interaction feedback in line with the animation-first philosophy of EaseMotion CSS.
