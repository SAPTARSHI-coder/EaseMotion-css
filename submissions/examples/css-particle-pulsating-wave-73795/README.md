# CSS Particle Effect - Pulsating Wave

A pure CSS Pulsating Wave particle animation that creates expanding glowing particles radiating from the center in a smooth wave-like motion.

## Features

- Pure HTML and CSS
- Pulsating wave particle effect
- Smooth hardware-accelerated animations
- Dark mode friendly
- Responsive design
- Accessible implementation
- No JavaScript required
