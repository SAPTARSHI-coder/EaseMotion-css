# Frosted Glass / Glassmorphism Card

A modern UI card component featuring frosted glass styling (`.ease-glass-card`).

## Specifications Implemented

- `.ease-glass-card` CSS class selector.
- Translucent `rgba(255, 255, 255, 0.08)` background.
- `backdrop-filter: blur(10px)` backdrop blurring.
- Subtle glass highlight borders and ambient depth box shadows.
