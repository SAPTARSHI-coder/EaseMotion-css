# Animated Star Rating Demo

## What does this do?

Demonstrates a reusable, animated five-star rating component built with HTML and CSS. The component features smooth left-to-right hover animations and can be used in product cards, customer reviews, testimonials, and other rating-based UI sections.

## How is it used?

Open `demo.html` in your browser to see the animated five-star rating component. Hover over the stars to preview the smooth color-fill and scale animation.

## Features

- Pure HTML & CSS
- No JavaScript
- Hover animation
- Smooth scaling
- Beginner friendly
