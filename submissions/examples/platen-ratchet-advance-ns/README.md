# Platen Ratchet Advance

## What does this do?
Renders a self-contained CSS-only `ease-platen-ratchet-advance` demo: Platen ratchet advancing a line.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-platen-ratchet-advance`. No build step or JavaScript is required for the effect.

```html
<section class="ease-platen-ratchet-advance">
  <div class="ease-platen-ratchet-advance__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
