# glow-modal-ak

Pure CSS animated glowing pop-in modal dialog window — no JavaScript required.

## How to use

```html
<input type="checkbox" id="modal" class="ease-modal-checkbox" />
<label for="modal" class="ease-modal-trigger">Open Modal</label>

<div class="ease-modal-overlay">
  <div class="ease-modal-dialog">
    <h3 class="ease-modal-title">Title</h3>
    <p class="ease-modal-desc">Content</p>
    <label for="modal" class="ease-modal-close">Close</label>
  </div>
</div>
