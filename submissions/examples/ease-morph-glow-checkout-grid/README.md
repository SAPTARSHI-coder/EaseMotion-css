# Ease Morph Glow Checkout Grid

A modern **CSS Morph-Glow Checkout Card Grid** built using pure HTML and CSS for the EaseMotion CSS showcase collection. This component demonstrates a responsive e-commerce checkout layout with animated glassmorphism cards, glowing borders, and smooth hover interactions.

---

## ✨ Features

- Responsive CSS Grid layout
- Glassmorphism card design
- Morphing glow border animation
- Smooth hover lift effects
- Gradient action buttons
- Modern checkout UI
- Mobile-friendly layout
- Accessible with `prefers-reduced-motion` support
- Pure HTML5 & CSS3 (No JavaScript)

## 🎨 CSS Custom Properties

The component uses CSS variables for easy customization.

| Variable | Purpose |
|----------|---------|
| `--bg` | Page background |
| `--surface` | Glass card background |
| `--border` | Card border |
| `--text` | Primary text color |
| `--muted` | Secondary text |
| `--primary` | Primary accent color |
| `--secondary` | Secondary accent color |
| `--success` | Success badge color |
| `--warning` | Warning badge color |
| `--radius` | Border radius |
| `--transition` | Transition timing |

---

## 🚀 Usage

1. Open `demo.html` in your browser.
2. Ensure `style.css` is in the same directory.
3. Resize the browser window to see the responsive layout.
4. Hover over the cards to view the morph-glow animation.

---

## 📱 Responsive Design

The layout automatically adapts to different screen sizes.

- **Desktop:** 3-column grid
- **Tablet:** 2-column grid
- **Mobile:** Single-column layout
