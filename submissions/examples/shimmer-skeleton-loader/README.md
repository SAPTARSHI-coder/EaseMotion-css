# Shimmer Skeleton Loader

A clean, responsive, zero-dependency skeleton loading card demo with a smooth linear gradient shimmer animation.

## Features

- **Zero Dependencies**: Pure HTML and CSS.
- **Accessible**: Built-in `@media (prefers-reduced-motion: reduce)` support for accessibility compliance.
- **Responsive**: Dynamic CSS Grid layout that adapts from mobile screens to desktop viewports.
- **Glassmorphism Theme**: Sleek dark mode visual hierarchy with customizable CSS variables.

## Preview

Open `index.html` in any web browser to view the live shimmer animation demo.
