# Slide-Up Carousel (Fintech Dashboard)

## What does this do?

This component provides a modern slide-up carousel designed for fintech dashboard layouts using pure HTML and CSS. It showcases financial information inside animated cards with smooth transitions and a responsive layout.

---

## Features

- Pure HTML & CSS (No JavaScript)
- Smooth slide-up animation
- CSS-only carousel navigation using radio buttons
- Glassmorphism-inspired card design
- Fintech dashboard styling
- Responsive layout
- Supports `prefers-reduced-motion`
- Easy to customize

---

## Files

- `demo.html` — Demo page showcasing the component
- `style.css` — Component styling and animations
- `README.md` — Documentation

---

## Usage

Simply include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

Then copy the carousel markup from `demo.html`.

---

## Customization

You can easily customize:

- Background colors
- Card colors
- Animation duration
- Border radius
- Typography
- Financial metrics
- Number of slides

---

## Accessibility

- Keyboard-friendly radio controls
- Responsive on desktop, tablet and mobile
- Supports `prefers-reduced-motion`

---

## Browser Support

Works in all modern browsers supporting:

- CSS Flexbox
- CSS Transforms
- CSS Transitions
- CSS Animations
- Media Queries
