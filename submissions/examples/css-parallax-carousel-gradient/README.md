# CSS Parallax Carousel Gradient

A high-performance, responsive horizontal parallax carousel featuring smooth gradient backgrounds, built entirely with vanilla CSS.

## 🚀 Features

- **Zero JavaScript Required:** Utilizes native CSS `scroll-snap` for smooth carousel behavior.
- **Gradient Aesthetic:** Each slide features high-contrast gradient overlays with backdrop blur content cards.
- **Responsive Design:** Fluidly adapts to mobile and desktop viewports using CSS Flexbox and scroll-snap alignment.

## 🛠️ Usage

Copy the HTML structure from `demo.html` and link the styles from `style.css`.
