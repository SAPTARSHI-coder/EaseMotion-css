# Morphing Shape Card

A modern pure CSS card component featuring an animated **Morphing Shape** visual treatment built with organic geometry, gradients, and smooth transitions.

## ✨ Features

- Animated organic morphing shapes
- Smooth border-radius transitions
- Layered gradient surfaces
- Floating visual motion
- Glowing center element
- Multiple color variations
- Responsive card grid
- Dark-mode compatible
- Light-mode compatible
- Keyboard-accessible links
- Visible focus states
- Reduced-motion support
- Hardware-friendly CSS transforms
- No JavaScript
- No external dependencies

## 🎨 Variants

The demo includes:

- Adaptive Forms
- Liquid Identity
- Living Surface

Each card uses a different gradient treatment while sharing the same morphing interaction.
