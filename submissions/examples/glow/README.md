# Brutalist Glowing Search Bar Input

A high-impact, neo-brutalist search bar component featuring hard shadow offsets, vibrant high-contrast backgrounds, a neon glow focus state, and zero JavaScript dependencies.

## Features
* **Zero JavaScript:** Built entirely using native HTML layout structure and advanced CSS pseudoclasses (`:focus-within`, `:hover`).
* **Brutalist Aesthetic:** Thick borders, chunky structural layouts, solid high-contrast drop-shadows, and a responsive configuration.
* **Responsive Layout:** Automatically scales from a horizontal input group on desktop/tablet to a stacked layout on smaller mobile screens.
* **Accessibility Support:** Gracefully handles `prefers-reduced-motion` settings to eliminate structural translation shifts while preserving accessibility cues.

## Usage
Include `style.css` in your project and integrate the markup template defined in `demo.html`.
