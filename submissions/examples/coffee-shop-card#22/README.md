# Coffee Shop Card

This submission demonstrates a warm coffee product card built with
**EaseMotion CSS**. It includes animated entrance effects, hover motion,
size selector chips, price section, order button, and responsive layout.

## 🌟 Features

- **Coffee product card** with visual banner, product name, and shop name.
- **Rating badge** for customer rating.
- **Size selector chips** for product options.
- **Price section** with order button.
- **Product tags** for coffee features.
- **Staggered entrance animation** using `ease-slide-up` and delay utilities.
- **Hover lift effect** using `ease-hover-lift`.
- **Button hover animation** using `ease-hover-grow`.
- **Responsive layout** for mobile and desktop.
- **Reduced motion support** for users who prefer less animation.

## 📁 Files

- `demo.html` — interactive coffee shop card demo
- `style.css` — original coffee card styling
- `README.md` — documentation for this submission

## 🛠️ How to Run

1. Open `demo.html` in your browser.
2. Watch the coffee card animate on page load.
3. Hover over the card to see the lift effect.
4. Hover over the order button to see the grow effect.
5. Resize the browser window to check responsive behavior.
