# Platen Press Impression

## What does this do?
Renders a self-contained CSS-only `ease-platen-press-impression` demo: Platen press closing for inked impression.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-platen-press-impression`. No build step or JavaScript is required for the effect.

```html
<section class="ease-platen-press-impression">
  <div class="ease-platen-press-impression__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
