# Crossbow String Draw

## What does this do?
Renders a self-contained CSS-only `ease-crossbow-string-draw` demo: Crossbow string drawn to latch then released.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-crossbow-string-draw`. No build step or JavaScript is required for the effect.

```html
<section class="ease-crossbow-string-draw">
  <div class="ease-crossbow-string-draw__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
