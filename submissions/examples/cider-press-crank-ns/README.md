# Cider Press Crank

## What does this do?
Renders a self-contained CSS-only `ease-cider-press-crank` demo: Cider press crank squeezing juice from apple pulp.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-cider-press-crank`. No build step or JavaScript is required for the effect.

```html
<section class="ease-cider-press-crank">
  <div class="ease-cider-press-crank__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
