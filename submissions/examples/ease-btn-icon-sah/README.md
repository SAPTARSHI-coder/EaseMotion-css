# Icon-Only Button Variants (`ease-btn-icon`)

## What does this do?
Provides perfectly proportioned square and circular icon button styles featuring tactile bounce animations on hover and click.

## How is it used?
Apply `ease-btn-icon` along with shape modifiers (`square` or `circle`) directly to button elements:
```html
<button class="ease-btn-icon circle primary">➕</button>
<button class="ease-btn-icon square">⚙️</button>
```

## Why is it useful?
Resolves issue #56093 by eliminating inconsistent padding and icon misalignments across toolbars and navigation menus in modern apps.
