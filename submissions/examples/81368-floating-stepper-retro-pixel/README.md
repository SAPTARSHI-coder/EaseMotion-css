# Floating Stepper — Retro Pixel

A responsive floating stepper with a retro arcade-inspired pixel
visual style created for EaseMotion CSS issue #81368.

## Features

- Retro Pixel / arcade-inspired UI
- Floating step cards
- Completed, active and upcoming states
- Pixel-style borders
- Bright arcade color palette
- Animated active marker
- Animated pixel progress bar
- Step-based entrance animation
- Responsive desktop, tablet and mobile layout
- Reduced-motion support
- Pure HTML and CSS
- No JavaScript dependencies
