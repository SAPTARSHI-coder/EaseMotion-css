# CSS Accordion – Holographic Flicker

A lightweight, responsive accordion featuring a subtle holographic flicker
effect using only HTML and CSS.

## Features

- Pure HTML & CSS
- No JavaScript
- Native `<details>` and `<summary>`
- Keyboard accessible
- Responsive design
- Dark-mode friendly
- Holographic flicker animation
- Smooth open/close interaction
- `prefers-reduced-motion` support
- Hardware-friendly CSS animations

## Files

- `demo.html` – Component demonstration
- `style.css` – Component styles and animations

## Usage

Copy the `<details>` accordion markup and the required CSS into your project.

## Accessibility

The component uses native HTML disclosure elements, allowing keyboard
interaction without JavaScript.

The `:focus-visible` state provides a clear keyboard focus indicator.

Users who prefer reduced motion are automatically given a reduced-motion
experience.

## Browser Support

Works in modern browsers supporting:

- CSS Grid
- CSS custom properties
- `<details>` / `<summary>`
- CSS animations
