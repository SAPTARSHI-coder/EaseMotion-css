# Floating Accordion — Glassmorphism

A responsive floating accordion component inspired by
glassmorphism UI patterns.

Implemented for EaseMotion CSS issue #79740.

## Features

- Glassmorphism surface
- Translucent card background
- Background blur using `backdrop-filter`
- Soft borders
- Floating elevation
- Smooth hover interaction
- Native HTML accordion behavior
- No JavaScript required
- Responsive layout
- Keyboard-friendly interaction
- Reduced-motion support
- CSS custom properties
- Zero external dependencies
