# CSS-only Slider with Gradient Styling

A responsive CSS-only slider component featuring a vibrant gradient track, modern styling, accessible focus states, and a clean responsive layout.

## Features

- CSS-only implementation
- Responsive across desktop, tablet, and mobile
- Gradient-styled slider track
- Native HTML range input
- Custom slider thumb
- Hover and focus interactions
- Accessible label for the range input
- Reduced-motion support
- No external dependencies

## Files

- `demo.html` - Slider markup and demo page
- `style.css` - Complete component styling

## Usage

Include the stylesheet in your HTML:

<link rel="stylesheet" href="style.css">
