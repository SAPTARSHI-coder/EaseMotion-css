# Pressure Bloom

Pressure Bloom is an experimental interactive component that visualizes system stress through organic pressure membranes.

Instead of using traditional dashboards, charts, gauges, or progress bars, each system variable behaves like a membrane under pressure.

The closer the system gets to its limit, the more unstable the membrane becomes.

---

## Concept

The central metaphor is:

> Every system has a pressure limit.

Each membrane represents a variable.

For example:

```text
CPU LOAD
MEMORY
NETWORK
QUEUE DEPTH
REQUEST RATE
