# Morphing Glassmorphism Modal

A responsive CSS-only modal component for EaseMotion CSS issue #78305.

## Features

- Pure HTML and CSS
- No JavaScript required
- Fully responsive
- Glassmorphism design
- Morphing modal entrance animation
- Animated gradient background effects
- Floating decorative glow elements
- Animated icon shape
- CSS-only open and close interaction
- Mobile-friendly layout
- Reduced-motion support
