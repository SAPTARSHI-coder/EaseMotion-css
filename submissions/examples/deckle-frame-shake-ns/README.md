# Deckle Frame Shake

## What does this do?
Renders a self-contained CSS-only `ease-deckle-frame-shake` demo: Deckle frame shake evening the slurry on the mould.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-deckle-frame-shake`. No build step or JavaScript is required for the effect.

```html
<section class="ease-deckle-frame-shake">
  <div class="ease-deckle-frame-shake__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
