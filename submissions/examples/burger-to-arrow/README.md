# CSS Burger to Arrow

## What does this do?

A pure CSS animation that smoothly transforms a three-line hamburger icon into a back arrow.

## How is it used?

Include the HTML structure and link the accompanying `style.css` file.

```html
<div
    class="burger-arrow"
    role="img"
    aria-label="Animated hamburger icon transforming into a back arrow"
>
    <span class="line line-top"></span>
    <span class="line line-middle"></span>
    <span class="line line-bottom"></span>
</div>
