# Skew-Active Progress Bar

A lightweight pure HTML and CSS progress bar featuring a dynamic skewed
active indicator for minimalist technology interfaces.

## Features

- Pure HTML and CSS
- No JavaScript or external frameworks
- Minimalist technology-inspired design
- Skewed active highlight animation
- Smooth progress fill animation
- Multiple progress indicators
- Responsive desktop, tablet, and mobile layouts
- Accessible ARIA progressbar semantics
- `prefers-reduced-motion` support
- Customizable CSS properties
