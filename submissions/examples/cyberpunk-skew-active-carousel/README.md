# Cyberpunk Skew-Active Carousel

A futuristic **CSS Skew-Active Carousel** built entirely with **HTML5** and **CSS3**. This showcase demonstrates a CSS-only carousel where the active slide smoothly transitions from a skewed state to a straight, focused view, enhanced with cyberpunk neon styling and glassmorphism effects.

---

## ✨ Features

- 🚀 Pure HTML5 & CSS3
- 🔷 Smooth Skew-to-Active slide transition
- 🌈 Cyberpunk neon visual theme
- 🪟 Glassmorphism card design
- 🎠 CSS-only carousel using radio buttons
- 📱 Fully responsive layout
- ♿ Keyboard-accessible navigation
- 🎨 Easy customization using CSS Custom Properties
- 🌙 Supports `prefers-reduced-motion`
- ⚡ Lightweight with no JavaScript or external libraries

## 🚀 Usage

1. Open `demo.html` in a modern web browser.
2. Select a navigation dot to switch between slides.
3. The active slide animates from a skewed state into a centered view.

No JavaScript is required.

## 🎨 CSS Custom Properties

Customize the appearance by modifying the variables inside `:root`.

| Variable | Description |
|----------|-------------|
| `--bg` | Background color |
| `--surface` | Glassmorphism background |
| `--primary` | Primary neon color |
| `--secondary` | Secondary neon color |
| `--accent` | Accent neon color |
| `--text` | Main text color |
| `--muted` | Secondary text color |
| `--radius` | Border radius |
| `--transition` | Transition duration |

Example:

```css
:root{
    --primary:#00f5ff;
    --secondary:#b026ff;
}
```
