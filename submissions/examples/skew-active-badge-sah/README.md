# Skew-Active Accessible Badge (`#54312`)

## What does this do?
Establishes a cyberpunk collection of geometric parallelogram WAI-ARIA indicator badges equipped with interactive hover tilt adjustment and unskewed legible typography.

## How is it used?
Configure parallelogram status indicator labels inside an `ease-badges-skew-active` container:
```html
<section class="ease-badges-skew-active" aria-label="Cyber Badges">
  <span class="badge-sk blue-sk" role="status"><span class="unsk">...</span></span>
</section>
```

## Why is it useful?
Solves issue #54312 by bringing bold geometric parallelogram framing and dynamic interactive hover tilts to accessible UI status badges.
