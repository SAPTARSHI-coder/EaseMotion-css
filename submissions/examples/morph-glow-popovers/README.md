# CSS Morph-Glow Popover

A responsive **Morph-Glow Popover** built with pure HTML and CSS for creative portfolio layouts.

## Features

- Pure HTML & CSS
- Morph + Glow hover animation
- Responsive design
- Lightweight and reusable
- Accessible with `prefers-reduced-motion`
- Customizable using CSS variables

## Files

- demo.html
- style.css

## Usage

Open `demo.html` directly in any modern browser.

## CSS Variables

```css
:root{
  --bg:#0f172a;
  --card:#1e293b;
  --accent:#38bdf8;
  --text:#ffffff;
}
```
