# CSS Zoom-In Feature Grid for Product Catalog Layouts

A modern **Zoom-In Feature Grid** built using pure HTML and CSS. The component features smooth zoom-in hover animations, responsive feature cards, CSS custom properties, and lightweight styling for product catalog interfaces.

## ✨ Features

- Pure HTML5 & CSS3
- Zoom-in hover animation
- Responsive feature grid
- Glassmorphism card design
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
