# Morphing Shape Toggle (#73876)

A pure HTML & Vanilla CSS toggle featuring a morphing border-radius track and thumb transition.

## Features
- **Aesthetic:** Fluid border-radius morphing from pill/circle to rounded-rect geometry upon activation.
- **Pure CSS:** Zero JavaScript dependencies; relies strictly on standard CSS checkbox state selectors.
- **Performance:** Hardware-accelerated transitions using `transform`, `border-radius`, and `will-change`.
- **Accessibility:** Keyboard focus ring support via `:focus-visible` and `@media (prefers-reduced-motion: reduce)` support.
