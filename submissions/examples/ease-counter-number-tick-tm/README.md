# Counter Number Tick Component

Add ease-counter-number-tick-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|--------|
| `--cp-accent` | `#6366f1` |
| `--cp-accent2` | `#ec4899` |
| `--cp-accent3` | `#10b981` |
| `--cp-radius` | `12px` |

## Note

CSS handles the visual styling. Tiny JS drives the number count-up animation.
