# Ease CSS Skew-Active Accordion for SaaS Showcase Layouts

A modern CSS-only accordion designed for SaaS product
showcase pages.

The component combines skewed inactive panels, smooth
active-state transitions, animated product visuals and
responsive layouts without JavaScript.

## Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- CSS skew effect on inactive panels
- Expanded active panel
- Smooth accordion transitions
- Animated SaaS dashboard visuals
- Workflow showcase
- Analytics showcase
- Collaboration showcase
- Automation showcase
- Responsive desktop layout
- Responsive tablet layout
- Responsive mobile layout
- Keyboard accessible `<details>` / `<summary>` interaction
- Visible focus state
- `prefers-reduced-motion` support
- CSS custom properties for easy customization
