# Backdrop Blur Card Component

Add ease-backdrop-blur-card-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|---------|
| `--bbc-accent` | `#6366f1` |
| `--bbc-radius` | `16px` |
| `--bbc-shadow` | `0 8px 40px rgba(0,0,0,.4)` |

## Technique

`backdrop-filter: blur(16px)` + semi-transparent card background creates frosted glass effect.
