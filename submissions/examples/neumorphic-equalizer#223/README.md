# Neumorphic Equalizer 🎵🎛️

A stunning neumorphic music player with animated equalizer bars, spinning vinyl album art, progress tracking, and soft UI controls. Built entirely with pure CSS animations.

## Features
- **Neumorphic Design**: Soft UI with dual shadows (light + dark) for embossed/debossed effects.
- **12-Band Equalizer**: Animated bars with staggered delays and varying durations for realistic audio visualization.
- **Spinning Vinyl**: Album art rotates like a record player with glow effects.
- **Progress Bar**: Neumorphic track with gradient fill and thumb.
- **Interactive Controls**: Play, previous, next buttons with press-down neumorphic effect.
- **Volume Slider**: Soft UI volume control with fill and thumb.
- **Hover Pause**: Equalizer and vinyl pause on hover.
- **Ambient Glow**: Background radial glow that pulses.
- **Zero JavaScript**: All animations and interactions are pure CSS.

## Customization
Edit CSS variables in `:root`:
- `--bg-base`: Change the neumorphic background color.
- `--shadow-dark` / `--shadow-light`: Adjust shadow colors.
- `--accent`: Change the primary accent color.
- `--eq-speed`: Control equalizer animation speed.

## Browser Support
Works in all modern browsers. Uses CSS custom properties, `box-shadow`, and `animation-play-state`.
