# CSS Gradient Picker

A lightweight CSS gradient picker showcase created with HTML and CSS.

## Features

* Gradient preview
* Color selection controls
* Gradient direction selection
* Responsive design
* Semantic HTML
* Accessible labels
* No JavaScript required for the visual demonstration
* Reduced-motion support

## Files

* `demo.html` - Demo markup and gradient controls
* `style.css` - Gradient picker styling and responsive layout

## Usage

Open `demo.html` in any modern browser to view the gradient picker demonstration.

## Accessibility

The demo uses semantic HTML, descriptive labels, accessible controls, and responsive styling. It also includes `prefers-reduced-motion` support for users who prefer reduced animation.
