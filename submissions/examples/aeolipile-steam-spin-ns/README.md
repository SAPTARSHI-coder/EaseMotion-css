# Aeolipile Steam Spin

## What does this do?
Renders a self-contained CSS-only `ease-aeolipile-steam-spin` demo: Aeolipile Hero steam reaction spin.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-aeolipile-steam-spin`. No build step or JavaScript is required for the effect.

```html
<section class="ease-aeolipile-steam-spin">
  <div class="ease-aeolipile-steam-spin__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
