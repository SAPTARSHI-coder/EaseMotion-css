# ease-ripple-click-bh

Pure CSS ripple click effect on buttons.

## What does this do?
Creates a water ripple effect when buttons are clicked, emanating from the click position.

## How is it used?
```html
<button class="ease-ripple-bh">Click Me</button>
```

## Why is it useful?
Adds satisfying visual feedback for button interactions, making clicks feel more tactile and responsive.
