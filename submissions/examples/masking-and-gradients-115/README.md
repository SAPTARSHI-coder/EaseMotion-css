# Shimmering Metallic Foil Text Effect

A premium glassmorphic typography component featuring a shimmering metallic foil text effect.

The component uses CSS gradients, text clipping, masking, glassmorphism, and animated highlights without requiring external libraries.

## ✨ Features

- Glassmorphic container
- Shimmering metallic typography
- CSS gradient animation
- CSS masking effects
- Animated glass reflection
- Metallic silver highlights
- Cyan, violet, and pink accents
- Hover glow
- Replay shimmer button
- Pause/resume animation
- Responsive layout
- Reduced-motion support
- No external dependencies
