# Animated Floating Input Field (Minimalist Variant)

A clean, zero-dependency, accessible floating input field component engineered for **EaseMotion CSS**. It uses modern CSS state-driven selectors (`:placeholder-shown` and `:focus`) to animate labels gracefully without requiring any JavaScript event listeners.

## Features
- **Pure CSS Motion:** Smooth label translation and border focus animations driven by EaseMotion design tokens.
- **Zero JavaScript:** Fully semantic HTML and CSS handling interactive states.
- **Dark Mode Ready:** Seamless adaptation to system color schemes using CSS custom properties.
- **Accessibility First:** Fully respects `prefers-reduced-motion` preferences by instantly snapping states when requested.
- **Fully Responsive:** Adapts to all viewport sizes smoothly across mobile, tablet, and desktop screens.
