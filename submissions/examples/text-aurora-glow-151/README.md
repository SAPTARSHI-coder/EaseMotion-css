# Aurora Glow Text

A smooth, hardware-accelerated aurora glow text animation that works in both dark and light modes.

## What does this do?
It creates a continuous, flowing aurora borealis inspired multi-color gradient animation over text, complete with an outer glow.

## How is it used?
Apply the `.aurora-text` class to your text element, and mirror the text in the `data-text` attribute.

```html
<h1 class="aurora-text" data-text="Your Text">Your Text</h1>
```

## Why is it useful?
It provides a premium, eye-catching visual effect for hero sections and important headings, utilizing CSS background clipping and pseudo-elements for optimal performance without the need for JavaScript.
