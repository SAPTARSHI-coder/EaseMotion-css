
---

## 🚀 Usage
1. Clone or copy the files into your project.
2. Open `index.html` in your browser.
3. Hover or focus on the button to see the neon tooltip glow into view.

---

## 🛠️ Customization
- **Glow colors** → Adjust `box-shadow` and `text-shadow` for different neon palettes.
- **Duration** → Change `transition: 0.3s` for faster/slower reveal.
- **Tooltip position** → Modify `bottom: 120%` or `left: 50%` for placement.
- **Font styling** → Customize `font-weight` and `text-shadow` for stronger neon vibes.

---

## 📖 Accessibility
- Uses `aria-describedby` for screen readers.
- Tooltip appears on both hover and focus for keyboard accessibility.
