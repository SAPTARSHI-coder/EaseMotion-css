# CSS DNA Helix Loader

A pure CSS animated DNA double-helix loader created using CSS transforms,
gradients, opacity, and staggered keyframe animations.

## Features

- Pure CSS implementation
- No JavaScript required
- No external dependencies
- Animated DNA double-helix appearance
- Responsive design
- CSS custom properties for easy theming
- Light and dark mode support
- Reduced-motion support
- Accessible loading status
