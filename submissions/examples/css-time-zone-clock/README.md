# CSS Time Zone Clock

A responsive CSS-only world clock component that displays multiple
city clocks with different UTC offsets.

## Features

- Pure HTML and CSS
- No JavaScript
- Multiple city clocks
- Responsive grid layout
- Animated second hands
- Hover interaction
- Accessible semantic HTML
- `prefers-reduced-motion` support
- No external dependencies

## Cities Included

- New York — UTC −5
- London — UTC +0
- Dubai — UTC +4
- India — UTC +5:30
- Tokyo — UTC +9
- Sydney — UTC +10
