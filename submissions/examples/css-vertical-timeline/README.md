# CSS Vertical Timeline

A pure CSS interactive vertical timeline component with glowing dots, hover animations, and a sleek dark aesthetic. 

## Features
- **No JavaScript:** Built entirely with CSS pseudoelements and transitions.
- **Glowing Nodes:** Custom styled nodes that scale and glow on hover.
- **Glassmorphism:** Elegant glassmorphism effect on the cards with subtle hover shifts.
- **Responsive:** Stacks correctly on smaller screen sizes.

## Usage
Simply structure your HTML as a `ul` list with the `.ease-timeline` class, where each `li` represents a step in the timeline. Use `.active` on any `li` to mark it as the current active step.
