# Score Roll Counter

A game score ticks up with a highlight flash on each roll.

## Features
- Increment highlight
- Digit roll loop
- Arcade-style frame
- Pure CSS

## Usage
```html
<span class="src-score"><i>0</i><i>5</i></span>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
