# CSS Accordion - Diamond Facet Edge

A premium accordion component inspired by the geometric reflections of cut diamonds. Featuring faceted borders, crystalline highlights, smooth expansion effects, and modern glass-inspired styling using only HTML and CSS.

## Features

- Pure HTML & CSS
- Diamond facet edge styling
- Crystal-inspired border highlights
- Smooth accordion reveal animations
- Dark mode compatible
- Responsive layout
- Accessible semantic markup
- Hardware accelerated transitions

## Usage

```html
<details class="diamond-accordion">
    <summary>Accordion Title</summary>
    <div class="accordion-content">
        Content goes here.
    </div>
</details>
```
