# CSS Scale-Hover Accordion

A modern **Scale-Hover Accordion** built using pure HTML5 and CSS3 for Gaming Hub layouts. The accordion smoothly enlarges on hover while maintaining accessibility, responsiveness, and lightweight performance.

---

## ✨ Features

- Pure HTML5 & CSS3
- Scale-hover interaction
- Gaming-inspired accordion
- Responsive layout
- CSS Custom Properties
- Lightweight and performant
- Accessible semantic HTML using `<details>` and `<summary>`
- `prefers-reduced-motion` support
- No JavaScript required

## 🚀 Usage

1. Copy the component into your project.
2. Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

3. Open `demo.html` in your browser.
