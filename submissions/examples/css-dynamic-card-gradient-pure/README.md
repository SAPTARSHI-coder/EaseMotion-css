# Dynamic Card with Gradient Styling

A visually striking, highly interactive card component that reveals an animated gradient border on hover. Built purely with HTML and CSS.

## Features
- Pure CSS animated gradient borders utilizing `inset` for masking
- Continuous infinite gradient background animation (`@keyframes`)
- Satisfying hover states (lift, scale, icon rotation, arrow translation)
- Fully responsive layout using modern CSS techniques
- Deep dark mode aesthetics

## Usage
Include `demo.html` and `style.css` in your project. The gradient border effect is achieved by placing a fast-moving, colorful gradient layer (`.gradient-bg`) behind a dark, slightly smaller inner container (`.card-content`). Hovering reveals the gradient layer around the edges.
