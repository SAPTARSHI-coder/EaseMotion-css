# Stat Pulse Ring

A KPI number breathes while concentric rings pulse outward.

## Features
- Radiating pulse rings
- Breathing value
- Dashboard framing
- Pure CSS

## Usage
```html
<div class="spr-ring" style="--d:0s"></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
