# Palette Knife · Thick Paint Application 🎨

An interactive palette knife painting tool with thick, textured paint application and blending effects. Drag to apply expressive, impasto-style paint strokes with realistic texture!

## Features

- 🎨 **Thick Paint** – Impasto-style thick paint application
- 🔪 **Palette Knife** – Realistic knife stroke effects
- 🎨 **Texture Selection** – Smooth, Rough, Heavily Textured
- 🖌️ **Color Control** – Pick any color
- 📏 **Size Control** – Adjust knife size (10-60px)
- ✨ **Organic Textures** – Each texture has unique characteristics
- 🎮 **Speed Control** – Adjust animation speed (1-10)
- ⏸️ **Pause/Resume** – Toggle animation
- 🗑️ **Clear** – Clear canvas
- 🔄 **Reset** – Reset to clean state
- 📱 **Touch Support** – Works on mobile devices

## How to Use

1. **Drag** on the canvas to apply thick paint strokes
2. Choose from **Smooth, Rough, or Heavily Textured** textures
3. Use **Color Picker** to change paint color
4. Adjust **Size** slider for knife thickness
5. Press **C** or click **CLEAR** to clear the canvas
6. Press **Space** or click **PAUSE** to pause/resume animation
7. Press **R** or click **RESET** to reset

## Technical Details

- **Stroke System:** Points-based strokes with thick paint rendering
- **Textures:** 3 unique texture algorithms with knife marks
- **Color Variation:** Each stroke has color variation (±40 RGB)
- **Size Variation:** Stroke size varies along path
- **Performance:** 60fps with requestAnimationFrame

## Customization

You can easily customize:
- **Knife Size:** Adjust slider range (10-60)
- **Texture Effects:** Modify texture algorithms
- **Color Variation:** Adjust RGB offset values
- **Stroke Density:** Change steps parameter
- **Opacity:** Modify alpha values in textures

## Browser Support

Works in all modern browsers:
- Chrome, Firefox, Safari, Edge
- Touch support for mobile devices
