How It Works

Every element in the hero section shares a single animation-timeline: scroll() — the root scroll position. As the user scrolls from 0% to 100% of the page, each layer animates through a choreographed sequence: the background orbs drift, the grid fades, the headline blurs in from below, the CTA rises, and decorative shapes float and fade.

Below the fold, stat cards rise into view using the same scroll timeline. This creates a seamless, cinematic narrative where every visual element is synced to scroll — with zero JavaScript.
