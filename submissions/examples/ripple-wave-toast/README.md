# CSS Ripple-Wave Toast

A lightweight pure CSS animated toast notification component built for **EaseMotion CSS**.

The component creates a modern ripple-wave effect with glassmorphism styling and smooth entrance animations for product catalog interfaces.

## ✨ Features

- Pure HTML and CSS implementation
- Ripple wave animation effect
- Glassmorphism notification card
- Smooth entrance transition
- Hover elevation effect
- Responsive design
- Accessible reduced motion support
