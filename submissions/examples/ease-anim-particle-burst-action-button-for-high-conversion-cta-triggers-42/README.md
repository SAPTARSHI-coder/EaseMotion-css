# Particle Burst Action Button for High-Conversion CTA Triggers

### Cyberpunk Theme

A futuristic **Cyberpunk Particle Burst Action Button** built with **HTML5** and **CSS3**. The component features glowing neon gradients, animated particle burst effects, smooth hover interactions, and a responsive design for modern landing pages and call-to-action sections.

---

## ✨ Features

- Cyberpunk neon design
- Animated particle burst effect
- Gradient CTA button
- Glow and shine animation
- Responsive layout
- Smooth hover interactions
- CSS Variables for customization
- Keyboard accessibility
- `prefers-reduced-motion` support
- Pure HTML & CSS implementation

## 🚀 Usage

1. Open the component folder.
2. Keep `demo.html` and `style.css` in the same directory.
3. Open `demo.html` in any modern browser.
4. Hover over the button to trigger the cyberpunk particle burst animation.

No external libraries or build tools are required.
