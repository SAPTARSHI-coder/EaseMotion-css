# CSS Liquid Wave Fill Text Animation

A pure CSS typography animation that creates a surging, animated liquid wave fill inside transparent outlined text using background clipping and multi-stop radial gradients.

## 🎯 Features
- **Pure CSS/HTML:** Zero JavaScript dependencies.
- **Hardware-Accelerated Fluid Fill:** Utilizes `background-clip: text` and animated `background-position` transitions for smooth 60fps wave motion.
- **Dark Mode Compatible:** Tuned with oceanic cyan and deep sapphire gradients on dark backgrounds.
- **Accessible & Responsive:** Adapts via `clamp()` typography, supports keyboard `:focus-visible`, and gracefully stops wave animation under `@media (prefers-reduced-motion: reduce)`.
