# CSS Gradient-Flow Progress Bar

A modern **Gradient-Flow Progress Bar** built using pure HTML5 and CSS3 for responsive dashboard layouts. Animated gradients continuously flow across the progress bars, creating an engaging visual effect while maintaining excellent performance.

---

## ✨ Features

- Pure HTML5 & CSS3
- Animated flowing gradients
- Responsive dashboard layout
- Multiple progress examples
- CSS Custom Properties
- Lightweight
- No JavaScript required
- `prefers-reduced-motion` support
