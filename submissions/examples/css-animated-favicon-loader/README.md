# CSS Animated Favicon Loader

A pure CSS loading animation inspired by animated browser favicons.

## Features

- Pure CSS implementation
- Responsive design
- Lightweight and reusable
- Smooth pulse animation
- No JavaScript required

## Usage

```html
<div class="favicon-loader">
  <span></span>
  <span></span>
  <span></span>
  <span></span>
</div>
