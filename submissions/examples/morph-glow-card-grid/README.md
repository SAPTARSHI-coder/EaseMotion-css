# CSS Morph-Glow Card Grid

A lightweight pure CSS card grid with smooth morphing and glow-inspired hover animations.

## Features

- Pure HTML and CSS
- Responsive card layout
- Smooth hover transformation
- CSS keyframe animation
- Accessible reduced-motion support
- No JavaScript required

## Usage

Copy the folder into:

submissions/examples/morph-glow-card-grid/

Open `demo.html` in a browser.
