# Animated Profile Card

A modern animated profile card component built with pure HTML and CSS. It includes a gradient banner, avatar status indicator, stats section, and a pure CSS follow button toggle.

## Features

- Pure HTML and CSS implementation.
- Animated gradient border card.
- Avatar with online status indicator.
- Stats section with hover effects.
- Pure CSS follow/following toggle.
- Responsive layout.
- Supports `prefers-reduced-motion`.

## Usage

Copy the HTML structure from `demo.html` and link `style.css`.

```html
<input type="checkbox" id="follow-toggle" class="follow-toggle" />

<section class="profile-card">
  <!-- Profile card content -->
</section>
