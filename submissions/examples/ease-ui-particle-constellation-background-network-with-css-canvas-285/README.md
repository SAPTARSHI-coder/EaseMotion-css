# Particle Constellation Background Network with CSS & Canvas (Minimalist Clean Edition)

1. **What does this do?** 
   This component provides a lightweight, interactive particle constellation background using HTML5 `<canvas>` and vanilla JavaScript, overlaid with a clean, glassmorphic minimalist UI component styled entirely with CSS variables. 

2. **How is it used?** 
   The `demo.html` contains an `<canvas id="particle-canvas">` which runs the background simulation, and a `<main class="content-wrapper">` that contains the actual UI layout. The JavaScript at the bottom of the HTML handles the physics, drawing, and interactive mouse-connecting logic for the particles. The `style.css` handles the layout, typography, and glassmorphic card effects.

3. **Why is it useful?** 
   Interactive backgrounds provide an engaging, state-of-the-art feel to landing pages and web apps. By combining the high performance of Canvas for the particles with modern CSS `backdrop-filter` for the UI overlays, this component delivers a stunning, premium aesthetic without relying on heavy external libraries like Three.js or particles.js.
