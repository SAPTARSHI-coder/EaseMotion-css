Utility Implementation Specifications

📐

Utility Class Target

Class `.ease-anim-perspective-fly-in` applies `@keyframes ease-perspective-fly-in` directly to any HTML element.

⚡

Hardware Accelerated

Uses GPU-accelerated CSS `transform: perspective() translateZ() scale()` and `opacity` for smooth 60 FPS rendering.

⚙️

Custom Property Control

Supports `--ease-duration` and `--ease-timing` custom CSS properties for dynamic timing customization.

♿

Accessibility Compliant

Includes explicit `@media (prefers-reduced-motion: reduce)` rules to disable 3D fly-in for sensitive users.
