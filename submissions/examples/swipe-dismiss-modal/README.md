# CSS Swipe Dismiss Modal


A pure CSS swipe-inspired dismiss modal component for EaseMotion CSS.


## Overview

`css-swipe-dismiss-modal` creates a bottom sheet modal with slide and dismiss animations.


## Features

- Pure CSS implementation
- No JavaScript dependency
- Mobile style bottom sheet UI
- Swipe down inspired dismiss effect
- Responsive design
- Reduced motion support

@keyframes slide_up

@keyframes swipe_down
