# CSS Shimmer-Sweep Popover for SaaS Showcase Layouts

A modern SaaS-style popover component featuring a smooth shimmer-sweep animation effect built completely with pure HTML and CSS.

This component is designed for SaaS dashboards, product showcases, and landing pages where lightweight animated interactions are required.


## ✨ Features

- 💬 Modern SaaS popover interface
- ✨ Smooth shimmer-sweep light animation
- 🎨 Glassmorphism inspired UI
- ⚡ Pure HTML and CSS implementation
- 📱 Fully responsive layout
- 🔄 CSS keyframe animation effects
- ♿ prefers-reduced-motion accessibility support
- 🚀 Lightweight and framework-free component

## 🚀 Usage

1. Open `demo.html` directly in your browser.

2. Hover over the product card to display the animated popover.

3. Customize CSS variables in `style.css` to match your branding.


## 🎨 CSS Custom Properties

The component uses CSS variables for easy customization:

```css
:root {

    --bg:#07111f;
    --card:#111827;
    --primary:#38bdf8;
    --secondary:#8b5cf6;
    --text:#f8fafc;
    --muted:#94a3b8;

}

Update these variables to create your own theme.
