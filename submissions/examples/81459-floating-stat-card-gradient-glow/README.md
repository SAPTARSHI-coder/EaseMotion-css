# Floating Stat Card — Gradient Glow

A responsive floating statistics card featuring animated
gradient glow effects and modern dashboard styling.

Created for EaseMotion CSS issue #81459.

## Features

- Gradient glow effect
- Floating hover animation
- Animated gradient movement
- Gradient-highlighted statistic
- Progress indicator
- Growth badge
- Responsive desktop, tablet and mobile layouts
- CSS custom properties
- Smooth state transitions
- `prefers-reduced-motion` support
- Zero JavaScript dependencies
