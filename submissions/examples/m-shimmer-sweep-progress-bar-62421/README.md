# CSS Shimmer-Sweep Progress Bar for Product Catalog Layouts

A modern **Shimmer-Sweep Progress Bar** built using pure HTML and CSS. The component features a smooth shimmer-sweep animation, responsive layout, CSS custom properties, and lightweight styling for product catalog interfaces.

## ✨ Features

- Pure HTML5 & CSS3
- Shimmer-sweep progress animation
- Responsive layout
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
