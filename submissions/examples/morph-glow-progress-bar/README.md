# CSS Morph-Glow Progress Bar for Responsive Dashboard Layouts

A modern **Morph-Glow Progress Bar** component built using only **HTML5 and CSS3**.

This example creates animated dashboard progress indicators with morphing shapes, glowing effects, smooth transitions, responsive cards, and accessibility support without JavaScript.

---

## ✨ Features

- 🌈 Morphing progress bar animation
- 💡 Dynamic glow effects
- ✨ Shine sweep animation
- 🎨 Gradient progress indicators
- ⚡ Pure CSS animations
- 📱 Responsive dashboard layout
- 🎯 CSS Custom Properties
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript dependency

## 🚀 Usage

1. Open `demo.html` in any modern browser.
2. View animated progress bars.
3. Customize colors, sizes, and animations using CSS variables.
