# Retro Arcade Pixel Bento Card

A retro-inspired bento grid component featuring classic arcade aesthetics,
pixel-style visuals and interactive CSS animations.

Built entirely with pure HTML and Vanilla CSS.

## Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Responsive bento grid
- Retro arcade visual style
- Pixel-inspired grid background
- Animated arcade orb
- High-score display
- System status indicator
- Pixel character animation
- Animated coin indicators
- Interactive start button
- Dark mode compatible
- Reduced-motion support
