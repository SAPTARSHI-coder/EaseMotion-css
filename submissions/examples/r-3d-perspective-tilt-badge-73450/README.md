# 3D Perspective Tilt Badge

A smooth and interactive badge featuring a 3D perspective tilt effect using pure HTML and CSS.

## Features

- Pure HTML and Vanilla CSS
- 3D perspective hover effect
- Smooth hardware-accelerated transitions
- Keyboard focus support
- Responsive design
- Dark-mode friendly styling
- Reduced-motion support
- No JavaScript or external libraries
