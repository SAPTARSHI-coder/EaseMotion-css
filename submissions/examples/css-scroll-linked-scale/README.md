# CSS Scroll-Linked Scale

A pure CSS scroll-driven animation that smoothly scales elements as they move through the viewport.

## Features

- Pure CSS implementation
- No JavaScript required
- Uses modern CSS scroll-driven animation APIs
- Uses `scroll()` as the animation timeline
- Uses `animation-timeline`
- Uses `animation-range`
- Smooth `transform: scale()` animation
- Responsive design
- CSS custom properties for theming
- Automatic light and dark mode support
- Reduced-motion support
- No external dependencies

## Files

- `demo.html` — standalone demonstration
- `style.css` — complete component styling
