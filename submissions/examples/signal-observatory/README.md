# Signal Observatory

Signal Observatory is a futuristic monitoring component that visualizes
incoming signals through an interactive radar-style interface.

Instead of presenting monitoring information as a conventional
dashboard, the component uses a visual signal field to create the
feeling of an active observatory.

## Features

- Interactive radar visualization
- Animated radar sweep
- Signal detection points
- Signal severity states
- Interactive signal selection
- Signal detail panel
- Frequency information
- Signal strength information
- Signal classification
- Live monitoring indicator
- Pause/resume scanning
- Clear signals functionality
- Radar parallax interaction
- Animated signal pulses
- Responsive layout
- Vanilla JavaScript
- No external JavaScript dependencies
- JavaScript contained inside `demo.html`
