# glow-notification-dot-ak

Pure CSS animated glowing bell notification alert badge — no JavaScript required.

## How to use

```html
<div class="ease-notification-icon">
  🔔
  <span class="ease-notification-dot"></span>
</div>

<!-- Count Badge -->
<div class="ease-notification-icon">
  💬
  <span class="ease-notification-count">5</span>
</div>
