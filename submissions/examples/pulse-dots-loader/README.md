# Pulse Dots Loader

A bouncing trio of pulse dots with staggered timing that reads as a friendly loading state.

## Features
- Three dots scale and fade on a shared loop with staggered delays
- Customizable size, gap and color via CSS custom properties
- Reduced-motion fallback so the loader never hurts users

## Usage
```html
<div class="pd-loader" aria-label="Loading">
  <span></span><span></span><span></span>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
