# Color Roll Palette

A swatch palette where each color chip flips through its tints in a rolling loop.

## Features
- Chips cycle through hue families
- Selected chip locks with a check pop
- Swatch labels float beneath

## Usage
```html
<div class="cr-palette">
  <div class="cr-chip cr-c1"></div>
  <div class="cr-chip cr-c4"></div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
