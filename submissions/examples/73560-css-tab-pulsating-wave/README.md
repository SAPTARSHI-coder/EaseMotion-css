# Pulsating Wave Tabs

Pure HTML and Vanilla CSS implementation for issue #73560.

## Features

- Animated active-state pulse
- Native radio controls
- Lightweight opacity and scale animation
- Responsive layout
- Visible keyboard focus
- Reduced-motion support
- No JavaScript dependencies

## Implementation

The selected label exposes a pseudo-element that expands outward as a wave ring. CSS sibling selectors reveal the matching panel.

## Accessibility

Native controls provide keyboard selection. Reduced-motion preferences disable the pulse and other transitions.

## Usage

Open `demo.html` directly in a modern browser.
