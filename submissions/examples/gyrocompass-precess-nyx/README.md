# Gyrocompass Precess

## What does this do?
Renders a self-contained CSS-only `ease-gyrocompass-precess` demo: Gyrocompass rotor precessing toward true north.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-gyrocompass-precess`. No build step or JavaScript is required for the effect.

```html
<section class="ease-gyrocompass-precess">
  <div class="ease-gyrocompass-precess__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
