# CSS Fade-In Badge for Fintech Dashboard Layouts

A modern fintech dashboard badge component featuring smooth fade-in animations, animated status indicators, and glassmorphism styling using pure HTML and CSS.

This component provides clean and lightweight status badges for financial dashboard interfaces without JavaScript or external dependencies.

## ✨ Features

- ✨ Smooth fade-in badge animation
- 💳 Fintech dashboard inspired UI
- 🟢 Animated status indicators
- 🎨 Gradient and glow effects
- 💎 Glassmorphism card design
- ⚡ Pure HTML and CSS implementation
- 📱 Fully responsive layout
- 🔄 Smooth CSS transitions
- ♿ Accessibility support with `prefers-reduced-motion`

## 🚀 Usage

1. Clone the EaseMotion CSS repository.

2. Navigate to:


submissions/examples/ease-css-fade-in-badge-fintech-dashboard-layouts/


3. Open `demo.html` in any modern browser.

No JavaScript, frameworks, or external libraries are required.

## 🎨 CSS Custom Properties

The component uses CSS variables for easy customization:

```css
:root {
    --bg:#050816;
    --primary:#00f5ff;
    --secondary:#8b5cf6;
    --green:#22c55e;
    --text:#f8fafc;
    --muted:#94a3b8;
}

Update these values to match your fintech dashboard branding.
