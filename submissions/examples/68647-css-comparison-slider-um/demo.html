Comparison Slider

Drag the center handle horizontally or use keyboard arrow keys to compare two image states side by side. Built using a native HTML range input, CSS variables, and modern clip-path polygons.

Engineering Details

Under the hood

Clip-Path Rendering The top image layer is clipped dynamically using a polygon() layout configured with the variable offset.
Composite Performance Updates map directly to a CSS variable boundary. Only painting takes place during drag actions, preventing document layout cycles.
Keyboard Accessible Uses a standard <input type="range"> component under the hood, natively unlocking keyboard arrows, Home, End, and focus rings.
Zero JS Overhead Interactive values are bound inline via single-statement updates without importing rendering scripts.
