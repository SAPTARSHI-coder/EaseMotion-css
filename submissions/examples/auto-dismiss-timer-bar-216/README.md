# Floating Notification Toast Alert with Auto-Dismiss Timer Bar

A compact mobile-first notification toast component built with pure HTML, CSS and JavaScript.

## Features

- Mobile-first responsive design
- Floating notification animation
- Automatic dismissal after 5 seconds
- Animated timer/progress bar
- Manual close button
- Pause timer while hovering
- Glassmorphism-inspired UI
- Gradient accents
- Keyboard focus states
- Reduced-motion accessibility support
- No external libraries or dependencies
