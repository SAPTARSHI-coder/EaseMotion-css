# 🌌 Portal Button – Opens a Swirling Portal Effect

> A magical, inter dimensional button that opens a swirling portal effect around it on hover, creating a stunning, immersive experience.

---

## 📖 Description

The **Portal Button** is a magical UI component that opens a swirling portal effect around it on hover. Eight expanding rings ripple outward from the button, creating a stunning, interdimensional portal effect. The rings expand and rotate with staggered delays, accompanied by glowing particles that burst outward, completing the magical portal illusion.

The component uses CSS animations with `transform` and `keyframes` to create the expanding rings and particle effects. Each ring has a unique size and color, expanding outward with a satisfying spring-like motion. The button also features a glowing gradient border and a subtle particle burst effect.

Perfect for fantasy-themed interfaces, gaming websites, creative portfolios, and any application where you want to create a magical, immersive interaction. The Portal Button transforms a simple hover into a stunning, interdimensional experience.
