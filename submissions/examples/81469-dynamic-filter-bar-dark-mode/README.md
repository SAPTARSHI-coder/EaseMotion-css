# Dynamic Filter Bar - Dark Mode

A responsive dynamic filter bar featuring a polished
dark-mode interface, subtle ambient lighting, interactive
filter controls, active filter chips, and smooth CSS
transitions.

## Features

- Pure HTML and CSS
- Dark mode visual system
- Responsive filter bar
- Search input
- Category filter
- Status filter
- Sorting control
- Clear and apply actions
- Active filter chips
- Live filter-sync indicator
- Responsive result cards
- Ambient background effects
- Hover and focus interactions
- Keyboard-friendly controls
- `prefers-reduced-motion` support
- Zero JavaScript dependencies
