# Claymorphism Command Palette Search

A soft claymorphism-inspired command palette for quickly accessing
common application actions.

## Features

- Claymorphism visual style
- Search input
- Command list
- Keyboard shortcut indicators
- Responsive layout
- CSS custom property theming
- Keyboard-accessible controls
- Visible focus states
- Reduced-motion support
