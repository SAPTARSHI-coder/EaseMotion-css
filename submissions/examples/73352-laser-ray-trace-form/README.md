# Laser Ray Trace Form

A smooth, responsive form component inspired by **Laser Ray Trace** styling using pure HTML and Vanilla CSS.

## ✨ Features

- Laser-inspired input focus effects
- Animated ray tracing across focused fields
- Glowing corner indicators
- Smooth CSS transitions
- Responsive form layout
- Automatic dark mode support
- Keyboard-friendly controls
- Visible focus states
- Reduced-motion support
- Hardware-friendly transform animations
- No JavaScript
- No external dependencies
