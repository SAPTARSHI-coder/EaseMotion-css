# Lease Renewal Expiry Fence

Lease Renewal Expiry Fence is an advanced CSS animation that visualizes coordinator leases, renewal heartbeats, expiry windows, and fenced stale holders. It uses pure HTML and CSS with responsive layout and reduced-motion support.

## Features

- Animated lease heartbeat and expiry timeline
- Fence barrier for stale holders
- Responsive coordination dashboard
- Accessible semantic demo markup
