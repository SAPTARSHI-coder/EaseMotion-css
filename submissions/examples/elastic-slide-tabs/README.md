# CSS Elastic-Slide Tabs

A lightweight CSS-only tabs component featuring a smooth elastic slide animation for creative portfolio layouts.

## Features

- Pure HTML & CSS
- Elastic slide transition
- CSS-only tab switching
- Responsive layout
- Accessible with `prefers-reduced-motion`
- No JavaScript required

## Files

```text
demo.html
style.css
README.md
```

## Usage

Open `demo.html` in any modern browser.

## Customization

- Tab colors
- Animation speed
- Border radius
- Typography
- Container width

## Browser Support

Compatible with all modern browsers supporting CSS animations and transitions.
