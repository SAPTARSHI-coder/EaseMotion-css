# CSS Multi-line Ellipsis Clamp

## Description

A pure CSS utility for truncating multi-line text using `-webkit-line-clamp`. This component helps maintain consistent layouts by limiting text to a specified number of lines and displaying an ellipsis when content overflows.

## Features

- Pure CSS implementation
- Multi-line text truncation
- Responsive layout
- No JavaScript required
- Reusable utility classes
- Ideal for cards, blog previews, and product descriptions

## Usage

```html
<p class="clamp-3">
  Long text content goes here...
</p>
```

Available classes:

- `.clamp-2`
- `.clamp-3`
- `.clamp-4`
