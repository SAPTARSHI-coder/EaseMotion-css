2 Line Clamp

This utility truncates long text after two lines and automatically displays an ellipsis when the content exceeds the available space.

3 Line Clamp

This utility truncates long text after three lines and automatically displays an ellipsis when the content exceeds the available space. It is useful for cards, blog previews, and product descriptions.

4 Line Clamp

This utility truncates long text after four lines and automatically displays an ellipsis when the content exceeds the available space. Developers can easily customize the number of visible lines by changing the line clamp value.
