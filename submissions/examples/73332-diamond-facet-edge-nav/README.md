# Diamond Facet Edge Navigation

A responsive navigation component inspired by **Diamond Facet Edge** styling, built entirely with HTML and Vanilla CSS.

## ✨ Features

- Diamond-inspired geometric navigation
- Layered facet edge effects
- Smooth hover and focus transitions
- Active navigation state
- Responsive CSS-only mobile menu
- Dark-mode compatible
- Keyboard-friendly navigation
- Visible focus states
- Reduced-motion support
- Hardware-friendly transform effects
- No JavaScript
- No external dependencies
