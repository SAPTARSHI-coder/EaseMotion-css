# CSS Gift Card Design

A polished digital gift card component built entirely with HTML and CSS.

## Features

- Digital gift card layout
- Balance and gift code display
- Glossy gradient styling
- Animated hover shine
- Responsive design
- Keyboard-accessible button
- Reduced-motion support
- Forced-colors support
- No JavaScript required

## Usage

Include `style.css` and copy the gift card markup from `demo.html`.

The colors can be customized through the CSS custom properties
defined in `:root`.
