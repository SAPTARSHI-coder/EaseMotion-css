# Cyberpunk Neon Card

A futuristic pure CSS card component featuring neon gradients, glowing borders, subtle hover elevation, and cyberpunk-inspired visual effects.

## What does this do?

The Cyberpunk Neon Card creates a futuristic card interface using only semantic HTML and vanilla CSS.

It includes:

- Neon cyan, pink, and purple accents
- Animated glowing status indicator
- Gradient neon border
- Hover elevation and shine effect
- Responsive layout
- Keyboard-accessible focus state
- Reduced-motion support
- Light and dark color-scheme compatibility
- No JavaScript or external dependencies

## How is it used?

Add the card markup to your HTML and include the accompanying `style.css`.

```html
<article class="cyber-card">
    <div class="card-content">
        <span class="card-tag">SYSTEM ONLINE</span>

        <h2>Neon Interface</h2>

        <p>
            A futuristic cyberpunk-inspired card for modern interfaces.
        </p>

        <a class="cyber-button" href="#">
            Explore
            <span aria-hidden="true">→</span>
        </a>
    </div>
</article>
