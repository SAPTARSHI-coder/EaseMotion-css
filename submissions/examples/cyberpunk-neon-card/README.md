# Cyberpunk Neon Card

A futuristic pure CSS card component featuring a Cyberpunk Neon visual style with glowing borders, neon accents, smooth hover transitions, and subtle interface effects.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript
- No external libraries
- Cyberpunk neon visual design
- Smooth hover transitions
- Glowing borders and accents
- Responsive layout
- Dark-mode compatible
- Hardware-accelerated CSS transforms
- Keyboard focus support
- `prefers-reduced-motion` support
