# Ease User Card Mini

## What does this do?

A compact user profile card displaying an avatar, name, and role with a subtle hover animation.

---

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<div class="user-card">
    <div class="avatar">
        V
    </div>

    <div class="user-info">
        <h3>Vidheendu</h3>
        <p>Frontend Developer</p>
    </div>
</div>
```

### Features

- Circular avatar
- User name
- User role
- Hover lift animation
- Avatar scale animation
- Responsive layout

---

## Why is it useful?

Compact user cards are commonly used in team sections, dashboards, collaboration tools, and profile lists.

This component provides a lightweight and reusable profile pattern with subtle motion while following the animation-first philosophy of EaseMotion CSS.
