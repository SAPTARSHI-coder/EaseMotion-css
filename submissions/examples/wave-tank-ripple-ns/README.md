# Wave Tank Ripple

## What does this do?
Renders a self-contained CSS-only `ease-wave-tank-ripple` demo: Wave tank generating expanding water ripples.

## How is it used?
Open `demo.html` in a browser. The animated face uses classes like `ease-wave-tank-ripple`, `ease-wave-tank-ripple__arm`, and `ease-wave-tank-ripple__core`. No build step or JavaScript is required for the motion.

```html
<section class="ease-wave-tank-ripple">
  <div class="ease-wave-tank-ripple__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
