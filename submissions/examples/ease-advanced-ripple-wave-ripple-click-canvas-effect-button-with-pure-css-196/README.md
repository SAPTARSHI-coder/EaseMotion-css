# Ripple Wave Ripple Click Canvas Effect Button with Pure CSS

A modern **Neumorphic Finish** button featuring animated ripple waves, soft neumorphic shadows, and responsive interactions using **pure HTML & CSS**.

## ✨ Features

- Neumorphic button design
- Pure CSS ripple wave animation
- Animated glow effect
- Smooth hover and click interactions
- Responsive layout
- Modern CSS variables
- Lightweight and dependency-free
- Easy customization

## 📁 Project Structure

```
ease-advanced-ripple-wave-ripple-click-canvas-effect-button-with-pure-css-196/
│── demo.html
│── style.css
└── README.md
```

## 🚀 Usage

1. Open `demo.html` in any modern browser.
2. Customize colors and animation speed in `style.css`.
3. Integrate the button into your own project.

## 🎨 Customization

Modify the CSS variables inside `:root`:

- Primary gradient colors
- Background color
- Border radius
- Shadow intensity
- Ripple size
- Ripple speed
