# CSS Shimmer-Sweep Tabs for Fintech Dashboard Layouts

A modern **Shimmer-Sweep Tabs** component built using pure HTML5 and CSS3 for fintech dashboard layouts. This component provides a premium financial dashboard experience with animated shimmer effects, smooth tab transitions, glassmorphism cards, and responsive design.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Fintech dashboard inspired layout
* Animated shimmer sweep effect
* Smooth tab hover transitions
* Gradient active tab indicator
* Glassmorphism dashboard cards
* Financial statistics showcase
* Responsive desktop, tablet, and mobile layouts
* CSS Custom Properties for easy customization
* Lightweight keyframe animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over the dashboard tabs to view shimmer animations.
3. Customize colors, shadows, spacing, and animation speed using CSS variables inside `:root`.

## CSS Custom Properties

```css
:root{
  --bg:#f8fafc;
  --surface:rgba(255,255,255,.85);
  --primary:#2563eb;
  --secondary:#06b6d4;
  --accent:#8b5cf6;
  --text:#111827;
  --muted:#64748b;
  --shadow:0 25px 70px rgba(37,99,235,.18);
  --radius:28px;
}
```
