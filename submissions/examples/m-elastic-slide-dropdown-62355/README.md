# CSS Elastic-Slide Dropdown for Product Catalog Layouts

A responsive dropdown component featuring an elastic slide-down animation built entirely with HTML and CSS. Perfect for product catalog navigation menus and category selectors.

## ✨ Features

- Pure HTML5 & CSS3
- Elastic slide-down opening animation
- Smooth hover interactions
- Responsive layout
- CSS Custom Properties
- Keyboard accessible with `:focus-within`
- `prefers-reduced-motion` support
- No JavaScript required
