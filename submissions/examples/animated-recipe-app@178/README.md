# Animated Recipe/Cooking App

A beautiful **Recipe App Interface** built with **EaseMotion CSS**. Features recipe cards with hover effects, cooking steps preview, chef profiles, category browsing, and a featured recipe section.

## ✨ Features

- **⭐ Featured Recipe**: Full-width hero with chef info and cooking CTA
- **🍽️ Recipe Cards**: Image cards with time, difficulty, ratings, and calories
- **📝 Cooking Steps**: Step-by-step preview with numbered cards
- **👨‍🍳 Chef Profiles**: Top chefs with specialties and follow buttons
- **🏷️ Category Chips**: Horizontally scrollable category filters
- **🥘 Floating Ingredients**: Ambient background food emoji animation
- **🎬 Staggered Entrance**: All sections slide up sequentially
- **📱 Fully Responsive**: Multi-column to single column adaptation

## 🧩 EaseMotion Classes Used

| Class | Purpose |
|-------|---------|
| `ease-fade-in` | Fades in the main page and footer |
| `ease-slide-up` | Slides sections up on entrance |
| `ease-delay-100` to `ease-delay-700` | Creates cascading staggered sequence |
| `ease-card` | Base card structure |
| `ease-hover-lift` | Lift effect on all cards |
| `ease-hover-grow` | Scale effect on buttons |
| `ease-btn` + `ease-btn-primary` | Styled cook button |
| `ease-grid` + `ease-grid-cols-*` | Responsive grid layouts |
| `ease-gap-4` | Spacing between grid items |

## 🚀 How to Use

1. Open `demo.html` in any modern browser
2. Watch all sections slide in with staggered animations
3. Hover over recipe cards to see image zoom and lift effect
4. Observe the **floating ingredients** in background
5. Hover over chef cards to see follow button effects
6. Resize to mobile to see the responsive layout
