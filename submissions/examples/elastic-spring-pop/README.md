# Elastic Spring Pop Animation

## Overview

This submission demonstrates a reusable **Elastic Spring Pop** animation using pure CSS. The element compresses and rebounds with a spring-like effect when hovered.

## Features

- Pure CSS animation
- Elastic spring scaling effect
- CSS keyframes
- Configurable timing using CSS variables
- `prefers-reduced-motion` support
- Responsive demo

## Customization

```css
--ease-duration: 600ms;
--ease-timing: cubic-bezier(.34,1.56,.64,1);
```

## Demo

Open `demo.html` directly in any modern browser.
