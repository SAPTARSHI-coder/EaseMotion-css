# CSS Rotate-Fade Navbar for SaaS Showcase Layouts

A modern **Rotate-Fade Navbar** built using pure HTML and CSS. The navigation bar smoothly rotates and fades into view while using a premium glassmorphism design suitable for SaaS landing pages, dashboards, and admin interfaces.

## ✨ Features

- Pure HTML5 & CSS3
- Rotate + fade entrance animation
- Glassmorphism navbar
- Responsive SaaS layout
- Gradient CTA button
- CSS Custom Properties
- `prefers-reduced-motion` support
- No JavaScript required
