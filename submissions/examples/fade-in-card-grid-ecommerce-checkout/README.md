# Fade-In Card Grid for E-Commerce Checkout

A lightweight, responsive CSS-only card grid designed for
e-commerce checkout layouts.

## Features

- Pure HTML and CSS
- Smooth fade-in and upward entrance animation
- Staggered card animation
- Hover elevation effect
- Subtle decorative hover effect
- Responsive desktop, tablet, and mobile layouts
- CSS custom properties for easy customization
- No JavaScript or external frameworks
- `prefers-reduced-motion` accessibility support
