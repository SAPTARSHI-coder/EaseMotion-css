# Parallax Button with Retro Styling

A responsive CSS-only button featuring a layered parallax effect and a retro arcade-inspired visual style.

## Features

- Retro-inspired visual design
- Layered parallax depth
- CSS-only interaction
- Hover depth movement
- Active/pressed state
- Responsive sizing
- Keyboard-accessible focus state
- Reduced-motion support
- No JavaScript
- No external dependencies

## Usage

Include the stylesheet:

<link rel="stylesheet" href="style.css" />
