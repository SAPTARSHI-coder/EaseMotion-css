# 🔮 Crystal Ball – Shows Swirling Visions Inside

> A mystical crystal ball component with swirling visions, glass effects, mist layers, and prophetic messages.

---

## 📖 Description

The **Crystal Ball** component creates a mystical fortune-telling experience with swirling visions inside a glass sphere. Built with vanilla HTML, CSS, and JavaScript, it features animated visions, mist layers, glass highlights, prophetic messages, and 3 swirl modes.

### 🎯 Core Features

- **Crystal ball** – glass sphere with highlights, glow, and mist layers
- **Swirling visions** – 12 animated symbols swirling inside the ball
- **3 swirl modes** – Spiral, Wave, Chaos with different motion patterns
- **Prophetic messages** – 15 unique vision messages with icons
- **Pulse effects** – ball pulses on vision reveal
- **Vision counter** – tracks number of visions seen
- **Interactive controls** – buttons, click on crystal ball, keyboard shortcuts
- **Responsive design** – adapts to different screen sizes

### ⌨️ Interaction Options

| Method | Action |
|--------|--------|
| **Click** | Click crystal ball to see a vision |
| **Buttons** | Show Vision, Toggle Swirl, Reset |
| **Keyboard** | `Space` or `V` – Vision · `S` – Swirl · `R` – Reset |

### ✨ Vision Experience

When revealing:
1. **Ball pulses** – crystal ball expands and glows
2. **Visions swirl** – symbols orbit and rotate inside
3. **Mists drift** – layered mist animations intensify
4. **Message appears** – prophetic text fades in
5. **Counter updates** – vision count increments

### 🛠️ Technologies Used

- **HTML5** – semantic structure
- **CSS3** – animations, gradients, transforms, glass effects
- **JavaScript (ES6)** – DOM manipulation, requestAnimationFrame, particle system

### 🎨 Design Philosophy

This component embodies **EaseMotion CSS's animation-first philosophy** through:

- **Continuous animation** – swirling visions with requestAnimationFrame
- **Glass effects** – highlights, gradients, and transparency
- **Mist layers** – drifting fog inside the crystal ball
- **Interactive feedback** – pulse effects, status updates, counter
- **Mystical atmosphere** – purple/blue glow and glass effects
- **Human-readable classes** – `.crystal-ball`, `.sphere`, `.vision`, `.mist-layer`

### 🔧 Customization Options

| Property | Location | Default |
|----------|----------|---------|
| Visions | `visions` array | 15 messages |
| Vision symbols | `vision` elements | 12 emojis |
| Swirl modes | `toggleSwirl()` | 3 modes |
| Ball size | CSS `width`/`height` | 200px |
| Mist layers | HTML `.mist-layer` | 3 layers |
