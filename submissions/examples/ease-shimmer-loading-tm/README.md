# Shimmer Loading Component

Add ease-shimmer-loading-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|---------|
| `--slc-accent` | `#6366f1` |
| `--slc-shimmer` | `rgba(255,255,255,0.06)` |
| `--slc-radius` | `8px` |

## Technique

`::after` pseudo-element with animated `translateX` shimmer sweep creates the loading effect.
