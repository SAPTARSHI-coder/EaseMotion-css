# CSS Shimmer-Sweep Pricing Table for Fintech Dashboard Layouts

A pure CSS Shimmer-Sweep pricing matrix designed with diagonal light reflection overlays, obsidian glassmorphism, and responsive tier structures for fintech platforms.

## Key Features

- **Shimmer Light Reflection Sweep:** A diagonal gradient flare sweeps across cards on hover (`left: -150%` to `left: 200%`), with a continuous keyframe shimmer on featured tiers.
- **Button Light Wave:** Includes matching shimmer sweeps on CTA buttons when hovered.
- **Pure CSS Billing Cycle Radio Switcher:** Allows zero-JS switching between monthly and annual billing calculations.
- **Responsive & Accessible:** Adaptable layout from 3 columns on desktop to a single column on mobile, featuring full `@media (prefers-reduced-motion: reduce)` support.

## Customization

```css
:root {
    --bg-dark: #080b11;
    --shimmer-cyan: #06b6d4;
    --shimmer-blue: #3b82f6;
}
```
