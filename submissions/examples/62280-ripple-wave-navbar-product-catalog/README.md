# CSS Ripple-Wave Navbar for Product Catalog Layouts

A modern **Ripple-Wave Navbar** component built completely with pure HTML5 and CSS3 for product catalog layouts.

This component provides a futuristic navigation experience with animated ripple effects, glassmorphism styling, smooth hover interactions, and responsive design.

---

## ✨ Features

- Pure HTML5 and CSS3 implementation
- No JavaScript dependency
- Product catalog navigation layout
- Ripple-wave hover animation
- Smooth CSS transitions
- Glassmorphism navbar design
- Animated navigation links
- Gradient action button
- Responsive layout
- CSS custom properties support
- Lightweight animations
- `prefers-reduced-motion` accessibility support

## 🚀 Usage

1. Open `demo.html` in any modern browser.
2. Hover over navigation links to view ripple-wave effects.
3. Customize colors and spacing using CSS variables.
