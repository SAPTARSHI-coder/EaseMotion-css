# CSS 3D-Flip Stepper for SaaS Showcase Layouts

A modern **3D-Flip Stepper** built using pure HTML5 and CSS3 for SaaS showcase layouts. This component creates an interactive onboarding journey with 3D card flipping effects, animated step indicators, and a responsive glassmorphism design.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* 3D card flip animation using CSS transforms
* SaaS onboarding workflow showcase
* Animated step navigation indicators
* Perspective-based 3D effects
* Glassmorphism container design
* Smooth CSS transitions and keyframe animations
* Responsive layout for desktop, tablet, and mobile
* CSS Custom Properties for easy customization
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Select different numbered steps to switch between SaaS workflow stages.
3. Hover over the step card to experience the 3D flip animation.
4. Customize colors, shadows, spacing, and animation timing using the CSS variables inside `:root`.

## CSS Custom Properties

```css
:root{
  --bg:#eef4ff;
  --surface:rgba(255,255,255,.9);
  --primary:#2563eb;
  --secondary:#06b6d4;
  --accent:#8b5cf6;
  --text:#111827;
  --muted:#64748b;
  --shadow:0 18px 45px rgba(37,99,235,.18);
  --radius:24px;
}
```
