# Text Shift Gradient

An animated gradient hue shifts continuously through the text.

## Features
- Flowing multi-hue gradient
- Rotating hue loop
- Full-bleed colour travel
- Pure CSS

## Usage
```html
<h2 class="tsg-title">Colour shift</h2>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
