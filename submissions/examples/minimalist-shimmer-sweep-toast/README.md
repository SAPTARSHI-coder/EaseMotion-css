# CSS Shimmer-Sweep Toast

A modern **CSS Shimmer-Sweep Toast** built entirely with **HTML5** and **CSS3**. This showcase demonstrates elegant toast notifications featuring a smooth shimmer-sweep hover animation, responsive layout, and accessibility-friendly markup—all without JavaScript.

---

## ✨ Features

- 🚀 Pure HTML5 & CSS3
- ✨ Shimmer-sweep hover animation
- ✅ Success toast variant
- ⚠️ Warning toast variant
- ℹ️ Information toast variant
- 💻 Minimalist tech-inspired design
- 📱 Fully responsive layout
- ♿ Accessible using `role="status"` and `aria-live="polite"`
- 🎨 Easy customization with CSS Custom Properties
- 🌙 Supports `prefers-reduced-motion`
- ⚙️ No JavaScript or external libraries

## 🚀 Usage

1. Open `demo.html` in a modern web browser.
2. Hover over any toast notification to view the shimmer-sweep animation.
3. Update the icons, colors, and messages to fit your project.
4. Customize the appearance using the CSS custom properties.

---

## 🎨 CSS Custom Properties

| Variable | Description |
|----------|-------------|
| `--bg` | Page background color |
| `--surface` | Toast background |
| `--success` | Success accent color |
| `--warning` | Warning accent color |
| `--info` | Information accent color |
| `--text` | Primary text color |
| `--muted` | Secondary text color |
| `--border` | Border color |
| `--radius` | Toast border radius |
| `--shadow` | Toast shadow |
| `--transition` | Transition timing |

Example:

```css
:root{
    --success:#16a34a;
    --warning:#f59e0b;
    --info:#2563eb;
}
```
