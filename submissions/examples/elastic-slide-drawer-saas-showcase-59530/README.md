# CSS Elastic-Slide Drawer

A modern, lightweight, pure CSS/HTML elastic-slide drawer showcase for SaaS applications.

## Features
- Pure CSS and HTML (No JS required)
- Smooth CSS transitions and keyframe animations for an elastic effect
- Fully responsive across desktop, tablet, and mobile viewports
- Accessible with `prefers-reduced-motion` support

## Usage
Simply include the `demo.html` structure and the corresponding `style.css` in your project.

### Custom Properties
You can easily customize the drawer using the following CSS custom properties defined in `style.css`:
- `--primary-color`: The primary theme color.
- `--bg-color`: The background color of the application.
- `--drawer-bg`: The background color of the drawer.
- `--text-color`: The primary text color.
- `--drawer-width`: The width of the drawer on desktop.
- `--animation-speed`: The base speed for transitions.
- `--elastic-timing`: The cubic-bezier timing function for the elastic effect.
