# Scale-Hover Drawer for E-Commerce Checkout

A lightweight CSS-only Scale-Hover Drawer designed for modern e-commerce checkout layouts.

The component provides an interactive order-summary drawer that subtly scales on hover or keyboard focus, creating a polished checkout experience without JavaScript.

## Features

- Pure HTML and CSS
- No JavaScript required
- Smooth scale-hover interaction
- Sticky order-summary drawer on desktop
- Responsive layout for desktop, tablet, and mobile
- CSS-only product summary
- Checkout and payment sections
- CSS custom properties for easy customization
- Keyboard-friendly focus states
- `prefers-reduced-motion` accessibility support
- Lightweight and dependency-free
