# Dark Mode Toggle Component

Add ease-dark-mode-toggle-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|---------|
| `--dmt-accent` | `#6366f1` |
| `--dmt-yellow` | `#f59e0b` |
| `--dmt-radius` | `50px` |
| `--dmt-shadow` | `0 4px 16px rgba(0,0,0,.3)` |

## Technique

Pure CSS toggle button. Tiny JS toggles `.on` class for state.
