# CSS Bounce-Pulse Progress Bar for Responsive Dashboard Layouts

A modern **Bounce-Pulse Progress Bar** component built using only **HTML5 and CSS3**.

This example provides animated dashboard progress indicators with bounce scaling, pulse glow effects, responsive cards, and accessibility support without JavaScript.

---

## ✨ Features

- 📊 Animated progress bars
- 🟢 Bounce scaling effect
- 💡 Pulse glow animation
- 🎨 Gradient progress indicators
- ⚡ Smooth CSS animations
- 📱 Responsive dashboard layout
- 🎯 CSS Custom Properties
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

## 🚀 Usage

1. Open `demo.html` in a modern browser.
2. View animated progress indicators.
3. Customize progress values and colors through CSS.
