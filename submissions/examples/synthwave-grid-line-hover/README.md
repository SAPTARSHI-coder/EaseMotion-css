# CSS Synthwave Grid Line Hover Effect

A retro-futuristic, pure CSS hover effect that creates a perspective-tilted 3D neon synthwave grid floor that scrolls and glows upon user interaction.

## 🎯 Features
- **Pure CSS/HTML:** Zero JavaScript dependencies.
- **Perspective Neon Grid:** Generates a 3D grid plane using `repeating-linear-gradient` and 3D transforms (`rotateX(65deg)`).
- **Infinite Grid Scrolling:** Smooth GPU-accelerated `background-position` keyframe animation.
- **Dark Mode Tuned:** Cyberpunk neon magenta (`#ec4899`) and cyan (`#06b6d4`) palette on deep violet backgrounds.
- **Accessible & Responsive:** Implements `:focus-visible` styling, `tabindex="0"`, and disables continuous grid scrolling under `@media (prefers-reduced-motion: reduce)`.
