# CSS Breathing Pulse Animation

A calm CSS-only breathing pulse animation designed for focus elements and interactive UI components.

The animation gently expands and fades circular rings around the central element, creating a soft breathing effect without JavaScript.

## Features

- Pure HTML and CSS
- No JavaScript
- Continuous breathing animation
- CSS keyframes
- Two staggered pulse rings
- Responsive layout
- Keyboard accessible button
- Visible focus state
- Reduced-motion support
- No external dependencies
