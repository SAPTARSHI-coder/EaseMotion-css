# Cyberpunk Neon Mesh Gradient

A futuristic CSS-only mesh gradient component inspired by cyberpunk interfaces, neon lighting, and digital cityscapes.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript
- No external dependencies
- Layered neon mesh gradients
- Cyan, pink, purple, and blue glow effects
- Animated gradient blobs
- Cyberpunk grid overlay
- Scanline effect
- Neon status indicator
- Glowing interactive buttons
- Responsive layout
- Dark and light color-scheme support
- Keyboard-accessible controls
- Reduced-motion support
