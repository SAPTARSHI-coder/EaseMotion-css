# CSS Slide-Up Navbar for Minimalist Tech Layouts

A modern, glassmorphic navbar with a smooth slide-up entry animation, designed for minimalist tech layouts.

## Usage

```html
<nav class="ease-slide-up-navbar">
  <div class="ease-logo">Brand</div>
  <ul class="ease-nav-links">
    <li class="ease-nav-item"><a href="#" class="ease-nav-link">Home</a></li>
    <li class="ease-nav-item"><a href="#" class="ease-nav-link">Features</a></li>
  </ul>
  <button class="ease-nav-btn">Get Started</button>
</nav>
```

## Features
- Pure CSS implementation with smooth `@keyframes` animations.
- Glassmorphic styling with `backdrop-filter`.
- Hover micro-animations on links and buttons.
- Responsive design for desktop, tablet, and mobile viewports.
- Fully respects `prefers-reduced-motion` settings.
