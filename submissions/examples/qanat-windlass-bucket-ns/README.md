# Qanat Windlass Bucket

## What does this do?
Renders a self-contained CSS-only `ease-qanat-windlass-bucket` demo: Qanat windlass bucket descent.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-qanat-windlass-bucket`. No build step or JavaScript is required for the effect.

```html
<section class="ease-qanat-windlass-bucket">
  <div class="ease-qanat-windlass-bucket__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
