# ☁️ Cotton Fluff – Cotton-Like Fluff Drifts Away

> A dreamy cotton fluff component where cotton-like fluff drifts away with 5 colors (White, Pink, Blue, Purple, Gold), wind control (0-100%), and soft particle effects.

---

## 📖 Description

The **Cotton Fluff** component creates a dreamy cotton fluff experience where cotton-like fluff drifts away with soft physics. Built with vanilla HTML, CSS, and JavaScript, it features 5 colors (White, Pink, Blue, Purple, Gold), wind control (0-100%), and soft particle effects for a calming, dreamy experience.

### 🎯 Core Features

- **Cotton fluff** – soft, cotton-like particles drift away
- **5 colors** – White, Pink, Blue, Purple, Gold
- **Wind control** – adjust wind from 0-100%
- **Soft particles** – fluff with fuzz and glow effects
- **Fluff counter** – tracks number of fluffs
- **Interactive controls** – slider, buttons, keyboard shortcuts
- **Responsive design** – adapts to different screen sizes

### ⌨️ Interaction Options

| Method | Action |
|--------|--------|
| **Click** | Click on display to release fluff |
| **Buttons** | Puff, Clear |
| **Keyboard** | `Space` or `P` – Puff · `C` – Clear |

### ✨ Cotton Experience

When interacting:
1. **Fluff releases** – cotton-like particles burst out
2. **Wind applies** – controls drift speed
3. **Color applies** – changes fluff color
4. **Fluffs drift** – soft, dreamy movement
5. **Status updates** – shows current state

### 🛠️ Technologies Used

- **HTML5** – semantic structure with Canvas
- **CSS3** – gradients, backdrop-filter, transforms
- **JavaScript (ES6)** – Canvas API, requestAnimationFrame, particle system

### 🎨 Design Philosophy

This component embodies **EaseMotion CSS's animation-first philosophy** through:

- **Soft motion** – fluff drifts with dreamy physics
- **Particle effects** – soft, glowing fluff with fuzz
- **Visual feedback** – status updates, counter, controls
- **Dreamy atmosphere** – soft colors and gentle motion
- **Human-readable classes** – `.cotton-controls`, `.color-btn`, `.cotton-text`

### 🔧 Customization Options

| Property | Location | Default |
|----------|----------|---------|
| Colors | `colorConfigs` object | 5 colors |
| Wind range | `windSlider` | 0-100% |
| Fluff count | `releaseFluff()` | 15-35 |
| Fluff size | `size` | 3-9px |
| Fuzz points | `fuzz` | 5-13 |
