# Parallax Badge with Material Design Styling

A responsive Material Design-inspired badge featuring layered elevation, subtle parallax-style motion, and tactile hover interactions using pure HTML and CSS.

## ✨ Features

- Material Design-inspired visual language
- Parallax-style hover interaction
- Layered depth using CSS transforms
- Elevation-inspired shadows
- Smooth hover transitions
- Interactive icon and arrow movement
- Responsive layout
- Keyboard focus support
- `prefers-reduced-motion` support
- Zero external JavaScript dependencies
- Reusable CSS design tokens
