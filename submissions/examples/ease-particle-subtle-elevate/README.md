# Subtle Elevate Particle Effect

A smooth, hardware-accelerated, pure CSS particle effect featuring a subtle, organic upward motion.

## Usage

Include the HTML structure in your project:

```html
<div class="ease-particle-container">
    <div class="ease-particle p1"></div>
    <div class="ease-particle p2"></div>
    <!-- Add as many particles as needed -->
</div>
```

Ensure the corresponding CSS styles are included for the animation and appearance.

## Why it's useful

It provides a lightweight, visually appealing background animation that supports dark mode and hardware acceleration, fitting perfectly with EaseMotion's focus on smooth, accessible design without the overhead of JavaScript. The SVG goo filter adds a more organic fluid-like interaction when particles cross paths.
