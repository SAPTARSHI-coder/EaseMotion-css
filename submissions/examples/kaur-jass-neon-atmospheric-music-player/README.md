# Neon Atmospheric Music Player (v40.5)

An atmospheric, cyberpunk-themed music player component featuring real-time audio visualizers, spinning vinyl disc animations, progress scrubbing, and volume controls.

## 🌟 Features

- **Cyberpunk Neon Aesthetics**: Ambient background glows with glowing glassmorphism card styling.
- **Dynamic Audio Visualizer**: Animated equalizer bars synchronized with play/pause playback states.
- **Spinning Vinyl Animation**: Smooth CSS keyframe rotation during active audio play.
- **Mobile Responsive**: Fully adaptive layout for smooth playback on mobile, tablet, and desktop devices.
