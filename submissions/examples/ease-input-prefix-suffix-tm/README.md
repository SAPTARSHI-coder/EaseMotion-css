# Input Prefix Suffix Component

Add ease-input-prefix-suffix-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|--------|
| `--ip-accent` | `#6366f1` |
| `--ip-radius` | `8px` |
| `--ip-shadow` | `0 4px 16px rgba(0,0,0,.3)` |

## Technique

Flexbox layout with prefix/suffix spans. Border radius split between elements creates the seamless look.
