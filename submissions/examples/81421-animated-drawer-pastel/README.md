# Animated Drawer with Pastel Styling

## Overview

A responsive animated drawer component created with pure HTML and CSS.

This component provides a soft pastel visual style with smooth drawer
transitions, interactive navigation states, and responsive behavior across
different screen sizes.

## Features

- Pure HTML and CSS implementation
- No external JavaScript dependencies
- Soft pastel visual design
- Smooth drawer open and close animation
- Interactive navigation links
- Responsive layout for mobile, tablet, and desktop
- Accessible focus-visible states
- `prefers-reduced-motion` support
- Semantic navigation structure
- CSS custom properties for reusable design tokens
