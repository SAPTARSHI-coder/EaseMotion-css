# CSS Zoom-In Tabs for SaaS Showcase

A modern SaaS showcase component featuring animated zoom-in tabs using only
HTML and CSS.

This example is created for EaseMotion CSS and requires no JavaScript or
external framework.

## Features

- Pure HTML and CSS
- Interactive CSS-only tabs
- Smooth zoom-in panel animation
- Responsive desktop, tablet and mobile layouts
- CSS custom properties
- Keyboard focus support
- Accessible focus states
- `prefers-reduced-motion` support
- Lightweight implementation
- No JavaScript dependencies
- SaaS-focused showcase design
