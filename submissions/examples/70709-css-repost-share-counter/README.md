# CSS Repost/Share Counter

A CSS-only social action component with a repost count and a flying icon feedback animation.

## Features

- Native button interaction
- Flying repost icon
- Responsive social card
- Visible keyboard focus
- Reduced-motion support
- No JavaScript or external dependencies

## Files

- `demo.html` — semantic post and action markup
- `style.css` — action styling, animation, responsive rules, and accessibility states

## Accessibility

The action is a native button with an accessible label and visible focus ring. Decorative animation is suppressed for reduced-motion users.
