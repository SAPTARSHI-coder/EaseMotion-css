# Pulsating Wave Dashboard Widget

A smooth, accessible, and performant dashboard widget featuring a
**Pulsating Wave** visual style using pure HTML and Vanilla CSS.

## Features

- 🌊 Pulsating wave visualization
- 💫 Animated pulse rings
- 📊 Real-time activity display
- 📈 Animated system metrics
- ⚡ CSS-only animations
- 🌙 Dark-mode compatible
- 📱 Responsive layout
- ♿ Reduced-motion support
- 🎨 Neon-inspired visual hierarchy
- 🚫 No JavaScript
- 🚫 No external dependencies
