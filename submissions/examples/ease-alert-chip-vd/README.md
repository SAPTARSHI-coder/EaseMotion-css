# Ease Alert Chip

## What does this do?

A compact alert chip for displaying warnings, notices, information, success messages, and errors.

---

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<div class="alert-chip warning">
    <span class="alert-icon">!</span>
    <span>Warning</span>
</div>
```

### Available variants

```html
<div class="alert-chip info">
    <span class="alert-icon">i</span>
    <span>Information</span>
</div>

<div class="alert-chip warning">
    <span class="alert-icon">!</span>
    <span>Warning</span>
</div>

<div class="alert-chip success">
    <span class="alert-icon">✓</span>
    <span>Success</span>
</div>

<div class="alert-chip danger">
    <span class="alert-icon">×</span>
    <span>Error</span>
</div>
```

### Features

- Icon support
- Alert text
- Multiple color variants
- Hover animation
- Responsive layout
- Lightweight and reusable

---

## Why is it useful?

Alert chips are commonly used for warnings, notices, success messages, errors, and notifications.

This component provides a compact and reusable alert pattern with subtle interaction feedback while following the animation-first philosophy of EaseMotion CSS.
