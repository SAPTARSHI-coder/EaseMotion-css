# Morphing Avatar

Showcase for issue #78681.

## Files

- `demo.html` — profile and avatar markup.
- `style.css` — morphing shape, spacing, interaction, and motion rules.

## Features

- Responsive avatar sizing.
- Shape morph on interaction.
- Keyboard focus state.
- Reduced-motion fallback.
- No JavaScript dependency.

Open `demo.html` to view the component.
