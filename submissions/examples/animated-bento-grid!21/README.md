# Animated Bento Grid Feature Showcase

A modern, responsive "Bento Box" style feature grid built with **EaseMotion CSS**. Inspired by Apple and modern SaaS landing pages, this layout uses staggered animations and subtle hover effects to create a premium, interactive showcase.

## ✨ Features

- **Trendy Bento Layout**: Complex CSS Grid layout that elegantly collapses into a single column on mobile devices.
- **Staggered Entrances**: Cards fade in sequentially using `.ease-fade-in` and `.ease-delay-*` classes.
- **Interactive Hover**: Cards smoothly scale up on hover using `.ease-hover-scale`, providing tactile feedback.
- **Ambient Animations**: Includes a floating gradient blur (`.ease-float`) and pulsing indicator dots (`.ease-pulse`) to bring the static layout to life.
- **Zero JavaScript**: 100% pure CSS layout and animations.
