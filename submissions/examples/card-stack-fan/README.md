# Card Stack Fan

A deck of cards fans out like playing cards on hover.

## Features
- Rotational fan spread
- Rise on hover
- Card back pattern
- Pure CSS

## Usage
```html
<div class="csf-card" style="--i:0">A</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
