# Timeline event marker

A vertical activity timeline whose node circles expand with a glow when a new event arrives.

## How to view

Open `demo.html` in any modern browser. The demo is fully self-contained — no CDN, no framework, no JavaScript.

## How to use

Copy `style.css` into your project's stylesheet. Every class used in the demo is namespaced with `timelineeventmarkernode-` to avoid collisions.

## Why this is useful for EaseMotion CSS

Activity log / changelog pattern; the node expansion draws the eye to the new event.
