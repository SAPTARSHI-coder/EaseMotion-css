# Elastic-Slide Toast Product Catalog

A lightweight product catalog showcase featuring an Elastic-Slide Toast
interaction built entirely with HTML and CSS.

No JavaScript or external frameworks are required.

## Features

- Pure HTML and CSS
- Elastic-slide toast animation
- CSS transitions and keyframe animations
- Spring-like elastic easing
- Responsive product catalog
- Desktop, tablet, and mobile layouts
- Keyboard-accessible interaction
- Visible focus states
- CSS custom properties
- `prefers-reduced-motion` support
- No external dependencies
