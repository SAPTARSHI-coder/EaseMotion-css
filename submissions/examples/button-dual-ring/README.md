# Button Dual Ring

Two rings orbit a circular button pulsing outward.

## Features
- Orbiting rings
- Pulsing core
- Circular icon button
- Pure CSS

## Usage
```html
<button class="bdr-btn">&#9654;</button>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
