# Ease Greenhouse Vent Louver

A CSS-only animated greenhouse roof ventilation system.

The component represents automated greenhouse louvers opening and closing to release excess heat.

## Features

- Pure HTML and CSS
- No JavaScript dependency
- Real-world greenhouse UI
- Animated roof louvers
- Temperature indicator
- Plant movement effect
- Responsive layout
- Reduced motion support
