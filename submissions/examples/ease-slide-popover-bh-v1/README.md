# ease-slide-popover-bh

Pure CSS slide-up popover for fintech dashboards.

## Features
- Slide-up hover effect
- Popover variants
- Responsive design
- Accessibility support

## Usage
```html
<div class="ease-popover ease-popover-slide">Content</div>
```

## CSS Classes
- `.ease-popover` - Base popover
- `.ease-popover-slide` - Slide-up effect
