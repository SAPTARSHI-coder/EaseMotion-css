# CSS 3D Effect: Minimalist Outline Variation

## Overview

A smooth and lightweight 3D Minimalist Outline effect created using
pure HTML and vanilla CSS.

The component uses CSS perspective, 3D transforms, layered outlines,
glassmorphism, and hover transitions to create a subtle depth effect.

## Features

- Pure HTML and CSS
- No JavaScript required
- CSS 3D perspective effect
- Minimalist outline styling
- Smooth hover interaction
- Dark mode support
- Hardware-friendly transforms
- Accessible focus state
- `prefers-reduced-motion` support
- Responsive layout

## Technologies

- HTML5
- CSS3
- CSS Transforms
- CSS Perspective
- CSS Backdrop Filter
- CSS Media Queries

## Usage

Open `demo.html` in a modern web browser.

Hover over the card to see the 3D perspective and layered outline
animation.

## Accessibility

The effect respects the user's reduced-motion preference through
`prefers-reduced-motion`.

Interactive elements also include visible keyboard focus styles.
