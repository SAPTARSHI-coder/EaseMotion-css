# CSS Feature List with Icons

A responsive feature checklist with animated icons built using pure HTML and CSS.

## Preview

The component displays a list of features with:

- Animated circular icons
- Checkmark entrance animation
- Continuous icon pulse
- Hover elevation effect
- Responsive layout
- Light and dark mode support
- Reduced-motion support
