# CSS Skew-Active Hero Section for SaaS Showcase Layouts

A modern **Skew-Active Hero Section** built using **pure HTML5 and CSS3** for EaseMotion CSS.

This component features elegant skew animations, glassmorphism effects, animated dashboard cards, gradient CTA buttons, floating statistics, responsive layouts, and accessibility-friendly motion preferences without requiring JavaScript.

---

## Features

- 🎯 Pure HTML5 & CSS3
- ⚡ Smooth skew hover animations
- 🚀 Floating SaaS dashboard card
- 💎 Glassmorphism UI
- 🌈 Gradient CTA buttons
- 📊 Animated analytics cards
- 📱 Fully responsive design
- ♿ Supports `prefers-reduced-motion`
- 🎨 Easy customization using CSS variables
- ❌ No JavaScript required

## CSS Custom Properties

```css
:root{
  --bg:#eef4ff;
  --surface:#ffffff;
  --primary:#5b5df0;
  --secondary:#7c5cff;
  --accent:#00d4ff;
  --text:#1b2235;
  --muted:#6b7890;
  --radius:24px;
  --shadow:0 20px 60px rgba(40,55,120,.15);
  --transition:.4s ease;
}
```

These variables allow quick customization of colors, shadows, spacing, and animation speed.
