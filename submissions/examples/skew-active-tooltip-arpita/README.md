# Skew Active Tooltip
A modern CSS-only skew-active tooltip component designed for creative portfolio layouts. The tooltip appears with a smooth skew animation, glassmorphism styling, gradient glow, and responsive interactions.

## Features
- 🎨 Modern glassmorphism design
- ⚡ Smooth skew tooltip animation
- ✨ Animated gradient glow
- 💎 Card hover effects
- 📱 Fully responsive
- ♿ Supports `prefers-reduced-motion`
- 🚫 No JavaScript required
- 🌐 Pure HTML & CSS

## Folder Structure

```
skew-active-tooltip-arpita/
│── demo.html

```

## How to Use
1. Open `demo.html` in any modern web browser.
2. Hover over the portfolio cards.
3. Watch the tooltip animate into view with a skew transition.
