# Floating Input Field

SaaS-style responsive floating-label input showcase for issue #78589.

## Files

- `demo.html` — accessible form markup.
- `style.css` — floating label, focus states, and responsive layout.

## Features

- Label remains associated with the input.
- Floating label activates on focus and entered values.
- Clear validation and focus treatment.
- Responsive card spacing.
- Reduced-motion support.

Open `demo.html` directly to preview the component.
