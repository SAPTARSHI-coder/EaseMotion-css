# Skeleton Loading Wave Component

Add ease-skeleton-loading-wave-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|--------|
| `--sk-base` | `#e2e8f0` |
| `--sk-highlight` | `#f1f5f9` |
| `--sk-radius` | `6px` |
| `--sk-speed` | `1.5s` |

## Technique

Gradient `background-position` animation creates the left-to-right shimmer sweep on skeleton shapes. Staggered `animation-delay` on lines for natural wave effect.
