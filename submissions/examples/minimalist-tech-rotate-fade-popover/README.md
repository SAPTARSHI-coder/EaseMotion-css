# CSS Rotate-Fade Popover

A lightweight, responsive popover component for minimalist tech interfaces using pure HTML and CSS.

## Features

- Smooth rotate-and-fade entrance animation
- Subtle scale transition for polished motion
- Pure HTML and CSS implementation
- No JavaScript or external libraries required
- Responsive across desktop, tablet, and mobile
- Keyboard focus support
- Customizable CSS custom properties
- `prefers-reduced-motion` support for accessibility
- Minimal technology-inspired visual design
