# Holographic Flicker Drawer

A futuristic **Holographic Flicker Drawer** built with pure HTML and
Vanilla CSS for the EaseMotion CSS component collection.

Implemented for **Issue #73585**.

## ✨ Features

- Holographic drawer styling
- Chromatic cyan, pink, and violet gradients
- Flicker-based drawer reveal
- Animated scanlines
- Holographic glow effects
- Sequential navigation animation
- Pure HTML and Vanilla CSS
- No JavaScript required
- Dark-mode friendly
- Responsive layout
- Hardware-friendly transforms
- `prefers-reduced-motion` support
- Semantic navigation structure

## 🎨 Style

**Category:** Drawers & Sidebars

**Style:** Holographic Flicker

The drawer uses layered gradients, scanlines, chromatic highlights,
and flicker animations to create a futuristic holographic interface.
