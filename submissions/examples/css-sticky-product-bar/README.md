# CSS Sticky Product Bar

A responsive sticky product information bar built entirely with CSS. The component remains visible while scrolling, keeping key product details and call-to-action buttons accessible.

## Features

- Pure CSS implementation
- Sticky positioning
- Responsive layout
- Light and dark mode support
- CSS custom properties for easy theming
- Accessible focus states
- Smooth entry animation
- No JavaScript required

## Usage

```html
<div class="sticky-product-bar">
  <div class="product-info">
    <h3>Wireless Headphones</h3>
    <span>$149.99</span>
  </div>

  <button class="buy-btn">
    Buy Now
  </button>
</div>
```

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

## Why it fits EaseMotion CSS

This component provides a practical e-commerce UI pattern that combines accessibility, responsiveness, and subtle animation while remaining lightweight and fully CSS-based.
