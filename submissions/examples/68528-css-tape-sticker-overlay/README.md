# CSS Tape/Sticker Overlay

## Overview

A decorative component demonstrating paper notes, image cards, adhesive tape, and sticker accents using only CSS.

## Features

- Tape overlays with rotation
- Sticker badge accent
- Paper-card shadows
- Hover lift animation
- Responsive two-column to one-column layout
- Native keyboard focus states
- Reduced-motion support
- No external assets or JavaScript

## Files

- `demo.html` — sample notes and image card
- `style.css` — paper styling, tape layers, sticker shapes, motion, and responsive rules
- `README.md` — documentation

## Usage

Open `demo.html` directly in a modern browser.

## Accessibility

The examples use headings, paragraphs, and native buttons. Buttons expose visible focus styling, while decorative tape and sticker elements remain non-interactive.
