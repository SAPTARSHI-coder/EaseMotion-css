# Wave Text Animation

A dependency-free CSS text animation where each letter gently moves like a sea wave.

## Usage

Add the `wave-text` class to a heading and wrap each character in a `<span>`:

```html
<h1 class="wave-text" aria-label="Wave Text">
  <span aria-hidden="true">W</span>
  <span aria-hidden="true">a</span>
  <span aria-hidden="true">v</span>
  <span aria-hidden="true">e</span>
  <span aria-hidden="true">&nbsp;</span>
  <span aria-hidden="true">T</span>
  <span aria-hidden="true">e</span>
  <span aria-hidden="true">x</span>
  <span aria-hidden="true">t</span>
</h1>
