# Combination Fence Drop

## What does this do?
Renders a self-contained CSS-only `ease-combination-fence-drop` demo: Combination fence dropping into the gates.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-combination-fence-drop`. No build step or JavaScript is required for the effect.

```html
<section class="ease-combination-fence-drop">
  <div class="ease-combination-fence-drop__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
