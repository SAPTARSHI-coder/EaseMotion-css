# Particle Burst Drawer

A vibrant **Particle Burst Drawer** built using only HTML and CSS.

## Features

- Pure HTML & CSS
- Animated particle burst background
- Smooth slide-in drawer
- Responsive layout
- Accessible checkbox toggle
- Hardware-accelerated animations
- Dark mode compatible
- No JavaScript required
