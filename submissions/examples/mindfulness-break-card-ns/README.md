# CSS Mindfulness Break Card (#71036)

A pure CSS mindfulness reminder card component featuring a synchronized visual breathing cycle animation to guide user relaxation breaks without JavaScript dependencies.

## Features
- Pure CSS keyframe animations simulating realistic Inhale/Exhale pace (`ease-breath-expand` and `ease-breath-core-pulse`).
- Dynamic text updates ("Inhale..." / "Exhale...") driven entirely via CSS content generation keyframes.
- Radial gradient pulse rings with glowing teal/cyan theme options.
- Clean BEM structure (`ease-mindfulness-card`, `ease-breathing-container`).
- Accessible keyboard navigation and fallback static states for users who prefer reduced motion (`prefers-reduced-motion`).
