# Form Step Bubbles

A multi-step form progress made of bubbles that fill and hop forward.

## Features
- Bubble hop on focus
- Filling connector line
- Numbered steps
- Pure CSS

## Usage
```html
<div class="fsb-bubble"><span>1</span><small>Details</small></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
