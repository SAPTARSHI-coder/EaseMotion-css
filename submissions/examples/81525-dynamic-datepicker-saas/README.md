# Dynamic Datepicker with SaaS Modern Styling

A clean and responsive SaaS-style datepicker component built with
semantic HTML and pure CSS for EaseMotion CSS.

## Features

- Pure HTML and CSS
- Zero external JavaScript dependencies
- Native HTML date input
- Modern SaaS dashboard styling
- Clean card-based layout
- Subtle purple primary accent
- Smooth hover and focus animations
- Quick-selection UI
- Responsive design
- Keyboard accessible
- Native browser validation
- `prefers-reduced-motion` support
