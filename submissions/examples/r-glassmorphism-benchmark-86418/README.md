# Scroll Animation FPS Benchmark

A reproducible Headless Chrome Puppeteer benchmark for measuring the performance of scroll-driven animations.

## Features

- Headless Chrome FPS measurement
- Puppeteer-based benchmark runner
- Scroll-driven CSS animations
- `requestAnimationFrame()` FPS measurement
- Bundle size measurement
- Execution time measurement
- Configurable performance budgets
- CI-compatible exit status
- Reduced-motion accessibility support
- No external UI libraries
