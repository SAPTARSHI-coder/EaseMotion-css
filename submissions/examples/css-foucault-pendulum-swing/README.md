# Foucault Pendulum Swing Background

A smooth and atmospheric Foucault Pendulum Swing background animation created using pure HTML and Vanilla CSS.

## Features

- Pure HTML and CSS
- No JavaScript
- Smooth pendulum swinging animation
- Atmospheric background glow
- Subtle grid texture
- Responsive design
- Dark-mode compatible
- Hardware-friendly CSS transforms
- Reduced-motion accessibility support
- Lightweight and dependency-free
