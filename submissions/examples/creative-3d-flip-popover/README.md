# CSS 3D-Flip Popover for Accessible Web Layouts

A modern **3D-Flip Popover** component built completely with **HTML5 and CSS3**. This showcase demonstrates interactive popovers with smooth 3D flip animations, glassmorphism styling, gradient effects, responsive layouts, and accessibility support without requiring JavaScript.

---

## ✨ Features

- 🔄 Smooth 3D flip animation
- 💎 Glassmorphism popover design
- 🌈 Gradient trigger buttons
- ✨ Glow effects
- 🎯 CSS Custom Properties
- ⚡ Smooth CSS transitions
- 📱 Fully responsive layout
- 🧩 Pure HTML5 & CSS3
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

## 🚀 Getting Started

1. Open `demo.html` in any modern browser.
2. Hover over the cards to trigger the 3D flip popover.
3. Customize colors, spacing, and animation timing using CSS variables.
