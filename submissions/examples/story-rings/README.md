# Story Rings

Social story avatars wrapped in a rotating gradient ring with an active pulse.

## Features
- Gradient ring cycles with a conic-gradient sweep
- Hover ring brightens and the avatar lifts
- Seen-state ring fades for extra realism

## Usage
```html
<div class="sr-ring"><div class="sr-avatar">JD</div></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
