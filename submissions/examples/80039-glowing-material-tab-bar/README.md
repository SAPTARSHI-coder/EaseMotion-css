# Glowing Material Design Tab Bar

A minimal and responsive tab bar inspired by Material Design,
enhanced with subtle glowing accents and modern dark surfaces.

## Features

- Responsive Material-inspired tab bar
- Minimal visual design
- Glowing active indicator
- Smooth hover effects
- Elevated surface styling
- Keyboard-visible focus state
- Mobile horizontal scrolling
- Reduced-motion accessibility support
- Pure HTML and CSS
- No JavaScript required

## Files

- `demo.html` — component markup and demonstration
- `style.css` — component styling and responsive behavior

## Usage

Add the stylesheet to your page:

```html
<link rel="stylesheet" href="style.css">
