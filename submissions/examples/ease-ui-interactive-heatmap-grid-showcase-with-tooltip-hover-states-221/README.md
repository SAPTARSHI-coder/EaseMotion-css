# Interactive Heatmap Grid Showcase with Tooltip Hover States

## Overview

A minimalist clean heatmap grid component with interactive tooltip
states, smooth hover animations, and data intensity visualization.

## Features

- 📊 Interactive heatmap visualization
- 💬 Tooltip hover states
- ✨ Smooth elevation animation
- 🎨 Minimal clean UI design
- 📱 Responsive grid layout
- ⚡ Pure HTML, CSS and JavaScript
- ♿ Reduced motion support

## Usage

Open `demo.html` directly in a browser.

Customize:
- Heatmap values inside `demo.html`
- Colors inside `style.css`
- Tooltip content using data attributes
