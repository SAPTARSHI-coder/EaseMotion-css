# CSS Scale Hover Popover Gaming Hub

A pure HTML and CSS showcase example featuring a modern gaming hub layout with interactive scale-hover cards and animated popovers.

## ✨ Features

- Pure HTML5 and CSS3 implementation
- No JavaScript or external frameworks required
- Smooth CSS scale hover animations
- Animated popover information panels
- Responsive gaming card grid layout
- Mobile-friendly design
- Accessible focus interactions
- Supports `prefers-reduced-motion`
