# Glass Bento Grid

## What does this do?

Creates a modern glassmorphism-inspired Bento Grid layout featuring responsive dashboard cards, colorful gradients, and smooth hover interactions.

---

## How is it used?

Open `demo.html` directly in any modern browser.

```html
<div class="bento-grid">

    <div class="card hero">
        ...
    </div>

    <div class="card stats">
        ...
    </div>

</div>
```

---

## Why is it useful?

Bento Grid layouts are widely used in AI applications, SaaS platforms, dashboards, product landing pages, and developer portfolios. This standalone example demonstrates how responsive CSS Grid and glassmorphism effects can be combined to build visually engaging interfaces using only HTML and CSS.
