# ease-blur-badge-bh

Pure CSS blur-entrance badge for fintech dashboards.

## Features
- Blur entrance animation
- Badge variants
- Responsive design
- Accessibility support

## Usage
```html
<span class="ease-badge ease-badge-blur">New</span>
```

## CSS Classes
- `.ease-badge` - Base badge
- `.ease-badge-blur` - Blur entrance effect
