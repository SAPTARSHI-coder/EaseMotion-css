# ease-blur-badge Blur-Entrance Badge

## What does this do?

A badge component with blur-entrance animation effects, perfect for fintech dashboard layouts. Features a smooth blur-to-sharp transition when elements enter the viewport.

## How is it used?

```html
<span class="ease-blur-badge">New</span>
<div class="ease-blur-badge">Featured</div>
```

### CSS Classes

| Class | Purpose |
|-------|---------|
| `.ease-blur-badge` | Base badge with blur entrance animation |
| `.ease-blur-badge-sm` | Small badge variant |
| `.ease-blur-badge-lg` | Large badge variant |
| `.ease-blur-badge-primary` | Primary color variant |
| `.ease-blur-badge-success` | Success/green variant |
| `.ease-blur-badge-warning` | Warning/amber variant |
| `.ease-blur-badge-error` | Error/red variant |

## Why is it useful?

Creates an elegant blur-entrance animation effect:

- ✅ Smooth blur-to-sharp CSS animation
- ✅ Multiple size variants
- ✅ Multiple color variants
- ✅ Accessible with prefers-reduced-motion
- ✅ Perfect for fintech dashboard badges
