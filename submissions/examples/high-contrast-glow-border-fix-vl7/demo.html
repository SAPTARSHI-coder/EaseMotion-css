Card Glow Effects & Active Outline High Contrast Mode Fix

Demonstrates transparent outline fallbacks and forced-colors: active media query support for glowing cards, cards with pulse animations, and interactive buttons when OS high-contrast themes strip box-shadow effects.

How to Verify Windows High Contrast Mode in Browser DevTools:

  1. Open Chrome or Microsoft Edge DevTools (Press F12 or Ctrl+Shift+I).
  2. Open the Command Menu (Press Ctrl+Shift+P).
  3. Type Rendering and select Show Rendering.
  4. Scroll down to Emulate CSS media feature forced-colors and set it to forced-colors: active.
  5. Observe that animated glowing cards preserve clearly defined 2px borders and active focus rings despite box-shadow removal.
