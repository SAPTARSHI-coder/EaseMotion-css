# ease-shimmer-popover-bh

Pure CSS shimmer-sweep popover for fintech dashboards.

## Features
- Shimmer sweep hover effect
- Popover variants
- Responsive design
- Accessibility support

## Usage
```html
<div class="ease-popover ease-popover-shimmer">Content</div>
```

## CSS Classes
- `.ease-popover` - Base popover
- `.ease-popover-shimmer` - Shimmer sweep effect
