# CSS Sound Level Meter

A pure CSS Sound Level Meter (VU Meter) component that simulates audio levels using animated vertical bars and a peak indicator.

## Features

- Pure CSS implementation
- Animated VU meter effect
- Peak indicator animation
- Responsive design
- No JavaScript required
- Accessible and lightweight

## Usage

```html
<div class="sound-meter">
  <div class="meter-bar"></div>
  <div class="meter-bar"></div>
  <div class="meter-bar"></div>
  <div class="meter-bar"></div>
  <div class="meter-bar"></div>
  <div class="meter-bar"></div>
  <div class="meter-bar"></div>
  <div class="meter-bar"></div>
  <div class="peak-indicator"></div>
</div>
