# Animated Accordion - Dark Mode

A modern responsive FAQ accordion built with semantic HTML and pure CSS, featuring a polished dark-mode interface and smooth animations.

## ✨ Features

- Pure HTML and CSS
- No JavaScript dependency
- Native `<details>` and `<summary>` interaction
- Modern dark-mode design
- Smooth accordion expansion
- Animated plus/minus indicator
- Numbered FAQ items
- Hover and focus states
- Responsive on desktop, tablet, and mobile
- CSS custom properties for easy customization
- Reduced-motion accessibility support
- No external dependencies
