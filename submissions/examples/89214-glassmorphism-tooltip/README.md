# Glassmorphism Tooltip Component

A floating, translucent hover tooltip component with smooth CSS translation and opacity keyframes.

## Features
- **Glassmorphism Backdrop:** Employs CSS `backdrop-filter` blur for frosted glass aesthetics.
- **Micro-Interaction:** Smooth slide-up and fade-in transition on parent element hover.
- **Pure CSS:** Zero JavaScript required.

## File Structure
- `demo.html` - Minimal button + tooltip markup wrapper.
- `style.css` - Component positioning, backdrop filters, and hover animations.
