# CSS Watercolor Wash Background

A soft, organic watercolor wash background created entirely with HTML and CSS.

## Features

- Pure CSS implementation
- No JavaScript required
- Animated watercolor washes
- Multiple overlapping color layers
- Soft blurred edges
- Organic movement
- Responsive design
- Glass-style content panel
- Accessible content structure
- Reduced-motion support
- No external libraries

## Demo

Open `demo.html` in a modern web browser.

The page demonstrates animated watercolor washes moving slowly behind the content.
