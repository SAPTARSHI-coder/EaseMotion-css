Performance Breakdown Details

Compositor-Only

GPU Transforms

Animating elements via transform (such as translateX, scale, or rotate) allows the browser to bypass both the Layout and Paint stages completely.

The element is promoted to its own compositor layer. The GPU handles the coordinates modification directly, freeing up the main thread and resulting in smooth 60 FPS animations.

Paint Triggered

Coordinate Positioning

Animating coordinate offsets like left, right, top, or bottom on positioned elements bypasses the Layout stage, but still triggers a Paint.

On every frame of the animation, the browser must redraw the visual pixels of the moving element and its overlapping elements. This runs on the CPU main thread and can lead to lag (jank) under load.

Reflow Triggered

Box Model Properties

Animating physical dimensions or margin metrics (like margin-left, width, or padding) forces the browser through the full Critical Rendering Path.

The layout engine (Reflow) must run on every frame to recalculate the exact geometry of this element and all surrounding layout elements, followed by a full repaint of the changed sections. This is extremely heavy.
