# Vertical Accordion Timeline Showcase

A responsive **Vertical Accordion Timeline** featuring CSS `grid-template-rows` smooth height transitions and glowing milestone markers.

## 🌟 Key Features

- **CSS Grid Height Transition**: Animates accordion collapse/expansion without fixed height hardcoding.
- **Glowing Milestone Markers**: Active milestone node highlights with blue neon halo.
- **Accessible Interactions**: Clickable milestone header cards to switch expanded timeline items.

## 🚀 Usage

Open `demo.html` in your browser.
