# CSS Fade-In Accordion for Product Catalog Layouts

A lightweight, responsive **Fade-In Accordion** built entirely with
HTML and CSS for modern product catalog interfaces.

The component uses CSS transitions, keyframe animations, and a
CSS-only checkbox interaction to reveal product details with a
smooth fade-in effect.

## Features

- Pure HTML and CSS
- No JavaScript required
- Smooth fade-in accordion animation
- CSS-only expand and collapse interaction
- Product-focused catalog layout
- Responsive across desktop, tablet, and mobile
- CSS custom properties for easy customization
- Keyboard-friendly focus states
- `prefers-reduced-motion` accessibility support
- Lightweight and reusable
- Works by opening `demo.html` directly in a browser
