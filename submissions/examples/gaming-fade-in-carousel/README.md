# CSS Fade-In Carousel for Gaming Hub Layouts

A modern **Gaming Hub Carousel** featuring smooth **Fade-In** slide transitions built entirely with **HTML5 and CSS3**. The component highlights featured games, tournaments, and rewards using lightweight CSS animations without requiring JavaScript.

---

## Features

- 🎮 Gaming Hub inspired carousel
- ✨ Smooth Fade-In slide transitions
- ⚡ Pure HTML5 & CSS3 (No JavaScript)
- 📱 Fully responsive layout
- 🎨 CSS Custom Properties
- ♿ `prefers-reduced-motion` support
- 🚀 Lightweight and easy to customize

## Usage

1. Open `demo.html` in any modern browser.
2. The carousel automatically cycles through featured gaming slides.
3. Customize colors, timing, and animations using CSS variables.
