# Interactive Audio Player Showcase

A premium, fully responsive, glassmorphic media player widget showcasing custom animations for CD rotation, glowing control states, and smooth progress tracking.

## Features
- Glassmorphic card design using `backdrop-filter: blur(12px)`.
- Interactive CSS-only rotate animation for active cover art.
- Glowing micro-interactions on player control states.
- Responsive layout supporting all viewports.
