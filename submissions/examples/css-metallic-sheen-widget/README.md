# CSS Widget: Metallic Sheen Variation

A polished, reusable dashboard widget featuring a hardware-accelerated metallic sheen interaction, built entirely with HTML and Vanilla CSS (no JavaScript required).

## Features

- **Metallic Sheen Animation**: Hovering or focusing the widget triggers a smooth light reflection sweeping across the surface, simulating polished metal.
- **Pure CSS**: Implemented entirely without JavaScript using `::before` pseudo-elements and optimized CSS transitions.
- **Hardware-Accelerated**: Animations exclusively utilize compositor-friendly properties (`transform: translateX()`) avoiding any layout thrashing.
- **Dark Mode Support**: Deep integration with `@media (prefers-color-scheme: dark)`, replacing bright backgrounds with realistic brushed-metal dark gradients and tuned reflection opacities.
- **Semantic Accessibility**: The widget utilizes `<article>` and `<header>` tags, wraps inside a navigable anchor `<a>`, and explicitly defines `:focus-visible` boundaries for keyboard users.
- **Reduced Motion Support**: Implements `@media (prefers-reduced-motion: reduce)` to gracefully disable the sweeping transform animation, providing a static, elegant glow fallback.
- **Responsive Architecture**: Built on CSS Grid, seamlessly collapsing from wide dashboard displays into stacked mobile layouts.

## Implementation Details

### HTML Structure
The component wraps realistic dashboard data metrics inside an `<article>`. To ensure keyboard accessibility and interactive affordance, the entire widget is wrapped in an anchor tag (`<a>`) simulating a clickable dashboard card.

### Metallic Sheen Mechanics
The sheen is generated by applying a complex `linear-gradient()` to the `::before` pseudo-element of the `.metallic-widget`. 
This gradient features sharp transitions from transparent base colors to semi-opaque white edges, creating the illusion of a harsh reflection line.

```css
background: linear-gradient(
  var(--sheen-angle),
  var(--sheen-color-base) 0%,
  var(--sheen-color-base) 40%,
  var(--sheen-color-edge) 45%,
  var(--sheen-color-mid) 50%,
  var(--sheen-color-edge) 55%,
  var(--sheen-color-base) 60%,
  var(--sheen-color-base) 100%
);
```

### Performance Constraints
To guarantee 60fps on low-end devices:
1. The sheen pseudo-element is statically positioned far to the left (`left: -150%`).
2. On `:hover` or `:focus-visible`, a `transform: translateX(250%)` is applied over a `1.2s` cubic-bezier transition.
3. The parent widget employs `overflow: hidden` to clip the sweeping pseudo-element perfectly to the border-radius bounds.
4. The sheen utilizes `pointer-events: none` to prevent it from blocking mouse clicks on underlying metrics.

### Theme Adaptation
CSS Custom Properties (variables) are heavily utilized. The root defines the light mode aesthetic (matte white cards with silver reflections), while the dark mode media query overrides the root variables to generate a dark graphite surface with subtle, sharp light catches typical of dark metallic interfaces.

## Usage

1. Open `demo.html` in any modern web browser.
2. Hover over the "System Reliability" or "Data Throughput" widgets.
3. Switch your operating system to Dark Mode to observe the adaptive aesthetic switch.
4. Try using the `Tab` key to navigate, verifying the sheen triggers on `:focus-visible`.
