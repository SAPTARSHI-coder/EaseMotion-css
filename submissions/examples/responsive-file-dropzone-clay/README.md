# Responsive File Dropzone — Claymorphism

A responsive file upload dropzone featuring a soft claymorphism
visual style, built entirely with HTML and CSS.

## Features

- Pure HTML and CSS
- Zero external JavaScript dependencies
- Responsive desktop, tablet, and mobile layouts
- Claymorphism-inspired raised and inset shadows
- Dashed upload area
- Native keyboard-accessible file input
- Smooth hover and active interactions
- Animated upload icon
- CSS custom properties/design tokens
- `prefers-reduced-motion` support
- No external dependencies
