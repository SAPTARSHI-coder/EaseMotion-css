Text Rendering Jitter Fix

Solving the infamous sub-pixel font wobbling and weight-shifting bug that occurs when animating elements containing text via CSS transforms.

Hover this button. Watch the text closely as the button scales up and down. The text shifts weight, becomes blurry, and nervously snaps back to sharpness when the animation ends.

The Crisp Text (Fixed)
