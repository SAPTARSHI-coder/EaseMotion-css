# Blur-Entrance Pricing Table

A responsive CSS-only pricing table designed for gaming hub layouts.

This example demonstrates a smooth blur-entrance animation using pure HTML and CSS.

## Features

- Pure HTML and CSS
- Blur and slide entrance animation
- Staggered pricing card animations
- Hover elevation effect
- Responsive desktop, tablet, and mobile layouts
- CSS custom properties
- No JavaScript or external libraries
- `prefers-reduced-motion` accessibility support

## Files

- `demo.html` - Pricing table markup
- `style.css` - Styling and animations
- `README.md` - Documentation
