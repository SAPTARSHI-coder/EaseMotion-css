# 3D Cube Rotation Gallery

Interactive 3D perspective cube gallery using CSS transform-style preserve-3d.

## Usage
```html
<link rel="stylesheet" href="style.css" />
<div class="ease-cube-scene">
  <div class="ease-cube">
    <div class="ease-cube-face ease-face-front">Front</div>
  </div>
</div>
```
