About This Demo

This modal uses the native <dialog> HTML element. Open/close animations are handled entirely in CSS using @starting-style, overlay, ::backdrop, and transition-behavior: allow-discrete.

Keyboard support is built-in: press Esc to close, focus is trapped automatically, and the backdrop is clickable to dismiss.
