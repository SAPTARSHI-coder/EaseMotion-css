# CSS Rotate-Fade Modal

A responsive modal featuring a rotate-and-fade entrance animation built with pure HTML and CSS.

## Features

- Pure HTML & CSS
- Rotate + Fade entrance animation
- Responsive layout
- Lightweight and reusable
- Accessible with `prefers-reduced-motion`
- Easy customization using CSS variables

## Files

- demo.html
- style.css

## Usage

Open `demo.html` directly in any modern browser.

## CSS Variables

```css
:root{
  --bg:#0f172a;
  --card:#1e293b;
  --accent:#38bdf8;
  --text:#ffffff;
}
```
