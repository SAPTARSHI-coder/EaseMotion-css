# CSS Zoom-In Navbar for Accessible Web Layouts

A modern **Zoom-In Navbar** component built completely with **HTML5 and CSS3**. This showcase demonstrates a smooth entrance animation, interactive navigation links, hover zoom effects, responsive behaviour, and accessibility support without JavaScript.

---

## ✨ Features

- 🔍 Smooth zoom-in entrance animation
- 🧭 Animated navigation links
- 💎 Glassmorphism navbar design
- ⚡ Lightweight CSS transitions
- 🎯 CSS Custom Properties
- 📱 Fully responsive layout
- 🧩 Pure HTML5 & CSS3
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

## 🚀 Usage

1. Open `demo.html` in any modern browser.
2. View the animated navigation bar.
3. Hover over links and buttons for zoom interactions.
4. Customize the design using CSS variables.
