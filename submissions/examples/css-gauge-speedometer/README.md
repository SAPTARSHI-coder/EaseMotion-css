# CSS Gauge Speedometer

A responsive speedometer-style gauge built using pure HTML and CSS.

## Features

- Pure HTML and CSS
- No JavaScript required
- Animated gauge needle
- Speedometer-style gauge
- Colored speed zones
- Gauge scale and labels
- Responsive design
- Accessible gauge labeling
- Reduced-motion support
- Modern glass-style interface

## Demo

Open `demo.html` in a modern browser.

The gauge displays a demonstration speed of `72 km/h` with an animated needle.
