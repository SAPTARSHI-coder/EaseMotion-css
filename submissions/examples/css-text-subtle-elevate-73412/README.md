# CSS Text - Subtle Elevate

A modern pure CSS text animation that creates a gentle floating elevation effect. The text smoothly rises and falls while dynamically adjusting its shadow depth, creating a refined sense of motion and dimensionality.

## Features

- Pure HTML & CSS
- Subtle elevation animation
- Smooth shadow transitions
- Dark mode compatible
- Hardware accelerated transforms
- Responsive typography
- Accessibility friendly
- No JavaScript required

## Usage

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

Add the animated text element:

```html
<h1 class="elevate-text">Subtle Elevate</h1>
```

This component follows EaseMotion CSS principles by delivering a clean, human-readable animation built entirely with CSS. It emphasizes smooth motion, accessibility, performance, and visual elegance while remaining lightweight and easy to integrate.
