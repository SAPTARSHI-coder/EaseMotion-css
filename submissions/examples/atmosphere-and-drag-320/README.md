# Ease Advanced Interactive 3D Globe

An interactive 3D globe component featuring a glowing particle atmosphere,
drag-based rotation, inertia and automatic rotation.

## Features

- Interactive 3D globe
- Mouse drag rotation
- Touch drag support
- Inertia after dragging
- Automatic rotation
- Glowing atmosphere
- Floating particles
- Latitude and longitude grid
- Responsive design
- Reduced-motion support
- No external libraries required
