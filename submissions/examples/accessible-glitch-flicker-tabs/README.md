# CSS Glitch-Flicker Tabs for Accessible Web Layouts

A modern **Accessible Tabs** component built using **pure HTML5 and CSS3**. This showcase features a subtle **Glitch-Flicker** animation for active tabs, glassmorphism styling, responsive layouts, and accessibility support without JavaScript.

---

## ✨ Features

- ⚡ Glitch-Flicker active tab animation
- ♿ Accessible semantic tab layout
- 💎 Glassmorphism content panels
- 🌈 Gradient active tab highlight
- 🚀 Smooth CSS transitions
- 📱 Fully responsive
- 🎨 CSS Custom Properties
- ♿ `prefers-reduced-motion` support
- 🚫 Pure HTML & CSS

## 🚀 Getting Started

1. Open `demo.html` in any modern browser.
2. Click the tabs to switch between content panels.
3. Customize colors, spacing, glow effects, and animation timing using CSS variables.

---

## 🎨 CSS Variables

```css
:root{
    --bg:#060b18;
    --surface:rgba(255,255,255,.08);
    --primary:#00e5ff;
    --secondary:#ff2ea6;
    --text:#ffffff;
    --muted:#cbd5e1;
    --border:rgba(255,255,255,.12);
    --radius:22px;
}
```
