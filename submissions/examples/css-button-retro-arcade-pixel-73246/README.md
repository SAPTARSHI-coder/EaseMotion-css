# CSS Button: Retro Arcade Pixel Variation #14

A nostalgic Retro Arcade Pixel button built entirely with HTML and CSS. Inspired by classic arcade machines and 8-bit video games, this component features chunky borders, pixel-style shadows, and retro interaction effects.

## Features

- Pure HTML & CSS
- Retro arcade-inspired design
- Pixelated shadow effects
- Accessible keyboard focus states
- Dark mode compatible
- Responsive layout
- No JavaScript required

## Usage

```html
<button class="pixel-btn">
    START GAME
</button>
```

## Customization

Update the button colors:

```css
.pixel-btn {
    background: #ffcc00;
}

.secondary {
    background: #00e5ff;
}
```
