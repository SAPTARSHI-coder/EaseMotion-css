# Hover Toggle — Gradient

A responsive CSS-only toggle featuring a modern gradient
visual style, smooth hover interaction, subtle depth, and
accessible keyboard support.

Implemented for issue #78745.

## Features

- Gradient toggle design
- Smooth hover animation
- Gradient active state
- Animated toggle thumb
- Shine effect on hover
- Responsive mobile layout
- Keyboard focus-visible state
- CSS-only interaction
- No external dependencies
- Reduced-motion support
