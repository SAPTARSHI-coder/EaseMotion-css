# CSS Fade-In Carousel for Product Catalog Layouts

A modern, responsive **Fade-In Carousel** built with pure HTML and CSS for showcasing products in catalog layouts. Each product card smoothly fades into view with staggered animation delays, creating an elegant browsing experience without requiring JavaScript.

## Features

- Pure HTML5 & CSS3
- Smooth fade-in entrance animations
- Responsive product grid layout
- Modern card-based UI
- Hover lift and scale effect
- CSS Custom Properties for easy customization
- Accessible `prefers-reduced-motion` support
- Lightweight and dependency-free

## CSS Custom Properties

```css
:root{
    --bg:#08111f;
    --card:#162234;
    --text:#ffffff;
    --muted:#a7b5c8;
    --primary:#3b82f6;
    --primary-dark:#2563eb;
    --radius:18px;
}
```

## Usage

1. Open `demo.html`.
2. Ensure `style.css` is in the same folder.
3. Customize colors using CSS variables.
4. Replace demo images with your own product assets.
