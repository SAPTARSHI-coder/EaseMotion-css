# Water Organ Hydraulis

## What does this do?
Renders a self-contained CSS-only `ease-water-organ-hydraulis` demo: Hydraulis water organ pipe sounding.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-water-organ-hydraulis`. No build step or JavaScript is required for the effect.

```html
<section class="ease-water-organ-hydraulis">
  <div class="ease-water-organ-hydraulis__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
