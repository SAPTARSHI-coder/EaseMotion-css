# Cyberpunk Glitch & Slicing Button

A highly stylized cyberpunk-themed button that features a rapid slicing animation and chromatic aberration on hover.

## Features
- Clip-Path Slicing: Utilizes complex clip-path polygon animations to simulate digital glitching.
- Chromatic Aberration: Offsets RGB channels using layered text-shadow.
- Pure CSS: Completely JavaScript free.

## Usage
Include the HTML and CSS. The button uses a custom data-text attribute or duplicated text in a span to achieve the layering effect needed for the glitch.
