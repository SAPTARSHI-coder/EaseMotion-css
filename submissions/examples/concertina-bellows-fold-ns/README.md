# Concertina Bellows Fold

## What does this do?
Renders a self-contained CSS-only `ease-concertina-bellows-fold` demo: Concertina bellows folding a pulse of air.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-concertina-bellows-fold`. No build step or JavaScript is required for the effect.

```html
<section class="ease-concertina-bellows-fold">
  <div class="ease-concertina-bellows-fold__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
