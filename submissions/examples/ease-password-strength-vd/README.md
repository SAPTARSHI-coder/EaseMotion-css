# Ease Password Strength

## What does this do?

A visual password strength indicator showing weak, medium, and strong states with a progress bar and state label.

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<div class="strength-bar">
    <span class="strength-progress medium"></span>
</div>
```

### Available strength levels

```html
<span class="strength-progress weak"></span>
<span class="strength-progress medium"></span>
<span class="strength-progress strong"></span>
```

### Features

- Weak, medium, and strong states
- Progress indicator
- State labels
- Smooth transitions
- Responsive layout
- Pure CSS
- No JavaScript required

## Why is it useful?

Password strength indicators are commonly used in registration forms, password creation screens, and account settings.

This component provides a clear visual representation of password strength using a simple progress indicator and color-coded states while following the animation-first philosophy of EaseMotion CSS.
