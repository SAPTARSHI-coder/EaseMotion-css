# Animated Gradient Text Component

A fluid text component featuring an animated multi-color gradient background clip for headers and hero titles.

## Features
- **Background Clip Animation:** Smooth 60fps CSS background position loop.
- **Cross-Browser Styling:** Incorporates WebKit background clipping attributes.
- **Pure CSS:** Zero JavaScript dependencies required.

## File Structure
- `demo.html` - Minimal markup previewing animated hero title.
- `style.css` - Text gradient utility rules and shifting keyframes.
