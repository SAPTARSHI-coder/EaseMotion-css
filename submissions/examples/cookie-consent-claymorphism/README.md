# Glowing Cookie Consent Banner (Claymorphism)

## Overview

A modern Cookie Consent Banner inspired by the Claymorphism design style. The component combines soft shadows, rounded surfaces, and subtle glowing effects to create a clean and visually appealing consent banner using only HTML and CSS.

## Features

- Claymorphism-inspired interface
- Soft glowing visual effects
- Pure HTML & CSS
- Responsive layout
- Smooth hover transitions
- Accessible keyboard focus styles
- No JavaScript required
- Supports `prefers-reduced-motion`

## Files

- `demo.html`
- `style.css`
- `README.md`

## Usage

Open `demo.html` in any modern browser.
