# 🧬 DNA Loader – DNA Helix Spins and Replicates

> A mesmerizing, scientific loading animation where a DNA helix spins and replicates, creating a biology-inspired visual experience.

---

## 📖 Description

The **DNA Loader** is a mesmerizing, scientific loading animation where a DNA helix spins and replicates. The double helix rotates in 3D space with colored base pairs, while particles float around it like replicating molecules. The animation creates a biology-inspired visual experience that's both educational and engaging.

The component uses CSS 3D transforms and keyframe animations to create the spinning helix effect. Two strands with alternating colored bases are connected by rungs, creating a realistic DNA structure. Floating particles add a replication effect, making the animation feel dynamic and alive.

Perfect for biology-themed interfaces, educational platforms, medical brands, and any application where you want to create a scientific, engaging loading animation. The DNA Loader transforms a simple loading indicator into a molecular biology experience.
