# Dynamic Stepper Nav — Brutalism

A responsive stepper navigation component inspired by brutalist web design.

The component uses bold borders, offset shadows, high-contrast colors,
strong typography, and CSS transitions to create a distinctive visual
stepper without JavaScript.

## Features

- Brutalist visual design
- Four-step navigation
- Completed and active states
- Animated active step
- Animated progress indicator
- Responsive desktop and mobile layouts
- Pure HTML and CSS
- No JavaScript
- CSS custom properties
- Keyboard-accessible action button
- `prefers-reduced-motion` support
