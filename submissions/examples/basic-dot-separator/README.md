# Basic Dot Separator (#75287)

A lightweight, CSS-only dot separator utility for cleanly separating inline metadata items such as dates, authors, categories, or reading times.

## Features
- **Clean Typography:** Dynamically inserts dot separators between inline child elements using CSS `::after` pseudo-elements.
- **Pure CSS:** Zero JavaScript dependencies; relies purely on standard CSS inline layouts.
- **Performance:** Lightweight utility with zero layout shift or rendering overhead.
- **Accessibility:** Keeps separator elements out of screen reader flow by using pseudo-elements rather than hardcoded text characters.
