# Glassmorphism Breadcrumb with Cyberpunk Styling

A responsive breadcrumb navigation component combining glassmorphism effects with vibrant cyberpunk neon aesthetics.

## Features

- Glassmorphism UI
- Cyberpunk neon colors
- Responsive layout
- Hover glow effects
- Lightweight implementation
- Pure HTML/CSS

## Files

- demo.html
- style.css

## Usage

Open `demo.html` directly in a browser.

## Customization

You can modify:

- Neon colors
- Blur intensity
- Border radius
- Glow effects
- Typography

## Browser Support

- Chrome
- Firefox
- Edge
- Safari
