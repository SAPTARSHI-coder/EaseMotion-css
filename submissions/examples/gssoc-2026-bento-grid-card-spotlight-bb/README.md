# Bento Grid Card Spotlight - GSSoC 2026

An asymmetric Bento grid layout showcasing subtle radial cursor spotlight illumination and responsive grid reordering.

## 1. What does this do?
It creates an modern Bento dashboard layout with multi-span feature cards and interactive radial spotlight highlights on hover.

## 2. How is it used?
Link `style.css` in your project HTML file and utilize `.bento-container` containing `.bento-card` elements.

## 3. Why is it useful?
It offers a modern layout pattern for SaaS marketing pages, analytics dashboards, and portfolio showcases with mobile responsiveness.
