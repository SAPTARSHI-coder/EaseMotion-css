# CSS Floating-Glass Popover

A modern **Floating-Glass Popover** built using pure HTML5 and CSS3 for Gaming Hub layouts. It features a glassmorphism design with smooth floating transitions and responsive behavior.

---

## ✨ Features

- Pure HTML5 & CSS3
- Floating glass popover
- Glassmorphism UI
- Responsive layout
- CSS Custom Properties
- Keyboard accessible
- Lightweight and performant
- `prefers-reduced-motion` support
- No JavaScript required

## 🚀 Usage

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

Open `demo.html` in any modern browser.

    --primary;
    --secondary;
    --glass;
    --border;
    --bg;
    --text;
    --radius;
}
