# Shimmer-Sweep Accordion Product Catalog

A lightweight, responsive product catalog example featuring a pure CSS
Shimmer-Sweep Accordion.

The component uses semantic HTML and CSS animations without JavaScript or
external frameworks.

## Features

- Pure HTML and CSS
- Native `<details>` and `<summary>` accordion
- Shimmer-sweep hover animation
- Animated product-card shimmer
- Smooth CSS transitions
- CSS keyframe animations
- Responsive desktop, tablet and mobile layouts
- Keyboard-accessible accordion behavior
- Visible focus state
- CSS custom properties
- `prefers-reduced-motion` support
- No JavaScript dependencies
