# Parallax Navbar with Glassmorphism Styling

A stunning, modern navigation bar component featuring a frosted glass aesthetic floating over a pure CSS animated parallax background gradient.

## Features
- True glassmorphism using `backdrop-filter: blur`
- Floating navbar layout (decoupled from the top edge)
- Pure CSS animated gradient background providing a parallax depth effect
- Underline hover animations for navigation links
- Fully responsive (hides links and shows a hamburger icon on mobile)
- High contrast and accessible text styling

## Usage
Include `demo.html` and `style.css` in your project. The background gradient (`.parallax-bg`) uses `position: fixed` to maintain depth as the user scrolls down the page underneath the frosted navbar.
