# Hover Navbar with Cyberpunk Styling

A futuristic responsive navigation component featuring a cyberpunk visual system, neon hover effects, responsive navigation, and pure CSS interactions.

## ✨ Features

- Cyberpunk-inspired visual design
- Responsive desktop and mobile navigation
- Pure HTML and CSS
- No external JavaScript dependencies
- Neon cyan and magenta hover effects
- Animated navigation indicators
- Mobile hamburger navigation
- Interactive status indicator
- Responsive hero section
- CSS grid background
- Terminal-style system status panel
- `prefers-reduced-motion` support
