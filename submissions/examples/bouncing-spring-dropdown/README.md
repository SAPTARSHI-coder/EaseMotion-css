# Bouncing Spring Dropdown

A playful and responsive dropdown menu featuring a smooth **Bouncing Spring** animation.

The component is built entirely with **HTML and vanilla CSS** and requires no JavaScript or external dependencies.

## ✨ Features

- Pure HTML and CSS
- No JavaScript required
- Smooth spring-style dropdown entrance
- Subtle overshoot and settle animation
- Staggered menu item animations
- Hover and focus interactions
- Native `<details>` / `<summary>` interaction
- Dark-mode friendly design
- Responsive layout
- Hardware-friendly CSS transforms
- `prefers-reduced-motion` support
- Accessible keyboard focus indicators
- Dependency-free
