# CSS Skew-Active Pricing Table for Fintech Dashboard Layouts

A pure CSS 3D Skew-Active pricing matrix featuring dynamic spatial angle skewing, cyberpunk grid optics, and tactile plan elevation for fintech terminals.

## Key Features

- **3D Skew Perspective Transformations:** Cards rest in a 3D perspective field (`transform: rotateY(-5deg) rotateX(2deg) skewY(-1deg)`), dynamically snapping to parallel alignment (`scale(1.06) translateZ(20px)`) on hover.
- **Pure CSS Billing Selector:** Allows toggling between monthly and annual pricing options via custom radio input states.
- **Cyberpunk Grid Geometry:** Dark aesthetic with background grid lines, neon cyan highlights, and angular typography.
- **Responsive & Accessible:** Converts to flat single-column layout on mobile devices and supports `@media (prefers-reduced-motion: reduce)`.

## Customization

```css
:root {
    --bg-dark: #070a0f;
    --skew-cyan: #00f2fe;
    --skew-blue: #3b82f6;
}
```
