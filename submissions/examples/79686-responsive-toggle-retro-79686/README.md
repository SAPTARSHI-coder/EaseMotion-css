# Responsive Toggle — Retro

## Overview

A responsive retro toggle component for EaseMotion issue #79686.

## Features

- Native checkbox control
- Retro visual treatment
- Clear checked and unchecked states
- Keyboard-visible focus
- Responsive layout
- Reduced-motion support
- Pure HTML and vanilla CSS

## Usage

Open `demo.html` directly. The hidden checkbox remains the functional control while the adjacent visual switch represents its state.

## Accessibility

The native checkbox preserves keyboard interaction. Focus is exposed through `:focus-visible`, and the label keeps the control easy to operate.

## Files

- `demo.html` — self-contained example
- `style.css` — visual treatment and responsive behavior
- `README.md` — documentation
