# CSS Elastic Slide Tabs

A responsive gaming-inspired tab component featuring a smooth elastic slide indicator using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Elastic slide tab indicator
- Responsive design
- CSS Custom Properties
- No JavaScript
- Accessible (`prefers-reduced-motion`)

## Folder Structure

```text
elastic-slide-tabs/
├── demo.html
├── style.css
└── README.md
```

## Usage

1. Open `demo.html`.
2. Click a tab to switch sections.
3. Customize colors and animation using CSS variables.

## CSS Variables

- `--bg`
- `--surface`
- `--primary`
- `--text`
- `--duration`
