# Modern Responsive Landing Page (EaseMotion CSS)

A self-contained landing page example demonstrating EaseMotion utility classes for:
- Hero entrance (fade/slide)
- Feature grid
- Hover-grow interactions on cards and buttons
- Clean CTA section
- Footer

## Files
- `index.html`
- `style.css` (custom styling only; animations use EaseMotion classes)
- `README.md`

## Live Preview
Open `index.html` in a browser.

## EaseMotion Classes Used
- `ease-fade-in`
- `ease-slide-up`
- `ease-hover-grow`
- `ease-center`
- `ease-grid`
- `ease-card`
