# Landing Page Example

This is a production-ready landing page example demonstrating the power of **EaseMotion CSS**.

## Features shown
- **Hero Staggering**: Sequential fade-ins to guide the user's eye.
- **Scroll Reveals**: Cards that pop into place as they enter the view.
- **Hover Micro-interactions**: Playful `ease-pop` and `ease-shake` animations on hover for engagement.
- **Tailwind Integration**: Used in combination with Tailwind CSS to show seamless compatibility.

## How to run
Since this is a static HTML page, you can simply open `index.html` in your browser!
Alternatively, use a local server like `npx serve .` or `python -m http.server 8000` to serve the directory.
