# CSS Character Select Screen

A gaming inspired character selection UI created using pure CSS.

## Features

- Horizontal character scrolling
- Selected character highlight
- Hover animations
- Gaming style UI
- Responsive design
- Keyboard accessible


## Technologies

- HTML5
- CSS3


## Use Cases

- Game menus
- Portfolio showcases
- Interactive dashboards
- Profile selectors


## Accessibility

- Keyboard focus support
- Semantic HTML structure
- ARIA label included
