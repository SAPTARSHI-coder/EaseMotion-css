Scroll Progress Bar

Scroll down to see the reading progress fill at the top of the viewport.

Dynamic CSS-Driven Motion

This implementation decouples the visual animation from JavaScript execution. JavaScript calculates a single custom CSS property (--scroll-percent) on scroll, while CSS handles the smooth rendering and hardware-accelerated transforms using scaleX().

Performance Considerations

By animating transform: scaleX() instead of width, we avoid triggering costly layout recalculations (reflows) on every scroll frame. This maintains a fluid 60 FPS experience across all desktop and mobile browsers.
