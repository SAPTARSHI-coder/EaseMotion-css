demo.html

README.md

Features
🎨 Saturation increase — colors become much more vibrant on hover.
🌈 Gradient-based visual — makes the effect easy to see.
🖱️ Interactive hover effect — activates when the cursor enters the card.
✨ Smooth animation — uses CSS transitions.
📦 Reusable — works on cards, images, buttons, backgrounds, and other elements.
⚡ No JavaScript — completely CSS-based.
🔧 Adjustable intensity — change 220% to any desired saturation level.
