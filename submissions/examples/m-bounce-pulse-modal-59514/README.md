# CSS Bounce-Pulse Modal for SaaS Showcase Layouts

A modern **Bounce-Pulse Modal** built using pure HTML and CSS. The modal features a smooth bounce-pulse entrance animation, elegant glassmorphism styling, responsive layout, and requires no JavaScript.

## ✨ Features

- Pure HTML5 & CSS3
- Bounce-pulse modal animation
- Glassmorphism design
- Responsive layout
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
