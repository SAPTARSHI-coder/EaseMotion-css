# CSS Morph-Glow Tooltip for Creative Portfolio Layouts

A modern **Creative Portfolio Tooltip** showcase built using **pure HTML5 and CSS3**. This example demonstrates elegant Morph-Glow animations with glassmorphism styling, gradient glow effects, responsive layouts, and accessibility support without JavaScript.

---

## ✨ Features

- ✨ Morph-Glow tooltip animation
- 💎 Glassmorphism tooltip design
- 🌈 Gradient glow border
- 🚀 Smooth hover transitions
- 🎯 Multiple tooltip placements
- 📱 Fully responsive
- 🎨 CSS Custom Properties
- ♿ `prefers-reduced-motion` support
- 🚫 Pure HTML & CSS

## 🚀 Getting Started

1. Open `demo.html` in any modern browser.
2. Hover over the buttons to reveal Morph-Glow tooltips.
3. Customize colors, spacing, glow effects, and animation timing using CSS variables.

---

## 🎨 CSS Variables

```css
:root{
    --bg:#070b18;
    --surface:rgba(255,255,255,.08);
    --primary:#7c3aed;
    --secondary:#06b6d4;
    --text:#ffffff;
    --muted:#cbd5e1;
    --border:rgba(255,255,255,.12);
    --radius:20px;
}
```
