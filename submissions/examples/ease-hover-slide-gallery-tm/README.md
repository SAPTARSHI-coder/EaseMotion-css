# Hover Slide Gallery Component

Add ease-hover-slide-gallery-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|--------|
| `--hg-accent` | `#6366f1` |
| `--hg-radius` | `12px` |
| `--hg-shadow` | `0 8px 32px rgba(0,0,0,.4)` |
| `--hg-trans` | `0.4s cubic-bezier(.4,0,.2,1)` |

## Technique

Image scale + overlay translateY + opacity on `:hover`. No JavaScript needed.
