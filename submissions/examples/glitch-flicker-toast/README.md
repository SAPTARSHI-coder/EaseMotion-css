# Glitch-Flicker Toast

A lightweight, pure CSS/HTML Glitch-Flicker Toast designed for modern Gaming Hub interfaces.

## Features

- Pure HTML and CSS
- No JavaScript or external frameworks
- Glitch and flicker animation
- Animated scan effect
- Responsive layout
- Keyboard-accessible close button
- Focus-visible support
- `prefers-reduced-motion` accessibility support
- Customizable CSS properties
