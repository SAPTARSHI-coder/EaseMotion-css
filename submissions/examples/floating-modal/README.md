# CSS Floating Modal

A demo project showcasing a **floating modal window** using HTML, CSS, and JavaScript.

## Features
- Modal floats into view with smooth animation.
- Background overlay with click-to-close functionality.
- Close button styled with neon accent.
- Responsive and centered layout.

## Files
- `demo.html` → Structure with modal and script logic.
- `style.css` → Floating animation, overlay, and styling.
- `README.md` → Documentation and usage instructions.

## Usage
1. Open `demo.html` in your browser.
2. Click **Open Modal** to show the floating modal.
3. Click the close button or outside the modal to dismiss it.

## Customization Ideas
- Add multiple modals for different content.
- Use CSS variables for theme colors.
- Integrate with forms or confirmation dialogs.
- Add entrance/exit animations like scale or rotate.
