# Particle Burst Bento Card

A dynamic bento grid component featuring a Particle Burst visual effect
using pure HTML and Vanilla CSS.

The component combines responsive bento layouts with expanding particle
animations, glowing energy rings and interactive UI elements.

## Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Responsive bento grid
- Particle burst animation
- Expanding energy rings
- Animated particle field
- Dynamic progress indicator
- System status indicator
- Hover interactions
- Dark-mode friendly design
- Hardware-accelerated CSS transforms
- Reduced-motion support
