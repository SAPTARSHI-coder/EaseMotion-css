# Chip Components

## What does this do?

Creates a colorful collection of reusable chip components for tags, filters, categories, and status indicators.

---

## How is it used?

Open `demo.html` directly in a browser.

```html
<button class="chip purple">
    🚀 Launch
</button>
```

---

## Why is it useful?

Chip components are commonly used in search filters, dashboards, admin panels, category selectors, labels, and productivity applications. This standalone example demonstrates multiple modern chip styles using only HTML and CSS.
