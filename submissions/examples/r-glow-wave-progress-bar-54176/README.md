# CSS Glow-Wave Progress Bar

A modern **Glow-Wave Progress Bar** built using pure HTML5 and CSS3 for responsive dashboard layouts. The component combines animated glow effects with a moving light wave for active progress visualization.

---

## ✨ Features

- Pure HTML5 & CSS3
- Glow-wave animation
- Responsive dashboard layout
- Multiple progress bars
- CSS Custom Properties
- Lightweight
- No JavaScript
- `prefers-reduced-motion` support
