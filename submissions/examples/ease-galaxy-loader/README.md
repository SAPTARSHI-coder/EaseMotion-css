# 🌌 Galaxy Loader – Spiral Galaxy Rotates Slowly

> A cosmic, mesmerizing loading animation where a spiral galaxy rotates slowly with twinkling stars, creating a celestial, space-inspired experience.

---

## 📖 Description

The **Galaxy Loader** is a cosmic, mesmerizing loading animation where a spiral galaxy rotates slowly with twinkling stars. Three spiral arms with colorful stars orbit around a glowing core, creating a beautiful, celestial visual experience reminiscent of a spiral galaxy. The galaxy rotates slowly with a gentle pulse, making it perfect for loading states.

The component uses CSS animations with `transform` and `keyframes` to create the spiral galaxy effect. Three arms rotate at different offsets, while stars twinkle with staggered delays. The core pulses with a soft glow, and the entire galaxy rotates slowly.

Perfect for space-themed interfaces, astronomy websites, sci-fi projects, and any application where you want to create a cosmic, mesmerizing loading animation. The Galaxy Loader transforms a simple loading indicator into a celestial experience.
