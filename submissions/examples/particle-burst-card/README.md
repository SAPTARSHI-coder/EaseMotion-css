# Particle Burst Card

A smooth, accessible and performant card component featuring a
CSS-only Particle Burst interaction.

## ✨ Features

- Particle burst hover effect
- CSS-only implementation
- No JavaScript
- No external dependencies
- Smooth transitions
- Hardware-friendly transforms
- Interactive glow
- Accessible keyboard focus
- Responsive layout
- Dark mode support
- Reduced-motion support
- Semantic HTML
