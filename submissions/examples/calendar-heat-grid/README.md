# CSS Calendar Heat Grid 📅


A pure CSS calendar heatmap grid for activity tracking.


## Features

- Pure CSS implementation
- GitHub style activity heatmap
- Multiple activity levels
- Hover animations
- Responsive layout
- Accessibility friendly


## Technologies

- HTML5
- CSS3


## Folder Structure

calendar-heat-grid/

├── demo.html
├── style.css
└── README.md



## Usage

Open `demo.html` in a browser.
