CSS Exclusive Accordion

A pure HTML exclusive accordion using <details name="group"> — the browser ensures only one section is open at a time. Animated with interpolate-size, ::details-content, and @starting-style. Zero JavaScript.

Frequently Asked Questions

What is the native <details> element?

The <details> HTML element creates a disclosure widget that users can open and close. It provides built-in accessibility, keyboard support, and no JavaScript is needed for basic show/hide behavior.

When given a name attribute, multiple <details> elements form an exclusive accordion — opening one automatically closes the others.

How does the exclusive accordion work?

All <details> elements that share the same name attribute value form an exclusive group. When one is opened, the browser automatically closes any other open item in the same group — similar to how <input type="radio" name="..."> works.

This is a native browser feature in Chromium 120+ and Firefox 131+.

What CSS features enable the animation?

Three modern CSS features work together:

  • ::details-content — targets the content wrapper for styling
  • interpolate-size: allow-keywords — enables transitions from auto height
  • @starting-style — defines the initial (closed) state for transitions
Is this accessible?

Yes. The native <details> element gets accessibility for free:

  • Arrow keys navigate between items
  • Space/Enter toggle items
  • Screen readers announce the open/closed state
  • Focus outlines are visible via :focus-visible
  • Respects prefers-reduced-motion to disable animations

Feature Comparison

🚀 Performance

Zero JavaScript means zero runtime overhead. The browser handles exclusive behavior natively — no event listeners, no DOM manipulation, no reflows triggered by script.

🎨 Styling

Full CSS control over every visual detail — borders, backgrounds, spacing, typography, and smooth open/close animations. No framework classes needed.

♿ Accessibility

Built-in keyboard support (Space, Enter, arrow keys), proper ARIA roles, screen reader announcements, and respect for reduced motion preferences. Nothing to configure.

📏 Size & Dependencies

No npm packages, no CDN scripts, no framework. The entire accordion is ~200 lines of CSS plus semantic HTML. It works by opening the demo.html file directly in any modern browser.
