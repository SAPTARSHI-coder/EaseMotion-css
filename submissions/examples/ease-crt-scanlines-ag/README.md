# Realistic CRT Monitor Scanlines

An immersive retro CRT screen effect overlay created purely with CSS.

## Features
- **Scanlines:** Built using layered transparent `linear-gradient` backgrounds to simulate old CRT raster lines.
- **Refresh Bar:** A slow scrolling transparent bar achieved using a pseudo-element (`::after`) and `@keyframes`.
- **Screen Curvature:** A combination of a subtle `border-radius`, `radial-gradient` glare, and intense `box-shadow` simulates the curvature and thickness of vintage glass screens.
- **Text Flicker & Glow:** Uses `text-shadow` for the neon phosphor glow and an opacity flickering animation to make the text feel alive.

## Structure
- `demo.html`: The markup representing the monitor, screen, and text content.
- `style.css`: The CSS that brings the retro effect to life.

## How to run
Simply open `demo.html` in any modern web browser to experience the nostalgic CRT effect!
