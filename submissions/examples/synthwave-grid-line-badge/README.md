# Synthwave Grid Line Badge

A pure CSS badge inspired by synthwave aesthetics with glowing neon borders and a subtle retro grid background.

## Features

- Pure HTML & CSS
- Synthwave neon styling
- Responsive layout
- Smooth hover transition
- Dark mode friendly
- Hardware-accelerated transform effects
- No JavaScript required

## Files

- `demo.html` – badge preview
- `style.css` – component styles
- `README.md` – documentation

## Preview

Open `demo.html` in any modern browser.

## Customization

You can easily modify:

- Border color
- Glow intensity
- Background gradient
- Badge radius
- Typography
- Spacing
