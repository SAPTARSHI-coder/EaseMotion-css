# Origami Paper Fold Bento Card

A responsive bento grid component inspired by origami paper,
folded surfaces and geometric paper structures.

The component is built entirely with HTML and Vanilla CSS.

## Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Origami-inspired folded surfaces
- Bento grid layout
- Smooth hover elevation
- Geometric paper layers
- Responsive layout
- Dark-background compatible
- Hardware-friendly CSS transforms
- Reduced-motion support
