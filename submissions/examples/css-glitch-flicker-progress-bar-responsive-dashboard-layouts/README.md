# CSS Glitch-Flicker Progress Bar for Responsive Dashboard Layouts

A modern pure CSS animated progress bar component designed for responsive dashboard interfaces.

The **CSS Glitch-Flicker Progress Bar** provides a futuristic glitch animation effect, smooth progress visualization, responsive card layouts, and customizable CSS variables without JavaScript.


## ✨ Features

- Pure HTML5 and CSS3 implementation
- Zero JavaScript dependency
- Smooth glitch-flicker animation
- Dashboard analytics inspired UI
- Responsive progress cards
- Multiple progress states
- CSS custom property support
- Lightweight animations
- prefers-reduced-motion support

🎨 CSS Custom Properties

Animation values can be customized using CSS variables.

:root {

    --glitch-speed: 1.8s;

    --progress-height: 18px;

}
⚙️ Custom Parameters
Variable	Description
--glitch-speed	Controls glitch animation speed
--progress-height	Controls progress bar thickness
