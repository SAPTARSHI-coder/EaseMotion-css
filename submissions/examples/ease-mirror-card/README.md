# 🔦 Mirror Card – Reflects Light Beam That Moves with Mouse

> An interactive, polished card where a light beam reflects across the surface following the mouse, creating a realistic mirror effect.

---

## 📖 Description

The **Mirror Card** is an interactive UI component where a light beam reflects across the surface following the mouse. When you hover over the card, a beam of light appears and follows your cursor, creating a realistic mirror reflection effect. The beam rotates and shifts based on cursor position, mimicking how light reflects off a polished surface.

The component uses JavaScript to track mouse position and dynamically update the beam's position, angle, and gradient. A subtle glow effect adds to the realism, creating the illusion of a reflective surface. The card features a dark, polished background that enhances the light reflection effect.

Perfect for futuristic interfaces, tech brands, creative portfolios, and any application where you want to create an interactive, polished experience. The Mirror Card transforms a simple card into a dynamic, light-reflecting surface.
