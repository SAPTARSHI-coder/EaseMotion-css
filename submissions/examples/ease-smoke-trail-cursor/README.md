# 💨 Smoke Trail Cursor – Leaves a Wispy Smoke Trail

> A mystical, ethereal cursor effect where the cursor leaves a wispy smoke trail that fades away, creating a haunting, atmospheric visual experience.

---

## 📖 Description

The **Smoke Trail Cursor** is a mystical, ethereal cursor effect where the cursor leaves a wispy smoke trail that fades away. As you move your mouse, soft, billowing smoke particles follow behind, drifting upward and dispersing like smoke in the air. The effect creates a haunting, atmospheric experience reminiscent of incense smoke or mist.

The component uses JavaScript to create smoke particles at the cursor position with random properties. Each particle has random size (10-40px), opacity (0.1-0.3), trajectory (upward drift), rotation, blur (2-8px), and duration (1.5-3.5s). The particles float upward with a wispy, organic motion, creating a realistic smoke trail effect.

Perfect for mystical interfaces, atmospheric websites, creative portfolios, and any application where you want to create a haunting, ethereal cursor experience. The Smoke Trail Cursor transforms a simple cursor into a mystical, atmospheric presence.
