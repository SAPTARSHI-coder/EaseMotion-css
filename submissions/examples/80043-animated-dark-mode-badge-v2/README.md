# Animated Dark Mode Badge (V2)

A responsive animated badge component designed for dark-themed
interfaces and modern dashboards.

## Features

- Dark mode visual styling
- Animated moon indicator
- Animated status indicator
- Subtle animated gradient border
- Hover elevation effect
- Soft neon glow
- Responsive layout
- Compact badge variation
- Keyboard focus support
- Reduced-motion accessibility support
- Pure HTML and CSS
- No JavaScript dependency

## Files

- `demo.html` — complete demonstration
- `style.css` — component styling and animations

## Usage

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
