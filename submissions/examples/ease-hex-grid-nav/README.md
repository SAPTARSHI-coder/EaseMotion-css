# 🔷 Hex Grid Nav – Items in Hexagonal Grid with Hover Glow

> A modern, geometric navigation with items arranged in a hexagonal grid, featuring a glowing hover effect and vibrant color accents.

---

## 📖 Description

The **Hex Grid Nav** is a modern, geometric navigation component where items are arranged in a hexagonal grid pattern. Each hexagon features a glowing hover effect with a gradient border, animated color shift, and subtle scale transformation. The hexagonal shape is achieved using CSS clip-path, creating a unique, contemporary aesthetic.

The component uses CSS clip-path to create the hexagonal shapes, with grid layout for arrangement. On hover, each hexagon glows with a gradient border, the icon scales and changes color, and a tooltip appears. The component is fully responsive and keyboard accessible.

Perfect for modern interfaces, dashboards, creative portfolios, and any application where you want a unique, geometric navigation experience. The Hex Grid Nav transforms a simple menu into a visually stunning, contemporary interaction.
