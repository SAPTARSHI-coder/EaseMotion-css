# Glowing Navbar - Cyberpunk

A futuristic responsive navigation bar featuring a cyberpunk-inspired
neon interface, glowing borders and interactive navigation states.

## ✨ Features

- Fully responsive
- Cyberpunk visual design
- Neon cyan and magenta glow effects
- Responsive mobile navigation
- Pure HTML and CSS
- No JavaScript required
- Interactive hover states
- Active navigation state
- Glowing CTA button
- Animated system status indicator
- Keyboard-friendly navigation
- Reduced-motion support
