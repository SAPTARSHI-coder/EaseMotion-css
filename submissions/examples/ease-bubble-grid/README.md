# Bubble Grid · Grid of Bubbles Pop and Reform 🫧

An interactive grid of bubbles that pop and reform with satisfying animations and iridescent colors. Watch the bubbles burst and reform!

## Features

- 🫧 **Bubble Grid** – Dynamic grid of bubbles
- 💥 **Pop Animation** – Bubbles burst with smooth animation
- 🔄 **Reform Animation** – Bubbles reform gracefully
- 🎨 **Iridescent Colors** – Rainbow shimmering effects
- 🎚️ **Size Control** – Adjust bubble size (4-12)
- 🎚️ **Speed Control** – Adjust animation speed (1-10)
- ⏸️ **Pause/Resume** – Toggle animation
- 🔄 **Reset** – Reset grid

## How to Use

1. Click **POP** or press **Space** to pop all bubbles
2. Click **REFORM** or press **R** to reform bubbles
3. Adjust **Size** for bubble density
4. Adjust **Speed** for animation pace
5. Press **RESET** or **X** to reset grid
6. Press **PAUSE** or **P** to pause/resume animation
