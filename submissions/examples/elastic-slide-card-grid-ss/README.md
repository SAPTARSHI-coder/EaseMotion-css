# Elastic Slide Card Grid

A lightweight, responsive portfolio card grid showcasing smooth elastic slide hover animations using pure HTML and CSS. This example is designed for the EaseMotion CSS showcase collection and demonstrates engaging interactions without requiring JavaScript.

## Features

- Pure HTML5 and CSS3
- Smooth elastic slide hover animation
- Responsive CSS Grid layout
- Image zoom effect on hover
- Sliding content reveal
- CSS custom properties for easy customization
- Keyboard accessible with focus styles
- Supports `prefers-reduced-motion`
- Lightweight and easy to integrate

## Folder Structure

submissions/

## Usage

1. Copy the `elastic-slide-card-grid` folder into the `submissions/examples/` directory.
2. Ensure the EaseMotion CSS library is correctly linked in `demo.html`.
3. Open `demo.html` in a browser to preview the component.

## CSS Custom Properties

| Variable | Description |
|----------|-------------|
| `--bg-color` | Page background color |
| `--card-bg` | Card background |
| `--text-color` | Primary text color |
| `--muted-text` | Secondary text color |
| `--accent` | Primary accent color |
| `--accent-hover` | Hover button color |
| `--overlay` | Card overlay gradient color |
| `--radius` | Border radius for cards |
| `--shadow` | Default card shadow |
| `--transition` | Global transition timing |

## Accessibility

- Semantic HTML elements
