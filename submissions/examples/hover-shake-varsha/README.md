# Hover Shake

## What does this do?
Adds a short horizontal shake/wiggle animation that plays when the user hovers over an element — useful for error states, alerts, or attention-grabbing buttons.

## How is it used?
```html
<button class="hover-shake-varsha">Delete Account</button>
```
The shake plays automatically on `:hover` and stops when the mouse leaves.

## Why is it useful?
EaseMotion's Motion Library already has grow, glow, lift, morph, shimmer, and bounce-text hover effects, but no shake/wiggle — a very common UI pattern for drawing attention to destructive or warning actions (e.g. delete buttons, validation errors).
