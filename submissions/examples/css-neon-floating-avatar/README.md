# Floating Avatar with Neon Styling (#78801)

A cyberpunk-themed user profile avatar component featuring smooth floating keyframes, cyan neon glow rings, and glassmorphic card containers.

## Features
- **Floating Motion Animation:** Continuous vertical translation keyframes providing a weightless hovering effect.
- **Neon Glow Aura:** Blurred multi-color gradient backdrop ring with intense cyan drop shadows.
- **Fully Responsive:** Centered glassmorphic card layout adapting cleanly across all device viewports.

## File Hierarchy
- `style.css` - Custom properties, float/pulse keyframes, glassmorphism filters, and layout metrics.
- `demo.html` - Semantic markup demonstrating avatar card integration with ARIA roles.
- `README.md` - Technical specification and architecture overview.
