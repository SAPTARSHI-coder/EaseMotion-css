# Shimmer Skeleton Loader

A standardized, highly polished skeleton loader animation designed for modern SaaS applications. It features a continuous shimmer-sweep effect to gracefully indicate data fetching states to users.

### Usage
```html
<div class="ease-skeleton-card">
    <div class="ease-skeleton-header">
        <div class="ease-skeleton-avatar ease-shimmer"></div>
        <div class="ease-skeleton-text-group">
            <div class="ease-skeleton-text ease-skeleton-title ease-shimmer"></div>
            <div class="ease-skeleton-text ease-skeleton-subtitle ease-shimmer"></div>
        </div>
    </div>
</div>
```

### Why is it useful?
Skeleton screens improve perceived performance significantly compared to static spinners. This component provides a clean, smooth, infinite shimmer animation using pure CSS gradients and keyframes (`ease-kf-shimmer`), making it an essential utility for modern data-heavy layouts.
