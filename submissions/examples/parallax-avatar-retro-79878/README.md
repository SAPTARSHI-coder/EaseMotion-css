# Parallax Avatar with Retro Styling

A retro-inspired avatar component featuring a subtle parallax hover effect and arcade-style visuals.

## Features

- Retro arcade aesthetic
- Parallax hover interaction
- Responsive design
- Pure HTML/CSS
- Lightweight implementation
- Easy customization

## Files

- demo.html
- style.css

## Usage

Open `demo.html` in a browser.

## Customization

Modify:

- Avatar colors
- Border styling
- Hover tilt amount
- Shadow effects
- Typography

## Browser Support

- Chrome
- Firefox
- Edge
- Safari
