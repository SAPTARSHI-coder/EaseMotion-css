# CSS Fade-In Drawer for Gaming Hub Layouts

A modern **Gaming Hub Drawer** showcasing a smooth **Fade-In** animation built entirely with **HTML5 and CSS3**. This lightweight component demonstrates how to create an elegant navigation drawer without JavaScript while remaining responsive and accessible.

---

## Features

- 🎮 Gaming Hub inspired interface
- ✨ Smooth Fade-In drawer animation
- 📱 Fully responsive layout
- 🎨 CSS Custom Properties for easy customization
- ⚡ Pure HTML5 & CSS3 (No JavaScript)
- 🌙 Modern dark gaming theme
- ♿ Supports `prefers-reduced-motion`
- 🚀 Lightweight and easy to integrate

## Usage

1. Open `demo.html` in any modern web browser.
2. Click the **menu button** to reveal the Fade-In drawer.
3. Customize colors, spacing, and animation using CSS variables.
