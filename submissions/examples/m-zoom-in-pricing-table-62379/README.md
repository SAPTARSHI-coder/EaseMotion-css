# CSS Zoom-In Pricing Table for Product Catalog Layouts

A modern **Zoom-In Pricing Table** built using pure HTML and CSS. The component features smooth zoom-in hover animations, responsive pricing cards, CSS custom properties, and lightweight styling for modern product catalog pages.

## ✨ Features

- Pure HTML5 & CSS3
- Zoom-in hover animation
- Responsive pricing table
- Glassmorphism design
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
