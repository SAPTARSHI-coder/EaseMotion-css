# CSS Shiny Metal Button

A responsive CSS-only metallic button featuring animated shine,
silver and gold variants, hover effects, and accessibility support.

## ✨ Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Silver and gold metal variants
- Animated shine highlight
- Gradient-based metallic surface
- Hover elevation effect
- Press/active state
- Keyboard focus indicator
- Responsive layout
- `prefers-reduced-motion` support
- CSS custom properties
- Lightweight and reusable
