# CSS Save Game Icon

A retro-inspired floppy disk save icon with a subtle animated saving state, created entirely with HTML and CSS.

## Features

- Pure CSS implementation
- Floppy disk save icon
- Animated save interaction
- Rotating and scaling motion
- Animated confirmation check
- Saving status indicator
- Responsive layout
- Reduced-motion support
- No JavaScript required

## Files

- `demo.html` — Interactive save icon demonstration
- `style.css` — Icon construction and animations
- `README.md` — Feature documentation

## Usage

The icon can be placed inside any interface:

```html
<div
  class="save-icon"
  role="img"
  aria-label="Animated save game floppy disk icon"
>
  <div class="disk-label"></div>
  <div class="disk-shutter"></div>
  <div class="disk-center"></div>
</div>
