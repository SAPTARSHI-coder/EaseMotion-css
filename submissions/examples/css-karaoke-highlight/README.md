# CSS Karaoke Highlight


Animated karaoke-style text highlighting using pure CSS.


## Features

- Word-by-word highlight animation
- Smooth lyric reveal effect
- Gradient text transition
- Fully responsive
- No JavaScript required


## Technologies

- HTML5
- CSS3


## CSS Concepts Used

- Keyframe animations
- Background clipping
- Gradient transitions
- Animation delays
- Responsive typography


## Accessibility

- Semantic HTML
- Descriptive aria-label
