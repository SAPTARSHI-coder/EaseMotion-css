# Interactive Floating Label Input with Pastel Styling

> Issue: [#81516](https://github.com/SAPTARSHI-coder/EaseMotion-css/issues/81516) / [#61938](https://github.com/SAPTARSHI-coder/EaseMotion-css/issues/61938)

A responsive floating label input component featuring soft pastel theme aesthetics and smooth micro-interactions.

---

## ✨ Features & Architectural Highlights

- **Zero-JS Floating Label:** Pure CSS label transition using `:focus` and `:not(:placeholder-shown)` pseudo-classes.
- **Pastel Aesthetic Design:** Soft lavender, mint, and pink accents with rounded UI container.
- **Accessible & Responsive:** Adapts to all viewports with full `@media (prefers-reduced-motion: reduce)` support.

---

## 🚀 Usage

1. Include `style.css` in your HTML `<head>`:
   ```html
   <link rel="stylesheet" href="style.css" />
   ```
2. Use the HTML structure provided in `demo.html`.
