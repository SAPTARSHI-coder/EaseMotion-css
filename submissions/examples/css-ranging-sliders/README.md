# CSS Range Slider

A custom-styled range slider with an animated thumb and focus feedback built with pure CSS.

##  Features
- **Animated Thumb:** Smooth scale-up and ripple glow ring on hover and drag.
- **Cross-Browser:** Custom styling for WebKit (`::-webkit-slider-thumb`) and Gecko (`::-moz-range-thumb`) engines.
- **Accessible:** Keyboard focus ring visualization and semantic ARIA labeling.

##  Files
- `demo.html` - Minimal HTML structure containing the range slider.
- `style.css` - Custom track, thumb styling, and smooth motion effects.
