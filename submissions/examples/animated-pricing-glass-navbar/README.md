# Animated Pricing & Glass Navbar Showcase

A pure CSS modern showcase component featuring an animated glassmorphic navigation bar, interactive pricing cards, and project showcase cards.

## Features
- **Pure CSS Glassmorphic Navbar**: Frosted glass blur effect with subtle hover transitions.
- **Animated Pricing Tier Cards**: Responsive grid with featured tier badges, price tags, and hover elevation.
- **Interactive Project Cards**: Illustration cards with pure CSS geometry and hover animations.
- **Zero JavaScript Dependency**: 100% pure HTML and CSS.
- **Responsive Design**: Mobile-friendly layout with modern CSS variables.

## Files
- `demo.html` — Interactive component demo
- `style.css` — Styling and animations
