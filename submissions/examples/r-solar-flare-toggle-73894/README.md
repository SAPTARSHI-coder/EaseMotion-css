# Solar Flare Radial Toggle

A futuristic pure CSS toggle component inspired by a solar flare
and radial energy burst.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript
- No external dependencies
- Solar Flare Radial visual style
- Smooth toggle transitions
- Radial flare expansion on activation
- Animated solar icon
- Glowing toggle thumb
- Dark-mode-friendly design
- Responsive layout
- Keyboard accessible control
- Visible focus indicator
- Reduced-motion support
- CSS-powered animations

## Files

- `demo.html` — Toggle component markup
- `style.css` — Complete component styling

## Usage

Open `demo.html` in any modern browser.

Click or focus the toggle and press Space to activate the
solar flare effect.

## Accessibility

The component uses a native checkbox input with an accessible
label.

The checkbox can be operated using a mouse, keyboard, or other
standard input method.

A visible `:focus-visible` state is provided for keyboard users.

The component also respects `prefers-reduced-motion`.

## Browser Support

Designed for modern browsers supporting:

- CSS custom properties
- CSS Grid
- CSS animations
- CSS transitions
- CSS transforms
- `backdrop-filter`
- `:focus-visible`
- `prefers-reduced-motion`

## Performance

The component uses CSS transforms and opacity for animated
elements where possible.

No JavaScript or external animation library is required.
