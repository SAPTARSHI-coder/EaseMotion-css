# CSS Elastic-Slide Navbar for SaaS Showcase Layouts

A modern **Elastic-Slide Navbar** built using pure HTML and CSS. The navigation bar enters with a smooth elastic slide animation and features a responsive glassmorphism design suitable for SaaS landing pages and dashboards.

## ✨ Features

- Pure HTML5 & CSS3
- Elastic slide entrance animation
- Glassmorphism navbar
- Responsive navigation layout
- Gradient CTA button
- CSS Custom Properties
- `prefers-reduced-motion` support
- No JavaScript required
