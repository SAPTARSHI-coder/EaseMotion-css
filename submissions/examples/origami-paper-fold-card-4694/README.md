# Origami Paper Fold Card

A pure CSS card featuring smooth 3D origami paper fold effects on hover.

## Usage

```html
<div class="origami-wrapper">
  <div class="origami-card">
    <div class="fold fold-top">
      <div class="content">
        <h3>Origami Card</h3>
        <span class="badge">New</span>
      </div>
      <div class="fold fold-middle">
        <div class="content">
          <p>A pure CSS card featuring smooth 3D origami paper fold effects. Hover to unfold the details below!</p>
        </div>
        <div class="fold fold-bottom">
          <div class="content">
            <a href="#" class="action-btn">Explore Now</a>
          </div>
        </div>
      </div>
    </div>
  </div>
</div>
```

## Why it's useful

It provides a highly interactive and engaging user experience using only CSS, leveraging hardware-accelerated 3D transforms for maximum performance. It's fully responsive, dark-mode compatible, and creates a sense of depth and realism without JavaScript.
