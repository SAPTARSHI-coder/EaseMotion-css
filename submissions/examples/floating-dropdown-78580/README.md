# Floating Dropdown

Retro-inspired floating dropdown showcase for issue #78580.

## Files

- `demo.html` — native select-style navigation example.
- `style.css` — retro panel, spacing, and interaction styling.

## Features

- Responsive dropdown presentation.
- Strong visual hierarchy.
- Keyboard-friendly controls.
- High-contrast focus state.
- Reduced-motion support.

The component is intentionally dependency-free and can be adapted to application navigation or filtering.
