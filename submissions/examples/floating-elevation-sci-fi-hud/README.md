# Floating Elevation Sci-Fi HUD

A pure HTML and Vanilla CSS cyberpunk HUD component featuring a smooth floating elevation effect.

## Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Smooth floating elevation animation
- Cyberpunk / sci-fi HUD appearance
- Animated neon status indicator
- Decorative HUD rings
- Moving background grid
- Scanner animation
- Responsive layout
- Hardware-accelerated transforms
- Reduced-motion accessibility support
- Works by opening `demo.html` directly in a browser
