# Interactive Heatmap Grid Showcase

A modern high-contrast interactive heatmap grid with tooltip hover states.

## ✨ Features

- High-contrast accessible design
- Interactive activity cells
- Tooltip information on hover
- Keyboard focus support
- `aria-label` accessibility support
- Responsive layout
- Pure HTML, CSS and JavaScript
- Randomized activity data
- Visual activity intensity levels
- Reduced-motion accessibility support
- No external dependencies
