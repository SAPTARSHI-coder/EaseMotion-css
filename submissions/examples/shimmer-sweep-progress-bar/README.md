# CSS Shimmer-Sweep Progress Bar for Responsive Dashboard Layouts

A modern **Shimmer-Sweep Progress Bar** component built using only **HTML5 and CSS3**.

This example provides animated dashboard progress indicators with a smooth shimmer light sweep effect, glowing progress fills, responsive layouts, and accessibility support without JavaScript.

---

## ✨ Features

- ✨ Shimmer sweep animation
- 💡 Glowing progress indicators
- 🎨 Gradient progress fills
- ⚡ Pure CSS implementation
- 📱 Responsive dashboard layout
- 🎯 CSS Custom Properties
- ♿ `prefers-reduced-motion` support
- 🚫 Zero JavaScript dependency

## 🚀 Usage

1. Open `demo.html` in any modern browser.
2. View animated progress bars with shimmer effects.
3. Customize colors and sizes using CSS variables.
