# Advanced Magnetic Cursor with Context-Aware Hover Distortion

## 📝 Description
A sophisticated custom cursor implementation with magnetic attraction, context-aware distortion effects, and interactive feedback.

## ✨ Features
- 🧲 **Magnetic Pull** - Cursor snaps to interactive elements
- 🎭 **Context-Aware Distortion** - Different shapes for different elements
- ✨ **Ripple Effect** - Beautiful click animations
- 🌟 **Particle Trail** - Dynamic following particles
- 🎯 **Smooth Animations** - Butter-smooth cursor movement
- ♿ **Reduced Motion Support** - Respects user preferences
- 📱 **Mobile Friendly** - Disables on touch devices

## 🎨 Context-Aware Effects

| Element Type | Effect |
|--------------|--------|
| Buttons | Organic blob shape + Pink glow |
| Links | Distorted oval + Green glow |
| Images | Pulsing ring + Gold glow |
| Cards | Rotating ring + Purple glow |

## 🚀 CSS Custom Properties

| Variable | Default | Description |
|----------|---------|-------------|
| `--cursor-primary` | `#6366f1` | Primary cursor color |
| `--cursor-secondary` | `#8b5cf6` | Secondary color |
| `--cursor-smoothness` | `0.15` | Animation smoothness |
| `--cursor-magnetic-strength` | `0.3` | Magnetic pull intensity |
