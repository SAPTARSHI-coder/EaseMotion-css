# Gradient Shimmer Form

## Overview

Implementation for EaseMotion issue #73357. The form uses a restrained moving sheen over a polished surface.

## Features

- Pure HTML and vanilla CSS
- Animated gradient shimmer
- Responsive form grid
- Native controls and labels
- Strong focus treatment
- Reduced-motion support
- No external dependencies

## Accessibility

The form uses semantic labels and native controls. Focus states remain visible and the decorative shimmer stops when reduced motion is requested.

## Performance

The shimmer is a single pseudo-element animation and does not require JavaScript or repeated DOM updates.

## Usage

Open `demo.html` in a modern browser. Adjust the gradient colors and shimmer timing in `style.css` to fit another visual system.
