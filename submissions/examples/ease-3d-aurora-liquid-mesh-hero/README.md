# Ease 3D Aurora Liquid Mesh Hero (`ease-3d-aurora-liquid-mesh-hero`)

Spatial 3D Aurora Borealis liquid wave mesh background using CSS WebGL/canvas shaders with dynamic HSL color wave distortion.

## Features
- 3D spatial liquid wave mesh vertex displacement
- Dynamic HSL color gradient shifts (Neon Blue -> Purple -> Emerald)
- Pointer position distortion influence on wave height
- Glassmorphism text card overlay with backdrop blur
- Responsive canvas viewport scaling
