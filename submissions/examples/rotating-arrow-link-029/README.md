# Rotating Arrow Link

A lightweight directional link with a smooth rotating arrow interaction.

## What does it do?

The component provides:

- Rotating directional arrow.
- Hover interaction.
- Keyboard focus interaction.
- Subtle link lift.
- Circular arrow presentation.
- Responsive layout.
- Reduced-motion support.
- No JavaScript.
- No external libraries or assets.

## How do I use it?

Add the `ease-rotating-arrow-link` class to an anchor:

```html
<a class="ease-rotating-arrow-link" href="#">
  <span>Explore projects</span>
  <span class="ease-rotating-arrow-link__arrow" aria-hidden="true">→</span>
</a>
```
