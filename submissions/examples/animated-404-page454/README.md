# Animated 404 Page

A modern animated 404 error page component built with pure HTML and CSS. It includes floating gradient orbs, animated gradient text, glowing buttons, and responsive layout.

## Features

- Pure HTML and CSS implementation.
- Animated 404 gradient text.
- Floating background orbs.
- Smooth entrance animations.
- Button hover shine effect.
- Responsive layout.
- Supports `prefers-reduced-motion`.

## Usage

Copy the HTML structure from `demo.html` and link `style.css`.

```html
<main class="error-page">
  <section class="error-card">
    <h1 class="error-code">404</h1>
    <h2>Page not found</h2>
  </section>
</main>
