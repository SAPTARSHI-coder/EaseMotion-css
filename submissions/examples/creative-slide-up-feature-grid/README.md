# CSS Slide-Up Feature Grid for Creative Portfolio Layouts

A modern **Creative Portfolio Feature Grid** built using **pure HTML5 and CSS3**. This showcase demonstrates elegant **Slide-Up** hover animations, glassmorphism feature cards, gradient accents, responsive layouts, and accessibility support without JavaScript.

---

## ✨ Features

- ⬆️ Slide-Up hover animation
- 💎 Glassmorphism feature cards
- 🌈 Gradient accent icons
- ✨ Hidden content reveal
- 🚀 Smooth CSS transitions
- 📱 Fully responsive
- 🎨 CSS Custom Properties
- ♿ `prefers-reduced-motion` support
- 🚫 Pure HTML & CSS

## 🚀 Getting Started

1. Open `demo.html` in any modern browser.
2. Hover over feature cards to reveal additional content.
3. Customize colors, spacing, shadows, and animations using CSS variables.

---

## 🎨 CSS Variables

```css
:root{
    --bg:#08111f;
    --surface:rgba(255,255,255,.08);
    --primary:#6366f1;
    --secondary:#06b6d4;
    --text:#ffffff;
    --muted:#cbd5e1;
    --border:rgba(255,255,255,.12);
    --radius:22px;
}
```
