# CSS Fade-In Carousel for Product Catalog Layouts

A modern **Fade-In Carousel** built with pure HTML and CSS for the EaseMotion CSS library. The carousel smoothly fades between product showcase cards, making it ideal for e-commerce stores, product landing pages, and online catalogs.

---

## Features

- Pure HTML5 & CSS3
- Smooth Fade-In animation
- Product showcase layout
- Responsive design
- Hover effects
- CSS Custom Properties
- Clean modern UI
- No JavaScript required
- Supports `prefers-reduced-motion`
