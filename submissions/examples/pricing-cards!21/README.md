# Animated Pricing Cards Example

This example demonstrates how to build a modern, responsive pricing table using **EaseMotion CSS** utility classes combined with clean, custom CSS.

## ✨ Features Showcased
- **Entrance Animations:** `ease-fade-in`, `ease-slide-up`, `ease-delay-200`
- **Hover Effects:** `ease-hover-lift`, `ease-hover-scale`
- **Attention Seekers:** `ease-pulse` (on the "Most Popular" badge)
- **Accessibility:** Fully respects `prefers-reduced-motion` media queries.
- **Responsive:** Uses CSS Grid (`auto-fit`) for seamless mobile-to-desktop scaling.

## 🚀 How to Run
1. Clone the EaseMotion CSS repository.
2. Navigate to this directory: `examples/pricing-cards/`
3. Open `demo.html` directly in your web browser. No build step or local server is required!

## 📂 Files
- `demo.html`: The main HTML structure utilizing EaseMotion classes.
- `style.css`: Custom styling for the pricing cards layout and aesthetics.
- `README.md`: This documentation file.

> **Note:** This is a self-contained example designed to showcase the capabilities of EaseMotion CSS without modifying any core library files.
