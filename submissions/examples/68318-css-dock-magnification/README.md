# CSS Dock Magnification

## Overview

A macOS-inspired dock magnification interaction using CSS relational selectors.

## Features

- Hover magnification
- Neighbor scaling
- Accessible links and focus states
- Responsive touch-friendly layout
- Reduced-motion support
- No JavaScript dependency

## Files

- `demo.html` — dock structure and application items
- `style.css` — magnification behavior and responsive styling

## Usage

Open `demo.html` in a modern browser with `:has()` support.
