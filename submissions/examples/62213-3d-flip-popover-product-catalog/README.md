# CSS 3D-Flip Popover for Product Catalog Layouts

A modern **3D-Flip Popover** built using pure HTML5 and CSS3 for product catalog layouts. The component provides responsive product quick-view popovers with smooth 3D flip animations, glassmorphism styling, and accessibility support.

## Features

* Pure HTML5 & CSS3
* 3D Flip popover animation
* Product quick-view popover
* Glassmorphism popover design
* CSS Perspective & 3D transforms
* Arrow indicator
* Product title, price, description, stock status, and CTA button
* Smooth CSS transitions & keyframe animations
* Responsive desktop, tablet, and mobile layout
* CSS Custom Properties
* No JavaScript required
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over the **Quick View** button to reveal the popover with a 3D flip animation.
3. Customize colors, spacing, shadows, and animation timing through the CSS variables in `:root`.
4. Integrate the component into any product catalog or e-commerce interface.
