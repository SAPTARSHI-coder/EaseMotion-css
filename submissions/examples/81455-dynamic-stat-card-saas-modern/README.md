# Dynamic Stat Card — SaaS Modern

A modern SaaS-style statistic card built entirely with
HTML and CSS for EaseMotion CSS.

Created for EaseMotion CSS issue #81455.

## Features

- Modern SaaS dashboard aesthetic
- Dynamic-looking revenue metric
- Percentage growth indicator
- Animated chart bars
- Subtle trend visualization
- Interactive options button
- Hover elevation
- Soft accent effects
- Responsive desktop, tablet and mobile layouts
- Zero JavaScript dependencies
- `prefers-reduced-motion` support
