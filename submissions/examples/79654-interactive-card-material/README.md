# Interactive Card — Material Design

A responsive interactive card component inspired by Material
Design principles, featuring elevation, clear hierarchy,
subtle motion, and responsive behavior.

Implemented for issue #79654.

## Features

- Material-inspired card layout
- Interactive hover elevation
- Featured card visual area
- Decorative animated shapes
- Hover interaction feedback
- Responsive layout
- Keyboard focus states
- CSS-only interaction
- No external dependencies
- Reduced-motion support
