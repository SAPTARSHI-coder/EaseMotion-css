# 3D Pagination with Neon Styling

A responsive CSS-only pagination component featuring layered 3D depth and neon-inspired visual styling.

## Features

- 3D layered pagination buttons
- Neon cyan and pink accents
- Active page styling
- Previous and next controls
- Hover depth interaction
- Pressed state
- Fully responsive
- Keyboard-accessible focus states
- Reduced-motion support
- No JavaScript
- No external dependencies
