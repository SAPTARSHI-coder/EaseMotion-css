# Parallax Avatar with Retro styling (#78857)

A responsive 3D parallax user avatar component featuring synthwave gradient borders, multi-layered `translateZ` depth separation, continuous neon lighting, and interactive hover transformations built using pure CSS.

## Features
- **Semantic Structure:** Accessible HTML markup (`<main>`, `<h1>`, `<h2>`, `<img>` with descriptive `alt` text).
- **3D Parallax Depth Layers:** Uses CSS `perspective`, `transform-style: preserve-3d`, and independent `translateZ` spatial offsets for the glow background, avatar frame, and status badge.
- **Retro Synthwave Styling:** Neon pink, cyan, and yellow variables combined with extruded retro typography.

## File Hierarchy
- `style.css` - Component variables, 3D perspective transforms, depth translations, and glowing color palettes.
- `demo.html` - Semantic DOM showcase structure.
- `README.md` - Implementation details and technical specifications.
