# Floating Hero Section - Neumorphism

A responsive Floating Hero Section featuring a soft neumorphic visual style,
floating UI elements, subtle depth, and smooth CSS-only interactions.

## Features

- Pure HTML and CSS implementation
- Neumorphic surface and layered shadows
- Floating decorative UI chips
- Animated orbital illustration
- Smooth hover and focus interactions
- Responsive layout for mobile, tablet, and desktop
- Accessible keyboard focus states
- `prefers-reduced-motion` support
- Zero external JavaScript dependencies
- No external libraries or frameworks
