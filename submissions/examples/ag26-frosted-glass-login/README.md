# Frosted Glass Login Form

A beautiful, modern login form using glassmorphism (frosted glass) effects.

## Preview
Open `demo.html` in your browser. You will see a login form that blurs the colorful gradient background behind it.

## Implementation
- Relies heavily on `backdrop-filter: blur(15px)` which blurs everything rendered behind the element.
- Semi-transparent rgba backgrounds (`rgba(255, 255, 255, 0.15)`) and subtle white borders give it the glass aesthetic.
- The inputs and buttons also share a lighter glass effect.
