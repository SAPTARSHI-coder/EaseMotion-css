# Morph-Glow Navbar (Fintech Dashboard)

## What does this do?

A modern fintech dashboard navigation bar featuring a smooth morph-glow hover effect, glassmorphism styling, and a responsive layout. Built entirely with HTML and CSS for lightweight dashboard interfaces.

---

## Features

- Morph-glow hover animation
- Glassmorphism navbar
- Responsive navigation layout
- Search bar
- Notification badge
- User profile section
- Pure HTML & CSS (No JavaScript)
- Supports `prefers-reduced-motion`

---
