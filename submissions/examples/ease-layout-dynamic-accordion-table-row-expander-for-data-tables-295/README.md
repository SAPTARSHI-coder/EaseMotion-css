# Dynamic Accordion Table Row Expander for Data Tables

### High-Contrast Accessibility Edition

A modern **Accordion Data Table** built with **HTML5** and **CSS3** featuring expandable table rows, high-contrast accessibility, responsive layout, and smooth interactions.

---

## ✨ Features

- Expandable table rows
- High-contrast accessible theme
- Responsive design
- Hover animations
- CSS Variables
- Keyboard-friendly structure
- `prefers-reduced-motion` support
- Pure HTML & CSS
