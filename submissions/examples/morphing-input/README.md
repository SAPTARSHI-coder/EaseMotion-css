# Morphing Input Field

A modern responsive input field featuring a smooth morphing animation and gradient styling.

## Features

- Gradient border on focus
- Smooth morphing border-radius animation
- Gradient glow effect
- Responsive design
- Accessible form label
- Mobile-friendly
- Pure HTML and CSS
- No JavaScript or external dependencies

## Preview

The input field starts with a subtle border.

When the user focuses on the input:

1. The border changes to a gradient.
2. The border radius morphs smoothly.
3. A soft gradient glow appears.
4. The input creates a modern interactive effect.

## Technologies

- HTML5
- CSS3
- CSS Variables
- CSS Animations
- CSS Transitions
- Flexbox

## Usage

Open `index.html` in any modern browser.
