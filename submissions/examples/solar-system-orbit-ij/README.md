\# Solar System Orbit Component



An astronomy-themed planetary motion component featuring orbiting celestial bodies, a pulsing central sun, and speed control layouts built for EaseMotion CSS.



\## Location

\- Directory: `submissions/examples/solar-system-orbit-ij/`



\## Files Included

\- `demo.html`: Interactive preview window showcasing the planetary orbit simulation.

\- `style.css`: Scoped orbital pathway designs and keyframe rules (`ease-orbit-spin`, `ease-sun-pulse`).

\- `README.md`: Documentation for the component submission.
