# 🌧️ Rain Memory

Rain Memory is an atmospheric interactive rainfall component where every raindrop leaves a temporary visual trace after reaching the ground.

The component uses a Canvas particle system to generate falling rain and expanding ground ripples.

Recent impacts remain visible for a short period, creating a visual memory of where the rain has recently landed.

---

## ✨ Features

- 🌧️ Continuous rainfall
- 💧 Individual raindrops
- 🌊 Ground impact ripples
- 🧠 Temporary impact memories
- 💨 Adjustable wind
- 🎚️ Rain intensity
- 📊 Impact counter
- 🖱️ Manual impact creation
- ⌨️ Keyboard shortcuts
- 🔄 Reset functionality
- 📱 Responsive design
