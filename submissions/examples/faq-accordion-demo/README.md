# FAQ Accordion Demo

## Description

This submission demonstrates a responsive FAQ Accordion built using EaseMotion CSS.

## Features

- Responsive layout
- Expand/collapse animation
- Five FAQ items
- Beginner-friendly example

## Files

```
faq-accordion-demo/
├── demo.html
├── style.css
└── README.md
```

## How to Run

Open `demo.html` in your browser.

## Expected Output

- Responsive FAQ section
- Smooth expand/collapse effect
- Easy to customize
