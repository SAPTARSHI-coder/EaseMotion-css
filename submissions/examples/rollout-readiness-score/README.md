# Rollout Readiness Score

Rollout Readiness Score is a responsive release-control panel that summarizes whether a deployment is ready to proceed. It combines smoke coverage, rollback status, and traffic guard readiness in compact review cards.

## Features

- Readiness score summary
- Good and review states
- Compact rollout check cards
- Responsive layout for mobile screens

## Files

- `demo.html` contains the rollout readiness markup.
- `style.css` contains the layout, cards, and state labels.
