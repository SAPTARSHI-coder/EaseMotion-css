# Cyberpunk Neon Border Button with Glowing Ripple Hover Effect 24

### Compact Mobile-First Edition

A modern cyberpunk-inspired neon border button built using pure HTML and CSS. The component features animated neon borders, glowing ripple hover effects, responsive mobile-first design, and accessibility enhancements.

---

## ✨ Features

- Cyberpunk neon UI
- Animated gradient border
- Glowing ripple hover effect
- Compact mobile-first layout
- Responsive design
- Keyboard accessible (`:focus-visible`)
- Smooth hover & active animations
- CSS variables for easy customization
- Pure HTML & CSS
- No external JavaScript required

3. Open `demo.html` in any modern browser.

No installation or build tools are required.
