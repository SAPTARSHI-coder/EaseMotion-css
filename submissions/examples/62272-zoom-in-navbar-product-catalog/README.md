# CSS Zoom-In Navbar for Product Catalog Layouts

## Overview

The **CSS Zoom-In Navbar for Product Catalog Layouts** is a modern navigation component created using pure HTML and CSS.

This component demonstrates smooth zoom entrance animation, glassmorphism styling, responsive product catalog layouts, and interactive hover effects without JavaScript.

It is developed for the EaseMotion CSS collection to showcase lightweight and reusable CSS animation techniques.

---

## Features

- Pure HTML and CSS implementation
- Smooth zoom-in entrance animation
- Product catalog navigation layout
- Glassmorphism UI design
- CSS-only hover interactions
- Responsive design
- CSS custom properties
- No JavaScript dependency
- prefers-reduced-motion accessibility support
