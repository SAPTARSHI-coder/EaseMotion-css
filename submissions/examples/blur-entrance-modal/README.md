# CSS Blur Entrance Modal

A responsive modal with a smooth blur entrance animation built entirely using HTML and CSS.

## Features

- Pure HTML & CSS
- Blur entrance animation
- Responsive layout
- No JavaScript required
- Accessible structure
- Supports `prefers-reduced-motion`

## Folder Structure

```
blur-entrance-modal/
├── demo.html
├── style.css
└── README.md
```

## Usage

Open `demo.html` in any modern browser.

## Customization

You can customize:

- Modal width
- Background colors
- Blur amount
- Animation duration
- Border radius
- Shadows
- Button styles

## Accessibility

- Responsive across devices
- Keyboard-friendly checkbox toggle
- Reduced motion support
- Semantic HTML structure
