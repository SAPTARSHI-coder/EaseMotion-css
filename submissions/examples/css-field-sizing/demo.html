CSS field-sizing

Auto-resizing form inputs without a single line of JavaScript. Inputs grow and shrink with your content — natively.

field-sizing: content field-sizing: fixed Chrome 123+ Edge 123+ Firefox 123+

How It Works

field-sizing: content tells the browser to size a form control based on its content rather than a fixed width. Inputs auto-expand as you type and shrink when you delete — no JS required.

Without field-sizing

Content overflows or gets hidden. JS needed for auto-resize.

With field-sizing: content

Input matches content width. Zero JS.

Best Practices

✓ Use min-width and max-width

Prevent fields from collapsing to zero or growing beyond layout bounds. Combine field-sizing: content with min/max constraints.

input {
  field-sizing: content;
  min-width: 8ch;
  max-width: 100%;
}

✓ Graceful fallback with @supports

Provide a reasonable fixed size attribute or width as fallback for older browsers.

input {
  width: 200px;        /* fallback */
  field-sizing: content;
  min-width: 8ch;
}

✓ Use ch units for min-width

ch units (character width) create natural minimums that match the input's font and content.

input[type="text"] {
  field-sizing: content;
  min-width: 10ch; /* ~10 characters */
}

⚠ Textareas need min-height

Textareas can shrink to zero height without a minimum. Set min-height and optionally max-height.

textarea {
  field-sizing: content;
  min-height: 2lh;
  max-height: 10lh;
}
