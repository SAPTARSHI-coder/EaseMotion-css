# Floating Stat Card — Minimalist

A clean and responsive floating statistic card built with
pure CSS for EaseMotion CSS.

Created for EaseMotion CSS issue #81453.

## Features

- Minimalist visual design
- Floating hover interaction
- Soft elevation and shadows
- Animated top accent line
- Animated mini bar chart
- Revenue statistic and trend indicator
- Responsive desktop, tablet and mobile layouts
- Semantic HTML
- Zero JavaScript dependencies
- `prefers-reduced-motion` support
