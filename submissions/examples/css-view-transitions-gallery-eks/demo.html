How It Works

1. Capture

When document.startViewTransition() is called, the browser takes a screenshot of the current page state.

2. Update

The DOM is updated (cards swap, content changes) while the old screenshot remains visible.

3. Animate

The browser cross-fades between the old and new states using ::view-transition-old and ::view-transition-new pseudo-elements.

4. Customize

Use view-transition-name and ::view-transition-group() to create per-element morphing animations.
