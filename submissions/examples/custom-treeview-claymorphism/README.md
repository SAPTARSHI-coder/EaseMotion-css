# Custom Treeview Menu — Claymorphism
A responsive, accessible treeview-style navigation menu built with pure HTML and CSS.

## Features
- Claymorphism-inspired neumorphic UI
- Pure HTML and CSS
- Zero JavaScript dependencies
- Native `<details>` and `<summary>` interaction
- Keyboard-accessible controls
- Visible `:focus-visible` states
- Responsive mobile, tablet, and desktop layout
- `prefers-reduced-motion` support
- EaseMotion-style CSS custom properties and design tokens
- Smooth expand/collapse and hover transitions
