# CSS Open Source Project Card (#70947)

GitHub-style open source repository project card with stars, forks, language indicator, and smooth interactive hover state in pure CSS.

## Features
- **GitHub UI Authenticity:** Features dark theme repository layout, language badge dot, star count, fork count, and license tags.
- **Pure CSS Interactive State:** Smooth hover lift dynamics and border accent highlighting without JavaScript.
- **Accessible Layout:** Uses semantic `<article>` containers, explicit `aria-label` tags for screen reader usability, and focused ring styling.
- **Responsive & Motion Sensitive:** Scales across viewports and respects `@media (prefers-reduced-motion: reduce)`.

## Structure
- `style.css` - Card styles, hover transitions, metadata layout, and responsive breakpoints.
- `demo.html` - Interactive demo displaying the open source repository project card.
