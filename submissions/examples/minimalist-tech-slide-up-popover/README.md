# Slide-Up Popover for Minimalist Tech Layouts

A lightweight, responsive slide-up popover built with pure HTML and CSS for minimalist technology interfaces.

## Features

- Pure HTML and CSS
- Uses the native HTML Popover API
- Smooth slide-up and fade-in animation
- Subtle scale transition for a polished entrance
- Responsive across desktop, tablet, and mobile
- Dark minimalist tech-inspired UI
- No JavaScript or external frameworks
- Accessible focus states
- `prefers-reduced-motion` support
- Customizable CSS variables
