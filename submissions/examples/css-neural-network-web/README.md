# CSS Neural Network Web

A fully animated CSS node-link visualization simulating data flowing through a neural network using complex animated `clip-path` masks, SVGs, and pulsating `box-shadow` glows.

## Features
- Pure CSS and HTML nodes and connections
- Rotating and scaling calculated via transform
- Simulated data packets flowing with `linear-gradient` animations
- `box-shadow` node pulsing
