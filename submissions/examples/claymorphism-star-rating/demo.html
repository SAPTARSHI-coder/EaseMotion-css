EaseMotion Component Variant

Animated Star Rating (Claymorphism Edition)

Note: Built with 100% pure CSS (Zero JS). Uses flex-direction: row-reverse combined with the general sibling combinator (~) to create a fully functioning rating system. The Claymorphism aesthetic is achieved through a combination of inset and drop shadows, creating a soft, tactile 3D effect. When a rating is selected, the buttons visually "press" down into the clay surface. Fully keyboard accessible and respects prefers-reduced-motion.
