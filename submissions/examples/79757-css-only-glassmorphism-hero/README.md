# CSS-only Hero Section with Glassmorphism

A modern, responsive hero section created using only HTML and CSS.

This component is designed for the EaseMotion CSS repository as part of GSSoC 2026.

## ✨ Features

- Pure HTML and CSS
- Modern glassmorphism UI
- Responsive layout
- Animated glass card
- Floating glass chips
- Gradient typography
- Background glow effects
- CSS grid background
- Responsive CTA buttons
- Responsive statistics section
- Smooth hover interactions
- No JavaScript
- No external dependencies
- `prefers-reduced-motion` support
