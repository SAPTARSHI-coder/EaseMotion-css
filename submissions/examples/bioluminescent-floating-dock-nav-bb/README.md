# Bioluminescent Floating Dock Navigation Component

## What does this do?
This component provides a sleek macOS-inspired floating navigation dock styled with bioluminescent cyan-to-purple background aura blurs, springy hover magnification, and glowing orb indicators.

## How is it used?
Include `style.css` in your webpage and insert the `.biolum-dock` navigation element at the bottom or top of your page.

## Why is it useful?
- Delivers an engaging, premium desktop-class floating navigation experience.
- High-performance spring cubic-bezier transitions for buttery smooth hover effects.
- Lightweight pure CSS component using standard HTML5 navigation tags.
