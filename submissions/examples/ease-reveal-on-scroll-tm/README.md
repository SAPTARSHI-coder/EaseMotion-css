# Reveal on Scroll Component

Add ease-reveal-on-scroll-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|--------|
| `--rs-accent` | `#6366f1` |
| `--rs-accent2` | `#ec4899` |
| `--rs-radius` | `12px` |
| `--rs-shadow` | `0 8px 32px rgba(0,0,0,.4)` |
| `--rs-trans` | `0.6s` |

## Note

IntersectionObserver adds `visible` class when elements enter viewport. CSS handles the animation.
