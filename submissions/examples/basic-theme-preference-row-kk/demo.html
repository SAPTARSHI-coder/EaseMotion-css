Basic Theme Preference Row

Simple theme rows for appearance settings.

A CSS-only row component for showing theme name, display mode, sync behavior, and active or suggested preference state.

LT
Light theme

Bright interface mode for daytime reading.

Light Manual Selected
DK
Dark theme

Low-glare interface mode for focused work.

Dark Manual Available
SY
System theme

Automatically follows the device appearance setting.

Auto System Suggested

HTML Usage

<article class="basic-theme-preference-row">
  <span class="theme-mark is-light" aria-hidden="true">LT</span>
  <div class="theme-copy">
    <strong>Light theme</strong>
    <p>Bright interface mode for daytime reading.</p>
  </div>
  <span class="theme-mode">Light</span>
  <span class="theme-sync">Manual</span>
  <span class="theme-state is-light">Selected</span>
</article>
