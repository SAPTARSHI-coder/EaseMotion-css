# Animated Underline Link

A lightweight link interaction with a smooth underline reveal from the left.

## What does it do?

The component provides:

- Animated underline reveal.
- Left-to-right motion.
- Hover interaction.
- Keyboard focus interaction.
- Subtle link lift.
- Animated directional indicator.
- Responsive layout.
- Reduced-motion support.
- No JavaScript.
- No external libraries or assets.

## How do I use it?

Add the `ease-underline-link` class to an anchor:

```html
<a class="ease-underline-link" href="#">
  <span>Explore the collection</span>
  <span aria-hidden="true">↗</span>
</a>
```
