# Staggered List Animation Component

Add ease-staggered-list-animation-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|--------|
| `--sla-accent` | `#6366f1` |
| `--sla-radius` | `10px` |
| `--sla-shadow` | `0 4px 20px rgba(0,0,0,.3)` |

## Technique

`nth-child` animation-delay creates staggered slide-in effect. Pure CSS keyframes.
