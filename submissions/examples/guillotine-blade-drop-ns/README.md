# Guillotine Paper Drop

## What does this do?
Renders a self-contained CSS-only `ease-guillotine-blade-drop` demo: Paper guillotine blade dropping a clean cut.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-guillotine-blade-drop`. No build step or JavaScript is required for the effect.

```html
<section class="ease-guillotine-blade-drop">
  <div class="ease-guillotine-blade-drop__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
