# Morphing Glassmorphic Step Progress Stepper Component

## What does this do?
This component renders an interactive step progress stepper widget with glassmorphism container styling, active node glow pulsing animations, and gradient connector bars.

## How is it used?
Include `style.css` in your project and copy the `.stepper-card` HTML structure into multi-step form workflows, checkout funnels, or wizard components.

## Why is it useful?
- Clear visual indicator for multi-step application user journeys.
- Hardware-accelerated CSS keyframe animations for active step pulse effects.
- Clean responsive structure with customizable step status states (`completed`, `active`).
