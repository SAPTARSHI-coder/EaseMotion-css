How It Works

1

Wrap the card in a containment context

The .ease-card-wrapper div declares container-type: inline-size and container-name: adaptCard. This makes the wrapper a "container" — the browser watches its inline (horizontal) size and uses it to evaluate @container rules.

2

The @container query fires — not a @media query

@container adaptCard (max-width: 500px) switches the card to a column layout when the container is narrow, not the viewport. The 1fr column is wide enough to keep the row layout; the 320px sidebar crosses the 500px threshold and automatically stacks vertically.

3

Identical HTML in both columns — no JavaScript needed

Both cards above use the exact same markup. The different visual outcomes come entirely from CSS container queries reacting to each wrapper's computed width. No JS, no state management, no conditional class names.
