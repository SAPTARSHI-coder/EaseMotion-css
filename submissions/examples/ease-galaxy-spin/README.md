# 🌌 Galaxy Spin – Spiral Galaxy Rotates with Interaction

> An interactive spiral galaxy component where stars rotate with cursor movement, featuring 4 color palettes (Cosmic, Sunset, Aurora, Galaxy), spin control (0-100%), and arm count control (2-6).

---

## 📖 Description

The **Galaxy Spin** component creates an immersive spiral galaxy experience where stars rotate with cursor interaction. Built with vanilla HTML, CSS, and JavaScript, it features 4 color palettes (Cosmic, Sunset, Aurora, Galaxy), spin control (0-100%), arm count control (2-6), and 400-600 stars with twinkling effects.

### 🎯 Core Features

- **Spiral galaxy** – stars rotate with cursor movement
- **4 color palettes** – Cosmic, Sunset, Aurora, Galaxy
- **Spin control** – adjust spin from 0-100%
- **Arm control** – adjust spiral arms from 2-6
- **Star system** – 400-600 stars with twinkling effects
- **Star counter** – tracks number of stars
- **Interactive controls** – sliders, keyboard shortcuts
- **Responsive design** – adapts to different screen sizes

### 🌌 Color Palettes

| Palette | Colors | Description |
|---------|--------|-------------|
| **Cosmic** | Blue/Purple/Pink/Green | Classic cosmic galaxy |
| **Sunset** | Red/Orange/Gold/Pink/Purple | Warm sunset galaxy |
| **Aurora** | Green/Blue/Purple/Pink/Gold | Aurora borealis galaxy |
| **Galaxy** | Indigo/Pink/Gold/Green | Deep galaxy colors |

### ⌨️ Interaction Options

| Method | Action |
|--------|--------|
| **Mouse** | Move cursor over display to spin galaxy |
| **Touch** | Drag on mobile to spin galaxy |
| **Sliders** | Adjust Spin (0-100%) and Arms (2-6) |
| **Keyboard** | `R` – Reset |

### ✨ Galaxy Experience

When interacting:
1. **Stars rotate** – spiral galaxy spins with cursor
2. **Spin applies** – controls rotation speed
3. **Arms apply** – controls number of spiral arms
4. **Stars twinkle** – individual star brightness varies
5. **Status updates** – shows interaction state

### 🛠️ Technologies Used

- **HTML5** – semantic structure with Canvas
- **CSS3** – gradients, backdrop-filter, transforms
- **JavaScript (ES6)** – Canvas API, requestAnimationFrame, particle system

### 🎨 Design Philosophy

This component embodies **EaseMotion CSS's animation-first philosophy** through:

- **Organic motion** – stars rotate with natural movement
- **Particle effects** – twinkling stars with glow
- **Visual feedback** – status updates, counter, controls
- **Cosmic atmosphere** – deep space colors and starfield
- **Human-readable classes** – `.galaxy-controls`, `.galaxy-text`

### 🔧 Customization Options

| Property | Location | Default |
|----------|----------|---------|
| Palettes | `palettes` array | 4 palettes |
| Spin range | `spinSlider` | 0-100% |
| Arms range | `armsSlider` | 2-6 |

| Star size | `size` | 0.5-3px |
