
---

## 🚀 Usage
1. Clone or copy the files into your project.
2. Open `demo.html` in your browser.
3. Click on accordion headers to expand/collapse sections.

---

## 🛠️ Customization
- **Colors** → Adjust text and background colors in `.accordion-header` and `.accordion-content`.
- **Animation speed** → Modify `transition: max-height 0.4s ease` for faster/slower expansion.
- **Shadow depth** → Change `box-shadow` values for stronger/weaker SaaS look.

---

## 📖 Accessibility
- Uses `role="region"` and `aria-label="SaaS modern accordion"`.
- Headers are `<button>` elements for keyboard accessibility.
