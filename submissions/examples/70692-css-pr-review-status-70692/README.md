# CSS PR Review Status

Issue #70692 demonstrates a pull request review panel with reviewer avatars and distinct review states.

## Features

- Pure HTML and vanilla CSS
- Approval progress bar
- Reviewer avatar initials
- Approved, changes-requested, and pending states
- Responsive layout
- Clear text status alongside visual indicators

The component uses semantic sections and text labels so state is not communicated by color alone. The reviewer list collapses naturally on narrow screens.

## Files

- `demo.html` — review status example
- `style.css` — status styling and responsive layout
- `README.md` — documentation
