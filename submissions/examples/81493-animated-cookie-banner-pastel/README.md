# Animated Cookie Banner - Pastel

A responsive animated cookie consent banner featuring a soft pastel
visual language, subtle motion, and modern interaction states.

## Features

- Pure HTML and CSS
- Pastel visual styling
- Animated banner entrance
- Floating cookie icon animation
- Smooth button hover interactions
- Animated close button
- Responsive desktop, tablet, and mobile layouts
- Accessible focus-visible states
- `prefers-reduced-motion` support
- Zero external JavaScript dependencies
- No external libraries
