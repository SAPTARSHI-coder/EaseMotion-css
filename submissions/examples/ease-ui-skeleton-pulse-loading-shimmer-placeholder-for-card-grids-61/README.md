# Skeleton Pulse Loading Shimmer Placeholder for Card Grids

### Minimalist Clean Edition

A clean and lightweight skeleton loading placeholder built using **HTML5** and **CSS3**. It features animated shimmer and pulse effects with a minimalist card layout suitable for dashboards, blogs, e-commerce, and loading states.

---

## ✨ Features

- Minimalist card design
- Animated shimmer effect
- Pulse loading animation
- Responsive card grid
- Smooth hover interaction
- CSS Variables
- `prefers-reduced-motion` support
- Pure HTML & CSS
