# 🪞 Memory Mirror

A surreal interactive mirror that temporarily remembers user interactions as glowing reflective fragments.

Memory Mirror transforms a normal reflective surface into a living interactive canvas. Every click creates a temporary "memory" that expands into a translucent shard, distorts the surrounding reflection, and gradually disappears.

Built as a lightweight, dependency-free HTML/CSS/JavaScript component.

---

## ✨ Features

- 🪞 Interactive reflective mirror
- ✦ Click-to-create memories
- 🌊 Expanding ripple animation
- 🔷 Irregular reflective fragments
- 💫 Multiple memories at once
- 🌫️ Subtle floating particles
- 🌟 Soft memory glow
- ⏳ Automatic memory fading
- 📊 Real-time memory counter
- 🖱️ Mouse interaction
- 📱 Touch interaction
- ⌨️ Keyboard shortcuts
- ↺ Clear memories
- 📱 Responsive layout
- ♿ Reduced-motion support
- 🚫 No external dependencies

## 🎨 What It Does

The component presents a dark reflective surface.

When the user interacts with the mirror, a memory is created at that position.

The memory follows a small lifecycle:

```text
Contact
   ↓
Ripple
   ↓
Fragment
   ↓
Reflection Distortion
   ↓
Fade
   ↓
Forgotten
