# Parallax Navbar with Minimalist Styling

A responsive minimalist navigation component with a layered parallax-inspired visual design, built entirely with HTML and CSS.

Created for EaseMotion CSS as part of GSSoC 2026.

## ✨ Features

- Pure HTML and CSS
- Fully responsive navbar
- Minimalist visual design
- Glass-style navigation surface
- Layered parallax-inspired hero visual
- CSS 3D transforms
- Smooth hover interactions
- Responsive navigation layout
- Animated background elements
- Accessible keyboard focus states
- Reduced-motion support
- No JavaScript
- No external dependencies
