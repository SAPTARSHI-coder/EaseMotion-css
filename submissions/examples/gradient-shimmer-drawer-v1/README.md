# ✨ CSS Drawer: Gradient Shimmer Variation

A futuristic responsive drawer and sidebar component featuring an
animated Gradient Shimmer visual style.

The component is built entirely with HTML and vanilla CSS and does
not require JavaScript or external dependencies.

## Features

- Pure HTML and CSS
- Gradient Shimmer styling
- CSS-only drawer interaction
- Responsive sidebar
- Mobile-friendly navigation
- Smooth drawer transitions
- Animated shimmer highlights
- Glowing gradient effects
- Dark-mode-friendly design
- Keyboard-accessible controls
- Visible interactive states
- `prefers-reduced-motion` support
- No external dependencies
