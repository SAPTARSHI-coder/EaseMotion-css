# Dynamic Badge with Pastel styling (#78858)

A responsive set of soft pastel status badges featuring subtle pulse animations, spring hover states, and WCAG-compliant color contrast using pure CSS.

## Features
- **Accessible & Semantic Markup:** Uses semantic structure with `aria-hidden` decorative pulse indicators and explicit status regions.
- **Dynamic Pulse Animation:** Integrated CSS `@keyframes` pulse effect for real-time status indicators.
- **Soft Pastel Aesthetics:** High-contrast pastel color tokens (Lavender, Mint, Peach, Sky) optimized for clean UI/UX designs.

## File Hierarchy
- `style.css` - Custom color tokens, badge shapes, pulse keyframe animations, and hover transitions.
- `demo.html` - Semantic HTML showcase structure.
- `README.md` - Implementation details and technical specifications.
