# CSS Hotel Room Card

A responsive hotel room card featuring a room visual,
amenities, rating, price, and reservation CTA.

## Features

- Pure HTML and CSS
- Responsive layout
- Hotel room visual without external images
- Amenities list
- Rating badge
- Price display
- Reservation CTA
- Hover interaction
- Keyboard focus state
- Reduced-motion support
- No JavaScript required

## Accessibility

The component uses semantic article content, descriptive
labels, accessible link text, and visible keyboard focus.

Decorative room visuals are not exposed as interactive content.

## Customization

Update the CSS custom properties and content in `demo.html`
to match different hotel brands or room types.
