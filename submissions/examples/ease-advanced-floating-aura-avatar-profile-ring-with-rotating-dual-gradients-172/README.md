# Floating Aura Avatar Profile Ring with Rotating Dual Gradients

### Neumorphic Finish

A premium **Floating Aura Avatar Profile Ring** built using **HTML5** and **CSS3** featuring rotating dual gradient rings, neumorphic styling, responsive design, and accessibility-friendly interactions.

---

## ✨ Features

- Rotating dual gradient aura rings
- Neumorphic UI
- Floating avatar profile
- Responsive mobile-first layout
- Smooth hover animations
- CSS Variables
- Keyboard accessibility
- prefers-reduced-motion support
- Pure HTML & CSS
