# CSS Solar Flare Tooltip

Issue #73498 demonstrates an accessible tooltip with a warm solar-flare visual treatment.

## Features

- Hover and keyboard focus states
- Solar gradient glow
- Tooltip semantics
- Responsive presentation
- Reduced-motion support
- Pure HTML and vanilla CSS

## Usage

Open `demo.html` and hover or focus the button. The tooltip appears beside the trigger.

## Accessibility

The trigger references the tooltip with `aria-describedby`, and the same interaction is available through keyboard focus.

## Files

- `demo.html` — tooltip markup
- `style.css` — visual treatment and transitions
- `README.md` — documentation
