# CSS Skew-Active Badge for Product Catalog Layouts

A modern **Skew-Active Badge** component built using pure HTML5 and CSS3 for product catalog layouts. The component showcases interactive skewed badges with smooth hover animations, responsive product cards, and accessibility support.

## Features

* Pure HTML5 & CSS3
* Skew-Active badge animation
* Interactive hover effects
* Multiple badge variants (New, Sale, Premium, Limited)
* Glassmorphism product cards
* Smooth CSS transforms & keyframe animations
* Responsive desktop, tablet, and mobile layout
* CSS Custom Properties
* No JavaScript required
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in a modern browser.
2. Hover over product cards to activate the skew badge animation.
3. Customize badge colors using the CSS variables in `:root`.
4. Integrate the component into any product catalog or e-commerce interface.
