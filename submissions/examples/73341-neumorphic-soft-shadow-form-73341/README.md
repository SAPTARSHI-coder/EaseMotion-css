# CSS Neumorphic Soft Shadow Form

Issue #73341 demonstrates a tactile form using raised and inset neumorphic shadows.

## Features

- Raised surface treatment
- Inset form controls
- Pressed button state
- Responsive layout
- Keyboard focus styles
- Reduced-motion support

## Accessibility

All controls are labeled and keyboard focus remains visible. Motion is limited to small interaction transitions.

## Files

- `demo.html` — semantic form
- `style.css` — neumorphic surface and control styling
- `README.md` — documentation
