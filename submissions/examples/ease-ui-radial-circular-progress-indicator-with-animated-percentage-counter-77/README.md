# Radial Circular Progress Indicator with Animated Percentage Counter (Minimalist Clean Edition)

A clean and lightweight radial progress indicator built using HTML, CSS and JavaScript. It features an animated circular progress ring, percentage counter, responsive layout, and minimalist design.

## Features

- Animated circular progress
- Percentage counter
- Minimal UI
- Responsive layout
- Pure HTML, CSS & JavaScript
- Easy customization

## Folder Structure

```
ease-ui-radial-circular-progress-indicator-with-animated-percentage-counter-77/
├── demo.html
├── style.css
├── script.js
└── README.md
```

## Usage

Open `demo.html` in your browser.

Adjust progress value and colors inside the CSS and JavaScript.
