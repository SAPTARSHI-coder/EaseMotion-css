# Interactive Accordion with Pastel Styling (#78612)

A clean pastel-themed interactive accordion component featuring zero-JavaScript state toggling, smooth max-height transitions, and soft blue accent highlights.

## Features
- **Zero JavaScript:** Pure CSS state management utilizing hidden checkbox inputs and adjacent sibling selectors (`+`).
- **Pastel Aesthetics:** Soft white container framing paired with gentle sky blue active headers and subtle borders.
- **Fully Responsive:** Fluid flexbox card layout scaling cleanly across all mobile and desktop viewports.

## File Hierarchy
- `style.css` - Custom properties, checkbox selector rules, accordion transition curves, and media queries.
- `demo.html` - Semantic markup demonstrating accordion item integration with accessible labels.
- `README.md` - Technical specification and architecture overview.
