# Interactive Rating — Glassmorphism

A responsive interactive rating component featuring a
modern glassmorphism interface, built with pure HTML and
CSS for EaseMotion CSS issue #81437.

## Features

- Glassmorphism visual design
- Interactive 1–5 star rating
- Smooth hover transitions
- Selected rating state
- Animated star interaction
- Frosted glass effect
- Backdrop blur
- Decorative ambient glow
- Keyboard focus support
- Responsive desktop, tablet and mobile layouts
- Reduced-motion support
- No JavaScript dependencies
