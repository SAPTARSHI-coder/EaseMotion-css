# ease-bounce-popover-bh

Pure CSS bounce-pulse popover for fintech dashboards.

## Features
- Bounce pulse hover effect
- Popover variants
- Responsive design
- Accessibility support

## Usage
```html
<div class="ease-popover ease-popover-bounce">Content</div>
```

## CSS Classes
- `.ease-popover` - Base popover
- `.ease-popover-bounce` - Bounce pulse effect
