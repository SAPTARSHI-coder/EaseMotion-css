# 3D Button with Neon Styling

A responsive 3D button component that combines layered depth,
neon lighting, glow effects, and tactile interaction using only
HTML and CSS.

## Features

- Fully responsive
- HTML/CSS only
- No JavaScript
- 3D layered button depth
- Neon cyan glow
- Hover and focus interactions
- Pressed/active state
- Animated status indicator
- Arrow movement interaction
- Keyboard-accessible focus state
- Reduced-motion support
- No external dependencies

## Interaction

The button provides multiple visual states:

- Default: layered 3D neon appearance
- Hover: increased glow and elevation
- Focus: accessible neon outline
- Active: tactile pressed-down effect

## Files

- `demo.html`
- `style.css`

## Technologies

- HTML5
- CSS3

## Accessibility

The component includes:

- Semantic anchor element
- Visible keyboard focus state
- Responsive text sizing
- `prefers-reduced-motion` support
