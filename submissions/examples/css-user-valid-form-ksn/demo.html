Why :user-valid?

  • No JS needed — pure CSS validation feedback
  • User-first — no red errors on page load like :invalid does
  • Instant feedback — validates as the user types, not just on submit
  • Icon indicators — inline status icons via ::after pseudo-elements
  • Accessible — respects prefers-reduced-motion, forced-colors, prefers-contrast
  • Dark mode — auto-adapts via prefers-color-scheme
  • Print-ready — clean print styles included
