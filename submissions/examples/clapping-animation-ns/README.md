# CSS Clapping Animation (#71054)

A pure CSS keyframe animation showcasing two hands rhythmically clapping together with impact visual feedback.

## Features
- Pure CSS keyframe implementation requiring zero JavaScript.
- Uses standard CSS transforms (`rotate`, `translate3d`, `scaleX`) for optimal 60fps hardware acceleration.
- Includes impact spark visual effects synchronized with the collision point.
- Fully accessible with proper `aria-hidden` tags on visual elements and support for `prefers-reduced-motion`.
