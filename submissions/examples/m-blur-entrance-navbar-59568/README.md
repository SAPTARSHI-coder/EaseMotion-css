# CSS Blur-Entrance Navbar for SaaS Showcase Layouts

A modern **Blur-Entrance Navbar** built using pure HTML and CSS. The navigation bar smoothly fades in from a blurred state while using a clean glassmorphism design suitable for SaaS dashboards, landing pages, and admin interfaces.

## ✨ Features

- Pure HTML5 & CSS3
- Blur entrance animation
- Glassmorphism navigation bar
- Responsive SaaS layout
- Gradient CTA button
- CSS Custom Properties
- `prefers-reduced-motion` support
- No JavaScript required
