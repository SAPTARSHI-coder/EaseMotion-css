# Hover Card — Material Design

A responsive hover card component inspired by Material Design,
featuring elevation, layered shadows, smooth hover motion, and
accessible interaction states.

Implemented for EaseMotion CSS issue #79743.

## Features

- Material Design inspired visual system
- Hover elevation effect
- Layered card shadows
- Smooth transform transitions
- Interactive media area
- Material-style badges
- Responsive two-column and single-column layouts
- Keyboard focus support
- `prefers-reduced-motion` support
- Semantic HTML structure
- Pure HTML and CSS
- Zero JavaScript dependencies
