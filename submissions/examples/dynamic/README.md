# Dynamic Search Bar Input with Gradient Glow Styling

An advanced, sleek search input component featuring smooth glassmorphism design parameters, multi-color dynamic gradient borders on focus, and zero JavaScript dependencies.

## Features
* **Zero JavaScript:** Built completely using standard CSS selectors (`:focus-within`) and semantic HTML5 structural layout blocks.
* **Gradient Glow Aesthetics:** Employs a crisp multi-stop linear gradient stroke that reveals itself when active, backed by deep atmospheric box-shadowing.
* **Responsive Multi-Device Layout:** Adapts smoothly across mobile, tablet, and widescreen desktop interfaces, with dynamic hiding of helper keyboard badges on smaller screens.
* **Accessibility Compliant:** Fully respects user motion preferences via built-in `prefers-reduced-motion` media query fallbacks.

## Usage
Include `style.css` in your project folder and implement the search wrapper elements as defined within `demo.html`.
