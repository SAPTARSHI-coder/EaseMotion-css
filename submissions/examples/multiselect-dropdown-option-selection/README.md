# Multi-Select Dropdown Option Selection Array

## Overview

This submission adds Vitest unit-test coverage for the selection-array
behavior of a multi-select dropdown.

## Covered Cases

- Adding an option
- Removing a selected option
- Selecting multiple options
- Removing the final selected option
- Preventing duplicate selections
- Repeated toggle operations
- Preserving array immutability
- Invalid option values
- Invalid selection arrays
- Preserving selection order

## Files

- `demo.html` — standalone multi-select dropdown demo
- `style.css` — responsive styling
- `multiselect.test.js` — Vitest unit tests
