# Glass Effect Card Component

Add ease-card-glass-effect-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|---------|
| `--gfe-accent` | `#818cf8` |
| `--gfe-radius` | `16px` |
| `--gfe-shadow` | `0 8px 40px rgba(0,0,0,.3)` |

## Technique

`backdrop-filter: blur(12px)` on semi-transparent card background. Works best over colorful backgrounds.
