# CSS Blur-Entrance Stepper for Responsive Dashboard Layouts

A modern **Blur-Entrance Stepper** component created using only **HTML5 and CSS3**.

This example demonstrates a smooth step-by-step dashboard timeline with blur entrance animations, glassmorphism styling, responsive layout support, and accessibility features without JavaScript.

---

## ✨ Features

- 🌫️ Blur entrance animation
- 📌 Step-based dashboard layout
- 💡 Glow hover effects
- 🎨 Gradient step indicators
- ⚡ Pure CSS implementation
- 📱 Responsive design
- 🎯 CSS Custom Properties
- ♿ `prefers-reduced-motion` support
- 🚫 Zero JavaScript dependency

## 🚀 Usage

1. Open `demo.html` in any modern browser.
2. View the animated stepper component.
3. Hover over steps for interactive glow effects.
4. Customize colors and animations using CSS variables.
