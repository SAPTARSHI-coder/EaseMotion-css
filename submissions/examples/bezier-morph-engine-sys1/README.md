# Dynamic Bezier Morphing Keyframe Engine Extension

## Overview
This submission demonstrates custom SVG and CSS polygon `clip-path` morphing driven by EaseMotion custom cubic-bezier timing curves.

## Structure
- `demo.html` — Interactive demonstration of multi-point vector morphing
- `style.css` — Morphing keyframes and responsive styling
- `README.md` — Technical documentation

## Usage
Link `easemotion.min.css` and `style.css`, then apply `.morph-shape` and state classes to animate shape transformations dynamically.
