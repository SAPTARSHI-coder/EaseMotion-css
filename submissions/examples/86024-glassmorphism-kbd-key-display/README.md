# Glassmorphism Kbd Key Display

A glassmorphism-style keyboard shortcut display using semantic HTML
`<kbd>` elements.

## Features

- Glassmorphism visual design
- Semantic keyboard markup
- Responsive layout
- CSS custom property configuration
- Accessible shortcut labels
- Reduced-motion support

## HTML Usage

```html
<div class="shortcut">
  <span>Save</span>

  <span class="keys">
    <kbd>Ctrl</kbd>
    <kbd>S</kbd>
  </span>
</div>
