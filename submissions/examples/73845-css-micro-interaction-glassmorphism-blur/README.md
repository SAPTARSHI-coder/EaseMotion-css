# CSS Micro-interaction: Glassmorphism Blur

## Overview

A frosted glass control using translucent backgrounds, backdrop blur, highlights, and a small hover elevation.

## Features

- Glassmorphism surface
- Backdrop blur
- Soft highlight layer
- Hover elevation
- Native button semantics
- Visible keyboard focus
- Responsive layout
- Reduced-motion support

## Files

- `demo.html` — semantic control and content
- `style.css` — glass surface and interaction states
- `README.md` — documentation

## Accessibility

The action is a native button with a visible focus ring. Decorative effects are visual only, and reduced-motion preferences minimize transitions.
