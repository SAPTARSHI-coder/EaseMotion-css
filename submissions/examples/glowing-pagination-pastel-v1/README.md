# Glowing Pagination with Pastel Styling

A responsive pagination component featuring soft pastel colors, glowing hover effects, and a clean glass-inspired interface built entirely with HTML and CSS.

## Features

- Pure HTML & CSS
- Responsive design
- Pastel color palette
- Soft glowing hover effects
- Active page indicator
- Previous & Next navigation
- Accessible navigation using `<nav>`
- No JavaScript required

## Folder Structure

```
glowing-pagination-pastel/
├── demo.html
├── style.css
└── README.md
```

## Technologies

- HTML5
- CSS3
- Flexbox
- CSS Transitions
- Responsive Design

## Purpose

A lightweight pastel-themed pagination component suitable for blogs, portfolios, documentation sites, dashboards, and modern web applications while following the EaseMotion CSS philosophy.
