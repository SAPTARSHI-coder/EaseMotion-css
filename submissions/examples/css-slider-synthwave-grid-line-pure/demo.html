Pure CSS Slider: Synthwave

A retro-futuristic, JavaScript-free carousel utilizing the CSS radio button hack. Features a 3D animated perspective grid and glowing neon borders.

CYBER_SPACE

The background utilizes a pseudo-3D CSS trick. A standard `linear-gradient` grid is drawn, then rotated 80 degrees on the X-axis within a perspective container.

NEON_GLOW

Extensive use of `box-shadow` and `text-shadow` layers (both inset and outset) are applied to buttons and text to create a realistic, multi-layered neon glow effect.

HYPER_DRIVE

When transitioning, slides use an elastic `cubic-bezier` timing function to mimic the sudden acceleration and deceleration of a retro-arcade racing game.
