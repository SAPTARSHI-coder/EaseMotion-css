# 📡 Echo Button – Sends Out Concentric Rings Like Sonar

> A sonar-inspired button that sends out concentric rings like sonar pulses on hover, creating a rhythmic, scanning effect.

---

## 📖 Description

The **Echo Button** is a sonar-inspired UI component that sends out concentric rings like sonar pulses on hover. Eight rings pulse outward from the button with staggered delays, creating a rhythmic, scanning effect that mimics sonar or radar technology. The center dot pulses in sync, completing the sonar experience.

The component uses CSS animations with `transform` and `keyframes` to create the expanding rings. Each ring has a unique size, opacity, and border width, creating a realistic sonar effect. The rings pulse outward with a spring-like motion, and the center dot pulses rhythmically.

Perfect for tech-themed interfaces, radar applications, gaming websites, and any application where you want to create a scanning, futuristic effect. The Echo Button transforms a simple hover into a rhythmic, technological experience.
