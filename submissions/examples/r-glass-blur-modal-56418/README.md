# CSS Glass-Blur Modal

A modern **Glass-Blur Modal** built using pure HTML5 and CSS3 for Gaming Hub layouts. It uses a frosted-glass effect with backdrop blur, subtle glow, and smooth transitions while remaining lightweight, responsive, and accessible.

---

## ✨ Features

- Pure HTML5 & CSS3
- Glassmorphism design
- Smooth fade & lift animation
- Responsive layout
- CSS Custom Properties
- Frosted glass effect with backdrop blur
- Keyboard-accessible checkbox toggle
- `prefers-reduced-motion` support
- No JavaScript required

## 🚀 Usage

1. Copy the component into your project.
2. Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

3. Open `demo.html` in a modern browser.
