# Ease Progress Pill

## What does this do?

A rounded progress indicator with a smooth animated fill, ideal for displaying upload progress, onboarding completion, or task status.

---

## How is it used?

Open `demo.html` in any modern browser.

Example:

```html
<div class="progress-pill">
    <div class="progress-fill"></div>
</div>
```

### Features

- Rounded progress bar
- Smooth animated fill
- Percentage display
- Responsive layout
- Lightweight and reusable

---

## Why is it useful?

Progress indicators are commonly used for uploads, downloads, onboarding flows, and task completion. This component provides a clean, reusable, animation-first progress bar that aligns with the EaseMotion CSS philosophy.
