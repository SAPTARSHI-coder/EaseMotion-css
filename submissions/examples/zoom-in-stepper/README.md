# CSS Zoom-In Stepper

A responsive CSS-only Zoom-In Stepper designed for Gaming Hub dashboard interfaces.

## Features

- Pure HTML and CSS
- No JavaScript required
- Zoom-in animation for the active step
- Interactive hover effects
- Gaming dashboard inspired design
- Responsive layout
- Progress indicator
- CSS custom properties
- `prefers-reduced-motion` accessibility support
