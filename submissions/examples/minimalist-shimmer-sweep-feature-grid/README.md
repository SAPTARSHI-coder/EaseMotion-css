# CSS Shimmer-Sweep Feature Grid

A modern **CSS Shimmer-Sweep Feature Grid** built entirely with **HTML5** and **CSS3**. This showcase demonstrates a responsive grid of feature cards with a smooth shimmer-sweep hover animation, minimalist tech styling, and accessibility support—without requiring JavaScript.

---

## ✨ Features

- 🚀 Pure HTML5 & CSS3
- ✨ Shimmer-sweep hover animation
- 🎴 Responsive feature card grid
- 💻 Minimalist tech-inspired interface
- 📱 Fully responsive layout
- ♿ Keyboard-accessible focus styles
- 🎨 Easy customization using CSS Custom Properties
- 🌙 Supports `prefers-reduced-motion`
- ⚙️ No JavaScript or external dependencies

## 🚀 Usage

1. Open `demo.html` in a modern web browser.
2. Hover over or focus on a feature card to view the shimmer-sweep effect.
3. Customize colors, spacing, and typography using the CSS custom properties.

---

## 🎨 CSS Custom Properties

| Variable | Description |
|----------|-------------|
| `--bg` | Page background color |
| `--surface` | Card background |
| `--primary` | Primary accent color |
| `--secondary` | Secondary accent color |
| `--text` | Primary text color |
| `--muted` | Secondary text color |
| `--border` | Card border color |
| `--radius` | Card border radius |
| `--shadow` | Card shadow |
| `--transition` | Transition timing |

Example:

```css
:root{
    --primary:#2563eb;
    --secondary:#38bdf8;
}
```
