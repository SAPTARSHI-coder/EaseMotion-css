# Wave Text Animation

A lightweight, fully responsive, zero-dependency CSS wave text animation built using custom CSS properties (`--i`) and fluid typography.

## 🌟 Features

- **Pure CSS**: No JavaScript overhead or extra libraries required.
- **Fluid & Mobile-Responsive**: Uses CSS `clamp()` and flexbox wrapping to adjust smoothly from small mobile screens to ultra-wide displays.
- **Customizable**: Control wave height, duration, and delay easily using CSS variables.
- **Accessibility Friendly**: Includes `aria-label` tags for screen readers and respects `prefers-reduced-motion`.
