# Grain Elevator Bucket

## What does this do?
Renders a self-contained CSS-only `ease-grain-elevator-bucket` demo: Grain elevator buckets lifting cereal upward.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-grain-elevator-bucket`. No build step or JavaScript is required for the effect.

```html
<section class="ease-grain-elevator-bucket">
  <div class="ease-grain-elevator-bucket__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
