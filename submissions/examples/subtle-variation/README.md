## 🚀 Usage
1. Clone or copy the files into your project.
2. Open `index.html` in your browser.
3. Hover over the button to see the subtle elevate animation.

---

## 🛠️ Customization
- **Elevation distance** → Adjust `translateY(-6px)` for stronger/weaker lift.
- **Shadow depth** → Modify `box-shadow` values for different elevation styles.
- **Transition speed** → Change `transition: 0.3s` for faster/slower effect.
- **Button size** → Adjust padding and font-size in `.elevate-btn`.

---

## 📖 Accessibility
- Includes `:focus` state for keyboard navigation.
- Smooth motion avoids harsh flicker.
