# Glowing Hero Section - Gradient Glow

A responsive hero section featuring a luminous gradient-glow
visual style with animated rings, glowing surfaces, floating
information cards, and a responsive layout.

## Features

- Pure HTML and CSS
- Gradient glow visual system
- Animated glowing central element
- Rotating decorative rings
- Floating information cards
- Animated background glow orbs
- Subtle grid background
- Gradient text treatment
- Smooth hover interactions
- Responsive desktop, tablet, and mobile layouts
- Keyboard focus states
- `prefers-reduced-motion` support
- No JavaScript dependencies
- No external libraries
