# CSS Page Flip Animation (#71052)

A 3D realistic page curl and flip animation implemented using pure CSS 3D transforms (`perspective`, `transform-origin`, and `preserve-3d`).

## Features
- Pure CSS implementation with zero JavaScript required.
- Interactive page flip triggers on `:hover` and keyboard `:focus-visible` state.
- Accessible ARIA labels and structure for screen reader accessibility.
- Includes `prefers-reduced-motion` compliance to respect accessibility settings.
