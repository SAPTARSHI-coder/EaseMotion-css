# Animated Travel Booking / Destination Showcase

A stunning **Travel Booking Interface** built with **EaseMotion CSS**. Features destination cards with parallax zoom, hero search bar, special offer countdown, experience listings, and interactive booking elements.

## ✨ Features

- **🔍 Hero Search Bar**: Multi-field search with destination, dates, and guests
- **🏝️ Destination Cards**: Image hover zoom, overlay info, and booking buttons
- **🏷️ Destination Badges**: Trending, Romantic, Cultural badges
- **⏰ Flash Sale Banner**: Countdown timer with price comparison
- **🎯 Experience Listings**: Activity cards with duration and ratings
- **❤️ Favorite Toggle**: Heart button with hover color change
- **🎬 Staggered Entrance**: All sections slide up sequentially
- **📱 Fully Responsive**: 3-column → 2-column → 1-column layout

## 🧩 EaseMotion Classes Used

| Class | Purpose |
|-------|---------|
| `ease-fade-in` | Fades in the main page and footer |
| `ease-slide-up` | Slides sections up on entrance |
| `ease-delay-100` to `ease-delay-600` | Creates cascading staggered sequence |
| `ease-card` | Base card structure |
| `ease-hover-lift` | Lift effect on cards |
| `ease-hover-grow` | Scale effect on buttons |
| `ease-center` | Centers search button icon |
| `ease-grid` + `ease-grid-cols-*` | Responsive grid layouts |
| `ease-gap-4` | Spacing between grid items |
| `ease-btn` + `ease-btn-primary` | Styled CTA buttons |

## 🚀 How to Use

1. Open `demo.html` in any modern browser
2. Watch all sections slide in with staggered animations
3. Hover over destination cards to see image zoom and lift effects
4. Hover over favorite buttons to see color change
5. Observe the flash sale countdown timer styling
6. Hover over experience cards to see image zoom
7. Resize to mobile to see responsive layout

## 🎨 Design Highlights

- **Elegant Typography**: Playfair Display for headings, Plus Jakarta Sans for body
- **Image Hover Zoom**: Destination and experience images scale on hover
- **Gradient Overlays**: Dark gradient on destination images for text readability
- **Countdown Timer**: Styled timer units for flash sale urgency
- **Multiple Badge Types**: Trending, Romantic, Cultural badges

## 🛠️ Technologies Used

- HTML5
