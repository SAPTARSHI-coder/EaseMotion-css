# Retro Arcade Pixel Slider

A smooth and responsive **Retro Arcade Pixel Slider** built using pure HTML and Vanilla CSS.

## ✨ Features

- 🎮 Retro arcade-inspired pixel styling
- ⚡ Pure HTML and CSS
- 🚫 No JavaScript required
- 📱 Responsive design
- 🎨 Neon arcade visual effects
- 🖱️ Smooth hover and focus interactions
- 🧲 CSS scroll snapping
- 🌙 Dark-mode friendly design
- ♿ Accessible labels and keyboard focus states
- ♿ Respects `prefers-reduced-motion`
- 🚀 Lightweight and performant
