# Animated Chat Widget Submission

## 1. What does this do?
It provides a modern, animated chat/messenger widget with smooth open/close transitions, animated message bubbles, typing indicator, and real-time messaging simulation. Perfect for customer support, live chat, and community platforms.

## 2. How is it used?
Add the chat toggle button and chat window to your page. The component automatically handles open/close animations, message sending/receiving, and typing indicators. JavaScript manages the chat logic and message rendering.

## 3. Why is it useful?
- Essential component for customer support and live chat
- Smooth open/close animations with scale and fade effects
- Animated message bubbles with staggered entrance
- Typing indicator with bouncing dots animation
- Real-time messaging simulation with bot responses
- Avatar and timestamp support for each message
- Notification badge for unread messages
- Fully accessible with ARIA labels
- Includes `prefers-reduced-motion` support for accessibility
- Mobile-responsive design
- Easy to customize colors and styles
- Maintainer can easily standardize this as `.ease-chat-[YOUR_INITIALS]` in the core library.
