# Interactive Avatar - Dark Mode

A responsive interactive avatar component built using pure HTML and
CSS with a modern dark-mode visual style.

## ✨ Features

- Fully responsive
- Dark mode interface
- Interactive avatar hover effect
- Online status indicator
- Profile information card
- Interactive profile action
- Avatar selector buttons
- Smooth CSS transitions
- Glowing accent effects
- Keyboard focus states
- Reduced-motion support
- No JavaScript dependency
