# CSS Float-Drift Badge

A lightweight, pure CSS Float-Drift Badge designed for product catalog layouts.

The component adds a subtle floating and drifting motion to product badges such as:

- Sale
- New
- Featured
- Limited
- Promotional labels

It is implemented entirely with HTML and CSS and requires no JavaScript or external libraries.

---

## Features

- Pure HTML and CSS
- Smooth floating and drifting animation
- No JavaScript required
- Responsive product catalog layout
- CSS custom properties for easy customization
- Multiple badge variants
- GPU-friendly `transform` animation
- Accessible `prefers-reduced-motion` support
- Works as a standalone example
- Opens directly in a browser without a server
