# CSS CTA Pulse Button

A responsive call-to-action button with a pure CSS pulsing ring effect.

## Features

- Pure HTML and CSS
- No JavaScript
- Animated pulse rings
- Hover lift interaction
- Arrow hover animation
- Keyboard accessible
- Visible focus state
- Responsive design
- Reduced-motion support

## Usage

```html
<a class="cta-pulse" href="#get-started">
  <span>Get Started</span>
  <span class="arrow" aria-hidden="true">→</span>
</a>
