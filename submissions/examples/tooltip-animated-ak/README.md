# tooltip-animated-ak

Pure CSS animated spring tooltip bubble with arrow — no JavaScript required.

## How to use

Set `data-tooltip` on target element:

```html
<div class="ease-tooltip-target" data-tooltip="Tooltip message here">
  Hover Target
</div>

<!-- Bottom Direction Variant -->
<div class="ease-tooltip-target ease-tooltip-target--bottom" data-tooltip="Message">
  Hover Target
</div>
