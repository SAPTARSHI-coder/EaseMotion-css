# Magnetic Floating Action Navigation Bar with Fluid Hover Indicators

### Vibrant Gradient Version

A modern **Magnetic Floating Action Navigation Bar** built with **HTML5** and **CSS3**. The component features vibrant gradients, glassmorphism, magnetic hover interactions, fluid hover indicators, and a fully responsive floating navigation experience.

---

## ✨ Features

- Vibrant gradient navigation bar
- Magnetic hover interactions
- Fluid hover indicators
- Glassmorphism floating container
- Smooth icon animations
- Responsive design
- CSS Variables for easy customization
- Keyboard accessibility
- `prefers-reduced-motion` support
- Pure HTML & CSS implementation

## 🚀 Usage

1. Open the component folder.
2. Keep `demo.html` and `style.css` together.
3. Open `demo.html` in any modern browser.
4. Hover over the navigation items to experience the magnetic floating effects and fluid indicators.

No build tools or external libraries are required.
