# CSS Collapsible Code Panel

A responsive collapsible code preview panel built with HTML and pure CSS.

## Features

- Pure CSS collapse/expand interaction
- Native accessible `<details>` and `<summary>` elements
- Smooth opening animation
- Responsive layout
- Hover interaction
- Keyboard accessible
- Reduced-motion support
- No JavaScript dependencies

## Files

- `demo.html` – Component demonstration
- `style.css` – Component styling

## Usage

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
