Understanding CSS Scroll-Driven Animations

Traditionally, tracking scroll percentage required listening to window scroll events in JavaScript, causing main thread overhead and potential layout thrashing. Modern CSS introduces the animation-timeline: scroll() feature, delegating all animation progress computation directly to the compositor thread.

.ease-scroll-progress-top { position: fixed; top: 0; left: 0; width: 100%; height: var(--ease-scroll-progress-height, 4px); transform-origin: left center; animation: ease-scroll-fill linear; animation-timeline: scroll(root block); }

How EaseMotion Custom Properties Work

All styles exposed in this showcase utilize --ease- prefixed CSS variables. Developers can easily customize the color palette, bar height, gradient colors, and z-index offsets directly at :root or on individual component instances without editing the raw CSS.

Cross-Browser & Progressive Enhancement

For browsers supporting the CSS Scroll-Driven Animations Specification (Chrome 115+, Edge 115+, Safari 18+), the scroll indicators automatically link progress to the page scroll timeline seamlessly. For non-supporting environments, clear fallbacks ensure the UI remains elegant and accessible.
