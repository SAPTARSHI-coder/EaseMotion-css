# Animated Stat Card — Claymorphism

A responsive animated statistics card with soft
claymorphism styling, created for EaseMotion CSS issue #81460.

## Features

- Claymorphism-inspired soft surface
- Layered neumorphic shadows
- Animated statistic value entrance
- Animated chart bars
- Floating decorative clay blobs
- Hover elevation effect
- Animated icon interaction
- Percentage growth badge
- Responsive desktop, tablet and mobile layouts
- CSS custom properties
- `prefers-reduced-motion` support
- Zero JavaScript dependencies
