# Morphing Shape Drawer

A smooth **Morphing Shape Drawer** built with pure HTML and Vanilla CSS
for the EaseMotion CSS component collection.

Implemented for **Issue #73589**.

## ✨ Features

- Morphing shape drawer reveal
- Smooth shape transformation
- Pure HTML and Vanilla CSS
- No JavaScript required
- CSS-only open/close interaction
- Animated navigation items
- Responsive layout
- Dark-mode friendly styling
- Hardware-friendly transforms
- `prefers-reduced-motion` support
- Semantic navigation structure

## 🎨 Style

**Category:** Drawers & Sidebars

**Style:** Morphing Shape

The drawer starts as a compact rounded form and smoothly morphs into
a full navigation panel when opened.
