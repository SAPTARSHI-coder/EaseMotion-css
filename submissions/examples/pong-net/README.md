# Pong Net

A ping-pong net with a ball that bounces across while the paddles shiver in anticipation.

## Features
- Dotted net with a mesh texture
- Ball arcs back and forth on a serve loop
- Paddles shift side to side

## Usage
```html
<div class="pn-table">
  <div class="pn-net"></div>
  <div class="pn-pad l"></div>
  <div class="pn-pad r"></div>
  <div class="pn-ball"></div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
