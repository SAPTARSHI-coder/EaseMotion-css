# CSS Meeting Notes Template

A professional meeting notes card featuring agenda sections, discussion notes, and actionable task items.

## Features

- Pure HTML and CSS
- Clean business-style layout
- Agenda section
- Notes section
- Action items checklist
- Responsive design
- Accessible form controls
- No JavaScript required

## Usage

```html
<div class="meeting-card">
  <div class="header">
    <h1>Meeting Title</h1>
  </div>

  <section class="section">
    <h2>Agenda</h2>
  </section>

  <section class="section">
    <h2>Action Items</h2>
  </section>
</div>
```

## Customization

- Modify colors and typography
- Add additional note sections
- Extend checklist items
- Integrate with internal documentation layouts

## Why it fits EaseMotion CSS

This component provides a reusable productivity-focused layout pattern commonly used for project planning, team meetings, sprint reviews, client discussions, and documentation workflows.
