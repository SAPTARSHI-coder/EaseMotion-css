# CSS Polaroid Stack Card

A responsive Polaroid card stack that spreads out like a hand of photographs on hover or keyboard focus.

Built using pure HTML and CSS for EaseMotion CSS.

## ✨ Features

- Pure HTML and CSS
- No JavaScript
- Polaroid card stack effect
- Smooth spread animation
- Individual card rotation
- Hover interaction
- Keyboard focus interaction
- Responsive desktop and mobile layouts
- Accessible card labels
- Visible keyboard focus indicator
- `prefers-reduced-motion` support
- CSS custom properties for easy customization
