# CSS Polaroid Stack Card

A responsive Polaroid-style card stack built with pure HTML and CSS.

The cards initially appear as a compact photo stack and smoothly spread out
like a hand of cards when the user hovers over the component.

## Features

- Pure HTML and CSS
- No JavaScript
- Responsive layout
- Smooth 3D card transitions
- Individual card rotation
- Hover interaction
- Keyboard/focus-friendly structure
- Reduced-motion support
- Self-contained CSS artwork
- No external assets or dependencies

## Demo

Open `demo.html` in any modern browser.
