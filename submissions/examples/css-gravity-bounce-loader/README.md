# CSS Gravity Bounce Loader

A loading animation featuring multiple colored orbs that fall and bounce. It utilizes customized `cubic-bezier` timing functions to simulate realistic gravity and squash/stretch physics at the bottom of the bounce.

## Features
- Realistic bounce physics via `cubic-bezier` timing
- Squash and stretch effect on impact via `scale`
- Cascading `animation-delay` across child elements
