# Hamburger Menu Button

A modern, dependency-free CSS component that morphs a three-line hamburger icon into an 'X' close indicator using offset bar rotations and scaling.

## Category
Menu

## Features
- **Zero JavaScript:** Uses the CSS checkbox hack (`:checked`) for interactive state toggling.
- **Fluid Morphing:** Utilizes custom `cubic-bezier` timing curves for responsive spring physics.
- **Customizable Tokens:** Easily configure bar dimensions, gap spacing, active colors, and animation speeds via CSS variables.

## Quick Start
1. Include `style.css` in your document head.
2. Pair an `<input type="checkbox">` with a matching `<label>` wrapping the 3-span bar structure as shown in `demo.html`.
