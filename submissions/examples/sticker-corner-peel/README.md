# Sticker Corner Peel Reveal

## Overview

A modern sticker/coupon card featuring a realistic corner peel animation. The folded corner peels back on hover or keyboard focus to reveal hidden promotional content, and a checkbox allows the peeled state to remain open.

---

## Features

- Realistic corner peel effect
- Hover and focus interactions
- Checkbox to lock peeled state
- Hidden content reveal
- Responsive design
- Pure HTML & CSS
- Supports `prefers-reduced-motion`
