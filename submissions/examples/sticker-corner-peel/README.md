# Sticker Corner Peel Reveal

## Overview

A modern sticker/coupon card featuring an interactive corner peel animation. The folded corner peels back on hover, keyboard focus, or when locked with a checkbox, revealing hidden promotional content beneath.

---

## Features

- Interactive corner peel effect
- Hover and keyboard focus support
- Checkbox to keep the peeled state open
- Hidden coupon/content reveal
- Responsive design
- Pure HTML & CSS
- Supports `prefers-reduced-motion`
