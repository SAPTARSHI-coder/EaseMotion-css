Chapter 1: The DOM

The Document Object Model is an incredibly powerful rendering engine. For years, developers have relied heavily on JavaScript to manipulate it.

However, modern CSS specifications have unlocked hardware-accelerated 3D transforms that allow us to manipulate the DOM spatially in three dimensions, directly on the GPU.

1

No JavaScript Required

By utilizing the :checked pseudo-class and the general sibling combinator (~), we can manage complex application state entirely within CSS.

input:checked ~ .book .sheet-2 {
  transform: rotateY(-180deg);
}
2

Hardware Acceleration

When you apply transform-style: preserve-3d to a parent container, you instruct the browser's compositor thread to maintain the Z-axis relationships of its children.

Flipping a page isn't just a 2D scale manipulation—it is a literal 180-degree rotation in physical space along the Y-axis.

Dynamic Lighting

Notice how the pages darken as they turn? This isn't a complex WebGL shader.

We use a simple CSS transition on a linear-gradient background. As the page reaches a 90-degree angle (facing the user edge-on), the shadow intensity maximizes.
