# 3D Perspective Tilt Tabs

Pure HTML and Vanilla CSS implementation for issue #73558.

## Features

- Perspective-based active state
- Layered depth and shadow
- Native radio controls
- Responsive segmented control
- Keyboard focus styling
- Reduced-motion support
- No JavaScript dependencies

## Implementation

The tabs use CSS perspective, transforms, and shadows to lift the selected label without requiring scripting. Radio state determines the visible content panel.

## Accessibility

Native controls remain keyboard accessible. Focus is visible and reduced-motion users receive a static presentation.

## Usage

Open `demo.html` directly in a modern browser.
