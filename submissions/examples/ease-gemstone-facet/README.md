# 💎 Gemstone Facet – Facets Reflect Light Like Diamond

> A brilliant gemstone component where facets reflect light like a diamond with 5 colors (Diamond, Ruby, Emerald, Sapphire, Amethyst), light control (0-100%), and sparkle effects.

---

## 📖 Description

The **Gemstone Facet** component creates a brilliant gemstone experience where facets reflect light like a diamond with sparkling effects. Built with vanilla HTML, CSS, and JavaScript, it features 5 colors (Diamond, Ruby, Emerald, Sapphire, Amethyst), light control (0-100%), and sparkle effects for a dazzling experience.

### 🎯 Core Features

- **Gemstone facets** – faceted gemstone with light reflection
- **5 colors** – Diamond, Ruby, Emerald, Sapphire, Amethyst
- **Light control** – adjust light intensity from 0-100%
- **Sparkle effects** – light reflections and sparkles
- **Brilliance level** – shows current brilliance
- **Interactive controls** – slider, color buttons, keyboard shortcuts
- **Responsive design** – adapts to different screen sizes

| Method | Action |

### ✨ Gemstone Experience

When interacting:
1. **Facets sparkle** – gemstone reflects light
2. **Light applies** – controls brilliance intensity
3. **Color applies** – changes gemstone color
4. **Sparkles burst** – light reflections appear
5. **Status updates** – shows current state

### 💡 Why Use This Component?

- Perfect for jewelry stores, fantasy games, or magical interfaces
- Brilliant gemstone with light reflection
- Self-contained – no external dependencies or frameworks

### 🛠️ Technologies Used

- **HTML5** – semantic structure with Canvas
- **CSS3** – gradients, backdrop-filter, transforms
- **JavaScript (ES6)** – Canvas API, requestAnimationFrame, particle system

### 🎨 Design Philosophy

This component embodies **EaseMotion CSS's animation-first philosophy** through:

- **Light reflection** – facets catch and reflect light
- **Sparkle effects** – sparkling light reflections
- **Visual feedback** – status updates, brilliance level, controls
- **Dazzling atmosphere** – gemstone brilliance and color
- **Human-readable classes** – `.gemstone-controls`, `.color-btn`, `.gemstone-text`

### 🔧 Customization Options

| Property | Location | Default |
|----------|----------|---------|
| Colors | `colorConfigs` object | 5 colors |
| Light range | `lightSlider` | 0-100% |
| Facet count | `facetCount` | 8 |
| Sparkle chance | `Math.random()` | 10% per frame |
