# CSS Float-Drift Hero Section

A responsive gaming hero section created using pure HTML and CSS.

## Features

- Floating and drifting animations
- Animated hero entrance
- Responsive desktop, tablet and mobile layout
- Interactive buttons
- CSS custom properties
- No JavaScript
- No external libraries
- Accessible reduced-motion support

## Files

- `demo.html` - Hero section markup
- `style.css` - Styling and animations
