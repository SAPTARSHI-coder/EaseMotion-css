# Aqueduct Water Arch

## What does this do?
Renders a self-contained CSS-only `ease-aqueduct-water-arch` demo: Roman aqueduct arches carrying a flowing water channel.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-aqueduct-water-arch`. No build step or JavaScript is required for the effect.

```html
<section class="ease-aqueduct-water-arch">
  <div class="ease-aqueduct-water-arch__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
