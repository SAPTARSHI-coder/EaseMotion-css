# CSS Blur Entrance Card Grid for Product Catalog Layouts

A modern product catalog card grid featuring smooth blur entrance animations built entirely with HTML5 and CSS3. Each card animates into view with a staggered blur transition, creating an elegant shopping experience.

## Features

- Pure HTML5 & CSS3
- Blur Entrance Animation
- Staggered Card Reveal
- Responsive Product Grid
- Hover Lift Effect
- Gradient Action Buttons
- CSS Custom Properties
- Mobile Friendly Layout
- Supports `prefers-reduced-motion`
- No JavaScript Required
