ease-sidebar-scroll-lock

Mobile sidebar with background scroll lock.

Fixes the bug where scrolling inside the mobile sidebar overlay leaked the scroll event to the background <body>, scrolling the page underneath. This example locks body scroll while the sidebar is open via a class on <html> (overflow: hidden + a scrollbar-gap compensation), and the sidebar's own content scrolls independently. Open the sidebar and scroll — the page behind stays put.

Scroll the page. Then open the sidebar and scroll inside it — the background will not move.
