# CSS Scale-Hover Popover for Product Catalog Layouts

A modern **pure HTML & CSS** product catalog showcasing elegant **scale-hover animations** with an interactive popover. When users hover over a product card, the card smoothly enlarges while a floating popover appears with additional product details and action buttons.

---

## ✨ Features

- Pure HTML5 & CSS3
- Smooth scale-hover animation
- Floating product popover
- Modern product card design
- Glass-inspired UI with soft shadows
- Responsive layout for desktop, tablet, and mobile
- CSS Custom Properties for easy customization
- No JavaScript required
- Accessibility support with `prefers-reduced-motion`

## 🎨 CSS Custom Properties

The component is easily customizable using CSS variables.

```css
:root{
    --bg:#eef2ff;
    --surface:#ffffff;
    --primary:#4f46e5;
    --primary-dark:#3730a3;
    --text:#1e293b;
    --muted:#64748b;
    --shadow:0 18px 45px rgba(15,23,42,.16);
    --radius:22px;
    --speed:.4s;
    --popover-width:280px;
}
```

You can modify these variables to change:

- Theme colors
- Card radius
- Animation speed
- Shadow intensity
- Popover width
- Typography appearance
