# Tessellation Loader – Geometric Patterns

An interactive tessellation loader that creates mesmerizing geometric patterns with hexagonal, triangular, square, and diamond tiles that flow, shift, and pulse with organic sine-wave motion. Watch as shapes tile the canvas in perfect mathematical harmony, with colors shifting dynamically along the pattern and each tile moving independently in a hypnotic dance.

## Features
- **4 Pattern Types**: Hexagonal, Triangular, Square, Diamond.
- **Adjustable Speed**: Change the speed from 1x up to 10x.
- **Tile Size**: Customize the tile size from 20px to 80px.
- **Shift Intensity**: Set how much the shapes wave and pulsate (0-100%).
- **Interactive Controls**: Play/pause buttons and a real-time shape count display.
- **Keyboard Shortcuts**: 
  - `Space`: Play/Pause
  - `P`: Change Pattern
  - `R`: Reset to default

## Tech Stack
- Pure HTML
- Pure CSS
- Pure Vanilla JavaScript

## Setup & Usage
1. Open `demo.html` in your web browser.
2. Use the on-screen UI panel to customize the patterns.
3. Enjoy the mesmerizing geometric effects!
