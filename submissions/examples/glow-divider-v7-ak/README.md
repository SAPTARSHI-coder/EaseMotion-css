# glow-divider-v7-ak

Pure CSS animated glowing gradient line divider component — no JavaScript required.

## How to use

```html
<hr class="ease-glowing-divider-v7" />

<!-- Divider with Badge -->
<div class="ease-glowing-divider-text-v7">
  <span class="ease-glowing-divider-badge-v7">OR</span>
</div>
