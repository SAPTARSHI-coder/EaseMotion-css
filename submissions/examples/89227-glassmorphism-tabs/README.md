# Glassmorphism Tab Navigation Component

A floating tab bar navigation component featuring frosted glass aesthetics and smooth active state transitions.

## Features
- **Glassmorphism Container:** Translucent container styled with CSS backdrop blur.
- **Active State Highlights:** Gradient highlight indicators for selected views.
- **Pure CSS:** Zero JavaScript dependencies.

## File Structure
- `demo.html` - Tab navigation bar markup.
- `style.css` - Component glass container and tab active styling.
