# Scroll Progress Offset Calculation Test

## Overview

This submission demonstrates edge-case testing for calculating scroll progress percentages.

## Included

- Interactive demo
- CSS styling
- Vitest-compatible test specification

## Test Coverage

- Initial scroll position
- Halfway scroll
- Bottom scroll
- Over-scroll values
- Negative scroll values
- Zero scrollable area
- Invalid document height
- Decimal calculations

## Usage

```bash
vitest scroll-progress.test.js
```

## Purpose

This example is packaged inside `submissions/examples/` to comply with the repository contribution policy while demonstrating comprehensive automated test coverage for scroll percentage calculations.
