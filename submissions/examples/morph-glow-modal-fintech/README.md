# Morph-Glow Modal for Fintech Dashboards

A pure HTML and CSS animated modal designed for modern fintech dashboard interfaces.

## Features

- Animated morph-glow border
- Pure CSS animations
- No JavaScript required
- Responsive design
- CSS custom properties
- Accessible reduced-motion support
- Fintech dashboard styling

## Files

- `demo.html` - Component showcase
- `style.css` - Component styles
- `README.md` - Documentation

:root {
