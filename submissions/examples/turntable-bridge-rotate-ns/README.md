# Turntable Bridge Rotate

## What does this do?
Renders a self-contained CSS-only `ease-turntable-bridge-rotate` demo: Turntable bridge rotating a locomotive.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-turntable-bridge-rotate`. No build step or JavaScript is required for the effect.

```html
<section class="ease-turntable-bridge-rotate">
  <div class="ease-turntable-bridge-rotate__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
