# Glassmorphic Pricing Table Toggle Component

A modern pricing card grid UI featuring translucent glassmorphic backdrop filters, custom toggle controls, and fluid spring physics.

## 1. What does this do?
Displays a modern responsive pricing table styled with glassmorphism visual effects (`backdrop-filter: blur()`). It includes an interactive toggle switch for switching billing state (monthly vs. annual) with spring transitions.

## 2. How is it used?
1. Import `style.css` in your document `<head>`.
2. Wrap pricing cards in a container styled with `.glass-card`.
3. Add the billing toggle element `.switch` to enable user switching.

## 3. Why is it useful?
- **Modern UI Aesthetic**: Frosted glass depth elevates SaaS landing page visual standards.
- **Micro-Interactions**: Custom spring curve physics on toggle state changes provide instant visual feedback.
- **Fully Responsive**: Automatically adapts layout across device breakpoints via CSS Grid auto-fit properties.
