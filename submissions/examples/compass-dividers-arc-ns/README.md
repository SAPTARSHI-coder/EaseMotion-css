# Compass Dividers Arc

## What does this do?
Renders a self-contained CSS-only `ease-compass-dividers-arc` demo: Drafting dividers swinging arcs on drafting paper.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-compass-dividers-arc`. No build step or JavaScript is required for the effect.

```html
<section class="ease-compass-dividers-arc">
  <div class="ease-compass-dividers-arc__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
