# 🌙 Moon Halo – Luminous Ring Forms Around Moon

> A mystical moon halo component where luminous rings form around the moon with 5 colors (White, Gold, Blue, Purple, Pink), intensity control (0-100%), and sparkle particle effects.

---

## 📖 Description

The **Moon Halo** component creates a mystical moon halo experience where luminous rings form around the moon with glowing effects. Built with vanilla HTML, CSS, and JavaScript, it features 5 colors (White, Gold, Blue, Purple, Pink), intensity control (0-100%), multiple ring layers, and sparkle particles for an enchanting celestial experience.

### 🎯 Core Features

- **Luminous halo** – glowing rings form around the moon
- **5 colors** – White, Gold, Blue, Purple, Pink
- **Intensity control** – adjust intensity from 0-100%
- **Multiple rings** – 3-7 layered rings with distortion
- **Sparkle particles** – twinkling star particles around the halo
- **Halo counter** – tracks number of halos created
- **Interactive controls** – sliders, color buttons, keyboard shortcuts
- **Responsive design** – adapts to different screen sizes

| **Keyboard** | `Space` – Create · `R` – Reset |

### ✨ Halo Experience

When creating:
1. **Rings form** – multiple luminous rings expand outward
2. **Intensity applies** – controls ring count and brightness
3. **Color applies** – changes halo color
4. **Sparkles appear** – twinkling particles orbit the halo
5. **Counter updates** – halo count increments
6. **Status updates** – shows creation state

### 🛠️ Technologies Used

- **HTML5** – semantic structure with Canvas
- **CSS3** – gradients, backdrop-filter, transforms
- **JavaScript (ES6)** – Canvas API, requestAnimationFrame, particle system

### 🎨 Design Philosophy

This component embodies **EaseMotion CSS's animation-first philosophy** through:

- **Luminous effects** – glowing rings with soft radiance
- **Particle effects** – twinkling sparkle particles
- **Visual feedback** – status updates, counter, controls
- **Mystical atmosphere** – moon glow and halo effects
- **Human-readable classes** – `.moonhalo-controls`, `.color-btn`, `.moonhalo-text`

### 🔧 Customization Options

| Property | Location | Default |
|----------|----------|---------|
| Colors | `colors` object | 5 colors |
| Intensity range | `intensitySlider` | 0-100% |
| Ring count | `ringCount` | 3-7 |
| Ring distortion | `wobble` | 2px |
| Sparkle count | `particleCount` | 20-50 |
