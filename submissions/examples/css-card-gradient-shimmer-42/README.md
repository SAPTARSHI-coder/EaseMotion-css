# Gradient Shimmer Card

A premium, dark-mode compatible card featuring a smooth, animated gradient border shimmer.

## What does this do?
It creates an eye-catching card with an animated gradient background that simulates a shimmering border effect.

## How is it used?

```html
<div class="gradient-shimmer-card">
  <div class="card-content">
    <h3>Gradient Shimmer</h3>
    <p>This card features a smooth, moving gradient background that creates a shimmering effect, perfect for highlighting premium content.</p>
  </div>
</div>
```

## Why is it useful?
It provides a high-quality visual effect using pure CSS without relying on JavaScript. This makes it perfect for highlighting premium tiers, special offers, or featured content while maintaining high performance through CSS animations.
