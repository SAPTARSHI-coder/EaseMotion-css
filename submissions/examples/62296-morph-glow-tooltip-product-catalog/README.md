# CSS Morph-Glow Tooltip for Product Catalog Layouts

A responsive **Morph-Glow Tooltip** component built using pure HTML and CSS for modern product catalog interfaces. The tooltip smoothly scales, glows, and morphs into view while displaying product information.

---

## Features

- Pure HTML5 & CSS3
- Morph + Glow tooltip animation
- Smooth hover transitions
- Product catalog showcase
- Responsive desktop, tablet, and mobile layout
- CSS Custom Properties for easy customization
- Accessible design with `prefers-reduced-motion` support
- No JavaScript required

## Usage

1. Open `demo.html`.
2. Hover over any tooltip trigger.
3. The tooltip appears with a glowing morph animation.

---

## CSS Custom Properties

```css
--bg
--surface
--card
--primary
--secondary
--accent
--text
--muted
--radius
--shadow
--transition
```

Modify these variables inside `:root` to create different color themes.
