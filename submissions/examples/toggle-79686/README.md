# Responsive Retro Toggle

Issue #79686 demonstrates a responsive toggle with retro styling.

## Features

- Native checkbox semantics
- Responsive sizing
- Visible keyboard focus
- Reduced-motion support
- Touch-friendly spacing
- Pure HTML and vanilla CSS

## Usage

Open demo.html to preview the component and link style.css when integrating it into another page.

## Accessibility

The native checkbox remains the source of truth and the focus-visible state keeps keyboard interaction clear.
