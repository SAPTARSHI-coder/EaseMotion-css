# 3D Perspective Tilt Toast

A smooth and visually polished notification/toast component featuring
**3D Perspective Tilt** styling using pure HTML and Vanilla CSS.

## ✨ Features

- Pure HTML and CSS
- No JavaScript required
- 3D perspective transformation
- Smooth X/Y tilt effect
- Depth using `translateZ()`
- Layered 3D visual elements
- Smooth hover interaction
- Responsive design
- Light and dark mode support
- Hardware-accelerated transforms
- Accessible semantic markup
- Keyboard-friendly close button
- Visible focus state
- `prefers-reduced-motion` support
- No external dependencies

## 🎨 Style

**3D Perspective Tilt**

The toast uses CSS 3D transforms to create a subtle depth effect.
The default state has a slight perspective tilt, while hovering smoothly
levels the component and moves it forward in 3D space.
