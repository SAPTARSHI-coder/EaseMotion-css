# Ripple Wave Testimonial Card

A beautiful, glassmorphism-inspired testimonial card featuring a continuous ripple wave animation in the background. Built as a submission for EaseMotion CSS.

## Features
- **Glassmorphism Design:** Uses `backdrop-filter` to create a frosted glass effect on the testimonial card.
- **Ripple Wave Animation:** A pure CSS pulsing wave that draws attention smoothly without being distracting.
- **EaseMotion Integration:** Uses CSS variables provided by the EaseMotion library for transitions, shadows, and base styling.
- **Responsive:** Scales down gracefully on smaller mobile screens.

## Usage
Simply open `demo.html` in your browser. The component requires no JavaScript and relies purely on HTML and CSS.

### File Structure
- `demo.html` - The live demonstration of the component.
- `style.css` - Custom styling complementing EaseMotion utility variables.
