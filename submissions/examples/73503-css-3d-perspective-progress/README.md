# CSS 3D Perspective Progress

Issue #73503 uses CSS perspective and transforms to give a progress bar a dimensional presentation.

## Features

- CSS perspective depth
- Animated progress fill
- Accessible progressbar semantics
- Responsive card sizing
- Reduced-motion support
- Pure HTML and vanilla CSS

## Usage

Open `demo.html` and adjust `--value` to change the progress amount.

## Files

- `demo.html` — semantic progress structure
- `style.css` — perspective, lighting, animation, and responsive styling
- `README.md` — documentation
