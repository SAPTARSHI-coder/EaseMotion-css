# Azure Loom

A unique landing page for Azure Loom built with EaseMotion CSS framework.

## Features
- Pure EaseMotion CSS from CDN
- Responsive across all devices
- Zero JavaScript
- 4 unique sections: contact, team, faq, features

## Setup
Open `demo.html` in any modern browser.

## Structure
```
ease-vapor-forge-ivoryloom/
  demo.html
  style.css
  README.md
```
