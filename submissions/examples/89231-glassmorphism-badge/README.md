# Glassmorphism Notification Badge Component

A floating badge component for notifications and counter alerts with a continuous CSS pulse scale effect.

## Features
- **Compact Overlay:** Positioned absolute badge with high-contrast indicator fill.
- **Micro-Interaction:** Continuous scaling keyframe animation for emphasis.
- **Pure CSS:** Zero JavaScript dependencies.

## File Structure
- `demo.html` - Minimal button and badge overlay markup.
- `style.css` - Badge positioning and keyframe bounce animation.
