# Laterna Magica Slide

## What does this do?
Renders a self-contained CSS-only `ease-laterna-magica-slide` demo: Laterna magica painted slide advancing through lamp.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-laterna-magica-slide`. No build step or JavaScript is required for the effect.

```html
<section class="ease-laterna-magica-slide">
  <div class="ease-laterna-magica-slide__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
