# CSS Scale-Hover Badge for SaaS Showcase Layouts

A modern **Scale-Hover Badge** component built using pure HTML and CSS. The component showcases animated SaaS badges with smooth hover scaling, colorful status labels, and responsive card layouts.

## ✨ Features

- Pure HTML5 & CSS3
- Scale-hover badge animation
- Responsive SaaS card layout
- Gradient section tag
- Smooth transitions
- CSS Custom Properties
- `prefers-reduced-motion` support
- No JavaScript required
