# CSS Particle Effect: Particle Burst

A smooth pure CSS particle burst effect where multiple particles radiate outward from a central point.

## Features

- Pure HTML and Vanilla CSS
- No external JavaScript
- Radial particle burst animation
- Smooth CSS transitions
- Hardware-accelerated transforms
- Responsive design
- Dark-mode friendly styling
- Reduced-motion accessibility support

## Files

- `demo.html` — Particle burst demo
- `style.css` — Particle styles and animations
- `README.md` — Documentation

## Accessibility

The particle effect is decorative and uses `aria-hidden="true"`. The animation also respects the user's `prefers-reduced-motion` preference.
