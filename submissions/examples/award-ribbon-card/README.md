# CSS Award Ribbon Card

A reusable award card featuring a decorative ribbon, medal, winner label, and responsive layout.

## Features

- Pure HTML and CSS
- Decorative award ribbon
- Medal-style centerpiece
- Winner/achievement label
- Responsive design
- Hover elevation effect
- Reduced-motion support
- No JavaScript or external assets
