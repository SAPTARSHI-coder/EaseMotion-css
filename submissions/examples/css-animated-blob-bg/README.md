# CSS Animated Blob Background

A hypnotic, organic background featuring slow-moving, color-shifting amorphous blobs. 

## Features
- Deeply blurred elements utilizing `filter: blur()` and high `contrast()` to create fluid merging (gooey effect)
- Continuously morphing `border-radius` values to create organic, irregular shapes
- Complex `transform: translate()` keyframes for wandering movement
