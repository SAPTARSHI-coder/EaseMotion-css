# Gradient Shimmer Toggle (#73885)

A pure HTML & Vanilla CSS toggle featuring a continuous, animated gradient shimmer background effect.

## Features
- **Aesthetic:** Continuous linear-gradient shimmer sweep across active switch track.
- **Pure CSS:** Zero JavaScript dependencies; relies purely on standard CSS keyframe animations.
- **Performance:** Hardware-accelerated background transitions using `background-position`.
- **Accessibility:** Keyboard focus navigation support and `@media (prefers-reduced-motion: reduce)` media query integration.
