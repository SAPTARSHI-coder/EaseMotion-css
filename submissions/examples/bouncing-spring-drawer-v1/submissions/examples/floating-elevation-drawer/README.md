# Floating Elevation Drawer

A modern **Floating Elevation Drawer** created using only HTML and CSS.

## Features

- Pure HTML & CSS
- Floating elevated card design
- Smooth slide-in animation
- Soft shadows and rounded corners
- Responsive layout
- Dark mode adaptable
- Accessible checkbox toggle
- Hardware-accelerated transitions
- No JavaScript required
