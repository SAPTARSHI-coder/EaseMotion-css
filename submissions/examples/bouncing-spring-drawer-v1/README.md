# Bouncing Spring Drawer

A pure HTML and CSS drawer featuring an elastic **Bouncing Spring** entrance animation.

## Features

- Pure HTML & CSS
- Spring-inspired opening animation
- Responsive sidebar
- Accessible checkbox toggle
- Dark mode compatible
- Hardware-accelerated motion
- No JavaScript required

- `demo.html`
- `style.css`
- `README.md`

## Preview

A modern sidebar that slides into view with a playful spring bounce effect, making navigation feel lively while remaining lightweight and accessible.
