# CSS Glassmorphism Blur Form

Issue #73340 implements a translucent glass form using pure HTML and vanilla CSS.

## Features

- Backdrop blur
- Layered translucent surfaces
- Native form controls
- Visible focus states
- Responsive layout
- Reduced-motion fallback

## Accessibility

All controls have labels and visible keyboard focus. Decorative orb movement is disabled for reduced-motion users.

## Files

- `demo.html` — form demonstration
- `style.css` — glass surface and interaction styling
- `README.md` — documentation
