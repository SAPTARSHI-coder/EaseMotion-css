# Minimalist Sliding Tab Selector with Smooth Spring Physics

A clean and responsive sliding tab selector featuring smooth spring-like transitions and a minimalist UI built with HTML, CSS and JavaScript.

## Features

- Minimalist design
- Smooth spring animation
- Sliding active indicator
- Responsive layout
- Pure HTML, CSS & JavaScript
- Lightweight and customizable

## Folder Structure

```
ease-ui-minimalist-sliding-tab-selector-with-smooth-spring-physics-205/
├── README.md
├── demo.html
├── style.css
└── script.js
```

## Usage

Open `demo.html` in your browser.

Modify colors and transition duration inside `style.css`.

- HTML5
- CSS3
