# Dropzone progress ring

A drag-and-drop target whose border changes on drag-over and reveals a circular progress ring while uploading.

## How to view

Open `demo.html` in any modern browser. The demo is fully self-contained — no CDN, no framework, no JavaScript.

## How to use

Copy `style.css` into your project's stylesheet. Every class used in the demo is namespaced with `filedropzoneprogress-` to avoid collisions.

## Why this is useful for EaseMotion CSS

File upload pattern; combines drag affordance and a clear progress indicator.
