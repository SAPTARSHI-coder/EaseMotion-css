# Glassmorphism Hover Slider

A responsive hover slider component built using pure HTML and CSS.

## Features

- Glassmorphism design
- Smooth card expansion on hover
- Responsive layout
- Pure HTML and CSS
- No JavaScript required
- CSS backdrop blur
- Smooth transitions
- Mobile-friendly layout
- Keyboard focus styling
- Reduced-motion support

## Files

- `demo.html` - Component markup
- `style.css` - Component styling

## Usage

Open `demo.html` in any modern browser.

## Technologies

- HTML5
- CSS3
- Flexbox
- CSS Transitions
- CSS Backdrop Filter
- CSS Media Queries

## Accessibility

The component includes:

- Semantic `<article>` elements
- Descriptive heading structure
- Visible focus styles
- Responsive text
- `prefers-reduced-motion` support
