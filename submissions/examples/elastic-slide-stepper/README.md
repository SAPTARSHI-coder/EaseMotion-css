# Elastic-Slide Stepper

A lightweight, responsive CSS-only stepper designed for product catalog layouts.

The component uses elastic slide and bounce animations to visually highlight
the current step while keeping the implementation simple and dependency-free.

## Features

- Pure HTML and CSS
- No JavaScript or external libraries
- Elastic slide animation
- Animated active step indicator
- Responsive desktop, tablet, and mobile layouts
- CSS custom properties for easy customization
- Keyboard-focusable buttons
- Accessible `prefers-reduced-motion` support
- Self-contained demo
- Lightweight and performant
