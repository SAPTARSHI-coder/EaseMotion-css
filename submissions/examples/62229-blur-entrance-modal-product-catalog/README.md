# CSS Blur-Entrance Modal for Product Catalog Layouts

A modern **Blur-Entrance Modal** built using pure HTML5 and CSS3 for product catalog layouts. The component features a responsive product quick-view modal with a smooth blur-and-fade entrance animation, glassmorphism styling, and accessibility support.

## Features

* Pure HTML5 & CSS3
* Blur-Entrance modal animation
* Product quick-view modal
* Glassmorphism modal design
* Backdrop blur effect
* Product image, price, specifications, and CTA buttons
* Smooth CSS transitions & keyframe animations
* Responsive desktop, tablet, and mobile layout
* CSS Custom Properties
* No JavaScript required
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Click **Quick View Product** to open the modal.
3. Close the modal using the close button or by clicking outside the modal.
4. Customize colors, spacing, blur intensity, and animation timing using the CSS variables defined in `:root`.
