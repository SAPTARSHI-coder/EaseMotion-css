# Ease Avatar Stack

## What does this do?

An overlapping group of avatars representing multiple users, with hover expansion and an extra-user indicator.

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<div class="avatar-stack">
    <div class="avatar avatar-one">A</div>
    <div class="avatar avatar-two">B</div>
    <div class="avatar avatar-three">C</div>
    <div class="avatar avatar-four">D</div>
    <div class="avatar extra">+4</div>
</div>
```

### Features

- Multiple avatars
- Overlapping layout
- Hover expansion
- Responsive sizing
- Extra-user indicator
- Smooth animation
- Pure CSS
- No JavaScript required

## Why is it useful?

Avatar stacks are commonly used to represent team members, collaborators, project participants, shared documents, and group activities.

This component provides a compact and reusable way to display multiple users while following the animation-first philosophy of EaseMotion CSS.
