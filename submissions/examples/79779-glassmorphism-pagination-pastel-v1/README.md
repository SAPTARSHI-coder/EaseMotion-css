# Glassmorphism Pagination - Pastel

A responsive pagination component featuring a soft glassmorphism interface with pastel colors.

## Features

- Glassmorphism visual design
- Pastel color palette
- Responsive layout
- Hover and active states
- Keyboard focus support
- Flexible wrapping on small screens
- No external dependencies

## Files

- `demo.html` - Component markup
- `style.css` - Component styles

## Usage

Open `demo.html` in a browser to preview the component.

## Responsive Design

The pagination automatically adapts to smaller screens using responsive media queries.

## Accessibility

Pagination links include accessible labels for previous and next controls, along with visible keyboard focus states.
