# CSS Flip Product Card

A responsive product card that uses a pure CSS 3D flip animation to reveal additional product information and pricing details.

## Features

- Pure CSS 3D flip animation
- No JavaScript required
- Hover and keyboard focus interaction
- Responsive layout
- Accessible focus state
- CSS custom properties for easy customization
- Reduced-motion support
- Works with light and dark card surfaces

## Files

- `demo.html` — Standalone demonstration
- `style.css` — Component styles and animation

## Usage

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
