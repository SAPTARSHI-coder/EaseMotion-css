# CSS Mesh Gradient: Minimalist Outline

## Overview

A restrained mesh variation built from fine animated contours and a low-contrast atmospheric background.

## Features

- Thin outline layers
- Subtle mesh lighting
- Responsive layout
- Dark-mode-friendly palette
- Focus-visible interaction styling
- Reduced-motion support
- No JavaScript

## Files

- `demo.html` — semantic example
- `style.css` — outline layers and animation
- `README.md` — documentation

## Accessibility

The outline layers are decorative. The action link has a clear focus indicator, and reduced-motion preferences disable the decorative animations.
