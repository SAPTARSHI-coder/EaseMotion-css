Basic Icon Circle Placeholder

Small circular placeholders for initials, icons, and compact UI markers.

This demo shows a lightweight CSS-only circular placeholder utility for profile initials, small icons, action markers, and compact dashboard labels.

K

Profile Initial

Use a circle placeholder for initials in profile cards or user rows.

i

Info Marker

The same utility can hold a small symbol or short single-letter label.

+

Action Marker

Circle placeholders are useful beside actions, notes, and compact summaries.

HTML Usage

<span class="basic-icon-circle">K</span>
