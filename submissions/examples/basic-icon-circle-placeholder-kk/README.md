# Basic Icon Circle Placeholder

## What it does

This submission creates a simple CSS-only circular placeholder utility for initials, small icons, compact markers, and short UI labels.

## How to use it

Place a short character, initial, or icon-like text inside the circle:

```html
<span class="basic-icon-circle">K</span>
```

## Why it fits EaseMotion CSS

It fits EaseMotion CSS because it is human-readable, composable, and useful across many interfaces. It works well in profile rows, cards, dashboards, action groups, and compact information layouts.

## Included features

- Basic circular placeholder utility
- Soft and warm variations in the demo
- Practical profile, info, and action examples
- Responsive demo layout
- Pure HTML and CSS implementation
