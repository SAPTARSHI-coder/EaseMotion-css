# Minimalist Sliding Tab Selector with Smooth Spring Physics (Vibrant Gradient Version)

A modern animated sliding tab selector featuring vibrant gradients, spring-inspired movement, and smooth transitions. Built using pure HTML, CSS, and JavaScript.

## Features

- Vibrant gradient UI
- Smooth spring-like sliding animation
- Animated active indicator
- Responsive layout
- Pure HTML, CSS & JavaScript
- Lightweight and customizable

## Folder Structure

```
ease-anim-minimalist-sliding-tab-selector-with-smooth-spring-physics-206/
├── README.md
├── demo.html
├── style.css
└── script.js
```

## Usage

Open `demo.html` in your browser.

Customize gradients, colors, and animation timing inside `style.css`.
