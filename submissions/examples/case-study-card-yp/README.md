# Case Study Card (`case-study-card-yp`)

A modern interactive Case Study Card component featuring a layered hover effect, smooth animations, customizable content, and responsive design. Built with HTML, CSS, and lightweight JavaScript, it is perfect for showcasing projects, articles, portfolios, and featured content. It follows EaseMotion CSS's animation-first philosophy by providing a clean, reusable, and visually engaging UI component.

## Features

* Smooth layered card hover animation
* Interactive "Click to Read" reveal card
* Responsive across desktop, tablet, and mobile devices
* Customizable title, category, logo, link, and background image
* Lightweight implementation using HTML, CSS, and vanilla JavaScript
* Modern design with rounded corners, soft shadows, and dot-grid background
* Easy to integrate into any website

## Folder Structure

```text
case-study-card-yp/
├── demo.html
├── style.css
└── README.md
```

## Usage

Simply include `style.css` and copy the HTML structure from `demo.html`.

```html
<link rel="stylesheet" href="style.css">

<div class="card-wrapper">
    <!-- Your Case Study Card -->
</div>
```

Customize the card content, colors, images, and interactions using the variables and options provided in `style.css` and `demo.html`.
