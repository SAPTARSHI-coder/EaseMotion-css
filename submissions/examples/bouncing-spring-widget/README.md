# Bouncing Spring Dashboard Widget

A smooth and playful dashboard widget featuring a **Bouncing Spring** visual style using pure HTML and Vanilla CSS.

## Features

- 🌀 Bouncing spring animation
- 🎨 Clean dashboard-card design
- 🌙 Automatic dark mode support
- ⚡ Hardware-accelerated transforms
- ♿ Accessible semantic HTML
- 📴 Reduced-motion support
- 📱 Responsive layout
- 🚫 No JavaScript or external dependencies
