# Rotate Fade Stepper - Glassmorphism UI


A modern pure CSS Rotate-Fade Stepper component built for EaseMotion CSS.

## Features

- Pure HTML and CSS
- Glassmorphism design
- Smooth rotate entrance animation
- Fade-in transition effects
- Responsive layout
- No JavaScript required
- Lightweight performance
- Reduced motion accessibility support
