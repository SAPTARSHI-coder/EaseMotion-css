# glow-card-stack-v8-ak

Pure CSS 3D floating stacked cards hover fan-out effect — no JavaScript required.

## How to use

```html
<div class="ease-card-stack-v8">
  <div class="ease-card-stack-item-v8">Top</div>
  <div class="ease-card-stack-item-v8">Middle</div>
  <div class="ease-card-stack-item-v8">Bottom</div>
</div>
