# CSS 3D Folding Ticket

An interactive ticket or receipt that folds up in 3D segments like an accordion when hovered, utilizing CSS `transform-origin` and `rotateX`.

## Features
- CSS 3D perspectives to simulate accordion folding
- `transform-origin: top` to anchor the folding sections
- Realistic dashed borders simulating tear-lines
