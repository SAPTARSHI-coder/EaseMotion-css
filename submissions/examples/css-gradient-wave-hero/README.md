# CSS Gradient Wave Hero

A responsive hero section featuring an animated gradient background with a
smooth flowing wave at the bottom.

## Features

- Pure CSS implementation
- Animated gradient background
- Smooth wave motion
- Responsive design
- No JavaScript required
- Accessible semantic HTML
- Keyboard-friendly CTA
- `prefers-reduced-motion` support
- Works by opening `demo.html` directly in a browser

## Files

- `demo.html` — Standalone demonstration page
- `style.css` — Complete CSS implementation

## How to Use

Copy the hero markup from `demo.html` and include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
