# CSS Laser Scan Barcode

A futuristic barcode graphic that features a glowing, neon laser line continuously scanning up and down over it using `translateY` animations.

## Features
- Simulated barcode using tight letter spacing and vertical pipe characters
- A glowing `box-shadow` laser line scanning via `translateY`
- Fading opacity during scan limits for a polished look
