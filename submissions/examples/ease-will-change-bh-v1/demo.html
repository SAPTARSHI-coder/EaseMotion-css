⚠️ Best Practices

  • Apply before animation: Add will-change to elements just before they animate, not globally
  • Remove after animation: Remove will-change after animation completes to free memory
  • Use sparingly: Only use on elements that will animate - don't apply to everything
  • Test performance: Use browser DevTools to verify GPU layer promotion is working

Proper will-change usage prevents frame drops during animations
