# Select Dropdown Style Component

Add ease-select-dropdown-style-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|---------|
| `--sds-accent` | `#6366f1` |
| `--sds-radius` | `10px` |
| `--sds-shadow` | `0 4px 20px rgba(0,0,0,.3)` |

## Technique

`appearance: none` removes default browser styling. Custom arrow via `::after` pseudo-element on wrapper.
