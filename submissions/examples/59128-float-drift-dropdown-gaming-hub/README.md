# CSS Float-Drift Dropdown for Gaming Hub Layouts

A modern **Float-Drift Dropdown** component built using pure HTML5 and CSS3 for gaming hub layouts. This component provides a futuristic navigation experience with floating dropdown panels, smooth drift animations, glassmorphism styling, and responsive design.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Gaming hub inspired interface
* Floating dropdown animation
* Smooth drift entrance effect
* Glassmorphism UI cards
* Animated navigation panels
* Hover-based interactions
* Responsive layouts
* CSS Custom Properties support
* Lightweight keyframe animations
* Accessible with `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over dropdown navigation items.
3. The floating menu panel will appear with a smooth drift animation.
4. Customize colors, shadows, and animations using CSS variables inside `:root`.

## CSS Custom Properties

```css
:root{
  --bg:#050816;
  --surface:rgba(255,255,255,.08);
  --primary:#8b5cf6;
  --secondary:#06b6d4;
  --accent:#ec4899;
  --text:#f8fafc;
  --muted:#94-slate-b8;
  --shadow:0 30px 80px rgba(139,92,246,.35);
  --radius:28px;
}
```
