# CSS Ripple-Wave Stepper for SaaS Showcase Layouts

A modern **Ripple-Wave Stepper** built using pure HTML and CSS for the EaseMotion CSS library. The design features animated ripple effects, glowing connectors, smooth hover interactions, floating cards, and responsive layouts suitable for SaaS onboarding, workflows, timelines, and product setup pages.

---

## Features

- 🌊 Ripple-wave animated step indicators
- ✨ Glowing connector animation
- 🎯 Interactive hover effects
- 📱 Fully responsive layout
- ♿ Accessible markup
- 🎨 Pure HTML & CSS
- ⚡ Lightweight with no JavaScript
- 🌙 Modern SaaS-inspired UI
- 🛠 CSS Custom Properties
- ♻ Supports `prefers-reduced-motion`

1. Open `demo.html`
2. Ensure `style.css` is in the same folder.
3. Customize colors using CSS variables.
4. Integrate the stepper into any SaaS onboarding or workflow UI.
