# CSS Letter-by-letter Decode

A pure CSS text animation that reveals letters from random characters into the final text one character at a time.

## Features

- Pure HTML and CSS
- Letter-by-letter staggered reveal
- Random placeholder characters before decoding
- Smooth blur, scale, and translate transitions
- Fully responsive
- No JavaScript required
- CSS custom properties for easy customization
- `prefers-reduced-motion` accessibility support
