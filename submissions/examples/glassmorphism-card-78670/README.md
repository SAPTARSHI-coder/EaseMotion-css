# Glassmorphism Card

Showcase for issue #78670.

## Files

- `demo.html` — semantic card markup.
- `style.css` — glass surface, spacing, responsive rules, and focus states.

## Features

- Translucent glass surface.
- Soft border and shadow treatment.
- Responsive sizing.
- Keyboard-visible link focus.

Open `demo.html` in a browser to view the component.
