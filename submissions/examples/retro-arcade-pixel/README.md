# CSS Modal: Retro Arcade Pixel

A pure HTML and Vanilla CSS modal inspired by classic arcade
machines, pixel interfaces and CRT displays.

## Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Retro arcade visual style
- Pixel-inspired borders and shadows
- CRT scanline overlay
- Neon arcade colors
- Pixel-style entrance animation
- Responsive design
- Accessible dialog markup
- Keyboard focus states
- Reduced-motion support
- Dark-mode-friendly design
- Hardware-accelerated transforms
