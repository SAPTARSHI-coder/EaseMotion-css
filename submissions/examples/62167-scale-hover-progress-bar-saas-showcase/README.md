# CSS Scale-Hover Progress Bar for SaaS Showcase Layouts

A modern **Scale-Hover Progress Bar** built with pure **HTML5** and **CSS3** for the EaseMotion CSS showcase collection.

This component presents elegant SaaS progress cards with animated gradient progress bars, hover scale interactions, responsive layouts, and accessibility-friendly motion support without requiring JavaScript.

---

## Features

- Pure HTML5 & CSS3
- Scale-hover card animation
- Animated gradient progress bars
- Smooth CSS transitions
- Glassmorphism-inspired design
- SaaS dashboard style layout
- Fully responsive
- CSS Custom Properties
- Accessible with `prefers-reduced-motion`
- No JavaScript required

## CSS Variables

```css
:root{
    --bg:#eef4ff;
    --surface:#ffffff;
    --primary:#5b5df0;
    --secondary:#7c5cff;
    --accent:#00d4ff;
    --text:#1b2235;
    --muted:#72809a;
    --radius:22px;
    --shadow:0 20px 45px rgba(38,52,120,.15);
    --transition:.35s ease;
}
```

Customize these variables to quickly update colors, shadows, spacing, and animation speed.
