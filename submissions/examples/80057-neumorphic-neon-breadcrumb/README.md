# Neumorphic Neon Breadcrumb

A responsive breadcrumb navigation component combining a soft neumorphic
interface with subtle neon accents.

Created for **EaseMotion CSS – Issue #80057**.

## Features

- Fully responsive breadcrumb navigation
- Neumorphic depth using layered shadows
- Neon accent for active navigation
- Smooth hover interactions
- Accessible breadcrumb structure
- Keyboard focus styling
- Mobile-friendly layout
- Compact mobile scrolling variant
- Pure HTML and CSS
- No external dependencies
- Reduced-motion support
