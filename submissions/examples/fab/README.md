# Minimalist Floating Action Button (FAB) Accessibility Setup

A lightweight, accessible Floating Action Button implementation designed for screen readers and keyboard navigation.

## HTML Markup Examples

### Standard Icon-Only FAB
```html
<button type="button" class="fab" aria-label="Create new item">
  <svg class="fab__icon" viewBox="0 0 24 24" aria-hidden="true" focusable="false">
    <path d="M19 13h-6v6h-2v-6H5v-2h6V5h2v6h6v2z"/>
  </svg>
</button>
