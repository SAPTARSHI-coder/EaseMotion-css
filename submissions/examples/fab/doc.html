Minimalist Floating Action Button (FAB) Documentation

A guide to responsive, accessible, and themeable floating action buttons.

HTML Markup Example

Ensure you use a standard <button> element to inherit native focus states and keyboard interactivity.

<!-- Standard Minimalist FAB -->
<button 
  type="button" 
  class="fab" 
  aria-label="Create new item">
  <svg class="fab__icon" aria-hidden="true" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">
    <line x1="12" y1="5" x2="12" y2="19"></line>
    <line x1="5" y1="12" x2="19" y2="12"></line>
  </svg>
</button>

<!-- Extended FAB (Icon + Text) -->
<button 
  type="button" 
  class="fab fab--extended" 
  aria-label="Create new post">
  <svg class="fab__icon" aria-hidden="true" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">
    <line x1="12" y1="5" x2="12" y2="19"></line>
    <line x1="5" y1="12" x2="19" y2="12"></line>
  </svg>
  <span class="fab__label">New Post</span>
</button>

Accessibility & Keyboard Navigation

  • Focus Management: Always maintain a visible outline using :focus-visible for keyboard users.
  • Screen Readers: Use aria-label on icon-only FABs to explicitly state the action. Mark decorative SVG icons with aria-hidden="true".
  • Keybindings: Native <button> elements automatically activate on Enter and Space keys.
