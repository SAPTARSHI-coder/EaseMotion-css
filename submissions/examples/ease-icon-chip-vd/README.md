# Ease Icon Chip

## What does this do?

A rounded chip component containing an icon and a label.

---

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<div class="icon-chip">
    <span class="chip-icon">★</span>
    <span>Featured</span>
</div>
```

### Features

- Icon support
- Text label
- Rounded design
- Hover animation
- Icon scale animation
- Responsive layout
- Lightweight and reusable

---

## Why is it useful?

Icon chips are commonly used for filters, categories, tags, and labels.

This component provides a simple and reusable way to combine an icon with a short label while adding subtle interaction feedback in line with the animation-first philosophy of EaseMotion CSS.
