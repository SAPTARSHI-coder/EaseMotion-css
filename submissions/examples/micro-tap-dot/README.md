# Micro Tap Dot

A tap target that responds with a shrinking dot, like a press leaves a fingerprint.

## Features
- Press prints a fading dot
- Dot shrinks while expanding its ring
- Target darkens briefly on contact

## Usage
```html
<div class="mt-target">
  TAP
  <span class="mt-dot"></span>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
