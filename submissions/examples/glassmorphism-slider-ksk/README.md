# Minimalist Glassmorphism Slider

> Issue: [#79868](https://github.com/SAPTARSHI-coder/EaseMotion-css/issues/79868) / [#40080](https://github.com/SAPTARSHI-coder/EaseMotion-css/issues/40080)

A responsive, lightweight glassmorphism slider combining native custom range inputs and scroll-snap cards.

---

## ✨ Features & Architectural Highlights

- **Pure Native CSS Implementation:** Uses HTML5 `<input type="range">` and CSS `scroll-snap-type` instead of heavy JavaScript carousel libraries.
- **Glassmorphic Aesthetics:** Built using `backdrop-filter: blur()`, subtle translucent borders, and glowing accents.
- **Accessible & Responsive:** Adapts to all viewports with full `prefers-reduced-motion` support.

---

## 🚀 Usage

1. Include `style.css` in your HTML `<head>`:
   ```html
   <link rel="stylesheet" href="style.css" />
   ```
2. Use the `.glass-container` and `.glass-range-input` components from `demo.html`.
