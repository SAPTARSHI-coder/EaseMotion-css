CSS anchor-size()
Responsive Anchored Elements

Size positioned elements relative to their anchor using anchor-size(width|height). Tooltips, popups, and dropdowns that match their trigger's dimensions automatically — no JavaScript, no getBoundingClientRect(), no resize observers.

1. Match Anchor Width

Tooltip width locked to the trigger via width: anchor-size(width).

Fixed-width trigger

Hover to reveal a tooltip that matches the button's width exactly. Resize the button and the tooltip follows.

This tooltip is anchor-size(width) — exactly as wide as the button above

How it works

.trigger { anchor-name: --btn; }
.tooltip {
  position: fixed;
  position-anchor: --btn;
  position-area: bottom;
  width: anchor-size(width);
}

The tooltip inherits the anchor's width dynamically. No hard-coded pixel values. If the button changes size (responsive, translation, dynamic content), the tooltip follows.

4. Multi-Anchor Sizing

Width anchored to button A, positioned below button A. Shows how different elements can share sizing information.

Two anchors, one sized element

Width matches anchor A (the wide button below)

How it works

.wide-btn { anchor-name: --a; }
.narrow-btn { anchor-name: --b; }

.combined {
  position-anchor: --a;
  width: anchor-size(width);
  /* anchored to A, sized from A */
}

5. Constrained anchor-size()

Use clamp() with anchor-size() for min/max constraints — no tooltip wider than 400px, no narrower than 180px.

Clamped to anchor width

Width: clamp(180px, anchor-size(width), 400px) — matches the button but stays within bounds.

How it works

width: clamp(
  180px,
  anchor-size(width),
  400px
);

anchor-size() is just a length — use it anywhere lengths are accepted: calc(), clamp(), min(), max().

6. inset-area + anchor-size()

Combine with inset-area (span keywords) to create adaptive panels that span across the anchor position.

Span-right popup

inset-area: bottom span-right + anchor-size(width)

How it works

.popup {
  position: fixed;
  position-anchor: --btn;
  inset-area: bottom span-right;
  width: anchor-size(width);
}

The element aligns to the bottom of the anchor and spans across the anchor's width to the right edge.
