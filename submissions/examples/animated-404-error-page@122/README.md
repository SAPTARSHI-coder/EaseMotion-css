# Animated 404 Error Page

A creative **404 Error Page** built with **EaseMotion CSS**. Features glitch text effects, floating astronaut illustration, animated background grid, search functionality, and quick navigation links.

## ✨ Features

- **🔢 Glitch 404 Text**: Animated glitch effect with color separation
- **👨‍🚀 CSS Astronaut**: Pure CSS floating astronaut illustration
- **🌌 Animated Background**: Moving grid and floating shapes
- **⭐ Twinkling Stars**: Animated star elements
- **🪐 Rotating Planets**: CSS planets with rotation animation
- **🔍 Search Bar**: Functional search input for finding content
- **🔗 Quick Links**: Popular destination shortcuts
- **📋 Error Details**: Technical error information display
- **🎬 Staggered Entrance**: All sections slide up sequentially
- **📱 Fully Responsive**: Adapts to all screen sizes

## 🧩 EaseMotion Classes Used

| Class | Purpose |
|-------|---------|
| `ease-fade-in` | Fades in the main page, astronaut, and footer |
| `ease-slide-up` | Slides sections up on entrance |
| `ease-delay-100` to `ease-delay-800` | Creates cascading staggered sequence |
| `ease-card` | Base card structure for search and details |
| `ease-hover-grow` | Scale effect on buttons and links |
| `ease-center` | Centers search button content |
| `ease-btn` + `ease-btn-primary` | Styled home button |
| `ease-pulse` | **Looping pulse** on astronaut |

## 🚀 How to Use

1. Open `demo.html` in any modern browser
2. Watch all sections slide in with staggered animations
3. Observe the **glitch effect** on the 404 text
4. Watch the **astronaut float** and **planets rotate**
5. Notice the **moving grid background**
6. Test the search bar and quick links
7. Resize to mobile to see responsive layout
