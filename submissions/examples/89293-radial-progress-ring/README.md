# Radial Progress Ring Component

An animated circular progress indicator using pure CSS SVG stroke offset keyframe animations.

## Features
- **SVG Stroke Animations:** Smooth `stroke-dashoffset` translation for percentage completion.
- **Center Label Placement:** Centered percentage value badge.
- **Zero JavaScript:** Fully responsive and animated using pure CSS keyframes.

## File Structure
- `demo.html` - SVG progress ring markup and percentage label.
- `style.css` - Stroke properties, dashoffset animations, and center label alignment.
