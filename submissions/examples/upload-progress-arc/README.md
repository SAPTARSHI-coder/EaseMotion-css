# Upload Progress Arc

A CSS-only upload status card with a rotating progress arc, animated file queue rows, and active transfer highlighting.

## Features

- Conic-gradient progress arc with subtle rotation and glow.
- Staggered file queue rows using CSS custom properties.
- Active upload row with animated progress bar treatment.
- Responsive layout and reduced-motion support.

## Files

- `demo.html` - upload status markup with progress and file rows.
- `style.css` - card layout, progress arc animation, file queue states, and responsive styling.

## How to Use

Open `demo.html` in a browser and hover over the upload card to preview the active transfer motion.
