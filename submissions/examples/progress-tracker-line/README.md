# Progress Tracker Line

A horizontal tracker with moving ticks and a filling line shows step progress.

## Features
- Filling connector line
- Animated ticker dots
- Clean step labels
- Pure CSS

## Usage
```html
<span class="ptl-dot">1</span>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
