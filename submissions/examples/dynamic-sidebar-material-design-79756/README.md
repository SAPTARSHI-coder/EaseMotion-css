# Dynamic Sidebar with Material Design Styling

A responsive sidebar component inspired by Material Design principles using pure HTML and CSS.

## Features

- Material Design aesthetics
- Dynamic hover interactions
- Active navigation state
- Fully responsive layout
- Mobile-friendly navigation
- Lightweight implementation

## Files

- demo.html
- style.css

## Usage

Open `demo.html` in a modern browser.

## Customization

### Change Primary Color

```css
.sidebar a.active{
  background:#1976d2;
}
```

### Adjust Sidebar Width

```css
.sidebar{
  width:300px;
}
```

### Modify Hover Effect

```css
.sidebar a:hover{
  transform:translateX(10px);
}
```
