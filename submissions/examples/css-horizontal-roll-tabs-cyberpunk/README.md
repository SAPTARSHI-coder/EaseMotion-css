# CSS Horizontal Roll Tabs for Cyberpunk Neon Layouts

A futuristic pure CSS animated tab component designed for cyberpunk neon interface layouts.

The **CSS Horizontal Roll Tabs** component provides a smooth horizontal rolling interaction with neon glow effects, cyberpunk styling, responsive behavior, and customizable CSS variables without JavaScript.


## ✨ Features

- Pure HTML5 and CSS3 implementation
- Zero JavaScript dependency
- Smooth horizontal roll animation
- Cyberpunk neon interface styling
- Futuristic glow effects
- Neon shimmer hover animation
- Responsive tab navigation
- CSS custom property support
- Lightweight animation performance
- Keyboard accessible focus states
- prefers-reduced-motion support

🎨 CSS Custom Properties

Animation values can be customized using CSS variables.

:root {

    --roll-distance: 35px;

    --animation-time: .45s;

    --hover-scale: 1.08;

}
⚙️ Custom Parameters
Variable	Description
--roll-distance	Controls horizontal movement distance
--animation-time	Controls transition duration
--hover-scale	Controls hover scaling amount
