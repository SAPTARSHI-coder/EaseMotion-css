# CSS Scale-Hover Tooltip for Fintech Dashboard Layouts

A modern CSS-only tooltip component designed for fintech dashboards with smooth scale hover animations, glowing effects, and responsive card layouts.

This component provides interactive financial information cards without using JavaScript or external dependencies.

## ✨ Features

- 🔍 Smooth scale-hover tooltip animation
- 💳 Fintech dashboard inspired card design
- ✨ Neon glow hover effects
- 🎨 Glassmorphism UI styling
- ⚡ Pure HTML and CSS implementation
- 📱 Fully responsive layout
- 🔄 Smooth CSS transitions
- ♿ Accessibility support with `prefers-reduced-motion`

## 🚀 Usage

1. Clone the EaseMotion CSS repository.

2. Navigate to:


submissions/examples/ease-css-scale-hover-tooltip-fintech-dashboard-layouts/


3. Open `demo.html` in your browser.

No frameworks, JavaScript, or external libraries are required.

## 🎨 CSS Custom Properties

The component uses CSS variables for easy customization:

```css
:root {
    --bg: #050816;
    --primary: #00f5ff;
    --secondary: #8b5cf6;
    --green: #22c55e;
    --text: #f8fafc;
    --muted: #94a3b8;
}

Update these variables to match your dashboard branding.
