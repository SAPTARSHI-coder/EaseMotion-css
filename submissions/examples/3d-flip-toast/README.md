# CSS 3D-Flip Toast

A lightweight fintech dashboard toast notification using a pure CSS 3D flip entrance animation.

## Features

- Pure HTML and CSS
- No JavaScript
- No external libraries
- CSS 3D perspective
- Flip entrance animation
- Responsive dashboard
- Mobile-friendly toast
- Accessible notification
- Reduced-motion support
