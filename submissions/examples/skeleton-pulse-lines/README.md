# Skeleton Pulse Lines

A shimmering skeleton layout of lines and an avatar that pulses while content loads.

## Features
- Pulsing translucent blocks
- Avatar + line skeleton layout
- Gradient shimmer sweep
- Pure CSS

## Usage
```html
<div class="spl-line" style="--w:60%"></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
