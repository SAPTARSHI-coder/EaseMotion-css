# Foucault Pendulum Swing Toggle (#73891)

A pure HTML & Vanilla CSS toggle featuring a pendulum swing animation effect.

## Features
- **Aesthetic:** Swinging pendulum thumb with smooth easing trajectory.
- **Pure CSS:** Zero JavaScript dependencies; relies on standard checkbox states.
- **Performance:** Hardware-accelerated using `transform` and `will-change`.
- **Accessibility:** Keyboard focus ring support and `@media (prefers-reduced-motion: reduce)` query integration.
