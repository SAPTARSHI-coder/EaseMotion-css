# CSS Glitch-Flicker Accordion for SaaS Showcase Layouts

A modern accordion component built with **pure HTML and CSS** featuring a glitch-inspired flicker animation, smooth expand/collapse transitions, responsive design, and accessibility support.

## Features

- ⚡ Pure HTML5 & CSS3
- ✨ Glitch flicker opening animation
- 🎨 Modern SaaS UI
- 📱 Fully responsive
- ♿ Accessible semantic `<details>` accordion
- 🚀 Hardware-accelerated animations
- 🌙 Dark theme
- 🎯 CSS Custom Properties
- ♻️ `prefers-reduced-motion` support
