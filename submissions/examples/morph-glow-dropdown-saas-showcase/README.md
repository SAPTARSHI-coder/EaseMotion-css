# CSS Morph-Glow Dropdown for SaaS Showcase Layouts

A modern **Morph-Glow Dropdown** component built using only **HTML5 and CSS3**. This showcase demonstrates elegant SaaS navigation menus featuring morphing hover effects, glowing gradients, glassmorphism styling, and smooth dropdown animations.

---

## Features

- ✨ Morph-Glow hover animation
- 🌈 Gradient glow effects
- 💎 Glassmorphism dropdown panels
- 🚀 Pure HTML & CSS
- 📱 Fully responsive
- ♿ Accessibility with `prefers-reduced-motion`
- 🎨 CSS Custom Properties
- ⚡ Smooth transitions and animations

## Accessibility

Supports users who prefer reduced motion:

```css
@media (prefers-reduced-motion: reduce)
```

Animations and transitions are disabled automatically.
