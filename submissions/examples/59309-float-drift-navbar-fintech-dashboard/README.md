# CSS Float-Drift Navbar for Fintech Dashboard Layouts

A modern **Float-Drift Navbar** component built using pure HTML5 and CSS3 for fintech dashboard layouts. This component provides a smooth floating navigation experience with animated drift effects, glassmorphism styling, responsive behavior, and accessibility support.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Fintech dashboard navigation design
* Smooth floating drift animation
* Glassmorphism navbar effect
* Animated navigation links
* Active navigation highlight
* Hover elevation effects
* Financial dashboard cards
* Responsive desktop, tablet, and mobile layouts
* CSS Custom Properties support
* Lightweight keyframe animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. View the floating animated fintech navigation bar.
3. Hover over navigation links and dashboard cards for interactive effects.
4. Customize colors, shadows, spacing, and animation speed using CSS variables.
