# Bento Grid Spotlight Reveal Component

An asymmetric Bento Grid dashboard layout featuring radial gradient hover spotlight reveals and keyboard accessibility.

## 1. What does this do?
Organizes content modules into an asymmetric grid (bento layout) with interactive radial gradient spotlight glow effects that track interaction and focus.

## 2. How is it used?
1. Link `style.css` in your HTML document.
2. Build grid containers using `.bento-grid` and apply `.bento-card`, `.bento-wide`, or `.bento-tall` class modifiers.
3. Include `tabindex="0"` on cards to support keyboard navigation focus spotlighting.

## 3. Why is it useful?
- **Modern Dashboard Aesthetics**: Asymmetric bento grids are ideal for modern SaaS feature showcases and tech portfolios.
- **Pure CSS Radial Lighting**: Creates high-end lighting highlights on interaction without runtime performance cost.
- **Fully Responsive**: Gracefully collapses multi-column spans into single-column layouts for small mobile devices.
