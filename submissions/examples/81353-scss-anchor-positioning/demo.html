SCSS API

Reusable Helper Mixins

These mixins demonstrate how anchor names and position anchors can be abstracted into reusable helpers. 

// Define an anchor on the reference element.
@mixin anchor-reference(
  $name: --ease-anchor
) {
  anchor-name: $name;
}

// Attach the positioned element to an anchor.
@mixin anchor-target(
  $anchor: --ease-anchor
) {
  position-anchor: $anchor;
}

// Align below the anchor's start edge.
@mixin anchor-bottom-start(
  $anchor: --ease-anchor,
  $gap: var(--ease-anchor-gap, 0.5rem)
) {
  position: absolute;
  position-anchor: $anchor;

  top: anchor(bottom);
  left: anchor(left);

  margin-top: $gap;
}

// Align above and center the target horizontally.
@mixin anchor-top-center(
  $anchor: --ease-anchor,
  $gap: var(--ease-anchor-gap, 0.5rem)
) {
  position: absolute;
  position-anchor: $anchor;

  bottom: anchor(top);
  left: anchor(50%);

  margin-bottom: $gap;
  transform: translateX(-50%);
}

// Align beside the anchor and center vertically.
@mixin anchor-end-center(
  $anchor: --ease-anchor,
  $gap: var(--ease-anchor-gap, 0.5rem)
) {
  position: absolute;
  position-anchor: $anchor;

  top: anchor(50%);
  left: anchor(right);

  margin-left: $gap;
  transform: translateY(-50%);
}
Compatibility

Progressive Enhancement

Anchor positioning is used when supported. The demo keeps conventional absolute positioning as a fallback so the component remains usable in browsers without anchor support.
