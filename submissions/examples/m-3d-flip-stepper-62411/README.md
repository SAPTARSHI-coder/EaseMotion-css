# CSS 3D-Flip Stepper for Product Catalog Layouts

A modern **3D-Flip Stepper** built using pure HTML and CSS. The component features interactive 3D flip effects, responsive layouts, CSS custom properties, and lightweight styling suitable for product catalog workflows.

## ✨ Features

- Pure HTML5 & CSS3
- 3D flip hover animation
- Responsive stepper layout
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
