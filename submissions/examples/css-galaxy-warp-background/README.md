# CSS Galaxy Warp Background

A pure CSS hyperspace-style background where stars travel outward from the center and stretch toward the viewer.

## Features

- Pure CSS implementation
- No JavaScript required
- Hyperspace-style star warp effect
- Multiple independently animated stars
- Responsive across screen sizes
- CSS custom properties for easy customization
- Supports `prefers-reduced-motion`
- Self-contained demo

## Usage

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
<div class="galaxy-warp" aria-hidden="true">
  <span class="star star-1"></span>
  <span class="star star-2"></span>
  <span class="star star-3"></span>
</div>
