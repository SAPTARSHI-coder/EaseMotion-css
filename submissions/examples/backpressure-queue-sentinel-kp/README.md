# Backpressure Queue Sentinel

Backpressure Queue Sentinel is an advanced CSS animation that visualizes queue depth, worker pressure, and graceful shedding during traffic spikes. The demo uses layered queue lanes, animated pressure pulses, and reduced-motion fallbacks to show how a system slows intake before failures cascade.

## Features

- Responsive queue dashboard layout
- Pressure waves and worker heartbeat animation
- Accessible labels and semantic status regions
- Pure HTML and CSS implementation
