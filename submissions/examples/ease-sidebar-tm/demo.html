Off-Canvas Sidebar Navigation

CSS-only — Issue #63671

Click the "Open Sidebar" button above to reveal the sliding navigation panel. The sidebar slides in from the left with a smooth animation. An overlay dims the background content. The hamburger icon animates into an X. This is achieved entirely with CSS using the checkbox hack — no JavaScript required for the open/close animation.

The sidebar includes sections for navigation, workspace tools, and settings. Each section has a header label. Active items are highlighted in the accent color, and items with badges show a notification count.

Resize the browser window to see the mobile-friendly behavior — the sidebar takes 85% of the viewport width on small screens.
