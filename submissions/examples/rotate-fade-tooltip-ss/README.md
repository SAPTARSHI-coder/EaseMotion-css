# Rotate Fade Tooltip

A lightweight, responsive tooltip component featuring a smooth rotate-and-fade animation for creative portfolio layouts. Built entirely with HTML and CSS, this showcase demonstrates elegant micro-interactions without requiring JavaScript.

## Features

- Pure HTML5 and CSS3
- Smooth rotate and fade tooltip animation
- Responsive portfolio card layout
- Image hover zoom effect
- CSS Custom Properties for easy customization
- Keyboard-accessible focus styles
- Supports `prefers-reduced-motion`
- Lightweight and performance-friendly

## Folder Structure

```text
submissions/

    └── rotate-fade-tooltip/
        ├── demo.html
        ├── style.css
        └── README.md
```

## Usage

1. Copy the `rotate-fade-tooltip` folder into `submissions/examples/`.
2. Ensure the EaseMotion CSS library is correctly linked in `demo.html`.
3. Open `demo.html` directly in any modern browser.
4. Hover over or focus the **Project Info** button to display the animated tooltip.

## CSS Custom Properties

| Variable | Description |
|----------|-------------|
| `--bg-color` | Page background color |
| `--surface` | Card background color |
| `--text-color` | Primary text color |
| `--muted-color` | Secondary text color |
| `--accent` | Primary button color |
| `--accent-hover` | Button hover color |
| `--tooltip-bg` | Tooltip background color |
| `--tooltip-text` | Tooltip text color |
| `--radius` | Card border radius |
| `--shadow` | Card shadow |
| `--transition` | Global transition timing |
