# 🔍 CSS Zoom-In Stepper for Glassmorphism UI Layouts


## 🎯 Overview

A modern **pure CSS Zoom-In Stepper component** designed with a glassmorphism interface.

This component provides a smooth step progression UI using CSS transforms, animations, and translucent glass effects without requiring JavaScript or external libraries.


## ✨ Features

- Pure HTML & CSS implementation
- Glassmorphism inspired UI
- Smooth zoom-in step animations
- Responsive design for desktop, tablet, and mobile
- Lightweight and framework independent
- CSS custom properties for easy customization
- Accessible reduced-motion support
