# Subtle Elevate Toast

A clean and minimal notification toast featuring a subtle elevated
interaction effect using pure HTML and Vanilla CSS.

## Features

- Subtle elevated hover effect
- Smooth entrance animation
- Layered soft shadows
- Minimal gradient surface
- Soft border highlight
- Light mode support
- Dark mode support
- Responsive design
- Accessible notification semantics
- Keyboard focus support
- Reduced-motion support
- No external dependencies

## Preview

The toast uses restrained shadows, a soft surface gradient, and a
small upward elevation on hover to create a polished UI without
excessive visual effects.
