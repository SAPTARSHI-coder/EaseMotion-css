# Subtle Elevate Neumorphic UI

A pure CSS neumorphic UI component featuring a subtle elevated surface,
soft layered shadows, smooth interactions, responsive layout, and
accessible focus states.

## Features

- Pure HTML and vanilla CSS
- Soft neumorphic elevation
- Smooth hover and active states
- Responsive layout
- Dark mode support
- `prefers-reduced-motion` support
- Keyboard-friendly focus states
- No JavaScript
- No external dependencies

## Files

- `demo.html` — standalone demonstration
- `style.css` — component styles

## Usage

Add the component structure to your HTML:

```html
<section class="neumorphic-card">
  <div class="icon">✦</div>

  <p class="eyebrow">NEUMORPHIC UI</p>

  <h1>Subtle Elevate</h1>

  <p class="description">
    A soft and minimal neumorphic component.
  </p>

  <div class="actions">
    <button class="elevate-button">Explore</button>
    <button class="secondary-button">Learn More</button>
  </div>
</section>
