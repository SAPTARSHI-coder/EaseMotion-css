# Rotate-Fade Progress Bar for Glassmorphism UI Layouts

## Overview

A modern CSS-only animated progress bar component featuring rotate and fade effects with a glassmorphism inspired interface.

## Features

- Pure HTML and CSS
- Rotate glow animation
- Fade transition effects
- Glassmorphism card design
- Responsive layout
- Reduced motion accessibility support
