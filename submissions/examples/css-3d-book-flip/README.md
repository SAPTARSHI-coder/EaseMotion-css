# CSS 3D Book Flip

A realistic 3D book that smoothly flips its cover page open on hover.

## Features
- Deep 3D environment established via `perspective: 1200px` on the body.
- The `transform-origin: left center` on the cover anchors the hinge of the book.
- Realistic hover interaction using `rotateY(-150deg)` to open the book cover.
