# Parallax Relic

A mysterious interactive artifact built with layered parallax.

Parallax Relic creates the illusion of a deep physical object by moving multiple visual layers at different speeds according to pointer position.

## ✨ Features

- Multi-layer parallax
- Interactive artifact
- Pointer-driven lighting
- Animated central core
- Floating particles
- Geometric symbols
- Rotating artifact ring
- Animated scan line
- Responsive design
- Touch support
- Reduced-motion support
- Dependency-free
- Vanilla JavaScript
