# Kaleidoscope Burst

A hypnotic kaleidoscope of rotating petals built from conic gradients and masks.

## Features
- Petals spin on offset loops
- Conic gradient feeds the mandala
- Slow counter-rotation adds depth

## Usage
```html
<div class="kb-scene">
  <div class="kb-petal"></div>
  <div class="kb-core"></div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
