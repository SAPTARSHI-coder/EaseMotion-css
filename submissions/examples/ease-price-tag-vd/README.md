# Ease Price Tag

## What does this do?

A compact rounded price tag badge for displaying product prices with multiple color variants and a subtle hover animation.

---

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<span class="price-tag blue">
    $29
</span>
```

### Available variants

```html
<span class="price-tag blue">$29</span>
<span class="price-tag green">$49</span>
<span class="price-tag orange">$79</span>
<span class="price-tag purple">$99</span>
```

### Features

- Price label
- Rounded design
- Multiple color variants
- Hover animation
- Responsive layout
- Lightweight and reusable

---

## Why is it useful?

Price tags are commonly used in e-commerce product cards, pricing sections, offers, and shopping interfaces.

This component provides a simple and reusable price display with subtle interaction feedback while following the animation-first philosophy of EaseMotion CSS.
