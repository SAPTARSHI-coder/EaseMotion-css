# CSS Cyberpunk Neon UI Card

## Overview

A responsive cyberpunk-themed UI card using diagonal cuts, neon accents, scan textures, and animated CSS effects.

## Implementation

- Pure HTML and CSS
- No JavaScript dependencies
- Responsive layout
- Keyboard focus state
- Accessible semantic content
- Reduced-motion support

## Files

- `demo.html` — component markup and demo content
- `style.css` — complete visual design and animations

## Usage

Open `demo.html` in a modern browser.
