# Ease File Drop Zone (`ease-file-drop-zone`)

A file upload area with a smooth border and scale response when a file is dragged over the drop zone. Provides animation-first visual feedback without requiring external libraries.

## Features
- Smooth `scale(1.05)` lift on drag-over / focus
- Pulsing indigo glow ring via `box-shadow` animation
- Animated upload cloud icon with vertical float
- Elastic spring easing (`cubic-bezier(0.34, 1.56, 0.64, 1)`)
- `prefers-reduced-motion` support
- Pure CSS — zero JavaScript dependencies
