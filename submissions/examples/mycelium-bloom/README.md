# 🍄 Mycelium Bloom

An interactive underground fungal-network animation where glowing mycelium threads organically grow from a central spore, branch through the soil, connect to nutrient nodes, and trigger small bioluminescent blooms.

## ✨ Features

- 🍄 Central fungal spore
- 🌱 Organic branching network
- 🟢 8 nutrient nodes
- ✨ Glowing mycelium connections
- 🌸 Bioluminescent bloom effects
- 🎚️ 0-100% growth control
- 🌌 Underground particle system
- 📊 Real-time connected-node counter
- ⌨️ Keyboard controls
- 🖱️ Click-to-grow interaction
- 📱 Responsive layout
- 🚫 No external dependencies

## 🎯 What It Does

Mycelium Bloom turns the hidden growth of fungal networks into an interactive visual experience.

The animation starts with a dormant underground environment containing only a central fungal spore.

As growth increases, mycelium threads gradually spread outward and form curved paths toward nutrient nodes.

When a branch reaches a node, the node begins glowing and a small fungal bloom develops around it.

At 100% growth, the complete network becomes visible.

The network uses a continuous growth value between `0` and `100`.
