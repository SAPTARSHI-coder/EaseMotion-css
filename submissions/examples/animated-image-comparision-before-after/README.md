# ease-compare-slider

## Description

Adds a draggable before-and-after image comparison slider for showcasing visual changes, edits, designs, or transformations.

---

## Features

- Smooth comparison
- Lightweight
- Responsive
- Pure HTML, CSS & JavaScript
- Easy customization

---

## Usage

```html
<div class="compare-container">
    ...
</div>
```

Replace:

- before.jpg
- after.jpg

with your own images.

---

## Browser Support

- Chrome ✅
- Firefox ✅
- Edge ✅
- Safari ✅

---

## Customization

Default position

```css
width:50%;
```

Slider color

```css
accent-color:#2563eb;
```

Container width

```css
width:700px;
```
