# Animated Breadcrumb with SaaS Modern Styling

A modern, highly responsive breadcrumb component designed for SaaS applications. Features smooth CSS animations and hover effects.

## Features
- Pure CSS implementation
- SaaS modern aesthetics (soft borders, subtle shadows, muted text)
- Background slide-up animation on hover
- Bouncing home icon on hover
- Slide-in entrance animation for the active route
- Fully responsive

## Usage
Include `demo.html` and `style.css` in your project. The SVG separator icon is injected cleanly via CSS `::after` pseudo-element.
