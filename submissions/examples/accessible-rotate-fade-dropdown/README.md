# CSS Rotate-Fade Dropdown for Accessible Web Layouts

A modern **Accessible Dropdown Navigation** built entirely with **HTML5 and CSS3**. This showcase demonstrates a smooth **Rotate-Fade Dropdown** animation with keyboard accessibility, glassmorphism styling, responsive layouts, and accessibility support without requiring JavaScript.

---

## ✨ Features

- ♿ Accessible navigation dropdown
- 🔄 Rotate-Fade reveal animation
- ⌨️ Keyboard-friendly (`:focus-within`)
- 💎 Glassmorphism dropdown panel
- 🌈 Modern responsive interface
- 📱 Fully responsive
- ⚡ Pure HTML5 & CSS3
- 🎯 CSS Custom Properties
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

## 🚀 Getting Started

1. Open `demo.html` in any modern browser.
2. Hover over or focus on the **Components** button.
3. Navigate the dropdown using mouse or keyboard.
4. Customize colors, spacing, and animation timing using CSS variables.
