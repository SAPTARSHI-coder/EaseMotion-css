# SaaS Modern Announce Top Bar — Accessibility Setup

This example documents an accessible announcement top bar for SaaS
websites, product dashboards and modern web applications.

## Features

- Semantic announcement structure
- Accessible dismiss button
- Descriptive link text
- Keyboard-friendly controls
- Visible focus indicators
- Responsive layout
- Custom CSS properties
- Reduced-motion support
- No JavaScript dependency for the visual component
