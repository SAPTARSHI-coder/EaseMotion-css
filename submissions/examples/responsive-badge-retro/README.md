# Responsive Badge with Retro Styling

A colorful retro-inspired badge component built using only HTML and CSS.

## Features

- Pure HTML & CSS
- Responsive design
- Retro color palette
- Hover lift animation
- Multiple badge variants
- Easy to customize

## Files

- demo.html
- style.css
- README.md

## Usage

```html
<link rel="stylesheet" href="style.css">

<span class="badge gold">NEW</span>
<span class="badge blue">POPULAR</span>
<span class="badge green">FEATURED</span>
<span class="badge pink">LIMITED</span>
```

Open `demo.html` directly in your browser.

## Customization

- Add more badge colors
- Change border radius
- Modify shadow depth
- Update typography
