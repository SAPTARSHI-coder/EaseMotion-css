# Neumorphic Spinner Loader Ring

A lightweight neumorphic spinner loader with customizable CSS
properties and accessibility support.

## Features

- Neumorphic visual style
- Circular loading ring
- Configurable size and speed
- CSS custom property overrides
- Reduced-motion support
- Semantic loading status
- Hardware-accelerated transform

## HTML Usage

```html
<div
  class="spinner"
  role="status"
  aria-label="Loading"
  aria-live="polite"
></div>
