# CSS 3D-Flip Hero Section

A responsive fintech hero section featuring a pure CSS 3D flip interaction.

The hero contains an interactive dashboard card. Hovering or focusing the
card rotates it in 3D and reveals a security-focused back panel.

## Features

- Pure HTML and CSS
- No JavaScript
- CSS 3D perspective
- `rotateY()` flip animation
- Backface visibility
- Responsive hero layout
- Animated dashboard chart
- Keyboard focus support
- CSS custom properties
- `prefers-reduced-motion` support
- Mobile, tablet, and desktop layouts
