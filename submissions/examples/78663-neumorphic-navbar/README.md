# Interactive Neumorphic Navbar

A responsive interactive navbar featuring a soft neumorphic visual style,
tactile controls, smooth interactions, and a CSS-only mobile menu.

## Features

- Neumorphic UI styling
- Responsive desktop and mobile layouts
- CSS-only mobile navigation
- Active navigation state
- Soft inset and raised shadows
- Tactile hover effects
- Responsive hero section
- Feature cards
- Keyboard-accessible controls
- Visible focus states
- Reduced-motion support
- No JavaScript
- No external dependencies

## Files

- `demo.html`
- `style.css`

## Usage

Open `demo.html` directly in a browser.

The mobile menu uses a hidden checkbox and CSS sibling selectors,
so JavaScript is not required.

## Technologies

- HTML5
- Vanilla CSS

## Accessibility

The component uses semantic navigation, descriptive labels, keyboard-focus
styles, and `prefers-reduced-motion` support.

## Responsive Behavior

- Desktop: horizontal navigation with action buttons
- Tablet: compact navigation with CSS-only menu
- Mobile: stacked navigation panel and responsive content
