# Glowing Filter Bar — Material Design

A responsive filter bar with Material-inspired surfaces,
elevation, glowing active states and smooth CSS interactions.

Built entirely with HTML and CSS for EaseMotion CSS.

## Features

- Material Design-inspired visual hierarchy
- Glowing active filter state
- Search field with focus glow
- Category filter chips
- Native radio controls
- Native checkbox controls
- Sort selector
- Reset action
- Material elevation shadows
- Animated accent line
- Resource preview cards
- Responsive layout
- Keyboard focus states
- Reduced-motion support
- Zero JavaScript dependencies

  ...
