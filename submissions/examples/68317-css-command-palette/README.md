# CSS Command Palette

## Overview

Spotlight-style command palette built with semantic HTML and CSS.

## Features

- Search-style command surface
- Suggested and navigation groups
- Keyboard shortcut hints
- Focus-visible states
- Responsive layout
- Reduced-motion support
- No JavaScript dependency

## Files

- `demo.html` — semantic command palette markup
- `style.css` — layout, states, responsive rules, and visual styling

## Usage

Open `demo.html` in a modern browser.
