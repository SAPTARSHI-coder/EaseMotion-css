Design notes

Keyboard-first by design

  • Semantic buttons make command rows independently focusable.
  • Visible focus treatment preserves orientation during keyboard navigation.
  • Shortcut hints remain secondary to the command name.
  • The layout collapses cleanly on narrow screens.
