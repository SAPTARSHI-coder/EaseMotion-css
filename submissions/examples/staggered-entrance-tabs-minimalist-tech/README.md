# Staggered Entrance Tabs — Minimalist Tech

A lightweight, responsive Tabs component featuring a subtle staggered entrance
animation designed for minimalist technology interfaces.

## Features

- Pure CSS
- Zero JavaScript
- Responsive layout
- Keyboard-focus support
- Staggered entrance animation
- CSS custom properties
- Reduced-motion support
- No external dependencies
- Works by opening `demo.html` directly
