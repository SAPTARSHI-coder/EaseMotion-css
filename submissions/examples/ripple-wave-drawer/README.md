# Ripple-Wave Drawer

A responsive off-canvas navigation drawer featuring a ripple-wave hover animation using only HTML and CSS.

## Features

- Pure HTML & CSS
- Ripple-wave hover animation
- Responsive layout
- Accessible checkbox toggle
- Smooth transitions
- prefers-reduced-motion support
- No JavaScript

## Files

```
demo.html
style.css
README.md
```

## Customization

Modify colors:

```css
background: #111827;
background: #2563eb;
```

Adjust drawer width:

```css
width:260px;
```

Adjust animation speed:

```css
transition:.45s;
```
