Document Direction: LTR (Left-to-Right)

This showcase demonstrates the usage of CSS Logical Properties across multiple UI components. Notice how margins, padding, absolute positioning, borders, and layouts natively mirror themselves when toggling the document's direction, without requiring a single [dir="rtl"] CSS override.
