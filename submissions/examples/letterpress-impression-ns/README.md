# Letterpress Impression

## What does this do?
Renders a self-contained CSS-only `ease-letterpress-impression` demo: Letterpress plate descending to stamp ink impression.

## How is it used?
Open `demo.html` in a browser. The animated face uses classes like `ease-letterpress-impression`, `ease-letterpress-impression__arm`, and `ease-letterpress-impression__core`. No build step or JavaScript is required for the motion.

```html
<section class="ease-letterpress-impression">
  <div class="ease-letterpress-impression__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
