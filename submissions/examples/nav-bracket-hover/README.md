# Nav Bracket Hover

Square brackets draw in around a nav link on hover.

## Features
- Bracket draw-in
- Hover-triggered
- Color shift
- Pure CSS

## Usage
```html
<a href="#" class="nbh-link">Work</a>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
