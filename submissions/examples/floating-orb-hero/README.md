# Floating Orb Hero

A soft glowing orb that drifts over a gradient hero backdrop with a halo ring.

## Features
- Orb floats on a gentle lissajous path
- Concentric halo rings pulse outward
- Backdrop shifts hue for depth

## Usage
```html
<div class="fh-scene">
  <div class="fh-orb"></div>
  <div class="fh-ring"></div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
