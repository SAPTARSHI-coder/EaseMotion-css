# Couillard Arm Throw

## What does this do?
Renders a self-contained CSS-only `ease-couillard-arm-throw` demo: Couillard trebuchet arm throw release.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-couillard-arm-throw`. No build step or JavaScript is required for the effect.

```html
<section class="ease-couillard-arm-throw">
  <div class="ease-couillard-arm-throw__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
