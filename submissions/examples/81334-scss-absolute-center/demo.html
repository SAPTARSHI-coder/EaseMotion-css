EaseMotion SCSS Helper

Absolute Center Transform

Reusable absolute-positioning patterns using top: 50%, left: 50%, and transform-based centering.

01

Absolute Center

Horizontal and vertical centering.

✦ Centered 50% / 50% 
@include absolute-center;
02

Absolute Center X

Horizontal centering only.

Centered X left: 50% 
@include absolute-center-x;
03

Absolute Center Y

Vertical centering only.

Centered Y top: 50% 
@include absolute-center-y;

SCSS Usage

@mixin absolute-center(
  $x: var(--ease-center-x, 50%),
  $y: var(--ease-center-y, 50%)
) {
  position: absolute;
  top: $y;
  left: $x;

  transform: translate(-50%, -50%);
}

.modal {
  @include absolute-center;
}
