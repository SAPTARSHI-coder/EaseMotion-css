💡 Hover / Click Controls

Hovering over either ticker bar will temporarily pause marquee motion. You can also click the top-right button to lock pause mode via pure CSS.

Ticker Specifications

🔄

Seamless Track Duplication

Uses CSS flexbox with duplicated track content moving from `0%` to `-100%` for continuous infinite scrolling.

⏸️

Zero-JS Pause State

Combines `.ticker-wrapper:hover` and checkbox `:checked` selectors to freeze `animation-play-state: paused` effortlessly.

🟢

Live Pulse Indicator

Features glowing radial keyframe rings mimicking real-time financial exchange status indicators.

♿

Reduced Motion Friendly

Automatically halts infinite scrolling animations when `@media (prefers-reduced-motion: reduce)` is detected.
