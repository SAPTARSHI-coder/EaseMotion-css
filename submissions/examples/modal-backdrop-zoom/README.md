# Modal Backdrop Zoom

This example adds a modal dialog composition with a fading backdrop and zooming panel entry.

## Files

- `demo.html` contains the dialog-like modal markup.
- `style.css` defines the backdrop fade, panel zoom, focus state, and reduced-motion fallback.

## Highlights

- Uses `role="dialog"` and `aria-modal="true"` in the demo markup.
- Keeps modal dimensions constrained across viewport sizes.
- Separates backdrop and panel animations for a polished entry.
- Disables animations for reduced-motion users.
