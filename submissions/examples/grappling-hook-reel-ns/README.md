# Ease Grappling Hook Reel

A CSS-only animated **Grappling Hook Reel** component for EaseMotion CSS.

This component represents an industrial rescue/recovery mechanism where a grappling hook launches and retracts using a cable reel animation.

## ✨ Features

- Pure HTML and CSS implementation
- No JavaScript required
- Real-world mechanical UI design
- Animated cable extension and retraction
- Rotating reel mechanism
- Moving grappling hook
- Responsive layout
- Reduced motion accessibility support

## 📂 Usage

Add the component:

```html
<div class="ease-grappling-hook-reel">
  <!-- grappling hook reel content -->
</div>
