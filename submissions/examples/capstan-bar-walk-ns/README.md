# Capstan Bar Walk

## What does this do?
Renders a self-contained CSS-only `ease-capstan-bar-walk` demo: Ship capstan bars walking sailors around.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-capstan-bar-walk`. No build step or JavaScript is required for the effect.

```html
<section class="ease-capstan-bar-walk">
  <div class="ease-capstan-bar-walk__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
