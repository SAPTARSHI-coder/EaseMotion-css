# CSS Nav: Cyberpunk Neon

A futuristic **Cyberpunk Neon Navigation** component built with pure HTML and Vanilla CSS.

The component combines neon cyan and magenta accents, glowing borders, scanline animation, grid visuals, and angular UI shapes to create a cyberpunk-inspired navigation system.

## ✨ Features

- Cyberpunk neon visual treatment
- Cyan and magenta glow effects
- Animated scanline
- Perspective grid background
- Luminous navigation indicators
- Angular clipped navigation container
- Smooth hover interactions
- Keyboard focus support
- Responsive layout
- Dark-mode compatible
- Reduced-motion support
- No JavaScript
- No external dependencies

## 🎨 Visual Treatment

The neon interface is created with layered gradients, shadows, and CSS variables.
