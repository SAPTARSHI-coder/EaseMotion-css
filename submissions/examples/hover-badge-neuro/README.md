
---

## 🚀 Usage
1. Clone or copy the files into your project.
2. Open `demo.html` in your browser.
3. Hover over the badge to see the neumorphic hover effect.

---

## 🛠️ Customization
- **Colors** → Adjust text and background colors in `.badge`.
- **Shadow depth** → Modify `box-shadow` values for stronger/weaker neumorphism.
- **Size** → Change `padding` and `font-size` for larger/smaller badges.

---

## 📖 Accessibility
- Badge is keyboard accessible and uses clear hover/focus states.
