# Select Chevron Rotate

A styled dropdown whose chevron flips and highlight spreads on open.

## Features
- Chevron rotation on focus-within
- Custom appearance removal
- Smooth gradient border glow
- Pure CSS

## Usage
```html
<div class="scr-box"><select>...</select><span class="scr-chev"></span></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
