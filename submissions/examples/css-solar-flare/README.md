# CSS Accordion: Solar Flare Radial Variation

A smooth, hardware-accelerated pure CSS accordion component showcasing a dynamic solar flare radial gradient effect upon expansion.

## Key Features

- **Solar Flare Effect**: Uses expanding radial gradients (`radial-gradient`) and subtle glowing outer drop-shadows on expand states.
- **Pure CSS Smooth Expand**: Employs CSS Grid row-height interpolation (`grid-template-rows: 0fr` $\rightarrow$ `1fr`) to transition smoothly to dynamic content heights without JavaScript.
- **Accessibility & Standards**: Leverages standard `<details>` and `<summary>` tags for native keyboard support (<kbd>Tab</kbd>, <kbd>Space</kbd>/<kbd>Enter</kbd>) and full dark-mode compatibility.
