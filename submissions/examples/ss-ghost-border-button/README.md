# CSS Ghost Border Button

A pure CSS outline button whose border animates around the perimeter when hovered or focused.

## Features

- Pure CSS implementation
- Animated perimeter border effect
- Responsive layout
- Keyboard accessible
- CSS custom properties for easy customization
- Light and dark mode support

## Usage

```html
<button class="ghost-btn">
  Hover Me
</button>
```

## File Structure

```text
css-ghost-border-button/
├── demo.html
├── style.css
└── README.md
```

## Customization

Edit the CSS variables:

```css
:root {
  --accent: #2563eb;
  --border-size: 2px;
}
```

## Why It Fits EaseMotion CSS

This component adds an elegant hover animation pattern that developers can easily integrate into forms, landing pages, and UI designs while remaining lightweight and JavaScript-free.
