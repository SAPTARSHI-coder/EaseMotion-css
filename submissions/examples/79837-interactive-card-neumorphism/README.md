# Interactive Card — Neumorphism

A responsive interactive card with a soft neumorphic visual
style, layered shadows, hover elevation, tactile controls,
and clean content structure.

Implemented for issue #79837.

## Features

- Neumorphic card styling
- Interactive hover elevation
- Soft raised and inset shadows
- Interactive favorite button
- Tactile button states
- Responsive layout
- Keyboard focus-visible states
- Reduced-motion support
- No JavaScript
- No external dependencies
