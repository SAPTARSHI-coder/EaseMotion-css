# Ease Theme Toggle (Sun/Moon Icon Morph)

A modern **Dark Mode Theme Toggle** built with HTML, CSS, and Vanilla JavaScript.

The component morphs from a **sun** into a **crescent moon** using pure CSS. The animation is created with `box-shadow` rays that fade away and a masking circle (`::before`) that slides across the icon—no SVGs or icon libraries required.

---

## Features

- Pure CSS Sun → Moon morph
- Animated sun rays using `box-shadow`
- Crescent moon masking animation
- Smooth theme transition
- Responsive design
- CSS Custom Properties
- Accessible toggle using checkbox input
- Lightweight Vanilla JavaScript

## Usage

1. Open `demo.html` in any modern browser.
2. Click the toggle to switch between light and dark mode.
3. Customize colors, size, and animation timing through CSS variables.
