# CSS Zoom-In Carousel for Product Catalog Layouts

A modern **Zoom-In Carousel** component built using pure HTML5 and CSS3 for product catalog showcase layouts. This component creates an engaging product browsing experience with zoom-focused cards, smooth scaling transitions, glassmorphism styling, and responsive behavior.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Smooth zoom-in focus animation
* Product catalog showcase layout
* Featured product highlighting
* Animated product cards
* Glassmorphism card design
* Hover scaling interactions
* Gradient badges
* Carousel indicator styling
* Responsive desktop, tablet, and mobile layouts
* CSS Custom Properties for easy customization
* Smooth keyframe animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over product cards to view the zoom-in focus effect.
3. Customize colors, shadows, spacing, and animations using CSS variables inside `:root`.

## CSS Custom Properties

```css
:root{
  --bg:#eef4ff;
  --surface:rgba(255,255,255,.92);
  --primary:#2563eb;
  --secondary:#06b6d4;
  --accent:#8b5cf6;
  --text:#111827;
  --muted:#64748b;
  --shadow:0 25px 60px rgba(37,99,235,.2);
  --radius:30px;
}
```
