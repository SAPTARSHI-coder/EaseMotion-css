# Neumorphic Slider with Dark Mode

A responsive CSS-based Neumorphic Slider component with a modern soft UI,
interactive range control, and dark mode support.

## Features

- Fully responsive design
- Neumorphic UI styling
- Interactive HTML range slider
- Live percentage value
- Dark mode toggle
- Smooth visual transitions
- Keyboard accessible slider
- Focus-visible states
- No external libraries
- Pure HTML, CSS, and JavaScript
- Mobile-friendly layout
- Supports reduced-motion preferences

## Technologies

- HTML5
- CSS3
- JavaScript
