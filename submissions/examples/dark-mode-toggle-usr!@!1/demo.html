How It Works

This component uses CSS custom properties (variables) to define color schemes for both light and dark themes. When the toggle is switched, the data-theme attribute on the HTML element changes, triggering a smooth transition between themes.

:root {
  --bg-primary: #ffffff;
  --text-primary: #1e293b;
}

[data-theme="dark"] {
  --bg-primary: #0f172a;
  --text-primary: #f8fafc;
}

The toggle switch uses a hidden checkbox with a custom-styled slider that animates between sun and moon icons. JavaScript handles the theme switching and localStorage persistence.
