# Input Shake Invalid

A text field shakes when its value is invalid and shows a red underline.

## Features
- Shake on :invalid / :user-invalid
- Red accent + message reveal
- Applies after user interaction
- Pure CSS

## Usage
```html
<input type="email" required />
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
