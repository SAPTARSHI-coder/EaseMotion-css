# CSS Scroll-Spy Navigation

A lightweight, pure CSS scroll-spy navigation component that highlights the active section while scrolling through a page.

## Features

- Pure HTML and CSS implementation
- No JavaScript or external dependencies
- Highlights the current navigation section using CSS scroll-driven behavior
- Smooth scrolling between sections
- Responsive layout for desktop, tablet, and mobile
- Accessible semantic navigation structure
- Supports `prefers-reduced-motion`
- Easy to customize with CSS custom properties
