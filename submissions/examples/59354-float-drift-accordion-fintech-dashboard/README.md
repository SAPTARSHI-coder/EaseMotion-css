# CSS Float-Drift Accordion for Fintech Dashboard Layouts

A modern **Float-Drift Accordion** component built using pure HTML5 and CSS3 for fintech dashboard layouts. This component combines smooth floating animations with an interactive accordion experience, glassmorphism design, and responsive behavior.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Fintech dashboard accordion layout
* Smooth float-drift animations
* CSS-only expand and collapse interaction
* Glassmorphism accordion cards
* Financial information panels
* Animated statistics sections
* Hover elevation effects
* Responsive desktop, tablet, and mobile layouts
* CSS Custom Properties support
* Lightweight keyframe animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Click accordion sections to expand financial details.
3. Customize colors, shadows, spacing, and animations using CSS variables.
