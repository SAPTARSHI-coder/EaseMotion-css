# 3D Spinner with Neon Styling

A modern 3D loading spinner created using pure HTML and CSS. The component combines rotating 3D effects with neon glow animations.

## ✨ Features

- 3D-inspired spinner
- Neon glow effects
- Multiple rotating layers
- Smooth CSS animations
- Pulsing center
- Animated loading text
- Fully responsive
- No JavaScript required
- No external dependencies

## 🛠️ Technologies

- HTML5
- CSS3
- CSS Animations
- CSS Transforms
- CSS Box Shadow

## 📁 Folder Structure

```text
3d-spinner-neon/
├── index.html
├── style.css
└── README.md
````

## 🚀 Usage

1. Open `index.html` in a modern browser.
2. The neon spinner will start automatically.
3. The animation is completely CSS-based.

## 🎨 Design

The component uses a dark background combined with bright neon cyan and magenta highlights. Multiple animated borders create a layered 3D spinner effect.

## 📱 Responsive Design

The spinner automatically adjusts its size on smaller screens using CSS media queries.

## ♿ Accessibility

The spinner includes an accessible loading label through `aria-label`.
