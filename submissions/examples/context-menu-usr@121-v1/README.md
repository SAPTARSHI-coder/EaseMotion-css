# Animated Context Menu Submission

## 1. What does this do?
It provides animated context menus with smooth entrance/exit animations, submenus, icons, keyboard shortcuts, and keyboard navigation. Perfect for modern web applications like Figma, Notion, VS Code, and Google Docs.

## 2. How is it used?
Right-click anywhere in the demo area to see the context menu. Click trigger buttons to see different menu variants (basic, with icons, with submenus). Right-click on items to see item-specific menus. Use keyboard arrows to navigate, Enter to select, Escape to close.

## 3. Why is it useful?
- Essential component for modern web applications
- Smooth scale and fade animations
- Multiple menu variants (basic, icons, submenus, item-specific)
- Nested submenus with smooth transitions
- Keyboard shortcuts display
- Full keyboard navigation (Arrow keys, Enter, Escape)
- Click outside to close functionality
- Auto-adjusts position to stay within viewport
- Danger action styling (delete)
- Menu dividers for organization
- Fully responsive design
- Accessible with ARIA labels and `prefers-reduced-motion` support
- Easy to customize colors, animations, and menu items
- Maintainer can easily standardize this as `.ease-context-menu-[YOUR_INITIALS]` in the core library.
