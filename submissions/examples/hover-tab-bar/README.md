# Hover Tab Bar – Minimalist Styling

A clean and responsive hover tab bar built using pure HTML and CSS.

## ✨ Features

* Minimalist and modern design
* Smooth hover animation
* Active tab indicator
* Fully responsive layout
* Keyboard focus support
* No JavaScript required
* Built with pure HTML and CSS

## 📁 Files

```text
hover-tab-bar/
├── index.html
├── style.css
└── README.md
```

## 🚀 Usage

1. Download or clone the repository.
2. Navigate to the `hover-tab-bar` folder.
3. Open `index.html` in any modern web browser.
4. Hover over the tabs to see the interaction.

## 🛠️ Technologies

* HTML5
* CSS3
* CSS Transitions
* CSS Media Queries

## 📱 Responsive Design

The tab bar automatically adapts to smaller screen sizes using CSS media queries, making it suitable for desktop, tablet, and mobile devices.

## 🎨 Customization

You can easily customize:

* Tab spacing
* Font size
* Border radius
* Hover colors
* Animation duration
* Active indicator width

## ♿ Accessibility

The component includes visible keyboard focus styling through `:focus-visible` for improved keyboard navigation.
