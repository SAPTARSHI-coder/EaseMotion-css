# Bounce-Pulse Carousel

A pure HTML and CSS carousel designed for cyberpunk and neon interface
layouts.

## Features

- Pure HTML and CSS
- No JavaScript or external frameworks
- Cyberpunk neon visual design
- Bounce-based active slide transition
- Pulsing neon glow
- Smooth carousel transitions
- Responsive desktop, tablet, and mobile layouts
- Accessible carousel controls
- `prefers-reduced-motion` support
- Customizable CSS variables
