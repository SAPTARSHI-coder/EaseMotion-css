# 3D Navbar - Gradient

A responsive 3D-inspired navigation bar built using HTML and CSS with layered depth and gradient styling.

## Features

- Fully responsive navigation
- 3D-inspired depth and perspective
- Gradient brand icon
- Gradient CTA button
- CSS-only mobile menu
- Interactive navigation states
- Floating 3D visual element
- Responsive hero section
- Reduced-motion support
- No external dependencies
- No JavaScript

## Files

- `demo.html` - Complete component markup
- `style.css` - Complete responsive styling

## Usage

Open `demo.html` in any modern browser.

On desktop, the navigation displays all links inline.

On smaller screens, the navigation transforms into a CSS-only hamburger menu.

## Responsive Behavior

The component adapts across screen sizes:

- Desktop uses a horizontal navigation.
- Tablet layouts stack the hero content.
- Mobile screens use a collapsible navigation menu.
- Feature cards switch to a single-column layout.

## Accessibility

The component uses semantic navigation markup, labels for interactive controls, visible focus states, and a `prefers-reduced-motion` media query.
