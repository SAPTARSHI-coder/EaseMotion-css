60FPS GPU Performance

Powered strictly by hardware-accelerated transform: translateX() CSS keyframe animations to prevent main-thread layout thrashing.

Pause-on-Hover & Focus

Hovering pointer or tabbing into interactive elements pauses the marquee track seamlessly using animation-play-state: paused.

Accessible & Reduced Motion

Respects prefers-reduced-motion: reduce by disabling keyframes and presenting a clean, accessible scrollable view.
