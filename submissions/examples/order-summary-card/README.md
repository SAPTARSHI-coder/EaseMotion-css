# Order Summary Card

A checkout summary with items, totals and a confirm button that charges forward on hover.

## Features
- Itemized list with thumbnail chips
- Totals slide up from a divider
- Confirm button pushes forward on hover

## Usage
```html
<div class="os2-card">
  <h3>Your order</h3>
  <div class="os2-item"><span class="os2-thumb os2-t1">&#127871;</span><span class="os2-name">Item</span><span class="os2-price">$79</span></div>
  <button class="os2-confirm">Confirm Order</button>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
