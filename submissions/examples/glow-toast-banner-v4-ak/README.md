# glow-toast-banner-v4-ak

Pure CSS animated notification toast banner with bottom progress timer line — no JavaScript required.

## How to use

```html
<div class="ease-toast-v4">
  <span class="ease-toast-icon-v4">🔔</span>
  <div class="ease-toast-content-v4">
    <span class="ease-toast-title-v4">Title</span>
    <span class="ease-toast-desc-v4">Description</span>
  </div>
  <div class="ease-toast-timer-v4"></div>
</div>
