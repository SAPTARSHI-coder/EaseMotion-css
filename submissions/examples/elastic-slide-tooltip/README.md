# CSS Elastic Slide Tooltip

A modern tooltip component featuring an elastic slide animation using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Elastic slide animation
- Responsive design
- Accessible with `prefers-reduced-motion`
- No JavaScript required
- Lightweight and customizable

## Files

```text
demo.html
style.css
README.md
```

## Usage

Open `demo.html` in any modern browser and hover over the button.

## Customization

- Tooltip colors
- Animation duration
- Border radius
- Typography
- Positioning

## Browser Support

Compatible with all modern browsers supporting CSS animations and transitions.
