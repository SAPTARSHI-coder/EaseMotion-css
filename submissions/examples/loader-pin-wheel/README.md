# Loader Pin Wheel

Eight pins light up in sequence around a turning wheel.

## Features
- Sequential pin lighting
- Wheel rotation
- Trailing fade
- Pure CSS

## Usage
```html
<div class="lpw-wheel"><i style="--i:0"></i></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
