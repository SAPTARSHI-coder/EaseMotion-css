# Glassmorphism Blur - Sci-Fi HUD

A pure CSS futuristic HUD component combining glassmorphism,
background blur, translucent panels, neon lighting, and subtle
motion effects.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript
- No external dependencies
- Glassmorphism blur effect
- Translucent futuristic HUD panel
- Neon sci-fi visual accents
- Animated glass light sweep
- Animated scanline
- Floating panel animation
- Interactive status cards
- Responsive design
- Dark-mode friendly appearance
- `prefers-reduced-motion` support
