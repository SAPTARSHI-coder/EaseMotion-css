# CSS Clip-path Shape Card

A responsive card using CSS `clip-path` to create a non-rectangular visual silhouette.

## Features

- Non-rectangular card geometry
- Layered decorative shape
- Hover and focus motion
- Responsive layout
- Accessible content
- Reduced-motion support

## Files

- `demo.html` — card content and actions
- `style.css` — clip-path shapes, layout, states, and responsive rules

## Accessibility

Content uses semantic headings and links with visible focus indicators. Decorative shapes do not carry essential information.
