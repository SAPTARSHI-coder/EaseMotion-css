# Glowing Button with Retro Styling

A vibrant retro-inspired button component featuring neon glow effects, smooth hover animations, and responsive design built entirely with HTML and CSS.

## Features

- Pure HTML & CSS
- Retro neon aesthetics
- Glowing visual effects
- Smooth hover and active interactions
- Fully responsive layout
- Lightweight and reusable
- No JavaScript required

## Files

- demo.html
- style.css

## Usage

```html
<button class="retro-btn">
    START GAME
</button>
```

## Why it fits EaseMotion CSS

This component embraces EaseMotion CSS principles through smooth motion, engaging retro-inspired visuals, lightweight implementation, and reusable styling patterns.
