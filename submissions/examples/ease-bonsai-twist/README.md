# 🌳 Bonsai Twist – Bonsai Tree Grows and Twists

> An interactive bonsai tree component where a tree grows and twists with 4 seasons, growth control (0-100%), twist control (0-100%), and organic branch generation.

---

## 📖 Description

The **Bonsai Twist** component creates an interactive bonsai tree experience where a tree grows and twists gracefully. Built with vanilla HTML, CSS, and JavaScript, it features growth control (0-100%), twist control (0-100%), 4 seasons (Spring, Summer, Autumn, Winter), and organic branch generation.

### 🎯 Core Features

- **Bonsai tree** – organic tree with branches and leaves
- **Growth control** – adjust growth from 0-100%
- **Twist control** – adjust twist from 0-100%
- **4 seasons** – Spring (🌸), Summer (🌿), Autumn (🍂), Winter (❄️)
- **Branch system** – recursive branch generation with depth
- **Leaf rendering** – seasonal leaf colors and shapes
- **Pot and soil** – detailed pot with rim and pebbles
- **Interactive controls** – sliders, buttons, keyboard shortcuts
- **Responsive design** – adapts to different screen sizes

### ⌨️ Interaction Options

| Method | Action |
|--------|--------|
| **Sliders** | Adjust Growth (0-100%) and Twist (0-100%) |
| **Buttons** | Grow, Reset |
| **Keyboard** | `Space` – Grow · `R` – Reset |

### ✨ Bonsai Experience

When interacting:
1. **Tree grows** – branches extend and leaves appear
2. **Twist applies** – branches twist with organic motion
3. **Seasons change** – colors shift as the tree grows
4. **Status updates** – shows current state

### 💡 Why Use This Component?

- Perfect for meditation apps, relaxation tools, or calming interfaces
- Interactive bonsai tree with organic growth
- Self-contained – no external dependencies or frameworks
- Easy to customize (colors, growth rate, twist behavior)
- 4 seasons for variety
- Growth and twist controls for customization

### 🛠️ Technologies Used

- **HTML5** – semantic structure with Canvas
- **CSS3** – gradients, backdrop-filter, transforms
- **JavaScript (ES6)** – Canvas API, requestAnimationFrame, recursive tree generation

### 🎨 Design Philosophy

This component embodies **EaseMotion CSS's animation-first philosophy** through:

- **Organic growth** – branches grow with natural motion
- **Seasonal changes** – colors shift gracefully
- **Visual feedback** – status updates, controls, counter
- **Calming atmosphere** – nature-inspired colors and motion
- **Human-readable classes** – `.bonsai-controls`, `.bonsai-text`

### 🔧 Customization Options

| Property | Location | Default |
|----------|----------|---------|
| Seasons | `seasons` array | 4 seasons |
| Growth range | `growthSlider` | 0-100% |
| Twist range | `twistSlider` | 0-100% |
| Branch depth | `maxDepth` | 4 |
| Branch length | `length` | 60px |
