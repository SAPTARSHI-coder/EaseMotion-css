# Wiggle Bounce Mascot

A friendly mascot blob that wiggles, squishes and bounces to say hello.

## Features
- Blob body squashes on every bounce
- Face stays put while the body wiggles
- Eyes blink at intervals

## Usage
```html
<div class="wm-mascot">
  <div class="wm-body"></div>
  <div class="wm-eye l"></div>
  <div class="wm-eye r"></div>
  <div class="wm-mouth"></div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
