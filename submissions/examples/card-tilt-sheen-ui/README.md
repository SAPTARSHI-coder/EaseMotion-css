# Card Tilt Sheen

A card tilts in 3D while a moving sheen tracks the tilt.

## Features
- 3D tilt on hover
- Co-tracking sheen highlight
- Depth border highlight
- Pure CSS

## Usage
```html
<div class="cts-card"><div class="cts-glow"></div>...</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
