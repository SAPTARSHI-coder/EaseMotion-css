# Subtle Elevate Toggle (#73886)

A pure HTML & Vanilla CSS toggle featuring a subtle shadow elevation and translation effect on state toggle.

## Features
- **Aesthetic:** Clean shadow elevation giving the thumb a floating 3D appearance upon check.
- **Pure CSS:** Zero JavaScript dependencies; relies strictly on standard CSS checkbox selectors.
- **Performance:** Hardware-accelerated transitions using `transform` and `box-shadow`.
- **Accessibility:** Includes `:focus-visible` outline rings and `@media (prefers-reduced-motion: reduce)` support.
