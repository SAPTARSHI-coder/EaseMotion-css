# Hourglass Grain Fall

## What does this do?
Renders a self-contained CSS-only `ease-hourglass-grain-fall` demo: Hourglass sand grains falling through the neck.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-hourglass-grain-fall`. No build step or JavaScript is required for the effect.

```html
<section class="ease-hourglass-grain-fall">
  <div class="ease-hourglass-grain-fall__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
