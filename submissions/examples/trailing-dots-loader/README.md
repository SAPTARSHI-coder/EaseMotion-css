# CSS Trailing Dots Loader

A CSS-only animated loader where multiple dots follow a circular path,
creating a trailing motion effect.

## ✨ Features

- Pure HTML and CSS
- No JavaScript required
- Circular trailing animation
- Staggered animation delays
- Responsive sizing
- CSS custom properties
- Smooth cubic-bezier animation
- Reduced-motion accessibility support
- Lightweight and dependency-free
