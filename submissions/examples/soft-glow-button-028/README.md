# Soft Glow Button

A lightweight button interaction that develops a soft surrounding glow on
hover or keyboard focus.

## What does it do?

The component provides:

- Soft surrounding glow.
- Subtle upward movement.
- Hover interaction.
- Keyboard focus interaction.
- Active-state feedback.
- Responsive layout.
- Reduced-motion support.
- No JavaScript.
- No external libraries or assets.

## How do I use it?

Add the `ease-glow-button` class to a native button:

```html
<button class="ease-glow-button" type="button">
  Get started
</button>
```
