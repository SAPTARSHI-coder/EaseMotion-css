Shimmer-Sweep Accordion

A minimalist accordion with a soft animated shimmer sweep, built entirely with semantic HTML and CSS.

01 Design System +

A restrained visual system combining dark surfaces, subtle borders, and a cool accent palette for modern interfaces.

02 Shimmer Interaction +

A lightweight highlight travels across the accordion surface when the item is hovered or focused.

03 CSS Only +

The component uses native details and summary elements, CSS transitions, and keyframe animations without JavaScript.

04 Responsive Layout +

Flexible spacing and typography keep the component usable across desktop, tablet, and mobile viewports.
