# CSS Shimmer-Sweep Accordion

A minimalist accordion component featuring a subtle animated shimmer sweep.

## Features

- Pure HTML and CSS
- No JavaScript dependencies
- Native `<details>` and `<summary>` elements
- Smooth shimmer-sweep animation
- Hover and focus states
- Responsive layout
- Keyboard accessible
- `prefers-reduced-motion` support
- Customizable CSS properties
