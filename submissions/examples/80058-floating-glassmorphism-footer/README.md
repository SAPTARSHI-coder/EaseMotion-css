# Floating Glassmorphism Footer

A modern floating footer component built with pure HTML and CSS.

Created for **EaseMotion CSS – Issue #80058**.

## Preview

The component features a floating glassmorphism footer with:

- Frosted glass effect
- Gradient glow decorations
- Responsive navigation columns
- Brand section
- Status indicator
- Social links
- Interactive hover states
- Smooth micro-interactions
- Reduced-motion support

## Features

- Fully responsive
- Pure HTML and CSS
- No external libraries
- No JavaScript required
- Modern glassmorphism styling
- Accessible navigation structure
- Mobile-friendly layout
- `prefers-reduced-motion` support
