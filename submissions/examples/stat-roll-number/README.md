# Stat Roll Number

A big number rolls through digits with a vertical ticker reel.

## Features
- Vertical digit reel
- Rounded frames
- Looping roll
- Pure CSS

## Usage
```html
<div class="srn-reel"><i>0</i><i>1</i>...</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
