Community Submission Benchmark Checklist

Before submitting your PR to submissions/examples/, ensure your component satisfies every item in this matrix.

📁

1. File & Directory Naming

  • Folder path: submissions/examples/<component-name-author>/
  • Contains demo.html (mandatory interactive demo)
  • Contains style.css (vanilla CSS only)
  • Contains script.js (if interactive)
  • Contains README.md documentation
🎨

2. CSS Token Architecture

  • All colors defined via :root variables
  • Light mode handled via [data-theme="light"]
  • RTL alignment uses CSS Logical Properties
  • Focus outlines use dual-layer :focus-visible
  • Reduced motion override block included
♿

3. ARIA & HTML5 Semantics

  • Semantic elements (header, main, article)
  • Interactive elements have role & ARIA states
  • Keyboard nav tested (Tab, Enter, Esc)
  • Screen reader friendly text via .em-sr-only
  • Color contrast ratio >= 4.5:1
⚙️

4. JS & Performance

  • Zero external dependencies (pure Vanilla JS)
  • No unhandled global scope pollution
  • Event listeners properly delegated
  • Works when JS is disabled gracefully
  • No inline JavaScript event handlers
