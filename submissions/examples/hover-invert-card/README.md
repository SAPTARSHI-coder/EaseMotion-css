# Hover Invert Card

A card's colours invert on hover with a smooth crossfade.

## Features
- True colour inversion
- Smooth crossfade
- Monochrome + accent pop
- Pure CSS

## Usage
```html
<div class="hic-card">...</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
