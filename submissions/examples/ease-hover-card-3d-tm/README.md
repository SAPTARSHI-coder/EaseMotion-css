# Hover Card 3D Component

Add ease-hover-card-3d-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|---------|
| `--hc3d-accent` | `#6366f1` |
| `--hc3d-radius` | `12px` |
| `--hc3d-shadow` | `0 8px 32px rgba(0,0,0,.4)` |

## Technique

`transform-style: preserve-3d` + `rotateY` + `rotateX` on hover creates 3D tilt effect.
