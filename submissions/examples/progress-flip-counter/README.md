# Progress Flip Counter

A flip-clock style counter counts upward inside a card.

## Features
- Flip counter digits
- Card container with divider
- Loops smoothly
- Pure CSS

## Usage
```html
<div class="pfc-cell"><b>8</b></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
