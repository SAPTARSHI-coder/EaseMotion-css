# Floating Badge — Cyberpunk

A responsive floating badge component with a futuristic Cyberpunk
visual style created for EaseMotion CSS issue #79864.

## Features

- Cyberpunk-inspired dark interface
- Floating neon badges
- Cyan, magenta, lime and yellow variants
- Animated badge floating effect
- Neon glow effects
- Futuristic clipped borders
- Interactive hover states
- Responsive desktop, tablet and mobile layout
- Reduced-motion support
- Pure HTML and CSS
- No JavaScript dependencies
