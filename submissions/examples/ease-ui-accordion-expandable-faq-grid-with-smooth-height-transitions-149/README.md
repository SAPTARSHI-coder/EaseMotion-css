# Accordion Expandable FAQ Grid with Smooth Height Transitions (Minimalist Clean Edition)

A clean and modern FAQ accordion component featuring smooth height transitions, responsive grid layout, and lightweight styling built using HTML, CSS and JavaScript.

## Features

- Minimalist design
- Smooth accordion animation
- Responsive FAQ grid
- Pure HTML, CSS & JavaScript
- Easy customization

## Folder Structure

```
ease-ui-accordion-expandable-faq-grid-with-smooth-height-transitions-149/
├── README.md
├── demo.html
├── style.css
└── script.js
```

## Usage

Open `demo.html` in your browser.

Customize colors, spacing and typography inside `style.css`.
