# Modal Footer Button Layout Fix

## Description

This submission fixes an issue where modal footer buttons become uneven, overflow, or stack incorrectly on smaller screens. The updated layout uses Flexbox and responsive rules to keep action buttons aligned and accessible.

## Features

- Prevents button overflow
- Even spacing between actions
- Responsive mobile layout
- Pure CSS solution

## Usage

```html
<div class="modal-footer">
  <button class="btn cancel">Cancel</button>
  <button class="btn archive">Archive</button>
  <button class="btn delete">Delete</button>
</div>
```

## Benefits

- Improves modal usability
- Responsive across screen sizes
- Maintains consistent button alignment
- Easy to integrate into existing modal components
