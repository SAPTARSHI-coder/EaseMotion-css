# Glassmorphism Noise Overlay

A premium frosted glass component that generates a realistic film grain/noise texture procedurally using mathematically dense CSS gradients, completely asset-free.

## Usage

```html
<div class="ease-glass-noise">
  <h2>Frosted Glass</h2>
  <p>Procedural noise overlay.</p>
</div>
```

## Why is it useful?

It provides a high-quality physical glass aesthetic without the need to load heavy, transparent PNG noise assets, maintaining performance while delivering premium visuals that fit EaseMotion's modern design philosophy.
