# Warded Bit Pass

## What does this do?
Renders a self-contained CSS-only `ease-warded-bit-pass` demo: Warded bit passing the obstruction.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-warded-bit-pass`. No build step or JavaScript is required for the effect.

```html
<section class="ease-warded-bit-pass">
  <div class="ease-warded-bit-pass__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
