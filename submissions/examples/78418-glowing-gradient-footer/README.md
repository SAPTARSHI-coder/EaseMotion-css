# Glowing Footer with Gradient Styling

A responsive footer component featuring layered gradients, ambient glow
effects, subtle interactions, and a polished dark visual style.

## Features

- Gradient glow accent
- Responsive multi-column layout
- Responsive mobile stacking
- Social link buttons
- Product and company navigation
- Gradient CTA button
- Animated hover interactions
- Ambient background glow
- Semantic footer and navigation structure
- Keyboard-visible focus states
- `prefers-reduced-motion` support
- Pure HTML and Vanilla CSS
- No JavaScript or external dependencies

## Files

- `demo.html`
- `style.css`

## Usage

Open `demo.html` directly in a browser.

The footer can be adapted by replacing the navigation labels, links,
branding, social links, and CTA content.

## Technologies

- HTML5
- Vanilla CSS

## Accessibility

The footer uses semantic `<footer>` and `<nav>` elements, descriptive
social-link labels, native anchor navigation, visible focus states, and
reduced-motion support.

## Responsive Behavior

- Desktop: four-column footer
- Tablet: three-column layout with a full-width CTA
- Mobile: stacked single-column layout
