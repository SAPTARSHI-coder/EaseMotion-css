# Animated Rating - Cyberpunk

A futuristic animated rating component built with pure HTML and CSS for EaseMotion CSS issue #81439.

## Features

- Cyberpunk-inspired visual design
- Interactive 1–5 star rating
- CSS-only rating interaction
- Neon cyan and magenta accents
- Animated scanline effect
- Pulsing system status indicator
- Star hover animations
- Selected rating state
- Neon glow effects
- Keyboard focus support
- Responsive across desktop, tablet, and mobile
- `prefers-reduced-motion` support
- No JavaScript dependencies
