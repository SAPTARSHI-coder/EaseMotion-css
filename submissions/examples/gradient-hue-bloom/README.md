# Gradient Hue Bloom

A radial bloom that cycles through every hue like a slow-motion color reveal.

## Features
- Full hue rotation across the bloom
- Soft blur edges melt into the card
- Core brightens on the half-turn

## Usage
```html
<div class="gb-bloom"></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
