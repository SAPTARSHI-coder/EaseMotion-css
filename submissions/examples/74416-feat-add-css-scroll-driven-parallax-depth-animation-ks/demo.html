CSS TECHNOLOGY

Driven by the scroll

This experience uses the CSS Scroll-Driven Animations API to connect animation progress directly to scrolling.

No JavaScript scroll listeners are required. Each visual layer has its own animation speed and range.

CSS SCROLL TIMELINE 
.layer {
  animation-timeline: scroll();
  animation-range: 0 100%;
}
