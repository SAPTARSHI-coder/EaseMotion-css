# CSS Bounce-Pulse Stepper for Product Catalog Layouts

A modern **Bounce-Pulse Stepper** built using pure HTML and CSS. The component features energetic bounce-pulse animations, responsive layouts, CSS custom properties, and lightweight styling for product catalog workflows.

## ✨ Features

- Pure HTML5 & CSS3
- Bounce-pulse step animation
- Responsive stepper layout
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
