# CSS Ripple-Wave Tabs

A responsive tab component featuring a ripple-wave hover animation built with pure HTML and CSS.

## Features

- Pure HTML & CSS
- Ripple-wave hover animation
- CSS-only tabs
- Responsive design
- Accessible with `prefers-reduced-motion`
- No JavaScript required

## Files

```text
demo.html
style.css
README.md
```

## Usage

Open `demo.html` in any modern browser.

## Customization

- Tab colors
- Ripple animation speed
- Border radius
- Typography
- Layout width

## Browser Support

Compatible with all modern browsers supporting CSS animations and transitions.
