# Text Shadow Glow

Headline typography that breathes through layered text-shadows and a shimmer.

## Features
- Multi-layer text-shadow glow
- Glow pulses from soft to bright
- Letter-spacing eases on hover

## Usage
```html
<h2 class="ts-title">GLOW&#9733;PULSE</h2>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
