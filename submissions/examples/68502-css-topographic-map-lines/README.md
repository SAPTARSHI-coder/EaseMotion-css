# CSS Topographic Map Lines

A CSS-only animated contour-line background inspired by topographic maps.

## Features

- Layered contour-line pattern
- Gentle animated drift
- Responsive composition
- Accessible foreground content
- Reduced-motion support
- No JavaScript or external assets

## Files

- `demo.html` — semantic map presentation
- `style.css` — contour layers, animation, layout, and responsive rules

## Usage

Open `demo.html` directly in a modern browser.

## Accessibility

The contour pattern is decorative and the main content remains readable above it. Motion is reduced through `prefers-reduced-motion`.
