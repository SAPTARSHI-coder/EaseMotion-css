# CSS Lyrics Scroll Display

A pure HTML and CSS lyrics display with an active-line treatment and a calm scrolling presentation.

## Features

- Responsive lyrics panel
- Clearly highlighted active line
- Accessible semantic text structure
- Keyboard-focusable controls
- CSS-only motion
- Reduced-motion support
- No external dependencies

## Files

- `demo.html` — lyrics display markup and controls
- `style.css` — layout, active states, motion, and responsive styling

## Usage

Open `demo.html` in a modern browser. No build step or JavaScript is required.

## Accessibility

The display uses headings, lists, buttons, visible focus states, and a reduced-motion media query. Decorative animation is disabled when users request reduced motion.
