# Glowing Neon Outline Input Field with Animated Floating Label

## Overview

A modern dark mode input component featuring glowing neon
outline effects and animated floating labels.

Built using pure HTML, CSS and JavaScript with no external
dependencies.

## Features

- 🌈 Neon glowing outline animation
- ✨ Animated floating labels
- 🌙 Dark mode glassmorphic UI
- ⚡ Smooth focus transitions
- 📱 Responsive mobile-friendly design
- 🎨 Gradient neon button styling
- ♿ Reduced motion accessibility support

## Usage

Open `demo.html` in any modern browser.

Customize:
- Neon colors using CSS variables
- Input animations
- Border glow intensity
