# CSS Sticky Element Scale


A CSS-only animated sticky element that scales smoothly when it reaches the viewport top.


## Overview

`ease-sticky-element-scale` demonstrates a modern scroll-based scaling interaction using pure CSS.


## Features

- Pure CSS implementation
- No JavaScript dependency
- Sticky viewport interaction
- Smooth scale animation
- Responsive layout
- Reduced motion accessibility support
