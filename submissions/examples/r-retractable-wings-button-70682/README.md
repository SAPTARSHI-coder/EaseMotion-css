# CSS Retractable Wings Button

A playful CSS-only button where two decorative wings retract beside the button and extend outward when the user hovers or focuses it.

## Features

- Pure HTML and CSS
- No JavaScript
- Responsive design
- Retractable decorative wings
- Hover interaction
- Keyboard focus interaction
- Accessible button element
- Visible focus indicator
- Reduced-motion support
- No external dependencies
