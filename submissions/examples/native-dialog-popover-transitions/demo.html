The browser manages the discrete visibility transition while CSS controls the visual motion.

@starting-style {
  dialog[open] {
    opacity: 0;
    transform:
      scale(.94)
      translateY(12px);
  }
}
transition-behavior 
dialog {
  transition:
    opacity 300ms ease,
    transform 300ms ease,
    display 300ms allow-discrete,
    overlay 300ms allow-discrete;
}
