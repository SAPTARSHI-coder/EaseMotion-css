# Ripple Pulse Button (`ease-ripple-pulse-rv`)

## Description
This submission adds a **Ripple Pulse Button** effect to EaseMotion CSS.

On hover or keyboard focus, the button fills with color and generates two expanding ripple rings around it. The effect is smooth, lightweight, and built using pure CSS only.

## Features
- Pure CSS, zero JavaScript
- Smooth ripple ring animation
- Works on hover and keyboard focus
- Accessible with `prefers-reduced-motion` support
- Customizable using CSS variables

## How to Use
Apply the class to a button element:

```html
<button class="ease-ripple-pulse-rv" type="button">
  Ripple Pulse
</button>
