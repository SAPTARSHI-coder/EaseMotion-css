# Rotate Fade Tooltip

A lightweight HTML and CSS example demonstrating a rotate-and-fade tooltip animation for creative portfolio layouts.

---

## Features

- Pure HTML5 & CSS3
- No JavaScript required
- Smooth rotate and fade animation
- Responsive layout
- Accessible with `prefers-reduced-motion`
- Easy customization using CSS variables

---

## Folder Structure

```
rotate-fade-tooltip/
├── demo.html
├── style.css
└── README.md
```

---

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over a portfolio card.
3. The tooltip smoothly rotates, fades in, and moves upward.

---

## CSS Custom Properties

| Variable | Description |
|----------|-------------|
| `--tooltip-bg` | Tooltip background color |
| `--tooltip-color` | Tooltip text color |
| `--tooltip-duration` | Animation duration |
| `--card-radius` | Border radius for cards |
