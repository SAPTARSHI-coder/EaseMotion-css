# Shimmer-Sweep Carousel

A lightweight CSS-only Shimmer-Sweep Carousel designed for e-commerce
checkout and product catalog layouts.

## Features

- Pure HTML and CSS
- No JavaScript or external libraries
- Shimmer-sweep animation
- CSS-only product navigation
- Responsive desktop, tablet and mobile layouts
- Smooth slide transitions
- Product status and pricing presentation
- Accessible reduced-motion support
- Customizable through CSS custom properties
