# Glowing Dropdown with Minimalist Styling

A responsive CSS-only dropdown component created for
EaseMotion CSS issue #78381.

## Features

- Fully responsive
- HTML and CSS only
- Uses native HTML `<details>` and `<summary>`
- No JavaScript
- Minimalist visual language
- Subtle glowing accent
- Smooth dropdown animation
- Hover interaction on dropdown items
- Keyboard focus states
- Accessible semantic structure
- Reduced-motion support
- No external dependencies

## Design

The component combines minimalist UI principles with a subtle
glowing green accent.

The design uses:

- Neutral backgrounds
- Fine borders
- Soft shadows
- Minimal typography
- Small visual indicators
- Subtle motion

## Responsive Behavior

The dropdown adapts to smaller screens through responsive
spacing, typography, menu sizing, and layout adjustments.

## Technologies

- HTML5
- CSS3

## Files

- `demo.html`
- `style.css`

## Accessibility

The dropdown uses native `<details>` and `<summary>` elements
for keyboard-friendly interaction without JavaScript.

Visible focus styles and `prefers-reduced-motion` support are
included.

## Issue

Closes #78381
