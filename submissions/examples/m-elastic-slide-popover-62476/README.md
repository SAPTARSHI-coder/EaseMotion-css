# CSS Elastic-Slide Popover for E-Commerce Checkout Layouts

A modern **Elastic-Slide Popover** built using pure HTML and CSS. The component features a smooth elastic slide entrance animation, premium glassmorphism styling, responsive layouts, and lightweight interactions for e-commerce checkout interfaces.

## ✨ Features

- Pure HTML5 & CSS3
- Elastic-slide entrance animation
- Glassmorphism popover
- Responsive layout
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
