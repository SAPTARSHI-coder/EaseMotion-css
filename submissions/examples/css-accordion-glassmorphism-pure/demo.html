Glassmorphism Accordion

A pure CSS, fully semantic accordion utilizing native details/summary elements and frosted glass aesthetics.

What is Glassmorphism?

Glassmorphism is a UI design trend characterized by semi-transparent, frosted glass-like backgrounds. It relies heavily on background blur (backdrop-filter), subtle borders to mimic the edge of glass, and vivid backgrounds that bleed through the interface to create a sense of depth and hierarchy.

How does this work without JavaScript?

This accordion uses the native HTML5 <details> and <summary> elements. The browser natively handles the state toggling (open/closed) and accessibility features (keyboard navigation, ARIA roles). We then use CSS to style the default markers, animate the content via CSS Grid, and apply the frosted glass aesthetics.

Is it accessible?

Yes. Because we are using the semantic <details> element, screen readers automatically understand this is an interactive widget. Keyboard users can use the Tab key to navigate between headers and the Enter/Space keys to toggle them open and closed.
