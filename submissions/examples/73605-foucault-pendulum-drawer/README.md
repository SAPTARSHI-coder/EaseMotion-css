# Foucault Pendulum Swing Drawer

A smooth, physics-inspired **Foucault Pendulum Swing Drawer** created
using pure HTML and Vanilla CSS.

This component is implemented for **EaseMotion CSS Issue #73605**.

## ✨ Features

- Pure HTML and CSS
- No JavaScript required
- Foucault pendulum-inspired swing animation
- Smooth drawer entrance and exit
- Physics-inspired pendulum movement
- Dark-mode friendly design
- Responsive layout
- Hardware-accelerated transforms
- Accessible drawer controls
- Reduced-motion support

## 🎨 Style

**Category:** Drawers & Sidebars

**Style:** Foucault Pendulum Swing

The drawer combines a sliding panel with a pendulum-inspired animation
to create a distinctive motion-based interaction.
