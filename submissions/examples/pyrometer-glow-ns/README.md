# Pyrometer Glow

## What does this do?
Renders a self-contained CSS-only `ease-pyrometer-glow` demo: Optical pyrometer filament glowing to match heat.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-pyrometer-glow`. No build step or JavaScript is required for the effect.

```html
<section class="ease-pyrometer-glow">
  <div class="ease-pyrometer-glow__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
