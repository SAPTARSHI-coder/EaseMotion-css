# Michelson Interferometer Fringe

## What does this do?
Renders a self-contained CSS-only `ease-michelson-interferometer-fringe` demo: Michelson interferometer fringe pattern drifting on detector.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-michelson-interferometer-fringe`. No build step or JavaScript is required for the effect.

```html
<section class="ease-michelson-interferometer-fringe">
  <div class="ease-michelson-interferometer-fringe__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
