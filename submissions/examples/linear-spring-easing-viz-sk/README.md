# Linear Spring Easing Visualizer

## What does this do?

A visualizer comparing classic easing vs linear() spring-like curves.

## How is it used?

```html
<div class="ease-viz"><div class="lane"><span class="ball"></span></div></div>
```

Open `demo.html` in a browser to try it.

## Why is it useful?

Easing education belongs in an animation-first library.
