# Dynamic Accordion with Minimalist Styling

A responsive and accessible accordion component with a clean minimalist
visual design, built using native HTML and Vanilla CSS.

## Features

- Native HTML `<details>` and `<summary>` interaction
- No JavaScript required
- Minimalist visual design
- Smooth open and close transitions
- Animated plus/minus indicator
- Responsive layout
- Keyboard-accessible controls
- Visible focus states
- Reduced-motion support
- Soft borders and subtle shadows
- Customizable content
- No external dependencies

## Files

- `demo.html`
- `style.css`

## Usage

Open `demo.html` directly in a browser.

Each accordion section is implemented with a native `<details>` element:

```html
<details>
  <summary>Your question</summary>
  <div>
    Your answer
  </div>
</details>
