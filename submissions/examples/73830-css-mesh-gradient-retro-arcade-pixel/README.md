# CSS Mesh Gradient: Retro Arcade Pixel

## Overview

A retro arcade variation using pixel-like blocks, neon colors, and scanline texture.

## Features

- Hard-edged pixel geometry
- Neon cyan, pink, and yellow palette
- Scanline texture
- Responsive layout
- Focus-visible keyboard styling
- Reduced-motion support
- Pure HTML and Vanilla CSS

## Files

- `demo.html` — semantic demo
- `style.css` — pixel layers, animation, responsive behavior, and accessibility styling
- `README.md` — documentation

## Accessibility

The decorative layers are hidden from assistive technology. The action link has a visible keyboard focus indicator and reduced-motion preferences disable the animations.
