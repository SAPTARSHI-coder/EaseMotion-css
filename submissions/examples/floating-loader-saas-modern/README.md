# Floating Loader - SaaS Modern

A responsive floating loader component built with pure HTML and Vanilla CSS.

The design uses a clean SaaS-inspired interface with a floating animated loader, subtle orbital rings, glowing status dots, and an animated progress indicator.

## Features

- SaaS-modern visual style
- Floating animated loader
- Subtle orbital pulse effect
- Animated loading dots
- Animated progress indicator
- Responsive layout
- Hardware-friendly CSS transforms
- No JavaScript
- No external dependencies
- Reduced-motion accessibility support
- Works directly by opening `demo.html`
