# Interactive Flip Flashcard

A responsive educational flashcard component with a smooth 3D flip
animation.

## Features

- 3D card flip animation
- Hover interaction
- Keyboard focus support
- Mobile-first responsive design
- Neumorphic card styling
- CSS-only animation
- Reduced-motion support
- No external libraries

## Files

- `demo.html` - Flashcard structure and content
- `style.css` - Styling, responsive layout, and animation

## Usage

Clone the repository and open `demo.html` in a browser.

No installation or dependencies are required.

## Customization

Change the question and answer directly inside `demo.html`.

Colors, shadows, card size, and animation duration can be customized
through the CSS variables in `style.css`.

## Accessibility

The flashcard uses `tabindex="0"` so keyboard users can focus on it.
The animation also respects the user's `prefers-reduced-motion`
setting.
