# Connection Status Online Offline Listener

A responsive connection-status component that detects browser online and offline events and updates the interface in real time.

## Features

- Detects the initial network state
- Responds to `online` events
- Responds to `offline` events
- Displays connection state visually
- Shows the time of the latest connection change
- Responsive layout
- No external dependencies
