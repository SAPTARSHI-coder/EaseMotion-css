# CSS Float-Drift Drawer for Product Catalog Layouts

A modern **Float-Drift Drawer** built using pure HTML5 and CSS3 for product catalog layouts. The drawer features a floating appearance with a smooth drift animation, responsive behavior, and accessibility support without using JavaScript.

## Features

- Pure HTML5 & CSS3
- Floating drawer animation
- Smooth drift transition
- Responsive product catalog layout
- CSS Custom Properties
- Accessible with `prefers-reduced-motion`
- No JavaScript required
