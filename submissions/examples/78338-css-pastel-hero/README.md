# CSS-only Hero Section with Pastel Styling

A fully responsive hero section built with pure HTML and CSS,
featuring a soft pastel visual language and subtle decorative animations.

## Features

- Pure HTML and CSS
- No JavaScript dependency
- Pastel pink, blue, yellow, lavender, and green palette
- Responsive hero layout
- Responsive navigation
- CTA buttons with hover interactions
- Decorative CSS blobs
- CSS-only visual card
- Floating decorative elements
- Soft shadows and glass-like surfaces
- Keyboard focus states
- Reduced-motion accessibility support
- Mobile-first responsive behavior

## Files

- `demo.html` — hero markup and demo content
- `style.css` — complete styling, animations, and responsive rules

## Usage

Open `demo.html` directly in a browser.

The text, navigation links, statistics, and CTA links can
be customized according to the application's requirements.

## Responsive Behavior

On desktop, the hero uses a two-column layout with the
content on the left and the decorative visual on the right.

On tablets and smaller screens, the layout switches to a
stacked single-column presentation.

The navigation, buttons, typography, visual card, and
decorative shapes scale down for mobile screens.

## Accessibility

The component includes:

- Semantic navigation and section structure
- Descriptive heading hierarchy
- Visible keyboard focus states
- Reduced-motion support using `prefers-reduced-motion`
- Decorative elements marked as non-essential
