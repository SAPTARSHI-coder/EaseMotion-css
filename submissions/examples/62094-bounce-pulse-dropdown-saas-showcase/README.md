# CSS Bounce-Pulse Dropdown for SaaS Showcase Layouts

A modern **Bounce-Pulse Dropdown** built using only HTML and CSS for EaseMotion CSS. The dropdown features a smooth bounce entrance animation, pulse-highlight icons, glassmorphism styling, and a responsive SaaS-inspired layout.

---

## Features

- Pure HTML5 & CSS3
- Bounce-Pulse dropdown animation
- Glassmorphism navigation
- Hover elevation effects
- Pulse animated feature icons
- CSS Custom Properties
- Responsive design
- Accessibility support with `prefers-reduced-motion`
- No JavaScript required
