# Ripple Wave Ripple Click Button

A vibrant gradient micro-animation button featuring expanding ripple waves,
animated gradients, hover elevation and accessible keyboard interaction.

## ✨ Features

- Pure HTML and CSS
- Expanding ripple wave animation
- Vibrant pink, purple and cyan gradient
- Animated gradient background
- Hover elevation effect
- Interactive arrow icon
- Keyboard-accessible focus state
- High-contrast focus outline
- Responsive design
- Reduced-motion support
- No external dependencies
