# CSS Elastic-Slide Badge

A responsive badge component featuring a smooth elastic slide hover animation built with pure HTML and CSS.

## Features

- Pure HTML & CSS
- Elastic slide hover animation
- Responsive design
- Accessible with `prefers-reduced-motion`
- No JavaScript required
- Lightweight and customizable

## Files

```text
demo.html
style.css
README.md
```

## Usage

Open `demo.html` in any modern browser.

## Customization

- Badge colors
- Animation duration
- Border radius
- Typography
- Spacing

## Browser Support

Compatible with all modern browsers supporting CSS animations and transitions.
