# Desert Dunes · Sand Shifts Like Dunes 🏜️

An interactive desert dunes simulation with shifting sand, flowing patterns, and atmospheric desert effects. Watch the sand shift like real dunes!

## Features

- 🏜️ **Desert Dunes** – Flowing sand particles
- 🌊 **Shift Animation** – Sand shifts like dunes
- 🎚️ **Speed Control** – Adjust shift speed (1-10)
- 🎚️ **Dune Control** – Adjust number of dunes (3-8)
- ⏸️ **Pause/Resume** – Toggle animation
- 🔄 **Reset** – Reset dunes
- 🌅 **Atmosphere** – Desert sky and sun

## How to Use

1. Click **SHIFT** or press **Space** to shift the sand
2. Watch dunes flow and reform
3. Adjust **Speed** for shift pace
4. Adjust **Dunes** for pattern complexity
5. Press **RESET** or **R** to reset
6. Press **PAUSE** or **P** to pause/resume animation

## Controls

| Action | Method |
|--------|--------|
| Shift Dunes | Shift button / Space |
| Reset | Reset button / R key |
| Pause/Resume | Pause button / P key |

## Technical Details

- **Particles:** 2000 flowing sand particles
- **Dunes:** 3-8 wave patterns
- **Shift:** Smooth dune movement
- **Performance:** 60fps with requestAnimationFrame

## Customization

You can easily customize:
- **Speed:** Adjust slider range (1-10)
- **Dunes:** Adjust slider range (3-8)
- **Colors:** Modify sand and sky colors
- **Particles:** Adjust particle count
- **Motion:** Modify wave parameters
