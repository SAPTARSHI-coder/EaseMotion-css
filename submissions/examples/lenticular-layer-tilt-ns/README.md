# Lenticular Layer Tilt

## What does this do?
Renders a self-contained CSS-only `ease-lenticular-layer-tilt` demo: Lenticular card tilting to reveal alternate printed layer.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-lenticular-layer-tilt`. No build step or JavaScript is required for the effect.

```html
<section class="ease-lenticular-layer-tilt">
  <div class="ease-lenticular-layer-tilt__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
