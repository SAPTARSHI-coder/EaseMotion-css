# Floating Sidebar with Glassmorphism Styling

A responsive floating sidebar built with pure HTML and CSS, featuring a modern glassmorphism visual system.

## Features

- Floating glassmorphism sidebar
- Responsive navigation
- Active navigation state
- Hover and focus interactions
- Notification badge
- Storage usage indicator
- Profile section
- Glass-style dashboard content
- Responsive mobile layout
- Decorative animated background orbs
- Pure HTML and CSS
- No JavaScript dependency
- Reduced-motion accessibility support

## Files

- `demo.html` — semantic HTML structure
- `style.css` — complete styling, responsiveness and animations

## Usage

Open `demo.html` directly in a browser.

The sidebar can be copied into any existing HTML project and customized through the CSS variables defined at the top of `style.css`.

## Accessibility

Keyboard focus states are included and `prefers-reduced-motion` is respected to reduce animations for users who request reduced motion.
