# Terminal Window

A mac-style terminal window with traffic lights, a blinking cursor and rolling output.

## Features
- Traffic-light window chrome
- Blinking block cursor
- Prompt lines reveal one after another

## Usage
```html
<div class="tw2-win">
  <div class="tw2-bar"><span class="tw2-dot r"></span><span class="tw2-dot g"></span></div>
  <div class="tw2-body"><div class="tw2-line"><span class="tw2-prompt">$</span> npm run build</div></div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
