# CSS Plant Growth Animation

A pure CSS plant growth animation created for the EaseMotion CSS library.

## Features

- Pure HTML and CSS
- No JavaScript required
- Plant stem grows upward on page load
- Leaves appear progressively during the animation
- Responsive design
- Accessible structure
- Supports `prefers-reduced-motion`
- Works on desktop and mobile screens
