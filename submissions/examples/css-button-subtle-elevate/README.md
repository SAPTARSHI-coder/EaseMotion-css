# CSS Button: Subtle Elevate

A smooth, high-performance, and accessible pure CSS button component featuring a refined Subtle Elevate hover effect with soft multi-layer drop shadows, built completely with vanilla CSS.

## 🚀 Features

- **Zero JavaScript Required:** Built entirely using native CSS transition properties and multi-layer box-shadows.
- **Subtle Elevate Hover Effect:** Smooth vertical translation combined with a subtle expansion of soft drop-shadows for a premium, grounded feel.
- **Dark Mode Compatible & Responsive:** Optimized dark theme styling that scales seamlessly across all viewports. Includes a strict `@media (prefers-reduced-motion: reduce)` override.

## 🛠️ Usage

Copy the HTML structure from `demo.html` and link the styles from `style.css`.

### CSS Custom Properties
Easily theme the component via `:root` variables:

```css
:root {
    --em-accent: #a855f7;            /* Accent purple color */
    --em-speed: 0.4s;                 /* Transition speed */
}
