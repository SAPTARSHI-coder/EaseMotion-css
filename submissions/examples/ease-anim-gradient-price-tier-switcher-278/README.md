# Interactive Price Comparison Card Tier Switcher Component

### Vibrant Gradient Version

A modern **Interactive Price Comparison Card Tier Switcher** built using **HTML5** and **CSS3**. This component features vibrant gradients, animated pricing tier switching, responsive pricing cards, and smooth micro-interactions for a modern SaaS pricing interface.

---

## ✨ Features

- Vibrant gradient theme
- Animated tier switcher
- Responsive pricing cards
- Featured pricing plan
- Smooth hover animations
- Gradient CTA buttons
- CSS variables for customization
- Mobile-first responsive layout
- Pure HTML & CSS
- Supports `prefers-reduced-motion`

## 🚀 Usage

1. Open the component folder.
2. Keep `demo.html` and `style.css` together.
3. Open `demo.html` in any modern browser.
4. Switch between pricing tiers and explore the animations.

No installation is required.
