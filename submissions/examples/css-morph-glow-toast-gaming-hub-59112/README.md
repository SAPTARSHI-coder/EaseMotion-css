# CSS Morph-Glow Toast for Gaming Hub Layouts

A modern **Morph-Glow Toast** built using pure HTML and CSS for gaming dashboards, achievement notifications, rewards, alerts, and system messages.

## Features

* Pure HTML5 & CSS3
* Morph Glow hover animation
* Gaming-inspired neon design
* Multiple toast variants
* Responsive layout
* CSS custom properties
* No JavaScript required
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Customize the toast title, icon, and message.
3. Modify colors using the CSS variables in `:root`.
4. Duplicate toast blocks to create additional notifications.
