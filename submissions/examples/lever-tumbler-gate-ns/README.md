# Lever Tumbler Gate

## What does this do?
Renders a self-contained CSS-only `ease-lever-tumbler-gate` demo: Lever tumbler gates lining up on the bolt stump.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-lever-tumbler-gate`. No build step or JavaScript is required for the effect.

```html
<section class="ease-lever-tumbler-gate">
  <div class="ease-lever-tumbler-gate__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
