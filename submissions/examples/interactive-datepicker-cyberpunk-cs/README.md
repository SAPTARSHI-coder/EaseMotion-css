# Interactive Datepicker Calendar — Cyberpunk
A responsive cyberpunk-styled datepicker calendar created with pure HTML and CSS.

## Features
- Cyberpunk visual treatment
- Responsive layout for mobile, tablet, and desktop
- Interactive hover and focus states
- Accessible keyboard focus indicators
- `prefers-reduced-motion` support
- No JavaScript dependencies
- Pure HTML and CSS implementation

## Files
- `demo.html` — calendar markup
- `style.css` — component styling

## Accessibility
The component includes:
- Semantic buttons for calendar controls
- Accessible labels for navigation controls
- Visible `:focus-visible` states
- Reduced-motion support through `prefers-reduced-motion`

## Usage
Open `demo.html` in a modern browser.

## Browser Support
Designed for modern browsers supporting:
- CSS Grid
- CSS custom properties
- CSS gradients
- `prefers-reduced-motion`

## Notes
The calendar is a visual/demo component. Month navigation and date selection are intentionally implemented without JavaScript to satisfy the zero-JavaScript requirement.
