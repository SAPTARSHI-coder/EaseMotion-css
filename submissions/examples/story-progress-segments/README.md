# Story Progress Segment Bar

## Overview

A modern multi-segment story progress bar inspired by story viewers found in social media applications. The component demonstrates completed, active, and upcoming segments with smooth CSS animations and radio-button navigation between story panels.

---

## Features

- Multi-segment progress indicator
- Animated active segment
- Completed segments remain filled
- Hover pauses active animation
- Radio button navigation
- Responsive layout
- Pure HTML & CSS
- Supports `prefers-reduced-motion`

---

## Files

- `demo.html` — Component showcase
- `style.css` — Styling and animations
