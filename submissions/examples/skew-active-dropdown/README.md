# CSS Skew-Active Dropdown

A responsive gaming dropdown component featuring a skew-based active
interaction using pure HTML and CSS.

## Features

- Pure HTML and CSS
- No JavaScript
- Native `<details>` and `<summary>` interaction
- Skew-active hover and focus states
- Smooth dropdown entrance animation
- Responsive desktop and mobile layouts
- CSS custom properties
- Keyboard accessible
- `prefers-reduced-motion` support
