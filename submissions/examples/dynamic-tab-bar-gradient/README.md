# Dynamic Tab Bar with Gradient Styling

A responsive CSS-only tab bar with animated gradient highlighting.

## Features

- Pure HTML & CSS
- Animated gradient indicator
- Smooth transitions
- Responsive layout
- Keyboard accessible using radio buttons
- No JavaScript required

## Files

```text
demo.html
style.css
```

## Usage

```html
<link rel="stylesheet" href="style.css">
```

Open `demo.html` directly in your browser.

## Browser Support

- Chrome
- Firefox
- Edge
- Safari
