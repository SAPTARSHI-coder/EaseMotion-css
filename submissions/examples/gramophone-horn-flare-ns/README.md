# Gramophone Horn Flare

## What does this do?
Renders a self-contained CSS-only `ease-gramophone-horn-flare` demo: Gramophone horn flaring acoustic rings outward.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-gramophone-horn-flare`. No build step or JavaScript is required for the effect.

```html
<section class="ease-gramophone-horn-flare">
  <div class="ease-gramophone-horn-flare__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
