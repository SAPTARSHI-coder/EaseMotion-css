# CSS Shimmer-Sweep Toast for SaaS Showcase Layouts

A modern **Shimmer-Sweep Toast Notification** component built using pure HTML5 and CSS3 for SaaS showcase layouts. This component provides animated notification cards with smooth shimmer light effects, glassmorphism styling, hover interactions, and responsive behavior.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Smooth shimmer sweep animation
* SaaS notification showcase UI
* Multiple toast notification states:

  * Success
  * Information
  * Warning
* Animated gradient icons
* Glassmorphism card design
* Light sweep hover effect
* Smooth entrance animations
* Responsive desktop, tablet, and mobile layouts
* CSS Custom Properties for easy customization
* Smooth transitions and keyframe animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. View animated SaaS notification toast cards.
3. Customize colors, shadows, radius, and animation timing using CSS variables inside `:root`.

## CSS Custom Properties

```css
:root{
  --bg:#eef4ff;
  --surface:rgba(255,255,255,.92);
  --primary:#2563eb;
  --success:#22c55e;
  --warning:#f59e0b;
  --info:#06b6d4;
  --text:#111827;
  --muted:#64748b;
  --shadow:0 20px 55px rgba(37,99,235,.18);
  --radius:24px;
}
```
