# Fluid Liquid Fill Water Button with Smooth Overflow Wave Effect

### Neumorphic Finish

A modern **Fluid Liquid Fill Water Button** built with **HTML5** and **CSS3**. The component combines a soft neumorphic design with animated liquid fill and flowing wave effects to create an engaging call-to-action button.

---

## ✨ Features

- Neumorphic UI design
- Animated liquid fill effect
- Smooth flowing wave animation
- Responsive layout
- Soft shadow styling
- CSS Variables for easy customization
- Keyboard accessibility
- `prefers-reduced-motion` support
- Pure HTML & CSS implementation

## 🚀 Usage

1. Open the component folder.
2. Keep `demo.html` and `style.css` in the same directory.
3. Open `demo.html` in any modern browser.
4. Hover over the button to see the animated liquid fill and wave overflow effect.

No external libraries or build tools are required.
