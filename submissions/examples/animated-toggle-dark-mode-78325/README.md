# Animated Toggle with Dark Mode Styling

An elegant, fully responsive, and purely CSS-based animated toggle switch designed for dark mode toggling.

## What does this do?
This component provides a smooth animated toggle switch that transitions between a "Sun" (light mode) and "Moon" (dark mode) state using only CSS and HTML.

## How is it used?
```html
<label class="theme-toggle">
    <input type="checkbox" class="theme-toggle-input">
    <span class="theme-toggle-slider">
        <span class="theme-toggle-icon"></span>
    </span>
</label>
```

## Why is it useful?
It fits EaseMotion's philosophy by delivering a polished, interactive micro-animation without relying on JavaScript, making it accessible, performant, and easy to drop into any project requiring a theme toggle.
