# Dynamic Stat Card — Material Design

A responsive, CSS-only statistics card component inspired by
Material Design principles.

Built for EaseMotion CSS issue #81454.

## Features

- Material Design-inspired stat cards
- Four reusable statistics
- Dynamic visual state animations
- Animated mini bar charts
- Hover elevation
- Smooth icon interactions
- Positive and negative trend indicators
- Live status indicator
- Performance insight panel
- Responsive desktop, tablet and mobile layouts
- Accessible buttons and labels
- Visible keyboard focus states
- `prefers-reduced-motion` support
- Zero external JavaScript dependencies

## Usage

Include `style.css` and use the stat-card markup from
`demo.html`.

  ...
