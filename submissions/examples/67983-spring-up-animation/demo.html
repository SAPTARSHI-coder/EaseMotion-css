Motion anatomy

Three stages create the spring.

  1. 01
    Start

    Element begins below its final position with low opacity.

  2. 02
    Overshoot

    Element moves slightly beyond the destination to create energy.

  3. 03
    Settle

    Element returns to its natural position with full opacity.

Minimal API

.spring-up {
  animation: ease-spring-up var(--spring-duration, 700ms) var(--spring-easing) both;
}

Change duration with one custom property while keeping the animation reusable.
