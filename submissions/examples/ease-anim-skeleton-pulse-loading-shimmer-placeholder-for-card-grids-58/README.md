# Skeleton Pulse Loading Shimmer Placeholder for Card Grids

## Overview

A cyberpunk themed skeleton loading animation component for card
grid layouts with neon shimmer effects and smooth pulse animations.

Built using pure HTML, CSS, and JavaScript.

## Features

- ⚡ Cyberpunk neon design
- ✨ Animated shimmer loading effect
- 🔥 Skeleton pulse placeholders
- 🎨 Gradient glow styling
- 📱 Responsive card grid layout
- 🖱️ Interactive loading toggle
- 🚀 Pure CSS animations

## Usage

1. Open `demo.html` in a browser.
2. View the animated skeleton placeholders.
3. Click toggle button to switch loading state.
