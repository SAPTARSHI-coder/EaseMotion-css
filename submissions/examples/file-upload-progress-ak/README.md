\# File Upload Progress Component (`ease-upload-progress-ak`)



A modern, responsive pure CSS file upload progress bar component featuring smooth animated filling states built for \*\*EaseMotion CSS\*\*.



\## Features

\- \*\*Animated Progress Fill\*\*: Smooth keyframe-driven progress transitions simulating active file uploads.

\- \*\*Custom CSS Variables\*\*: Control timing parameters, fill colors, and easing curves globally via `--upload-timing`, `--upload-fill`, and `--upload-easing`.

\- \*\*Keyboard \& Accessibility Ready\*\*: Fully complies with `@media (prefers-reduced-motion: reduce)`.

\- \*\*Zero JavaScript Dependencies\*\*: Powered completely by high-performance native CSS animations.



\## Quick Usage

1\. Place this folder under:

&#x20;  `submissions/examples/file-upload-progress-ak/`

2\. Open `demo.html` in any browser to review the file upload progress showcase.
