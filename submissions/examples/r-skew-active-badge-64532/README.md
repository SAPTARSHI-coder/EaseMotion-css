# CSS Skew-Active Badge

A minimalist tech badge featuring a smooth skew transformation during interaction.

## Features

- Pure HTML and CSS
- No JavaScript dependencies
- Smooth skew-active interaction
- Multiple color variants
- Responsive layout
- Hover and keyboard focus support
- `prefers-reduced-motion` support
- Customizable CSS properties
