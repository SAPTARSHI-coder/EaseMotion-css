What is EaseMotion CSS?▾

An animation-first CSS framework that ships motion utilities, easing tokens and component demos you can drop into any project.

How do I contribute?▾

Open an issue to claim a component, then submit a PR adding your demo.html, style.css and README.md under submissions/. The validator checks structure automatically.

Is JavaScript required?▾

No. Most demos are pure CSS — states use hover, focus or the checkbox-hack. A few toggles ship tiny inline scripts for realism.
