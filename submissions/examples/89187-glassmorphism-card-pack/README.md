# Glassmorphism Card & Buttons Component

A modern, responsive UI component featuring a sleek glassmorphism card container paired with animated primary and secondary buttons.

## Features
- **Modern Glassmorphism:** Uses CSS `backdrop-filter` for translucent blur effects.
- **Hover Micro-Interactions:** Subtle vertical lift and dynamic shadow expansions on hover.
- **Fully Responsive:** Adapts cleanly to mobile and desktop screens.

## File Structure
- `demo.html` - Minimal markup for previewing the component.
- `style.css` - Component styling and custom CSS property variables.
