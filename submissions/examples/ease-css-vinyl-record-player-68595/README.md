# CSS Vinyl Record Player

A pure CSS spinning vinyl record player with album art and a tonearm that moves into place on hover.

## How to use

```html
<div class="ease-vinyl-player-container">
  <div class="ease-turntable">
    <div class="ease-record">
      <div class="ease-album-art"></div>
      <div class="ease-record-hole"></div>
    </div>
    <div class="ease-tonearm">
      <div class="ease-tonearm-base"></div>
      <div class="ease-tonearm-arm"></div>
      <div class="ease-tonearm-head"></div>
    </div>
  </div>
</div>
```

## Why is this useful for EaseMotion CSS

This component provides a delightful, interactive CSS-only UI pattern for music players, audio applications, and retro-themed designs, expanding the library's collection of creative CSS animations.
