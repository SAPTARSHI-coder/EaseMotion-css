# CSS Building Fill Progress (#70971)

A architectural progress component featuring a building silhouette that fills floor by floor with glowing window illumination and top antenna pulsing effects.

## Features
- Pure CSS staggered bottom-up floor loading animations (`@keyframes ease-floor-fill`).
- Glowing active floor states and pulsing roof spire indicator.
- Fully responsive layout with proper semantic accessibility support (`role="progressbar"`, `aria-valuenow`).
- Built-in `prefers-reduced-motion` accessibility fallbacks.
