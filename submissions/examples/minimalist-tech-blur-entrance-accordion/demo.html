Auto-scaling can be configured via the node pool settings in your dashboard or declaratively via the Kubernetes Horizontal Pod Autoscaler (HPA) API. We recommend setting a minimum of 3 nodes to maintain high availability across availability zones during scale-down events.

kubectl autoscale deployment core-api --cpu-percent=80 --min=3 --max=10

All data at rest is encrypted using AES-256 block-level encryption. Encryption keys are managed automatically by the AWS Key Management Service (KMS). For enterprise-tier customers, we support Bring Your Own Key (BYOK) architecture via HashiCorp Vault integrations.

Standard instances support up to 10,000 concurrent WebSocket connections. If you require higher throughput, you must provision an API Gateway layer with dedicated load balancers configured for long-polling protocols.
