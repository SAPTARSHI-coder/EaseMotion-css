# Ease Particle Burst Social Share Menu

A modern **Particle Burst Social Share Menu** built with HTML, CSS, and Vanilla JavaScript.

The component features a floating action button that expands social share buttons in a radial burst using spring-style animations. It also includes a copy-to-clipboard action with a feedback toast.

---

## Features

- Floating action share button
- Radial particle burst expansion
- Spring animation using `cubic-bezier(0.34, 1.56, 0.64, 1)`
- 45° rotating trigger button
- Copy link to clipboard
- Feedback toast notification
- Accessible button controls (`aria-label`)
- Responsive layout
- CSS Custom Properties
- Lightweight Vanilla JavaScript

## Usage

1. Open `demo.html` in any modern browser.
2. Click the floating **+** button to expand the social share menu.
3. Click the **Copy Link** button to copy the current page URL to your clipboard.
4. Customize the icons, colors, spacing, and animation timing using the CSS variables.

---
