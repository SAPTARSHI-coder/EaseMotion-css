# Unread Badge

A notification bell with a floating count badge that rings a subtle wobble.

## Features
- Count badge hovers above the icon corner
- Hover triggers a playful bell wobble
- Badge scales in on load

## Usage
```html
<div class="ub-wrap">
  <div class="ub-bell">&#128276;</div>
  <span class="ub-badge">7</span>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
