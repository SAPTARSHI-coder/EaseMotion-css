# Accordion Expandable FAQ Grid with Smooth Height Transitions (Vibrant Gradient Version)

A modern animated FAQ accordion featuring vibrant gradients, smooth expand/collapse transitions, responsive layout, and colorful hover effects built with pure HTML, CSS and JavaScript.

## Features

- Vibrant gradient design
- Smooth accordion animation
- Responsive FAQ grid
- Animated expand/collapse
- Pure HTML, CSS & JavaScript
- Lightweight and customizable

## Folder Structure

```
ease-anim-accordion-expandable-faq-grid-with-smooth-height-transitions-150/
├── README.md
├── demo.html
├── style.css
└── script.js
```

## Usage

Open `demo.html` in your browser.

Customize gradients, colors and animation timing inside `style.css`.

## Technologies

- HTML5
- CSS3
- JavaScript
