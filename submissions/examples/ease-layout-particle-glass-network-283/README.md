# Particle Constellation Background Network with CSS & Canvas

### Glassmorphic Style

A modern full-screen particle constellation background built using **HTML5 Canvas**, **CSS3**, and **Glassmorphism** design principles. The component creates an animated network of moving particles connected by dynamic lines with a floating glass card overlay.

---

## ✨ Features

- Animated particle constellation background
- HTML5 Canvas rendering
- Glassmorphism UI card
- Responsive layout
- Smooth hover effects
- Gradient accents
- Mobile-friendly design
- Modern CSS variables
- Pure HTML, CSS & JavaScript
- Reduced motion accessibility support

## 🚀 Usage

1. Open the component folder.
2. Keep `demo.html` and `style.css` together.
3. Open `demo.html` in any modern browser.
4. The particle animation starts automatically.

No installation or external libraries are required.
