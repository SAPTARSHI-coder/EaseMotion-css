# Pin Tumbler Lift

## What does this do?
Renders a self-contained CSS-only `ease-pin-tumbler-lift` demo: Pin tumblers lifting to the shear line.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-pin-tumbler-lift`. No build step or JavaScript is required for the effect.

```html
<section class="ease-pin-tumbler-lift">
  <div class="ease-pin-tumbler-lift__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
