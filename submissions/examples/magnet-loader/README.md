# CSS Magnet Loader


A CSS-only animated magnetic loader where dots attract and repel in a continuous loading loop.


## Overview

`ease-magnet-loader` creates a magnetic motion effect using pure CSS animations.


## Features

- Pure CSS implementation
- No JavaScript dependency
- Magnetic attraction and repulsion effect
- Smooth loading animation
- Responsive layout
- Reduced motion accessibility support
