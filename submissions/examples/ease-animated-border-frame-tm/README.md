# Animated Border Frame Component

Add ease-animated-border-frame-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|---------|
| `--ab-accent` | `#6366f1` |
| `--ab-radius` | `12px` |
| `--ab-speed` | `3s linear infinite` |
| `--ab-dash` | `8px` |

## Technique

CSS mask with xor compositing + animated gradient background creates the border-only effect.
