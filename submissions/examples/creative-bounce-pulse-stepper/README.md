# CSS Bounce-Pulse Stepper for Creative Portfolio Layouts

A modern **Bounce-Pulse Stepper** component built completely with **HTML5 and CSS3**. This showcase demonstrates a creative portfolio stepper with smooth bounce animations, pulse glow effects, responsive layouts, and accessibility support without requiring JavaScript.

---

## ✨ Features

- 🔵 Bounce-pulse step animations
- ✨ Glowing active step indicator
- 🎨 Gradient step circles
- 💎 Glassmorphism cards
- ⚡ Smooth CSS transitions
- 🎯 CSS Custom Properties
- 📱 Fully responsive layout
- 🧩 Pure HTML5 & CSS3
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

## 🚀 Getting Started

1. Open `demo.html` in any modern browser.
2. Hover over the step items to trigger bounce animations.
3. Customize colors, spacing, and animation timing using CSS variables.
