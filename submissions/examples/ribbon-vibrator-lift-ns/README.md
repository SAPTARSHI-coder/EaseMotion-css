# Ribbon Vibrator Lift

## What does this do?
Renders a self-contained CSS-only `ease-ribbon-vibrator-lift` demo: Ribbon vibrator lifting the bichrome band.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-ribbon-vibrator-lift`. No build step or JavaScript is required for the effect.

```html
<section class="ease-ribbon-vibrator-lift">
  <div class="ease-ribbon-vibrator-lift__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
