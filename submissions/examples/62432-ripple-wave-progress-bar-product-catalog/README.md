# CSS Ripple-Wave Progress Bar for Product Catalog Layouts

A modern **Ripple-Wave Progress Bar** built using pure HTML5 and CSS3 for product catalog layouts. The component displays animated loading progress with ripple-wave effects, responsive product cards, and accessibility support.

## Features

* Pure HTML5 & CSS3
* Ripple-Wave progress animation
* Animated loading indicator
* Product catalog progress showcase
* Multiple progress states (25%, 50%, 75%, 100%)
* Glassmorphism product cards
* Responsive desktop, tablet, and mobile layout
* CSS Custom Properties
* Smooth CSS keyframe animations
* No JavaScript required
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in a modern browser.
2. Customize the progress percentages by adjusting the width of each `.fill-*` class.
3. Modify colors and spacing using the CSS variables in `:root`.
4. Integrate the component into any product catalog or dashboard interface.
