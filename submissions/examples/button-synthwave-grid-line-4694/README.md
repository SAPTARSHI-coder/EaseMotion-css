# Synthwave Grid Line Button

A smooth, accessible, and performant pure CSS button featuring a **Synthwave Grid Line** styling, complete with neon colors, glowing shadows, and an animated 3D grid background.

## What does this do?
It creates an interactive button with a synthwave aesthetic, featuring neon glows and a perspective grid that animates on hover.

## How is it used?
```html
<button class="btn-synthwave-grid">Synthwave</button>
```

## Why is it useful?
It provides a striking, retro-futuristic styling perfect for gaming, portfolio, or stylized websites, utilizing pure CSS with hardware acceleration and smooth transitions, adhering to EaseMotion's performance philosophy.
