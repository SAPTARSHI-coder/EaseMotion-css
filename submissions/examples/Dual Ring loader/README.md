Features
Dual rotating rings — two rings rotate independently.
Opposite rotation — creates a dynamic interlocking effect.
Gradient-style neon appearance — cyan and pink colors give it a modern UI look.
Pure HTML + CSS — no JavaScript or external libraries.
Responsive positioning — centered automatically on the screen.
Transparent borders — only selected portions of each ring are visible.
Infinite animation — continuously loops using CSS @keyframes.
Customizable speed — change 1.2s and 0.9s.
Customizable colors — modify #00e5ff and #ff00cc.
Lightweight — suitable for loading screens, buttons, dashboards, and web apps.
