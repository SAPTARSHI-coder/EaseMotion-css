
---

## 🚀 Usage
1. Clone or copy the files into your project.
2. Open `demo.html` in your browser.
3. The dialog will appear with a bouncy scale-in animation.

---

## 🛠️ Customization
- **Animation speed** → Adjust `animation: bounceIn 0.8s` for faster/slower bounce.
- **Dialog size** → Modify `max-width` and `padding` in `.dialog`.
- **Overlay color** → Change `background: rgba(0,0,0,0.4)` in `.dialog-overlay`.

---

## 📖 Accessibility
- Uses `role="dialog"` and `aria-modal="true"` for screen readers.
- Overlay ensures focus remains on the dialog.
