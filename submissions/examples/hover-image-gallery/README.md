# Hover Image Gallery

A responsive CSS-only image gallery with smooth image zoom and transition effects.

## Features

- Pure HTML and CSS
- Smooth image zoom on hover
- Responsive grid layout
- Image transition effects
- No JavaScript required
- Reduced-motion support
- Easy to customize

## Usage

Add an image inside the gallery structure:

```html
<article class="gallery-item">
  <div class="image-wrapper">
    <img
      src="your-image-url.jpg"
      alt="Description of image">
  </div>

  <h2>Image Title</h2>
</article>
