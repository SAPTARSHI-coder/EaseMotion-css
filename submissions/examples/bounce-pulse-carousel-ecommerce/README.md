# CSS Bounce-Pulse Carousel for E-Commerce Checkout Layouts

A responsive, lightweight, CSS-only product carousel designed for
E-Commerce Checkout layouts.

The component demonstrates a bounce-pulse animation that provides
visual feedback when a product card is hovered or receives keyboard focus.

## Features

- Pure HTML and CSS
- No JavaScript
- No external frameworks
- Bounce entrance animation
- Subtle repeating pulse effect
- Responsive product carousel
- Desktop, tablet, and mobile support
- Keyboard-friendly focus interaction
- `:focus-visible` support
- `prefers-reduced-motion` support
- CSS custom properties for customization
- Suitable for checkout recommendation sections
