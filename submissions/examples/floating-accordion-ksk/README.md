# Floating Accordion with Minimalist Styling

> Issue: [#79876](https://github.com/SAPTARSHI-coder/EaseMotion-css/issues/79876) / [#82011](https://github.com/SAPTARSHI-coder/EaseMotion-css/issues/82011)

A responsive, lightweight floating accordion component with minimalist design elevation.

---

## ✨ Features & Architectural Highlights

- **Pure HTML5/CSS Architecture:** Native `<details>` and `<summary>` tags for zero-JS accordion interaction.
- **Floating Minimalist Aesthetics:** Subtle shadow elevation depth and micro-lift hover interactions.
- **Accessible & Responsive:** Includes `@media (prefers-reduced-motion: reduce)` overrides and dark mode support.

---

## 🚀 Usage

1. Include `style.css` in your HTML `<head>`:
   ```html
   <link rel="stylesheet" href="style.css" />
   ```
2. Use the HTML structure provided in `demo.html`.
