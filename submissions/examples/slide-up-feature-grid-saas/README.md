# Slide-Up Feature Grid

A clean slide-up feature grid component for SaaS showcase layouts.

## Features

- Staggered slide-up entrance animation for each card
- Responsive CSS Grid layout
- Accessible with `prefers-reduced-motion` support
- CSS custom properties for easy theming

## Customization

```css
:root {
  --suf-white: #ffffff;
  --suf-bg: #fafafa;
  --suf-text: #111827;
  --suf-muted: #6b7280;
  --suf-border: #e5e7eb;
  --suf-indigo: #6366f1;
}
```

## Usage

```html
<link rel="stylesheet" href="style.css">
```

## Files

- `demo.html` — Demo markup
- `style.css` — All styles and animations
