# 3D Perspective Tilt Product Showcase Card with Light Reflections

### Compact Mobile-First Edition

A premium **3D Product Showcase Card** built with **HTML5** and **CSS3** featuring realistic perspective tilt, animated light reflections, responsive mobile-first design, and accessibility-friendly interactions.

---

## ✨ Features

- 3D perspective tilt effect
- Animated light reflection
- Mobile-first responsive layout
- Gradient CTA button
- Glass-inspired modern UI
- Smooth hover animations
- CSS Variables for customization
- Keyboard accessibility
- `prefers-reduced-motion` support
- Pure HTML & CSS implementation
