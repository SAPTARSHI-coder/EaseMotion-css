# Cannon Pinion Drive

## What does this do?
Renders a self-contained CSS-only `ease-cannon-pinion-drive` demo: Cannon pinion driving minute hand motion from the center.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-cannon-pinion-drive`. No build step or JavaScript is required for the effect.

```html
<section class="ease-cannon-pinion-drive">
  <div class="ease-cannon-pinion-drive__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
