\# Matrix Digital Rain Component



A retro terminal style data stream component featuring vertical cascading numbers, glowing emerald typography effects, and interactive controls built for EaseMotion CSS.



\## Location

\- Directory: `submissions/examples/matrix-digital-rain-ij/`



\## Files Included

\- `demo.html`: Interactive preview window showcasing the digital rain simulation.

\- `style.css`: Scoped terminal styling and keyframe rules (`ease-matrix-fall`).

\- `README.md`: Documentation for the component submission.
