# Fade-In Badge

A responsive Fade-In Badge example built with pure HTML and CSS for EaseMotion CSS.

## Features

- Pure HTML & CSS
- Smooth fade-in animation
- Responsive layout
- Hover effect
- Multiple badge variants
- CSS custom properties
- Supports `prefers-reduced-motion`

## Folder Structure

```
fade-in-badge-vk/
├── demo.html
├── style.css
└── README.md
```

## Accessibility

- Responsive design
- Motion reduction support
- Semantic HTML
- Lightweight and framework-free

## Browser Support

Works in all modern browsers supporting CSS animations and media queries.
