# ⚡ CSS Glitch-Flicker Popover for Minimalist Tech Layouts

A futuristic **pure CSS popover component** built for the EaseMotion CSS collection.

This component creates a cyber-tech style notification using glitch animation, neon effects, and flicker transitions without requiring JavaScript.

---

## ✨ Features

- Pure HTML & CSS implementation
- No JavaScript dependency
- Glitch entrance animation
- Neon sweep animation
- Flicker effect
- Responsive layout
- CSS custom properties support
- Accessible with `prefers-reduced-motion`
