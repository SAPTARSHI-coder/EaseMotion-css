# Chalk Line Snap

## What does this do?
Renders a self-contained CSS-only `ease-chalk-line-snap` demo: Mason chalk line snapping a blue mark across a board.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-chalk-line-snap`. No build step or JavaScript is required for the effect.

```html
<section class="ease-chalk-line-snap">
  <div class="ease-chalk-line-snap__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
