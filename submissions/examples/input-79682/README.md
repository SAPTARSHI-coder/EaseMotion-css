# CSS-only Neumorphic Input

Issue #79682 demonstrates a responsive input field using a soft neumorphic surface.

## Features

- Native form controls
- Inset depth styling
- Responsive spacing
- Visible focus states
- Mobile-friendly layout
- Pure HTML and vanilla CSS

## Usage

Open demo.html to preview the component and link style.css when integrating it into another page.

## Accessibility

Native labels and controls remain in place, with a clear focus treatment for keyboard users.

## Design

Inset shadows separate fields from the surrounding surface without images or JavaScript.
