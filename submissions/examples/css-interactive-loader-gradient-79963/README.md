# Interactive Loader with Gradient Styling

A modern responsive loader featuring multiple animated gradient rings and a pulsing center effect.

## Features

- Fully responsive
- Pure HTML & CSS
- Multi-layer animated loader
- Gradient-inspired visual design
- Smooth continuous animations
- Lightweight and reusable

## Files

- demo.html
- style.css

## Preview

The component displays:

- Rotating concentric loader rings
- Gradient color accents
- Pulsing center animation
- Responsive layout for mobile and desktop

## Usage

Open `demo.html` in any modern browser.
