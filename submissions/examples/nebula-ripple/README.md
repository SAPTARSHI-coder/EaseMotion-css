# 🌊 Nebula Ripple

> Touch the cosmic surface. Disturb the stars. Watch the universe react.

Nebula Ripple is a fully interactive cosmic ripple component where pointer interactions generate glowing waves across an animated space-like surface.

Each click or touch creates a luminous ripple that expands from the interaction point, pushes nearby particles away, and gradually disappears into the surrounding nebula.

The component is built entirely with vanilla HTML, CSS, and JavaScript and requires no external libraries, frameworks, packages, or build tools.

---

## ✨ Features

- 🌌 Animated deep-space background
- 🌊 Interactive cosmic ripples
- ✨ 60 animated background particles
- 🪐 Orbital particle system
- 💫 Particle displacement based on ripple proximity
- 🌈 Multi-layer nebula gradients
- 🔮 Central cosmic glow
- 📊 Real-time ripple counter
- 🎚️ Ripple intensity control
- ⚡ Ripple speed control
- 🔄 Reset functionality
- 🖱️ Mouse interaction
- 📱 Touch support
- ⌨️ Keyboard shortcuts
- 📐 Responsive layout
- 🚫 Zero external dependencies
