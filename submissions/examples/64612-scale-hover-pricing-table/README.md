# CSS Scale-Hover Pricing Table for Minimalist Tech Layouts

A modern and responsive **CSS-only Scale-Hover Pricing Table** designed for minimalist SaaS and technology showcase layouts.

This component provides interactive pricing cards with smooth scaling effects, clean UI, and lightweight animations without using JavaScript.

---

## ✨ Features

- Smooth scale-hover animation
- Modern SaaS pricing card design
- Pure HTML & CSS implementation
- Responsive across all screen sizes
- Glass-inspired minimalist layout
- Highlighted popular plan badge
- Customizable CSS variables
- Accessibility support with `prefers-reduced-motion`
