# Float-Drift Card Grid (Fintech Dashboard)

## What does this do?

A modern fintech dashboard featuring a responsive grid of financial cards with a smooth floating drift animation. Built entirely with HTML and CSS, the component combines glassmorphism styling with subtle motion to create an engaging dashboard experience.

---

## Features

- Float-drift card animation
- Glassmorphism card design
- Fintech-inspired dashboard UI
- Smooth staggered floating effect
- Responsive grid layout
- Pure HTML & CSS (No JavaScript)
- Supports `prefers-reduced-motion`

---

## Files

- `demo.html` — Component showcase
- `style.css` — Component styling and animations
- `README.md` — Documentation
