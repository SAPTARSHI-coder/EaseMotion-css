# Image Glitch Hover

Hovering an image triggers a chromatic glitch slice effect.

## Features
- RGB split slices
- Hover-triggered glitch
- Clip-path banding
- Pure CSS

## Usage
```html
<div class="igh-frame"><div class="igh-ghost"></div></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
