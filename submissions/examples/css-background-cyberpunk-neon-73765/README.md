# CSS Cyberpunk Neon Background

A futuristic Cyberpunk Neon animated background built entirely with HTML and CSS. The design combines glowing neon beams, colorful blur effects, and subtle motion to create an immersive sci-fi atmosphere.

## Features

- Pure HTML & CSS
- Cyberpunk neon visual style
- Animated glowing light beams
- Floating neon glow effects
- Hardware-accelerated CSS animations
- Dark mode friendly
- Fully responsive
- Accessible structure
- No JavaScript required

## Usage

Include the stylesheet and use the background container.

```html
<div class="cyberpunk-bg">
  <span class="line line-1"></span>
  <span class="line line-2"></span>
  <span class="glow glow-1"></span>
</div>
