# CSS Message Read Receipts

A demo project showcasing **message read receipts** styled with CSS, similar to chat apps.

## Features
- Chat bubble design with sent messages aligned to the right.
- Read receipt indicators:
  - ✔ (single tick) → Sent
  - ✔✔ (double tick) → Delivered
  - ✔✔ (colored) → Read
- Clean, responsive layout.

## Files
- `demo.html` → Structure with sample messages and receipts.
- `style.css` → Styling for chat bubbles and receipt states.
- `README.md` → Documentation and usage instructions.

## Usage
1. Open `demo.html` in your browser.
2. Observe different receipt states for each message.
3. Customize colors and icons to match your app’s theme.

## Customization Ideas
- Replace ticks with SVG icons for sharper visuals.
- Add hover tooltips (e.g., “Sent”, “Delivered”, “Read”).
- Integrate with JavaScript to dynamically update receipt state.
- Extend to include timestamps and incoming messages.
