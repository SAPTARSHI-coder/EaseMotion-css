# Morphing Buttons

A lightweight CSS-only button animation that smoothly transforms button shapes on hover and focus.

## Features

- Pure HTML and CSS
- No JavaScript required
- Smooth shape transformation
- Multiple morphing styles
- Responsive design
- Keyboard accessible
- Supports `prefers-reduced-motion`
- Uses CSS custom properties for animation control

## Files

- `demo.html` - Demonstration page
- `style.css` - Morphing button styles
- `README.md` - Documentation

## Usage

Add the button class to any HTML button:

```html
<button class="morph-btn morph-circle">
  Hover Me
</button>
