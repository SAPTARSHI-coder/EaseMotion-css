# Interactive Tooltip with Neon Styling

This is a fully responsive interactive tooltip featuring cyberpunk neon glow effects on hover.

### Usage
```html
<button class="tooltip-btn">
    Hover Me
    <span class="tooltip-content">Neon Tooltip Active</span>
</button>
```

### Why is it useful?
It provides a sleek, modern UI element for displaying additional information, perfectly matching dark mode and cyberpunk design aesthetics.
