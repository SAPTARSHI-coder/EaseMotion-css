# Dynamic Cookie Consent Banner (Brutalism)

## Overview

A bold Brutalism-inspired cookie consent banner built with pure HTML and CSS. The component uses high-contrast colors, thick borders, and responsive layouts while maintaining accessibility and smooth interactions.

## Features

- Brutalist visual design
- Pure HTML & CSS
- Responsive layout
- Smooth hover transitions
- Accessible keyboard focus styles
- No JavaScript required
- Supports `prefers-reduced-motion`

## Files

- `demo.html`
- `style.css`
- `README.md`

## Usage

Open `demo.html` in any modern browser.
