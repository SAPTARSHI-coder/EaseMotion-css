# Cyclone Dust Separator

## What does this do?
Renders a self-contained CSS-only `ease-cyclone-dust-separator` demo: Workshop cyclone separator spinning dust downward.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-cyclone-dust-separator`. No build step or JavaScript is required for the effect.

```html
<section class="ease-cyclone-dust-separator">
  <div class="ease-cyclone-dust-separator__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
