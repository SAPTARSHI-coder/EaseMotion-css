# Interactive Price Comparison Card Tier Switcher Component

1. **What does this do?** 
   A minimalist, clean pricing card section featuring a smooth monthly/annually billing toggle switcher with fluid number transitions.

2. **How is it used?** 
   Simply copy the `demo.html` structure (which includes the vanilla JS for the toggle) and apply the `style.css` stylesheet. It works entirely standalone and relies on standard CSS variables.

3. **Why is it useful?** 
   It demonstrates a highly requested UI component—a responsive pricing table with interactive state—while adhering to a clean, modern "glassmorphism / neon accent" aesthetic. It maintains performance and readability without relying on heavy external JS frameworks, fitting perfectly with EaseMotion's philosophy.
