# CSS Glass Effect: 3D Perspective Tilt

A smooth, accessible, and performant pure CSS glassmorphism component featuring
a subtle 3D perspective tilt effect.

## Features

- Pure HTML and Vanilla CSS
- Glassmorphism-inspired translucent surface
- 3D perspective depth
- CSS `perspective` and `transform`
- Subtle hover tilt interaction
- Layered depth using `translateZ()`
- Animated ambient background lighting
- Smooth CSS transitions
- Dark mode compatible
- Responsive layout
- Accessible keyboard focus states
- `prefers-reduced-motion` support
- Hardware-friendly transforms
- No JavaScript
- No external libraries
