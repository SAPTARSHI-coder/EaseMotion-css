# Slide-Up Creative Portfolio Drawer (`#54510`)

## What does this do?
Produces an expansive bottom portfolio sheet that smoothly glides upwards from the screen baseline, enabling immersive multi-column project browsing without navigating away.

## How is it used?
Configure exhibition columns inside an `ease-drawer-slide-up` bottom container box:
```html
<div class="ease-bottom-portal open">
  <aside class="ease-drawer-slide-up">...</aside>
</div>
```

## Why is it useful?
Solves issue #54510 by transforming basic slide drawers into spacious mobile-friendly exhibition dashboards.
