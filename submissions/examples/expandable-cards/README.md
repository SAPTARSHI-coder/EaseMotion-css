# Expandable Cards

A reusable CSS-only expandable card component for EaseMotion CSS.

## Features

- Smooth width expansion
- Scale and lift interaction
- Fade-in content
- Responsive layout
- CSS custom properties for customization
- Keyboard-friendly focus interaction
- Reduced-motion support
- No JavaScript required

## Files

- `demo.html` — Component demonstration
- `style.css` — Component styles and animations
- `README.md` — Documentation

## Usage

Add the following structure:

```html
<article class="card">
    <div class="icon">01</div>

    <div class="content">
        <h2>Design</h2>
        <p>
            Create clean and engaging interfaces with smooth interactions.
        </p>
    </div>
</article>
