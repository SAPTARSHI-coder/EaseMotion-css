\# Ease Corner Reveal Hover



\## Description



Ease Corner Reveal Hover is a CSS-only hover animation that creates a smooth diagonal reveal effect from the top-left corner of an element.



The effect is lightweight, reusable, and requires no JavaScript.



\---



\## Features



\- CSS-only implementation

\- Smooth diagonal reveal animation

\- Lightweight and reusable

\- Responsive

\- Includes reduced-motion accessibility support



\---



\## Usage



```html

<div class="ease-corner-reveal">

&#x20;   Hover Me

</div>

```



Include the stylesheet.



```html

<link rel="stylesheet" href="style.css">

```



\---



\## Suitable For



\- Buttons

\- Cards

\- Hero Sections

\- Call-to-Action Buttons

\- Product Cards

\- Interactive Components



\---



\## Accessibility



Supports



```css

@media (prefers-reduced-motion: reduce)

```



to respect the user's motion preferences.



\---



\## Demo



Open \*\*demo.html\*\* directly in any modern browser and hover over the element to view the animation.
