# Perspective Hover Tilt

A subtle perspective tilt follows hover position using pure CSS variables.

## Features
- Variable-driven tilt angles
- Gradient highlight shifts with tilt
- Smooth springy easing
- Zero JS

## Usage
```html
<div class="pht-card">...</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
