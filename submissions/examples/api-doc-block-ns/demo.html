Get User Profile

Retrieves public profile details and configuration settings for a specified user account ID.

GET /api/v1/users/{id}

Parameters

Name Type Description
id Required string

Unique alphanumeric identifier assigned to the user profile.
include_stats Optional boolean

Appends performance analytics and contribution metrics to payload.

Response Example (200 OK)

{
  "status": "success",
  "data": {
    "id": "usr_998124",
    "username": "frontend_dev",
    "verified": true
  }
}
