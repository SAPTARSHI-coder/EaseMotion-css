# CSS Ripple-Wave Tooltip for SaaS Showcase Layouts

A modern **Ripple-Wave Tooltip** component built using pure HTML and CSS. The tooltip displays a smooth expanding ripple-wave animation combined with a clean glassmorphism design, making it suitable for SaaS dashboards and product showcases.

## ✨ Features

- Pure HTML5 & CSS3
- Ripple-wave tooltip animation
- Glassmorphism styling
- Responsive layout
- Smooth hover transitions
- CSS Custom Properties
- `prefers-reduced-motion` support
- No JavaScript required
