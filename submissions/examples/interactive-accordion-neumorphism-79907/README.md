# Interactive Accordion with Neumorphism Styling

A responsive accordion component featuring soft neumorphic shadows, smooth interactions, and a clean modern aesthetic built entirely with HTML and CSS.

## Features

- Interactive accordion sections
- Soft neumorphic design
- Responsive layout
- Accessible native `<details>` element
- Pure HTML/CSS implementation
- Lightweight and customizable

## Files

- demo.html
- style.css

## Usage

```html
<details class="accordion">
  <summary>Accordion Title</summary>

  <div class="content">
    Accordion content goes here.
  </div>
</details>
```

## Customization

Modify:

- Shadow intensity
- Background colors
- Border radius
- Typography
- Spacing
