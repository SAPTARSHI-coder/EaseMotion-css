# Animated CSS Buttons - Massive Collection

This submission provides an extensive collection of modern CSS-only animated buttons, fulfilling the issue [feat: Add interactive animated button examples #87408](https://github.com/SAPTARSHI-coder/EaseMotion-css/issues/87408).

## Features

- **100 Unique Variations**: Each variation features a unique combination of colors (using HSL), hover effects (pulse, swipe, gradient shift), and animations.
- **CSS Only**: No JavaScript or external libraries are required.
- **Light/Dark Mode**: The demo includes a built-in theme toggle.

## Usage

1. Open `demo.html` in your browser to preview all 100 variations.
2. Find a button you like, note its variation number (e.g., Variation 42).
3. Copy the HTML from `demo.html` and the corresponding CSS from `style.css`.

### HTML Example

```html
<button class="btn btn-variation-42">Hover Me</button>
```

### CSS Example

Check `style.css` for the `.btn-variation-X` classes corresponding to your chosen variation.

## Customization

Easily customize any button by adjusting its properties in `style.css`:
- Modify `padding` and `font-size` for sizing.
- Adjust `background-color` and `border` for theming.
- Tweak the `transition` or `animation` durations.
