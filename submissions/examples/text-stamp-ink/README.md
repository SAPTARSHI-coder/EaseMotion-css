# Text Stamp Ink

A rubber-stamp effect hammers in with a dusty ink press.

## Features
- Stamp press entrance
- Grainy ink texture
- Slight rotation slap
- Pure CSS

## Usage
```html
<div class="tsi-stamp">APPROVED</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
