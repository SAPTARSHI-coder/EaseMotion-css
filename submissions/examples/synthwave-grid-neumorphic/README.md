# Synthwave Grid Neumorphic Effect

A pure CSS neumorphic UI component inspired by retro synthwave interfaces.

This variation combines a dark neumorphic surface with a glowing perspective
grid, neon accents, smooth transitions, and an accessible interactive layout.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript or external dependencies
- Synthwave-inspired perspective grid
- Neumorphic shadows and surfaces
- Smooth hover and focus transitions
- Responsive layout
- Dark-mode compatible styling
- Hardware-friendly CSS transforms
- `prefers-reduced-motion` support
- Keyboard-accessible buttons

## Files

- `demo.html` — Self-contained demonstration
- `style.css` — Component styles
