# ease-skeleton-shimmer-bh

Pure CSS skeleton loading shimmer animation.

## Features
- Smooth shimmer loading effect
- Multiple skeleton variants
- Responsive design
- Accessibility support

## Usage
```html
<div class="ease-skeleton ease-skeleton-shimmer">Loading...</div>
```

## CSS Classes
- `.ease-skeleton` - Base skeleton
- `.ease-skeleton-shimmer` - Shimmer animation
