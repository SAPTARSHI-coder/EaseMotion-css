# Floating Stepper Nav – Minimalist

A clean and modern **Floating Stepper Navigation** component built with **pure HTML and CSS** using a minimalist design approach.

## Features

- ✨ Floating card interface
- 📱 Responsive layout
- 🎯 Active & completed step indicators
- 🎨 Minimalist styling
- ⚡ Smooth hover transitions
- ♿ Accessible navigation (`aria-current="step"`)
- 🌙 CSS Custom Properties
- 🚫 No JavaScript
- 🎭 `prefers-reduced-motion` support
