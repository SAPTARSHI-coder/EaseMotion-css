Basic Notification Permission Row

Permission rows for notification and privacy settings.

A CSS-only row component for showing permission copy, current state, and a simple toggle-style control in settings or onboarding screens.

N
Product updates

Receive release notes and important feature announcements.

Allowed
R
Review reminders

Get notified before pending reviews become inactive.

Ask
M
Marketing messages

Optional product tips and promotional updates are disabled.

Blocked

<article class="basic-notification-permission-row">
  <span class="permission-icon" aria-hidden="true">N</span>
  <div class="permission-copy">
    <strong>Product updates</strong>
    <p>Receive release notes and important announcements.</p>
  </div>
  <span class="permission-state is-granted">Allowed</span>
  <span class="permission-toggle is-on" aria-hidden="true"></span>
</article>
