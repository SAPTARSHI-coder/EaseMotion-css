# 3D SaaS Modern Accordion (Lite)

A clean and responsive 3D-inspired accordion component designed with a modern SaaS visual style.

## Features

- Modern SaaS-inspired UI
- Subtle 3D depth and layered shadows
- Native HTML accordion behavior
- No JavaScript required
- Smooth open/close interaction
- Responsive across desktop, tablet, and mobile
- Keyboard accessible using native `<details>` and `<summary>`
- Reduced-motion support
- No external dependencies
