# CSS Scratch-Off Card


A pure CSS scratch-off reward card animation for EaseMotion CSS.


## Overview

`css-scratch-off-card` creates a scratch card effect where the overlay disappears on hover revealing hidden content.


## Features

- Pure CSS implementation
- No JavaScript dependency
- Scratch reveal animation
- Responsive layout
- Smooth transition effect
- Reduced motion accessibility support


## Animation

Uses CSS transitions to reveal the hidden reward content.


## Usage

Useful for:

- Reward cards
- Coupon sections
- Promotional UI
- Interactive landing pages
