# Glassmorphism Button

Retro-inspired glassmorphism button showcase for issue #78665.

## Files

- `demo.html` — semantic button examples.
- `style.css` — translucent surfaces, borders, and interaction states.

## Features

- Glass-like translucent surface.
- Retro accent treatment.
- Hover, active, and focus-visible states.
- Responsive button group.
- Reduced-motion support.

The example relies on CSS only and can be integrated with existing application actions.
