# Radial Circular Progress Indicator with Animated Percentage Counter

### High-Contrast Accessibility Edition

A modern **Radial Circular Progress Indicator** built with **HTML5** and **CSS3**. Designed for accessibility with a high-contrast theme, animated progress ring, responsive layout, and keyboard-friendly interactions.

---

## ✨ Features

- High-contrast accessible design
- Animated radial progress indicator
- Percentage counter display
- Responsive mobile-first layout
- Hover glow effect
- CSS Variables
- `prefers-reduced-motion` support
- Pure HTML & CSS
