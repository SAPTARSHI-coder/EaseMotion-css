# Velvet Smooth Transition Button

A polished pure CSS button collection featuring a **Velvet Smooth Transition** visual style.

## ✨ Features

- Velvet-inspired gradient styling
- Smooth hover transitions
- Soft elevation effects
- Animated sheen sweep
- Multiple button variations
- Responsive layout
- Dark-mode compatible
- Light-mode compatible
- Keyboard-accessible buttons
- Visible focus states
- Reduced-motion support
- Hardware-friendly CSS transforms
- No JavaScript
- No external dependencies
