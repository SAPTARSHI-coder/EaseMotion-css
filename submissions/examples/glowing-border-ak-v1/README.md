# glowing-border-ak

Pure CSS animated rotating gradient border card — no JavaScript required.

## How to use

```html
<div class="ease-glow-card">
  <h3 class="ease-glow-card__title">Card Title</h3>
  <p class="ease-glow-card__desc">Card description goes here.</p>
</div>

<!-- Color Variants -->
<div class="ease-glow-card ease-glow-card--cyber">...</div>
<div class="ease-glow-card ease-glow-card--fire">...</div>
