# Dynamic Card with Cyberpunk Styling

A responsive cyberpunk-inspired card component featuring neon gradients,
glowing visual elements, dynamic hover interactions, and futuristic UI
details.

## Features

- Cyberpunk visual design
- Responsive card grid
- Three card variations
- Neon gradient accents
- Glowing visual core
- Animated ambient glow
- Scanline hover effect
- Hover elevation
- Interactive CTA
- Responsive behavior
- Keyboard-visible focus states
- `prefers-reduced-motion` support
- Pure HTML and Vanilla CSS
- No JavaScript or external dependencies

## Files

- `demo.html`
- `style.css`

## Usage

Open `demo.html` directly in a browser.

The component can be customized by changing the card title, description,
statistics, status, accent colors, and CTA labels.

## Technologies

- HTML5
- Vanilla CSS

## Accessibility

Interactive links use native keyboard navigation and visible
`:focus-visible` states.

The component also respects the user's `prefers-reduced-motion`
preference.

## Responsive Behavior

The cards display in a three-column layout on larger screens, adapt to
two columns on medium screens, and stack into a single-column layout on
mobile devices.
