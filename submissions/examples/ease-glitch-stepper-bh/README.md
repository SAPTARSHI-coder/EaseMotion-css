# ease-glitch-stepper-bh

Pure CSS glitch-flicker stepper component.

## What does this do?
Creates animated steppers with glitch and flicker effects.

## How is it used?
```html
<div class="ease-stepper-bh ease-glitch-stepper-bh">
  <div class="ease-step-bh active">1</div>
  <div class="ease-step-bh">2</div>
</div>
```

## Why is it useful?
Creates edgy, gaming-style step indicators with glitch effects.
