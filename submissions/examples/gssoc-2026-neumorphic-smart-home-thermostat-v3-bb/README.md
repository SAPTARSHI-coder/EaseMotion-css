# Neumorphic Smart Home Thermostat v3

## 1. What does this do?
The Neumorphic Smart Home Thermostat component renders a soft tactile smart thermostat UI with dual inset and outset shadows, glowing temperature metrics, and mode selection buttons.

## 2. How is it used?
Incorporate the thermostat widget into IoT control applications, smart home dashboards, or energy management suites.

## 3. Why is it useful?
It provides a realistic soft-UI tactile feel using CSS dual drop-shadow and inset-shadow techniques.
