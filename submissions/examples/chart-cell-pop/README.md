# Chart Cell Pop

Heatmap cells pop and glow in sequence to show intensity.

## Features
- Sequential cell pulse
- Colour heat ramp
- Grid alignment
- Pure CSS

## Usage
```html
<i style="--i:0;--v:0.6"></i>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
