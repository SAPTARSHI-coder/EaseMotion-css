# Parallax Hero Section Component

**Issue:** [#71813](https://github.com/SAPTARSHI-coder/EaseMotion-css/issues/71813)

Hero section with animated gradient background and parallax-style depth using pure CSS.

## Design Tokens

| Token | Default |
|-------|---------|
| `--tm-px-height` | `100vh` |
| `--tm-px-accent` | `#6366f1` |
| `--tm-px-heading` | `clamp(2.5rem, 6vw, 5rem)` |
| `--tm-px-bg-1` | `#0f172a` |
| `--tm-px-card-radius` | `16px` |

## Structure

- `.px-hero` — full-viewport hero with animated background
- `.px-heading` / `.px-sub` / `.px-btn` — hero content
- `.px-section` / `.px-grid` / `.px-card` — supporting sections
