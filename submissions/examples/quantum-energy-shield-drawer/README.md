# Quantum Energy Shield Drawer

A futuristic **Quantum Energy Shield Drawer** built entirely with HTML and CSS.

## Features

- Pure HTML & CSS
- Quantum energy shield glow effect
- Smooth slide-in drawer animation
- Responsive sidebar layout
- Accessible checkbox toggle
- Hardware-accelerated transitions
- Dark mode compatible
- No JavaScript required
