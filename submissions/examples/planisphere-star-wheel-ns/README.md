# Planisphere Star Wheel

## What does this do?
Renders a self-contained CSS-only `ease-planisphere-star-wheel` demo: Planisphere star wheel rotating night sky against horizon mask.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-planisphere-star-wheel`. No build step or JavaScript is required for the effect.

```html
<section class="ease-planisphere-star-wheel">
  <div class="ease-planisphere-star-wheel__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
