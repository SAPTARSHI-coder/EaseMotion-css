# float-card-stack-ak

Pure CSS 3D floating stacked cards hover fan-out effect — no JavaScript required.

## How to use

```html
<div class="ease-card-stack">
  <div class="ease-card-stack-item">Top Card</div>
  <div class="ease-card-stack-item">Middle Card</div>
  <div class="ease-card-stack-item">Bottom Card</div>
</div>
