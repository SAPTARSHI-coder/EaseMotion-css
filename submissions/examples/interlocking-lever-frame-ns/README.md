# Interlocking Lever Frame

## What does this do?
Renders a self-contained CSS-only `ease-interlocking-lever-frame` demo: Interlocking lever frame pulling a route.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-interlocking-lever-frame`. No build step or JavaScript is required for the effect.

```html
<section class="ease-interlocking-lever-frame">
  <div class="ease-interlocking-lever-frame__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
