# Floating Tooltip Component

A lightweight, pure CSS tooltip component featuring a slide-and-fade entrance transition on hover.

## Features
- **Hover Micro-Interaction:** Smooth 60fps vertical translate and opacity fade.
- **CSS Arrow Pointer:** Native CSS border pseudo-element arrow positioning.
- **Zero Dependencies:** Pure CSS implementation requiring no JavaScript handlers.

## File Structure
- `demo.html` - Button wrapper and tooltip layout structure.
- `style.css` - Absolute positioning rules and hover animation utilities.
