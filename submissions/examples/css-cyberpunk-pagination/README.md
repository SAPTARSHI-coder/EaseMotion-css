# CSS-only Pagination with Cyberpunk Styling

A responsive cyberpunk-themed pagination component built using only HTML and CSS.

## Features

- Pure HTML & CSS
- Neon cyberpunk appearance
- Hover glow animation
- Active page highlight
- Responsive layout
- Accessible navigation

## Files

- demo.html
- style.css

## Usage

```html
<link rel="stylesheet" href="style.css">
```

Open `demo.html` directly in your browser.

## Customization

- Change neon colors
- Modify border radius
- Adjust glow intensity
- Add/remove page buttons
