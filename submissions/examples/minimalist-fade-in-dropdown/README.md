# CSS Fade-In Dropdown

A modern **CSS Fade-In Dropdown** built entirely with **HTML5** and **CSS3**. This showcase demonstrates a clean, minimalist dropdown menu with a smooth fade-in animation, responsive design, and accessibility-friendly interactions—all without JavaScript.

---

## ✨ Features

- 🚀 Pure HTML5 & CSS3
- ✨ Smooth fade-in dropdown animation
- 📂 CSS-only hover and keyboard interactions
- 💻 Minimalist tech-inspired design
- 📱 Fully responsive layout
- ♿ Keyboard-accessible using `:focus-within`
- 🎨 Easy customization using CSS Custom Properties
- 🌙 Supports `prefers-reduced-motion`
- ⚙️ No JavaScript or external libraries

## 🚀 Usage

1. Open `demo.html` in a modern web browser.
2. Hover over the dropdown button or focus it using the keyboard.
3. The dropdown menu will smoothly fade into view.
4. Customize colors, spacing, and animation timing using the CSS custom properties.

---

## 🎨 CSS Custom Properties

| Variable | Description |
|----------|-------------|
| `--bg` | Page background color |
| `--surface` | Dropdown background |
| `--primary` | Primary accent color |
| `--secondary` | Secondary accent color |
| `--text` | Primary text color |
| `--muted` | Secondary text color |
| `--border` | Border color |
| `--radius` | Border radius |
| `--shadow` | Dropdown shadow |
| `--transition` | Transition timing |

Example:

```css
:root{
    --primary:#2563eb;
    --secondary:#38bdf8;
}
```
