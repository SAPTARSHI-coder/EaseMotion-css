# Pantograph Contact Rise

## What does this do?
Renders a self-contained CSS-only `ease-pantograph-contact-rise` demo: Pantograph rising to the contact wire.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-pantograph-contact-rise`. No build step or JavaScript is required for the effect.

```html
<section class="ease-pantograph-contact-rise">
  <div class="ease-pantograph-contact-rise__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
