# Cotton Gin Roller

## What does this do?
Renders a self-contained CSS-only `ease-cotton-gin-roller` demo: Cotton gin rollers separating fiber from seed.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-cotton-gin-roller`. No build step or JavaScript is required for the effect.

```html
<section class="ease-cotton-gin-roller">
  <div class="ease-cotton-gin-roller__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
