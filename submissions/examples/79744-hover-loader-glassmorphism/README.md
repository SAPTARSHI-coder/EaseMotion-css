# Hover Loader — Glassmorphism

A responsive CSS-only hover loader with a modern glassmorphism visual
style, animated rings, soft glowing effects, and responsive behavior.

Implemented for EaseMotion CSS issue #79744.

## Features

- Glassmorphism UI
- CSS-only loader
- Animated concentric loader rings
- Hover-based loader interaction
- Glass blur effect
- Soft glowing accents
- Animated progress indicator
- Status indicator
- Floating decorative background orbs
- Responsive desktop, tablet, and mobile layout
- `prefers-reduced-motion` support
- Keyboard-independent visual interaction
- Zero JavaScript dependencies
