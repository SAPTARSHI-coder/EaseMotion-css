# Dynamic Accordion Table Row Expander

## Issue

#58232

## Description

A modern expandable data table component that allows users to reveal
additional information underneath individual table rows.

The component combines a clean data-table layout with a smooth accordion
animation.

## Features

- Expandable table rows
- Smooth reveal animation
- Neumorphic UI design
- Responsive table layout
- Interactive expand buttons
- Only one row expanded at a time
- Semantic HTML table structure
- Reduced-motion support
- No external libraries required

## Files

- `demo.html` - Component demonstration
- `style.css` - Styling and animations
- `script.js` - Row expansion functionality
