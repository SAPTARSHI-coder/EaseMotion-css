# Liquid Wave Waveform Audio Visualizer

A modern, responsive audio visualizer component featuring animated
liquid waveform bars, gradient effects, and a compact mobile-first UI.

## Features

- Animated waveform bars
- Play and pause interaction
- Animated progress indicator
- Current playback timer
- Gradient neon styling
- Responsive mobile-first design
- CSS animations
- Reduced-motion accessibility support
- No external libraries
