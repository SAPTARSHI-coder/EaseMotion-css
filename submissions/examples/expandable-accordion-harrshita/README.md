# Expandable Accordion Menu

Smooth height animated accordion using CSS Grid grid-template-rows.

## Usage
```html
<link rel="stylesheet" href="style.css" />
<div class="ease-accordion-item">
  <button class="ease-accordion-header">Header</button>
  <div class="ease-accordion-wrapper">
    <div class="ease-accordion-content"><p>Content</p></div>
  </div>
</div>
```
