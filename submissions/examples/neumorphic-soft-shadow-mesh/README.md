# Neumorphic Soft Shadow Mesh

A pure CSS mesh-gradient effect combined with a soft neumorphic shadow
treatment. It uses layered radial gradients, soft shadows, smooth
transitions, and responsive styling without JavaScript.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript or external dependencies
- Soft neumorphic shadow treatment
- Layered mesh-gradient background
- Smooth hover transitions
- Dark mode support
- Responsive layout
- Reduced-motion support
- Keyboard-accessible controls
- Hardware-friendly CSS transforms
