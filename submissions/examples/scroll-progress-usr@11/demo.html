What is a Scroll Progress Indicator?

A scroll progress indicator is a visual element that shows users how far they've scrolled down a page. It's commonly used in long-form content like articles, blog posts, and documentation to help users understand their position within the content.

This component uses EaseMotion CSS for smooth animations and JavaScript to calculate the scroll percentage in real-time.

Why Use It?

  • Improved UX: Users know how much content remains
  • Engagement: Visual feedback encourages continued reading
  • Accessibility: Helps users with cognitive disabilities track their progress
  • Modern Design: Adds a professional touch to long-form content

Features

  • ✅ Fixed position at the top of the viewport
  • ✅ Smooth gradient animation as you scroll
  • ✅ Percentage indicator (optional)
  • ✅ Back to top button with smooth scroll
  • ✅ Fully responsive design
  • ✅ Respects prefers-reduced-motion
  • ✅ Lightweight and performant

How It Works

The component calculates the scroll percentage using this formula:

scrollPercentage = (scrollTop / (scrollHeight - clientHeight)) * 100

This percentage is then applied to the width of the progress bar, creating a smooth fill effect as the user scrolls.

Customization

You can easily customize the progress bar by modifying the CSS variables:

  • --progress-height: Height of the progress bar
  • --progress-color-1: Starting gradient color
  • --progress-color-2: Ending gradient color
  • --progress-shadow: Box shadow for depth

Best Practices

When implementing a scroll progress indicator, keep these tips in mind:

  • Keep it subtle - don't let it distract from the content
  • Use colors that complement your brand
  • Ensure it's accessible (respects reduced motion preferences)
  • Test on mobile devices to ensure it doesn't obstruct content
  • Consider adding a percentage indicator for better clarity

Browser Support

This component works in all modern browsers including Chrome, Firefox, Safari, and Edge. It uses standard CSS and JavaScript APIs that have excellent browser support.

Performance Considerations

The scroll event listener is optimized using requestAnimationFrame to ensure smooth performance without causing layout thrashing. The component uses CSS transforms for animations, which are GPU-accelerated.

Accessibility

This component is designed with accessibility in mind:

  • Respects prefers-reduced-motion media query
  • Back to top button has proper ARIA label
  • Keyboard accessible (Tab to focus, Enter to activate)
  • High contrast colors for visibility

Integration with EaseMotion

This component seamlessly integrates with EaseMotion CSS by using utility classes like ease-hover-scale for the back-to-top button and ease-slide-up for content sections. The scroll progress bar itself uses custom animations that complement the EaseMotion design philosophy.

Conclusion

Scroll progress indicators are a simple yet effective way to enhance user experience on long-form content pages. They provide visual feedback, improve engagement, and add a modern touch to your website's design.
