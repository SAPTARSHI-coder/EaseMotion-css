# Neumorphic Footer with Material Design Styling

A responsive footer component combining neumorphic UI principles with
Material Design-inspired typography, spacing, elevation, and interaction
patterns.

## Features

- Fully responsive layout
- Neumorphic surfaces and soft shadows
- Material Design-inspired visual hierarchy
- Responsive navigation columns
- Social media icon buttons
- Interactive hover and active states
- Keyboard-accessible focus states
- Reduced-motion support
- Mobile, tablet, and desktop layouts
- No JavaScript dependency
- Pure HTML and CSS implementation
