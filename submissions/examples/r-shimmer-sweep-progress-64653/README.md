# Shimmer-Sweep Progress Bar

A lightweight pure HTML and CSS progress bar featuring a smooth shimmer
sweep animation for minimalist technology interfaces.

## Features

- Pure HTML and CSS
- No JavaScript or external frameworks
- Minimalist technology-inspired design
- Animated shimmer sweep effect
- Smooth progress fill animation
- Multiple progress indicators
- Responsive desktop, tablet, and mobile layouts
- Accessible `progressbar` semantics
- `prefers-reduced-motion` support
- Customizable CSS properties
