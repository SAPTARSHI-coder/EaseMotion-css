# glow-popover-menu-v9-ak

Pure CSS animated glowing popover menu component — no JavaScript required.

## How to use

```html
<div class="ease-popover-wrapper-v9">
  <button class="ease-popover-trigger-v9">Options</button>

  <ul class="ease-popover-menu-v9">
    <li class="ease-popover-item-v9"><a href="#">Item 1</a></li>
    <li class="ease-popover-item-v9"><a href="#">Item 2</a></li>
  </ul>
</div>
