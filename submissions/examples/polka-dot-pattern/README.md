
---

## 🚀 Usage
1. Clone or copy the files into your project.
2. Open `demo.html` in your browser.
3. Hover over the polka dot pattern to see the color shift.

---

## 🛠️ Customization
- **Dot size** → Adjust `background-size` in `.polka-dot`.
- **Colors** → Change gradient colors in `.polka-dot` and `.polka-dot:hover`.
- **Pattern area** → Modify width/height of `.polka-dot`.

---

## 📖 Accessibility
- Uses `role="img"` and `aria-label="Animated polka dot pattern"` for screen readers.
- Hover interaction demonstrates animated state.
