What the plugin would generate

Given component authors write only the animated rule:

.em-bounce { animation: em-bounce 1s ease infinite; }

The plugin scans the built CSS for any animation or transition declaration on an em-* class and auto-appends this global safety net once per build:

@media (prefers-reduced-motion: reduce) {
  [class*="em-"] {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}

That block is included directly in style.css below, so this page demonstrates the actual resulting behavior, not just the idea.
