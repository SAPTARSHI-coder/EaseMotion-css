# CSS Bounce-Pulse Toast for SaaS Showcase Layouts

A modern **Bounce-Pulse Toast Notification** component built using pure HTML5 and CSS3 for SaaS showcase layouts. This component provides animated notification messages with bounce entrance effects, pulse glow animations, glassmorphism styling, and responsive behavior.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Smooth bounce entrance animation
* Continuous pulse glow effect
* SaaS notification showcase UI
* Multiple toast states:

  * Success
  * Warning
  * Information
* Animated notification icons
* Glassmorphism card design
* Interactive close button hover effect
* Responsive desktop, tablet, and mobile layouts
* CSS Custom Properties for easy customization
* Smooth transitions and keyframe animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. View animated SaaS notification toasts.
3. Customize colors, shadows, spacing, and animation speed using CSS variables inside `:root`.
