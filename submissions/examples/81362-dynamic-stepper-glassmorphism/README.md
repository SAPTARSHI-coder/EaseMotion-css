# Dynamic Stepper — Glassmorphism

A responsive dynamic stepper with a modern glassmorphism visual
style created for EaseMotion CSS issue #81362.

## Features

- Glassmorphism cards
- Frosted translucent surfaces
- Backdrop blur
- Active step highlighting
- Completed step indicators
- Animated progress bar
- Smooth hover transitions
- Animated entrance states
- Responsive desktop, tablet and mobile layout
- Reduced-motion support
- Pure HTML and CSS
- No JavaScript dependencies
