# Fortune Wheel Spin

A prize wheel spins and decelerates with a bouncing pointer.

## Features
- Decelerating wheel spin
- Bouncing pointer
- Segmented gradient wedges
- Pure CSS

## Usage
```html
<div class="fws-wheel"><div class="fws-wedge" style="--i:0">1</div></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
