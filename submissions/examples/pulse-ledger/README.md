# 🫀 Pulse Ledger

Pulse Ledger is a dependency-free interactive visualization of a fictional synthetic living system.

Instead of behaving like a conventional dashboard, the component combines three layers of information:

1. Current system state
2. Continuous signal behavior
3. Recent event history

The result is a digital monitoring interface that feels less like a static dashboard and more like an observed synthetic organism.

> Every change leaves a trace.

## 🧠 Concept

Traditional dashboards usually answer:

> What is happening right now?

Pulse Ledger asks a slightly different question:

> What is happening now, and what just happened?
