# Parallax Spinner with Retro Styling (#79893)

A retro-styled neumorphic parallax spinner component featuring multi-layered concentric rotational tracks, 3D Z-axis translation keyframes, and soft extruded surface depth shadows.

## Features
- **Multi-Layered Parallax Motion:** Differential rotational speed and counter-rotation across concentric rings combined with 3D Z-axis translation.
- **Neumorphic Retro Aesthetics:** Inset background well housing extruded shadow rings with warm amber and orange retro accents.
- **Fully Responsive:** Fluid flexbox container scaling smoothly across desktop and mobile devices.

## File Hierarchy
- `style.css` - Custom properties, neumorphic shadow tokens, 3D parallax keyframes, and media queries.
- `demo.html` - Semantic markup demonstrating spinner integration with ARIA accessibility tags.
- `README.md` - Technical specification and architecture overview.
