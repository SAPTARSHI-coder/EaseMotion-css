
---

## 🚀 Usage
1. Clone or copy the files into your project.
2. Open `demo.html` in your browser.
3. Hover over the dropdown to see the morphing neon effect.

---

## 🛠️ Customization
- **Colors** → Adjust neon glow colors in `box-shadow` and `text-shadow`.
- **Animation speed** → Modify `transition: all 0.5s ease` for faster/slower morphing.
- **Menu items** → Add/remove `<li>` elements inside `.dropdown-menu`.

---

## 📖 Accessibility
- Uses `role="navigation"` and `aria-label="Cyberpunk morphing dropdown"`.
- Keyboard navigation supported via `<button>` and `<a>` elements.
