# CSS Morph-Glow Accordion

A pure CSS/HTML Morph-Glow Accordion designed for modern fintech dashboard layouts.

## Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Native HTML `<details>` and `<summary>`
- Morph and glow interaction
- Smooth accordion content entrance
- Responsive design
- Keyboard accessible
- Focus-visible support
- `prefers-reduced-motion` support
- CSS custom properties for customization
