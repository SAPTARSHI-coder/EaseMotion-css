# Hover Modal with Cyberpunk Styling

A responsive CSS-only hover modal inspired by futuristic cyberpunk
terminals and neon digital interfaces.

## Features

- Fully responsive
- Pure HTML and CSS
- No JavaScript
- Hover-triggered modal interaction
- CSS-only cyberpunk terminal
- Neon cyan and magenta effects
- Animated scanline
- Glowing status indicators
- Responsive modal data layout
- Hover transitions and micro-interactions
- Reduced-motion accessibility support

## Files

- `demo.html`
- `style.css`

## Interaction

Hover over the terminal interface to reveal the cyberpunk modal.

The modal also responds to keyboard focus through `:focus-within`,
keeping the interaction usable without JavaScript.

## Design

The component uses:

- Dark futuristic surfaces
- Neon cyan accents
- Magenta secondary highlights
- Terminal-inspired borders
- Glowing shadows
- Grid background
- Scanline animation
- Responsive modal layout

## Technologies

- HTML5
- CSS3
