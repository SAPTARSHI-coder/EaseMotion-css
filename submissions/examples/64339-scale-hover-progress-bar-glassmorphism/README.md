# CSS Scale-Hover Progress Bar for Glassmorphism UI Layouts

A modern **pure CSS animated progress bar component** built with a glassmorphism design style.

This example demonstrates smooth scaling hover interactions, animated progress loading, and responsive layouts using only HTML and CSS.

## ✨ Features

- Pure HTML & CSS implementation
- Glassmorphism UI design
- Smooth scale hover animation
- Animated progress loading effect
- Responsive design for desktop, tablet and mobile
- Lightweight and framework-free
- Accessible with `prefers-reduced-motion` support
