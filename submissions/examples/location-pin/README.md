\# CSS Animated Location Pin



A lightweight, pure CSS animated location pin that drops into position with a smooth bounce effect.



\## Features



\- Pure CSS animation

\- No external dependencies

\- Responsive design

\- Accessible button with an ARIA label

\- Keyboard accessible

\- Click to replay the animation

\- Supports `prefers-reduced-motion`

\- Includes a soft landing shadow



\## Files



\- `demo.html` — Demo page and accessible location pin markup

\- `style.css` — Location pin styling and animations



\## Usage



Open `demo.html` in a browser to view the animation.



Click or focus the location pin to interact with it.



\## Accessibility



The location pin uses a semantic button with an accessible label. Keyboard users can focus and activate the pin.



The animation respects the user's `prefers-reduced-motion` system preference.



\## Animation



The pin:



1\. Drops from above the map.

2\. Lands at the target position.

3\. Bounces slightly.

4\. Settles into place.



The shadow scales along with the movement to create a landing effect.
