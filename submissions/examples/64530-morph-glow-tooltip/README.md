# Morph Glow Tooltip

A pure CSS animated tooltip component with morphing and glowing effects.

## Features

- Pure HTML and CSS
- Smooth morph-glow animation
- Minimalist tech UI design
- Responsive layout
- Glassmorphism effect
- Hover-based interaction
- prefers-reduced-motion support
