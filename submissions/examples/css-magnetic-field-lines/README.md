# CSS Magnetic Field Lines

A pure CSS animated magnetic field effect where multiple field lines flow around a central magnetic element.

## Features

- Pure CSS animation
- No JavaScript required
- Responsive layout
- Light and dark mode support
- CSS custom properties for easy customization
- Reduced-motion accessibility support
- Self-contained demo

## Usage

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
<div class="magnetic-field">
  <div class="field-line line-1"></div>
  <div class="field-line line-2"></div>
  <div class="field-line line-3"></div>
  <div class="field-line line-4"></div>
  <div class="field-line line-5"></div>
  <div class="field-line line-6"></div>

  <div class="magnet">
    <span class="magnet-pole north">N</span>
    <span class="magnet-pole south">S</span>
  </div>
</div>
