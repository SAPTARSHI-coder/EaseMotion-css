# Responsive Hero Section with Dark Mode

A responsive hero section created for EaseMotion CSS issue
#78359.

## Features

- Fully responsive layout
- Dark mode visual system
- HTML and CSS only
- No JavaScript
- Semantic HTML structure
- Responsive navigation
- CTA buttons
- Animated glowing background
- CSS-only 3D visual panel
- Floating information cards
- Feature information strip
- Keyboard-visible focus states
- Reduced-motion support
- No external dependencies

## Design

The component uses a modern dark interface with:

- Deep black surfaces
- Muted secondary text
- Lime accent color
- Soft background glow
- Glass-like cards
- Subtle borders
- CSS 3D perspective
- Large editorial typography

The visual hierarchy keeps the primary heading and call-to-action
focused while the 3D visual reinforces the futuristic dark-mode
aesthetic.

## Responsive Behavior

Desktop screens use a two-column layout with the textual content
on the left and the visual composition on the right.

Tablet and mobile layouts collapse into a single column.
Navigation links are hidden on smaller screens while the primary
action remains accessible.

The feature strip also changes from three columns into a vertical
layout on mobile devices.

## Technologies

- HTML5
- CSS3
- CSS Grid
- CSS Flexbox
- CSS gradients
- CSS 3D transforms
- CSS animations
- Media queries

## Accessibility

The navigation and CTA links use meaningful labels and visible
focus styles.

The component respects `prefers-reduced-motion` and minimizes
animations for users who request reduced motion.
