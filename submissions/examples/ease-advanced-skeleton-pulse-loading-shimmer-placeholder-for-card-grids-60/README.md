# Skeleton Pulse Loading Shimmer Placeholder for Card Grids

### Neumorphic Finish

A modern **Skeleton Pulse Loading Shimmer Placeholder** built with **HTML5** and **CSS3**. The component features neumorphic cards with animated shimmer loading placeholders, pulse effects, and a responsive grid layout.

---

## ✨ Features

- Neumorphic card design
- Animated shimmer loading effect
- Pulse animation
- Responsive card grid
- Smooth hover interactions
- CSS Variables for customization
- `prefers-reduced-motion` support
- Pure HTML & CSS implementation

## 🚀 Usage

1. Open the component folder.
2. Keep `demo.html` and `style.css` together.
3. Open `demo.html` in a modern browser.
4. The shimmer and pulse animations start automatically.

No external libraries or build tools are required.
