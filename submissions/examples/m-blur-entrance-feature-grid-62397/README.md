# CSS Blur-Entrance Feature Grid for Product Catalog Layouts

A modern **Blur-Entrance Feature Grid** built using pure HTML and CSS. The component introduces feature cards with a smooth blur-to-clear entrance animation, responsive layout, CSS custom properties, and lightweight styling for product catalog interfaces.

## ✨ Features

- Pure HTML5 & CSS3
- Blur-Entrance animation
- Staggered card reveal
- Responsive feature grid
- Glassmorphism design
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
