# CSS Snowman

A cheerful snowman illustration created entirely with HTML and CSS.

## Features

- Pure CSS snowman illustration
- Carrot nose and classic hat
- Scarf and wooden arms
- Animated snowfall background
- Subtle floating animation
- Responsive design
- Accessible semantic labeling
- Reduced-motion support
- No JavaScript required

## Files

- `demo.html` - Snowman markup and scene structure
- `style.css` - Complete snowman styling and animations

## Usage

Open `demo.html` in a modern browser to view the animation.

## Accessibility

The illustration includes an accessible label describing the snowman. Decorative visual elements are created with CSS and do not require keyboard interaction.

The `prefers-reduced-motion` media query disables decorative animations for users who prefer reduced motion.

## Browser Support

Works in modern browsers supporting:

- CSS gradients
- CSS animations
- CSS `clip-path`
- CSS media queries
