# Neumorphic Notification Alert Badge

A lightweight, fully responsive notification badge built with pure CSS, soft neumorphic shadows, and EaseMotion design tokens.

## Features
- **Zero JavaScript Dependencies:** Pure CSS state handling via pseudo-classes and keyframes.
- **EaseMotion Integrated:** Utilizes specialized timing tokens and spring curves for natural feedback.
- **Accessible:** Includes built-in support for `prefers-reduced-motion` media queries and high-contrast shadow definitions.
- **Responsive:** Scales seamlessly across mobile, tablet, and desktop viewports.

## Quick Start
1. Include `style.css` in your project head.
2. Structure your HTML elements using the `.neu-container` and `.neu-badge` classes as shown in `demo.html`.
