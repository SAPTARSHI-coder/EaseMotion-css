# CSS Shimmer-Sweep Tooltip for SaaS Showcase Layouts

A modern SaaS tooltip component featuring a smooth shimmer-sweep light animation effect built completely with pure HTML and CSS.

This component is designed for SaaS dashboards, product showcases, and landing pages where elegant animated interactions are required without JavaScript.


## ✨ Features

- ✨ Smooth shimmer-sweep animation
- 💬 Modern SaaS tooltip interface
- 🎨 Glassmorphism inspired design
- ⚡ Pure HTML and CSS implementation
- 🌈 Gradient lighting effects
- 📱 Fully responsive layout
- 🔄 CSS transition and keyframe animations
- ♿ prefers-reduced-motion accessibility support
- 🚀 Lightweight and framework-free

## 🚀 Usage

1. Open `demo.html` directly in your browser.

2. Hover over the feature card to display the animated tooltip.

3. Customize CSS variables inside `style.css` according to your brand.


## 🎨 CSS Custom Properties

The component uses CSS variables for easy customization:

```css
:root {

    --bg:#020617;
    --primary:#38bdf8;
    --secondary:#8b5cf6;
    --card:#0f172a;
    --text:#f8fafc;
    --muted:#94a3b8;

}

Modify these values to create your own theme.
