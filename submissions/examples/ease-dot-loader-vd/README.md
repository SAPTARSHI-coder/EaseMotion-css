# Ease Dot Loader

## What does this do?

A lightweight three-dot loading indicator built entirely with CSS animations.

---

## How is it used?

Open `demo.html` in any modern browser.

Example:

```html
<div class="dot-loader">
    <span></span>
    <span></span>
    <span></span>
</div>
```

### Features

- Three animated dots
- Pure CSS animation
- Infinite looping
- Lightweight and reusable
- Responsive layout

---

## Why is it useful?

Loading indicators are used throughout web applications, dashboards, forms, and content placeholders. This component provides a simple animation-first loading indicator that is lightweight, reusable, and aligns with the EaseMotion CSS philosophy.
