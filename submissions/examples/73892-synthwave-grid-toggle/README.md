# Synthwave Grid Line Toggle (#73892)

A pure HTML & Vanilla CSS toggle featuring a Synthwave Grid aesthetic with hardware-accelerated transitions and reduced-motion support.

## Feature Overview
- **Aesthetic:** Synthwave/Retrowave neon grid line design with cyan and magenta accents.
- **Pure CSS:** Zero JavaScript dependencies; relies on standard `<input type="checkbox">` pseudo-class states.
- **Performance:** Hardware-accelerated animations using `transform`, `box-shadow`, and `opacity` with `will-change` optimizations.
- **Accessibility:** Keyboard navigation supported via `:focus-visible` outlines and full `@media (prefers-reduced-motion: reduce)` support.
