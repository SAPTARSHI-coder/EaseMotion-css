ease-view-morph-card

Natively morphs a small UI card into a full-screen layout using the browser's View Transitions API. Zero JS animation libraries. The browser engine handles all layout interpolation automatically.

✦
View Transition

Indigo Nebula

A living, breathing UI component that transitions seamlessly between its compact card state and a full-screen detail view — all driven by a single browser API, no JS animation loops required.

How it works: When you click the card, document.startViewTransition() captures a screenshot of the current DOM, applies the CSS class to expand the card, then smoothly interpolates between the two states using the browser's compositor — not JavaScript.
The secret: The card declares view-transition-name: ease-morph-card-1 in CSS. The browser automatically matches the old and new snapshots of this named element and animates position, size, and border-radius in a single shared element transition.
Performance: The morph runs entirely on the GPU compositor thread. There is no JS requestAnimationFrame loop, no FLIP coordinate math, and no external library. If the user has prefers-reduced-motion: reduce set, all transitions are disabled gracefully.

Click the card to expand · Escape to collapse

CSS hook

Set view-transition-name on any element. The browser auto-tracks it across DOM mutations triggered inside startViewTransition().

JS trigger

Only two lines of JS needed: call document.startViewTransition() and toggle the .expanded class inside the callback. All animation math lives in CSS.

Browser support

Chrome 111+, Edge 111+, Safari 18+, Opera 97+. Falls back gracefully — the card still expands/collapses without animation on unsupported browsers.
