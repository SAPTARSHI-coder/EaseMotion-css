# CSS Elastic-Slide Pricing Table for Product Catalog Layouts

A responsive **Elastic-Slide Pricing Table** built with pure HTML and CSS. Pricing cards animate into view using an elastic slide effect and include smooth hover interactions for modern product catalog pages.

## ✨ Features

- Pure HTML5 & CSS3
- Elastic-Slide entrance animation
- Featured pricing plan
- Glassmorphism card design
- Responsive layout
- CSS Custom Properties
- Smooth hover effects
- `prefers-reduced-motion` support
- No JavaScript required
