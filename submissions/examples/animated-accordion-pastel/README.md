# Animated Accordion - Pastel Styling

A responsive animated accordion component created using semantic
HTML and pure CSS.

The component uses a soft pastel visual language with smooth
open/close transitions and does not require JavaScript.

## ✨ Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Fully responsive
- Soft pastel color palette
- Smooth accordion animation
- Native `<details>` and `<summary>` interaction
- Animated plus/minus indicators
- Individual pastel accents
- Hover effects
- Keyboard-friendly native controls
- Visible focus state
- Reduced-motion support
- Mobile-friendly layout
