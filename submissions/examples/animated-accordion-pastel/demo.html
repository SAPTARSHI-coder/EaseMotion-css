Everything explained.

A soft pastel accordion component with smooth CSS-only animations and a responsive layout.

What is this component?

This is a lightweight accordion built with semantic HTML and CSS. It can be used for FAQs, documentation, product information, onboarding content and more.

Does it require JavaScript?

No. The interactive open and close behavior uses the native HTML details and summary elements, while CSS handles the visual transitions and styling.

Is the accordion responsive?

Yes. The layout automatically adapts to desktop, tablet and mobile screen sizes. Typography, spacing and the content width are adjusted for smaller displays.

Can I customize the colors?

Absolutely. The component uses CSS custom properties, making it easy to replace the pastel palette with colors that match your project or design system.

Does it support reduced motion?

Yes. The component respects the user's prefers-reduced-motion setting and reduces decorative animations when requested.
