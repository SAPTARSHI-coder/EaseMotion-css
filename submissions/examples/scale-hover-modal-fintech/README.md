# CSS Scale-Hover Modal for Fintech Dashboard

A modern, responsive fintech dashboard showcase featuring a pure CSS
Scale-Hover Modal.

The component uses HTML and CSS only and does not require JavaScript or
external UI frameworks.

## Features

- CSS-only modal interaction
- Scale-in modal animation
- Scale-hover interaction
- Smooth CSS transitions
- Responsive dashboard layout
- Responsive modal
- Fintech-inspired UI
- CSS custom properties
- Keyboard-friendly form controls
- Accessible modal semantics
- `prefers-reduced-motion` support
- No JavaScript dependencies
- No external frameworks
