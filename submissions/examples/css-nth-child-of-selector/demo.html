:nth-child(An+B of S)

The of S syntax lets :nth-child() select among a pre-filtered subset instead of all siblings. Style "every 3rd visible card" or "every other hidden row" — impossible before, trivial now.

Demo 2: Task List with Pinned Items

Every 2nd pinned item gets a different accent color. The unpinned items are completely ignored in the :nth-child() count.

Show CSS 
/* Base pinned items */
.task-item.pinned {
  border-left: 4px solid var(--color-primary);
}

/* Every 2nd pinned item gets a different accent */
.task-item.pinned:nth-child(even of .pinned) {
  border-left-color: var(--color-success);
}

Demo 4: Gallery — Ignore Hidden Items

Some items are .hidden. But :nth-child(An+B of .visible) ignores them, keeping the visible grid layout consistent.

Show CSS 
/* Hidden items collapse via display:none (or visually collapse) */
.gallery-item.hidden { display: none; }

/* Style the 2nd, 4th, etc visible items */
.gallery-item.visible:nth-child(even of .visible) {
  --item-bg: light-dark(#e8e6ff, #1e1a40);
}
