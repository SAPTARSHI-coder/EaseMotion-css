# Animated Retro Slider

A responsive CSS-only slider component with a retro arcade-inspired design.

## Features

- Pure HTML and CSS
- No JavaScript
- Animated progress track
- Interactive range input
- Retro arcade styling
- Responsive layout
- Keyboard accessible
- Reduced-motion support
