# CSS Reveal-on-Scroll Card

A responsive card component that reveals itself as it enters the viewport using modern CSS scroll-driven animations.

## Features

- Pure CSS implementation
- No JavaScript required
- Uses `animation-timeline: view()` for scroll-driven animation
- Smooth fade, translate, and scale reveal effect
- Responsive layout
- Light and dark mode support
- CSS custom properties for easy customization
- Reduced-motion support
- Browser fallback for unsupported scroll-driven animation features
