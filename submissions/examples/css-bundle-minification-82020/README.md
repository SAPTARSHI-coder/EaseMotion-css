# CSS Bundle Minification Validator

A modern CSS validation dashboard created with pure HTML and CSS.

## Features

- Clean CSS bundle validation interface
- Minification status display
- Original and minified bundle statistics
- CSS code preview
- Validation check cards
- Responsive layout
- No JavaScript or external libraries

## Preview

The demo displays:

- Bundle validation status
- CSS size reduction
- Minified CSS preview
- Syntax validation
- Empty bundle edge-case status
- Invalid input handling
