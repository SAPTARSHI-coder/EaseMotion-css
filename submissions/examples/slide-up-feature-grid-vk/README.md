# Slide-Up Feature Grid

A responsive feature grid built with **pure HTML and CSS**. Each feature card smoothly slides upward on hover or keyboard focus, creating an elegant and accessible user experience without JavaScript.

---

## ✨ Features

- Pure HTML5 & CSS3
- Smooth slide-up hover animation
- Responsive CSS Grid layout
- Keyboard accessible with `:focus-visible`
- CSS Custom Properties
- Lightweight and dependency-free
- Supports `prefers-reduced-motion`
- Easy to customize

---

## 📂 Folder Structure

```text
slide-up-feature-grid-vk/
├── demo.html
├── style.css

```

---

## 🚀 Usage

1. Open `demo.html` in a browser.
2. Hover over any feature card to view the slide-up animation.
3. Navigate using the **Tab** key to view keyboard focus styles.
