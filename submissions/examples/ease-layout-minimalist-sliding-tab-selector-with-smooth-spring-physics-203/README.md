# Minimalist Sliding Tab Selector with Smooth Spring Physics (Glassmorphic Style)

A modern glassmorphic sliding tab selector with smooth spring-like transitions built using HTML, CSS, and Vanilla JavaScript.

## Features

- Glassmorphism UI
- Smooth sliding indicator
- Spring-like animations
- Responsive layout
- Accessible keyboard focus
- Pure HTML, CSS and JavaScript

## Folder Structure


## Usage

Open `demo.html` in your browser and customize colors through CSS variables.
