# Text Stroke Pulse

Outlined lettering pulses their stroke color with a soft glow.

## Features
- Outline-only lettering
- Stroke color pulse
- Glow breathing
- Pure CSS

## Usage
```html
<h2 class="tsp-text">OUTLINE</h2>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
