# Accordion Expandable FAQ Grid

A responsive FAQ accordion component with smooth height transitions and a modern mobile-first design.

## Features

- Smooth accordion expand/collapse animation
- Responsive two-column FAQ grid
- Mobile-first layout
- Modern glass-style UI
- Hover interactions
- Accessible buttons with `aria-expanded`
- Vanilla JavaScript
- No external libraries or dependencies
- Supports reduced-motion preferences
