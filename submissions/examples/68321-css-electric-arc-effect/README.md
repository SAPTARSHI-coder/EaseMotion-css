# CSS Electric Arc Effect

## Overview

A CSS-only electric arc connecting two animated energy nodes.

## Features

- Layered lightning path
- Electric glow and flicker
- Moving energy pulses
- Animated endpoint nodes
- Responsive stage
- Reduced-motion support
- No JavaScript dependency

## Files

- `demo.html` — semantic arc scene and supporting content
- `style.css` — arc geometry, glow, pulse animation, and responsive rules

## Usage

Open `demo.html` in a modern browser.
