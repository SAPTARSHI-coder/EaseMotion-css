# Animated Avatar Group Submission

## 1. What does this do?
It provides a modern, animated avatar group component with stacked layout, hover effects, status indicators, and tooltips. Perfect for team sections, user lists, collaboration features, and social platforms.

## 2. How is it used?
Wrap avatars in `.avatar-group` with `.avatar-wrapper` for each person. Add `.status-indicator` with `.online`, `.away`, or `.offline` classes. Include `.avatar-tooltip` for hover information. Use `.avatar-more` and `.avatar-count` for "show more" functionality.

## 3. Why is it useful?
- Essential component for team sections and user lists
- Stacked layout with smooth hover expansion
- Status indicators (online, away, offline)
- Tooltips showing name and role on hover
- "More" count for large groups
- Smooth scale and lift animations
- Two size variants (regular and small)
- Fully responsive design
- Accessible with `prefers-reduced-motion` support
- Easy to customize colors and sizes
- Maintainer can easily standardize this as `.ease-avatar-group-[YOUR_INITIALS]` in the core library.
