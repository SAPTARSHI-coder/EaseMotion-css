# Solar Flare Radial Neumorphic Effect

A pure CSS neumorphic UI component inspired by the intense radial glow
and energy of a solar flare.

The component combines a dark neumorphic surface with warm radial
gradients, glowing orbital rings, smooth transitions, and an animated
energy indicator.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript or external dependencies
- Solar-flare inspired radial glow
- Neumorphic shadows and surfaces
- Smooth hover and focus interactions
- Animated radial energy effect
- Responsive layout
- Dark-mode compatible styling
- Hardware-friendly CSS transforms
- Keyboard-accessible controls
- `prefers-reduced-motion` support

## Files

- `demo.html` — Self-contained demonstration
- `style.css` — Complete component styling
