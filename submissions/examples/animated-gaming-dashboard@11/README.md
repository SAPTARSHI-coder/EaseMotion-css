# Animated Gaming Dashboard

A neon-styled **Gaming Dashboard** built with **EaseMotion CSS**. Features player stats with XP progress, game library with completion bars, achievements, leaderboard, friends online, and store previews.

## ✨ Features

- **👤 Player Profile**: Avatar with rotating ring, badges, XP progress bar
- **🕹️ Game Library**: Continue playing cards with progress indicators
- **🏆 Achievements**: Unlocked and locked achievement badges
- **🥇 Leaderboard**: Global rankings with position indicators
- **👥 Friends Online**: Real-time status with join/invite actions
- **🛒 Store Preview**: Featured games with discount badges
- **🎨 Neon Aesthetic**: Cyan/purple gaming theme with glow effects
- **🎬 Staggered Entrance**: All sections slide up sequentially
- **📱 Fully Responsive**: Multi-column to single column adaptation

## 🧩 EaseMotion Classes Used

| Class | Purpose |
|-------|---------|
| `ease-fade-in` | Fades in the main page and footer |
| `ease-slide-up` | Slides sections up on entrance |
| `ease-delay-100` to `ease-delay-800` | Creates cascading staggered sequence |
| `ease-card` | Base card structure |
| `ease-hover-lift` | Lift effect on all cards |
| `ease-hover-grow` | Scale effect on buttons |
| `ease-center` | Centers play buttons |
| `ease-grid` + `ease-grid-cols-*` | Responsive grid layouts |
| `ease-gap-4` | Spacing between grid items |
| `ease-pulse` | **Looping pulse** on notification dot and online count |

## 🚀 How to Use

1. Open `demo.html` in any modern browser
2. Watch all sections slide in with staggered animations
3. Observe the **rotating avatar ring** animation
4. See the **XP bar filling** on load
5. Hover over game cards to see play overlay and glow effect
6. Notice the **pulsing notification** and online count
7. Resize to mobile to see the responsive layout
