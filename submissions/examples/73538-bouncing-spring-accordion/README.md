# Bouncing Spring Accordion

A playful CSS-only accordion featuring a spring-inspired bouncing
interaction.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript required
- Native `<details>` and `<summary>` controls
- Spring-like opening animation
- Animated plus/minus indicator
- Smooth content expansion
- Dark mode compatible
- Responsive layout
- Keyboard accessible
- Reduced-motion support
- Hardware-friendly CSS transforms
