# CSS Pulse-Glow Status Badge

A reusable pure CSS status badge with a soft pulsing indicator and glow effect.

## Features

- Pure HTML and CSS
- Animated status indicator
- Multiple status color variants
- Soft neon glow
- Responsive layout
- No JavaScript required
- Lightweight CSS animation
- `prefers-reduced-motion` support
- Customizable CSS properties

## Usage

```html
<span class="status-badge status-badge--online">
  <span class="status-badge__dot" aria-hidden="true"></span>
  <span>Online</span>
</span>
