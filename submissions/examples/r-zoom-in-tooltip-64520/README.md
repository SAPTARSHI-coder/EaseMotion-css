# CSS Zoom-In Tooltip

A minimalist tooltip component featuring a smooth zoom-in reveal animation.

## Features

- Pure HTML and CSS
- No JavaScript dependencies
- Smooth zoom-in animation
- Hover and keyboard focus support
- Multiple color variants
- Responsive layout
- `prefers-reduced-motion` support
- Customizable CSS properties
