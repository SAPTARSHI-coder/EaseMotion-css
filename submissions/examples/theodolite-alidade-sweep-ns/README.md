# Theodolite Alidade Sweep

## What does this do?
Renders a self-contained CSS-only `ease-theodolite-alidade-sweep` demo: Surveying theodolite with sweeping alidade across graduated circle.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-theodolite-alidade-sweep`. No build step or JavaScript is required for the effect.

```html
<section class="ease-theodolite-alidade-sweep">
  <div class="ease-theodolite-alidade-sweep__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
