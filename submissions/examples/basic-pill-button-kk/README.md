# Basic Pill Button

## What it does

This submission creates a simple CSS-only pill button utility for compact actions, filters, and lightweight call-to-action elements.

## How to use it

Apply the button class directly in HTML:

```html
<button class="basic-pill-button">Explore</button>
```

## Why it fits EaseMotion CSS

It fits EaseMotion CSS because it is human-readable, composable, and useful across many interfaces. It works well in cards, dashboards, action groups, filter rows, and compact navigation patterns.

## Included features

- Rounded pill button utility
- Soft, warm, and outline variations in the demo
- Compact action-group example
- Responsive demo layout
- Pure HTML and CSS implementation

## Files

- `demo.html` - self-contained demo that opens directly in a browser
- `style.css` - raw CSS for the pill button utility
- `README.md` - usage and contribution context
