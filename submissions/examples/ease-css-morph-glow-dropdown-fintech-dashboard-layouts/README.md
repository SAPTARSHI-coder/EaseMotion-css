# CSS Morph-Glow Dropdown for Fintech Dashboard Layouts

A modern CSS-only dropdown component designed for fintech dashboard interfaces.

This component features a glowing morph animation, glassmorphism styling, and smooth transitions while maintaining accessibility and responsive behavior.

## ✨ Features

- Morphing glow dropdown animation
- Modern fintech dashboard UI design
- Pure HTML and CSS implementation
- Neon gradient effects
- Smooth hover interactions
- Responsive layout support
- Glassmorphism card styling
- Accessibility support with `prefers-reduced-motion`

## 🚀 Usage

1. Clone the repository.

2. Navigate to the component folder:


submissions/examples/ease-css-morph-glow-dropdown-fintech-dashboard-layouts/


3. Open `demo.html` in your browser.

No additional dependencies or frameworks are required.

## 🎨 CSS Custom Properties

The component uses CSS variables for easy customization:

```css
:root {
    --bg: #050816;
    --primary: #00f5ff;
    --secondary: #8b5cf6;
    --accent: #22c55e;
    --text: #f8fafc;
}

You can modify these values to customize colors and branding.
