# Pelorus Bearing Ring

## What does this do?
Renders a self-contained CSS-only `ease-pelorus-bearing-ring` demo: Pelorus bearing ring rotating to a relative bearing.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-pelorus-bearing-ring`. No build step or JavaScript is required for the effect.

```html
<section class="ease-pelorus-bearing-ring">
  <div class="ease-pelorus-bearing-ring__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
