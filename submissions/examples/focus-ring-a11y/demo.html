Accessible Focus Rings

Keyboard users MUST be able to see which element currently has focus. The most common accessibility failure is developers writing outline: none because they don't like how the default blue ring looks when they click a button.

Press the Tab key to navigate through the interactive elements below. Notice how the focus ring is highly visible even against complex gradient backgrounds.
