# CSS Shimmer-Sweep Progress Bar for SaaS Showcase Layouts

A modern, responsive **Shimmer-Sweep Progress Bar** component built using pure HTML and CSS for the EaseMotion CSS collection. The progress bars feature smooth fill animations with a continuous shimmer sweep effect, making them ideal for SaaS dashboards, analytics panels, admin interfaces, and KPI showcases.

## Features

- Pure HTML5 & CSS3
- Smooth shimmer sweep animation
- Animated progress fill
- Responsive grid layout
- Modern SaaS dashboard styling
- CSS Custom Properties for easy customization
- Accessible with `prefers-reduced-motion`
- No JavaScript required

## Usage

1. Open `demo.html`.
2. Include `style.css`.
3. Update the progress value using:

```css
style="--progress:75%;"
```

## CSS Custom Properties

| Variable | Description |
|----------|-------------|
| --progress | Progress width |
| --blue | Blue theme |
| --purple | Purple theme |
| --green | Green theme |
| --orange | Orange theme |
| --pink | Pink theme |
| --cyan | Cyan theme |
| --radius | Border radius |
| --speed | Animation speed |
