# Ease Counter Chip

## What does this do?

A compact rounded chip for displaying numeric values, counts, and analytics data.

---

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<span class="counter-chip blue">24</span>
```

### Available color variants

```html
<span class="counter-chip blue">24</span>
<span class="counter-chip green">128</span>
<span class="counter-chip purple">1.2K</span>
<span class="counter-chip orange">99+</span>
```

### Features

- Numeric value
- Rounded pill design
- Multiple color variants
- Hover animation
- Responsive layout
- Lightweight CSS

---

## Why is it useful?

Counter chips are commonly used in analytics dashboards, notification areas, statistics, filters, and other interfaces where a compact numeric value needs to be displayed.

This component provides a simple and reusable counter pattern with subtle interaction feedback while following the animation-first philosophy of EaseMotion CSS.
