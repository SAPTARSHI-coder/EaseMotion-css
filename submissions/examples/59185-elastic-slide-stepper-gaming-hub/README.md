# CSS Elastic-Slide Stepper for Gaming Hub Layouts

A modern **Elastic-Slide Stepper** component built using pure HTML5 and CSS3 for gaming hub layouts. This component creates an engaging game progression interface with elastic animations, level tracking, glowing indicators, and responsive behavior.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Gaming progression stepper UI
* Elastic sliding progress indicator
* Animated active level state
* Neon gaming inspired theme
* Glowing achievement card
* Smooth CSS keyframe animations
* Hover interactions
* Responsive desktop, tablet, and mobile layouts
* CSS Custom Properties for easy customization
* Supports `prefers-reduced-motion`

## Folder Structure

## Usage

1. Open `demo.html` in any modern browser.
2. View the animated gaming level progression stepper.
3. Customize colors, shadows, spacing, and animation speed using CSS variables inside `:root`.

## CSS Custom Properties

```css
:root{
  --bg:#050816;
  --surface:rgba(255,255,255,.08);
  --primary:#8b5cf6;
  --secondary:#06b6d4;
  --accent:#ec4899;
  --text:#f8fafc;
  --muted:#94a3b8;
  --shadow:0 30px 80px rgba(139,92,246,.35);
  --radius:30px;
}
```
