# Neumorphic Navbar with Material Design Styling

A responsive navigation bar combining soft neumorphic depth with clean Material Design-inspired structure, built entirely with HTML and CSS.

## Features

- Pure HTML & CSS
- Neumorphic shadow effects
- Material Design-inspired layout
- Responsive navigation structure
- Smooth hover interactions
- Lightweight and reusable
- No JavaScript required

## Files

- demo.html
- style.css

## Usage

```html
<nav class="neo-navbar">
  <div class="logo">EaseMotion</div>

  <ul class="nav-links">
    <li><a href="#">Home</a></li>
    <li><a href="#">Components</a></li>
    <li><a href="#">Docs</a></li>
  </ul>

  <button class="nav-btn">Get Started</button>
</nav>
```

## Why it fits EaseMotion CSS

This component aligns with EaseMotion CSS by providing a visually polished, motion-friendly, responsive navigation pattern that emphasizes clean interactions, accessibility, and reusable design.
