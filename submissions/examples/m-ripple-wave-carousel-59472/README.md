# CSS Ripple-Wave Carousel for SaaS Showcase Layouts

A modern **Ripple-Wave Carousel** built using pure HTML and CSS. The carousel cards feature a ripple-wave hover animation with elegant glassmorphism styling, responsive layouts, and smooth interactions suitable for SaaS landing pages and product showcases.

## ✨ Features

- Pure HTML5 & CSS3
- Ripple-wave hover animation
- Glassmorphism carousel cards
- Responsive layout
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
