# Custom Morphing Cursor Pointer Trail Effect for Portfolios (Dark Mode Variant)

A modern **Dark Mode Morphing Cursor Pointer Trail** concept built using pure HTML and CSS. It showcases animated cursor-inspired visuals, glowing pointer effects, floating orbs, and glassmorphism styling for portfolio landing pages.

## ✨ Features

- Pure HTML5 & CSS3
- Animated morphing cursor concept
- Floating glowing orbs
- Rotating cursor trail ring
- Dark mode glassmorphism UI
- Responsive layout
- CSS Custom Properties
- `prefers-reduced-motion` support
- No JavaScript required
