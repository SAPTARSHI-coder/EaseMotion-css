# CSS Blur-Entrance Toast for Minimalist Tech Layouts

## Overview

A modern **Blur-Entrance Toast UI component** created using pure HTML and CSS.

This component provides a clean notification style with smooth blur and scale entrance animation, suitable for minimalist tech interfaces.

---

## Features

- ✨ Smooth blur entrance animation
- 🎨 Minimalist dark tech design
- ⚡ Pure HTML and CSS
- 📱 Fully responsive layout
- 🚀 Lightweight and performance friendly
- ♿ `prefers-reduced-motion` accessibility support
- 🔧 Easy customization using CSS variables
