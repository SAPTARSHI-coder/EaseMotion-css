# Marver Roll Gather

## What does this do?
Renders a self-contained CSS-only `ease-marver-roll-gather` demo: Marver roll shaping a gather against the steel plate.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-marver-roll-gather`. No build step or JavaScript is required for the effect.

```html
<section class="ease-marver-roll-gather">
  <div class="ease-marver-roll-gather__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
