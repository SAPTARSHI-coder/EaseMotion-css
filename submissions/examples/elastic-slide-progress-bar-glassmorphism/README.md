# Elastic-Slide Progress Bar for Glassmorphism UI Layouts

A modern pure CSS animated progress bar component built for the EaseMotion CSS collection.

## ✨ Features

- Pure HTML + CSS implementation
- Elastic slide animation effect
- Glassmorphism UI design
- Smooth gradient progress indicator
- Responsive layout support
- Lightweight and framework-free
- Accessible with prefers-reduced-motion support

## 📂 Usage

Copy the following files:


elastic-slide-progress-bar/
│
├── demo.html
├── style.css
└── README.md


Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
🎨 CSS Custom Properties

The component uses CSS variables:

:root {
    --bg: #08111f;
    --glass: rgba(255,255,255,0.12);
    --primary: #6ee7ff;
    --secondary: #8b5cf6;
}

You can customize colors according to your project theme.
