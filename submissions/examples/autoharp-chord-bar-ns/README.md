# Autoharp Chord Bar

## What does this do?
Renders a self-contained CSS-only `ease-autoharp-chord-bar` demo: Autoharp chord bar damping the unselected strings.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-autoharp-chord-bar`. No build step or JavaScript is required for the effect.

```html
<section class="ease-autoharp-chord-bar">
  <div class="ease-autoharp-chord-bar__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
