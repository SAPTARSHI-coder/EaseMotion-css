# Product Catalog Glitch-Flicker Toast

A lightweight, pure HTML/CSS glitch-flicker toast designed for modern
product catalog and e-commerce interfaces.

## Features

- Pure HTML and CSS
- No JavaScript or external frameworks
- Glitch-flicker notification animation
- CRT-style scanline effect
- Animated scan effect
- CSS-only toast dismissal
- Product catalog showcase layout
- Responsive across desktop, tablet, and mobile
- Keyboard-friendly controls
- `:focus-visible` support
- `prefers-reduced-motion` support
- Customizable CSS custom properties
