# Reduced Motion Demo

1. What does this do? It shows a small animation set (orbit, dash, pulse) and a graceful non-animated layout when `prefers-reduced-motion: reduce` is enabled.

2. How is it used? Add `demo.html` and `style.css` side-by-side, then open `demo.html` in any browser that supports `prefers-reduced-motion` media query.

3. Why is it useful? It gives contributors a practical pattern for motion-sensitive users, keeping the same UI meaning while removing movement that can trigger discomfort.
