# Ease File Chip

## What does this do?

A compact file display chip showing a file icon, filename, and extension badge with a subtle hover animation.

---

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<div class="file-chip">
    <div class="file-icon">📄</div>

    <div class="file-info">
        <span class="filename">project-report</span>
        <span class="extension">PDF</span>
    </div>
</div>
```

### Features

- File icon
- Filename display
- Extension badge
- Hover lift animation
- Icon scale animation
- Responsive layout

---

## Why is it useful?

File chips are commonly used in upload interfaces, document managers, dashboards, and attachment sections.

This component provides a lightweight and reusable way to display file information while adding subtle interaction feedback in line with the animation-first philosophy of EaseMotion CSS.
