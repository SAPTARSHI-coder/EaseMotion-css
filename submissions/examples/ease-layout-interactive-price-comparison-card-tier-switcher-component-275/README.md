# Interactive Price Comparison Card Tier Switcher Component (Glassmorphic Style)

1. **What does this do?** 
   A visually stunning, glassmorphic pricing card layout. It features ambient animated background blobs, frosted glass cards using `backdrop-filter`, and a sleek glass pill toggle switcher that transitions prices with a cool scale-and-blur animation.

2. **How is it used?** 
   Copy the `demo.html` structure and attach the `style.css`. The component handles the complex backdrop blurs and glowing hover states entirely via CSS variables and structure. A lightweight JavaScript snippet is included in the demo to handle the class switching and number transition effect. No dependencies required.

3. **Why is it useful?** 
   Glassmorphism is a highly popular design trend but often lacks interactive feedback. This component bridges that gap by adding responsive hover glows, premium border highlights, and fluid transitions—demonstrating how EaseMotion CSS can be extended into complex, state-of-the-art UI layouts while remaining lightweight.
