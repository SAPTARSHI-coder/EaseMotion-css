# Sticky Blur Glass Navigation Header with Scroll Shrink Effect

## Overview

A modern compact mobile-first navigation header component featuring
glassmorphism styling, backdrop blur effects, and smooth scroll-based
shrink animation.

Designed for modern landing pages, dashboards, and portfolio websites.

## Features

- ✨ Sticky floating navigation header
- 🌫️ Glassmorphism blur effect
- 📉 Scroll shrink animation
- 📱 Mobile-first responsive design
- 🎨 Gradient branding effects
- 🖱️ Smooth hover interactions
- ♿ Reduced motion accessibility support
- ⚡ Pure HTML, CSS and JavaScript

## Usage

1. Open `demo.html` in any modern browser.
2. Add your own navigation links.
3. Customize colors and blur values from CSS variables.

## Customization

You can modify:

- Navbar glass effect
- Scroll shrink distance
- Gradient colors
- Responsive breakpoints
