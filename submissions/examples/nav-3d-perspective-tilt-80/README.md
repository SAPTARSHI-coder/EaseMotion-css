# 3D Perspective Tilt Navigation

A premium, purely CSS-based navigation menu featuring a 3D perspective tilt effect. It includes hardware-accelerated 3D transforms, smooth interactive hover states, glassmorphism aesthetics, and automatic dark mode compatibility.

## Usage

```html
<div class="nav-container">
    <nav class="nav-3d">
        <a href="#" class="nav-item">Home</a>
        <a href="#" class="nav-item">Features</a>
        <a href="#" class="nav-item">Pricing</a>
        <a href="#" class="nav-item">About</a>
        <a href="#" class="nav-item">Contact</a>
    </nav>
</div>
```

## Why is it useful?

This navigation style provides a highly engaging, interactive, and premium 3D feel to a website without relying on any JavaScript. It utilizes CSS `perspective` and `transform-style: preserve-3d` to create depth, perfectly aligning with EaseMotion CSS's philosophy of delivering high-performance, pure CSS components.
