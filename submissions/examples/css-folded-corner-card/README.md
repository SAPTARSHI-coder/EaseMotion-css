# CSS Folded Corner Card

A reusable CSS-only card component featuring a decorative folded corner effect created using CSS pseudo-elements, transforms, and clipping.

## Features

- Pure CSS implementation
- No JavaScript or external dependencies
- Responsive design
- Customizable with CSS custom properties
- Supports light and dark color schemes
- Includes hover and focus interactions
- Respects `prefers-reduced-motion`

## Usage

```html
<article class="folded-card">
  <div class="folded-card__content">
    <span class="folded-card__label">Featured</span>

    <h2>Creative Design</h2>

    <p>
      A decorative folded corner created entirely with CSS.
    </p>

    <a href="#" class="folded-card__link">
      Learn More
    </a>
  </div>
</article>
