# Magnetic Floating Action Navigation Bar with Fluid Hover Indicators

## Overview

A minimalist floating navigation bar component featuring a magnetic hover
effect, smooth moving indicator, and clean modern UI design.

Built using pure HTML, CSS, and JavaScript.

## Features

- 🧲 Magnetic hover interaction
- 🌊 Fluid moving indicator animation
- ✨ Smooth transitions
- 🎨 Minimal clean design
- 📱 Responsive mobile layout
- ⚡ Lightweight implementation
- 🖥️ Pure HTML, CSS & JavaScript

## Usage

1. Open `demo.html` in a browser.
2. Hover over navigation items.
3. Indicator smoothly moves between options.
4. Click any item to activate it.
