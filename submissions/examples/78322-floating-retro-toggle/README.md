# Floating Toggle with Retro Styling

A responsive floating toggle component inspired by classic
retro and arcade interfaces.

The component is implemented entirely with HTML and CSS and
does not require JavaScript.

## Features

- Pure HTML and CSS
- No JavaScript dependency
- Retro arcade-inspired styling
- Chunky black borders
- Floating offset shadows
- Interactive hover state
- Toggle checked state
- Pressed interaction effect
- Keyboard focus styling
- Responsive desktop, tablet and mobile layouts
- Reduced-motion accessibility support
- Multiple reusable toggle instances

## Files

- `demo.html` — component markup and demo
- `style.css` — complete styling and responsive behavior

## Usage

Open `demo.html` directly in a browser.

The toggle uses a native checkbox hidden visually and a
corresponding label for interaction.

## Customization

The main visual values are defined as CSS custom properties
at the beginning of `style.css`.

Colors, shadows, borders and spacing can be adjusted there
without changing the component structure.

## Accessibility

The component provides:

- Native checkbox interaction
- Keyboard accessibility
- Visible `:focus-visible` state
- Reduced-motion support
- Descriptive labels for each toggle
