# Gradient Shimmer 3D Effect

A smooth and accessible 3D Gradient Shimmer effect created using pure HTML and Vanilla CSS.

## ✨ Features

- Pure HTML & CSS
- No JavaScript
- 3D perspective effect
- Animated gradient background
- Smooth shimmer animation
- Hover interaction
- Glass-like inner surface
- Dark-mode friendly
- Hardware-friendly CSS transforms
- Responsive design
- `prefers-reduced-motion` support
