Traditional vs light-dark()

Traditional Approach

body {
  --bg: #fff;
  --text: #1a1a2e;
}
@media (prefers-color-scheme: dark) {
  body {
    --bg: #0f0f1a;
    --text: #e8e8f0;
  }
}
.card {
  background: var(--bg);
  color: var(--text);
}

Requires variables everywhere + media queries. Hard to mix with other theming.

With light-dark()

body {
  color-scheme: light dark;
}
.card {
  background: light-dark(#fff, #0f0f1a);
  color: light-dark(#1a1a2e, #e8e8f0);
}

Single declaration. Clean, readable, composable. No variables, no media queries.
