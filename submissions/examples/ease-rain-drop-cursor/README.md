# 🌧️ Rain Drop Cursor – Drops Fall from Cursor Position

> A calming, atmospheric cursor effect where raindrops fall from the cursor position, creating a soothing, weather-inspired visual experience.

---

## 📖 Description

The **Rain Drop Cursor** is a calming, atmospheric cursor effect where raindrops fall from the cursor position. As you move your mouse, raindrops continuously fall, creating a soothing, weather-inspired visual experience reminiscent of a gentle rain shower. Each drop has random size, speed, and opacity, with a subtle splash effect on impact.

The component uses JavaScript to create raindrops at the cursor position with random properties (size: 1.5-4.5px, length: 12-32px, speed: 0.5-1.3s). Drops fall with a slight horizontal drift and fade out at the bottom. Clicking creates a rain burst with 15 drops and a splash effect, and hovering over interactive elements triggers a smaller burst.

Perfect for calming interfaces, weather apps, meditation tools, and any application where you want to create a soothing, atmospheric cursor experience. The Rain Drop Cursor transforms a simple cursor into a gentle rain shower.
