# 🕯️ Echo Candle

Echo Candle is an ambient interactive flame component inspired by the idea that a flame can retain a visual memory of every disturbance it experiences.

The flame responds to wind, pointer interaction, and environmental changes.

Previous flame positions are temporarily stored as faint glowing particles, creating a visual "memory" trail behind the flame.

The component is implemented using vanilla HTML, CSS, and JavaScript.

---

## ✨ Features

- 🕯️ Animated candle
- 🔥 Layered flame
- 💨 Adjustable wind
- 🌬️ Organic flame movement
- ✨ Floating embers
- 🧠 Flame memory particles
- 🌫️ Ambient glow
- 💧 Wax drip visuals
- 🔥 Extinguishing behaviour
- 🔄 Relight interaction
- 📊 Flame status feedback
- 🖱️ Pointer disturbance
- ⌨️ Keyboard-friendly controls
- 📱 Responsive design
