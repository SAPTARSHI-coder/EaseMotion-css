# Morphing Badge with Neon Styling

A responsive neon badge component featuring glowing effects and smooth morphing border-radius animations.

## Features

- Neon glow styling
- Morphing animation
- Hover interaction
- Fully responsive
- Pure HTML & CSS

## Files

- demo.html
- style.css

## Usage

Open `demo.html` in a browser.

## Customization

Modify gradient colors, glow intensity, animation timing, and badge labels inside `style.css`.
