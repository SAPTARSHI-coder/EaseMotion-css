# CSS Glitch-Flicker Tooltip for Product Catalog Layouts

A modern **Glitch-Flicker Tooltip** built using pure HTML5 and CSS3 for product catalog layouts. The component provides interactive product tooltips with glitch-flicker title animations, glassmorphism styling, responsive layouts, and accessibility support.

## Features

* Pure HTML5 & CSS3
* Glitch-Flicker tooltip animation
* Hover-triggered tooltip
* Glassmorphism product cards
* Animated glitch heading effect
* Responsive desktop, tablet, and mobile layout
* CSS Custom Properties
* Smooth CSS transitions & keyframe animations
* No JavaScript required
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over the **Hover Details** button to display the tooltip.
3. Customize colors and animations through the CSS variables in `:root`.
4. Integrate the component into any product catalog or e-commerce interface.
