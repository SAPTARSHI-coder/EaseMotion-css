# CSS Animated Empty Dashboard

## Description

A pure CSS empty dashboard state featuring animated dashed borders, floating illustration, and a call-to-action button.

## Features

- Pure CSS animation
- Animated dashed border
- Floating dashboard icon
- CTA button hover effect
- Responsive layout
- No JavaScript required
