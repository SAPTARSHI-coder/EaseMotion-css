# Profile Card Component

### 1. What does this do?
Provides a clean, modern, and customizable Profile Card UI component that displays an avatar image, user details, bio, and social links.

### 2. How is it used?
```html
<div class="profile-card">
    <img src="avatar.jpg" alt="Profile">
    <h2>Jane Doe</h2>
    <p class="role">Frontend Developer</p>
    <p class="bio">Passionate about web experiences.</p>
    <div class="social-links">
        <a href="#">GitHub</a>
        <a href="#">LinkedIn</a>
    </div>
</div>
