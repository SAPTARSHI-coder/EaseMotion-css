# Elevator Governor Trip

## What does this do?
Renders a self-contained CSS-only `ease-elevator-governor-trip` demo: Elevator overspeed governor spinning then tripping.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-elevator-governor-trip`. No build step or JavaScript is required for the effect.

```html
<section class="ease-elevator-governor-trip">
  <div class="ease-elevator-governor-trip__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
