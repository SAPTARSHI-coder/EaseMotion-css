# CSS Neon Pulse Loader

A hypnotic loading animation composed of intense glowing neon dots that expand and shrink in a cascading wave pattern.

## Features
- Deep glowing aura created by chaining multiple layered `box-shadow` values.
- Smooth pulsing rhythm utilizing `transform: scale()` mapped to an `ease-in-out` animation curve.
- Perfect cascading wave effect generated purely by staggered `animation-delay` offsets.
