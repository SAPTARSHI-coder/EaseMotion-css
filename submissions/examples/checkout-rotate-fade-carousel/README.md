# CSS Rotate-Fade Carousel (Checkout)

A dynamic, pure CSS carousel designed specifically for E-Commerce Checkout Layouts, featuring a striking 3D `rotateX` entrance animation paired with a fade effect.

## Features
- Pure CSS and HTML (No JavaScript required).
- State management handled purely through hidden radio buttons.
- Distinctive 3D `rotateX` and `scale` entrance effect for an engaging interaction.
- Interactive, scaling dot indicators for smooth navigation.
- Clean and modern e-commerce checkout styling.
- Fully responsive across all device sizes.
- Honors the `prefers-reduced-motion` accessibility standard.

## Usage
Open `demo.html` in your browser. Click on the circular pagination indicators below the card to switch between different checkout options, watching the cards rotate on their X-axis and fade seamlessly into focus.

## Files
- `demo.html`: HTML structure for the checkout component utilizing radio buttons and 3D perspective layers.
- `style.css`: Pure CSS styles containing the layout rules and `rotateX` transition logic.
