# Ease Color Dot

## What does this do?

A small reusable colored status dot with optional pulse animation for indicating different states.

---

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<span class="color-dot green"></span>
```

### Available variants

```html
<span class="color-dot green"></span>
<span class="color-dot yellow"></span>
<span class="color-dot red"></span>
<span class="color-dot gray"></span>
```

### Features

- Small rounded status dot
- Multiple color variants
- Pulse animation
- Simple and reusable
- Responsive layout

---

## Why is it useful?

Colored status dots are commonly used in dashboards, messaging applications, monitoring interfaces, and user profiles.

This component provides a lightweight status indicator with subtle motion while following the animation-first philosophy of EaseMotion CSS.
