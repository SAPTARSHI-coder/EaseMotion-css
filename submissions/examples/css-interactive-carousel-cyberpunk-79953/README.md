# Interactive Carousel with Cyberpunk Styling

A futuristic carousel-inspired component featuring neon cyberpunk aesthetics, glowing accents, interactive cards, and responsive layouts using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Cyberpunk neon design
- Glowing hover effects
- Responsive layout
- Smooth animations
- Accessible structure
- No JavaScript required

## Files

- demo.html
- style.css

## Usage

```html
<div class="carousel">
  <div class="card active">
    <h2>Neon City</h2>
    <p>Content here</p>
  </div>
</div>
```

## Why it fits EaseMotion CSS

This component emphasizes visual motion, futuristic styling, and reusable CSS patterns while maintaining performance, accessibility, and responsiveness.
