# Centered Message Box

## What it does

This submission creates a simple CSS-only centered message box utility for short success, info, warning, or empty-state messages.

## How to use it

Wrap the message title and supporting text inside the shared container:

```html
<div class="centered-message-box">
  <h3>Saved successfully</h3>
  <p>Your changes have been updated.</p>
</div>
```

## Why it fits EaseMotion CSS

It fits EaseMotion CSS because it is human-readable, composable, and useful across many interfaces. It works well in dashboards, forms, cards, settings pages, and content sections.

## Included features

- Centered message box utility
- Soft variation included in the demo
- Practical success, info, and review examples
- Responsive demo layout
- Pure HTML and CSS implementation
