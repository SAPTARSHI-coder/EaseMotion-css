# CSS Background: Origami Paper Fold

A smooth pure CSS background animation inspired by folded origami paper.

## Features

- Pure HTML and Vanilla CSS
- No external JavaScript
- Layered origami-inspired paper surfaces
- Smooth 3D fold and rotation animation
- CSS gradients for paper-like surfaces
- Hardware-accelerated transforms
- Responsive across screen sizes
- Dark-mode friendly background
- Reduced-motion accessibility support

## Files

- `demo.html` — Origami background demo
- `style.css` — Background styling and animations
- `README.md` — Documentation

## Accessibility

The decorative fold elements use `aria-hidden="true"`. The animation also respects the user's `prefers-reduced-motion` preference.
