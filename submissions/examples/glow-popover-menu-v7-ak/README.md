# glow-popover-menu-v7-ak

Pure CSS animated glowing popover menu component — no JavaScript required.

## How to use

```html
<div class="ease-popover-wrapper-v7">
  <button class="ease-popover-trigger-v7">Options</button>

  <ul class="ease-popover-menu-v7">
    <li class="ease-popover-item-v7"><a href="#">Item 1</a></li>
    <li class="ease-popover-item-v7"><a href="#">Item 2</a></li>
  </ul>
</div>
