# CSS Skew-Active Navbar for Fintech Dashboard Layouts

A modern fintech dashboard navigation component featuring skew-based active states and smooth hover interactions built completely with pure HTML and CSS.

This component is designed for fintech dashboards, SaaS applications, and financial platforms where dynamic navigation effects are required without JavaScript.


## ✨ Features

- 📐 Skew-active navigation states
- 💳 Fintech dashboard inspired UI
- 🎨 Glassmorphism navbar design
- ⚡ Pure HTML and CSS implementation
- 🔄 Smooth CSS transform transitions
- 🌈 Gradient buttons and modern effects
- 📱 Fully responsive layout
- ♿ prefers-reduced-motion accessibility support
- 🚀 Lightweight and framework-free

## 🚀 Usage

1. Open `demo.html` directly in your browser.

2. Hover over navigation items to view skew interactions.

3. Customize CSS variables inside `style.css` for your own theme.


## 🎨 CSS Custom Properties

The component uses CSS variables for easy customization:

```css
:root {

    --bg:#020617;
    --card:#0f172a;
    --primary:#38bdf8;
    --secondary:#8b5cf6;
    --accent:#22c55e;
    --text:#f8fafc;
    --muted:#94a3b8;

}

Modify these values to match your fintech dashboard branding.
