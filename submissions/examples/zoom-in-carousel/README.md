# CSS Zoom-In Carousel

A pure CSS carousel component designed for E-Commerce Checkout Layouts, featuring a lively zoom-in (scale) animation when switching between active selection cards.

## Features
- Pure CSS and HTML (No JavaScript required).
- Radio-button hack utilized for fully functional state management.
- Bouncy `cubic-bezier` scale transitions for an engaging zoom-in effect.
- Animated pagination indicators featuring expanding rings.
- Clean and modern e-commerce checkout styling.
- Fully responsive across desktop, tablet, and mobile viewports.
- Honors the `prefers-reduced-motion` accessibility standard.

## Usage
Open `demo.html` in your browser. Click on the pagination indicators below the card to transition smoothly between different checkout options using the zoom-in scaling animation.

## Files
- `demo.html`: The HTML structure for the checkout UI and the radio-input state management.
- `style.css`: The styling, flexbox properties, and CSS transformations for the zoom-in carousel logic.
