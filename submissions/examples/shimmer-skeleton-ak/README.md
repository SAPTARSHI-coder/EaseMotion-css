# shimmer-skeleton-ak

Pure CSS animated glassmorphism skeleton shimmer card loader — no JavaScript required.

## How to use

```html
<div class="ease-skeleton-card">
  <div class="ease-skeleton-header">
    <div class="ease-skeleton-box ease-skeleton-avatar"></div>
    <div class="ease-skeleton-header-info">
      <div class="ease-skeleton-box ease-skeleton-title"></div>
      <div class="ease-skeleton-box ease-skeleton-text ease-skeleton-text--short"></div>
    </div>
  </div>
  
  <div class="ease-skeleton-box ease-skeleton-text"></div>
  <div class="ease-skeleton-box ease-skeleton-text"></div>
</div>
