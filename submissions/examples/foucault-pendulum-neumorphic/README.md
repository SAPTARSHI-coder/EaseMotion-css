# Foucault Pendulum Neumorphic

A pure CSS neumorphic UI component inspired by the elegant swinging motion of a Foucault pendulum.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript required
- Smooth pendulum swing animation
- Soft neumorphic depth and shadows
- Responsive layout
- Dark mode support
- Reduced-motion accessibility support
- Hardware-friendly CSS animations
- Self-contained demo
