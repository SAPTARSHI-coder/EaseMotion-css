# CSS Ripple-Wave Toast for Fintech Dashboard Layouts

A modern fintech notification toast component featuring smooth ripple-wave animations, glassmorphism styling, and responsive alert cards built completely with HTML and CSS.

This component provides animated dashboard notifications without JavaScript or external dependencies.

## ✨ Features

- 🌊 Smooth ripple-wave animation effect
- 💳 Fintech dashboard notification design
- 🔔 Multiple toast states (success, warning, info)
- ✨ Glassmorphism UI styling
- 🎨 Gradient glow effects
- ⚡ Pure HTML and CSS implementation
- 📱 Fully responsive layout
- 🔄 CSS keyframe animations and transitions
- ♿ Accessibility support with `prefers-reduced-motion`

## 🚀 Usage

1. Clone the EaseMotion CSS repository.

2. Navigate to:


submissions/examples/ease-css-ripple-wave-toast-fintech-dashboard-layouts/


3. Open `demo.html` in any modern browser.

No JavaScript, frameworks, or external libraries are required.

## 🎨 CSS Custom Properties

The component uses CSS variables for easy customization:

```css
:root {
    --bg:#050816;
    --primary:#00f5ff;
    --secondary:#8b5cf6;
    --green:#22c55e;
    --yellow:#facc15;
    --red:#ef4444;
    --text:#f8fafc;
    --muted:#94a3b8;
}

Modify these values to match your fintech dashboard branding.
