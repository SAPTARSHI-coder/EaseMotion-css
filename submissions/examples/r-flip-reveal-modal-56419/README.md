# CSS Flip-Reveal Modal

A modern **Flip-Reveal Modal** built using pure HTML5 and CSS3 for Gaming Hub layouts. The modal flips into view with a smooth 3D reveal animation while remaining lightweight, responsive, and accessible.

---

## ✨ Features

- Pure HTML5 & CSS3
- Flip-Reveal opening animation
- Gaming-inspired interface
- Fully responsive
- CSS Custom Properties
- Lightweight and performant
- Accessible checkbox toggle
- `prefers-reduced-motion` support
- No JavaScript required
