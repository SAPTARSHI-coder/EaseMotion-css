# Floor Plan · Floor Plan Unfolds 🏠

An interactive floor plan that unfolds room by room, revealing the layout with furniture, doors, and architectural details.

## Features

- 🏠 **Floor Plan Layout** – Multiple rooms with labels
- 📐 **Unfold Animation** – Rooms appear progressively
- 🪑 **Furniture** – Sofa, table, bed, and more
- 🚪 **Doors** – Doorways between rooms
- 🎚️ **Speed Control** – Adjust unfold speed (1-10)
- 🎚️ **Detail Control** – Adjust visual detail (1-10)
- ⏸️ **Pause/Resume** – Toggle animation
- 🔄 **Reset** – Reset to un-unfolded state

## How to Use

1. Click **UNFOLD** or press **Space** to start the unfold
2. Watch rooms appear one by one
3. Furniture and doors appear as rooms unfold
4. Adjust **Speed** for faster/slower reveal
5. Adjust **Detail** for visual fidelity
6. Press **RESET** or **R** to reset
7. Press **PAUSE** or **P** to pause/resume animation

## Controls

| Action | Method |
|--------|--------|

## Technical Details

- **Unfold System:** Progressive room-by-room reveal
- **Rendering:** Canvas-based floor plan
- **Controls:** Real-time parameter adjustment
- **Performance:** 60fps with requestAnimationFrame

## Customization

You can easily customize:
- **Rooms:** Add/modify room data
- **Furniture:** Add/modify furniture items
- **Colors:** Change room and furniture colors
- **Speed:** Adjust speed range (1-10)
- **Layout:** Modify room positions and sizes
