Fix #60878 — Password Strength Meter ARIA Semantics

Type in either field, or use the buttons below each panel to change strength. Turn on a screen reader (or check the accessibility tree in DevTools) to hear the difference.

❌ Before (Bug)

The bar is a plain, unlabeled <div>. Screen readers announce nothing when strength changes.

Strength Empty 
<div class="ease-password-strength">
  <div class="ease-password-strength-bar is-weak"></div>
  <div class="ease-password-strength-label">
    <span>Strength</span>
    <span>Weak</span>
  </div>
</div>
✅ After (Fix)

The bar exposes role="progressbar" with live aria-valuenow/aria-valuetext, and the label is an aria-live region.

Strength Empty 
<div
  class="ease-password-strength-bar is-weak"
  role="progressbar"
  aria-label="Password strength"
  aria-valuemin="0"
  aria-valuemax="100"
  aria-valuenow="25"
  aria-valuetext="Weak"
></div>
<div class="ease-password-strength-label">
  <span>Strength</span>
  <span aria-live="polite">Weak</span>
</div>
