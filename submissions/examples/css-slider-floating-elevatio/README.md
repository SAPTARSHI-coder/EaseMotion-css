# CSS Slider: Floating Elevation Variation

A responsive pure CSS slider featuring a floating
elevation effect using layered shadows, transforms,
and subtle ambient animations.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript
- No external dependencies
- Floating elevation effect
- Layered box shadows
- Smooth hover transitions
- Ambient floating decoration
- CSS Scroll Snap
- Responsive design
- Keyboard-accessible navigation
- Focus-visible states
- Reduced-motion support
- Dark-mode compatible
- Hardware-accelerated transforms
