# CSS Parallax Scrolling Image Gallery

A visually appealing image gallery where background images move at a slower rate than the foreground content as the user scrolls, creating a 3D parallax effect using CSS `background-attachment: fixed`.

## Preview
Open `demo.html` in your browser. Scroll down the page to observe the parallax effect where the background images appear fixed relative to the viewport while the page content scrolls over them.

## Implementation
- Utilizes `background-attachment: fixed` on each section to keep the background image static in the viewport.
- Uses `background-size: cover` and `background-position: center` to ensure the images look great at any screen size.
- Pure CSS solution, no JavaScript required.
