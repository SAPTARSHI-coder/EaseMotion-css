# CSS Morph-Glow Tabs for Product Catalog Layouts

A modern **Morph-Glow Tabs** component built using pure HTML5 and CSS3 for product catalog layouts. The component provides responsive category tabs with elegant morphing glow effects, smooth content switching, and a glassmorphism-inspired interface.

## Features

* Pure HTML5 & CSS3
* Morph-Glow tab animation
* CSS-only tab switching using radio buttons
* Product category tabs (Featured, New Arrivals, Trending, Deals)
* Animated glowing active state
* Responsive product showcase cards
* Smooth CSS transitions & keyframe animations
* Modern glassmorphism container
* CSS Custom Properties for easy customization
* Fully responsive across desktop, tablet, and mobile devices
* No JavaScript required
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in a modern browser.
2. Click any tab to switch between product categories.
3. Hover over tabs to experience the Morph-Glow animation.
4. Customize colors, spacing, glow intensity, border radius, and animation timing using the CSS variables defined in `:root`.
