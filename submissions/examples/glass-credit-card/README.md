# Glassmorphism Credit Card with Shine Effect

## What it does
A highly stylized, premium `.ease-credit-card` component showcasing a modern frosted glass aesthetic using advanced background layering and backdrop-filters. On hover, a sharp diagonal glare smoothly sweeps across the card, adding a dynamic "shine" effect.

## How to use it

```html
<div class="ease-credit-card">
    <div class="card-logo">VISA</div>
    <div class="card-chip"></div>
    <div class="card-number">•••• •••• •••• 4242</div>
    <div class="card-details">
        <div class="card-holder">
            <span class="label">Card Holder</span>
            <span class="name">Jane Doe</span>
        </div>
        <div class="card-expiry">
            <span class="label">Expires</span>
            <span class="date">12/28</span>
        </div>
    </div>
</div>
```

Ensure you include the CSS class `.ease-credit-card` and its internal elements as structured above.

## Why it fits EaseMotion CSS
Payment UIs heavily rely on sleek, animated representations of credit cards to build trust and convey a premium feel. Implementing a pure CSS glassmorphism effect combined with a sweeping glare transition demonstrates advanced visual techniques without Javascript. It perfectly embodies the "animation-first philosophy" of EaseMotion by making modern micro-interactions human-readable and accessible.
