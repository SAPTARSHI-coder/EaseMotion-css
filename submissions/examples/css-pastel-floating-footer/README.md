# Floating Footer with Pastel Styling (#78796)

A soft pastel-themed floating footer component featuring glassmorphism backdrop blur, sticky base alignment, and peach badge accents.

## Features
- **Pastel Aesthetics:** Clean light slate background pairing with soft peach badge highlights and neutral text.
- **Glassmorphism Backdrop:** Translucent surface cards with CSS `backdrop-filter: blur(12px)` filtering.
- **Fully Responsive:** Fluid flexbox layout adapting gracefully into stacked vertical alignments on mobile devices.

## File Hierarchy
- `style.css` - Custom properties, sticky footer positioning, backdrop blur filters, and media queries.
- `demo.html` - Semantic markup demonstrating floating footer integration with ARIA accessibility roles.
- `README.md` - Technical specification and architecture overview.
