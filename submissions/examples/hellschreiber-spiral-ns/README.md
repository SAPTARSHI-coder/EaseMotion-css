# Hellschreiber Spiral

## What does this do?
Renders a self-contained CSS-only `ease-hellschreiber-spiral` demo: Hellschreiber spiral printing a column of dots.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-hellschreiber-spiral`. No build step or JavaScript is required for the effect.

```html
<section class="ease-hellschreiber-spiral">
  <div class="ease-hellschreiber-spiral__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
