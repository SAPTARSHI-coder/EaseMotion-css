# Ease Toggle Switch

## What does this do?

A reusable animated toggle switch for boolean settings with accessible keyboard focus support and responsive sizing.

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<label class="toggle-field">
    <span class="toggle-label">Notifications</span>

    <input type="checkbox" class="toggle-input">

    <span class="toggle-switch">
        <span class="toggle-thumb"></span>
    </span>
</label>
```

### Features

- On/off states
- Smooth toggle animation
- Accessible checkbox input
- Keyboard focus state
- Responsive sizing
- Hover interaction
- Pure CSS
- No JavaScript required

## Why is it useful?

Toggle switches are commonly used in settings panels, preferences, configuration interfaces, and dashboards where users need to enable or disable a boolean option.

This component provides a clean and reusable toggle pattern with smooth state transitions while following the animation-first philosophy of EaseMotion CSS.
