# Blur-Entrance Accordion

A minimalist, tech-inspired accordion that uses native HTML `<details>` and `<summary>` elements with a pure CSS blur-entrance animation.

## Features

- **Pure HTML/CSS**: No JavaScript required.
- **Native Accessibility**: Uses semantic `<details>` and `<summary>` elements for built-in keyboard and screen reader support.
- **Animation**: Smooth blur and fade-in animation for content when expanded.
- **Responsive Design**: Works perfectly across mobile, tablet, and desktop viewports.
- **Accessibility**: Includes visible focus states and `prefers-reduced-motion` support.

## Usage

Simply include the HTML structure and link the `style.css` file.

```html
<details>
  <summary>Your Title</summary>
  <div class="content">
    Your content goes here.
  </div>
</details>
```

## Customization

You can easily customize colors, timing, and spacing by modifying the CSS variables and properties in `style.css`.
