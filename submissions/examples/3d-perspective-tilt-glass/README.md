# CSS 3D Perspective Tilt Glass Effect

A pure CSS glassmorphism component featuring a smooth 3D perspective tilt interaction.

## ✨ Features

- Pure HTML and CSS
- 3D perspective transformation
- Glassmorphism styling
- Smooth hover transitions
- Layered depth using `translateZ()`
- Glass reflection layer
- Ambient background glow
- Dark-mode friendly design
- Responsive layout
- Reduced-motion accessibility support
- No JavaScript or external libraries

## 🎨 Effect

The component combines:

- `perspective()`
- `rotateX()`
- `rotateY()`
- `translateZ()`
- `transform-style: preserve-3d`
- `backdrop-filter`
- CSS gradients
- CSS transitions

The card starts in a neutral position and develops a subtle 3D tilt when hovered.
