# Interactive Timeline Roadmap Component

A modern vertical Product Roadmap Timeline featuring glowing milestone node markers, alternating card alignment, and pulsing active node keyframes.

## What does this do?
Renders an interactive product roadmap timeline with completed, active, and upcoming milestone cards connected along a central track.

## How is it used?
1. Open `demo.html` to preview the roadmap timeline layout.
2. Incorporate `.vertical-timeline` into landing pages or product documentation.
3. Import `style.css` to enable pulse keyframes and backdrop filters.

## Why is it useful?
Timeline components effectively communicate project history and feature roadmaps. CSS keyframe animations ensure smooth presentation at 60fps across all devices.
