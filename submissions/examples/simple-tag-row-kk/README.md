# Simple Tag Row

## What it does

This submission creates a simple CSS-only tag row utility for displaying multiple small tags with clean spacing and wrapping.

## How to use it

Place tags inside the shared row container:

```html
<div class="simple-tag-row">
  <span>HTML</span>
  <span>CSS</span>
  <span>Responsive</span>
</div>
```

## Why it fits EaseMotion CSS

It fits EaseMotion CSS because it is human-readable, composable, and useful across many interfaces. It works well for badges, categories, filters, skills, labels, and metadata groups.

## Included features

- Simple wrapped tag row utility
- Practical skill, category, and filter examples
- Consistent spacing between tags
- Responsive demo layout
- Pure HTML and CSS implementation
