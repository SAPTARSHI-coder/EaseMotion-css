# Interactive Price Comparison Card Tier Switcher Component (Cyberpunk Theme)

1. **What does this do?** 
   A high-octane, neon-drenched Cyberpunk pricing table. It features clipped corners via `clip-path`, glowing cyan and yellow accents, an ambient grid background, and a unique CSS glitch animation on the main heading. 

2. **How is it used?** 
   Copy the `demo.html` structure and link the `style.css`. The component heavily utilizes standard CSS properties (`clip-path`, `@keyframes`) for its aesthetic. A lightweight JavaScript snippet is included in `demo.html` to handle the billing toggle; this JS specifically triggers a cool randomized number glitch effect when swapping prices between Monthly and Annual modes.

3. **Why is it useful?** 
   It serves as a perfect example for the "Micro-Animations" category by demonstrating how standard CSS and minimal JS can create highly complex, thematic micro-interactions (like text glitching on state change) without needing heavy external WebGL or animation libraries. It fits seamlessly into EaseMotion CSS’s animation-first philosophy.
