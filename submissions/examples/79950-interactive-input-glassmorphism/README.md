# Interactive Input Field - Glassmorphism

A responsive interactive input field component built with pure HTML
and CSS, featuring a modern glassmorphism interface.

## ✨ Features

- Pure HTML and CSS
- Fully responsive
- Glassmorphism card and input surfaces
- Interactive focus states
- Animated focus feedback
- Hover states
- Accessible labels
- Keyboard-friendly controls
- Responsive textarea
- Animated status indicator
- Ambient background effects
- CSS custom properties for customization
- Reduced-motion support
- No JavaScript dependency
