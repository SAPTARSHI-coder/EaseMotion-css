# CSS Segmented Control Button

A responsive iOS-style segmented control built using HTML and CSS.

## Features

- Pure CSS implementation
- Sliding selection indicator
- Three selectable options
- Responsive design
- Keyboard focus support
- Accessible radio-button semantics
- Reduced-motion support
- No JavaScript required
