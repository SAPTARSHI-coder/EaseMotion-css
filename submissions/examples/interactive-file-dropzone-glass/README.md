# Interactive File Dropzone — Glassmorphism

A responsive, accessible, CSS-only file dropzone with a modern
Glassmorphism visual style.

## Features

- Pure HTML and CSS implementation
- No external JavaScript dependencies
- Glassmorphism-inspired translucent surface
- Interactive hover and focus states
- Drag-and-drop styled upload area
- Native file input for accessibility
- Responsive across mobile, tablet, and desktop
- `prefers-reduced-motion` support
- Uses CSS custom properties/design tokens
- Works with multiple file selection
