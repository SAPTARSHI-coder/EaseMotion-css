# Ease Harbor Crane Slewing

A CSS-only animated harbor slewing crane component for the EaseMotion CSS showcase.

The component represents a realistic harbor crane rotating its boom while a
cargo load remains suspended from the hook.

## Features

- Pure HTML and CSS
- No JavaScript required
- Realistic harbor crane visual metaphor
- Animated crane slewing motion
- Suspended cargo load with subtle sway
- Slew speed control dial
- Slew angle readout
- Load status indicator
- Industrial control-panel styling
- Harbor water and dock details
- Responsive design
- CSS custom properties
- `prefers-reduced-motion` accessibility support
- Named CSS `@keyframes` animations
- Lightweight and dependency-free
