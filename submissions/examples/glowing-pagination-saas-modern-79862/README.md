# Glowing Pagination with SaaS Modern Styling

A responsive pagination component featuring glowing effects and a modern SaaS-inspired design.

## Features

- Modern SaaS appearance
- Glowing hover effects
- Gradient active state
- Fully responsive layout
- Pure HTML/CSS implementation
- Lightweight and reusable

## Files

- demo.html
- style.css

## Usage

Open `demo.html` in any modern browser.

## Customization

Modify:

- Glow intensity
- Gradient colors
- Button size
- Border radius
- Typography

Example:

```css
.pagination .active{
  background:linear-gradient(
    135deg,
    #7c3aed,
    #06b6d4
  );
}
```
