# CSS Origami Crane Loader

A pure CSS loading animation featuring an origami-inspired crane that gently flaps its wings while loading.

## Features

- Pure HTML and CSS
- No JavaScript required
- Animated crane wings
- Floating crane motion
- Pulsing loading text
- Responsive design
- Accessible loading status
- `prefers-reduced-motion` support
