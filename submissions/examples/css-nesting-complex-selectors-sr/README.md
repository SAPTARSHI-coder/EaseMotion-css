# CSS Nesting — Complex Selectors

A modern, JavaScript-free demonstration of CSS nesting with pseudo-classes,
relational selectors, focus states, pseudo-elements, responsive layouts,
and reduced-motion accessibility support.

## ✨ Features

- Native CSS nesting using the `&` selector
- Nested `:hover` interactions
- Nested `:focus-visible` states
- `:focus-within` accessibility states
- `:has()` relational selector examples
- Nested pseudo-element styling
- Responsive CSS Grid layout
- Mobile-friendly presentation
- Keyboard-accessible interactive elements
- `prefers-reduced-motion` support
- No JavaScript
- No external dependencies
- Self-contained demo
