# Interactive Treeview — Material Design

A responsive interactive treeview component inspired by
Material Design principles, built with pure HTML and CSS
for EaseMotion CSS issue #81429.

## Features

- Material-inspired visual design
- Interactive expandable and collapsible folders
- Native HTML `<details>` and `<summary>` interaction
- Smooth expand and collapse animations
- Folder and file indicators
- Hover states
- Keyboard focus support
- Responsive desktop, tablet and mobile layouts
- Reduced-motion support
- No JavaScript dependencies
