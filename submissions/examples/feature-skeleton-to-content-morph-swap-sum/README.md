# Skeleton-to-Content Morph Swap

1. **What does this do?**  
   Morphs skeleton placeholders into real content using blur→sharp, scale, and clip-path cues, with a replay control.

2. **How is it used?**  
   Open `demo.html` and press **Replay morph**:
   ```html
   <article class="swap-card is-skeleton" id="swap-card">...</article>
   ```

3. **Why is it useful?**  
   Most skeleton demos only pulse forever. This shows a deliberate placeholder→content handoff that fits EaseMotion’s animation-first teaching style.
