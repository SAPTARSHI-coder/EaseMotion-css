# Neumorphic Navbar with Pastel Styling (#78806)

A clean navigation bar component combining soft neumorphic shadow depth with a warm pastel color palette.

## Features
- **Soft Neumorphic Depth:** Dual-cast outer container shadows paired with inset hover states.
- **Pastel Palette:** Warm grayish-pink neutral tones and rose accent colors.
- **Fully Responsive:** Adapts flexibly from a horizontal desktop layout to a stacked mobile view.

## File Hierarchy
- `style.css` - Custom properties, neumorphic shadow variables, and responsive media queries.
- `demo.html` - Semantic navigation markup adhering to accessibility guidelines.
- `README.md` - Technical specification and architecture overview.
