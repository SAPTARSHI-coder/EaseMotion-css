# Cyberpunk Neon - Sci-Fi HUD

A futuristic cyberpunk HUD interface created using pure HTML and
Vanilla CSS.

The component combines neon cyan and magenta accents, animated
target rings, glowing borders, grid effects, status indicators,
and subtle floating motion.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript
- No external dependencies
- Cyberpunk neon styling
- Sci-fi HUD interface
- Animated rotating target rings
- Neon glow effects
- Subtle floating animation
- Interactive status cards
- Responsive layout
- Dark background compatible
- `prefers-reduced-motion` support
- Hardware-friendly CSS transforms
