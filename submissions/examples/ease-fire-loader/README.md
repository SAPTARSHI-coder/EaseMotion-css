# 🔥 Fire Loader – Flames Flicker and Dance

> A dynamic, fiery loading animation where flames flicker and dance, creating a captivating, energetic visual experience.

---

## 📖 Description

The **Fire Loader** is a dynamic, fiery loading animation where flames flicker and dance. Multiple flame layers of different sizes and colors create a realistic fire effect, with ember particles rising and a pulsing glow at the base. The flames flicker with varying speeds and intensities, creating a captivating, energetic visual experience.

The component uses CSS animations with `transform` and `keyframes` to create the flame flickering and ember rising effects. Five flame layers (red, orange, yellow, white) flicker at different speeds, while ember particles rise with staggered delays. A glowing pulse at the base adds to the fiery atmosphere.

Perfect for fire-themed interfaces, energy brands, gaming, and any application where you want to create a dynamic, energetic loading animation. The Fire Loader transforms a simple loading indicator into a captivating, fiery spectacle.
