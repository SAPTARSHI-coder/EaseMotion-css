# Animated Number Counter

A lightweight animated number counter component for EaseMotion CSS.

The component uses the native Intersection Observer API to detect when
a counter enters the viewport. JavaScript updates the displayed number,
while CSS handles the visual animation.

No third-party animation library is required.

## Features

- Starts counting when the component enters the viewport
- Uses the native Intersection Observer API
- CSS-powered visual animation
- Smooth ease-out counting
- Supports integer values up to 1,000,000
- Automatic comma formatting
- Customizable animation duration
- Accessible static value without JavaScript
- Dark mode support
- Responsive layout
- Reduced-motion support
- No third-party dependencies
