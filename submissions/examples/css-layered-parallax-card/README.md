# CSS Layered Parallax Card

A lightweight, reusable layered parallax card built with pure HTML and CSS.

## Features

- Pure HTML and CSS implementation
- CSS 3D transforms and perspective
- Multiple visual layers for depth
- Smooth hover and keyboard-focus interaction
- Responsive across desktop, tablet, and mobile
- No JavaScript or external dependencies
- Accessible keyboard focus state
- `prefers-reduced-motion` support
- Easy-to-customize CSS variables

## Files

- `demo.html` — Standalone demonstration page
- `style.css` — Complete component styling and animation

## Usage

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
