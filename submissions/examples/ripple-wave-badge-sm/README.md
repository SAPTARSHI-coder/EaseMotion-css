# Ripple-Wave Badge

A pure CSS Ripple-Wave Badge designed for fintech dashboard interfaces.

The component provides a lightweight status indicator with expanding
ripple waves, subtle glow, and responsive behavior without JavaScript.

## Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Expanding ripple-wave animation
- Hover interaction
- Keyboard focus support
- Success, pending, and secure variants
- Responsive layout
- CSS custom properties
- `prefers-reduced-motion` support
- Suitable for fintech dashboard status indicators
