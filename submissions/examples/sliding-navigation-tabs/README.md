# Sliding Navigation Tabs

A lightweight CSS-only navigation component featuring a smooth sliding
indicator for active, hovered, and focused tabs.

## Features

- Pure HTML and CSS
- No JavaScript required
- Smooth sliding indicator
- Hover and focus interactions
- Keyboard accessible
- Responsive design
- Reduced-motion support
- Customizable CSS variables

## Files

- `demo.html` - Component demonstration
- `style.css` - Component styling and animation
- `README.md` - Documentation

## Usage

Add the navigation markup:

```html
<nav class="tabs" aria-label="Main navigation">
  <a href="#home" class="tab active">Home</a>
  <a href="#about" class="tab">About</a>
  <a href="#services" class="tab">Services</a>
  <a href="#contact" class="tab">Contact</a>
</nav>
