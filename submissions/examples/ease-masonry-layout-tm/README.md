# Masonry Layout Component

Add ease-masonry-layout-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|---------|
| `--msn-accent` | `#6366f1` |
| `--msn-radius` | `10px` |
| `--msn-shadow` | `0 4px 16px rgba(0,0,0,.3)` |

## Technique

`grid-template-columns` + `grid-auto-rows` + `grid-column: span 2` and `grid-row: span 2` for masonry effect.
