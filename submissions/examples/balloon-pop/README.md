# Balloon Pop

A cluster of balloons that inflate, wobble and pop away in a satisfying burst.

## Features
- Balloon bodies stretch and wobble on the string
- Hover pops a balloon with a scale burst
- String tails sway in the breeze

## Usage
```html
<div class="bp-sky">
  <div class="bp-balloon bp-b1"><div class="bp-body"></div><div class="bp-knot"></div><div class="bp-string"></div></div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
