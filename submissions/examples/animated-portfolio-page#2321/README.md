# Animated Portfolio/CV Page

A stunning **Portfolio/CV Page** built with **EaseMotion CSS**. Features hero section with floating cards, skills progress bars, project showcase, experience timeline, and contact section.

## ✨ Features

- **👤 Hero Section**: Profile image with floating stat cards
- **📊 Skills Progress**: Animated skill bars with gradient fill
- **💼 Project Cards**: Image hover zoom with overlay buttons
- **📅 Experience Timeline**: Vertical timeline with dot indicators
- **🚀 Contact CTA**: Gradient background call-to-action
- **🎬 Staggered Entrance**: All sections slide up sequentially
- **📱 Fully Responsive**: Desktop → tablet → mobile layout

## 🧩 EaseMotion Classes Used

| Class | Purpose |
|-------|---------|
| `ease-fade-in` | Fades in floating cards and footer |
| `ease-slide-up` | Slides sections up on entrance |
| `ease-delay-100` to `ease-delay-800` | Creates cascading staggered sequence |
| `ease-card` | Base card structure |
| `ease-hover-lift` | Lift effect on cards |
| `ease-hover-grow` | Scale effect on buttons |
| `ease-center` | Centers project overlay content |
| `ease-grid` + `ease-grid-cols-*` | Responsive grid layouts |
| `ease-gap-4` | Spacing between grid items |
| `ease-btn` + `ease-btn-primary` | Styled CTA buttons |
| `ease-pulse` | **Looping pulse** on availability badge |

## 🚀 How to Use

1. Open `demo.html` in any modern browser
2. Watch all sections slide in with staggered animations
3. Observe the floating cards animation on hero image
4. Watch skill bars fill with gradient animation
5. Hover over project cards to see overlay and zoom
6. Scroll through the experience timeline
7. Resize to mobile to see responsive layout
