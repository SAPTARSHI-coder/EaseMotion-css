# Notification Badge Pulse Component

Add ease-notification-badge-pulse-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|--------|
| `--nbp-accent` | `#6366f1` |
| `--nbp-red` | `#ef4444` |
| `--nbp-radius` | `10px` |
| `--nbp-shadow` | `0 4px 16px rgba(0,0,0,.3)` |

## Technique

Expanding ring on `.red` badges using `::before` with `border` + `scale` animation.
