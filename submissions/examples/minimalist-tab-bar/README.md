# Minimalist Tab Bar

A clean and responsive CSS-only tab bar component built with
HTML and CSS.

## ✨ Features

- CSS-only tab switching
- No JavaScript required
- Minimalist design
- Smooth active-tab indicator
- Responsive layout
- Mobile friendly
- Lightweight
- Accessible radio-button based interaction
- Reduced-motion support
