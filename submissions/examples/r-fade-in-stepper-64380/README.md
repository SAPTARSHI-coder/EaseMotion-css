# CSS Fade-In Stepper

A responsive glassmorphism stepper featuring a smooth staggered fade-in
animation for each progress step.

## Features

- Pure HTML and CSS
- No JavaScript dependencies
- Glassmorphism UI
- Staggered fade-in step animation
- Smooth hover interactions
- Responsive desktop, tablet, and mobile layout
- Semantic ordered list structure
- `prefers-reduced-motion` support
