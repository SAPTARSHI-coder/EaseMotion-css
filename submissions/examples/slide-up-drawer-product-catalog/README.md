# CSS Slide-Up Drawer for Product Catalog Layouts

A modern **Slide-Up Drawer Product Catalog** component built using pure HTML5 and CSS3 for the EaseMotion CSS project. The drawer smoothly slides upward on hover to reveal product details, pricing, and action buttons while maintaining a clean, responsive design.

---

## ✨ Features

- Pure HTML5 & CSS3
- Smooth slide-up drawer animation
- Modern product catalog layout
- Glassmorphism drawer effect
- Responsive across desktop, tablet, and mobile
- CSS custom properties for easy customization
- Hover interactions and transitions
- Accessible with `prefers-reduced-motion`
- No JavaScript required
