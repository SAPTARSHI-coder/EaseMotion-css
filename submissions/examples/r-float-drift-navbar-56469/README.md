# CSS Float-Drift Navbar

A modern **Float-Drift Navbar** built using pure HTML5 and CSS3 for Gaming Hub layouts. Navigation links gently float and drift on hover while remaining lightweight, responsive, and accessible.

---

## ✨ Features

- Pure HTML5 & CSS3
- Float-drift hover animation
- Gaming-inspired navigation
- Responsive layout
- CSS Custom Properties
- Lightweight and performant
- Accessible semantic HTML
- `prefers-reduced-motion` support
- No JavaScript required

## 🚀 Usage

1. Copy the component into your project.
2. Link the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

3. Open `demo.html` in your browser.
