# Signal Scar

Signal Scar is an experimental interactive UI component inspired by damaged futuristic transmissions.

Instead of communicating system activity through a conventional status badge or progress bar, the component uses a continuously evolving signal waveform.

Moving the pointer through the panel distorts and intensifies the signal around the pointer.

## ✨ Features

- Animated SVG waveform
- Pointer-reactive signal distortion
- Dynamic frequency readout
- Dynamic integrity readout
- Signal echo
- Signal shadow
- Transmission markers
- Interactive scan zone
- Responsive layout
- Touch support
- Reduced-motion support
- Dependency-free
- Vanilla JavaScript
