# 💜 Amethyst Glow – Purple Crystals Glow from Within

> A mystical amethyst component where purple crystals glow from within with intensity control (0-100%), sparkle control (0-100%), faceted crystal shapes, and inner glow particles.

---

## 📖 Description

The **Amethyst Glow** component creates a mystical amethyst experience where purple crystals glow from within with faceted shapes and sparkle effects. Built with vanilla HTML, CSS, and JavaScript, it features intensity control (0-100%), sparkle control (0-100%), and faceted crystal shapes for a magical experience.

### 🎯 Core Features

- **Amethyst crystals** – purple crystals with faceted shapes
- **Intensity control** – adjust glow intensity from 0-100%
- **Sparkle control** – adjust sparkle frequency from 0-100%
- **Inner glow** – crystals pulse with inner light
- **Glow particles** – floating particles around crystals
- **Interactive controls** – sliders, keyboard shortcuts
- **Responsive design** – adapts to different screen sizes

### 💜 Crystal Features

| Feature | Description |
|---------|-------------|
| **Facets** | 4-8 faceted crystal shapes |
| **Colors** | Multiple purple shades |
| **Glow** | Inner light with pulse animation |
| **Particles** | Floating glow particles |
| **Sparkles** | Random sparkle bursts |

### ⌨️ Interaction Options

| Method | Action |
|--------|--------|
| **Sliders** | Adjust Intensity (0-100%) and Sparkle (0-100%) |
| **Keyboard** | `R` – Reset |

### ✨ Amethyst Experience

When interacting:
1. **Crystals glow** – purple light pulses from within
2. **Intensity applies** – controls glow brightness
3. **Sparkle applies** – controls sparkle frequency
4. **Particles float** - glow particles orbit crystals
5. **Status updates** – shows current state

### 💡 Why Use This Component?

- Perfect for mystical interfaces, crystal shops, or magical themes
- Beautiful amethyst glow with faceted crystals
- Self-contained – no external dependencies or frameworks
- Easy to customize (colors, glow behavior, sparkle)
- Intensity and sparkle controls for customization

### 🛠️ Technologies Used

- **HTML5** – semantic structure with Canvas
- **CSS3** – gradients, backdrop-filter, transforms
- **JavaScript (ES6)** – Canvas API, requestAnimationFrame, particle system

### 🎨 Design Philosophy

This component embodies **EaseMotion CSS's animation-first philosophy** through:

- **Glow effects** – inner light with pulse animation
- **Particle effects** – floating glow particles
- **Visual feedback** – status updates, glow level, controls
- **Mystical atmosphere** – purple colors and glow
- **Human-readable classes** – `.amethyst-controls`, `.amethyst-text`

### 🔧 Customization Options

| Property | Location | Default |
|----------|----------|---------|
| Intensity range | `intensitySlider` | 0-100% |
| Sparkle range | `sparkleSlider` | 0-100% |
| Crystal count | `generateCrystals()` | 6-12 |
| Crystal size | `size` | 8-35px |
| Facets | `facets` | 4-8 |
