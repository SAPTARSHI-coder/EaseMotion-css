# Holographic Flicker

A futuristic CSS micro-interaction featuring a subtle **Holographic Flicker** effect.

The component combines animated RGB color separation, scanlines, irregular flickering, and glowing UI details using only HTML and vanilla CSS.

## ✨ Features

- Pure HTML and CSS
- No JavaScript required
- Holographic RGB gradient
- Irregular flicker animation
- Subtle scanline overlay
- Holographic light sweep
- Glowing status indicator
- Hover and keyboard focus states
- Dark-mode friendly
- Responsive layout
- Hardware-friendly CSS transforms
- `prefers-reduced-motion` support
- Accessible focus indicators
- Dependency-free
