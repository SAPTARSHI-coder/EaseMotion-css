# Holographic Flicker 3D Effect

A smooth and lightweight **Holographic Flicker** 3D animation created using pure HTML and vanilla CSS.

## ✨ Features

- Pure HTML & CSS
- No JavaScript
- No external libraries
- 3D transform effects
- Holographic flickering animation
- Smooth floating motion
- Dark and light mode support
- Hardware-accelerated transforms
- Responsive design
- `prefers-reduced-motion` accessibility support
