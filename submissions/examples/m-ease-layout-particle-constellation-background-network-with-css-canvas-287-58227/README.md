# Particle Constellation Background Network (High-Contrast Accessibility Edition)

A **high-contrast constellation background** built using pure HTML and CSS. The component features glowing particles, connecting network lines, glassmorphism cards, and accessibility-focused color contrast for dashboards and landing pages.

## ✨ Features

- Pure HTML5 & CSS3
- High-contrast accessible design
- Animated constellation particles
- Glowing network lines
- Glassmorphism information panel
- Responsive layout
- CSS Custom Properties
- `prefers-reduced-motion` support
- No JavaScript required
