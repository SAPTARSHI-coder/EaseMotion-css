# CSS Slide-Up Accordion for Fintech Dashboard Layouts

A responsive fintech dashboard accordion built with pure HTML and CSS.

This component demonstrates a smooth slide-up reveal effect without JavaScript or external libraries.

## Features

- Pure HTML and CSS
- Native `<details>` and `<summary>` interaction
- Smooth slide-up content reveal
- Opacity and translate animation
- Rotating accordion indicator
- Responsive desktop, tablet, and mobile layouts
- Fintech dashboard styling
- Keyboard accessible
- Visible `:focus-visible` state
- `prefers-reduced-motion` support
- No JavaScript
- No external dependencies
