# CSS Morphing Glassmorphism Orb

A mesmerizing, organic floating orb that fluidly morphs its shape behind a frosted glass container. This showcases the premium modern aesthetic of combining glassmorphism with organic movement.

## Features

- **Pure CSS**: Zero JavaScript used.
- **Glassmorphism**: Uses `backdrop-filter: blur()` to create the frosted glass effect.
- **Organic Morphing**: Animates complex `border-radius` values to create a fluid, non-uniform blob that rotates and scales.
- **Gradient Shifts**: The orb's background gradient shifts smoothly as it morphs.
