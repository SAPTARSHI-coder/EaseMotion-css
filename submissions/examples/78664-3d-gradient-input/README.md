# 3D Gradient Input Field

A responsive 3D input field component featuring layered depth,
animated gradient borders, smooth focus interactions, and accessible
form controls.

## Features

- 3D depth effect
- Gradient border styling
- Smooth focus animation
- Responsive design
- Multiple input types
- Textarea support
- Keyboard-friendly controls
- Visible focus states
- Reduced-motion support
- No JavaScript
- No external dependencies

- `demo.html`
- `style.css`
