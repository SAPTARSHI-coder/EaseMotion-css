# Catapult Arm Throw

## What does this do?
Renders a self-contained CSS-only `ease-catapult-arm-throw` demo: Trebuchet-style catapult arm hurling a payload arc.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-catapult-arm-throw`. No build step or JavaScript is required for the effect.

```html
<section class="ease-catapult-arm-throw">
  <div class="ease-catapult-arm-throw__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
