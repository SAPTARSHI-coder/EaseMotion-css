# Tessellation · Tiled Pattern Shifts and Morphs 🔷

An interactive tessellation with shifting and morphing geometric patterns, vibrant colors, and mesmerizing motion. Watch as the tiled pattern transforms!

## Features

- 🔷 **Tessellated Pattern** – Geometric tiled design
- 🌀 **Morph Animation** – Pattern shifts and transforms
- 🎨 **Vibrant Colors** – Dynamic color shifting
- 🎚️ **Speed Control** – Adjust morph speed (1-10)
- 🎚️ **Complexity Control** – Adjust pattern complexity (3-8)
- ⏸️ **Pause/Resume** – Toggle animation
- 🔄 **Reset** – Reset to initial pattern
- 🎯 **Three Shape Types** – Hexagons, diamonds, triangles

## How to Use

1. Click **MORPH** or press **Space** to transform the pattern
2. Watch the shapes shift, rotate, and change color
3. Adjust **Speed** for morph pace
4. Adjust **Complexity** for pattern density
5. Press **RESET** or **R** to reset
6. Press **PAUSE** or **P** to pause/resume animation

## Technical Details

- **Tessellation:** 8×10 grid of shapes
- **Morphing:** Smooth interpolation between patterns
- **Colors:** HSL-based dynamic coloring
- **Performance:** 60fps with requestAnimationFrame

## Customization

You can easily customize:
- **Colors:** Modify the color palette
- **Complexity:** Adjust slider range (3-8)
- **Speed:** Modify morph speed
- **Shapes:** Add/remove shape types
- **Grid:** Change rows and columns
