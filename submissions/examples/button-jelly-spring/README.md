# Button Jelly Spring

A button wobbles like jelly when clicked and squishes on press.

## Features
- Jelly wobble
- Squish press
- Bouncy overshoot
- Pure CSS

## Usage
```html
<button class="bjs-btn">Squish</button>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
