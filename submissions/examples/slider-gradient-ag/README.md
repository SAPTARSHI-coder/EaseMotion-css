# CSS-only Slider with Gradient Styling

What does this do?
This is a fully responsive, custom-styled range slider with a vibrant gradient background and smooth hover effects.

How is it used?
```html
<div class="slider-container-ag">
    <input type="range" min="0" max="100" value="50" class="slider-gradient-ag">
</div>
```

Why is it useful?
It provides a modern, visually appealing alternative to default browser sliders, fitting well with EaseMotion's aesthetic and interactive philosophy without relying on JavaScript.
