# Badge Achievement

An achievement badge pops in with a ribbon and shimmering star.

## Features
- Badge pop entrance
- Ribbon tails
- Shimmer star face
- Pure CSS

## Usage
```html
<div class="ba-badge"><span class="ba-star">&#9733;</span></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
