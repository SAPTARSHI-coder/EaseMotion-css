# Holographic Pricing Table Showcase

A futuristic SaaS pricing table featuring holographic shimmer sweep keyframe effects and responsive card scale transitions.

## 1. What does this do?
This component renders an interactive 3-tier pricing table with iridescent holographic gradients, floating popular ribbons, and dynamic card hover elevations.

## 2. How is it used?
Apply `.pricing-card` and `.ease-holo-card` to plan cards:

```html
<article class="pricing-card ease-holo-card" tabindex="0">
  <div class="holo-shimmer"></div>
  <h2 class="plan-name">Pro Team</h2>
</article>
```

## 3. Why is it useful?
- Elevates product tier monetization pages with eye-catching visual depth.
- Uses `mix-blend-mode: overlay` and CSS transforms for smooth rendering performance.
- Works cleanly across standard web browsers with responsive mobile stacked layouts.
