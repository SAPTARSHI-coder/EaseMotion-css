# Hover Neon Navbar

A responsive navigation bar created for EaseMotion CSS issue #78304.

## Features

- Pure HTML and CSS
- No JavaScript
- Fully responsive
- Neon cyber-style visual treatment
- Interactive hover effects
- Animated underline on navigation links
- Glowing borders and shadows
- Responsive navigation layout
- Mobile-friendly horizontal navigation
- Keyboard focus states
- Reduced-motion accessibility support
