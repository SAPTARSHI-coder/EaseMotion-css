# CSS Bulk Quantity Selector

A responsive bulk quantity selector component featuring discount tiers, pricing summaries, and interactive quantity controls built entirely with HTML and CSS.

## Features

- Pure CSS implementation
- Responsive design
- Bulk discount tier cards
- Animated hover effects
- Pricing summary section
- Modern card-based layout
- CSS custom properties for easy theming
- Accessible structure

## Usage

```html
<div class="quantity-card">
  <div class="quantity-display">
    <button>−</button>
    <span>50 Units</span>
    <button>+</button>
  </div>
</div>
```
