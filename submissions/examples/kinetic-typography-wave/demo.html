How It Works

Staggered Animation Delays & Transforms

Kinetic typography wave animations split words into individual character glyphs. By applying incrementally staggered delays to each character, we cause the keyframe cycle to trigger sequentially, creating the illusion of a rolling wave.

🔢
Staggered Delays via Inline Vars Instead of writing complex child selectors in CSS, each character has a custom property --i in the HTML. The CSS calculates the delay dynamically: calc(var(--i) * 0.12s).
🎢
Smooth Keyframe Oscillations The keyframes cycle through vertical translation (translateY(-35px)), rotation (rotate(12deg)), scale adjustments (scale(1.15)), and opacity changes.
♿
Reduced-Motion Protection We respect user OS accessibility preferences. When prefers-reduced-motion: reduce is active, the staggered movement is disabled, presenting a stable layout.

Implementation Details

Clean CSS Architecture

Below is the exact CSS code block for the staggered kinetic typography wave. Self-contained, responsive, and fully optimized.

style.css
/* 1. Define the typography keyframes */
@keyframes kinetic-wave {
  0%, 100% {
    transform: translateY(0) rotate(0deg) scale(1);
    opacity: 0.8;
  }
  50% {
    transform: translateY(-35px) rotate(12deg) scale(1.15);
    opacity: 1;
    color: #00f5d4;
  }
}

/* 2. Bind the wave animation with staggered delays */
.wave-line span {
  display: inline-block;
  animation: kinetic-wave 2.2s ease-in-out infinite;
  animation-delay: calc(var(--i) * 0.12s);
  will-change: transform, opacity;
}

/* 3. Handle accessibility gracefully */
@media (prefers-reduced-motion: reduce) {
  .wave-line span {
    animation: none !important;
    transform: none !important;
    opacity: 1 !important;
  }
}
