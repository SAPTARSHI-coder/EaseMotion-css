# Kinetic Typography Wave

A pure CSS kinetic typography effect where individual characters move through a
staggered wave pattern.

The example demonstrates how CSS animation delays can be combined with
transforms and opacity changes to create fluid text motion without JavaScript
or external animation libraries.

## Features

- Pure HTML and CSS
- Individual character animation
- Staggered animation delays
- Vertical character movement
- Subtle rotation
- Scale variation
- Opacity transitions
- Responsive typography
- Dark visual presentation
- CSS custom properties for easy customization
- `prefers-reduced-motion` support
- No JavaScript
- No external dependencies
