# CSS Gradient Footer

A responsive gradient footer created with pure HTML and CSS.

The component combines a vibrant multi-color gradient, decorative glow effects, navigation links, social links, and a responsive layout.

## Features

- Pure CSS implementation
- No JavaScript
- Responsive design
- Multi-color gradient background
- Decorative CSS glow effects
- Navigation links
- Accessible social links
- Keyboard focus states
- Hover interactions
- Mobile-friendly layout
- Reduced-motion support
- No external dependencies
