# CSS Scroll-driven Reveal

A CSS scroll-driven animation demo where content fades, slides, and scales into view as it enters the viewport.

## Files

- `demo.html` — semantic reveal sequence
- `style.css` — view-timeline animations, fallback, responsive styling, and reduced-motion rules

## Usage

Open `demo.html` in a modern browser. No JavaScript is required.

## Accessibility

Content remains present in the document regardless of animation support, and reduced-motion preferences disable animated transitions.
