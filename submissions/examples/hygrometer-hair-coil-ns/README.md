# Hygrometer Hair Coil

## What does this do?
Renders a self-contained CSS-only `ease-hygrometer-hair-coil` demo: Hair-tension hygrometer coil unwinding with humidity.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-hygrometer-hair-coil`. No build step or JavaScript is required for the effect.

```html
<section class="ease-hygrometer-hair-coil">
  <div class="ease-hygrometer-hair-coil__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
