# CSS Magnetic Social Links

A responsive collection of social links with a magnetic-style hover
interaction created entirely using CSS.

## Issue

This contribution addresses:

**Issue #68386 - [FEATURE] CSS Magnetic Social Links**

## Features

- Pure CSS implementation
- No JavaScript required
- Magnetic-style hover movement
- Smooth scaling effect
- Individual hover variations
- Social media labels
- Keyboard accessibility
- Visible focus state
- Responsive layout
- Reduced-motion support
- No external libraries
