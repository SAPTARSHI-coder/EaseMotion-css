# ease-zoom-pricing Zoom-In Pricing Table

## What does this do?

A pricing table component with smooth zoom-in animations on hover, designed for fintech dashboards. Each element animates in with a satisfying scale effect.

## How is it used?

```html
<div class="ease-zoom-pricing">
  <div class="ease-zoom-card">
    <span class="plan-name">Pro</span>
    <span class="plan-price">$29</span>
    <button class="ease-zoom-btn">Select Plan</button>
  </div>
</div>
```

### CSS Classes

| Class | Purpose |
|-------|---------|
| `.ease-zoom-pricing` | Container for pricing cards |
| `.ease-zoom-card` | Individual pricing card with zoom animation |
| `.ease-zoom-btn` | CTA button with zoom effect |
| `.ease-zoom-featured` | Featured/highlighted plan |

## Why is it useful?

Creates an engaging pricing experience with smooth zoom animations:

- ✅ Smooth zoom-in animations
- ✅ Multiple pricing tiers
- ✅ Featured plan highlighting
- ✅ Staggered element animations
- ✅ Responsive layout
