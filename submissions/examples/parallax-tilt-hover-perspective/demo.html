Hover for Parallax Depth

New

When you hover over this card, the entire container tilts in 3D space, while child elements with the parallax class physically pop out towards you.

Inverted Perspective

You can easily configure the tilt direction and Z-depth popping distance via CSS variables to create distinct layers of depth.

Note: If you have "Prefers Reduced Motion" enabled in your OS settings, this animation will gracefully degrade. The 3D spatial tilt and Z-depth popping will be entirely stripped out, replacing them with a simple, subtle 2D scale to prevent vestibular discomfort.
