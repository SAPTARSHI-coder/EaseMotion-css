# Seasons Change · Tree Cycles Through Seasons 🌳

An interactive tree that cycles through four seasons with changing colors, leaves, and atmospheric effects. Watch the tree transform!

## Features

- 🌳 **4 Seasons** – Spring, Summer, Fall, Winter
- 🍃 **Dynamic Leaves** – Changing colors and falling
- 🌸 **Seasonal Effects** – Flowers, snow, colors
- 🎚️ **Speed Control** – Adjust animation speed (1-10)
- 🎚️ **Leaf Count** – Adjust number of leaves (50-300)
- ⏸️ **Pause/Resume** – Toggle animation
- 🔄 **Reset** – Reset to Spring
- 📱 **Touch Support** – Works on mobile devices

## How to Use

1. Click **CYCLE** or press **Space** to change seasons
2. Click on the canvas to cycle
3. Adjust **Speed** for animation pace
4. Adjust **Leaves** for leaf density
5. Press **RESET** or **R** to reset
6. Press **PAUSE** or **P** to pause/resume animation

## Controls

| Action | Method |
|--------|--------|

## Technical Details

- **Seasons:** 4 distinct seasonal states
- **Leaves:** Particle system with behavior
- **Colors:** Dynamic palette switching
- **Performance:** 60fps with requestAnimationFrame

- **Colors:** Modify seasonal palettes

- **Effects:** Adjust particle behavior
