# Sonometer Wire Pluck

## What does this do?
Renders a self-contained CSS-only `ease-sonometer-wire-pluck` demo: Sonometer wire pluck rippling between bridges.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-sonometer-wire-pluck`. No build step or JavaScript is required for the effect.

```html
<section class="ease-sonometer-wire-pluck">
  <div class="ease-sonometer-wire-pluck__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
