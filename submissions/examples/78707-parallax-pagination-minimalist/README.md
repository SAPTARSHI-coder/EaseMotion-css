# Parallax Pagination with Minimalist Styling

A fully responsive pagination component built with pure HTML and CSS,
featuring a minimalist interface and subtle parallax-inspired depth.

## Features

- Pure HTML and CSS
- No JavaScript dependency
- Minimalist visual design
- Parallax-inspired layered depth
- Smooth hover transitions
- Active page indicator
- Previous and next controls
- Pagination status information
- Responsive desktop, tablet, and mobile layouts
- Project content preview
- Reduced-motion support

## Files

- `demo.html` — component markup and live demonstration
- `style.css` — complete styling, animations, and responsive rules
