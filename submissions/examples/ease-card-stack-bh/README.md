# ease-card-stack-bh

Physics-based Draggable Card Stack with Spring Return.

## What does this do?
A stacked card UI with hover lift effect and spring-like transitions.

## How is it used?
```html
<div class="ease-card-stack">
  <div class="ease-card-stack-item">Card 1</div>
  <div class="ease-card-stack-item">Card 2</div>
</div>
```

## Features
- Card stack effect
- Hover lift animation
- Spring-like transitions
- CSS-only implementation
