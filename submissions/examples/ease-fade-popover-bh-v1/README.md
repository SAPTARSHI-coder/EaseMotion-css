# ease-fade-popover-bh

Pure CSS fade-in popover for fintech dashboards.

## Features
- Fade-in hover effect
- Popover variants
- Responsive design
- Accessibility support

## Usage
```html
<div class="ease-popover ease-popover-fade">Content</div>
```

## CSS Classes
- `.ease-popover` - Base popover
- `.ease-popover-fade` - Fade-in effect
