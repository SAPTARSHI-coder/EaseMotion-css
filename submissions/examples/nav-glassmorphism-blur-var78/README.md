# Glassmorphism Blur Navigation (nav-glassmorphism-blur-var78)

A smooth, accessible, and performant pure CSS navigation featuring Glassmorphism Blur styling.

### Usage
```html
<nav class="nav-glass-blur-var78">
    <div class="nav-logo">GlassNav</div>
    <ul class="nav-links">
        <li><a href="#" class="nav-link active">Home</a></li>
        <li><a href="#" class="nav-link">About</a></li>
    </ul>
    <div class="nav-actions">
        <button class="nav-btn">Sign In</button>
    </div>
</nav>
```

### Why is it useful?
It provides a modern, premium frosted-glass aesthetic for top-level navigation, fully equipped with smooth hardware-accelerated transitions, interactive hover states, and seamless dark mode compatibility using only native CSS.
