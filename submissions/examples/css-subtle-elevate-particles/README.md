# Subtle Elevate Particle Effect

A smooth, accessible, and performant pure CSS particle effect featuring a subtle upward-elevating motion style.

## Features

- Pure HTML and Vanilla CSS
- Smooth particle elevation
- Soft opacity transitions
- Subtle particle glow
- Dark mode compatible
- Light mode support
- Responsive design
- Hardware-friendly `transform` animations
- No JavaScript required
- No external dependencies
- Keyboard-accessible interactive element
- `prefers-reduced-motion` support
