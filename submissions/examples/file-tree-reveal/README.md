# File Tree Reveal

A project file tree whose folders unfold branch by branch with indented children.

## Features
- Folders and files cascade down the tree
- Branch glyphs pop with a spring
- Highlighted file draws the eye

## Usage
```html
<div class="ft-tree">
  <div class="ft-node"><span class="ft-folder">&#128193; src</span></div>
  <div class="ft-node"><span class="ft-file">&#128196; motion.css</span></div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
