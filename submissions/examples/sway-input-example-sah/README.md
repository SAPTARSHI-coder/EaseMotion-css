# Sway Input Interaction Example (`#54667`)

## What does this do?
Provides a delightful form input wrapping container that gently sways with rotational pendulum physics when users focus into the text field.

## How is it used?
Wrap text inputs inside an `ease-input-sway` parent container configured with optional prefix icons:
```html
<div class="ease-input-sway">
  <input type="text" placeholder="Type here..." />
</div>
```

## Why is it useful?
Solves issue #54667 by giving form inputs a playful, responsive personality during account creation and authentication flows.
