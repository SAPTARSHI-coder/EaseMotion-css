# Scale-Hover Carousel (Fintech Dashboard)

## What does this do?

A modern fintech dashboard carousel featuring interactive cards that smoothly scale on hover. The component highlights financial metrics with a clean glassmorphism design and responsive layout using only HTML and CSS.

---

## Features

- Smooth scale-hover animation
- Glassmorphism card design
- Fintech-inspired dashboard UI
- Hover glow effect
- Responsive layout
- Pure HTML & CSS (No JavaScript)
- Supports `prefers-reduced-motion`

---

## Files

- `demo.html` — Component showcase
- `style.css` — Component styling and animations
- `README.md` — Documentation
