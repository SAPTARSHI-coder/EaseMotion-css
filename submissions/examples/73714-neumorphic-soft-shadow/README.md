# CSS Glass Effect: Neumorphic Soft Shadow

A smooth, accessible, and performant pure CSS glassmorphism component featuring
a Neumorphic Soft Shadow design.

## Features

- Pure HTML and Vanilla CSS
- Neumorphic soft-shadow styling
- Glassmorphism-inspired transparency
- Soft light and dark shadows
- Subtle hover elevation
- Smooth CSS transitions
- Dark mode support
- Responsive layout
- Accessible keyboard focus states
- `prefers-reduced-motion` support
- Hardware-friendly transforms
- No JavaScript
- No external libraries
