# Particle Constellation Background Network with CSS & Canvas

### Vibrant Gradient Version

A modern animated **Particle Constellation Background** built with **HTML5 Canvas**, **HTML5**, and **CSS3**. It features moving particles, dynamic connection lines, vibrant gradients, responsive layout, and accessibility-friendly motion support.

---

## ✨ Features

- HTML5 Canvas particle animation
- Dynamic constellation network
- Vibrant gradient background
- Floating glassmorphism content card
- Responsive mobile-first layout
- Animated gradient CTA button
- CSS Variables for customization
- `prefers-reduced-motion` support
- Pure HTML, CSS & Vanilla JavaScript

---

## 📂 Folder Structure

```text
submissions/

    └── ease-anim-particle-constellation-background-network-with-css-canvas-286/
        ├── demo.html
        ├── style.css
```

---

## 🚀 Usage

Open `demo.html` in any modern browser. No external libraries or build tools are required.
