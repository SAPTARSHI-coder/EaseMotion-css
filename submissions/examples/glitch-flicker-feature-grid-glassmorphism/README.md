# Glitch-Flicker Feature Grid for Glassmorphism UI

A modern futuristic feature grid created using pure HTML and CSS.

This component combines:

- Glassmorphism UI design
- Glitch flicker text animation
- Floating cards
- Neon hover effects
- Responsive grid layout


## Features

✨ Pure HTML & CSS  
✨ No JavaScript dependency  
✨ Smooth CSS keyframe animations  
✨ Glass blur effect  
✨ Responsive across devices  
✨ Reduced motion accessibility support
