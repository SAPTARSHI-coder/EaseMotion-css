# Responsive File Dropzone - Cyberpunk

A responsive cyberpunk-inspired file dropzone built with pure HTML and CSS for EaseMotion CSS.

## ✨ Features

- Cyberpunk visual styling
- Responsive file dropzone
- Neon cyan and pink accents
- Animated scan line
- Glowing upload icon
- Cyberpunk corner decorations
- Interactive browse button
- Upload connection status
- Responsive desktop, tablet, and mobile layouts
- Pure CSS implementation
- Zero external JavaScript dependencies
- Smooth hover and transition effects
- `prefers-reduced-motion` support
