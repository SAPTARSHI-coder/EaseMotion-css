# glow-pricing-switch-v2-ak

Pure CSS animated pricing plan switcher toggle — no JavaScript required.

## How to use

```html
<div class="ease-pricing-switch-container-ak">
  <input type="radio" name="plan" id="m" checked />
  <label for="m" class="ease-pricing-label-ak">Monthly</label>
  <input type="radio" name="plan" id="y" />
  <label for="y" class="ease-pricing-label-ak">Yearly</label>
  <span class="ease-pricing-glider-ak"></span>
</div>
