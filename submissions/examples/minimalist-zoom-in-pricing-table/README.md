# CSS Zoom-In Pricing Table

A modern **CSS Zoom-In Pricing Table** built entirely with **HTML5** and **CSS3**. This showcase demonstrates a clean, responsive pricing table with smooth zoom-in hover animations, minimalist tech styling, and accessibility-friendly interactions—without any JavaScript.

---

## ✨ Features

- 🚀 Pure HTML5 & CSS3
- 🔍 Smooth zoom-in hover animation
- 💳 Three responsive pricing plans
- ⭐ Highlighted featured plan
- 📱 Fully responsive layout
- ♿ Keyboard-accessible buttons with visible focus states
- 🎨 Easy customization using CSS Custom Properties
- 🌙 Supports `prefers-reduced-motion`
- ⚙️ No JavaScript or external libraries

## 🚀 Usage

1. Open `demo.html` in any modern web browser.
2. Hover over a pricing card to view the zoom-in animation.
3. Navigate using the keyboard to test the button focus states.
4. Customize colors, spacing, and typography through the CSS custom properties.

---

## 🎨 CSS Custom Properties

| Variable | Description |
|----------|-------------|
| `--bg` | Page background color |
| `--surface` | Card background |
| `--primary` | Primary accent color |
| `--secondary` | Secondary accent color |
| `--text` | Primary text color |
| `--muted` | Secondary text color |
| `--border` | Card border color |
| `--radius` | Card border radius |
| `--shadow` | Card shadow |
| `--transition` | Transition timing |

Example:

```css
:root{
    --primary:#2563eb;
    --secondary:#38bdf8;
}
```
