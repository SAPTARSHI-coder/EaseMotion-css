# Corkscrew Helix Pull

## What does this do?
Renders a self-contained CSS-only `ease-corkscrew-helix-pull` demo: Wine corkscrew helix twisting then cork extracting.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-corkscrew-helix-pull`. No build step or JavaScript is required for the effect.

```html
<section class="ease-corkscrew-helix-pull">
  <div class="ease-corkscrew-helix-pull__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
