# CSS Skew-Active Progress Bar

A modern animated progress bar featuring a skewed active fill effect for creative portfolio layouts.

## Features

- Pure HTML & CSS
- Skew active animation
- Responsive layout
- CSS Custom Properties
- Lightweight
- Accessible with prefers-reduced-motion

## Folder

```
skew-active-progress-bar/
├── demo.html
├── style.css
└── README.md
```

## Usage

```html
<div class="progress">
    <div class="fill"></div>
</div>
```

Include:

```html
<link rel="stylesheet" href="style.css">
```
