# CSS Tilt Card Grid

A responsive grid of cards featuring a CSS-only 3D tilt hover effect using perspective transforms.

## Features

- Pure CSS implementation
- 3D tilt-on-hover interaction
- Responsive card grid
- Keyboard accessible
- CSS custom properties for easy theming
- No JavaScript required

## Usage

```html
<div class="card-grid">
  <article class="tilt-card">
    <h3>Card Title</h3>
    <p>Card content...</p>
  </article>
</div>
```

## Customization

```css
:root {
  --card-bg: #1e293b;
  --accent: #38bdf8;
}
```
