# CSS Elastic-Slide Card Grid

## Overview

A responsive gaming-inspired card grid with a smooth elastic slide animation built using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Responsive Grid Layout
- Elastic Slide Hover Animation
- CSS Custom Properties
- Accessible (`prefers-reduced-motion`)
- Easy to Customize

## Folder Structure

```text
elastic-slide-card-grid/
├── demo.html
├── style.css
└── README.md
```

## Usage

1. Open `demo.html`.
2. Customize the CSS variables.
3. Integrate into your project.

## CSS Variables

- `--primary`
- `--background`
- `--card`
- `--text`
- `--duration`

## Browser Support

- Chrome
- Firefox
- Edge
- Safari
