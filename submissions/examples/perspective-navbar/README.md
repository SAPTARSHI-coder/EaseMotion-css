# CSS Perspective Navbar

A responsive navigation bar with a smooth 3D perspective hover effect using
pure CSS.

## Features

- Pure CSS implementation
- 3D perspective hover effect
- Smooth transitions
- Keyboard-accessible navigation links
- Responsive layout
- Mobile-friendly navigation
- Reduced-motion support
- No JavaScript dependencies

## Files

- `demo.html` – Component demonstration
- `style.css` – Component styling

## Usage

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
