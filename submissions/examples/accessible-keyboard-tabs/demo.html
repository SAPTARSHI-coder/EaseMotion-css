Accessible keyboard tabs

A tab widget matching the WAI-ARIA APG Tabs pattern: click a tab or focus one and use ← → (or Home/End) to move between them — focus and selection move together, and the sliding indicator follows smoothly.

Arrow-key interception is outside what CSS can do on its own, so this one includes a small, real keydown handler — documented in full in the README rather than pretending a CSS-only trick covers it.
