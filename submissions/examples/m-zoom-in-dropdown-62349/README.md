# CSS Zoom-In Dropdown for Product Catalog Layouts

A modern dropdown component with a smooth zoom-in opening animation built using pure HTML and CSS. Suitable for product catalogs, navigation menus, and category selectors.

## ✨ Features

- Pure HTML5 & CSS3
- Zoom-in dropdown animation
- Responsive layout
- CSS Custom Properties
- Smooth hover effects
- Keyboard accessible using `:focus-within`
- `prefers-reduced-motion` support
- No JavaScript required
