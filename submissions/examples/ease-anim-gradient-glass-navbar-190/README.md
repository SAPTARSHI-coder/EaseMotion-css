# Sticky Blur Glass Navigation Header with Scroll Shrink Effect

### Vibrant Gradient Version

A modern **Sticky Blur Glass Navigation Header** built with **HTML5** and **CSS3**. This component features a glassmorphism navigation bar, vibrant gradient accents, smooth shrink-on-hover interaction, and responsive accessibility-focused design.

---

## ✨ Features

- Sticky glass navigation header
- Vibrant gradient styling
- Blur (glassmorphism) effect
- Smooth shrink animation
- Animated gradient highlight
- Responsive navigation layout
- Keyboard accessibility
- CSS Variables for easy customization
- `prefers-reduced-motion` support
- Pure HTML & CSS implementation

## 🚀 Usage

1. Open the component folder.
2. Keep `demo.html` and `style.css` in the same directory.
3. Open `demo.html` in a modern browser.
4. Hover over the navigation bar and scroll the page to experience the glass blur and smooth shrink interaction.

No external libraries or build tools are required.
