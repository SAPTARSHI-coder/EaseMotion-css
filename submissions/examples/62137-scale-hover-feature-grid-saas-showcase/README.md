# CSS Scale-Hover Feature Grid for SaaS Showcase Layouts

A modern **Scale-Hover Feature Grid** built using pure HTML5 and CSS3 for SaaS showcase layouts. This component creates an interactive feature presentation with smooth scaling effects, hover animations, glassmorphism cards, and responsive grid behavior.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Smooth scale-hover interactions
* Modern SaaS feature card layout
* Animated card elevation effects
* Glassmorphism UI design
* Gradient icon containers
* Shine sweep hover effect
* Responsive grid system
* CSS Custom Properties for easy customization
* Smooth transitions and keyframe animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over feature cards to view the scale and glow interactions.
3. Customize colors, shadows, radius, and animations using CSS variables inside `:root`.

## CSS Custom Properties

```css
:root{
  --bg:#f1f5ff;
  --surface:rgba(255,255,255,.92);
  --primary:#2563eb;
  --secondary:#06b6d4;
  --accent:#8b5cf6;
  --text:#111827;
  --muted:#64748b;
  --shadow:0 20px 55px rgba(37,99,235,.18);
  --radius:28px;
}
```
