# Pretzel Dough Twister

## What does this do?
Renders a self-contained CSS-only `ease-pretzel-dough-twister` demo: Pretzel dough twisting into classic knot shape.

## How is it used?
Open `demo.html` in a browser. The animated face uses classes like `ease-pretzel-dough-twister`, `ease-pretzel-dough-twister__arm`, and `ease-pretzel-dough-twister__core`. No build step or JavaScript is required for the motion.

```html
<section class="ease-pretzel-dough-twister">
  <div class="ease-pretzel-dough-twister__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
