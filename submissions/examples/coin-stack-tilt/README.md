# Coin Stack Tilt

Coins stack up and wobble with a toppling tease.

## Features
- Coin stack build
- Wobble animation
- Edge-shine accent
- Pure CSS

## Usage
```html
<div class="cst-coin" style="--i:0"></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
