# ease-mountain-cable-car
A gondola line across an alpine pass with two steel towers, a shimmering cable, and gondolas that glide and swing along the route.
## Run
Open `demo.html` directly in a browser to see the gondola movement.
## Notes
- The lead gondola swings gently while the second gondola shuttles along the cable.
- The tower trellis and status lamp reinforce the alpine transport look.
