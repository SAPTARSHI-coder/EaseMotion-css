# glow-accordion-v7-ak

Pure CSS animated glowing neon border accordion drawer component — no JavaScript required.

## How to use

```html
<div class="ease-accordion-v7">
  <input type="checkbox" id="item1" class="ease-accordion-checkbox-v7" />
  <div class="ease-accordion-item-v7">
    <label for="item1" class="ease-accordion-header-v7">
      <span>Header</span>
      <span class="ease-accordion-icon-v7">▼</span>
    </label>
    <div class="ease-accordion-drawer-v7">
      <div class="ease-accordion-body-v7">Content</div>
    </div>
  </div>
</div>
