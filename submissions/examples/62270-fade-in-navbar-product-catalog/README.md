# CSS Fade-In Navbar for Product Catalog Layouts

A modern **Fade-In Navbar** built using pure HTML5 and CSS3 for product catalog layouts. The component features a smooth fade-in entrance animation, responsive navigation links, integrated search bar, shopping cart button, and accessibility support.

## Features

* Pure HTML5 & CSS3
* Fade-In navbar entrance animation
* Responsive navigation layout
* Glassmorphism navbar design
* Product search input
* Shopping cart action button
* Smooth hover transitions
* Sticky navigation bar
* CSS Custom Properties
* No JavaScript required
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Customize navigation links, logo, and search placeholder as needed.
3. Modify colors, spacing, and animations using the CSS variables defined in `:root`.
4. Integrate the navbar into any product catalog or e-commerce application.
