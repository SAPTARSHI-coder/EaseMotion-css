# Cyclone Classifier Spin

## What does this do?
Renders a self-contained CSS-only `ease-cyclone-classifier-spin` demo: Cyclone classifier spinning a vortex finder.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-cyclone-classifier-spin`. No build step or JavaScript is required for the effect.

```html
<section class="ease-cyclone-classifier-spin">
  <div class="ease-cyclone-classifier-spin__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
