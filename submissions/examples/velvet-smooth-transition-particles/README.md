# Velvet Smooth Transition Particles

A rich, accessible, and performant pure CSS particle effect featuring Velvet Smooth Transition styling.

## What does this do?
This component provides a premium "velvet smooth" floating particle effect featuring deep rich colors entirely through HTML and Vanilla CSS without relying on JavaScript or Canvas.

## How is it used?

```html
<div class="velvet-container">
  <div class="particle-velvet-smooth-transition-1"></div>
  <div class="particle-velvet-smooth-transition-2"></div>
  <div class="particle-velvet-smooth-transition-3"></div>
  <!-- Add as many particles as needed -->
</div>
```

## Why is it useful?
It uses hardware-accelerated transforms (`translate3d`, `scale`, `rotate`) and CSS `will-change` to ensure perfectly smooth frame rates. It automatically adapts to dark and light modes through CSS media queries, fitting perfectly into the EaseMotion CSS philosophy of high-performance, accessible, and declarative animations.
