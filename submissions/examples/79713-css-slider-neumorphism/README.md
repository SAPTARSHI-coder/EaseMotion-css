# CSS-only Slider — Neumorphism

A responsive CSS-only range slider featuring a soft
neumorphic interface, inset track depth, raised thumb,
and accessible keyboard interaction.

Implemented for issue #79713.

## Features

- Neumorphic visual styling
- Native HTML range input
- Soft raised thumb
- Inset slider track
- Smooth hover interaction
- Active thumb feedback
- Responsive layout
- Keyboard accessible
- Focus-visible styling
- Reduced-motion support
- No JavaScript
- No external dependencies
