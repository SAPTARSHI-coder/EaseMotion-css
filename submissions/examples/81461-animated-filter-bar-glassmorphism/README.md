# Animated Filter Bar — Glassmorphism

A responsive Animated Filter Bar created for EaseMotion CSS
using a modern glassmorphism visual style.

The component combines translucent surfaces, backdrop blur,
gradient ambient lighting, animated filter controls, and
responsive layouts while remaining completely CSS-driven.

## Features

- Glassmorphism visual styling
- Translucent filter container
- Backdrop blur
- Gradient ambient background
- Animated floating background orbs
- Animated filter controls
- Active filter state
- Hover elevation effects
- Animated filter icons
- Responsive filter wrapping
- Responsive result cards
- Pure CSS abstract artwork
- Keyboard focus states
- `prefers-reduced-motion` support
- Semantic HTML
- Zero external JavaScript dependencies
- No external assets
