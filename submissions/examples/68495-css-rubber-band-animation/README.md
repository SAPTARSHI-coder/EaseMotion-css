# CSS Rubber Band Animation

A reusable CSS motion demo where elements stretch and snap back with a rubber-band effect.

## Features

- Elastic stretch animation
- Hover and focus triggers
- Multiple sample targets
- Responsive layout
- Reduced-motion support
- No JavaScript

## Files

- `demo.html` — sample interactive elements
- `style.css` — elastic keyframes, states, layout, and responsive rules

## Accessibility

Interactive targets use native controls and visible focus styles. The animation is disabled for reduced-motion preferences.
