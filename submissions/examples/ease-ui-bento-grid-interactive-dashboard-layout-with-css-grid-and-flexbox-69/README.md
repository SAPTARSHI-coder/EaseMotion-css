# Bento Grid Interactive Dashboard Layout with CSS Grid and Flexbox

## Overview

A minimalist clean dashboard component built with CSS Grid and Flexbox.
It provides a modern bento-style layout with interactive cards and
smooth animations.

## Features

- 📊 Bento grid dashboard layout
- 🎨 Clean minimalist design
- ✨ Interactive card animations
- 📱 Responsive grid system
- ⚡ CSS Grid and Flexbox implementation
- 🌈 Gradient UI elements
- 🖱️ Smooth hover interactions

## Usage

1. Open `demo.html` in a browser.
2. Explore dashboard cards.
3. Click "Animate Cards" for interaction effects.
