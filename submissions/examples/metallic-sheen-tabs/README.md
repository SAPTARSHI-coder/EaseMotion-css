# Metallic Sheen Tabs

A modern pure CSS segmented tab component featuring a polished metallic finish and animated sheen effect.

## Features

- Pure HTML & CSS
- Metallic gradient styling
- Animated sheen hover effect
- Smooth transitions
- Active tab indicator
- Responsive layout
- Dark mode compatible
- Hardware accelerated animations
- No JavaScript required
