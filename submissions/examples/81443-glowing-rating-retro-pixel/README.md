# Glowing Rating — Retro Pixel

A responsive glowing rating component with a retro
arcade/pixel-inspired visual style, implemented entirely
with HTML and CSS for EaseMotion CSS issue #81443.

## Features

- Retro pixel-inspired visual design
- Neon cyan and magenta accents
- Glowing five-star rating
- Pixel-style stepped animations
- Animated rating bars
- Arcade-inspired status indicator
- Subtle scanline effect
- Hover elevation and glow
- Responsive desktop, tablet and mobile layouts
- `prefers-reduced-motion` support
- Zero JavaScript dependencies
