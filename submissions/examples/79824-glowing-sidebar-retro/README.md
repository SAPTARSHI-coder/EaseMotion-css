# Glowing Sidebar with Retro Styling

A responsive retro-inspired sidebar component built with pure HTML and CSS.

The component combines glowing neon accents, pixel-inspired UI details, responsive navigation, and smooth hover interactions.

## ✨ Features

- Retro-inspired sidebar design
- Neon glowing effects
- Fully responsive layout
- CSS-only mobile sidebar toggle
- No external JavaScript dependencies
- Interactive navigation states
- Profile/status section
- Mission progress panel
- Responsive dashboard layout
- `prefers-reduced-motion` support
- Modern CSS transitions
