# Orbit Testimonial Cards

This submission demonstrates a modern testimonial section built with
**EaseMotion CSS**. It includes animated testimonial cards, hover lift
effects, star ratings, avatar badges, and responsive grid layout.

## 🌟 Features

- **Testimonial cards** with rating, quote, avatar, name, and role.
- **Staggered entrance animation** using `ease-slide-up` and delay utilities.
- **Hover lift effect** using `ease-hover-lift`.
- **Responsive grid layout** for desktop, tablet, and mobile.
- **Custom orbit-style dark theme** using original CSS.
- **Reduced motion support** for users who prefer less animation.

## 📁 Files

- `demo.html` — interactive testimonial cards demo
- `style.css` — original orbit testimonial styling
- `README.md` — documentation for this submission

## 🛠️ How to Run

1. Open `demo.html` in your browser.
2. Watch the testimonial cards enter with staggered animation.
3. Hover over the cards to see the lift effect.
4. Resize the browser window to check responsive behavior.

## 🧩 EaseMotion Classes Used

- `ease-delay-100`
