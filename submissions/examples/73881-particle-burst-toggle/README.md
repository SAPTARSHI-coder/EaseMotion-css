# Particle Burst Toggle (#73881)

A pure HTML & Vanilla CSS toggle featuring a radial particle burst animation on state transition.

## Features
- **Aesthetic:** Dynamic radial particle burst expanding outwards upon toggle check.
- **Pure CSS:** Zero JavaScript dependencies; utilizes CSS state selectors and keyframes.
- **Performance:** Hardware-accelerated transitions leveraging `transform` and `opacity`.
- **Accessibility:** Keyboard focus ring support via `:focus-visible` and `@media (prefers-reduced-motion: reduce)` support.
