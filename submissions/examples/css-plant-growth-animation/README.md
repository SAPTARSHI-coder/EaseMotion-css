# CSS Plant Growth Animation

A pure CSS plant growth animation created for the EaseMotion CSS library.

## Features

- Pure HTML and CSS
- No JavaScript required
- Plant grows automatically on page load
- Animated stem and leaves
- Responsive design
- Supports `prefers-reduced-motion`
- Lightweight and easy to customize

## Files

- `demo.html` - Demo page
- `style.css` - Plant styling and animations

## How It Works

The animation uses CSS keyframes to create the plant growth effect.
