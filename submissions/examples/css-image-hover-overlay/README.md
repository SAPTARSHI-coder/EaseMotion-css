# CSS Image Hover Overlay

A responsive image card featuring a colored overlay with animated text and button that appear on hover.

## Features

- Smooth hover overlay
- Fade-in text animation
- Image zoom effect
- Responsive card layout
- Accessible image markup
- Pure HTML & CSS
- No JavaScript required

## Folder Structure

```
css-image-hover-overlay/
├── demo.html
├── style.css
└── README.md
```

## Technologies

- HTML5
- CSS3
- CSS Grid
- CSS Transitions
- Flexbox

## Purpose

Provides a reusable image hover overlay component suitable for portfolios, galleries, blogs, and landing pages while maintaining EaseMotion CSS's lightweight, animation-first philosophy.
