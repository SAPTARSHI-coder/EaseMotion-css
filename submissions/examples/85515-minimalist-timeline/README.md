# Dynamic Vertical Timeline — Minimalist

A clean, lightweight vertical timeline built with pure HTML and CSS.

The component follows a minimalist visual approach using generous whitespace,
thin borders, restrained typography, subtle interactions, and a focused
monochrome design system.

## Features

- Minimalist visual design
- Dynamic progress indicator
- Completed, current, and upcoming states
- Thin vertical timeline rail
- Subtle hover interactions
- Responsive desktop, tablet, and mobile layouts
- CSS custom properties for theming
- `prefers-reduced-motion` support
- Semantic timeline markup
- Pure HTML and CSS
- No JavaScript
