# CSS Bounce-Pulse Modal for Product Catalog Layouts

A modern **HTML5 & CSS3** product catalog featuring a **Bounce-Pulse Modal** animation. Clicking **Quick View** opens a responsive modal with a smooth bounce and pulse entrance effect, providing detailed product information without using JavaScript.

---

## ✨ Features

- Pure HTML5 & CSS3
- Bounce-Pulse modal animation
- Responsive product catalog
- Modern UI design
- CSS Custom Properties
- No JavaScript required
- Accessible with `prefers-reduced-motion`
- Lightweight and reusable
