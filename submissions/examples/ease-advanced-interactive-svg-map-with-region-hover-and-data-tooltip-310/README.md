#Interactive SVG map with region hover and data tooltip
Interactive SVG map visualization componenet featuring region hover and highlighting and dynamic cursor-following tooltips

## features
** SVG path styling
**Dyanamic tooltip tracking 
**Data attribute Integration

## usage
Include "style.css" in your project documents.
Embed the SVG map structure with 'data-*' attributes on "<path class = "map-region">" elements.
