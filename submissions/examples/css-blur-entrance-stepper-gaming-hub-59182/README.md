# CSS Blur-Entrance Stepper for Gaming Hub Layouts

A modern **Blur-Entrance Stepper** built using pure HTML and CSS for gaming hubs, onboarding flows, player progression, and achievement tracking.

## Features

* Pure HTML5 & CSS3
* Blur entrance animation
* Smooth step reveal sequence
* Gaming-inspired UI
* Fully responsive layout
* CSS custom properties
* No JavaScript required
* Supports `prefers-reduced-motion`

## Folder Structure

```text
css-blur-entrance-stepper-gaming-hub-59182/
├── demo.html
├── style.css
└── README.md
```

## Usage

1. Open `demo.html` in any modern browser.
2. Edit the step titles and descriptions.
3. Customize colors using the CSS variables in `:root`.
4. Adjust animation timing by modifying the animation delays.
