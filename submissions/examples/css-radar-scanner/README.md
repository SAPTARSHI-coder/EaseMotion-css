# CSS Radar Sweep Scanner

A classic radar screen animation utilizing `conic-gradient` for the sweeping beam and timed `@keyframes` to make target blips appear precisely as the scanner passes them.

## Features
- Circular grid patterns with repeating radial gradients
- `conic-gradient` rotating sweep animation
- Timed blinking keyframes for target blips
