# Neumorphic Soft Shadow Dashboard Widget

A smooth and responsive dashboard widget featuring a **Neumorphic Soft Shadow**
design using pure HTML and Vanilla CSS.

## Features

- 🎨 Neumorphic soft-shadow interface
- 📊 System health dashboard
- 💻 CPU, RAM, storage and network statistics
- 📈 Animated performance chart
- 🔄 Interactive refresh button
- 🌙 Automatic dark mode support
- ⚡ CSS-only animations
- ♿ Reduced-motion accessibility support
- 📱 Responsive design
- 🚫 No JavaScript
- 🚫 No external dependencies
