# Bounce-On-Hover Icon

A lightweight icon interaction with a short directional bounce on hover
or keyboard focus.

## What does it do?

The component provides:

- Short icon bounce animation.
- Hover interaction.
- Keyboard focus interaction.
- Subtle parent lift.
- Circular icon presentation.
- Responsive layout.
- Reduced-motion support.
- No JavaScript.
- No external libraries or assets.

## How do I use it?

Add the `ease-bounce-icon` class to an interactive element:

```html
<a class="ease-bounce-icon" href="#">
  <span>Open</span>
  <span class="ease-bounce-icon__symbol" aria-hidden="true">→</span>
</a>
```
