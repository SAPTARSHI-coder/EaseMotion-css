# Neumorphic Pagination with Pastel styling (#78884)

A fully responsive tactile pagination component featuring soft neumorphic double-shadow extrusions, inset pressed active states, and pastel highlights built using pure CSS.

## Features
- **Semantic Structure:** Accessible `<nav>` and list elements with explicit `aria-current="page"` markers.
- **Neumorphic Soft UI:** Extruded double box-shadow effects (`#b8c2d0` and `#ffffff`) with inset active states.
- **Pastel Accents:** Soft lavender active button background tinting paired with dark purple typography.

## File Hierarchy
- `style.css` - Component tokens, dual shadow calculations, and active inset states.
- `demo.html` - Semantic HTML structure showcasing pagination control.
- `README.md` - Technical specification and usage guidelines.
