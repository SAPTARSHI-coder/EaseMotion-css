# 🎨 Watercolor Spread – Colors Bleed Like Watercolor

> An organic watercolor component where colors bleed and spread across the canvas with fluid, artistic effects.

---

## 📖 Description

The **Watercolor Spread** component creates an organic watercolor painting experience where colors bleed and spread across the canvas with fluid, artistic effects. Built with vanilla HTML, CSS, and JavaScript, it features canvas-based rendering, color blending, and interactive controls.

### 🎯 Core Features

- **Watercolor bleed** – colors spread organically like real watercolor
- **5 color styles** – Dreamy, Ocean, Sunset, Forest, Galaxy
- **Canvas rendering** – smooth, artistic color blending
- **Multiple blobs** – 5-10 color blobs spread on each click
- **Organic animation** – blobs expand with fluid motion
- **Real-time status** – shows spread count and current style
- **Interactive controls** – buttons, click on canvas, keyboard shortcuts
- **Responsive design** – adapts to different screen sizes

### 🎨 Color Styles

| Style | Colors | Description |
|-------|--------|-------------|
| **Dreamy** | Purple/Blue/Pink/Green/Gold | Soft, dreamy palette |
| **Ocean** | Blue/Cyan | Cool ocean tones |
| **Sunset** | Red/Orange/Gold | Warm sunset vibes |
| **Forest** | Green | Natural forest tones |
| **Galaxy** | Purple/Pink/Blue | Cosmic galaxy palette |

### ⌨️ Interaction Options

| Method | Action |
|--------|--------|
| **Click** | Click on display to spread colors |
| **Buttons** | Spread Color, Toggle Style, Reset |
| **Keyboard** | `Space` or `S` – Spread · `T` – Style · `R` – Reset |

### ✨ Spread Experience

When spreading:
1. **Blobs appear** – 5-10 color blobs emerge
2. **Colors bleed** – colors spread organically outward
3. **Layers blend** – multiple layers create watercolor depth
4. **Canvas renders** – smooth, artistic color blending
5. **Counter updates** – spread count increments

### 🛠️ Technologies Used

- **HTML5** – semantic structure with Canvas
- **CSS3** – animations, gradients, blur effects
- **JavaScript (ES6)** – Canvas API, requestAnimationFrame, particle system

### 🎨 Design Philosophy

This component embodies **EaseMotion CSS's animation-first philosophy** through:

- **Organic animation** – colors spread with fluid motion
- **Canvas rendering** – smooth, artistic color blending
- **Visual feedback** – status updates, counter, color changes
- **Artistic atmosphere** – soft, blended colors with blur effects
- **Human-readable classes** – `.blob`, `.watercolor-text`, `.spread-counter`

### 🔧 Customization Options

| Property | Location | Default |
|----------|----------|---------|
| Color styles | `styles` array | 5 styles |
| Blob count | `numBlobs` | 5-10 |
| Spread speed | `blob.speed` | 0.01-0.03 |
| Blob size | `size` variable | 30-100px |
| Canvas rendering | `renderWatercolor()` | 5 layers per blob |
