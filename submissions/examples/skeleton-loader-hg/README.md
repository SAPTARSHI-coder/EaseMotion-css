# Skeleton Loading Utility (`.em-skeleton`)

Pre-built lightweight utilities for skeleton loading animation states in **EaseMotion-css**.

## Features
- `.em-skeleton` - Core base styling for skeleton blocks.
- `.em-skeleton-shimmer` - Continuous moving linear-gradient background effect.
- `.em-skeleton-pulse` - Fading pulse opacity animation effect.

## Usage

```html
<link rel="stylesheet" href="style.css">

<!-- Shimmer Text Line -->
<div class="em-skeleton em-skeleton-shimmer" style="height: 1rem; width: 80%;"></div>

<!-- Circular Avatar Skeleton -->
<div class="em-skeleton em-skeleton-circle em-skeleton-shimmer"></div>
