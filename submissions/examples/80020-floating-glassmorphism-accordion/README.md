# Floating Glassmorphism Accordion (Lite)

A clean and responsive floating accordion component built with a
modern glassmorphism visual style.

The component uses native HTML `details` and `summary` elements,
so it provides accordion functionality without JavaScript.

## Features

- Floating glassmorphism cards
- Frosted glass effect
- Background blur
- Soft translucent surfaces
- Gradient ambient background
- Smooth hover interactions
- Expand/collapse animation
- Plus/minus indicator
- Responsive layout
- Keyboard-accessible native controls
- Reduced-motion support
- No JavaScript
- No external dependencies
