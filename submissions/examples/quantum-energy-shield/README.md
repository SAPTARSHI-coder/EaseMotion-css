# CSS Modal: Quantum Energy Shield

A futuristic pure HTML and Vanilla CSS modal featuring a
Quantum Energy Shield visual style.

## Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Quantum energy core
- Animated energy rings
- Floating energy particles
- Neon cyan and purple glow effects
- Smooth modal transitions
- Dark-mode-friendly appearance
- Responsive layout
- Accessible dialog markup
- Keyboard focus states
- Reduced-motion support
- Hardware-accelerated transforms
