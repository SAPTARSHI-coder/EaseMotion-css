# Glowing Avatar with Retro styling (#78881)

A responsive retro-styled user avatar component featuring synthwave gradient borders, continuous multi-stop neon glowing animation, and an online status marker built using pure CSS.

## Features
- **Semantic Structure:** Accessible HTML markup (`<main>`, `<h1>`, `<h2>`, `<img>` with meaningful `alt` text).
- **80s Synthwave Palette:** Vibrant combination of hot pink, cyan, and neon yellow variables.
- **Pulsing Neon Glow:** CSS keyframe scale and box-shadow animation creating continuous ambient illumination.

## File Hierarchy
- `style.css` - Component variables, gradient border calculations, pulsing animation, and typography.
- `demo.html` - Semantic DOM showcase structure.
- `README.md` - Implementation details and component specification.
