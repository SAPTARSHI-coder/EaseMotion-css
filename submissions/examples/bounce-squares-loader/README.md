# Bounce Squares Loader

A 2x2 grid of rounded squares bounces in a diagonal wave, then rests.

## Features
- Grid layout with per-cell animation delays creates a diagonal pulse
- Rounded squares pop with a soft indigo fill
- Waves travel in both axes for depth

## Usage
```html
<div class="bs-grid" role="status" aria-label="Loading">
  <span></span><span></span><span></span><span></span>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
