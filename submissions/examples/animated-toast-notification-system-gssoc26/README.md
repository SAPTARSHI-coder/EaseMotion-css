# Animated Toast Notification System Component

A multi-state Toast Notification component system featuring slide-in physics entrance animations, status variants (success, warning, error), and auto-dismiss countdown timer progress bars.

## What does this do?
Provides responsive feedback toast cards with custom state styling, smooth entrance transform keyframes, and shrinking countdown progress bars.

## How is it used?
1. Open `demo.html` to preview the toast notification stack.
2. Incorporate `.toast` elements into your notification container or global alert service.
3. Import `style.css` for entry keyframe animations and timer progress bar styles.

## Why is it useful?
Toast alerts communicate system state changes clearly to users. Hardware-accelerated CSS keyframe animations ensure smooth entry and progress countdown without blocking application logic.
