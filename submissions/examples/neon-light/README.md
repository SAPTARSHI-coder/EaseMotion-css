# CSS Neon Light Tubes

A demo project showcasing glowing neon light tubes using **HTML and CSS**.

## Features
- Neon glowing tubes with different colors.
- Flickering neon title effect.
- Pulsing animation to simulate radiant light tubes.
- Responsive flexbox layout.

## Files
- `demo.html` → Structure with title, neon tubes, and caption.
- `style.css` → Neon glow styles, animations, and layout.
- `README.md` → Documentation and usage instructions.

## Usage
1. Open `demo.html` in your browser.
2. Observe the glowing neon tubes and flickering title.
3. Customize tube colors by editing the `.tube-*` classes in `style.css`.

## Customization Ideas
- Add more tubes with different neon colors.
- Adjust animation speed for faster or slower pulses.
- Use gradients for multi‑color neon tubes.
- Create interactive effects (hover to brighten, click to toggle glow).
