# CSS Ripple-Wave Progress Bar for Gaming Hub Layouts

A modern **Ripple-Wave Progress Bar** built using pure HTML and CSS for gaming hubs, achievement trackers, player progression, and XP dashboards.

## Features

* Pure HTML5 & CSS3
* Animated ripple-wave progress effect
* Smooth CSS keyframe animations
* Gaming-inspired neon styling
* Fully responsive layout
* CSS custom properties
* No JavaScript required
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Change the progress percentage by modifying the `.progress-fill` width.
3. Customize colors using the CSS variables in `:root`.
4. Update the status text and labels according to your project.
