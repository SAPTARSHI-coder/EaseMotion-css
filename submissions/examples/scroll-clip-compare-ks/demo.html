Technique 1

Horizontal
Slide Reveal

clip-path: inset(0 calc(100% - var(--reveal)) 0 0) reveals the overlay image from left to right as the comparison panel enters the viewport. The @property registration for <percentage> enables smooth clip-path animation — impossible with standard CSS transitions.

CSS APIs Used

The modern CSS primitives powering scroll-driven clip reveals
API Role Support
clip-path Defines a clipping region that reveals or hides portions of the overlay image Chrome 55+, Safari 9.1+, Firefox 54+
@property Registers --reveal as <percentage> for smooth interpolation inside clip-path values Chrome 85+, Safari 16.4+, Firefox 128+
animation-timeline: view() Links clip-path animation progress to element visibility within the scroll container Chrome 115+, Safari 18+
animation-range Controls the scroll range where the reveal animation is active Chrome 115+, Safari 18+

In browsers without animation-timeline support, static fallback clip-path values show each comparison at a fixed reveal position. The images remain visible and the layout is functional everywhere.
