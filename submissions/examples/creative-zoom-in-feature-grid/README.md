# CSS Zoom-In Feature Grid for Creative Portfolio Layouts

A modern **Creative Portfolio Feature Grid** built entirely with **HTML5 and CSS3**. This showcase demonstrates elegant **Zoom-In** animations with glassmorphism styling, responsive layouts, and accessibility-friendly interactions without requiring JavaScript.

---

## ✨ Features

- 🎨 Creative Portfolio inspired feature grid
- 🔍 Zoom-In reveal animation
- ✨ Smooth hover interactions
- 🌈 Gradient feature icons
- 🪟 Glassmorphism cards
- 📱 Fully responsive
- ⚡ Pure HTML5 & CSS3
- 🎯 CSS Custom Properties
- ♿ `prefers-reduced-motion` support
- 🚀 No JavaScript required

## 🚀 Getting Started

1. Open `demo.html` in any modern browser.
2. Watch the Zoom-In reveal animation as the cards appear.
3. Hover over each card to explore interactive effects.
4. Customize colors, spacing, and animation timing using CSS variables.

## 🎨 CSS Custom Properties

```css
:root{
    --bg:#070b16;
    --card:rgba(17,24,39,.88);
    --primary:#00e5ff;
    --secondary:#7c3aed;
    --text:#ffffff;
    --muted:#cbd5e1;
    --border:rgba(255,255,255,.08);
```
