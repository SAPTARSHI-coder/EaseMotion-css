# CSS Spring Physics Tabs — Dashboard Analytics

A pure CSS animated tabs component designed for dashboard and analytics interfaces.

The component uses a spring-like easing curve and lightweight panel transitions to create a responsive, polished interaction without JavaScript.

## Features

- Pure HTML and CSS
- No JavaScript
- Spring-style tab interaction
- Responsive dashboard layout
- Keyboard accessible tab controls
- Customizable animation timing
- Customizable easing
- Customizable active-tab scale
- Reduced-motion support
- Self-contained demo
