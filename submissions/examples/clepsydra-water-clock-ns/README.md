# Clepsydra Water Clock

## What does this do?
Renders a self-contained CSS-only `ease-clepsydra-water-clock` demo: Ancient water clock dripping into a rising float chamber.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-clepsydra-water-clock`. No build step or JavaScript is required for the effect.

```html
<section class="ease-clepsydra-water-clock">
  <div class="ease-clepsydra-water-clock__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
