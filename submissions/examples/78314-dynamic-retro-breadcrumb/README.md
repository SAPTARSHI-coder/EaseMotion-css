# Dynamic Breadcrumb with Retro Styling

A responsive breadcrumb navigation component featuring a
retro-inspired visual style.

The component uses only HTML and CSS and does not require
JavaScript.

## Features

- Pure HTML and CSS
- No JavaScript dependency
- Responsive breadcrumb navigation
- Retro arcade-inspired styling
- Chunky borders and offset shadows
- Interactive hover effects
- Pressed link interaction
- Distinct current-page state
- Horizontal overflow support on small screens
- Keyboard focus support
- Reduced-motion accessibility support

## Files

- `demo.html` — breadcrumb markup and demo page
- `style.css` — complete component styling

## Usage

Open `demo.html` directly in a browser.

The navigation uses semantic `<nav>`, `<ol>` and `<li>`
elements and exposes the current page using `aria-current="page"`.

## Customization

CSS custom properties are defined at the beginning of
`style.css`.

You can easily modify:

- Colors
- Shadows
- Border sizes
- Spacing
- Typography

## Accessibility

The component includes:

- Semantic breadcrumb navigation
- `aria-label="Breadcrumb"`
- `aria-current="page"`
- Keyboard-visible focus states
- Reduced-motion support
- Horizontal scrolling for narrow screens
