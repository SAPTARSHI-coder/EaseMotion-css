# Shimmering Metallic Foil Text Effect

## High-Contrast Accessibility Edition

A modern metallic foil text animation component created using CSS masking,
animated gradients, and smooth transitions.

This component provides a high contrast visual experience with readable
typography and strong accessibility-focused colors.

## Features

- ✨ Animated metallic shimmer effect
- 🎨 CSS gradient text masking
- 🌈 Smooth foil reflection animation
- 🖱️ Interactive 3D mouse movement
- ♿ High contrast color palette
- 📱 Responsive mobile layout
- ⚡ Pure HTML, CSS and JavaScript

## Usage

1. Open `demo.html` in your browser.
2. Move the cursor to see the interactive effect.
3. Customize colors and animations in `style.css`.
