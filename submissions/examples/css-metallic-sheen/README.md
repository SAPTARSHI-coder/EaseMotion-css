# Metallic Sheen Background

A smooth and performant **Metallic Sheen** background animation built using only HTML and Vanilla CSS.

## Features

- Pure HTML and CSS
- Animated metallic light sweep
- Smooth transitions
- Dark-mode friendly visual
- Responsive layout
- Hardware-friendly `transform` animations
- No external JavaScript
- `prefers-reduced-motion` accessibility support

## Files

- `demo.html` - Demo markup
- `style.css` - Metallic sheen animation and styling

## Usage

Open `demo.html` in a modern browser to view the effect.

## Accessibility

The animation respects the user's `prefers-reduced-motion` preference and disables continuous motion when reduced motion is requested.
