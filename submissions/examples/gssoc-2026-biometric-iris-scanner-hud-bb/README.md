# Biometric Iris Scanner HUD - GSSoC 2026

A sci-fi biometric iris scanner HUD component featuring counter-rotating concentric rings, sweeping laser lines, and glowing telemetry text.

## 1. What does this do?
It renders a futuristic biometric iris authentication scanner animation complete with rotating target reticles and vertical laser sweep.

## 2. How is it used?
Link `style.css` in your HTML document and insert `.scanner-card` containing concentric `.scanner-ring` elements.

## 3. Why is it useful?
It provides immersive visual feedback for security dashboards, auth screens, and gaming interfaces without any JavaScript dependencies.
