# Magnetic Floating Action Navigation Bar

A modern neumorphic floating navigation component featuring magnetic
hover interactions and a fluid active-state indicator.

## Features

- Neumorphic UI design
- Magnetic cursor-following interaction
- Fluid navigation indicator
- Smooth hover animations
- Responsive mobile-first layout
- Keyboard accessible navigation
- Reduced-motion support
- Pure HTML, CSS and JavaScript
- No external dependencies
