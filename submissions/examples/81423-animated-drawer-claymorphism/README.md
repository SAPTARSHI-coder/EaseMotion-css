# Animated Drawer - Claymorphism

A responsive animated navigation drawer featuring a soft
Claymorphism visual style.

The component is implemented using pure HTML and CSS,
with no external JavaScript dependencies.

## Features

- Claymorphism-inspired UI
- Animated slide-in drawer
- CSS-only drawer interaction
- Responsive layout
- Mobile-friendly navigation
- Soft neumorphic/clay-style shadows
- Active navigation state
- Hover interactions
- Profile section
- Workspace upgrade card
- Smooth drawer and interaction transitions
- Keyboard focus states
- `prefers-reduced-motion` support
- Zero external JavaScript dependencies
