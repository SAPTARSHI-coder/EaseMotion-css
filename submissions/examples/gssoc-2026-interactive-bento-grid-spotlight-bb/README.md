# Interactive Bento Grid Spotlight Showcase

A responsive, high-performance **Bento Grid** component featuring dynamic cursor-following spotlight glow and 3D hover micro-interactions.

## 🌟 Key Features

- **Radial Cursor Spotlight**: Calculates mouse tracking CSS variables (`--mouse-x`, `--mouse-y`) for smooth lighting effect.
- **Fluid Layout**: Auto-adapts from multi-column grid layout to single-column on mobile viewports.
- **Glassmorphism Base**: Built using dark theme contrast tokens and subtle backdrop blur filters.

## 🚀 Usage

Open `demo.html` in your browser.
