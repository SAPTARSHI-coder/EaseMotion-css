# CSS Glass Effect: Morphing Shape

A modern glassmorphism UI component featuring a smooth animated
morphing shape using pure HTML and CSS.

## ✨ Features

- Pure HTML and Vanilla CSS
- Glassmorphism effect
- Animated organic morphing shape
- Smooth CSS keyframe animations
- Responsive layout
- Dark-mode friendly design
- Hardware-friendly transforms
- Keyboard focus support
- Accessible semantic structure
- `prefers-reduced-motion` support
- No JavaScript
- No external dependencies
