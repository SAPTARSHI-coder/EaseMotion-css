# Coordinated Omission Profiler

An advanced EaseMotion example for monitoring distributed Profiler Reprofilers, histogram debt, retry pressure, and Retention margin recovery.

## Features

- Interactive controls for profiler risk, histogram debt, retry pressure, and Retention margin health.
- Animated radar, Histogram lanes, recovery metrics, Reprofiler timeline, decision matrix, and audit profiler.
- State-driven stable, watch, Profiler, and recovered modes.
- Responsive CSS-only dashboard built with `demo.html`, `style.css`, and this `README.md`.
