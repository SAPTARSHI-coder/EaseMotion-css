# Minimalist Outline Toggle (#73884)

A pure HTML & Vanilla CSS toggle featuring a clean, high-contrast minimalist outline transition.

## Features
- **Aesthetic:** Clean monochrome outline style with crisp border transitions.
- **Pure CSS:** Zero JavaScript dependencies; relies strictly on standard CSS checkbox selectors.
- **Performance:** Hardware-accelerated transitions using `transform` and `border-color`.
- **Accessibility:** Keyboard focus ring support via `:focus-visible` and `@media (prefers-reduced-motion: reduce)` support.
