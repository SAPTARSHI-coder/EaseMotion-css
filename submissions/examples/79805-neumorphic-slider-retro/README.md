# Neumorphic Slider - Retro

A responsive range slider with a retro-inspired neumorphic interface.

## Features

- Neumorphic design
- Retro visual styling
- Interactive range control
- Live value display
- Smooth thumb interaction
- Responsive layout
- Keyboard focus support
- Reduced-motion support
- No external dependencies

## Files

- `demo.html` - Demo and component markup
- `style.css` - Component styling

## Usage

Open `demo.html` in a modern browser.

The slider value updates dynamically as the user moves the control.

## Accessibility

The slider uses a native range input with a semantic accessible label and visible keyboard focus styling.
