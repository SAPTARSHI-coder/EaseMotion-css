# glow-tabs-ak

Pure CSS animated sliding tab menu with neon glowing pill glider — no JavaScript required.

## How to use

```html
<div class="ease-glow-tabs">
  <input type="radio" name="tabs" id="tab1" checked />
  <label for="tab1" class="ease-glow-tab-label">Tab 1</label>

  <input type="radio" name="tabs" id="tab2" />
  <label for="tab2" class="ease-glow-tab-label">Tab 2</label>

  <span class="ease-glow-tabs-glider"></span>
</div>
