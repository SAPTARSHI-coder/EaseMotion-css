# CSS Rotate-Fade Navbar

A modern, lightweight CSS-only Rotate-Fade Navbar designed for
Fintech Dashboard Layouts.

The component provides smooth navigation interactions using pure
HTML and CSS without JavaScript or external dependencies.

## Features

- Pure HTML and CSS
- No JavaScript required
- Rotate-fade navigation interactions
- Animated navigation indicators
- Responsive mobile navigation
- Fintech dashboard visual style
- CSS custom properties
- Smooth CSS transitions
- Keyboard accessible navigation
- Visible `:focus-visible` states
- Responsive across desktop, tablet, and mobile
- `prefers-reduced-motion` support
- No external libraries or frameworks
