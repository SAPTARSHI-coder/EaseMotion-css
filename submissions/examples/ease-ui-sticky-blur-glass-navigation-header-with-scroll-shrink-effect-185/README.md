# Sticky Blur Glass Navigation Header with Scroll Shrink Effect (Dark Mode Variant)

A modern sticky navigation header featuring a glassmorphism effect, smooth scroll shrink animation, responsive navigation, and a premium dark-mode aesthetic. Built using pure HTML, CSS, and JavaScript.

## ✨ Features

- Sticky navigation bar
- Scroll shrink animation
- Glassmorphism blur effect
- Dark mode interface
- Smooth hover animations
- Responsive design
- Pure HTML, CSS & JavaScript
- Modern CSS variables
- Lightweight and customizable

## 🚀 Usage

1. Open `demo.html`.
2. Keep `style.css` in the same folder.
3. Scroll the page to see the header shrink animation.
