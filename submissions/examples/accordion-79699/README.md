# Responsive Neon Accordion

Issue #79699 demonstrates a semantic responsive accordion.

## Features

- Native details behavior
- Neon styling
- Responsive sizing
- Keyboard accessibility
- Reduced-motion support
- Pure HTML and vanilla CSS

## Usage

Open `demo.html` to preview the component and link `style.css` when integrating it into another page.

## Accessibility

The example keeps native disclosure semantics and provides a visible keyboard focus state.

## Responsive behavior

Spacing and typography adapt at smaller viewport widths while preserving readable content.
