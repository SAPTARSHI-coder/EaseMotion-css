# CSS FAQ Search Results

This is a simple demo project that showcases a searchable FAQ list using **HTML, CSS, and JavaScript**.

## Features
- Search bar to filter FAQ questions dynamically.
- Clean and responsive design with CSS styling.
- Hover effect for better user experience.

## Files
- `demo.html` → Main HTML structure with FAQ content and search functionality.
- `style.css` → Styling for the FAQ container, search bar, and list items.
- `README.md` → Documentation for setup and usage.

## How to Use
1. Clone or download the project.
2. Open `demo.html` in your browser.
3. Type in the search bar to filter FAQ results in real-time.

## Example FAQs
- What is CSS?
- How do I center a div?
- Difference between relative and absolute positioning?
- How to apply a background image?

This demo can be extended with more FAQs or integrated into larger projects.
