# Animated Carousel with Gradient styling (#78833)

A responsive, zero-JavaScript carousel component featuring an infinitely animated mesh gradient border, glassmorphism surface backdrop, active pill pagination morphing, and gradient button interactions.

## Features
- **Mesh Gradient Border:** Continuous 300% linear gradient animation around the card perimeter using CSS `@keyframes`.
- **Glassmorphism Backdrop:** Glass-like container using semi-transparent dark tones and `backdrop-filter: blur(20px)`.
- **Pure CSS Controls:** Driven completely by radio input state selectors (`:checked ~ .carousel-inner-container`) with smooth spring transitions.
- **Morphing Indicators:** Active pagination dots seamlessly stretch into gradient pills upon interaction.

## File Hierarchy
- `submissions/examples/css-animated-carousel-gradient/style.css` - Keyframe mesh animations, glassmorphism filters, slider mechanics, and responsive media queries.
