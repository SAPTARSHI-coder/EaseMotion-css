# CSS Morphing Tab Indicator

A responsive morphing tab indicator built entirely with HTML and CSS.

The component uses a single pill-shaped indicator that smoothly slides between
tabs when the selected tab changes.

## Features

- Pure CSS implementation
- No JavaScript required
- Animated sliding pill indicator
- Smooth tab transitions
- Responsive design
- CSS custom properties for theming
- Light and dark mode support
- Keyboard focus support
- Reduced-motion support
- Animated content transitions
