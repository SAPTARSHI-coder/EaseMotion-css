# CSS Morph-Glow Card Grid for Product Catalog Layouts

A modern **Morph-Glow Card Grid** built using pure HTML5 and CSS3 for product catalog layouts. This component creates interactive product cards with animated glow effects, morphing gradients, smooth hover transformations, and a responsive grid system.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Morphing glow border animation
* Animated gradient effects
* Interactive product showcase cards
* Glassmorphism card design
* Smooth hover transformations
* Floating product image animation
* Product pricing and rating sections
* Responsive CSS Grid layout
* CSS Custom Properties for easy customization
* Smooth transitions and keyframe animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over product cards to view the Morph-Glow effects.
3. Customize colors, shadows, spacing, and animation speed using CSS variables inside `:root`.

## CSS Custom Properties

```css
:root{
  --bg:#eef4ff;
  --surface:rgba(255,255,255,.9);
  --primary:#2563eb;
  --secondary:#06b6d4;
  --accent:#8b5cf6;
  --text:#111827;
  --muted:#64748b;
  --shadow:0 18px 42px rgba(37,99,235,.18);
  --radius:24px;
}
```
