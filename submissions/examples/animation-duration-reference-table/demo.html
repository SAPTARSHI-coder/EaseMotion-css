Animation Duration Reference

A quick reference for choosing animation durations based on the type of interaction and the desired feel.

Animation Durations

Use shorter durations for small interface interactions and longer durations for larger visual movements.

Duration Animation Feel Recommended Use Example
100ms Very fast Micro-interactions Icon or color feedback
150ms Fast Small UI transitions Button hover
200ms Quick Common interface changes Dropdown or tooltip
300ms Balanced General UI motion Card hover or fade
400ms Smooth Larger UI transitions Panel movement
500ms Relaxed Prominent visual effects Modal entrance
700ms Slow Large visual movement Hero animation
1000ms+ Dramatic Decorative animations Background or showcase effects

How to Choose a Duration

01

Small Changes

Use short durations when only a small visual property changes, such as color, opacity, or a small transform.

02

Interface Movement

Use medium durations when an element moves across the interface or changes its position.

03

Large Visual Effects

Longer durations work better for large, decorative, or attention-focused animations.

Usage Examples

Fast Button Interaction

.button {
    transition:
        transform 150ms ease,
        background-color 150ms ease;
}

Card Hover

.card {
    transition:
        transform 300ms ease,
        box-shadow 300ms ease;
}

Panel Entrance

.panel {
    animation:
        slide-in 400ms ease-out;
}

Recommended Use Cases

  • Button and link interactions
  • Hover and focus effects
  • Cards and navigation elements
  • Dropdowns and tooltips
  • Modal and panel entrances
  • Hero and landing-page animations
  • Decorative background effects
