# CSS Dark Mode Transition (#70993)

A smooth, zero-JavaScript full-page dark and light mode transition component driven by pure CSS selectors and standard form controls.

## Features
- Pure CSS state handling using the hidden checkbox pattern.
- Smooth interpolated transitions for backgrounds, text colors, card borders, and box-shadows.
- Custom SVG toggle handle with smooth icon rotation and scale keyframe effects.
- Fully responsive across desktop, tablet, and mobile displays.
- Accessible keyboard navigation (`tabindex`, visible focus indicators, and ARIA state roles).
- Respects system accessibility preferences via `prefers-reduced-motion`.
