# CSS Zoom-In Carousel for Gaming Hub Layouts

A modern **Gaming Hub Carousel** built using **pure HTML5 and CSS3**. This showcase features elegant **Zoom-In** animations, glassmorphism cards, neon gradients, and responsive layouts without requiring JavaScript.

---

## ✨ Features

- 🎮 Gaming-inspired carousel
- 🔍 Smooth Zoom-In hover animation
- 💎 Glassmorphism UI
- 🌈 Neon gradient highlights
- ⭐ Featured center card
- 📱 Fully responsive
- ⚡ Pure HTML & CSS
- 🎨 CSS Custom Properties
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

## 🚀 Getting Started

1. Open `demo.html` in any modern browser.
2. Hover over the cards to experience the Zoom-In effect.
3. Customize colors, spacing, and animation timing using CSS variables.

---

## 🎨 CSS Variables

```css
:root{
    --bg:#050816;
    --surface:rgba(15,23,42,.88);
    --primary:#00e5ff;
    --secondary:#8b5cf6;
    --text:#ffffff;
    --muted:#cbd5e1;
    --border:rgba(255,255,255,.08);
    --radius:24px;
}
```
