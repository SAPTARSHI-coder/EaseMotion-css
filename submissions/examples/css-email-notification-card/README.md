# CSS Email Notification Card

A responsive and accessible email notification card built entirely with HTML and CSS.

## Features

- Pure HTML and CSS
- Sender avatar
- Sender name and email address
- Email timestamp
- Subject and preview text
- New email badge
- Mark-as-read action
- Hover interaction
- Keyboard focus support
- Responsive layout
- `prefers-reduced-motion` support
- No JavaScript
- No external dependencies
