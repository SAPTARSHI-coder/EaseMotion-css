Basic Reminder Schedule Row

Reminder rows for task and notification settings.

A CSS-only row component for showing reminder frequency, schedule details, next run time, and reminder status in compact panels.

DY
Daily standup reminder

Repeats every weekday at 9:30 AM.

Today Active
WK
Weekly report reminder

Sent every Friday before the dashboard review.

Fri Scheduled
OD
Contract renewal reminder

Needs attention because the previous reminder was missed.

2d late Overdue

HTML Usage

<article class="basic-reminder-schedule-row">
  <span class="reminder-icon is-daily" aria-hidden="true">DY</span>
  <div class="reminder-copy">
    <strong>Daily standup reminder</strong>
    <p>Repeats every weekday at 9:30 AM.</p>
  </div>
  <span class="reminder-time">Today</span>
  <span class="reminder-state is-daily">Active</span>
</article>
