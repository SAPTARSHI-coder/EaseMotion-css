GET /api/v2/cluster

Retrieves the current state and health metrics of the primary server cluster.

curl -X GET "https://api.tech.local/v2/cluster" \ -H "Authorization: Bearer [TOKEN]"

Standard Response Object

All successful API responses return a strictly typed JSON payload.

{ "status": 200, "data": { "cluster_id": "c-88219x", "uptime_seconds": 86400 } }

Bearer Token Authentication

Generate a secure Ed25519 signed JWT using your developer console credentials.
