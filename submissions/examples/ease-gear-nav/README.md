# ⚙️ Gear Nav – Mechanical Gears Interlock and Rotate

> A steampunk, industrial navigation where gears interlock and rotate on hover, creating a mechanical, engineering-inspired effect.

---

## 📖 Description

The **Gear Nav** is a steampunk, industrial navigation component where mechanical gears interlock and rotate on hover. Six gears orbit around a central gear, each spinning at a different speed when hovered, creating a dynamic, mechanical effect reminiscent of a clockwork mechanism. The gears feature teeth-like borders and metallic styling.

The component uses CSS transforms and keyframe animations to create the gear rotation and orbiting effects. Each gear has a unique color and spin speed, creating a complex, interlocking mechanical feel. The central gear pulses gently, anchoring the design.

Perfect for steampunk-themed interfaces, engineering websites, tech brands, and any application where you want to create a mechanical, industrial navigation experience. The Gear Nav transforms a simple menu into a dynamic, clockwork interaction.
