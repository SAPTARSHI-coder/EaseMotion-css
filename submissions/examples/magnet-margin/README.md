# Magnet Margin

Magnet Margin is an experimental interactive layout component where UI
elements behave like magnetic objects.

Instead of simply dragging cards around independently, each object has an
invisible magnetic field.

When objects move close enough to each other, they begin attracting one
another and a visual relationship is created between them.

## ✨ Features

- Magnetic object interaction
- Drag-and-drop positioning
- Distance-based attraction
- Dynamic attraction strength
- Magnetic relationship detection
- Dynamic SVG connection lines
- Active-object tracking
- Relationship counter
- Strongest relationship detection
- Attraction percentage
- Live coordinates
- Reset functionality
- Pointer Events
- Mouse support
- Touch support
- Stylus support
- Responsive layout
- Reduced-motion support
- No external JavaScript dependencies
