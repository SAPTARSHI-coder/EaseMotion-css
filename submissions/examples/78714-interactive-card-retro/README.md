# Interactive Card with Retro Styling

A responsive interactive card component built with pure HTML and CSS.
The design combines retro arcade aesthetics with modern interaction
patterns.

## Features

- Pure HTML and CSS
- No JavaScript dependency
- Retro arcade-inspired design
- Interactive hover animations
- Animated status indicator
- Pixel-inspired visual element
- Interactive CTA button
- Animated button arrow
- Interactive statistics
- Responsive desktop, tablet, and mobile layouts
- Keyboard-accessible focus state
- Reduced-motion support

## Files

- `demo.html` — complete component demonstration
- `style.css` — styling, animations, interactions, and responsive
  behavior
