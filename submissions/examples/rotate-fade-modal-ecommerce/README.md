# Rotate-Fade Modal for E-Commerce Checkout

A lightweight CSS-only Rotate-Fade Modal designed for modern
E-Commerce Checkout layouts.

This example demonstrates how a checkout confirmation modal can
appear using CSS transitions and transforms without JavaScript.

## Features

- Pure HTML and CSS
- No JavaScript required
- Rotate + fade entrance animation
- Scale and translate motion
- CSS-only modal interaction using `:target`
- Responsive desktop, tablet, and mobile layouts
- Checkout confirmation UI
- CSS custom properties for easy customization
- Keyboard focus-visible states
- `prefers-reduced-motion` accessibility support
- Lightweight and dependency-free
