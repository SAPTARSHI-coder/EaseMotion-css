# CSS Cyberpunk Glitch Box

A container with a neon cyberpunk aesthetic featuring angled corners using `clip-path` and an intermittent glitching text effect.

## Features
- Angled corners using `clip-path`
- Intermittent glitching text using `inset` clip-paths
- Cyberpunk neon glow effects
