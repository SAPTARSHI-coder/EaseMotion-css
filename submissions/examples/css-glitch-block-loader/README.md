# CSS Glitch Block Loader

What does this do?
A pure CSS loading animation where pixel blocks glitch, jump, and scale before assembling into a unified logo/grid shape.

How is it used?
```html
<div class="loader-container" role="status" aria-label="Loading">
  <div class="glitch-blocks">
    <div class="block"></div>
    <div class="block"></div>
    <div class="block"></div>
    <div class="block"></div>
    <div class="block"></div>
    <div class="block"></div>
    <div class="block"></div>
    <div class="block"></div>
    <div class="block"></div>
  </div>
</div>
```

Why is it useful?
This component expands the library's collection of ready-to-use CSS animations and UI patterns, helping front-end developers implement a glitch-style loader without relying on JavaScript libraries.
