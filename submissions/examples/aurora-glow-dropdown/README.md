# CSS Dropdown: Aurora Glow Variation

A pure CSS dropdown menu featuring a soft Aurora Glow visual style.

## ✨ Features

- Pure HTML and Vanilla CSS
- No JavaScript required
- Aurora-inspired gradient glow
- Smooth dropdown entrance animation
- Animated gradient border glow
- Glassmorphism-inspired surface
- Hover interaction
- Keyboard-friendly `:focus-within` interaction
- Responsive design
- Dark-mode friendly
- `prefers-reduced-motion` support
- Hardware-friendly CSS transforms

## 🎨 Design

The component combines:

- CSS gradients
- `backdrop-filter`
- CSS blur effects
- CSS transforms
- CSS transitions
- CSS keyframe animations
- `:hover`
- `:focus-within`

The dropdown creates a soft aurora-like glow around the trigger and menu while maintaining a clean interface.
