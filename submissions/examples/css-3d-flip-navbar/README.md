# CSS 3D Flip Navbar

A responsive navigation bar with smooth 3D flip hover effects built using only HTML and CSS.

## Features

- Pure HTML & CSS
- 3D flip hover animation
- Responsive layout
- Lightweight
- No JavaScript required
- Supports `prefers-reduced-motion`

## Files

```
demo.html
style.css
README.md
```

## Customization

Change navbar color:

```css
.navbar{
    background:#1f2937;
}
```

Change hover color:

```css
.nav-links a:hover{
    color:#60a5fa;
}
```

Change animation speed:

```css
transition:transform .5s ease;
```
