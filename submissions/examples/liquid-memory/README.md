# 🫧 Liquid Memory – Interactions Become Floating Memories

Liquid Memory is an interactive UI component where every user interaction leaves behind a temporary visual memory.

Clicking or tapping the liquid surface creates a ripple at the exact interaction position. Once the ripple settles, a small glowing memory bubble appears and begins drifting through the surface before gradually fading away.

The component turns ordinary user interactions into visible, temporary artifacts.

Built with vanilla HTML, CSS, and JavaScript with no external dependencies.
