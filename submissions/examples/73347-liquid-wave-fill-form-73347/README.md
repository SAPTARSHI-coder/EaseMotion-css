# CSS Liquid Wave Fill Form

Issue #73347 demonstrates a liquid wave fill effect around a semantic form using pure CSS.

## Features

- Fluid wave layer
- Native form controls
- Responsive layout
- Keyboard focus styles
- Reduced-motion fallback
- No external JavaScript

## Accessibility

The liquid layer is decorative. Form controls retain labels and visible focus states, while the wave becomes static for reduced-motion users.

## Files

- `demo.html` — form demonstration
- `style.css` — liquid animation and responsive rules
- `README.md` — documentation
