# CSS Flip to Dark Card (#70989)

An interactive 3D card flipping component that seamlessly transitions from a light theme front face to an immersive dark mode back face upon hover or keyboard focus.

## Features
- Pure CSS 3D perspective transformation (`perspective`, `transform-style: preserve-3d`, `backface-visibility`).
- Triggerable via both mouse hover and keyboard focus (`:focus-visible`) for accessibility.
- Dual-theme layout with customized typography and borders on both faces.
- Built-in motion safety overrides (`prefers-reduced-motion`).
