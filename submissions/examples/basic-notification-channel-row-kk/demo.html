Basic Notification Channel Row

Channel rows for account notification preferences.

A CSS-only row component for showing notification delivery channels, helper copy, and active, quiet, or disabled states.

@
Email notifications

Send product updates and security alerts to the primary email.

Active
#
SMS reminders

Only urgent reminders are delivered during quiet hours.

Quiet
IN
In-app messages

Workspace tips and promotional messages are disabled.

Disabled

HTML Usage

<article class="basic-notification-channel-row">
  <span class="channel-mark" aria-hidden="true">@</span>
  <div class="channel-copy">
    <strong>Email notifications</strong>
    <p>Send product updates and security alerts to the primary email.</p>
  </div>
  <span class="channel-state is-active">Active</span>
</article>
