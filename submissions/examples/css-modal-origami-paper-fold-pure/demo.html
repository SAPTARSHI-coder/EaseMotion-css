Pure CSS Modal: Origami Fold

A tactile, JavaScript-free modal utilizing the checkbox hack. Features 3D CSS transforms and staggered perspective rotations to simulate a piece of paper unfolding.

Paper Architecture

Notice the entrance physics. A wrapper element applies `perspective: 1200px`. The modal card itself is set to `transform-origin: 50% 0%` (the top edge) and animated from `rotateX(-90deg)` to `rotateX(0deg)`. A subtle shadow change during the rotation enhances the illusion of physical depth.
