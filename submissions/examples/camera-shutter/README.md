# CSS Camera Shutter

A cinematic camera shutter animation built entirely with HTML and CSS.

## ✨ Features

- Pure CSS implementation
- No JavaScript
- Animated camera shutter blades
- Camera flash effect
- Lens animation
- Camera shake on capture
- Interactive capture button
- Keyboard accessible
- Visible focus state
- Responsive design
- Reduced-motion support
- Semantic HTML
- CSS custom properties
- Works without external dependencies
