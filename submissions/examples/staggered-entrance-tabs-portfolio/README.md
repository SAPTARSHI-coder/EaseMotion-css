# CSS Staggered Entrance Tabs for Creative Portfolio

A pure CSS animated tabs component designed for creative
portfolio layouts.

The component uses a smooth staggered entrance animation
when switching between portfolio categories.

## Features

- Pure HTML and CSS
- No JavaScript
- Responsive design
- Creative portfolio aesthetic
- Staggered content entrance
- CSS custom properties
- Keyboard-focusable controls
- Reduced-motion support
- No external dependencies
