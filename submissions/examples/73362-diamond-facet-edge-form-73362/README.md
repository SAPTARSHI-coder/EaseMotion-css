# Diamond Facet Edge Form

Implementation for EaseMotion issue #73362.

## Features

- Pure HTML and vanilla CSS
- Faceted geometric panel edges
- Responsive two-column form
- Native controls and visible focus states
- Reduced-motion support
- No external JavaScript

The angular treatment is created with CSS clipping and borders rather than image assets. The form remains semantic and usable independently of the decorative style.

Open `demo.html` to view the component and edit the custom properties in `style.css` to change the palette.
