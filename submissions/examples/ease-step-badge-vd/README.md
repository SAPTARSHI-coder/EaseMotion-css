# Ease Step Badge

## What does this do?

A numbered step badge component for displaying progress through onboarding flows, multi-step forms, and other sequential processes.

---

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<div class="step active">
    <div class="step-badge">1</div>
    <span>Account</span>
</div>
```

### Features

- Circular numbered badge
- Active state
- Completed state
- Label support
- Hover animation
- Responsive layout

---

## Why is it useful?

Step indicators help users understand their progress through multi-step forms, onboarding flows, checkout processes, and setup screens.

This component provides a lightweight and reusable step indicator with subtle interactions while following the animation-first philosophy of EaseMotion CSS.
