# Foucault Pendulum Swing Media Visualizer

A pure HTML and CSS audio/media visualizer inspired by the motion of a Foucault pendulum.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript or external dependencies
- Smooth pendulum swing animation
- Animated media visualizer bars
- Responsive layout
- Dark-mode friendly design
- Accessible focus states
- `prefers-reduced-motion` support
- Hardware-friendly CSS animations using `transform` and `will-change`

## Files

- `demo.html` — Component markup
- `style.css` — Complete styling and animations

## Usage

Open `demo.html` directly in a modern browser.

## Accessibility

The component includes semantic controls, accessible labels, visible keyboard focus states, and reduced-motion support for users who prefer less animation.
