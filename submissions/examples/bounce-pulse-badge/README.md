# CSS Bounce-Pulse Badge

A lightweight badge component featuring a smooth bounce and pulse hover animation built using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Bounce-pulse hover animation
- Fully responsive
- Accessible with `prefers-reduced-motion`
- No JavaScript required
- Easy to customize

## Folder Structure

```text
bounce-pulse-badge/
├── demo.html
├── style.css
└── README.md
```

## Usage

Open `demo.html` in any modern browser.

## Customization

- Badge colors
- Animation duration
- Border radius
- Font size
- Spacing

## Browser Support

Compatible with all modern browsers supporting CSS animations and transitions.
