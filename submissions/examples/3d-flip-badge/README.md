# CSS 3D-Flip Badge

A responsive badge component featuring a smooth 3D flip animation built using pure HTML and CSS.

## Features

- Pure HTML & CSS
- 3D flip hover animation
- Fully responsive
- Accessible with `prefers-reduced-motion`
- No JavaScript required
- Lightweight and customizable

## Folder Structure

```text
3d-flip-badge/
├── demo.html
├── style.css
└── README.md
```

## Usage

Open `demo.html` in any modern browser and hover over a badge to see the flip effect.

## Customization

- Badge colors
- Flip duration
- Badge size
- Typography
- Border radius

## Browser Support

Compatible with all modern browsers supporting CSS 3D transforms.
