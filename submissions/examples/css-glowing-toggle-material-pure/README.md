# Glowing Material Toggle

A beautifully crafted Material Design inspired toggle switch with a glowing checked state and ripple hover effects.

## Features
- Authentic Material Design metrics and easings
- Pure CSS implementation using the Checkbox Hack
- Ripple hover and active effects for tactile feedback
- Glowing drop-shadow effect in the checked state
- Dark mode optimized colors
- Fully accessible via keyboard focus indicators

## Usage

Simply include `demo.html` and `style.css`. Adjust the CSS color variables to match your application's primary brand color.
