## Description

This PR implements a new **Floating Avatar with SaaS Modern styling** for issue #78704.

It is a critical issue because modern SaaS interfaces require lightweight,
responsive, and visually engaging team/user presence components.

### Features

- Added a modern floating avatar component
- Added multiple team member avatar cards
- Added online status indicators
- Added SaaS-inspired glassmorphism styling
- Added smooth floating animations
- Added hover interactions
- Added responsive layouts for desktop, tablet, and mobile
- Added reduced-motion accessibility support
- Added documentation in README.md
