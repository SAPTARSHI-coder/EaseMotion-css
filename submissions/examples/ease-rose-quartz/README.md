# 💗 Rose Quartz – Pink Crystals Form and Glow

> A mystical rose quartz component where pink crystals form and glow with formation control (0-100%), sparkle control (0-100%), faceted crystal shapes, and inner glow particles.

---

## 📖 Description

The **Rose Quartz** component creates a mystical rose quartz experience where pink crystals form and glow with faceted shapes and sparkle effects. Built with vanilla HTML, CSS, and JavaScript, it features formation control (0-100%), sparkle control (0-100%), and faceted crystal shapes for a magical experience.

### 🎯 Core Features

- **Rose quartz crystals** – pink crystals with faceted shapes
- **Formation control** – adjust formation from 0-100%
- **Sparkle control** – adjust sparkle frequency from 0-100%
- **Inner glow** – crystals pulse with pink light
- **Glow particles** – floating particles around crystals
- **Interactive controls** – sliders, keyboard shortcuts
- **Responsive design** – adapts to different screen sizes

### 💗 Crystal Features

| Feature | Description |
|---------|-------------|
| **Facets** | 4-8 faceted crystal shapes |
| **Colors** | Multiple pink shades |
| **Glow** | Inner light with pulse animation |
| **Particles** | Floating glow particles |
| **Sparkles** | Random sparkle bursts |

### ⌨️ Interaction Options

| Method | Action |
|--------|--------|
| **Sliders** | Adjust Formation (0-100%) and Sparkle (0-100%) |
| **Keyboard** | `R` – Reset |

### ✨ Rose Quartz Experience

When interacting:
1. **Crystals form** – pink crystals grow and develop
2. **Formation applies** – controls crystal size and growth
3. **Sparkle applies** – controls sparkle frequency
4. **Particles float** – glow particles orbit crystals
5. **Status updates** – shows current state

### 💡 Why Use This Component?

- Perfect for mystical interfaces, crystal shops, or magical themes
- Beautiful rose quartz glow with faceted crystals
- Self-contained – no external dependencies or frameworks
- Easy to customize (colors, glow behavior, sparkle)
- Formation and sparkle controls for customization

### 🛠️ Technologies Used

- **HTML5** – semantic structure with Canvas
- **CSS3** – gradients, backdrop-filter, transforms
- **JavaScript (ES6)** – Canvas API, requestAnimationFrame, particle system

### 🎨 Design Philosophy

This component embodies **EaseMotion CSS's animation-first philosophy** through:

- **Glow effects** – inner light with pulse animation
- **Particle effects** – floating glow particles
- **Visual feedback** – status updates, glow level, controls
- **Mystical atmosphere** – pink colors and glow
- **Human-readable classes** – `.rosequartz-controls`, `.rosequartz-text`

### 🔧 Customization Options

| Property | Location | Default |
|----------|----------|---------|
| Formation range | `formationSlider` | 0-100% |
| Sparkle range | `sparkleSlider` | 0-100% |
| Crystal count | `generateCrystals()` | 6-12 |
| Crystal size | `size` | 5-25px |
| Facets | `facets` | 4-8 |
