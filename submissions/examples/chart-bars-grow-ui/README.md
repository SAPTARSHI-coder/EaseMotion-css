# Chart Bars Grow

Bar chart columns grow from zero with a springy overshoot.

## Features
- Bars grow with bounce
- Staggered by column
- Value labels on top
- Pure CSS

## Usage
```html
<div class="cbg-col" style="--h:78%"><b>2</b><i></i></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
