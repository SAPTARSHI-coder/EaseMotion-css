# CSS Rotate-Fade Feature Grid for Creative Portfolio Layouts

A modern **Creative Portfolio Feature Grid** showcasing elegant **Rotate-Fade** animations built entirely with **HTML5 and CSS3**. This example demonstrates responsive feature cards with smooth entrance effects, CSS custom properties, and accessibility support—without requiring JavaScript.

---

## ✨ Features

- 🎨 Creative Portfolio inspired layout
- 🔄 Rotate-Fade entrance animation
- 🪟 Glassmorphism feature cards
- 🌈 Gradient circular icons
- ⚡ Pure HTML5 & CSS3 (No JavaScript)
- 📱 Fully responsive across desktop, tablet, and mobile
- 🎯 CSS Custom Properties for easy customization
- ♿ Accessibility support with `prefers-reduced-motion`
- 🚀 Lightweight and performance-friendly

## 🚀 Getting Started

1. Open `demo.html` in any modern browser.
2. Watch the feature cards rotate and fade into view.
3. Hover over cards to see interactive elevation effects.
4. Customize colors, spacing, and animation timing through the CSS variables.

## 🎨 CSS Custom Properties

```css
:root{
    --bg:#0f172a;
    --card:rgba(30,41,59,.85);
    --primary:#38bdf8;
    --secondary:#8b5cf6;
    --text:#ffffff;
    --muted:#cbd5e1;
    --border:rgba(255,255,255,.08);
    --radius:18px;
    --transition:.35s ease;
}
```
