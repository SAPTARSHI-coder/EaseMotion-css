# Cupola Furnace Tap

## What does this do?
Renders a self-contained CSS-only `ease-cupola-furnace-tap` demo: Foundry cupola tapped with molten iron pour.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-cupola-furnace-tap`. No build step or JavaScript is required for the effect.

```html
<section class="ease-cupola-furnace-tap">
  <div class="ease-cupola-furnace-tap__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
