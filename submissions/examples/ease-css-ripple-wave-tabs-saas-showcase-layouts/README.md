# CSS Ripple-Wave Tabs for SaaS Showcase Layouts

A modern SaaS-style tab component featuring a smooth ripple-wave interaction effect built completely with pure HTML and CSS.

This component is designed for SaaS dashboards, product showcases, and landing pages where lightweight animated navigation interactions are required without JavaScript.


## ✨ Features

- 🌊 Smooth ripple-wave hover animation
- 📑 Modern SaaS tab navigation UI
- 🎨 Glassmorphism inspired design
- ⚡ Pure HTML and CSS implementation
- 📱 Fully responsive layout
- 🔄 CSS keyframe ripple animations
- ♿ prefers-reduced-motion accessibility support
- 🚀 Lightweight and framework-free

## 🚀 Usage

1. Open `demo.html` directly in your browser.

2. Hover over the tabs to view the ripple-wave animation.

3. Customize CSS variables inside `style.css` according to your branding.


## 🎨 CSS Custom Properties

The component uses CSS variables for easy customization:

```css
:root {

    --bg:#020617;
    --card:#0f172a;
    --primary:#22d3ee;
    --secondary:#8b5cf6;
    --text:#f8fafc;
    --muted:#94a3b8;

}

Modify these values to create your own theme.
