# Solar Flare Radial Button

This is a smooth, performant pure CSS button featuring a "Solar Flare Radial" hover effect, optimized for dark mode.

### Usage
```html
<button class="solar-flare-button">Initiate Sequence</button>
```

### Why is it useful?
It provides a visually striking, premium-feeling interaction that instantly grabs user attention using hardware-accelerated transitions and radial gradients, perfectly aligning with EaseMotion CSS's goal of fluid and engaging UI elements.
