# CSS Dropdown: Glassmorphism Blur

A pure HTML and CSS dropdown featuring a translucent
**Glassmorphism Blur** visual style.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript
- Semantic `<details>` and `<summary>` interaction
- Glassmorphism translucent surfaces
- `backdrop-filter` blur effect
- Smooth dropdown reveal animation
- Soft borders and shadows
- Interactive hover states
- Keyboard-friendly controls
- Visible focus states
- Responsive design
- Light and dark mode support
- Reduced-motion support
