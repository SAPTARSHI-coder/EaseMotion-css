# Ease Menu Item

## What does this do?

A reusable sidebar and navigation menu item containing an icon and label with hover and active states.

---

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<a href="#" class="menu-item active">
    <span class="menu-icon">⌂</span>
    <span>Dashboard</span>
</a>
```

### Features

- Icon support
- Label
- Active state
- Hover transition
- Smooth movement animation
- Responsive layout
- Lightweight and reusable

---

## Why is it useful?

Menu items are commonly used in sidebars, dashboards, admin panels, and navigation menus.

This component provides a simple and reusable navigation item with subtle interaction feedback while following the animation-first philosophy of EaseMotion CSS.
