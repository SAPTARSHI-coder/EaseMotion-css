# dna-helix-abz
An animated 3D DNA double helix sequence where two strands twist opposingly with color-coded nodes.

## Run
Open `demo.html` directly in a browser to view the DNA sequencing animation.

## Notes
- The helix structure twists using opposing `rotateY` keyframes on `dna-strand` elements.
- The base pair nodes cycle opacity and scale with staggered delays to simulate 3D rotation and vertical flow.
- Zero dependencies, using raw CSS keyframes and modern selectors.
