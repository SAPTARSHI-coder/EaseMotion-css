# Glassmorphic Milestone Timeline

A modern, responsive vertical milestone timeline built with pure HTML and CSS.

This showcase demonstrates a clean timeline layout with connected milestone nodes, glowing active indicators, frosted glass cards, and smooth hover offset animations.

## Features

- Vertical milestone timeline layout
- Connected timeline spine
- Glowing active milestone indicators
- Frosted glassmorphic cards
- Smooth horizontal card translation on hover
- CSS pseudo-elements for timeline connections
- Pure HTML and CSS
- No JavaScript required
- No external frameworks required
- Responsive across desktop, tablet, and mobile
- Customizable CSS variables
- Accessible semantic HTML structure
- Reduced-motion support with `prefers-reduced-motion`

---

## Preview

The component is designed for interfaces such as:

- Product roadmaps
- Company milestones
- Project timelines
- Product development journeys
- Release histories
- Career timelines
- Project progress tracking

Each milestone is connected through a vertical spine, while active milestones receive a glowing node treatment.
