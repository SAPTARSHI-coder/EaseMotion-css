# CSS Fade-In Drawer for Product Catalog Layouts

A modern Pure CSS product card component featuring a smooth fade-in bottom drawer for product catalogs. The drawer reveals additional product information and action buttons with elegant transitions, making it suitable for e-commerce interfaces and product showcases.

## Features

- Pure HTML5 & CSS3
- Smooth Fade-In Drawer Animation
- Responsive Product Grid
- Hover Elevation Effect
- Gradient Drawer Panel
- CTA Buttons
- CSS Custom Properties
- Mobile Friendly
- No JavaScript Required
- Accessible Motion Support using `prefers-reduced-motion`
