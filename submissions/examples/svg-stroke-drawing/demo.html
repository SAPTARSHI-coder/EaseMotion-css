How It Works

The Dasharray / Dashoffset Magic

To animate drawing lines in SVG, we convert continuous paths into dash segments, slide them out of view, and then slide them back in using CSS keyframes.

📐
stroke-dasharray Defines the length of the dash and the gap. We set it equal to the total path length (e.g. 535 for the outer ring) so that one single dash covers the entire shape.
🔄
stroke-dashoffset Controls where the dash pattern starts. Setting it to the path length pushes the dash out of view. Animating it to 0 pulls it back, creating the drawing effect.
⏳
Sequential Staggering By applying staggered animation-delay values (e.g. 0s, 0.6s, 1.2s), we draw the outer frame first, then the inner geometry, and finally the central core.

Implementation Details

Self-Contained Clean CSS

Check out the clean CSS code mapping dasharrays and offset sequences. Zero JS required.

style.css
/* 1. Define the universal path drawing keyframes */
@keyframes draw-path {
  from { stroke-dashoffset: var(--path-len); opacity: 0; }
  to { stroke-dashoffset: 0; opacity: 1; }
}

/* 2. Style paths, specify lengths, and map staggered delays */
.path-ring {
  --path-len: 535;
  stroke-dasharray: var(--path-len);
  animation: draw-path 1.6s cubic-bezier(0.4, 0, 0.2, 1) forwards;
  animation-delay: 0s;
}

.path-geometry-1 {
  --path-len: 430;
  stroke-dasharray: var(--path-len);
  animation: draw-path 1.4s cubic-bezier(0.4, 0, 0.2, 1) forwards;
  animation-delay: 0.8s;
}

/* 3. Handle prefers-reduced-motion dynamically */
@media (prefers-reduced-motion: reduce) {
  svg path, svg circle {
    animation: none !important;
    stroke-dashoffset: 0 !important;
    opacity: 1 !important;
  }
}
