# CSS Text: Foucault Pendulum Swing

A physics-inspired text animation that recreates the smooth oscillating motion of a Foucault pendulum using pure CSS.

## Features

- Pure HTML & CSS
- Pendulum-style swing animation
- Smooth easing transitions
- Hardware accelerated transforms
- Responsive typography
- Dark mode compatible
- Accessible implementation

## Usage

```html
<h1 class="pendulum-text">
    FOUCAULT SWING
</h1>
```

## Files

- demo.html
- style.css

## EaseMotion CSS

This animation demonstrates natural motion principles through smooth rotational movement while remaining lightweight, reusable, and entirely CSS-powered.
