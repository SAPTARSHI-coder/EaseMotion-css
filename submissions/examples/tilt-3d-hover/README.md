# Tilt 3D Hover

What does this do?
Adds a 3D tilt and scale effect using keyframes when the user hovers over an element.

How is it used?
```html
<div class="ease-anim-tilt-3d-hover">Hover me</div>
```

Why is it useful?
It provides a hardware-accelerated, performant 3D hover effect that feels interactive and modern, aligning with EaseMotion's focus on smooth, high-quality animations.
