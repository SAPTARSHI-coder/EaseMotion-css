# Tilt 3D Hover Animation

## Overview

This submission demonstrates a reusable Tilt 3D Hover animation inspired by the EaseMotion feature request.

## Features

- Smooth 3D tilt hover effect
- CSS keyframes animation
- Configurable timing using CSS variables
- GPU-friendly transforms
- Supports `prefers-reduced-motion`

## Demo

Open `demo.html` directly in any browser.

## Customization

```css
--ease-duration: 400ms;
--ease-timing: ease-in-out;
```
