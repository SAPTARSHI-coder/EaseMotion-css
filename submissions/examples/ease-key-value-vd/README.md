# Ease Key Value

## What does this do?

A compact key-value display component with labels, values, dividers, and a responsive layout.

---

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<div class="key-value">
    <span class="key">Name</span>
    <span class="divider"></span>
    <span class="value">Vidheendu</span>
</div>
```

### Features

- Label
- Value
- Divider
- Responsive layout
- Lightweight and reusable

---

## Why is it useful?

Key-value displays are commonly used on profile pages, settings pages, account information sections, and dashboards.

This component provides a clean and reusable way to display related information while following the simple and human-readable philosophy of EaseMotion CSS.
