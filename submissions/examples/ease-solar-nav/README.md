# 🌞 Solar Nav – Items Orbit Like Solar System with Planets

> A cosmic, space-themed navigation where items orbit like planets around a sun, creating a dynamic, celestial navigation experience.

---

## 📖 Description

The **Solar Nav** is a cosmic, space-themed navigation component where items orbit like planets around a sun. Six planets orbit around a central sun at different distances and angles, creating a dynamic, celestial navigation experience. The planets appear with a smooth, staggered animation when activated, mimicking the orbital motion of a solar system.

The component uses CSS transforms and trigonometric positioning to arrange the planets on their orbits. Each planet has a unique color and icon, and orbits at a different distance from the sun. The center sun button morphs from a sun icon to a close icon when activated.

Perfect for space-themed interfaces, astronomy websites, sci-fi projects, and any application where you want to create a cosmic, dynamic navigation experience. The Solar Nav transforms a simple menu into a celestial journey through the solar system.
