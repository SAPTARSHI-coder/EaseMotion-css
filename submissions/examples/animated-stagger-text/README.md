# ease-stagger-text

## Description

Creates a staggered text reveal animation by animating each character independently with a slight delay.

Ideal for:

- Hero headings
- Landing pages
- Marketing websites
- Portfolio websites
- Product showcases

---

## Features

- Pure CSS animation
- Lightweight
- Character-by-character reveal
- Smooth stagger timing
- Easy customization

---

## Usage

```html
<h1 class="ease-stagger-text">
    EaseMotion CSS
</h1>
```

A tiny JavaScript helper splits the text into animated `<span>` elements.

---

## Browser Support

- Chrome ✅
- Firefox ✅
- Edge ✅
- Safari ✅

---

## Customization

Animation delay

```css
animation-delay:0.05s;
```

Animation duration

```css
animation:.6s forwards;
```
