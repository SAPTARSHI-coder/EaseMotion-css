# CSS Accordion - Foucault Pendulum Swing

A unique accordion component inspired by the motion of a Foucault pendulum. Accordion panels reveal content with a smooth pendulum-like swinging animation, creating a visually engaging interaction while maintaining accessibility and performance.

## Features

- Pure HTML & CSS
- Foucault pendulum swing animation
- Smooth accordion expansion
- Accessible keyboard navigation
- Responsive design
- Dark mode compatible
- Hardware accelerated animations
- No JavaScript required

## Usage

```html
<details class="pendulum-accordion">
  <summary>Accordion Title</summary>
  <div class="accordion-content">
    Content goes here
  </div>
</details>
```
