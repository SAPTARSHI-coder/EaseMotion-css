# Neumorphic Modal — Dark Mode

A responsive dark-mode modal featuring a soft neumorphic
visual style, layered shadows, accessible controls, and
a CSS-only open/close interaction.

Implemented for issue #78749.

## Features

- Dark neumorphic styling
- Soft raised and inset shadows
- CSS-only modal interaction
- Responsive modal layout
- Backdrop blur
- Modal entrance transition
- Accessible close control
- Keyboard focus-visible states
- Reduced-motion support
- No external dependencies
