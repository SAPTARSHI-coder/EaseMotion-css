# Glassmorphism Blur Tabs

Pure HTML and Vanilla CSS implementation for EaseMotion issue #73556.

## Features

- Frosted glass surface
- Three-state segmented control
- Native radio inputs for state selection
- Backdrop blur and translucent borders
- Responsive layout
- Visible focus styling
- Reduced-motion support
- No JavaScript dependencies

## Implementation

Radio inputs control which content panel is visible. CSS sibling selectors connect each checked input to its corresponding label and content panel.

## Accessibility

The state controls remain native form inputs and can be operated from the keyboard. The focus indicator is visible, and motion is disabled for reduced-motion users.

## Usage

Open `demo.html` directly in a modern browser.
