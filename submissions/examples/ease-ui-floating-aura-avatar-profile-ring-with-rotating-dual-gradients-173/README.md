# Floating Aura Avatar Profile Ring with Rotating Dual Gradients

A clean and modern **Floating Aura Avatar Profile Ring** built using pure HTML and CSS. This Minimalist Clean Edition features rotating dual-gradient rings, floating animations, glassmorphism-inspired styling, and a responsive layout.

## ✨ Features

- Minimalist Clean UI
- Rotating dual gradient profile rings
- Floating avatar animation
- Online status indicator
- Smooth hover effects
- Responsive design
- Pure HTML & CSS
- Lightweight and reusable

## 📂 Files

```
demo.html
style.css
README.md
```

## 🚀 Usage

1. Download or clone the project.
2. Open `demo.html` in your browser.
3. Customize the avatar image, colors, and text as needed.

## 📱 Responsive

The component is fully responsive and optimized for desktop, tablet, and mobile devices.
