# Rainbow Progress Bars

Three progress bars chase each other in a looping rainbow cycle.

## Features
- Hue-shifting bar fills
- Staggered cycle phases
- Rounded caps
- Pure CSS

## Usage
```html
<div class="rpb-bar"><i style="--h:0deg"></i></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
