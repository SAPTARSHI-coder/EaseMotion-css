# Timeline Marker Sweep

A compact CSS-only timeline interaction where the progress rail sweeps down the list and each marker lifts with a staggered glow.

## Features

- Animated vertical progress rail triggered on hover or keyboard focus.
- Staggered milestone markers with subtle lift, scale, and glow effects.
- Responsive card layout that keeps the timeline readable on small screens.
- Reduced-motion fallback for users who prefer less animation.

## Files

- `demo.html` - semantic timeline markup with focusable interaction area.
- `style.css` - timeline layout, marker animation, progress sweep, and responsive styling.

## How to Use

Open `demo.html` in a browser, then hover over or tab to the timeline panel to preview the marker sweep animation.
