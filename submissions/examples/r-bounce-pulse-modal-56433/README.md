# CSS Bounce-Pulse Modal

A modern **Bounce-Pulse Modal** built using pure HTML5 and CSS3 for Gaming Hub layouts. The modal opens with a smooth bounce and pulse animation while remaining lightweight, responsive, and accessible.

---

## ✨ Features

- Pure HTML5 & CSS3
- Bounce-pulse entrance animation
- Gaming-inspired design
- Fully responsive
- CSS Custom Properties
- Lightweight
- Keyboard-accessible checkbox toggle
- `prefers-reduced-motion` support
- No JavaScript required
