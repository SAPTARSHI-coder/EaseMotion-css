# Hover Pagination with Cyberpunk Styling

A responsive pagination component with a futuristic cyberpunk
visual style, glowing borders, angular shapes, and interactive
hover states.

## Features

- Fully responsive
- HTML/CSS only
- No JavaScript
- Cyberpunk visual styling
- Glowing cyan and magenta accents
- Hover elevation and glow
- Active page state
- Previous and next controls
- Keyboard-accessible focus states
- Responsive mobile layout
- Reduced-motion support
- No external dependencies

## Interaction

### Default
Pagination items use a dark futuristic surface with subtle
cyan borders.

### Hover
Page items move upward slightly while their borders and glow
become more prominent.

### Active
The current page uses a bright cyan surface with a neon glow.

### Previous / Next
Navigation controls use magenta accents and directional
micro-interactions.

## Files

- `demo.html`
- `style.css`

## Technologies

- HTML5
- CSS3

## Accessibility

The component uses:

- Semantic `<nav>` and ordered list structure
- `aria-label` for pagination navigation
- `aria-current="page"` for the active page
- Visible keyboard focus states
- Reduced-motion support
