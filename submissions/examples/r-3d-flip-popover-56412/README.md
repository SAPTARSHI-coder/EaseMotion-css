# CSS 3D-Flip Popover

A modern **3D-Flip Popover** built using pure HTML5 and CSS3 for Gaming Hub layouts. The popover flips smoothly into view using a 3D rotation while remaining lightweight, responsive, and accessible.

---

## ✨ Features

- Pure HTML5 & CSS3
- 3D flip animation
- Gaming-inspired interface
- Fully responsive
- CSS Custom Properties
- Keyboard accessible
- Lightweight and performant
- `prefers-reduced-motion` support
- No JavaScript required
