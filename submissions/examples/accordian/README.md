### Ease Accordion Component

A lightweight, accessible, and high-performance collapsible container built with modern CSS grid animation techniques.

#### Features
* **Smooth Panel Reveal:** Powered by `grid-template-rows` transitions for height-agnostic accordion expansion.
* **Animated Chevron:** The `ease-accordion-chevron` class applies a fluid 180-degree rotation transition.
* **Accessible:** Uses proper `aria-expanded` attributes for screen readers.

#### Usage
Include `style.css` and structure your HTML markup using the `ease-accordion`, `ease-accordion-header`, `ease-accordion-chevron`, and `ease-accordion-panel` classes as outlined in `demo.html`.
