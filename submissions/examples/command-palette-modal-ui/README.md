# Command Palette Modal

A fuzzy-search command palette that drops down with a scale bounce and highlights results.

## Features
- Palette scales in with a spring
- Row hover slides a highlight bar
- Caret pulses in the search input

## Usage
```html
<div class="cm-palette">
  <div class="cm-search"><input placeholder="Type a command&hellip;" /></div>
  <div class="cm-row">Preferences</div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
