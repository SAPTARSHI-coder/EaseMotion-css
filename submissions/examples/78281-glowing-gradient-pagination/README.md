# Glowing Pagination with Gradient Styling

A responsive pagination component with a modern gradient and glowing visual treatment.

## Features

- Responsive pagination layout
- Gradient active-page indicator
- Neon-style glow effects
- Smooth hover animations
- Previous and next controls
- Ellipsis support
- Keyboard-accessible focus states
- Reduced-motion accessibility support
- Pure HTML and CSS
- No JavaScript dependency

## Files

- `demo.html` — pagination markup
- `style.css` — complete styling and responsive behavior

## Accessibility

The pagination uses semantic navigation with an accessible label and
`aria-current="page"` for the active page.

Keyboard focus states are clearly visible, and animations are reduced when
the user has enabled `prefers-reduced-motion`.

## Responsive Behavior

The component adapts across desktop, tablet and mobile screen sizes.
On smaller screens the pagination controls rearrange into a compact grid
while retaining usable touch targets.
