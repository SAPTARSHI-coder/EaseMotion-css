# 🌀 Light Tunnel – Tunnel of Light Spirals Forward

> A mesmerizing light tunnel component where rings of light spiral forward with 5 colors (Rainbow, Blue, Purple, Gold, Pink), speed control (0-100%), and 3D perspective effects.

---

## 📖 Description

The **Light Tunnel** component creates a mesmerizing light tunnel experience where rings of light spiral forward with 3D perspective. Built with vanilla HTML, CSS, and JavaScript, it features 5 colors (Rainbow, Blue, Purple, Gold, Pink), speed control (0-100%), and 60 dynamic rings for an immersive journey.

### 🎯 Core Features

- **Light tunnel** – rings of light spiral forward with 3D perspective
- **5 colors** – Rainbow, Blue, Purple, Gold, Pink
- **Speed control** – adjust tunnel speed from 0-100%
- **60 rings** – dynamic rings with individual properties
- **3D perspective** – realistic depth and projection
- **Ring counter** – tracks number of active rings
- **Interactive controls** – slider, color buttons, keyboard shortcuts
- **Responsive design** – adapts to different screen sizes

### ✨ Tunnel Experience

When interacting:
1. **Rings spiral** – rings move forward with 3D perspective
2. **Speed applies** – controls ring movement speed
3. **Color applies** – changes ring colors
4. **Depth effect** – rings scale and fade with distance
5. **Counter updates** – ring count in real-time
6. **Status updates** – shows current state

### 🛠️ Technologies Used

- **HTML5** – semantic structure with Canvas
- **CSS3** – gradients, backdrop-filter, transforms
- **JavaScript (ES6)** – Canvas API, requestAnimationFrame, 3D projection

### 🎨 Design Philosophy

This component embodies **EaseMotion CSS's animation-first philosophy** through:

- **3D perspective** – realistic depth projection
- **Dynamic rings** – organic ring properties
- **Visual feedback** – status updates, counter, controls
- **Immersive atmosphere** – tunnel effect with glow
- **Human-readable classes** – `.tunnel-controls`, `.color-btn`, `.tunnel-text`

### 🔧 Customization Options

| Property | Location | Default |
|----------|----------|---------|
| Colors | `colorConfigs` object | 5 colors |
| Speed range | `speedSlider` | 0-100% |
| Ring count | `generateRings()` | 60 |
| Perspective | `perspective` | 500 |
| Ring size | `maxSize` | 40% of canvas |
