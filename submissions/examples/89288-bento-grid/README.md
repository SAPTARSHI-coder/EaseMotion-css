# Animated Bento Grid Layout Component

A responsive, modular Bento Grid layout component with hover lift animations and border illumination.

## Features
- **Responsive Layout:** Automatically collapses to a single column on mobile devices.
- **Span Utilities:** Custom grid column span classes for emphasis on key features.
- **Zero Dependencies:** Pure CSS grid implementation with subtle hover transformations.

## File Structure
- `demo.html` - Bento grid markup example.
- `style.css` - Grid column rules and interactive hover states.
