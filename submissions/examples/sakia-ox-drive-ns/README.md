# Sakia Ox Drive

## What does this do?
Renders a self-contained CSS-only `ease-sakia-ox-drive` demo: Sakia ox-driven irrigation wheel.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-sakia-ox-drive`. No build step or JavaScript is required for the effect.

```html
<section class="ease-sakia-ox-drive">
  <div class="ease-sakia-ox-drive__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
