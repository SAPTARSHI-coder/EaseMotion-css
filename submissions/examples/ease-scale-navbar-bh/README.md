# ease-scale-navbar Scale-Hover Navbar

## What does this do?

A responsive navigation bar with scale-hover effects on menu items, perfect for fintech dashboards. Menu items scale up smoothly on hover.

## How is it used?

```html
<nav class="ease-scale-navbar">
  <a class="ease-scale-nav-link" href="#">Dashboard</a>
  <a class="ease-scale-nav-link" href="#">Portfolio</a>
  <a class="ease-scale-nav-link" href="#">Analytics</a>
</nav>
```

### CSS Classes

| Class | Purpose |
|-------|---------|
| `.ease-scale-navbar` | Container for navbar |
| `.ease-scale-nav-link` | Nav link with scale hover |
| `.ease-scale-nav-active` | Active/current page link |

## Why is it useful?

Creates an engaging navigation experience:

- ✅ Smooth scale-up hover effects
- ✅ Active link highlighting
- ✅ Responsive mobile menu
- ✅ Fully accessible
