# Gradient Text Animation Component

**Issue:** [#71858](https://github.com/SAPTARSHI-coder/EaseMotion-css/issues/71858)

Animated gradient text using `background-clip: text` and keyframes.

## Design Tokens

| Token | Default |
|-------|--------|
| `--gt-size` | `clamp(2rem,5vw,3.5rem)` |
| `--gt-weight` | `800` |
| `--gt-trans` | `3s linear infinite` |
