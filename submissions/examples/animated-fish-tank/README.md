# CSS Animated Fish Tank


A pure CSS animated aquarium with swimming fish and bubbles.


## Overview

`css-animated-fish-tank` creates a decorative underwater scene using only HTML and CSS.


## Features

- Pure CSS animation
- Swimming fish movement
- Floating bubbles
- Aquarium water effect
- Responsive layout
- Reduced motion accessibility


## Animation

Includes:

- Fish swimming motion
- Bubble rising animation
- CSS plant decoration


## Usage

Useful for:

- Landing pages
- Creative portfolios
- Educational websites
- UI animation demos
