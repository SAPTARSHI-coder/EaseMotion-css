# Cyberpunk Ripple-Wave Carousel

A futuristic **CSS-only Ripple-Wave Carousel** inspired by cyberpunk interfaces. This showcase demonstrates smooth slide transitions, animated ripple-wave effects, neon glow styling, and glassmorphism using only **HTML5** and **CSS3**—no JavaScript required.

---

## ✨ Features

- 🚀 Pure HTML5 & CSS3
- 🌊 CSS-only Ripple-Wave animation
- ✨ Neon shimmer overlay effect
- 🎨 Cyberpunk-inspired UI
- 🪟 Glassmorphism card design
- 🎠 CSS-only carousel using radio buttons
- 📱 Fully responsive layout
- ♿ Keyboard accessible
- 🎨 Customizable with CSS Custom Properties
- 🌙 Supports `prefers-reduced-motion`

## 🚀 Usage

1. Open `demo.html` in a modern browser.
2. Use the navigation dots to switch between carousel slides.
3. Observe the ripple-wave animation and neon effects.

No JavaScript or external libraries are required.

## 🎨 CSS Custom Properties

The component uses CSS variables for easy customization.

| Variable | Description |
|----------|-------------|
| `--bg` | Background color |
| `--surface` | Glassmorphism container |
| `--primary` | Primary neon color |
| `--secondary` | Secondary neon color |
| `--accent` | Accent highlight |
| `--text` | Primary text color |
| `--muted` | Secondary text color |
| `--radius` | Border radius |
| `--transition` | Transition duration |

Example:

```css
:root{
    --primary:#00f5ff;
    --secondary:#b026ff;
}
```
