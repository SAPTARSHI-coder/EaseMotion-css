# CSS Layered Overlay Stack


A pure CSS component that creates multiple overlapping modal layers with depth.


## Overview

`css-layered-overlay-stack` demonstrates stacked overlays using CSS positioning, transforms and animations.


## Features

- Pure CSS implementation
- No JavaScript dependency
- Multiple depth layers
- Smooth hover interaction
- Responsive design
- Reduced motion accessibility


## Animation

Uses CSS:

- transform
- scale
- translate
- keyframe animation


## Usage

Useful for:

- Modal previews
- Dashboard UI
- Portfolio cards
- Modern interface designs
