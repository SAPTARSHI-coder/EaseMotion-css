# 🌈 Hologram Button – Iridescent Rainbow Shimmer

> A stunning, futuristic button with an iridescent rainbow shimmer that moves across the surface on hover, creating a mesmerizing holographic effect.

---

## 📖 Description

The **Hologram Button** is a futuristic UI component that features an iridescent rainbow shimmer moving across its surface on hover. The button creates a stunning holographic effect with multiple layers of shimmering colors, a glowing border, and a subtle glass-morphism background. The effect mimics the look of a holographic sticker or iridescent material, with colors shifting across the rainbow spectrum.

The component uses multiple CSS techniques: conic gradients for the shimmer effect, backdrop blur for the glass-morphism background, and animated borders for the holographic glow. The button features two shimmer layers spinning at different speeds and directions, creating a complex, mesmerizing holographic effect.

Perfect for futuristic interfaces, cyberpunk themes, creative portfolios, and any application where you want to create a premium, eye-catching button. The Hologram Button transforms a simple interaction into a stunning visual experience.
