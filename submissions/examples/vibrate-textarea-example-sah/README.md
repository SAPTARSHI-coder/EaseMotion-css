# Vibrate Textarea Feedback (`#54715`)

## What does this do?
Delivers intuitive haptic-style horizontal shake and vibration feedback animations when form textareas encounter validation failures or interaction triggers.

## How is it used?
Attach the `ease-textarea-vibrate` class directly to multi-line input elements:
```html
<textarea class="ease-textarea-vibrate" required></textarea>
```

## Why is it useful?
Solves issue #54715 by reinforcing accessibility and user form error awareness through unmistakable kinetic visual cues.
