# Ease Download Pill

## What does this do?

A rounded download status pill containing a download icon and label with a subtle hover animation.

---

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<div class="download-pill">
    <span class="download-icon">↓</span>
    <span>Download</span>
</div>
```

### Features

- Download icon
- Label
- Rounded pill design
- Hover animation
- Click feedback
- Responsive layout
- Lightweight and reusable

---

## Why is it useful?

Download pills are commonly used for file downloads, document links, resource pages, and media interfaces.

This component provides a simple and reusable download control with subtle interaction feedback while following the animation-first philosophy of EaseMotion CSS.
