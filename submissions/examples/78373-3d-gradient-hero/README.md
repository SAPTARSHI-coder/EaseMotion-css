# 3D Hero Section with Gradient Styling

A responsive hero section built with pure HTML and CSS, featuring
layered gradients, 3D perspective, floating cards, glowing ambient
lights, and a CSS-generated cube.

## Features

- Responsive 3D hero section
- CSS-generated 3D cube
- Gradient typography
- Floating information cards
- Animated ambient lighting
- Rotating orbital rings
- Glowing central core
- Responsive navigation
- Responsive CTA layout
- Stats section
- Supporting feature cards
- Hover and focus interactions
- Reduced-motion support
- No JavaScript
- No external assets or dependencies

## Files

- `demo.html`
- `style.css`

## Usage

Open `demo.html` directly in a browser.

The hero can be integrated using the following basic structure:

```html
<section class="hero">
  <div class="hero__content">
    <div class="hero__copy">
      <span class="hero__eyebrow">
        NEXT GENERATION / 3D INTERFACE
      </span>

      <h1>
        Build beyond
        <span>the surface.</span>
      </h1>

      <p>
        Your hero description.
      </p>
    </div>

    <div class="hero__visual">
      <!-- CSS-generated visual content -->
    </div>
  </div>
</section>
