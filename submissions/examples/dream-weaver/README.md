# Dream Weaver

Dream Weaver is a constellation-inspired visualization component that
represents ideas, goals, memories, and concepts as stars within an
interactive dream network.

Instead of organizing information in lists or cards, Dream Weaver
creates a living constellation where relationships become visual paths.

## Features

- Interactive constellation visualization
- Animated twinkling stars
- Connection network rendering
- Fragment inspector panel
- Category display
- Energy scoring
- Creation timestamps
- Focus mode
- Generate connection action
- Toast notifications
- Responsive layout
- Vanilla JavaScript
- No external dependencies
