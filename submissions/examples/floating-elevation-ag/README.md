# Floating Elevation (Soft Lift)

1. What does this do? A smooth hover transition where an element translates upward slightly while casting a larger, softer, and more diffused drop shadow.
2. How is it used? Apply `.hover-lift-card` to a card, image, or container block.
3. Why is it useful? This is a staple for modern web design that mimics a physical object lifting off a surface towards the user. It embodies the "composable" philosophy by handling complex bezier curve transitions automatically for the developer.
