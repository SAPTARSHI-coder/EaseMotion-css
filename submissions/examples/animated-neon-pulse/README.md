# ease-neon-pulse

## Description

Adds a reusable neon glow animation that continuously pulses using animated box-shadows.

The effect works well for:

- CTA Buttons
- Status Indicators
- Badges
- Hero Sections
- Premium Cards

---

## Features

- Pure CSS
- Lightweight
- Infinite Pulse Animation
- Easy Customization
- Responsive

---

## Usage

```html
<button class="ease-neon-pulse">
    Download
</button>
```

---

## Browser Support

- Chrome ✅
- Firefox ✅
- Edge ✅
- Safari ✅

---

## Customization

Change animation duration

```css
animation:neonPulse 2s ease-in-out infinite;
```

Change glow color

```css
box-shadow:
0 0 20px #22d3ee;
```
