Cyberpunk Neon Accordion

Pure HTML & CSS • No JavaScript

01 What is this component? +

A futuristic accordion component inspired by cyberpunk interfaces, featuring neon borders, glow effects and smooth transitions.

02 Is JavaScript required? +

No. The accordion uses the native HTML <details> and <summary> elements, making it lightweight and accessible.

03 Does it support keyboard navigation? +

Yes. Native details/summary behavior provides keyboard support without additional scripting.

04 Is it responsive? +

Yes. The layout adapts to smaller screens while preserving the neon visual effects and readable spacing.
