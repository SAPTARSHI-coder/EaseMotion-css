# Cyberpunk Neon Accordion

A futuristic, responsive accordion built using pure HTML and vanilla CSS.

## Features

- Cyberpunk neon visual design
- Pure HTML & CSS
- No JavaScript
- Native `<details>` and `<summary>` behavior
- Keyboard accessible
- Responsive layout
- Dark-mode friendly
- Reduced-motion support
- Smooth hover and open-state effects
- Lightweight and dependency-free
