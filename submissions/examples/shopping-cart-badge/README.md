# CSS Shopping Cart Badge

A reusable shopping cart component with an animated item-count badge using
pure HTML and CSS.

## Features

- Pure HTML and CSS
- Shopping cart icon
- Item-count badge
- CSS badge pop animation
- Responsive design
- Keyboard accessible
- Visible focus state
- Reduced-motion support
- No JavaScript required

## Files

- `demo.html` – Component demonstration
- `style.css` – Component styles

## Usage

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
