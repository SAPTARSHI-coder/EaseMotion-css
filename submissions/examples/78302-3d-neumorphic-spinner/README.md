# 3D Neumorphic Spinner

A responsive 3D loading spinner built for EaseMotion CSS issue #78302.

## Features

- Pure HTML and CSS
- No JavaScript
- Fully responsive
- Neumorphic visual style
- 3D layered appearance
- Rotating gradient ring
- Animated inner core
- Floating and tilting motion
- Pulsing center indicator
- Responsive mobile layout
- Reduced-motion support
