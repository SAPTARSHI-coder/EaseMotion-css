# CSS Border Radius Morph Visualizer

An interactive visualizer demonstrating how CSS `border-radius` can
smoothly transform an element between different shapes.

## ✨ Features

- Rounded rectangle state
- Circle state
- Pill state
- Organic/blob-like state
- Smooth CSS border-radius transitions
- Replay Morph button
- Current shape indicator
- Current border-radius value
- Responsive layout
- Keyboard-accessible controls
- Visible focus states
- Reduced-motion support
- No external dependencies
