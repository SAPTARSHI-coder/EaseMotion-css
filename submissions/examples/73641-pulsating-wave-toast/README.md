# CSS Toast: Pulsating Wave

A pure CSS toast notification featuring a smooth **Pulsating Wave**
visual effect.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript
- Animated expanding wave rings
- Staggered pulse animation
- Smooth toast entrance
- Subtle shimmer highlight
- Responsive design
- Light and dark mode support
- Keyboard-accessible close control
- Visible focus states
- Reduced-motion support
- Hardware-friendly CSS animations
