# 🎮 Bounce-Pulse Gaming Hero Section

A modern, responsive **Gaming Hub Hero Section** built with pure HTML and CSS for the **EaseMotion CSS** project. The design features bounce and pulse animations, interactive call-to-action buttons, floating decorative elements, and accessibility support.

---

## ✨ Features

- 🎮 Modern gaming-inspired hero section
- 🏀 Bounce animation for the featured gaming card
- 💓 Pulse animation for the live badge
- 🎨 CSS Custom Properties for easy customization
- 📱 Fully responsive layout
- ♿ `prefers-reduced-motion` accessibility support
- ⚡ Smooth CSS transitions and keyframe animations
- 🚫 No JavaScript or external frameworks required

---

## 🚀 Usage

1. Open `demo.html` in any modern browser.
2. Ensure `style.css` is in the same folder.
3. Customize the CSS variables in `:root` to match your project's branding.

---

## 🎨 CSS Custom Properties

```css
:root{
    --bg:#0f172a;
    --bg-secondary:#1e293b;
    --primary:#7c3aed;
    --secondary:#06b6d4;
    --accent:#22c55e;
    --text:#ffffff;
    --text-light:#cbd5e1;
    --radius:20px;
}
```

You can easily change these values to create a different visual theme.
