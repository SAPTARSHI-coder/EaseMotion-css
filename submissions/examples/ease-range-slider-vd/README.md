# Ease Range Slider

## What does this do?

A styled range slider with a progress track and animated thumb interaction.

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<input
    class="ease-range"
    type="range"
    min="0"
    max="100"
    value="65"
    aria-label="Volume"
>
```

### Features

- Adjustable range
- Styled progress track
- Animated thumb interaction
- Focus state
- Responsive layout
- Pure CSS
- No JavaScript required

## Why is it useful?

Range sliders are commonly used for filters, pricing controls, volume settings, preferences, and other interfaces requiring numeric input.

This component provides a clean and reusable slider pattern with subtle interaction feedback while following the animation-first philosophy of EaseMotion CSS.
