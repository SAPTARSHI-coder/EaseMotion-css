# CSS Webhook Payload Viewer (#70982)

A pure CSS collapsible JSON payload viewer designed for inspecting webhook responses and nested event data.

## Features
- Pure CSS collapsible tree built using native `<details>` and `<summary>` elements without JavaScript.
- Syntax highlighting for JSON keys, strings, numbers, booleans, and structural objects.
- Fully accessible with keyboard navigation support and focus indicators.
- Responsive layout with theme styling suitable for light/dark web application dashboards.
