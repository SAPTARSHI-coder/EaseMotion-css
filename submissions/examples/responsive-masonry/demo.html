CSS Container Queries

Style components based on their parent's width instead of the viewport. This makes layouts far more composable — a card can adapt whether it sits in a sidebar or a full-width grid. Browser support is solid now, so there's little reason to wait. Start with a containment context on your layout wrapper and test a few breakpoints before rolling it out everywhere.
