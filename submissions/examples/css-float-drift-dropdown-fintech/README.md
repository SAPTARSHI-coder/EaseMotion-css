# CSS Float-Drift Dropdown for Fintech Dashboard Layouts

A lightweight, responsive fintech dashboard dropdown built using only HTML and CSS.

This example demonstrates a subtle **Float-Drift** interaction where the dropdown smoothly appears from its trigger with opacity, scale, and vertical movement.

## Features

- Pure HTML and CSS
- No JavaScript required
- No external libraries or frameworks
- Smooth CSS transitions
- Float-drift keyframe animation
- Responsive desktop, tablet, and mobile layouts
- CSS custom properties for easy customization
- Keyboard-friendly `:focus-within` interaction
- Visible focus states
- `prefers-reduced-motion` accessibility support
- Lightweight and performant
