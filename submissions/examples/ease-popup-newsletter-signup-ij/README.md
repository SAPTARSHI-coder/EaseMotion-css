# ease-popup-newsletter-signup

A CSS animation component with a scale and rotate transition.

## Usage
Open demo.html in a browser. Click the button to toggle the animation on and off.

## Custom Properties
| Property | Default | Description |
|----------|---------|-------------|
| --primary | hsl(227,80%,50%) | Primary color |
| --bg | #f8fafc | Background color |
| --duration | 0.5s | Animation duration |

## Notes
CSS handles all visual transitions. JavaScript toggles the active state class.
