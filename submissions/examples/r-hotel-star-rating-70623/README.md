# CSS Hotel Star Rating

A responsive hotel rating card styled with a warm luxury-hotel aesthetic.

## Features

- Pure HTML and CSS
- Gold five-star rating display
- 4.8/5 rating presentation
- Rating breakdown bars
- Hotel information and location
- Animated hotel window illustration
- Responsive layout
- Accessible rating information
- Keyboard-focusable review button
- Reduced-motion support
- No JavaScript required

## Files

- `demo.html` - Component markup
- `style.css` - Styling and animations

## Usage

Open `demo.html` in a modern browser.

## Accessibility

The star rating has an accessible `aria-label` describing the
rating. Decorative stars and the hotel illustration are hidden from
assistive technologies where appropriate.

The review button has a visible keyboard focus state.

Animations are disabled when the user has enabled
`prefers-reduced-motion`.

## Browser Support

Designed for modern browsers supporting CSS Grid, gradients,
animations, transforms, and media queries.
