# Floating Hero Section with Glassmorphism

A responsive floating hero section created for EaseMotion CSS
issue #78340.

## Features

- Glassmorphism-inspired interface
- Floating layered cards
- Responsive hero layout
- Animated ambient backgrounds
- Glass shine animation
- Floating dashboard visualization
- Interactive CTA buttons
- Navigation bar
- Floating statistics cards
- Responsive mobile layout
- CSS-only implementation
- No external dependencies
- Reduced-motion support

## Design

The component uses translucent surfaces, backdrop blur,
subtle borders, layered shadows, gradients, and floating
motion to create a modern glassmorphism visual system.

The hero contains:

- Brand navigation
- Large headline
- Supporting description
- Primary and secondary CTAs
- Creator/social proof section
- Floating dashboard card
- Insight card
- Statistics card
- Decorative glass rings

## Responsive Behavior

On desktop, the hero uses a two-column layout with the
content on the left and layered floating cards on the right.

On tablets, the hero switches to a centered single-column
layout.

On mobile devices, navigation is simplified, cards scale
down, buttons stack vertically, and decorative elements are
repositioned to avoid overflow.
