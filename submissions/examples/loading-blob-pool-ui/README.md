# Loading Blob Pool

Three morphing blobs bob inside a pool as an organic loading indicator.

## Features
- Morphing border-radius blobs
- Staggered bob animation
- Soft pastel palette
- Pure CSS

## Usage
```html
<span class="lbp-blob" style="--i:0;--c:#ff7a7a"></span>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
