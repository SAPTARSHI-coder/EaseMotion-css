# Minimalist Outline Drawer

A clean and modern **Minimalist Outline Drawer** built entirely with HTML and CSS.

## Features

- Pure HTML & CSS
- Outline-inspired minimalist design
- Smooth slide-in drawer
- Responsive layout
- Accessible checkbox toggle
- Hardware-accelerated transitions
- Dark mode adaptable
- No JavaScript required
