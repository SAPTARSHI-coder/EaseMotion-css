# Skeleton Loading Screens Submission

## 1. What does this do?
It provides beautiful, animated skeleton loading screens with shimmer effects for various content types (article cards, profile cards, list items). Perfect for modern web applications to show loading states while content is being fetched.

## 2. How is it used?
Add skeleton elements with `.skeleton-shimmer` class to create placeholder content. The shimmer animation creates a smooth gradient effect across the elements. Use different skeleton structures for different content types (cards, profiles, lists).

## 3. Why is it useful?
- Essential component for modern web applications
- Smooth shimmer animation for loading states
- Multiple variants (article cards, profiles, lists)
- Pure CSS implementation (no JavaScript required for animation)
- Lightweight and performant
- Improves user experience by showing content structure
- Fully responsive design
- Accessible with `prefers-reduced-motion` support
- Easy to customize colors and sizes
- Toggle demo to show loaded vs loading states
- Maintainer can easily standardize this as `.ease-skeleton-[YOUR_INITIALS]` in the core library.
