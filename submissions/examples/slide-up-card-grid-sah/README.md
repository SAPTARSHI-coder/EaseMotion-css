# Slide-Up Creative Portfolio Card Grid (`#54525`)

## What does this do?
Provides a pristine editorial gallery grid whose project cards glide smoothly upwards on load and elevate vertically during mouseover.

## How is it used?
Configure card feature blocks inside an `ease-grid-slide-up` layout box:
```html
<div class="ease-grid-slide-up">
  <article class="slide-card step-1 blue">...</article>
</div>
```

## Why is it useful?
Solves issue #54525 by giving high-end editorial and minimalist agency portfolios an effortless vertical storytelling rhythm.
