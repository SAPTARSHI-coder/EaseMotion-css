# Vitest Unit Spec — Split Button Main Action Click Handler

A comprehensive Vitest unit specification for **Split Button Main Action Click Handler**.

## Features

- 🎯 Primary action click handler isolation
- 🔒 Dropdown menu state decoupling (clicking main action does NOT toggle dropdown)
- 🚫 Disabled button click prevention assertions
- 🌊 Ripple animation CSS class activation
- 🧹 Listener detachment on destroy()
