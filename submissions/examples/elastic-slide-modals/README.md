# CSS Elastic-Slide Modal

A responsive modal with an elastic slide entrance animation built using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Responsive layout
- Elastic slide entrance animation
- Lightweight and reusable
- Accessible with `prefers-reduced-motion`
- Easy customization using CSS variables

## Files

- demo.html
- style.css

## Usage

Open `demo.html` directly in any modern browser.

## CSS Variables

```css
:root{
  --bg:#0f172a;
  --card:#1e293b;
  --accent:#38bdf8;
  --text:#ffffff;
}
```
