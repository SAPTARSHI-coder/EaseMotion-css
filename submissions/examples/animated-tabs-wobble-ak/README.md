\# Wobble-Focus Animated Tabs Component (`ease-tabs-wobble-ak`)



A minimalist tech-styled pure CSS animated tabs component featuring a smooth wobble-focus interaction transition built for \*\*EaseMotion CSS\*\*.



\## Features

\- \*\*Wobble-Focus Interaction\*\*: Leverages custom spring easings (`cubic-bezier(0.34, 1.56, 0.64, 1)`) for lively hover and focus states.

\- \*\*Custom CSS Variables\*\*: Easily control timing, scale, and easing globally via `--tabs-timing` and `--tabs-wobble-easing`.

\- \*\*Keyboard Accessible\*\*: Fully supports standard focus rings and keyboard interactions.

\- \*\*Zero JavaScript Dependencies\*\*: Powered entirely by native CSS states and animations.



\## Quick Usage

&#x20;  `submissions/examples/animated-tabs-wobble-ak/`
