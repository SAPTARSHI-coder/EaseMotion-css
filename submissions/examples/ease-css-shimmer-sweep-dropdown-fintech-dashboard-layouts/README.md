# CSS Shimmer-Sweep Dropdown for Fintech Dashboard Layouts

A modern CSS-only dropdown component designed for fintech dashboards with animated shimmer sweep effects, glassmorphism styling, and smooth transitions.

This component provides a lightweight and responsive financial analytics dropdown without using any JavaScript or external libraries.

## ✨ Features

- ✨ Shimmer-sweep hover animation
- 💳 Fintech dashboard inspired UI
- 🎨 Glassmorphism card design
- ⚡ Pure HTML and CSS implementation
- 🔄 Smooth dropdown expand/collapse transition
- 📱 Responsive layout for desktop, tablet, and mobile
- 🌈 Gradient glow effects
- ♿ Accessibility support with `prefers-reduced-motion`

## 🚀 Usage

1. Clone the EaseMotion CSS repository.

2. Navigate to the component folder:


submissions/examples/ease-css-shimmer-sweep-dropdown-fintech-dashboard-layouts/


3. Open `demo.html` in your browser.

No installation or dependencies are required.

## 🎨 CSS Custom Properties

The component uses CSS variables for easy customization:

```css
:root {
    --bg: #050816;
    --primary: #00f5ff;
    --secondary: #8b5cf6;
    --green: #22c55e;
    --text: #f8fafc;
    --muted: #94a3b8;
}

Modify these variables to customize the theme and branding.
