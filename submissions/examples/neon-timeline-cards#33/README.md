# Neon Timeline Cards

This submission demonstrates a glowing timeline UI built with **EaseMotion CSS**.
It includes animated timeline cards, hover lift effects, staggered entrance
animation, and custom neon styling.

## 🌟 Features

- **Timeline layout** with alternating left and right cards on desktop.
- **Staggered entrance animation** using `ease-slide-up` and delay utilities.
- **Hover lift effect** using `ease-hover-lift`.
- **Neon timeline line and dots** created with custom CSS.
- **Responsive layout** that becomes a single-column timeline on mobile.
- **Accessible semantic markup** using header, section, article, and footer.
- **Reduced motion support** for users who prefer less animation.

## 📁 Files

- `demo.html` — interactive timeline demo
- `style.css` — original neon timeline styling
- `README.md` — documentation for this submission

## 🛠️ How to Run

1. Open `demo.html` in your browser.
2. Watch the timeline cards enter with staggered animation.
3. Hover over the cards to see the lift effect.
4. Resize the browser window to check mobile responsiveness.
