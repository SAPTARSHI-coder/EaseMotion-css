# Gradient Flow Shift Color Module

Part of the EaseMotion core animation engine (`core/animations.css`). This module delivers high-performance background gradient shifting using hardware-accelerated matrix transformations.

## Usage

Apply the `.ease-anim-gradient-flow-shift-color` class to any container element. 

```html
<div class="ease-anim-gradient-flow-shift-color">
  Animated Content
</div>
