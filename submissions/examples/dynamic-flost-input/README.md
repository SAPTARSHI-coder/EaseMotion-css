
---

## 🚀 Usage
1. Clone or copy the files into your project.
2. Open `demo.html` in your browser.
3. Click into the input fields to see the floating label animation.

---

## 🛠️ Customization
- **Colors** → Adjust border and label colors in `.input-group input` and `.input-group label`.
- **Animation speed** → Modify `transition: 0.3s ease`.
- **Typography** → Change `font-weight` and `text-transform` for different brutalist aesthetics.

---

## 📖 Accessibility
- Labels are linked with `for` attributes for screen readers.
- Supports `prefers-reduced-motion` for users with motion sensitivity.
- Inputs use `aria-required="true"` for accessibility compliance.
