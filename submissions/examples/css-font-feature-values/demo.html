@font-feature-values

Define named aliases for OpenType stylistic sets — apply them with a single font-variant-alternates: styleset(name) call instead of raw four-character tags.

Stylistic Sets via Named Aliases

Three distinct visual styles activated through custom-named feature values rather than opaque "ss01"/"ss02" tags. Each set changes the letterform without changing the font.

Elegant
styleset(elegant)

Refined letterforms with elongated terminals and wider apertures. Best for headings.

Modern
styleset(modern)

Geometric precision with simplified, clean shapes. Best for UI and data displays.

Playful
styleset(playful)

Expressive, creative letterforms with unexpected curves. Best for branding.

@font-feature-values "Source Serif 4" {
  @styleset {
    elegant: 1;   /* maps to ss01 in the font */
    modern:  2;   /* maps to ss02 in the font */
    playful: 3;   /* maps to ss03 in the font */
  }
}
.card-elegant { font-variant-alternates: styleset(elegant); }
.card-modern  { font-variant-alternates: styleset(modern); }
.card-playful { font-variant-alternates: styleset(playful); }
