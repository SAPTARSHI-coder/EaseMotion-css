# Responsive Floating Label Input with Gradient Glow

A responsive floating-label input component featuring an animated gradient border and glow effect, implemented entirely with HTML and CSS.

## Features

- Pure HTML and CSS
- Zero JavaScript dependencies
- Floating labels
- Animated gradient focus border
- Gradient glow effect
- Smooth hover and focus transitions
- Input validation states
- Responsive desktop, tablet, and mobile layouts
- Keyboard-accessible focus indicators
- `prefers-reduced-motion` support
- Semantic form controls
- No external libraries
