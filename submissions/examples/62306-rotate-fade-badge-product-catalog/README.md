# CSS Rotate-Fade Badge for Product Catalog Layouts

A modern **Rotate-Fade Badge** component built using pure HTML5 and CSS3 for product catalog showcase layouts. This component provides animated product badges with smooth rotation, fade-in effects, glassmorphism cards, and responsive design.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Smooth rotate and fade entrance animation
* Product catalog card showcase
* Animated category badges
* New, sale, and premium badge variants
* Gradient badge styling
* Smooth hover card elevation
* Responsive product grid layout
* CSS Custom Properties for easy customization
* Lightweight keyframe animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. View animated product cards with rotating badges.
3. Customize colors, shadows, radius, and animations using CSS variables inside `:root`.

## CSS Custom Properties

```css
:root{
  --bg:#eef4ff;
  --surface:rgba(255,255,255,.92);
  --primary:#2563eb;

  --muted:#64748b;
  --shadow:0 25px 60px rgba(37,99,235,.18);

}
```
