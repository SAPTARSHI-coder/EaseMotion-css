# Slide-Right Tabs (SaaS Showcase Component)

A modern, high-performance UI tab component built with **zero JavaScript**, engineered using CSS structural selectors and smooth custom transition curves tailored for SaaS landing pages and application showcases.

## Features
- **Zero JavaScript Overhead:** Runs entirely on native HTML radio buttons and CSS state evaluation (`:checked` combinators).
- **Slide-Right Animation:** Utilizes `transform: translateX()` coupled with smooth cubic-bezier transitions.
- **Customizable Properties:** Easily tweak animation timelines and easing profiles using standard CSS variables (`--tab-duration`, `--tab-easing`).
- **Fully Responsive:** Gracefully collapses from a horizontal layout to a stacked column structure on smaller mobile viewports.

## How to Use
1. Include `demo.html` and `style.css` in your project workspace.
2. Structure your radio inputs matching the corresponding panel IDs.
