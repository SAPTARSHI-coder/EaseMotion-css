# Floating Label Input Component

An interactive form input component featuring pure CSS floating label focus transitions.

## Features
- **Zero JavaScript:** Utilizes the CSS `:not(:placeholder-shown)` and `:focus` selector trick.
- **Smooth Translation:** Keyframe-free transform translation with smooth font scaling.
- **Custom Glow Focus:** Integrated ring glow on active input focus.

## File Structure
- `demo.html` - Form field structure with input and label markup.
- `style.css` - Floating translation rules and border glow states.
