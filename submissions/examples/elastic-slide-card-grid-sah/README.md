# Elastic-Slide Creative Portfolio Card Grid (`#54532`)

## What does this do?
Provides an exhibition gallery grid whose card overlays slide upwards from the bottom border with lively elastic spring rebound when hovered.

## How is it used?
Encapsulate sliding content panels within cards inside an `ease-grid-elastic-slide` parent grid:
```html
<div class="ease-grid-elastic-slide">
  <article class="elastic-card blue"><div class="slide-panel">...</div></article>
</div>
```

## Why is it useful?
Solves issue #54532 by giving designer case study thumbnails an appealing storytelling mechanism that reveals details on demand.
