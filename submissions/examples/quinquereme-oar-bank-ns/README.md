# Quinquereme Oar Bank

## What does this do?
Renders a self-contained CSS-only `ease-quinquereme-oar-bank` demo: Quinquereme oar bank synchronized stroke.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-quinquereme-oar-bank`. No build step or JavaScript is required for the effect.

```html
<section class="ease-quinquereme-oar-bank">
  <div class="ease-quinquereme-oar-bank__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
