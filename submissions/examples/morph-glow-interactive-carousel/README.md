# CSS Morph-Glow Carousel for Accessible Web Layouts

A modern **Morph-Glow Carousel** component created using only **HTML5 and CSS3**. This showcase provides animated carousel cards with morphing glow effects, smooth hover interactions, responsive design, and accessibility support without JavaScript.

---

## ✨ Features

- 🌈 Morphing glow animation
- 🎴 Interactive carousel cards
- 💫 Animated gradient effects
- 🔥 Smooth hover transitions
- 💎 Glassmorphism UI
- 🎯 CSS Custom Properties
- 📱 Responsive layout
- 🧩 Pure HTML5 & CSS3
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

---

## 🚀 Usage

1. Open `demo.html` in any modern browser.
2. Hover over cards to activate morphing glow effects.
3. Modify CSS variables to customise the component.
