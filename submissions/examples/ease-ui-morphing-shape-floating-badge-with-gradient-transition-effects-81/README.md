# Morphing Shape Floating Badge with Gradient Transition Effects

## Overview

A modern dark mode floating badge component featuring animated
morphing shapes, gradient color transitions, and smooth floating
effects.

Built using pure HTML, CSS, and JavaScript.

## Features

- 🌈 Animated gradient transitions
- 🔄 Morphing blob shape animation
- ✨ Floating motion effect
- 🌙 Dark mode UI design
- ⚡ Smooth CSS animations
- 🎨 Modern vibrant colors
- 📱 Responsive layout

## Usage

1. Open `demo.html` in any modern browser.
2. View the animated floating badge.
3. Click the button to change badge appearance.
