# Slide-Up Pricing Table

A responsive pricing table built with **pure HTML and CSS**. Each pricing card smoothly slides upward on hover or keyboard focus while maintaining accessibility and responsive behavior without requiring JavaScript.

---

## ✨ Features

- Pure HTML5 & CSS3
- Smooth slide-up hover animation
- Responsive pricing cards
- Featured pricing plan
- CSS Custom Properties
- Keyboard accessible
- Supports `prefers-reduced-motion`
- Lightweight and dependency-free

---

```text
slide-up-pricing-table-vk/
```

---

## 🚀 Usage

1. Open `demo.html` in any modern browser.
2. Hover over a pricing card to see the slide-up animation.
3. Navigate using the **Tab** key to test keyboard accessibility.

## 📱 Responsive Design

The pricing table uses CSS Grid with `auto-fit` and `minmax()` to automatically adapt across desktop, tablet, and mobile devices.
