# Floating Dock Navigation Component

A glassmorphism macOS-style dock navigation component featuring hover magnification and tooltip labels.

## Features
- **Interactive Magnification:** 60fps translate and scale transformations on item hover.
- **Pure CSS Tooltips:** Data-attribute tooltips rendered using CSS `attr()` content.
- **Zero JavaScript:** Interactive floating dock created purely using CSS.

## File Structure
- `demo.html` - Dock layout container and action items.
- `style.css` - Backdrop filter rules and hover magnification scale utilities.
