# CSS Notification Bell Dropdown

## Features

- Pure CSS notification dropdown
- Animated bell icon
- Notification badge counter
- Smooth dropdown reveal animation
- Responsive design
- No JavaScript required

## Files

- `demo.html`
- `style.css`

## How to Use

Open `demo.html` in any browser.

Click the bell icon to toggle the notification panel.

## Why it fits EaseMotion CSS

This component provides a reusable notification dropdown pattern with smooth CSS-based animations and interactions. It is lightweight, responsive, visually appealing, and requires no JavaScript, making it a valuable addition to the EaseMotion CSS component library.
