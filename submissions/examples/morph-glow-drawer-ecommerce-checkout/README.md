# Morph-Glow Drawer for E-Commerce Checkout

A pure CSS/HTML Morph-Glow Drawer designed for modern
e-commerce checkout layouts.

## Features

- Pure HTML and CSS
- No JavaScript
- No external frameworks
- Smooth drawer entrance animation
- Morphing border-radius hover effect
- Subtle glow animation
- Responsive checkout layout
- CSS custom properties
- Interactive checkout button
- Keyboard focus support
- `prefers-reduced-motion` accessibility support
