# CSS Animated Rocket Launch


A pure CSS animated rocket launch component with flame effects and smoke trail.


## Overview

`ease-animated-rocket-launch` creates a space rocket launching animation using only CSS.


## Features

- Pure CSS animation
- No JavaScript dependency
- Animated rocket movement
- Flame effect
- Smoke trail animation
- Responsive design
- Reduced motion accessibility support


## Animations

Used animations:

```css
@keyframes rocket_launch

@keyframes fire_move

@keyframes smoke_rise
