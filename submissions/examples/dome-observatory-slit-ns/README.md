# Dome Observatory Slit

## What does this do?
Renders a self-contained CSS-only `ease-dome-observatory-slit` demo: Observatory dome slit rotating to track the sky.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-dome-observatory-slit`. No build step or JavaScript is required for the effect.

```html
<section class="ease-dome-observatory-slit">
  <div class="ease-dome-observatory-slit__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
