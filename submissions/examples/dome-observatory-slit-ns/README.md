# Ease Dome Observatory Slit

A CSS-only animated observatory dome slit component for EaseMotion CSS.

## Overview

`ease-dome-observatory-slit` recreates an astronomical observatory dome rotating to track objects in the sky.

## Features

- Pure CSS animation
- No JavaScript dependency
- Rotating dome slit effect
- Observatory themed UI
- Telescope tracking indicator
- Responsive design
- Reduced motion support
