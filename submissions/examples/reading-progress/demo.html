Scroll-Driven Reading Progress Bar

Scroll down the page to see the progress bar animate at the top of the screen.

This reading progress bar is built 100% in CSS using the modern animation-timeline: scroll() feature. No JavaScript is required to calculate the scroll percentage or update the DOM.
