# Slide-Up Creative Portfolio Tabs (`#54465`)

## What does this do?
Provides a pristine editorial tabbed layout where section panels transition into view via clean ascending vertical gliding mechanics.

## How is it used?
Configure slide panels inside an `ease-tabs-slide-up` component layout:
```html
<div class="ease-tabs-slide-up">
  <div class="slide-pane active">...</div>
</div>
```

## Why is it useful?
Solves issue #54465 by giving luxury brand showcases and magazine UX layouts an effortless ascending storytelling rhythm.
