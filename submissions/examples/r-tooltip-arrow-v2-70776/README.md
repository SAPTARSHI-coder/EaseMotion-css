# CSS Tooltip With Arrow v2

A responsive CSS-only tooltip component with an arrow pointer,
delayed appearance, and smooth fade/slide animation.

## Features

- Pure HTML and CSS
- No JavaScript
- Delayed tooltip appearance
- Delayed disappearance
- CSS-generated arrow
- Hover support
- Keyboard focus support
- Multiple tooltip positions
- Responsive design
- Accessible tooltip roles
- Reduced-motion support

## Files

- `demo.html` — Tooltip demonstration
- `style.css` — Complete component styling
- `README.md` — Documentation
