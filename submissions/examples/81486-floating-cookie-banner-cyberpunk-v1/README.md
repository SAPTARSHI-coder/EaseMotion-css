# Floating Cookie Banner — Cyberpunk

A futuristic floating cookie consent banner built with pure HTML
and CSS, featuring a cyberpunk-inspired visual language.

## Features

- Pure HTML and CSS
- Zero external JavaScript dependencies
- Floating responsive layout
- Cyberpunk neon accents
- Cyan and magenta glow effects
- Animated status indicator
- Animated scanline
- Futuristic corner decorations
- Interactive buttons
- Keyboard focus states
- Responsive desktop, tablet, and mobile layouts
- `prefers-reduced-motion` support
