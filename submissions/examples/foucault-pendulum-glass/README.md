# Foucault Pendulum Glass Effect

A smooth glassmorphism UI featuring a Foucault Pendulum Swing animation using pure HTML and Vanilla CSS.

## ✨ Features

- Pure HTML & CSS
- No JavaScript
- Glassmorphism UI
- Foucault pendulum swing animation
- Smooth CSS transitions
- 3D perspective
- Responsive design
- Dark-mode friendly
- Hardware-friendly CSS transforms
- Reduced-motion accessibility support
