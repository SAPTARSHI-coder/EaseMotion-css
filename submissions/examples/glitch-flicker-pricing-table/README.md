# CSS Glitch-Flicker Pricing Table

A responsive fintech pricing table featuring a lightweight CSS
glitch-flicker interaction.

The component is built entirely with HTML and CSS and requires
no JavaScript or external animation library.

## Features

- Pure HTML and CSS
- No JavaScript
- Glitch-flicker hover animation
- Animated light sweep effect
- Responsive pricing cards
- Featured pricing plan
- Keyboard focus support
- CSS custom properties
- `prefers-reduced-motion` support
- Semantic HTML structure
- Mobile-friendly layout
