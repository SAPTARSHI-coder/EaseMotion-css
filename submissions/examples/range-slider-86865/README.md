# Range Slider (#86865)

A modern custom range slider component featuring an active progressive track fill, luminous glowing thumb on drag, and a floating value tooltip.

## Features
- **Dynamic Track Fill:** Uses CSS custom property `--slider-fill` to update progressive gradient fills across the slider track.
- **Glowing Thumb State:** Neon pulse and ambient shadow elevation active on dragging/interaction.
- **Floating Value Tooltip:** Real-time badge positioned above the slider thumb reflecting current numeric value.
- **Accessibility:** Semantic HTML `<input type="range">` with full keyboard adjustment support (Arrow keys, Page Up/Down).

## Usage
Include `style.css` in your project and structure the markup using `.slider-wrapper`.
