# CSS Shimmer-Sweep Tooltip for Accessible Web Layouts

A modern **Shimmer-Sweep Tooltip** component built completely with **HTML5 and CSS3**. This showcase demonstrates interactive tooltips with animated shimmer effects, smooth transitions, glassmorphism styling, responsive behaviour, and accessibility support without requiring JavaScript.

---

## ✨ Features

- ✨ Shimmer sweep animation
- 🌊 Smooth tooltip entrance
- 💎 Glassmorphism tooltip design
- 🎨 Gradient action buttons
- 🔥 Animated highlight effect
- ⚡ Lightweight CSS animations
- 🎯 CSS Custom Properties
- 📱 Fully responsive layout
- 🧩 Pure HTML5 & CSS3
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

## 🚀 Getting Started

1. Open `demo.html` in any modern browser.
2. Hover over the buttons to display the tooltips.
3. Use keyboard focus to access tooltip content.
4. Customize colors and animation values using CSS variables.
