# Magnetic Hover Glow Button

1. What does this do? Creates a soft, premium glowing aura that radiates outward when a button is hovered.
2. How is it used? Apply `.magnetic-glow-btn` to a button element.
3. Why is it useful? It instantly transforms static buttons into premium, interactive components without any JavaScript dependencies, staying true to EaseMotion CSS's philosophy of accessible, animation-first utilities.
