# Foldline

Foldline is an experimental interactive paper-folding component.

Instead of using a traditional card-flip interaction, the component allows
users to drag a physical-looking corner of a sheet and progressively reveal
another surface underneath it.

The interaction is designed around the metaphor of architectural paper,
technical drawings, and physical stationery.

## ✨ Features

- Interactive paper surface
- Drag-to-fold interaction
- Dynamic fold percentage
- Dynamic fold angle
- Dynamic fold distance
- Fold-line visualization
- Dynamic fold shadow
- Progressive hidden-surface reveal
- Full reveal state
- Technical measurement panel
- Reset interaction
- Responsive layout
- Mouse support
- Touch support
- Stylus support
- Pointer Events
- Reduced-motion support
- No external JavaScript dependencies
