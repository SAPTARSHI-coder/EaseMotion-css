# Circular color picker

A round colour-selection wheel whose hue ring glows and a rotating pointer selects the active hue.

## How to view

Open `demo.html` in any modern browser. The demo is fully self-contained — no CDN, no framework, no JavaScript.

## How to use

Copy `style.css` into your project's stylesheet. Every class used in the demo is namespaced with `circularcolorpicker-` to avoid collisions.

## Why this is useful for EaseMotion CSS

Picker UI used in design tools; the glow on the ring signals which slice is active.
