# Float-Drift Card Grid for Minimalist Tech Layouts

## Overview

The **Float-Drift Card Grid** is a lightweight CSS animation component designed for modern minimalist technology interfaces.

It creates a collection of glass-style cards with smooth floating drift motion using only HTML and CSS.

No JavaScript or external libraries are required.

---

## Features

- ✨ Smooth floating drift animation
- 🎨 Minimalist glassmorphism card design
- ⚡ Pure CSS implementation
- 📱 Fully responsive card grid
- 🖱️ Interactive hover elevation effect
- ♿ Supports `prefers-reduced-motion`
- 🚀 Lightweight and performance friendly
