# CSS Cyberpunk Neon Variation

A demo project showcasing a **cyberpunk neon aesthetic** using HTML and CSS.

## Features
- Neon glowing title with flicker animation.
- Futuristic card with glowing border and shadows.
- Neon-styled button with hover color swap.
- Dark gradient background for cyberpunk atmosphere.

## Files
- `demo.html` → Structure with hero section and neon card.
- `style.css` → Neon glow styles, animations, and layout.
- `README.md` → Documentation and usage instructions.

## Usage
1. Open `demo.html` in your browser.
2. Observe the glowing neon card with animated title and button.
3. Customize text and colors for your own cyberpunk theme.

## Customization Ideas
- Add multiple neon cards in a grid layout.
- Use CSS variables for easier color swapping.
- Integrate with background animations (moving grids, glitch effects).
- Extend into a full cyberpunk landing page.
