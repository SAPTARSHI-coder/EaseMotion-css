ease-rotate-fade-carousel

Slides transition with a combined rotate + fade motion. Use the dots or arrow keys to navigate.

01

Zero Dependencies

A single CSS file powers every animation. No build step, no runtime, no framework.

02

GPU Accelerated

All motion runs on transform and opacity so compositing stays on the GPU.

03

Accessible

Reduced-motion support and keyboard navigation are built in by default.

04

Composable

Drop a slide in, change the easing variable, ship the carousel.
