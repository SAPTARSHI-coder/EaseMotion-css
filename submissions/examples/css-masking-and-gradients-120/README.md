# Shimmering Metallic Foil Text Effect

A CSS-only shimmering metallic foil text effect using gradients,
background clipping, and smooth animation.

## Features

- Metallic gradient effect
- Smooth shimmer animation
- Responsive typography
- CSS-only implementation
- Reduced-motion accessibility support
- No external libraries

## Files

- `demo.html` - Component demo
- `style.css` - Component styling and animation

## Usage

1. Open `demo.html` in a browser.
2. The metallic text effect will automatically animate.
3. Copy the HTML and CSS into your project to reuse the effect.

## Technologies

- HTML5
- CSS3
- CSS Gradients
- CSS Animations
- Background Clipping

## Accessibility

The animation respects the user's
`prefers-reduced-motion` setting.
