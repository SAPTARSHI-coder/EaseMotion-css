# CSS Two-Factor QR Code

A responsive two-factor authentication setup component built using pure HTML and CSS.

## Features

- Pure HTML and CSS
- QR-code style setup placeholder
- Manual authentication setup key
- Six-digit verification input
- Responsive design
- Keyboard accessible controls
- Visible focus states
- Semantic labels and ARIA attributes
- `autocomplete="one-time-code"` support
- Reduced-motion support
- No JavaScript dependencies
- Modern authentication UI
