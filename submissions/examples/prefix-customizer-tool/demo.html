Prefix Customizer Script

This submission provides a Node.js utility to safely customize the default .em- prefix inside the compiled easemotion.min.css file.

Why do this?

If your codebase already has another library that uses .em- classes, you can use this script to easily rename all EaseMotion classes to something unique like .motion- or .mybrand-, avoiding CSS namespace collisions without having to fork the core library.

How to use:

# Navigate to this example folder
cd submissions/examples/prefix-customizer-script/

# Run the script with your desired prefix
node customize.js myapp-

# The script will generate a new file:
easemotion.custom.css

You can then link easemotion.custom.css in your HTML and use class="myapp-fade-in"!
