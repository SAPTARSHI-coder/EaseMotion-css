# Cyberpunk Glowing Navbar

A highly stylized, pure CSS navigation bar featuring aggressive neon aesthetics, text glitch effects, and a responsive 3D perspective grid background.

## Features
- **Authentic Glitch Logo**: The branding logo utilizes a pure CSS text glitch effect generated by duplicating the text via `::before` and `::after` pseudo-elements, offsetting their `clip-path` masks, and animating them with `@keyframes`.
- **Neon Micro-interactions**: Hovering over navigation links reveals neon pink bracket brackets `[ ]` that animate outwards, while the text itself glows with a deep cyan `text-shadow`.
- **Clipped Cyber Button**: The primary Call-to-Action button features the classic cyberpunk angled/clipped corners, achieved flawlessly using CSS `clip-path: polygon()`.
- **Pure CSS Mobile Menu**: Fully responsive dropdown menu controlled entirely by the `<input type="checkbox">` hidden hack. The hamburger icon elegantly animates into a close 'X' when triggered, shifting color from Cyan to Pink.
- **3D Perspective Grid Background**: The ambient background utilizes CSS `transform: perspective()` and `rotateX()` to lay a neon grid flat into the background, animating it continuously towards the user.

## Usage
Include `demo.html` and `style.css` in your project. Ensure the `Orbitron` font family is loaded in your `<head>`. 
- **Important**: To use the Glitch Logo, you must ensure the `data-text` HTML attribute matches the actual text content of the `.glitch-text` span exactly (e.g., `<span class="glitch-text" data-text="YOUR_TEXT">YOUR_TEXT</span>`).
