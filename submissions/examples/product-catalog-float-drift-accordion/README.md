# Product Catalog Float-Drift Accordion

A lightweight, pure HTML/CSS Float-Drift Accordion designed for modern
product catalog and e-commerce layouts.

## Features

- Pure HTML and CSS
- No JavaScript or external frameworks
- CSS `<details>` and `<summary>` accordion interaction
- Smooth float-drift animation
- Animated product visuals
- Responsive product catalog layout
- CSS custom properties for easy customization
- Keyboard-friendly native accordion interaction
- `prefers-reduced-motion` support
- Mobile, tablet, and desktop responsive behavior
