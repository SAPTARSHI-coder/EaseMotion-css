# CSS Shimmer Sweep Navbar for Product Catalog Layouts

A sleek and modern navigation bar featuring a shimmering sweep animation for active and hovered navigation links. Designed specifically for product catalog interfaces using only HTML and CSS.

## Features

- Pure HTML5 & CSS3
- Elegant shimmer sweep hover animation
- Sticky responsive navbar
- Modern glassmorphism appearance
- Gradient CTA button
- Product showcase cards
- Mobile responsive layout
- CSS Custom Properties for easy customization
- Supports `prefers-reduced-motion`
- No JavaScript required
