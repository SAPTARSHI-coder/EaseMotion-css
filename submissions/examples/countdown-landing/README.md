# Countdown Landing

A landing countdown where flip cards tick down days, hours, minutes and seconds.

## Features
- Each unit flips down like a scoreboard
- Colons pulse between unit groups
- Gradient digits on dark flip cards

## Usage
```html
<div class="cd-row">
  <div class="cd-unit"><div class="cd-card">23</div><div class="cd-label">Days</div></div>
  <div class="cd-colon">:</div>
  <div class="cd-unit"><div class="cd-card">08</div><div class="cd-label">Secs</div></div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
