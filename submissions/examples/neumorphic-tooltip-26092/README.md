# Neumorphic Tooltip

This component adds a smooth, minimalist neumorphic tooltip that reveals on hover with a subtle transition.

## Usage

```html
<div class="tooltip-container">
  <button class="neumorphic-btn">Hover Me</button>
  <div class="neumorphic-tooltip">Minimalist Tooltip</div>
</div>
```

## Why is it useful?

It provides an elegant, modern, and accessible way to display additional context without cluttering the UI, aligning perfectly with EaseMotion's philosophy of smooth and minimalist interactive elements.
