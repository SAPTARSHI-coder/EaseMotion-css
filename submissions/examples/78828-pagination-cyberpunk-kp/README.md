# Glassmorphism Pagination - Cyberpunk

A cyberpunk glassmorphism pagination component for issue #78828. It includes frosted page controls, neon active states, scanline motion, responsive wrapping, and reduced-motion support.

## Features

- Frosted glass pagination controls
- Cyberpunk active, hover, and keyboard focus states
- Responsive layout with previous and next affordances
- Pure HTML and CSS, no external assets
