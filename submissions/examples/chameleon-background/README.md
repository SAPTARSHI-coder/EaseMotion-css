# Chameleon Background

A page background that slowly morphs through a full-spectrum gradient wash.

## Features
- Background cycles through six palettes
- Hue shifts across the whole panel
- Soft noise of moving gradient stops

## Usage
```html
<div class="stage">
  <div class="cmb-panel"></div>
  <div class="cmb-text">ALWAYS CHANGING</div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
