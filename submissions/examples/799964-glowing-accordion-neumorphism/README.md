# Glowing Neumorphic Accordion

A responsive accordion component combining soft Neumorphism styling with subtle glowing interactions.

## ✨ Features

- Pure HTML and CSS
- No JavaScript
- Responsive design
- Neumorphic raised and pressed surfaces
- Glowing hover and active states
- Smooth content reveal
- Native HTML `details` and `summary`
- Interactive plus/minus indicators
- Keyboard-friendly controls
- Reduced-motion support
- Mobile-friendly layout
