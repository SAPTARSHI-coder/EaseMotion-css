# Retro Arcade Pixel Neumorphic

A pure CSS neumorphic UI component inspired by classic retro arcade interfaces.

## Features

- Retro arcade pixel-inspired visual design
- Neumorphic soft-shadow surfaces
- Smooth hover and active interactions
- CSS-only pixel animations
- Responsive layout
- Dark-mode-friendly color palette
- Hardware-friendly CSS transforms
- No JavaScript or external dependencies
- Accessible keyboard focus states
- `prefers-reduced-motion` support

## Files

- `demo.html` — Self-contained demonstration page
- `style.css` — Complete component styling
