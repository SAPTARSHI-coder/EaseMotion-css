# Animated Call To Action

A modern animated call-to-action section built with pure HTML and CSS. It includes floating gradient orbs, animated buttons, stat badges, and responsive layout.

## Features

- Pure HTML and CSS implementation.
- Animated gradient border card.
- Floating background orbs.
- Smooth button hover shine effect.
- Stat badges with hover effect.
- Responsive layout.
- Supports `prefers-reduced-motion`.

## Usage

Copy the HTML structure from `demo.html` and link `style.css`.

```html
<section class="cta-card">
  <div class="cta-content">
    <h1>Build beautiful animated interfaces</h1>
    <p>Call to action description here.</p>

    <div class="cta-actions">
      <a href="#" class="cta-btn primary">Start Free</a>
      <a href="#" class="cta-btn ghost">View Docs</a>
    </div>
  </div>
</section>
