# Glassmorphism Switch Component

A toggle switch component featuring frosted glass container styling and smooth slider thumb transitions.

## Features
- **Glassmorphism Backdrop:** Translucent track built with CSS `backdrop-filter`.
- **Fluid Slider:** Pure CSS cubic-bezier sliding transform on check state toggle.
- **Pure CSS:** Zero JavaScript dependencies.

## File Structure
- `demo.html` - Minimal checkbox label structure.
- `style.css` - Component track styling and active slider state animations.
