Mobile Sidebar Scroll Lock

Pure CSS mobile drawer overlay with overscroll-behavior contain and background body scroll isolation.

Scroll Leak Issue

When mobile sidebars open, scrolling inside the drawer frequently leaks to the background document body, creating confusing layout shifts.

Pure CSS Solution

This implementation utilizes overscroll-behavior: contain and container state body locking to guarantee independent scroll behavior.

Accessibility & ARIA

Features semantic navigation markup, focus rings, and high contrast WCAG AA compliant theme variables.
