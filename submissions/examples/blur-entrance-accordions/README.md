# CSS Blur-Entrance Accordion

A responsive accordion component featuring a blur-to-clear entrance animation for creative portfolio layouts.

## Features

- Pure HTML & CSS
- Blur entrance animation
- Smooth transitions
- Mobile responsive
- Accessible markup
- Supports `prefers-reduced-motion`

## Files

- demo.html
- style.css

## Usage

```html
<link rel="stylesheet" href="style.css">
```

Use the provided accordion structure from `demo.html`.

## Customization

Modify CSS variables:

```css
:root{
  --accent:#6366f1;
  --duration:.5s;
  --radius:12px;
}
```

## Accessibility

- Keyboard accessible
- Semantic HTML
- Reduced motion support
