# Bounce-Pulse Toast

A pure CSS animated toast component for product catalog layouts.

## Features

- Bounce entrance animation
- Smooth pulse glow effect
- Glass-style UI
- Responsive design
- No JavaScript required
- Reduced motion accessibility support


## Usage

Copy `demo.html` and `style.css`
into your project.
