Sticky Header Shrink on Scroll

Scroll down to see the header shrink and adjust its styling.

Features

✓ Smooth height transition

✓ Background color change

✓ Shadow adjustment

✓ Font size reduction

✓ Blur effect option

✓ Border effect option

How It Works

The header uses JavaScript to detect scroll position and apply the "ease-scrolled-bh" class when the page is scrolled. The CSS then transitions all properties smoothly.

Usage

Add the "ease-scrolled-bh" class to the header when page is scrolled.

window.addEventListener('scroll', () => {
  const header = document.querySelector('.ease-sticky-header-bh');
  if (window.scrollY > 50) {
    header.classList.add('ease-scrolled-bh');
    document.body.classList.add('ease-header-scrolled');
  } else {
    header.classList.remove('ease-scrolled-bh');
    document.body.classList.remove('ease-header-scrolled');
  }
});
