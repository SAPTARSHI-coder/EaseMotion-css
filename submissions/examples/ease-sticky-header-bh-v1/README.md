# ease-sticky-header-bh

Pure CSS sticky header that shrinks on scroll.

## What does this do?
Creates a sticky header that reduces its height and adjusts styling when the page is scrolled.

## How is it used?
```html
<header class="ease-sticky-header-bh">
  <!-- Header content -->
</header>
```

## Why is it useful?
Saves screen space while maintaining navigation accessibility as users scroll.
