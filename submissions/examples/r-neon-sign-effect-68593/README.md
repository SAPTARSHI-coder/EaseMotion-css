# CSS Neon Sign Effect

A glowing neon sign text effect with a subtle flicker animation.

## Features

- Pure HTML and CSS
- Neon glow using text shadows
- Subtle flicker animation
- Responsive typography
- Reduced-motion support
- No JavaScript required

## Accessibility

The heading provides the main accessible name and the animation
is disabled when `prefers-reduced-motion: reduce` is enabled.

## Customization

Change `--pink`, `--cyan`, and the text-shadow values to create
different neon color themes.
