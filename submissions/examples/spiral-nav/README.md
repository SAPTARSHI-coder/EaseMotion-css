# 🌀 Spiral Nav – Items in Spiral Pattern

## Overview

**Spiral Nav** is an interactive navigation component that arranges menu items in a smooth spiral pattern using pure HTML, CSS, and JavaScript. It provides an engaging and visually unique navigation experience suitable for creative portfolios, dashboards, games, and interactive websites.

---

## Features

- 🌀 Dynamic spiral layout
- ✨ Smooth expand/collapse animation
- 🎯 Click to select navigation items
- 🔄 Optional auto-rotation
- 🎚️ Adjustable spiral spacing
- ⚡ Adjustable rotation speed
- ⌨️ Keyboard shortcuts
- 📱 Responsive design
- 🎨 Pure HTML, CSS & JavaScript
- 🚫 No external libraries required

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| Space | Expand / Collapse |
| R | Toggle Auto Rotation |
| 1–9 | Select Navigation Item |

---

## Controls

- **Expand / Collapse** button
