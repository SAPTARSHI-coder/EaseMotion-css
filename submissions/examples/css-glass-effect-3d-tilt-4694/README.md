# CSS Glass Effect: 3D Perspective Tilt Variation

A smooth, accessible, and performant pure CSS glassmorphism UI featuring 3D Perspective Tilt styling.

## Features
- Pure HTML & Vanilla CSS (no external JS required).
- Hardware-accelerated 3D transforms (`transform: rotateX`, `rotateY`, `translateZ`, `preserve-3d`).
- Smooth hover transitions.
- Fully compatible with Dark Mode using CSS variables and `prefers-color-scheme`.
- High accessibility standards.

## How to use
1. Copy the HTML structure into your project.
2. Link the provided `style.css` file or copy its contents into your stylesheet.
3. The `.ease-glass-tilt-4694` class implements the 3D tilt glassmorphism effect.

## Preview
Open `demo.html` in your web browser to view the effect.
