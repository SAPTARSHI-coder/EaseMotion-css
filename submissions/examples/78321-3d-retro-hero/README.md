# 3D Retro Hero Section

A responsive 3D hero section inspired by retro arcade interfaces.

## Features

- Pure HTML and CSS
- No JavaScript
- CSS 3D cube with perspective
- Animated orbit rings and particles
- Retro arcade typography
- Layered shadows and gradients
- Responsive desktop, tablet, and mobile layouts
- Keyboard-friendly CTA links
- Reduced-motion support
