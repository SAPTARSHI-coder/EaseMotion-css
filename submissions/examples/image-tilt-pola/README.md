# Image Tilt Pola

Polaroid-style photos tilt at playful angles and straighten on hover.

## Features
- Polaroid frame + tape
- Alternating tilt
- Straighten + lift on hover
- Pure CSS

## Usage
```html
<figure class="itp-pola"><div class="itp-photo"></div><figcaption>Beach</figcaption></figure>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
