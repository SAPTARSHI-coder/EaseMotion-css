# Interactive Bento Metrics Grid Component

## What does this do?
This component presents a modern Apple/Vercel-style Bento Grid metrics layout featuring background radial spotlight sweeps, sparkline bar animations, and live status pulse indicators.

## How is it used?
Include `style.css` in your project and copy the `.bento-container` HTML grid structure into analytics pages, SaaS landing pages, or executive dashboards.

## Why is it useful?
- High-converting modern UI pattern widely adopted in top-tier tech web applications.
- Hardware-accelerated CSS grid and transform animations.
- Responsive design tailored for modular dashboard cards.
