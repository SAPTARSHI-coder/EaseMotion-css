# 3D Tab Bar - Retro Styling

A responsive retro-inspired tab bar built using pure HTML and CSS.

The component combines layered borders, hard shadows, bold colors,
and subtle 3D hover interactions to create a vintage interface style.

## Features

- Pure HTML and CSS
- No JavaScript required
- Responsive layout
- 3D layered shadow effect
- Smooth hover and active states
- Keyboard focus support
- Reduced-motion support
- Works when `demo.html` is opened directly
