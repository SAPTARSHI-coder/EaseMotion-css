Print Preview Animation Reset Demo

Demonstrates how @media print resets active infinite keyframe animations (like spinners, pulses, and loaders) to upright, fully opaque static elements when printing or exporting to PDF.

⚙️ Processing System Diagnostics (Spinning Loader)
🔴 Live Status Indicator (Pulsing Element)
📦 Pending Delivery Package (Bouncing Indicator)

How to Verify:

  1. Press Ctrl + P (or Cmd + P on macOS) to open the browser Print Preview dialog.
  2. Notice how all active animations pause cleanly.
  3. Animated icons render upright (no random rotation angles) and 100% visible (no mid-fade opacity transparency).
