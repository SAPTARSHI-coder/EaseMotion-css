# Aurora Task Dashboard

This submission demonstrates a modern dark dashboard UI built with **EaseMotion CSS**.
It includes stat cards, task progress bars, team widgets, activity updates, hover motion,
and staggered entrance animation.

## 🌟 Features

- **Staggered entrance animation** using `ease-slide-up`, `ease-fade-in`, and delay utilities.
- **Hover interactions** using `ease-hover-lift` and `ease-hover-grow`.
- **Glow button style** using `ease-hover-glow` plus custom gradient button CSS.
- **Responsive layout** using CSS Grid and mobile breakpoints.
- **Custom progress bars** with animated fill and CSS variables.
- **Accessible markup** using semantic sections, buttons, ARIA progress values, and labels.
- **Reduced motion support** for users who prefer less animation.

## 📁 Files

- `demo.html` — interactive dashboard demo
- `style.css` — original dark aurora/glass styling
- `README.md` — documentation for this submission

## 🛠️ How to Run

1. Open `demo.html` in your browser.
2. Watch the cards and panels enter with staggered animation.
3. Hover over cards to see the lift effect.
4. Hover over buttons to see grow/glow motion.
5. Resize the browser window to check responsive behavior.
