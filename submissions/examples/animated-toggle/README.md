# CSS Animated Toggle

A demo project showcasing a **CSS-only animated toggle switch**.

## Features
- Smooth transition between ON/OFF states.
- Neon glow effect when active.
- Pure HTML + CSS, no JavaScript required.
- Responsive and modern design.

## Files
- `demo.html` → Structure with toggle input and slider.
- `style.css` → Styling for toggle, slider, and animation.
- `README.md` → Documentation and usage instructions.

## Usage
1. Open `demo.html` in your browser.
2. Click the toggle switch to see the animation.
3. Customize colors and sizes for your own theme.

## Customization Ideas
- Add labels (ON/OFF) inside the toggle.
- Use gradient backgrounds for more futuristic effects.
- Integrate into forms or dashboards.
- Extend with JavaScript to trigger actual functionality.
