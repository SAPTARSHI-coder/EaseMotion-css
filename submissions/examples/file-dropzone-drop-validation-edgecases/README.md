# File Dropzone Drop File Validation Edge Tests

## Overview

Vitest edge-case tests for validating dropped files.

### Covers

- Valid uploads
- Maximum file count
- Too many files
- Invalid MIME type
- Oversized files
- Negative size
- Missing properties
- Empty array
- Null input
- Undefined input
- Malformed objects
- Custom validation configuration

## Files

- demo.html
- style.css
- file-dropzone-edge.test.js

Run:

```bash
vitest
```
