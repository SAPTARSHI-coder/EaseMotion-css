# Neumorphic Interactive Toggle Switch with Smooth Haptic Elasticity 15

### High-Contrast Accessibility Edition

A modern, high-contrast neumorphic toggle switch built using pure HTML and CSS. This component emphasizes accessibility with strong visual contrast, keyboard-friendly interactions, smooth elastic animations, and responsive behavior.

---

## ✨ Features

- High-contrast accessibility-first design
- Neumorphic UI styling
- Smooth haptic-inspired elastic animation
- Responsive mobile-friendly layout
- Keyboard accessibility (`:focus-visible`)
- Strong visual focus indicators
- Reduced motion support
- Pure HTML & CSS implementation

## 🚀 Usage

1. Open the component folder.
2. Keep `demo.html` and `style.css` in the same directory.
3. Open `demo.html` in any modern web browser.

No installation or external dependencies are required.
