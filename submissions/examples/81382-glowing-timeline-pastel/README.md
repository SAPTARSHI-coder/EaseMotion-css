# Glowing Timeline — Pastel

A responsive timeline component using soft pastel colors,
glowing accents and smooth CSS interactions.

Implemented for EaseMotion CSS issue #81382.

## Features

- Pastel gradient color palette
- Glowing timeline nodes
- Animated pulse rings
- Smooth hover interactions
- Soft elevated cards
- Responsive desktop, tablet and mobile layout
- Pure HTML and CSS
- Reduced-motion support
- No JavaScript dependencies
