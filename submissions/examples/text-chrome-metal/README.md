# Text Chrome Metal

A chrome-like gradient sweeps across metallic lettering.

## Features
- Metallic chrome gradient
- Sweeping light band
- Bevel highlight
- Pure CSS

## Usage
```html
<h1 class="tcm-text">CHROME</h1>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
