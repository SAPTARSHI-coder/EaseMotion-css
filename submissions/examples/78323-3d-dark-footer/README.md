# 3D Dark Mode Footer

A responsive 3D footer component built using pure HTML and CSS.

## Features

- 3D depth with layered shadows
- Dark mode visual styling
- Subtle accent glow
- Responsive grid layout
- Hover interactions on navigation links
- Mobile-friendly layout
- No JavaScript required
- Reduced-motion support
