# Morphing Hero Section with Neumorphism Styling

A fully responsive hero section built with HTML and CSS, combining
soft neumorphic surfaces with subtle morphing and floating animations.

## Features

- Fully responsive layout
- Neumorphic interface design
- Morphing ambient background shape
- Interactive dashboard card
- Animated performance chart
- Floating information cards
- Interactive navigation links
- Responsive mobile navigation button
- Accessible focus states
- Reduced-motion support
- No JavaScript or external dependencies

## Files

- `demo.html`
- `style.css`

## Design

The component uses:

- Soft light and dark shadows
- Rounded neumorphic surfaces
- Muted neutral tones
- Indigo accent color
- Layered floating cards
- Smooth CSS transitions
- CSS keyframe animations

## Responsive Behavior

The hero switches from a two-column layout to a stacked layout on
smaller screens.

The navigation, dashboard, floating cards, typography, buttons, and
feature cards adapt for tablet and mobile widths.

## Technologies

- HTML5
- CSS3
