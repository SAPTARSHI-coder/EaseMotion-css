# Tumble Spinner Component (`#54698`)

## What does this do?
Provides an organic multi-axis tumbling polygon loading ring that transitions dynamically between rounded square and spherical geometries during rotation.

## How is it used?
Insert the spinner element with optional speed and color modifiers:
```html
<div class="ease-spinner-tumble cyan"></div>
```

## Why is it useful?
Solves issue #54698 by offering modern high-end asynchronous loading visual indicators without SVG sequence files.
