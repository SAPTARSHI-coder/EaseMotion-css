# Interactive Avatar with Retro Styling

A responsive interactive avatar component inspired by retro pixel-art
interfaces.

The component uses HTML and CSS to create a character-style profile card
with retro colors, pixel-inspired geometry, hover interaction, status
indicators, and responsive behavior.

## Features

- Fully responsive
- Retro / pixel-inspired visual design
- Interactive avatar hover effect
- Animated avatar eyes and mouth
- Hover cursor indicator
- Pixel-style shadows and borders
- Animated online status
- Profile information and stats
- Interactive action buttons
- CSS-only implementation
- Reduced-motion support
- No external dependencies

## Files

- `demo.html`
- `style.css`

## Interaction

Hover over the card to activate:

- Avatar movement
- Facial expression changes
- Interactive cursor
- Orbit movement
- Card lift effect
- Navigation-style visual feedback

## Responsive Design

The component adapts to smaller screens by:

- Scaling the avatar
- Stacking profile information
- Adjusting card spacing
- Preserving readable controls

## Accessibility

- Native buttons are used for actions
- Visible keyboard focus states
- Descriptive page metadata
- Reduced-motion support

## Technologies

- HTML5
- CSS3
