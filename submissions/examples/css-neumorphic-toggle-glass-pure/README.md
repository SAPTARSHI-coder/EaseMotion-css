# Neumorphic Toggle with Glassmorphism Styling

A highly unique component combining two popular UI design trends: Neumorphism (Soft UI) and Glassmorphism.

## Features
- Pure CSS Checkbox hack for state management
- Animated abstract background shapes to demonstrate the glass effect
- Neumorphic baseplate with outer drop shadows
- Neumorphic toggle track with inner inset shadows for physical depth
- Frosted glass effect applied via `backdrop-filter: blur`
- Smooth spring-like easing for the toggle thumb

## Usage
Include `demo.html` and `style.css` in your project. Ensure the background blobs are placed behind the `.toggle-container` utilizing appropriate z-indexing for the frosted glass to render correctly.
