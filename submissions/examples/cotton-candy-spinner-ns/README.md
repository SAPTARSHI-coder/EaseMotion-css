# Cotton Candy Spinner

## What does this do?
Renders a self-contained CSS-only `ease-cotton-candy-spinner` demo: Spinning cotton-candy drum with sugar-floss strands wrapping around a cone.

## How is it used?
Open `demo.html` in a browser. The animated face uses classes like `ease-cotton-candy-spinner`, `ease-cotton-candy-spinner__arm`, and `ease-cotton-candy-spinner__core`. No build step or JavaScript is required for the motion.

```html
<section class="ease-cotton-candy-spinner">
  <div class="ease-cotton-candy-spinner__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
