# Floating Cyberpunk Sidebar

A futuristic floating sidebar component built with pure HTML and CSS for EaseMotion CSS.

## ✨ Features

- Cyberpunk-inspired visual design
- Floating glass-style sidebar
- Neon cyan and magenta glow effects
- Expandable desktop navigation
- Compact responsive navigation on mobile
- Interactive hover states
- Active navigation state
- Animated status indicator
- Keyboard focus support
- `prefers-reduced-motion` support
- No JavaScript dependencies
- Fully responsive

## 🎨 Design

The component uses a dark futuristic interface with:

- Neon cyan accents
- Magenta highlights
- Purple ambient glow
- Transparent layered surfaces
- Cyberpunk grid background
- Glowing borders
- Monospace system labels
