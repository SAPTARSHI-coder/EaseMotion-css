# CSS Environment Badge

A set of sleek, animated environment indicator badges (`dev`, `staging`, `production`) built entirely with pure CSS. Designed to sit in navigation bars or footers to clearly indicate the current deployment state.

## 🎯 Features
- **Pure CSS:** No JavaScript required.
- **State Animations:** Subtle pulse animations for live/production states and soft fading for staging environments.
- **Accessible:** Implements `role="status"` and `aria-label` attributes for screen readers. fully respects `@media (prefers-reduced-motion: reduce)` by gracefully disabling the glowing pulses.
- **Responsive:** Scales cleanly based on typography size.
