# Speedometer needle rotation

A gauge whose needle rotates from 0 to the target angle on first paint, with a soft elastic ease.

## How to view

Open `demo.html` in any modern browser. The demo is fully self-contained — no CDN, no framework, no JavaScript.

## How to use

Copy `style.css` into your project's stylesheet. Every class used in the demo is namespaced with `speedometerneedlerotation-` to avoid collisions.

## Why this is useful for EaseMotion CSS

Performance / score pattern; the needle sweep is dramatic and informative.
