# CSS Toast: Origami Paper Fold

A pure HTML and Vanilla CSS toast component featuring an
**Origami Paper Fold** visual style.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript
- Paper-fold inspired visual design
- CSS triangular fold corners
- 3D perspective entrance animation
- Smooth hover elevation
- Paper highlight effect
- Fold edge details
- Responsive layout
- Light and dark mode support
- Reduced-motion support
- Keyboard-focusable close control
