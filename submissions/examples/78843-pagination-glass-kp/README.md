# CSS-only Pagination - Glassmorphism

A glassmorphism pagination component for issue #78843. It uses pure HTML and CSS to render frosted page controls, animated active states, previous/next affordances, and keyboard-visible focus rings.

## Features

- Frosted glass page controls
- Hover, focus, active, and disabled states
- Animated shimmer and depth layers
- Responsive wrapping layout with reduced-motion support
