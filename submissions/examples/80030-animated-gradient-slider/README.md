# Animated Gradient Slider (V1)

A responsive animated gradient slider component built with HTML, CSS, and vanilla JavaScript.

## Features

- Animated multi-color gradient track
- Smooth interactive range slider
- Glowing gradient thumb
- Live percentage value
- Animated preview area
- Responsive layout for desktop, tablet, and mobile
- Glassmorphism-inspired card styling
- Keyboard accessible native range input
- `prefers-reduced-motion` support
- No external libraries or dependencies
