# Glowing Carousel with Retro styling (#78861)

A responsive, JS-free slider component featuring Synthwave retro aesthetic, neon box-shadow glows, scanline CRT overlays, rotated diamond navigation indicators, and seamless CSS transitions.

## Features
- **Retro Arcade Aesthetic:** Cyberpunk neon palettes (`#ff007f`, `#00f3ff`, `#ffe600`), background grid patterns, CRT scanlines, and polygon clipped buttons.
- **Pure CSS State Logic:** Driven by hidden `<input type="radio">` elements and CSS general sibling (`~`) transform properties without JavaScript overhead.
- **Responsive & Accessible:** Fully mobile-adapted typography tokens, interactive focus states, and semantic HTML5 card tags.

## File Hierarchy
- `style.css` - Retro design tokens, scanline overlays, neon glow keyframes/effects, track transitions, and media queries.
- `demo.html` - Semantic markup displaying the glowing retro carousel component.
- `README.md` - Component documentation and setup guidelines.
