IMPLEMENTATION

Design notes

Layered depth

Opposing shadows establish the raised surface while keeping the background consistent.

Readable type

The text remains semantic and selectable instead of being rendered as an image.

Reduced motion

The decorative animation is removed when the user requests less motion.
