# EaseMotion CSS - Bento Grid Interactive Dashboard Layout with CSS Grid and Flexbox (Glassmorphic Style)

A modern **Glassmorphic Bento Grid Dashboard** built using semantic HTML and modern CSS Grid/Flexbox. The layout features frosted glass cards, gradient accents, hover animations, responsive behavior, and dashboard widgets arranged in a visually appealing bento grid.

## ✨ Features

- Glassmorphism UI with backdrop blur
- Responsive Bento Grid layout
- CSS Grid + Flexbox
- Smooth hover and elevation effects
- Gradient highlights
- Modern dashboard widgets
- Mobile-friendly design
- Pure HTML & CSS (No dependencies)

1. Open `demo.html` in any modern browser.
2. Ensure `style.css` is in the same directory.
3. Customize widgets, colors, or layout as needed.
