# Morphing Sidebar with Dark Mode Styling (#78798)

A responsive dark-mode application sidebar component featuring smooth collapsing transitions, indigo glowing accents, and sticky viewport positioning.

## Features
- **Dark Mode Aesthetics:** Deep slate background framing paired with indigo-purple gradient branding and subtle borders.
- **Responsive Collapsing:** Automatically collapses into a compact icon-only rail layout on smaller viewports.
- **Pure CSS Implementation:** Lightweight flexbox setup with zero JavaScript dependencies and full accessibility support.

## File Hierarchy
- `style.css` - Custom properties, sticky layout metrics, responsive media queries, and transition rules.
- `demo.html` - Semantic markup demonstrating sidebar navigation integration with ARIA roles.
- `README.md` - Technical specification and architecture overview.
