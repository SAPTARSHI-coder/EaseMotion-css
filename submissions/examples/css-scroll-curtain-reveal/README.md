# CSS Scroll Curtain Reveal (#70425)

A cinematic curtain reveal component where dual side panels part left and right on load, built entirely with pure CSS.

## Features
- **Semantic Structure:** Uses accessible markup containers with decorative background panels hidden from screen readers.
- **Pure CSS Animations:** Driven by custom keyframe translations and smooth cubic-bezier easing functions.
- **Responsive Layout:** Fluidly adapts to all viewports and device configurations.

## File Hierarchy
- `style.css` - Curtain panel positioning, keyframe animations, and card layouts.
- `demo.html` - Semantic markup and accessibility attributes.
- `README.md` - Technical specification and architecture summary.
