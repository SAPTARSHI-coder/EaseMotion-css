# CNC Mill Path

## What does this do?
Renders a self-contained CSS-only `ease-cnc-mill-path` demo: CNC mill bit following a toolpath with chip spark accents.

## How is it used?
Open `demo.html` in a browser. The animated face uses classes like `ease-cnc-mill-path`, `ease-cnc-mill-path__arm`, and `ease-cnc-mill-path__core`. No build step or JavaScript is required for the motion.

```html
<section class="ease-cnc-mill-path">
  <div class="ease-cnc-mill-path__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
