How it works — pure CSS

.ease-scroll-card {
  position: sticky;
  top: 2rem;

  /* Scroll-Driven Animation — no JS needed */
  animation: ease-scale-down linear forwards;
  animation-timeline: view();
  animation-range: exit-crossing 0% exit-crossing 100%;
}

@keyframes ease-scale-down {
  to { transform: scale(0.85); opacity: 0.4; filter: blur(4px); }
}
✦

That's all — no JavaScript.

Powered by animation-timeline: view() — a native browser API.
