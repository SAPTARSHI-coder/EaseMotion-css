# Ease Status Pill

## What does this do?

A rounded status badge with an animated pulse indicator supporting Online, Away, Busy, and Offline states.

---

## How is it used?

Open `demo.html` in any modern browser.

Example:

```html
<div class="status-pill online">
    <span class="dot"></span>
    Online
</div>
```

Features:

- Rounded pill
- Online, Away, Busy, Offline variants
- Animated pulse indicator
- Responsive layout

---

## Why is it useful?

Status indicators are commonly used in dashboards, messaging apps, collaboration tools, and profile cards. This component provides a lightweight, reusable, animation-first solution that aligns with EaseMotion CSS's design philosophy.
