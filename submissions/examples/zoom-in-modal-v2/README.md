# CSS Zoom-In Modal

## Overview

A modern gaming-inspired modal featuring a smooth zoom-in animation built using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Responsive Modal Layout
- Zoom-In Animation
- CSS Custom Properties
- Accessible (`prefers-reduced-motion`)
- No JavaScript Required

## Folder Structure

```text
zoom-in-modal/
├── demo.html
├── style.css
└── README.md
```

## Usage

1. Open `demo.html` in your browser.
2. Click **Open Modal**.
3. Customize the CSS variables to fit your project.

## CSS Variables

- `--primary`
- `--background`
- `--surface`
- `--text`
- `--duration`

## Browser Support

- Chrome
- Firefox
- Edge
- Safari
