# CSS Verified Badge

A blue verified checkmark badge featuring a spring-pop entry animation and smooth hover scaling built with pure CSS.

## 🌟 Features
- **Pop Entry Motion:** Features a smooth cubic-bezier scale pop keyframe animation on load.
- **Interactive:** Scales up and rotates slightly on hover and keyboard focus.
- **Accessible:** Includes semantic SVG paths and `aria-label` attribute for screen readers.

## 📁 Files
- `demo.html` - Minimal profile card displaying the verified user badge.
- `style.css` - Component badge styling, SVG dimensions, and `@keyframes` pop animation.
