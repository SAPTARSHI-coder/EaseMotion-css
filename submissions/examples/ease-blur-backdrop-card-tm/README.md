# Backdrop Blur Card Component

Add ease-blur-backdrop-card-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|---------|
| `--bb-blur` | `16px` |
| `--bb-radius` | `16px` |
| `--bb-accent` | `#6366f1` |
| `--bb-shadow` | `0 8px 40px rgba(0,0,0,.5)` |

## Technique

`backdrop-filter: blur()` with hover state transition from heavy blur to light blur.
