# 🌈 Prism Nav – Items Split into Rainbow Spectrum

> A colorful, light-refracting navigation where items split into a rainbow spectrum on hover, creating a stunning prismatic effect.

---

## 📖 Description

The **Prism Nav** is a colorful, light-refracting navigation component where items split into a rainbow spectrum on hover. When you hover over a navigation item, a rainbow gradient sweeps across the surface, and the text and icon transform into vibrant prismatic colors. The effect creates a stunning, light-refracting experience reminiscent of light passing through a prism.

The component uses CSS animations with gradient sweeps and text clipping to create the prism effect. Each item features a rainbow gradient that sweeps across on hover, with text and icons adopting vibrant colors. The effect is smooth, colorful, and engaging.

Perfect for colorful brands, creative portfolios, music apps, and any application where you want to create a vibrant, prismatic navigation experience. The Prism Nav transforms a simple menu into a colorful, light-filled interaction.
