# CSS Dropdown: Floating Elevation

A smooth and accessible pure CSS dropdown featuring a **Floating Elevation** visual style.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript or external dependencies
- Floating layered elevation effect
- Soft neumorphic shadows
- Smooth dropdown transitions
- Hover and keyboard-focus interaction
- Dark mode support
- Responsive layout
- Reduced-motion accessibility support
- Hardware-friendly transform and opacity animations

## Preview

The dropdown presents a raised control with a floating menu that gently
elevates into view.
