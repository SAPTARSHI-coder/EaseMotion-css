# Selectable Radio Choice Cards

## What does this do?

Plan/shipping choice cards powered by radio inputs with lift and check states.

## How is it used?

```html
<label class="choice"><input type="radio" name="plan"/><span class="choice__body">Pro</span></label>
```

Open `demo.html` in a browser to try it.

## Why is it useful?

Practical form pattern with accessible selected-state motion.
