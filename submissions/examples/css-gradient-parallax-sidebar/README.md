# Parallax Sidebar with Gradient Styling (#78788)

A vibrant blue-to-indigo gradient sidebar component featuring smooth parallax hover translation, sticky viewport positioning, and responsive icon-only collapse.

## Features
- **Vibrant Gradient Styling:** Multi-stop vertical blue-indigo background gradient paired with translucent glass borders.
- **Parallax Hover Translation:** Smooth horizontal shift and background highlight upon item hover.
- **Fully Responsive:** Automatically collapses into a compact icon-only rail layout on smaller viewports.

## File Hierarchy
- `style.css` - Custom properties, gradient tokens, sticky layout rules, hover translations, and media queries.
- `demo.html` - Semantic markup demonstrating sidebar integration with ARIA accessibility roles.
- `README.md` - Technical specification and architecture overview.
