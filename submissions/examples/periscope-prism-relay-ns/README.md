# Periscope Prism Relay

## What does this do?
Renders a self-contained CSS-only `ease-periscope-prism-relay` demo: Periscope prism relay bouncing a sightline through two elbows.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-periscope-prism-relay`. No build step or JavaScript is required for the effect.

```html
<section class="ease-periscope-prism-relay">
  <div class="ease-periscope-prism-relay__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
