# CSS Tic Tac Toe

A responsive Tic Tac Toe board built using pure HTML and CSS for EaseMotion CSS.

## ✨ Features

- Pure HTML and CSS
- Responsive 3×3 game board
- Modern glass-style UI
- Smooth hover animations
- Keyboard-accessible cells
- Visible focus indicators
- Screen-reader-friendly labels
- `aria-live` game status
- Reduced-motion support
- No JavaScript dependency
