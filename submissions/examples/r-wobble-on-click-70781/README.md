# CSS Wobble on Click

A playful CSS-only interaction that makes an element wobble when clicked
or activated.

## Features

- Pure HTML and CSS
- No JavaScript
- Click-triggered wobble animation
- Keyboard accessible
- Focus-visible styling
- Responsive layout
- Touch-friendly buttons
- Multiple color variants
- Reduced-motion support

## Files

- `demo.html` — Component demonstration
- `style.css` — Complete styling and animation
- `README.md` — Documentation
