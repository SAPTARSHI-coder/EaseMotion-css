# Elastic Slide Badge Example

A lightweight CSS badge featuring a smooth **elastic slide animation** designed for creative portfolio layouts, featured projects, status labels, and call-to-action elements.

The badge gently slides horizontally with an elastic overshoot effect when hovered, creating a lively and modern interaction while remaining lightweight and accessible.

---

## Features

- Smooth elastic slide animation on hover
- Modern gradient badge design
- Rounded pill-shaped appearance
- Soft glow and shadow for depth
- Pure HTML and CSS implementation
- No JavaScript required
- Lightweight and reusable
- Responsive across different screen sizes
- Accessible with `prefers-reduced-motion` support

## Usage

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

Add the badge element:

```html
<span class="elastic-slide-badge-example-ag">
    ✨ Featured Project
</span>
```

## Customization

You can easily customize the badge by modifying:

- Background gradient colors
- Text color
- Font size
- Border radius
- Padding
- Box shadow intensity
- Animation duration
- Animation timing function
- Horizontal slide distance

---

## Animation

The hover animation creates an elastic sliding effect by:

- Sliding the badge horizontally
- Overshooting slightly
- Bouncing back smoothly
- Settling into its final position

This creates a polished interaction without requiring JavaScript.

---

## Accessibility

This example includes accessibility support by respecting:

- `prefers-reduced-motion`

Users who prefer reduced motion will automatically receive a static version without animations.
