# Animated Drawer — SaaS Modern

A responsive animated drawer component built with pure HTML and CSS
for EaseMotion CSS issue #81418.

## Features

- SaaS modern visual style
- CSS-only animated drawer
- Smooth slide-in and slide-out transitions
- Full-screen overlay
- Backdrop blur effect
- Responsive drawer width
- Workspace profile section
- Navigation items
- Active navigation state
- Notification badge
- Upgrade workspace card
- Responsive desktop, tablet, and mobile layouts
- Keyboard focus states
- Reduced-motion support
- Zero external JavaScript dependencies
