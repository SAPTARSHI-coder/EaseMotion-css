# Vaporwave Grid Pulse Horizon

1. What does this do? Creates a retro-futuristic 3D grid floor that infinitely pulses forward towards the user, fading out into the horizon using a CSS gradient mask.
2. How is it used? Place the `.grid-plane` inside a `.vaporwave-grid-horizon` container. Use the CSS variables `--vaporwave-duration`, `--grid-color`, and `--grid-glow` to configure the animation timing and styling directly in your HTML or CSS.
3. Why is it useful? Synthwave and vaporwave aesthetics are a major design trend. Building a 3D animated floor usually requires heavy WebGL/Three.js libraries. Providing a pure CSS, hardware-accelerated alternative fits perfectly within EaseMotion's animation-first, dependency-free ecosystem.
