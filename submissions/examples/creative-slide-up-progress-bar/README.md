# CSS Slide-Up Progress Bar for Creative Portfolio Layouts

A modern **Creative Portfolio Progress Bar** component featuring elegant **Slide-Up** animations built entirely with **HTML5 and CSS3**. This example demonstrates animated progress bars with smooth entrance effects, responsive layouts, CSS custom properties, and accessibility support—without requiring JavaScript.

---

## ✨ Features

- 🎨 Creative Portfolio inspired interface
- ⬆️ Slide-Up entrance animations
- 📊 Animated progress bars
- 🌈 Gradient progress fills
- ⚡ Pure HTML5 & CSS3 (No JavaScript)
- 📱 Fully responsive across desktop, tablet, and mobile
- 🎯 CSS Custom Properties for easy customization
- ♿ Accessibility support with `prefers-reduced-motion`
- 🚀 Lightweight and performance-friendly

## 🚀 Getting Started

1. Open `demo.html` in any modern browser.
2. Observe the Slide-Up animation as each skill card appears.
3. Watch the animated progress bars fill smoothly.
4. Customize colors, spacing, and animation timing using the CSS variables.

## 🎨 CSS Custom Properties

```css
:root{
    --bg:#0f172a;
    --card:rgba(30,41,59,.85);
    --primary:#38bdf8;
    --secondary:#8b5cf6;
    --success:#22c55e;
    --text:#ffffff;
    --muted:#cbd5e1;
    --track:#334155;
    --radius:18px;
    --transition:.35s ease;
}
```
