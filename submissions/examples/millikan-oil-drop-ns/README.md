# Millikan Oil Drop

## What does this do?
Renders a self-contained CSS-only `ease-millikan-oil-drop` demo: Millikan oil drop hovering between charged plates.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-millikan-oil-drop`. No build step or JavaScript is required for the effect.

```html
<section class="ease-millikan-oil-drop">
  <div class="ease-millikan-oil-drop__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
