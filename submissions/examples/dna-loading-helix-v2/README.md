# CSS DNA Loading Helix v2


Animated DNA helix loader built completely with CSS.


## Features

- Pure CSS implementation
- Colored DNA base pairs
- Smooth helix rotation
- Responsive layout
- No JavaScript dependency
- Accessible loading component


## Technologies

- HTML5
- CSS3 Animations


## Usage

Useful for:

- Loading screens
- Scientific websites
- Medical dashboards
- Modern UI animations
