# Heliochronometer Shadow

## What does this do?
Renders a self-contained CSS-only `ease-heliochronometer-shadow` demo: Precision sundial gnomon shadow tracking solar noon.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-heliochronometer-shadow`. No build step or JavaScript is required for the effect.

```html
<section class="ease-heliochronometer-shadow">
  <div class="ease-heliochronometer-shadow__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
