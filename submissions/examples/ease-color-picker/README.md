# Ease Color Picker

A lightweight, animated color swatch selection component.

## Features
- Smooth scale-up hover and active tap transitions.
- Focus-visible and `.is-selected` active state indicators.
- Sizing variants (`default`, `.ease-color-picker-sm`, `.ease-color-picker-lg`).
- Fully responsive wrapping layout.

## Usage
\`\`\`html
<link rel="stylesheet" href="style.css" />

<div class="ease-color-picker">
  <button class="ease-color-option is-selected" style="--ease-color: #3b82f6;"></button>
  <button class="ease-color-option" style="--ease-color: #ef4444;"></button>
</div>
\`\`\`
