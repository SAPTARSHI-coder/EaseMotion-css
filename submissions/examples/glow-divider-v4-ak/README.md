# glow-divider-v4-ak

Pure CSS animated glowing gradient line divider component — no JavaScript required.

## How to use

```html
<hr class="ease-glowing-divider-v4" />

<!-- Divider with Badge -->
<div class="ease-glowing-divider-text-v4">
  <span class="ease-glowing-divider-badge-v4">OR</span>
</div>
