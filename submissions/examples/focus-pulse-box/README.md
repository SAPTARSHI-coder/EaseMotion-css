# Focus Pulse Box

An input field that blooms with a soft pulse ring when it takes focus.

## Features
- Focus ring pulses outward in waves
- Border shifts to indigo
- Placeholder label floats on focus

## Usage
```html
<div class="fp-field">
  <label class="fp-label">Your email</label>
  <input class="fp-input" type="text" placeholder="hello@world.dev" />
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
