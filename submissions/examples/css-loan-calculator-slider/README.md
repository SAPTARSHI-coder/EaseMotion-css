# CSS Loan Calculator Slider

A responsive CSS-only loan calculator interface featuring animated range sliders for loan amount, loan term, and interest rate.

## Features

- Pure HTML and CSS
- No JavaScript required
- Loan amount range slider
- Loan term range slider
- Interest rate range slider
- Responsive design
- Animated calculator entrance
- Animated result card
- Interactive slider thumb
- Keyboard accessible range inputs
- Visible focus states
- `prefers-reduced-motion` support
- Mobile-friendly layout

## Demo

Open `demo.html` in a modern browser.

Use the keyboard or mouse to interact with the sliders.
