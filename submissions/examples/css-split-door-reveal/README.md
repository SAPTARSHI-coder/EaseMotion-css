# CSS Split Door Reveal

A dynamic layout element that flawlessly splits into two halves (sliding apart left and right) upon hovering, revealing hidden premium content underneath.

## Features
- Hardware-accelerated `transform: translateX()` for smooth sliding
- Pseudo-physical styling with center borders giving a "door split" aesthetic
- Smooth `cubic-bezier` timing function
