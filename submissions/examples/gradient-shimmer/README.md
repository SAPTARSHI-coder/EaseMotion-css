# Gradient Shimmer Slider

A smooth, modern and performant **Gradient Shimmer Slider** built entirely with HTML and vanilla CSS.

## ✨ Features

* Pure HTML and CSS
* Smooth gradient shimmer animation
* Automatic sliding transitions
* Responsive design
* Dark mode support
* Hardware-accelerated animations
* Accessible structure
* `prefers-reduced-motion` support
* No external JavaScript or libraries

## 📁 Structure

```text
gradient-shimmer/
├── index.html
├── style.css
└── README.md
```

## 🎨 Preview

The slider contains three animated slides with:

* Gradient backgrounds
* Shimmer highlights
* Smooth transitions
* Interactive buttons
* Responsive layout

## 🛠️ Technologies

* HTML5
* CSS3
* CSS Animations
* CSS Gradients
* CSS Media Queries

## 🚀 Usage

Open `index.html` directly in a browser.

No installation or dependencies are required.

## ♿ Accessibility

The component includes:

* Semantic HTML
* Accessible slider labels
* Descriptive button labels
* Responsive behavior
* Reduced-motion support through `prefers-reduced-motion`

## 🌙 Dark Mode

The component automatically adapts to the user's system color preference using:

```css
@media (prefers-color-scheme: dark)
```

## 📱 Responsive Design

The slider adapts to desktop, tablet and mobile screen sizes using CSS media queries.
