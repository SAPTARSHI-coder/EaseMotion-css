# CSS Modal: Gradient Shimmer

A smooth and responsive modal component featuring an animated
Gradient Shimmer effect using pure HTML and Vanilla CSS.

## Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Animated gradient shimmer
- Gradient modal border
- Smooth modal entrance
- Responsive design
- Dark UI compatible
- Accessible dialog semantics
- Keyboard focus indicators
- Reduced-motion support
- Hardware-friendly CSS animations
