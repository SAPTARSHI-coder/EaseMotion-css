# Glassmorphism Footer — Neon

A responsive glassmorphism footer featuring translucent
surfaces, neon cyan and purple accents, soft glow effects,
and modern navigation.

Implemented for issue #79841.

## Features

- Glassmorphism visual style
- Neon cyan, purple, and pink accents
- Translucent footer surface
- Backdrop blur
- Decorative neon glow effects
- Responsive desktop, tablet, and mobile layouts
- Animated navigation links
- Interactive social buttons
- Keyboard focus-visible states
- Reduced-motion support
- No JavaScript
- No external dependencies
