# Croissant Layer Fold

## What does this do?
Renders a self-contained CSS-only `ease-croissant-layer-fold` demo: Croissant dough layers folding with buttery sheen.

## How is it used?
Open `demo.html` in a browser. The animated face uses classes like `ease-croissant-layer-fold`, `ease-croissant-layer-fold__arm`, and `ease-croissant-layer-fold__core`. No build step or JavaScript is required for the motion.

```html
<section class="ease-croissant-layer-fold">
  <div class="ease-croissant-layer-fold__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
