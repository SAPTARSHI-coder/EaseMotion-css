# Dynamic Loader - Material Design

A responsive Material Design inspired loading animation built using only HTML and CSS.

## Features

- Pure HTML & CSS
- Responsive
- Material Design inspired colors
- Smooth bouncing animation
- No JavaScript

## Usage

```html
<div class="ease-material-loader">
    <span></span>
    <span></span>
    <span></span>
</div>
```
