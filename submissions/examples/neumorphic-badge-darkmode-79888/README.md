# Neumorphic Badge with Dark Mode Styling

A responsive badge component featuring dark-mode neumorphic design with soft shadows and interactive hover effects.

## Features

- Dark mode UI
- Neumorphic styling
- Soft shadow depth effects
- Responsive layout
- Hover interaction
- Pure HTML/CSS implementation

## Files

- demo.html
- style.css

## Usage

Open `demo.html` in a browser.

## Badge Variants

- Primary
- Success
- Warning
- Danger
- Info
- Premium

## Customization

You can easily modify:

- Colors
- Shadow depth
- Border radius
- Font styling
- Hover animations

## Responsive Design

The badges automatically stack on smaller screens.

- Chrome
- Firefox
