# Card Rotate 3D

A card rotates in 3D revealing its back face with depth.

## Features
- True 3D rotation
- Back face content
- Perspective depth
- Pure CSS

## Usage
```html
<div class="cr3d-card"><div class="cr3d-front">Front</div><div class="cr3d-back">Back</div></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
