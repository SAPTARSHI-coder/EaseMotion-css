# CSS Loader – Diamond Facet Edge

A pure CSS loader inspired by the reflective geometry of a diamond. Multiple facet layers create a gemstone-like appearance while a smooth rotation animation delivers an elegant loading effect.

## Features

- Pure HTML & CSS
- Diamond-inspired faceted design
- Smooth infinite rotation animation
- Hardware-accelerated transforms
- Dark-mode friendly appearance
- Responsive sizing
- Accessibility support with ARIA attributes
- No JavaScript required

## Usage

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

Add the loader markup:

```html
<div
  class="diamond-loader"
  role="status"
  aria-label="Loading content">
  <span class="facet facet-1"></span>
  <span class="facet facet-2"></span>
  <span class="facet facet-3"></span>
  <span class="facet facet-4"></span>
</div>
```
