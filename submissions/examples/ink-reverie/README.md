# 🖋️ Ink Reverie

An interactive generative ink-flow canvas where every click becomes a
living pigment bloom.

Ink Reverie recreates the unpredictable beauty of ink dispersing through
water using nothing more than HTML5 Canvas, CSS3, and vanilla JavaScript.

No frameworks.
No external dependencies.
No build step.

---

## ✨ Preview

Ink Reverie starts as a quiet dark canvas.

Click anywhere to release pigment.

The pigment expands into an organic bloom, develops small branching
tendrils, releases particles, drifts through the canvas, and gradually
dissolves.

Multiple ink formations can exist simultaneously, allowing the user to
create completely different compositions during every interaction.

## 🖱️ Interaction

### Mouse

Click anywhere inside the canvas to create an ink bloom.

Drag across the canvas to continuously release pigment.

### Touch

Touch and drag interactions are supported through pointer events, allowing
the same interaction model to work on touch devices.

### Keyboard

| Key | Action |
|-----|--------|
| `Space` | Create ink burst |
| `R` | Reset canvas |
