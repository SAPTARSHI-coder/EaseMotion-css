# Hover Slider — Neumorphism

A responsive hover-focused slider component using a soft
neumorphic visual style for EaseMotion CSS.

Implemented for issue #79784.

## Features

- Neumorphic design
- Soft inset and raised shadows
- Hover emphasis on slider controls
- Smooth thumb scaling
- Responsive layout
- CSS-only implementation
- No JavaScript
- No external dependencies
- Reduced-motion support
