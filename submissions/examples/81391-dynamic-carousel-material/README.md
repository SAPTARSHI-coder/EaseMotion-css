# Dynamic Carousel — Material Design

A responsive CSS-only carousel inspired by Material Design principles,
created for EaseMotion CSS issue #81391.

## Features

- Material Design-inspired surfaces
- Responsive carousel layout
- CSS-only slide navigation
- Smooth slide transitions
- Elevation and shadow effects
- Interactive slide content
- Mobile-friendly layout
- Reduced-motion support
- No JavaScript
- No external dependencies
