# CSS Skew Active Modal

## Overview

A modern gaming-inspired modal featuring a smooth skew-to-active entrance animation using only HTML and CSS.

## Features

- Pure HTML & CSS
- Responsive Modal
- Skew Active Animation
- CSS Custom Properties
- Accessible (`prefers-reduced-motion`)
- No JavaScript Required

## Folder Structure

```text
skew-active-modal/
├── demo.html
├── style.css
└── README.md
```

## Usage

1. Open `demo.html`.
2. Click **Launch Modal**.
3. Customize the CSS variables to match your design.

## CSS Variables

- `--primary`
- `--background`
- `--surface`
- `--text`
- `--duration`

## Browser Support

- Chrome
- Firefox
- Edge
- Safari
