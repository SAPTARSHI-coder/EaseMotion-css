# CSS Skew Active Modal

A simple, responsive modal built using only HTML and CSS.

## Features

- Pure HTML and CSS
- No JavaScript required
- Smooth skew animation
- Responsive design
- Accessible with `prefers-reduced-motion` support

## Files

- demo.html
- style.css
- README.md

## Usage

Open `demo.html` in a browser to view the demo.

## CSS Custom Properties

You can customize:

- Background color
- Button color
- Border radius
- Animation duration

## Browser Support

Works in all modern browsers.
