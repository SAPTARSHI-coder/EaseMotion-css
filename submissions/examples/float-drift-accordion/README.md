# Float-Drift Accordion

A lightweight CSS-only accordion component designed for fintech dashboard layouts.

## Features

- Pure HTML and CSS
- No JavaScript required
- Uses native HTML `<details>` and `<summary>`
- Float-drift entrance animation
- Smooth hover interactions
- Responsive design
- Accessible reduced-motion support
- Easy to customize
