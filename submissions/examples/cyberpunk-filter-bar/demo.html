Custom Filter Bar Header (Cyberpunk Edition)

Note: Built with 100% pure CSS (Zero JS). Utilizes native radio buttons styled via the :checked pseudo-class. The design features a high-contrast Cyberpunk aesthetic with hard angled cuts via clip-path, neon colors, monospace typography, and a hardware-accelerated text glitch effect on the active item hover. filter: drop-shadow is used in combination with modern :has() to project shadows outside the clipped polygons.
