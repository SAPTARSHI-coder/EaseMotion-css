# Bridge Cable Tension

## What does this do?
Renders a self-contained CSS-only `ease-bridge-cable-tension` demo: Suspension bridge cable clamps flexing under load.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-bridge-cable-tension`. No build step or JavaScript is required for the effect.

```html
<section class="ease-bridge-cable-tension">
  <div class="ease-bridge-cable-tension__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
