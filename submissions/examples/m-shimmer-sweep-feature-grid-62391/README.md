# CSS Shimmer-Sweep Feature Grid for Product Catalog Layouts

A modern **Shimmer-Sweep Feature Grid** built using pure HTML and CSS. The component features elegant shimmer hover animations, responsive feature cards, CSS custom properties, and lightweight styling for modern product catalog interfaces.

## ✨ Features

- Pure HTML5 & CSS3
- Shimmer-sweep hover animation
- Responsive feature grid
- Glassmorphism card design
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
