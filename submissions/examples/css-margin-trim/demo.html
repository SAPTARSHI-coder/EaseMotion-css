margin-trim

The margin-trim property trims child margins that touch the edges of their container. No more negative margins, no more :last-child { margin-bottom: 0 } — the browser handles it natively.

Both containers have cards with margin-block: 16px. The right container uses margin-trim: block to trim the top and bottom excess.

How It Works

margin-trim: block 
/* Trims top-bottom margins of direct children
   that touch the container edge */
.container-with-trim {
  margin-trim: block;
}

/* All children keep their margins for spacing */
.container-with-trim > * {
  margin-block: 16px;
}

/* No need for:
   .container > :first-child { margin-top: 0; }
   .container > :last-child  { margin-bottom: 0; }
*/
margin-trim: inline 
/* Trims left-right margins of direct children
   that touch the container edges */
.tag-cloud {
  display: flex; flex-wrap: wrap;
  margin-trim: inline;
}

.tag-cloud .tag {
  margin-inline-end: 8px;
  margin-block-end: 8px;
}

/* No need for:
   .tag-cloud::after { content: ''; flex: auto; }
   .tag:last-child { margin-inline-end: 0; }
*/
