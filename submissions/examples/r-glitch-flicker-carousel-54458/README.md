# CSS Glitch-Flicker Carousel

A modern **Glitch-Flicker Carousel** built using pure HTML5 and CSS3 for creative portfolio layouts. The component features a subtle glitch and flicker animation on active and hovered cards, responsive layout, and accessibility support without requiring JavaScript.

---

## ✨ Features

- Pure HTML5 & CSS3
- Glitch-flicker hover animation
- Responsive portfolio carousel
- Modern card-based layout
- CSS Custom Properties
- Lightweight and performant
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required

## 🚀 Usage

1. Copy the component into your project.
2. Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

3. Open `demo.html` in any modern browser.
