# 🫧 Bubble Trail Cursor – Bubbles Trail Behind Cursor and Pop

> A playful, magical cursor effect where colorful bubbles trail behind the cursor and pop, creating a delightful, whimsical experience.

---

## 📖 Description

The **Bubble Trail Cursor** is a playful, magical UI effect where colorful bubbles trail behind the cursor and pop. As you move your mouse, bubbles of various sizes and colors follow in a graceful arc, drifting upward and popping with a burst of particles. The effect creates a delightful, whimsical experience reminiscent of blowing bubbles.

The component uses JavaScript to create bubbles at the cursor position with random properties (size, color, trajectory, speed). Each bubble floats upward with a gentle drift, then pops with a burst of colorful particles. The effect is smooth and responsive, with bubbles spawning at regular intervals.

Perfect for playful interfaces, children's apps, creative portfolios, and any application where you want to add a touch of magic and whimsy. The Bubble Trail Cursor transforms a simple cursor into a delightful, interactive experience.
