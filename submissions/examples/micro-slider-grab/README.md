# Micro Slider Grab

A range slider whose thumb grows, glows and shows a drag grip when you grab it.

## Features
- Thumb springs larger on grab
- Track fill pushes ahead of the grip
- Floating value tag hovers above

## Usage
```html
<div class="msg-wrap">
  <span class="msg-value">60%</span>
  <input class="msg-range" type="range" min="0" max="100" value="60" />
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
