# Animated Spinner with Dark Mode Styling

A responsive animated loading spinner built using only HTML and CSS.

## Features

- Dark mode inspired interface
- Animated circular spinner
- Gradient glow effects
- Pulsing center indicator
- Animated loading dots
- Animated progress indicator
- Fully responsive layout
- Pure HTML and CSS
- No JavaScript dependency
- Reduced-motion accessibility support

## Files

- `demo.html` — component markup
- `style.css` — spinner styling, animation and responsive behavior

## Usage

Open `demo.html` directly in a browser.

The spinner can also be extracted from the demo and integrated into existing applications.

## Accessibility

The spinner uses a semantic loading status and provides a `prefers-reduced-motion` fallback for users who prefer limited animation.
