# CSS Morph-Glow Carousel for Gaming Hub Layouts

## Overview

A lightweight CSS-only Morph-Glow Carousel designed for modern gaming dashboard layouts.

The component creates animated cards with smooth morphing shapes and glowing effects using pure CSS.

---

## Features

- Pure HTML and CSS
- Morphing border animation
- Glow effect animation
- Responsive layout
- Hover interactions
- No JavaScript required
- CSS custom properties
- prefers-reduced-motion accessibility support
