# Ease Advanced Ripple Grid Background

An interactive grid background that creates animated ripple waves
around the user's cursor.

## Features

- Interactive cursor-based ripple effect
- Dynamic wave propagation
- Responsive grid
- Glowing grid intersections
- Animated background gradient
- Glassmorphism content panel
- Mouse and pointer support
- Responsive design
- Reduced-motion support
- No external libraries
