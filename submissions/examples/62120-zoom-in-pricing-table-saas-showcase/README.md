# CSS Zoom-In Pricing Table for SaaS Showcase Layouts

A modern **Zoom-In Pricing Table** built using pure HTML5 and CSS3 for SaaS showcase layouts. This component provides animated pricing cards with smooth zoom entrance effects, highlighted plans, glowing backgrounds, and responsive design.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Smooth zoom-in entrance animation
* SaaS pricing card showcase
* Multiple pricing tiers:

  * Starter
  * Professional
  * Enterprise
* Featured pricing plan highlight
* Animated glow effects
* Hover scale and elevation interactions
* Glassmorphism card design
* Responsive CSS Grid layout
* CSS Custom Properties for easy customization
* Smooth CSS transitions and keyframe animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Observe the zoom-in animation when pricing cards appear.
3. Hover over cards for scaling and glow interactions.
4. Customize colors, spacing, shadows, and animations using CSS variables inside `:root`.

## CSS Custom Properties

```css
:root{
  --bg:#eef4ff;
  --surface:rgba(255,255,255,.92);
  --primary:#2563eb;
  --secondary:#06b6d4;
  --accent:#8b5cf6;
  --text:#111827;
  --muted:#64748b;
  --shadow:0 18px 45px rgba(37,99,235,.18);
  --radius:26px;
}
```
