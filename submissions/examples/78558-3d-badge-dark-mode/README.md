# 3D Badge - Dark Mode

A responsive 3D-inspired badge component with multiple states and light/dark theme support.

## Features

- 3D-inspired visual depth
- Multiple badge variants
- Success, warning, danger, info, neutral and featured states
- Responsive layout
- Light and dark mode
- Theme persistence with `localStorage`
- Hover elevation effects
- Pure HTML, CSS and minimal JavaScript
- Reduced-motion support
- No external dependencies

## Files

- `demo.html` - Badge examples and theme toggle
- `style.css` - Complete component styling

## Usage

Open `demo.html` in a modern browser.

Use the Theme button to switch between light and dark modes.

The selected theme is saved using `localStorage`.

## Responsive Behavior

The badge layout automatically changes from three columns to two columns and then to a single column on smaller screens.

## Accessibility

The demo uses semantic sections, descriptive labels, keyboard-accessible controls, and a `prefers-reduced-motion` media query.
