# Ease CSS Slide-Up Badge for SaaS Showcase Layouts

A modern CSS-only Slide-Up Badge designed for SaaS
landing pages, product announcements, feature releases,
dashboards and promotional interfaces.

The component uses CSS transforms, keyframe animations
and smooth transitions to create a polished upward entrance
effect without JavaScript.

## Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Slide-up entrance animation
- Smooth transform-based motion
- Badge shine animation
- Floating accent particles
- Interactive hover states
- Animated secondary showcase badge
- Responsive SaaS layout
- Desktop support
- Tablet support
- Mobile support
- Keyboard focus support
- `prefers-reduced-motion` support
- CSS custom properties
- Lightweight implementation
