# Floating Hero Section — SaaS Modern

A modern floating SaaS hero section created for EaseMotion CSS.

The component combines a clean SaaS landing-page layout with
a floating product dashboard preview and CSS-powered micro
interactions.

## Features

- Modern SaaS landing-page aesthetic
- Floating dashboard product preview
- Floating notification card
- Floating team activity card
- Floating productivity card
- Gradient headline treatment
- Animated background orbs
- Subtle grid background
- Interactive navigation links
- Interactive CTA buttons
- Interactive dashboard controls
- Animated analytics bars
- Hover states for dashboard metrics
- Responsive layout
- CSS custom properties/design tokens
- Keyboard focus states
- `prefers-reduced-motion` support
- Zero external JavaScript dependencies
- No external assets required
