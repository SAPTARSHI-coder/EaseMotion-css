# CSS Collapsible Sidebar

A responsive collapsible sidebar built using pure HTML and CSS.

The sidebar smoothly transitions between an expanded navigation layout
and a compact icon-only layout without JavaScript.

## Features

- Pure CSS implementation
- No JavaScript required
- Smooth width transition
- Icon-only collapsed state
- Responsive layout
- Keyboard-focusable navigation links
- Accessible semantic navigation
- `prefers-reduced-motion` support
- Works on desktop and mobile screens
