# CSS Bounce-Pulse Pricing Table for Product Catalog Layouts

A modern **Bounce-Pulse Pricing Table** component built using pure HTML5 and CSS3 for product catalog layouts. This component creates an engaging pricing showcase with animated pricing cards, featured plan highlighting, smooth bounce effects, and responsive design.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Product catalog pricing layout
* Smooth bounce-pulse animations
* Featured pricing plan highlight
* Animated pricing cards
* Gradient CTA buttons
* Glassmorphism card design
* Hover scale interactions
* Responsive pricing grid
* CSS Custom Properties support
* Lightweight keyframe animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Explore the pricing cards and hover interactions.
3. Customize colors, shadows, spacing, and animations using CSS variables.
