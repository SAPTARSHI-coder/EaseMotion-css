# Floating Accordion with Glassmorphism

A responsive floating accordion component built with semantic HTML and modern CSS.

## Features

- Glassmorphism visual design
- Floating card-style accordion items
- Responsive across desktop, tablet, and mobile
- CSS-only accordion interaction
- No external dependencies
- Soft glass borders and shadows
- Background blur using `backdrop-filter`
- Smooth open/close transitions
- Keyboard focus styling
- `prefers-reduced-motion` support
- Fallback styling for browsers without `backdrop-filter`
