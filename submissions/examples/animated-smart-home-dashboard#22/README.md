# Animated Smart Home Dashboard

A modern **Smart Home Dashboard** built with **EaseMotion CSS**. Features room controls with toggle switches, circular temperature dial, energy usage charts, device lists, and room cards with active indicators.

## ✨ Features

- **🏠 Room Controls**: Device list with animated toggle switches and brightness slider
- **🌡️ Temperature Dial**: SVG circular gauge with gradient fill animation
- **⚡ Energy Charts**: Weekly bar chart with hover tooltips and device breakdown
- **🔘 Toggle Switches**: Interactive-style toggles with glow effects for active devices
- **🚪 Room Cards**: Grid of rooms with active/inactive indicators
- **📊 Quick Stats**: Energy, temperature, humidity, and security status cards
- **🎬 Staggered Entrance**: All sections slide up sequentially
- **📱 Fully Responsive**: Multi-column to single column adaptation

## 🧩 EaseMotion Classes Used

| Class | Purpose |
|-------|---------|
| `ease-fade-in` | Fades in the main page and footer |
| `ease-slide-up` | Slides sections up on entrance |
| `ease-delay-100` to `ease-delay-700` | Creates cascading staggered sequence |
| `ease-card` | Base card structure |
| `ease-hover-lift` | Lift effect on all cards and items |
| `ease-hover-grow` | Scale effect on buttons and icons |
| `ease-center` | Centers settings button icon |
| `ease-grid` + `ease-grid-cols-*` | Responsive grid layouts |
| `ease-gap-4` | Spacing between grid items |

## 🚀 How to Use

1. Open `demo.html` in any modern browser
2. Watch all dashboard sections slide in with staggered animations
3. Observe the **temperature dial filling** with gradient on load
4. See the **energy bars growing** with hover tooltips
5. Hover over device items and room cards to see glow effects
6. Notice the **pulsing room indicators** for active rooms
7. Resize to mobile to see the responsive layout
