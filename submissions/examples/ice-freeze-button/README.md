# CSS Ice Freeze Button


A CSS-only animated freeze button where ice crystals spread across the surface on hover.


## Overview

`ease-ice-freeze-button` creates an icy interaction effect using pure CSS animations.


## Features

- Pure CSS implementation
- No JavaScript dependency
- Ice crystal spreading effect
- Smooth hover animation
- Responsive design
- Reduced motion accessibility support
