# Animated Data Badge UI Example

A modern glassmorphism-inspired data badge component featuring animated counters, gradient highlights, and glowing hover effects.

## Features

- Animated numeric count
- Gradient background highlight
- Continuous glow animation
- Hover lift effect
- Glassmorphism design
- Three badge sizes:
  - Small
  - Medium
  - Large
