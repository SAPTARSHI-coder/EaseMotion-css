EaseMotion CSS

Vertical Rhythm Utility

Simple CSS utility classes for maintaining consistent vertical spacing between content elements.

Spacing Scale

.stack-xs

Extra Small Rhythm

This example uses the smallest spacing value between consecutive elements.

.stack-sm

Small Rhythm

A compact vertical rhythm suitable for closely related content.

.stack-md

Medium Rhythm

A balanced spacing option for most content sections.

.stack-lg

Large Rhythm

Larger spacing creates clear visual separation between content elements.

.stack-xl

Extra Large Rhythm

Useful for prominent sections and major content separation.

Example Usage

Consistent Content Spacing

Apply a rhythm utility class to a container and its child elements will receive consistent vertical spacing.

This keeps layouts predictable and reduces the need for repeatedly writing custom margin rules.
