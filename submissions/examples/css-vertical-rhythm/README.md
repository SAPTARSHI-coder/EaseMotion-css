# CSS Vertical Rhythm Utility

A lightweight collection of CSS utility classes for maintaining
consistent vertical spacing between adjacent elements.

## Features

- Pure CSS
- No JavaScript
- Reusable utility classes
- Consistent spacing scale
- Responsive demo
- Easy to customize
- Keyboard accessible demo controls
- Reduced-motion support
