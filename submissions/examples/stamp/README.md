# CSS Stamp Collection Card

A demo project that showcases a **stamp collection card** styled with CSS.  
It mimics the look of collectible stamps with a perforated border effect.

## Features
- Card layout with image and stamp details.
- Decorative dashed border to simulate perforations.
- Elegant typography for a vintage feel.

## Files
- `demo.html` → HTML structure of the stamp card.
- `style.css` → Styling for card, border effect, and text.
- `README.md` → Documentation and usage instructions.

## Usage
1. Open `demo.html` in your browser.
2. Replace the placeholder image with your own stamp image.
3. Update the text fields with stamp details (year, country, description).

## Customization Ideas
- Adjust border styles for different perforation effects.
- Add hover animations (e.g., zoom on stamp image).
- Create a grid of multiple stamp cards for a full collection display.
