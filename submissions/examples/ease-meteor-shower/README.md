# ☄️ Meteor Shower – Meteors Streak Across the Sky

> A dynamic meteor shower component where meteors streak across the night sky with 5 colors (White, Blue, Gold, Green, Pink), intensity control (0-100%), and particle trail effects.

---

## 📖 Description

The **Meteor Shower** component creates a dynamic meteor shower experience where meteors streak across the night sky with trailing particles. Built with vanilla HTML, CSS, and JavaScript, it features 5 colors (White, Blue, Gold, Green, Pink), intensity control (0-100%), and 100 background stars for an immersive celestial experience.

### 🎯 Core Features

- **Meteor shower** – meteors streak across the sky with trailing particles
- **5 colors** – White, Blue, Gold, Green, Pink
- **Intensity control** – adjust meteor frequency from 0-100%
- **Trail effects** – glowing trails with particle fade
- **Background stars** – 100 twinkling stars
- **Meteor counter** – tracks total meteors
- **Interactive controls** – sliders, color buttons, keyboard shortcuts
- **Responsive design** – adapts to different screen sizes

### ✨ Meteor Experience

When interacting:
1. **Meteors streak** – meteors fly across the sky
2. **Intensity applies** – controls meteor frequency
3. **Color applies** – changes meteor color
4. **Trails follow** – glowing particles trail behind
5. **Counter updates** – meteor count increments
6. **Status updates** – shows current state

### 🛠️ Technologies Used

- **HTML5** – semantic structure with Canvas
- **CSS3** – gradients, backdrop-filter, transforms
- **JavaScript (ES6)** – Canvas API, requestAnimationFrame, particle system

### 🎨 Design Philosophy

This component embodies **EaseMotion CSS's animation-first philosophy** through:

- **Dynamic motion** – meteors streak with natural speed
- **Particle effects** – glowing trails with fade
- **Visual feedback** – status updates, counter, controls
- **Celestial atmosphere** – night sky and stars
- **Human-readable classes** – `.meteor-controls`, `.color-btn`, `.meteor-text`

### 🔧 Customization Options

| Property | Location | Default |
|----------|----------|---------|
| Colors | `colors` object | 5 colors |
| Intensity range | `intensitySlider` | 0-100% |
| Meteor speed | `speed` | 2-6px/frame |
| Meteor length | `length` | 30-110px |
| Star count | `generateStars()` | 100 |
