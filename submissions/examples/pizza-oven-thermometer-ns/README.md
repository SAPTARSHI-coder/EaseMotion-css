# Pizza Oven Thermometer

## What does this do?
Renders a self-contained CSS-only `ease-pizza-oven-thermometer` demo: Pizza oven door thermometer needle sweeping into the bake zone.

## How is it used?
Open `demo.html` in a browser. The animated face uses classes like `ease-pizza-oven-thermometer`, `ease-pizza-oven-thermometer__arm`, and `ease-pizza-oven-thermometer__core`. No build step or JavaScript is required for the motion.

```html
<section class="ease-pizza-oven-thermometer">
  <div class="ease-pizza-oven-thermometer__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
