# CSS Shimmering Skeleton Loader

A skeleton loader component with smooth shimmering sweep animations for loading states.

## What does this do?

Creates placeholder loading skeletons with animated shimmer effects that provide visual feedback while content is loading. Uses pure CSS animations with no JavaScript.

## How is it used?

```html
<!-- Text Lines -->
<div class="skeleton skeleton--text"></div>
<div class="skeleton skeleton--text skeleton--short"></div>

<!-- Avatar -->
<div class="skeleton skeleton--avatar"></div>

<!-- Image -->
<div class="skeleton skeleton--image"></div>

<!-- Card Skeleton -->
<div class="skeleton-card">
  <div class="skeleton skeleton--image"></div>
  <div class="skeleton skeleton--text"></div>
  <div class="skeleton skeleton--text skeleton--short"></div>
</div>

<!-- Button -->
<div class="skeleton skeleton--button"></div>
```

## Why is it useful?

- Pure CSS shimmer animation
- Multiple skeleton variants
- Card layout presets
- Customizable colors
- Reduced motion support
- Improves perceived loading performance
