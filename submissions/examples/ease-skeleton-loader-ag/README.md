# Shimmering Skeleton Loader

A shimmering skeleton loader built purely with CSS, designed to provide a smooth loading state placeholder for your web layouts. It features a sweeping animated gradient that seamlessly blends into dark mode themes.

## Preview

Open `demo.html` in your browser to see the effect in action.

## Implementation Details

- **No JavaScript:** The animation is completely driven by CSS keyframes.
- **Gradient Animation:** Uses `linear-gradient` with a `background-size` of 200% and animates the `background-position` to create the shimmer effect.
- **Responsive:** Fluid layout using Flexbox that works gracefully on any screen size.
