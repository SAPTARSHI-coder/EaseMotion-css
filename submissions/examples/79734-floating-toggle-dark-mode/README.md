# Floating Toggle — Dark Mode

A responsive floating dark mode toggle built with pure HTML and CSS
for EaseMotion CSS.

Implemented for issue #79734.

## Features

- Floating dark mode toggle
- Modern dark UI styling
- Smooth toggle animation
- Sun and moon indicators
- Hover elevation effect
- Press interaction
- Keyboard accessibility
- Responsive layout
- Reduced-motion support
- No JavaScript
- No external dependencies
