# 3D Button — Cyberpunk

A responsive CSS-only 3D button inspired by cyberpunk
interfaces, featuring layered depth, neon accents, hover
elevation, and tactile press feedback.

Implemented for issue #79726.

## Features

- Cyberpunk visual design
- 3D layered button depth
- Neon cyan, purple, and pink accents
- Hover elevation
- Press-down interaction
- Animated glow sweep
- Animated arrow
- Responsive layout
- Keyboard focus-visible support
- Reduced-motion support
- No JavaScript
- No external dependencies
