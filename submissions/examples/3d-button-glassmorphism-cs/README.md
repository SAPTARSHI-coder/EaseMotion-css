# 3D Glassmorphism Button

A responsive 3D button component combining glassmorphism styling with a tactile depth effect using only HTML and CSS.

## Features

- Pure HTML and CSS
- Glassmorphism surface with transparency and blur
- Layered 3D button depth
- Hover elevation effect
- Pressed-state animation
- Keyboard-accessible focus state
- Responsive layout
- CSS custom properties for easy theming
- `prefers-reduced-motion` support
- No JavaScript
- No external dependencies
