# CSS Mesh Gradient: Holographic Flicker ✨

## Overview
The **CSS Mesh Gradient: Holographic Flicker Variation** creates a smooth, accessible, and performant gradient background with a holographic flicker effect.  
It is implemented entirely in **pure CSS**, ensuring lightweight performance and compatibility across devices.

---

## Specifications
- **Category**: Gradients & Mesh
- **Style**: Holographic Flicker
- **Features**:
  - Smooth CSS transitions
  - Dark mode compatible
  - Hardware accelerated with `will-change`

---

## Features
- ✅ Pure CSS (no JavaScript required)
- ✅ Responsive across all screen sizes
- ✅ Accessible with `role="img"` and `aria-label`
- ✅ Dark mode support
- ✅ Demo included (`demo.html` + `style.css`)
