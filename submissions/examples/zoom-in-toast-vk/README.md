# Zoom-In Toast

A modern, responsive Zoom-In Toast example built with pure HTML and CSS for EaseMotion CSS.

## Features

- Pure HTML & CSS
- Smooth zoom-in animation
- Responsive layout
- Hover interaction
- Success, Information, Warning and Error variants
- Accessible close buttons
- Supports `prefers-reduced-motion`
- Easy to customize with CSS variables

- Responsive layout
- Keyboard-friendly close buttons
- Motion reduction support using `prefers-reduced-motion`

Works in all modern browsers supporting CSS animations and media queries.
