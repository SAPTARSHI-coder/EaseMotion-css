# CSS 3D Layered Text

A striking typography effect that builds deep 3D volume using multiple offset `text-shadow` layers and dynamically tilts on hover.

## Features
- Deep extrusion created by chaining precise `text-shadow` offsets
- Dynamic hover interaction using `perspective`, `rotateX`, and `rotateY`
- Enhanced shadow casting via `translateZ` pushing the text forward on hover
