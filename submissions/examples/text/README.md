## Neon Text Flicker Sign Animation (`ease-anim-neon-text-flicker-sign`)

A keyframe utility simulating a realistic flickering neon sign effect, optimized for high-performance rendering.

### Usage

Add the `ease-anim-neon-text-flicker-sign` class to any text element:

```html
<h1 class="ease-anim-neon-text-flicker-sign">NEON SIGN</h1>
