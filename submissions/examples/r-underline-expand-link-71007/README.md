# CSS Underline Expand Link

A responsive CSS-only link interaction where the underline smoothly expands from the center outward on hover and keyboard focus.

## Features

- Pure CSS implementation
- Center-out underline animation
- Hover and keyboard focus support
- Multiple accent color variations
- Responsive layout
- Visible focus state
- Reduced-motion support
- No JavaScript required

## Files

- `demo.html` — Interactive demonstration
- `style.css` — Component styling
- `README.md` — Documentation

## Usage

```html
<a class="expand-link" href="#home">
  <span>Home</span>
</a>
