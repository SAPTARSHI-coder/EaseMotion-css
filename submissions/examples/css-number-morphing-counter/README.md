# CSS Number Morphing Counter

A pure CSS animated number counter that smoothly transitions between predefined numeric states.

## Features

- Pure CSS — no JavaScript required
- Smooth number-morphing animation
- Uses CSS custom properties for easy customization
- Responsive layout
- Light and dark mode support
- Reduced-motion support
- Suitable for dashboards, statistics, metrics, and landing pages

## Usage

Include the HTML structure:

```html
<div class="number-counter" aria-label="Projects completed">
  <div class="number-counter__value">
    <span class="number-counter__digit">1</span>
    <span class="number-counter__digit">2</span>
    <span class="number-counter__digit">8</span>
  </div>
  <span class="number-counter__label">Projects Completed</span>
</div>
