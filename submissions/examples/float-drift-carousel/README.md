# CSS Float-Drift Carousel for Accessible Web Layouts

A modern **Float-Drift Carousel** component built using only **HTML5 and CSS3**.

This example demonstrates smooth floating animations, drifting glow effects, responsive carousel cards, and accessibility support without JavaScript.

---

## ✨ Features

- 🌊 Floating drift animation
- 🎴 Interactive carousel cards
- 💫 Animated background glow
- ⚡ Smooth CSS transitions
- 🎨 Gradient UI effects
- 📱 Fully responsive layout
- 🎯 CSS Custom Properties
- ♿ `prefers-reduced-motion` support
- 🚫 Zero JavaScript dependency

---

## 🚀 Usage

1. Open `demo.html` in any modern browser.
2. Hover over cards to see floating interactions.
3. Customize colors and animation speed using CSS variables.
