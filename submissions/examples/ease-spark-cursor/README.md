# ✨ Spark Cursor – Emits Sparks in All Directions

> A magical, celebratory cursor effect where the cursor emits colorful sparks in all directions, creating a dazzling, festive visual experience.

---

## 📖 Description

The **Spark Cursor** is a magical, celebratory cursor effect where the cursor emits colorful sparks in all directions. As you move your mouse, vibrant sparks burst outward in a 360° spray, creating a dazzling, festive visual experience reminiscent of sparklers or magical energy. The sparks have random colors, sizes, and trajectories, with a soft glow that adds to the magical feel.

The component uses JavaScript to create sparks at the cursor position with random properties (every 30ms). Each spark has random size (2-7px), color from a vibrant 16-color palette, direction (360°), speed (30-120px/s), glow (10-40px), rotation, and duration (0.6-1.6s). Clicking creates a spark burst with 50 sparks, and hovering over interactive elements triggers a smaller burst of 25 sparks.

Perfect for magical interfaces, celebration apps, creative portfolios, and any application where you want to create a dazzling, energetic cursor experience. The Spark Cursor transforms a simple cursor into a magical, festive spectacle.
