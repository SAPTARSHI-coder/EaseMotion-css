# ease-skew-pricing Skew-Active Pricing Table

## What does this do?

A pricing table component with dynamic skew animations on hover, creating a modern dynamic feel perfect for fintech dashboards.

## How is it used?

```html
<div class="ease-skew-pricing">
  <div class="ease-skew-card">
    <span class="plan-name">Pro</span>
    <span class="plan-price">$29</span>
    <button class="ease-skew-btn">Get Started</button>
  </div>
</div>
```

### CSS Classes

| Class | Purpose |
|-------|---------|
| `.ease-skew-pricing` | Container for pricing cards |
| `.ease-skew-card` | Individual pricing card with skew animation |
| `.ease-skew-btn` | CTA button with skew effect |
| `.ease-skew-featured` | Featured/highlighted plan |

## Why is it useful?

Creates a dynamic, modern pricing experience with skew transformations:

- ✅ Dynamic skew animations
- ✅ Multiple pricing tiers
- ✅ Featured plan highlighting
- ✅ Modern fintech aesthetic
- ✅ Responsive layout
