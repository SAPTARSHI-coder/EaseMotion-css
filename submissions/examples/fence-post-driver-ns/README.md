# Ease Fence Post Driver

A CSS-only animated fence post driver component created for EaseMotion CSS.

## Overview

`ease-fence-post-driver` simulates a mechanical fence post driver repeatedly striking a wooden post into the ground.

## Features

- Pure CSS animation
- No JavaScript dependency
- Industrial motion metaphor
- Hammer impact animation
- Real-world construction themed UI
- Responsive layout
- Reduced motion support

<div class="ease-fence-post-driver">
