# Fence Post Driver

## What does this do?
Renders a self-contained CSS-only `ease-fence-post-driver` demo: Fence post driver slamming a post into ground.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-fence-post-driver`. No build step or JavaScript is required for the effect.

```html
<section class="ease-fence-post-driver">
  <div class="ease-fence-post-driver__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
