# CSS Fade-In Carousel for SaaS Showcase Layouts

A modern SaaS showcase carousel component featuring smooth fade-in entrance animation, glassmorphism cards, responsive layout, and a pure CSS implementation.

Built completely with HTML and CSS without JavaScript or external dependencies.


## ✨ Features

- ✨ Smooth fade-in entrance animation
- 🎭 CSS opacity and transform based reveal effect
- 💎 Glassmorphism carousel card design
- 🎨 Modern SaaS showcase interface
- 🖱️ Smooth hover interactions
- ⚡ Pure HTML and CSS implementation
- 📱 Responsive across desktop, tablet, and mobile
- ♿ prefers-reduced-motion accessibility support
- 🚀 Lightweight and framework-free

## 🚀 Usage

1. Open `demo.html` in any modern browser.

2. The carousel cards automatically appear with a fade-in animation.

3. Customize content, colors, and animation duration inside `style.css`.

✨ Animation Details

Cards use CSS keyframe animation:

.card {

    animation:

    fadeIn .9s ease forwards;

}
