# glow-card-stack-v7-ak

Pure CSS 3D floating stacked cards hover fan-out effect — no JavaScript required.

## How to use

```html
<div class="ease-card-stack-v7">
  <div class="ease-card-stack-item-v7">Top</div>
  <div class="ease-card-stack-item-v7">Middle</div>
  <div class="ease-card-stack-item-v7">Bottom</div>
</div>
