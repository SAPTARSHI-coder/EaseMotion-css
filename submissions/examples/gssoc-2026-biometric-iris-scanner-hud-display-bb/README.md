# Biometric Iris Scanner HUD Display

A sci-fi biometric iris authentication scanner component with concentric rotating reticle rings and animated laser scanline beams.

## 1. What does this do?
This component renders an interactive HUD security card featuring continuous counter-rotating dashed reticles, a laser targeting sweep beam, and real-time encryption telemetry data boxes.

## 2. How is it used?
Link `style.css` and use the `.hud-card` container:

```html
<link rel="stylesheet" href="style.css">

<div class="hud-card" tabindex="0">
  <div class="scanner-core">
    <div class="ring outer-ring"></div>
    <div class="scan-beam"></div>
  </div>
</div>
```

## 3. Why is it useful?
It provides cybersecurity platforms, futuristic gaming hubs, and biometrics onboarding screens with a high-fidelity HUD interface requiring zero JS dependencies.
