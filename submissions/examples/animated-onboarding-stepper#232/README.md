# Animated Onboarding/Stepper Form

A polished **Onboarding/Stepper Form** built with **EaseMotion CSS**. Features multi-step progress indicator, animated orbit illustration, form fields with focus states, option selectors, and helpful tips.

## ✨ Features

- **📊 Progress Stepper**: 4-step wizard with completed/active states
- **🪐 Orbit Animation**: Rotating orbit illustration with pulse center
- **📷 Photo Upload**: Circular upload area with rotating ring
- **📝 Form Fields**: Styled inputs with focus glow effects
- **🎯 Option Selector**: Grid of selectable options
- **💡 Tips Section**: Helpful onboarding tips
- **🎬 Staggered Entrance**: All sections animate sequentially
- **📱 Fully Responsive**: Desktop → tablet → mobile layout

## 🧩 EaseMotion Classes Used

| Class | Purpose |
|-------|---------|
| `ease-fade-in` | Fades in the main page and photo upload |
| `ease-slide-up` | Slides sections up on entrance |
| `ease-slide-in-left` | Slides illustration from left |
| `ease-slide-in-right` | Slides form from right |
| `ease-delay-100` to `ease-delay-900` | Creates cascading staggered sequence |
| `ease-card` | Base card structure |
| `ease-hover-lift` | Lift effect on form card |
| `ease-hover-grow` | Scale effect on buttons and options |
| `ease-btn` + `ease-btn-primary` | Styled continue button |
| `ease-pulse` | **Looping pulse** on active step and center icon |

## 🚀 How to Use

1. Open `demo.html` in any modern browser
2. Watch the illustration and form slide in from opposite directions
3. Observe the **rotating orbit animation** and **pulsing center icon**
4. Notice the **progress bar filling** animation
5. Test form field focus states
6. Click option buttons to see active states
7. Resize to mobile to see responsive layout
