# Glowing Toggle - Retro

A responsive CSS-only glowing toggle switch inspired by retro arcade and neon control interfaces.

## Features

- Retro neon visual design
- Glowing ON/OFF states
- Smooth toggle animation
- Fully responsive layout
- Keyboard accessible
- Visible focus state
- Reduced-motion support
- No JavaScript required
- Pure HTML and CSS

## Preview

Open `demo.html` in a modern browser to view the component.
