# CSS Snowglobe Background

A responsive snowglobe scene built entirely with HTML and CSS.

## Features

- Animated falling snow
- CSS-only mountains, trees, moon, snow and globe
- Responsive layout
- No JavaScript or external libraries
- Respects `prefers-reduced-motion`

## Usage

Link the stylesheet and use the snowglobe markup from `demo.html`.

```html
<link rel="stylesheet" href="style.css">
<main class="snowglobe">
  <!-- Snowglobe content -->
</main>
