# CSS Button - Neumorphic Soft Shadow

A modern Neumorphic Soft Shadow button built entirely with HTML and CSS. This design uses soft dual shadows and subtle depth effects to create a tactile, physical interface inspired by neumorphism.

## Features

- Pure HTML & CSS
- Neumorphic Soft Shadow styling
- Soft raised surface effect
- Interactive pressed state
- Smooth hover animations
- Keyboard accessible
- Responsive design
- Dark mode compatible
- Hardware accelerated transitions
- No JavaScript required

## Usage

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

Use the button:

```html
<button class="neumorphic-btn">
  Soft Touch
</button>
```
