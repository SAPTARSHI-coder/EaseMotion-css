# Interactive Heatmap Grid Showcase

A cyberpunk-themed interactive heatmap grid with animated hover states and tooltips.

Built using pure HTML, CSS and JavaScript without external dependencies.

## Features

- Cyberpunk visual design
- Interactive heatmap cells
- Tooltip on hover and keyboard focus
- Activity intensity levels
- Click interaction animation
- Neon glow effects
- Responsive mobile layout
- Keyboard accessible cells
- Reduced-motion accessibility support
- No external libraries
