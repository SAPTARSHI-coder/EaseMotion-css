# Dynamic File Dropzone with Gradient Glow

A responsive, CSS-only file dropzone featuring animated gradient glow
effects, modern interactions, and an accessible responsive layout.

## Features

- Pure HTML and CSS
- Zero external JavaScript dependencies
- Animated gradient glow effects
- Smooth hover and focus transitions
- Responsive layout
- Keyboard-accessible file selection
- Native file input
- `prefers-reduced-motion` support
- Modern dark gradient interface
