# Ivory Glen

A unique landing page for Ivory Glen built with EaseMotion CSS framework.

## Features
- Pure EaseMotion CSS from CDN
- Responsive across all devices
- Zero JavaScript
- 4 unique sections: stats, contact, testimonials, services

## Setup
Open `demo.html` in any modern browser.

## Structure
```

  demo.html
```
