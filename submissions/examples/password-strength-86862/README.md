# Password Strength Meter (#86862)

An interactive password input component featuring a dynamic four-stage security evaluation bar, real-time criteria checklist, and password visibility toggle.

## Features
- **4-Stage Strength Calculation:** Evaluates length, lower/upper characters, numbers, and special symbols.
- **Dynamic Segment Progression:** Segmented status bars smoothly transition color from weak red to secure emerald.
- **Interactive Toggles:** Visibility eye toggle with instant focus preservation.
- **Accessibility:** Fully accessible with standard input semantics and `@media (prefers-reduced-motion: reduce)` support.

## Usage
Include `style.css` in your project and structure your password elements inside `.password-field-group`.
