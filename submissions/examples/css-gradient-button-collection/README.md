# CSS Gradient Button Collection

A collection of 10 vibrant gradient buttons with smooth hover lift effects built using pure HTML and CSS.

## Features

- 10 unique gradient button styles
- Hover lift animation
- Responsive grid layout
- Rounded modern design
- Lightweight implementation
- Pure HTML & CSS
- No JavaScript required

## Folder Structure

```
css-gradient-button-collection/
├── demo.html
├── style.css
└── README.md
```

## Technologies

- HTML5
- CSS3
- CSS Gradients
- CSS Transitions
- CSS Grid

## Purpose

Provides a reusable collection of colorful gradient buttons suitable for landing pages, dashboards, portfolios, and modern web interfaces while following EaseMotion CSS's animation-first philosophy.
