# CSS Elastic-Slide Navbar for Product Catalog Layouts

A modern **Elastic-Slide Navbar** component built using pure HTML5 and CSS3 for product catalog showcase layouts. This component provides a smooth elastic navigation experience with animated indicators, glassmorphism styling, responsive behavior, and interactive hover effects.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Modern product catalog navigation
* Elastic slide indicator animation
* Smooth hover transitions
* Glassmorphism navbar design
* Gradient CTA button styling
* Responsive desktop, tablet, and mobile layouts
* CSS Custom Properties for easy customization
* Lightweight keyframe animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over navigation items to view the elastic slide effect.
3. Customize colors, spacing, shadows, and animation values using CSS variables inside `:root`.

## CSS Custom Properties

```css
:root{
  --bg:#f8fafc;
  --surface:rgba(255,255,255,.85);
  --primary:#2563eb;
  --secondary:#06b6d4;
  --text:#111827;
  --muted:#64748b;
  --shadow:0 20px 60px rgba(37,99,235,.18);
  --radius:25px;
}
```
