ease-badge-pulse-keyframe

Pulse badge with a declared keyframe.

Fixes the issue where .ease-badge-pulse referenced an animation whose @keyframes rule was missing, so the badge rendered without pulsing. This example declares the ease-kf-ping keyframes and a complete, working pulse badge — with size variants, color variants, and reduced-motion support.

The fix

/* The missing keyframes — now declared */
@keyframes ease-kf-ping {
  0%   { transform: scale(1);   opacity: 0.55; }
  70%  { transform: scale(2.2); opacity: 0; }
  100% { transform: scale(2.2); opacity: 0; }
}

.ease-badge-pulse::before {
  content: "";
  position: absolute; inset: 0;
  border-radius: inherit;
  background: inherit;
  z-index: -1;
  animation: ease-kf-ping 1.8s cubic-bezier(0.22,1,0.36,1) infinite;
}
