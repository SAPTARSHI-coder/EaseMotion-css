# Profile Setup Dashboard

A responsive pure CSS profile setup dashboard with animated progress tracking, completion states, and interactive step cards.

## Features

- Responsive profile setup dashboard
- Animated 75% progress indicator
- Four-step profile completion workflow
- Completed, active, and pending step states
- Interactive hover effects
- Smooth CSS animations
- Gradient progress bar and modern glass-style UI
- Fully responsive layout
- Pure HTML and CSS implementation
- No external dependencies

## Topics Covered

- CSS Grid and Flexbox
- CSS custom properties
- Linear and radial gradients
- CSS animations and keyframes
- Responsive media queries
- Hover and transition effects
- `clamp()` and `min()` functions
- `prefers-reduced-motion`
- Modern dashboard UI design

## Files

- `demo.html` — Dashboard markup
- `style.css` — Complete component styling and animations
- `README.md` — Component documentation

## Usage

Open `demo.html` directly in a modern web browser.

No build tools or dependencies are required.

## Preview

The component displays a profile setup dashboard showing:

1. Personal Information — Completed
2. Profile Photo — Completed
3. Contact Details — Active
4. Preferences — Pending

The progress indicator displays **75% completion**.
