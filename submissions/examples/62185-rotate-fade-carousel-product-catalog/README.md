# CSS Rotate-Fade Carousel for Product Catalog Layouts

A modern **Rotate-Fade Carousel** component built using pure HTML5 and CSS3 for product catalog showcase layouts. This component creates an engaging product display experience with 3D rotation effects, fade transitions, animated indicators, and responsive design.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* CSS-only product carousel animation
* Smooth rotate-fade transitions
* 3D rotation effects
* Product showcase card layout
* Glassmorphism UI styling
* Animated carousel indicators
* Smooth hover interactions
* Responsive desktop, tablet, and mobile layouts
* CSS Custom Properties for easy customization
* Lightweight keyframe animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. View the automatic rotate-fade product carousel animation.
3. Hover over cards to pause the visual interaction and explore product details.
4. Customize colors, shadows, spacing, and animation duration using CSS variables inside `:root`.

## CSS Custom Properties

```css
:root{
  --bg:#eef4ff;
  --surface:rgba(255,255,255,.92);
  --primary:#2563eb;
  --secondary:#06b6d4;
  --accent:#8b5cf6;
  --text:#111827;
  --muted:#64748b;
  --shadow:0 30px 80px rgba(37,99,235,.2);
  --radius:30px;
}
```
