# Morph-Glow Accordion

A pure CSS accordion component designed for minimalist tech layouts. The component combines smooth content expansion with a subtle morphing and glow effect to create an interactive, modern interface without JavaScript.

## Features

- Pure HTML and CSS
- Smooth accordion expand/collapse animation
- Morphing border-radius effect
- Subtle glow interaction
- Responsive layout for desktop, tablet, and mobile
- Keyboard-accessible native `<details>` and `<summary>` interaction
- Supports `prefers-reduced-motion`
- No external libraries or frameworks
- Works by opening `demo.html` directly in a browser

## Files

- `demo.html` — Standalone demonstration of the accordion
- `style.css` — CSS styles, transitions, animations, and responsive rules
- `README.md` — Documentation and usage information
