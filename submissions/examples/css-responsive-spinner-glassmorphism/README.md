# Responsive Spinner with Glassmorphism styling (#78850)

A responsive loading spinner component built with translucent frosted glass panels (`backdrop-filter`), concentric dual-rotating neon rings, pulsating glowing core elements, and background ambient keyframe orbs.

## Features
- **Concentric Dual-Rotation:** Outer and inner spinning rings moving in opposing directions with distinct cubic-bezier timing functions.
- **Glassmorphism Aesthetic:** Translucent backdrop blur panel (`backdrop-filter: blur()`), subtle border reflections, and glowing orb backgrounds.
- **Accessible & Responsive:** Accessible `role="status"` markup with `aria-label` definitions and fully responsive layout dimensions.

## File Hierarchy
- `style.css` - Glassmorphism design tokens, CSS `@keyframes` rotation rules, and responsive media queries.
- `demo.html` - Semantic HTML structure presenting the loading spinner card.
- `README.md` - Technical specification and architecture overview.
