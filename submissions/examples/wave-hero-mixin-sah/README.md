# Wave Hero Banner Gradient Mixin (`#54687`)

## What does this do?
Generates an immersive background gradient waveform that smoothly cycles across multi-stop aurora chromatic palettes for premium website landing headers.

## How is it used?
Apply the `ease-hero-wave` background container class directly to top-level section banners:
```html
<section class="ease-hero-wave">
  <h1>Aurora Hero Title</h1>
</section>
```

## Why is it useful?
Solves issue #54687 by eliminating heavy canvas video file textures with ultra-smooth pure CSS aurora background rendering.
