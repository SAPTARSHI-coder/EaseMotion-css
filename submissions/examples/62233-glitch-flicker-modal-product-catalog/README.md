# CSS Glitch-Flicker Modal for Product Catalog Layouts

A modern **Glitch-Flicker Modal** built using pure HTML5 and CSS3 for product catalog layouts. The component provides a responsive product quick-view modal with stylish glitch-flicker entrance animations, glassmorphism styling, and accessibility support.

## Features

* Pure HTML5 & CSS3
* Glitch-Flicker modal animation
* CSS-only modal toggle using checkbox technique
* Responsive product catalog layout
* Glassmorphism modal design
* Product image, title, description, price, rating, stock status, and CTA button
* Animated overlay backdrop
* Smooth CSS transitions & keyframe animations
* CSS Custom Properties
* No JavaScript required
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in a modern browser.
2. Click the **Quick View** button to open the Glitch-Flicker Modal.
3. Click the **✕** button or the overlay to close the modal.
4. Customize colors, spacing, shadows, and animation timing through the CSS variables defined in `:root`.
