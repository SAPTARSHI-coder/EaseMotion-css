# 3D-Flip Creative Portfolio Carousel (`#54453`)

## What does this do?
Provides an avant-garde creative exhibition carousel deck where switching between slides rotates the entire presentation container across 180-degree 3D perspective space.

## How is it used?
Organize front and back slide cards inside an `ease-carousel-3d-flip` perspective wrapper:
```html
<div class="ease-carousel-3d-flip">
  <div class="flip-deck">
    <div class="card front">...</div>
    <div class="card back">...</div>
  </div>
</div>
```

## Why is it useful?
Solves issue #54453 by enabling design studios to pair visual prototypes on Side A with underlying engineering specifications on Side B via clean 3D flips.
