# CSS Rotate-Fade Pricing Table for Product Catalog Layouts

A modern **Rotate-Fade Pricing Table** built using pure HTML and CSS. The component features subtle rotate-fade hover animations, responsive pricing cards, CSS custom properties, and lightweight styling for modern product catalog pages.

## ✨ Features

- Pure HTML5 & CSS3
- Rotate-fade hover animation
- Responsive pricing table
- Glassmorphism design
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
