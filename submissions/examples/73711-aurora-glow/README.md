# CSS Glass Effect: Aurora Glow

A smooth, accessible, and performant pure CSS glassmorphism component featuring
a dynamic Aurora Glow aesthetic.

## Features

- Pure HTML and Vanilla CSS
- Aurora-inspired animated gradients
- Glassmorphism translucent surface
- Soft background lighting
- Animated internal aurora icon
- Backdrop blur
- Smooth hover elevation
- Hardware-friendly CSS transforms
- Dark mode compatible
- Responsive design
- Accessible keyboard focus states
- `prefers-reduced-motion` support
- No JavaScript
- No external libraries
