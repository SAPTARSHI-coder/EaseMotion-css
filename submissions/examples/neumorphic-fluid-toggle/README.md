# Neumorphic Fluid Toggle Switch

A physically accurate neumorphic toggle switch demonstrating fluid width shifting during interaction.

## Features
- Momentum Physics: The thumb expands on active state creating a squishy, fluid feel when moving.
- Neumorphism: Relies on contrasting inner and outer box-shadows matching the background color for extrusion effects.

## Usage
Utilizes the checkbox hack for state retention. Ensure the checkbox and track are sibling elements.
