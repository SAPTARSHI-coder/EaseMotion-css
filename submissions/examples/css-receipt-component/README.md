# CSS Receipt Component

A clean, responsive digital receipt component built entirely with HTML and CSS.

## Features

- Pure HTML and CSS
- No JavaScript required
- Responsive on desktop, tablet, and mobile
- Dotted receipt separators
- Order details and purchased items
- Subtotal, tax, and total sections
- CSS entrance animation
- Success icon animation
- CSS custom properties for easy customization
- Automatic light/dark mode support
- `prefers-reduced-motion` accessibility support
- Semantic HTML structure
