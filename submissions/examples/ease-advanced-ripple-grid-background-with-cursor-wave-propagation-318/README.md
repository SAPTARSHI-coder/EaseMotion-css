# Advanced Ripple Grid Background with Cursor Wave Propagation

An interactive, dark-themed CSS and minimal JS background component featuring:
- A dynamic 3D-perspective moving grid
- A glowing aura that tracks the user's cursor
- A wave-propagation ripple effect triggered on click
- Glassmorphic content cards

## Files Included
- `demo.html`: The HTML structure and minimal JS for interaction tracking.
- `style.css`: The CSS styling for the 3D grid, animations, gradients, and layout.
- `README.md`: This documentation file.

## How to use
1. Open `demo.html` in your browser.
2. Move your cursor across the window to see the glow track your movement.
3. Click anywhere on the background to trigger the wave propagation ripple effect.

Developed for EaseMotion-css.
