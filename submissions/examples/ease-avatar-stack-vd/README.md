# Ease Avatar Stack

## What does this do?

A reusable overlapping avatar group component with a remaining members badge.

---

## How is it used?

Open `demo.html` in any modern browser.

Example:

```html
<div class="avatar-stack">

    <div class="avatar">A</div>
    <div class="avatar">B</div>
    <div class="avatar">C</div>

    <div class="avatar more">
        +8
    </div>

</div>
```

Features:

- Overlapping avatars
- Hover lift animation
- Remaining members badge
- Responsive layout

---

## Why is it useful?

Avatar stacks are commonly used in collaboration tools, team dashboards, project management platforms, and chat applications. This lightweight component provides a clean and reusable way to display grouped users while matching EaseMotion CSS's animation-first philosophy.
