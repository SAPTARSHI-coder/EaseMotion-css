# Dance Floor · Floor Lights Up with Movement 🪩

An interactive dance floor where tiles light up with movement, creating a dynamic light show effect with vibrant colors and disco vibes.

## Features

- 🪩 **Dance Floor** – Grid of light-up tiles
- 💃 **Movement Tracking** – Lights follow cursor
- 🎨 **Rainbow Colors** – Dynamic hue shifting
- 🎚️ **Size Control** – Adjust tile size (4-16)
- 🎚️ **Speed Control** – Adjust animation speed (1-10)
- ⏸️ **Pause/Resume** – Toggle animation
- 🔄 **Reset** – Reset floor
- ✨ **Glow Effects** – Glowing tiles with shadows

## How to Use

1. **Move your mouse** or **drag your finger** on the canvas
2. Watch the tiles light up around your cursor
3. A trail effect follows your movement
4. Adjust **Size** for tile density
5. Adjust **Speed** for animation pace
6. Press **RESET** or **R** to reset
7. Press **PAUSE** or **P** to pause/resume animation

## Technical Details

- **Grid:** Dynamic tile grid based on size
- **Lighting:** Distance-based brightness
- **Colors:** HSL hue shifting
- **Performance:** 60fps with requestAnimationFrame

## Customization

You can easily customize:
- **Tile Size:** Adjust slider range (4-16)
- **Speed:** Modify animation speed
- **Colors:** Change hue range
- **Glow:** Adjust glow intensity
- **Radius:** Modify light radius

## Browser Support

Works in all modern browsers:
