# glow-card-stack-v6-ak

Pure CSS 3D floating stacked cards hover fan-out effect — no JavaScript required.

## How to use

```html
<div class="ease-card-stack-v6">
  <div class="ease-card-stack-item-v6">Top</div>
  <div class="ease-card-stack-item-v6">Middle</div>
  <div class="ease-card-stack-item-v6">Bottom</div>
</div>
