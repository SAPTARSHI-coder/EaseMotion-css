# Particle Burst Action Button for High-Conversion CTA Triggers

### Minimalist Clean Edition

A clean **Particle Burst Action Button** built with **HTML5** and **CSS3** featuring subtle burst particles, responsive design, and accessibility-friendly interactions.

---

## ✨ Features

- Minimalist CTA button
- Particle burst hover animation
- Responsive layout
- Smooth transitions
- CSS Variables
- Keyboard accessibility
- `prefers-reduced-motion` support
- Pure HTML & CSS
