# Traction Trebuchet Pull

## What does this do?
Renders a self-contained CSS-only `ease-traction-trebuchet-pull` demo: Traction trebuchet team pull release.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-traction-trebuchet-pull`. No build step or JavaScript is required for the effect.

```html
<section class="ease-traction-trebuchet-pull">
  <div class="ease-traction-trebuchet-pull__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
