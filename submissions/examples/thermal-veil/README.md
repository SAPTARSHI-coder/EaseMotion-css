# 🌡️ Thermal Veil

An interactive atmospheric heat-flow visualization where invisible thermal currents become visible through animated particles, flowing streamlines, and localized turbulence.

The user's pointer acts as a temporary heat source, allowing the atmosphere to react dynamically to movement.

Built with native HTML, CSS, JavaScript, and the Canvas API.

## 🧠 Concept

Thermal energy is normally invisible.

You cannot directly see warm air rising or convection currents moving through a room.

Thermal Veil creates an abstract visualization of that hidden movement.

The component continuously generates a procedural vector field and moves particles through it.

When the user interacts with the field, a localized heat source modifies the surrounding flow.

This produces a temporary turbulent region.
