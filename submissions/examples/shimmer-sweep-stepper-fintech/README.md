# CSS Shimmer-Sweep Stepper for Fintech Dashboard Layouts

A modern, responsive fintech transaction stepper built entirely with
HTML and CSS.

The active transaction stage features a continuous shimmer-sweep
animation that visually communicates an operation that is currently
being processed.

## Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- CSS shimmer-sweep animation
- Active transaction indicator
- Animated progress bar
- Completed states
- Active state
- Upcoming states
- Responsive desktop layout
- Responsive tablet layout
- Responsive mobile layout
- CSS custom properties
- Semantic HTML
- Accessible progressbar
- Reduced-motion support
