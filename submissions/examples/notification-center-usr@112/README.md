# Animated Notification Center Submission

## 1. What does this do?
It provides a modern, animated notification center with bell icon, dropdown panel, unread badges, filter tabs, and smooth animations. Perfect for social media, dashboards, email clients, and collaboration tools.

## 2. How is it used?
Click the bell icon to open the notification dropdown. Notifications are categorized by type (mention, message, task, system, like) and can be filtered (All, Unread, Mentions). Click to mark as read, or use "Mark all as read" button. The dropdown closes when clicking outside or pressing Escape.

## 3. Why is it useful?
- Essential component for modern web applications
- Animated bell icon with shake effect on click
- Unread notification badge with pulse animation
- Smooth dropdown with staggered item entrance
- Filter tabs for different notification types
- Mark as read functionality (individual and bulk)
- Different notification types with color-coded icons
- Click outside to close functionality
- Keyboard accessible (Escape to close)
- Fully responsive design
- Includes `prefers-reduced-motion` support for accessibility
- Easy to customize colors, icons, and notification types
- Maintainer can easily standardize this as `.ease-notification-center-[YOUR_INITIALS]` in the core library.
