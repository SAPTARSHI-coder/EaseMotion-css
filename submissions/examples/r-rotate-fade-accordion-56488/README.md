# CSS Rotate-Fade Accordion

A modern **Rotate-Fade Accordion** built using pure HTML5 and CSS3 for Gaming Hub layouts. The accordion panels smoothly rotate and fade into view while remaining lightweight, responsive, accessible, and easy to customize.

---

## ✨ Features

- Pure HTML5 & CSS3
- Rotate-fade entrance animation
- Gaming-inspired accordion layout
- Responsive design
- CSS Custom Properties
- Lightweight and performant
- Accessible semantic HTML using `<details>` and `<summary>`
- `prefers-reduced-motion` support
- No JavaScript required

## 🚀 Usage

1. Copy the component into your project.
2. Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

3. Open `demo.html` in any modern browser.
