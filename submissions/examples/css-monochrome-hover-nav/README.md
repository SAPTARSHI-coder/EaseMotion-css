# CSS Monochrome Hover Nav (#70801)

A navigation component where hovering over any link mutes and desaturates neighboring items, built entirely with pure CSS.

## Features
- **Semantic Structure:** Uses accessible `<nav>` and unordered list markup with keyboard focus support.
- **Pure CSS Selectors:** Uses clever parent-hover child selectors to dim non-targeted links without JavaScript.
- **Responsive Layout:** Flexbox-based architecture that scales cleanly across viewports.

## File Hierarchy
- `style.css` - Navigation layouts, hover pseudo-classes, and color transitions.
- `demo.html` - Semantic markup and accessibility attributes.
- `README.md` - Technical specification and architecture summary.
