# CSS Shortcut Reference Card

A polished and responsive keyboard shortcut reference card built using pure HTML and CSS for EaseMotion CSS.

## ✨ Features

- Pure HTML and CSS
- No JavaScript dependency
- Semantic `<kbd>` elements
- Responsive desktop and mobile layouts
- Organized shortcut categories
- Keyboard-style keycaps
- Interactive hover states
- Subtle elevation and transitions
- Accessible focus-friendly structure
- Reduced-motion support
- Modern CSS custom properties
- No external dependencies
