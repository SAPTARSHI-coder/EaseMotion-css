Keyboard Shortcuts

Quick reference for common productivity shortcuts.

01

Editing

Common text and content operations.

Copy Copy selected content
Ctrl + C
Paste Paste copied content
Ctrl + V
Undo Undo the previous action
Ctrl + Z
Redo Restore the previous action
Ctrl + Shift + Z
02

Navigation

Move quickly through your workspace.

Search Open application search
Ctrl + K
Select All Select all available content
Ctrl + A
Find Find text on the current page
Ctrl + F
03

Browser

Useful browser-level shortcuts.

New Tab Open a new browser tab
Ctrl + T
Close Tab Close the active browser tab
Ctrl + W
Refresh Reload the current page
Ctrl + R
CSS-only component Keyboard friendly
