# Gear Train Mesh

## What does this do?
Renders a self-contained CSS-only `ease-gear-train-mesh` demo: Clock gear train teeth meshing in cascade.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-gear-train-mesh`. No build step or JavaScript is required for the effect.

```html
<section class="ease-gear-train-mesh">
  <div class="ease-gear-train-mesh__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
