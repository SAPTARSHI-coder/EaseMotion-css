# Rotate-Fade Progress Bar

A minimalist, tech-inspired progress bar featuring a glowing tip that rotates and fades smoothly. Ideal for dashboards, loaders, and modern tech layouts.

## Usage

```html
<div class="ease-progress-track">
    <div class="ease-rotate-fade-bar" style="width: 75%;"></div>
</div>
```

## Why is it useful?

It adds a subtle yet futuristic micro-animation to standard progress indicators, keeping users engaged without overwhelming the interface. This fits perfectly into EaseMotion's philosophy of modern, fluid, and accessible design.

## Features
- Pure CSS implementation with no external JS dependencies
- Smooth 3D rotation and fade animation on the progress tip
- Elegant glow effect for minimalist tech layouts
- Built-in `prefers-reduced-motion` support for accessibility
- Fully responsive and easily adaptable to different themes
