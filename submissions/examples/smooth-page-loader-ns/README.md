# CSS Smooth Page Loader (#70990)

A full-page loading overlay component featuring a glowing spinner and an upward sweeping transition curtain that reveals underlying content using pure CSS.

## Features
- Pure CSS multi-stage transition overlay (`@keyframes ease-loader-sweep`, `ease-loader-fadeout`).
- Smooth custom cubic-bezier timing curve for professional cinematic feel.
- Zero JavaScript required to execute the load sequence.
- Built-in accessibility override (`prefers-reduced-motion`) to bypass the overlay immediately for motion-sensitive users.
