# Animated Food Delivery App UI

A vibrant **Food Delivery App Interface** built with **EaseMotion CSS**. Features food category pills, dish cards with hover zoom, promotional banner, delivery tracking progress, and interactive add-to-cart buttons.

## ✨ Features

- **🍕 Category Pills**: Horizontally scrollable food category filters with active states
- **🎯 Promo Banner**: Gradient promotional card with bouncing emoji animation
- **🍽️ Dish Cards**: 8 food cards with image hover zoom, ratings, badges, and add buttons
- **🏷️ Multiple Badge Types**: Popular, New, Discount, and Healthy badges
- **❤️ Favorite Button**: Heart button with hover color change
- **🚴 Delivery Tracking**: Progress bar with step indicators and pulse animation
- **🔍 Search Bar**: Styled search input with focus state
- **🎬 Staggered Entrance**: All sections slide up sequentially
- **📱 Fully Responsive**: 4-column → 3-column → 2-column → 1-column grid

## 🧩 EaseMotion Classes Used

| Class | Purpose |
|-------|---------|
| `ease-fade-in` | Fades in the main page and footer |
| `ease-slide-up` | Slides sections up on entrance |
| `ease-delay-100` to `ease-delay-600` | Creates cascading staggered sequence |
| `ease-card` | Base card structure for dishes and tracking |
| `ease-hover-lift` | Lift effect on cards and banners |
| `ease-hover-grow` | Scale effect on buttons and pills |
| `ease-center` | Centers button icons |
| `ease-grid` + `ease-grid-cols-4` | Responsive dish grid layout |
| `ease-gap-4` | Spacing between grid items |
| `ease-btn` + `ease-btn-primary` | Styled promo button |
| `ease-pulse` | **Looping pulse** on tracking progress and active step |

## 🚀 How to Use

1. Open `demo.html` in any modern browser
2. Watch all sections slide in with staggered animations
3. Hover over dish cards to see image zoom and lift effects
4. Hover over category pills and buttons to see scale effects
5. Observe the bouncing emoji in the promo banner
6. Watch the delivery tracking progress bar pulse
7. Resize to mobile to see the responsive grid adaptation
