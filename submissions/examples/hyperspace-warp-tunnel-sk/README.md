# Hyperspace Warp Tunnel Loader

## What does this do?

A perspective star-tunnel loading state with streaking lines.

## How is it used?

```html
<div class="warp" role="status"><span class="warp__streak"></span></div>
```

Open `demo.html` in a browser to try it.

## Why is it useful?

Distinct waiting state beyond generic spinners.
