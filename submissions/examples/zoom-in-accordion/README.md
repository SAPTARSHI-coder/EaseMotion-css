# CSS Zoom-In Accordion

A responsive accordion component featuring a smooth zoom-in entrance animation for creative portfolio layouts.

## Features

- Pure HTML & CSS
- Zoom-in animation
- Responsive design
- Accessible using `<details>` and `<summary>`
- Supports `prefers-reduced-motion`
- No JavaScript required

## Files

- demo.html
- style.css

## Usage

```html
<link rel="stylesheet" href="style.css">
```

Open `demo.html` directly in any browser.

## Customization

Edit CSS variables:

```css
:root{
  --primary:#5b5ff7;
  --radius:14px;
  --speed:.45s;
}
```

## Accessibility

- Semantic HTML
- Keyboard accessible
- Reduced motion support
