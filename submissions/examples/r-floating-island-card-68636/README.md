# CSS Floating Island Card

A responsive floating card component built entirely with HTML and CSS.

## Features

- Pure CSS implementation
- Layered drop shadows for a floating island appearance
- Smooth floating animation
- Subtle ambient glow
- Hover and focus interactions
- Responsive layout
- Keyboard-accessible link
- `prefers-reduced-motion` support
- No JavaScript required

## Files

- `demo.html` — Component demo
- `style.css` — Component styling and animations

## Usage

Copy the HTML structure and include `style.css` in your project.

## Accessibility

The component uses semantic HTML, a labelled section, a descriptive link, visible keyboard focus styling, and reduced-motion support.
