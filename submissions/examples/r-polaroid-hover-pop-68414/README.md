# CSS Polaroid Hover Pop

A pure CSS Polaroid component that pops forward and rotates into a straight position on hover or keyboard focus.

## Features

- Pure HTML and CSS
- No JavaScript
- Polaroid styling
- Hover pop effect
- Keyboard focus support
- Responsive gallery
- Customizable rotation
- Reduced-motion support

## Usage

```html
<a class="polaroid polaroid-one" href="#">
  <div class="photo photo-one"></div>
  <span class="caption">Mountain Escape</span>
</a>
