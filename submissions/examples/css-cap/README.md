# CSS Drop Cap Initial

This project demonstrates how to create a **drop cap effect** using pure CSS.

## Features
- Styles the first letter of each paragraph as a large decorative initial.
- Uses `::first-letter` pseudo-element for clean implementation.
- Elegant typography with serif fonts and subtle styling.

## Files
- `demo.html` → Contains sample paragraphs to showcase the drop cap.
- `style.css` → Applies drop cap styling and overall page design.
- `README.md` → Documentation and usage instructions.

## Usage
1. Open `demo.html` in your browser.
2. Observe the first letter of each paragraph styled as a drop cap.
3. Customize the `p::first-letter` CSS rule to change font, size, color, or spacing.

## Customization Ideas
- Change `font-family` for a more decorative initial.
- Adjust `font-size` to make the drop cap larger or smaller.
- Add background color or border to highlight the initial further.
