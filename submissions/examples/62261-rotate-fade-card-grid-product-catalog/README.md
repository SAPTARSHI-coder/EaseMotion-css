# CSS Rotate-Fade Card Grid for Product Catalog Layouts

A modern **Rotate-Fade Card Grid** built using pure HTML5 and CSS3 for EaseMotion CSS.

## Features

- Rotate + Fade entrance animation
- Smooth hover interactions
- Responsive product grid
- Pure HTML & CSS
- CSS Custom Properties
- Modern card design
- Accessible markup
- Supports prefers-reduced-motion
