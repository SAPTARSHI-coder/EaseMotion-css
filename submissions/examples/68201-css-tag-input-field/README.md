# CSS Tag Input Field

## Overview

A CSS-focused tag input field demonstrating chips, input states, removable tags, and responsive wrapping. The example is designed to match EaseMotion's visual component style while keeping the implementation dependency-free.

## Features

- Tag and chip presentation
- Responsive tag wrapping
- Input and focus states
- Clear interactive affordances
- Keyboard-visible focus styling
- Pure HTML and CSS implementation
- Reduced-motion support

## Files

- `demo.html` — semantic tag input markup and sample tags
- `style.css` — component layout, chip styling, interaction states, and responsive rules

## Usage

Open `demo.html` in a modern browser. No JavaScript, package installation, or build process is required for the visual demonstration.

## Accessibility

The form controls use semantic HTML and include visible focus styling. Reduced-motion preferences are respected through the stylesheet.
