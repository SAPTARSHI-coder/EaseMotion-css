# ❄️ Snow Angel – Impression Forms Like Snow Angel

> An interactive snow angel component where an impression forms like a snow angel with 4 scenes (Day, Twilight, Night, Aurora), form control (0-100%), and sparkle effects.

---

## 📖 Description

The **Snow Angel** component creates a magical snow angel experience where an impression forms in the snow with sparkle effects. Built with vanilla HTML, CSS, and JavaScript, it features 4 scenes (Day, Twilight, Night, Aurora), form control (0-100%), and sparkle effects for a delightful winter experience.

### 🎯 Core Features

- **Snow angel** – impression forms like a snow angel
- **4 scenes** – Day, Twilight, Night, Aurora
- **Form control** – adjust form from 0-100%
- **Sparkle effects** – shimmering snow particles
- **Impression counter** – tracks number of snow angels
- **Interactive controls** – slider, scene buttons, keyboard shortcuts
- **Responsive design** – adapts to different screen sizes

### ❄️ Scenes

| Scene | Icon | Colors | Description |
|-------|------|--------|-------------|
| **Day** | ☀️ | Blue/White | Bright day scene |
| **Twilight** | 🌆 | Purple | Twilight scene |
| **Night** | 🌙 | Dark Blue | Night scene |
| **Aurora** | 🌌 | Green/Blue | Aurora scene |

### ⌨️ Interaction Options

| Method | Action |
|--------|--------|
| **Click** | Click on snow to make angel |
| **Buttons** | Make Snow Angel, Reset |
| **Keyboard** | `Space` – Make · `R` – Reset |

### ✨ Snow Angel Experience

When making:
1. **Impression forms** – snow angel appears in the snow
2. **Form applies** – controls impression progress
3. **Scene applies** – changes background colors
4. **Sparkles appear** – shimmering snow particles
5. **Status updates** – shows current state

- Perfect for winter themes, holiday interfaces, or magical experiences
- Delightful snow angel with sparkle effects

### 🛠️ Technologies Used

- **HTML5** – semantic structure with Canvas
- **CSS3** – gradients, backdrop-filter, transforms
- **JavaScript (ES6)** – Canvas API, requestAnimationFrame, particle system

### 🎨 Design Philosophy

This component embodies **EaseMotion CSS's animation-first philosophy** through:

- **Organic formation** – snow angel appears gradually
- **Sparkle effects** – shimmering snow particles
- **Visual feedback** – status updates, counter, controls
- **Winter atmosphere** – snow and scenes
- **Human-readable classes** – `.snowangel-controls`, `.scene-btn`, `.snowangel-text`

### 🔧 Customization Options

| Property | Location | Default |
|----------|----------|---------|
| Scenes | `scenes` object | 4 scenes |
| Form range | `formSlider` | 0-100% |
| Snowflakes | `generateSnowflakes()` | 50 |
| Impression speed | `speed` | 0.02-0.03 |
