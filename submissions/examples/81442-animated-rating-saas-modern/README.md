# Animated Rating — SaaS Modern

A clean, responsive and animated SaaS-style rating component
built with pure HTML and CSS for EaseMotion CSS issue #81442.

## Features

- Modern SaaS-inspired visual design
- Interactive 1–5 star rating
- CSS-only star hover preview
- Animated selected rating state
- Smooth card entrance animation
- Animated accent line
- Subtle status indicator
- Hover elevation
- Responsive layout
- Keyboard focus support
- `prefers-reduced-motion` support
- Zero JavaScript dependencies
