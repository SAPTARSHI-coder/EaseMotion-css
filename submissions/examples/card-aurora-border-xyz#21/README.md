# Aurora Spinning Border Card (`ease-card-aurora-xyz`)

## Description
This submission adds a modern, high-performance **Spinning Gradient Border** effect to EaseMotion CSS. It uses the modern CSS `@property` rule to smoothly animate a `conic-gradient` around the card's border on hover, creating a vibrant "Aurora" or "Neon" effect without any JavaScript.

## Features
- 🚀 **Zero JavaScript**: Pure CSS animation using `@property`.
- 🎨 **Modern Gradients**: Uses `conic-gradient` for a seamless color loop.
- ⚡ **Performance**: Hardware-accelerated and highly optimized.
- 🎯 **Hover Triggered**: Animates only on hover to save resources.

## How to Use
Apply the `ease-card-aurora-xyz` class to any wrapper div.

```html
<div class="ease-card-aurora-xyz">
    <div class="card-content">
        <h2>Your Title</h2>
        <p>Your content here...</p>
    </div>
</div>
