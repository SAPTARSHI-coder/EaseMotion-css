# Retro Nixie Tube Digital Clock Component

## What does this do?
This component provides a retro vintage Nixie tube glass vacuum display with glowing warm neon filament text-shadows, wire grid overlays, and rhythmic flickering colon animations.

## How is it used?
Include `style.css` in your project and copy the `.nixie-clock-container` HTML component into your web app header, retro dashboard, or timer widget.

## Why is it useful?
- Authentic vintage gas-discharge tube visual presentation.
- Hardware-accelerated high-frequency text-shadow flicker animation.
- Zero external image assets required—100% pure CSS & HTML.
