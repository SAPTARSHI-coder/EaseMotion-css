# CSS Staggered Hero Entrance

## Description

A hero section where content elements enter sequentially using staggered CSS animations. Each item fades and slides upward with a slight delay, creating a polished page-load effect.

## Features

- Pure CSS implementation
- Staggered entrance animation
- Responsive design
- Accessible semantic HTML
- No JavaScript required
- Smooth fade and slide transitions

## Usage

```html
<section class="hero">
  <h1 class="hero-title">Heading</h1>
  <h2 class="hero-subtitle">Subtitle</h2>
  <p class="hero-text">Description</p>
  <a href="#" class="hero-btn">Button</a>
</section>
```
