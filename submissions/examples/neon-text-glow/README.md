# Neon Text Glow Component

A responsive, standalone CSS text effect featuring multi-layered neon glow shadows, interactive hover amplification, and ambient pulse/flicker animations.

## Structure
- `demo.html` - Minimal demo showcasing cyan and pink neon variants.
- `style.css` - Component styles, color presets, and glow keyframes.

## Features
- Scalable fluid typography using `clamp()`
- CSS-only pulse and flicker animations
- Zero external dependencies
