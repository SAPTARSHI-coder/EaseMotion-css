# Floating Sidebar — Material

## Issue

EaseMotion CSS issue #78795.

## Overview

A responsive material-inspired sidebar with elevated surface styling and adaptive navigation.

## Features

- Sticky floating surface
- Responsive mobile navigation
- Native links and focus states
- Material-style elevation
- Reduced-motion support

## Usage

Open `demo.html` and adapt the sidebar links to the target application. The layout switches from a vertical sidebar to a compact navigation bar on smaller screens.

## Accessibility

Navigation uses native links, active state is visually distinct, and focus indicators remain visible. Decorative transitions respect reduced-motion preferences.
