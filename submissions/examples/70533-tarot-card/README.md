# CSS Tarot Card

A mystical tarot card component created using pure CSS animations.

## Features

- Ornate golden border
- Mystical glowing effect
- Hover 3D card movement
- Floating symbol animation
- Fully responsive
- No JavaScript required
- Keyboard accessible
