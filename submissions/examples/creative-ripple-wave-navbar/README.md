# CSS Ripple-Wave Navbar for Accessible Web Layouts

A modern **Ripple-Wave Navbar** component built using only **HTML5 and CSS3**. This showcase demonstrates animated ripple hover effects, smooth transitions, responsive navigation, and accessibility support without JavaScript.

---

## ✨ Features

- 🌊 Ripple-wave hover animation
- 🧭 Animated navigation links
- 💎 Glassmorphism navbar design
- ⚡ Lightweight CSS animations
- 🎯 CSS Custom Properties
- 📱 Fully responsive layout
- 🧩 Pure HTML5 & CSS3
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

---

## 🚀 Usage

1. Open `demo.html` in any modern browser.
2. Hover over navigation links to see ripple effects.
3. Customize colors and animation speed using CSS variables.
