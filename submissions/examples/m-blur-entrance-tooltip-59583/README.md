# CSS Blur-Entrance Tooltip for SaaS Showcase Layouts

A modern **Blur-Entrance Tooltip** component built using pure HTML and CSS. The tooltip smoothly fades and unblurs into view, making it ideal for SaaS dashboards, admin panels, and product showcases.

## ✨ Features

- Pure HTML5 & CSS3
- Blur entrance tooltip animation
- Glassmorphism tooltip design
- Responsive layout
- Smooth hover transitions
- CSS Custom Properties
- `prefers-reduced-motion` support
- No JavaScript required
