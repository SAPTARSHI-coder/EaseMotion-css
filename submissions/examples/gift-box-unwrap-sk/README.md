# Gift Box Unwrap Reveal

## What does this do?

A gift box that unwraps: lid lifts and reward content fades/scales in.

## How is it used?

```html
<label class="gift"><input type="checkbox"/><div class="gift__lid"></div></label>
```

Open `demo.html` in a browser to try it.

## Why is it useful?

Delightful staged reveal for rewards and promotions.
