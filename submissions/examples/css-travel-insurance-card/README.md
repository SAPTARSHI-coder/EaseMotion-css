# CSS Travel Insurance Card (#70915)

A pure CSS travel insurance summary card featuring inline coverage feature tiles, pricing header, active status indicators, and subtle hover scale states.

## Features
- **Pure CSS Layout:** Grid-based coverage feature tiles with CSS icon wrappers and state transitions.
- **Micro-Interactions:** Subtle vertical lift and accent border highlights on card focus and hover.
- **Responsive & Accessible:** Fully responsive across mobile viewports, accessible with ARIA region labels, keyboard focus styling, and `@media (prefers-reduced-motion: reduce)` fallbacks.

## File Structure
- `style.css` - Card grid layout, badge styles, hover transitions, and mobile queries.
- `demo.html` - Semantic card structure with inline SVG icons and coverage details.
- `README.md` - Technical specification and component documentation.
