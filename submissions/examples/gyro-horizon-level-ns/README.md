# Gyro Horizon Level

## What does this do?
Renders a self-contained CSS-only `ease-gyro-horizon-level` demo: Artificial horizon gyro cage precessing back to level.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-gyro-horizon-level`. No build step or JavaScript is required for the effect.

```html
<section class="ease-gyro-horizon-level">
  <div class="ease-gyro-horizon-level__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
