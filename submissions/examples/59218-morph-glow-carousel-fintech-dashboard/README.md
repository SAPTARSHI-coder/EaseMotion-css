# CSS Morph-Glow Carousel for Fintech Dashboard Layouts

A modern **Morph-Glow Carousel** component built using pure HTML5 and CSS3 for fintech dashboard layouts.

This component creates an interactive financial dashboard experience with animated glow effects, morphing elements, glassmorphism cards, and smooth CSS-only transitions.

---

## ✨ Features

- Pure HTML5 and CSS3
- No JavaScript dependency
- Fintech dashboard carousel design
- Morphing glow border animation
- Animated financial metric cards
- Glassmorphism UI effects
- Smooth hover interactions
- Gradient buttons
- Animated icons
- Responsive grid layout
- CSS custom properties support
- Lightweight keyframe animations
- `prefers-reduced-motion` accessibility support

## 🚀 Usage

1. Open `demo.html` in any modern browser.
2. Hover over dashboard cards to view glow and morph animations.
3. Customize colors, spacing, and animation speed using CSS variables.
