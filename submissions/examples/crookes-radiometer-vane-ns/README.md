# Crookes Radiometer Vane

## What does this do?
Renders a self-contained CSS-only `ease-crookes-radiometer-vane` demo: Crookes radiometer vanes spinning inside glass bulb.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-crookes-radiometer-vane`. No build step or JavaScript is required for the effect.

```html
<section class="ease-crookes-radiometer-vane">
  <div class="ease-crookes-radiometer-vane__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
