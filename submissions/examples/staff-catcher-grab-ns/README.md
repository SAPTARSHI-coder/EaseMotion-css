# Staff Catcher Grab

## What does this do?
Renders a self-contained CSS-only `ease-staff-catcher-grab` demo: Staff catcher grabbing the pouch at speed.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-staff-catcher-grab`. No build step or JavaScript is required for the effect.

```html
<section class="ease-staff-catcher-grab">
  <div class="ease-staff-catcher-grab__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
