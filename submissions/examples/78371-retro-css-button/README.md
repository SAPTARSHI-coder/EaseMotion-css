# CSS-only Retro Button

A responsive CSS-only button collection inspired by classic arcade
machines, pixel interfaces, and retro game consoles.

## Features

- Pure HTML and CSS
- Fully responsive
- Four retro button color variants
- Pixel-inspired layered borders
- Tactile hover state
- Pressed/active state
- Keyboard focus state
- CRT-style scanlines
- Arcade-inspired showcase layout
- No JavaScript
- No external dependencies
- Reduced-motion support

## Files

- `demo.html`
- `style.css`

## Usage

Open `demo.html` directly in a browser.

A button can be used with:

```html
<button class="retro-button retro-button--red" type="button">
  <span>START GAME</span>
  <i aria-hidden="true"></i>
</button>
