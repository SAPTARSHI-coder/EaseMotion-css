# CSS 3D Flip Card Grid

A responsive card grid with an interactive 3D flip animation built using only HTML and CSS.

## Features

- Pure HTML & CSS
- 3D Flip Hover Effect
- Responsive Grid Layout
- CSS Custom Properties
- Modern Portfolio Style
- No JavaScript
- Accessible (`prefers-reduced-motion` support)

## Folder Structure

```
3d-flip-card-grid/
├── demo.html
├── style.css
└── README.md
```

## CSS Variables

```css
--bg
--card
--accent
--text
--radius
--duration
```

## Usage

1. Open `demo.html`.
2. Hover over a card.
3. The card flips to reveal the back content.

## Accessibility

- Supports `prefers-reduced-motion`
- Responsive on desktop, tablet and mobile
- Semantic HTML structure
