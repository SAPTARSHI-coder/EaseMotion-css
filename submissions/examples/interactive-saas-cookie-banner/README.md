# Interactive Cookie Banner with SaaS Modern Styling

A clean and responsive cookie consent component inspired by modern SaaS interfaces.

The component uses a compact notification-card layout, subtle borders, purple accent colors, interactive controls, and responsive behavior.

## Features

- Modern SaaS-style cookie banner
- Clean white surface
- Purple product-style accent
- Privacy status indicators
- Accept and decline actions
- Cookie preference settings
- Interactive CSS toggle switches
- Responsive desktop, tablet, and mobile layouts
- Keyboard-accessible controls
- Visible focus states
- `prefers-reduced-motion` support
- Pure HTML and CSS
- Zero JavaScript dependencies
- No external assets or libraries
