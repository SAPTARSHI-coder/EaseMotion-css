# Floating Notification Toast Alert with Auto-Dismiss Timer Bar

## Overview

A modern glassmorphic floating toast notification component with
automatic dismissal timer animation and smooth transition effects.

Built using pure HTML, CSS, and JavaScript.

## Features

- 🔔 Floating glassmorphic toast UI
- ⏳ Auto-dismiss timer progress bar
- 🪟 Backdrop blur glass effect
- ✨ Smooth entrance and exit animations
- 🎨 Gradient modern styling
- ⚡ Interactive show and close actions
- 📱 Responsive mobile-first layout

## Usage

1. Open `demo.html` in a browser.
2. Click the **Show Notification** button.
3. Toast notification appears with a countdown timer.
4. Notification automatically dismisses after completion.
