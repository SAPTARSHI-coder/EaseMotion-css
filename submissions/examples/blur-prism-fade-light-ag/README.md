# Blur Prism Fade Light Animation

1. What does this do? Adds a hardware-accelerated entrance animation combining a blur, fade, and a chromatic "prism" drop-shadow effect.
2. How is it used? Apply `.ease-anim-blur-prism-fade-light` to an element.
3. Why is it useful? It creates a modern, cyberpunk or vibrant aesthetic entrance effect while remaining performant and respecting accessibility settings (`prefers-reduced-motion`).
