# CSS Glitch-Flicker Accordion

A modern **Glitch-Flicker Accordion** built using pure HTML5 and CSS3 for gaming hub layouts. The component features a cyber-inspired glitch flicker animation for expanded accordion panels, responsive design, customizable CSS variables, and accessibility support without requiring JavaScript.

---

## ✨ Features

- Pure HTML5 & CSS3
- Glitch-flicker animation
- Smooth accordion expand/collapse interaction
- Gaming-inspired dark UI
- CSS Custom Properties
- Lightweight and performant
- Accessible semantic HTML using `<details>` and `<summary>`
- `prefers-reduced-motion` support
- No JavaScript required

## 🚀 Usage

1. Copy the component into your project.
2. Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

3. Open `demo.html` in any modern browser.
