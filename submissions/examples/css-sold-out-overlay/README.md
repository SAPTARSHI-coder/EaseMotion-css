# CSS Sold Out Overlay

A responsive diagonal "SOLD OUT" stamp overlay for product cards, built entirely with HTML and CSS.

## Features

- Pure CSS implementation
- Diagonal sold-out stamp
- Responsive product card layout
- CSS custom properties for easy customization
- Light and dark mode support
- Reduced-motion support
- No JavaScript or external libraries
- Self-contained browser demo

## Usage

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
