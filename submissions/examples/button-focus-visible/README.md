# Button Focus Visible

## Description

This submission restores a clear keyboard focus indicator for interactive buttons using the `:focus-visible` pseudo-class. It improves accessibility by making keyboard navigation easier without affecting mouse interactions.

## Features

- Visible keyboard focus outline
- Uses `:focus-visible`
- Accessible high-contrast focus ring
- Responsive layout
- Pure CSS implementation

## Usage

```html
<button class="btn btn-primary">Primary</button>

<button class="btn btn-secondary">Secondary</button>

<a href="#" class="btn btn-link">Learn More</a>
```

## Benefits

- Improves keyboard accessibility
- Meets modern accessibility practices
- Does not interfere with hover effects
- Lightweight and easy to integrate
