# CSS Blur-Entrance Feature Grid for Creative Portfolio Layouts

A modern **Creative Portfolio Feature Grid** featuring elegant **Blur-Entrance** animations built entirely with **HTML5 and CSS3**. This example showcases animated feature cards with glassmorphism styling, smooth entrance effects, responsive layouts, and accessibility support—without requiring JavaScript.

---

## ✨ Features

- 🎨 Creative Portfolio inspired layout
- 🌫️ Blur-Entrance animation
- 🪟 Glassmorphism feature cards
- ✨ Smooth hover lift effects
- 📱 Fully responsive
- ⚡ Pure HTML5 & CSS3 (No JavaScript)
- 🎯 CSS Custom Properties
- ♿ Accessibility support with `prefers-reduced-motion`
- 🚀 Lightweight and easy to customize

## 🚀 Getting Started

1. Open `demo.html` in any modern browser.
2. Watch the Blur-Entrance animation when the page loads.
3. Hover over feature cards for interactive effects.
4. Customize colors, spacing, and animation timing using CSS variables.
