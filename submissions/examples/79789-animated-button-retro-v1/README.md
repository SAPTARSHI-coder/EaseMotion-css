# Animated Button with Retro Styling

A responsive animated button component inspired by bold retro interfaces and playful arcade aesthetics.

## Features

- Retro-inspired visual design
- Bold borders and offset shadows
- Smooth hover animation
- Animated shine effect
- Arrow interaction on hover
- Press/tactile interaction
- Subtle idle animation
- Fully responsive
- Keyboard accessible
- Visible focus state
- Reduced-motion support
- Pure HTML and CSS
- No external dependencies

## Preview

Open `demo.html` in a modern browser to preview the component.
