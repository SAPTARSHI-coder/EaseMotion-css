# Animated SVG Data Chart with Path Drawing and Tooltip

A responsive animated data visualization built with semantic HTML and SVG.

This component demonstrates an SVG line chart that draws itself on entrance and provides interactive data tooltips when users hover over chart points.

## Features

- Animated SVG path drawing
- Interactive SVG data-point tooltips
- Responsive chart layout
- Pure HTML and CSS
- No JavaScript dependencies
- CSS custom properties
- Smooth hover interactions
- Responsive mobile layout
- Accessible SVG description
- `prefers-reduced-motion` support
- Lightweight and framework-free
