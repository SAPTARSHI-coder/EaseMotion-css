# CSS Skew-Active Drawer for Product Catalog Layouts

A modern **Skew-Active Drawer** built using pure HTML5 and CSS3 for product catalog layouts. The component features a responsive slide-in drawer with a skew-active entrance animation, glassmorphism styling, interactive product cards, and accessibility support.

## Features

* Pure HTML5 & CSS3
* Skew-Active drawer entrance animation
* Responsive slide-in drawer
* Product quick-view panel
* Interactive skew hover effects
* Glassmorphism UI
* Smooth CSS transitions & keyframe animations
* Responsive desktop, tablet, and mobile layout
* CSS Custom Properties
* No JavaScript required
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Click **Open Drawer** or **Launch Drawer** to reveal the drawer.
3. Customize colors, drawer width, spacing, and animation timing through the CSS variables in `:root`.
4. Integrate the drawer into any product catalog or e-commerce interface.
