# Modal Animation

A responsive CSS modal component with smooth scale and backdrop animations.

## Features

- Scale entrance animation
- Animated backdrop
- Pure CSS animation
- Native HTML `<dialog>` element
- Responsive design
- CSS custom properties
- Reduced-motion support
- No external libraries

## Files

- `demo.html` - Modal demonstration
- `style.css` - Modal styles and animations

## Usage

The component uses the native HTML `<dialog>` element.

```html
<dialog id="modal" class="modal">
  <div class="modal-content">
    <h2>Hello!</h2>
    <p>This is an animated modal.</p>
  </div>
</dialog>
