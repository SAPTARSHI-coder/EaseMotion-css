# Animated Expanding Search Bar

A smooth, responsive search bar that expands on hover/focus with an animated search icon, built using pure HTML and CSS.

## What it does

- Starts as a compact circular search button.
- Expands smoothly to reveal a text input on hover or focus.
- Search icon has a subtle rotate + pulse animation on interaction.
- Fully responsive — shrinks input width on smaller screens.

## How to use

1. Copy `demo.html` and `style.css` into your project.
2. Open `demo.html` directly in a browser — no build step or server required.
3. Reuse the `.search-wrapper`, `.search-box`, `.search-input`, and `.search-btn` markup/classes anywhere you need a compact expanding search field.

## Why it fits EaseMotion CSS

- Pure HTML/CSS, no JavaScript or external dependencies.
- Beginner-friendly: clear class names, simple transition-based animation.
- Meets all requirements from issue #47326: smooth width expansion, animated icon, responsive design.
