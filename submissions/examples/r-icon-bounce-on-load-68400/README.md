# CSS Icon Bounce On Load

A pure CSS animation component that makes interface icons bounce into position with a staggered entrance effect.

## Features

- Pure HTML and CSS
- No JavaScript required
- Staggered icon entrance
- Spring-like bounce easing
- Responsive grid layout
- Customizable colors and timing
- Semantic HTML structure
- `prefers-reduced-motion` support
- Lightweight CSS animations
