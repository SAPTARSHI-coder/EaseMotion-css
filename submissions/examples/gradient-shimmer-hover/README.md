# CSS Gradient Shimmer Hover Effect

A lightweight, performant pure CSS hover effect that casts an angled, multi-stop gradient light sweep across interactive elements.

## 🎯 Features
- **Pure CSS/HTML:** Zero JavaScript dependencies.
- **Hardware Accelerated:** Powered by `linear-gradient` overlays and GPU-accelerated keyframed positioning.
- **Dark Mode Compatible:** Optimized light-bleed colors tuned for dark UI surfaces.
- **Accessible:** Includes `:focus-visible` states, `tabindex="0"`, and automatically disables the shimmer animation under `@media (prefers-reduced-motion: reduce)`.
