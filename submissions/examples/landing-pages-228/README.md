# 3D Rotating Cube Navigation Menu

A modern neumorphic 3D rotating cube navigation component built with
HTML, CSS, and vanilla JavaScript.

## Features

- Interactive 3D cube navigation
- Neumorphic UI design
- Smooth CSS 3D transformations
- Clickable cube faces
- Previous and Next controls
- Auto-rotation mode
- Keyboard navigation
- Responsive mobile layout
- Reduced-motion accessibility support
- No external dependencies
