Native Popover Modal

Zero JS · CSS @starting-style transitions

This modal is opened and closed exclusively through the popover HTML attribute and the popovertarget button attribute — no JavaScript whatsoever.

The silky enter and exit animations are powered by @starting-style, which sets the modal's initial CSS values before the browser renders the first frame of the open state, allowing a transition from display:none.

  • @starting-style seeds the entry animation without any JS timeout hacks
  • allow-discrete on display & overlay keeps the element in the top layer during the exit transition
  • Blurred & dimmed ::backdrop transitions in sync with the modal
  • Full prefers-reduced-motion support — transitions disabled for users who prefer it
  • Light-dismiss enabled: click outside or press Esc to close

How it works

1

HTML — zero JS wiring

Add popover to the modal element and popovertarget="id" to any button. The browser handles open, close, light-dismiss, and top-layer promotion natively.

2

Entry — @starting-style

@starting-style declares the values the browser should treat as "before open". Without it, the element jumps from display:none straight to the open state, skipping the transition entirely.

3

Exit — allow-discrete

display and overlay are discrete properties (they don't interpolate). Using allow-discrete in the transition shorthand defers hiding until the opacity and transform animations finish.

4

Backdrop in sync

::backdrop gets the same treatment: opacity: 0 closed, opacity: 1 open, seeded by @starting-style — so it fades in and out perfectly in step with the modal panel.
