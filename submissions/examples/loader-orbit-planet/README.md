# Loader Orbit Planet

A tiny planet loader with a ring and an orbiting moon.

## Features
- Planet + ring system
- Orbiting moon
- Slow rotation
- Pure CSS

## Usage
```html
<div class="lop-wrap"><div class="lop-moon"></div></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
