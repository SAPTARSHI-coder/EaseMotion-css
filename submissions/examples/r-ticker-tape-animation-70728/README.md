# CSS Ticker Tape Animation

A continuously scrolling horizontal ticker tape animation built entirely with HTML and CSS.

## Features

- Pure CSS implementation
- Continuous horizontal scrolling
- Seamless infinite-loop effect
- Pauses on hover
- Responsive across screen sizes
- Reduced-motion support
- No JavaScript
- No external dependencies
