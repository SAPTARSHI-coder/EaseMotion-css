# CSS 3D Flip Modal for E-Commerce Checkout Layouts

A lightweight **Pure HTML & CSS** modal featuring a smooth **3D Flip entrance animation** for modern e-commerce checkout experiences.

---

## Features

- Pure HTML & CSS
- Smooth 3D Flip animation
- No JavaScript required
- Responsive design
- CSS Custom Properties
- Accessible structure
- Supports `prefers-reduced-motion`

## Usage

```html
<link rel="stylesheet" href="style.css">
```

Use the provided modal structure in your HTML.
