# Cyberpunk Neon Border Button with Glowing Ripple Hover Effect 22

### Vibrant Gradient Version

A modern cyberpunk-inspired button built using pure HTML and CSS. It features an animated neon gradient border, glowing ripple hover effect, smooth micro-interactions, and a responsive design without any external JavaScript.

---

## ✨ Features

- Vibrant animated gradient border
- Cyberpunk neon aesthetics
- Glowing ripple hover animation
- Smooth hover and active transitions
- Responsive design
- Keyboard accessibility (`:focus-visible`)
- Reduced motion support
- Pure HTML & CSS implementation

## 🚀 Usage

1. Navigate to the component folder.
2. Keep `demo.html` and `style.css` in the same directory.
3. Open `demo.html` in any modern web browser.

No installation or additional dependencies are required.
