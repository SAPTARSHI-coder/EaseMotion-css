# CSS Hyper Speed Warp Drive

A dynamic particle starfield effect utilizing massive algorithmic `box-shadow` generations scaled infinitely through a central 3D perspective point to simulate warp speed.

## Features
- Hardware-accelerated 3D scaling utilizing `transform: translateZ()` within a perspective container to create deep depth-of-field movement.
- High-performance particle system rendering hundreds of stars on only 3 `div` elements by utilizing complex comma-separated `box-shadow` matrices.
- Infinite, seamless looping achieved with staggered animation durations and an opacity fade-out at the apex of the Z-translation.
