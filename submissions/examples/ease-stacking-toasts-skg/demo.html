Stacking Notification Toasts

Older toasts fan behind newer ones using only CSS transforms and z-index. Click the × button on any toast to dismiss it — driven entirely by <input type="checkbox"> and the :checked selector. No JavaScript required.

Fan Stack — Bottom Right

The top toast is full size. Each older toast is scaled down and offset backward, creating a "fanned deck" effect. Dismiss the top toast to see the stack collapse upward.

Dismiss toasts — the list collapses up with pure CSS

How It Works

Two CSS-only techniques, each using hidden checkboxes as state holders.

Fan Stack — the stacking trick

/* Newest toast sits on top, z-index highest */
.toast--pos-1 { z-index: 5; transform: scale(1) translateY(0); }
.toast--pos-2 { z-index: 4; transform: scale(.96) translateY(8px); }
.toast--pos-3 { z-index: 3; transform: scale(.92) translateY(16px); }

/* Checking the dismiss input hides that toast */
#d1-t1:checked ~ .toast-stack .toast--pos-1 {
  transform: translateX(120%) scale(.9);
  opacity: 0;
  pointer-events: none;
}

/* Remaining toasts move up to fill the gap */
#d1-t1:checked ~ .toast-stack .toast--pos-2 {
  transform: scale(1) translateY(0);
  z-index: 5;
}

Flat List — the collapse trick

/* Toast has max-height and opacity for smooth collapse */
.toast-item {
  max-height: 120px;
  opacity: 1;
  overflow: hidden;
  transition:
    max-height .4s ease,
    opacity .3s ease,
    margin .3s ease,
    padding .3s ease;
}

/* :checked on its sibling input collapses it */
#d2-t1:checked ~ .toast-list .toast-item:nth-child(1) {
  max-height: 0;
  opacity: 0;
  margin-bottom: 0;
  padding: 0 1rem;
  pointer-events: none;
}
