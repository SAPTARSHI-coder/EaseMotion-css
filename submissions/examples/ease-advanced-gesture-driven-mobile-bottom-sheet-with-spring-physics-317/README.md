# Gesture-Driven Mobile Bottom Sheet with Spring Physics

An advanced mobile UI component demonstrating a gesture-driven bottom sheet utilizing CSS spring physics. 

## Features
- Interactive swipe-to-dismiss drag handle.
- Real-time gesture tracking using touch and mouse events.
- Spring-like transition cubic-bezier for a natural snapping effect.
- Rubber-band resistance effect when pulled beyond the maximum height.

## Files Included
- `demo.html`: The markup, layout, and JavaScript logic handling the drag events.
- `style.css`: The styling, spring transitions, and aesthetic presentation.
- `README.md`: This documentation.

## Usage
Open `demo.html` in your browser. Click "Now Playing" to open the bottom sheet. You can then drag the handle at the top of the sheet down to close it, or drag it up to feel the rubber-band resistance. When released, it smoothly snaps back into position using spring-like CSS transitions.
