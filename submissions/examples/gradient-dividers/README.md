# CSS Gradient Dividers Collection

A collection of responsive section dividers created using pure CSS gradients
and shapes.

## Features

- Pure HTML and CSS
- No JavaScript or external libraries
- Multiple gradient and shape divider styles
- Responsive design
- Easy to customize
- Lightweight and reusable
- Works across modern browsers

## Included Dividers

The demo includes several divider styles:

1. Gradient Wave
2. Curved Divider
3. Diagonal Divider
4. Zigzag Divider
5. Double Wave
6. Soft Gradient Divider
