What is interpolate-size?

The interpolate-size: allow-keywords CSS property tells the browser to numerically interpolate between keyword values like auto, min-content, and fit-content. Before this feature, transitions from height: 0 to height: auto would jump — the browser had no numeric representation of auto to animate between.

Why not use max-height?

The old max-height: 999px trick has several problems: the transition timing is distorted (it moves at a constant rate, not proportionally), the duration is inaccurate for variable content, and it breaks entirely if content exceeds your arbitrary maximum. interpolate-size respects the actual natural height.

Browser support

As of 2026, interpolate-size is supported in Chrome 129+, Edge 129+, Opera 115+, and Safari 18.2+. Firefox support is tracked in Bug 1884770. This demo degrades gracefully — unsupported browsers simply snap open/closed with no animation.

Developer Experience

Open Source

Zero-config, drop-in CSS class. No build step. No npm install. Just add class="ease-auto-height" to any element and get smooth height transitions to and from auto.

Works with <details>, custom toggles, and any mechanism that changes the content height.

Performance

GPU Accelerated

Unlike max-height workarounds that cause layout thrashing, interpolate-size integrates with the browser's layout engine to produce correct, performant animations.

Pair with calc-size(auto, round(up, size, 1px)) to avoid sub-pixel rendering artifacts.

Accessibility

WCAG 2.2

Respects prefers-reduced-motion to disable animations for users with vestibular disorders. Works naturally with <details> elements for built-in keyboard and screen reader support.
