# CSS Timeline Navigation

A responsive vertical timeline navigation component built using pure HTML and CSS.

## Features

- Pure CSS implementation
- No JavaScript
- Responsive layout
- Vertical timeline with dots and dates
- Smooth hover animation
- Keyboard accessible
- Semantic HTML
- Accessible navigation label

## Files

- `demo.html` - Timeline structure
- `style.css` - Timeline styling
- `README.md` - Documentation

## Usage

Open `demo.html` in a browser to view the timeline navigation.

## Accessibility

The timeline uses semantic navigation with an accessible label. Each timeline item is a keyboard-focusable link and includes semantic `<time>` elements for dates.

## Technologies

- HTML5
- CSS3
