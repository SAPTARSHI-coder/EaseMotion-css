# CSS Cyberpunk Neon Progress

## Overview

A pure CSS progress bar with a cyberpunk-inspired neon surface, glowing fill, and compact status steps.

## Features

- Animated neon progress fill
- Semantic progressbar attributes
- Responsive layout
- Dark interface styling
- Reduced-motion support
- No JavaScript dependencies

## Implementation

The progress fill uses a gradient and glow shadow. A small brightness animation provides the pulsing neon effect while the progress value remains visually clear.

## Accessibility

The progress track exposes its value with ARIA progressbar attributes. The content remains readable without animation, and reduced-motion users receive a static presentation.

## Files

- `demo.html` — progress component and status steps
- `style.css` — neon visuals, animation, and responsive rules
- `README.md` — documentation
