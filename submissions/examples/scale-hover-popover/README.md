# Scale Hover Popover for Creative Portfolio

A simple and responsive **Scale Hover Popover** built using **HTML** and **CSS**. When the user hovers over the **View Details** button, a popover appears displaying the portfolio owner's information, skills, and contact option.

## ✨ Features

- Responsive portfolio card
- Circular profile image
- Hover-triggered popover
- Skill badges
- Clean and minimal UI
- Pure HTML & CSS (No JavaScript)

## 📂 Project Structure

```
submissions/
└── examples/
    └── scale-hover-popover/
        ├── demo.html
        ├── style.css
        └── README.md
```

## 🚀 How to Run

1. Download or clone the project.
2. Open `demo.html` in any modern web browser.
3. Hover over the **View Details** button to see the popover.

## 🛠️ Technologies Used

- HTML5
- CSS3
