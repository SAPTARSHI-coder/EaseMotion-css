# CSS Button - Pulsating Wave

A modern Pulsating Wave button built entirely with HTML and CSS. The component creates expanding wave rings around the button to attract attention while maintaining a clean and accessible design.

## Features

- Pure HTML & CSS
- Pulsating Wave styling
- Expanding ripple animations
- Smooth hover interactions
- Responsive design
- Keyboard accessible
- Dark mode compatible
- Hardware accelerated animations
- No JavaScript required

## Usage

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

Use the button:

```html
<button class="wave-btn">
  Get Started
</button>
```

This component demonstrates motion-first design through visually engaging wave animations while remaining lightweight, reusable, accessible, and fully CSS-powered.
