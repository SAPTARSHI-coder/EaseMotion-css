# Folio Page Turner

## What does this do?
Renders a self-contained CSS-only `ease-folio-page-turner` demo: Rare-book folio page lifting and settling.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-folio-page-turner`. No build step or JavaScript is required for the effect.

```html
<section class="ease-folio-page-turner">
  <div class="ease-folio-page-turner__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
