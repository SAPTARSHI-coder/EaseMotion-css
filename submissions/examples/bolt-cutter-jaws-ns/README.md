# Bolt Cutter Jaws

## What does this do?
Renders a self-contained CSS-only `ease-bolt-cutter-jaws` demo: Heavy bolt-cutter jaws closing through a padlock shackle.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-bolt-cutter-jaws`. No build step or JavaScript is required for the effect.

```html
<section class="ease-bolt-cutter-jaws">
  <div class="ease-bolt-cutter-jaws__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
