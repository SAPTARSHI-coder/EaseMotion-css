# CSS Fade-In Tooltip for Product Catalog Layouts

A lightweight **Fade-In Tooltip** component created using pure HTML and CSS for product catalog interfaces. The tooltip smoothly fades into view on hover, providing additional product information while maintaining a clean and modern appearance.

---

## Features

- Pure HTML5 & CSS3
- Smooth fade-in animation
- Responsive product card layout
- Modern tooltip UI
- CSS Custom Properties for easy customization
- Mobile-friendly design
- Supports `prefers-reduced-motion`
- No JavaScript required

---

---

## Usage

1. Open `demo.html` in your browser.
2. Hover over any information button.
3. The tooltip smoothly fades into view.

---

## CSS Custom Properties

```css
--bg
--card
--surface
--primary
--accent
--text
--muted
--radius
--shadow
```

Update these variables inside `:root` to customize the design.
