# CSS Bounce-Pulse Popover for Product Catalog Layouts

A modern **Bounce-Pulse Popover** component built using pure HTML5 and CSS3 for the EaseMotion CSS project. The popover appears with a smooth bounce-pulse animation to highlight product details while maintaining a clean and responsive design.

---

## ✨ Features

- Pure HTML5 & CSS3
- Smooth bounce-pulse popover animation
- Modern glassmorphism interface
- Responsive product catalog layout
- CSS custom properties for easy customization
- Smooth hover transitions
- Supports `prefers-reduced-motion`
- No JavaScript required
