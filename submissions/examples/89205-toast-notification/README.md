# Glassmorphism Toast Notification Component

A floating, translucent alert notification component with a cubic-bezier entrance animation.

## Features
- **Glassmorphism Backdrop:** Uses CSS backdrop blur for modern translucency.
- **Smooth Animation:** Fluid cubic-bezier keyframe slide-in.
- **Pure CSS:** Zero JavaScript dependencies.

## File Structure
- `demo.html` - Toast notification markup and success icon layout.
- `style.css` - Component styling and slide keyframe definitions.
