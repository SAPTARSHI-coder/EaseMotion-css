# Bento Grid Interactive Dashboard Layout

## Overview

A high-contrast accessibility-focused bento dashboard layout built with CSS Grid
and Flexbox. The component provides a clean dashboard interface with readable
colors, responsive cards, and smooth interactions.

## Features

- ♿ High contrast accessibility design
- 📊 Bento grid dashboard layout
- 🎨 CSS Grid and Flexbox structure
- ✨ Smooth hover animations
- 📱 Responsive mobile layout
- ⚡ Animated chart bars
- 🔍 Clear typography and spacing

1. Open `demo.html` in your browser.
