# Skeleton Pulse Loading Shimmer Placeholder for Card Grids

### High-Contrast Accessibility Edition

A modern **Skeleton Pulse Loading Shimmer Placeholder** component built with **HTML5** and **CSS3**. It provides responsive loading cards with shimmer animation, high-contrast styling, and accessibility-focused design for dashboards, e-commerce pages, and content loading screens.

---

## ✨ Features

- High-contrast accessible design
- Animated shimmer loading effect
- Responsive card grid layout
- Modern dashboard-style skeleton cards
- Smooth hover interactions
- CSS Variables for easy customization
- `prefers-reduced-motion` support
- `prefers-contrast` optimization
- Pure HTML & CSS implementation

## 🚀 Usage

1. Open the component folder.
2. Keep `demo.html` and `style.css` together.
3. Open `demo.html` in any modern browser.
4. Use the skeleton cards as placeholders while content is loading.

No external libraries or build tools are required.
