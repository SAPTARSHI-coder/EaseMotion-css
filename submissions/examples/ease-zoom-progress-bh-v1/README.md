# ease-zoom-progress-bh

Pure CSS zoom-in progress bar component.

## What does this do?
Creates animated progress bars with zoom-in animation effect.

## How is it used?
```html
<div class="ease-zoom-progress-bh">
  <div class="ease-zoom-progress-fill-bh" style="--progress: 75%"></div>
</div>
```

## Why is it useful?
Creates dynamic progress indicators with zoom animation for gaming layouts.
