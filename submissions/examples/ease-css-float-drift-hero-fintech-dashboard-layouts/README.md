# CSS Float-Drift Hero Section for Fintech Dashboard Layouts

A modern fintech hero section featuring smooth floating drift animations, dashboard cards, and glassmorphism styling built entirely with HTML and CSS.

This component creates a futuristic financial dashboard landing experience without JavaScript or external dependencies.

## ✨ Features

- 🌊 Smooth float-drift hero animation
- 📊 Fintech dashboard inspired visuals
- 💎 Glassmorphism floating cards
- ✨ Gradient glow effects
- 📈 Animated analytics widgets
- ⚡ Pure HTML and CSS implementation
- 📱 Fully responsive hero layout
- 🔄 CSS keyframe animations and transitions
- ♿ Accessibility support with `prefers-reduced-motion`

## 🚀 Usage

1. Clone the EaseMotion CSS repository.

2. Navigate to:


submissions/examples/ease-css-float-drift-hero-fintech-dashboard-layouts/


3. Open `demo.html` in any modern browser.

No JavaScript, frameworks, or external libraries are required.

## 🎨 CSS Custom Properties

The component uses CSS variables for simple customization:

```css
:root {
    --bg:#050816;
    --primary:#00f5ff;
    --secondary:#8b5cf6;
    --green:#22c55e;
    --text:#f8fafc;
    --muted:#94a3b8;
}

Customize these values to match your fintech brand identity.
