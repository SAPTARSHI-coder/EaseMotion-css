# Airbrush Fade · Smooth Gradient Airbrush 🎨

An interactive airbrush tool with smooth gradient fade effects, adjustable opacity, and soft spray particles. Drag to create beautiful, airbrushed gradients with smooth fade transitions!

## Features

- 🎨 **Smooth Airbrush** – Soft, gradient spray particles
- 💨 **Fade Effect** – Particles fade in and out smoothly
- 🎮 **Opacity Control** – Adjust spray opacity (1-10)
- 📏 **Size Control** – Adjust spray size (5-80px)
- 🖌️ **Color Control** – Pick any color
- ✨ **Soft Particles** – Gentle, diffused spray effect
- 🎮 **Speed Control** – Adjust animation speed (1-10)
- ⏸️ **Pause/Resume** – Toggle animation
- 🗑️ **Clear** – Clear canvas
- 🔄 **Reset** – Reset to clean state
- 📱 **Touch Support** – Works on mobile devices

## How to Use

1. **Drag** on the canvas to spray with airbrush fade
2. Use **Color Picker** to change spray color
3. Adjust **Size** slider for spray radius
4. Adjust **Opacity** slider for spray density
5. Particles fade in and out smoothly for gradient effect
6. Press **C** or click **CLEAR** to clear the canvas
7. Press **Space** or click **PAUSE** to pause/resume animation
8. Press **R** or click **RESET** to reset

## Technical Details

- **Particle System:** Soft particles with fade in/out
- **Fade Effect:** Particles fade in then fade out
- **Opacity Control:** Adjustable particle density
- **Soft Glow:** Radial gradient for soft edges
- **Performance:** 60fps with requestAnimationFrame

## Customization

You can easily customize:
- **Spray Size:** Adjust slider range (5-80)
- **Opacity:** Modify slider range (1-10)
- **Particle Count:** Adjust `numParticles` range
- **Fade Speed:** Modify `fadeInSpeed` values
- **Decay Rate:** Adjust `decay` values
