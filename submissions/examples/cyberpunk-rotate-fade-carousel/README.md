# Cyberpunk Rotate-Fade Carousel

A futuristic **CSS Rotate-Fade Carousel** built entirely with **HTML5** and **CSS3**. This showcase demonstrates a smooth CSS-only carousel with rotate-and-fade transitions, cyberpunk neon styling, glassmorphism effects, and responsive behavior—without any JavaScript.

---

## ✨ Features

- 🚀 Pure HTML5 & CSS3
- 🔄 Rotate + Fade slide transition
- 🌈 Cyberpunk neon design
- 🪟 Glassmorphism card layout
- 🎠 CSS-only carousel using radio buttons
- 📱 Fully responsive across desktop, tablet, and mobile
- ♿ Keyboard accessible
- 🎨 Easy customization with CSS Custom Properties
- 🌙 Supports `prefers-reduced-motion`
- ⚡ Lightweight with no external dependencies

## 🚀 Usage

1. Open `demo.html` in any modern web browser.
2. Select a navigation dot to switch between slides.
3. Watch the active slide smoothly rotate and fade into view.

No JavaScript or third-party libraries are required.

## 🎨 CSS Custom Properties

Customize the appearance using CSS variables defined in `:root`.

| Variable | Description |
|----------|-------------|
| `--bg` | Page background color |
| `--surface` | Glassmorphism container background |
| `--primary` | Primary neon color |
| `--secondary` | Secondary neon color |
| `--accent` | Accent neon color |
| `--text` | Primary text color |
| `--muted` | Secondary text color |
| `--radius` | Border radius |
| `--transition` | Transition duration |

Example:

```css
:root {
    --primary: #00f5ff;
    --secondary: #b026ff;
}
```
