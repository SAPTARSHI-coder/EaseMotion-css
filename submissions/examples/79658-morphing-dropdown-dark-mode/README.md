# Morphing Dropdown — Dark Mode

A responsive dark-mode dropdown component featuring a subtle
morphing interaction, layered depth, hover states, and
accessible keyboard support.

Implemented for issue #79658.

## Features

- Dark-mode visual design
- Morphing dropdown animation
- CSS-only interaction
- Smooth dropdown reveal
- Scale and translate transitions
- Hover elevation
- Interactive option states
- Responsive mobile layout
- Keyboard focus-visible support
- Reduced-motion support
- No external dependencies
