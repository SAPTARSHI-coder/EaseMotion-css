# Ripple Wave Click Water

A lightweight CSS-only ripple wave animation inspired by water ripples after a click.

## Features

- Pure CSS animation
- Reusable `ease-anim-ripple-wave-click-water` utility class
- Hardware-accelerated `transform` and `opacity`
- Configurable animation duration
- Configurable timing function
- `prefers-reduced-motion` support
- No JavaScript required
- Responsive demo

## Usage

Apply the utility class to the element that should display the ripple:

```html
<span class="ease-anim-ripple-wave-click-water"></span>
