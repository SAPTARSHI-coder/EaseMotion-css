# ease-shimmer-grid Shimmer-Sweep Feature Grid

## What does this do?

A feature grid component with smooth shimmer-sweep animation effects, perfect for Fintech dashboard layouts. Each card has a subtle gradient sweep animation that creates an elegant, modern feel.

## How is it used?

```html
<div class="ease-shimmer-grid">
  <div class="ease-shimmer-card">
    <div class="ease-shimmer-icon">📊</div>
    <h3>Analytics</h3>
    <p>Real-time data visualization</p>
  </div>
  <div class="ease-shimmer-card">
    <div class="ease-shimmer-icon">🔒</div>
    <h3>Security</h3>
    <p>Bank-grade encryption</p>
  </div>
</div>
```

### CSS Classes

| Class | Purpose |
|-------|---------|
| `.ease-shimmer-grid` | Container for the feature grid |
| `.ease-shimmer-card` | Individual feature card |
| `.ease-shimmer-icon` | Icon container with shimmer |
| `.ease-shimmer-sweep` | Sweep animation modifier |

## Why is it useful?

Perfect for showcasing features in a modern fintech dashboard with elegant shimmer animations:

- ✅ Smooth CSS-only shimmer animations
- ✅ Fully responsive grid layout
- ✅ Accessible with prefers-reduced-motion
- ✅ Modern fintech aesthetic
