# 🌌 CSS Neumorphic Effect: Aurora Glow

A smooth and accessible neumorphic UI component enhanced with an
animated Aurora Glow effect.

The component combines soft neumorphic shadows, subtle gradients,
luminous aurora orbs, and CSS transitions to create a modern tactile
interface.

Built entirely with HTML and vanilla CSS.

## Features

- Pure HTML and CSS
- No external JavaScript
- Neumorphic styling
- Aurora-inspired glow
- Animated gradient border
- Floating background glow orbs
- Hardware-friendly transforms
- Interactive CSS toggle
- Keyboard-accessible toggle
- Visible focus state
- Responsive layout
- Dark-mode-friendly color palette
- Reduced-motion support
- No external assets
