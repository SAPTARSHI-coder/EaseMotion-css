Copy Confirmation Tick

A copy button that shows an animated tick the moment it is activated. Pure CSS — the confirmation state is driven by a hidden checkbox toggle, so it works with the mouse and the keyboard (Tab to focus, Space to copy).

  • API endpoint https://api.easemotion.dev/v1/animate
  • Install command npm install easemotion-css
  • Brand color #6366F1
