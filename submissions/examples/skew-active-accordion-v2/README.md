# Skew-Active Accordion

A lightweight, responsive CSS-only accordion component designed for
modern fintech dashboard interfaces.

## Features

- Pure HTML and CSS
- No JavaScript required
- Subtle skew interaction on hover
- Native `<details>` and `<summary>` behavior
- Responsive desktop, tablet and mobile layout
- CSS custom properties
- Smooth keyframe animation
- Keyboard accessible
- `prefers-reduced-motion` support
