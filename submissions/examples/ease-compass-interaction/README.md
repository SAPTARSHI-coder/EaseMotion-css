# 🧭 Compass Interaction – Needle Points Toward Cursor

> An interactive, magnetic compass where the needle smoothly rotates to point toward the cursor, creating a responsive, engaging navigation experience.

---

## 📖 Description

The **Compass Interaction** is an interactive, magnetic compass where the needle smoothly rotates to point toward the cursor. As you move your mouse around the compass, the needle follows with a smooth, fluid motion, creating a responsive, engaging experience reminiscent of a real compass. The compass displays cardinal directions (N, S, E, W, NE, NW, SE, SW), tick marks, and real-time angle and direction labels.

The component uses JavaScript with smooth interpolation to track the cursor position and rotate the needle accordingly. The needle uses a two-tone design (red north, grey south) with a glowing center. The compass face features a clean, modern design with subtle shadows and a professional aesthetic.

Perfect for navigation apps, interactive maps, educational tools, and any application where you want to create an engaging, directional interaction. The Compass Interaction transforms a simple compass into an interactive, magnetic experience.
