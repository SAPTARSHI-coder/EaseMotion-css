# CSS Stacked Parallax Cards

Interactive cards that tilt on hover, revealing multiple stacked glassmorphism layers inside using `translateZ` within a 3D perspective to simulate parallax depth.

## Features
- Pure CSS 3D parallax effect using `perspective` and `translateZ`
- Glassmorphism layered elements (`backdrop-filter`)
- Dynamic easing transitions on hover
