# CSS Vertical Sidebar with Tooltips

A CSS-only vertical sidebar component with a compact navigation rail, smooth expansion, contextual tooltips, responsive behavior, and keyboard-friendly focus states.

## Features

- Pure HTML and CSS
- No JavaScript required
- Collapsed vertical navigation rail
- Expands when hovered or focused
- Animated navigation labels
- Contextual CSS tooltips
- Keyboard-focusable navigation
- Visible focus indicators
- Responsive mobile navigation
- Semantic navigation structure
- `prefers-reduced-motion` support
- Customizable CSS variables
- Works as a standalone showcase example
