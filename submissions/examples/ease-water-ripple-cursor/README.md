# 🌊 Water Ripple Cursor – Ripples Spread from Cursor

> A calming, fluid cursor effect where ripples spread from the cursor like water drops, creating a peaceful, organic visual experience.

---

## 📖 Description

The **Water Ripple Cursor** is a calming, fluid cursor effect where ripples spread from the cursor like water drops. As you move your mouse, concentric rings expand outward, creating a peaceful, organic visual experience reminiscent of ripples on a pond. The ripples have random sizes, colors, and speeds, with a soft, fluid motion that is both calming and mesmerizing.

The component uses JavaScript to create ripples at the cursor position with random properties (every 60ms). Each ripple has random size (5-20px), color from a palette of blue/cyan/green tones, border width (1-3px), duration (1.0-2.2s), and opacity (0.3-0.7). Clicking creates a ripple burst with 20 ripples, and hovering over interactive elements triggers a smaller burst of 10 ripples.

Perfect for calming interfaces, water-themed apps, meditation tools, and any application where you want to create a peaceful, fluid cursor experience. The Water Ripple Cursor transforms a simple cursor into a serene, aquatic presence.
