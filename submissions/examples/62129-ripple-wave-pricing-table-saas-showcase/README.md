# CSS Ripple-Wave Pricing Table for SaaS Showcase Layouts

A modern **Ripple-Wave Pricing Table** built using pure HTML5 and CSS3 for SaaS showcase layouts. This component provides animated pricing cards with ripple wave effects, responsive layouts, highlighted plans, and smooth interactive transitions.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Animated ripple-wave background effect
* SaaS pricing card layout
* Multiple pricing tiers:

  * Starter
  * Professional
  * Enterprise
* Highlighted popular pricing plan
* Smooth hover elevation effects
* Animated CTA buttons
* Glassmorphism card design
* Responsive CSS Grid layout
* CSS Custom Properties for easy customization
* Smooth CSS transitions and keyframe animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over pricing cards to experience ripple-wave animations.
3. Select or customize your preferred pricing plan.
4. Modify CSS variables inside `:root` to change colors, shadows, and spacing.

## CSS Custom Properties

```css
:root{
  --bg:#eef4ff;
  --surface:rgba(255,255,255,.92);
  --primary:#2563eb;
  --secondary:#06b6d4;
  --accent:#8b5cf6;
  --text:#111827;
  --muted:#64748b;
  --shadow:0 18px 45px rgba(37,99,235,.18);
  --radius:26px;
}
```
