# Sierpinski Triangle · Fractal Grows Outward 🔺

An interactive Sierpinski triangle fractal that grows outward with recursive depth, vibrant colors, and smooth animation. Watch the fractal expand!

## Features

- 🔺 **Sierpinski Triangle** – Classic fractal pattern
- 🌱 **Grow Animation** – Fractal expands outward
- 🎨 **Vibrant Colors** – Dynamic color generation
- 🎚️ **Speed Control** – Adjust growth speed (1-10)
- 🎚️ **Depth Control** – Adjust fractal depth (1-6)
- ⏸️ **Pause/Resume** – Toggle animation
- 🔄 **Reset** – Reset to initial state
- 📊 **Triangle Counter** – Shows number of triangles

## How to Use

1. Click **GROW** or press **Space** to grow the fractal
2. Watch triangles appear and expand outward
3. Adjust **Speed** for growth pace
4. Adjust **Depth** for fractal complexity
5. Press **RESET** or **R** to reset
6. Press **PAUSE** or **P** to pause/resume animation

## Controls
