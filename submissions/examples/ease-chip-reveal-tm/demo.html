This is a demo of the floating action button with chip reveal. Click the purple button to expand the action menu. Each chip has a staggered entrance animation. The main button icon rotates 45 degrees to become an X when open.

Features include: spring-easing animations, staggered chip reveals, multiple chip actions, extended FAB variant, mini FAB variant, color variants (primary, secondary, success, error), and top/bottom positioning.

The component uses the checkbox hack for pure CSS state management. No JavaScript is required for the open/close animation. The chips can link to different pages or trigger actions.
