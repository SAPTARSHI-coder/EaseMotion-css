# Rotate-Fade Toast for Product Catalog Layouts

A lightweight animated toast notification component built using pure HTML and CSS.

This component is part of the EaseMotion CSS collection and demonstrates a smooth rotate + fade entrance animation suitable for product catalog interfaces.

## ✨ Features

- Pure HTML and CSS implementation
- Smooth rotate-fade entrance animation
- Modern glassmorphism design
- Responsive layout support
- Lightweight and performance friendly
- No JavaScript dependency
- Accessible motion handling with `prefers-reduced-motion`
