# glow-toast-banner-v6-ak

Pure CSS animated notification toast banner with bottom progress timer line — no JavaScript required.

## How to use

```html
<div class="ease-toast-v6">
  <span class="ease-toast-icon-v6">🔔</span>
  <div class="ease-toast-content-v6">
    <span class="ease-toast-title-v6">Title</span>
    <span class="ease-toast-desc-v6">Description</span>
  </div>
  <div class="ease-toast-timer-v6"></div>
</div>
