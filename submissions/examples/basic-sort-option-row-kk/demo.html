Basic Sort Option Row

Simple sort rows for filter and settings panels.

A CSS-only row component for showing sort label, order type, preview hint, and selected, recommended, or disabled state.

AZ
Name A to Z

Sorts items alphabetically using the visible title.

Ascending A-Z Selected
RC
Most relevant

Recommended for search results and filtered lists.

Ranked Best Recommended
OFF
Recently archived

Disabled because archived items are hidden in this view.

Newest Hidden Disabled

<article class="basic-sort-option-row">
  <span class="sort-mark is-selected" aria-hidden="true">AZ</span>
  <div class="sort-copy">
    <strong>Name A to Z</strong>
    <p>Sorts items alphabetically using the visible title.</p>
  </div>
  <span class="sort-order">Ascending</span>
  <span class="sort-preview">A-Z</span>
  <span class="sort-state is-selected">Selected</span>
