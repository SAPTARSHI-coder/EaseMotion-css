# Polaroid Gallery

A playful fan of polaroid frames that straighten and lift as you hover toward them.

## Features
- Tilted polaroid frames that rotate into place on hover
- Layered stack effect with drop shadows
- Pure CSS transforms for a lively, tactile feel

## Usage
```html
<div class="pg-stack">
  <div class="polaroid p1"><div class="shot shot-a"></div><p>Caption</p></div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
