# Blacksmith Quench Steam

## What does this do?
Renders a self-contained CSS-only `ease-blacksmith-quench-steam` demo: Hot blade quenched in water with rising steam plume.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-blacksmith-quench-steam`. No build step or JavaScript is required for the effect.

```html
<section class="ease-blacksmith-quench-steam">
  <div class="ease-blacksmith-quench-steam__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
