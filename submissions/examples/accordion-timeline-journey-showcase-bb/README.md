# Accordion Timeline Journey Component

A vertical milestone timeline combining native semantic `<details>` / `<summary>` expandable accordion panels with glowing node indicators.

## 1. What does this do?
Presents chronological company roadmap items or project milestones in a vertical timeline format with smooth expandable accordion panels.

## 2. How is it used?
1. Include `style.css` in your HTML `<head>`.
2. Markup timeline milestones using `<details class="timeline-item">` and `<summary class="timeline-header">`.
3. Nest milestone details inside `.timeline-content`.

## 3. Why is it useful?
- **Native Semantic HTML**: Uses standard `<details>` elements for built-in accessible toggle functionality without JavaScript.
- **Visual Depth**: Vertical connecting lines and glowing node icons provide clear visual hierarchy.
- **Responsive Layout**: Adapts gracefully across mobile viewports and desktop displays.
