# CSS Countdown Flip Tiles

A responsive countdown-style UI component featuring a 3D card-flip animation created entirely with CSS.

## Features

- Pure CSS implementation
- No JavaScript required
- 3D flip animation using CSS transforms
- Perspective and backface visibility effects
- Responsive layout
- Light and dark mode support
- CSS custom properties for easy customization
- Reduced-motion support
- Standalone HTML demo

Include the stylesheet:
