# CSS Shimmer Sweep Card Grid

A responsive card grid featuring a shimmer sweep hover animation built using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Responsive Grid Layout
- Shimmer Sweep Hover Effect
- Smooth CSS Transitions
- Accessible with `prefers-reduced-motion`
- Lightweight and reusable

## Files

demo.html
style.css
README.md

## Usage

Open `demo.html` in a browser.

## Customization

- Card background
- Animation duration
- Border radius
- Grid spacing
- Highlight gradient

## Accessibility

Animations are disabled automatically for users who enable reduced motion.
