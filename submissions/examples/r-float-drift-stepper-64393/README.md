# CSS Float-Drift Stepper

A responsive glassmorphism stepper with a subtle floating drift effect on
the active step.

## Features

- Pure HTML and CSS
- No JavaScript dependencies
- Glassmorphism visual style
- Float-drift animation for the active step
- Smooth entrance transitions
- Responsive desktop, tablet, and mobile layout
- Semantic ordered stepper structure
- `prefers-reduced-motion` support
