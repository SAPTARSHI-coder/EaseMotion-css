# Funicular Car

## What does this do?
Renders a self-contained CSS-only `ease-funicular-car` demo: Funicular cars ascending and descending a hillside track.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-funicular-car`. No build step or JavaScript is required for the effect.

```html
<section class="ease-funicular-car">
  <div class="ease-funicular-car__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
