# Bar Chart

A grouped bar chart whose columns grow from baseline with rounded tops.

## Features
- Bars scale up one after another on load
- Hover lifts a bar and shows its value tooltip
- Grid lines keep the chart scannable

## Usage
```html
<div class="br-chart">
  <div class="br-col"><div class="br-bar" data-v="42" style="height:42%;"></div><span class="br-label">Mon</span></div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
