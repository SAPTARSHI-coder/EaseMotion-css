# Coupon Input

A promo-code field with a dashed border that dashes into motion and validates on focus.

## Features
- Dashed border with marching-ants motion
- Prefix tag anchored to the field edge
- Apply button brightens the whole control

## Usage
```html
<div class="ci-wrap">
  <span class="ci-prefix">PROMO</span>
  <input class="ci-input" placeholder="CODE" />
  <button class="ci-apply">Apply</button>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
