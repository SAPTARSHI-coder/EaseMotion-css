# Interactive Sidebar with Glassmorphism Styling

A responsive sidebar component built with pure HTML and CSS, using glassmorphism principles for a modern translucent navigation experience.

## Features

- Responsive sidebar layout
- Glassmorphism surfaces
- `backdrop-filter` blur effects
- Interactive hover states
- Active navigation indicator
- Profile section with online status
- Notification counters
- Upgrade card
- Responsive mobile layout
- Keyboard focus-visible states
- Reduced-motion accessibility support
- No JavaScript dependency

## Files

- `demo.html` — component structure and demo
- `style.css` — complete styling and responsive behavior

## Usage

Open `demo.html` directly in a browser.

The navigation links are regular HTML links and can be connected to application routes as needed.

## Accessibility

The component provides visible keyboard focus states and respects the user's `prefers-reduced-motion` preference.
