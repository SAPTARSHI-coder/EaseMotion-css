CSS Motion Path

Animate elements along any geometric path — circles, arcs, rays, curves, and custom SVG paths. All native CSS, zero JavaScript.

offset-path offset-distance offset-rotate offset-anchor circle() ray() path()

Path Type Demonstrations

CSS Motion Path supports three path types: circle(), ray(), and path(). Each animates elements along a different kind of trajectory.

circle() — Circular Orbit

An element orbits around a fixed radius. Set offset-rotate: 0deg to keep the element upright, or auto to rotate with the path.

ray() — Linear Ray

Animates along a straight line at a specific angle. Includes optional contain to keep the element within bounds.

path() — Custom SVG Path

Follow any SVG path string. Curves, zig-zags, spirals — anything you can draw, you can animate along.

rect() — Rectangle Path

Animate along a rectangular path with rounded corners. Perfect for progress indicators and loading animations.

offset-rotate — Element Orientation

Control how the element rotates as it moves along the path.

auto — Rotate with path tangent

The element naturally follows the curve, aligned with the path direction.

0deg — Stay upright

The element maintains its original orientation regardless of path direction.

reverse auto — Face backward

Rotates 180° relative to the path tangent. Elements face "backward" along the curve.

✓ Use for Decorative Motion

Motion paths are ideal for decorative animations — loaders, progress indicators, hero visuals. Use prefers-reduced-motion to disable for accessibility.

.loader {
  offset-path: circle(40px);
  animation: spin 2s linear infinite;
}

@media (prefers-reduced-motion: reduce) {
  .loader { animation: none; }
}
