# CSS Float-Drift Carousel for Product Catalog Layouts

A responsive product carousel built using pure HTML and CSS featuring elegant floating drift animations, smooth hover effects, shimmer highlights, and responsive product cards.

## Features

- Pure HTML5 & CSS3
- Float-Drift animation
- Smooth hover transitions
- Animated shimmer overlay
- Responsive layout
- Modern product cards
- CSS Custom Properties
- Accessible with prefers-reduced-motion support
