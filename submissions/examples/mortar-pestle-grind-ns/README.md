# Mortar Pestle Grind

## What does this do?
Renders a self-contained CSS-only `ease-mortar-pestle-grind` demo: Mortar and pestle grinding in a circular press.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-mortar-pestle-grind`. No build step or JavaScript is required for the effect.

```html
<section class="ease-mortar-pestle-grind">
  <div class="ease-mortar-pestle-grind__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
