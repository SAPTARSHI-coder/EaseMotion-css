# Elastic Spring Pop Bounce

A reusable CSS animation that creates an elastic spring-like pop and bounce effect.

## Features

- Elastic pop and bounce motion
- Uses `transform` and `opacity`
- Configurable animation duration and timing
- Supports `prefers-reduced-motion`
- No JavaScript required
- Lightweight and reusable

## Usage

Add the animation class to an element:

```html
<div class="ease-anim-elastic-spring-pop-bounce">
  Content
</div>
