# Diamond Facet Edge

A smooth and visually rich CSS text animation inspired by the
reflective facets and sharp edges of a diamond.

## ✨ Features

- Pure HTML and Vanilla CSS
- No JavaScript
- No external dependencies
- Animated gradient facets
- Moving reflective highlight
- Subtle edge depth effect
- Smooth GPU-friendly transforms
- Responsive typography
- Dark mode support
- Reduced-motion accessibility support
- Mobile-friendly layout
