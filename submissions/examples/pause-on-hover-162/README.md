# Infinite Seamless Logo Carousel Slider

A cyberpunk-themed infinite logo carousel with a smooth continuous scrolling animation and pause-on-hover interaction.

## Features

- Infinite seamless scrolling
- Pause animation on hover
- Cyberpunk neon aesthetic
- Cyan and magenta glow effects
- Responsive layout
- CSS-only animation
- No external dependencies
- Hover elevation effects
- Reduced-motion accessibility support
- Responsive mobile design
