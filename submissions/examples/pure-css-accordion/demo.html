Pure CSS Accordion

No JavaScript. Radio inputs track which panel is open, and grid-template-rows animates the height smoothly.

A zero-dependency, animation-first CSS framework with human-readable class names. No build step, just link the stylesheet.
Each panel sits inside a grid whose row track animates between 0fr and 1fr. Since grid tracks are animatable (unlike height: auto), the browser can smoothly transition the panel's height on its own.
Not with radio inputs sharing one name — that's what makes it exclusive, like native accordion behavior. Swap the radios for checkboxes if you want independently expandable panels.
