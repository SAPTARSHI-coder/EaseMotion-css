# Dynamic Glassmorphism Tab Bar

A responsive navigation tab bar featuring a modern glassmorphism design, smooth hover interactions, and a highlighted active tab.

## ✨ Features

- Modern glassmorphism UI
- Dynamic active tab styling
- Smooth hover animations
- Responsive desktop and mobile layout
- Frosted glass effect using `backdrop-filter`
- Interactive navigation items
- No JavaScript required
- No external libraries
- Reduced-motion support

## 🛠️ Technologies

- HTML5
- CSS3

## 📁 Folder Structure

```text
dynamic-glass-tab-bar/
├── index.html
├── style.css
└── README.md
````

## 🚀 Usage

Open `index.html` in a modern web browser.

The navigation tabs can be customized by changing the links and labels inside the HTML file.

## 🎨 Customization

You can customize:

* Glass background opacity
* Blur intensity
* Border radius
* Tab colors
* Shadows
* Hover animation
* Tab spacing
* Responsive breakpoints

## 📱 Responsive Design

The tab bar automatically adapts to smaller screens.

On very small screens, the icon and label are displayed vertically to maintain a clean layout.

## ♿ Accessibility

The component uses semantic navigation markup and provides an accessible navigation label.

It also respects the user's `prefers-reduced-motion` preference.
