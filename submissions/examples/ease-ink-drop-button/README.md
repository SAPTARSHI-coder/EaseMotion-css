# 🖌️ Ink Drop Button – Ink Spreads Outward Like Watercolor

> A beautiful, artistic button where colorful ink drops spread outward like watercolor on click, creating a mesmerizing, painterly effect.

---

## 📖 Description

The **Ink Drop Button** is a beautiful, artistic UI component where colorful ink drops spread outward like watercolor on click. When you click the button, a burst of colorful ink droplets explodes outward, creating a stunning, painterly effect reminiscent of watercolor painting. Each drop has a unique color, size, trajectory, and organic shape, mimicking the unpredictable nature of real ink spreading on paper.

The component uses JavaScript to create and animate ink droplets with random colors, sizes, angles, and organic shapes. Each drop follows a smooth, eased trajectory with a blur effect and multiply blend mode for a realistic watercolor feel. A central splash adds to the effect, creating a complete, immersive ink drop experience.

Perfect for artistic interfaces, creative portfolios, art-related brands, and any application where you want to create a beautiful, organic interaction. The Ink Drop Button transforms a simple click into a moment of artistic expression.
