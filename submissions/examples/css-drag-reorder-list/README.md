# CSS Drag-reorder List

A pure CSS drag-reorder list component featuring draggable visual handles, hover effects, focus states, and responsive styling.

## Features

- Pure CSS implementation
- Responsive layout
- Drag handle styling
- Hover lift animation
- Keyboard focus support
- CSS custom properties for easy theming
- Light and dark mode support
- No JavaScript required

Include the stylesheet:
