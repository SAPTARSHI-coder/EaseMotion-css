# Ripple-Wave Stepper

A pure HTML and CSS Ripple-Wave Stepper designed for Gaming Hub layouts.

## Features

- Pure HTML and CSS
- No JavaScript
- Animated active-step ripple effect
- Completed-step indicators
- Responsive desktop, tablet and mobile layouts
- CSS custom properties
- Smooth transitions
- Hover interactions
- Accessible `aria-current` state
- `prefers-reduced-motion` support
