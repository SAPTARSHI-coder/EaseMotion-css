# Hover Modal

Dark-mode hover modal showcase for issue #78650.

## Files

- `demo.html` — accessible dialog-style panel.
- `style.css` — hover reveal, depth, and responsive spacing.

## Features

- Dark surface treatment.
- Hover and focus reveal states.
- Semantic dialog structure.
- Responsive actions.
- Reduced-motion fallback.

The component is presented as a visual showcase and can be connected to application state when integrated into a product.
