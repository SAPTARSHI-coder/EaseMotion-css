# CSS Float-Drift Card Grid for Fintech Dashboard Layouts

A modern **Float-Drift Card Grid** component built using pure HTML5 and CSS3 for fintech dashboard layouts. This component creates a premium financial dashboard experience with floating card animations, glassmorphism styling, smooth hover interactions, and responsive layouts.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Fintech dashboard card grid design
* Smooth float-drift animations
* Animated financial statistic cards
* Glassmorphism UI effects
* Hover lift and scale interactions
* Balance and analytics showcase cards
* Responsive grid layout
* CSS Custom Properties support
* Lightweight keyframe animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. View the floating fintech dashboard cards.
3. Hover over cards to see smooth elevation and scaling effects.
4. Customize colors, shadows, spacing, and animation speed using CSS variables.
