# CSS Blur-Entrance Badge

A modern **Blur-Entrance Badge** component built using pure HTML5 and CSS3 for Gaming Hub layouts. Badges animate into view with a smooth blur entrance effect while remaining lightweight, responsive, and accessible.

---

## ✨ Features

- Pure HTML5 & CSS3
- Blur entrance animation
- Gaming-inspired badge cards
- Responsive grid layout
- CSS Custom Properties
- Lightweight and performant
- Accessible semantic HTML
- `prefers-reduced-motion` support
- No JavaScript required

## 🚀 Usage

1. Copy the component into your project.
2. Link the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

3. Open `demo.html` in any modern browser.
