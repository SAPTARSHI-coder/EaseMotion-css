# CSS Gradient Picker

An interactive, user-friendly CSS Gradient Picker tool that lets developers visually customize linear or radial gradient properties and copy clean generated CSS code outputs.

## 🚀 Features

- **Dynamic Interactive Preview:** Real-time updates to gradient styling properties.
- **Customizable Properties:** Easily customize linear/radial types, start/end color selection, individual stop positions, and gradient rotation angles.
- **Direct CSS Code Generation:** Code display updates automatically and copy-to-clipboard button simplifies direct integrations.
- **A11y Compliant:** Interactive states are fully keyboard accessible with screenreader friendly controls and `@media (prefers-reduced-motion: reduce)` support.

## 🛠️ Usage

Copy the visual components markup from [demo.html](file:///Users/mallarapuujwal9gmail.com/GSSOC2026ease/EaseMotion-cssUM/submissions/examples/70231-css-gradient-picker/demo.html) and styled rules in [style.css](file:///Users/mallarapuujwal9gmail.com/GSSOC2026ease/EaseMotion-cssUM/submissions/examples/70231-css-gradient-picker/style.css) into your project.

### CSS Custom Customizations

Update the default fallback variables within CSS root definitions:

```css
:root {
  --color-bg: #070a13;
  --color-panel-bg: rgba(17, 22, 34, 0.75);
  --color-accent: #3b82f6;
}
```
