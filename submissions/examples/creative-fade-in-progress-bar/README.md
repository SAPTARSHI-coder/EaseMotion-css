# CSS Fade-In Progress Bar for Creative Portfolio Layouts

A modern **Creative Portfolio Progress Bar** built entirely with **HTML5 and CSS3**. This showcase demonstrates elegant **Fade-In** progress animations with glassmorphism styling, responsive layouts, and accessibility-friendly interactions without requiring JavaScript.

---

## ✨ Features

- 🎨 Creative Portfolio inspired design
- ✨ Fade-In progress animation
- 📊 Animated skill indicators
- 🌈 Gradient progress fills
- 🪟 Glassmorphism container
- 📱 Fully responsive
- ⚡ Pure HTML5 & CSS3
- 🎯 CSS Custom Properties
- ♿ `prefers-reduced-motion` support
- 🚀 No JavaScript required

## 🚀 Getting Started

1. Open `demo.html` in any modern browser.
2. Observe the fade-in animated progress bars.
3. Hover over each progress item to view interactive effects.
4. Customize colors, widths, and animation timing using CSS variables.
