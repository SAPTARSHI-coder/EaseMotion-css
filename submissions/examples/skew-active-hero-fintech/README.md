# CSS Skew-Active Hero Section

A responsive fintech dashboard hero section featuring a smooth
skew-based active interaction using pure HTML and CSS.

## Features

- Pure HTML and CSS
- Skew-based hover interaction
- Animated dashboard card
- Responsive desktop, tablet, and mobile layouts
- CSS custom properties
- Smooth transitions and keyframe animations
- No JavaScript required
- `prefers-reduced-motion` accessibility support
