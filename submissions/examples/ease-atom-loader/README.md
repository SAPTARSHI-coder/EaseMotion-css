# ⚛️ Atom Loader – Electrons Orbit a Nucleus Like Atom

> A scientific, dynamic loading animation where electrons orbit a nucleus like an atom, creating a physics-inspired visual experience.

---

## 📖 Description

The **Atom Loader** is a scientific, dynamic loading animation where electrons orbit a nucleus like an atom. Three orbits with different radii contain pairs of electrons that orbit the nucleus at different speeds, creating a realistic atomic model. The nucleus pulses with a gentle glow, and each electron has a unique color, making the animation visually engaging.

The component uses CSS animations with `transform` and `keyframes` to create the orbital motion. Each orbit rotates at a different speed and direction, while electrons independently orbit along their paths. The nucleus pulses with a soft glow animation.

Perfect for science-themed interfaces, educational platforms, tech brands, and any application where you want to create a scientific, engaging loading animation. The Atom Loader transforms a simple loading indicator into a physics-inspired experience.
