# CSS Pixel Art Box Shadow

A retro 8-bit character walking animation achieved entirely without images, using only CSS `box-shadow` on a single `div` to map out the pixel grid.

## Features
- Zero image footprint: an entire multi-colored sprite rendered on a single `div` using stacked `box-shadow` offsets.
- Classic frame-by-frame sprite sheet animation emulated using a `steps(1)` keyframe pacing.
- Entire sprite scaled fluidly via `transform: scale(1.5)`.
