# Dynamic Progress Bar with Glassmorphism Styling

A responsive progress indicator designed with a modern glassmorphism aesthetic using pure HTML and CSS.

## Features

- Glassmorphism card design
- Animated progress bar
- Gradient progress indicator
- Percentage display
- Project milestone indicators
- Progress shimmer effect
- Active milestone pulse animation
- Responsive desktop and mobile layouts
- Reduced-motion support
- No JavaScript dependencies

## Files

- `demo.html` — Component markup and demo page
- `style.css` — Complete component styling

## Usage

Open `demo.html` in a modern browser to preview the component.

The progress value can be changed by updating the following CSS custom property:

```html
<div class="progress-fill" style="--progress: 78%;">
