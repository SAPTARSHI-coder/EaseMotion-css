# Bounce-Pulse Creative Portfolio Carousel (`#54456`)

## What does this do?
Produces an interactive exhibition carousel whose active slides spring into place with lively bouncing kinetic energy while pulsing their status indicator beacons.

## How is it used?
Organize studio slide panels inside an `ease-carousel-bounce-host` structure:
```html
<div class="ease-carousel-bounce-host">
  <div class="bounce-slide active">...</div>
</div>
```

## Why is it useful?
Solves issue #54456 by replacing mechanical slide shifts with tactile, hardware-accelerated spring animations.
