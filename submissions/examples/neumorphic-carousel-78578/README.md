# Neumorphic Carousel

Gradient neumorphic carousel showcase for issue #78578.

## Files

- `demo.html` — semantic slide content.
- `style.css` — soft surfaces, depth, and responsive scrolling.

## Features

- Horizontal responsive carousel.
- Scroll snapping.
- Neumorphic card surfaces.
- Hover depth effect.
- Reduced-motion support.

The demo uses native horizontal scrolling so the core interaction remains usable without JavaScript.
