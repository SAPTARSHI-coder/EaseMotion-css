# Slide-Up Navbar for Minimalist Tech Layouts

## Overview

A lightweight pure CSS Slide-Up Navbar component designed for modern minimalist tech interfaces.

This component demonstrates a smooth entrance animation with glassmorphism styling and responsive behavior.

## Features

- Pure HTML and CSS implementation
- Smooth slide-up entrance animation
- Glassmorphism inspired navbar
- Responsive layout for all devices
- Hover underline effects
- Interactive button animation
- No JavaScript dependency
- Accessibility support with `prefers-reduced-motion`
