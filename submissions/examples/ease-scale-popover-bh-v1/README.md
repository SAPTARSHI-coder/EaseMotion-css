# ease-scale-popover-bh

Pure CSS scale-hover popover for fintech dashboards.

## Features
- Scale hover effect
- Popover variants
- Responsive design
- Accessibility support

## Usage
```html
<div class="ease-popover ease-popover-scale">Content</div>
```

## CSS Classes
- `.ease-popover` - Base popover
- `.ease-popover-scale` - Scale hover effect
