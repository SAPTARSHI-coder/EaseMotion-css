# Ease Floating Badge

## What does this do?

A floating badge positioned on the corner of a card or image with rounded styling, shadow, and hover animation.

---

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<div class="card-image">
    <img src="image.jpg" alt="Product">
    <span class="floating-badge">New</span>
</div>
```

### Features

- Corner placement
- Rounded badge
- Shadow effect
- Hover animation
- Scale interaction
- Responsive layout

---

## Why is it useful?

Floating badges are commonly used for labels such as "New", "Sale", and "Featured" on product cards, images, galleries, and promotional content.

This component provides a lightweight and reusable floating label with subtle interaction feedback while following the animation-first philosophy of EaseMotion CSS.
