# Ease CSS Glitch-Flicker Badge for SaaS Showcase Layouts

A modern CSS-only glitch-flicker badge designed for
SaaS landing pages, product releases, feature announcements
and status interfaces.

The component combines controlled digital glitch effects,
scanline flickering, status indicators and hover interactions
while remaining lightweight and dependency-free.

## Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Glitch displacement layers
- Cyan and pink glitch accents
- Scanline flicker effect
- Animated status indicator
- Interactive hover distortion
- Animated icon
- SaaS showcase layout
- Responsive desktop design
- Responsive tablet design
- Responsive mobile design
- Keyboard focus support
- `prefers-reduced-motion` support
- CSS custom properties
- Lightweight implementation
