# Erhu Bow Hair

## What does this do?
Renders a self-contained CSS-only `ease-erhu-bow-hair` demo: Erhu bow hair trapped between the strings.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-erhu-bow-hair`. No build step or JavaScript is required for the effect.

```html
<section class="ease-erhu-bow-hair">
  <div class="ease-erhu-bow-hair__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
