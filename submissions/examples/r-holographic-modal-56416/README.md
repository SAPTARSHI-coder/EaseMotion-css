# CSS Holographic Modal

A futuristic **Holographic Modal** built using pure HTML5 and CSS3 for Gaming Hub layouts. It combines a glassmorphism panel with animated holographic lighting for a modern gaming interface.

---

## ✨ Features

- Pure HTML5 & CSS3
- Animated holographic overlay
- Glassmorphism design
- Responsive layout
- CSS Custom Properties
- Keyboard-accessible checkbox toggle
- `prefers-reduced-motion` support
- No JavaScript required
