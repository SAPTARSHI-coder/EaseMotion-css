# Morphing Shape Floating Badge with Gradient Transition Effects

## Overview

A futuristic cyberpunk floating badge component featuring animated morphing
shapes, gradient transitions, neon glow effects, and interactive 3D hover.

Built using pure HTML, CSS, and JavaScript.

## Features

- ⚡ Morphing blob animation
- 🌈 Animated gradient background
- ✨ Neon glow effects
- 🌀 Floating hover interaction
- 🎨 Cyberpunk theme
- 📱 Responsive design
- 🖥️ Pure HTML/CSS/JS

## Usage

1. Open `demo.html` in your browser.
2. Hover over the badge.
3. Experience morphing and 3D animation effects.
