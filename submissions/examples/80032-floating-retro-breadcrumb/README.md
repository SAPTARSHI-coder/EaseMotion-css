# Floating Retro Breadcrumb (Variant A)

A responsive breadcrumb navigation component inspired by retro and
pixel-era interface design.

The component combines chunky borders, warm colors, floating shadows,
and subtle hover movement to create a playful retro UI.

## Features

- Retro-inspired visual design
- Floating layered shadows
- Responsive layout
- Horizontal scrolling on narrow screens
- Semantic breadcrumb navigation
- Keyboard-friendly links
- Clear current-page state
- No JavaScript required
- No external dependencies
- Reduced-motion support
