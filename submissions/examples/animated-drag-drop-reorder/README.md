# ease-drag-reorder

## Description

Adds a reusable drag-and-drop list reordering utility with smooth animations using the native HTML5 Drag and Drop API.

Ideal for:

- Task Managers
- Kanban Boards
- Playlists
- Dashboards
- Sortable Lists

---

## Features

- Native HTML5 Drag & Drop
- Lightweight
- Responsive
- Smooth Hover Animation
- Easy Customization

---

## Usage

```html
<ul class="ease-drag-reorder">

    <li draggable="true">Item 1</li>

    <li draggable="true">Item 2</li>

</ul>
```

## Customization

Card Color

```css
background:#1e293b;
```

Hover Effect

```css
transform:translateY(-2px);
```

Dragging Style

```css
.dragging{
opacity:.55;
transform:scale(1.03);
}
```
