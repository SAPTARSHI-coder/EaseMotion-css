# Spotlight Follow Cursor Component

Add ease-spotlight-follow-cursor-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|---------|
| `--sf-accent` | `#6366f1` |
| `--sf-blur` | `120px` |
| `--sf-radius` | `12px` |
| `--sf-shadow` | `0 8px 32px rgba(0,0,0,.4)` |

## Note

Tiny JS updates CSS custom properties on mousemove. CSS handles the glow visual.
