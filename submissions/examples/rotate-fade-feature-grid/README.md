# CSS Rotate-Fade Feature Grid

A responsive, pure CSS/HTML feature grid for fintech dashboard layouts.

The component combines subtle rotation, fade-style visual transitions,
scaling, and elevation to create an interactive feature showcase without
JavaScript.

## Features

- Pure HTML and CSS
- No JavaScript required
- Rotate-fade hover interaction
- Smooth CSS transitions
- Responsive grid layout
- Desktop, tablet, and mobile support
- Keyboard focus support
- CSS custom properties
- `prefers-reduced-motion` support
- Semantic HTML
