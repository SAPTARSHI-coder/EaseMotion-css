# Memory Card Grid

A grid of memory cards performs a wave shuffle reveal.

## Features
- Wave shuffle reveal
- Card back + face
- Directional cascade
- Pure CSS

## Usage
```html
<div class="mcg-card" style="--i:0">1</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
