# 3D Perspective Tilt Product Showcase Card with Light Reflections

### Vibrant Gradient Version

A modern **3D Perspective Tilt Product Showcase Card** built using **HTML5** and **CSS3**. The component features vibrant gradient styling, animated light reflections, 3D hover interactions, and a responsive layout to create a visually engaging product showcase.

---

## ✨ Features

- 3D perspective tilt animation
- Vibrant gradient theme
- Animated light reflection effect
- Product image depth animation
- Gradient CTA button
- Responsive mobile-first layout
- CSS variables for easy customization
- Pure HTML & CSS implementation
- Reduced motion accessibility support

## 🚀 Usage

1. Open the component folder.
2. Keep `demo.html` and `style.css` in the same directory.
3. Open `demo.html` in any modern browser.
4. Hover over the card to view the 3D tilt and animated reflection effects.

No external libraries or installation are required.
