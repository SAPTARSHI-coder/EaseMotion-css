# Animated Filter Bar — Claymorphism

A responsive Animated Filter Bar created for EaseMotion CSS
using a soft claymorphism visual language.

The component combines rounded surfaces, soft extruded shadows,
inset highlights, animated active states, and responsive filter
controls while remaining completely CSS-driven.

## Features

- Claymorphism visual styling
- Animated filter controls
- Soft extruded shadows
- Inset clay surfaces
- Active filter state
- Hover elevation effects
- Animated filter icons
- Filter status indicator
- Responsive filter wrapping
- Responsive result cards
- Pure CSS abstract artwork
- Keyboard focus states
- `prefers-reduced-motion` support
- Semantic HTML
- Zero external JavaScript dependencies
- No external assets
