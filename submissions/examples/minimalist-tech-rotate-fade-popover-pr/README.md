# Rotate-Fade Popover

A lightweight CSS-only popover interaction designed for minimalist
technology-focused interfaces.

The component combines a subtle rotation, scale, and opacity transition
to create a polished popover entrance without JavaScript or external
dependencies.

## Features

- Pure HTML and CSS
- No JavaScript required
- Rotate + fade entrance animation
- Scale transition for a smooth presentation
- Hover and keyboard-focus support
- Responsive desktop, tablet, and mobile layouts
- CSS custom properties for easy customization
- Accessible focus styling
- `prefers-reduced-motion` support
- Self-contained demo that works by opening `demo.html` directly
