# Ease Media Control

## What does this do?

A compact media control component for displaying play, pause, and stop actions.

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<div class="media-control">
    <button class="media-button play" aria-label="Play">
        ▶
    </button>

    <button class="media-button pause" aria-label="Pause">
        ||
    </button>

    <button class="media-button stop" aria-label="Stop">
        ■
    </button>
</div>
```

### Features

- Play state
- Pause state
- Stop state
- Icon hover animation
- Active interaction
- Focus state
- Responsive sizing
- Pure CSS
- No JavaScript required

## Why is it useful?

Media controls are commonly used in audio players, video interfaces, podcast applications, media dashboards, and other interfaces that require compact playback controls.

This component provides a simple and reusable media control group with smooth interaction feedback while following the animation-first philosophy of EaseMotion CSS.
