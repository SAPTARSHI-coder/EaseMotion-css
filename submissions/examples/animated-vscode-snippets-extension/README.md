# Ease-* Classes Demo

This project demonstrates how to use **ease-in**, **ease-out**, and **ease-in-out** transition classes with a simple HTML + CSS setup.

## 🚀 How to Run
1. Open `demo.html` in your browser.
2. Hover over the colored boxes.
3. Watch the different easing effects:
   - **Ease In** → starts slow, speeds up.
   - **Ease Out** → starts fast, slows down.
   - **Ease In-Out** → slow-fast-slow.

## 💡 VS Code Snippets Extension
You can create a custom snippet in VS Code to quickly insert these classes:

```json
"Ease Classes": {
  "prefix": "ease",
  "body": [
    "ease-in",
    "ease-out",
    "ease-in-out"
  ],
  "description": "Insert ease-* transition classes"
}
