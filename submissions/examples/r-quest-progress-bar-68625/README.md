# CSS Quest Progress Bar

A responsive quest and mission progress tracker built entirely
with HTML and CSS.

## Features

- Pure HTML and CSS
- No JavaScript required
- Quest progress indicator
- Completed checkpoints
- Active checkpoint with pulse animation
- Reward section
- Responsive layout
- CSS custom properties
- Accessible progressbar semantics
- Reduced-motion support

## Usage

Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
