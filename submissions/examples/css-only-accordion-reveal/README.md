# CSS-Only Accordion Reveal Animation

A pure CSS accordion component demonstrating smooth
expand and collapse interactions.

## Features

- Pure HTML + CSS
- No JavaScript dependency
- Smooth reveal animation
- Animated plus/cross indicator
- Glassmorphism design
- Hover and focus interaction
- Fully responsive
- Reduced motion support


## Usage

Add the component:

```html
<details class="ease-accordion">

<summary>
Question
<span class="accordion-icon">+</span>
</summary>

<div class="accordion-content">
<p>
Answer content
</p>
</div>

</details>
