# 3D Flip Vertical Flip

A reusable 3D vertical flip animation utility for EaseMotion.

## Features

- Vertical 3D flip using `rotateX()`
- Hardware-accelerated `transform`
- Configurable duration and timing
- Uses `will-change` for smoother rendering
- Supports `prefers-reduced-motion`
- Simple reusable animation class

## Usage

Add the animation class to any suitable element:

```html
<div class="ease-anim-3d-flip-vertical-flip">
  Content
</div>
