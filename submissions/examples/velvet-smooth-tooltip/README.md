# Velvet Smooth Transition Tooltip

A smooth, elegant tooltip component featuring a **Velvet Smooth Transition** effect using pure HTML and Vanilla CSS.

## Features

- Velvet-inspired visual styling
- Smooth CSS transitions
- Hover and keyboard focus support
- Top, bottom, left, and right positioning
- Responsive layout
- Dark-mode support
- Hardware-accelerated transforms
- Accessible tooltip semantics
- `aria-describedby` support
- `role="tooltip"`
- `:focus-visible` support
- `prefers-reduced-motion` support
- No JavaScript
- No external dependencies
