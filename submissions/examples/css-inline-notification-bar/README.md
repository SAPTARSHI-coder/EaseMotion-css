# CSS Inline Notification Bar

A clean, responsive inline notification component with icons, status colors, and a close button built entirely with HTML and CSS.

## Features

- Info, Success, and Warning variants
- Hover elevation effect
- Accessible semantic markup
- Responsive layout
- Close button styling
- Pure HTML & CSS
- No JavaScript required

## Folder Structure

```
css-inline-notification-bar/
├── demo.html
├── style.css
└── README.md
```

## Technologies

- HTML5
- CSS3
- Flexbox
- CSS Transitions

## Purpose

Provides a reusable inline notification component for dashboards, forms, settings pages, and web applications while following EaseMotion CSS's lightweight, animation-first philosophy.
