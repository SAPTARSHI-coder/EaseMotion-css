# Disco Floor

A dance-floor grid of shimmering tiles that strobe like a mirrorball room.

## Features
- Tiles flash on staggered loops
- Checkerboard gradient shimmers
- Glow pulses like club lights

## Usage
```html
<div class="df-floor">
  <div class="df-tile df-t1"></div>
  <div class="df-tile df-t5"></div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
