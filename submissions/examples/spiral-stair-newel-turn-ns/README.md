# Spiral Stair Newel Turn

## What does this do?
Renders a self-contained CSS-only `ease-spiral-stair-newel-turn` demo: Spiral staircase newel post turn climb.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-spiral-stair-newel-turn`. No build step or JavaScript is required for the effect.

```html
<section class="ease-spiral-stair-newel-turn">
  <div class="ease-spiral-stair-newel-turn__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
