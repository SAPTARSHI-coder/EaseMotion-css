# Ease Multi-Layered Border Spotlight Bento Card (`ease-multi-layer-border-spotlight-card`)

Dark Bento Grid card with a multi-layered border spotlight beam tracking mouse position.

## Features
- Cursor-position-synced dual-layer gradient border spotlight
- Ambient backlight aura glow reflecting cursor coordinates
- Dark glassmorphism card container with backdrop blur
- Smooth mousemove LERP coordinate tracking
- Accessible static fallback for mobile devices
