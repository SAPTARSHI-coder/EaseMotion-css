# Pastel Glassmorphism Input Field

A beautiful, soft, and modern input field component featuring a frosted glass aesthetic over animated abstract pastel backgrounds.

## Features
- True glassmorphism using `backdrop-filter: blur`
- Soft, translucent white background with semi-transparent borders
- Animated CSS abstract shapes for background depth (`filter: blur`)
- Accessible input fields with focus rings and placeholder styling
- Minimal, clean typography (Outfit font)
- Fully responsive

## Usage
Include `demo.html` and `style.css` in your project. Note that the background shapes (`.shape`) must be placed behind the `.glass-container` to achieve the glassmorphic effect.
