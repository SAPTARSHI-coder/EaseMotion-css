# CSS Login Page Splitscreen

A modern, responsive split-screen login page built using only HTML and
Vanilla CSS.

This component is created for the EaseMotion CSS library and demonstrates
how CSS animations and transitions can be used to create a polished login
experience without JavaScript or external UI libraries.

## ✨ Features

- Responsive split-screen layout
- Pure HTML and Vanilla CSS
- Smooth entrance animations
- Animated gradient typography
- Floating background effects
- Interactive login button
- Accessible form labels
- Keyboard-friendly focus states
- Dark mode support
- Reduced-motion support
- Mobile-first responsive behavior
- No JavaScript dependency
- No external libraries
