# Bouncing Spring Tabs

A modern pure CSS tabs and segmented control featuring a playful **Bouncing Spring** animation.

## Features

- Pure HTML & CSS
- Spring bounce active animation
- Smooth transitions
- Responsive design
- Dark mode compatible
- Hardware-accelerated animations
- Accessible radio-button implementation
- No JavaScript required

## Files

- `demo.html`
- `style.css`

## Preview
