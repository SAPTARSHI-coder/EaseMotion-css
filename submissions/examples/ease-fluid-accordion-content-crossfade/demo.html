Ease Fluid Accordion

EaseMotion CSS is a lightweight animation library providing reusable UI animation components with accessible defaults.

Nested accordions use the same fluid CSS Grid animation while maintaining independent state.

Include the EaseMotion CSS stylesheet and begin using animation utility classes in your project.

Supports keyboard interaction, ARIA attributes, and smooth motion with reduced layout shifts.

Modify colors, spacing, border radius, transition duration and typography using CSS custom properties.
