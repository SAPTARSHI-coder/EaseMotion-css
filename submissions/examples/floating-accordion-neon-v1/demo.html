Floating Neon Accordion

✨ What is EaseMotion CSS?

EaseMotion CSS provides lightweight CSS animations and UI components with zero JavaScript dependencies.

🚀 Why use this component?

It creates an eye-catching futuristic accordion using only semantic HTML and CSS.

🎨 Features

Responsive layout, neon glow, floating hover effect, and smooth transitions.

💡 Browser Support

Works in all modern browsers supporting the native HTML details element.
