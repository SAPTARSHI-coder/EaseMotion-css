# Floating Accordion with Neon Styling

A responsive CSS-only accordion featuring a futuristic neon aesthetic using the native HTML `<details>` and `<summary>` elements.

## Features

- Pure HTML & CSS
- Responsive layout
- Neon glow styling
- Floating hover animation
- Smooth expand/collapse
- Semantic HTML
- Accessible native accordion
- No JavaScript required

## Folder Structure

```
floating-accordion-neon/
├── demo.html
├── style.css
└── README.md
```

## Technologies

- HTML5
- CSS3
- CSS Transitions
- CSS Animations
- Native `<details>` element

## Purpose

Provides a reusable neon-themed accordion component suitable for FAQs, documentation pages, dashboards, and futuristic UI designs while following the lightweight philosophy of EaseMotion CSS.
