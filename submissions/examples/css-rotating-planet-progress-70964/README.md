# CSS Rotating Planet Progress

A beautiful, pure CSS rotating planet animation that fills to show completion like a partial eclipse.

## Usage

```html
<div class="planet-progress-container" role="progressbar" aria-valuenow="50" aria-valuemin="0" aria-valuemax="100" aria-label="Loading progress">
  <div class="planet-progress">
    <div class="planet">
      <div class="eclipse-shadow"></div>
    </div>
    <div class="planet-ring"></div>
  </div>
</div>
```

## Why is this useful for EaseMotion CSS

This component expands the library's collection of ready-to-use CSS animations and UI patterns, helping front-end developers implement stunning space-themed loaders and progress indicators without JavaScript. It utilizes CSS animations, gradients, and 3D transforms for a rich visual experience.
