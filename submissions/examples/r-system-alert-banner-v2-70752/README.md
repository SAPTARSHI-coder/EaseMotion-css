# CSS System Alert Banner v2

A responsive system alert banner component built using pure CSS.

This example provides four reusable alert variants:

- Info
- Success
- Warning
- Error

## Features

- Pure HTML and CSS
- No JavaScript
- Responsive layout
- Animated entrance effect
- Animated status icons
- Four visual alert variants
- Semantic ARIA roles
- Keyboard-friendly because no unnecessary interactive controls are used
- Reduced-motion support
- Mobile-friendly design
- Easy to customize

## Variants

### Info

Used for general informational messages.

### Success

Used when an action has completed successfully.

### Warning

Used when the user should pay attention to a possible issue.

### Error

Used when an operation has failed or requires immediate attention.
