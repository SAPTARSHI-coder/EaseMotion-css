# Micro Badge Pop

A notification bell whose badge pops out every time a new count lands.

## Features
- Badge springs with a scale bounce
- Bell tilts when the badge drops
- Badge pulses to demand attention

## Usage
```html
<div class="mbb-bell">
  &#128276;
  <span class="mbb-badge">3</span>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
