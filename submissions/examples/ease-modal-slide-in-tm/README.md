# Modal Slide In Component

Add ease-modal-slide-in-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|--------|
| `--mm-accent` | `#6366f1` |
| `--mm-radius` | `12px` |
| `--mm-shadow` | `0 20px 60px rgba(0,0,0,.5)` |
| `--mm-overlay` | `rgba(0,0,0,.6)` |

## Note

CSS handles overlay and card animation. Tiny JS toggles `open` class on overlay.
