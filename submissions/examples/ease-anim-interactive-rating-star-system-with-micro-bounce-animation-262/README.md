# Interactive Rating Star System with Micro-Bounce Animation (Vibrant Gradient Version)

## Features

- Interactive 5-star rating
- Micro-bounce hover animation
- Vibrant animated gradient background
- Dynamic rating messages
- Animated progress bar
- Responsive design
- Pure HTML, CSS and Vanilla JavaScript
