# Glassmorphism Accordion with Neumorphism Styling

A modern, responsive accordion component that combines glassmorphism
surfaces with subtle neumorphic depth.

## Features

- Glassmorphism UI
- Neumorphic shadows
- Responsive layout
- Native HTML accordion behavior
- Smooth open/close animation
- Interactive hover states
- Keyboard focus support
- Accessible semantic markup
- Decorative ambient glow
- Reduced-motion support
- No external dependencies

## Technologies

- HTML5
- CSS3
