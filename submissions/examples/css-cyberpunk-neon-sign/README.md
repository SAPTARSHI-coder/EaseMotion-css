# CSS Cyberpunk Neon Sign

A highly detailed neon sign simulation perfect for a cyberpunk aesthetic. It features intense glowing text and a faulty electrical flicker effect.

## Features

- **Pure CSS**: Fully built with HTML and CSS.
- **Layered Text Shadows**: The intense neon glow is created by stacking multiple `text-shadow` layers with increasing blur radii.
- **Faulty Flicker Animation**: Complex `@keyframes` simulate the irregular flickering of a broken neon tube.
- **Atmospheric Background**: A subtle CSS grid background adds depth to the scene.
