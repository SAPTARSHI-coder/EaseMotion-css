# Neumorphic Spinner - Minimalist

A responsive minimalist loading spinner built with pure HTML and CSS.

## ✨ Features

- Fully responsive
- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Neumorphic visual design
- Soft dual-direction shadows
- Animated spinner
- Animated loading indicator
- Responsive sizing
- Reduced-motion support
- Clean minimalist interface
