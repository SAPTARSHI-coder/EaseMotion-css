# CSS Skew-Active Toast

A responsive toast notification component with a skew entrance animation built using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Skew entrance animation
- Hover scale effect
- Responsive layout
- Accessible with prefers-reduced-motion
- Easy customization

## Files

```
demo.html
style.css
README.md
```

## Usage

Open `demo.html` in any browser.

## Customization

Modify the background colors, border radius, animation duration, or skew angle in `style.css`.

## Accessibility

Supports:

- Responsive design
- Reduced motion preference
- Keyboard-friendly structure
