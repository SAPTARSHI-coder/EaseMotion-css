# Command Palette Keyboard Item Selection

## Overview

This submission adds automated Vitest coverage for keyboard navigation in a command palette.

## Test Coverage

* Initial selection
* Down-arrow navigation
* Up-arrow navigation
* First-item boundary
* Last-item boundary
* Empty command list
* Single-item list
* Repeated key presses
* Duplicate command names
* Alternating navigation
* Current item selection

## Demo

Open `demo.html` directly in a browser.

## Run Tests

```bash
npx vitest run submissions/examples/command-palette-keyboard-selection/command-palette-keyboard.test.js
```
