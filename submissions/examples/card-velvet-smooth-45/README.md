# Velvet Smooth Transition Card

What does this do?
This is a card component featuring luxurious, hardware-accelerated "velvet smooth" CSS transitions on hover, with built-in dark mode compatibility.

How is it used?
```html
<div class="velvet-card">
  <h3 class="velvet-card-title">Velvet Smooth</h3>
  <p class="velvet-card-content">Experience the luxurious and velvety smooth transitions in this card component. Hardware accelerated and fully responsive.</p>
  <button class="velvet-card-btn">Explore</button>
</div>
```

Why is it useful?
It provides a premium, highly responsive user interaction without relying on JavaScript, aligning with EaseMotion's philosophy of pure, performant CSS animations.
