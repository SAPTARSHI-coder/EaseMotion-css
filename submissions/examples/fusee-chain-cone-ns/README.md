# Fusee Chain Cone

## What does this do?
Renders a self-contained CSS-only `ease-fusee-chain-cone` demo: Fusee chain climbing a cone to equalize spring torque.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-fusee-chain-cone`. No build step or JavaScript is required for the effect.

```html
<section class="ease-fusee-chain-cone">
  <div class="ease-fusee-chain-cone__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
