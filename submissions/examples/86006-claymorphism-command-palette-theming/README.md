# Claymorphism Command Palette Search — Theming Configuration

This example documents how to customize the visual theme of a
Claymorphism Command Palette using CSS custom properties.

## Features

- Claymorphism visual style
- CSS custom property based theming
- Custom colors
- Custom radius and spacing
- Responsive layout
- Keyboard-accessible controls
- Visible focus states
- Reduced-motion support
