# High-Contrast Dark Mode Badge Components

Accessible, high-contrast badge component modifiers optimized for dark mode backgrounds.

## Features
- **Enhanced Contrast:** High-contrast borders and subtle background opacities to ensure legibility on dark themes.
- **Interactive Micro-Animations:** Smooth hover transitions.
- **Lightweight:** Pure CSS implementation with zero external dependencies.

## File Structure
- `demo.html` - Minimal HTML structure to test badge variants.
- `style.css` - Custom badge class styling and dark mode contrast variables.
