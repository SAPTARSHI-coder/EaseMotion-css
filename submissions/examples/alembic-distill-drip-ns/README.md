# Alembic Distill Drip

## What does this do?
Renders a self-contained CSS-only `ease-alembic-distill-drip` demo: Alchemy alembic condenser dripping distillate into a flask.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-alembic-distill-drip`. No build step or JavaScript is required for the effect.

```html
<section class="ease-alembic-distill-drip">
  <div class="ease-alembic-distill-drip__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
