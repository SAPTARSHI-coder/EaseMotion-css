# Zynoscope Color Wheel

## What does this do?
Renders a self-contained CSS-only `ease-zynoscope-color-wheel` demo: Zynoscope color wheel spinning complementary sectors into blend.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-zynoscope-color-wheel`. No build step or JavaScript is required for the effect.

```html
<section class="ease-zynoscope-color-wheel">
  <div class="ease-zynoscope-color-wheel__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
