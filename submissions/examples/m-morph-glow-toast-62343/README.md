# CSS Morph-Glow Toast for Product Catalog Layouts

A modern toast notification component featuring a morphing glow effect built entirely with HTML and CSS. Ideal for product catalogs, e-commerce notifications, and status messages.

## ✨ Features

- Pure HTML5 & CSS3
- Morph-glow hover animation
- Glassmorphism design
- Responsive layout
- CSS Custom Properties
- Smooth entrance animation
- `prefers-reduced-motion` support
- No JavaScript required
