# Mesh Gradient Background

## What does this do?

Creates a vibrant animated mesh gradient background using layered radial gradients, blurred color fields, and CSS animations.

---

## How is it used?

Open `demo.html` directly in a browser.

The background consists of multiple independently positioned gradient layers:

```html
<div class="mesh-background">

    <div class="mesh-orb orb-purple"></div>
    <div class="mesh-orb orb-cyan"></div>
    <div class="mesh-orb orb-pink"></div>
    <div class="mesh-orb orb-blue"></div>

</div>
```

---

## Why is it useful?

Mesh gradients are useful for modern landing pages, hero sections, authentication screens, portfolios, dashboards, and promotional interfaces.

This implementation creates the effect entirely with CSS, making it lightweight and framework-independent while adding subtle movement through CSS animations.

---

## Features

- Animated mesh gradient
- Multiple layered color fields
- Purple, cyan, blue and pink palette
- Glassmorphism content panel
- Responsive design
- Reduced-motion support
- Pure HTML and CSS
- No JavaScript
- No external dependencies
