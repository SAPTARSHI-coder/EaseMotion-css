# Animated Pricing Toggle Submission

## 1. What does this do?
It provides a modern, animated pricing component with a monthly/yearly billing toggle, smooth price transitions, and interactive pricing cards. Perfect for SaaS websites and subscription-based services.

## 2. How is it used?
Add the billing toggle switch and pricing cards with `data-monthly` and `data-yearly` attributes on the price amounts. JavaScript handles the toggle functionality and animates the price changes smoothly using requestAnimationFrame.

## 3. Why is it useful?
- Essential component for SaaS and subscription websites
- Smooth animated price transitions when switching billing periods
- Toggle switch with gradient styling
- "Save 20%" badge to incentivize yearly billing
- Interactive pricing cards with hover effects
- Popular plan highlighting with badge
- Feature list with check/cross icons
- Fully responsive design for all devices
- Accessible with `prefers-reduced-motion` support
- Easy to customize plans, prices, and features
- Maintainer can easily standardize this as `.ease-pricing-toggle-[YOUR_INITIALS]` in the core library.
