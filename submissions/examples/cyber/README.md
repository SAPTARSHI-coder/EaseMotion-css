# Cyberpunk Floating Audio Player Widget

A high-tech, futuristic floating audio player component built with strict zero-JS requirements, neon CSS custom properties, and EaseMotion tokens.

## Features
* **Zero JavaScript:** Relies entirely on native HTML5 audio controls and modern CSS layout features.
* **Cyberpunk Aesthetic:** Features custom corner clipping paths (`clip-path`), glowing neon box-shadows, and monospace tracking.
* **Responsive Layout:** Automatically adjusts from a corner floating module on desktop to a full-width bottom layout on mobile devices.
* **Accessibility Support:** Respects `prefers-reduced-motion` settings to eliminate hover transforms.

## Usage
Include `style.css` in your project workspace and apply the `.cyber-player-wrapper` structure containing the native `<audio>` element as shown in `demo.html`.
