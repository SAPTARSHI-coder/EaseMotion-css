# CSS Breathing Neon Ring

A pure CSS animated neon ring that continuously expands and contracts with a soft glowing effect.

## Features

- Pure HTML and CSS
- No JavaScript
- Smooth breathing animation
- Multi-layer neon glow
- Responsive sizing
- CSS custom properties
- Reduced-motion support

## Usage

```html
<div class="neon-ring">
  <span class="ring-core"></span>
</div>
