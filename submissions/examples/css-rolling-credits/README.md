# CSS Rolling Credits

A pure CSS movie-style rolling credits component that continuously scrolls content upward, similar to film and television end-credit sequences.

## Features

- Pure HTML & CSS
- Infinite smooth scrolling animation
- Perspective effect for cinematic appearance
- Fully responsive
- Accessible structure
- No JavaScript required

## Usage

```html
<div class="credits-container">
  <div class="credits">
    <!-- Credit content -->
  </div>
</div>
