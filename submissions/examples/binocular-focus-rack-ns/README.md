# Binocular Focus Rack

## What does this do?
Renders a self-contained CSS-only `ease-binocular-focus-rack` demo: Binoculars focus wheel racking sharpness in and out.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-binocular-focus-rack`. No build step or JavaScript is required for the effect.

```html
<section class="ease-binocular-focus-rack">
  <div class="ease-binocular-focus-rack__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
