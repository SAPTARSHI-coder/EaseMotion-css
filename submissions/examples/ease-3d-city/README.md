# 3D City · City Buildings Rise and Glow 🏙️

An interactive 3D city where buildings rise and glow, creating a dynamic urban skyline with animated growth and illuminated windows.

## Features

- 🏙️ **3D City** – Buildings with depth and detail
- 🌆 **Rise Animation** – Buildings grow from the ground
- ✨ **Glow Effect** – Buildings glow as they rise
- 💡 **Windows** – Illuminated windows with glow
- 🎚️ **Speed Control** – Adjust rise speed (1-10)
- 🎚️ **Building Count** – Adjust number of buildings (15-40)
- ⏸️ **Pause/Resume** – Toggle animation
- 🔄 **Reset** – Reset to flat ground
- 🌟 **Stars** – Twinkling night sky

## How to Use

1. Click **RISE** or press **Space** to start the city rising
2. Watch buildings grow from the ground
3. Windows light up as buildings rise
4. Adjust **Speed** for faster/slower growth
5. Adjust **Buildings** for more/less density
6. Press **RESET** or **R** to reset
7. Press **PAUSE** or **P** to pause/resume animation

## Technical Details

- **Rise System:** Smooth height transition (ease-out)
- **Glow Effect:** Intensity increases with height
- **Rendering:** Canvas-based 3D buildings
- **Performance:** 60fps with requestAnimationFrame

## Customization

You can easily customize:
- **Building Count:** Modify slider range (15-40)
- **Speed:** Adjust rise speed (1-10)
- **Colors:** Change building and window colors
- **Height Range:** Adjust maxHeight values
- **Windows:** Modify window count and size

## Browser Support

Works in all modern browsers:
- Chrome, Firefox, Safari, Edge

## Run Locally

Simply open `index.html` in your browser – no server required!
