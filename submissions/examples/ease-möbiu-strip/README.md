# Möbius Strip · Strip Rotates Continuously ♾️

An interactive 3D Möbius strip with continuous rotation, vibrant colors, and mesmerizing surface flow. Watch the non-orientable surface rotate!

## Features

- ♾️ **3D Möbius Strip** – Non-orientable surface
- 🔄 **Continuous Rotation** – Smooth 3D rotation
- 🎨 **Vibrant Colors** – Rainbow gradient
- 🎚️ **Speed Control** – Adjust rotation speed (1-10)
- 🎚️ **Detail Control** – Adjust mesh detail (2-6)
- ⏸️ **Pause/Resume** – Toggle animation
- 🔄 **Reset** – Reset rotation
- ✨ **Glow Effects** – Vertex and edge glow

## How to Use

1. Watch the Möbius strip rotate continuously
2. Adjust **Speed** for rotation pace
3. Adjust **Detail** for mesh complexity
4. Press **RESET** or **R** to reset rotation
5. Press **PAUSE** or **P** to pause/resume animation

## Technical Details

- **3D Rendering:** Perspective projection
- **Mesh:** Triangle-based surface rendering
- **Rotation:** Continuous 3-axis rotation
- **Performance:** 60fps with requestAnimationFrame

## Customization

You can easily customize:
- **Colors:** Modify color generation
- **Detail:** Adjust slider range (2-6)
- **Speed:** Modify rotation speed
- **Mesh:** Change U/V segments
- **Möbius:** Adjust radius and width
