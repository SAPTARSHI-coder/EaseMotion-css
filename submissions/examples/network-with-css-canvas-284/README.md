# Particle Constellation Background Network

A neumorphic particle constellation background component built with
HTML Canvas, CSS, and JavaScript.

## Features

- Interactive particle network
- Dynamic particle connections
- Mouse interaction
- Neumorphic UI design
- Responsive layout
- Mobile-friendly particle count
- Smooth animations
- No external libraries

## Files

- `demo.html` - Component structure and JavaScript
- `style.css` - Neumorphic styling and responsive design
- `README.md` - Documentation

## Usage

Open `demo.html` directly in any modern browser.

No installation or external dependencies are required.

## Interaction

Move the mouse around the page to interact with nearby particles.

Click **Explore Network** to increase the interaction radius.

## Technologies

- HTML5
- CSS3
- JavaScript
- Canvas API
