# Animated Pagination with Gradient styling (#78852)

A responsive pagination component featuring continuous vibrant linear gradient fills, ambient shadow glows, and spring hover scaling animations built using pure CSS.

## Features
- **Semantic & Accessible Navigation:** Structured with `<nav>`, `<ul>`, `<a>` controls, `aria-label`, and `aria-current="page"` linkage.
- **Vibrant Gradient Effects:** Layered CSS linear gradients with opacity transitions and ambient drop-shadow glows.
- **Spring Scale Transitions:** GPU-accelerated cubic-bezier hover and active button state dynamics.

## File Hierarchy
- `style.css` - Custom gradient variables, pagination item alignment, active page glows, and media query responsiveness.
- `demo.html` - Semantic HTML structure showcasing page controls.
- `README.md` - Technical specification and architecture overview.
