# Synthwave Grid Line Form

Implementation for EaseMotion issue #73365.

## Features

- Pure HTML and vanilla CSS
- Perspective grid made from repeating gradients
- Neon cyan and magenta accents
- Responsive form layout
- Visible focus states
- Reduced-motion support

The grid is decorative and sits behind the semantic form. No image assets or JavaScript are required.

Open `demo.html` to preview the component and adjust the grid size, colors, or animation duration in `style.css`.
