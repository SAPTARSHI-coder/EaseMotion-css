Typography Specifications

⏱️

CSS Custom Variables

Uses inline CSS custom properties (`--i: index`) to calculate proportional staggered keyframe delays (`calc(var(--i) * 0.06s)`).

🎯

Tactile Hover Wiggle

Individual `.char:hover` pseudoclass triggers elastic spring keyframes with dynamic text-shadow glow reflections.

🧊

3D Perspective Tilt

Leverages CSS `perspective: 1000px` and `rotateX` / `rotateY` transforms for realistic 3D letter rotations.

♿

Accessible & Responsive

Preserves screen-reader accessibility via `aria-label` attributes on parent titles and disables motion for reduced-motion settings.
