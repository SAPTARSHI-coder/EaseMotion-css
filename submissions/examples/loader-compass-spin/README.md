# Loader Compass Spin

A compass needle spins while the dial rotates opposite.

## Features
- Needle + dial counter-rotation
- Cardinal ticks
- Glow point
- Pure CSS

## Usage
```html
<div class="lcs-needle"></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
