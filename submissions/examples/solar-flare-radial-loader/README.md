# Solar Flare Radial Loader

A smooth, accessible, and performant pure CSS loader featuring Solar Flare Radial styling.

## Usage

```html
<div class="solar-flare-loader" role="status" aria-label="Loading">
    <div class="flare flare-1"></div>
    <div class="flare flare-2"></div>
    <div class="flare flare-3"></div>
    <div class="core"></div>
</div>
```

## Why is it useful?

This loader provides a visually engaging, dark-mode compatible loading indicator utilizing hardware acceleration for smooth rendering, aligning perfectly with EaseMotion's philosophy of performant and accessible design.
