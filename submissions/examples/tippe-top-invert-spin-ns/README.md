# Tippe Top Invert Spin (#71067)

A classic tippe-top physical toy simulation featuring high-speed 3D angular spin, friction wobble, and mid-cycle inversion onto its central stem.

## Features
- Pure CSS 3D transformation sequence (`preserve-3d`, `rotateX`, `rotateY`, `translateY`).
- Dynamic shadow feedback reflecting vertical elevation during inversion.
- Human-readable BEM class hierarchy (`ease-tippe-top-invert-spin`).
- Accessible decoration (`aria-hidden="true"`).
- Gracefully disables motion when `prefers-reduced-motion` is enabled.
