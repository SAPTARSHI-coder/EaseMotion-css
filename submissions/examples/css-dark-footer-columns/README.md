# CSS Dark Footer with Columns

A responsive 4-column dark footer component with visual dividers and smooth link hover interactions built with pure CSS.

## 🌟 Features
- **Responsive Layout:** Automatically collapses from 4 columns to 2 columns and single-column on mobile devices using CSS Grid.
- **Pure CSS Motion:** Smooth shift effect on link hover/focus state.
- **Accessible Design:** Uses semantic `<footer>` element with explicit high-contrast text ratios.

## 📁 Files
- `demo.html` - Interactive footer layout with 4 columns.
- `style.css` - Dark theme styling, grid system, and media queries.
