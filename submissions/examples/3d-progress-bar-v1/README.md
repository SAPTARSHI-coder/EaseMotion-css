# 3D Progress Bar

A modern, responsive 3D Progress Bar with gradient styling built using pure HTML and CSS.

## ✨ Features

- Fully responsive
- CSS-only component
- 3D depth effect
- Gradient progress indicator
- Animated loading effect
- Animated shine effect
- Glass-style container
- Accessible progressbar attributes
- Mobile-friendly
- Reduced-motion support
- No external dependencies
