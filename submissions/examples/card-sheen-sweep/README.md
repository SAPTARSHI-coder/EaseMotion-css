# Card Sheen Sweep

A glossy sheen sweeps diagonally across a card on hover.

## Features
- Diagonal light sweep
- Skewed beam edge
- Wraps rounded corners
- Pure CSS

## Usage
```html
<div class="css-card">...</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
