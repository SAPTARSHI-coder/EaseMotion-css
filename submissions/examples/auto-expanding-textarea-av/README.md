# Auto-expanding Textarea UI

## What does this do?

Creates a modern textarea interface with a premium composition area, floating toolbar, and responsive layout.

---

## How is it used?

Open `demo.html` directly in a browser.

```html
<div class="composer">

    <textarea></textarea>

</div>
```

---

## Why is it useful?

Text composition interfaces are widely used in messaging apps, contact forms, comment sections, feedback portals, and note-taking tools. This standalone example demonstrates a polished textarea UI using only HTML and CSS. JavaScript can be added later to implement automatic height expansion if required.
