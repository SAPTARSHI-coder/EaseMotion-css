# 3D Button with Glassmorphism styling (#78876)

A tactile, responsive 3D button component combining frosted glassmorphic backdrop blur and multi-layered extruded depth effects built using pure CSS.

## Features
- **Semantic & Accessible Structure:** Clean `<button>` element implementation with focus indicators and proper ARIA container roles.
- **Glassmorphism Aesthetic:** Semi-transparent background fills paired with native `backdrop-filter: blur()`.
- **Dimensional 3D Press Effect:** Multi-layered CSS `box-shadow` depth combined with `transform: translateY()` feedback on state triggers (`:hover`, `:active`).

## File Hierarchy
- `style.css` - Component variables, backdrop blur attributes, and 3D shadow extrusion logic.
- `demo.html` - Semantic HTML structure showcasing the 3D button trigger.
- `README.md` - Technical specification and usage guidelines.
