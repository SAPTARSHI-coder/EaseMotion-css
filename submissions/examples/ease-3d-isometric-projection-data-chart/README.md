# Ease 3D Isometric Projection Data Dashboard Chart

An interactive, responsive 3D isometric projection data dashboard chart built using pure HTML5, modern CSS3 (3D Transforms & Custom Properties), and vanilla JavaScript.

## Features

- **Isometric 3D Perspective**: Utilizes `transform: rotateX(60deg) rotateZ(-45deg)` with `preserve-3d` CSS context for realistic depth.
- **Dynamic Growth Animations**: Smooth vertical growth animation on initial load and dataset changes.
- **Interactive Elevation & Reflections**: Elevated hover states with real-time top-face reflections and projected drop shadows.
- **Floating Tooltip**: Precise cursor-tracking tooltip displaying dynamic metrics and comparison data.
- **Responsive Layout**: Fluid viewport scaling adapted for desktop, tablet, and mobile displays.
- **Zero External Dependencies**: Pure vanilla HTML, CSS, and JS.
