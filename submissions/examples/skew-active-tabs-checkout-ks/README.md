# Skew-Active Tabs for E-Commerce Checkout Layouts

A beautiful, modern, and highly responsive checkout progress tab layout built with pure HTML and CSS. Features a dynamic skew effect on the active state and glassmorphism design.

## 🚀 Features

- Pure HTML and CSS implementation
- Dynamic CSS skew (`skewX`) on active tabs
- Glassmorphism design system
- Smooth hover and focus transitions
- `prefers-reduced-motion` support
- Fully responsive layout
- Accessible markup

## 📁 File Structure

- `demo.html` - The HTML structure
- `style.css` - The styles and animations
- `README.md` - Documentation

## 🛠️ Usage

Simply open `demo.html` in any modern web browser to see the animation in action. You can easily integrate the `.checkout-tabs` component into your own projects by copying the relevant HTML and CSS.

## 🌐 Browser Support

Works in all modern browsers (Chrome, Edge, Firefox, Safari).
