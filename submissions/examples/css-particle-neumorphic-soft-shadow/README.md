# CSS Particle Effect: Neumorphic Soft Shadow

A pure CSS particle effect featuring floating particles with a soft neumorphic shadow style.

## Features

- Pure HTML and Vanilla CSS
- No external JavaScript
- Smooth floating particle animations
- Neumorphic soft-shadow styling
- Dark mode support
- Responsive design
- Hardware-accelerated transforms
- Reduced-motion accessibility support

## Files

- `demo.html` — Particle effect demo
- `style.css` — Component styles and animations
- `README.md` — Documentation

## Accessibility

Decorative particles use `aria-hidden="true"` and the animation respects the user's `prefers-reduced-motion` preference.
