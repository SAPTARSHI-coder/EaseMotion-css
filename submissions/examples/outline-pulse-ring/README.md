# Outline Pulse Ring

## Overview

A pure HTML and CSS example demonstrating an animated outline pulse ring effect. The expanding outline draws attention to interactive elements such as buttons, icons, avatars, and call-to-action components.

## Features

- Animated outline pulse effect
- Pure HTML & CSS
- Smooth animation
- Responsive layout
- Accessible with `prefers-reduced-motion`
- No JavaScript required

## Files

- `demo.html`
- `style.css`
- `README.md`

## Usage

Open `demo.html` in any modern browser to preview the animation.

## Browser Support

- Chrome
- Firefox
- Edge
- Safari
