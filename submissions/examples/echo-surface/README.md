# Echo Surface

Echo Surface is an experimental motion-driven UI component that transforms
pointer movement into temporary visual traces.

Instead of displaying a conventional cursor trail, the component interprets
movement as data and creates geometric "echoes" based on:

- Speed
- Direction
- Distance
- Direction changes

The interface effectively creates a temporary memory of how the user moved
through the surface.

## ✨ Features

- Real-time pointer tracking
- Movement sampling
- Distance calculation
- Speed calculation
- Direction calculation
- Direction-change detection
- Dynamic geometric echoes
- Speed-dependent echo length
- Direction-dependent echo rotation
- Temporary fading traces
- Movement classification
- Live motion statistics
- Session timer
- Clear-memory functionality
- Responsive layout
- Touch and stylus compatibility
- Reduced-motion support
- No external JavaScript dependencies
