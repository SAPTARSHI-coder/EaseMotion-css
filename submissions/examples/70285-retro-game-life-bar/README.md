# CSS Retro Game Life Bar

A retro video-game inspired life bar component built entirely with
HTML5 and Vanilla CSS.

## ✨ Features

- Classic arcade-style health bar
- Segmented green life indicator
- Heart-based health indicators
- Player avatar built with CSS
- Player statistics cards
- Healthy, warning, and critical state indicators
- Smooth CSS animations
- Responsive layout
- Dark-mode compatible
- Reduced-motion support
- No JavaScript
- No external dependencies

## 🎮 Visual Elements

The component demonstrates:

- Player name and stage indicator
- Large percentage-based life bar
- Heart health indicators
- Attack statistic
- Defense statistic
- XP statistic
- Remaining lives
- Health-state legend

## ❤️ Life Bar

The main health indicator combines:

- Segmented progress fill
- Bright green health color
- Subtle animated pulse
- Moving highlight
- Numeric percentage
- Heart indicators

The current demo represents an `80%` health state.

## ♿ Accessibility

The component includes:

- Semantic HTML
- Accessible section headings
- `role="progressbar"` for the health bar
- `aria-label`
- `aria-valuemin`
- `aria-valuemax`
- `aria-valuenow`
- Reduced-motion support

## 📱 Responsive Design

The layout adapts to smaller screens.

The main character and life-bar sections stack vertically,
statistics move into fewer columns, and heart indicators wrap
into multiple rows.

## ⚡ Performance

All animation effects are implemented using CSS.

No JavaScript animation loops or external libraries are required.

## 🛠️ Technologies

- HTML5
- Vanilla CSS
