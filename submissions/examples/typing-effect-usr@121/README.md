# Animated Text Typing Effect Submission

## 1. What does this do?
It provides a beautiful, animated text typing effect component that displays text character-by-character with cursor animation, multiple phrase rotation, and smooth delete effects. Perfect for hero sections, landing pages, and creative portfolios.

## 2. How is it used?
Wrap your text in a `.typing-wrapper` with `.typing-text` span and `.typing-cursor` span. Initialize the TypingEffect class with phrases array and options. Customize typing speed, cursor style, colors, and add custom phrases dynamically.

## 3. Why is it useful?
- Essential component for hero sections and landing pages
- Realistic character-by-character typing with natural speed variations
- Multiple phrase rotation with smooth transitions
- Customizable typing speed (slow, normal, fast)
- Multiple cursor styles (line, block, underline)
- Color theme options (gradient, blue, green, purple)
- Add custom phrases dynamically
- Smooth delete/backspace effect
- Blinking cursor animation
- Fully responsive design
- Accessible with `prefers-reduced-motion` support
- Easy to integrate and customize
- Maintainer can easily standardize this as `.ease-typing-[YOUR_INITIALS]` in the core library.
