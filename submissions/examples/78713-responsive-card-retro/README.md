# Responsive Card with Retro Styling

A responsive retro-inspired card component built with pure HTML and
CSS. The design combines vintage arcade aesthetics, bold borders,
synthwave-inspired visuals, and responsive layouts.

## Features

- Pure HTML and CSS
- No JavaScript dependency
- Retro visual design
- Synthwave-inspired gradient artwork
- Pixel-inspired grid effect
- Vintage typography
- Bold offset shadows
- Interactive hover effects
- Responsive desktop, tablet, and mobile layouts
- Accessible focus state
- Reduced-motion support

## Files

- `demo.html` — component structure and demonstration
- `style.css` — complete styling, responsive behavior, and animations
