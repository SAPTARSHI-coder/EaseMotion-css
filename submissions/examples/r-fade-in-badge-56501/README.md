# CSS Fade-In Badge

A modern **Fade-In Badge** component built using pure HTML5 and CSS3 for Gaming Hub layouts. The badges smoothly fade into view while remaining lightweight, responsive, and accessible.

---

## ✨ Features

- Pure HTML5 & CSS3
- Smooth fade-in animation
- Gaming-themed badge cards
- Responsive grid layout
- CSS Custom Properties
- Lightweight and performant
- Accessible semantic HTML
- `prefers-reduced-motion` support
- No JavaScript required

## 🚀 Usage

1. Copy the component into your project.
2. Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

3. Open `demo.html` in any modern browser.
