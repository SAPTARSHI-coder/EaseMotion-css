# Type Slug Compose

## What does this do?
Renders a self-contained CSS-only `ease-type-slug-compose` demo: Type slug composing then justifying a line.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-type-slug-compose`. No build step or JavaScript is required for the effect.

```html
<section class="ease-type-slug-compose">
  <div class="ease-type-slug-compose__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
