# Spotlight Command Palette

A modern **CSS-only Spotlight Command Palette** inspired by applications like GitHub, Linear, Raycast, and VS Code.

## ✨ Features

- Glassmorphism design
- Smooth fade and scale animation
- Responsive layout
- Hover animation for command items
- Keyboard shortcut badge
- Pure HTML & CSS
- No JavaScript required

## 📁 Folder Structure

```
spotlight-command-palette/
├── demo.html
├── style.css
└── README.md
```

## 🚀 Usage

1. Open `demo.html` in any modern browser.
2. Ensure `style.css` is in the same folder.
3. Customize colors, spacing, or commands as needed.

## 📸 Preview

The component displays a floating command palette with:

- Search input
- Keyboard shortcut badge
- Animated command list
- Glassmorphism effect
- Smooth hover interactions

## 🛠 Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Animations
- Glassmorphism UI
