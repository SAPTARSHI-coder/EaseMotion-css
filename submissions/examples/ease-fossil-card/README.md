# 🦴 Fossil Card – Reveals Hidden Texture Like Fossil Excavation

> An archaeological card that reveals a hidden fossil texture on hover, creating a discovery-themed experience like excavating a fossil.

---

## 📖 Description

The **Fossil Card** is an archaeological-themed UI component that reveals a hidden fossil texture on hover. When you hover over the card, bone-like shapes emerge from the surface with a rotating, scaling animation, while dust particles scatter like dirt being brushed away from a fossil excavation. The card content fades slightly to reveal the hidden fossil layer beneath.

The component uses CSS animations with `transform` and `keyframes` to create the bone reveal and particle burst effects. Each bone has a unique size, position, and animation delay, creating an organic excavation feel. The dust particles add to the archaeological theme, mimicking the process of carefully uncovering a fossil.

Perfect for museum websites, archaeological themes, educational content, and any application where you want to create a discovery-themed, interactive experience. The Fossil Card transforms a simple card into an engaging archaeological dig.
