# Hydraulic Ram Pulse

## What does this do?
Renders a self-contained CSS-only `ease-hydraulic-ram-pulse` demo: Hydraulic ram delivering intermittent lift pulses.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-hydraulic-ram-pulse`. No build step or JavaScript is required for the effect.

```html
<section class="ease-hydraulic-ram-pulse">
  <div class="ease-hydraulic-ram-pulse__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
