# Ease Divider Text

## What does this do?

A horizontal divider component with centered text for separating sections such as **OR**, **Continue**, or category labels.

---

## How is it used?

Open `demo.html` in any modern browser.

Example:

```html
<div class="divider">
    <span>OR</span>
</div>
```

Variants included:

- Default
- Primary
- Gradient

---

## Why is it useful?

Divider text components are frequently used in authentication forms, onboarding screens, landing pages, and content sections. This lightweight component provides a clean, reusable way to visually separate content while matching EaseMotion CSS's animation-first philosophy.
