# Neumorphic Spinner with Retro Styling (#78594)

A retro-styled neumorphic loading spinner component featuring soft dual-shadow extrusion effects, inset track framing, and amber accent rotation.

## Features
- **Neumorphic Soft UI:** Extruded surface cards combined with inset track depth shadows using precise light/dark offsets.
- **Smooth Rotation:** Keyframe rotation animation paired with custom easing curves and amber spinner rings.
- **Fully Responsive:** Fluid card container scaling cleanly across desktop and mobile viewports.

## File Hierarchy
- `style.css` - Custom properties, neumorphic shadow tokens, spin keyframes, and media queries.
- `demo.html` - Semantic markup demonstrating spinner integration with ARIA accessibility roles.
- `README.md` - Technical specification and architecture overview.
