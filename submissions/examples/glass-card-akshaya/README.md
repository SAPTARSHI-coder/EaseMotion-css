# Glassmorphism Card Component

A reusable glassmorphism card component for EaseMotion CSS.

This component provides a modern frosted-glass surface using
`backdrop-filter`, translucent backgrounds, semi-transparent borders,
and a subtle hover lift effect.

## Features

- Glassmorphism effect using `backdrop-filter: blur()`
- Graceful fallback when `backdrop-filter` is unavailable
- Safari support using `-webkit-backdrop-filter`
- Small, medium, and large size variants
- Dark glass variant
- Smooth hover lift animation
- CSS custom properties for customization
- Responsive layout
- Reduced-motion accessibility support
- No JavaScript dependencies
