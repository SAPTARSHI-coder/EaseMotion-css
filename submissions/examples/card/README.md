# Responsive Stat Metric Card — Cyberpunk

A responsive stat/metric card component built using pure CSS with a cyberpunk-inspired visual style.

## Features

- Pure HTML + CSS
- Zero JavaScript dependencies
- Responsive mobile, tablet and desktop layouts
- Cyberpunk-inspired UI
- EaseMotion CSS variables and design tokens
- Smooth hover and focus transitions
- Positive and negative metric states
- Keyboard-friendly focus behavior
- `prefers-reduced-motion` support
- Semantic HTML
- No external libraries required
