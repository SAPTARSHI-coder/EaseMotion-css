# Interactive Filter Bar — Retro Pixel

A CSS-only interactive filter bar inspired by retro arcade
interfaces and pixel-based game UI.

Built for EaseMotion CSS issue #81468.

## Features

- Retro pixel-inspired visual design
- CSS-only filter interactions
- Category radio filters
- Checkbox-based flags
- Search field
- Sort selector
- Reset button styling
- Neon green, pink and yellow accents
- Pixel-style hard shadows
- CRT scanline effect
- Background pixel grid
- Glowing active states
- Hover transitions
- Resource preview cards
- Responsive layout
- Keyboard focus states
- Reduced-motion support
- Zero JavaScript dependencies
