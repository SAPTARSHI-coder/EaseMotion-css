Basic Status Filter Row

Simple filter rows for dashboard lists.

A CSS-only row component for showing filter name, item count, scope, and selected, active, or archived state.

ALL
All items

Shows every item across active and archived states.

248 Global Selected
ON
Active items

Shows only currently active records in the workspace.

214 Live Active
AR
Archived items

Shows items hidden from the default dashboard view.

34 Stored Archived

HTML Usage

<article class="basic-status-filter-row">
  <span class="filter-mark is-selected" aria-hidden="true">ALL</span>
  <div class="filter-copy">
    <strong>All items</strong>
    <p>Shows every item across active and archived states.</p>
  </div>
  <span class="filter-count">248</span>
  <span class="filter-scope">Global</span>
  <span class="filter-state is-selected">Selected</span>
</article>
