# Interactive Tooltip with Neumorphism Styling

A responsive interactive tooltip component built with HTML and CSS,
using a soft neumorphic visual style.

## Features

- Fully responsive
- HTML and CSS only
- No JavaScript
- Interactive hover tooltips
- Keyboard-friendly focus states
- Soft neumorphic shadows
- Multiple tooltip variants
- Smooth CSS transitions
- Responsive mobile layout
- Reduced-motion support

## Files

- `demo.html`
- `style.css`

## Interaction

Hover or focus the Dashboard, Analytics, or Settings controls to
reveal their contextual tooltips.

## Design

The component uses:

- Soft light-gray surfaces
- Raised and inset neumorphic shadows
- Rounded controls
- Subtle blue, purple, and green accents
- Smooth hover elevation
- Floating contextual hints

## Technologies

- HTML5
- CSS3
