Floating Elevation Accordion

A responsive, accessible accordion built with semantic HTML and pure CSS.

01 What is CSS-only accordion?

A CSS-only accordion uses semantic HTML elements and CSS transitions to reveal and hide content without JavaScript.

02 Does it require JavaScript?

No. The interaction is powered entirely by the native HTML details and summary elements.

03 Is it responsive?

Yes. The component adapts to smaller screens while maintaining comfortable spacing and readable typography.

04 Does it support dark mode?

Yes. The design automatically follows the user's preferred color scheme through the prefers-color-scheme media query.
