# CSS Accordion — Floating Elevation

A responsive and accessible CSS-only accordion featuring a floating
elevation interaction, smooth transitions, and automatic dark-mode support.

## ✨ Features

- Pure HTML and CSS
- No JavaScript
- Native `<details>` / `<summary>` interaction
- Floating elevation effect
- Smooth content expansion
- Responsive design
- Dark mode support
- Keyboard accessible
- `prefers-reduced-motion` support
- Hardware-friendly CSS transforms
- No external dependencies
