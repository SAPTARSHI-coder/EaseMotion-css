# Ease Audio Spectrum

A lightweight animated audio spectrum visualizer built using HTML, CSS, and JavaScript.

## Features

- 🎵 Animated audio spectrum bars
- ▶️ Play / Pause animation
- 🎨 Multiple color themes
- 📱 Responsive layout
- ⚡ Smooth CSS animations

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

## Folder Structure

```
ease-audio-spectrum/
│── demo.html
│── style.css
│── script.js
└── README.md
```

## Usage

1. Open `demo.html` in a web browser.
2. Click the **Play/Pause** button to start or stop the animation.
3. Select a theme from the dropdown.
