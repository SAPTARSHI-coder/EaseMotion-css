# Glowing Navbar Cyberpunk

A fully responsive, cyberpunk-themed navigation bar featuring neon glowing effects, custom clip-paths, and interactive hover animations.

## Usage

```html
<nav class="cyberpunk-navbar">
    <div class="logo">NEON_CITY</div>
    <ul class="nav-links">
        <li><a href="#" class="nav-item">HOME</a></li>
        <li><a href="#" class="nav-item">ABOUT</a></li>
        <li><a href="#" class="nav-item">SERVICES</a></li>
        <li><a href="#" class="nav-item">CONTACT</a></li>
    </ul>
    <button class="nav-btn">LOGIN</button>
</nav>
```

## Why it's useful

This component provides a high-energy, futuristic navigation aesthetic perfect for gaming sites, Web3 platforms, or tech portfolios, fitting perfectly with EaseMotion's dynamic and bold animation philosophy.
