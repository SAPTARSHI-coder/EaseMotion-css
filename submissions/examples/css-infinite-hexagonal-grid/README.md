# CSS Infinite Hexagonal Grid

A mathematically tessellated background pattern using cleverly overlapping linear-gradient triangles and angles to simulate an infinite geometric honeycomb grid.

## Features

- Pure HTML and CSS
- No JavaScript required
- No SVGs or external images; 100% CSS gradients
- Smooth infinite scrolling animation using background gradients
- Radial gradient mask to fade the edges seamlessly
- Glassmorphism content card layered on top
- Responsive across desktop, tablet, and mobile
