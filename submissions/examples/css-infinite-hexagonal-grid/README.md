# CSS Infinite Hexagonal Grid

A modern animated infinite hexagonal (honeycomb) background built entirely with HTML and CSS using layered linear gradients.

## Features

- Infinite tessellated hexagonal pattern
- Pure CSS (No JavaScript)
- Animated grid movement
- Soft glowing lighting effect
- Glassmorphism content card
- Responsive design
- Hardware accelerated animations
- Dark mode compatible

## Files

```
css-infinite-hexagonal-grid/
```

## Usage

Open `demo.html` in any modern browser.
