# 🌪️ Tornado Card – Spins with a Whirlwind Effect

> A dramatic card that spins with a whirlwind effect on hover, creating a swirling, tornado-like motion with flying particles.

---

## 📖 Description

The **Tornado Card** is a dramatic UI component that spins with a whirlwind effect on hover. The card tilts in 3D space while colorful particles swirl around it like debris in a tornado. The effect creates a powerful, energetic visual experience that mimics the raw power of a tornado.

The component uses CSS 3D transforms and keyframe animations to create the spinning card and swirling particles. Each particle has a unique color, size, and trajectory, flying outward in different directions with staggered delays. The card also features a subtle shine effect and animated icons for added impact.

Perfect for weather-themed interfaces, gaming websites, creative portfolios, and any application where you want to create a dramatic, energetic interaction. The Tornado Card transforms a simple card into a powerful, swirling experience.
