# Responsive Hero Section - Pastel

A responsive hero section featuring a soft pastel visual design, subtle gradients, floating decorative elements, and smooth CSS interactions.

## ✨ Features

- Responsive hero layout
- Pastel color palette
- Modern gradient typography
- Animated decorative background orbs
- Floating glass-style information pills
- Interactive CTA buttons
- CSS-only visual dashboard
- Responsive mobile, tablet, and desktop layouts
- Keyboard-accessible links
- Visible focus states
- `prefers-reduced-motion` support
- No JavaScript dependencies
