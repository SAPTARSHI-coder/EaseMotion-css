# CSS Grid Magnetic Button

A button that simulates JS cursor-tracking magnetic physics utilizing purely CSS!

## Features
- Faked magnetic physics generated by an invisible 3x3 `grid` overlaying the button container.
- Physics calculations mapped using the general sibling combinator `~` to shift the `.mag-btn` translation coordinates towards whichever grid square is currently being hovered.
- Tactile, snappy feedback provided by an aggressive `cubic-bezier` transition curve.
