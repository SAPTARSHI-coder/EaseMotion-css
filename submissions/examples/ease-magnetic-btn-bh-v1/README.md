# ease-magnetic-btn-bh

Pure CSS magnetic button pull effect with hover attraction.

## What does this do?
Creates a magnetic attraction effect on buttons where the button subtly moves toward the cursor on hover.

## How is it used?
```html
<button class="ease-magnetic-btn-bh">Hover Me</button>
```

## Why is it useful?
Adds an engaging interactive effect that makes buttons feel responsive and alive, improving user experience.
