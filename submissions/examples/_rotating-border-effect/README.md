This contribution adds a Rotating Border Effect to the submissions/examples/_rotating-border-effect directory.

Included File:
1. demo.html
2. style.css
3. README.md

Features
🔄 Continuously rotating border
🌈 conic-gradient() creates the moving color effect
💡 Neon-style cyan, purple, and pink colors
🪟 Dark inner card
🎨 Rounded corners
⚡ Pure HTML + CSS
🚫 No JavaScript
🔧 Easy to customize animation speed
📱 Responsive-friendly
