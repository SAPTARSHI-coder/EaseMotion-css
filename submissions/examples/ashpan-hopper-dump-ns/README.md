# Ashpan Hopper Dump

## What does this do?
Renders a self-contained CSS-only `ease-ashpan-hopper-dump` demo: Ashpan hopper dumping firebed ash.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-ashpan-hopper-dump`. No build step or JavaScript is required for the effect.

```html
<section class="ease-ashpan-hopper-dump">
  <div class="ease-ashpan-hopper-dump__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
