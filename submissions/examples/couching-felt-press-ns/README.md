# Couching Felt Press

## What does this do?
Renders a self-contained CSS-only `ease-couching-felt-press` demo: Couching felt press squeezing water from the post.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-couching-felt-press`. No build step or JavaScript is required for the effect.

```html
<section class="ease-couching-felt-press">
  <div class="ease-couching-felt-press__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
