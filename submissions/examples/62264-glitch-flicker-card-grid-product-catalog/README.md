# CSS Glitch-Flicker Card Grid for Product Catalog Layouts

A futuristic **Glitch-Flicker Card Grid** built using only HTML and CSS. Product cards feature a subtle glitch distortion, flicker overlay, image zoom, and sweeping light animation on hover to create a modern cyber-inspired catalog.

---

## Features

- Pure HTML & CSS
- Glitch Flicker hover animation
- Sweep light effect
- Image zoom interaction
- Responsive card grid
- CSS Custom Properties
- Smooth transitions
- No JavaScript required
- prefers-reduced-motion support
- Cross-browser compatible
