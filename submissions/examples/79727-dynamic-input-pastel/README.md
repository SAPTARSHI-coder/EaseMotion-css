# Dynamic Input Field — Pastel

A responsive dynamic input field component with a soft pastel visual
system, smooth focus interactions, floating decorative elements, and
accessible form structure.

Implemented for EaseMotion CSS issue #79727.

## Features

- Pastel-themed modern UI
- Responsive form layout
- Smooth hover interactions
- Focus-within animations
- Animated decorative background blobs
- Custom input indicators
- Text input, email input, and textarea
- Responsive submit button
- Keyboard focus support
- `prefers-reduced-motion` support
- Semantic HTML labels
- Pure HTML and CSS
- No JavaScript dependencies
- No external libraries
