# Subtle Elevate Tabs

A modern pure CSS tabs and segmented control featuring a clean **Subtle Elevate** style with smooth interactions and a softly elevated active state.

## Features

- Pure HTML & CSS
- Subtle elevate active tab effect
- Smooth CSS transitions
- Responsive segmented control
- Dark mode compatible
- Hardware-accelerated animations
- Accessible radio-button implementation
- No JavaScript required

- `demo.html`
- `style.css`
