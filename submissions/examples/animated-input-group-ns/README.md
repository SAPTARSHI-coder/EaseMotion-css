# CSS Animated Input Group (#71045)

A pure CSS input group component featuring prepended/appended addons with animated focus rings, smooth label emphasis, and icon transformations.

## Features
- Pure CSS `:focus-within` state handling for seamless input group container highlighting.
- Animated addon background shift, border-color matching, and icon scaling/rotation.
- Supports both prepended icons/symbols and appended text/action buttons.
- Standardized BEM structure (`ease-input-group`).
- Accessible keyboard focus states, ARIA associations (`aria-describedby`), and `prefers-reduced-motion` safety overrides.
