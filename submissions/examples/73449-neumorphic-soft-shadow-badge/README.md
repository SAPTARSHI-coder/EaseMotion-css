# Neumorphic Soft Shadow Badge

A soft and tactile CSS badge variation inspired by neumorphic UI design.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript
- Soft neumorphic shadows
- Elevated and pressed states
- Multiple badge variants
- Smooth hover interactions
- Dark mode compatible
- Responsive design
- Reduced-motion support
- Accessible semantic structure

## Badge Variants

The demo includes:

- Available
- Verified
- Pending
- Offline
- Featured

## Technologies

- HTML5
- CSS3
- CSS Box Shadows
- CSS Transitions
- CSS Media Queries
- CSS `color-mix()`

## Usage

Open `demo.html` in a modern browser.

The component can be reused with the following structure:

```html
<span class="badge badge-success">
  <span class="badge-dot"></span>
  Verified
</span>
