# Bounce-Pulse Dropdown for Gaming Hub

A lightweight, responsive gaming dropdown component built with pure HTML and CSS.

## Features

- Pure HTML and CSS
- No JavaScript or external frameworks
- Smooth dropdown entrance animation
- Bounce-pulse interaction on gaming icons
- Hover and keyboard focus states
- Responsive layout for desktop, tablet, and mobile
- CSS custom properties for easy customization
- `prefers-reduced-motion` accessibility support
- Suitable for gaming dashboards and hub interfaces
