# ☀️ Solar Flare Radial Progress

A smooth and modern radial progress indicator inspired by the visual energy of a solar flare.

Built using **pure HTML and vanilla CSS** with no JavaScript or external dependencies.

## ✨ Features

- Radial progress indicator
- Solar flare glow effect
- Animated conic-gradient
- Glassmorphism-inspired container
- Smooth CSS animations
- Hardware-friendly transforms
- Dark-mode friendly design
- Responsive layout
- Accessible progressbar semantics
- `prefers-reduced-motion` support
- No JavaScript
- No external libraries
