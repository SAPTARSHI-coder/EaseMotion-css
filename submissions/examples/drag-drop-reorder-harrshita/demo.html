Drag and Drop Reorder

Reorder list items using native HTML5 Drag and Drop. Smooth CSS transitions animate each swap.

Live Demo

Drag any item by the handle (☰) and drop it into a new position.

Usage

<ul class="ease-dnd-list" id="myList">
  <li class="ease-dnd-item" draggable="true">
    <span class="ease-dnd-handle">&#9776;</span>
    <span class="ease-dnd-label">Item content</span>
  </li>
</ul>

<link rel="stylesheet" href="style.css" />
<script src="drag-drop.js"></script>

CSS Classes Reference

Class Element Description

.ease-dnd-item<li>Draggable list item

.ease-dnd-badge<span>Optional category badge
.ease-dnd-item--dragging<li>Applied while item is being dragged
