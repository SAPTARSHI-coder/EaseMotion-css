# CSS Glowing Ring Loader

A loading animation consisting of overlapping, spinning neon rings utilizing complex `box-shadow` glows and offset rotations.

## Features
- Multi-layered border spinning via `transform: rotate`
- Intense neon glows via `box-shadow`
- Bi-directional spinning utilizing `animation-direction: reverse`
- Pulsing inner core
