# CSS Glitch-Flicker Dropdown for Minimalist Tech Layouts

## Overview

This project adds a modern **Glitch-Flicker Dropdown** component built using pure HTML and CSS.

It provides a futuristic dropdown UI suitable for:
- Tech websites
- Product catalogs
- SaaS dashboards
- Developer platforms

No JavaScript or external libraries are required.

---

## Features

- ⚡ Pure HTML & CSS implementation
- 🎨 Glitch flicker hover animation
- ✨ Smooth dropdown reveal effect
- 📱 Fully responsive design
- 🚀 Lightweight and performance friendly
- ♿ Supports `prefers-reduced-motion`
- 🌐 Easy integration with existing layouts
