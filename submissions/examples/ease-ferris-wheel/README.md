# Ferris Wheel · Wheel Turns with Interaction 🎡

An interactive Ferris wheel with realistic rotation, glowing cabins, and a city skyline background. Start the wheel and watch the cabins rotate!

## Features

- 🎡 **Ferris Wheel** – Realistic wheel with cabins
- ▶️ **Start/Stop** – Control the rotation
- 🎚️ **Speed Control** – Adjust rotation speed (1-10)
- 🎚️ **Cabin Count** – Choose 6-16 cabins (even numbers)
- 📊 **Rotation Counter** – Tracks full rotations
- 📊 **RPM Display** – Real-time speed readout
- ⏸️ **Pause/Resume** – Toggle animation
- 🔄 **Reset** – Reset to starting position
- 🌃 **City Skyline** – Night city background

## How to Use

1. Click **START** or press **Space** to start the wheel
2. Click **STOP** or press **Space** again to stop
3. Adjust **Speed** for rotation speed
4. Adjust **Cabins** for number of cabins
5. Press **RESET** or **R** to reset
6. Press **PAUSE** or **P** to pause/resume animation

## Controls

| Action | Method |

## Technical Details

- **Rotation:** Angular velocity with speed control
- **Rendering:** Detailed wheel with cabins
- **Controls:** Real-time parameter adjustment
- **Performance:** 60fps with requestAnimationFrame

## Customization

You can easily customize:
- **Speed:** Modify slider range (1-10)
- **Cabins:** Modify slider range (6-16)
- **Wheel Size:** Adjust radius (150)
- **Colors:** Modify wheel and cabin colors
- **Skyline:** Add/remove buildings
