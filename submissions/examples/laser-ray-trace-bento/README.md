# Laser Ray Trace Bento Card

A futuristic CSS-only bento card layout featuring a Laser Ray Trace visual style.

## Features

- Pure HTML and Vanilla CSS
- Animated laser ray traces
- Futuristic sci-fi visual design
- Responsive bento grid
- Smooth hover elevation
- Dark-mode friendly design
- Hardware-friendly CSS animations
- No JavaScript or external dependencies
- `prefers-reduced-motion` support

## Demo

Open `demo.html` directly in any modern browser.

No server or build process is required.
