# Elastic-Slide Badge

A lightweight, pure CSS Elastic-Slide Badge designed for modern fintech
dashboard layouts.

The component combines a horizontal slide entrance with a subtle elastic
overshoot effect. It requires no JavaScript or external dependencies.

## Features

- Pure HTML and CSS
- No JavaScript
- No external libraries
- Elastic slide entrance animation
- Success, warning, danger, and information variants
- CSS custom properties
- Hover and focus interaction
- Responsive design
- `prefers-reduced-motion` support
- Suitable for fintech and SaaS dashboards
