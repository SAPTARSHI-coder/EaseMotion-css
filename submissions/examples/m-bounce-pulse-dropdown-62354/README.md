# CSS Bounce-Pulse Dropdown for Product Catalog Layouts

A modern dropdown component featuring a bounce-opening animation and pulse button interaction built entirely with HTML and CSS. Ideal for product catalog navigation menus.

## ✨ Features

- Pure HTML5 & CSS3
- Bounce opening animation
- Pulse hover button effect
- Responsive layout
- CSS Custom Properties
- Keyboard accessible using `:focus-within`
- `prefers-reduced-motion` support
- No JavaScript required
