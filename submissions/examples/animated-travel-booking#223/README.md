# Animated Travel Booking App

A beautiful **Travel Booking Interface** built with **EaseMotion CSS**. Features destination cards with image zoom, flight search with route visualization, hotel listings, floating clouds animation, and a comprehensive search form.

## ✨ Features

- **✈️ Flight Search**: Multi-field search card with tabs and swap button
- **🌍 Destination Cards**: 4 destination cards with image hover zoom and badges
- **🛫 Flight Deals**: Route visualization with animated plane icon
- **🏨 Hotel Listings**: Cards with amenities, ratings, and booking buttons
- **☁️ Floating Clouds**: Ambient background clouds animation
- **📊 Stats Banner**: Gradient banner with travel statistics
- **🎬 Staggered Entrance**: All sections slide up sequentially
- **📱 Fully Responsive**: Multi-column to single column adaptation

## 🧩 EaseMotion Classes Used

| Class | Purpose |
|-------|---------|
| `ease-fade-in` | Fades in the main page and footer |
| `ease-slide-up` | Slides sections up on entrance |
| `ease-delay-100` to `ease-delay-700` | Creates cascading staggered sequence |
| `ease-card` | Base card structure |
| `ease-hover-lift` | Lift effect on all cards |
| `ease-hover-grow` | Scale effect on buttons and avatars |
| `ease-center` | Centers swap button icon |
| `ease-grid` + `ease-grid-cols-*` | Responsive grid layouts |
| `ease-gap-4` | Spacing between grid items |
| `ease-btn` + `ease-btn-primary` | Styled search and book buttons |
| `ease-pulse` | **Looping pulse** on deals badge |

## 🚀 How to Use

1. Open `demo.html` in any modern browser
2. Watch all sections slide in with staggered animations
3. Hover over destination cards to see image zoom effect
4. Observe the **animated plane icon** flying on the route path
5. Notice the **floating clouds** in the background
6. Hover over flight and hotel cards to see lift effects
7. Resize to mobile to see the responsive layout
