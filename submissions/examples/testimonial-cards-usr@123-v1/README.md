# Animated Testimonial Cards Submission

## 1. What does this do?
It provides beautiful, animated testimonial cards with auto-rotation, smooth transitions, rating stars, author information, and company logos. Perfect for showcasing customer reviews and building trust on business websites.

## 2. How is it used?
Wrap testimonials in `.testimonial-container` with `.testimonial-card` for each review. Each card includes quote text, rating stars, author avatar, name, role, and company logo. Navigation controls allow manual browsing, and auto-play can be toggled on/off.

## 3. Why is it useful?
- Essential component for building trust and social proof
- Smooth fade and slide transitions between testimonials
- Auto-rotation with pause on hover
- Navigation dots and arrow buttons
- Rating stars with pulse animation on hover
- Author information with avatar and company logo
- Auto-play toggle control
- Keyboard navigation (Arrow keys)
- Touch/swipe support for mobile
- Stats section to showcase key metrics
- Fully responsive design
- Accessible with ARIA labels and `prefers-reduced-motion` support
- Easy to customize colors, animations, and content
- Maintainer can easily standardize this as `.ease-testimonial-[YOUR_INITIALS]` in the core library.
