Animation Utility

Animated Number Counter

Zero-JavaScript count-up animations for landing page stats and dashboard metrics. An animatable @property integer drives a CSS counter that is rendered through generated content.

Basic count-up

Set the end value with --em-count-target. Everything else has a sensible default.

Uptime Suffix token plus a shorter duration.
Monthly revenue Prefix token with a staggered delay.

Thousands separator

Add counter--grouped for values between 1,000 and 999,999. The separator character is configurable.

Scroll-triggered count-up

Add counter--on-view to bind the animation to a scroll progress timeline instead of page load.

In browsers that support animation-timeline: view() the counter below stays at zero until it scrolls into the viewport, then counts as you scroll. Elsewhere it falls back to the standard time-based animation.

Custom properties

Every token can be overridden inline or in a stylesheet.

Property Default Purpose
--em-count-target 100 End value of the count-up. Required in practice.
--em-count-duration 2s How long the count takes.
--em-count-delay 0s Delay before counting starts. Useful for staggering.
--em-count-easing ease-out Timing function applied to the numeric ramp.
--em-count-prefix "" String rendered before the number, e.g. a currency symbol.
--em-count-suffix "" String rendered after the number, e.g. % or +.
--em-count-separator "," Thousands separator used by counter--grouped.
