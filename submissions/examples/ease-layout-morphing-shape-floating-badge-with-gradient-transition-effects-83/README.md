# Morphing Shape Floating Badge with Gradient Transition Effects

### Glassmorphic Style

A modern **Morphing Shape Floating Badge** built using **HTML5** and **CSS3** featuring a glassmorphism design, animated morphing gradient blob, responsive layout, and accessibility-friendly interactions.

---

## ✨ Features

- Glassmorphism floating badge
- Morphing gradient animation
- Smooth hover effects
- Responsive mobile-first layout
- CSS variables
- Modern UI
- `prefers-reduced-motion` support
- Pure HTML & CSS
