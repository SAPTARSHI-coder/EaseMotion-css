## Tooltip Slide-in Animation Variants 

A1. What does this do?
\nAdds animation variants for tooltips with slide, fade, and bounce effects.

A2. How is it used?
```\n<span class="ease-tooltip ease-tooltip-slide">Slide Tooltip</span>\n<span class="ease-tooltip ease-tooltip-fade">Fade Tooltip</span>\n<span class="ease-tooltip ease-tooltip-bounce">Bounce Tooltip</span>```

A3. Why is it useful?
Animated tooltips provide better visual feedback and user experience.
