# Tooltip Slide-in Animation Variants

## 1. What does this do?
Adds animation variants for tooltips with slide, fade, and bounce effects.

## 2. How is it used?
```html
<span class="ease-tooltip ease-tooltip-slide">Slide Tooltip</span>
<span class="ease-tooltip ease-tooltip-fade">Fade Tooltip</span>
<span class="ease-tooltip ease-tooltip-bounce">Bounce Tooltip</span>
```

## 3. Why is it useful?
Animated tooltips provide better visual feedback and user experience.
