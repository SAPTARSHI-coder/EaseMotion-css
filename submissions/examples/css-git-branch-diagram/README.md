# CSS Git Branch Diagram

A pure CSS Git branch visualization component.

## Features

- Visual Git commit history
- Main branch representation
- Feature branch representation
- Merge visualization
- CSS animations
- Responsive design

## Technologies

- HTML5
- CSS3

## Usage

Copy demo.html and style.css into your project.

## Accessibility

- Semantic section structure
- Descriptive labels
- Keyboard-friendly static visualization
