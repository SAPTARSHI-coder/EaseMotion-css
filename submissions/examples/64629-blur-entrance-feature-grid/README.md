# Blur-Entrance Feature Grid

A modern pure CSS animated feature grid created for **EaseMotion CSS**.

This component demonstrates a minimalist tech layout with smooth blur entrance effects and glassmorphism styling.

## ✨ Features

- Pure HTML & CSS implementation
- Smooth blur entrance animation
- Minimalist tech inspired design
- Glassmorphism UI effect
- Responsive feature grid
- Lightweight and performant
- No JavaScript dependency
- CSS keyframe animations
- `prefers-reduced-motion` support
