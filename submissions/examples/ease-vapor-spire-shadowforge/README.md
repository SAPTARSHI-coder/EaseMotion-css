# Jade Breeze

A unique landing page for Jade Breeze built with EaseMotion CSS framework.

## Features
- Pure EaseMotion CSS from CDN
- Responsive across all devices
- Zero JavaScript
- 4 unique sections: timeline, testimonials, pricing, gallery

## Setup
Open `demo.html` in any modern browser.

## Structure
```
ease-vapor-spire-shadowforge/
  demo.html
  style.css
  README.md
```
