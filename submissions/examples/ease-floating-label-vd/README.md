# Ease Floating Label

## What does this do?

A floating label input component where the label smoothly moves above the input when it receives focus or contains text.

---

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<div class="floating-field">
    <input type="text" id="name" placeholder=" ">
    <label for="name">Your Name</label>
</div>
```

### Features

- Animated floating label
- Focus state
- Smooth transition
- Responsive layout
- No JavaScript required
- Lightweight and reusable

---

## Why is it useful?

Floating labels are commonly used in login forms, registration forms, search interfaces, and other form inputs.

This component provides a simple CSS-only floating label with smooth interaction while following the animation-first philosophy of EaseMotion CSS.
