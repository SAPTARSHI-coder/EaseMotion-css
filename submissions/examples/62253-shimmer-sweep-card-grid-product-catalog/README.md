# CSS Shimmer-Sweep Card Grid for Product Catalog Layouts

A modern **Shimmer-Sweep Card Grid** built using pure HTML5 and CSS3 for product catalog layouts. The component features responsive product cards with an elegant shimmer sweep hover effect, glassmorphism styling, and accessibility support.

## Features

* Pure HTML5 & CSS3
* Shimmer-Sweep hover animation
* Responsive product card grid
* Glassmorphism product cards
* Product badges, pricing, ratings, and CTA buttons
* Smooth CSS transitions & keyframe animations
* Responsive desktop, tablet, and mobile layout
* CSS Custom Properties
* No JavaScript required
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over any product card to see the shimmer-sweep animation.
3. Customize colors, spacing, shadows, and animation speed using the CSS variables defined in `:root`.
4. Integrate the component into any product catalog or e-commerce landing page.
