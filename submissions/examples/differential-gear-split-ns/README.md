# Differential Gear Split

## What does this do?
Renders a self-contained CSS-only `ease-differential-gear-split` demo: Differential gears splitting rotation between two outputs.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-differential-gear-split`. No build step or JavaScript is required for the effect.

```html
<section class="ease-differential-gear-split">
  <div class="ease-differential-gear-split__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
