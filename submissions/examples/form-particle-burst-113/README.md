# Particle Burst Form

A pure CSS form featuring a smooth particle burst animation on input focus and button click. It follows a dark mode aesthetic and uses hardware-accelerated animations for maximum performance.

### Usage
Use the HTML structure provided in `demo.html` along with `style.css`.
The `.particle-burst` class can be added adjacent to any input element, and `.particle-burst-btn` inside a button to enable the effects.

### Why is this useful?
This form provides engaging, dynamic visual feedback when users interact with it, without relying on JavaScript. This makes the UI feel highly responsive and polished while keeping it accessible and performant.
