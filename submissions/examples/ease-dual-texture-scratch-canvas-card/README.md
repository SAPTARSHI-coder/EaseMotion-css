# Ease Multi-Layer Dual Texture Canvas Scratch Card (`ease-dual-texture-scratch-canvas-card`)

Scratch-off reveal card with a dual-texture metallic coating and particle dust trail.

## Features
- Dual-layer canvas surface texture erasing
- Particle spark spawner following scratch stroke
- Auto-reveal trigger at 50% scratched threshold
- Confetti celebration explosion on reveal
- Touch gesture support for mobile screens
