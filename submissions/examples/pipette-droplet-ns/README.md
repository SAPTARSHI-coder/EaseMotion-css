# Pipette Droplet

## What does this do?
Renders a self-contained CSS-only `ease-pipette-droplet` demo: Pipette dispensing a forming and falling droplet.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-pipette-droplet`. No build step or JavaScript is required for the effect.

```html
<section class="ease-pipette-droplet">
  <div class="ease-pipette-droplet__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
