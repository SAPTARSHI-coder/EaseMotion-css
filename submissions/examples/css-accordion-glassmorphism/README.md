# Glassmorphism Blur Accordion

A responsive and accessible accordion featuring a modern
glassmorphism blur design.

## Features

- Pure HTML and vanilla CSS
- No JavaScript required
- Glassmorphism styling
- `backdrop-filter` blur effect
- Responsive layout
- Smooth open/close animations
- Keyboard accessible
- Visible focus states
- Reduced-motion support
- Graceful fallback when backdrop blur is unavailable
- Mobile friendly
