# CSS Tilt-Reveal Image Card

A pure CSS image card with a subtle 3D tilt effect, image reveal,
gradient overlay, and interactive content.

## Features

- Pure HTML and CSS
- 3D tilt interaction
- Image zoom reveal on hover
- Animated light sweep
- Responsive layout
- No JavaScript required
- Accessible reduced-motion support

## Usage

Include `demo.html` and `style.css` in your project.

```html
<article class="tilt-card">
  <div class="tilt-card__image">
    <img src="image.jpg" alt="Descriptive image">
  </div>

  <div class="tilt-card__content">
    <span class="tilt-card__tag">Explore</span>
    <h1>Into The Wild</h1>
    <p>Discover unforgettable moments.</p>
    <a href="#" class="tilt-card__link">Discover More →</a>
  </div>
</article>
