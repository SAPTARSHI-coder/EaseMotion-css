# Ripple-Wave Pricing Table

A responsive glassmorphism pricing table with an expanding ripple-wave effect on hover and keyboard focus.

## Usage

Open `demo.html` directly in a browser. Each `.plan` contains a decorative `.wave` element used only for the CSS effect.

## Features

- Pure HTML/CSS with no JavaScript.
- CSS `@keyframes ripple` expands a circular wave from the card center.
- Responsive three-column layout with mobile fallback.
- Keyboard focus styling and semantic content.
- `prefers-reduced-motion` disables the ripple animation.

## CSS custom properties

`--bg`, `--glass`, `--border`, `--text`, and `--muted` define the core visual tokens.
