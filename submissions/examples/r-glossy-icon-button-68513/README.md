# CSS Glossy Icon Button

A glossy iOS-inspired icon button built entirely with HTML and CSS.

## Features

- Glossy gradient appearance
- Animated shine effect
- Multiple color variants
- Hover and focus interactions
- Keyboard accessible
- Responsive layout
- Reduced-motion support
- Forced-colors support
- No JavaScript required

## Usage

Copy the button markup and include `style.css`.

The component can be customized by changing the `--button-color`
CSS custom property.
