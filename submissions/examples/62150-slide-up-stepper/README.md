# CSS Slide-Up Stepper for SaaS Showcase Layouts

A modern and lightweight **CSS-only Slide-Up Stepper component** designed for SaaS product showcase layouts.

This component uses smooth entrance animations, clean card styling, and responsive design without requiring JavaScript or external libraries.

---

## ✨ Features

- Smooth slide-up entrance animation
- Minimalist SaaS-inspired UI
- Pure HTML & CSS implementation
- Responsive design for desktop, tablet, and mobile
- Customizable CSS variables
- Hover interaction effects
- Accessible motion handling with `prefers-reduced-motion`
