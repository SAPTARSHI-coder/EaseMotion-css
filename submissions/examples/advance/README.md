# EaseMotion-css - Advanced Component Iteration 102

An accordion component built with pure HTML5 and CSS3, engineered without reliance on JavaScript.

## Features
- **Dynamic Height Transitions:** Uses CSS Grid (`grid-template-rows`) to animate dynamic height smoothly.
- **Zero JavaScript:** Driven entirely by native radio/checkbox input controls.
- **Modern Styling:** Built with CSS custom properties (variables) for theme customizability.

## Installation & Usage

1. Clone the repository or copy the `style.css` file into your project.
2. Link the stylesheet inside your HTML `<head>`:

```html
<link rel="stylesheet" href="style.css">
