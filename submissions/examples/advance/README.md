### Advanced Components Batch 24 V2

A comprehensive library expansion for **EaseMotion-css**, introducing advanced high-performance UI components built with native CSS selectors and smooth animations.

#### Included Components
* **Pure CSS Tabs (`.ease-tabs`):** Scriptless state switching utilizing hidden radio inputs, paired with custom smooth fade-in pane animations.
* **Command Palette UI (`.ease-command-palette`):** A sleek search modal layout featuring keyboard shortcut badges (`.ease-kbd`) and interactive row highlights.

#### Installation & Usage
Include `style.css` in your project workspace and copy the structural HTML elements from `demo.html` to integrate fully responsive, lightweight widgets into your dashboard or documentation site.
