# Button Neon Slide

A neon gradient slides horizontally across the button face.

## Features
- Neon gradient slide
- Slide on hover
- Glow edge
- Pure CSS

## Usage
```html
<button class="bns-btn"><span>Neon</span></button>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
