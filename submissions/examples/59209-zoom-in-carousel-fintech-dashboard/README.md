# CSS Zoom-In Carousel for Fintech Dashboard Layouts

A modern **Zoom-In Carousel** component built using pure HTML5 and CSS3 for fintech dashboard layouts. This component provides an engaging financial dashboard interface with smooth zoom animations, highlighted cards, glassmorphism styling, and responsive behavior.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Fintech dashboard inspired design
* Smooth zoom-in card animations
* Active card emphasis
* Interactive hover scaling
* Glassmorphism UI style
* Financial analytics cards
* Gradient action buttons
* Responsive desktop, tablet, and mobile layouts
* CSS Custom Properties support
* Lightweight keyframe animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over cards to view smooth zoom and elevation effects.
3. Customize colors, spacing, shadows, and animation behavior through CSS variables.
