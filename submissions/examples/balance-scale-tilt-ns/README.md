# Balance Scale Tilt

## What does this do?
Renders a self-contained CSS-only `ease-balance-scale-tilt` demo: Pharmacy balance scale pans tilting to equilibrium.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-balance-scale-tilt`. No build step or JavaScript is required for the effect.

```html
<section class="ease-balance-scale-tilt">
  <div class="ease-balance-scale-tilt__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
