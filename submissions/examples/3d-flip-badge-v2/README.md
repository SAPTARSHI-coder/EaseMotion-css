# 3D-Flip Badge

A lightweight, responsive, CSS-only 3D flip badge component for modern fintech dashboard layouts.

The component uses CSS 3D transforms to reveal additional information when the user hovers over or focuses a badge.

## Features

- Pure HTML and CSS
- No JavaScript
- No external libraries
- 3D flip animation
- Hover interaction
- Keyboard focus interaction
- Multiple fintech status variants
- Responsive across desktop, tablet and mobile
- CSS custom properties
- Smooth transitions
- Reduced-motion accessibility support
- Semantic HTML structure
- Lightweight implementation

## Preview

The demo contains four badge variants:

- Payment Verified
- Processing
- Account Verified
- Pending Review

Hover or keyboard-focus a badge to reveal additional information.
