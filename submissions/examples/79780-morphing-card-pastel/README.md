# Morphing Card with Pastel Styling

A soft and playful morphing card component built with pure HTML and CSS.

The component uses pastel gradients, organic shapes, smooth transitions, and responsive layouts to create a modern interactive card experience.

## ✨ Features

- Pastel visual styling
- Organic morphing shapes
- Smooth hover transitions
- Animated decorative elements
- Interactive call-to-action
- Responsive card grid
- Desktop, tablet, and mobile support
- Pure HTML and CSS
- Zero external JavaScript dependencies
- CSS custom properties for reusable design tokens
- `prefers-reduced-motion` support
