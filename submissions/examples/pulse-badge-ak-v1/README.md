# pulse-badge-ak

Pure CSS animated pulsing status indicator badge — no JavaScript required.

## How to use

```html
<span class="ease-pulse-badge ease-pulse-badge--success">
  <span class="ease-pulse-dot"></span> System Operational
</span>

<!-- Variants -->
<span class="ease-pulse-badge ease-pulse-badge--primary">
  <span class="ease-pulse-dot"></span> Live
</span>

<span class="ease-pulse-badge ease-pulse-badge--warning">
  <span class="ease-pulse-dot"></span> Away
</span>

<span class="ease-pulse-badge ease-pulse-badge--danger">
  <span class="ease-pulse-dot"></span> Offline
</span>
