# Escapement Pallet Tick

## What does this do?
Renders a self-contained CSS-only `ease-escapement-pallet-tick` demo: Escapement pallets locking and releasing an escape wheel.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-escapement-pallet-tick`. No build step or JavaScript is required for the effect.

```html
<section class="ease-escapement-pallet-tick">
  <div class="ease-escapement-pallet-tick__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
