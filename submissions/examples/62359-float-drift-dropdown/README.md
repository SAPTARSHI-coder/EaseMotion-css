# Float-Drift Dropdown for Product Catalog Layouts

A modern pure CSS animated dropdown component created for the EaseMotion CSS collection.

This component provides a smooth floating drift entrance effect with a glassmorphism product catalog design.

## ✨ Features

- Pure HTML + CSS implementation
- Float-drift dropdown animation
- Glassmorphism UI styling
- Smooth hover interactions
- Responsive across devices
- Lightweight and framework-free
- Accessible reduced motion support
