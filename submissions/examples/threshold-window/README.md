# Threshold Window

Threshold Window is an experimental layered-document UI component that lets
users reveal a hidden analytical layer underneath a primary visual
composition.

The interaction behaves like moving a physical inspection window across a
document.

Instead of simply hiding and showing content, the component keeps two
independent visual interpretations perfectly aligned.

## ✨ Features

- Interactive horizontal threshold
- Progressive underlayer reveal
- Surface/underlayer composition
- Live reveal percentage
- Region detection
- Layer status indicator
- Mouse interaction
- Touch interaction
- Stylus-compatible pointer interaction
- Keyboard-controlled slider
- Home/End controls
- Technical measurement guides
- Architectural annotations
- Responsive design
- Reduced-motion compatibility
- No external JavaScript dependencies
