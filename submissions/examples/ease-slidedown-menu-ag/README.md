# Slide-Down Dropdown Menu

A smooth slide-down and fade-in dropdown menu using only CSS state.

## Preview

Open `demo.html` in your browser to see the effect in action.

## Implementation Details

- **No JavaScript:** The animation is completely driven by CSS using the `:hover` pseudo-class.
- **Animation:** Uses CSS transitions on `opacity`, `visibility`, and `transform` for a smooth slide-down effect.
- **Accessible:** Can be easily extended to support keyboard navigation.
