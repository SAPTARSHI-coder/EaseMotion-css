# CSS Scale-Hover Hero Section

A modern, responsive gaming hero section featuring a subtle scale-hover
interaction built entirely with HTML and CSS.

## Features

- Pure HTML and CSS
- No JavaScript or external frameworks
- Scale-hover hero visual
- Interactive CTA buttons
- CSS Grid background
- Responsive desktop, tablet, and mobile layouts
- CSS custom properties
- Keyboard focus states
- `prefers-reduced-motion` support
- Semantic and accessible HTML
