# Hero CTA Bounce

A primary call-to-action button that bounces gently and nudges the visitor to click.

## Features
- Gentle idle bounce to draw the eye
- Gradient button with a soft glow
- Chevron icon nudges downward

## Usage
```html
<a class="hb-cta">
  Get started now
  <svg viewBox="0 0 24 24"><path d="M6 9l6 6 6-6"/></svg>
</a>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
