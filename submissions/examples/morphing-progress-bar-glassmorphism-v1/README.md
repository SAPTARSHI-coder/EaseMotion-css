# Morphing Progress Bar – Glassmorphism

A responsive CSS-only progress bar featuring a modern glassmorphism design and smooth morphing animation.

## Features

- Responsive design
- Glassmorphism card effect
- Animated morphing progress indicator
- Animated highlight effect
- Pure HTML and CSS
- No JavaScript required
- Accessible progressbar attributes
- Reduced-motion support
