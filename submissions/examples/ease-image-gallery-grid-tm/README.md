# Image Gallery Grid Component

Add ease-image-gallery-grid-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|---------|
| `--igg-accent` | `#6366f1` |
| `--igg-radius` | `8px` |
| `--igg-shadow` | `0 4px 20px rgba(0,0,0,.3)` |

## Technique

CSS Grid with `aspect-ratio: 1` squares. Hover `scale` + overlay fade.
