
---

## 🚀 Usage
1. Clone or copy the files into your project.
2. Open `demo.html` in your browser.
3. Hover over the dropdown to see the parallax gradient effect.

---

## 🛠️ Customization
- **Colors** → Adjust gradient values in `background: linear-gradient(...)`.
- **Animation speed** → Modify `transition: 0.6s ease` for faster/slower dropdown.
- **Menu items** → Add/remove `<li>` elements inside `.dropdown-menu`.

---

## 📖 Accessibility
- Uses `role="navigation"` and `aria-label="Gradient parallax dropdown"`.
- Keyboard navigation supported via `<button>` and `<a>` elements.
