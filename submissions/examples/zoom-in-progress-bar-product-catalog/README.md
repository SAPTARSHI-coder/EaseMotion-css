# Zoom-In Progress Bar for Product Catalogs

A lightweight, responsive CSS-only Zoom-In Progress Bar designed for
product catalog and e-commerce interfaces.

## Features

- Pure HTML and CSS
- Zoom-in progress animation
- Responsive product catalog layout
- CSS custom properties for easy customization
- No JavaScript or external dependencies
- Smooth CSS keyframe animation
- Accessible progressbar semantics
- `prefers-reduced-motion` support
- Works by opening `demo.html` directly in a browser
