# Velvet Smooth Transition Toggle (#73888)

A pure HTML & Vanilla CSS toggle featuring a velvet smooth transition animation.

## Features
- **Aesthetic:** Soft velvet finish track with smooth cubic-bezier sliding transition.
- **Pure CSS:** Zero JavaScript dependencies; uses native checkbox state selectors.
- **Performance:** Hardware-accelerated transitions utilizing `transform` and `will-change`.
- **Accessibility:** Includes `:focus-visible` outline rings and `@media (prefers-reduced-motion: reduce)` support.
