# Glowing Pulse Avatar Component

An animated avatar UI component featuring a continuous gradient pulse glow for live status indicators.

## Features
- **CSS Pulse Glow:** Smooth 60fps keyframe pulse animation around profile avatars.
- **Pure CSS:** Zero JavaScript required.
- **Fully Responsive:** Centered flex layout with fluid sizing.

## File Structure
- `demo.html` - HTML markup for the avatar component and online status indicator.
- `style.css` - Component styling and gradient pulse keyframe animation.
