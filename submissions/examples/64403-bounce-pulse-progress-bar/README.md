# CSS Bounce-Pulse Progress Bar for Glassmorphism UI Layouts

A modern animated progress bar component built with pure HTML and CSS.

The component combines glassmorphism styling with a smooth bounce-pulse loading animation.

## Features

- Pure HTML and CSS
- Glassmorphism card design
- Bounce pulse progress animation
- Smooth gradient progress indicator
- Animated shine effect
- Responsive design
- No JavaScript dependency
- prefers-reduced-motion support
