# CSS Scale-Hover Tooltip for SaaS Showcase Layouts

A modern SaaS showcase component featuring interactive scale-hover cards with floating tooltips, gradient effects, and smooth CSS animations.

This component is built completely with HTML and CSS without JavaScript or external dependencies.

## ✨ Features

- 🔍 Smooth scale-hover card animation
- 💡 Floating product information tooltips
- 🚀 Modern SaaS product showcase design
- 💎 Glassmorphism card UI
- 🎨 Gradient glow effects
- ⚡ Pure HTML and CSS implementation
- 📱 Fully responsive layout
- 🔄 Smooth CSS transitions
- ♿ Accessibility support with `prefers-reduced-motion`

## 🚀 Usage

1. Clone the EaseMotion CSS repository.

2. Navigate to:


submissions/examples/ease-css-scale-hover-tooltip-saas-showcase-layouts/


3. Open `demo.html` in any modern browser.

No JavaScript, frameworks, or external libraries are required.

## 🎨 CSS Custom Properties

The component uses CSS variables for easy customization:

```css
:root {
    --bg:#070b18;
    --primary:#38bdf8;
    --secondary:#8b5cf6;
    --accent:#22c55e;
    --text:#f8fafc;
    --muted:#94a3b8;
}

Update these values to match your SaaS branding.
