# CSS 3D-Flip Carousel for Product Catalog Layouts

A modern **3D Flip Carousel** built using pure HTML and CSS for product catalog interfaces. Each product card performs a smooth 3D flip on hover, revealing additional product information and action buttons. The layout is fully responsive, lightweight, and optimized for modern browsers.

---

## Features

- Pure HTML5 & CSS3
- Smooth 3D flip animation
- Modern product card layout
- Floating card animation
- Gradient badges
- Responsive design
- Mobile-friendly layout
- Hardware accelerated transforms
- Accessible structure
- Supports `prefers-reduced-motion`
