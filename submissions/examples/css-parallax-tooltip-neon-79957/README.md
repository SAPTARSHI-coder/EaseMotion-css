# Parallax Tooltip with Neon Styling

A responsive tooltip component featuring neon glow effects, subtle parallax-inspired motion, and smooth hover animations built entirely with HTML and CSS.

## Features

- Pure HTML & CSS
- Neon glow styling
- Parallax-inspired 3D reveal effect
- Fully responsive layout
- Smooth transitions
- Dark mode friendly
- No JavaScript required

## Files

- demo.html
- style.css

## Usage

```html
<div class="tooltip-wrapper">
  <button class="trigger">Hover Me</button>

  <div class="tooltip">
    Tooltip content
  </div>
</div>
```

## Why it fits EaseMotion CSS

This component emphasizes motion-first design through subtle 3D parallax interactions, neon visual effects, and reusable CSS patterns while remaining lightweight, responsive, and accessible.
