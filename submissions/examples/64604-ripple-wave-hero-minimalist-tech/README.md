# Ripple Wave Hero Section

A modern **CSS Ripple-Wave Hero Section** created for minimalist tech layouts using pure HTML and CSS.

This component provides a smooth animated background ripple effect with a clean futuristic hero design.

---

## ✨ Features

- Pure HTML and CSS implementation
- No JavaScript dependency
- Smooth ripple wave animations
- Minimalist futuristic tech design
- Responsive across desktop, tablet, and mobile
- Lightweight and performance friendly
- Accessible motion control using `prefers-reduced-motion`
