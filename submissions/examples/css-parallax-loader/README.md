# Parallax Loader with Material Design styling (#78895)

A multi-layer parallax loader component featuring Material Design aesthetics and counter-rotating rings built entirely with pure CSS.

## Features
- **Semantic Structure:** Accessible container markup with decorative loaders hidden from screen readers.
- **Pure CSS Keyframes:** Counter-rotating rings and pulsing center core animations using cubic-bezier easing.
- **Responsive Layout:** Centered modern card layout scaling smoothly across all viewports.

## File Hierarchy
- `style.css` - Keyframe animations, layering, and color variables.
- `demo.html` - Semantic markup and accessibility attributes.
- `README.md` - Technical specification and architecture overview.
