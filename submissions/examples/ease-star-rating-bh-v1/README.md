# ease-star-rating-bh

Pure CSS interactive star rating form component.

## What does this do?
Creates an interactive 5-star rating component where users can select ratings using radio buttons styled as stars.

## How is it used?
```html
<div class="ease-star-rating-bh">
  <input type="radio" id="star5" name="rating" value="5">
  <label for="star5">★</label>
  <!-- more stars -->
</div>
```

## Why is it useful?
Provides a native, accessible star rating input without JavaScript.
