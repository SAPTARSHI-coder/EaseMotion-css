# Cheese Press Weight

## What does this do?
Renders a self-contained CSS-only `ease-cheese-press-weight` demo: Cheese press screw applying weight to a curd mold.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-cheese-press-weight`. No build step or JavaScript is required for the effect.

```html
<section class="ease-cheese-press-weight">
  <div class="ease-cheese-press-weight__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
