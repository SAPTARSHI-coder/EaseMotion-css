# Bookbinding Sewing Frame

## What does this do?
Renders a self-contained CSS-only `ease-bookbinding-sewing-frame` demo: Bookbinding sewing frame needle pass.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-bookbinding-sewing-frame`. No build step or JavaScript is required for the effect.

```html
<section class="ease-bookbinding-sewing-frame">
  <div class="ease-bookbinding-sewing-frame__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
