# Origami Paper Fold Form

Implementation for EaseMotion issue #73363.

## Features

- Pure HTML and vanilla CSS
- Folded paper corner created with CSS borders
- Soft paper depth and shadows
- Responsive form layout
- Native accessible controls
- Reduced-motion support

The component uses a semantic form inside a paper-like surface. The folded corner is decorative and does not affect interaction or document structure.

Open `demo.html` to preview the component and customize paper, ink, and accent variables in `style.css`.
