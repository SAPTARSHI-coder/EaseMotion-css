# CSS Retrospective Card (#71012)

A clean, responsive sprint retrospective card component featuring color-coded "What Went Well" and "What Could Improve" feedback columns with pure CSS hover elevations.

## Features
- Dual-column agile retrospective layout with responsive stack overrides for mobile viewports.
- Distinct color-coded thematic styles for positive vs. feedback channels.
- Full keyboard focusability (`tabindex="0"`) on feedback cards.
- ARIA landmarks (`aria-label`, `aria-labelledby`, `role="list"`, `role="article"`).
- `prefers-reduced-motion` safety fallbacks.
