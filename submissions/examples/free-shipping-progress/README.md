# Free Shipping Progress

A threshold meter that fills toward free shipping with a motoring truck icon.

## Features
- Gradient progress bar that fills the track
- Truck icon travels with the fill
- Remaining-amount message updates the story

## Usage
```html
<div class="fs-card">
  <p class="fs-msg">Add <b>$18</b> more for free shipping!</p>
  <div class="fs-track"><div class="fs-fill"><span class="fs-truck">&#128666;</span></div></div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
