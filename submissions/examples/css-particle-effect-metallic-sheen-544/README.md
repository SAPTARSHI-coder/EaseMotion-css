# Metallic Sheen Particle Effect

A pure CSS particle effect featuring a smooth metallic sheen when hovering over the container.

## What does this do?

It creates an elegant, hardware-accelerated particle animation with a metallic golden sheen effect that activates on hover.

## How is it used?

```html
<div class="metallic-container">
  <div class="metallic-sheen-particle particle-1"></div>
  <div class="metallic-sheen-particle particle-2"></div>
  <div class="metallic-sheen-particle particle-3"></div>
  <div class="metallic-sheen-particle particle-4"></div>
  <div class="metallic-sheen-particle particle-5"></div>
  <div class="metallic-sheen-particle particle-6"></div>
  <div class="metallic-sheen-particle particle-7"></div>
  <div class="metallic-sheen-particle particle-8"></div>
  <div class="metallic-sheen-particle particle-9"></div>
  <div class="metallic-sheen-particle particle-10"></div>
  
  <div class="metallic-content">
    <h1>Metallic Sheen</h1>
  </div>
</div>
```

## Why is it useful?

It provides a premium, hardware-accelerated visual enhancement for cards and interactive elements without relying on heavy JavaScript canvas rendering, perfectly aligning with EaseMotion's philosophy of accessible, smooth pure CSS effects.
