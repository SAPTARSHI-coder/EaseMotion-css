# Aurora Glow Toggle (#73868)

A pure HTML & Vanilla CSS toggle featuring a vibrant Aurora Glow gradient shift.

## Features
- **Aesthetic:** Smooth cyan to purple aurora gradient glow transition.
- **Pure CSS:** Zero JavaScript dependencies; relies on standard checkbox state selectors.
- **Performance:** Hardware-accelerated transitions utilizing `transform` and `will-change`.
- **Accessibility:** Includes `:focus-visible` outline rings and `@media (prefers-reduced-motion: reduce)` support.
