# Mini Stat Item

## What it does

This submission creates a simple CSS-only mini stat utility for displaying a small value with a short label.

## How to use it

Place the value and label inside the shared stat container:

```html
<div class="mini-stat-item">
  <strong>24</strong>
  <span>Projects</span>
</div>
```

## Why it fits EaseMotion CSS

It fits EaseMotion CSS because it is human-readable, composable, and useful across many interfaces. It works well in dashboards, cards, widgets, summary sections, and compact metrics displays.

## Included features

- Compact value-and-label stat utility
- Practical metric grid example
- Readable muted label styling
- Responsive demo layout
- Pure HTML and CSS implementation
