How this transition works

  1. In style.css, @view-transition { navigation: auto; } opts both pages into cross-document View Transitions.
  2. Both the gallery card and this hero image share the same view-transition-name value (e.g. product-img-1).
  3. When you click a card, the browser takes a screenshot of the old state, renders the new page, then animates the shared elements from their old position/size to their new one — entirely on the GPU compositor thread.
  4. ::view-transition-old() and ::view-transition-new() pseudo-elements let us customise the animation timing and easing in pure CSS.

This demo uses the native View Transitions API — no JavaScript frameworks, no animation libraries. Pure HTML & CSS.
