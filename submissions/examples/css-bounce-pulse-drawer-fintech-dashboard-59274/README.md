# CSS Bounce-Pulse Drawer for Fintech Dashboard Layouts

A modern **Bounce-Pulse Drawer** built using pure HTML and CSS for fintech dashboards, banking portals, admin panels, and analytics interfaces.

## Features

* Pure HTML5 & CSS3
* Bounce entrance animation
* Pulse hover effects
* CSS-only drawer toggle
* Responsive layout
* CSS custom properties
* No JavaScript required
* Supports `prefers-reduced-motion`

## Folder Structure

```text
css-bounce-pulse-drawer-fintech-dashboard-59274/
├── demo.html
├── style.css
└── README.md
```

## Usage

1. Open `demo.html` in any modern browser.
2. Click the menu button to open and close the drawer.
3. Customize colors using the CSS variables in `:root`.
4. Edit navigation items according to your project.
