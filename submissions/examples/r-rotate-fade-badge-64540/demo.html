Scale-Hover Accordion

A lightweight accordion with subtle scale and glow interactions, built entirely with HTML and CSS.

01 Minimal Interface +

A clean dark interface with restrained borders, soft gradients, and a subtle scale effect for focused accordion items.

02 Smooth Interaction +

Hover and focus states gently scale the accordion surface while adding a soft accent glow for visual feedback.

03 Pure CSS Motion +

The component uses native HTML details and summary elements, CSS transitions, and keyframes without JavaScript.

04 Responsive by Design +

Flexible sizing and mobile-friendly spacing keep the accordion comfortable across desktop, tablet, and mobile screens.
