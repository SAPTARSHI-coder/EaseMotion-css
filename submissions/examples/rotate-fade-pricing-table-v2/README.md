# CSS Rotate-Fade Pricing Table

A responsive SaaS pricing table featuring a lightweight CSS Rotate-Fade entrance animation.

## Features

- Pure HTML and CSS
- No JavaScript required
- Rotate and fade entrance animation
- Staggered pricing-card animations
- Hover elevation effect
- Responsive desktop, tablet, and mobile layouts
- CSS custom properties for easy customization
- `prefers-reduced-motion` accessibility support
- Self-contained browser demo
