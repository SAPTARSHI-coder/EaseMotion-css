# Timeline Layout Component

**Issue:** [#69809](https://github.com/SAPTARSHI-coder/EaseMotion-css/issues/69803)

A pure CSS timeline layout component with smooth animations and dark/light mode.

## Design Tokens

| Token | Value |
|-------|-------|
| `--comp-primary` | `#6366f1` |
| `--comp-accent` | `#f59e0b` |
| `--comp-bg` | `#0f172a` |
| `--comp-bg-card` | `#1e293b` |
| `--comp-radius` | `12px` |

## Features

- Smooth hover effects
- Dark and light mode
- No JavaScript required
- CSS custom properties for theming

- `style.css` - Component styles
