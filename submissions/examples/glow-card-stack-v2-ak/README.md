# glow-card-stack-v2-ak

Pure CSS 3D floating stacked cards hover fan-out effect — no JavaScript required.

## How to use

```html
<div class="ease-card-stack-v2">
  <div class="ease-card-stack-item-v2">Top</div>
  <div class="ease-card-stack-item-v2">Middle</div>
  <div class="ease-card-stack-item-v2">Bottom</div>
</div>
