Key Core Features

Subtle Gradient Shimmer

During hover and keyboard focus, a light reflection sweep sweeps across the link capsules. The active element maintains a soft, low-frequency background animation for visual hierarchy.

GPU-Accelerated Performance

The shimmer sweep utilizes 3D compositor properties (transform translate and skew) rather than background-position. This runs on the GPU, avoiding CPU repaints and maintaining a stable 60 FPS.

Robust Accessibility (A11y)

Features high-contrast text ratios conforming to WCAG standards, explicit focus-visible borders for keyboard navigation, semantic layout tags, and screen-reader safe toggle attributes.

Reduced Motion Friendly

Respects users with vestibular motion sensitivities. If the OS prefers reduced motion, the CSS disables the translation animations completely and falls back to simple opacity transitions.
