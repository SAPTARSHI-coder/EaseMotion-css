# Cyber Status Grid

This submission demonstrates a futuristic status monitoring grid built with
**EaseMotion CSS**. It includes animated status cards, progress meters, hover
lift effects, and custom cyber-themed styling.

## 🌟 Features

- **Responsive status grid** built with CSS Grid and EaseMotion grid utilities.
- **Staggered entrance animation** using `ease-slide-up` and delay utilities.
- **Hover lift effect** using `ease-hover-lift`.
- **Animated progress meters** using custom CSS variables.
- **Cyber-themed visual style** with glowing gradients and scan animation.
- **Accessible progress values** using `role="progressbar"` and ARIA attributes.
- **Reduced motion support** for users who prefer less animation.

## 📁 Files

- `demo.html` — interactive cyber status grid demo
- `style.css` — original cyber-themed CSS styling
- `README.md` — documentation for this submission

## 🛠️ How to Run

1. Open `demo.html` in your browser.
2. Watch the status cards enter with staggered animation.
3. Hover over the cards to see the lift effect.
4. Resize the browser window to check responsive behavior.
