# Diamond Facet Edge

A smooth, accessible, and performant **pure CSS 3D Diamond Facet Edge**
animation created for the EaseMotion-css project.

## ✨ Features

- Pure HTML and Vanilla CSS
- No JavaScript
- No external libraries
- CSS 3D perspective
- Multiple diamond facets
- Smooth rotation
- Floating effect
- Facet edge highlights
- Light reflection effect
- Dark-mode friendly
- Responsive design
- Reduced-motion accessibility support
- GPU-friendly CSS transforms
