# CSS Bioluminescent Glow


A pure CSS animated bioluminescent lighting effect inspired by glowing underwater organisms.


## Features

- Animated glowing particles
- Dark underwater atmosphere
- Smooth floating animation
- Responsive design
- No JavaScript required


## Technologies

- HTML5
- CSS3


## CSS Concepts Used

- Radial gradients
- Blur filters
- Keyframe animations
- Absolute positioning
- Transform animations


## Accessibility

- Semantic main element
- ARIA label added for animation context
