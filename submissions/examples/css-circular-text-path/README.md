# CSS Circular Text Path

A pure CSS circular text effect where characters are positioned around a circle using CSS transforms and rotation.

## Features

- Pure CSS implementation
- Circular text layout
- Smooth continuous rotation
- Responsive design
- Easy customization using CSS variables
- No JavaScript required

## Usage

```html
<div class="circle-text">
  <span style="--i:1">E</span>
  <span style="--i:2">A</span>
  ...
</div>
