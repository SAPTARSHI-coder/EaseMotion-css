# Neumorphic Interactive Toggle Switch with Smooth Haptic Elasticity 12

### Neumorphic Finish

A premium neumorphic toggle switch built using pure HTML and CSS. The component features soft shadows, elastic thumb animation, responsive behavior, and accessibility-focused interactions.

---

## ✨ Features

- Modern neumorphic interface
- Smooth elastic toggle animation
- Soft inner & outer shadow effects
- Responsive layout
- Keyboard accessibility (`:focus-visible`)
- Reduced motion support
- Pure HTML & CSS implementation
- Easily customizable with CSS variables

## 🚀 Usage

1. Open the component folder.
2. Keep `demo.html` and `style.css` in the same directory.
3. Open `demo.html` in any modern web browser.

No installation or build tools are required.
