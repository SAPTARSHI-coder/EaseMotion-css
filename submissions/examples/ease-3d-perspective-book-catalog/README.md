# Ease 3D Perspective Book Catalog

A responsive **3D Bookshelf Catalog Showcase** built with HTML, CSS, and Vanilla JavaScript.

The component presents books on a digital bookshelf using CSS 3D transforms. Hovering over a book pulls it forward with a perspective effect, while clicking a book opens a modal displaying its synopsis.

---

## Features

- 3D bookshelf layout
- CSS `transform-style: preserve-3d`
- Hover pull-forward animation
- `translateZ()` and `rotateY()` transforms
- Click-to-open synopsis modal
- Responsive bookshelf grid
- CSS Custom Properties
- Lightweight Vanilla JavaScript
- Beginner-friendly implementation

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over a book to view the 3D pull-forward animation.
3. Click a book to display its synopsis.
4. Close the modal using the close button or by clicking outside it.
