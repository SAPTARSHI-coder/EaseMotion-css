# Animated Recipe/Cooking App

A delicious **Recipe App Interface** built with **EaseMotion CSS**. Features recipe cards with food images, cooking time badges, difficulty levels, category filters, and a featured recipe spotlight.

## ✨ Features

- **🍕 Recipe Cards**: Food images with hover zoom, time badges, and favorites
- **⭐ Featured Recipe**: Large spotlight card with full details
- **🏷️ Category Tags**: Cuisine and dietary tags with color coding
- **⏱️ Cooking Time**: Time badges on recipe images
- **📊 Difficulty Levels**: Easy, Medium, Hard indicators
- **🔍 Search Bar**: Rounded search with quick category pills
- **🎬 Staggered Entrance**: All sections slide up sequentially
- **📱 Fully Responsive**: 4-column → 3-column → 2-column → 1-column

## 🧩 EaseMotion Classes Used

| Class | Purpose |
|-------|---------|
| `ease-fade-in` | Fades in the main page and footer |
| `ease-slide-up` | Slides sections up on entrance |
| `ease-delay-100` to `ease-delay-500` | Creates cascading staggered sequence |
| `ease-card` | Base card structure |
| `ease-hover-lift` | Lift effect on cards |
| `ease-hover-grow` | Scale effect on buttons |
| `ease-center` | Centers search button content |
| `ease-grid` + `ease-grid-cols-4` | Responsive recipe grid |
| `ease-gap-4` | Spacing between grid items |
| `ease-btn` + `ease-btn-primary` | Styled CTA buttons |

## 🚀 How to Use

1. Open `demo.html` in any modern browser
2. Watch all sections slide in with staggered animations
3. Hover over recipe cards to see image zoom and lift effects
4. Hover over favorite buttons to see color change
5. Test the filter pills and quick category buttons
6. Resize to mobile to see responsive layout

- **Warm Color Palette**: Orange accent with food-themed styling
