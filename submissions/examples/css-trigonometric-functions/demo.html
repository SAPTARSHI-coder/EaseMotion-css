sin() & cos()

Position elements on a circle using basic trigonometry. Each element's x and y coordinates are computed from a single --angle custom property.

Circular Dot Menu

Each dot's position is computed from sin() and cos() of its angle. Change any dot's angle and the entire circle redistributes. No JavaScript — pure CSS math.

--angle: calc(var(--idx) * 45deg);
--x: calc(cos(var(--angle)) * 120px);
--y: calc(sin(var(--angle)) * 120px);
translate: var(--x) var(--y);

Orbital Motion

Satellites orbit a center using @property-typed angles combined with sin() and cos(). Each orbit has a different radius and speed. Pure CSS animations.

@property --orbit-angle {
  syntax: '';
  initial-value: 0deg;
  inherits: false;
}
--x: calc(cos(var(--orbit-angle) + var(--orbit-offset)) * var(--orbit-radius));
--y: calc(sin(var(--orbit-angle) + var(--orbit-offset)) * var(--orbit-radius));

Scroll-Driven Angle Gauge

Scroll down and the needle rotates, driven by animation-timeline: scroll(). The needle's endpoint is positioned with sin() and cos() for precise circular tracing.

tan()

Calculate the relationship between opposite and adjacent sides of a right triangle. Use tan() for perspective offsets, slope-based layouts, and dynamic shadow angles.

Perspective Tilt from Slope

Cards tilt dynamically using tan() to preserve a constant light-source direction. The tilt's vertical component is calculated from the horizontal angle. Hover each card to see the effect.

Light Source Position from Angle

A simulated light source rotates, and shadows are offset using sin(), cos(), and tan() to maintain realistic perspective as the light moves.

atan2()

Calculate the angle from a point to another using rise and run — the inverse tangent that handles all quadrants correctly. Perfect for directional indicators and compass-style UI.
