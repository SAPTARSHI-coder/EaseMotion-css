# Animated Image Gallery

A modern animated image gallery component built with pure HTML and CSS. It includes hover zoom effects, caption animation, responsive grid layout, and gradient placeholder visuals.

## Features

- Pure HTML and CSS gallery.
- Responsive grid layout.
- Hover zoom effect.
- Animated caption overlay.
- Tall and wide grid item variants.
- Supports `prefers-reduced-motion`.

## Usage

Copy the HTML structure from `demo.html` and link `style.css`.

```html
<figure class="gallery-item">
  <div class="gallery-thumb thumb-1"></div>

  <figcaption class="gallery-caption">
    <h2>Image Title</h2>
    <p>Image description</p>
  </figcaption>
</figure>
