# Floating Cookie Banner - Glassmorphism

A responsive floating cookie consent banner featuring a modern
glassmorphism visual style.

## Features

- Pure HTML and CSS
- Glassmorphism surface
- Translucent layered background
- Backdrop blur and saturation
- Floating entrance animation
- Animated ambient background orbs
- Soft glow effects
- Interactive hover and active states
- Responsive desktop, tablet, and mobile layouts
- Accessible keyboard focus states
- `prefers-reduced-motion` support
- No JavaScript dependencies
- No external libraries
