# Cyberpunk Stat Metric Card Component

A pure CSS responsive metric display card designed with a cyberpunk aesthetic using EaseMotion design tokens and transition variables.

## Features
- **Zero JS Dependencies**: Pure HTML5 and CSS3 implementation.
- **Cyberpunk Aesthetic**: Angle-cut clip path, high-contrast neon accents, and subtle glow effects.
- **Responsive Layout**: Scales seamlessly across mobile, tablet, and desktop breakpoints.
- **Accessibility**: Native `prefers-reduced-motion` query support to disable transform and state transitions.

## Usage
Include `style.css` in your HTML page and use the markup structure shown in `demo.html`.
