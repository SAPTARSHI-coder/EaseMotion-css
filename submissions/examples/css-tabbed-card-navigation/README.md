# CSS Tabbed Card Navigation

A polished, responsive tabbed card navigation component built with
pure HTML and CSS.

Part of the EaseMotion CSS component collection.

## ✨ Features

- Pure HTML and Vanilla CSS
- No JavaScript
- Responsive layout
- Animated tab switching
- Animated progress indicator
- Animated analytics bars
- Activity timeline
- CSS-only toggle visuals
- Dark mode support
- `prefers-reduced-motion` support
- Keyboard focus visibility
- Modern responsive card layout
- Hardware-friendly transform animations
- No external dependencies
