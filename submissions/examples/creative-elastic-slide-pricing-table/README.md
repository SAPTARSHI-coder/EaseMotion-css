# CSS Elastic-Slide Pricing Table for Creative Portfolio Layouts

A modern **Creative Portfolio Pricing Table** built using **pure HTML5 and CSS3**. This showcase demonstrates smooth **Elastic-Slide** hover animations, premium glassmorphism pricing cards, gradient accents, responsive layouts, and accessibility support without JavaScript.

---

## ✨ Features

- 🎯 Elastic-Slide hover animation
- 💳 Premium pricing cards
- 💎 Glassmorphism design
- 🌈 Gradient CTA buttons
- ⭐ Featured pricing plan
- 🚀 Smooth CSS transitions
- 📱 Fully responsive
- 🎨 CSS Custom Properties
- ♿ `prefers-reduced-motion` support
- 🚫 Pure HTML & CSS

## 🚀 Getting Started

1. Open `demo.html` in any modern browser.
2. Hover over the pricing cards to experience the Elastic-Slide animation.
3. Customize colors, shadows, spacing, and animation timing using CSS variables.

---

## 🎨 CSS Variables

:root{
    --bg:#08111f;
    --surface:rgba(255,255,255,.08);
