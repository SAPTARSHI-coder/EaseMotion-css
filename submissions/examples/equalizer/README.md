# CSS Equalizer Bars 🎵

## Overview
The **CSS Equalizer Bars** component simulates music playback using five animated bars.  
It is implemented entirely in **pure CSS**, making it lightweight, responsive, and accessible.

This example expands the EaseMotion CSS library with a ready-to-use animation pattern that developers can drop into their projects without needing JavaScript.

---

## Features
- ✅ Pure CSS animation (`@keyframes bounce`)
- ✅ Responsive across all screen sizes
- ✅ Accessible with `role="img"` and `aria-label`
- ✅ Minimal, reusable design
- ✅ Demo included (`demo.html` + `style.css`)
