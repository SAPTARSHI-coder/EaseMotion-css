# Pulsating Wave Navigation

A responsive navigation component inspired by **Pulsating Wave** styling, built entirely with semantic HTML and Vanilla CSS.

## ✨ Features

- Pulsating wave visual effects
- Animated concentric wave layers
- Fluid gradient typography
- Active and hover navigation states
- Responsive CSS-only mobile navigation
- Dark-mode compatible
- Light-mode compatible
- Keyboard-accessible controls
- Visible focus states
- Reduced-motion support
- Smooth CSS transitions
- No JavaScript
- No external dependencies
