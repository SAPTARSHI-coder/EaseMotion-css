# Ease Keyboard Key

## What does this do?

A keyboard shortcut badge component inspired by GitHub and VS Code documentation, designed to display keyboard shortcuts in a clean and reusable format.

---

## How is it used?

Open `demo.html` in any modern browser.

Example:

```html
<div class="shortcut">
    <kbd>Ctrl</kbd>
    <span>+</span>
    <kbd>K</kbd>
</div>
```

Features:

- Rounded keyboard keys
- Multiple key combinations
- Hover interaction
- Responsive layout

---

## Why is it useful?

Keyboard shortcut badges are commonly used in documentation, tutorials, productivity tools, and developer portals. This lightweight component provides a familiar visual style while fitting EaseMotion CSS's reusable, animation-first philosophy.
