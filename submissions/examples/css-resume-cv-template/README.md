# CSS Resume/CV Template


A responsive one-page resume template built using CSS Grid.


## Features

- Professional resume layout
- CSS Grid based structure
- Responsive mobile design
- Hover animations
- No JavaScript required


## Technologies

- HTML5
- CSS3


## CSS Concepts Used

- CSS Grid
- Media Queries
- Cards
- Transitions
- Responsive Layout


## Accessibility

- Semantic HTML sections
- Proper heading hierarchy
- Readable content structure
