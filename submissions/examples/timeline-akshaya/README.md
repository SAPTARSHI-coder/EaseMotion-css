# Animated Timeline Component

A reusable vertical timeline component for EaseMotion CSS.

The component uses CSS `@keyframes` and `animation-delay` to create a
staggered entry effect for timeline events without requiring JavaScript.

## Features

- Vertical timeline layout
- CSS connector line between events
- Staggered entry animation
- CSS `@keyframes`
- `animation-delay` with `:nth-child()` selectors
- Three dot color variants
- Date, title, and description slots
- Responsive mobile layout
- Dark mode support
- Reduced-motion support
- Accessible content without animation
- No JavaScript dependencies
