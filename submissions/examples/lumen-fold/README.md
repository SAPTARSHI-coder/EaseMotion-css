# Lumen Fold

An interactive light-surface component that creates the illusion of a flexible illuminated sheet folding around the user's pointer.

Lumen Fold combines a responsive grid, radial lighting, pointer tracking, and subtle 3D transformations to create a futuristic interactive surface.

## ✨ Features

- Interactive pointer-driven surface
- Dynamic light propagation
- Soft 3D folding effect
- Responsive layout
- Touch-friendly pointer events
- Glassmorphism-inspired visuals
- Dependency-free
- No JavaScript framework required
- Reduced-motion support
- Lightweight implementation
