# Animated Treeview - Retro Pixel

A responsive animated treeview component inspired by classic
retro and pixel-based interfaces.

Built using pure HTML and CSS with zero external JavaScript
dependencies.

## Features

- Retro pixel-inspired visual design
- CSS-only expandable tree nodes
- Nested directory structure
- Smooth hover interactions
- Animated tree expansion
- Active node state
- Responsive across desktop, tablet, and mobile
- Keyboard focus support
- `prefers-reduced-motion` support
- No external JavaScript dependencies
