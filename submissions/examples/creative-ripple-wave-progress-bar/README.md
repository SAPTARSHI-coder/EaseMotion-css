# CSS Ripple-Wave Progress Bar for Responsive Dashboard Layouts

A modern **Ripple-Wave Progress Bar** component created using only **HTML5 and CSS3**. This showcase demonstrates animated progress indicators with ripple wave effects, smooth transitions, responsive dashboard layouts, and accessibility support without JavaScript.

---

## ✨ Features

- 🌊 Ripple wave animation effect
- 📊 Animated progress indicators
- 💎 Glassmorphism dashboard cards
- ⚡ Lightweight CSS animations
- 🎯 CSS Custom Properties
- 📱 Fully responsive layout
- 🧩 Pure HTML5 & CSS3
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

## 🚀 Usage

1. Open `demo.html` in a modern browser.
2. View animated progress bars.
3. Hover over cards for interactive elevation effects.
4. Customize colors using CSS variables.
