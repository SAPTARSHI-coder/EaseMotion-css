# Complex 3D Paper Unfold/Origami Reveal

A component that folds and unfolds via CSS 3D transforms, pivoting around carefully placed transform origins.

## Features
- Hinge Simulation: Leverages transform-origin to ensure segments fold exactly at their connecting seams.
- Realistic 3D: rotateX creates a physical paper-folding aesthetic.

## Usage
Structure your segments accurately in HTML. The top and bottom classes rely on the hover state of the wrapper to initiate the unfold sequence.
