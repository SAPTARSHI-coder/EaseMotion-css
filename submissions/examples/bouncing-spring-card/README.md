# Bouncing Spring Card

A smooth, responsive and accessible card component featuring a
spring-inspired interaction built entirely with semantic HTML and
vanilla CSS.

## ✨ Features

- Pure HTML and CSS
- No JavaScript
- No external libraries
- Spring-like hover interaction
- Hardware-accelerated transforms
- Responsive layout
- Dark mode support
- Keyboard accessible
- Visible focus states
- Reduced-motion support
- Lightweight implementation
- Semantic HTML structure

## 🎨 Design

The component uses an overshooting CSS cubic-bezier curve to create
a natural spring-like interaction.

The card subtly rises when hovered or focused, while its decorative
elements and icon respond with independent spring transitions.

## 🛠️ Technologies

- HTML5
- CSS3
- CSS Custom Properties
- CSS Grid
- CSS Flexbox
- CSS Transforms
- CSS Transitions
- Media Queries
