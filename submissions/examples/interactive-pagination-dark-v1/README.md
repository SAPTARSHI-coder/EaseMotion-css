# CSS Interactive Pagination (Dark Mode)

A modern, highly interactive, dark-themed pagination navigation component built entirely with pure CSS and semantic HTML.

## 🎯 Features
- **Pure CSS/HTML:** Zero JavaScript required for styling, states, and responsive collapsing.
- **Dark Mode Aesthetics:** Features high-contrast typography, subtle background hovers, and a glowing active state (cyan).
- **Responsive:** Gracefully collapses on mobile viewports (hides middle page numbers to ensure the `Prev` and `Next` buttons remain accessible).
- **Accessible:** Fully semantic list structure (`<nav>`, `<ul>`, `<li>`), keyboard focus rings, and proper ARIA labels (`aria-current="page"`, `aria-label`).
- **Interactive:** Includes smooth hardware-accelerated translations (`translateY`) on hover.
