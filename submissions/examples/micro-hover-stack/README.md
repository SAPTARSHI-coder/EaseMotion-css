# Micro Hover Stack

A stack of cards that separate into a fan the deeper you hover into the pile.

## Features
- Each card lifts at a steeper angle
- Depth grows with hover position
- Shadows sharpen as cards rise

## Usage
```html
<div class="mhs-stack">
  <div class="mhs-card c1"></div>
  <div class="mhs-card c2"></div>
  <div class="mhs-card c3"></div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
