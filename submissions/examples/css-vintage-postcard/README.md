# CSS Vintage Postcard

A retro-inspired postcard component built entirely with CSS featuring a stamp area, message section, address lines, and vintage styling.

## Features

- Pure CSS implementation
- Vintage postcard appearance
- Decorative stamp section
- Responsive layout
- Easy customization using CSS variables
- No JavaScript required

## Usage

```html
<div class="postcard">
  <div class="message">
    <h2>Greetings!</h2>
    <p>Your message here...</p>
  </div>

  <div class="divider"></div>

  <div class="address-section">
    <div class="stamp">✉</div>
  </div>
</div>
```

## Customization

```css
:root {
  --card-bg: #f6e7c1;
  --border: #c9a86a;
  --stamp-bg: #d27d60;
}
```
