# Neumorphic Dropdown with Gradient Styling (#78811)

A tactile neumorphic UI dropdown component featuring dual-cast shadows and vibrant gradient hover effects.

## Features
- **Soft Neumorphic Depth:** Soft extrusion and inset shadows mimicking physical surfaces.
- **Gradient Hover States:** Smooth indigo-to-purple gradient highlights upon list item selection.
- **Fully Responsive:** Adapts fluidly to mobile screen widths with container padding adjustments.

## File Hierarchy
- `style.css` - Neumorphic box shadows, custom properties, and interactive hover states.
- `demo.html` - Semantic dropdown menu markup with proper ARIA attributes.
- `README.md` - Technical specification and architecture overview.
