# CSS Float-Drift Navbar for SaaS Showcase Layouts

A modern **Float-Drift Navbar** built using pure HTML and CSS. The component features a floating glassmorphism navigation bar with a subtle drifting animation, responsive layout, and smooth hover effects for SaaS landing pages.

## ✨ Features

- Pure HTML5 & CSS3
- Floating glassmorphism navbar
- Smooth drift animation
- Responsive navigation layout
- Gradient CTA button
- CSS Custom Properties
- `prefers-reduced-motion` support
- No JavaScript required
