# Dynamic Tooltip — Minimalist

A responsive tooltip component with a clean minimalist visual
style, subtle transitions, multiple placement options, and
keyboard-friendly interaction.

Implemented for issue #79712.

## Features

- Minimalist visual design
- Top, bottom, left and right tooltip positions
- Hover interaction
- Keyboard focus interaction
- Smooth appearance transition
- Responsive mobile layout
- Native buttons
- Accessible tooltip semantics
- CSS-only implementation
- No external dependencies
- Reduced-motion support
