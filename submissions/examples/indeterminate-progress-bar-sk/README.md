# Material Indeterminate Progress Bar

## What does this do?

A Material-style indeterminate bar with primary and secondary query spans.

## How is it used?

```html
<div class="progress-indeterminate" role="progressbar"><span class="bar"></span></div>
```

Open `demo.html` in a browser to try it.

## Why is it useful?

Communicates unknown wait time clearly without core progress changes.
