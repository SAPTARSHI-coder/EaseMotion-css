# CSS Glitch-Flicker Popover for E-Commerce Checkout Layouts

A modern **Glitch-Flicker Popover** built using pure HTML5 and CSS3 for e-commerce checkout interfaces. The component showcases promotional offers inside an animated popover featuring a glitch flicker text effect, responsive design, and accessibility support.

## Features

* Pure HTML5 & CSS3
* Glitch-Flicker text animation
* Interactive hover popover
* Glassmorphism product card
* Modern checkout offer UI
* Responsive desktop, tablet, and mobile layout
* CSS Custom Properties
* Smooth CSS keyframe animations
* No JavaScript required
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over the **Hover for Offer** button to reveal the animated popover.
3. Customize colors and animations using the CSS variables defined in `:root`.
4. Integrate into any e-commerce checkout or product page.
