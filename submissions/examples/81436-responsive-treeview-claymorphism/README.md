# Responsive Treeview — Claymorphism

A responsive claymorphic treeview component built with pure
HTML and CSS for EaseMotion CSS issue #81436.

## Features

- Claymorphism-inspired soft UI
- Interactive expandable folders
- Native HTML `details` and `summary`
- Nested tree structure
- Smooth expand and hover transitions
- File and folder indicators
- Item count badges
- Keyboard focus support
- Responsive desktop, tablet, and mobile layouts
- Small-screen support
- Reduced-motion support
- No external JavaScript dependencies
