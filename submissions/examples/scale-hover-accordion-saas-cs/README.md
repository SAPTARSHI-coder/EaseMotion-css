# Scale Hover Accordion for SaaS Showcase Layouts

A responsive, pure HTML and CSS accordion showcasing SaaS product features with subtle hover scaling and smooth transitions.

## Features

- Pure HTML & CSS
- Responsive layout
- Hover scale interaction
- Smooth expand/collapse animation
- Keyboard accessible
- Semantic `<details>` and `<summary>` structure
- CSS custom properties for easy customization
- Supports `prefers-reduced-motion`
- Compatible with EaseMotion utility animation classes


## CSS Custom Properties

```css
--primary
--hover-scale
--duration
--easing
--radius
--shadow
--surface
--border
```

## Accessibility

- Semantic HTML using `<details>`
- Keyboard accessible
- Visible focus styles
- Skip link
- Reduced motion support
