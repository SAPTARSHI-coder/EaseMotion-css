# Liquid Ripple Hover

A smooth and lightweight **Liquid Ripple Hover** effect built entirely with HTML and vanilla CSS.

## Features

- Pure HTML and CSS
- No JavaScript required
- Smooth liquid ripple animation
- Responsive design
- Keyboard accessible
- `:focus-visible` support
- Reduced-motion support
- Dark and light mode compatible
- Hardware-friendly CSS transforms

## Usage

Add the `liquid-ripple` class to any button or interactive element.

```html
<button class="liquid-ripple" type="button">
  <span>Explore</span>
</button>
