# CSS KPI Metric Card

## Overview

A dashboard-style KPI card with a large metric, trend indicator, animated sparkline, target progress, and comparison values.

## Features

- Prominent KPI value
- Positive trend badge
- Animated seven-period sparkline
- Target progress indicator
- Comparison metrics
- Responsive layout
- Focus-safe native controls
- Reduced-motion support
- Pure HTML and CSS

## Files

- `demo.html` — semantic metric content
- `style.css` — card layout, sparkline animation, progress styling, responsive rules
- `README.md` — documentation

## Usage

Open `demo.html` directly in a modern browser. No dependencies are required.

## Accessibility

The sparkline includes an accessible text description and the demo uses semantic headings and native controls. Motion is disabled for reduced-motion users.
