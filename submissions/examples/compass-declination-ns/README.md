# Compass Declination

## What does this do?
Renders a self-contained CSS-only `ease-compass-declination` demo: Magnetic needle settling with a declination offset mark.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-compass-declination`. No build step or JavaScript is required for the effect.

```html
<section class="ease-compass-declination">
  <div class="ease-compass-declination__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
