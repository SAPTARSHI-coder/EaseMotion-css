# Glassmorphism Profile Card with Dynamic Ambient Glow 8

### Compact Mobile-First Edition

A premium glassmorphism profile card built using pure HTML and CSS. The component combines dynamic ambient glow effects, frosted glass styling, responsive mobile-first design, and accessibility-focused interactions for a modern user experience.

---

## ✨ Features

- Modern glassmorphism interface
- Dynamic ambient glow background
- Frosted glass effect
- Compact mobile-first layout
- Responsive profile card
- Interactive statistics section
- Animated hover effects
- Keyboard accessibility (`:focus-visible`)
- Reduced motion support
- Pure HTML & CSS implementation

## 🚀 Usage

1. Open the component folder.
2. Keep `demo.html` and `style.css` together.
3. Launch `demo.html` in any modern web browser.

No installation or additional dependencies are required.
