# CSS Fade-In Progress Bar for SaaS Showcase Layouts

A modern SaaS-style progress bar component built using only HTML and CSS.

## Features

- Pure HTML & CSS
- Fade-in card animation
- Smooth animated progress bars
- Responsive design
- Modern SaaS dashboard appearance
- No JavaScript required
- Supports prefers-reduced-motion

## Files

```
demo.html
style.css
README.md
```

## Usage

Open `demo.html` in any modern browser.

## Customization

Edit CSS variables inside `:root`.

```css
--blue
--purple
--green
--orange
--card
--bg
```

## Accessibility

- Keyboard friendly
- Reduced motion support
- Responsive layout
