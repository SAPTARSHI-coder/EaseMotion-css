# Smooth Scroll Anchor Position

A responsive CSS-only smooth scroll navigation component with precise anchor positioning.

## Features

- Smooth anchor scrolling
- Fixed navigation bar
- `scroll-margin-top` for accurate anchor positioning
- Responsive navigation
- Smooth hover transitions
- Performance-friendly CSS
- Reduced-motion support
- No JavaScript or external dependencies

## How It Works

The component uses native CSS scrolling behavior:

```css
html {
  scroll-behavior: smooth;
}
