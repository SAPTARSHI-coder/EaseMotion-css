# Floating Elevation Tabs

A modern pure CSS tabs and segmented control featuring a **Floating Elevation** design with soft shadows and lifted active states.

## Features

- Pure HTML & CSS
- Floating elevation animation
- Smooth CSS transitions
- Responsive segmented control
- Dark mode compatible
- Hardware-accelerated animations
- Accessible radio-button implementation
- No JavaScript required
