# CSS Zoom-In Stepper for SaaS Showcase Layouts

A modern onboarding stepper built using pure HTML and CSS. Each step smoothly zooms into view with polished hover effects, making it ideal for SaaS landing pages, onboarding flows, and feature walkthroughs.

## Features

- Pure HTML & CSS
- Zoom-In entrance animation
- Interactive hover effects
- Responsive design
- CSS Custom Properties
- Accessible with `prefers-reduced-motion`
- No JavaScript required
