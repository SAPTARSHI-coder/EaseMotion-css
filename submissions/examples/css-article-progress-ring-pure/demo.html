Article Progress Ring

A pure CSS circular reading progress indicator fixed in the corner, powered by the modern animation-timeline: scroll() API.

Scroll down this page to watch the circular progress ring in the bottom right corner fill up automatically. No JavaScript scroll event listeners are required.

Section 2: Scroll-Driven Animations

The CSS animation-timeline: scroll() property allows us to bind an animation directly to the scroll progression of the document or a specific scroll container.

Section 3: SVG Stroke Animations

To create the circular fill effect, we use the classic SVG stroke-dasharray and stroke-dashoffset trick. We set the dash array to the exact circumference of the circle, and animate the offset from the circumference value down to zero.

Section 4: Conclusion

Combining these two CSS techniques gives us a highly performant, buttery-smooth reading indicator that runs entirely on the browser's compositor thread.
