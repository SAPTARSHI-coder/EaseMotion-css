# Ease Lighthouse Beam Signal (#74828)

An animated, fully-rendered lighthouse UI component with a rotating light beam signal built using pure HTML and Vanilla CSS.

## Features
- **Real UI Component:** Fully styled lighthouse structure including base, tower, lantern room, and sweeping light beam.
- **Pure CSS:** Zero JavaScript dependencies; relies strictly on CSS keyframe animations.
- **Performance:** Smooth 60 FPS rotation using `transform: rotate()` and hardware-accelerated rendering.
- **Accessibility:** Includes `@media (prefers-reduced-motion: reduce)` support to disable rotation for motion-sensitive users.
