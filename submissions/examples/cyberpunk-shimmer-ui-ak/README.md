# Cyberpunk Gradient Shimmer UI

1. What does this do?
Provides a hardware-accelerated, pure CSS sci-fi themed button with an animated gradient shimmer border on hover.

2. How is it used?
```html
<button class="cyberpunk-shimmer-btn-ak">
  <span>Initialize</span>
  <div class="shimmer-layer-ak"></div>
</button>
```

3. Why is it useful?
It creates a complex, dynamic "neon energy" aesthetic using only basic CSS features (conic-gradients, clip-path, and animations) without relying on heavy JS or SVG elements. It is performant, accessible (handles reduced motion), and easily customizable.
