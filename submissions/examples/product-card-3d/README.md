# Product Card 3D

A tilt-on-hover product card with layered shadow, floating badge and a slide-up add button.

## Features
- 3D tilt effect on the whole card
- Floating discount badge and price footer
- Add button slides into view on hover

## Usage
```html
<div class="pc-card">
  <div class="pc-media">&#127871;<span class="pc-badge">-20%</span></div>
  <div class="pc-body"><h3>Product</h3><div class="pc-price">$79</div><button class="pc-add">Add</button></div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
