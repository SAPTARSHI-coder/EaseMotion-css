# Fracture Atlas

Fracture Atlas is an experimental interactive UI component that visualizes
invisible pressure travelling across a fragile material surface.

The user's pointer acts as a pressure source.

Moving across the surface changes the simulated stress, propagation radius,
fracture density, and dynamic fracture lines.

The component intentionally uses fictional measurements to create an artistic
material-response interface rather than attempting to model real-world physics.

## ✨ Features

- Interactive pressure field
- Dynamic stress index
- Dynamic fracture density
- Pointer velocity measurement
- Propagation radius
- Live pressure coordinates
- SVG fracture network
- Procedural dynamic fracture lines
- Pointer Events
- Mouse support
- Touch support
- Responsive layout
- Reduced-motion support
- Dependency-free implementation
