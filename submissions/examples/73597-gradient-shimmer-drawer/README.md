# Gradient Shimmer Drawer

A smooth, responsive, and lightweight **Gradient Shimmer Drawer** built using pure HTML and Vanilla CSS.

Created for EaseMotion CSS issue **#73597**.

## Features

- Gradient shimmer visual effect
- Smooth drawer entrance and exit
- CSS-only interaction
- No JavaScript
- No external dependencies
- Responsive side drawer
- Dark-mode support
- Animated gradient trigger
- Animated shimmer overlay
- Accessible dialog semantics
- Keyboard-focusable controls
- `prefers-reduced-motion` support
- Hardware-accelerated transforms
