# CSS Layered Glow Card

A modern layered glow card component built using pure CSS.

## Features

- Multiple stacked glow layers
- Hover separation animation
- 3D layered effect
- Smooth transitions
- Responsive design
- Keyboard focus support

## Technologies

- HTML5
- CSS3

## Usage

Useful for:

- Portfolio cards
- Product showcases
- Landing pages
- Modern UI sections


## Accessibility

- Keyboard focus support
- Semantic article element
- ARIA label included
