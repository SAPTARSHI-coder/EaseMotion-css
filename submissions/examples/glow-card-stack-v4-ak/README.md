# glow-card-stack-v4-ak

Pure CSS 3D floating stacked cards hover fan-out effect — no JavaScript required.

## How to use

```html
<div class="ease-card-stack-v4">
  <div class="ease-card-stack-item-v4">Top</div>
  <div class="ease-card-stack-item-v4">Middle</div>
  <div class="ease-card-stack-item-v4">Bottom</div>
</div>
