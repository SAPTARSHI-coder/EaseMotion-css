# Accumulator Bladder

## What does this do?
Renders a self-contained CSS-only `ease-accumulator-bladder` demo: Hydraulic accumulator bladder compressing and recovering.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-accumulator-bladder`. No build step or JavaScript is required for the effect.

```html
<section class="ease-accumulator-bladder">
  <div class="ease-accumulator-bladder__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
