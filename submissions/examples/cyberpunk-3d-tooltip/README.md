# CSS 3D Cyberpunk Tooltip

A high-impact, pure CSS tooltip component featuring authentic cyberpunk aesthetics. It utilizes CSS `clip-path` for chamfered corners, multi-layered chromatic `drop-shadow`, and a 3D perspective transform to make the tooltip physically swing outward into view.

## 🎯 Features
- **Pure CSS/HTML:** Zero JavaScript required. Uses `:hover` and `:focus-within` for state management.
- **Hardware-Accelerated 3D:** Applies `perspective` to the parent wrapper and `rotateX` to the tooltip for a smooth, physical popup effect.
- **Cyberpunk Aesthetics:** Integrates high-contrast neon colors, monospace typography, and a synthetic system message prefix using pseudo-elements.
- **Accessible:** Includes `role="tooltip"`, `aria-describedby` linkage, and strips the 3D rotation animation for users who prefer reduced motion.
