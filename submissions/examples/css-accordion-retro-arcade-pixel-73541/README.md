# CSS Accordion - Retro Arcade Pixel

A Retro Arcade Pixel themed accordion component built with pure HTML and CSS. Inspired by classic 8-bit arcade interfaces, it combines pixel-style borders, neon highlights, smooth expand/collapse transitions, and accessible native accordion behavior.

## Features

- Retro arcade pixel aesthetic
- Pure HTML & CSS
- Accessible native `<details>` accordion
- Smooth expand/collapse transitions
- Dark mode friendly
- Hardware accelerated animations
- Responsive design

## Usage

```html
<details class="pixel-accordion">
  <summary>START GAME</summary>
  <div class="content">
    Accordion content goes here.
  </div>
</details>
```
