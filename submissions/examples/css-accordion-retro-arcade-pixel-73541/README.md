# CSS Retro Arcade Pixel Accordion

A Retro Arcade Pixel themed accordion inspired by classic 8-bit gaming interfaces, featuring pixel-style borders, neon arcade colors, and smooth expand/collapse interactions.

## Features

- Pure HTML & CSS
- Retro arcade inspired design
- Pixel-style borders and shadows
- Smooth content reveal animation
- Responsive layout
- Dark mode compatible
- Accessible native accordion behavior
- No JavaScript required

## Usage

```html
<details class="pixel-accordion">
    <summary>START GAME</summary>
    <div class="content">
        Accordion content goes here.
    </div>
</details>
```

## Why it fits EaseMotion CSS

This component adds a nostalgic arcade-inspired UI pattern to the EaseMotion CSS collection while maintaining accessibility, responsiveness, performance, and animation-first design principles.
