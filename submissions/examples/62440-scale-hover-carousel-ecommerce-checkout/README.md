# CSS Scale-Hover Carousel for E-Commerce Checkout Layouts

A modern **Scale-Hover Carousel** built using pure HTML5 and CSS3 for e-commerce checkout layouts. The component showcases featured products inside responsive cards with smooth scale-hover animations, glassmorphism styling, and accessibility support.

## Features

* Pure HTML5 & CSS3
* Scale-Hover card animation
* Product showcase carousel layout
* Glassmorphism UI
* Featured product highlighting
* Smooth CSS transitions & keyframes
* Responsive desktop, tablet, and mobile layout
* CSS Custom Properties
* No JavaScript required
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over product cards to trigger the scale animation.
3. Customize colors, spacing, and animations using the CSS variables in `:root`.
4. Integrate the carousel into any e-commerce landing page or checkout flow.
