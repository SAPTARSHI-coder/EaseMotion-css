# Copy to Clipboard Component

Add ease-copy-to-clipboard-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|---------|
| `--ctc2-accent` | `#6366f1` |
| `--ctc2-green` | `#10b981` |
| `--ctc2-radius` | `10px` |
| `--ctc2-code-bg` | `#0f0f1a` |

## Note

CSS handles the styled code block and copy button. Tiny JS uses Clipboard API.
