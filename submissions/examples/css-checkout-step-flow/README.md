# CSS Checkout Step Flow

A responsive checkout progress flow created entirely with HTML and CSS.

## Features

* Four-step checkout flow
* Cart, Shipping, Payment, and Confirmation steps
* Responsive progress indicator
* Semantic HTML
* Accessible form labels
* Keyboard-friendly controls
* Responsive design
* No JavaScript required
* Reduced-motion support

## Files

* `demo.html` - Checkout flow markup
* `style.css` - Progress indicator, form, buttons, and responsive styling

## Usage

Open `demo.html` in any modern browser to view the checkout step flow.

## Accessibility

The checkout progress indicator uses semantic navigation and an ordered list. The current step is identified with `aria-current="step"`. Form controls have descriptive labels and visible keyboard focus states.

The demo also respects `prefers-reduced-motion` for users who prefer reduced animation.
