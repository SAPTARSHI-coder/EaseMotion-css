# CSS Social Share Buttons

A set of responsive, accessible, animated social media share buttons built with pure CSS.

##  Features
- **Pure CSS Motion:** Smooth elevation scale and icon tilt animation on hover.
- **Accessible:** Semantic links with explicit `aria-label` tags and focus states.
- **Zero Dependencies:** Uses SVG icons and native CSS transitions.

##  Files
- `demo.html` - Interactive demo page displaying social share buttons.
- `style.css` - Component layout, hover transitions, and brand styling.
