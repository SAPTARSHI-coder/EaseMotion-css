# CSS Morph-Glow Navbar for Product Catalog Layouts

A modern **HTML5 & CSS3** navigation component featuring a **Morph-Glow Navbar** designed for product catalog websites. The navigation uses smooth glow transitions, glassmorphism, and responsive layouts without JavaScript.

---

## ✨ Features

- Pure HTML5 & CSS3
- Morph-Glow hover animation
- Glassmorphism navbar
- Responsive navigation
- Product showcase section
- CSS Custom Properties
- No JavaScript required
- Accessible with `prefers-reduced-motion`
