Mesh Gradient

An organic, flowing mesh gradient background built utilizing stacked radial gradients and background-position animation.

Zero Extra DOM Nodes

This vibrant, organic background effect is achieved without cluttering your HTML with dozens of empty <div> elements.

It utilizes a single element with multiple overlapping radial-gradient background images. By animating the background-position and sizing it up to 200%, the colors organically blend and shift across the screen in an infinite loop.
