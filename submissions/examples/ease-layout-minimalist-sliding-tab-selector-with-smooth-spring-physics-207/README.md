# Minimalist Sliding Tab Selector with Smooth Spring Physics (High-Contrast Accessibility Edition)

A responsive sliding tab selector designed for accessibility with high-contrast colors, smooth spring-inspired animations, keyboard-friendly interactions, and a clean modern interface.

## Features

- High-contrast accessibility design
- Smooth spring sliding animation
- Responsive layout
- Keyboard-friendly controls
- Pure HTML, CSS & JavaScript
- Lightweight and reusable

## Folder Structure

```
ease-layout-minimalist-sliding-tab-selector-with-smooth-spring-physics-207/
├── README.md
├── demo.html
├── style.css
└── script.js
```

## Usage

Open `demo.html` in your browser.

Modify colors, spacing and animation values inside `style.css`.
