# CSS Scroll Snap Story

Issue #70343 demonstrates a full-screen vertical story using native CSS scroll snapping.

## Features

- `scroll-snap-type: y mandatory`
- Full viewport story slides
- Keyboard-friendly anchor navigation
- Responsive mobile controls
- Pure HTML and vanilla CSS
- Reduced-motion support

Each slide is a semantic section with a heading and supporting text. The fixed navigation links directly to each slide without JavaScript.

## Files

- `demo.html` — four story sections
- `style.css` — snapping, responsive layout, and navigation
- `README.md` — documentation
