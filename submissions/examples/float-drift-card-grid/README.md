# CSS Float-Drift Card Grid

A responsive card grid featuring subtle floating drift animations built entirely with HTML and CSS.

## Features

- Pure HTML & CSS
- Float drift animation
- Responsive CSS Grid layout
- Hover elevation effect
- Accessible (`prefers-reduced-motion`)
- No JavaScript required

## Folder Structure

```text
float-drift-card-grid/
├── demo.html
├── style.css
└── README.md
```

## Usage

Open `demo.html` in any modern browser.

## Customization

- Card colors
- Border radius
- Animation duration
- Grid spacing
- Typography

## Accessibility

- Supports keyboard navigation
- Responsive across devices
- Reduced motion support
