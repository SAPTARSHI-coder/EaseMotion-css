# Skeleton Pulse Loading Shimmer Placeholder for Card Grids

### Glassmorphic Style

A modern **Skeleton Pulse Loading Placeholder** built with **HTML5** and **CSS3** featuring a glassmorphism card layout, shimmer loading effect, responsive design, and accessibility-friendly animations.

---

## ✨ Features

- Glassmorphism skeleton cards
- Animated shimmer loading effect
- Responsive card grid
- Smooth hover transitions
- CSS Variables
- Mobile-first design
- `prefers-reduced-motion` support
- Pure HTML & CSS
