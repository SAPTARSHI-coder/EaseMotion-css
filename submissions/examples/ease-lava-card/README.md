# 🌋 Lava Card – Glowing Lava Cracks Spread Across Surface

> A fiery, dramatic card where glowing lava cracks spread across the surface on hover, creating a volcanic, eruption-like effect.

---

## 📖 Description

The **Lava Card** is a fiery UI component where glowing lava cracks spread across the surface on hover. When you hover over the card, glowing orange-red cracks erupt from various points, spreading across the dark volcanic surface with a pulsing glow. The effect creates a dramatic, volcanic experience that mimics the look of molten lava breaking through cooled rock.

The component uses CSS animations with `transform` and `keyframes` to create the crack-spreading effect. Each crack has a unique position, size, and animation delay, creating an organic, spreading pattern. The cracks glow with a warm orange-red color, and a pulsing lava glow adds to the volcanic atmosphere.

Perfect for volcanic-themed interfaces, fire brands, gaming websites, and any application where you want to create a dramatic, fiery interaction. The Lava Card transforms a simple card into an erupting volcanic experience.
