# Ripple Wave Modal

A lightweight, responsive modal component featuring a smooth ripple-wave opening animation for creative portfolio layouts. Built entirely with HTML and CSS, this showcase demonstrates modern motion design without relying on JavaScript.

## Features

- Pure HTML5 and CSS3
- CSS-only modal using checkbox toggle
- Smooth ripple-wave opening animation
- Responsive portfolio card layout
- Image hover zoom effect
- CSS Custom Properties for easy customization
- Keyboard-friendly focus styles
- Supports `prefers-reduced-motion`
- Lightweight and performance-focused

submissions/

## Usage

1. Copy the `ripple-wave-modal` folder into `submissions/examples/`.
2. Ensure the EaseMotion CSS library is correctly linked in `demo.html`.
3. Open `demo.html` directly in any modern browser.
4. Click **View Project** to open the ripple-wave modal.

## CSS Custom Properties

| Variable | Description |
|----------|-------------|
| `--bg-color` | Page background color |
| `--surface` | Card and modal background |
| `--text-color` | Primary text color |
| `--muted-color` | Secondary text color |
| `--accent` | Primary accent color |
| `--accent-hover` | Hover state color |
| `--overlay` | Modal backdrop color |
| `--radius` | Border radius |
| `--shadow` | Card shadow |
| `--transition` | Global transition timing |
