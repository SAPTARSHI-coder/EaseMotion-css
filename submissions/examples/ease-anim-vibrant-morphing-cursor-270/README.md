# Custom Morphing Cursor Pointer Trail Effect for Portfolios

### Vibrant Gradient Version

A modern **Custom Morphing Cursor Pointer Trail Effect** built with **HTML5**, **CSS3**, and a small amount of **vanilla JavaScript** for cursor tracking. The component features a vibrant gradient morphing cursor, glowing effects, and a responsive portfolio-style hero section.

---

## ✨ Features

- Vibrant gradient morphing cursor
- Smooth cursor tracking
- Animated glow effects
- Modern portfolio hero section
- Responsive mobile-first layout
- CSS variables for easy customization
- Lightweight vanilla JavaScript
- Keyboard accessibility
- `prefers-reduced-motion` support

## 🚀 Usage

1. Open the component folder.
2. Keep `demo.html` and `style.css` together.
3. Open `demo.html` in any modern browser.
4. Move the cursor across the screen to experience the morphing pointer trail effect.

No build tools or external libraries are required.
