# Radial Circular Progress Indicator with Animated Percentage Counter

### Glassmorphic Style

A modern **Glassmorphic Radial Progress Indicator** built with **HTML5** and **CSS3** featuring a circular animated progress ring, percentage counter, soft glassmorphism effects, and responsive design.

---

## ✨ Features

- Glassmorphism card
- Animated radial progress ring
- Percentage counter
- Circular rotating animation
- Responsive layout
- CSS Variables
- Keyboard-friendly structure
- `prefers-reduced-motion` support
- Pure HTML & CSS
