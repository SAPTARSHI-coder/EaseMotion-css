# Ease Furling Sail Roll

A CSS-only animated sail furling component for EaseMotion CSS.

## Overview

`ease-furling-sail-roll` represents a jib sail rolling tightly around the forestay using smooth CSS animations.

## Features

- Pure CSS animation
- No JavaScript required
- Sail furling motion
- Rotating reel mechanism
- Nautical themed UI
- Responsive design
- Reduced motion support
