Utility Implementation Specifications

📐

Utility Class Target

Class `.ease-anim-fold-out-drop` applies `@keyframes ease-fold-out-drop` directly to any HTML element.

⚡

Hardware Accelerated

Uses GPU-accelerated CSS `transform: perspective() rotateX() translateY()` and `opacity` for smooth 60 FPS motion.

⚙️

Custom Property Control

Supports `--ease-duration` and `--ease-timing` custom CSS properties for dynamic timing customization.

♿

Accessibility Compliant

Includes explicit `@media (prefers-reduced-motion: reduce)` rules to disable 3D folding for sensitive users.
