# Floating Modal — Glassmorphism

A responsive floating modal with a modern glassmorphism
visual style, translucent surfaces, subtle glow effects,
responsive spacing, and accessible native dialog behavior.

Implemented for issue #79843.

## Features

- Glassmorphism modal surface
- Translucent background
- Backdrop blur
- Decorative cyan and purple glow
- Floating depth effect
- Responsive layout
- Native HTML `<dialog>`
- Close button
- Primary and secondary actions
- Responsive feature list
- Keyboard-friendly controls
- Focus-visible styling
- Reduced-motion support
- No external dependencies
