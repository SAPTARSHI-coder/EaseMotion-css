# CSS Typeracer (#71038)

A gamified car racing progress bar inspired by Typeracer, implemented strictly in pure CSS.

## Features
- Pure CSS animation driving car movement along a track using non-linear keyframe interpolation without JavaScript.
- Accessible progress bar element with proper ARIA attributes (`role="progressbar"`).
- Syntax-highlighted typing snippet demonstrating live typing progress states.
- Responsive layout with `prefers-reduced-motion` compliance.
