# CSS Bounce-Pulse Feature Grid for SaaS Showcase Layouts

A modern **Bounce-Pulse Feature Grid** built using pure HTML5 and CSS3 for SaaS showcase layouts. This component presents SaaS features using interactive cards with smooth bounce animations, glowing pulse effects, and a responsive grid structure.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Bounce-Pulse hover animation
* SaaS feature showcase cards
* Animated glowing pulse backgrounds
* Floating feature icons
* Smooth scale and transform effects
* Modern glassmorphism card design
* Responsive CSS Grid layout
* CSS Custom Properties for easy customization
* Smooth transitions and keyframe animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over feature cards to experience the Bounce-Pulse animation.
3. Customize colors, shadows, spacing, and animation timing using CSS variables defined inside `:root`.

## CSS Custom Properties

```css
:root{
  --bg:#eef4ff;
  --surface:rgba(255,255,255,.9);
  --primary:#2563eb;
  --secondary:#06b6d4;
  --accent:#8b5cf6;
  --text:#111827;
  --muted:#64748b;
  --shadow:0 18px 45px rgba(37,99,235,.18);
  --radius:24px;
}
```
