# CSS Ripple-Wave Modal

A responsive modal with a ripple-wave entrance animation built using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Ripple-wave opening animation
- Responsive layout
- Accessible structure
- Supports `prefers-reduced-motion`
- No JavaScript required

## Files

```
demo.html
style.css
README.md
```

## Usage

Open `demo.html` in your browser.

## Customization

Modify these values in `style.css`:

- Background color
- Animation duration
- Modal width
- Border radius
- Button colors
- Shadow intensity

## Accessibility

- Responsive on all devices
- Reduced-motion support
- Semantic HTML
- Keyboard-friendly checkbox toggle
