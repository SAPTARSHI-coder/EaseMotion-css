# Glassmorphism Kbd Key Display - Responsive Breakpoints

Responsive documentation and demo for a glassmorphism keyboard shortcut
display using semantic `<kbd>` elements.

## Features

- Glassmorphism appearance
- Responsive breakpoints
- Semantic keyboard markup
- CSS custom property configuration
- Mobile-friendly layout
- Reduced-motion support

## Basic Markup

```html
<div class="shortcut">
  <span>Save</span>

  <span class="keys">
    <kbd>Ctrl</kbd>
    <kbd>S</kbd>
  </span>
</div>
