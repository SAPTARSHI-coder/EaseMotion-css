CSS :has() Fallback Pattern

A progressive enhancement architecture that gracefully degrades layout and animation logic for older browsers (like Firefox ESR) that do not support the modern :has() parent selector.

The Modern Pattern (:has)

Hover the image. The entire parent card's border turns blue and scales slightly because it :has(:hover) on the child image.

Hover the Image

Modern browsers can style the parent based on child state.

The Fallback Pattern (@supports)

If :has() is unsupported, the browser uses a traditional :focus-within and standard direct hovers as a safe, static fallback, preventing broken layouts.

Falls back to standard CSS rules cleanly via @supports.
