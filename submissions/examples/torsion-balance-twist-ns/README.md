# Torsion Balance Twist (#71084)

A Cavendish-style torsion balance animation component featuring a twisting suspension fiber and angular boom oscillation.

## Features
- Pure CSS damped harmonic oscillation keyframe physics.
- BEM-based human-readable component classes ready for maintainer standardization (`ease-torsion-balance-twist`).
- Fully responsive housing and bezel artwork.
- Accessible with decorative motion hidden via `aria-hidden="true"`.
- Respects `prefers-reduced-motion` settings.
