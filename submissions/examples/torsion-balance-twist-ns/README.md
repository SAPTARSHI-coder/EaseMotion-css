# Torsion Balance Twist

## What does this do?
Renders a self-contained CSS-only `ease-torsion-balance-twist` demo: Cavendish torsion balance fiber twist and boom oscillation.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-torsion-balance-twist`. No build step or JavaScript is required for the effect.

```html
<section class="ease-torsion-balance-twist">
  <div class="ease-torsion-balance-twist__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
