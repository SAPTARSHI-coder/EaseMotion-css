# Lute Pegbox Wind

## What does this do?
Renders a self-contained CSS-only `ease-lute-pegbox-wind` demo: Lute peg winding a course up to pitch.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-lute-pegbox-wind`. No build step or JavaScript is required for the effect.

```html
<section class="ease-lute-pegbox-wind">
  <div class="ease-lute-pegbox-wind__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
