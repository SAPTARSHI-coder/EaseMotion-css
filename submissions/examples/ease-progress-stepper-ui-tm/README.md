# Progress Stepper Component

Add ease-progress-stepper-ui-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|---------|
| `--ps-accent` | `#6366f1` |
| `--ps-done` | `#10b981` |
| `--ps-size` | `32px` |
| `--ps-trans` | `0.4s` |

## Technique

Radio inputs + `:checked` sibling selectors drive step state without JavaScript.
