# Solar Flare Radial Modal

A pure CSS modal inspired by the radial glow and energy of a solar flare.

## Features

- Solar-flare-inspired radial glow
- Smooth modal entrance animation
- Animated radial light effect
- Dark-mode-friendly design
- Accessible dialog structure
- Keyboard-focus indicators
- `prefers-reduced-motion` support
- No external JavaScript libraries
- No external CSS dependencies

## Files

- `demo.html` — standalone demonstration
- `style.css` — modal and animation styles

## Usage

Open `demo.html` directly in a browser.

The modal uses the native HTML `<dialog>` element:

```html
<dialog id="solar-modal" class="solar-modal">
  <div class="modal-content">
    <!-- Modal content -->
  </div>
</dialog>
