# FAQ Accordion Component

Add ease-faq-accordion-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|---------|
| `--faq-accent` | `#6366f1` |
| `--faq-radius` | `10px` |
| `--faq-shadow` | `0 4px 20px rgba(0,0,0,.3)` |

## Note

CSS handles expand/collapse via max-height. Tiny JS toggles open class.
