# CSS Bounce-Pulse Tabs for Product Catalog Layouts

A modern **Bounce-Pulse Tabs** component built using pure HTML5 and CSS3 for product catalog layouts. The component provides responsive category tabs with lively bounce-pulse animations, smooth content transitions, and a clean glassmorphism-inspired interface.

## Features

* Pure HTML5 & CSS3
* Bounce-Pulse tab animation
* CSS-only tab switching using radio buttons
* Product category tabs (Featured, New Arrivals, Trending, Deals)
* Responsive product showcase cards
* Smooth CSS transitions & keyframe animations
* Glassmorphism container design
* CSS Custom Properties for easy customization
* Fully responsive across desktop, tablet, and mobile devices
* No JavaScript required
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Click on a category tab to switch between product sections.
3. Hover over the tabs to view the Bounce-Pulse animation.
4. Customize colors, spacing, border radius, and animation timing using the CSS variables in `:root`.
