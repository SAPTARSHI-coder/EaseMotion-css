# CSS Glitch-Flicker Dropdown for SaaS Showcase Layouts

A modern **Glitch-Flicker Dropdown** component built with pure HTML and CSS for SaaS dashboards, landing pages, and product showcase websites. The component features cyber-inspired glitch animations, flicker effects, smooth hover interactions, and responsive layouts without requiring JavaScript.

---

## Features

- Pure HTML5 & CSS3 implementation
- Modern glassmorphism dropdown panel
- Glitch sweep hover animation
- Flicker reveal transition
- Scan-line overlay effect
- Smooth hover interactions
- Fully responsive design
- CSS Custom Properties for easy customization
- Accessibility support with `prefers-reduced-motion`
- No JavaScript dependency
