# CSS Rotate-Fade Modal for Product Catalog Layouts

A modern **Rotate-Fade Modal** built using **pure HTML and CSS** for showcasing featured products. The modal smoothly rotates and fades into view using CSS transforms and transitions, making it suitable for product catalogs, e-commerce websites, and landing pages.

---

## ✨ Features

- Pure HTML & CSS (No JavaScript)
- Smooth rotate + fade animation
- Product showcase modal
- Responsive layout
- Modern UI design
- Hover interactions
- CSS Custom Properties
- Accessible with `prefers-reduced-motion`

---

## 🚀 Usage

1. Copy the folder into:

```
submissions/examples/rotate-fade-modal-product/
```

2. Open `demo.html` in your browser.

3. Click **View Product** to open the modal.

---

## 🎨 CSS Custom Properties

```css
:root{
    --primary:#4f46e5;
    --secondary:#6366f1;
    --bg:#eef2ff;
    --text:#1f2937;
    --white:#ffffff;
    --radius:20px;
    --transition:.5s ease;
    --shadow:0 20px 50px rgba(0,0,0,.15);
}
```

You can easily customize:

- Primary color
- Secondary color
- Border radius
- Shadow
- Transition speed
