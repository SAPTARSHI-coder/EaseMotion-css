# CSS-only Breadcrumb

Documentation showcase for issue #78667.

## Files

- `demo.html` — semantic breadcrumb markup.
- `style.css` — responsive presentation and interaction styles.

## Features

- Semantic breadcrumb navigation.
- No JavaScript dependency.
- Responsive wrapping on narrow screens.
- Keyboard-visible focus states.
- Clean, reusable CSS structure.

Open `demo.html` in a browser to view the example.
