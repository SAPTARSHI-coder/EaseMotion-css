# Liquid Wave Fill Card

A smooth, accessible and performant CSS-only card featuring a
layered Liquid Wave Fill interaction.

## ✨ Features

- Liquid wave fill effect
- Multiple animated wave layers
- Pure HTML and Vanilla CSS
- No JavaScript
- No external dependencies
- Smooth CSS transitions
- Spring-inspired interactions
- Dark mode support
- Responsive design
- Keyboard accessible
- Reduced-motion support
- Semantic HTML
