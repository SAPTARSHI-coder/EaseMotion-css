# CSS Floating Elevation Variation

A demo project showcasing a **floating elevation effect** using CSS shadows and transforms.

## Features
- Base card with subtle shadows.
- On hover, card "floats" upward with increased shadow layers.
- Smooth transition for realistic elevation change.

## Files
- `demo.html` → Structure with a card element.
- `style.css` → Shadow layering, transform, and transition effects.
- `README.md` → Documentation and usage instructions.

## Usage
1. Open `demo.html` in your browser.
2. Hover over the card.
3. Watch the card elevate and shadows deepen, simulating floating.

## Customization Ideas
- Adjust shadow colors for neon or colored elevation.
- Add keyframe animations for continuous floating (like breathing motion).
- Apply to buttons, modals, or hero sections for interactive depth.
