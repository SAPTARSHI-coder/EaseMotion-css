# Carousel Slider

A scroll-snap carousel with edge peek, dot indicators and buttery magnetic snapping.

## Features
- Horizontal scroll-snap rail that glides between slides
- Dot indicator rail with hoverable slide jump
- Responsive card sizing with edge-peek preview

## Usage
```html
<div class="cs-rail">
  <div class="cs-slide cs-s1">Slide 01</div>
  <div class="cs-slide cs-s2">Slide 02</div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
