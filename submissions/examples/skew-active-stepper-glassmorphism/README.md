# CSS Skew-Active Stepper for Glassmorphism UI Layouts

A modern **pure CSS animated stepper component** featuring glassmorphism styling and skew-based hover interactions.

This component demonstrates how CSS transforms, transitions, and animations can create smooth interactive UI elements without using JavaScript.

---

## ✨ Features

- Pure HTML and CSS implementation
- Glassmorphism card design
- Skew hover interaction
- Active step highlighting
- Smooth transform animations
- Responsive layout
- Lightweight and framework-free
- `prefers-reduced-motion` accessibility support
