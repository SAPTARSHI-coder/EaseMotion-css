# Floating Aura Avatar Profile Ring with Rotating Dual Gradients

### Cyberpunk Theme

A modern **Floating Aura Avatar Profile Ring** built using **HTML5** and **CSS3**. This component showcases a cyberpunk-inspired profile card featuring rotating dual gradient rings, floating aura effects, glassmorphism, neon lighting, and smooth hover animations.

---

## ✨ Features

- Cyberpunk-inspired design
- Rotating dual gradient profile ring
- Floating neon aura animation
- Glassmorphism profile card
- Smooth hover interactions
- Responsive layout
- CSS Variables for easy customization
- Keyboard accessibility
- `prefers-reduced-motion` support
- No external frameworks required

## 🚀 Usage

1. Navigate to the component folder.
2. Keep `demo.html` and `style.css` in the same directory.
3. Open `demo.html` in any modern browser.
4. Hover over the avatar card to experience the cyberpunk floating aura and rotating gradient ring.

No build tools or dependencies are required.
