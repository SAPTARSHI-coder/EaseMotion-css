# CSS Ripple-Wave Pricing Table

A modern **CSS Ripple-Wave Pricing Table** built entirely with **HTML5** and **CSS3**. This showcase presents a responsive pricing table with a smooth ripple-wave hover animation, minimalist tech styling, and accessibility-friendly interactions—all without JavaScript.

---

## ✨ Features

- 🚀 Pure HTML5 & CSS3
- 🌊 Ripple-wave hover animation
- 💳 Three responsive pricing plans
- ⭐ Featured "Most Popular" plan
- 📱 Fully responsive layout
- ♿ Keyboard-accessible buttons
- 🎨 Easy customization using CSS Custom Properties
- 🌙 Supports `prefers-reduced-motion`
- ⚙️ No JavaScript or external libraries

## 🚀 Usage

1. Open `demo.html` in a modern web browser.
2. Hover over a pricing card to see the ripple-wave animation.
3. Use the buttons to preview the call-to-action styles.
4. Customize colors, spacing, and typography using the CSS custom properties.

---

## 🎨 CSS Custom Properties

| Variable | Description |
|----------|-------------|
| `--bg` | Page background color |
| `--surface` | Card background |
| `--primary` | Primary accent color |
| `--secondary` | Secondary accent color |
| `--text` | Primary text color |
| `--muted` | Secondary text color |
| `--border` | Card border color |
| `--radius` | Card border radius |
| `--shadow` | Card shadow |
| `--transition` | Transition timing |

Example:

```css
:root{
    --primary:#2563eb;
    --secondary:#38bdf8;
}
```
