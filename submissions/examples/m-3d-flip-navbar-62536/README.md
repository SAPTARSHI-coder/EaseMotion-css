# CSS 3D-Flip Navbar for E-Commerce Checkout Layouts

A modern **3D-Flip Navbar** built using pure HTML and CSS. The navigation bar features elegant 3D flip hover animations, premium glassmorphism styling, responsive layouts, and smooth interactions suitable for e-commerce checkout pages.

## ✨ Features

- Pure HTML5 & CSS3
- 3D flip hover animation
- Glassmorphism navbar
- Responsive checkout layout
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
