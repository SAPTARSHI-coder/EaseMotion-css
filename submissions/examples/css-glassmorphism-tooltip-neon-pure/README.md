# Glassmorphism Tooltip with Neon Styling

A striking cyberpunk-inspired tooltip that combines frosted glass aesthetics (`backdrop-filter`) with vibrant neon glowing borders and shadows.

## Features
- Pure CSS implementation using the `:hover` pseudo-class
- Authentic frosted glass effect utilizing `backdrop-filter: blur`
- Cyberpunk dual-tone neon borders (Cyan top, Pink bottom)
- Responsive multi-layered drop shadows for intense neon glowing effect
- CSS triangle arrows carefully layered to maintain the glassmorphism aesthetic
- Smooth spring-like entrance animation (`cubic-bezier`)

## Usage
Include `demo.html` and `style.css` in your project. Ensure the tooltip is placed over a visually interesting background (like the provided neon orb and grid) for the frosted glass blur to take effect properly.
