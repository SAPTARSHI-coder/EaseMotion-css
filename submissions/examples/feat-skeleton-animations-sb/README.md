# Skeleton Loading Animation Variants

## 1. What does this do?
Adds multiple animation styles for skeleton loading components.

## 2. How is it used?
```html
<div class="ease-skeleton ease-skeleton-wave"></div>
<div class="ease-skeleton ease-skeleton-pulse"></div>
<div class="ease-skeleton ease-skeleton-fade"></div>
```

## 3. Why is it useful?
Different animation styles provide flexibility for various loading contexts.
