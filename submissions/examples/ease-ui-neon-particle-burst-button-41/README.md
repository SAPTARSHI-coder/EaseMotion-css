# Particle Burst Action Button for High-Conversion CTA Triggers

### Dark Mode Variant

A modern **Particle Burst Action Button** built with **HTML5** and **CSS3**. The component features a dark mode interface with vibrant neon gradients, a particle burst hover effect, smooth micro-interactions, and a fully responsive layout.

---

## ✨ Features

- Dark mode UI
- Particle burst hover animation
- Neon gradient CTA button
- Responsive design
- Smooth hover & active interactions
- CSS variables for easy customization
- Pure HTML & CSS implementation
- Keyboard accessibility
- `prefers-reduced-motion` support

## 🚀 Usage

1. Open the component folder.
2. Keep `demo.html` and `style.css` in the same directory.
3. Open `demo.html` in any modern browser.
4. Hover over the button to see the particle burst animation.

No installation or external libraries are required.
