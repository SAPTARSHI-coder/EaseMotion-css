# Magic Text Reveal Component

Add ease-magic-text-reveal-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|---------|
| `--mtr-accent` | `#6366f1` |
| `--mtr-accent2` | `#ec4899` |
| `--mtr-size` | `clamp(2rem,6vw,4rem)` |
| `--mtr-weight` | `900` |

## Technique

`transform: translateY(100%)` animates to `translateY(0)` with staggered delays for cinematic reveal.
