# Retro Arcade Pixel Toggle (#73882)

A pure HTML & Vanilla CSS toggle featuring pixelated box shadows and retro arcade gaming styling.

## Features
- **Aesthetic:** Crisp 8-bit arcade styling with blocky pixel box shadows and bold borders.
- **Pure CSS:** Zero JavaScript dependencies; uses standard CSS state selectors.
- **Performance:** Stepped transform steps for authentic retro movement.
- **Accessibility:** Keyboard focus ring support via `:focus-visible` and `@media (prefers-reduced-motion: reduce)` media query integration.
