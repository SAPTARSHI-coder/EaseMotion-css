# CSS DNA Unwrap Loader

A pure CSS loading animation inspired by a DNA double helix. The strands smoothly unwind and rewind in a continuous loop, creating an engaging visual effect without JavaScript.

## Features

- Pure CSS implementation
- DNA-inspired helix animation
- Smooth unwind and rewind motion
- Responsive design
- Accessible loader markup
- Lightweight and reusable

## Usage

```html
<div class="dna-loader" aria-label="Loading" role="status">
  <span></span>
  <span></span>
  <span></span>
  <span></span>
  <span></span>
  <span></span>
  <span></span>
  <span></span>
</div>
```

Link the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

## How it Works

The loader consists of multiple paired elements representing DNA strands. CSS keyframe animations rotate and translate the strands to simulate a helix unwinding and rewinding effect.

## Why it fits EaseMotion CSS

This component adds a unique and visually appealing loader animation to the EaseMotion CSS library. It demonstrates advanced motion design techniques using only CSS while remaining lightweight, reusable, and easy to customize.
