# Sticky Header Scroll Component

Add ease-sticky-header-scroll-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|--------|
| `--sh-accent` | `#6366f1` |
| `--sh-height` | `64px` |
| `--sh-blur` | `12px` |
| `--sh-shadow` | `0 2px 16px rgba(0,0,0,.4)` |

## Note

CSS handles sticky positioning and blur. Tiny JS adds `scrolled` class for shadow.
