# 🌸 Lotus Bloom – Lotus Flower Slowly Opens

> A sacred lotus component where petals slowly unfold with 4 styles (Pink, White, Purple, Golden), bloom control, and graceful animation.

---

## 📖 Description

The **Lotus Bloom** component creates a sacred lotus flower experience where petals slowly and gracefully unfold. Built with vanilla HTML, CSS, and JavaScript, it features 4 lotus styles (Pink, White, Purple, Golden), bloom control (0-100%), and organic petal animation.

### 🎯 Core Features

- **Sacred lotus** – petals slowly unfold with organic motion
- **4 styles** – Pink (🌸), White (🤍), Purple (💜), Golden (🌟)
- **Bloom control** – adjust bloom from 0-100% with slider
- **4 petal layers** – outer, mid, inner, and center petals
- **Water effects** – ripples and reflections
- **Bloom counter** – shows current bloom percentage
- **Interactive controls** – slider, buttons, keyboard shortcuts
- **Responsive design** – adapts to different screen sizes

| Method | Action |

### ✨ Bloom Experience

When blooming:
1. **Petals unfold** – multiple layers open gracefully
2. **Bloom applies** – controls petal openness
3. **Style applies** – changes lotus colors
4. **Water effects** – ripples and reflections
5. **Status updates** – shows current state

### 🛠️ Technologies Used

- **HTML5** – semantic structure with Canvas
- **CSS3** – gradients, backdrop-filter, transforms
- **JavaScript (ES6)** – Canvas API, requestAnimationFrame, animation system

### 🎨 Design Philosophy

This component embodies **EaseMotion CSS's animation-first philosophy** through:

- **Organic motion** – petals unfold with graceful animation
- **Layered petals** – multiple layers create depth
- **Visual feedback** – status updates, counter, controls
- **Sacred atmosphere** – serene colors and water effects
- **Human-readable classes** – `.lotus-controls`, `.style-btn`, `.lotus-text`

### 🔧 Customization Options

| Property | Location | Default |
|----------|----------|---------|
| Styles | `lotusStyles` object | 4 styles |
| Bloom range | `bloomSlider` | 0-100% |
| Petal layers | `petalLayers` array | 4 layers |
| Animation speed | `animateBloom()` | 0.06 interpolation |
