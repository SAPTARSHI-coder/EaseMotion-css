# CSS Skew-Active Pricing Table for SaaS Showcase Layouts

A modern **Skew-Active Pricing Table** built using pure HTML5 and CSS3 for SaaS showcase layouts. This component creates dynamic pricing cards with skew transformations, animated active states, gradient accents, and responsive layouts.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Skew transform hover effects
* Animated active pricing plan
* SaaS pricing card showcase
* Multiple pricing tiers:

  * Starter
  * Professional
  * Enterprise
* Highlighted recommended plan
* Gradient shape decorations
* Smooth elevation effects
* Glassmorphism pricing cards
* Responsive CSS Grid layout
* CSS Custom Properties for easy customization
* Smooth transitions and keyframe animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over pricing cards to experience skew-active animations.
3. The Professional plan includes an animated active state.
4. Customize colors, shadows, spacing, and animations using CSS variables inside `:root`.

## CSS Custom Properties

```css
:root{
  --bg:#eef4ff;
  --surface:rgba(255,255,255,.92);
  --primary:#2563eb;
  --secondary:#06b6d4;
  --accent:#8b5cf6;
  --text:#111827;
  --muted:#64748b;
  --shadow:0 18px 45px rgba(37,99,235,.18);
  --radius:26px;
}
```
