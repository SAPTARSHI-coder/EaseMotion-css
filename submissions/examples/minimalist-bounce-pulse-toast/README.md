# CSS Bounce-Pulse Toast

A modern **CSS Bounce-Pulse Toast** built entirely with **HTML5** and **CSS3**. This showcase demonstrates lightweight toast notifications with a smooth bounce-pulse animation, responsive design, and accessibility support—all without requiring JavaScript.

---

## ✨ Features

- 🚀 Pure HTML5 & CSS3
- 🎯 Bounce-pulse animation
- ✅ Success and information toast variants
- 💻 Minimalist tech-inspired design
- 📱 Fully responsive layout
- ♿ Accessible with `role="status"` and `aria-live="polite"`
- 🎨 Easy customization using CSS Custom Properties
- 🌙 Supports `prefers-reduced-motion`
- ⚙️ No JavaScript or external libraries

## 🚀 Usage

1. Open `demo.html` in any modern web browser.
2. The toast notifications display a subtle bounce-pulse animation.
3. Customize the icons, messages, colors, and spacing as needed.
4. Modify the CSS custom properties to match your project theme.

---

## 🎨 CSS Custom Properties

| Variable | Description |
|----------|-------------|
| `--bg` | Page background color |
| `--surface` | Toast background |
| `--success` | Success accent color |
| `--info` | Information accent color |
| `--text` | Primary text color |
| `--muted` | Secondary text color |
| `--border` | Border color |
| `--radius` | Border radius |
| `--shadow` | Toast shadow |
| `--transition` | Transition timing |

Example:

```css
:root{
    --success:#16a34a;
    --info:#2563eb;
}
```
