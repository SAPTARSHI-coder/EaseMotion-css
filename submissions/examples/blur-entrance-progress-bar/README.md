# CSS Blur-Entrance Progress Bar

A pure CSS, smooth blur-entrance progress bar component designed for product catalog layouts to reveal stock status or funding progress upon hover.

## Features
- Pure CSS and HTML implementation.
- Smooth un-blur (filter) and scale transformations on hover.
- Staggered entrance for the progress bar and status text.
- Fully responsive across desktop, tablet, and mobile.
- Follows the `prefers-reduced-motion` accessibility standards.

## Usage
Open `demo.html` in your browser. Hover over the product card to see the progress bar un-blur, scale in, and reveal the stock information underneath.

## Files
- `demo.html`: The HTML structure for the card component.
- `style.css`: The styling, flexbox layouts, and CSS transitions.
