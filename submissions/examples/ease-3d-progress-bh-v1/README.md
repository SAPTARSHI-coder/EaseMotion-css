# ease-3d-progress-bh

Pure CSS 3D flip progress bar component.

## What does this do?
Creates animated progress bars with 3D flip/fold animation effects.

## How is it used?
```html
<div class="ease-3d-progress-bh">
  <div class="ease-3d-progress-fill-bh" style="--progress: 75%"></div>
</div>
```

## Why is it useful?
Creates visually engaging progress indicators with immersive 3D animations.
