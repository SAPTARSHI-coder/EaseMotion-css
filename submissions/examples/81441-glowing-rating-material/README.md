# Glowing Rating — Material Design

A responsive glowing rating component inspired by
Material Design principles, implemented entirely with
HTML and CSS for EaseMotion CSS issue #81441.

## Features

- Material-inspired surface and elevation
- Glowing star rating
- Animated star glow
- Animated rating progress bars
- Material-style primary purple accent
- Subtle hover elevation
- Interactive visual feedback
- Responsive desktop, tablet and mobile layouts
- CSS custom properties
- `prefers-reduced-motion` support
- Zero JavaScript dependencies
