# Calorimeter Stir

## What does this do?
Renders a self-contained CSS-only `ease-calorimeter-stir` demo: Calorimeter stirrer mixing a thermal sample bath.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-calorimeter-stir`. No build step or JavaScript is required for the effect.

```html
<section class="ease-calorimeter-stir">
  <div class="ease-calorimeter-stir__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
