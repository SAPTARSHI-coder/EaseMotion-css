# Interactive Neon Dropdown (Variant B)

A responsive and clean Interactive Dropdown component built with pure HTML and CSS.

## Features

- Neon-inspired futuristic styling
- Click-to-open interaction using CSS
- Smooth dropdown transitions
- Responsive layout
- Keyboard focus support
- No JavaScript required
- No external dependencies
