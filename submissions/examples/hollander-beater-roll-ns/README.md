# Hollander Beater Roll

## What does this do?
Renders a self-contained CSS-only `ease-hollander-beater-roll` demo: Hollander beater roll fibrillating rag pulp.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-hollander-beater-roll`. No build step or JavaScript is required for the effect.

```html
<section class="ease-hollander-beater-roll">
  <div class="ease-hollander-beater-roll__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
