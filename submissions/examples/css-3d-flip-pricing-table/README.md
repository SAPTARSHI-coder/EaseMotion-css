# CSS 3D-Flip Pricing Table

A responsive SaaS pricing table featuring a smooth 3D card-flip interaction using only HTML and CSS.

## Features

- Pure HTML and CSS
- 3D flip animation using `transform: rotateY()`
- No JavaScript required
- Responsive desktop, tablet, and mobile layouts
- CSS custom properties for easy customization
- Keyboard-friendly focus interaction
- Accessible reduced-motion support
- Lightweight and dependency-free
