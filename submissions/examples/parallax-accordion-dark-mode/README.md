# Parallax Accordion - Dark Mode

A responsive accordion component built using pure HTML and CSS.

## Features

- Dark mode interface
- Parallax-style hover effect
- Smooth opening animation
- Responsive design
- No JavaScript required
- Semantic HTML using `<details>` and `<summary>`
- Reduced-motion support

## Files

- `index.html` - Component structure
- `style.css` - Styling and animations

## Usage

Open `index.html` in any modern web browser.

No dependencies or installation are required.

## Customization

You can customize the component by changing the CSS variables in `style.css`:

```css
:root {
  --bg: #090b10;
  --card: #11151d;
  --text: #f4f7fb;
  --muted: #98a2b3;
  --accent: #7c5cff;
  --border: #252c38;
}
