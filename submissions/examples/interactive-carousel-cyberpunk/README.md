# Interactive Carousel - Cyberpunk Styling

A responsive interactive carousel with a futuristic cyberpunk-inspired
design using HTML and CSS.

## Features

- Cyberpunk-inspired UI
- Responsive desktop and mobile layouts
- Interactive hover expansion
- Horizontal scrolling on smaller screens
- Neon cyan and pink visual effects
- CSS grid background
- Smooth transitions
- No JavaScript required
- Reduced-motion support
