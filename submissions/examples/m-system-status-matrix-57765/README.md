# System Status Dashboard Matrix

A responsive **System Status Dashboard Matrix** built using pure HTML5 and CSS3 for monitoring service availability.

## ✨ Features

- Pure HTML5 & CSS3
- Animated pulsing status indicators
- System operational banner
- 90-day uptime matrix
- Pure CSS tooltips using `data-tooltip`
- Responsive layout
- CSS Custom Properties
- `prefers-reduced-motion` support
