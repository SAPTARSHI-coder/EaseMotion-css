# Elastic Underline Expand Hover

A premium hover interaction for navigation links where the underline scales outward from the center with an elastic, spring-like motion.

---

## What does this do?

This feature adds an elastic underline hover effect to links, making the underline expand smoothly from the center with a springy easing curve.

## How is it used?

Use the `.elastic-link` class on any inline link or navigation item:

```html
<a href="#" class="elastic-link">Dashboard</a>
```

## Why is it useful?

It improves navigation micro-interactions by adding tactile motion, while keeping the effect lightweight and CSS-only for easy integration into EaseMotion CSS.
