# CSS Float-Drift Modal for Gaming Hub Layouts

A modern **Gaming Hub Modal** built entirely with **HTML5 and CSS3**. This showcase demonstrates an elegant **Float-Drift Modal** featuring floating animations, neon-inspired visuals, glassmorphism styling, responsive layouts, and accessibility support without requiring JavaScript.

---

## ✨ Features

- 🎮 Gaming Hub inspired modal
- 🌊 Float-Drift animation
- 💎 Glassmorphism modal
- 🌈 Neon gradient accents
- ✨ Floating background particles
- 📱 Fully responsive
- ⚡ Pure HTML5 & CSS3
- 🎯 CSS Custom Properties
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

## 🚀 Getting Started

1. Open `demo.html` in any modern browser.
2. Click **Launch Gaming Modal**.
3. Experience the floating modal animation and glowing gaming interface.
4. Customize colors, spacing, and animation timing using CSS variables.
