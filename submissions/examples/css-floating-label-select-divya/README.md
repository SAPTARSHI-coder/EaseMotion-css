# CSS Floating Label Select

A responsive floating-label select dropdown built using pure CSS.

## Features

- Pure CSS implementation
- No JavaScript required
- Floating label animation
- Responsive design
- Keyboard accessible
- Native select functionality
- Custom dropdown arrow

## Usage

Include `demo.html` and `style.css` in the same folder and open `demo.html` in a browser.

## Files

- `demo.html` - HTML structure
- `style.css` - Styling and floating-label animation

## Accessibility

The select element is associated with its label using the `for` and `id` attributes and can be operated using keyboard navigation.

## Technologies

- HTML5
- CSS3
