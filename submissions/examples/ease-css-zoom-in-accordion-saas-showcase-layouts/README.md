# CSS Zoom-In Accordion for SaaS Showcase Layouts

A modern SaaS-style accordion component featuring smooth zoom-in reveal animations built completely with pure HTML and CSS.

This component is designed for SaaS dashboards, product showcases, and landing pages where interactive content sections are required without JavaScript.


## ✨ Features

- 🔍 Smooth zoom-in accordion animation
- 📦 Modern SaaS showcase layout
- 🎨 Glassmorphism inspired UI
- ⚡ Pure HTML and CSS implementation
- 📱 Fully responsive design
- 🔄 CSS transitions and keyframe animations
- ♿ prefers-reduced-motion accessibility support
- 🚀 Lightweight and framework-free

## 🚀 Usage

1. Open `demo.html` directly in your browser.

2. Click any accordion section to expand the content.

3. Customize CSS variables inside `style.css` to match your SaaS branding.


## 🎨 CSS Custom Properties

The component uses CSS variables for easy customization:

```css
:root {

    --bg:#020617;
    --card:#0f172a;
    --primary:#38bdf8;
    --secondary:#8b5cf6;
    --text:#f8fafc;
    --muted:#94a3b8;

}

Modify these variables to create your own color theme.

The component supports users who prefer reduced motion.

Animations and transitions are minimized for improved accessibility.
