Nested Animation Delay Fix

Solving the cascading inheritance bug where nested animated elements improperly inherit or compound their parent's animation delays.

The Bug Context

When a parent container fades in with a delay, and a child element inside it has its own continuous animation (like a spinning loading icon), some browsers compound the delay, causing the child to freeze unexpectedly.
