# Floating Footer with Neon Styling

A futuristic floating footer component built with pure HTML and CSS.

The component combines a glass-like dark surface with neon cyan and purple accents, responsive navigation, social buttons, and subtle hover interactions.

## ✨ Features

- Floating footer layout
- Neon-inspired visual styling
- Cyan and purple glow accents
- Responsive navigation
- Social action buttons
- Smooth hover interactions
- Soft glassmorphism surface
- Responsive across desktop, tablet, and mobile
- Pure HTML and CSS
- Zero external JavaScript dependencies
- CSS custom properties for reusable design tokens
- `prefers-reduced-motion` support
