# ease-rotate-modal-bh

Pure CSS rotate-fade modal for fintech dashboards.

## Features
- Rotate-fade hover effect
- Modal variants
- Responsive design
- Accessibility support

## Usage
```html
<div class="ease-modal ease-modal-rotate">Content</div>
```

## CSS Classes
- `.ease-modal` - Base modal
- `.ease-modal-rotate` - Rotate-fade effect
