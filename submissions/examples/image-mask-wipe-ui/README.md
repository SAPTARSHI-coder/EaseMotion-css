# Image Mask Wipe

An image is revealed through a circular mask that expands outward.

## Features
- Mask-expansion reveal
- Soft feathered edge
- Loops automatically
- Pure CSS

## Usage
```html
<div class="imw-img"></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
