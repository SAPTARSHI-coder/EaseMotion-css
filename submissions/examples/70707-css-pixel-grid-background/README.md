# CSS Pixel Grid Background

## Overview

A responsive retro pixel grid background made entirely with HTML and CSS. Individual grid cells animate with staggered timing so color changes travel through the field organically.

## Features

- Pure CSS implementation
- Staggered cell animation
- Responsive grid density
- Decorative semantic separation
- Keyboard-safe surrounding content
- Reduced-motion support
- No JavaScript or dependencies

## Files

- `demo.html` — accessible demo structure
- `style.css` — grid layout, animation, responsive rules, and motion preferences

## Usage

Open `demo.html` in a modern browser. The component requires no build step.

## Accessibility

The animated grid is decorative and is hidden from assistive technology with `aria-hidden`. Important information is presented as normal HTML outside the decorative layer. Reduced-motion preferences disable the animation.
