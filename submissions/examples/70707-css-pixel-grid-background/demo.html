Component notes

Designed for interfaces

01

Independent cells

Grid items use staggered delays so the field never moves as one solid layer.

02

Responsive grid

The number and size of cells adapt at smaller breakpoints without scripts.

03

Decorative layer

The animation is marked decorative so important interface content remains semantic.

04

Reduced motion

The motion is disabled when the visitor asks the operating system to reduce animation.
