# Hover Badge with SaaS Modern Styling

A clean and responsive SaaS-style hover badge collection built with pure HTML and CSS.

The component provides multiple badge variants with subtle hover motion, soft elevation, and modern dashboard-friendly styling.

## ✨ Features

- SaaS-inspired modern design
- Multiple badge variants
- Smooth hover interactions
- Soft elevation effects
- Subtle accent shadows
- Responsive layout
- Pure HTML and CSS
- Zero external JavaScript dependencies
- CSS custom properties for design tokens
- `prefers-reduced-motion` support
