# Hover Tab Bar with Pastel styling (#78885)

A fully responsive, fluid tab bar component featuring soft pastel hover fills, subtle lift elevation, and clean ARIA accessibility controls built using pure CSS.

## Features
- **Semantic ARIA Structure:** Built with `<nav>` and appropriate `role="tablist"` / `role="tab"` attributes.
- **Pastel Interactive Fills:** Soft color transitions (`--pastel-purple` and `--pastel-pink`) on hover/focus triggers.
- **Responsive Layout:** Flexbox-driven container ensuring seamless scaling across desktop and mobile screens.

## File Hierarchy
- `style.css` - CSS variables, hover state transitions, and responsive flex alignment rules.
- `demo.html` - Accessible HTML structure showcasing the tab navigation layout.
- `README.md` - Technical specification and architecture summary.
