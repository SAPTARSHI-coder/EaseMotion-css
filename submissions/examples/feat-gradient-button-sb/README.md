# Gradient Button Variant

## 1. What does this do?
Adds a new `.ease-btn-gradient` class that provides a modern gradient button with animated hover effect.

## 2. How is it used?
```html
<button class="ease-btn ease-btn-gradient">Gradient Button</button>
```

## 3. Why is it useful?
Creates eye-catching call-to-action buttons with smooth gradient animations.
