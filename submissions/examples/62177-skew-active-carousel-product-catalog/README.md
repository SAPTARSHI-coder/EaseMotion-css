# CSS Skew-Active Carousel for Product Catalog Layouts

A modern **Skew-Active Carousel** component built using pure HTML5 and CSS3 for product catalog showcase layouts. This component creates an interactive product browsing experience with skew transformations, active card emphasis, smooth transitions, and responsive design.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Modern product catalog carousel
* Skew transformation effects
* Active product card highlighting
* Smooth hover interactions
* 3D perspective styling
* Animated product images
* Gradient CTA buttons
* Responsive desktop, tablet, and mobile layouts
* CSS Custom Properties for easy customization
* Lightweight CSS animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over product cards to experience skew and elevation effects.
3. The active card appears highlighted with enhanced scale and positioning.
4. Customize colors, shadows, spacing, and animation values using CSS variables inside `:root`.

## CSS Custom Properties

```css
:root{
  --bg:#f8fafc;
  --surface:#ffffff;
  --primary:#2563eb;
  --secondary:#06b6d4;
  --accent:#8b5cf6;
  --text:#111827;
  --muted:#64748b;
  --shadow:0 30px 80px rgba(37,99,235,.2);
  --radius:30px;
}
```
