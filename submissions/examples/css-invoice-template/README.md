# CSS Invoice Template

A modern, responsive and accessible invoice template built using pure HTML and
Vanilla CSS for the EaseMotion CSS library.

## ✨ Features

- 📄 Professional invoice layout
- 📱 Fully responsive design
- 🌙 Automatic dark-mode support
- 🖨️ Print-friendly A4 layout
- ♿ Semantic and accessible HTML
- ⌨️ Keyboard-friendly links and focus states
- 🎨 Modern visual hierarchy
- ✨ Smooth CSS micro-interactions
- ⚡ No JavaScript
- 🚀 Hardware-friendly CSS animations
- 📊 Invoice items, tax, discount and total sections
- 💳 Payment status and payment information
- 🎯 Reduced-motion support
