# CSS Sword Slash Button

A pure CSS button interaction featuring a diagonal sword-like slash
that sweeps across the button when the user hovers over or focuses it.

## Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Diagonal sword slash effect
- Glowing blade effect
- Hover interaction
- Keyboard focus interaction
- Responsive design
- Accessible button markup
- `prefers-reduced-motion` support
