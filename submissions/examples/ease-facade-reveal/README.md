# Facade Reveal · Building Facade with Windows Lighting 🏢

An interactive building facade reveal with windows lighting up floor by floor, creating a beautiful architectural illumination effect.

## Features

- 🏢 **Building Facade** – Detailed building with windows
- ✨ **Floor-by-Floor Reveal** – Windows light up sequentially
- 🎚️ **Speed Control** – Adjust reveal speed (1-10)
- 🎚️ **Floor Control** – Adjust number of floors (3-10)
- 💡 **Window Lighting** – Warm glow with flicker effect
- 🌙 **Night Atmosphere** – Starry sky background
- ⏸️ **Pause/Resume** – Toggle animation
- 🔄 **Reset** – Reset to dark facade

## How to Use

1. Click **REVEAL** or press **Space** to start the reveal
2. Watch windows light up floor by floor
3. Adjust **Speed** for faster/slower reveal
4. Adjust **Floors** for building height
5. Press **RESET** or **R** to reset
6. Press **PAUSE** or **P** to pause/resume animation
