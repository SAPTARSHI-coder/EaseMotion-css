# ✨ Glitter Sparkle – Sparkles Like Glitter When Touched

> An interactive glitter sparkle component that creates shimmering, sparkling particles when touched or clicked, with 4 styles (Rainbow, Gold, Silver, Holographic).

---

## 📖 Description

The **Glitter Sparkle** component creates a magical glitter effect with shimmering, sparkling particles that burst when touched or clicked. Built with vanilla HTML, CSS, and JavaScript, it features 4 styles (Rainbow, Gold, Silver, Holographic), particle physics, and interactive controls.

### 🎯 Core Features

- **Glitter particles** – 30-60 particles burst on touch with physics
- **4 styles** – Rainbow (multi-color), Gold (golden shimmer), Silver (metallic), Holographic (iridescent)
- **Particle physics** – gravity, friction, rotation, and shimmer animation
- **Two shapes** – star and circle particles with glow effects
- **Sparkle counter** – tracks total sparkles created
- **Overlay sparkles** – additional CSS-based sparkles for extra shimmer
- **Interactive controls** – click/touch, buttons, keyboard shortcuts
- **Responsive design** – adapts to different screen sizes

### ✨ Glitter Styles

| Style | Colors | Description |
|-------|--------|-------------|
| **Rainbow** | Multi-color | Colorful glitter burst |
| **Gold** | Gold/Yellow | Warm golden sparkle |
| **Silver** | Silver/White | Cool metallic shimmer |
| **Holographic** | Purple/Pink/Blue | Iridescent holographic effect |

### ⌨️ Interaction Options

| Method | Action |
|--------|--------|
| **Click** | Click on display to create sparkles |
| **Touch** | Touch on mobile to create sparkles |
| **Buttons** | Toggle Style, Clear |
| **Keyboard** | `Space` – Sparkle · `S` – Style · `C` – Clear |

### ✨ Sparkle Experience

When touching:
1. **Particles burst** – 30-60 glitter particles explode
2. **Physics apply** – particles move with gravity and friction
3. **Shimmer effect** – particles pulse with shimmer animation
4. **Overlay sparkles** – CSS sparkles add extra shimmer
5. **Counter updates** – total sparkles count increments
6. **Status updates** – shows sparkle state

### 🛠️ Technologies Used

- **HTML5** – semantic structure with Canvas
- **CSS3** – animations, gradients, clip-path, transforms
- **JavaScript (ES6)** – Canvas API, particle system, requestAnimationFrame

### 🎨 Design Philosophy

This component embodies **EaseMotion CSS's animation-first philosophy** through:

- **Particle physics** – gravity, friction, rotation, and shimmer
- **Two shapes** – star and circle particles
- **Glow effects** – radial gradients and shadows
- **Interactive feedback** – status updates, counter, visual effects
- **Style variety** – 4 distinct color palettes
- **Human-readable classes** – `.glitter-particles`, `.overlay-sparkle`, `.glitter-text`

### 🔧 Customization Options

| Property | Location | Default |
|----------|----------|---------|
| Styles | `styles` array | 4 styles |
| Particle count | `createSparkleBurst()` | 30-60 |
| Particle size | `sizeRange` | 2-11px |
| Gravity | `gravity` variable | 0.02-0.05 |
| Friction | `friction` variable | 0.98 |
| Shimmer speed | `shimmerSpeed` | 0.02-0.05 |
