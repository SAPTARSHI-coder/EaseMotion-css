# Connection Status Online Offline Listener

A simple responsive component that demonstrates network connection status monitoring using browser online/offline events.

## Features

- Detects online status
- Detects offline status
- Responsive design
- Browser event listener example
- Interactive status display

## Files

- demo.html – Component demo
- style.css – Component styling
- README.md – Documentation

## Usage

Open `demo.html` in a browser.

The component automatically updates when browser network status changes.

You can also use the simulation buttons to preview status changes.

## Responsive

Works across desktop, tablet, and mobile devices.
