# Skip Hoist Cage

## What does this do?
Renders a self-contained CSS-only `ease-skip-hoist-cage` demo: Skip hoist cage riding the headframe.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-skip-hoist-cage`. No build step or JavaScript is required for the effect.

```html
<section class="ease-skip-hoist-cage">
  <div class="ease-skip-hoist-cage__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
