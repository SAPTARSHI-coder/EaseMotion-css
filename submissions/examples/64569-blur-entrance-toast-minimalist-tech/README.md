# CSS Blur-Entrance Toast for Minimalist Tech Layouts

A modern pure CSS toast notification component featuring a smooth blur entrance animation.

## Features

- Pure HTML and CSS
- No JavaScript dependency
- Glassmorphism inspired UI
- Blur + scale entrance animation
- Responsive design
- Smooth hover interaction
- Accessibility support with prefers-reduced-motion

## Usage

Copy the HTML structure and include the CSS file.

```html
<link rel="stylesheet" href="style.css">
