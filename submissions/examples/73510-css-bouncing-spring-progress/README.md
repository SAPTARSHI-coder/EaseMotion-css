# CSS Bouncing Spring Progress

Issue #73510 demonstrates a spring-like progress entrance using a cubic-bezier easing curve and a small scale bounce.

## Features

- Spring-style entrance
- Soft glow treatment
- Accessible progressbar semantics
- Responsive layout
- Reduced-motion support
- Pure CSS implementation

## Usage

Open `demo.html` and adjust `--value` to change the progress amount.

## Files

- `demo.html` — progress markup
- `style.css` — spring animation and responsive styling
- `README.md` — documentation
