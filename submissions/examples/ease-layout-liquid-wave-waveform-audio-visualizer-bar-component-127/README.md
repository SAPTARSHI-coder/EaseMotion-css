# Liquid Wave Waveform Audio Visualizer Bar Component

A modern **Liquid Wave Waveform Audio Visualizer** built using pure HTML and CSS. This High-Contrast Accessibility Edition features animated waveform bars, bold colors, responsive layout, and accessibility-focused styling.

---

## ✨ Features

- High-Contrast Accessibility Edition
- Animated liquid waveform bars
- Pure CSS animations
- Responsive design
- High-contrast color palette
- Smooth hover effects
- Lightweight and reusable
- No JavaScript required

## 🚀 Usage

1. Clone or download this project.
2. Open `demo.html` in your browser.
3. Customize colors, animation timing, and content in `style.css`.
