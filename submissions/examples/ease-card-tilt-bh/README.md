# ease-card-tilt-bh

Pure CSS/JS card tilt on mouse effect.

## What does this do?
Creates interactive cards that tilt in 3D perspective following the mouse cursor.

## How is it used?
```html
<div class="ease-card-tilt-bh">
  <div class="ease-card-face-bh">
    <h3>Card Title</h3>
    <p>Card content</p>
  </div>
</div>
```

## Why is it useful?
Creates engaging interactive card experiences with realistic 3D perspective transforms.
