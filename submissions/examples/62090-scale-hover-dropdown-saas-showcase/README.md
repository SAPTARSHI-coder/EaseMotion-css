# CSS Scale-Hover Dropdown for SaaS Showcase Layouts

A modern **Scale-Hover Dropdown** component built with pure HTML and CSS for SaaS dashboards, landing pages, admin panels, and product showcase websites. The dropdown uses smooth scaling animations, glassmorphism styling, and responsive layouts without requiring JavaScript.

---

## Features

- Pure HTML5 & CSS3 implementation
- Smooth scale-hover dropdown animation
- Modern glassmorphism design
- Elegant hover transitions
- Responsive layout for all devices
- CSS Custom Properties for easy customization
- Accessible with `prefers-reduced-motion`
- No JavaScript dependency

## Usage

1. Copy the component folder into:

```
submissions/examples/
```

2. Open `demo.html` in any modern browser.

3. Customize colors, spacing, shadows, and animation timing through CSS variables.

## CSS Custom Properties

```css
:root{
    --bg:#f4f7fb;
    --card:#ffffff;

    --primary:#4f46e5;
    --secondary:#8b5cf6;
    --accent:#06b6d4;

    --text:#1f2937;
    --muted:#6b7280;

    --radius:18px;
    --shadow:0 18px 45px rgba(79,70,229,.12);

    --transition:.45s cubic-bezier(.22,1,.36,1);
}
```
