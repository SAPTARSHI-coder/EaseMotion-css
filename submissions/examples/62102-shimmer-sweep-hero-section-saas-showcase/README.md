# CSS Shimmer-Sweep Hero Section for SaaS Showcase Layouts

A modern **pure HTML & CSS** SaaS Hero Section featuring a premium **Shimmer-Sweep** animation, glassmorphism UI, floating dashboard preview, responsive layout, and accessibility support.

---

## Features

- ✨ Shimmer-Sweep animation across badge and dashboard
- 💎 Modern glassmorphism design
- 🚀 SaaS landing page hero layout
- 📊 Animated dashboard preview
- 🌈 Gradient CTA buttons
- 📱 Fully responsive (Desktop / Tablet / Mobile)
- ♿ Accessible with `prefers-reduced-motion`
- 🎨 Pure HTML5 & CSS3 (No JavaScript)

