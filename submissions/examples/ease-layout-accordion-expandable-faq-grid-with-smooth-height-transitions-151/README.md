# Accordion Expandable FAQ Grid with Smooth Height Transitions (High-Contrast Accessibility Edition)

A responsive FAQ accordion designed with accessibility in mind. This version features high-contrast colors, keyboard-friendly interactions, smooth expand/collapse animations, and a clean responsive grid.

## Features

- High-contrast accessible design
- Smooth accordion animation
- Responsive FAQ grid
- Keyboard-friendly layout
- Pure HTML, CSS & JavaScript
- Lightweight and customizable

## Folder Structure

```
ease-layout-accordion-expandable-faq-grid-with-smooth-height-transitions-151/
├── README.md
├── demo.html
├── style.css
└── script.js
```

## Usage

Open `demo.html` in your browser.

Modify colors, spacing, and fonts inside `style.css`.
