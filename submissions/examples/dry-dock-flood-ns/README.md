# Dry Dock Flood

## What does this do?
Renders a self-contained CSS-only `ease-dry-dock-flood` demo: Dry dock flooding as keel blocks disappear under water.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-dry-dock-flood`. No build step or JavaScript is required for the effect.

```html
<section class="ease-dry-dock-flood">
  <div class="ease-dry-dock-flood__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
