# CSS Kinetic Typography

A pure CSS kinetic typography component where words move,
rotate, skew, scale, and change opacity rhythmically.

## Features

- Pure HTML and CSS
- No JavaScript
- Multiple animated words
- CSS keyframe animations
- Transform and opacity effects
- Responsive typography
- CSS custom properties
- Reduced-motion support

## Usage

```html
<h1 class="kinetic-title">
  <span class="word word-one">MOVE</span>
  <span class="word word-two">CREATE</span>
  <span class="word word-three">INSPIRE</span>
</h1>
