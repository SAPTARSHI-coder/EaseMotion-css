# Burette Titrate Drip

## What does this do?
Renders a self-contained CSS-only `ease-burette-titrate-drip` demo: Burette titration dripping toward endpoint color.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-burette-titrate-drip`. No build step or JavaScript is required for the effect.

```html
<section class="ease-burette-titrate-drip">
  <div class="ease-burette-titrate-drip__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
