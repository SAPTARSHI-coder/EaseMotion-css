# CSS Underwater Caustics

A lightweight underwater lighting effect built entirely with HTML and CSS.

The component creates animated caustic light patterns, floating water particles, and a subtle underwater atmosphere without JavaScript or external dependencies.

## ✨ Features

- 🌊 Animated underwater background
- 💡 Layered CSS caustic light patterns
- ✨ Floating underwater particles
- 🫧 Subtle floating content animation
- 📱 Responsive layout
- ♿ `prefers-reduced-motion` support
- ⚡ Pure HTML and CSS
- 🚫 No JavaScript or external libraries
