# CSS Spinning Logo Animation

A lightweight SVG logo animation that spins and assembles on page load using pure CSS.

## Features

- Pure HTML, SVG, and CSS
- No JavaScript or external dependencies
- Spinning entrance animation
- Individual logo pieces assemble sequentially
- Subtle glow and pulse effects
- Responsive design
- `prefers-reduced-motion` support

Include the stylesheet:

```html
