# Blur Entrance Accordion for SaaS Showcase Layouts

A modern, responsive accordion component featuring elegant blur entrance animations, glassmorphism styling, and smooth CSS transitions. Built entirely with HTML and CSS for the EaseMotion CSS examples collection.

---

## Features

- Pure HTML and CSS (no JavaScript)
- Blur entrance animation when accordion panels expand
- Glassmorphism-inspired card styling
- Responsive desktop, tablet, and mobile layout
- Semantic HTML using `<details>` and `<summary>`
- Smooth hover and focus interactions
- CSS custom properties for quick customization
- Keyboard accessible
- Skip link for improved navigation
- Supports `prefers-reduced-motion`
- Compatible with EaseMotion utility animation classes

---

## Usage

Include the stylesheet:

```html
<link rel="stylesheet" href="../../../dist/easemotion.css">
<link rel="stylesheet" href="style.css">
```

Use the accordion structure shown in `demo.html`.

---

## CSS Custom Properties

```css
--bg
--surface
--primary
--primary-light
--text
--muted
--border
--radius
--shadow
--blur
--duration
--ease
```

These variables allow easy customization of colors, blur intensity, spacing, borders, shadows, animation timing, and easing.
