# CSS Float-Drift Navbar for Product Catalog Layouts

A modern **Float-Drift Navbar** built using pure HTML5 and CSS3 for product catalog layouts. The component provides a responsive floating navigation bar with elegant drift animations, glassmorphism styling, and accessibility support for modern e-commerce interfaces.

## Features

* Pure HTML5 & CSS3
* Float-Drift navigation animation
* CSS-only responsive mobile menu using checkbox toggle
* Floating glassmorphism navbar
* Brand logo, navigation links, search button, cart button, profile button, and CTA button
* Animated floating underline indicator
* Smooth CSS transitions & keyframe animations
* CSS Custom Properties for easy customization
* Fully responsive across desktop, tablet, and mobile devices
* No JavaScript required
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over navigation links to experience the Float-Drift animation.
3. Resize the browser window to test the responsive mobile navigation.
4. Customize colors, spacing, border radius, shadows, and animation timing using the CSS variables defined in `:root`.
