# CSS Ripple-Wave Feature Grid for Creative Portfolio Layouts

A modern **Ripple-Wave Feature Grid** component built completely with **HTML5 and CSS3**. This showcase demonstrates interactive feature cards with smooth ripple-wave hover animations, glassmorphism styling, glowing effects, responsive layouts, and accessibility support without requiring JavaScript.

---

## ✨ Features

- 🌊 Ripple-wave hover animation
- 💎 Glassmorphism feature cards
- ✨ Glow border effects
- 🎨 Gradient icon styling
- ⚡ Smooth CSS transitions
- 🎯 CSS Custom Properties
- 📱 Fully responsive layout
- 🧩 Pure HTML5 & CSS3
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

## 🚀 Getting Started

1. Open `demo.html` in any modern browser.
2. Hover over feature cards to trigger ripple-wave effects.
3. Customize colors, spacing, and animation timing using CSS variables.

## 🎨 CSS Custom Properties

```css
:root{
    --bg:#020617;
    --surface:rgba(255,255,255,.08);
    --primary:#06b6d4;
    --secondary:#8b5cf6;
    --accent:#22c55e;
    --text:#ffffff;
    --muted:#cbd5e1;
    --border:rgba(255,255,255,.15);
    --radius:24px;
```
