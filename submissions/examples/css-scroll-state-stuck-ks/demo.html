Container Query: scroll-state(stuck:)

Detect when position: sticky elements are stuck — in CSS. No IntersectionObserver. No scroll events. No JavaScript.

Requires Chrome 133+ with chrome://flags/#enable-experimental-web-platform-features enabled. This is an emerging CSS feature. Falls back gracefully in unsupported browsers — the sticky positioning still works, just without the visual style changes.

Demo 1: Sticky Section Headers

Scroll the container below. When a section header hits the top and "sticks," it changes color and shows a STUCK indicator.

Section A H1

This is the first section. Keep scrolling down to see the sticky header effect.

The header above is positioned with position: sticky; top: 0;. When it reaches the top of the scroll container, a @container scroll-state(stuck: top) query fires and transforms its appearance.

Try scrolling slowly to watch the transition between unstuck and stuck states. No JavaScript is involved — the browser's scroll-driven container query handles everything.

This is useful for: table of contents markers, section indicators, sticky navigation, and table headers that need to visually change when they become the active reference point.

Section B H2

Section B content. As you scroll past, notice how the header changes only while it's actively stuck to the top.

Once you scroll far enough that this header scrolls off-screen and Section C takes over, the previous header returns to its normal appearance.

Each header independently responds to its own stuck state via the same @container scroller scroll-state(stuck: top) query.

Section C H3

Section C content. The same container query applies to all headers equally.

This pattern eliminates the need for IntersectionObserver or scroll event listeners in JavaScript. The browser's compositor handles it natively with zero main-thread work.

Section D H4

Section D — the final section. Scroll all the way down.

When there's not enough content below to push this header off the top, it remains "stuck" permanently at the bottom of the scroll container.

@container scroller scroll-state(stuck: top) {
  .section-header {
    background: var(--ss-accent);
    color: white;
    box-shadow: 0 4px 12px rgba(99,102,241,0.3);
  }
}
