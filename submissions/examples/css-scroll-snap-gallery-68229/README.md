# CSS Scroll Snap Gallery

## Overview

CSS Scroll Snap Gallery is a pure CSS full-screen gallery that uses CSS Scroll Snap to create smooth section-by-section navigation. Each slide occupies the entire viewport and automatically snaps into place while scrolling.

## Features

- Pure CSS implementation
- Full-screen gallery sections
- Smooth scroll snapping
- Responsive design
- Accessible structure
- Modern gradient backgrounds
- Lightweight and easy to customize
