# Hover Loader - SaaS Modern

A responsive hover-activated loader component with a clean SaaS-inspired interface.

## Features

- Modern SaaS visual style
- Hover and keyboard-focus activation
- Animated loading dots
- Smooth interaction feedback
- Responsive layout
- Accessible focus state
- Reduced-motion support
- No external dependencies

## Files

- `demo.html` - Component markup
- `style.css` - Component styles

## Usage

Open `demo.html` in a modern browser to preview the component.

Hover over the button or focus it using the keyboard to activate the loader.

## Accessibility

The component uses a semantic button element with a visible keyboard focus state and `prefers-reduced-motion` support.
