# Floating Breadcrumb — SaaS Modern

A responsive floating breadcrumb component with a clean
SaaS-inspired visual style, subtle elevation, rounded
surfaces, and polished hover interactions.

Implemented for issue #79819.

## Features

- SaaS modern visual design
- Floating elevated breadcrumb surface
- Responsive horizontal layout
- Mobile-friendly overflow handling
- Current-page indication
- Hover feedback
- Keyboard focus-visible states
- Reduced-motion support
- Semantic breadcrumb navigation
- No JavaScript
- No external dependencies
