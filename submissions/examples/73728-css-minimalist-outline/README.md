# CSS Glass Effect: Minimalist Outline

A smooth, accessible, and performant pure CSS glassmorphism UI featuring a clean **Minimalist Outline** style.

## Features

- Pure HTML and Vanilla CSS
- Minimal glassmorphism design
- Subtle animated outline
- Smooth hover and focus interactions
- Translucent glass surface
- Backdrop blur
- Responsive layout
- Dark mode compatible
- Light mode support
- Hardware-friendly transforms
- Accessible keyboard focus state
- `prefers-reduced-motion` support
- No external JavaScript
- No external libraries
