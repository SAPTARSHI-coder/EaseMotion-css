# Animated Accordion Component

An accessible accordion component built on native `<details>` and `<summary>` elements with smooth CSS grid height expansion.

## Features
- **Native HTML Semantics:** Built using standard `<details>` and `<summary>` tags.
- **CSS Grid Animation:** Uses `grid-template-rows: 0fr -> 1fr` transition for smooth height expanding without fixed heights.
- **Zero JavaScript:** Pure CSS toggle state and chevron rotation.

## File Structure
- `demo.html` - Interactive FAQ accordion layout markup.
- `style.css` - Grid height transitions, border states, and icon rotation keyframes.
