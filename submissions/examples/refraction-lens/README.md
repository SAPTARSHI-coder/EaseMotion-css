# Refraction Lens

Refraction Lens is an experimental interactive data visualization component that presents telemetry through a simulated optical lens.

Instead of simply displaying information in a conventional table, the component creates an inspection surface where a movable lens acts as an optical viewport.

---

## Concept

The component is inspired by optical inspection equipment.

The underlying surface contains structured telemetry:
