Basic Alert Route Row

Alert routing rows for monitoring settings.

A CSS-only row component for showing alert destination, owner team, escalation delay, channel type, and routing health state.

ON
Critical production incidents

Routes urgent alerts to the platform on-call team.

Pager 0 min Active
MT
Staging deployment warnings

Muted during the scheduled release validation window.

Slack 15 min Muted
ER
Billing export failures

Webhook destination is unavailable and needs repair.

Webhook Retry Broken

<article class="basic-alert-route-row">
  <span class="route-mark is-active" aria-hidden="true">ON</span>
  <div class="route-copy">
    <strong>Critical production incidents</strong>
    <p>Routes urgent alerts to the platform on-call team.</p>
  </div>
  <span class="route-channel">Pager</span>

</article>
