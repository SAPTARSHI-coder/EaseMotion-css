# Ease Scroll-Synced SVG Bezier Path Traveler & Roadmap (`ease-scroll-driven-bezier-path-traveler`)

Animates an icon marker along a curved SVG Bezier path while revealing timeline roadmap nodes as the user scrolls down.

## Features
- Smooth scroll-synced translation along SVG paths (`offset-distance`)
- Auto-rotation alignment following the curve tangent vector
- Active milestone node elevation and lighting activation
- Reversible path progress on scroll up
- Fully responsive vector path scaling
