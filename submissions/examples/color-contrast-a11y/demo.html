Color Contrast (Light & Dark Mode)

Ensuring WCAG 2.1 AA Compliance across themes

WCAG 2.1 AA requires a contrast ratio of at least 4.5:1 for normal text and 3.0:1 for large text (or UI components). A common accessibility failure occurs when developers manually flip colors for Dark Mode without verifying the new contrast ratios.

This text uses highly compliant color tokens that guarantee legibility in both light and dark modes.
