# Faucet Drip Valve

## What does this do?
Renders a self-contained CSS-only `ease-faucet-drip-valve` demo: Compression faucet stem opening to a controlled drip.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-faucet-drip-valve`. No build step or JavaScript is required for the effect.

```html
<section class="ease-faucet-drip-valve">
  <div class="ease-faucet-drip-valve__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
