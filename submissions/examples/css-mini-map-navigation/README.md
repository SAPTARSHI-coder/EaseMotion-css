# CSS Mini Map Navigation

A pure CSS miniature page navigation indicator.

## Features

- Fixed mini navigation map
- Section indicators
- Smooth scrolling
- Hover interaction
- CSS animation
- Responsive design

## Technologies

- HTML5
- CSS3

## Usage

Add the component to long scrolling pages like:
- Documentation
- Blogs
- Portfolio websites

## Accessibility

- Semantic navigation
- ARIA labels
- Keyboard accessible links
