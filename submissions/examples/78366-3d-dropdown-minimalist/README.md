# 3D Dropdown with Minimalist Styling

A responsive CSS-only 3D dropdown created for
EaseMotion CSS issue #78366.

## Features

- Fully responsive
- HTML and CSS only
- No JavaScript
- Native `<details>` and `<summary>` interaction
- Minimalist visual design
- Layered 3D shadows
- Subtle pressed/inset states
- Smooth dropdown animation
- Interactive menu items
- Keyboard focus states
- Reduced-motion support
- No external dependencies

## Design

The component combines a minimalist interface with subtle
3D depth.

The visual system uses:

- Neutral tones
- Soft highlights
- Layered shadows
- Inset shadows
- Rounded surfaces
- restrained typography
- subtle motion

## Responsive Behavior

The component adapts to smaller screens through:

- fluid container widths
- responsive typography
- compact menu spacing
- mobile-specific grid sizing
- flexible status metadata

## Technologies

- HTML5
- CSS3

## Files

- `demo.html`
- `style.css`

## Accessibility

The dropdown uses semantic native HTML controls through
`<details>` and `<summary>`.

Keyboard-visible focus styles are included, along with
`prefers-reduced-motion` support.

Closes #78366
