# Residual Signal

Residual Signal is an experimental interactive UI component that visualizes
the invisible residue produced by user movement.

Instead of representing only the current cursor position, the component stores
recent movement temporarily and renders it as a fading signal trail.

The result is an interface that appears to remember where the user has been.

## ✨ Features

- Interactive signal field
- Historical movement trail
- Automatic residual decay
- Dynamic signal strength
- Dynamic frequency
- Dynamic residual memory
- Dynamic drift measurement
- Pointer velocity tracking
- Procedural waveform
- Live coordinate readout
- Transmission status
- Pointer Events
- Mouse support
- Touch support
- Responsive layout
- Reduced-motion support
- Dependency-free implementation
