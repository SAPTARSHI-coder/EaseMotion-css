# CSS Shimmer-Sweep Drawer for E-Commerce Checkout Layouts

A modern **Shimmer-Sweep Drawer** built using pure HTML5 and CSS3 for e-commerce checkout interfaces. The drawer features a premium shimmer animation, shopping cart summary, coupon section, secure checkout panel, and responsive glassmorphism design.

## Features

* Pure HTML5 & CSS3
* Animated shimmer-sweep effect
* Glassmorphism drawer UI
* Shopping cart summary
* Coupon code section
* Payment summary
* Secure checkout badge
* Responsive layout
* CSS Custom Properties
* No JavaScript required
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Customize products, pricing, and checkout details.
3. Modify colors through the CSS variables in `:root`.
4. Integrate the drawer into any e-commerce checkout flow.
