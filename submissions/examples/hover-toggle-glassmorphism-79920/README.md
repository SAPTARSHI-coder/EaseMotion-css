# Hover Toggle with Glassmorphism Styling

A modern hover toggle component featuring glassmorphism effects, frosted backgrounds and smooth state transitions.

## Features

- Glassmorphism design
- Hover glow effect
- Smooth toggle animation
- Responsive layout
- Pure HTML and CSS
- Mobile-friendly

## Files

- demo.html
- style.css

## Usage

Open `demo.html` in your browser.

## Customization

Modify:

- Background gradients
- Toggle dimensions
- Glass blur intensity
- Glow effects
- Colors and shadows
