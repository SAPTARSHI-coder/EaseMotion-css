# Button Magnet Pull

A button pulls toward the cursor like a magnet on hover.

## Features
- Magnetic attraction
- Springy settle
- Hover glow
- Pure CSS

## Usage
```html
<button class="bmp-btn">Hover Me</button>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
