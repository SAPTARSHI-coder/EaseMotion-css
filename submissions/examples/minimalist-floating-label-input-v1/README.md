# Dynamic Floating Label Input — Minimalist Styling

A clean, responsive floating label input component with a minimalist
visual design.

The component uses pure HTML and CSS and does not require JavaScript
or external libraries.

## Features

- Minimalist visual design
- Dynamic floating labels
- Responsive layout
- Smooth focus transitions
- Hover states
- Native HTML validation
- Keyboard accessibility
- Visible focus indicators
- Textarea support
- Error state
- Reduced-motion support
- No JavaScript dependency
- No external libraries
