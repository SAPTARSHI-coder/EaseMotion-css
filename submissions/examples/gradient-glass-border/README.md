# Gradient Glass Border

A card wrapped in a gradient border that rotates its light around the glass panel.

## Features
- Rotating conic border behind glass
- Frosted inner panel with sheen
- Spotlight sweep across the surface

## Usage
```html
<div class="gg-card">
  <div class="gg-inner">
    <h3>Frosted frame</h3>
  </div>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
