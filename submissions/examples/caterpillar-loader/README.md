# CSS Caterpillar Loader

A playful, segmented caterpillar loader that crawls across a responsive progress track using pure CSS.

## Features

- Pure CSS animation
- No JavaScript
- Segmented caterpillar body
- Animated crawling movement
- Progress track animation
- Individual segment bouncing
- Responsive design
- Accessible loading status
- Keyboard-friendly semantic structure
- `prefers-reduced-motion` support
- No external dependencies
