# Neumorphic Audio Synthesizer Interface Component

A soft 3D Neumorphic Equalizer & Audio Player interface featuring inset shadow waveform animations, rotary knobs, and tactile press states.

## What does this do?
Renders an audio player UI with soft light-and-dark dual box shadows, animated frequency visualizer bars, rotatable EQ control knobs, and tactile button press animations.

## How is it used?
1. Open `demo.html` to test button press states and waveform pulse animations.
2. Integrate `.audio-player-card` into music apps, podcast dashboards, or audio settings.
3. Import `style.css` for neumorphic shadow tokens.

## Why is it useful?
Provides physical, tactile feedback for digital audio controls. CSS keyframes handle waveform oscillations smoothly at 60fps without JS canvas processing.
