# Hover Navbar with Gradient Styling

What does this do?
This component is a modern, responsive navigation bar featuring a dynamic, scaling background gradient and glow effect on hover, creating a premium and interactive aesthetic.

How is it used?
```html
<nav class="ease-hover-navbar-gradient">
    <ul class="ease-nav-list">
        <li class="ease-nav-item"><a href="#" class="ease-nav-link">Home</a></li>
        <li class="ease-nav-item"><a href="#" class="ease-nav-link">Features</a></li>
        <li class="ease-nav-item"><a href="#" class="ease-nav-link">Pricing</a></li>
        <li class="ease-nav-item"><a href="#" class="ease-nav-link">Contact</a></li>
    </ul>
</nav>
```

Why is it useful?
It provides an elevated user experience with smooth micro-interactions. The gradient hover state combined with scaling and soft drop shadows immediately draws user attention, perfectly aligning with EaseMotion's focus on fluid and engaging interfaces.
