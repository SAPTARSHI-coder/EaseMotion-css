ease-fade-tabs-neumorphic

Pure CSS tabs — soft neumorphic surface, fade-in panel transitions, zero JavaScript.

Overview

Tab, or use Arrow keys once focused, to move between tabs — the underlying <input type="radio"> group handles all of it natively, no JavaScript involved.

Details

Each panel cross-fades in place using CSS Grid stacking, so the container never jumps height when you switch tabs.

Settings

Tune --ease-tabs-duration, --ease-tabs-easing, and --ease-tabs-scale to change the feel of the transition.
