# Small Status Dot Utility

## What it does

This submission creates a tiny CSS-only status dot utility for indicating states such as online, warning, error, or idle.

## How to use it

Apply the base utility with a state modifier class:

```html
<span class="status-dot online"></span>
```

## Why it fits EaseMotion CSS

It fits EaseMotion CSS because it is human-readable, composable, and useful across many interfaces. It can be reused in cards, tables, profile rows, dashboards, and lightweight status labels.

## Included features

- Tiny circular status dot utility
- Online, warning, error, and idle variations
- Example labeled status rows
- Responsive demo layout
- Pure HTML and CSS implementation

## Files

- `demo.html` - self-contained demo that opens directly in a browser
- `style.css` - raw CSS for the status dot utility
