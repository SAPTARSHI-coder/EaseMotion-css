# CSS Zoom-In Hero Section

A responsive glassmorphism hero section featuring a smooth CSS zoom-in
entrance animation.

## Features

- Pure HTML and CSS
- No JavaScript dependencies
- Glassmorphism design
- Smooth zoom-in entrance animation
- Animated ambient glow and floating elements
- Responsive layout
- Accessible focus states
- `prefers-reduced-motion` support
