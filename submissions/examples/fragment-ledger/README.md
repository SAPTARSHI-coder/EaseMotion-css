# Fragment Ledger

Fragment Ledger is an experimental UI component that treats a sentence as a
collection of independently movable structural fragments.

Instead of behaving like a conventional sortable list, the component
visualizes how changing the order of individual fragments affects the
structure of the overall composition.

The interface continuously calculates structural coherence as the user
rearranges the fragments.

## ✨ Features

- Draggable text fragments
- Reorderable composition
- Fragment metadata
- Original-position tracking
- Live coherence calculation
- Displacement calculation
- Relationship-break detection
- Neighbor relationship visualization
- Completion detection
- Reset functionality
- Mouse interaction
- Touch/stylus-compatible pointer interaction
- Responsive layout
- Reduced-motion support
- No external JavaScript dependencies
