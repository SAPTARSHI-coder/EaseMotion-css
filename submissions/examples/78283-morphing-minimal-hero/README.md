# Morphing Hero Section with Minimalist Styling

A responsive hero section designed around minimalist typography, abstract morphing shapes and subtle CSS motion.

## Features

- Minimalist visual design
- Animated morphing headline treatment
- Abstract CSS-only decorative shapes
- Responsive layout
- Pure HTML and CSS
- No JavaScript dependency
- Responsive navigation
- CTA buttons
- Scroll indicator
- Keyboard focus states
- Reduced-motion accessibility support

## Files

- `demo.html` — hero section markup
- `style.css` — complete responsive styling and animations

## Highlights

The hero uses CSS animations to morph:

- Headline accent shapes
- Background blobs
- Main visual container
- Decorative objects
- Scroll indicator

The layout automatically switches from a two-column desktop design to a stacked mobile layout.
