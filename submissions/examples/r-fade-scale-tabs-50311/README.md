# CSS Fade-Scale Tabs

A responsive **Fade-Scale Tabs** component built using pure HTML5 and CSS3 for Responsive Dashboard layouts. The active tab displays content with a smooth fade-and-scale transition while maintaining accessibility and responsiveness.

---

## ✨ Features

- Pure HTML5 & CSS3
- Fade-scale content animation
- Responsive dashboard layout
- Keyboard accessible using radio inputs
- CSS Custom Properties
- No JavaScript required
- `prefers-reduced-motion` support
