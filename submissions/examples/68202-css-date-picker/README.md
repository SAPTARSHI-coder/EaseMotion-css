# CSS Date Picker

## Overview

A pure HTML and CSS date picker interface designed as a reusable EaseMotion example. The demo focuses on calendar layout, date states, navigation controls, and polished interactive styling without JavaScript.

## Features

- Calendar-style date selection interface
- Clear selected, available, unavailable, and adjacent-month states
- Responsive layout
- Hover and keyboard focus states
- Semantic form controls
- CSS-only visual interactions
- Reduced-motion support

## Files

- `demo.html` — date picker structure and sample calendar data
- `style.css` — calendar layout, controls, states, responsive styling, and motion

## Usage

Open `demo.html` directly in a modern browser. The example requires no dependencies or build tooling.

## Accessibility

Interactive controls include visible focus states, and the stylesheet respects `prefers-reduced-motion` for users who request reduced animation.
