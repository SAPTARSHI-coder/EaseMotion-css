# Morphing Tab Bar

## Issue

EaseMotion CSS issue #78781.

## Overview

A minimalist responsive tab bar with a clear active surface and subtle shape transitions.

## Features

- Responsive tab layout
- Native keyboard-focusable links
- Smooth active-state transitions
- Reduced-motion support
- No external dependencies

## Usage

Open `demo.html` in a browser and reuse the `.tabs` and `.tab` classes in another interface. The example intentionally uses native anchors so the component remains useful without JavaScript.

## Accessibility

Focus indicators remain visible, labels are readable, and motion is disabled when the user prefers reduced motion.
