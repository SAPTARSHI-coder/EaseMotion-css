# ease-float-modal-bh

Pure CSS float-drift modal for fintech dashboards.

## Features
- Float drift hover effect
- Modal variants
- Responsive design
- Accessibility support

## Usage
```html
<div class="ease-modal ease-modal-float">Content</div>
```

## CSS Classes
- `.ease-modal` - Base modal
- `.ease-modal-float` - Float drift effect
