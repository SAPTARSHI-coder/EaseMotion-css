Water Ripple Button

A tactile button with a layered water ripple that expands from the interaction area using CSS alone.

Interactive surface

Make every press feel fluid.

Press and hold the buttons to see the ripple expand. The effect uses a pseudo-element and the active state, so the control remains a real keyboard and assistive-technology-friendly button.

Design principles

A small interaction, carefully layered.

01

Native control

The effect is attached to a real button element, preserving normal keyboard semantics and browser behavior.

02

Layered water

Multiple radial gradients and a soft ring make the expanding shape feel like a disturbance on a liquid surface.

03

Press feedback

The active state compresses the control while the ripple expands, creating a clear tactile response.

04

Reduced motion

Users who prefer less motion receive a static pressed treatment without a continuous animated ripple.

Usage

Drop it into any action.

Use the same button pattern for navigation, calls to action, product controls, or compact dashboard interactions. Change the CSS custom properties to tune the surface and ripple colors.
