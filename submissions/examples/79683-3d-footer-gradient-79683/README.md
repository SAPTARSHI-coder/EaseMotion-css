# 3D Footer — Gradient

## Overview

Issue #79683 demonstrates a responsive footer with layered gradient depth and a restrained three-dimensional presentation.

## Features

- Gradient surface layers
- Perspective depth
- Responsive navigation groups
- Native links and keyboard focus
- Mobile stacking
- Reduced-motion support

## Implementation

The footer combines gradients, shadows, and a small perspective transform. The depth remains decorative, while the navigation itself stays semantic and usable.

## Accessibility

Navigation uses native links and clear headings. Focus-visible styling keeps keyboard interaction visible. No essential information is communicated through the visual effect alone.

## Usage

Open `demo.html` directly and copy the `.footer` structure into a site footer. Adjust the custom properties in `style.css` to match an existing brand.

## Files

- `demo.html` — expanded footer example
- `style.css` — gradient, perspective, responsive, and accessibility styles
- `README.md` — documentation
