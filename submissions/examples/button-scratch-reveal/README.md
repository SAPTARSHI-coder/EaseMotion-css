# Button Scratch Reveal

Hovering scrapes away a solid layer to reveal color underneath.

## Features
- Scratch-away layer
- Clip-path reveal
- Hand-drawn edge
- Pure CSS

## Usage
```html
<button class="bsr-btn">Scratch</button>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
