# Bounce Pulse Card Grid

A responsive card grid featuring a smooth bounce and pulse hover animation built using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Bounce pulse hover animation
- Responsive grid layout
- Accessible with prefers-reduced-motion
- Lightweight
- No JavaScript required

## Folder

```
bounce-pulse-card-grid/
├── demo.html
├── style.css
└── README.md
```

## Usage

Link the stylesheet.

```html
<link rel="stylesheet" href="style.css">
```

Use the card component.

```html
<div class="card">
    <h2>Title</h2>
    <p>Description</p>
</div>
```

## Customization

Modify colors, spacing, border radius, animation duration, and shadow inside `style.css`.

## Browser Support

- Chrome
- Firefox
- Edge
