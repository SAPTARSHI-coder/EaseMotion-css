# ease-phone-number-format

Animated phone number format display with fade transition between numbers.

## Usage
Open demo.html. Click "Re-format" to cycle through phone numbers with a fade animation.

## Custom Properties
| Property | Default | Description |
|----------|---------|-------------|
| --primary | #0891b2 | Accent color |

## Notes
CSS fade-in animation triggers on each phone number change.
