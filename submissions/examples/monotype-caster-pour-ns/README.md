# Monotype Caster Pour

## What does this do?
Renders a self-contained CSS-only `ease-monotype-caster-pour` demo: Monotype caster molten metal pour.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-monotype-caster-pour`. No build step or JavaScript is required for the effect.

```html
<section class="ease-monotype-caster-pour">
  <div class="ease-monotype-caster-pour__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
