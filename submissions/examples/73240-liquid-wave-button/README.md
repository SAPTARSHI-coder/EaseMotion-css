# Liquid Wave Fill Button (#73240)

A pure HTML & Vanilla CSS button featuring a fluid liquid wave fill effect on hover.

## Features
- **Aesthetic:** Fluid wave rise filling the button container on hover.
- **Pure CSS:** Zero JavaScript dependencies; relies on pure CSS transitions and clip-path/border-radius rotations.
- **Performance:** Hardware-accelerated using `transform` and `will-change`.
- **Accessibility:** Includes `:focus-visible` outline rings and `@media (prefers-reduced-motion: reduce)` support.
