# CSS Slider: Foucault Pendulum Swing

A smooth, accessible, and performant pure CSS slider inspired by the
swinging motion of a Foucault pendulum.

## Features

- Pure HTML and Vanilla CSS
- Foucault pendulum-inspired animation
- Smooth pendulum swinging motion
- CSS-only slide navigation
- Three presentation slides
- Layered pendulum depth
- Animated pendulum shadow
- Visual swing arcs
- Smooth CSS transitions
- Dark mode compatible
- Light mode support
- Responsive layout
- Hardware-friendly CSS transforms
- Accessible navigation labels
- `prefers-reduced-motion` support
- No JavaScript
- No external libraries
