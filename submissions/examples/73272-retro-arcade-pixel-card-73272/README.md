# Retro Arcade Pixel Card

## Overview

Issue #73272 implements a retro arcade pixel card with crisp borders, scanline texture, neon accents, and tactile interaction.

## Features

- Pure HTML and vanilla CSS
- Smooth transform-based hover motion
- Dark-mode friendly palette
- Responsive card layout
- Keyboard-visible focus
- Reduced-motion support

## Files

- `demo.html` — semantic card content
- `style.css` — pixel styling and interaction
- `README.md` — documentation
