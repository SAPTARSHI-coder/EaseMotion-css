# Task Search and Filter UI Component

A clean, modern, accessible, and responsive Task Search and Filter UI component designed for task management applications.

## 🌟 Features

- **Real-Time Title Search**: Instant filtering as you type into the search bar with clear button controls.
- **Status Filter Controls**: Toggle effortlessly between **All**, **Pending**, and **Completed** tasks.
- **Dynamic Counters**: Live counts updating task totals according to status.
- **Clear Active Visual States**: High-contrast, accessible visual indicators for selected filters and completed items.
- **Fully Responsive**: Mobile-first flexible layout optimized for small screen viewports.
