# CSS Float-Drift Dropdown for SaaS Showcase Layouts

A modern **Float-Drift Dropdown** built using pure HTML5 and CSS3 for SaaS showcase layouts. This component creates an interactive dropdown navigation experience with smooth floating motion, hover interactions, glassmorphism styling, and responsive behavior.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Smooth float-drift animation
* CSS hover-based dropdown interaction
* SaaS navigation showcase component
* Animated dropdown menu reveal
* Floating feature card design
* Glassmorphism UI styling
* Gradient buttons and modern effects
* Responsive desktop, tablet, and mobile layout
* CSS Custom Properties for easy customization
* Smooth CSS transitions and keyframe animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over the **Product Menu** button to reveal the dropdown.
3. Customize colors, shadows, animation speed, and spacing using CSS variables inside `:root`.

## CSS Custom Properties

```css
:root{
  --bg:#eef4ff;
  --surface:rgba(255,255,255,.92);
  --primary:#2563eb;
  --secondary:#06b6d4;
  --accent:#8b5cf6;
  --text:#111827;
  --muted:#64748b;
  --shadow:0 20px 55px rgba(37,99,235,.18);
  --radius:26px;
}
```
