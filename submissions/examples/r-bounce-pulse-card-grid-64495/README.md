# CSS Bounce-Pulse Card Grid

A minimalist responsive card grid featuring subtle bounce and pulse animations.

## Features

- Pure HTML and CSS
- No JavaScript dependencies
- Bounce interaction on cards
- Soft pulse decoration
- Multiple color variants
- Responsive grid layout
- Hover and focus support
- `prefers-reduced-motion` support
- Customizable CSS properties
