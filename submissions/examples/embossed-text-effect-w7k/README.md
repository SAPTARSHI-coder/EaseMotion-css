1. What does this do?
A realistic, pure CSS tactile letter-press effect offering both raised (embossed) and sunken (debossed) 3D text depths.

2. How is it used?
<div class="ete-card">
  <h1 class="ete-text ete-embossed">EMBOSSED</h1>
  <h2 class="ete-text ete-debossed">DEBOSSED</h2>
</div>

3. Why is it useful?
It creates high-quality tactile typography effects using modern multi-layered text shadows without needing image assets, Canvas, or JS frameworks.
