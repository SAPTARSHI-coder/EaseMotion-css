# CSS Floating Elevation Form

Issue #73349 demonstrates a floating form surface using transform and changing shadow depth.

## Features

- Subtle vertical lift
- Dynamic shadow depth
- Native form controls
- Responsive layout
- Visible focus states
- Reduced-motion fallback

## Accessibility

The form is semantic and keyboard accessible. Decorative movement is removed for reduced-motion users.

## Files

- `demo.html` — form demonstration
- `style.css` — elevation and responsive styling
- `README.md` — documentation
