# Shaduf Counterpoise

## What does this do?
Renders a self-contained CSS-only `ease-shaduf-counterpoise` demo: Shaduf counterpoise well sweep lift.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-shaduf-counterpoise`. No build step or JavaScript is required for the effect.

```html
<section class="ease-shaduf-counterpoise">
  <div class="ease-shaduf-counterpoise__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
