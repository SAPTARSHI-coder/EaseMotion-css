# Claymorphic Profile Card Canvas (#87640)

A 3D tactile user profile card designed with modern claymorphism physics, dynamic particle canvas backdrop, and interactive action buttons.

## Features
- **Claymorphic Styling:** Soft 3D inflated appearance achieved through multiple inset and outset box-shadow layers with organic corner rounding.
- **Particle Mesh Canvas:** Lightweight, dependency-free interactive HTML5 Canvas background with ambient floating nodes and connecting filaments.
- **Hover Micro-Interactions:** Subtle floating lift physics and pressed tactile button feedback on interactions.
- **Accessibility:** Honors `@media (prefers-reduced-motion: reduce)` by disabling canvas animation loops and transition springs.

## Usage
Include `style.css` in your project, initialize the canvas particle context, and structure the profile container using `.clay-card`.
