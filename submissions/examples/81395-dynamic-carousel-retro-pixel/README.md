# Dynamic Carousel — Retro Pixel

A responsive CSS-only carousel with a Retro Pixel visual style,
created for EaseMotion CSS issue #81395.

## Features

- Pure HTML and CSS
- Retro pixel-inspired design
- CSS-only slide navigation
- Responsive across desktop, tablet and mobile
- Smooth slide transitions
- Hover interaction effects
- Pixel-style shadows and borders
- Native radio-button state control
- `prefers-reduced-motion` support
- No JavaScript dependencies
