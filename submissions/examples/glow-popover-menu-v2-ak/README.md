# glow-popover-menu-v2-ak

Pure CSS animated glowing popover menu component — no JavaScript required.

## How to use

```html
<div class="ease-popover-wrapper-v2">
  <button class="ease-popover-trigger-v2">Options</button>

  <ul class="ease-popover-menu-v2">
    <li class="ease-popover-item-v2"><a href="#">Item 1</a></li>
    <li class="ease-popover-item-v2"><a href="#">Item 2</a></li>
  </ul>
</div>
