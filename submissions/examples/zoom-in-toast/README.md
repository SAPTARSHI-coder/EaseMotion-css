# CSS Zoom-In Toast for Fintech Dashboard Layouts

A modern, responsive fintech dashboard showcase featuring a CSS-only
Zoom-In Toast notification.

## Features

- Pure HTML and CSS
- No JavaScript or external frameworks
- Smooth zoom-in entrance animation
- Subtle notification glow animation
- Responsive dashboard layout
- Fintech-focused UI design
- CSS custom properties for easy customization
- Accessible `prefers-reduced-motion` support
- Keyboard-accessible toast dismissal control
- Mobile, tablet, and desktop friendly
