# Theater & Performing Arts Landing Page

### 1. What does this do?

This is a complete, polished, and fully responsive Theater & Performing Arts Landing Page showcasing the direct integration of EaseMotion CSS animations, grid/flex layout utilities, navigation menus, and modal dialogs.

### 2. How is it used?

It is used as a ready-to-copy landing page template that utilizes standard EaseMotion classes:

- **On-Scroll Reveals:** `<div class="ease-reveal ease-reveal-up ease-reveal-delay-2">`
- **Interactive Modals:** `<div id="booking-modal" class="ease-modal-overlay">` (opened via `<a href="#booking-modal">`)
- **Hover Transitions:** `<article class="ease-card ease-card-hover">`
- **Flex & Grid Layouts:** `<div class="ease-grid ease-grid-cols-3 ease-gap-8">`

### 3. Why is it useful?

It provides a high-fidelity, real-world showcase of EaseMotion CSS's versatility, showing how its modular class naming system allows developers to build elegant, motion-driven, accessible interfaces without writing custom animation keyframes or relying on heavy JavaScript frameworks.
