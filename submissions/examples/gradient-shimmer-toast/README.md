# Gradient Shimmer Toast

A modern notification toast featuring an animated Gradient Shimmer
effect created entirely with HTML and Vanilla CSS.

## Features

- Animated gradient shimmer
- Moving shimmer highlight
- Animated gradient border
- Smooth entrance transition
- Interactive hover effects
- Responsive layout
- Light mode support
- Dark mode support
- Accessible notification semantics
- Keyboard focus support
- Reduced-motion support
- No external dependencies

## Preview

The component combines translucent surfaces, animated gradients,
soft glow, and a moving highlight to create a polished shimmer effect.
