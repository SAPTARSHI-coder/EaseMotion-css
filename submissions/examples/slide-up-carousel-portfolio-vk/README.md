# Slide-Up Carousel for Creative Portfolio Layouts

A responsive carousel component built with pure HTML and CSS. The carousel showcases portfolio projects using smooth slide-up animations, making it suitable for creative portfolios, design showcases, and project galleries without requiring JavaScript.

---

## Features

- Pure HTML5 and CSS3 (No JavaScript)
- Smooth slide-up carousel animation
- Fully responsive across desktop, tablet, and mobile devices
- Easy customization using CSS custom properties
- Lightweight and performant
- Supports `prefers-reduced-motion`

---

## Folder Structure

```
slide-up-carousel-portfolio-vk/
```

---

## Usage

1. Open `demo.html` in any modern browser.
2. The carousel automatically cycles through portfolio slides using CSS keyframe animations.
3. Customize the slide content, colors, animation timing, and button styles to match your project.

---

## CSS Custom Properties

```css
:root {
    --primary: #4f46e5;
    --secondary: #7c3aed;
    --accent: #ec4899;

    --background: #f5f7fb;
    --surface: #ffffff;
    --text: #1f2937;

    --radius: 18px;
    --shadow: 0 12px 30px rgba(0, 0, 0, 0.12);

    --duration: 9s;
}
```
