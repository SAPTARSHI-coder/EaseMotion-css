# Liquid Morphing Blob Card - GSSoC 2026

An organic liquid morphing blob card featuring dynamic CSS keyframe-based border-radius shifting, ambient glow, and glassmorphic overlay depth.

## 1. What does this do?
It displays an interactive glassmorphic UI card containing animated fluid background blobs that organically morph their shape and shift colors using pure CSS keyframe transformations.

## 2. How is it used?
Link `style.css` in your HTML document and copy the `.blob-card` HTML structure along with its background blob elements `.blob-background`.

## 3. Why is it useful?
It provides a futuristic visual effect for landing page features, hero callouts, and product showcases while maintaining high performance and responsiveness without external JavaScript libraries.
