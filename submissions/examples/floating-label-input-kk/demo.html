Floating Label Input

Modern form fields with labels that lift on focus and value.

This demo showcases a clean CSS-only input pattern where the label moves upward when the field is focused or contains text. It works well for login forms, contact forms, profile editors, and dashboard settings screens.

HTML Usage

<label class="floating-input">
  <input type="text" placeholder=" " required />
  <span>Full Name</span>
</label>
