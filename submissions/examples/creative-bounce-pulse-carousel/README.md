# CSS Bounce-Pulse Carousel for Accessible Web Layouts

A modern **Bounce-Pulse Carousel** component created using only **HTML5 and CSS3**. This showcase demonstrates animated bounce interactions, pulse effects, responsive card layouts, and accessibility support without JavaScript.

---

## ✨ Features

- 🏀 Bounce animation effects
- 💓 Pulse background animation
- 🎴 Interactive carousel cards
- 🌈 Gradient UI design
- ⚡ Smooth CSS transitions
- 🎯 CSS Custom Properties
- 📱 Fully responsive layout
- 🧩 Pure HTML5 & CSS3
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

---

## 🚀 Usage

1. Open `demo.html` in a modern browser.
2. Hover over cards to view bounce interactions.
3. Customize colors and animation values using CSS variables.
