# Glitch Text Reveal Effect with Keyframe Distortion Animations

### Compact Mobile-First Edition

A modern glitch text reveal component built with **HTML5** and **CSS3**, featuring layered keyframe distortion animations, neon accents, and a compact mobile-first layout. The component delivers a futuristic cyber-inspired text reveal without requiring JavaScript.

---

## ✨ Features

- Animated glitch text reveal
- Layered pseudo-element distortion effects
- CSS keyframe animations
- Compact mobile-first design
- Glassmorphism-inspired container
- Neon gradient button
- Responsive layout
- CSS variables for easy customization
- Pure HTML & CSS implementation
- Reduced motion accessibility support

## 🚀 Usage

1. Open the component folder.
2. Keep `demo.html` and `style.css` in the same directory.
3. Open `demo.html` in any modern browser.

No installation or external libraries are required.
