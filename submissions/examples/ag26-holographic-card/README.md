# AG26 Holographic Card

A modern **CSS-only holographic trading card** built using HTML and CSS.

This example demonstrates a colorful holographic overlay with an animated rainbow gradient, shimmer sweep, hover elevation, and subtle 3D perspective—without using JavaScript.

---

## Features

- CSS-only holographic card
- Iridescent animated gradient
- Shimmer sweep hover effect
- Smooth hover elevation
- 3D perspective illusion
- Responsive design
- No JavaScript required
- Easy to customize

---

## Folder Structure

```
ag26-holographic-card/
├── demo.html
├── style.css
└── README.md
```

---

## Usage

1. Open `demo.html` in a modern browser.
2. Hover over the card to see the holographic shimmer.
3. Customize the colors and animation in `style.css`.

---

## Customization

You can easily change:

- Gradient colors
- Card size
- Border radius
- Animation speed
- Shadow intensity
- Background colors
