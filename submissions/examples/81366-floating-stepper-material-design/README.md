# Floating Stepper — Material Design

A responsive floating stepper with a clean Material Design-inspired
visual style created for EaseMotion CSS issue #81366.

## Features

- Material Design-inspired cards
- Floating elevated step surfaces
- Completed, active and upcoming states
- Animated active marker
- Animated progress indicator
- Subtle elevation and shadows
- Smooth hover interactions
- Responsive desktop, tablet and mobile layout
- Reduced-motion support
- Pure HTML and CSS
- No JavaScript dependencies
