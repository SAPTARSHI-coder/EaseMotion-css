# Elastic Spring Tab Bar Navigation - GSSoC 2026

An elastic spring navigation tab bar with smooth cubic-bezier physics-based indicator sliding.

## 1. What does this do?
It renders a sleek pill navigation bar where switching tabs triggers an elastic spring animation of the background active pill indicator.

## 2. How is it used?
Include `style.css` in your webpage and structure your navigation using CSS radio inputs paired with labels.

## 3. Why is it useful?
It elevates navigation UX in modern dashboards, SaaS applications, and mobile web apps with physical spring feedback without requiring JS script overhead.
