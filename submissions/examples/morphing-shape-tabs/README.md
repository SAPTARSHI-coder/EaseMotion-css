# Morphing Shape Tabs

A modern pure CSS tabs and segmented control featuring a **Morphing Shape** animation where the active tab smoothly changes its border radius and scale.

## Features

- Pure HTML & CSS
- Morphing shape animation
- Smooth CSS transitions
- Responsive segmented control
- Dark mode compatible
- Hardware-accelerated animations
- Accessible radio-button implementation
- No JavaScript required
