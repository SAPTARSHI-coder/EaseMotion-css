# CSS Kinetic Typography

An animated text display that continuously breathes, stretches, and shifts using intense CSS `transform: skew()` and `scale()` animations.

## Features
- Staggered character animations using `animation-delay` on `span` elements.
- Fluid shape-shifting text utilizing `scaleY` and `skewX` keyframes.
- Distinct stylistic layers utilizing `-webkit-text-stroke` vs solid fills.
