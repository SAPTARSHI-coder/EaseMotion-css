# Morphing Modal with Gradient Styling

A modern, responsive CSS-only modal component featuring animated
gradients, morphing borders, glassmorphism, and smooth transitions.

## ✨ Features

- CSS-only interaction
- Animated gradient background
- Morphing modal entrance animation
- Glassmorphism design
- Responsive layout
- No JavaScript dependencies
- No external libraries
- Supports reduced-motion preferences
- Mobile friendly
