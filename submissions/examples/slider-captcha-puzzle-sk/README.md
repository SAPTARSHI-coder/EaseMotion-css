# Slider Captcha Puzzle

## What does this do?

A slide-piece captcha UI that snaps/succeeds near the target slot.

## How is it used?

```html
<div class="captcha"><div class="captcha__piece"></div><input type="range"/></div>
```

Open `demo.html` in a browser to try it.

## Why is it useful?

Recognizable interaction with drag/success motion states (demo only).
