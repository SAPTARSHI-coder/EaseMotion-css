# CSS Hologram Foil Text

A stunning, iridescent text effect that mimics shiny holographic foil using CSS backgrounds and clipping. 

## Features
- Iridescent `linear-gradient` to map holographic colors
- `-webkit-background-clip: text` mapped to the gradient
- Continuous `background-position` shifting via keyframes for a shimmering effect
