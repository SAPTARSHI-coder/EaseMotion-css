# Responsive Stepper — Neumorphism

A responsive stepper component with a soft Neumorphism visual
style created for EaseMotion CSS issue #81363.

## Features

- Neumorphic soft-depth design
- Responsive stepper layout
- Completed, active and upcoming states
- Soft light and dark shadows
- Animated active marker
- Animated progress indicator
- Smooth hover interactions
- Responsive desktop, tablet and mobile layout
- Reduced-motion support
- Pure HTML and CSS
- No JavaScript dependencies
