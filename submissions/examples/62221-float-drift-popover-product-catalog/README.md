# CSS Float-Drift Popover for Product Catalog Layouts

A modern **Float-Drift Popover** built using pure HTML5 and CSS3 for product catalog layouts. The component provides responsive product quick-view popovers with elegant floating drift animations, glassmorphism styling, and accessibility support.

## Features

* Pure HTML5 & CSS3
* Float-Drift popover animation
* Product quick-view popover
* Glassmorphism popover design
* Floating product image with drift animation
* Product title, description, price, rating, availability, and CTA button
* Arrow indicator
* Smooth CSS transitions & keyframe animations
* Responsive desktop, tablet, and mobile layout
* CSS Custom Properties
* No JavaScript required
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over the **Quick View** button to display the Float-Drift Popover.
3. Customize colors, spacing, shadows, and animation timing using the CSS variables defined in `:root`.
4. Integrate the component into any product catalog or e-commerce interface.
