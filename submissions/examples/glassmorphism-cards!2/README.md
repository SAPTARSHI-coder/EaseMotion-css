# Glassmorphism Cards Example

This example demonstrates how to combine **EaseMotion CSS** animations with modern **Glassmorphism** design principles. 

## ✨ Features
- Uses EaseMotion utility classes (`ease-fade-in`, `ease-slide-up`, `ease-hover-lift`, `ease-hover-grow`)
- Pure CSS glassmorphism effect using `backdrop-filter`
- ♿ Respects `prefers-reduced-motion` media queries for accessibility
- 📱 Fully responsive grid layout

## 🚀 How to Run
1. Clone the EaseMotion CSS repository.
2. Navigate to this directory: `submissions/examples/glassmorphism-cards/`
3. Open `demo.html` in your web browser. No build step or local server is required!

## 📂 Files
- `demo.html`: The main HTML structure utilizing EaseMotion classes.
- `style.css`: Custom styling for the glassmorphism effect (complements EaseMotion CSS).
