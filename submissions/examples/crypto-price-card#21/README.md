# Crypto Price Card

This submission demonstrates a modern cryptocurrency price card built with
**EaseMotion CSS**. It includes animated entrance effects, hover motion,
mini chart, price stats, action buttons, and responsive layout.

## 🌟 Features

- **Crypto price card** with coin icon, name, symbol, and price change badge.
- **Large price display** with last updated text.
- **Mini bar chart** created using pure CSS.
- **Market stats** for 24h high, 24h low, and volume.
- **Buy and sell buttons** with hover grow effect.
- **Staggered entrance animation** using `ease-slide-up` and delay utilities.
- **Hover lift effect** using `ease-hover-lift`.
- **Responsive layout** for mobile and desktop.
- **Reduced motion support** for users who prefer less animation.

## 📁 Files

- `demo.html` — interactive crypto price card demo
- `style.css` — original crypto card styling
- `README.md` — documentation for this submission

## 🛠️ How to Run

1. Open `demo.html` in your browser.
2. Watch the crypto card animate on page load.
3. Hover over the card to see the lift effect.
4. Hover over the buttons to see the grow effect.
5. Resize the browser window to check responsive behavior.
