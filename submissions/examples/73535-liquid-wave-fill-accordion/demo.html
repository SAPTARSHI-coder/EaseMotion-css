Liquid Wave Fill

A fluid accordion interaction inspired by a gently moving liquid surface, created entirely with HTML and CSS.

01 What is Liquid Wave Fill? Fluid visual feedback

Liquid Wave Fill creates the impression of a fluid surface flowing into the accordion when its content is revealed.

02 How is the wave created? Layered CSS pseudo-elements

A combination of pseudo-elements, border-radius, transforms and keyframe animation creates the flowing wave effect without external dependencies.

03 Is JavaScript required? Native HTML interaction

No JavaScript is required. The native details and summary elements provide the accordion interaction, while CSS handles the complete visual treatment.

04 Does it support dark mode? Automatic system adaptation

Yes. The component automatically adapts its colors to the user's preferred system color scheme.
