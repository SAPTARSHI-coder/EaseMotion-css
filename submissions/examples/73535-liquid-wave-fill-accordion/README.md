# Liquid Wave Fill Accordion

A smooth CSS-only accordion featuring a fluid Liquid Wave Fill
visual style.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript required
- Native `<details>` and `<summary>` interaction
- Liquid-inspired wave layers
- Smooth accordion expansion
- Animated plus/minus indicator
- Dark mode compatible
- Responsive layout
- Keyboard accessible
- Reduced-motion support
- CSS transform-based animations
