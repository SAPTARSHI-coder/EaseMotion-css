# Custom Vertical Timeline — SaaS Modern

A clean SaaS-style vertical timeline component built with pure HTML and CSS.

The component uses modern cards, status badges, subtle shadows, responsive behavior, and smooth transitions to create a professional product-roadmap timeline.

## Features

- Modern SaaS visual design
- Vertical timeline rail
- Status badges
- Active progress state
- Smooth hover transitions
- Responsive desktop, tablet, and mobile layouts
- CSS custom properties for easy theming
- `prefers-reduced-motion` support
- Semantic timeline structure
- Pure HTML and CSS
- No JavaScript
