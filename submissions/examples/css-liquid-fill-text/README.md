# CSS Liquid Fill Text Effect

A striking text effect where the letters appear to be filled with liquid using CSS pseudo-elements, `-webkit-text-stroke`, and animated clipping widths.

## Features
- Hollow text outline using `-webkit-text-stroke`
- Animated pseudo-element overlay simulating a liquid fill
- Glowing drop shadows for a neon aesthetic
