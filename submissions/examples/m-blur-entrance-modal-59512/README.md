# CSS Blur-Entrance Modal for SaaS Showcase Layouts

A modern **Blur-Entrance Modal** built using pure HTML and CSS. The modal appears with a smooth blur-to-focus animation, elegant glassmorphism styling, and a responsive layout suitable for SaaS dashboards, landing pages, and product showcases.

## ✨ Features

- Pure HTML5 & CSS3
- Blur entrance animation
- Glassmorphism modal
- Responsive layout
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
