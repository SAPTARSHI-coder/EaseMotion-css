# Particle Burst Accordion

A smooth and interactive CSS accordion featuring a Particle Burst visual effect.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript required
- Native `<details>` and `<summary>` elements
- Particle burst effect on expansion
- Smooth content transitions
- Animated expand/collapse indicator
- Dark mode compatible
- Responsive design
- Hardware-friendly CSS transforms
- Reduced-motion support
- Keyboard accessible native accordion controls
