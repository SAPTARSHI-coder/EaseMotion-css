CSS ACCORDION

Particle Burst

A playful accordion interaction where decorative particles burst outward when a panel is opened.

01 What is Particle Burst? Explore the interaction

Particle Burst is a CSS-only accordion variation that combines expanding content with lightweight decorative particles for a dynamic visual response.

02 How does it work? Pure CSS interaction

The component uses the native HTML details and summary elements. CSS selectors detect the open state and animate the panel and its decorative particle elements.

03 Is JavaScript required? No external dependencies

No. The accordion relies entirely on semantic HTML and vanilla CSS. There are no scripts, frameworks, or external libraries required.

04 Does it support dark mode? Automatic theme adaptation

Yes. The component includes a prefers-color-scheme media query that automatically adapts the colors for dark-mode environments.
