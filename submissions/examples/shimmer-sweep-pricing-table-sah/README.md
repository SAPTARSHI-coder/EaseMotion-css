# Shimmer-Sweep Accessible Pricing Table (`#54388`)

## What does this do?
Establishes an accessible commercial subscription comparison table across whose featured enterprise package a periodic metallic light beam refracts diagonally.

## How is it used?
Organize subscription comparison tiers inside an `ease-pricing-shimmer-sweep` layout equipped with a metallic shimmer beam element:
```html
<div class="ease-pricing-shimmer-sweep">
  <div class="shimmer-grid">
    <div class="tier-s prime-shimmer"><div class="beam"></div>...</div>
  </div>
</div>
```

## Why is it useful?
Solves issue #54388 by giving accessible enterprise conversion packages an upscale, eye-catching luminous metallic sheen.
