# Animated Status Pulse Dot

A lightweight status indicator with a continuously expanding pulse around
a central dot.

## What does it do?

The component provides:

- Animated expanding pulse.
- Central status dot.
- Online, live, and active examples.
- Subtle visual feedback.
- Responsive layout.
- Reduced-motion support.
- No JavaScript.
- No external libraries or assets.

## How do I use it?

Add the `ease-status-pulse` class to a status indicator:

```html
<span
  class="ease-status-pulse"
  aria-label="Online"
>
  <span></span>
</span>
```
