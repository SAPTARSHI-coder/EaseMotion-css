# Expandable Timeline Cards

A CSS-only animated timeline component that displays events using interactive cards connected through a vertical timeline.

## ✨ Features

- Pure HTML and CSS
- No JavaScript required
- Animated timeline markers
- Smooth hover card expansion
- Modern card design
- Responsive layout
- Easy customization

## 📁 Folder Structure

```
expandable-timeline-cards/
├── demo.html
├── style.css
└── README.md
```

## 🚀 Usage

Open `demo.html` directly in your browser.

The component can be used for:

- Portfolio timelines
- Resume experience sections
- Project roadmaps
- Company history pages
- Product launch journeys

## ⚙️ How It Works

The timeline uses:

- CSS pseudo-elements for the connecting line
- CSS transitions for smooth movement
- Transform animations for card interaction
- Hover states for visual feedback

## 🎨 Customization

You can customize:

- Timeline colors
- Card shadows
- Animation speed
- Border radius
- Spacing

## 🛠 Technologies Used

- HTML5
- CSS3
- CSS Transforms
- CSS Transitions
- Responsive Design
