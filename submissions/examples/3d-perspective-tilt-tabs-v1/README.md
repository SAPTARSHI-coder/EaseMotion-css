# CSS 3D Perspective Tilt Tabs

A pure CSS animated tabs component featuring a smooth 3D perspective tilt
interaction designed for modern SaaS showcase interfaces.

## Features

- Pure HTML and CSS
- No JavaScript required
- 3D perspective tilt interaction
- Smooth tab transitions
- Keyboard accessible
- Responsive layout
- Customizable CSS custom properties
- Reduced-motion support
- SaaS-style visual design

## Usage

Copy the HTML structure and CSS into your project.

No JavaScript or external libraries are required.

## Customization

The animation can be customized using CSS custom properties:

```css
:root {
  --tabs-perspective: 1000px;
  --tabs-tilt: 12deg;
  --tabs-scale: 1.03;
  --tabs-duration: 500ms;
  --tabs-easing: cubic-bezier(0.22, 1, 0.36, 1);
}
