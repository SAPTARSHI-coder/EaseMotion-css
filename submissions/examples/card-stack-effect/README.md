# Pure CSS Card Stack Effect

An interactive, multi-layered card stacking component built entirely with pure HTML and CSS. Hovering over the card stack triggers a smooth 3D fan-out animation that spreads the cards horizontally and vertically for clear visibility.

## 🚀 Features

- **Pure CSS**: Zero JavaScript required for all transforms, layering, and hover states.
- **Smooth 3D Fan-out Animation**: Built with custom `cubic-bezier` timing functions and rotation transforms.
- **Modern Glassmorphic UI**: Gradient palettes, backdrop blurs, and soft glow shadows.
- **Accessible & Responsive**: Clean semantic markup that adapts seamlessly to desktop and mobile viewports.
