# CSS Range Slider

A responsive, CSS-only range slider component with a custom-styled track, animated thumb, progress indicator, and value tooltip.

## Features

- 🎚️ Custom-styled HTML range input
- ✨ Smooth thumb hover animation
- 💬 Value tooltip positioned above the slider
- 🎨 CSS custom properties for easy theming
- 🌓 Supports light and dark color schemes
- 📱 Responsive layout for desktop and mobile screens
- ⌨️ Keyboard accessible using the native range input
- ♿ Uses the native `<input type="range">` accessibility behavior
- 🚫 No JavaScript required
- ♿ Includes reduced-motion support with `prefers-reduced-motion`
