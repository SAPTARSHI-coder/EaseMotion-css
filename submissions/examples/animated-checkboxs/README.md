# Animated Checkbox Collection

## Issue

#57924

## Description

A collection of reusable CSS-only animated checkbox styles for modern interfaces.

## Features

- Smooth check animation
- Multiple checkbox variants
- CSS-only implementation
- No JavaScript required
- Hover interaction
- Keyboard-friendly native checkbox
- Reduced-motion support

## Variants

### Default Checkbox

A simple animated square checkbox.

### Circle Checkbox

A rounded circular checkbox style.

### Fill Checkbox

A filled checkbox with a smooth checkmark animation.

## Files

- `demo.html` - Demonstration page
- `style.css` - Checkbox styles and animations

## Usage

```html
<label class="checkbox-item">
  <input type="checkbox">
  <span class="checkmark"></span>
  <span>Option</span>
</label>
