# CSS Float-Drift Progress Bar

A lightweight SaaS dashboard progress component featuring a smooth floating indicator and animated progress fill using only HTML and CSS.

## Features

- Pure HTML and CSS
- No JavaScript or external frameworks
- Smooth progress-fill animation
- Floating/drifting progress indicator
- Responsive desktop, tablet, and mobile layouts
- Project milestone indicators
- SaaS-style statistics cards
- CSS custom properties for customization
- `prefers-reduced-motion` support
- Semantic progressbar accessibility attributes
