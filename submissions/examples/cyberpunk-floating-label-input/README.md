# Responsive Floating Label Input — Cyberpunk Styling

A futuristic responsive floating label input component inspired by
cyberpunk interfaces.

The component is implemented entirely with HTML and CSS and does not
require JavaScript or external libraries.

## Features

- Cyberpunk inspired visual design
- Responsive floating labels
- Neon cyan and magenta accents
- Futuristic dark interface
- Background grid effect
- Smooth hover and focus transitions
- Native HTML validation
- Keyboard accessibility
- Visible focus indicators
- Textarea support
- Error state
- Reduced-motion support
- No JavaScript dependency
- No external libraries
