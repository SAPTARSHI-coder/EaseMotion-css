# Neumorphic Footer with Dark Mode styling (#78825)

A responsive, zero-JavaScript dark mode footer component featuring authentic soft neumorphic depth shadows, extruded buttons, recessed input fields, and circular social badges.

## Features
- **Dark Neumorphism (Soft UI):** Utilizes multi-layered inset and drop box shadows (`box-shadow`) matching dark surface tokens for tactile physical depth.
- **Interactive Elements:** Extruded buttons that depress upon hover/click and recessed newsletter input fields with glowing focus borders.
- **Accessible & Responsive:** Structured using semantic HTML5 tags (`<footer>`, `<form>`), explicit aria-labels, and fluid grid layouts adapting for mobile viewports.

## File Hierarchy
- `submissions/examples/css-neumorphic-footer-dark-mode/style.css` - Neumorphic shadow variables, button states, input styling, and responsive grid layout.
- `submissions/examples/css-neumorphic-footer-dark-mode/demo.html` - Semantic HTML5 markup displaying the dark neumorphic footer.
- `submissions/examples/css-neumorphic-footer-dark-mode/README.md` - Technical specification and architecture overview.
