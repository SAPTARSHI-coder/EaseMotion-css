# CSS Rotate-Fade Stepper for Product Catalog Layouts

A modern **Rotate-Fade Stepper** built using pure HTML and CSS. The component features smooth rotate-fade animations, responsive layouts, CSS custom properties, and lightweight styling for product catalog workflows.

## ✨ Features

- Pure HTML5 & CSS3
- Rotate-fade step animation
- Responsive stepper layout
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
