# CSS Slide-Up Tooltip

A minimalist CSS tooltip with a smooth slide-up and fade-in interaction.

## Features

- Pure HTML and CSS
- No JavaScript dependencies
- Slide-up and fade animation
- Hover and keyboard focus support
- Responsive design
- Reduced-motion support
- Customizable CSS variables
