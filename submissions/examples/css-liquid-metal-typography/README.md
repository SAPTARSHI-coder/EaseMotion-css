# CSS Liquid Metal Typography

Metallic, highly reflective 3D text utilizing sweeping `linear-gradient` overlays and typography masking to simulate chrome.

## Features
- Extremely complex `linear-gradient` mapping highly contrasting darks and bright whites to simulate environmental reflections on a chrome surface.
- Smooth animation mapping via `background-position` shifting on a `200%` background size to simulate fluid movement across the metal.
- Perfect typography clipping utilizing `-webkit-background-clip: text` and `-webkit-text-fill-color: transparent`.
- Artificial ambient occlusion (3D shadowing) created using a pseudo-element casting dense `text-shadow` layers beneath the text body.
