# CSS Liquid Metal Typography

Metallic, highly reflective 3D text utilizing multiple sweeping `linear-gradient` overlays, `-webkit-text-fill-color: transparent`, and severe contrast filters.

## Features
- Pure CSS multi-layered reflective gradients
- Background clipping on text
- Animated lighting sweeps mimicking liquid metal
