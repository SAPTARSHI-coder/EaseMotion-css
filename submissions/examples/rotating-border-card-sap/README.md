# Rotating Border Card\n\nA card component featuring a CSS conic-gradient animation simulating a glowing rotating border upon hover.\n\n### Usage\n```html\n<div class="card-wrapper">\n  <div class="card-content">\n    <h2>Premium Card</h2>\n    <p>Hover me to see the rotating border effect.</p>\n  </div>\n</div>\n```\n\n### Why is it useful?\nThis component provides a premium aesthetic and smooth micro-interaction that perfectly aligns with EaseMotion's framework-quality design standards. It relies entirely on CSS, making it performant and easy to integrate without JavaScript dependencies.
