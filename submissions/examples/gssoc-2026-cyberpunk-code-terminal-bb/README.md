# Cyberpunk Code Terminal Showcase

An interactive **Cyberpunk Code Block Terminal** with CRT scanlines, neon syntax glow, animated copy feedback, and high contrast styling.

## 🌟 Key Features

- **Neon Syntax Glow**: High contrast cyberpunk palette highlighting keywords, functions, strings, and comments.
- **Copy Feedback**: Interactive clip button with dynamic state confirmation.
- **CRT Scanlines**: Subtle linear-gradient overlay mimicking authentic terminal monitors.

## 🚀 Usage

Open `demo.html` in your browser.
