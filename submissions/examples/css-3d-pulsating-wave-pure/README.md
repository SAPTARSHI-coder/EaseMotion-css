# CSS 3D Effect: Pulsating Wave

A hardware-accelerated, JavaScript-free 3D animation utilizing `transform-style: preserve-3d` and a matrix of staggered `animation-delay` properties to simulate wave physics in a 3D isometric grid.

## Features
- Pure CSS and HTML implementation. No JavaScript required for the 3D physics, rendering, or the mathematical wave delays.
- **Component Architecture**: 
  - **The 3D Isometric Scene**: The `.scene-3d` element establishes the depth using `perspective: 1500px`. The `.grid-3d` container applies `transform-style: preserve-3d` and rotates the entire grid into an isometric viewing angle using `transform: rotateX(60deg) rotateZ(45deg)`.
  - **Constructing 3D Columns**: Since the grid is viewed from a specific isometric top-down angle, we don't need to render all 6 sides of a cube. For performance, each `.column` only renders 3 faces: `.top`, `.left`, and `.right`. These faces are constructed by translating and rotating standard `div` elements on the X, Y, and Z axes.
  - **The Physics Engine (Animation Delays)**: The core wave effect is generated by a single `@keyframes` animation (`translateZ(-20px)` to `translateZ(60px)`) applied to every column. To create the wave, each column in the 5x5 grid is given a specific class (e.g. `.col-3-3` for the center). The CSS then applies a staggered `animation-delay` based on the radial distance of that column from the center, creating a perfect cascading sine wave out from the middle.
- **Theming**: Configured via CSS Custom Properties. The color palette utilizes distinct shades of blue for the top, left, and right faces to provide built-in visual shading, making the 3D extrusion immediately obvious even without complex lighting.
- Fully accessible semantic structure. Honors the `prefers-reduced-motion` accessibility standard by freezing the continuous Z-axis animation. For motion-sensitive users, the CSS falls back to hardcoded static Z-translations, presenting a beautiful "frozen" wave sculpture instead of a moving one.

## Usage
Open `demo.html` in your browser. Observe the continuous radial wave originating from the center of the grid, driven entirely by CSS animation delays.

## Files
- `demo.html`: The HTML structure defining the 3D scene, the grid container, and the 25 individual column elements with their respective coordinates.
- `style.css`: The styling, the isometric `preserve-3d` mechanics, the 3D face geometry, the `@keyframes` Z-axis translation, and the mathematical matrix of `animation-delay` properties.
