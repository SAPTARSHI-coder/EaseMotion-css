# CSS Signal Pulse Button

A native CSS button with expanding signal rings that communicate an action through motion.

## Features

- Pure CSS pulse rings
- Native accessible button
- Hover, focus, and active states
- Responsive sizing
- Reduced-motion support
- No JavaScript

## Files

- `demo.html` — semantic button and component notes
- `style.css` — pulse animation, responsive layout, and accessibility rules

## Accessibility

The action uses a native button and a visible `:focus-visible` indicator. Decorative rings are suppressed for reduced-motion users.
