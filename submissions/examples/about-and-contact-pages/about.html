About EaseMotion

Making CSS animations simple.

EaseMotion is an animation-first CSS library created to help developers build smooth, expressive and engaging web experiences using simple, human-readable class names.

01 — About

What is EaseMotion?

EaseMotion is a lightweight CSS animation library designed around one simple idea: animations should be easy to understand and easy to use.

Instead of writing complicated animation code every time, developers can simply apply descriptive classes to their HTML elements and create beautiful animations quickly.

Whether you are building a portfolio, landing page, dashboard, documentation website or web application, EaseMotion helps bring your interface to life.

Simple. Readable. Animation-first. 
<div class="ease-fade-in">
    Hello World
</div>

<div class="ease-slide-up">
    Welcome
</div>

<div class="ease-bounce">
    ↑
</div>
