# About Us & Contact Us Pages

A complete, responsive multi-page showcase featuring animated "About Us" and "Contact Us" pages styled with pure CSS.

## Features
- **Modern About Us Page**: Interactive team showcase, story section, animated stat cards, and mission statement.
- **Interactive Contact Us Page**: Floating label inputs, responsive form layout, and smooth focus states.
- **Pure CSS Layout & Styling**: Built with CSS Grid, Flexbox, and custom easing transitions.
- **Zero JavaScript Dependency**: Fully functional with HTML and CSS.

## Files
- `demo.html` / `about.html` — Interactive About Us page
- `contact.html` — Interactive Contact Us page
- `style.css` — Styling and layout rules
- `README.md` — Documentation
