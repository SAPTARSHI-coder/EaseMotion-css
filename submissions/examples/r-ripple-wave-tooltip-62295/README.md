# CSS Ripple-Wave Tooltip

A lightweight pure CSS ripple-wave tooltip designed for product catalog
layouts.

## Features

- Pure HTML and CSS
- No JavaScript dependencies
- Animated ripple-wave effect
- Glassmorphism tooltip
- Responsive product card
- Keyboard accessible tooltip trigger
- Visible focus states
- `prefers-reduced-motion` support
- Customizable CSS properties
