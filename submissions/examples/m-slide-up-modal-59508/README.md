# CSS Slide-Up Modal for SaaS Showcase Layouts

A modern **Slide-Up Modal** built using pure HTML and CSS. The modal smoothly slides upward into view with elegant glassmorphism styling, making it ideal for SaaS dashboards, landing pages, and product showcases.

## ✨ Features

- Pure HTML5 & CSS3
- Smooth slide-up entrance animation
- Glassmorphism modal
- Responsive layout
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
