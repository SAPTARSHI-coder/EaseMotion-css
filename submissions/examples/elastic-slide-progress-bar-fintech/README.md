# CSS Elastic-Slide Progress Bar for Fintech Dashboard Layouts

A modern fintech dashboard component featuring animated elastic-slide
progress bars built entirely with HTML and CSS.

The component demonstrates smooth progress animations suitable for
financial dashboards, analytics platforms, payment applications and
SaaS products.

## Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Elastic progress-bar animation
- Smooth slide-in entrance effects
- Progress-bar highlight animation
- Financial KPI cards
- Transaction activity panel
- Performance score visualization
- Responsive desktop layout
- Responsive tablet layout
- Responsive mobile layout
- CSS custom properties
- Semantic HTML
- Accessible progressbar attributes
- Visible focus styles
- `prefers-reduced-motion` support
