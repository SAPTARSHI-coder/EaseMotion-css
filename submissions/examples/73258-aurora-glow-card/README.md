# Aurora Glow Card

A responsive pure CSS card component featuring an **Aurora Glow** visual treatment with layered gradients, ambient light, soft elevation, and smooth interactions.

## ✨ Features

- Aurora-inspired layered gradients
- Animated ambient glow
- Soft elevation on hover
- Responsive card grid
- Dark-mode compatible
- Light-mode compatible
- Keyboard-accessible links
- Visible focus states
- Reduced-motion support
- Smooth CSS transitions
- Hardware-friendly transforms
- No JavaScript
- No external dependencies
