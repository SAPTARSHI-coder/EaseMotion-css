# Reed Organ Valve

## What does this do?
Renders a self-contained CSS-only `ease-reed-organ-valve` demo: Reed organ valve fluttering under wind chest pressure.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-reed-organ-valve`. No build step or JavaScript is required for the effect.

```html
<section class="ease-reed-organ-valve">
  <div class="ease-reed-organ-valve__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
