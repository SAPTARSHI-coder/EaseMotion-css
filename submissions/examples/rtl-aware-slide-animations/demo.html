RTL-Aware Slide Animations

A smart CSS architecture using direction multipliers to make transform: translateX() animations fully compatible with Right-to-Left (RTL) languages.

Hardcoded Slide-In (Buggy)

Uses a hardcoded translateX(-100%). When switched to RTL, it slides in from the wrong logical side!

Direction-Aware Slide-In (Fixed)

Uses translateX(calc(-100% * var(--dir-multiplier))). This magically flips the axis when in RTL mode!
