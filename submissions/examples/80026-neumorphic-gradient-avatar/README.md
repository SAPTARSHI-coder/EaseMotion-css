# Neumorphic Gradient Avatar (Ultra)

A polished avatar component combining soft neumorphic depth with
vibrant gradient styling.

The component is built using only HTML and CSS and is designed to be
responsive, accessible, and easy to reuse.

## Features

- Neumorphic layered shadows
- Vibrant animated gradient avatar ring
- Gradient avatar background
- Online status indicator
- Profile information section
- Profile tags
- Interactive profile button
- Multiple gradient avatar variants
- Responsive layout
- Keyboard-friendly focus state
- Reduced-motion support
- No JavaScript required
- No external dependencies
