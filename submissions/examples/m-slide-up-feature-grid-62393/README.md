# CSS Slide-Up Feature Grid for Product Catalog Layouts

A modern **Slide-Up Feature Grid** built using pure HTML and CSS. The component features elegant slide-up hover animations, responsive feature cards, CSS custom properties, and lightweight styling for product catalog interfaces.

## ✨ Features

- Pure HTML5 & CSS3
- Slide-up hover animation
- Responsive feature grid
- Glassmorphism card design
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
