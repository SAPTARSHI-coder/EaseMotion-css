# Glassmorphism Blur Text Animation

What does this do?
This adds a smooth, hardware-accelerated text reveal animation featuring a glassmorphism blur effect and container, compatible with dark mode.

How is it used?
```html
<div class="glass-container">
  <h1 class="glass-text">Your Text Here</h1>
</div>
```

Why is it useful?
It provides a modern, premium aesthetic suitable for hero sections or headers, adhering to the EaseMotion philosophy of performant and beautiful animations.
