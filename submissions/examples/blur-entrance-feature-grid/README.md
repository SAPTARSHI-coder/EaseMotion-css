# Blur-Entrance Feature Grid

A responsive, CSS-only feature grid designed for modern gaming hub
interfaces.

The component uses a smooth blur, fade, scale, and vertical entrance
animation to reveal feature cards.

## Features

- Pure HTML and CSS
- No JavaScript
- No external frameworks
- Responsive gaming dashboard layout
- CSS Grid based layout
- Blur + fade entrance animation
- Staggered card animations
- Hover elevation effects
- Animated progress indicator
- CSS custom properties
- Mobile and tablet support
- `prefers-reduced-motion` support
- Lightweight implementation
