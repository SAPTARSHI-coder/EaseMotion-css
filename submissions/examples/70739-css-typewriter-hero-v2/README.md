# CSS Typewriter Hero v2

A CSS-only hero that cycles through multiple typewriter phrases with responsive typography and a reduced-motion fallback.

## Features

- Multiple animated phrases
- Stepped typewriter reveal
- Responsive headline sizing
- Native link action
- Focus-visible styling
- Reduced-motion fallback
- No JavaScript

## Files

- `demo.html` — hero content and semantic navigation
- `style.css` — phrase timing, typography, responsive layout, and accessibility rules

## Accessibility

The hero has a readable static phrase available when animation is disabled. The action has a visible keyboard focus state and reduced-motion users see a non-animated presentation.
