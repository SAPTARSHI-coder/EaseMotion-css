# CSS Glitched Cyberpunk Text

Extreme, chaotic typography simulating a severe digital glitch.

## Features
- Classic RGB split using intense offset `text-shadow` colors on stacked pseudo-elements.
- Chaotic digital slicing achieved using rapid `clip-path: polygon()` slice reassignments.
- Aggressive jitter introduced by combining the clip-path slices with tight `translate` shifting on multiple keyframes.
