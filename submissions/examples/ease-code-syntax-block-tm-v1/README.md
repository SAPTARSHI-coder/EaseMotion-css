# Code Syntax Block Component

Add ease-code-syntax-block-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|---------|
| `--csb-accent` | `#6366f1` |
| `--csb-green` | `#10b981` |
| `--csb-yellow` | `#f59e0b` |
| `--csb-red` | `#ef4444` |
| `--csb-radius` | `10px` |
| `--csb-code-bg` | `#0f0f1a` |

## Technique

CSS class-based syntax highlighting using `<span>` classes for keywords, strings, functions, etc.
