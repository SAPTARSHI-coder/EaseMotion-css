# Glassmorphism Blur Progress Bar

A modern glassmorphism-style progress bar created using pure HTML and
Vanilla CSS.

## ✨ Features

- Glassmorphism UI
- Blur and translucent effects
- Smooth progress transition
- Animated glass reflection
- Soft progress glow
- Responsive design
- Dark-mode compatible
- Accessible progressbar semantics
- `prefers-reduced-motion` support
- Hardware-friendly CSS transforms
- No JavaScript
- No external libraries

## 🛠️ Technologies

- HTML5
- CSS3
- CSS Variables
- CSS Gradients
- CSS Animations
- Backdrop Filter
- CSS Transitions
