# Lightbox Gallery Component

Add ease-lightbox-gallery-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|---------|
| `--lbg-accent` | `#6366f1` |
| `--lbg-radius` | `12px` |
| `--lbg-overlay` | `rgba(0,0,0,0.92)` |

## Note

CSS handles overlay display/animation. Tiny JS manages open/close state.
