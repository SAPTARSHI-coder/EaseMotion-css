# Morphing Toggle with Glassmorphism Styling

A responsive CSS-only toggle component featuring a soft glassmorphism interface and smooth morphing interaction.

## Features

- Glassmorphism-inspired visual design
- Morphing toggle animation
- Pure HTML and CSS
- No JavaScript dependency
- Fully responsive
- Multiple reusable toggle instances
- Keyboard-accessible focus states
- Reduced-motion accessibility support
- Smooth hover interactions
- ON/OFF visual states

## Files

- `demo.html` — component structure and examples
- `style.css` — complete styling and responsive behavior

## Usage

Use a standard checkbox inside the `.switch` component:

```html
<label class="switch">
  <input type="checkbox">
  <span class="slider">
    <span class="thumb"></span>
    <span class="state-text">
      <span class="on-text">ON</span>
      <span class="off-text">OFF</span>
    </span>
  </span>
</label>
