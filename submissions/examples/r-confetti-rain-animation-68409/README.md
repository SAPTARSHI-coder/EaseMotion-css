# CSS Confetti Rain Animation

A lightweight celebration effect where colorful confetti pieces continuously fall from the top of a container using pure CSS.

## Features

- Pure HTML and CSS
- No JavaScript required
- Colorful falling confetti
- Random-looking staggered timing
- Multiple confetti colors
- Responsive layout
- CSS custom properties
- Lightweight keyframe animation
- `prefers-reduced-motion` support

Include the stylesheet:
