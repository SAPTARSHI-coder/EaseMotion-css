# CSS Liquid Wave Fill Loader

A smooth liquid wave fill loader built using pure HTML and CSS.

## Features

- Pure HTML and CSS
- No JavaScript
- Smooth liquid wave animation
- Dual-layer wave effect
- Glass-style loader container
- Responsive design
- Dark-mode friendly
- Hardware-friendly CSS transforms
- Accessible loading status
- `prefers-reduced-motion` support
- Forced-colors support
- No external dependencies

## Preview

The loader displays a circular container with animated liquid waves
moving continuously inside it.
