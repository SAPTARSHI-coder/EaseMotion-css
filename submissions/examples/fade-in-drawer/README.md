# CSS Fade-In Drawer

A responsive creative portfolio drawer featuring a smooth fade-in overlay effect built with pure HTML and CSS.

## Features

- Pure HTML & CSS
- Responsive design
- Smooth fade-in animation
- Accessible with prefers-reduced-motion
- Easy customization using CSS variables

## Files

- demo.html
- style.css

## Usage

Open `demo.html` in any modern browser.

## CSS Variables

```css
:root{
  --bg:#0f172a;
  --card:#1e293b;
  --accent:#38bdf8;
  --text:#fff;
}
```
