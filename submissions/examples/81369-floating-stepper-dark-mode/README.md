# Floating Stepper — Dark Mode

A responsive floating stepper with a polished dark-mode visual
style created for EaseMotion CSS issue #81369.

## Features

- Dark-mode interface
- Floating elevated cards
- Completed, active and upcoming states
- Soft neon accent glow
- Animated active marker
- Animated progress indicator
- Smooth hover elevation
- Responsive desktop, tablet and mobile layout
- Reduced-motion support
- Pure HTML and CSS
- No JavaScript dependencies
