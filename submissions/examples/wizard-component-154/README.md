# Multi-Step Animated Progress Stepper Wizard

A futuristic Cyberpunk-themed multi-step progress stepper wizard for onboarding flows, setup processes, dashboards, checkout experiences, and multi-stage forms.

## ✨ Features

- Four-step animated progress indicator
- Cyberpunk visual design
- Neon cyan and magenta accents
- Terminal-inspired interface
- Animated progress connectors
- Previous and Continue navigation
- Completed-step indicators
- Interactive protocol selection
- Responsive layout
- Keyboard focus states
- Reduced-motion support
- No external dependencies

## 📁 Structure

```text
ease-anim-multi-step-animated-progress-stepper-wizard-component-154/
├── demo.html
├── style.css
├── script.js
└── README.md
````

## 🚀 Usage

Navigate to the component directory:

```bash
cd submissions/examples/ease-anim-multi-step-animated-progress-stepper-wizard-component-154
```

Open `demo.html` in any modern browser.

No npm packages or build tools are required.

## 🧭 Wizard Steps

1. **Identity** — Enter operator information.
2. **Profile** — Configure professional details.
3. **Protocol** — Select communication preferences.
4. **Deploy** — Complete the initialization process.

## 🎨 Customization

The main theme is controlled through CSS variables:

```css
:root {
  --bg: #050608;
  --cyan: #00f6ff;
  --pink: #ff2bd6;
  --green: #39ff88;
}
```

Change these variables to create your own cyberpunk color palette.

## ♿ Accessibility

The component includes:

* Semantic HTML
* Accessible progress navigation
* `aria-label`
* `aria-labelledby`
* `aria-live`
* Visible keyboard focus states
* Reduced-motion support
* Responsive text and controls

## 📱 Responsive Design

The layout adapts to desktop, tablet, and mobile screen sizes.

On smaller screens, the progress stepper becomes horizontally scrollable and form fields switch to a single-column layout.
