# CSS Blur-Entrance Modal for Fintech Dashboard Layouts

A modern **Blur-Entrance Modal** component built using pure HTML5 and CSS3 for fintech dashboard layouts. This component provides a premium financial interface with smooth blur animations, glassmorphism styling, responsive design, and accessibility support.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Fintech dashboard inspired design
* Smooth blur entrance animation
* Fade and scale transition effects
* Glassmorphism modal UI
* Financial transaction showcase
* Animated statistics section
* Gradient action buttons
* Responsive desktop, tablet, and mobile layouts
* CSS Custom Properties support
* Lightweight keyframe animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. View the animated financial modal component.
3. Customize colors, shadows, spacing, and animations through CSS variables.
