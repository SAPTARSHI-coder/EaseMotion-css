# Ease Pill Group

## What does this do?

A horizontal group of selectable pill buttons with an active state, hover animation, and responsive wrapping.

---

## How is it used?

Open `demo.html` directly in any modern browser.

Example:

```html
<div class="pill-group">
    <button class="pill active">All</button>
    <button class="pill">Design</button>
    <button class="pill">Development</button>
</div>
```

### Features

- Multiple selectable pills
- Active state
- Hover animation
- Click feedback
- Responsive wrapping
- Lightweight and reusable

---

## Why is it useful?

Pill groups are commonly used for filters, categories, segmented controls, and navigation choices.

This component provides a simple and reusable selectable pill pattern with subtle interaction feedback while following the animation-first philosophy of EaseMotion CSS.
