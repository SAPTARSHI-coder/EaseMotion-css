# CSS-Only Flip Book

A lightweight animated flip book created using only HTML and CSS.

## ✨ Features

- Pure HTML and CSS
- No JavaScript
- 3D page-flip animation
- Responsive design
- Hover-to-pause interaction
- Reduced-motion support
- Semantic HTML
- Accessible descriptive labels
- Works on desktop, tablet, and mobile
