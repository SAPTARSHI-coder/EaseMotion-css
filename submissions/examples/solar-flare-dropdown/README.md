# ☀️ CSS Dropdown: Solar Flare Radial

A responsive and accessible dropdown menu inspired by the radiant
energy and radial glow of a solar flare.

The component uses pure HTML and vanilla CSS with no external
JavaScript or dependencies.

## Features

- Pure HTML and CSS
- No external JavaScript
- Solar Flare-inspired visual design
- Radial glow effects
- Smooth dropdown transitions
- CSS-only hover and focus interaction
- Keyboard-accessible navigation
- Visible focus states
- Responsive layout
- Dark-mode-friendly palette
- Hardware-friendly transforms
- Reduced-motion support
- No external assets
