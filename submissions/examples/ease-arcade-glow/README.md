# Arcade Glow · Neon Arcade Effect 🎰

An interactive neon arcade glow effect with hover animations, retro color schemes, pulsating neon lights, and sparkle trails. Perfect for creating that classic 80s/90s arcade atmosphere.

## Features

- 🎰 **Neon Glow Effects** – 6 vibrant neon colors with hover-activated glow
- ✨ **Sparkle Trail** – Mouse movement creates sparkling particle trails
- 🎮 **Retro Design** – Arcade-inspired cards with classic gaming aesthetic
- 💫 **Pulse Animation** – Title and cards have subtle pulsing neon glow
- 🎨 **Color Variants** – Pink, Blue, Green, Purple, Orange, Cyan themes
- 📱 **Responsive** – Adapts to any screen size (3, 2, or 1 column grid)
- 🖱️ **Interactive** – Hover effects with translate, scale, and glow transitions

## How to Use

1. **Hover** over any card to activate neon glow effect
2. **Watch** the sparkle trail follow your mouse movement
3. **Enjoy** the pulsing arcade title and vibrant neon colors
4. **Each card** has its own unique neon color scheme

## Files Included

- `index.html` – Main HTML file with embedded JavaScript
- `style.css` – All styling and neon effects
- `README.md` – This documentation

## Technical Details

- **Grid Layout:** 3-column responsive grid with flex fallback
- **Colors:** 6 neon color variants (#ff2d75, #00d4ff, #39ff14, #b026ff, #ff6b00, #00ffcc)
- **Effects:** Radial gradients, box shadows, text shadows, transforms
- **Animation:** CSS keyframes for pulsing title
- **Sparkles:** JavaScript-generated DOM elements with fade-out

## Browser Support

Works in all modern browsers:
- Chrome, Firefox, Safari, Edge
- Mobile browsers with touch support (hover effects work on tap)

## Customization

You can easily customize:
- **Colors:** Add new color variants in both CSS and JavaScript
- **Sparkle count:** Modify `MAX_SPARKLES` in the JavaScript
- **Animation speed:** Adjust `animation-duration` in `titlePulse`
- **Card layout:** Change grid columns in `grid-template-columns`

## Run Locally

Simply open `index.html` in your browser – no server required!
