# Dip Circle Inclination

## What does this do?
Renders a self-contained CSS-only `ease-dip-circle-inclination` demo: Magnetic dip circle needle settling to local inclination angle.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-dip-circle-inclination`. No build step or JavaScript is required for the effect.

```html
<section class="ease-dip-circle-inclination">
  <div class="ease-dip-circle-inclination__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
