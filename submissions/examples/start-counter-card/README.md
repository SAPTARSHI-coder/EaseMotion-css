# Stat Counter Card

A dependency-free Stat Counter Card component created for the EaseMotion CSS gallery.

## Description

A metric card where the main number pops up and a mini bar chart animates when the user hovers over the card.

## Features

- Large animated statistic
- Mini bar chart
- Hover animations
- Staggered bar animation
- Percentage growth indicator
- Responsive design
- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Accessible reduced-motion support
