# Responsive Filter Bar — Neumorphism

A responsive filter bar component featuring a soft
neumorphic visual style, implemented entirely with HTML
and CSS.

Created for EaseMotion CSS issue #81462.

## Features

- Neumorphic surface styling
- Search input
- Category selector
- Sort selector
- Apply filters action
- Reset action
- Quick filter chips
- Active filter state
- Soft inset and raised shadows
- Hover and active interactions
- Keyboard focus states
- Responsive desktop, tablet and mobile layouts
- `prefers-reduced-motion` support
- Zero JavaScript dependencies
