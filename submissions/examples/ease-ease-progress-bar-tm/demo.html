Scroll-Linked Reading Progress Bar

This component tracks your reading position on the page and updates the progress bar as you scroll.

How It Works

The progress bar uses JavaScript to read the scroll position and update the CSS transform on the fill element. The CSS handles all the visual styling, animations, and variants.

Variants Available

Several visual variants are provided: default thin line, thick line, double-line with glow, glow with shadow, solid color, and chapter markers at 25% and 50%.
