# Subgrid & Container Query Browser Layout Repaint Benchmark

## Overview
This submission demonstrates a browser-side benchmark comparing traditional CSS Grid layouts with CSS Subgrid and Container Queries.

## Metrics
- FPS
- Frame render time
- Layout repaint duration
- Performance budget status

## Performance Budget
- FPS ≥ 60
- Frame time ≤ 16.7 ms
- Repaint ≤ 8 ms

## Usage
Open `demo.html` directly in any modern browser.
