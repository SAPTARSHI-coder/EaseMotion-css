# Holographic Product Card

A futuristic holographic product card created for EaseMotion CSS.

The component uses pure HTML and CSS to create a layered holographic
appearance with interactive light refraction, depth movement and
responsive behavior.

## Features

- Pure HTML and CSS
- No JavaScript required
- Holographic lighting
- Mouse-hover light refraction
- 3D-inspired hover movement
- Animated holographic product orb
- Responsive layout
- CSS custom properties
- Keyboard-accessible CTA
- Reduced-motion accessibility support
- Lightweight implementation
