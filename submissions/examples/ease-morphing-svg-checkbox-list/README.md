# Ease Morphing SVG Checkbox List

An interactive task checklist built using HTML, CSS, and Vanilla JavaScript.

## Features

- SVG animated checkbox
- Strike-through text animation
- Animated progress bar
- Glassmorphism UI
- Keyboard accessible
- Responsive layout
- Completion message

## Folder Structure

```
ease-morphing-svg-checkbox-list/
├── demo.html
├── style.css
├── script.js
└── README.md
```

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

## Usage

Open `demo.html` in a web browser.
