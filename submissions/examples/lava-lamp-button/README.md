# CSS Lava Lamp Button


A pure CSS animated button with floating lava lamp blobs.


## Overview

`css-lava-lamp-button` creates a modern interactive button where colorful blobs slowly move and transform on hover.


## Features

- Pure CSS implementation
- No JavaScript dependency
- Animated lava blobs
- Smooth hover interaction
- Responsive design
- Reduced motion support


## Animation

Uses:

- transform
- blur effects
- border-radius animation
- CSS transitions


## Usage

Useful for:

- Landing pages
- CTA buttons
- Portfolio websites
- Modern UI components
