# CSS Scale-Hover Stepper for Product Catalog Layouts

A modern **Scale-Hover Stepper** built using pure HTML and CSS. The component features elegant scale-hover interactions, responsive layouts, CSS custom properties, and lightweight styling for product catalog workflows.

## ✨ Features

- Pure HTML5 & CSS3
- Scale-hover interaction
- Responsive stepper layout
- CSS Custom Properties
- Smooth transitions
- `prefers-reduced-motion` support
- No JavaScript required
