ease-accordion CSS @property Demo

Hover each card to see it in action:

The progress bar smoothly animates because --ease-accordion-progress is registered as a <number> via @property. The bar width is calc(var(--ease-accordion-progress) * 1%). The hue also shifts from blue to green via an animated --ease-accordion-hue property. None of this is possible with regular CSS variables!
