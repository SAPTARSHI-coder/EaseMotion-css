# Bounce-Pulse Drawer for E-Commerce Checkout

A lightweight, pure CSS/HTML Bounce-Pulse Drawer designed for
modern e-commerce checkout layouts.

## Features

- Pure HTML and CSS
- No JavaScript
- No external frameworks
- Bounce-style drawer entrance animation
- Subtle pulse animation
- Animated decorative glow
- Interactive hover states
- Responsive desktop, tablet, and mobile layouts
- CSS custom properties
- Keyboard-accessible button focus state
- `prefers-reduced-motion` support
