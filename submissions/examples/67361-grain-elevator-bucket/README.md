# Ease Grain Elevator Bucket

A CSS-only animated grain elevator bucket component that represents cereal grain transportation using moving elevator buckets.

## Features

- Real-world agricultural motion metaphor
- Pure HTML and CSS implementation
- Animated bucket lifting system
- Industrial control panel UI
- Responsive design
- Reduced motion accessibility support


## Usage

Add:

```html
<div class="ease-grain-elevator-bucket">
</div>
