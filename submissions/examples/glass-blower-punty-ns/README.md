# Glass Blower Punty

## What does this do?
Renders a self-contained CSS-only `ease-glass-blower-punty` demo: Glassblower punty rotating a glowing gather.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-glass-blower-punty`. No build step or JavaScript is required for the effect.

```html
<section class="ease-glass-blower-punty">
  <div class="ease-glass-blower-punty__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
