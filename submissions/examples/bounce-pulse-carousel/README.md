# CSS Bounce-Pulse Carousel for Gaming Hub Layouts

## Overview

A lightweight CSS-only Bounce-Pulse Carousel designed for modern gaming interfaces.

The component provides animated cards with smooth bouncing and glowing pulse effects using pure CSS.

---

## Features

- Pure HTML and CSS
- Bounce animation effect
- Pulse glow interaction
- Responsive layout
- Hover scaling effect
- CSS custom properties
- No JavaScript required
- prefers-reduced-motion support
