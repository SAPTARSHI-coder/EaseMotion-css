# Aurora Pulse Fit

Aurora Pulse Fit is a lightweight animated UI component that combines flowing
aurora lights with a breathing pulse effect around a central visual element.

## What does this do?

The component creates an interactive aurora-inspired pulse animation with
three drifting light layers, a continuously expanding pulse ring, and a
central glowing core.

The pulse intensity can be adjusted in real time using the slider.
