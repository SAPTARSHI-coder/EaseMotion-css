# CSS 3D Laser Ray Trace

A pure CSS 3D laser ray trace effect featuring glowing animated rays, perspective depth, a central energy core, and a futuristic grid.

## Features

- Pure HTML and CSS
- No JavaScript or external libraries
- 3D perspective and transforms
- Animated laser rays
- Glowing central core
- Responsive layout
- Dark-mode friendly design
- Reduced-motion support

## Usage

Open `demo.html` directly in any modern browser.

The component can be reused by copying the HTML structure and linking `style.css`.

## Accessibility

The component uses semantic HTML, an accessible section label, descriptive text, and `prefers-reduced-motion` support for users who request reduced animation.

## EaseMotion CSS

This component demonstrates a reusable CSS-only 3D animation pattern suitable for futuristic interfaces, hero sections, dashboards, and interactive landing pages.
