# Claymorphism Interactive Multi-Select Dropdown

A pure CSS multi-select dropdown component featuring tactile, 3D claymorphic UI elements and springy motion transitions powered by EaseMotion CSS tokens.

## Features
- **Zero JS Engine:** Utilizes native HTML checkbox inputs and CSS sibling selectors for toggling states.
- **Claymorphism Aesthetic:** Inner highlights, soft multi-layered drop shadows, and pill-shaped badges.
- **Responsive Sheet Design:** Converts to an accessible bottom sheet drawer on mobile viewports (<480px).
- **EaseMotion Tokens:** Includes spring cubic-bezier transitions (`cubic-bezier(0.34, 1.56, 0.64, 1)`).
- **Accessibility:** Fully supports `prefers-reduced-motion` overrides and keyboard toggle focus.
