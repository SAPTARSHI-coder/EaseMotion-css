# CSS Blur-Entrance Badge

A responsive badge component featuring a smooth blur-to-clear entrance animation for creative portfolio layouts.

## Features

- Pure HTML & CSS
- Blur entrance animation
- Hover elevation effect
- Fully responsive
- Accessible
- Supports `prefers-reduced-motion`

## Files

- demo.html
- style.css

## Usage

```html
<link rel="stylesheet" href="style.css">

<span class="blur-badge">Frontend</span>
```

## Customization

Update the CSS variables:

```css
:root{
  --primary:#5b5ff7;
  --secondary:#7c6cff;
  --duration:.6s;
}
```

## Accessibility

- Responsive layout
- Motion reduction support
- Semantic HTML
- Keyboard friendly
