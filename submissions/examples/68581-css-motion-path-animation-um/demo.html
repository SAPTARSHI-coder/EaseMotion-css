Engineering Details

How it works

Offset Path Specification Uses the native CSS offset-path property matching standard SVG layout coords.
Automatic Rotation By leveraging native offset-rotate: auto (default), the element automatically rotates to match the path's exact angle coordinates.
Hardware Accelerated Runs directly on the browser compositor layer, leaving main script queues fully open.
Accessibility Aware Respects system motion requests using prefers-reduced-motion styles to anchor the animation loop immediately.
