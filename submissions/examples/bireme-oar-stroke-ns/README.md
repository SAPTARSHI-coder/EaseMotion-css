# Bireme Oar Stroke

## What does this do?
Renders a self-contained CSS-only `ease-bireme-oar-stroke` demo: Bireme dual-bank oar stroke cycle.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-bireme-oar-stroke`. No build step or JavaScript is required for the effect.

```html
<section class="ease-bireme-oar-stroke">
  <div class="ease-bireme-oar-stroke__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
