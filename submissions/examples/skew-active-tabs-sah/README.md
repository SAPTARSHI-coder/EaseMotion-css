# Skew-Active Creative Portfolio Tabs (`#54462`)

## What does this do?
Provides an avant-garde geometric tabbed layout whose active selection controls and content panels tilt into bold parallelogram geometries during switching interactions.

## How is it used?
Structure skew views inside an `ease-tabs-skew` layout block:
```html
<div class="ease-tabs-skew">
  <div class="skew-view active"><div class="view-content">...</div></div>
</div>
```

## Why is it useful?
Solves issue #54462 by delivering assertive industrial streetwear aesthetics to multi-category design showcases.
