# ease-vending-soda-dispenser
A soda vending machine with a cold display rack, a coin slot that flaps open, selector buttons, and a dispenser that drops a can into the tray.
## Run
Open `demo.html` directly in a browser to watch the vending cycle.
## Notes
- Cola and orange cans wobble in place while the berry can drops into the pickup tray.
- The coin flap opens and closes above the A1-A3 selection buttons.
