ease-carousel View Transitions Demo

Native Morphing Animations:

Click the card below. The browser natively animates the bounds of the card, the font size of the title, and the position of the content using the View Transitions API (view-transition-name).

No FLIP animations, no complex JS math, just a simple DOM state change intercepted by document.startViewTransition()!

Note: The View Transitions API is currently supported in Chromium browsers and Safari 18+. Browsers that don't support it will just see a sudden jump (graceful degradation).
