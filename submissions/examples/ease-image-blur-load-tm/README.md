# Image Blur Load Component

Add ease-image-blur-load-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|--------|
| `--ibl-blur` | `20px` |
| `--ibl-radius` | `12px` |
| `--ibl-shadow` | `0 4px 20px rgba(0,0,0,.3)` |

## Note

Small blurred placeholder clears on `onload`. Full image fades in smoothly.
