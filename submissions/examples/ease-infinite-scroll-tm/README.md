# Infinite Scroll Component

Add ease-infinite-scroll-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|---------|
| `--isc-accent` | `#6366f1` |
| `--isc-radius` | `10px` |
| `--isc-shadow` | `0 4px 16px rgba(0,0,0,.3)` |

## Technique

Staggered card entrance with `animation-delay` creates the infinite scroll feed effect.
