# CSS Skew-Active Popover for Accessible Web Layouts

A modern **Skew-Active Popover** component built completely with **HTML5 and CSS3**. This showcase demonstrates interactive popovers with smooth skew transformations, animated hover states, gradient styling, responsive layouts, and accessibility support without requiring JavaScript.

---

## ✨ Features

- 📐 Smooth skew-active animation
- 💎 Glassmorphism popover design
- 🌈 Gradient trigger buttons
- ✨ Glow border effects
- 🎯 CSS Custom Properties
- ⚡ Smooth CSS transitions
- 📱 Fully responsive layout
- 🧩 Pure HTML5 & CSS3
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

## 🚀 Getting Started

1. Open `demo.html` in any modern browser.
2. Hover over the buttons to reveal the skew popovers.
3. Customize colors, spacing, and animation timing using CSS variables.
