# CSS Bounce-Pulse Progress Bar for SaaS Showcase Layouts

A modern **Bounce-Pulse Progress Bar** component built using pure HTML and CSS for EaseMotion CSS.

## Features

- Smooth bounce-pulse animation
- Animated progress fill
- Percentage indicator
- Responsive layout
- Glassmorphism design
- CSS Custom Properties
- Pure HTML & CSS
- No JavaScript required
- Accessible
- Supports `prefers-reduced-motion`
