# Glassmorphism Tab Bar with Gradient Styling

A fully responsive tab bar component featuring glassmorphism effects combined with vibrant gradient accents.

## Features

- Glassmorphism UI
- Gradient active tab indicator
- Smooth hover animations
- Mobile responsive layout
- Pure HTML and CSS
- No external dependencies

## Files

- demo.html
- style.css

## Usage

Open `demo.html` in a browser.

## Customization

Modify the gradient colors inside `style.css`:

```css
background: linear-gradient(135deg, #7c3aed, #06b6d4);
```

Adjust blur intensity:

```css
backdrop-filter: blur(18px);
```
