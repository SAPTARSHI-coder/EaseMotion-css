# CSS Skew-Active Stepper for Creative Portfolio Layouts

A modern **Creative Portfolio Stepper** built entirely with **HTML5 and CSS3**. This showcase demonstrates an elegant **Skew-Active** stepper featuring smooth transitions, gradient highlights, responsive layouts, and accessibility support without requiring JavaScript.

---

## ✨ Features

- 🚀 Creative Portfolio stepper
- 🔷 Skew-Active card design
- 🎨 Gradient active state
- ✨ Smooth hover animations
- 📱 Fully responsive
- ⚡ Pure HTML5 & CSS3
- 🎯 CSS Custom Properties
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

## 🚀 Getting Started

1. Open `demo.html` in any modern browser.
2. View the responsive skewed stepper layout.
3. Hover over the cards to see smooth transitions.
4. Customize colors, spacing, and animation timing using CSS variables.
