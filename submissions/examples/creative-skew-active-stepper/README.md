# CSS Skew-Active Stepper for Creative Portfolio Layouts

A modern **Creative Portfolio Stepper Component** built using **pure HTML5 and CSS3**. This showcase demonstrates a unique **Skew-Active animation**, glassmorphism cards, gradient highlights, and responsive workflow presentation without JavaScript.

---

## ✨ Features

- 🔥 Skew-Active hover animation
- 📍 Multi-step workflow layout
- 💎 Glassmorphism cards
- 🌈 Gradient glow effects
- ✨ Active step highlighting
- 🚀 Smooth CSS transitions
- 📱 Fully responsive design
- 🎨 CSS Custom Properties
- ♿ `prefers-reduced-motion` support
- 🚫 Pure HTML & CSS

## 🚀 Getting Started

1. Open `demo.html` in a modern browser.
2. Hover over the step cards to view the skew animation.
3. Customize colors, spacing, and animation effects using CSS variables.

---

## 🎨 CSS Variables

:root{

    --bg:#07111f;
    --surface:rgba(255,255,255,.08);

    --secondary:#06b6d4;
    --text:#ffffff;
