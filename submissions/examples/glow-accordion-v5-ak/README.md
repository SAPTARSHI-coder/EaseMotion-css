# glow-accordion-v5-ak

Pure CSS animated glowing neon border accordion drawer component — no JavaScript required.

## How to use

```html
<div class="ease-accordion-v5">
  <input type="checkbox" id="item1" class="ease-accordion-checkbox-v5" />
  <div class="ease-accordion-item-v5">
    <label for="item1" class="ease-accordion-header-v5">
      <span>Header</span>
      <span class="ease-accordion-icon-v5">▼</span>
    </label>
    <div class="ease-accordion-drawer-v5">
      <div class="ease-accordion-body-v5">Content</div>
    </div>
  </div>
</div>
