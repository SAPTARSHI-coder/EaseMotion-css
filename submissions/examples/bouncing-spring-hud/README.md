# Bouncing Spring Sci-Fi HUD

A pure HTML and vanilla CSS cyberpunk HUD component featuring a smooth
bouncing spring entrance animation.

## Features

- Pure HTML and CSS
- No JavaScript
- No external dependencies
- Cyberpunk / sci-fi HUD styling
- Bouncing spring animation
- Smooth CSS transitions
- Animated status indicator
- Animated HUD rings
- Scanning light effect
- Responsive layout
- Hardware-accelerated transforms
- Dark-mode friendly design
- Keyboard-accessible controls
- Reduced-motion support

## Preview

The component creates a futuristic sci-fi HUD panel with:

- Neon cyan interface elements
- Technical system readouts
- Animated HUD rings
- Grid background
- Glowing status indicator
- Spring-style entrance animation
- Interactive initialize button
