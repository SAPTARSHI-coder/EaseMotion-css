# Animated Hero Section — Glassmorphism

A responsive animated hero section built with pure HTML and CSS,
using a modern glassmorphism visual style.

## What does this do?

This component creates a modern glassmorphism hero experience
with translucent surfaces, blurred backgrounds, floating
dashboard cards, animated gradients, responsive layouts,
and smooth CSS interactions.

## How is it used?

Place the markup from `demo.html` in a page and include the
provided `style.css`.

The primary hero wrapper is:

```html
<section class="glass-hero">
  ...
</section>
