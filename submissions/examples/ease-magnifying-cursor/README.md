# 🔍 Magnifying Cursor – Magnifies Content Beneath It

> A practical, interactive cursor effect where the cursor magnifies content beneath it, creating a useful, engaging visual experience.

---

## 📖 Description

The **Magnifying Cursor** is a practical, interactive cursor effect where the cursor magnifies content beneath it. As you move your mouse, a circular magnifying lens follows your cursor, showing a magnified view of the content underneath. The effect is smooth and responsive, with a clean lens design, crosshair, and subtle glow.

The component uses HTML Canvas to render the magnified content in real-time. The lens captures a portion of the page and draws it at a larger scale (2.5x magnification). The lens has a circular shape with a border ring, crosshair, and outer glow for a polished look. The magnifier follows the cursor with a slight offset to avoid obstructing the view.

Perfect for product showcases, image galleries, design previews, and any application where you want to allow users to examine details closely. The Magnifying Cursor transforms a simple cursor into a useful, interactive tool.
