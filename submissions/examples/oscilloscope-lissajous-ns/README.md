# Oscilloscope Lissajous

## What does this do?
Renders a self-contained CSS-only `ease-oscilloscope-lissajous` demo: Oscilloscope Lissajous figure blooming from two phases.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-oscilloscope-lissajous`. No build step or JavaScript is required for the effect.

```html
<section class="ease-oscilloscope-lissajous">
  <div class="ease-oscilloscope-lissajous__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
