# Verge Foliot Swing

## What does this do?
Renders a self-contained CSS-only `ease-verge-foliot-swing` demo: Verge and foliot oscillating in early clock rhythm.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-verge-foliot-swing`. No build step or JavaScript is required for the effect.

```html
<section class="ease-verge-foliot-swing">
  <div class="ease-verge-foliot-swing__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
