# ⚡ Lightning Loader – Bolts of Lightning Crackle

> A powerful, electric loading animation where bolts of lightning crackle and flash, creating a dynamic, energetic visual experience.

---

## 📖 Description

The **Lightning Loader** is a powerful, electric loading animation where bolts of lightning crackle and flash. Multiple lightning bolts flicker with random intensity, spark particles flash around them, and a pulsing glow illuminates the center. The effect creates a dynamic, energetic visual experience reminiscent of a thunderstorm.

The component uses CSS animations with `stroke` and `opacity` to create the lightning flicker, while JavaScript adds random flash effects for unpredictability. Spark particles flash with staggered delays, and the entire loader pulses gently.

Perfect for electric-themed interfaces, energy brands, gaming, and any application where you want to create a powerful, dynamic loading animation. The Lightning Loader transforms a simple loading indicator into an electrifying experience.
