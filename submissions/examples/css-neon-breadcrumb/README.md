# Floating Breadcrumb with Neon Styling (#78819)

A floating, glassmorphism-enabled navigation component featuring futuristic neon text glows and smooth interactive states.

## Features
- **Glassmorphism Backdrop:** Implements modern `backdrop-filter` blur effects over dark sci-fi interfaces.
- **Neon Glow Dynamics:** High-contrast cyan and pink glow effects using CSS text shadows and custom properties.
- **Fully Responsive:** Adapts cleanly from pill-shaped floating containers to compact padded boxes on mobile devices.

## File Hierarchy
- `style.css` - Custom properties, backdrop blur panel layout, and hover/active glowing states.
- `demo.html` - Accessible semantic navigation markup with ARIA landmarks.
- `README.md` - Technical specification and architecture overview.
