# Glowing Modal with Gradient Styling

A stunning, attention-grabbing modal component built with pure HTML and CSS. Features an animated glowing gradient background, perfect for "Upgrade", "Pro", or "Special Offer" dialogs.

## Features
- Pure CSS glowing background effect (`filter: blur`)
- Infinite gradient animation (`@keyframes`)
- Glassmorphic backdrop blur overlay
- Smooth entrance/exit transitions with custom easing
- Fully responsive design
- Minimal JavaScript required for simple toggle state

## Usage
Include `demo.html` and `style.css` in your project. Ensure you include the wrapper `.modal-glow` inside the `.modal-wrapper` but behind `.modal-content` via `z-index`.
