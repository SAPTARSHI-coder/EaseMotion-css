# ease-accordion

A smoothly animated accordion panel for **EaseMotion CSS**, built on native `<details>`/`<summary>` for free accessibility.

## Usage

```html
<details class="accordion">
  <summary class="accordion-trigger">
    Question here
    <span class="accordion-icon">⌄</span>
  </summary>
  <div class="accordion-content">
    <p>Answer content here.</p>
  </div>
</details>
