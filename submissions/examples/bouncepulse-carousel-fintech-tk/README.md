# Bounce-Pulse Carousel (Fintech Dashboard)

## What does this do?

A modern fintech dashboard carousel featuring a bounce-pulse animation to highlight the active financial insight card. Built entirely with HTML and CSS for lightweight dashboard interfaces.

---

## Features

- Bounce-pulse animation for the active card
- Glassmorphism card design
- Soft fintech glow effect
- Responsive carousel layout
- Animated pagination indicator
- Pure HTML & CSS (No JavaScript)
- Supports `prefers-reduced-motion`
