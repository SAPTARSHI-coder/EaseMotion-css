# Confirmation Dialog Showcase

A modern confirmation modal with glassmorphism styling, warning icon, and responsive buttons, built for EaseMotion CSS.

## Features

- 💎 Glassmorphism dialog
- ⚠️ Warning icon with subtle animation
- 📝 Information card
- 🔘 Gradient action buttons
- ✅ Pure HTML & CSS
- 📱 Responsive layout
- 🖼️ Standalone browser-compatible demo
- 🚀 No JavaScript or external frameworks

## Folder Structure

```
submissions/examples/confirm-modal-dialog-av/
├── demo.html
├── style.css
└── README.md
```

## Usage

This component uses the `<dialog>` element for accessibility. Just open and close it with `showModal()` and `close()`.

### Customization

All colors, spacing, and animations are easily customizable by modifying the CSS variables or direct properties in style.css.

## Why this fits

Follows the three-file submission structure and aligns with EaseMotion CSS's animation-first design philosophy. Perfect for destructive actions like deleting files, removing accounts, or resetting settings!
