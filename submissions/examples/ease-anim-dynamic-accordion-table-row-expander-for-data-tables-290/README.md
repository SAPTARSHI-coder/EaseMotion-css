# Dynamic Accordion Table Row Expander

### Cyberpunk Theme

A modern **Cyberpunk Accordion Table Row Expander** built using **HTML5** and **CSS3** featuring glowing neon accents, smooth expand/collapse animations, responsive layout, and accessibility-friendly interactions.

---

## ✨ Features

- Cyberpunk neon design
- Animated accordion table rows
- Expand / collapse interaction
- Responsive layout
- CSS variables
- Mobile-first design
- `prefers-reduced-motion` support
- Pure HTML & CSS
