# Hover Text Outline Reveal

1. **What does this do?**
   Smoothly transitions solid text into an outlined style when the element is hovered.

2. **How is it used?**
   Apply the `.hover-text-outline` class to text you want to transform on hover.

   ```html
   <h2 class="hover-text-outline">
     Hover Me
   </h2>
   ```

3. **Why is it useful?**
   It provides a simple, readable, and composable typography interaction that fits EaseMotion CSS's animation-first philosophy.
