# Interactive Hero Section — Retro Pixel

A responsive interactive hero section inspired by classic
retro pixel-art games.

Implemented with pure HTML and CSS for EaseMotion CSS.

## Features

- Retro pixel-art visual language
- Interactive hover states
- Pixel-style typography
- Pixel landscape scene
- CSS pixel character
- Animated coins
- Animated clouds
- Animated character idle state
- CRT scanline overlay
- Pixel grid background
- Floating quest and score cards
- Responsive navigation
- Responsive CTA buttons
- Responsive feature cards
- CSS custom properties/design tokens
- Keyboard focus states
- `prefers-reduced-motion` support
- Zero external JavaScript dependencies
- No external assets required
