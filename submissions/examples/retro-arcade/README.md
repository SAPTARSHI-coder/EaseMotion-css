## 🚀 Usage
1. Clone or copy the files into your project.
2. Open `index.html` in your browser.
3. Hover over the badge to see the retro arcade pixel hover effect.

---

## 🛠️ Customization
- **Colors** → Adjust `color`, `border`, and `box-shadow` for different neon palettes.
- **Pixel depth** → Modify shadow offsets for stronger/weaker retro look.
- **Font** → Use pixel-style fonts like `'Press Start 2P'` for authentic arcade vibes.
- **Size** → Adjust padding and font-size in `.pixel-badge`.

---

## 📖 Accessibility
- Clear, bold text for readability.
- Smooth motion avoids harsh flicker.
