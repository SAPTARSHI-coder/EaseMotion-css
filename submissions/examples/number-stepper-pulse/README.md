# Number Stepper Pulse

A number input with pulsing +/- controls and a bump on change.

## Features
- Pulsing stepper buttons
- Value bump animation
- Accessible spin-free styling
- Pure CSS

## Usage
```html
<div class="nsp-box"><button>−</button><input type="number" /><button>+</button></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
