This contribution adds a Hue Rotation Effect to the submissions/examples/_hue-rotation-effect directory.

What is included?
demo.html
style.css
README.md

Features
🌈 360° hue rotation — cycles through the complete color spectrum.
⚡ Pure CSS animation — no JavaScript required.
🔄 Smooth infinite animation — continuously changes colors.
🎨 Works with gradients, images, buttons, and cards.
🪶 Lightweight — uses only CSS filter: hue-rotate().
📱 Responsive — works on desktop and mobile.
⏱️ Adjustable speed — change 5s to control animation speed.
