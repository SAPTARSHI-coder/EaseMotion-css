# One-Shot Typewriter Animation Component

## 1. What does this component do?

Provides a play-once (non-looping) typewriter text effect (`ease-typewriter-oneshot`) with customizable typing speeds (`.ease-typewriter-fast`, `.ease-typewriter-slow`) and cursor blinking. Unlike continuous loop typewriter keyframes, this animation types the text once and holds the final complete text state for optimal readability.

## 2. How is it used?

```html
<!-- HTML Structure -->
<span class="ease-typewriter-oneshot">Hello, EaseMotion CSS!</span>
<span class="ease-typewriter-oneshot ease-typewriter-fast">Fast Typing Speed</span>
<span class="ease-typewriter-oneshot ease-typewriter-slow">Slow Typing Speed</span>
```

## 3. Why does it fit EaseMotion CSS?

Fills the gap for a single-play typewriter animation utility, expanding EaseMotion's text animation suite while preserving content accessibility and readability.

## 4. Demo Instructions

Open `demo.html` in any web browser and click **↺ Replay Animation** to trigger the one-shot typewriter sequence again.
