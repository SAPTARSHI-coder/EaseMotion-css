# Cyberpunk Neon Glitch Modal

## 1. What does this do?
A cyberpunk neon styled modal with glitch flicker animation effect.

## 2. How is it used?
Apply `.ease-glitch-modal` class to modal element.

## 3. Why is it useful?
- Creates edgy, futuristic cyberpunk aesthetic
- Eye-catching glitch animation effect
- Smooth entrance animation
