# CSS Trial Expiry Warning

A responsive warning banner showing remaining trial time with
an upgrade call-to-action.

## Features

- Pure CSS
- Responsive layout
- Expiry countdown-style message
- Upgrade CTA
- Hover interaction
- Keyboard focus state
- Reduced-motion support
- No JavaScript required

## Accessibility

The banner uses a status role, a descriptive heading, and a
keyboard-accessible upgrade link.

## Customization

Change the orange color variables and text content to match
your application's branding.
