# Ease Gyrocompass Precess

A CSS-only animated **Gyrocompass Precess** component for EaseMotion CSS.

This component represents a navigation gyrocompass rotor that continuously stabilizes and aligns toward true north using pure CSS animations.

## ✨ Features

- Pure HTML and CSS implementation
- No JavaScript required
- Real-world navigation system themed UI
- Animated gyro rotor rotation
- Compass stabilization motion
- North direction indicator
- Responsive design
- Accessibility support with reduced motion preference

## 📂 Usage

Add the component:

```html
<div class="ease-gyrocompass-precess">
  <!-- gyrocompass content -->
</div>
