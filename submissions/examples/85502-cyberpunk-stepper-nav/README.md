# Dynamic Stepper Nav – Cyberpunk

A futuristic **Dynamic Stepper Navigation** component built with **pure HTML and CSS**, featuring a bold cyberpunk-inspired interface with glowing neon effects, animated progress states, and a responsive layout.

## Features

- 🌌 Cyberpunk-inspired design
- ⚡ Neon glow effects
- 🎯 Active and completed step indicators
- ✨ Animated progress state
- 📱 Fully responsive layout
- 🎨 CSS Custom Properties for easy theming
- ♿ Accessible markup with `aria-current="step"`
- 🚫 No JavaScript required
- 🎭 Supports `prefers-reduced-motion`
