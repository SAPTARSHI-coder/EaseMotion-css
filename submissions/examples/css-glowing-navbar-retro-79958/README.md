# Glowing Navbar with Retro Styling

A responsive navigation bar inspired by classic retro-wave aesthetics featuring neon glow effects, vibrant colors, and smooth hover interactions using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Retro neon styling
- Glowing logo and navigation links
- Responsive layout
- Smooth hover animations
- Dark mode compatible
- No JavaScript required

## Files

- demo.html
- style.css

## Usage

```html
<nav class="retro-navbar">
    <div class="logo">RETROWAVE</div>

    <ul class="nav-links">
        <li><a href="#">Home</a></li>
        <li><a href="#">Games</a></li>
    </ul>
</nav>
```

## Why it fits EaseMotion CSS

This component combines visually engaging motion, glowing retro aesthetics, responsive design, and lightweight implementation while maintaining EaseMotion CSS principles of accessibility and simplicity.
