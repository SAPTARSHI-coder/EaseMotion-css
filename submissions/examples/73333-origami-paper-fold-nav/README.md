# Origami Paper Fold Navigation

A responsive navigation component inspired by **Origami Paper Fold** geometry, created entirely with HTML and Vanilla CSS.

## ✨ Features

- Origami-inspired folded corner effects
- Smooth paper-fold hover transitions
- Active navigation state
- CSS-only responsive mobile menu
- Dark-mode compatible
- Keyboard-friendly navigation
- Visible focus states
- Reduced-motion support
- Hardware-friendly transform animations
- No JavaScript
- No external dependencies
