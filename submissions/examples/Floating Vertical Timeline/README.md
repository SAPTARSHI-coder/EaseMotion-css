# EaseMotion - Floating Vertical Timeline (Dark Mode)

A pure CSS responsive floating vertical timeline component built with dark mode styling, hardware-accelerated state transitions, and EaseMotion design system tokens.

## Features

- **Pure CSS Implementation:** Zero JavaScript dependencies required for interactive hover/focus elevation states.
- **Responsive Layout:**
  - **Mobile (< 768px):** Left-aligned linear timeline with integrated spine.
  - **Desktop (≥ 768px):** Alternating left/right centered floating layout.
- **Accessibility Ready:**
  - Full keyboard accessibility using standard `:focus-within` and `:focus-visible` styling.
  - Native `prefers-reduced-motion: reduce` query handling that disables translation animations for motion-sensitive users.
- **Design Token Integration:** Built on `--em-*` CSS custom properties for uniform dark background colors, radiuses, shadows, and neon accent glows.
