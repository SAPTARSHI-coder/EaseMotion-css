# Cyberpunk Zoom-In Carousel

A modern **CSS Zoom-In Carousel** built entirely with **HTML5** and **CSS3**. This showcase demonstrates a smooth zoom-in transition, cyberpunk-inspired neon styling, glassmorphism effects, and responsive behavior—all without JavaScript.

---

## ✨ Features

- 🚀 Pure HTML5 & CSS3
- 🔍 Smooth Zoom-In slide transition
- 🌈 Cyberpunk neon visual theme
- 🪟 Glassmorphism card interface
- 🎠 CSS-only carousel using radio buttons
- 📱 Fully responsive layout
- ♿ Keyboard-accessible navigation
- 🎨 Easy customization using CSS Custom Properties
- 🌙 Supports `prefers-reduced-motion`
- ⚡ Lightweight and dependency-free

## 🚀 Usage

1. Open `demo.html` in any modern browser.
2. Click a navigation dot to switch between carousel slides.
3. The active slide smoothly zooms into view while inactive slides remain hidden.

No JavaScript or external libraries are required.

## 🎨 CSS Custom Properties

Customize the appearance by editing the variables inside `:root`.

| Variable | Description |
|----------|-------------|
| `--bg` | Background color |
| `--surface` | Glassmorphism background |
| `--primary` | Primary neon color |
| `--secondary` | Secondary neon color |
| `--accent` | Accent neon color |
| `--text` | Main text color |
| `--muted` | Secondary text color |
| `--radius` | Border radius |
| `--transition` | Transition speed |

Example:

```css
:root{
    --primary:#00f5ff;
    --secondary:#b026ff;
}
```
