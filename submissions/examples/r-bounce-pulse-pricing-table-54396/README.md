# CSS Bounce-Pulse Pricing Table

A modern **Bounce-Pulse Pricing Table** built using pure HTML5 and CSS3 for accessible web layouts. The component features a highlighted pricing card with a smooth bounce-pulse animation, responsive design, customizable CSS variables, and accessibility support without requiring JavaScript.

---

## ✨ Features

- Pure HTML5 & CSS3
- Bounce-pulse featured pricing card
- Responsive pricing table layout
- Modern gradient call-to-action buttons
- CSS Custom Properties
- Lightweight and performant
- Accessible design
- `prefers-reduced-motion` support
- No JavaScript required

## 🚀 Usage

1. Copy the component into your project.
2. Include the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

3. Open `demo.html` in any modern browser.
