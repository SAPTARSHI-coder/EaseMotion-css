# Hover Navbar - Pastel Styling

A responsive navigation bar featuring a soft pastel visual language, smooth hover interactions, dropdown navigation, and a mobile-friendly menu.

The component is built using only HTML and CSS.

## ✨ Features

- Pure HTML and CSS
- No JavaScript dependency
- Responsive navigation
- Pastel color palette
- Smooth hover effects
- Animated navigation underline
- Dropdown menu
- Mobile navigation menu
- Responsive hamburger menu
- Keyboard focus states
- Glass-like navigation surface
- Floating decorative elements
- Reduced-motion support
- Customizable CSS variables
