# Gradient Border Card Component

Add ease-gradient-border-card-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|--------|
| `--gbc-radius` | `16px` |
| `--gbc-shadow` | `0 8px 40px rgba(0,0,0,.5)` |

## Technique

CSS mask with xor compositing creates a border-only gradient effect on the card wrapper.
