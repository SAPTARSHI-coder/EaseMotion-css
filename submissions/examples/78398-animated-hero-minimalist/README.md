# Animated Hero Section with Minimalist Styling

A responsive animated hero section created with HTML and CSS for
EaseMotion CSS.

## Features

- Fully responsive layout
- Minimalist visual design
- CSS-only animations
- Animated circular visual element
- Subtle floating background elements
- Animated typography entrance
- Interactive CTA buttons
- Responsive metadata section
- Scroll indicator
- Keyboard-accessible controls
- Reduced-motion support
- No JavaScript or external dependencies

## Design

The component focuses on:

- Large expressive typography
- Generous whitespace
- Neutral colors
- Fine borders
- Subtle geometric details
- Smooth motion

## Responsive Behavior

On large screens, the hero uses a two-column layout.

On smaller screens, the layout switches to a single-column
structure so the typography, CTA controls, and animated visual
remain readable and balanced.
