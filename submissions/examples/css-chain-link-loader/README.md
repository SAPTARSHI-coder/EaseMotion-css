# CSS Chain Link Loader

A circular chain link loading animation built completely with CSS.

## Features

- Pure CSS implementation
- Chain links appear sequentially
- Circular rotation animation
- Glowing neon effect
- Responsive design
- No JavaScript required


## Technologies

- HTML5
- CSS3


## Use Cases

- Loading screens
- Game interfaces
- Dashboard loaders
- Futuristic UI


## Accessibility

- Semantic HTML structure
- ARIA label for loader
