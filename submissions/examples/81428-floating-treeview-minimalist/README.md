# Floating Treeview - Minimalist

A clean and responsive floating treeview component built with
pure HTML and CSS.

The design focuses on lightweight spacing, subtle elevation,
soft borders, and smooth interactions.

## Features

- Minimalist visual design
- Floating elevated card presentation
- CSS-only expandable and collapsible tree nodes
- Nested tree structure
- Smooth hover interactions
- Animated tree expansion
- Active item state
- Responsive layout
- Keyboard focus states
- `prefers-reduced-motion` support
- Zero external JavaScript dependencies
