# Glitch-Flicker Navbar

A futuristic CSS animated navbar created for EaseMotion CSS.

## Features

- Pure HTML and CSS
- Glitch flicker animation
- Glassmorphism navbar design
- Responsive layout
- Smooth hover interactions
- No JavaScript required
- prefers-reduced-motion support
