# CSS Rain on Glass Background

A responsive CSS-only animated glass pane with water droplets
running down the surface.

## ✨ Features

- Pure HTML and CSS
- No JavaScript
- Animated rain droplets
- Large water droplets running down the glass
- Glass reflection effect
- Background night scene
- Responsive design
- Hover-to-pause interaction
- Keyboard focus support
- Reduced-motion support
- No external dependencies
