# CSS Scale-Hover Tabs for Product Catalog Layouts

A modern **Scale-Hover Tabs** component built using pure HTML5 and CSS3 for product catalog layouts. The component provides responsive category tabs with smooth scale-hover interactions, animated content switching, glassmorphism styling, and accessibility support.

## Features

* Pure HTML5 & CSS3
* Scale-Hover tab animation
* Product category tabs
* Animated tab content panels
* Responsive product showcase cards
* Glassmorphism container
* Smooth CSS transitions & keyframe animations
* Responsive desktop, tablet, and mobile layout
* CSS Custom Properties
* No JavaScript required
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Click any category tab to switch between product sections.
3. Hover over the tabs to experience the scale-hover animation.
4. Customize colors, spacing, typography, and animation speed through the CSS variables defined in `:root`.
