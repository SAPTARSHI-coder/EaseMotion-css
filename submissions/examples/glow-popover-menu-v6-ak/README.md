# glow-popover-menu-v6-ak

Pure CSS animated glowing popover menu component — no JavaScript required.

## How to use

```html
<div class="ease-popover-wrapper-v6">
  <button class="ease-popover-trigger-v6">Options</button>

  <ul class="ease-popover-menu-v6">
    <li class="ease-popover-item-v6"><a href="#">Item 1</a></li>
    <li class="ease-popover-item-v6"><a href="#">Item 2</a></li>
  </ul>
</div>
