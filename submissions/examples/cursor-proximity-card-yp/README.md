# Cursor Proximity Card

## What does this do?

This component creates an interactive card that softly reacts as the user's cursor approaches it. A radial glow follows the cursor and gradually increases in intensity based on its proximity to the card, creating a smooth and modern interaction.

## How is it used?

Include the provided `style.css` and use the HTML structure from `demo.html`.

```html
<article class="proximity-card">
    <div class="icon">✨</div>
    <h2>Cursor Proximity Card</h2>
    <p>
        Watch the card softly react as your cursor approaches,
        creating a premium interactive experience.
    </p>
    <button>Learn More →</button>
</article>
```

## Why is it useful?

Cursor proximity interactions make interfaces feel more responsive and engaging without relying on heavy animations. This component provides a lightweight effect using CSS variables, a radial gradient, and minimal JavaScript while remaining easy to customize and integrate into modern websites.
