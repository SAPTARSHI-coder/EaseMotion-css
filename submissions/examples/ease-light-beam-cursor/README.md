# 🔦 Light Beam Cursor – Emits Beam That Illuminates Dark Areas

> A dramatic, exploratory cursor effect where the cursor emits a beam of light that illuminates dark areas, creating a flashlight-like, revealing experience.

---

## 📖 Description

The **Light Beam Cursor** is a dramatic, exploratory cursor effect where the cursor emits a beam of light that illuminates dark areas. As you move your mouse, a warm, golden beam of light spreads outward, revealing the dark background beneath. The effect creates a flashlight-like experience, perfect for mystery, exploration, and dramatic visual storytelling.

The component uses HTML Canvas with JavaScript to create the light beam effect. A radial gradient creates the main light beam, with inner glow, floating light particles, and subtle rays that pulse and shift. The canvas has a dark overlay, and the light beam reveals the content beneath. Clicking creates a light burst with 30 particles, and hovering over interactive elements triggers a smaller burst.

Perfect for mystery-themed interfaces, storytelling, horror websites, and any application where you want to create a dramatic, exploratory cursor experience. The Light Beam Cursor transforms a simple cursor into a magical, revealing light source.
