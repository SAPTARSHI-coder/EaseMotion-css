# 📳 Quartz Vibration – Quartz Crystal Hums and Vibrates

> An interactive quartz vibration component where a crystal hums and vibrates with 4 tones (Crystal, Warm, Deep, Bright), frequency control (0-100%), and wave effects.

---

## 📖 Description

The **Quartz Vibration** component creates an interactive quartz vibration experience where a crystal hums and vibrates with wave effects. Built with vanilla HTML, CSS, and JavaScript, it features 4 tones (Crystal, Warm, Deep, Bright), frequency control (0-100%), and wave effects for a resonant experience.

### 🎯 Core Features

- **Quartz vibration** – crystal hums with wave effects
- **4 tones** – Crystal, Warm, Deep, Bright
- **Frequency control** – adjust vibration from 0-100%
- **Wave effects** – vibration waves radiate outward
- **Particle effects** – floating vibration particles
- **Interactive controls** – slider, tone buttons, keyboard shortcuts
- **Responsive design** – adapts to different screen sizes

### ✨ Vibration Experience

When interacting:
1. **Crystal vibrates** – crystal hums with energy
2. **Frequency applies** – controls vibration intensity
3. **Tone applies** – changes vibration character
4. **Waves radiate** – vibration waves expand
5. **Status updates** – shows current state

### 🛠️ Technologies Used

- **HTML5** – semantic structure with Canvas
- **CSS3** – gradients, backdrop-filter, transforms
- **JavaScript (ES6)** – Canvas API, requestAnimationFrame, particle system

### 🎨 Design Philosophy

This component embodies **EaseMotion CSS's animation-first philosophy** through:

- **Resonant motion** – crystal vibrates with energy
- **Wave effects** – radiating vibration waves
- **Particle effects** – floating vibration particles
- **Visual feedback** – status updates, frequency display, controls
- **Energetic atmosphere** – vibration and resonance
- **Human-readable classes** – `.quartz-controls`, `.tone-btn`, `.quartz-text`

### 🔧 Customization Options

| Property | Location | Default |
|----------|----------|---------|
| Tones | `tones` object | 4 tones |
| Frequency range | `vibrateSlider` | 0-100% |
| Particle count | `generateParticles()` | 30 |
| Wave count | `drawVibrationWaves()` | 3-8 |
