# 🧬 DNA Nav – Items Twist in Double-Helix Spiral

> A scientific, dynamic navigation where items twist in a double-helix spiral on hover, creating a stunning, biology-inspired effect.

---

## 📖 Description

The **DNA Nav** is a scientific, dynamic navigation component where items twist in a double-helix spiral on hover. When you hover over a navigation item, it rotates in 3D space while colorful helix strands spin around it, mimicking the structure of DNA. The effect creates a stunning, biology-inspired visual experience that feels both educational and engaging.

The component uses CSS 3D transforms and keyframe animations to create the helix effect. Each item features two spinning helix strands with different colors (blue and pink), representing the double-helix structure of DNA. The items rotate with perspective, adding depth and realism.

Perfect for science-themed websites, educational platforms, biology brands, and any application where you want to create a scientific, dynamic navigation experience. The DNA Nav transforms a simple menu into a captivating, biological interaction.
