# CSS Neon Border Trace

A sleek container featuring a glowing neon light that continuously traces its outer perimeter.

## Features
- Pure CSS perimeter tracing without SVGs, achieved by animating `clip-path: inset()` on pseudo-elements.
- Double-chaser effect by duplicating the pseudo-element and offsetting its `animation-delay` by half the total duration.
- Rich neon aesthetics achieved by combining outer border colors with deep inner and outer `box-shadow` glows.
