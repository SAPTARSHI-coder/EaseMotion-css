# Sibling-Index Cascading Stagger Grid

## What does this do?

A card grid staggered with sibling-index() and an @supports fallback.

## How is it used?

```html
<div class="stagger-grid"><article>1</article></div>
```

Open `demo.html` in a browser to try it.

## Why is it useful?

Keeps the catalog current with modern CSS platform features.
