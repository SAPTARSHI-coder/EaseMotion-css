# CSS Glitch-Flicker Accordion for Product Catalog Layouts

A modern **Glitch-Flicker Accordion** component built using pure HTML5 and CSS3 for product catalog layouts.

This component creates an interactive product showcase with glitch animations, flicker effects, expandable accordion sections, and a futuristic catalog interface.

---

## ✨ Features

- Pure HTML5 and CSS3 implementation
- No JavaScript dependency
- Product catalog accordion layout
- Glitch-flicker animation effects
- CSS-only accordion interaction
- Animated product icons
- Glassmorphism card design
- Smooth hover transitions
- Gradient action buttons
- Responsive layout
- CSS custom properties support
- Lightweight keyframe animations
- `prefers-reduced-motion` accessibility support

## 🚀 Usage

1. Open `demo.html` in any modern browser.
2. Click product sections to expand accordion content.
3. Customize colors and animations using CSS variables.
