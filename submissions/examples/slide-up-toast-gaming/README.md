# Slide-Up Toast for Gaming Hub

A lightweight, responsive CSS-only toast notification designed for
gaming dashboard and gaming hub interfaces.

## Features

- Pure HTML and CSS
- No JavaScript required
- Smooth slide-up entrance animation
- Gaming-oriented visual design
- Responsive on desktop, tablet, and mobile
- CSS custom properties for easy customization
- GPU-friendly `transform` and `opacity` animation
- Supports `prefers-reduced-motion`
- Self-contained demo
