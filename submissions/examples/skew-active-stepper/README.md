# CSS Skew-Active Stepper

A responsive, CSS-only Skew-Active Stepper designed for Gaming Hub dashboards.

## Features

- Pure HTML and CSS
- No JavaScript required
- Skew animation for the active step
- Interactive hover effects
- Gaming dashboard styling
- Responsive layout
- Progress indicator
- CSS custom properties
- Reduced-motion accessibility support
