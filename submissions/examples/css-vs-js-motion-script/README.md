# Pure CSS vs JS Motion Engine Performance Benchmark Comparison (#82104)

An example benchmark submission implementing a runner script comparing execution thread blocking, frame rates, and resource utilization between declarative CSS animations and JS runtime motion engines.

- **Target Frame Rate:** >= 60.0 FPS
