# Metallic Sheen Navigation

A smooth, responsive navigation component featuring a polished **Metallic Sheen** visual style using pure HTML and Vanilla CSS.

## ✨ Features

- Metallic gradient navigation styling
- Reflective sheen hover animation
- Smooth navigation transitions
- Active navigation state
- Responsive mobile navigation
- CSS-only mobile menu
- Automatic dark mode support
- Keyboard-friendly navigation
- Visible focus states
- Reduced-motion support
- Hardware-friendly transform animations
- No JavaScript
- No external dependencies
