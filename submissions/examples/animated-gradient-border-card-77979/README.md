# Animated Gradient Border Card

**What does this do?**
Creates a reusable card interaction with a continuously moving gradient border using a conic gradient and rotation animation.

**How is it used?**
```html
<article class="gradient-border-card">
  <div class="gradient-border-card__content">
    <span>Featured</span>
    <h2>Animated Surface</h2>
    <p>
      A subtle moving gradient creates depth around the card.
    </p>
  </div>
</article>
```

**Why is it useful?**
Animated borders can add visual hierarchy to featured content, status cards, pricing cards, and highlighted UI elements without requiring large or distracting animations, fitting EaseMotion CSS's animation-first and composable design philosophy.
