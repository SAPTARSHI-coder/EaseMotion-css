# SaaS Modern Parallax Dropdown

A sleek, responsive dropdown menu designed for modern SaaS landing pages. Built with pure HTML/CSS featuring a subtle 3D rotational reveal and hover-based parallax background effects.

## Features
- Pure CSS 3D rotate-X entrance animation
- CSS Grid based mega-menu layout
- Modern SaaS aesthetics (soft shadows, rounded corners, tinted icons)
- Fully responsive (adapts to single column on mobile)
- CSS only (no JavaScript required for the core functionality)

## Usage

Simply link `style.css` and use the HTML structure from `demo.html`.

For the parallax background effect to dynamically follow the mouse (optional enhancement), you can add a simple JS snippet to track `mousemove` within the `.dropdown-content` and adjust the `transform: translate(x, y)` of `.parallax-bg`.
