## Overview

A responsive, interactive analytics dashboard component for EaseMotion-css,
built entirely with HTML and CSS.

## Features

- CSS-only interactive dashboard tabs
- Overview, activity, and goals panels
- Responsive metric card layout
- Animated progress indicators
- Performance score ring using CSS conic gradients
- Activity timeline with semantic HTML
- Keyboard-focusable tab controls
- Responsive mobile layout
- CSS custom properties for easy theming
- `prefers-reduced-motion` support
- No JavaScript dependency

## Files

- `demo.html` — component demonstration
- `style.css` — component styles, layout, and animations

## Implementation

The dashboard uses native radio inputs and CSS sibling selectors to switch
between content panels without JavaScript.

Relates to issue #88609.
