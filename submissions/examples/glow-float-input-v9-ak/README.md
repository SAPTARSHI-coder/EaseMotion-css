# glow-float-input-v9-ak

Pure CSS animated floating label input field with neon border focus — no JavaScript required.

## How to use

```html
<div class="ease-float-input-wrapper-v9">
  <input type="text" class="ease-float-input-v9" placeholder=" " id="inp" />
  <label for="inp" class="ease-float-label-v9">Label Text</label>
</div>
