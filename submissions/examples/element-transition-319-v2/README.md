# Ease Advanced Morphing Modal

A modern morphing modal component inspired by shared-element transitions.

The component transforms a feature card into an expanded modal experience
using smooth scale, opacity and movement animations.

## Features

- Shared-element inspired morphing effect
- Smooth modal entrance animation
- Smooth modal exit animation
- Backdrop blur
- Background overlay
- Escape key support
- Click-outside-to-close
- Accessible dialog semantics
- Focus management
- Responsive design
- Reduced-motion support
- No external dependencies
