
---

## 🚀 Usage
1. Clone or copy the files into your project.
2. Open `index.html` in your browser.
3. Watch the pendulum swing with smooth blur effects.

---

## 🛠️ Customization
- **Swing angle** → Adjust degrees in `@keyframes swing`.
- **Duration** → Change `animation: swing 4s` for faster/slower swings.
- **Bob size** → Modify `.bob` width/height for different pendulum weights.
- **Blur strength** → Tweak `backdrop-filter` values for stronger/weaker frosted look.

---

## 📖 Accessibility
- Large visual pendulum for clear visibility.
- Smooth motion avoids harsh flicker.
