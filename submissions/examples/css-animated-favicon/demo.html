Look Up! ☝️

Check your browser tab. The favicon is animating using pure CSS.

How does this work?

Traditionally, animating a favicon required complex JavaScript to generate frames on a hidden Canvas element and constantly swap the href of the link tag via `requestAnimationFrame`.

However, modern browsers now support SVG favicons. By embedding a <style> block directly inside the favicon.svg file, the browser natively executes the standard CSS @keyframes animations while rendering the icon.

Even better, CSS Media Queries like @media (prefers-color-scheme: dark) work inside the SVG! Try toggling your OS Light/Dark mode and watch the favicon seamlessly change colors to remain visible.
