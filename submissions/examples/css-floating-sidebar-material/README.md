# Floating Sidebar with Material Design styling (#78878)

A responsive floating sidebar component based on Material Design 3 guidelines featuring pill-shaped selection indicators, realistic surface depth elevations, and accessible semantic landmarks built using pure CSS.

## Features
- **Semantic Structure:** Constructed with `<aside>`, `<nav>`, `<ul>`, and explicit `aria-current="page"` attributes.
- **Material 3 Tokens:** Custom CSS properties matching Material Design color palettes and standard surface elevations.
- **Pill Selection Indicators:** Fully rounded active states (`border-radius: 6.25rem`) with container background fills.

## File Hierarchy
- `style.css` - Component styling, elevation calculations, and Material 3 design tokens.
- `demo.html` - Semantic HTML structure showcasing floating navigation drawer.
- `README.md` - Technical overview and implementation specifications.
