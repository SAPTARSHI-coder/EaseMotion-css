# Hover Toggle with Dark Mode Styling (#78625)

A sleek dark-mode switch toggle component featuring smooth cubic-bezier transitions and glowing hover shadow states.

## Features
- **Dark Mode Aesthetics:** Deep slate background framing with high-contrast indigo thumb accents.
- **Hover Illumination:** Subtle outer shadow casting and track color shift upon pointer hover.
- **Pure CSS Implementation:** Lightweight setup with zero JavaScript dependencies and full accessibility support.

## File Hierarchy
- `style.css` - Custom properties, toggle slide transition curves, track layout metrics, and media queries.
- `demo.html` - Semantic markup demonstrating switch toggle integration with ARIA attributes.
- `README.md` - Technical specification and architecture overview.
