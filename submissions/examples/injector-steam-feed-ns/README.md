# Injector Steam Feed

## What does this do?
Renders a self-contained CSS-only `ease-injector-steam-feed` demo: Injector steam feed lifting water into the boiler.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-injector-steam-feed`. No build step or JavaScript is required for the effect.

```html
<section class="ease-injector-steam-feed">
  <div class="ease-injector-steam-feed__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
