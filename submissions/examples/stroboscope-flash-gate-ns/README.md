# Stroboscope Flash Gate

## What does this do?
Renders a self-contained CSS-only `ease-stroboscope-flash-gate` demo: Stroboscope flash gate freezing rotating marks.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-stroboscope-flash-gate`. No build step or JavaScript is required for the effect.

```html
<section class="ease-stroboscope-flash-gate">
  <div class="ease-stroboscope-flash-gate__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
