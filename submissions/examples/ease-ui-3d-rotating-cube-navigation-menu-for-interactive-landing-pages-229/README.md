# 3D Rotating Cube Navigation Menu (Minimalist Clean Edition)

A high-performance, visually striking interactive 3D navigation menu built with vanilla HTML, modern CSS variables, and lightweight JavaScript. Designed with a premium minimalist glassmorphism aesthetic suitable for next-generation interactive landing pages.

## Features

- **Interactive 3D Orbiting**: Drag/swipe anywhere in the viewport to rotate and inspect the 3D navigation cube freely.
- **Synchronized Navigation**: Clicking any item in the glassmorphic navbar rotates the cube smoothly to its corresponding face and updates the contextual information panel.
- **Glassmorphic Aesthetic & Theme Toggle**: Integrated controls to switch from the high-tech glowing style to ultra-minimal transparent glassmorphic faces.
- **Fluid Layout**: Completely responsive grid layout adapting cleanly to desktop, tablet, and mobile (icon-only bar support).
- **Auto-Rotation**: Graceful, slow auto-rotation with dynamic sin-wave floating effect when user is idle.

## How to Run & Use

1. Double-click or open `demo.html` in any modern web browser to view the interactive scene.
2. Click any of the navigation icons/labels on the floating top bar (`Home`, `About`, `Services`, `Portfolio`, `Contact`, `Settings`) to watch the cube rotate and focus onto that specific face.
3. Left-click and drag (or drag with your finger on touch screens) anywhere outside the nav bar to orbit the cube freely in three dimensions.
4. Interact with settings on the `Settings` page (accessible via the gear icon or bottom menu link) to dynamically toggle glassmorphism style or adjust parameters.
