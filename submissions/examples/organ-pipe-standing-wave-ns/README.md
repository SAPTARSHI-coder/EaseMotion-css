# Organ Pipe Standing Wave

## What does this do?
Renders a self-contained CSS-only `ease-organ-pipe-standing-wave` demo: Organ pipe standing wave nodes shimmering in air column.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-organ-pipe-standing-wave`. No build step or JavaScript is required for the effect.

```html
<section class="ease-organ-pipe-standing-wave">
  <div class="ease-organ-pipe-standing-wave__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
