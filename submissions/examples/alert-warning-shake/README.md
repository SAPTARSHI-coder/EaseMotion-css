
---

## 🚀 Usage
1. Clone or copy the files into your project.
2. Open `demo.html` in your browser.
3. The warning icon will shake continuously to indicate an error state.

---

## 🛠️ Customization
- **Shake intensity** → Adjust `translateX` values in `@keyframes shake`.
- **Animation speed** → Modify `animation: shake 0.6s` for faster/slower shake.
- **Colors** → Change background and text colors for different alert types.

---

## 📖 Accessibility
- Uses `role="alert"` and `aria-label="Warning"` for screen readers.
- Keyboard focus supported.
