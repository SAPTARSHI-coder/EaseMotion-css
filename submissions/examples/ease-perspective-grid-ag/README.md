# CSS Perspective Grid Background

A retro synthwave-style animated perspective grid background with CSS-only animations.

## What does this do?

Creates an animated retro-style perspective grid background reminiscent of 80s synthwave aesthetics. The grid animates infinitely towards the viewer creating a sense of depth and motion.

## How is it used?

```html
<!-- Grid Background -->
<div class="grid-bg"></div>

<!-- Grid with Gradient Overlay -->
<div class="grid-bg grid-bg--gradient"></div>

<!-- Grid with Glow Effect -->
<div class="grid-bg grid-bg--glow"></div>

<!-- Full Page Layout -->
<section class="grid-page">
  <h1>Synthwave</h1>
  <p>Retro-futuristic design</p>
</section>
```

## Why is it useful?

- Pure CSS animation, no JavaScript required
- Lightweight alternative to video backgrounds
- Adds dramatic visual interest to hero sections
- Fully customizable colors via CSS variables
- Supports reduced motion preferences
- Creates immersive retro-futuristic atmosphere
