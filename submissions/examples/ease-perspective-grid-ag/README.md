# Synthwave Perspective Grid Background

An animated retro synthwave-style perspective grid background, built entirely
in CSS and HTML — no JavaScript.

## Features
- Gradient sunset sky (purple → pink → orange)
- Glowing sun with horizon glow line
- Perspective-tilted magenta grid floor with infinite scroll animation
- Optional star field layer

## Usage
Open `demo.html` in a browser, or copy the `.synthwave-grid` markup and
`style.css` rules into your project. Wrap any content you want inside the
`.synthwave-grid` div — it works as a full background layer.
