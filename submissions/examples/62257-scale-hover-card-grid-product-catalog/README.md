# CSS Scale-Hover Card Grid for Product Catalog Layouts

A modern **Scale-Hover Card Grid** built using pure HTML5 and CSS3 for product catalog layouts. The component features responsive product cards with smooth scale-hover animations, glassmorphism styling, interactive badges, and accessibility support.

## Features

* Pure HTML5 & CSS3
* Scale-Hover card animation
* Responsive product card grid
* Glassmorphism product cards
* Product badges, pricing, ratings, and CTA buttons
* Smooth CSS transitions & keyframe animations
* Responsive desktop, tablet, and mobile layout
* CSS Custom Properties
* No JavaScript required
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over any product card to experience the scale-hover animation.
3. Customize colors, spacing, typography, and animation values using the CSS variables defined in `:root`.
4. Integrate the component into any product catalog or e-commerce landing page.
