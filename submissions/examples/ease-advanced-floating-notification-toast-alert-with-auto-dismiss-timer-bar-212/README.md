# Floating Notification Toast Alert with Auto-Dismiss Timer Bar

## Overview

A modern neumorphic floating toast notification component with an
automatic dismiss timer animation.

Built using pure HTML, CSS, and JavaScript.

## Features

- 🔔 Floating toast notification UI
- ⏳ Auto-dismiss timer progress bar
- ✨ Neumorphic soft shadow design
- 🎨 Modern gradient button styling
- ⚡ Smooth entrance and exit animations
- 📱 Responsive mobile-friendly layout
- 🖱️ Manual close interaction

## Usage

1. Open `demo.html` in any modern browser.
2. Click the "Show Notification" button.
3. Toast will appear with an automatic countdown timer.
4. Close manually using the close button.
