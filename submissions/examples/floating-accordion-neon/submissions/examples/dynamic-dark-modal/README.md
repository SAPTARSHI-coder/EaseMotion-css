# Dynamic Modal with Dark Mode Styling

A modern responsive modal component built entirely with HTML and CSS using the `:target` selector.

## Features

- Pure HTML & CSS
- Dark mode interface
- Responsive design
- CSS-only open/close behavior
- Smooth fade and scale animation
- Accessible semantic structure
- No JavaScript required

## Folder Structure

```
dynamic-dark-modal/
├── demo.html
├── style.css
└── README.md
```

## Technologies

- HTML5
- CSS3
- Flexbox
- CSS Transitions
- CSS :target selector

## Purpose

Provides a reusable dark-themed modal suitable for confirmation dialogs, alerts, login prompts, and settings pages while following the lightweight philosophy of EaseMotion CSS.
