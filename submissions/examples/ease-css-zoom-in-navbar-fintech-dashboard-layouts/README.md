# CSS Zoom-In Navbar for Fintech Dashboard Layouts

A modern fintech dashboard navigation component featuring smooth zoom-in entrance animations built completely with pure HTML and CSS.

This component is designed for banking dashboards, SaaS platforms, and financial applications where lightweight animated navigation experiences are required without JavaScript.


## ✨ Features

- 🔍 Smooth zoom-in navbar entrance animation
- 💳 Fintech dashboard inspired UI
- 🎨 Glassmorphism navigation design
- ⚡ Pure HTML and CSS implementation
- 🌈 Gradient styled buttons and effects
- ✨ Interactive hover animations
- 📱 Fully responsive layout
- ♿ prefers-reduced-motion accessibility support
- 🚀 Lightweight and framework-free

## 🚀 Usage

1. Open `demo.html` directly in your browser.

2. View the animated fintech dashboard navbar.

3. Customize CSS variables inside `style.css` to match your branding.


## 🎨 CSS Custom Properties

The component uses CSS variables for easy customization:

```css
:root {

    --bg:#020617;
    --card:#0f172a;
    --primary:#38bdf8;
    --secondary:#8b5cf6;
    --accent:#22c55e;
    --text:#f8fafc;
    --muted:#94a3b8;

}

Modify these variables to create your own theme.
