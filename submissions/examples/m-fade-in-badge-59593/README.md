# CSS Fade-In Badge for SaaS Showcase Layouts

A modern **Fade-In Badge** component built using pure HTML and CSS. The badges smoothly fade into view while maintaining a clean SaaS-inspired layout suitable for dashboards, pricing pages, and product showcases.

## ✨ Features

- Pure HTML5 & CSS3
- Fade-in badge animation
- Responsive SaaS card layout
- Smooth CSS transitions
- CSS Custom Properties
- `prefers-reduced-motion` support
- No JavaScript required
