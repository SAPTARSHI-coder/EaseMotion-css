# Image Wipe Diagonal

An image is revealed by a diagonal wipe sweeping corner to corner.

## Features
- Diagonal wipe
- Smooth reveal
- Loops with hold
- Pure CSS

## Usage
```html
<div class="iwd-img"></div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
