# CSS Domino Tiles Component

A responsive collection of domino tiles built entirely with HTML and CSS.

Each tile contains CSS-generated dot patterns and flips in 3D when hovered or keyboard-focused.

## Features

- Pure HTML and CSS
- CSS-generated domino pips
- Multiple domino combinations
- 3D flip animation
- Hover interaction
- Keyboard focus interaction
- Responsive tile sizing
- Accessible labels
- Visible keyboard focus state
- Reduced-motion support
- No JavaScript
- No external assets
