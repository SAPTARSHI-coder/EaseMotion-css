# CSS Window Frame Card

A responsive operating-system-inspired window card built entirely with HTML and CSS.

The component features a styled title bar, window controls, toolbar,
content area, and status bar.

## Features

- Pure HTML and CSS
- OS-style window frame
- Styled title bar
- Window control buttons
- Toolbar and status bar
- Responsive layout
- Hover interactions
- Keyboard-accessible controls
- Visible focus states
- Reduced-motion support
- No JavaScript
- No external dependencies
