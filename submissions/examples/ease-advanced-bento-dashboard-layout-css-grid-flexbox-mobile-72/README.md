# Bento Grid Interactive Dashboard Layout with CSS Grid and Flexbox

## Overview

A modern compact mobile-first dashboard UI component built with
CSS Grid and Flexbox.

This component features a responsive bento grid structure with
interactive cards, glassmorphism styling, and modern dashboard
visual elements.

## Features

- 🧩 Responsive bento grid layout
- 📱 Mobile-first design approach
- ✨ Interactive hover animations
- 🪟 Glassmorphism card styling
- 📊 Dashboard analytics sections
- 🎨 Gradient accent effects
- ⚡ Pure HTML, CSS and JavaScript
- ♿ Reduced motion accessibility support

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over cards to view interactive effects.
3. Customize colors and layouts using CSS variables.

## Technologies Used

- HTML5
- CSS3 (Grid + Flexbox)
- JavaScript
