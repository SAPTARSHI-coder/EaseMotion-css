# Material Design Hover Slider

A clean and responsive slider component inspired by Material Design principles.

The component uses pure HTML and CSS with smooth hover interactions.

## ✨ Features

- Material Design inspired UI
- Responsive layout
- Smooth hover animation
- Interactive slider thumb
- Progress indicator
- Clean card design
- No JavaScript
- No external libraries
- Reduced-motion support
