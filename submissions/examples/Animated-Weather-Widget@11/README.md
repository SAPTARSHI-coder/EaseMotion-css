# Animated Weather Widget Submission

## 1. What does this do?
It provides a beautiful, animated weather widget with dynamic weather icons (sunny, cloudy, rainy, snowy), current conditions, hourly forecast, and 7-day forecast. Perfect for weather apps, dashboards, and travel websites.

## 2. How is it used?
Wrap your weather content in the `.weather-widget` container. The component includes animated weather icons, temperature display, weather details (humidity, wind, pressure, visibility), hourly forecast with horizontal scroll, and 7-day forecast. JavaScript handles weather type switching and real-time updates.

## 3. Why is it useful?
- Essential component for weather apps and dashboards
- Animated weather icons with smooth transitions (sun rotation, cloud float, rain shake, snow fall)
- Current weather with detailed information
- Scrollable hourly forecast
- 7-day forecast with high/low temperatures
- Interactive weather type selector for demo
- Real-time date/time updates
- Beautiful gradient background with glassmorphism effects
- Fully accessible with proper ARIA labels
- Includes `prefers-reduced-motion` support for accessibility
- Mobile-responsive design
- Easy to customize colors and styles
- Maintainer can easily standardize this as `.ease-weather-[YOUR_INITIALS]` in the core library.
