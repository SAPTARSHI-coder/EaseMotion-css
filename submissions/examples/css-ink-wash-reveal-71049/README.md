# CSS Ink Wash Reveal (#71049)

An organic ink wash spreading reveal animation created using pure CSS `clip-path` masks and radial gradient transitions.

## Features
- Pure CSS implementation using `clip-path: circle()` expansion and CSS blur filters.
- Zero JavaScript dependencies.
- Interactive expansion triggered via `:hover` and keyboard `:focus-visible` states.
- Accessible ARIA labeling with full support for `prefers-reduced-motion`.
