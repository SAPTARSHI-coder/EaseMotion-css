# CSS Ripple Wave Popover

A responsive popover component featuring a ripple-wave animation using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Ripple hover animation
- Floating wave effect
- Responsive layout
- Smooth transitions
- No JavaScript required
- Supports `prefers-reduced-motion`

## Folder Structure

```
ripple-wave-popover/
├── demo.html
├── style.css
└── README.md
```

## Usage

Open `demo.html` in any modern browser.

## Customization

You can customize:

- Button color
- Popover width
- Shadow
- Animation duration
- Border radius
- Typography

## Accessibility

- Semantic HTML
- Responsive design
