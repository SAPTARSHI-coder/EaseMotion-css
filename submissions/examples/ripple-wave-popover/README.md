# 🌊 Ripple-Wave Popover

A modern **Ripple-Wave Popover** component built with **pure HTML and CSS** for fintech dashboard layouts. The component features a ripple-wave background animation, glassmorphism styling, smooth hover transitions, and responsive design without requiring JavaScript.

---

## ✨ Features

- 🌊 CSS-only ripple wave animation
- 💳 Fintech dashboard inspired popover
- 🪟 Glassmorphism design
- ✨ Smooth fade and slide transitions
- 🎨 CSS Custom Properties for easy customization
- 📱 Fully responsive layout
- ♿ Supports `prefers-reduced-motion`
- 🚫 No JavaScript required

---

ripple-wave-popover/

---

## 🚀 Usage

1. Open `demo.html` in a modern web browser.
2. Hover over any button to display the popover.
3. Customize colors and spacing using the CSS variables in `style.css`.

---

:root{
