# feat(examples): Add pure CSS advanced component v34

## Overview

A pure CSS interactive 3D profile card for EaseMotion-css.

## Features

- 3D flip interaction using CSS transforms
- Hover and keyboard focus support
- Responsive mobile layout
- Dark visual theme with CSS custom properties
- Reduced-motion support
- No JavaScript dependency

## Files

- `demo.html` — component demonstration
- `style.css` — component styles and animations

Relates to issue #88636.
