# glow-float-input-v10-ak

Pure CSS animated floating label input field with neon border focus — no JavaScript required.

## How to use

```html
<div class="ease-float-input-wrapper-v10">
  <input type="text" class="ease-float-input-v10" placeholder=" " id="inp" />
  <label for="inp" class="ease-float-label-v10">Label Text</label>
</div>
