# CSS Skew-Active Navbar for Product Catalog Layouts

A modern **Skew-Active Navbar** built using pure HTML5 and CSS3 for product catalog interfaces. The navigation features skewed active states, smooth hover transitions, responsive layouts, and accessibility support without requiring JavaScript.

## Features

- Pure HTML5 & CSS3
- Skew active navigation effect
- Smooth hover animations
- Fully responsive layout
- Product catalog showcase
- CSS Custom Properties
- Accessible with `prefers-reduced-motion`
- No JavaScript required
