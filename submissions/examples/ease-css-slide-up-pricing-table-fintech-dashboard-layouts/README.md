# CSS Slide-Up Pricing Table for Fintech Dashboard Layouts

## Overview

A modern fintech pricing table component with animated slide-up
feature panels using pure HTML and CSS.

- 💳 Fintech pricing dashboard layout
- ⬆️ Smooth slide-up reveal animation
- 🎨 Gradient modern UI

- 📱 Responsive design
- ♿ prefers-reduced-motion support
- 🧩 Lightweight component
