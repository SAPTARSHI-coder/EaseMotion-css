# CSS Subscription Tier Card

A responsive subscription pricing component built using pure HTML and CSS.

## Features

- Responsive three-tier pricing layout
- Starter, Professional and Enterprise plans
- Featured "Most Popular" plan
- Animated gradient borders
- Glassmorphism effect
- Hover elevation animation
- Animated shine effect on buttons
- Gradient glow effects
- Accessible focus states
- Keyboard-friendly links
- `prefers-reduced-motion` support
- No JavaScript required

## Files

- `demo.html` – Component markup and demonstration
- `style.css` – Complete styling and animations

## Technologies

- HTML5
- CSS3
- CSS Grid
- CSS Flexbox
- CSS Animations
- CSS Gradients
- CSS Backdrop Filter
