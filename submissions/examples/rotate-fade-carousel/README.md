# CSS Rotate-Fade Carousel for Accessible Web Layouts

A modern **Rotate-Fade Carousel** component built using only **HTML5 and CSS3**.

This example demonstrates a lightweight CSS-only carousel with smooth rotation, fade transitions, glowing effects, responsive layouts, and accessibility support without JavaScript.

---

## ✨ Features

- 🔄 Rotate transition effects
- 🌫️ Smooth fade animations
- 💡 Animated glow effects
- 🎨 Gradient card styling
- ⚡ Pure CSS implementation
- 📱 Fully responsive layout
- 🎯 CSS Custom Properties
- ♿ `prefers-reduced-motion` support
- 🚫 Zero JavaScript dependency

## 🚀 Usage

1. Open `demo.html` in any modern browser.
2. Cards automatically rotate with fade transitions.
3. Hover on cards to pause animation.
4. Customize colors and effects through CSS variables.

## ♿ Accessibility

Includes:

- Semantic HTML structure
- Clear content hierarchy
- Reduced motion support
- `prefers-reduced-motion` handling

For users who prefer less motion, animations are disabled and cards become static.
