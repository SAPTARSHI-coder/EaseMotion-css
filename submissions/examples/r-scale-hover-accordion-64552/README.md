# CSS Scale-Hover Accordion

A minimalist tech-style accordion built with pure HTML and CSS.

## Features

- Scale-hover interaction
- Smooth CSS transitions
- Soft accent glow
- Native accessible `<details>` and `<summary>`
- Responsive desktop, tablet, and mobile layout
- Pure HTML and CSS
- `prefers-reduced-motion` support
- No JavaScript or external dependencies
