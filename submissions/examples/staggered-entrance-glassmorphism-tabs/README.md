# Staggered Entrance Tabs — Glassmorphism UI

A pure CSS tab component featuring a smooth staggered entrance animation
and glassmorphism-inspired interface styling.

## Features

- Pure HTML and CSS
- No JavaScript
- Smooth staggered entrance animation
- Glassmorphism UI
- Responsive layout
- Keyboard-friendly tab selection
- `prefers-reduced-motion` support
- CSS custom properties for animation customization
- Works by opening `demo.html` directly in a browser
