# CSS-only Carousel - Retro

A responsive retro-styled carousel created entirely with HTML and CSS.

This component does not require JavaScript or external dependencies.

## ✨ Features

- Pure HTML and CSS
- No JavaScript
- Fully responsive
- Retro / vintage visual style
- Four interactive slides
- Previous and next navigation
- Slide indicator dots
- CSS radio-button state management
- Keyboard-friendly controls
- Reduced-motion support
- Responsive artwork using CSS shapes
- No external images required
