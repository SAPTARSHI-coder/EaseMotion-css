# Phosphor Amber CRT Terminal Theme

## What does this do?

An amber phosphor CRT text theme with glow, scanlines, and optional flicker.

## How is it used?

```html
<div class="crt crt--amber"><pre>ease@motion:~$</pre></div>
```

Open `demo.html` in a browser to try it.

## Why is it useful?

Reusable atmospheric utility for terminals and retro dashboards.
