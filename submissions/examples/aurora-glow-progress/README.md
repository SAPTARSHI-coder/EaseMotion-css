# 🌌 CSS Progress: Aurora Glow Variation

A smooth, responsive progress bar inspired by the shifting colors
and luminous glow of an aurora.

The component is built using pure HTML and vanilla CSS with no
external JavaScript or dependencies.

## Features

- Pure HTML and CSS
- Aurora-inspired gradient
- Animated color flow
- Glowing progress indicator
- Smooth CSS transitions
- Multiple progress examples
- Responsive layout
- Dark-mode-friendly design
- Accessible progressbar semantics
- Reduced-motion support
- No external dependencies
- Hardware-friendly CSS animations
