# CSS Rotate-Fade Carousel for Fintech Dashboard Layouts

A modern **Rotate-Fade Carousel** component built using pure HTML5 and CSS3 for fintech dashboard layouts. This component creates a premium financial dashboard experience with smooth rotation effects, fade transitions, animated cards, and responsive design.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Fintech dashboard inspired interface
* Rotate entrance animation
* Fade transition effects
* Active card highlighting
* Glassmorphism financial cards
* Smooth hover interactions
* Gradient action buttons
* Responsive desktop, tablet, and mobile layouts
* CSS Custom Properties support
* Lightweight keyframe animations
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over financial cards to view rotation and elevation effects.
3. The active card appears with enhanced rotate-fade animation.
4. Customize colors, shadows, spacing, and animation values using CSS variables inside `:root`.

## CSS Custom Properties

```css
:root{
  --bg:#f8fafc;
  --surface:rgba(255,255,255,.85);
  --primary:#2563eb;

  --shadow:0 30px 80px rgba(37,99,235,.2);
  --radius:30px;
}
```
