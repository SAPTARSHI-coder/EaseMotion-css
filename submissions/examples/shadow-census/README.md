# Shadow Census

Shadow Census is an experimental interactive component built around a simple idea:

> Instead of showing the object, show what the object does to light.

The component contains several subtle hidden structures and a virtual light source controlled by pointer movement.

As the light moves, the hidden structures produce different shadow lengths and directions.

## ✨ Features

- Interactive virtual light source
- Dynamic shadow projection
- Multiple hidden objects
- Shadow length calculation
- Shadow opacity calculation
- Vector indicator
- Shadow density indicator
- Pointer Events
- Touch support
- Responsive design
- Reduced-motion support
- Dependency-free
- Vanilla JavaScript
