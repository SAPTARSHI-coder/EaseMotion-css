# Ribbon Dance · Ribbons Swirl and Twist 🎀

An interactive ribbon dance with swirling, twisting ribbons and graceful flowing motion. Watch ribbons dance across the canvas!

## Features

- 🎀 **Ribbon Dance** – Graceful swirling ribbons
- 💃 **Dance Animation** – Ribbons swirl and twist
- 🎨 **Vibrant Colors** – Rainbow color shifting
- 🎚️ **Speed Control** – Adjust dance speed (1-10)
- 🎚️ **Ribbon Count** – Adjust number of ribbons (3-8)
- ⏸️ **Pause/Resume** – Toggle animation
- 🔄 **Reset** – Reset ribbons
- ✨ **Glow Effects** – Soft ribbon glow

## How to Use

1. Click **DANCE** or press **Space** to make ribbons dance
2. Click again to stop
3. Adjust **Speed** for dance pace
4. Adjust **Ribbons** for more/less complexity
5. Press **RESET** or **R** to reset
6. Press **PAUSE** or **P** to pause/resume animation

## Controls

| Action | Method |
|--------|--------|
| Dance/Stop | Dance button / Space |
| Reset | Reset button / R key |
| Pause/Resume | Pause button / P key |
| Speed | Speed slider |

## Technical Details

- **Ribbons:** Segmented flowing lines
- **Motion:** Wave-based swirling
- **Colors:** HSL shifting along ribbon
- **Performance:** 60fps with requestAnimationFrame

## Customization

You can easily customize:
- **Speed:** Adjust slider range (1-10)
- **Ribbons:** Adjust slider range (3-8)
- **Colors:** Modify hue ranges
- **Motion:** Adjust wave parameters
- **Glow:** Modify glow intensity

## Browser Support

Works in all modern browsers:
- Chrome, Firefox, Safari, Edge

## Run Locally

Simply open `index.html` in your browser – no server required!
