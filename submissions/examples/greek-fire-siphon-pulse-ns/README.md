# Greek Fire Siphon Pulse

## What does this do?
Renders a self-contained CSS-only `ease-greek-fire-siphon-pulse` demo: Greek fire siphon pulse flame jet.

## How is it used?
Open `demo.html` in a browser. Motion uses classes under `ease-greek-fire-siphon-pulse`. No build step or JavaScript is required for the effect.

```html
<section class="ease-greek-fire-siphon-pulse">
  <div class="ease-greek-fire-siphon-pulse__housing">...</div>
</section>
```

## Why is it useful?
It packs a recognizable real-world motion metaphor into three submission files, fitting EaseMotion's curated CSS-first model and giving maintainers a concrete effect to standardize into `ease-*` utilities.
