# Card Stack Overlap

A stack of cards fanned backward settles into neat overlap.

## Features
- Fanned stack
- Offset layers
- Settle entrance
- Pure CSS

## Usage
```html
<div class="cso-card" style="--i:0">A</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
