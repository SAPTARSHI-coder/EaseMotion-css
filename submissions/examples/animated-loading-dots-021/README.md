# Animated Loading Dots

A compact three-dot loading indicator with a smooth staggered animation.

## What does it do?

The component provides:

- Three animated loading dots.
- Sequential animation delays.
- Continuous loading feedback.
- Smooth vertical movement and scaling.
- Reduced-motion support.
- No JavaScript.
- No external libraries or assets.

## How do I use it?

Add three spans inside the loading container:

```html
<div class="ease-loading-dots" role="status" aria-label="Loading">
  <span></span>
  <span></span>
  <span></span>
</div>
```
