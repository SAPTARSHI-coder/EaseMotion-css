# CSS 3D-Flip Navbar

A modern **3D-Flip Navbar** built using pure HTML5 and CSS3 for Gaming Hub layouts. Navigation items perform a smooth 3D flip animation on hover while maintaining accessibility and responsive behavior.

---

## ✨ Features

- Pure HTML5 & CSS3
- 3D flip hover animation
- Gaming-inspired navigation
- Responsive layout
- CSS Custom Properties
- Lightweight and performant
- Accessible semantic HTML
- `prefers-reduced-motion` support
- No JavaScript required

## 🚀 Usage

1. Copy the component into your project.
2. Link the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

3. Open `demo.html` in any modern browser.
