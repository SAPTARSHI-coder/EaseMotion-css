# File Dropzone Drop File Validation

## Overview

Vitest unit tests covering file validation logic for a file dropzone.

## Test Coverage

- Valid PNG/JPEG uploads
- Multiple valid files
- Unsupported file types
- Oversized files
- Empty array
- Null input
- Undefined input
- Malformed objects
- Mixed valid/invalid files
- Custom validation options

## Files

- demo.html
- style.css
- file-dropzone-validation.test.js

Run:

```bash
vitest
```
