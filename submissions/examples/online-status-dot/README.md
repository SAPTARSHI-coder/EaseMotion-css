# Online Status Dot

A presence dot that glows with a breathing ring to signal someone is online.

## Features
- Breathing halo ring around the presence dot
- Subtle idle pulse keeps attention on the user
- Works at any avatar size via CSS variables

## Usage
```html
<div class="os-user">
  RM
  <span class="os-dot"></span>
</div>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
