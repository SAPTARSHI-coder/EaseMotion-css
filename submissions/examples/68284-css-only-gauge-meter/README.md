# CSS-Only Gauge Meter

A responsive speedometer-style percentage gauge implemented with HTML and CSS only.

## Files

- `demo.html` — semantic gauge demo
- `style.css` — dial, needle, scale, responsive styling, and animation

## Usage

Open `demo.html` in a modern browser. No JavaScript or dependencies are required.

## Accessibility

The gauge exposes a descriptive accessible label and respects reduced-motion preferences.
