# 3D Perspective Tilt Product Showcase Card

## Overview

A minimalist clean edition product showcase card featuring smooth 3D
perspective tilt interaction, light reflection effects, and modern UI styling.

Built with pure HTML, CSS, and JavaScript.

## Features

- 🧊 3D perspective tilt effect
- ✨ Light reflection animation
- 🎨 Minimal clean design
- ⚡ Smooth hover transitions
- 📱 Responsive layout
- 🖱️ Interactive mouse movement

## Folder Structure

## Usage

1. Open `demo.html` in browser.
2. Move cursor over the card.
3. Experience the 3D tilt effect.
