# CSS Feature Block Grid

A modern, responsive three-column feature block grid built entirely with HTML and CSS. The component uses clean visual hierarchy, subtle hover animations, and responsive layouts to present feature information in an engaging way.

## ✨ Features

- Three-column feature grid layout
- Clean feature cards with icons, titles, and descriptions
- Subtle card lift animation on hover
- Animated top-border reveal
- Interactive icon hover effect
- Smooth arrow movement on hover
- Responsive layout for desktop, tablet, and mobile
- Pure CSS implementation
- No JavaScript or external libraries
- Semantic HTML structure
- Decorative SVG icons with appropriate accessibility attributes
- Reduced-motion support
- Clean and maintainable CSS

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Grid
- CSS Custom Properties
- Inline SVG
- CSS Transitions
- CSS Media Queries

## 📱 Responsive Behavior

The grid adapts automatically to different screen sizes.

- **Desktop:** Three-column layout
- **Tablet:** Two-column layout
- **Mobile:** Single-column layout

The cards, spacing, typography, and icons also scale appropriately for smaller screens.

## 🎬 Animations

The component includes lightweight CSS-only animations:

- Cards lift upward on hover.
- A top accent line reveals across the card.
- Feature icons rotate and scale slightly.
- The icon background changes on hover.
- The arrow moves horizontally to provide visual feedback.
- Decorative background elements appear during interaction.

All animations are implemented using CSS transitions without JavaScript.

## ♿ Accessibility

The component follows accessible design practices.

- Semantic HTML elements such as `main`, `section`, `header`, and `article` are used.
- Decorative SVG icons use `aria-hidden="true"`.
- The main section has a descriptive heading association.
- Content remains readable across different screen sizes.
- `prefers-reduced-motion` is supported to reduce animations for users who prefer less motion.
- Sufficient spacing and clear typography improve readability.

## 🚀 How to Use

1. Open `demo.html` in a modern web browser.
2. Hover over the feature cards to view the CSS interactions.
3. Resize the browser window to see the responsive grid behavior.

No installation or additional dependencies are required.
