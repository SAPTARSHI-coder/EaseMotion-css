# Eco Habit Tracker

This submission demonstrates a clean habit tracker card built with
**EaseMotion CSS**. It includes animated progress, weekly day indicators,
stats, hover effects, and custom eco-themed styling.

## 🌟 Features

- **Habit tracker card** with title, streak badge, and daily goal.
- **Animated progress bar** using CSS variables.
- **Weekly day tracker** showing completed, current, and upcoming days.
- **Action buttons** with hover grow effect.
- **Stats section** for streak, weekly goal, and points.
- **Staggered entrance animation** using `ease-slide-up` and delay utilities.
- **Hover lift effect** using `ease-hover-lift`.
- **Responsive layout** for mobile and desktop.
- **Reduced motion support** for users who prefer less animation.

## 📁 Files

- `demo.html` — interactive habit tracker demo
- `style.css` — original eco-themed styling
- `README.md` — documentation for this submission

## 🛠️ How to Run

1. Open `demo.html` in your browser.
2. Watch the habit card animate on page load.
3. Hover over the card to see the lift effect.
4. Hover over the buttons to see the grow effect.
5. Resize the browser window to check responsive behavior.
