# Morphing Shape Dashboard Widget

A futuristic dashboard widget featuring a **Morphing Shape** visual style using pure HTML and Vanilla CSS.

## Features

- 🔷 Continuously morphing central shape
- 🔄 Animated 3D holographic rings
- 🌀 Orbiting visual elements
- 📊 Dashboard statistics
- 📈 Animated capacity indicator
- 🌙 Automatic dark mode support
- ⚡ Hardware-accelerated CSS animations
- ♿ Accessible semantic HTML
- 📴 Reduced-motion support
- 📱 Responsive layout
- 🚫 No JavaScript or external dependencies
