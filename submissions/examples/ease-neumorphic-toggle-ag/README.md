# Neumorphic Toggle Switch

A soft UI toggle switch with realistic depth and lighting, built with neumorphic design principles entirely in HTML and CSS.

## Preview

Open `demo.html` in your browser and click on the toggle to see the soft, elastic transition.

## Implementation Details

- **No JavaScript:** Powered completely by the `<input type="checkbox">` and `<label>` CSS hack.
- **Neumorphism:** Uses multiple inset and drop `box-shadow`s to create the illusion of extruded shapes and indented tracks.
- **Elastic Animation:** The toggle knob utilizes a `cubic-bezier` timing function to give it a satisfying, slightly elastic spring feel when switched.
