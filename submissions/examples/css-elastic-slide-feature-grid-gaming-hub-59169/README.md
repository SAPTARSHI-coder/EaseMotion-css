# CSS Elastic-Slide Feature Grid for Gaming Hub Layouts

A modern **Elastic-Slide Feature Grid** built using pure HTML and CSS for gaming hubs, esports platforms, and futuristic landing pages.

## Features

* Pure HTML5 & CSS3
* Elastic slide hover animation
* Gaming-inspired neon design
* Responsive feature grid
* CSS custom properties
* No JavaScript required
* Lightweight and customizable
* Supports `prefers-reduced-motion`

## Folder Structure

```text
css-elastic-slide-feature-grid-gaming-hub-59169/
├── demo.html
├── style.css
└── README.md
```

## Usage

1. Open `demo.html` in any modern browser.
2. Customize feature titles, icons, and descriptions.
3. Modify colors using the CSS variables in `:root`.
