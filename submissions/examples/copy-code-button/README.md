# 📋 Copy Code Button for Documentation

## Overview

This feature introduces a **Copy Code** button for documentation code blocks.

Instead of manually selecting code snippets, users can copy them instantly with a single click.

---

## Features

- 📋 One-click copy
- ✅ Success feedback after copying
- 🎨 Modern UI
- ⚡ Uses Clipboard API
- 📱 Responsive
- ♻️ Works for multiple code blocks

## How it Works

1. User clicks the copy icon.
2. JavaScript reads the code block.
3. Clipboard API copies the content.
4. Icon changes to a checkmark.
5. After 1.5 seconds, the button returns to the copy icon.
