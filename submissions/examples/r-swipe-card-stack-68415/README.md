# CSS Swipe Card Stack

A pure CSS card stack inspired by swipe-based interfaces.

The component uses CSS radio buttons and labels to change the active card without JavaScript.

## Features

- Pure HTML and CSS
- No JavaScript
- Stacked cards
- Swipe-away style transitions
- Keyboard accessible controls
- Responsive layout
- CSS custom properties
- Reduced-motion support

## Usage

```html
<input
  class="stack-control"
  type="radio"
  name="card"
  id="card-1"
  checked
>

<input
  class="stack-control"
  type="radio"
  name="card"
  id="card-2"
>
