# Scroll Progress Indicator Component

Add ease-scroll-indicator-bar-tm pure CSS component.

## Design Tokens

| Token | Default |
|-------|---------|
| `--sp-accent` | `#6366f1` |
| `--sp-accent2` | `#ec4899` |
| `--sp-bar` | `4px` |
| `--sp-pos` | `top` |

## Note

Uses a tiny JS scroll listener to update `width`. CSS handles the visual.
