# Accordion Smooth Animation

## Description

This submission improves the accordion expansion animation by replacing abrupt height changes with a smooth `max-height` transition. The result is a cleaner and more natural expand/collapse effect for panels containing different amounts of content.

## Features

- Smooth expand/collapse animation
- Supports variable-height content
- Pure CSS solution
- Responsive design
- Lightweight implementation

## Usage

```html
<details class="accordion-item">
  <summary>Question</summary>

  <div class="content">
    <p>Your content goes here.</p>
  </div>
</details>
```

## Benefits

- Eliminates abrupt layout jumps
- Improves user experience
- Works on desktop and mobile
- Easy to integrate into existing projects
