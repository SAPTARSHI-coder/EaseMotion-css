# Scale-Hover Accordion Product Catalog

A lightweight product catalog showcase featuring a responsive CSS
Scale-Hover Accordion interaction.

The component uses semantic HTML and pure CSS without JavaScript or external
frameworks.

## Features

- Pure HTML and CSS
- Native `<details>` and `<summary>` accordion
- Scale effect on accordion controls
- Scale-hover effect on product cards
- Smooth CSS transitions
- CSS keyframe animation
- Responsive product catalog
- Desktop, tablet and mobile layouts
- Keyboard-accessible native accordion
- Visible focus states
- CSS custom properties
- `prefers-reduced-motion` support
- No external dependencies
