# Pure CSS Glitch Text Component

**What does this do?**
Provides a highly dynamic, cyberpunk-style text glitch animation using pure CSS.

**How is it used?**
Apply the `.glitch` class to an element and mirror the text content inside the `data-text` attribute.
```html
<div class="glitch" data-text="YOUR TEXT">YOUR TEXT</div>
```

**Why is it useful?**
It utilizes advanced CSS `clip` properties and rapid keyframe steps on pseudo-elements to create a complex visual distortion effect entirely without JavaScript, aligning perfectly with EaseMotion's CSS-first capabilities.
