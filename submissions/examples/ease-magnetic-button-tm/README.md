# Magnetic Button Component

**Issue:** [#71810](https://github.com/SAPTARSHI-coder/EaseMotion-css/issues/71810)

Interactive button with hover lift and scale effect using pure CSS.

## Design Tokens

| Token | Default |
|-------|---------|
| `--tm-mag-btn-bg` | `#6366f1` |
| `--tm-mag-btn-hover` | `#4f46e5` |
| `--tm-mag-btn-radius` | `8px` |
| `--tm-mag-btn-shadow` | `0 4px 20px rgba(99,102,241,0.4)` |
| `--tm-mag-scale` | `1.05` |

## Variants

- `.mag-btn` — filled button (default)
- `.mag-btn-outline` — outlined variant

## States

- Default, hover (lift + scale), active (pressed), focus-visible
