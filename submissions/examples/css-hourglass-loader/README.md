# CSS Hourglass Loader

A lightweight, pure CSS hourglass loader featuring animated sand particles and a continuous flipping animation.

## Features

- Pure HTML and CSS
- No JavaScript or external dependencies
- Animated hourglass rotation
- CSS-generated sand particles
- Smooth continuous loading animation
- Responsive design
- Accessible loading status
- Supports `prefers-reduced-motion`
- Easy to customize with CSS variables
