# Holographic Flicker Toggle (#73873)

A pure HTML & Vanilla CSS toggle featuring a flickering cyan/magenta holographic glow animation.

## Features
- **Aesthetic:** Cyan and magenta holographic scanline background with dynamic flickering thumb.
- **Pure CSS:** Zero JavaScript dependencies; relies strictly on CSS state selectors and keyframe matrices.
- **Performance:** Hardware-accelerated transitions using `transform`, `opacity`, and `will-change`.
- **Accessibility:** Includes `:focus-visible` outline rings and `@media (prefers-reduced-motion: reduce)` support.
