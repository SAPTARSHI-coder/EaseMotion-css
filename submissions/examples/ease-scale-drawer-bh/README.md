# ease-scale-drawer-bh

Pure CSS scale hover drawer for fintech dashboards.

## Features
- Scale hover effect
- Multiple positions
- Responsive design
- Accessibility support (prefers-reduced-motion)

## Usage
```html
<div class="ease-drawer ease-drawer-scale">
  <h2>$124.5K</h2>
  <p>Total Balance</p>
</div>
```

## CSS Classes
- `.ease-drawer` - Base drawer styles
- `.ease-drawer-scale` - Scale hover effect
