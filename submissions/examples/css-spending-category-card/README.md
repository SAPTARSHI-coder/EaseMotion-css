# CSS Spending Category Card

A modern spending category card component displaying budget allocation versus actual spending through animated progress bars.

## Features

- Pure HTML and CSS
- Budget vs actual spending visualization
- Animated progress indicators
- Responsive card layout
- Hover elevation effect
- Multiple spending categories
- Clean financial dashboard styling
- Accessible and lightweight
