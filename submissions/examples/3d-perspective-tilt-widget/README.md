# 3D Perspective Tilt Dashboard Widget

A futuristic dashboard widget featuring a **3D Perspective Tilt** visual
style using pure HTML and Vanilla CSS.

## Features

- 🎛️ 3D perspective dashboard card
- 🧊 CSS `perspective` and `transform-style: preserve-3d`
- 🔄 Smooth floating tilt animation
- ✨ Animated holographic shine
- 📊 Performance metrics
- 📈 Animated performance indicator
- 🌙 Automatic dark mode support
- ⚡ Hardware-accelerated transforms
- ♿ Reduced-motion accessibility support
- 📱 Responsive design
- 🚫 No JavaScript or external dependencies
