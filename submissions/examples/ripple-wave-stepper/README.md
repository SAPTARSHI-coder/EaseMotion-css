# CSS Ripple-Wave Stepper for Responsive Dashboard Layouts

A modern **Ripple-Wave Stepper** component created using only **HTML5 and CSS3**.

This example demonstrates a responsive dashboard stepper with animated ripple effects, glowing step indicators, smooth entrance transitions, and accessibility support without JavaScript.

---

## ✨ Features

- 🌊 Ripple-wave animation effects
- 📌 Dashboard stepper layout
- 💡 Glowing circular indicators
- 🎨 Gradient UI styling
- ⚡ Pure CSS implementation
- 📱 Responsive design
- 🎯 CSS Custom Properties
- ♿ `prefers-reduced-motion` support
- 🚫 Zero JavaScript dependency

## 🚀 Usage

1. Open `demo.html` in any modern browser.
2. View the animated stepper component.
3. Hover over steps for interactive effects.
4. Customize colors using CSS variables.
