# Origami Paper Fold Neumorphic UI

A pure CSS neumorphic interface inspired by folded origami paper.

The component combines soft neumorphic shadows with angled CSS surfaces
to create the appearance of layered and folded paper.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript
- No external dependencies
- Origami-inspired folded surfaces
- Soft neumorphic shadows
- Smooth hover transitions
- Responsive design
- Dark mode support
- Reduced-motion support
- Keyboard focus styling
- Hardware-friendly CSS transforms

## Demo

Open `demo.html` directly in a modern browser.

No server or build process is required.
