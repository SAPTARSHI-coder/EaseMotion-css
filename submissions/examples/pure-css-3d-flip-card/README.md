# Pure CSS 3D Flip Card

A responsive interactive card that smoothly rotates in 3D to reveal a secondary face using only CSS transforms.

## Features

- Pure HTML and CSS
- 3D Y-axis rotation
- Smooth hover interaction
- Keyboard focus interaction
- Responsive design
- Front and back card faces
- CSS-generated visual effects
- Accessible semantic markup
- Visible keyboard focus state
- Reduced-motion support
- No JavaScript
- No external dependencies
