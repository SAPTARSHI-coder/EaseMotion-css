# CSS Diff View

A polished, responsive code-diff component built using pure HTML and CSS.

This component provides a clean visual representation of added, removed,
and unchanged lines without requiring JavaScript.

## Features

- Pure HTML and CSS
- Added line highlighting
- Removed line highlighting
- Unchanged line styling
- Line numbers
- Diff markers
- File header
- Change summary
- Responsive horizontal scrolling
- Keyboard-focusable code region
- Accessible labels
- Reduced-motion support
- Smooth entrance animation
- No external dependencies

## Preview

The component displays code changes using three visual states:

- Green: Added lines
- Red: Removed lines
- Neutral: Unchanged lines
