# Skeleton Loader Component

A loading placeholder component with animated shimmer gradient translation keyframes.

## Features
- **Gradient Shimmer Wave:** Seamless 200% background-position loop transition.
- **Composable Utilities:** Variant helper classes for avatar circles, titles, and text lines.
- **Zero JavaScript:** Pure CSS keyframes and linear gradient rules.

## File Structure
- `demo.html` - Skeleton card layout markup.
- `style.css` - Shimmer keyframes, gradient stops, and variant size rules.
