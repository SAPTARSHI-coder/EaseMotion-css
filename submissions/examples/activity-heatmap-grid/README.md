# Activity heatmap grid

A grid of cells (GitHub-style) that brighten and pop on hover with a tooltip.

## How to view

Open `demo.html` in any modern browser. The demo is fully self-contained — no CDN, no framework, no JavaScript.

## How to use

Copy `style.css` into your project's stylesheet. Every class used in the demo is namespaced with `activityheatmapgrid-` to avoid collisions.

## Why this is useful for EaseMotion CSS

Activity / streak pattern; the grid is dense but reads at a glance.
