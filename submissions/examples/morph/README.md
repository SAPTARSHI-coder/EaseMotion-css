# CSS Morphing Shape Variation

A demo project showcasing a **morphing blob shape** using CSS animations.

## Features
- Shape smoothly morphs between different border-radius values.
- Neon gradient fill with glowing shadow.
- Infinite looping animation with ease-in-out timing.

## Files
- `demo.html` → Structure with container and morphing shape.
- `style.css` → Morphing animation, gradient, and glow styling.
- `README.md` → Documentation and usage instructions.

## Usage
1. Open `demo.html` in your browser.
2. Watch the blob morph between different shapes.
3. Customize gradient colors and border-radius values for unique variations.

## Customization Ideas
- Use `clip-path` polygons for more complex morphing.
- Replace with SVG paths and animate with JavaScript for precise control.
- Add hover effects to trigger morphing on interaction.
- Integrate into hero sections or background visuals for futuristic designs.
