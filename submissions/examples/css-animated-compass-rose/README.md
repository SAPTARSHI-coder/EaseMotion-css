# CSS Animated Compass Rose

A lightweight animated compass rose built entirely with HTML and CSS.

The component demonstrates a rotating direction needle with compass labels,
ticks, responsive sizing, and accessible reduced-motion support.

## Features

- Pure HTML and CSS
- No JavaScript required
- Animated compass needle
- North, East, South, and West indicators
- Responsive design
- Light and dark mode support
- CSS custom properties for easy customization
- `prefers-reduced-motion` support
- Semantic HTML and accessible labeling
- Works by opening `demo.html` directly in a browser
