# CSS Zoom-In Progress Bar

A responsive zoom-in animated progress bar built with pure HTML and CSS for creative portfolio layouts.

## Features

- Pure HTML & CSS
- Zoom-in fill animation
- Responsive layout
- CSS Custom Properties
- Accessible with prefers-reduced-motion
- Lightweight and reusable

## Files

```
zoom-in-progress-bar/
├── demo.html
├── style.css
└── README.md
```

## Usage

```html
<div class="progress">
    <div class="progress-fill"></div>
</div>
```

Link the stylesheet:

```html
<link rel="stylesheet" href="style.css">
```

## Custom Properties

```css
--bg
--card
--track
--fill
--duration
--radius
```
