# Nav Pill Float

A floating pill background slides between active nav items.

## Features
- Sliding pill highlight
- Active item tracking
- Smooth easing
- Pure CSS

## Usage
```html
<nav class="npf-nav"><a href="#" class="npf-link">Home</a></nav>
```

## Browser Support
- Chrome, Firefox, Safari, Edge (evergreen)

## Tech Stack
- Pure HTML + CSS, zero JavaScript dependencies
