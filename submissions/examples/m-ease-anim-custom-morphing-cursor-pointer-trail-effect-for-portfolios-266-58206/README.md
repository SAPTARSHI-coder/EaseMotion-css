# Custom Morphing Cursor Pointer Trail Effect for Portfolios (Cyberpunk Theme)

A futuristic **Cyberpunk Morphing Cursor Pointer Trail** built using pure HTML and CSS. The component features glowing cursor rings, animated pointer trails, floating neon particles, and a holographic glassmorphism interface.

## ✨ Features

- Pure HTML5 & CSS3
- Cyberpunk-inspired cursor animation
- Animated pointer trail
- Floating neon particles
- Glassmorphism interface
- Responsive layout
- CSS Custom Properties
- `prefers-reduced-motion` support
- No JavaScript required
