# Avatar Stack Overflow Count Calculator - Edge Case Assertions

A comprehensive Vitest test suite and demo for **Avatar Stack Overflow Count Calculator** edge cases.

## Features

- 👥 Overlapping avatar stack layout
- 🔢 Overflow count calculation (+N)
- 🛡 Boundary assertions for limit = 0, negative limits, and empty inputs
- 📊 Compact formatting for large overflow counts (>999)
