# Minimal FAQ Accordion

This submission demonstrates a clean FAQ accordion built with
**EaseMotion CSS**. It uses native HTML `details` and `summary` elements,
animated entrance effects, hover lift, and custom minimal styling.

## 🌟 Features

- **Accordion FAQ items** using semantic HTML `details` and `summary`.
- **Staggered entrance animation** using `ease-slide-up` and delay utilities.
- **Hover lift effect** using `ease-hover-lift`.
- **Custom open/close indicator** with animated plus icon.
- **Smooth content reveal** using original CSS animation.
- **Responsive layout** for mobile and desktop.
- **Accessible focus styling** for keyboard users.
- **Reduced motion support** for users who prefer less animation.

## 📁 Files

- `demo.html` — interactive FAQ accordion demo
- `style.css` — original minimal FAQ styling
- `README.md` — documentation for this submission

## 🛠️ How to Run

1. Open `demo.html` in your browser.
2. Watch the FAQ items enter with staggered animation.
3. Click any question to open or close the answer.
4. Hover over the cards to see the lift effect.
5. Resize the browser window to check responsive behavior.
