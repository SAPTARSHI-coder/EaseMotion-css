# 🧊 Thermal Bloom

Thermal Bloom is a dependency-free interactive visualization that simulates the conceptual diffusion of heat across a fictional crystalline surface.

Instead of presenting temperature as a conventional chart, the component turns temperature into a visual transformation.

The user heats the surface directly with the pointer.

Heat spreads.

The crystal changes.

Cracks appear.

Critical regions bloom.

As the surface cools, the transformation gradually disappears.

> Touch the cold surface. Create a reaction.

## 🧠 Concept

Thermal Bloom represents a simplified fictional material system.

The core interaction is:

```text
POINTER
   ↓
HEAT SOURCE
   ↓
DIFFUSION
   ↓
TEMPERATURE
   ↓
MATERIAL RESPONSE
   ↓
CRACKS / BLOOMS
   ↓
COOLING
