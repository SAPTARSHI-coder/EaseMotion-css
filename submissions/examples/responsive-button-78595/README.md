# Responsive Button

Pastel responsive button showcase for issue #78595.

## Files

- `demo.html` — button states and semantic actions.
- `style.css` — responsive sizing, hover, active, and focus styling.

## Features

- Flexible button sizing.
- Pastel visual treatment.
- Hover, active, and keyboard states.
- Mobile-friendly layout.
- Reduced-motion support.

Use the native button element for actions and replace the sample labels with product-specific copy.
