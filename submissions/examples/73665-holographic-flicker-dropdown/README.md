# Holographic Flicker Dropdown

A futuristic pure CSS dropdown component featuring a holographic flicker
visual effect.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript
- Native `<details>` and `<summary>` interaction
- Holographic gradient effect
- Smooth dropdown reveal
- Interactive hover states
- Keyboard-friendly interaction
- Visible focus state
- Light and dark mode support
- Responsive design
- Hardware-friendly transform animations
- `prefers-reduced-motion` support

## Preview

The component presents a futuristic dropdown with animated cyan,
purple, pink, and blue holographic highlights.
