# Bento Grid Interactive Dashboard

A modern neumorphic Bento Grid dashboard layout built with CSS Grid,
Flexbox, HTML and CSS.

## Features

- Responsive Bento Grid layout
- Neumorphic visual style
- CSS Grid and Flexbox
- Interactive hover elevation
- Productivity statistics
- Activity chart
- Task list
- Monthly goal indicator
- Mobile-first responsive behavior
- No external dependencies
- Reduced-motion support
