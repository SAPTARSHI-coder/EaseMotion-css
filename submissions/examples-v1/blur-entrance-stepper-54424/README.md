# Blur Entrance Stepper

A lightweight responsive stepper component built using pure HTML and CSS. The active step uses a smooth blur-to-focus entrance animation while maintaining accessibility and responsive behavior.

## Features

- Pure HTML5 & CSS3
- Blur entrance keyframe animation
- Fully responsive layout
- CSS custom properties for easy customization
- No JavaScript required
- Supports `prefers-reduced-motion`

## CSS Custom Properties

```css
--primary
--completed
--inactive
--background
--text
--step-size
--animation-speed
```

## Accessibility

Animations are automatically disabled when users enable **Reduce Motion**, ensuring a comfortable and accessible experience.

## Browser Support

Compatible with all modern browsers supporting CSS animations, custom properties, filters, and media queries.
