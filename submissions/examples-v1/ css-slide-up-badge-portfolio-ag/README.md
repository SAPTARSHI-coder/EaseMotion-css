# CSS Slide-Up Badge

A lightweight CSS-only Slide-Up Badge component for creative portfolio layouts.

## Features

- Pure HTML & CSS
- Slide-up information panel
- Smooth hover animation
- Responsive design
- No JavaScript
- Accessible
- Supports `prefers-reduced-motion`

## Files

```
demo.html
style.css
README.md
```

## Usage

Hover over the badge to reveal the content panel.

## Accessibility

- Keyboard-friendly using `:focus-within`
- Reduced motion support
- Responsive layout
