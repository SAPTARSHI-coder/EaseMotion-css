# Skew Hover Button Utility

A reusable CSS utility that applies a subtle skew animation on hover.

## Features

- Pure HTML & CSS
- Smooth skew animation
- Scale effect
- Shadow animation
- Accessible focus styles
- Reduced motion support
- Responsive

## Files

```
demo.html
style.css
README.md
```

## Usage

```html
<button class="skew-hover-button">
    Hover Me
</button>
```

## Accessibility

- Keyboard focus indicator
- Supports `prefers-reduced-motion`
- No JavaScript required
