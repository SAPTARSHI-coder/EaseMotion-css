# CSS 3D Flip Badge

A lightweight CSS-only 3D Flip Badge component for creative portfolio layouts.

## Features

- Pure HTML & CSS
- 3D flip animation
- Responsive
- Smooth transitions
- No JavaScript
- Accessible
- Supports `prefers-reduced-motion`

## Files

```
demo.html
style.css
README.md
```

## Usage

Hover over the badge to reveal the back side.

## Accessibility

- CSS-only interaction
- Reduced motion support
- Responsive layout
