# Rotate Fade Stepper

A lightweight stepper component built with pure HTML and CSS. The active step is highlighted with a smooth rotate-and-fade animation while maintaining accessibility and responsive behavior.

## Features

- Pure HTML5 & CSS3
- Rotate + fade keyframe animation
- Fully responsive layout
- CSS custom properties for easy customization
- No JavaScript required
- Supports `prefers-reduced-motion`

## CSS Custom Properties

```css
--primary
--completed
--inactive
--background
--text
--step-size
--animation-speed
```

## Accessibility

Animations are automatically disabled for users who enable **Reduce Motion** in their operating system while preserving the component's layout and usability.

## Browser Support

Compatible with modern browsers supporting CSS animations, custom properties, and media queries.
