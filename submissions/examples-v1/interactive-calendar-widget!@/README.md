# Interactive Calendar Widget

This is a self-contained example demonstrating how to create a modern, interactive calendar widget with month navigation, event indicators, event details panel, upcoming events sidebar, and add event modal using minimal JavaScript, seamlessly integrated with **EaseMotion CSS** utility classes.

## Features
- 📅 **Full Calendar View:** Month view with all days displayed in a grid.
- 🎯 **Today Highlight:** Current day highlighted with pulsing animation.
- 📊 **Event Indicators:** Color-coded dots showing events on each day.
- 📋 **Event Details Panel:** Shows all events for selected date.
- 📆 **Upcoming Events Sidebar:** Lists next 7 days of events.
- ➕ **Add Event Modal:** Create new events with title, time, category, and description.
- 🎨 **Category Colors:** Meeting (blue), Personal (green), Work (yellow), Important (red).
- ⬅️➡️ **Month Navigation:** Previous/Next month buttons with smooth transitions.
- 🎛️ **View Toggle:** Switch between Month and Week views.
- 🏷️ **Weekend Highlighting:** Weekend days have subtle background.
- ✨ **Smooth Animations:** Hover effects, transitions, and event slide-ins.
- ♿ **Fully Accessible:** Proper ARIA labels, keyboard navigation, and reduced motion support.
- 📱 **Responsive Design:** Adapts to mobile screens with adjusted layouts.
- 🚫 **Minimal JavaScript:** Only for calendar logic and event management.

## How to Use
1. Ensure the EaseMotion CSS CDN is linked in your `<head>`.
2. Link the `style.css` file.
3. Copy the calendar HTML structure.
4. Include the JavaScript class at the bottom of your page.
5. Initialize: `const calendar = new CalendarWidget();`
6. Click on dates to view events, use navigation to change months.
