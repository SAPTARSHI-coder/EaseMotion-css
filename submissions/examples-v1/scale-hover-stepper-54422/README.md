# Scale Hover Stepper

A responsive multi-step progress indicator built using pure HTML and CSS. Each step gently scales on hover while the active step remains highlighted for improved visual focus.

## Features

- Pure HTML5 & CSS3
- Smooth hover scale interaction
- Responsive layout
- CSS custom properties
- Active and completed step styling
- No JavaScript required
- Supports `prefers-reduced-motion`

## CSS Custom Properties

```css
--primary
--completed
--inactive
--background
--text
--step-size
--radius
--transition
```

## Accessibility

The component respects the user's **prefers-reduced-motion** setting by disabling transitions and animations while preserving usability.

## Browser Support

Compatible with modern browsers supporting Flexbox, CSS custom properties, transitions, and media queries.
