# Rotate Fade Tabs

A responsive **Rotate Fade Tabs** component built using pure HTML and CSS.

## Features

- Pure HTML & CSS
- Rotate and fade hover animation
- Responsive layout
- Keyboard accessible
- prefers-reduced-motion support
- No JavaScript required

## Folder Structure

```
rotate-fade-tabs/
├── demo.html
├── style.css
└── README.md
```

## Usage

Open `demo.html` in any modern browser.
