# Animated Pricing Card

A premium, conversion-optimized pricing card component built with **EaseMotion CSS**. It uses staggered entrance animations and smooth hover interactions to draw attention to key features and the call-to-action.

## ✨ Features

- **Zero JavaScript**: Pure CSS animations powered entirely by EaseMotion utility classes.
- **Attention-Grabbing Badge**: Uses `.ease-bounce` to make the "Most Popular" tag stand out immediately.
- **Staggered Feature List**: Each feature item slides up sequentially using `.ease-slide-up` and `.ease-delay-*` classes, guiding the user's eye down the card.
- **Interactive Hover**: The entire card lifts smoothly on hover (`.ease-hover-lift`), and the CTA button grows (`.ease-hover-grow`).
- **Modern Dark Theme**: Sleek design with gradient text and subtle borders, easily customizable via CSS variables.
