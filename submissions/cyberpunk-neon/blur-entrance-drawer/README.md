# Blur-Entrance Drawer

## 1. What does this do?
Cyberpunk neon drawer with blur-to-sharp entrance animation.

## 2. How is it used?
Apply `.ease-blur-drawer` class to drawer element.

## 3. Why is it useful?
- Smooth blur-to-focus reveal effect
- Cyberpunk neon aesthetic with glowing accents
- Creates dramatic drawer entrance animations
