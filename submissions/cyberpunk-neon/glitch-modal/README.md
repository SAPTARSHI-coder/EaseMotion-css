# Glitch-Flicker Modal

## 1. What does this do?
Cyberpunk neon modal with glitch flicker animation.

## 2. How is it used?
Apply `.ease-glitch-modal` class to modal element.

## 3. Why is it useful?
- Glitch effect for cyberpunk aesthetic
- Creates edgy, futuristic modal appearance
- Eye-catching flicker animation
