# 3D-Flip Drawer

## 1. What does this do?
Cyberpunk neon drawer with 3D flip entrance animation.

## 2. How is it used?
Apply `.ease-flip-drawer` class to drawer element.

## 3. Why is it useful?
- Impressive 3D flip animation effect
- Cyberpunk neon styling with glowing borders
- Creates memorable drawer entrance experience
