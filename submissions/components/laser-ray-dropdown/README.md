# Laser Ray Trace Dropdown

A smooth, cyberpunk-inspired dropdown menu featuring an animated **Laser Ray Trace** border effect.

Built using only **HTML and vanilla CSS** with no JavaScript or external dependencies.

## ✨ Features

- Pure HTML and CSS
- No JavaScript required
- Animated laser ray-trace border
- Smooth dropdown opening transition
- Hover and focus states
- Keyboard-friendly native `<details>` and `<summary>` elements
- Dark-mode friendly design
- Hardware-friendly CSS animations
- Responsive layout
- `prefers-reduced-motion` support
- Accessible focus indicators
- Lightweight and dependency-free
