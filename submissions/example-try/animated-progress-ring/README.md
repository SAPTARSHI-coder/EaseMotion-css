# Animated Progress Ring (Gradient Style)

A lightweight, clean circular loading components utilizing inline SVG, CSS transitions, and basic vanilla JS synchronization logic.

## Details
- **Fluid Easing:** Uses a clean `cubic-bezier(0.25, 1, 0.5, 1)` transition function for standard easing curve behaviors.
- **Dynamic Glow:** Integrates basic SVG mapping and linear drop-shadow rules.
- **Counter Layering:** JS values scale incrementally via a cubic curve matching the visual layout fill.
