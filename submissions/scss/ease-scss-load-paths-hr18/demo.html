Fixing @use 'easemotion-css/scss' path failures

A live look at the load-path error, the one-line fix, and the animation utilities it unlocks — for Vite and Next.js.

The error, and the fix

build log
$ npm run dev
−Error: Can't find stylesheet to import.
− @use 'easemotion-css/scss';
− ^^^^^^^^^^^^^^^^^^^^^^^^^^^^
 
# add a Sass load path pointing at node_modules, then:
$ npm run dev
+✓ compiled successfully
+✓ @use 'easemotion-css/scss' resolved

The one-line fix

import { defineConfig } from 'vite';

export default defineConfig({
  css: {
    preprocessorOptions: {
      scss: {
        loadPaths: ['node_modules'],
      },
    },
  },
});
/** @type {import('next').NextConfig} */
const nextConfig = {
  sassOptions: {
    includePaths: ['./node_modules'],
  },
};

module.exports = nextConfig;
