Detailed Timing Functions

linear

cubic-bezier(0, 0, 1, 1)

Moves at a constant, uniform speed from start to end. There is no acceleration or deceleration. 

animation-timing-function: linear;

ease

cubic-bezier(0.25, 0.1, 0.25, 1)

Starts slightly slow, accelerates rapidly in the middle, and then decelerates gradually at the end. (CSS default) 

animation-timing-function: ease;

ease-in

cubic-bezier(0.42, 0, 1, 1)

Starts slowly and accelerates gradually until it reaches the end, stopping abruptly. Ideal for exit transitions. 

animation-timing-function: ease-in;

ease-out

cubic-bezier(0, 0, 0.58, 1)

Starts quickly and decelerates gradually toward the end, resulting in a gentle, smooth landing. Best for entrance animations. 

animation-timing-function: ease-out;

ease-in-out

cubic-bezier(0.42, 0, 0.58, 1)

Starts slowly, accelerates in the middle, and decelerates back to a crawl at the end. Great for responsive movement. 

animation-timing-function: ease-in-out;
