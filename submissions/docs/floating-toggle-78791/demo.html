Floating Toggle

A reusable CSS-only toggle pattern with a floating elevation effect, keyboard focus treatment, responsive sizing, and reduced-motion support.

Live example

Enable floating mode

Use the checkbox or press Space when the control is focused.

HTML

<input class="toggle-input" type="checkbox" id="floating-toggle">
<label class="toggle" for="floating-toggle">
  <span class="toggle-track" aria-hidden="true">
    <span class="toggle-thumb">
      <span class="thumb-icon"></span>
    </span>
  </span>
  <span class="toggle-label">Floating mode</span>
</label>

Behavior

  • Unchecked state keeps the thumb level with the track.
  • Checked state moves the thumb upward and starts a subtle float.
  • Hover adds temporary elevation without changing the control state.
  • :focus-visible provides a clear keyboard indicator.
  • prefers-reduced-motion disables animated movement when requested.
