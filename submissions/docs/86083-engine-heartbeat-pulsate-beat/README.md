# Heartbeat Pulsate Beat

## Overview

The **Heartbeat Pulsate Beat** utility provides a smooth rhythmic
scaling animation for UI elements that need subtle attention or
activity feedback.

It can be used for:

- Live status indicators
- Notification badges
- Active system states
- Monitoring dashboards
- Health/status interfaces
- Interactive UI elements
- Attention indicators
