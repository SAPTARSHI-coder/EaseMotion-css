# Dynamic Tooltip

A lightweight and responsive Dynamic Tooltip component built using pure HTML and CSS.

## ✨ Features

- Responsive design
- Smooth tooltip animation
- Multiple tooltip positions
- Top, bottom and right placement
- Clean modern UI
- No JavaScript required
- Keyboard focus support
- Reduced-motion support
- Easy to customize
