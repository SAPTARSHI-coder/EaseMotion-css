# Contributor Onboarding Guide

## Description

A beginner-friendly visual guide explaining the basic workflow for contributing to EaseMotion CSS.

## Steps Covered

1. Find an issue
2. Fork the repository
3. Clone your fork
4. Create a branch
5. Make your changes
6. Test your contribution

## Before Submitting

Contributors should:

- Check for duplicate issues
- Read the contribution guide
- Follow the repository structure
- Keep changes focused
- Test their contribution locally
