Contributing to EaseMotion CSS

A beginner-friendly guide to making your first contribution.

01

Find an Issue

Choose an open issue that matches your skills and make sure nobody else is already working on it.

02

Fork the Repository

Create your own fork of the EaseMotion CSS repository from GitHub.

03

Clone Your Fork

git clone https://github.com/YOUR_USERNAME/EaseMotion-css.git
04

Create a Branch

git checkout -b feature/your-feature
05

Make Your Changes

Follow the repository guidelines and place your contribution inside the required submissions directory.

06

Test Your Contribution

Test your example locally and make sure everything works correctly before submitting it.

Before You Submit

  • Check for duplicate issues.
  • Read the contribution guide.
  • Keep your changes focused.
  • Test your contribution locally.
  • Follow the project's folder structure.
