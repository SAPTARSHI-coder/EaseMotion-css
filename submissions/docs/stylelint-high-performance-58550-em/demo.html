Compositor-Only High Performance Animations (#58550)

Hardware-accelerated animations using transform and opacity to eliminate layout thrashing and 60fps jank.

Squish Border

Uses GPU transform: scaleX() scaleY() instead of repainting border-radius.

Glow Exit

Uses GPU-accelerated filter: drop-shadow() instead of repainting box-shadow.

Gradient Rotation

Uses filter: hue-rotate() instead of triggering layout with background-position.
