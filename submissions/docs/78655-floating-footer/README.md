# Floating Footer

Documentation and a standalone demonstration for the Floating Footer component requested in issue #78655.

## Overview

The Floating Footer is a compact footer surface that visually separates itself from the page content with spacing, rounded corners, and a subtle elevation effect.

## Demo

Open `demo.html` to preview a complete footer with branding, navigation links, and a small status action.

## Usage

Place the footer after the main page content and keep the navigation links grouped semantically. The component can be reused as a page-level footer or a compact utility panel.

## Accessibility

Native links are used for navigation, focus states remain visible, and decorative effects do not carry meaning. Reduced-motion users receive a static presentation.

## Customization

Edit the maximum width, padding, corner radius, shadow, and spacing values in `style.css` to match the surrounding design.

## Files

- `demo.html` — complete footer example.
- `style.css` — floating layout and responsive styles.
