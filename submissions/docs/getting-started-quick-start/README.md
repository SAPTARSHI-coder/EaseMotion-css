# Getting Started with EaseMotion CSS

This example demonstrates the quickest way to start using EaseMotion CSS.

## Folder Structure

```
getting-started-quick-start/
│── demo.html
│── style.css
└── README.md
```

## Features Demonstrated

- Importing EaseMotion CSS
- Fade-in animation
- Slide-up animation
- Simple responsive layout
- Custom styling

## Running the Demo

1. Clone the repository.

```bash
git clone https://github.com/SAPTARSHI-coder/EaseMotion-css.git
```

2. Navigate to this example.

3. Open `demo.html` in your browser.

## Expected Output

The page displays:

- Animated heading
- Animated button
- Clean centered layout

This serves as a beginner-friendly quick start example for new users learning EaseMotion CSS.
