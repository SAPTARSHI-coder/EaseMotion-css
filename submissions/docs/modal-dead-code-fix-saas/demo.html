Modal Dead Code Removal Fix

Demonstration and documentation for removing unreachable dead code in core/modal.js.

Problem Summary

In core/modal.js inside checkModal(), there was an unreachable conditional block:

// Line 24: class added
overlay.classList.add('is-active');

const modal = overlay.querySelector('.ease-modal');
if (modal) {
  // Unreachable check - overlay.classList.contains('is-active') is ALWAYS true!
  if (!overlay.classList.contains('is-active')) {
    previousFocusedElement = document.activeElement; // DEAD CODE
  }

  modal.setAttribute('tabindex', '-1');
  modal.focus();
}

Solution

Removed the dead if (!overlay.classList.contains('is-active')) block since previousFocusedElement is already recorded on line 22 before is-active is added.

previousFocusedElement = document.activeElement;

overlay.classList.add('is-active');

const modal = overlay.querySelector('.ease-modal');
if (modal) {
  modal.setAttribute('tabindex', '-1');
  modal.focus();
}
