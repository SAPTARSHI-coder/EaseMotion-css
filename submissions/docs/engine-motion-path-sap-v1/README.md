# Engine Motion Path Path-Follower Keyframe Compiler

## What does this do?
Enables elements to animate along custom SVG paths using `em="path-follow(path-id)"` attributes.

## How is it used?
```html
<div em="path-follow(motionPath) duration-slow repeat-infinite">🚀</div>
```

## Why is it useful?
Allows elements to follow curved SVG motion paths cleanly without writing custom JavaScript animation loops.
