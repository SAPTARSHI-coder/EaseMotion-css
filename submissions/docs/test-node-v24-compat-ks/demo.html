Node.js v24 Test Suite Compatibility

Problem

Running npm test on Node.js v24 produces:

FAIL  tests/modal.test.js
FAIL  tests/reveal.test.js
FAIL  tests/tabs.test.js
Error: No such built-in module: node:

The @vitest-environment jsdom annotation prevents vitest from resolving node:-prefixed built-in module imports.

Root Cause

The three failing test files use:

import fs from 'fs';
import path from 'path';

Node.js v24+ enforces node: prefix for ESM built-in imports, but vitest's jsdom environment cannot resolve them.

The working smoke.test.js already uses the correct pattern — default Node environment with manual JSDOM setup.

Fix

modal.test.js: Remove @vitest-environment jsdom, manually create JSDOM, use dom.window.eval() to execute the modal IIFE.

reveal.test.js & tabs.test.js: Keep @vitest-environment jsdom, inline the source logic directly to avoid file system imports.

 ✓ tests/tabs.test.js (7 tests)
 ✓ tests/smoke.test.js (13 tests)
