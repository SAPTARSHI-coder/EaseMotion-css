# Interactive Tooltip

1. **What does this do?**
   Provides a smoothly animated, interactive tooltip that appears on hover or focus with a subtle scale and translate effect.

2. **How is it used?**
   ```html
   <div class="tooltip-container">
     <button class="tooltip-trigger">Hover me</button>
     <div class="tooltip-content ease-tooltip-sap">
       This is an interactive tooltip.
     </div>
   </div>
   ```

3. **Why is it useful?**
   It aligns with EaseMotion's philosophy by adding a performant, fluid motion to an essential UI element, enhancing the user experience without overwhelming the interface.
