# Morphing Footer Component

## What does this do?
This is a responsive footer component that seamlessly morphs from a compact pill shape into an expanded rectangular card on hover, revealing hidden navigation links.

## How is it used?
```html
<div class="morphing-footer">
    <p>Hover over this footer</p>
    <div class="footer-content">
        <a href="#">About</a>
        <a href="#">Services</a>
        <a href="#">Contact</a>
    </div>
</div>
```

## Why is it useful?
It provides a space-saving and visually striking way to include footer content or navigation links, aligning with EaseMotion's focus on dynamic, fluid, and interactive user experiences without cluttering the initial layout.
