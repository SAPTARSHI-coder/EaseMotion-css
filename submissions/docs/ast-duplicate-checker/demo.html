CSS AST Duplicate Checker Proposal

Robust duplicate detection using PostCSS

This documentation proposes upgrading the repository's internal check-duplicates.mjs script from fragile Regular Expressions to a robust Abstract Syntax Tree (AST) parser using PostCSS.

Why AST parsing is better than Regex for CSS:

  • Context Awareness: Regex cannot easily distinguish between a duplicated class inside a media query vs outside of it.
  • Whitespace Agnostic: AST parses the structure, meaning .btn { color: red; } and .btn{color:red;} are correctly identified as duplicates.
  • Property Checking: AST can detect if two entirely different class names happen to contain the exact same CSS properties, enforcing DRY principles.
Note for Maintainers: Because the GSSoC submission bot prevents contributors from directly modifying the scripts/ directory in pull requests, the full implementation code for the new check-duplicates.mjs has been provided in the README.md of this submission directory. Maintainers can simply replace the existing script with the provided code.
