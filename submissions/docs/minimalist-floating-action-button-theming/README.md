# Documentation: Minimalist Floating Action Button Theming (#81640)

Comprehensive documentation guide covering HTML markup examples, modifier classes, custom CSS property overrides, and accessibility/keyboard navigation guidance for Minimalist Floating Action Buttons (`#81640`).

## 🚀 Overview & Features

- **Minimalist Aesthetic:** Clean circular geometry designed for primary action triggers without visual clutter.
- **Elevation & Depth:** Smooth shadow elevation changes on hover and active states.
- **Themable:** Fully customizable via local and global CSS variables.

## 📋 Copy-Paste HTML Markup

```html
<button class="em-fab-btn" type="button" aria-label="Create New Item">
  <span class="em-fab-icon" aria-hidden="true">+</span>
</button>
