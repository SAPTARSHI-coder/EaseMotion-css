Animated Button — Usage Guide

EaseMotion CSS ships a composable button system: a base ease-btn class combined with color, shape, and animation modifier classes. Every class name reads like plain English — no memorization required.

1. Base button

Every animated button starts with the base ease-btn class.

<button class="ease-btn">Default Button</button>

2. Color variants

Add ease-btn-primary for the accent-colored variant.

<button class="ease-btn ease-btn-primary">Primary Button</button>

3. Shape modifiers

Stack ease-btn-pill for fully rounded corners.

<button class="ease-btn ease-btn-primary ease-btn-pill">Pill Button</button>

4. Hover animations

Layer a hover-motion class to make the button react on hover.

<button class="ease-btn ease-btn-primary ease-hover-grow">Hover Grow</button>
<button class="ease-btn ease-btn-primary ease-hover-lift">Hover Lift</button>

5. Entrance animation

Add ease-fade-in (or ease-slide-up) so the button animates in on page load, optionally combined with a ease-delay-* class to stagger it after other elements. 

<button class="ease-btn ease-btn-primary ease-btn-pill ease-hover-grow ease-fade-in ease-delay-200">
  Get Started →
</button>
