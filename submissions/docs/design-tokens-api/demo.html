JS Design Tokens API

Bridging the gap between CSS and JS Frameworks

This documentation proposes exporting EaseMotion's highly curated design tokens (colors, spacing, shadows) as a JSON/JS API, drastically expanding compatibility with modern React/Next.js ecosystems.

Why export to JSON/JS?

  • CSS-in-JS Compatibility: Developers using Styled Components, Emotion, or Tailwind/Panda CSS can consume the exact same design tokens as the CSS framework, ensuring cross-platform consistency.
  • Zero Maintenance Cost: By using a build script to dynamically generate tokens.json from the existing variables.css, maintainers don't have to manually keep two systems in sync.
Note for Maintainers: Because the GSSoC submission bot prevents contributors from modifying build scripts in pull requests, the full Node.js token parser script has been provided in the README.md of this submission directory.
