# Engine Scroll-Scrub Keyframe Controller

## What does this do?
Enables frame-by-frame animation scrubbing linked directly to viewport scroll position using `em="scroll-scrub"`.

## How is it used?
```html
<div em="scroll-scrub spin duration-slow">Scrubbed Element</div>
```

## Why is it useful?
Provides 60fps scroll-driven motion scrubbing without requiring third-party scroll animation libraries.
