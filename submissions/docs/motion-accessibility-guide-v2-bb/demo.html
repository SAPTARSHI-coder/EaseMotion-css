Motion Accessibility Guide

Comprehensive engineering standards for implementing WCAG 2.1 compliant CSS motion, focus management, and reduced-motion media query handling.

1. Reduced Motion Media Query Handling

Users suffering from vestibular disorders rely on reduced motion preferences. EaseMotion CSS provides fallback rule declarations for all keyframe animations:

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}

2. Keyboard Focus Visibility

Ensure interactive elements feature distinct high-contrast outline focus rings without layout distortion:

.interactive-element:focus-visible {
  outline: 3px solid #38bdf8;
  outline-offset: 4px;
}

3. Hardware Acceleration & Will-Change

Target only compositor-safe properties (transform, opacity) to prevent unexpected screen flashing and excessive GPU power draw.
