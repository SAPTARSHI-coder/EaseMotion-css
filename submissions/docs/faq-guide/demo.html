EaseMotion CSS - FAQ Guide

Answers to common questions about installing and using EaseMotion CSS

1. Installation

You can install EaseMotion CSS using npm:

npm install easemotion-css

Or download the CSS file directly from the repository and include it in your project folder.

2. CDN Usage

If you prefer not to install the package, you can use a CDN link directly in your HTML file:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/easemotion-css/dist/easemotion.min.css">

This is the fastest way to try out EaseMotion CSS without any build tools.

3. Local Setup

To set up the project locally for development or contribution:

  1. Clone the repository using git clone
  2. Navigate into the project folder
  3. Install dependencies with npm install
  4. Open the demo HTML files in your browser to preview changes

4. Using Animation Classes

EaseMotion CSS provides ready-to-use classes that can be added directly to any HTML element:

<div class="fade-in">Hello World</div>

Simply add the desired class name to trigger the corresponding animation. No JavaScript is required.

5. Contribution Workflow

Contributions are welcome as part of GSSoC. To contribute:

  1. Fork the repository
  2. Create a new branch for your feature or fix
  3. Make your changes and commit with a clear message
  4. Push your branch and open a Pull Request
  5. Wait for review and address any requested changes
