# FAQ Guide - EaseMotion CSS

A simple, beginner-friendly Frequently Asked Questions (FAQ) page for the EaseMotion CSS library. This guide answers common questions new users and contributors have when getting started.

## 📚 Supported Topics

This FAQ guide covers the following topics:

1. **Installation** — how to install EaseMotion CSS via npm or direct download
2. **CDN Usage** — how to use the library directly via a CDN link
3. **Local Setup** — how to clone and run the project locally
4. **Using Animation Classes** — how to apply animation classes to HTML elements
5. **Contribution Workflow** — how to fork, branch, and submit a Pull Request
6. **Demo Examples** — simple code examples showing common usage patterns

## 📁 Files in This Folder

├── demo.html   # The FAQ page itself
├── style.css   # Styling for the FAQ page
└── README.md   # This file

## 🚀 How to Open demo.html

1. Make sure demo.html and style.css are in the same folder.
2. Open demo.html in any modern web browser (double-click the file, or right-click and choose "Open with" your browser).
3. Browse through each section to find answers to common questions.
