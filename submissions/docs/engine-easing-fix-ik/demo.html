Engine Bug Fix: ease-in-out Easing Curve

In easemotion/engine/parser.js, the ease-in-out key was mistakenly assigned cubic-bezier(0.4, 0, 0.2, 1) — identical to default ease. This fix maps ease-in-out to standard W3C cubic-bezier(0.42, 0, 0.58, 1).

❌ Buggy (Duplicate cubic-bezier)

cubic-bezier(0.4, 0, 0.2, 1)   [Identical to ease]

EASE
const EASING_MAP = { 'ease': 'cubic-bezier(0.4, 0, 0.2, 1)', 'ease-in-out': 'cubic-bezier(0.4, 0, 0.2, 1)', // BUG };

✅ Fixed (Standard Symmetric Curve)

cubic-bezier(0.42, 0, 0.58, 1)   [Symmetric ease-in-out]

EIO
const EASING_MAP = { 'ease': 'cubic-bezier(0.4, 0, 0.2, 1)', 'ease-in-out': 'cubic-bezier(0.42, 0, 0.58, 1)', // FIX };
