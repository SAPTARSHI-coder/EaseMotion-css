# Cubic-Bezier Easing Curves Guide

A visual & technical documentation guide on custom `cubic-bezier()` timing functions, spring acceleration vectors, and keyframe curve physics.

## What does this do?
Renders interactive curve comparison tracks comparing `cubic-bezier()` parameters like spring overshoots vs. snappy entrance curves with real-time motion previews.

## How is it used?
1. Open `demo.html` to visually compare different cubic-bezier velocity profiles.
2. Select appropriate cubic-bezier parameters for your UI transition classes.
3. Import `style.css` for curve visualization layouts.

## Why is it useful?
Choosing precise cubic-bezier easing parameters transforms standard linear transitions into organic, fluid micro-interactions while retaining 60fps performance.
