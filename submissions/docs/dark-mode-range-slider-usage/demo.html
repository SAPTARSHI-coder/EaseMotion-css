Dark Mode Range Slider — Basic Usage

The ease-range-slider component is a styled <input type="range"> designed for dark UIs by default, with an optional light-mode override. It works with keyboard, mouse, and touch out of the box, since it's built on the native range input.

1. Basic markup

Wrap a native range input in the required container structure.

Volume 50% 
<div class="ease-range-slider" style="--ease-range-value: 50%;">
  <div class="range-label-row">
    <span class="range-name">Volume</span>
    <span class="range-value">50%</span>
  </div>
  <input type="range" min="0" max="100" value="50" aria-label="Volume" />
</div>

2. Light mode override

Add ease-range-slider--light to switch to the light-mode palette.

Brightness 65% 
<div class="ease-range-slider ease-range-slider--light" style="--ease-range-value: 65%;">
  ...
</div>

3. Accent color modifiers

Stack a color modifier to change the fill/thumb accent.

Speed 30% 
<div class="ease-range-slider ease-range-slider--pink" style="--ease-range-value: 30%;">
  ...
</div>

4. Keeping the fill in sync (JavaScript)

CSS can't read the current slider value directly, so a small script updates --ease-range-value on input. This is the only JavaScript required — all animation and styling is CSS. 

document.querySelectorAll('.ease-range-slider').forEach((wrap) => {
  const input = wrap.querySelector('input[type=range]');
  const label = wrap.querySelector('.range-value');
  input.addEventListener('input', () => {
    wrap.style.setProperty('--ease-range-value', input.value + '%');
    label.textContent = input.value + '%';
  });
});

Accessibility & keyboard interaction

  • Built on a native <input type="range"> — no custom ARIA widget logic needed.
  • Arrow Left / Down — decrease value by one step
  • Arrow Right / Up — increase value by one step
  • Home — jump to minimum value
  • End — jump to maximum value
  • Page Up / Page Down — larger increment/decrement steps
  • Always include a descriptive aria-label (or a linked <label>) — the visual label text alone is not programmatically associated unless linked.
  • Respects prefers-reduced-motion by disabling the thumb hover/active scale transition.
