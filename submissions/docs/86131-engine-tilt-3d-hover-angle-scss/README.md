# Tilt 3D Hover Angle SCSS Animation Mixin Pattern

Adds the Tilt 3D Hover Angle animation pattern.

Keyframe:

`ease-tilt-3d-hover-angle`

Utility class:

`ease-anim-tilt-3d-hover-angle`

Supports configurable duration, timing, tilt angle and depth.

Uses transform and opacity for hardware-friendly animation and includes
a `prefers-reduced-motion` override.
