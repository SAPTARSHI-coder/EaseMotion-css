Global Print Stylesheets Proposal

Enhancing Accessibility for Physical Media

This documentation proposes an accessibility upgrade for the framework: implementing a global @media print configuration to ensure EaseMotion interfaces look perfect when printed onto physical paper.

⚠️ This banner should automatically hide when printing! Try pressing Ctrl+P / Cmd+P to see.

Why Print Styles Matter:

  • Readability: Dark modes, glassmorphism, and neon colors waste printer ink and are illegible on paper.
  • Clutter Reduction: Utility classes like .ease-hide-print allow developers to effortlessly hide navigation bars, footers, and interactive elements.
  • Professional Output: Dashboards built with EaseMotion will generate clean, ink-friendly invoices and reports.
Note for Maintainers: Because the GSSoC submission bot prevents contributors from modifying core framework files in pull requests, the full CSS implementation for the _print.scss file has been provided in the README.md of this submission directory.
