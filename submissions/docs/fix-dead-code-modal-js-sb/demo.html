Modal Dead Code Fix

Demonstrates the removal of unreachable code in core/modal.js

Modal Component

Click the button below to open a modal dialog.

The Bug

The original code had unreachable code at lines 28-30:

const modal = overlay.querySelector(".ease-modal");
if (modal) {
  if (!overlay.classList.contains("is-active")) {  // ALWAYS FALSE!
    previousFocusedElement = document.activeElement;
  }
  modal.setAttribute("tabindex", "-1");
  modal.focus();
}

The inner if check is always false because is-active was added on the line just before.

The Fix

Removed the unreachable code block:

const modal = overlay.querySelector(".ease-modal");
if (modal) {
  modal.setAttribute("tabindex", "-1");
  modal.focus();
}
