# 3D Toggle

A simple and responsive 3D toggle switch built using only HTML and CSS.

## Features

- Pure HTML and CSS
- No JavaScript required
- Smooth 3D toggle animation
- Responsive design
- Interactive press effect
- Easy to customize

## Usage

Include the HTML structure in your project:

```html
<label class="toggle">
  <input type="checkbox">
  <span class="slider">
    <span class="knob"></span>
  </span>
</label>
