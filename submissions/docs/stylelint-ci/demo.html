Stylelint CI — Submission

This submission proposes a Stylelint GitHub Actions workflow to run CSS linting in CI. It contains a candidate workflow file, a .stylelintignore, and documentation for maintainers to adopt.

What I am proposing

  • Provide a candidate workflow YAML (stylelint-workflow.yml) that maintainers can copy to .github/workflows/stylelint.yml.
  • Provide a .stylelintignore to exclude generated artifacts.
  • Do NOT duplicate or replace the repo's top-level .stylelintrc.json. This uses the existing config.
