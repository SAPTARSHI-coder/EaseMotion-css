# CSS Variables Customization Example

## Overview

This example demonstrates how to customize EaseMotion CSS using CSS custom properties (variables). By overriding the default variables, you can quickly change the appearance and behavior of components without modifying the core framework.

## Variables Demonstrated

| Variable | Purpose |
|----------|---------|
| `--ease-color-primary` | Primary theme color |
| `--ease-speed-fast` | Fast animation duration |
| `--ease-speed-medium` | Medium animation duration |
| `--ease-radius-md` | Medium border radius |
| `--ease-shadow-md` | Medium shadow |

## Files

- `demo.html` – Example page using customized variables.
- `style.css` – CSS variable overrides.

## How to Use

1. Open `demo.html` in a browser.
2. Edit the variables inside `style.css`.
3. Refresh the page to view the updated design.

## Benefits

- Easy theme customization
- No changes to framework source files
- Beginner-friendly example
