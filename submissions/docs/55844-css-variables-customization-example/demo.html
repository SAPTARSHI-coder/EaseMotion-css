Active CSS Override Declaration

Copy and paste this CSS snippet into your project stylesheet after importing easemotion.css: 

/* Custom EaseMotion CSS Token Overrides */
:root {
  --ease-color-primary: #06b6d4;
  --ease-speed-fast: 100ms;
  --ease-speed-medium: 250ms;
  --ease-radius-md: 16px;
  --ease-space-4: 1.25rem;
  --ease-space-6: 1.75rem;
  --ease-shadow-md: 0 10px 25px -5px rgba(6, 182, 212, 0.25);
}
