# Animated Card Component

A fully responsive, accessible, and performant pure CSS animated card component featuring smooth elevation lifts, gradient hover effects, and custom transition properties for the EaseMotion CSS library.

## 🚀 Features

- **Zero JavaScript Required:** Built using native CSS transition properties, hardware-accelerated transforms, and backdrop filters.
- **Elevation & Hover FX:** Refined vertical translation and glowing multi-layer drop shadows on hover.
- **Dark Mode Compatible & Accessible:** Built with proper landmark regions, semantic typography, and keyboard focus states.

## 🛠️ Usage Example

```html
<div class="em-card" role="region" aria-label="Animated Card Showcase" tabindex="0">
    <span class="em-card-badge">COMPONENTS</span>
    <h2 class="em-card-title">Animated Card</h2>
    <p class="em-card-desc">A high-performance card featuring smooth elevation and hover states.</p>
    <a href="#" class="em-card-btn" role="button">Explore</a>
</div>
