🖨️ Print-Friendly EaseMotion Animation Reset

Demonstrates the fix for infinite animations (such as .ease-spin and .ease-pulse) when printing or saving as PDF (Ctrl + P). In print preview, all keyframe animations, opacity fades, and transforms reset to clean, upright static elements.

⚙️
Spinner Animation
.ease-spin

On screen: Spins infinitely.
On print: Stops rotation cleanly upright (0deg).

💓
Pulse Animation
.ease-pulse

On screen: Pulses scale and opacity.
On print: Resets to opacity 1 & scale 1.

🚀
Bounce Animation
.ease-bounce

On screen: Bounces up & down.
On print: Renders static without vertical shift.

✨
Fade In Animation
.ease-fade-in

On screen: Fades in opacity.
On print: Ensures full opacity (1.0).
