Animation Duration Reference

A quick reference for choosing animation durations based on the type of interaction.

Duration Timing Best Used For Example
100ms Instant Micro-interactions and very small UI changes Button press feedback
150ms Very Fast Small hover and focus interactions Icon hover
200ms Fast Common interface transitions Button hover
300ms Moderate General UI animations Card entrance
500ms Slow Larger visual transitions Panel reveal
800ms Very Slow Decorative or dramatic animations Hero animation
1000ms+ Extended Large decorative motion Background effects

Usage Examples

Fast Interaction

Suitable for buttons, icons and small UI feedback.

animation-duration: 200ms;

Standard Transition

Suitable for cards, panels and common UI transitions.

animation-duration: 300ms;

Decorative Motion

Suitable for larger visual or decorative animations.

animation-duration: 800ms;

Use shorter durations for small interactions and longer durations for larger visual transitions.
