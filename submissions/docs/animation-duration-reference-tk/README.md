\# Animation Duration Reference



A visual reference table that helps developers choose appropriate animation durations for different UI interactions.



\## What does this do?



This documentation showcase provides a quick reference for common animation durations, ranging from fast micro-interactions to longer decorative animations.



\## How is it used?



Open `demo.html` directly in a browser to view the reference table and interactive examples.



Example:



```css

animation-duration: 300ms;
