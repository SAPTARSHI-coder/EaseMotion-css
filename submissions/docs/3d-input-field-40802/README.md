# 3D Input Field

### What does this do?
Provides a dynamic 3D-styled input field that pops out and shifts perspective when hovered or focused, adding depth and interactivity to forms.

### How is it used?
```html
<div class="input-wrapper">
    <input type="text" class="ease-3d-input" placeholder="Type something..." />
</div>
```

### Why is it useful?
It fits EaseMotion CSS's philosophy of highly interactive, fluid UI elements by utilizing simple CSS transforms and box-shadows to create a modern 3D depth effect, making forms more engaging without heavy JavaScript.
