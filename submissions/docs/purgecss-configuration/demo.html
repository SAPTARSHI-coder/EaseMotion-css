Production Optimization via PurgeCSS

Shipping only what you use.

This documentation proposes an official PurgeCSS configuration for EaseMotion, allowing users to strip thousands of unused utility classes from the final production bundle.

Why Provide Official Configuration?

  • Bundle Size: Utility frameworks ship with massive CSS files. PurgeCSS can reduce a 150KB CSS file down to 10KB.
  • Animation Safety: Dynamic classes (like .ease-fade-in-on-scroll added via Intersection Observers) are often accidentally deleted by bundlers. An official config ensures these are safely allowlisted.
Note for Maintainers: Because the GSSoC submission bot prevents contributors from modifying the root README.md, the full official PurgeCSS configuration block to be appended to the root documentation has been provided in the README.md of this submission directory.
