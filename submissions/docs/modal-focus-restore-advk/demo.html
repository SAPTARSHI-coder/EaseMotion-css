Modal Focus Restore

A modal must return focus to the control that opened it. If the opener is recorded every time the open-handler runs, a second run overwrites it with a node inside the dialog — and closing strands focus on a hidden element.

Focus is on the page.

Dialog

Press Esc or Close. Focus should land back on the opener button.

// guard the capture so re-entrant opens cannot clobber it
if (!overlay.classList.contains('is-active')) {
  previousFocusedElement = document.activeElement;
}
overlay.classList.add('is-active');
