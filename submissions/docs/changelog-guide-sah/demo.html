EaseMotion CHANGELOG Entry Guide

Standardizing release notes & contributor docs

Recommended Entry Format

- **[TYPE]** Short description of change (#PR_NUMBER by @username)

Live Examples:

  • FEAT Added horizontal card component variant (#56094 by @sahare77)
  • FIX Resolved Safari hover jump bug on card shadows (#56091 by @sahare77)
  • DOCS Documented flex and grid utility usage examples (#56089)
