# CHANGELOG Entry Format Guide

## What does this do?
Provides a standardized release note and CHANGELOG format guide to help contributors document their additions and bug fixes clearly.

## How is it used?
Contributors refer to this guide when creating PRs or updating release logs, using semantic tags like `[FEAT]`, `[FIX]`, and `[DOCS]`.
```html
<ul class="changelog-list">
  <li><span class="badge badge-feat">FEAT</span> Added component (#123)</li>
</ul>
```

## Why is it useful?
Maintains uniform documentation standards across EaseMotion CSS releases, enhancing visibility and traceability of contributor efforts as outlined in issue #56095.
