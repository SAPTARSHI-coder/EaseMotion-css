# Responsive Carousel

A clean and responsive carousel component built using pure HTML and CSS.

## ✨ Features

- Fully responsive
- Mobile, tablet, and desktop friendly
- Smooth horizontal scrolling
- Card-based layout
- Hover animation
- No JavaScript required
- Easy to customize
- Accessible image alt text
