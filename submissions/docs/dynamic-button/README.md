# Dynamic Button Component

A fully responsive, accessible, and performant pure CSS dynamic button component featuring smooth transition states, scaling hover effects, and custom focus outlines for the EaseMotion CSS library.

## 🚀 Features

- **Zero JavaScript Required:** Built using native CSS transition properties, hardware-accelerated transforms, and active states.
- **Dynamic Interaction:** Refined vertical scaling and glowing box-shadow expansion on hover and active click states.
- **Dark Mode Compatible & Accessible:** Built with proper semantic button elements (`<button>`), ARIA labels, and keyboard focus states.

## 🛠️ Usage Example

```html
<button class="em-btn em-dynamic-btn" role="button" aria-label="Dynamic Action">
    Dynamic Action
</button>
