Robust SCSS API Export

Empowering Developers with Variables, Maps, and Mixins

This documentation proposes an architectural upgrade to EaseMotion-css: officially exporting a structured SCSS API alongside the pre-compiled CSS bundle.

Developer Experience (DX) Benefits:

  • True Customization: Users can override the $ease-colors map before importing the framework, allowing deep theme integration without relying entirely on CSS variables.
  • Reusable Mixins: Developers can use @include ease-button-variant($color); to create custom buttons that perfectly match the framework's design language.
  • Responsive Helpers: Access to @include ease-mq('md') { ... } simplifies media queries across user projects.
Note for Maintainers: Because the GSSoC submission bot prevents contributors from modifying core structural files in pull requests, the full SCSS architectural proposal and the mixin source code have been provided in the README.md of this submission directory.
