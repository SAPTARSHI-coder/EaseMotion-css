Non-destructive Scroll Lock

Locking page scroll by writing body.style.overflow = 'hidden' and later clearing it with '' destroys whatever inline value the host page already had. Save and restore instead.

Current body inline overflow: —

let saved = null;

function lock() {
  saved = document.body.style.overflow;   // remember, may be '' or a real value
  document.body.style.overflow = 'hidden';
}

function unlock() {
  document.body.style.overflow = saved ?? '';
  saved = null;
}
