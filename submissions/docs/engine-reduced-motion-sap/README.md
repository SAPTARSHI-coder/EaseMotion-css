# Engine Prefers-Reduced-Motion Smart Alternative Generator

## What does this do?
Maps spatial motion keyframes to gentle opacity fade alternatives under `prefers-reduced-motion: reduce`.

## How is it used?
```html
<div em="bounce duration-slow">Accessible Motion Element</div>
```

## Why is it useful?
Ensures full WCAG 2.1 compliance by eliminating jarring motion triggers without causing instant visual popping.
