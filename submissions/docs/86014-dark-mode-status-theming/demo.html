Themeable Connection Status

CSS custom properties make the surface, text, border, and state colors easy to align with a product theme.

Theme tokens

Service health

Dark theme
ConnectedPrimary services are responding normally.
DegradedOne background service is responding slowly.
OfflineUpdates will resume after connectivity returns.

Customize the component

Override the component custom properties to change its theme without rewriting the markup.

.status-demo {
  --status-surface: #151b26;
  --status-text: #f5f7fb;
  --status-muted: #aeb8c8;
  --status-border: #2a3445;
}
