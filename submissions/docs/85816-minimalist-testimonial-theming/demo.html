A minimal quote card controlled through CSS custom properties for the surface, text, muted attribution, border, radius, and shadow.

Customer perspective

Override the component variables to adapt this card to a light, dark, branded, or editorial product theme without changing the markup.

Alex Morgan Product Designer

Theme tokens

  • --card-surface controls the card background.
  • --card-text controls primary text.
  • --card-muted controls attribution and supporting text.
  • --card-border controls the component border.
  • --card-radius controls the corner treatment.
  • --card-shadow controls visual depth.
