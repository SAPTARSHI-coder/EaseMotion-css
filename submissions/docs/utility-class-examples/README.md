# Utility Class Examples

## Description

This submission demonstrates practical examples of commonly used EaseMotion CSS utility classes.

## Included Examples

- Fade In
- Slide Up
- Zoom In
- Bounce

## Folder Structure

```
utility-class-examples/
├── demo.html
├── style.css
└── README.md
```

## How to Run

1. Clone the repository.
2. Navigate to this folder.
3. Open `demo.html` in your browser.

- Beginner-friendly examples
