Tabs MutationObserver — Memory Leak Fix

Fixes memory leak from accumulated event listeners when MutationObserver triggers multiple times.

Problem: Duplicate Event Listeners

Each time initializeTabs() is called:

// Bug: Event listeners added on every call
window.addEventListener('resize', updateTabIndicator);
document.addEventListener('change', handleTabChange);
// Result: 10 DOM changes = 10 sets of listeners!

Solution: Initialization Flag

// Fix: Prevent duplicate initialization
let tabsInitialized = false;

function initializeTabs() {
  if (tabsInitialized) return;
  tabsInitialized = true;
  
  window.addEventListener('resize', updateTabIndicator);
  document.addEventListener('change', handleTabChange);
}

Benefits

  • ✅ No memory leaks
  • ✅ Consistent performance
  • ✅ Single event handling
