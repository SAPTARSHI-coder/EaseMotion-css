Skeleton Shimmer Animation - Safari 14 Compatibility

Fixed Version (transform: translateX)

Works on Safari 14, Firefox ESR 102, and all modern browsers

CSS (Fixed) 
.skeleton-shimmer::before {
  transform: translateX(-100%);
  animation: shimmer 2s infinite linear;
}

@keyframes shimmer {
  0% {
    transform: translateX(-100%);
  }
  100% {
    transform: translateX(100%);
  }
}

What Was Broken

The original code used the translate property from CSS Transforms Level 2, which is not supported in Safari 14, iOS 14, or Firefox ESR 102. On these browsers, the shimmer overlay would freeze at its starting position.

Original (Broken) Code

.skeleton-shimmer::before {
  translate: -100% 0;  /* Unsupported in Safari 14, Firefox ESR 102 */
  animation: shimmer 2s infinite linear;
}

@keyframes shimmer {
  0% {
    translate: -100% 0;
  }
  100% {
    translate: 100% 0;
  }
}

Browser Support

Browser translate (broken) transform: translateX (fixed)
Safari 14 ❌ Not supported ✅ Supported
iOS 14 ❌ Not supported ✅ Supported
Firefox ESR 102 ❌ Not supported ✅ Supported
Chrome 104+ ✅ Supported ✅ Supported
Firefox 72+ ✅ Supported ✅ Supported
Safari 15.4+ ✅ Supported ✅ Supported

Impact

  • Skeleton loading animations appear frozen on older Safari and Firefox versions
  • Poor loading experience for users unable to update their browsers
  • Reduced accessibility for devices with limited update capabilities (iOS 14)

Testing Instructions

  1. Open this demo in Safari 14 (or earlier)
  2. Open this demo in Firefox ESR 102
  3. Verify that the shimmer animation plays smoothly in all browsers
  4. Compare with the old code to see the difference
