ease-tabs Memory Leak Fix

Demonstrates the fix for event listener accumulation in tabs.js

Fixed Tabs Component

The tabs component now properly handles event listeners without memory leaks.

Overview

This tab demonstrates the fixed tabs implementation. The memory leak has been resolved by:

  • Adding an `initialized` flag to prevent duplicate event listener registration
  • Using document-level event delegation instead of per-container listeners
  • Properly scoping the resize timeout handler

Details

The original code added event listeners every time initializeTabs() was called by the MutationObserver, causing memory leaks.

The fix ensures event listeners are only registered once, regardless of how many times the initialization runs.

Code Changes

// Before: Event listeners added on every MutationObserver callback
// After: Flag ensures listeners are only added once
var initialized = false;
if (!initialized) {
  initialized = true;
  window.addEventListener('resize', ...);
  document.addEventListener('change', ...);
}
