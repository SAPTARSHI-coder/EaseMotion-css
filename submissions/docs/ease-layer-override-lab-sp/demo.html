Layer guidance

      

        
Layer order

        
    
          
  • easemotion-base — tokens, resets (lowest)
    • 
          
  • easemotion-components — buttons, cards, tabs
    • 
          
  • easemotion-utilities — spacing, display (highest)
    • 
        

      

      

        
Correct override

        
    
          
  • Wrap theme CSS in @layer easemotion-components.
    • 
          
  • Load your stylesheet after EaseMotion CDN.
    • 
          
  • No !important required for component theming.
    • 
        

      

      

        
Common mistakes

        
    
          
  • Overrides in easemotion-base lose to components.
    • 
          
  • Same-layer CSS before CDN gets overwritten.
    • 
          
  • Plain unlayered CSS works but breaks predictable cascade.
