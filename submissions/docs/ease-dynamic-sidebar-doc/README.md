# Dynamic Sidebar (`ease-dynamic-sidebar-doc`)

**What does this do?**
This component provides a responsive, dynamic sidebar that collapses gracefully on smaller screens.

**How is it used?**
Use the `.ease-dynamic-sidebar-doc` wrapper around a `.sidebar` and `.content` area. 
```html
<div class="ease-dynamic-sidebar-doc">
    <nav class="sidebar">
        <ul>
            <li><a href="#">Home</a></li>
            <li><a href="#">About</a></li>
        </ul>
    </nav>
    <main class="content">Content goes here.</main>
</div>
```

**Why is it useful?**
It fits EaseMotion's philosophy by offering smooth, CSS-only transitions and a clean, utility-driven approach to responsive navigation layouts.
