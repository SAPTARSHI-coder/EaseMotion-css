EaseMotion CSS — Utility Class Examples

Live, working demos for ease-fade-in, ease-slide-up, ease-zoom-in, ease-bounce-in, ease-delay-* and ease-duration-* (issue #63963). Every card below can be replayed with its button.

1. Fade In Animation

ease-fade-in
Fade In
<div class="ease-fade-in">...</div>

2. Slide Up Animation

ease-slide-up
Slide Up
<div class="ease-slide-up">...</div>

3. Zoom In Animation

ease-zoom-in
Zoom In
<div class="ease-zoom-in">...</div>

4. Bounce Animation

ease-bounce-in
Bounce In
<div class="ease-bounce-in">...</div>

For a looping bounce (e.g. a "new" indicator) use ease-bounce instead of the one-shot entrance shown here.

5. Delay Utilities

ease-delay-100 / 300 / 500

Combine any entrance animation with a delay class to stagger a group of elements.

delay-100
delay-300
delay-500
<div class="ease-fade-in ease-delay-100">...</div>
<div class="ease-fade-in ease-delay-300">...</div>
<div class="ease-fade-in ease-delay-500">...</div>

6. Duration Utilities

ease-duration-fast / medium / slow

Override how long an animation takes without touching the keyframes themselves.

fast (150ms)
medium (300ms)
slow (600ms)
<div class="ease-slide-up ease-duration-fast">...</div>
<div class="ease-slide-up ease-duration-medium">...</div>
<div class="ease-slide-up ease-duration-slow">...</div>
