Motion Accessibility

Animations and transitions can improve user experience, but excessive motion may cause discomfort for some users. Websites should respect the user's reduced-motion preference.

Accessible Motion

Enable "Reduce Motion" in your operating system to see the reduced-motion alternative.

Recommended CSS Pattern

@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}

Accessibility Compliance Checklist

  • ✓ Respect prefers-reduced-motion
  • ✓ Avoid unnecessary large-scale movement
  • ✓ Avoid rapidly flashing animations
  • ✓ Provide non-motion alternatives where appropriate
  • ✓ Keep essential information available without animation
  • ✓ Test reduced-motion behavior before release
