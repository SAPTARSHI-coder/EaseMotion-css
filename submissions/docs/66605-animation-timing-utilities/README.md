# Animation Timing Utility Coverage

This submission provides a focused demonstration and documentation reference
for animation delay and duration utilities.

## Covered Utilities

### Delay

- `ease-delay-100`
- `ease-delay-200`
- `ease-delay-300`

### Duration

- `ease-duration-fast`
- `ease-duration-medium`
- `ease-duration-slow`

## Usage

Timing utilities can be combined with an animation class:

```html
<div class="ease-delay-200 ease-duration-medium">
  Animated content
</div>
