# Bouncing Spring Loader

A lightweight CSS-only loading indicator with a smooth bouncing spring effect.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript required
- Smooth spring-like bouncing motion
- Staggered animation between loader dots
- Dark-mode support
- Hardware-friendly transforms
- Reduced-motion support for accessibility
- Works by opening `demo.html` directly in a browser
