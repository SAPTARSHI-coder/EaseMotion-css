GitHub Actions Dependency Caching

Proposal for issue #63638 — not a runtime HTML/CSS feature, no end-user markup involved.

Confirmed gaps

Found via grep -l "actions/setup-node" .github/workflows/*.yml | xargs grep -L "cache:" plus manual review of ci.yml:

WorkflowJobStatus
ci.ymllintNo cache (inconsistent with test job)
ci.ymltestAlready cached
release-minified-css.ymlbuildNo cache
honeypot-sandbox.ymlsandboxNo cache

Proposed diff — ci.yml (lint job)

       - name: Setup Node.js
         if: steps.changed-files.outputs.any_changed == 'true'
         uses: actions/setup-node@v4
         with:
           node-version: 20
+          cache: 'npm'

Same one-line addition applies to release-minified-css.yml and honeypot-sandbox.yml's respective setup-node steps.

Mockup: workflow summary before/after

Before (no cache)

Installing dependencies...
⏱ npm ci: 34.2s

After (cached)

⏱ npm ci: 4.8s

Why this matters

Every workflow run currently installs dependencies from scratch, increasing build times and consuming unnecessary GitHub Actions minutes. Caching package manager dependencies can significantly speed up CI while reducing infrastructure usage — with a minimal, low-risk change.
