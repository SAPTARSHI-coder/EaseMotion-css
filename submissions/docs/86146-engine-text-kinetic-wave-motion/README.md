# Text Kinetic Wave Motion

Adds the Text Kinetic Wave Motion animation utility.

Keyframe:

`ease-text-kinetic-wave-motion`

Utility class:

`ease-anim-text-kinetic-wave-motion`

The preset supports configurable duration, timing, wave distance and
character stagger.

It uses transform and opacity for hardware-friendly animation and includes
a `prefers-reduced-motion` override.
