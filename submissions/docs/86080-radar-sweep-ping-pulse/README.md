# Radar Sweep Ping Pulse

## Overview

The **Radar Sweep Ping Pulse** utility provides a radar-inspired
motion effect combining a sweep and expanding pulse.

It is suitable for:

- Monitoring dashboards
- Network activity indicators
- Signal status interfaces
- Location markers
- Live system states
- Discovery interfaces
- Interactive data visualizations
