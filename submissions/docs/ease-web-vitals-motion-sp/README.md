# Core Web Vitals Impact of Animations Guide

1. What does this do? It demonstrates how heavy animation patterns can hurt Core Web Vitals metrics such as LCP, CLS, and INP, and contrasts them with safer EaseMotion-friendly alternatives.
2. How is it used? Open the demo in a browser and compare the heavy-motion panel with the optimized-motion panel. The reduced-motion toggle also shows how the experience changes when motion is minimized.
3. Why is it useful? It helps beginners understand that expressive motion should be used carefully in production, especially when aiming for fast, stable, and responsive interfaces that still feel polished.
