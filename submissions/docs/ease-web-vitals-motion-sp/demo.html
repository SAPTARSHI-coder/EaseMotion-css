LCP lesson

Hero content should appear early and stay stable

Heavy pattern

Long entrance timing, repeated bounce loops, and delayed content fades can push the hero past a user’s first meaningful perception window.

Safe pattern

Short, fade-based motion for the hero keeps the main content visible quickly and avoids unnecessary paint work.

CLS lesson

Avoid motion that changes layout after content is visible

Heavy pattern

New Card grows and reflows

Size and position changes create noticeable jumps.

Animating height, margins, or font size can cause layout shift as the viewport settles.

Safe pattern

New Card fades and lifts

Content stays in place while motion feels intentional.

Using transform and opacity keeps the layout stable and avoids reflow-driven CLS spikes.

INP lesson

Interaction feedback should be quick and predictable

Heavy pattern

Multi-step bounce, scale chain, and long delays can make even simple buttons feel sluggish.

Safe pattern

Short feedback and a single easing curve let the interface respond quickly without visual noise.

Production tips

Use safe motion patterns for real products

Prefer transform + opacity

These properties avoid layout thrashing and keep the browser’s compositor path efficient.

Limit looping motion

Use bounce, pulse, or ping sparingly. Repeated loops are more likely to distract and fatigue users.

Respect reduced motion

Provide a reduced-motion fallback so motion-sensitive users get a calmer interface.

Safe class combination

class="ease-fade-in ease-translate-y-sm ease-fast"
class="ease-hover-lift ease-hover-scale-sm"

Reduced motion fallback

@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}

Checklist

Use this before shipping

  • Keep the first viewport content visible quickly.
  • Limit long entrance delays on hero components.
  • Avoid animating height, width, or position when possible.
  • Keep interaction feedback under 200ms where practical.
  • Respect reduced motion preferences.
  • Prefer one motion cue over several simultaneous effects.
