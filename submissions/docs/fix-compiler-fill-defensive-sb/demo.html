Compiler Fill — Defensive Check Fix

Demonstrates the fix for ast.fill defensive check in compiler.js

Problem: Undefined in CSS Output

When ast.fill is undefined, the compiler produces invalid CSS:

animation: ease-kf-fade-in 300ms cubic-bezier(...) undefined;

Solution: Defensive Check

Add a check to only include fill mode when defined:

const fillStr = ast.fill ? ` ${ast.fill}` : "";
