Copy-ready workaround snippets

iOS Safari URL bar behavior & animation timing
  • 100vh on iOS includes the area behind the URL bar — then shrinks when it collapses.
  • 100dvh (dynamic viewport height) tracks the current visible viewport.
  • 100svh (small viewport height) uses the smallest possible viewport — safest for full-screen heroes.
  • Pair stable viewport units with ease-fade-in instead of animating height itself.
  • Test on a real iPhone — desktop DevTools cannot fully reproduce URL bar collapse.
  • Support: dvh/svh in Safari 15.4+, Chrome 108+, Firefox 101+.
