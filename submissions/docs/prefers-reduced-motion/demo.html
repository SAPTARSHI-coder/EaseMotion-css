Global Accessibility Update

Enforcing `prefers-reduced-motion` across the framework

For a CSS framework focused heavily on motion, accessibility is not optional. Users with vestibular disorders can experience nausea and dizziness from heavy UI animations.

The Proposal

We need to add a global CSS reset that forces all transitions and animations to resolve instantly when a user's operating system requests reduced motion.

Interactive Demo

If your OS settings have "Reduce Motion" enabled, the button below will snap instantly on hover. Otherwise, it will transition smoothly.
