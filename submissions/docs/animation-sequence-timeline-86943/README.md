# Animation Sequence / Timeline Support

## Overview

This example demonstrates how multiple animations can be organized into
a simple animation sequence or timeline.

The demo follows this sequence:

1. Fade in
2. Slide up
3. Scale
4. Fade out

Each step can have its own duration and delay.

## Features

- Sequential animations
- Configurable delays
- Multiple animation stages
- Restart support
- Sequence cancellation
- Completion status
- Self-contained browser demo
