# Responsive Glassmorphism Navbar Guide

A lightweight, pure CSS navigation bar featuring modern glassmorphism (frosted glass) visual effects, blur filters, and a responsive CSS-only hamburger menu.

## Highlights

- **Pure CSS Glassmorphism:** Uses `backdrop-filter: blur()` paired with semi-transparent rgba borders and backgrounds.
- **Zero JS Mobile Menu:** Utilizes the CSS "Checkbox Hack" (`#nav-toggle:checked`) to manage menu toggling cleanly on smaller screens.
- **Accessible & Responsive:** Adapts seamlessly from desktop row navigation to mobile stacked drawers.
