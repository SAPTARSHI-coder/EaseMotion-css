Get Started

1. HTML Markup Structure

Structure your navigation bar with standard semantic elements. Apply .morph-navbar to the <nav> container and .nav-link to navigation items.

2. CSS Customization Tokens

Customize the morphing transition duration, glass surface color, active indicator gradient, and glow radius through custom CSS properties defined in :root.

3. Accessibility & Motion Safety

Includes complete keyboard navigation focus rings and automatically respects user motion preferences via prefers-reduced-motion media queries.
