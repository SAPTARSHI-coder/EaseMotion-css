# Spotlight Beam Sweep Light

## Overview

The **Spotlight Beam Sweep Light** utility provides a reusable cinematic
light-beam sweep animation for modern interfaces.

It is suitable for:

- Hero sections
- Product cards
- Landing pages
- Dashboards
- Interactive cards
- Portfolio interfaces
- Highlight effects
