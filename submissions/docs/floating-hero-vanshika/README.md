# Floating Hero Section

A responsive hero section with floating information cards and smooth CSS motion.

## How is it used?

Use the `.floating-hero` container for the main section and add `.floating-card` elements for the floating content.

```html
<section class="floating-hero">
  <div class="hero-content">
    <span class="hero-badge">EaseMotion CSS</span>
    <h1>Build Beautiful Experiences</h1>
    <p>Create modern and engaging interfaces with smooth motion.</p>
    <a href="#" class="hero-button">Get Started</a>
  </div>

  <div class="floating-card">
    <strong>+42%</strong>
    <span>Growth</span>
  </div>
</section>
