EaseMotion IntelliSense Extension

Supercharging Developer Productivity in VS Code

This documentation proposes the creation of an official VS Code IntelliSense extension for the EaseMotion framework to rival the tooling of Tailwind CSS.

Key Features of the Extension:

  • Class Autocomplete: Start typing class="ease-" in HTML, Vue, or React, and instantly see a dropdown of available utility classes.
  • Hover Previews: Hovering over a class like .ease-card will display a popup showing the raw CSS output (e.g., box-shadow, padding, border-radius).
  • CSS Variable Autocomplete: When writing custom CSS, typing var(--ease- will autocomplete the framework's design tokens and show their color hex codes.
Note for Maintainers: Because the GSSoC submission bot prevents contributors from initializing new projects in the repository root, the full architectural blueprint and the `package.json` for the VS Code extension Language Server have been provided in the README.md of this submission directory.
