# Gradient Glow Chip Status Tag — Theming Configuration

A quickstart guide for using and theming the Gradient Glow Chip Status Tag.

The component provides a compact visual status indicator with gradient
backgrounds, configurable glow effects, status modifiers, size modifiers,
and CSS custom property overrides.

## Demo

Open `demo.html` in a browser to view the component and its available
theming examples.

## Basic Usage

```html
<span class="glow-chip glow-chip--success">
  <span class="glow-chip__dot" aria-hidden="true"></span>
  Success
</span>
