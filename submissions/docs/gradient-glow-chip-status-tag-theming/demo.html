Accessibility

  • Use semantic text to communicate the current status.
  • Decorative status dots use aria-hidden="true".
  • Interactive chips use a native button element.
  • Keyboard users can focus interactive chips with the Tab key.
  • The component respects prefers-reduced-motion.
