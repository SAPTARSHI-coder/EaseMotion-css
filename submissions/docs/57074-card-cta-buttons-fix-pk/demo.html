Bug Fix — Issue #57074

Cards CTA Buttons Fix

The Explore, Learn More, and Get Started buttons in the Cards section previously appeared clickable but did nothing. This fix converts them from inert <button> elements into working anchor links that smoothly scroll to relevant sections.

Setup

Installation

Link one stylesheet. No build steps, no dependencies, no configuration.

html 
<!-- CDN via jsDelivr (recommended) -->
<link rel="stylesheet"
  href="https://cdn.jsdelivr.net/gh/SAPTARSHI-coder/EaseMotion-css@main/easemotion.min.css" />
bash 
npm install easemotion-css

Components

Cards

Flexible card system. Below shows the fixed CTA buttons — each now navigates to its intended section.

🔧
What was fixed (Issue #57074): The three CTA buttons — Explore, Learn More, and Get Started — were <button> elements with no onclick, href, or any event attached. They now use <a> anchor elements that scroll smoothly to their target sections.
❌ Before (broken)
html 
<!-- Button does nothing when clicked -->
<button class="ease-btn ease-btn-primary ease-btn-sm">
  Explore
</button>

<button class="ease-btn ease-btn-success ease-btn-sm">
  Learn More
</button>

<button class="ease-btn ease-btn-danger ease-btn-sm">
  Get Started
</button>
✅ After (fixed)
html 
<!-- Anchor scrolls to #animations section -->
<a href="#animations-section"
   class="ease-btn ease-btn-primary ease-btn-sm">
  Explore
</a>

<!-- Anchor scrolls to #buttons section -->
<a href="#buttons-section"
   class="ease-btn ease-btn-success ease-btn-sm">
  Learn More
</a>

<!-- Anchor scrolls to #installation section -->
<a href="#installation-section"
   class="ease-btn ease-btn-danger ease-btn-sm">
  Get Started
</a>
// Fixed cards — click the buttons to verify
