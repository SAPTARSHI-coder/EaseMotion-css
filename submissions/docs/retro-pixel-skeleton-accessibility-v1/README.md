# Retro Pixel Skeleton – Accessibility Integration

A documentation example for using the Retro Pixel Skeleton loading component with accessible HTML, CSS custom properties, and reduced-motion support.

## Features

- Pixel-inspired skeleton loading UI
- Copy-paste HTML markup
- Semantic accessibility attributes
- Screen-reader loading status
- Custom CSS variables
- Responsive layout
- Keyboard-friendly implementation
- Reduced-motion support
