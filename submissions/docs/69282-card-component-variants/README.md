# Card Component Variants

This submission provides a visual demonstration of common EaseMotion card variants.

## Variants

- Default Card
- Shadow Card
- Glass Card
- Neumorphic Card
- Accent Card
- Hover Card

## Usage

Open `demo.html` directly in a browser.

The examples demonstrate the expected visual behavior of each card variant.

## Testing

Verify that:

- Default cards retain their basic styling.
- Shadow cards display the expected shadow.
- Glass cards retain their translucent appearance.
- Neumorphic cards retain their soft shadow effect.
- Accent cards retain their accent styling.
- Hover cards apply the expected hover transformation.

## Purpose

These examples provide a simple way to visually verify card variant behavior and help identify accidental styling regressions.
