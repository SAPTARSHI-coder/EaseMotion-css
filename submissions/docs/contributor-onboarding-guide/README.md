# 📚 Contributor Onboarding Guide

Welcome to **EaseMotion CSS**! This guide is designed to help first-time open-source contributors navigate the entire workflow—from finding an issue to getting your Pull Request merged.

---

## 🚀 Step-by-Step Onboarding Workflow

### 1. Finding & Claiming an Issue
- Browse the [Issues tab](https://github.com/SAPTARSHI-coder/EaseMotion-css/issues).
- Look for open issues with labels like `good first issue`, `help wanted`, or `GSSoC-26`.
- Comment `/claim` on the issue thread to get assigned. 
- *Note:* Do not start working until the bot assigns you! You have **24 hours** from assignment to submit a PR.

### 2. Forking & Cloning the Repository
1. Click the **Fork** button at the top-right of the repository page.
2. Clone your fork locally using terminal or open it directly on GitHub:

   cd EaseMotion-css
