📚 Contributor Onboarding Guide

Interactive summary of the onboarding workflow for EaseMotion CSS.

1

Find & Claim Issue

Find an unassigned issue and comment /claim.

2

Correct Folder Structure

Place files under submissions/docs/your-feature/ or submissions/examples/your-feature/.

3

Include Required Files

Ensure demo.html, style.css, and README.md are present.

4

Submit Pull Request

Open PR referencing your issue number (e.g., Fixes #67727).
