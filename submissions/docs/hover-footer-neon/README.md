# Hover Footer with Neon Styling

A modern and responsive footer component created using pure HTML and CSS.

The component uses glowing neon effects that appear when users hover over the navigation and social links.

## Features

- Responsive footer layout
- Neon glow hover effects
- Smooth CSS transitions
- Responsive design for mobile devices
- Semantic HTML structure
- No JavaScript required
- Easy to customize

## Technologies Used

- HTML5
- CSS3
