Customizable Class Prefix via $ease-prefix

Proposal for issue #65816 — avoids collisions with libraries like Elementor's .em- classes.

Default prefix

$ease-prefix: 'ease-' !default;

<div class="ease-fade-in"></div>

Custom prefix

$ease-prefix: 'motion-';

<div class="motion-fade-in"></div>

Compiled SCSS output comparison

/* Default */
.ease-fade-in {
  animation: ease-kf-fade-in 0.3s ease-out forwards;
}

/* With $ease-prefix: 'motion-' */
.motion-fade-in {
  animation: ease-kf-fade-in 0.3s ease-out forwards;
}
