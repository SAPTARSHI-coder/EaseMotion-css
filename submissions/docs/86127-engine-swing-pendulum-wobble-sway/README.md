# Swing Pendulum Wobble Sway

A reusable Swing Pendulum Wobble Sway keyframe animation utility.

Keyframe:

`ease-swing-pendulum-wobble-sway`

Class:

`ease-anim-swing-pendulum-wobble-sway`

The animation uses configurable duration, timing, angle, and distance
variables. It relies on transform and opacity for smooth motion and includes
a prefers-reduced-motion accessibility override.
