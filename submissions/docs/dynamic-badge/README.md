# Dynamic Badge Component

A fully responsive, accessible, and performant pure CSS dynamic badge component featuring glowing emerald neon effects, smooth scale transitions, and frosted glassmorphism card styling for the EaseMotion CSS library.

## 🚀 Features

- **Zero JavaScript Required:** Built entirely using native CSS transition properties, flexbox alignment, and glowing box-shadows.
- **Dynamic Glow State:** Smooth vertical lift and enhanced emerald aura on hover.
- **Dark Mode Compatible & Accessible:** Built with proper landmark regions (`role="region"`), keyboard focus states, and `prefers-reduced-motion` support.

## 🛠️ Usage Example

```html
<header class="em-badge-card" role="region" aria-label="Dynamic Badge Showcase" tabindex="0">
    <span class="em-card-badge">COMPONENTS</span>
    <h2 class="em-card-title">Dynamic Badge</h2>
    <p class="em-card-desc">A high-performance dynamic badge component.</p>
    <div class="em-badge-wrapper">
        <span class="em-dynamic-badge">LIVE STATUS</span>
    </div>
</header>
