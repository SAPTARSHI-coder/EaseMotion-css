# Header Logo Size Fix

Resolves #43263.

### What does this do?
Increases the font size of the `.ease-navbar-brand` class to make the header logo larger and more prominent.

### How is it used?
The fix applies automatically to any element using the `.ease-navbar-brand` class within an `.ease-navbar-glass`.

### Why is it useful?
Users reported that the default header logo was too small and difficult to notice. This fix improves visibility and hierarchy in the navbar.
