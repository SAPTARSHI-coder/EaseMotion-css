# Interactive Card

A modern and responsive Interactive Card component built using pure HTML and CSS.

## ✨ Features

- Responsive design
- Smooth hover animation
- Gradient border effect
- Modern dark card design
- Interactive button
- Keyboard focus support
- Reduced-motion support
- No JavaScript required
