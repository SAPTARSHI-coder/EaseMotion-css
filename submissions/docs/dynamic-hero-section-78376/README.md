# Dynamic Hero Section

What does this do?
This is a modern, dynamic hero section featuring smooth entrance animations, floating background blobs, and hover effects on buttons.

How is it used?
Include the provided HTML and CSS in your project. You can use the `ease-in-up` class on text elements to make them slide up smoothly, and `ease-hover-grow` on interactive elements like buttons to make them scale up slightly on hover.

```html
<div class="hero-container">
  <div class="hero-content">
    <h1 class="hero-title ease-in-up">Welcome to EaseMotion</h1>
    <p class="hero-subtitle ease-in-up">Experience smooth and dynamic web animations with our simple CSS framework.</p>
    <div class="hero-buttons ease-in-up">
      <button class="hero-btn primary ease-hover-grow">Get Started</button>
      <button class="hero-btn secondary ease-hover-grow">Learn More</button>
    </div>
  </div>
  ...
</div>
```

Why is it useful?
It provides a visually striking first impression for any landing page, demonstrating how EaseMotion's philosophy of combining smooth micro-interactions (like hover effects) with larger entrance animations can create an engaging user experience without complex JavaScript.
