# Live Docs for Grid and Flex Utilities (`#56089`)

## What does this do?
Provides practical, interactive layout demos illustrating the syntax and responsiveness of `ease-flex` and `ease-grid` utilities.

## How is it used?
Copy the utility combinations directly to create responsive flex containers and uniform grids:
```html
<div class="ease-flex ease-flex-center">
  <div>Aligned Flex Item</div>
</div>
<div class="ease-grid ease-grid-3">
  <div>Three-column Grid Item</div>
</div>
```

## Why is it useful?
Resolves issue #56089 by plugging a documentation gap with a self-contained testbed showing real-time responsive collapsing on mobile devices.
