# Hover Hero Section Documentation

This documentation demonstrates how to use the **Hover Hero Section** component for landing pages and promotional websites.

## Features

- Pure HTML & CSS
- Responsive layout
- Hover elevation effect
- Animated gradient background
- CTA button
- Easy customization

## Folder Structure

```
submissions/docs/hover-hero-section/
├── demo.html
├── style.css
└── README.md
```

## Usage

```html
<link rel="stylesheet" href="style.css">
```

```html
<section class="hero">
    <div class="hero-content">
        <h1>Hover Hero Section</h1>
        <p>Your hero content...</p>
        <a href="#" class="btn">Explore</a>
    </div>
</section>
```

Open `demo.html` directly in your browser.

## Customization

- Change gradient colors
- Modify button style
- Adjust hover animation
- Edit spacing and typography
