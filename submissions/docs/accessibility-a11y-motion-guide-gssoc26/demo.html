WCAG 2.1 AAA

Accessible Motion & Reduced Motion Guide

Designing inclusive animations that respect user preferences and vestibular needs.

1. Prefers-Reduced-Motion

Always respect `@media (prefers-reduced-motion: reduce)` media query overrides.

2. Avoid Flashing Mechanics

Ensure flashing animations do not exceed 3 flashes per second threshold.

3. ARIA Motion States

Pair CSS keyframe animations with `aria-live` and `aria-expanded` attributes.

@media (prefers-reduced-motion: reduce) {
  *, ::before, ::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
