# Accessibility & Reduced Motion Best Practices Guide

An accessibility-focused documentation guide on implementing inclusive CSS animations, `@media (prefers-reduced-motion)` overrides, and WCAG motion compliance.

## What does this do?
Provides documentation guidelines and code patterns for supporting vestibular-sensitive users, reducing motion triggers, and maintaining WCAG 2.1 compliance.

## How is it used?
1. Open `demo.html` to review accessibility principles and CSS media query overrides.
2. Incorporate the reduced-motion media query block into your global CSS reset file.
3. Import `style.css` for card grid layouts and syntax styling.

## Why is it useful?
Ensures motion UI libraries remain accessible to all users. Respecting user system preferences is critical for enterprise production web apps.
