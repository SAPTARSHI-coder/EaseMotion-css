# Hover Sidebar

A responsive sidebar that expands smoothly when the user hovers over it.

## Features

- Pure HTML and CSS
- Smooth hover expansion
- Responsive design
- No JavaScript required
- Simple navigation layout

## Files

- `index.html` – Sidebar structure
- `style.css` – Sidebar styling and animations

## Usage

1. Open `index.html` in a browser.
2. Move the cursor over the sidebar.
3. The sidebar expands automatically.
4. Move the cursor away to collapse it.

## Technologies

- HTML5
- CSS3
