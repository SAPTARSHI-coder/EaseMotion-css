Issue #61569 — Expand prefers-reduced-motion support

components/loaders.css defines four animated loader variants (.ease-loader-spin, .ease-loader-pulse, .ease-loader-ping, .ease-loader-dot) but has no prefers-reduced-motion override today, unlike components/ease-marquee.css which already handles it.

To verify: enable "Reduce motion" in your OS accessibility settings (or emulate prefers-reduced-motion: reduce in DevTools' Rendering tab) and reload — all three loaders above should stop animating instead of running indefinitely.

Scope note: components/ease-marquee.css already covers reduced-motion (no change needed there). No central typewriter component file exists — typewriter implementations only live inside individual submissions/ folders, so they're out of scope for a components/ fix. This demo does not cover scroll-gallery.css, since it defines no @keyframes at all — only native scroll-snap behavior.
