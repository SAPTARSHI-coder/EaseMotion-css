# Animation Timing Comparison

## Overview

This documentation demonstrates how different EaseMotion CSS animation duration and delay utilities affect animations.

## Features

- Compare fast, medium, and slow animation durations.
- Compare different animation delays.
- Beginner-friendly visual examples.
- Uses only EaseMotion CSS classes.

## Files

- `demo.html` – Live animation comparison.
- `style.css` – Custom styling for the demo.

## Purpose

This example helps developers understand how animation timing changes the appearance and feel of UI animations.
