Dark Mode Connection Status Bar

A compact status pattern for communicating whether a service is online, reconnecting, or unavailable.

ConnectedAll services are operational.
ReconnectingTrying to restore the network connection.
OfflineChanges will sync when you reconnect.

Quickstart guidance

  1. Choose a status modifier such as status-bar--online.
  2. Keep the status message concise and meaningful.
  3. Use a native button for optional actions.
  4. Keep color as a visual enhancement, not the only status signal.
