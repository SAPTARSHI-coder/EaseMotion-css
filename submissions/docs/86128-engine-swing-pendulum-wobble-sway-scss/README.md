# Swing Pendulum Wobble Sway SCSS Animation Mixin Pattern

A reusable Swing Pendulum Wobble Sway animation pattern.

Keyframe:

`ease-swing-pendulum-wobble-sway`

Class:

`ease-anim-swing-pendulum-wobble-sway`

The pattern provides configurable duration, timing, angle and distance
variables. It uses transform and opacity for efficient animation and
supports prefers-reduced-motion.
