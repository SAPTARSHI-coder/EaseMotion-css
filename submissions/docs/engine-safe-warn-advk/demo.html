Why the optional chain is not enough

// throws ReferenceError in a browser: `process` was never declared
if (process?.env?.NODE_ENV !== 'production') { /* ... */ }

// safe: typeof never throws on an undeclared identifier
const isDev =
  typeof process !== 'undefined' && process.env
    ? process.env.NODE_ENV !== 'production'
    : true;

Optional chaining short-circuits on null and undefined values. It does not protect against an identifier that was never declared in scope — only typeof does.
