ease-dialog — Focus Outline Clip Fix (#59752)

Before / Bug context

Tab into the element below. Its parent has overflow: hidden, which previously clipped the default outline-based focus ring.

How the fix works

The focus ring now uses an inset box-shadow instead of an outward outline. Because it paints inside the element's own border box, it can never be cut off by an ancestor's overflow: hidden or overflow: auto.
