# Interactive 3D Book Cover Reveal

A beginner-friendly hover animation that makes a book cover rotate open in 3D and reveal its inner pages.

## Features
- Pure HTML and CSS
- 3D perspective with `transform-style: preserve-3d`
- Smooth `rotateY()` transition on hover
- Soft shadow and depth for a realistic book effect

## Files
- `demo.html` – structure for the book cover and content
- `style.css` – animation, layout, and 3D styling
- `README.md` – project overview and usage notes

## How to run
1. Open `demo.html` in your browser.
2. Hover over the book cover to see it open.

## CSS concepts used
- `perspective`
- `transform-style: preserve-3d`
- `transform-origin: left`
- `rotateY()`
- `transition`
- `box-shadow`

## Beginner tip
Start by changing the book title, author name, and content text inside `demo.html` to make the example your own.
