Beginner Troubleshooting Guide

New to EaseMotion CSS? If something is not working as expected, try these simple checks before looking for advanced solutions.

1. My animation is not showing

What you see

You added an EaseMotion animation class, but the element looks completely normal.

What to check

  • Make sure the EaseMotion CSS file is loaded.
  • Check that the animation class is spelled correctly.
  • Make sure the class is added to the correct element.
<div class="ease-fade-in">
    Hello!
</div>

2. My CSS changes are not appearing

What you see

You changed your HTML or CSS, but the browser still shows the old result.

Try this

  • Save your files.
  • Refresh the page.
  • Try a hard refresh if the old result remains.
  • Check that you are editing the correct file.

3. My custom CSS is overriding the animation

What you see

The EaseMotion class is present, but the animation looks different or does not behave as expected.

What to check

Your own CSS may be overriding an EaseMotion rule. Temporarily remove custom animation or transform rules to check whether the EaseMotion animation works normally.

4. The animation works on one page but not another

What to check

  • Make sure EaseMotion CSS is loaded on that page.
  • Check that the animation class is applied correctly.
  • If using a framework, check that the stylesheet is imported correctly.

5. Scroll reveal is not working

What you see

An element using a scroll-reveal effect does not animate when you scroll.

What to check

Scroll-based effects may require the appropriate EaseMotion reveal script in addition to the CSS. Check the documentation for the required reveal setup.

6. Animations are not moving on my device

What you see

Animations appear reduced or do not play.

What to check

Your device or browser may have a reduced-motion setting enabled. Check your accessibility settings if you cannot see an animation.

7. I am using React or another framework

What to check

  • Make sure the EaseMotion stylesheet is imported.
  • Make sure the animation class is applied to the correct element.
  • Use the framework's correct syntax for HTML classes.
<div class="ease-fade-in">
    Hello!
</div>

For example, React uses className instead of class.

Quick Checklist

  • EaseMotion CSS file is loaded
  • Animation class is spelled correctly
  • Class is applied to the correct element
  • Custom CSS is not overriding the animation
  • Files are saved and the page is refreshed
  • Required JavaScript is included when needed
  • Reduced motion is not hiding the animation
  • Framework stylesheet is imported correctly

Still Having Trouble?

If these checks do not solve the problem, check the detailed EaseMotion documentation and existing troubleshooting resources for more advanced cases.
