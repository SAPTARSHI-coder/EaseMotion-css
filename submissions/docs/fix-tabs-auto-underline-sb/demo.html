Tabs Auto Width Underline Fix

Fixes the CSS specificity issue where .ease-tabs-auto underline wasn't hidden

The Bug

The ease-tabs-auto variant's underline wasn't hidden due to CSS specificity conflict.

The transform rules had higher specificity and were overriding display: none.

The Fix

Increased specificity and added !important:

/* Before: */
.ease-tabs-auto .ease-tab-underline {
  display: none;
}

/* After: */
.ease-tabs-auto .ease-tabs-nav .ease-tab-underline {
  display: none !important;
}
