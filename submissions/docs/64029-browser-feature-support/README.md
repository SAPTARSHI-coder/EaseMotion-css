# Browser Feature Support Reference

## Overview

This documentation provides a quick reference for browser support of CSS features commonly used with EaseMotion CSS.

## Included Features

- CSS Grid
- Flexbox
- CSS Variables
- backdrop-filter
- aspect-ratio
- @layer
- prefers-reduced-motion

## Why This Matters

A feature-based compatibility table helps developers understand which CSS capabilities are widely supported before using them in production.

## Files

- `demo.html` – Browser compatibility reference table.
- `style.css` – Styling for the documentation page.
- `README.md` – Project explanation.

## Usage

Open `demo.html` in any modern browser.

No build tools or installation required.

## Benefits

- Easier browser compatibility reference.
- Faster development decisions.
- Better documentation for beginners.
- Improves EaseMotion CSS learning experience.
