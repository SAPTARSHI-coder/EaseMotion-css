# Underline Expand Center Draw

Adds the Underline Expand Center Draw animation preset.

Keyframe:

`ease-underline-expand-center-draw`

Utility class:

`ease-anim-underline-expand-center-draw`

Supports configurable duration, timing, width, height and color.

Uses transform and opacity for smooth hardware-friendly animation and
supports `prefers-reduced-motion`.
