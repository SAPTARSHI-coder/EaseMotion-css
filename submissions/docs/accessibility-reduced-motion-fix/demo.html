Test Instructions

To test reduced motion support:

  1. Open your system accessibility settings
  2. Enable "Reduce motion" or "Prefers reduced motion"
  3. Return to this page
  4. All animations above should be disabled!

Or add this CSS temporarily:
* { animation: none !important; transition: none !important; }

What's Covered

  • All ease-* animation classes
  • All ease-kf-* keyframe animations
  • Marquee and ticker animations
  • Typewriter and cursor blink
  • Loading spinners
  • Hover-triggered animations
  • Scroll-triggered animations
  • Modal/dialog transitions
  • Focus states remain visible (accessibility!)
