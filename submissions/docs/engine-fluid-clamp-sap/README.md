# Engine Fluid Clamp Typography DSL Token

## What does this do?
Enables fluid responsive typography using `em="fluid-text(min, preferred, max)"` syntax in the EaseMotion DSL.

## How is it used?
```html
<h1 em="fluid-text(1.2rem, 3.5vw, 3rem) slide-up">Fluid Responsive Title</h1>
```

## Why is it useful?
Eliminates manual CSS clamp rules and breakpoint media queries for fluid typography scaling across mobile, tablet, and desktop screens.
