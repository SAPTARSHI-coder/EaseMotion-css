# Animated Modal - Retro Styling

A responsive retro-inspired animated modal created using only HTML and CSS.

## Features

- Retro-inspired UI
- Smooth modal opening animation
- Pure HTML and CSS
- No JavaScript required
- Responsive on mobile and desktop
- Accessible navigation labels
- Uses CSS `:target` for modal control
- Reduced-motion support
