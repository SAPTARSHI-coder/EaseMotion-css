# Glowing Cyberpunk Sidebar

A documentation example demonstrating a futuristic sidebar with glowing cyberpunk styling.

## Features

- Neon glow appearance
- Responsive sidebar layout
- Smooth hover transitions
- Pure HTML & CSS
- No JavaScript

## Files

- `demo.html` – component preview
- `style.css` – styling
- `README.md` – documentation

## Preview

Open `demo.html` in any modern browser.

## Customization

Change the glow color:

```css
.sidebar{
    border-color:#00e5ff;
}

.sidebar a:hover{
    color:#00e5ff;
}
```

You can also customize:

- Background colors
- Typography
- Border radius
- Sidebar width
- Glow intensity
