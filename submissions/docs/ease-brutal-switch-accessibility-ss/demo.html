Accessibility Guide

Segmented Switch: Accessibility Setup

Correctly wired ARIA radiogroup semantics, roving tabindex, and keyboard support. Try it with Tab, Space, Enter, and the Arrow keys.

1. Correct Setup (Reference)

Use the Left and Right arrow keys to change the selected billing cycle.

Exactly one segment starts with is-active, aria-checked="true", and tabindex="0". Every other segment starts with aria-checked="false" and tabindex="-1".

2. Vertical Layout (Same Semantics)

.ease-switch-vertical only changes visual layout. Roving tabindex and Arrow Key behavior are identical to the horizontal switch above — Up/Down work the same as Left/Right.

Tab moves focus to the active segment only. Left/Right (or Up/Down in the vertical example) move selection and focus together. Space/Enter on a focused segment also selects it, via the native <button> click behavior.
