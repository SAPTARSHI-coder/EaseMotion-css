# Beginner's Getting Started Checklist

This guide helps first-time users quickly set up EaseMotion CSS and verify that everything is working correctly.

---

## ✅ Step 1: Install EaseMotion CSS

Choose one installation method:

- CDN
- npm

---

## ✅ Step 2: Import the Stylesheet

Import the CSS file into your project.

### CDN

```html
<link rel="stylesheet" href="https://cdn.example.com/easemotion.min.css">
```

### npm

```bash
npm install easemotion-css
```

```javascript
import "easemotion-css";
```

---

## ✅ Step 3: Add Your First Animation

Apply an animation class to an element.

```html
<button class="ease-fade-in">
  Click Me
</button>
```

---

## ✅ Step 4: Test Your Installation

Open your project in the browser and verify that the animation is working correctly.

---

## ✅ Step 5: Explore Components

Try different animation classes, hover effects, and utilities provided by EaseMotion CSS.

---

## ✅ Step 6: Read the Customization Guide

Learn how to customize animation duration, delay, and easing options.

---

## ✅ Step 7: Check Browser Compatibility

Test your project in Chrome, Firefox, and Edge to ensure consistent behavior.

---
