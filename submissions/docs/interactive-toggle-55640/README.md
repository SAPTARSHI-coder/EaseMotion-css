# Interactive Toggle

What does this do?
This is a smooth, interactive toggle switch component for turning settings on and off.

How is it used?
```html
<label class="interactive-toggle-label">
    <input type="checkbox" class="interactive-toggle-input">
    <span class="interactive-toggle-switch"></span>
    <span class="interactive-toggle-text">Toggle Me</span>
</label>
```

Why is it useful?
It provides a modern, accessible, and easily customizable toggle switch that seamlessly integrates with EaseMotion's fluid animation philosophy.
