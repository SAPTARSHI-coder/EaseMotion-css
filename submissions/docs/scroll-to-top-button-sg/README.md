# Scroll To Top Button

1. What does this do?
   This adds a floating button that appears after the page is scrolled a bit and smoothly returns the user to the top.

2. How is it used?
   Open the demo in a browser and scroll down. The button appears automatically and can be clicked to return to the top.

3. Why is it useful?
   It improves navigation on long pages and fits EaseMotion CSS by pairing a simple interaction with smooth motion.
