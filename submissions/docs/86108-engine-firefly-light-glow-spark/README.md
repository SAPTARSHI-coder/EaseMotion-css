# Firefly Light Glow Spark

## Overview

The **Firefly Light Glow Spark** animation creates a soft,
intermittent glowing effect inspired by a firefly's natural light.

The animation smoothly varies the element's opacity and scale while
using small compositor-friendly translations to create a subtle
floating spark appearance.
