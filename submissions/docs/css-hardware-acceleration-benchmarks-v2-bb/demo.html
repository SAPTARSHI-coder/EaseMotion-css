GPU Hardware Acceleration

Technical reference documentation and performance benchmark guidelines for eliminating layout thrashing and achieving 60FPS rendering in CSS motion systems.

1. Compositor-Only vs Triggering Layout Properties

Animating non-composite properties (such as width, height, margin, or top) forces synchronous layout recalculation and repaint cycles. EaseMotion components strictly enforce compositor-only properties:

Property Category Properties Layout / Reflow Paint Compositor 60FPS
Compositor Safe transform, opacity ❌ No ❌ No ✅ 60 FPS GPU
Paint Triggering background-color, box-shadow ❌ No ⚠️ Yes ⚠️ 30-45 FPS
Layout Thrashing width, height, margin, padding ⚠️ Heavy Reflow ⚠️ Heavy Repaint ❌ < 30 FPS CPU

2. Layer Promotion via will-change

Optimize layer creation on targeted elements to prevent over-promotion memory leaks:

.high-performance-card {
  will-change: transform, opacity;
  transform: translateZ(0);
}
