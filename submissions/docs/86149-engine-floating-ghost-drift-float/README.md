# Floating Ghost Drift Float

Adds the Floating Ghost Drift Float animation preset.

Keyframe:

`ease-floating-ghost-drift-float`

Utility class:

`ease-anim-floating-ghost-drift-float`

Supports configurable duration, timing, floating distance and rotation.

Uses transform and opacity for smooth hardware-friendly animation and
supports `prefers-reduced-motion`.
