# 3D Dropdown

**What does this do?**
This adds a smooth 3D flipping animation effect for a dropdown menu on hover.

**How is it used?**
Use the `.dropdown-container` on the wrapper, and `.dropdown-menu` on the list. The CSS handles the 3D rotation (`rotateX`) originating from the top.

```html
<div class="dropdown-container">
  <button class="dropdown-button">Hover Me</button>
  <div class="dropdown-menu">
    <a href="#" class="dropdown-item">Action</a>
    <a href="#" class="dropdown-item">Another Action</a>
  </div>
</div>
```

**Why is it useful?**
It adds a modern and engaging 3D interaction to standard dropdowns, perfectly aligning with EaseMotion CSS's goal of fluid and beautiful micro-interactions.
