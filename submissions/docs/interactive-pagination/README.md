# Interactive Pagination

A simple, responsive, and reusable pagination component built with pure HTML and CSS.

## Features

- Responsive design
- Clean and minimal UI
- Active page state
- Previous and next buttons
- Hover animations
- Keyboard focus support
- No JavaScript required
- Easy to customize

## Technologies Used

- HTML5
- CSS3
