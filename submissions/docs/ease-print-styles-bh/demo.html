Press Ctrl+P (Windows) or Cmd+P (Mac) to open print preview.

Notice how navigation and decorative elements are hidden, while content remains readable!

⚠️ This section won't print

Elements with .ease-no-print class are hidden when printing.

Article Title

This is a sample article demonstrating how EaseMotion CSS components appear when printed. The dark background and shadows are removed, making the content more ink-friendly.

Feature Screen Print

Notice how this table is properly formatted for print with borders visible.

Buttons (Hidden when printing)

Interactive elements like buttons should not appear in print.

Code Example

/* Use ease-no-print to hide elements */
.ease-no-print {
  display: none;
}

/* Use ease-print-only to show elements */
.ease-print-only {
  display: none;
}

@media print {
  .ease-print-only {
    display: block !important;
  }
}
