# ease-gradient-border

Animated gradient border effect using pure CSS.

## Features

- Smooth color transitions
- Customizable animation duration
- Multiple gradient presets
- Responsive sizing
- Reduced motion support

## Usage

```html
<link rel="stylesheet" href="style.css">
<div class="ease-gradient-border">Content</div>
```

## Classes

- `.ease-gradient-border` - Basic animated gradient border
- `.ease-gradient-border-slow` - Slower animation (5s)
- `.ease-gradient-border-fast` - Faster animation (1.5s)
- `.ease-gradient-border-rainbow` - Rainbow gradient effect

## Browser Support

Works in all modern browsers. Uses CSS mask and mask-composite properties.
