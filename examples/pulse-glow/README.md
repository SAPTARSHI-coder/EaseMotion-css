# ease-pulse-glow

Pulsing glow effect for UI elements using pure CSS.

## Features

- Smooth pulsing glow animations
- Multiple color variants
- Customizable intensity
- Reduced motion support

## Usage

```html
<link rel="stylesheet" href="style.css">
<div class="ease-pulse-glow">Pulsing Element</div>
```

## Classes

- `.ease-pulse-glow` - Basic pulsing glow
- `.ease-pulse-glow-primary` - Primary color glow
- `.ease-pulse-glow-success` - Success/green glow
- `.ease-pulse-glow-warning` - Warning/orange glow
- `.ease-pulse-glow-danger` - Danger/red glow
