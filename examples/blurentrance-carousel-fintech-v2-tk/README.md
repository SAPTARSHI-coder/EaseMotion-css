# Blur-Entrance Carousel (Fintech Dashboard)

## Overview

A modern fintech dashboard carousel featuring a smooth blur-entrance animation. Cards transition from a blurred, transparent state into sharp focus, highlighting key financial insights with a clean glassmorphism interface.

---

## Features

- Blur-entrance animation
- Glassmorphism card design
- Featured center card
- Responsive carousel layout
- Animated pagination indicators
- Pure HTML & CSS
- Supports `prefers-reduced-motion`
